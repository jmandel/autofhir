AutoFHIR Review App

The active review UI is generated from a run by scripts/export-issue-fixup-diff-viewer.ts. This page is a stable Pages entry point for the AutoFHIR repository; generated run-specific review artifacts are intentionally not committed to main.

Generate a local standalone review app with:

bun autofhir/scripts/export-issue-fixup-diff-viewer.ts --run-id <run-id>
