# Review App Source

The current production review UI is generated by `scripts/export-issue-fixup-diff-viewer.ts`. This directory is a stable GitHub Pages entry point for future extracted app assets and for documenting where review artifacts should be published.

Generated review reports should still be produced from a live run with:

```bash
bun autofhir/scripts/export-issue-fixup-diff-viewer.ts --run-id <run-id>
```
