FHIR-11315 was a Published FHIR-core Sequence change request, resolved Not Persuasive with Modification for DSTU2, asking whether Sequence.pointer represented complex variants and phase, with the accepted clarification to add a complex-variant example using CIGAR and to note that sequence.pointer linked relative sequences for genome graph use.

Initial application:
The issue appears to have been applied by git commit c45e176bae, which explicitly mentioned #11315 and added source/sequence/sequence-complex-variant.xml with a CIGAR-bearing variant plus example registration in the legacy Sequence spreadsheet.

Additional context:
The legacy Sequence artifact is not part of the current build. source/fhir.ini comments out molecularsequence as a resource and uses moleculardefinition for CG, diagnostics-module.html says MolecularSequence has been replaced by MolecularDefinition, and later Published CG decisions FHIR-37413 and FHIR-37414 removed MolecularSequence.pointer and MolecularSequence.relative.edit.cigar before the remaining MolecularSequence references were removed in 2025. Current MolecularDefinition source instead models complex sequence differences with relative edit operations and examples, without restoring the retired pointer or CIGAR fields.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-11315; any future changes to molecular variation examples should be handled as new CG/MolecularDefinition work rather than resurrecting the retired Sequence.pointer mechanism.
