FHIR-16139: Audit reference range normal definition

Issue request:
FHIR-16139 was an OO Published/Persuasive STU3-era FHIR-core Observation change request asking whether the ReferenceRange meaning code `normal` definition, then "Based on 95th percentile for the relevant control population," was correct. The accepted resolution was to clarify the description, with Jira comments proposing "within two standard deviations from the mean and accounting for 95.45% of the relevant control population."

Initial application:
The issue was applied in commit 1e59a65e1b6dc1798196f55d782d17e3400b1355 (`GF#16139`), which changed the then-core `source/observation/codesystem-referencerange-meaning.xml` `normal` concept definition from the 95th-percentile wording to the two-standard-deviation/95.45% wording. No existing commit with `Issue-Reconcile-Key: FHIR-16139` was found on the combined branch before this audit.

Additional context:
A later same-artifact issue, FHIR-19772, found the FHIR-16139 wording too strict and was resolved Applied/Persuasive to say that normal ranges are values expected for a normal member of the control population and are usually, not necessarily, defined within two standard deviations. That issue was pre-applied in commit f103fbd30441a7596bc298842427ef0fdf1be564 and already has combined-branch audit commit 7bd090c2d0111946a038368a15583db2cc91eaf9. FHIR core no longer maintains `source/observation/codesystem-referencerange-meaning.xml`: commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed it during the UTG/THO content move. The current active core source binds Observation and ObservationDefinition elements to `ValueSet/referencerange-meaning`, and that ValueSet includes the external THO CodeSystem where the refined `normal` definition is now maintained.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original FHIR-16139 ambiguity was fixed historically, the stricter wording was later relaxed by FHIR-19772, and the current FHIR core source correctly references the THO terminology source whose current definition contains the accepted refined wording.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-16139; any future wording change to `CodeSystem/referencerange-meaning` should be handled through the terminology/THO process, and FHIR-19772 is already represented on the combined branch.
