FHIR-17578: Audit Observation refinement guidance

Issue request:
FHIR-17578 was a Published STU3 FHIR-core Observation change request resolved Persuasive. It asked to add Observation Notes guidance explaining how other observations, codes, components, or a precondition-style context can provide additional context that may alter the semantics or interpretation of an Observation.

Initial application:
The issue was applied before this reconciliation by git commit 1c6e2d841cd2, which added the Observation #refine section to source/observation/observation-notes.xml. Observation is an active current-build resource in source/fhir.ini, so the notes file is in build scope.

Additional context:
OO minutes for 2018-08-02 record the motion and 8-0-2 vote to add this guidance. Later Published issue FHIR-18310 modified the same section by changing the second option from "translations" to "additional codes", reversing the oxygen-saturation example order, replacing the explicit precondition-extension example with grouping/extension guidance, and adding an implementer-feedback note. Still later R6 work added Observation.interpretationContext and the extension-pack observation-precondition definition now says to use Observation.interpretationContext after R5. The combined branch already contains the FHIR-18310 reconciliation commit that aligned the third bullet with that current R6 mechanism.

AutoFHIR reconciliation:
Made no source change. The current source/observation/observation-notes.xml still has the #refine guidance requested by FHIR-17578: use the most specific code, use additional codes, and use related Observations or Observation.interpretationContext when context is needed to understand interpretation. The current wording differs from the original precondition-extension example because later applied decisions superseded that mechanism for the current build.

Recommendation:
Keep this no-change audit. Reinstating the original STU3 precondition-extension wording would conflict with later Observation decisions and would make the current R6 guidance less accurate.
