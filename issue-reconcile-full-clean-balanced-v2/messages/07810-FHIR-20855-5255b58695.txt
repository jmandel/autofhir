FHIR-20855: Audit obsolete substance resource list fix

Issue request:
FHIR-20855 is Published/Persuasive for R5. The issue reported that the R4 resource maturity tab listed SubstanceNucleicAcid, SubstanceProtein, and SubstanceSourceMaterial, but the categorized and alphabetical resource-list tabs did not, and asked whether they should be added.

Initial application:
The request was applied before this reconciliation. Jira records Grahame Grieve's GH#0a3fa2810d comment, and commit 0a3fa2810d90d4b0701369f5704fe9c820d326ef changed source/resourcelist.html to add the missing R4-era substance resource entries where they were absent from the resource index.

Additional context:
Those old Substance* resources are no longer active current-build resources. FHIR-51930 is Applied/Persuasive for R6 and records a BR&R 9-0-0 decision to remove/delete SubstanceNucleicAcid, SubstancePolymer, SubstanceProtein, SubstanceReferenceInformation, and SubstanceSourceMaterial from the FHIR specification. The cited BR&R minutes confirm that motion, and the existing combined-branch audit commit e5842e71424820c971bc515b3c188fbb74063be2 already represents FHIR-51930. Current source/fhir.ini has active build entries for Substance and SubstanceDefinition, but not for the obsolete SubstanceNucleicAcid, SubstanceProtein, or SubstanceSourceMaterial resources.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the three FHIR-20855 resources to the current categorized or alphabetical resource list would contradict the later R6 removal decision. The current resource list already includes the active replacement/current substance-definition resource, SubstanceDefinition, in both the categorized Medication Definition group and the alphabetical list.

Recommendation:
Keep this audit commit as-is for FHIR-20855. No follow-up core source edit is needed unless the work group later reverses FHIR-51930 or reintroduces one of the obsolete Substance* resources as an active build resource.
