Initial application:

Later R6 work moved immature/additional resources, including MolecularDefinition, out of the normative core build and into the CG incubator/additional-resource track. The diagnostics page now links MolecularDefinition to the CG incubator, the active [resources] list no longer includes MolecularSequence or MolecularDefinition, and FHIR-53610 later removed the orphaned Observation.valueReference and Observation.component.valueReference type/search-parameter remnants. The checked-in Observation SVG still mentions MolecularSequence, but that is a generated-looking diagram artifact; the authoritative Observation XML no longer does.
