FHIR-7839: Audit MedicationStatement RXA mapping removal

Issue request:
FHIR-7839 was a Published/Persuasive Pharmacy change request from the DSTU1 QA cycle asking to remove the HL7 v2 mapping "RXA-3-Date/Time Start of Administration / RXA-4-Date/Time End of Administration" from MedicationStatement.effective[x], leaving that v2 mapping blank because MedicationStatement is not MedicationAdministration.

Initial application:
No prior git commit was found whose message explicitly names FHIR-7839. However, the 2015 v2 mapping cleanup commit 5bb461af1063efe577bac2b8b17b6992be7560bf changed the MedicationStatement spreadsheet and removed the requested RXA-3/RXA-4 v2 mapping from MedicationStatement.effective[x] along with other RXA mappings. The current resource has since moved to StructureDefinition XML, and that removal is preserved.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. The current authoritative StructureDefinition defines only the mapping namespace and the PID-3 v2 map for MedicationStatement.subject; MedicationStatement.effective[x] maps to workflow, w5, and RIM, with no v2/RXA map. A current source search for RXA-3/RXA-4 finds MedicationAdministration and Immunization mappings only, not MedicationStatement. Jira search found only FHIR-7839 for the MedicationStatement/RXA/effective query, and Zulip/Confluence searches found no directly relevant conflicting discussion or minutes.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build-scope MedicationStatement source already implements the requested removal and adding or editing source would not change implementer understanding.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-7839 unless a future Pharmacy decision intentionally reintroduces a MedicationStatement-to-RXA mapping.
