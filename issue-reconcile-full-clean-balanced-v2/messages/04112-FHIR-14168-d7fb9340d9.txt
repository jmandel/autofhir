FHIR-14168: Audit principal investigator definition

Issue request:
FHIR-14168 was a Published/Persuasive STU3 BR&R request to change the ResearchStudy.principalInvestigator definition to describe a researcher who oversees multiple aspects of a study, including concept development, protocol work, IRB submission, recruitment, informed consent, data collection, analysis, interpretation, and presentation.

Initial application:
The request was applied before this reconciliation. Git commit 61b5fa557635a9d272e7508b2c7e139a895be930 explicitly included GF#14168 and changed the old ResearchStudy.principalInvestigator spreadsheet short text and definition to the requested wording. The Jira resolution says the change was made and published in the Dec 2017 FHIR ballot.

Additional context:
ResearchStudy remains in the current build, but the standalone ResearchStudy.principalInvestigator element is no longer current source. Later Published/Persuasive FHIR-37814 deleted ResearchStudy.sponsor, ResearchStudy.principalInvestigator, and ResearchStudy.contact because their semantics are supported through ResearchStudy.associatedParty.role; current source/fhir.ini records the cross-version mapping from ResearchStudy.principalInvestigator to ResearchStudy.associatedParty.party with role='primary-investigator'. Later Applied/Persuasive FHIR-41330 revised the Research Study Party Role code displays and definitions, including primary-investigator displayed as Principal investigator with the current approved definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or locally restating the retired element definition would conflict with the later R5 consolidation. Changing the current primary-investigator code definition back to the 2017 element wording would conflict with the later R6 role-code decision that already governs the current representation.

Recommendation:
Keep this audit commit as-is. If BR&R wants the current primary-investigator role definition to use the older 2017 wording or a hybrid, that should be a new review against FHIR-41330 rather than a reconciliation fix for FHIR-14168.
