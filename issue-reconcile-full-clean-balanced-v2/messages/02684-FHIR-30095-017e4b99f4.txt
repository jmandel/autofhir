FHIR-30095: Audit ClinicalUseDefinition scope boundaries

Issue request:
FHIR-30095 was Published/Persuasive with Modification for R5. It asked to fix the old ClinicalUseIssue Scope and Usage and Boundaries and Relationships text by replacing stale ClinicalParticulars wording, adding device/procedure scope alongside medication/medicinal product, clarifying that the resource is not about actual use events, and aligning the indication/contraindication/interaction/undesirable-effect bullets.

Initial application:
The requested narrative change was applied in git commit 5adb76573d2e46c8ba0f5b0d0043a3d22d20cc9b, which edited source/clinicaluseissue/clinicaluseissue-introduction.xml to replace ClinicalParticulars with ClinicalUseIssue, add device/procedure wording, fix the contraindication typo, and align the boundary bullets. OO catalog minutes around the BRR decision record FHIR-30095 as agreed/applied, and Jira comments in 2022 state that the area had changed substantially and the issue could be considered applied.

Additional context:
The current build no longer has ClinicalUseIssue as the active resource name. FHIR-31847 renamed it to ClinicalUseDefinition, source/fhir.ini has ClinicalUseDefinition as the active normative BRR resource while ClinicalUseIssue is commented out, and the old MedicinalProductContraindication artifact maps to ClinicalUseDefinition. Later same-resource changes, especially FHIR-32064 and FHIR-31394, added warning and broadened the scope to medication, substance, device, procedure, biologically derived product, and nutrition product. FHIR-31394 is already represented on the combined branch and completed stale root/module summaries, so the current ClinicalUseDefinition narrative and definitions now preserve and extend the FHIR-30095 intent.
