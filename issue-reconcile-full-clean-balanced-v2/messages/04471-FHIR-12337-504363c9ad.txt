FHIR-12337: Audit medication category search parameters

Issue request:
FHIR-12337 was a Published Pharmacy change request with a Persuasive resolution. It asked to add category search parameters for MedicationRequest and MedicationStatement after FHIR-10141 added the underlying category element to the medication request/statement resources.

Initial application:
Jira records the issue as applied on November 14, 2016 in build@10195. Git history corroborates that with git-svn commit a14bb96e03, whose subject explicitly says TR#12337 added category to search parameters for medicationstatement and medicationrequest and whose patch added token search rows for MedicationRequest.category and MedicationStatement.category.

Additional context:
MedicationPrescription/MedicationOrder was later represented by the current MedicationRequest resource. MedicationRequest and MedicationStatement are active current-build resources in source/fhir.ini, and their current search-parameter bundle inputs both contain a category token SearchParameter with expression MedicationRequest.category or MedicationStatement.category. The 2021 build-source refactor carried those search parameters forward into the current bundle-MedicationRequest-search-params.xml and bundle-MedicationStatement-search-params.xml files, and release-history artifacts show the parameters persisted from STU3 through later releases. FHIR-10141 is the prerequisite element-addition issue; FHIR-12345 was applied in the same historical commit but concerns a separate MedicationStatement.category binding-description typo and is already audited on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source already contains category search parameters for both resources requested by FHIR-12337, and the active resource configuration confirms those inputs are in the current build scope.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed for FHIR-12337 unless a future Pharmacy decision changes the semantics of MedicationRequest.category or MedicationStatement.category search.
