FHIR-16064: Audit DiagnosticReport.result wording

Issue request:
FHIR-16064 was a Published/Persuasive with Modification STU3 OO change request asking whether DiagnosticReport.result allowed Observation.component content, because the old element definition described simple and grouping Observations without making component use clear. The approved resolution was to remove the more descriptive element-definition prose and simply state "Observations that are part of this diagnostic report" with an inline link to Observation.

Initial application:
The issue was applied in git commit 468774c1b07865f7af97bf1643874d2e37067aaf, whose message included GF#16064 and whose DiagnosticReport spreadsheet patch removed the old DiagnosticReport.result definition text about simple name/value pairs and grouping observations. The current XML source was later rebuilt in commit 33b409a4b6d while preserving the simplified linked definition.

Additional context:
DiagnosticReport is an active current-build resource in source/fhir.ini. Current source/diagnosticreport/structuredefinition-DiagnosticReport.xml defines DiagnosticReport.result as a Reference(Observation) and uses the simplified linked definition, while Observation.component remains defined in the Observation resource. Broader DiagnosticReport/Observation grouping guidance appears in narrative pages and later Jira issues, but those do not reverse FHIR-16064 or require adding DiagnosticReport-level component text to the result element definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current element definition already matches the approved FHIR-16064 resolution, and adding redundant local component guidance would reintroduce the kind of DiagnosticReport.result detail the work group chose to leave to Observation.

Recommendation:
Keep this audit commit as-is. Future grouping changes should be handled under their own OO Jira decisions rather than by reopening FHIR-16064, whose requested element-definition cleanup is already present.
