FHIR-7223: Audit Medication compartment master-file note

Issue request:
FHIR-7223 was a Published, Persuasive FHIR-core Medication clarification raised against the DSTU1 Medication wording. It asked that Medication be distinguished as a master file or knowledge-base resource rather than patient-specific data. The Jira resolution says this was made more explicit by the compartment note.

Initial application:
The Jira comments point to the related FHIR-7222 discussion and state that the clarification was made by the compartment note. Git commit 3be288e561fbfb7b91f0568b3db68023e53784b0 (git-svn build@6453, subject "@7367 - note about resources not in compartments") added a compartments note saying that Medication, Substance, and Location are not in any compartment, are sometimes called master files, and that Medication itself does not link to a patient while MedicationAdministration connects a Medication to a patient.

Additional context:
FHIR-7222 is the broader companion issue about distinguishing master files from patient-specific resources; its resolution says patient-specific resources include patient or subject data, and Grahame's comment says this can be told by whether a resource has a subject link. Medication is active in the current build, CompartmentDefinition is active, and the current security categorization classifies Medication as a business resource rather than patient. Later Medication wording and resource-model refactors do not remove the specific compartment guidance that resolved this issue.

AutoFHIR reconciliation:
No source change was made. The current in-scope compartment definition notes already state that Medication is not in any compartment, is a master-file-style resource, and does not link directly to a patient. Adding the same distinction to the Medication page would be redundant and could drift from the authoritative compartment guidance.

Recommendation:
Keep this audit commit as-is. The current source already satisfies the Jira decision; future work should only revisit this if the compartment guidance or Medication's compartment/security categorization is intentionally changed by a later work-group decision.
