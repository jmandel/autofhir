FHIR-20572: Audit value-set binding slicing validator fix

Issue request:
FHIR-20572 was a Published/Persuasive FHIR-core technical correction, raised against STU3 and applied for R5, reporting that the IG Publisher validator returned an informational message that it could not find a slice when an Observation.component slice was distinguished by a value discriminator on code and the sliced code element carried a required value-set binding.

Initial application:
No source commit tagged with FHIR-20572 and no current source occurrence of the issue key were found. The only direct application evidence found is FHIR-I minutes from 2020-01-27 where Grahame Grieve stated that FHIR-20572 was fixed. The current R5/R6 core source also reflects the adjacent rule needed for this scenario: value discrimination can be based on a required value set binding, and the deprecated pattern discriminator is equivalent to value.

Additional context:
The seed is a tooling/validator behavior report rather than a request for new normative prose. The closely related Published issue FHIR-25206, already represented on the combined branch, records the broader FHIR-I decision to merge value and pattern discriminator semantics and allow required value-set bindings as value discriminators. FHIR-34152, also already represented on the combined branch, supplied later profiling prose that explicitly says value discrimination can use a fixed value, pattern value, or required value set binding.
