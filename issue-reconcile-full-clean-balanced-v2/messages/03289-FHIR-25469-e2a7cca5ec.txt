FHIR-25469: Audit removed SNOMED CodeSystem example

Issue request:
FHIR-25469 was a Published/Persuasive R4 technical correction from Vocabulary asking to correct the SNOMED CT canonical CodeSystem filter.code from "expression" to "constraint". The final resolution instead identified the local CodeSystem example as out of date and directed that the CodeSystem example be removed from the specification, with possible future linking to SNOMED-on-FHIR guidance.

Initial application:
The issue was applied in commit 9500b398d1d850a06cd180c82ce330e4809a2b49, whose R5 vocabulary batch explicitly listed FHIR-25469 and deleted source/codesystem/codesystem-snomedct.xml. That deleted file contained the stale SNOMED CT filter with code="expression" for Expression Constraint. Follow-up commit 9049817626509bd4faf0ac6b8187b08149e1f0a3 removed remaining narrative links from source/snomedct.html to codesystem-snomedct.html.

Additional context:
The current build no longer contains source/codesystem/codesystem-snomedct.xml or source/snomedct.html. The active [codesystems] section in source/fhir.ini does not include codesystem-snomedct, source/hierarchy.xml only exposes the SNOMED CT Usage Report under Code Systems, and source/terminologies-systems.html links SNOMED CT implementers to the THO "Using SNOMED CT with HL7 Standards" page plus the local usage summary. The linked Zulip thread confirmed "constraint" as the correct filter name, and the Vocabulary minutes for 2021-08-04 recorded the decision to will-fix by treating the old CodeSystem as an out-of-date example.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the stale canonical SNOMED CT CodeSystem example that caused the incorrect filter.code has already been removed from the current build, and current source does not preserve an active local reference to that obsolete page.

Recommendation:
Keep this audit commit as-is. Any future detailed SNOMED CodeSystem metadata maintenance should remain with the external SNOMED/THO guidance rather than reintroducing the removed core example.
