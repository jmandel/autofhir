FHIR-39138: Audit Ingredient resource rationale

Issue request:
FHIR-39138 was a Published FHIR-core BRR change request, resolved Not Persuasive with Modification, asking whether Ingredient should be collapsed under ManufacturedItemDefinition and AdministrableProductDefinition. The approved resolution kept Ingredient as a separate resource and required comments in the scope/boundaries section explaining why Ingredient exists as a separate resource.

Initial application:
The issue appears to have been applied by Rik Smithies in git commit 482ac65067c4308498bf89328b85ef034a16f399, "added better introduction for FHIR-39138", which added a Scope and Usage paragraph to source/ingredient/ingredient-introduction.xml explaining that Ingredient is a resource because some use cases need it to be referenced from other resources, while contained Ingredient remains available for projects that do not need a separate persisted resource.

Additional context:
Ingredient is active in the current build through source/fhir.ini, and the current StructureDefinition still associates Ingredient with MedicinalProductDefinition, AdministrableProductDefinition, and ManufacturedItemDefinition through Ingredient.for. Earlier Zulip and BRR minutes show the same modeling concern was discussed before the Jira issue, including backbone-versus-resource alternatives and reuse/authorization use cases. Later Jira FHIR-31877 reconsidered a closely related objection and was resolved No Change because Ingredient has cases where it needs its own identifier and reuse.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current Ingredient Scope and Usage section already contains the requested rationale: it says Ingredient is represented as a resource rather than a backbone/datatype for practical use cases where another resource must reference the ingredient, gives authorization and multi-part tablet examples, and documents contained Ingredient as the simpler-project alternative.

Recommendation:
Keep this no-change audit commit. Further source edits would be redundant unless BRR makes a new decision to change the Ingredient modeling approach; the current source matches the published FHIR-39138 resolution and later supporting context.
