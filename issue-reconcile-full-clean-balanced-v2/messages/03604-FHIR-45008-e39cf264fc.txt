FHIR-45008: Audit BodyStructure landmark orientation enhancement

Issue request:
FHIR-45008 was Applied with a Persuasive with Modification resolution for R6. The OO work group agreed to clarify BodyStructure.includedStructure.bodyLandmarkOrientation so artificial or implanted landmarks are understood as valid body landmarks, and to expand BodyStructure/skin-patch with an example such as 2 cm distal from a heart tattoo.

Initial application:
The Jira comment says the change was added to the build in HL7/fhir PR #3101, citing commit 8909642886c3490e04706499e7304f91e12038d6. Source history shows the substantive implementation in 238839faadab4fc3f5b32733442ec222ff33897d, which changed source/bodystructure/structuredefinition-BodyStructure.xml and source/bodystructure/bodystructure-example-skin-patch.xml before PR #3101 was merged as 0064cbe1d23c1030df096f3c91c1cf214535bda6.

Additional context:
The linked Zulip thread records the motivating question about endotracheal tubes, stents, prostheses, and other artificial artifacts, and Rob Hausam confirmed that artificial landmarks are consistent with the intended use when they provide a relatively fixed reference point. OO minutes for 2024-03-22 recorded the same FHIR-45008 block-vote disposition. BodyStructure is an active resource in source/fhir.ini, and later BodyStructure history did not remove the requested definition or skin-patch example.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already contains the requested definition text, including implanted device as an example landmark, and the active skin-patch example already contains bodyLandmarkOrientation with a heart tattoo, 2.0 cm distance, and distal surface orientation.

Recommendation:
Keep this audit commit as-is. No follow-up source edit is needed for FHIR-45008 unless the work group later chooses a broader editorial cleanup of BodyStructure wording beyond this issue's approved clarification.
