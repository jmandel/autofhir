FHIR-32783: Audit SubscriptionTopic resource rename

Issue request:
FHIR-32783 was Published/Persuasive for R5 and asked to rename SubscriptionTopic.resourceTrigger.resourceType because the element name collided with the JSON serialization pseudo-element resourceType. The accepted resolution was to use SubscriptionTopic.resourceTrigger.resource instead.

Initial application:
The rename was pre-applied before final publication. Git commit 3a668a39553ac56050d01698384db9513004075b changed the SubscriptionTopic StructureDefinition from resourceTrigger.resourceType to resourceTrigger.resource and explicitly noted FHIR#32783. Git commit d6a7fe20f9258525ddc48b03a71b313545b30849 updated the corresponding SubscriptionTopic search parameter from resource-type/resourceTrigger.resourceType to resource/resourceTrigger.resource, and later history retained the resource search parameter.

Additional context:
FHIR-46492 subsequently collapsed SubscriptionTopic.resourceTrigger and SubscriptionTopic.eventTrigger into SubscriptionTopic.trigger for R6. Current build-scope source/fhir.ini lists SubscriptionTopic as an active resource and maps the old R5 SubscriptionTopic.resourceTrigger.resource path to SubscriptionTopic.trigger.resource for cross-version handling. Current authoritative source uses SubscriptionTopic.trigger.resource and the SubscriptionTopic-resource search parameter expression points at SubscriptionTopic.trigger.resource. Searches found no remaining SubscriptionTopic resourceTrigger.resourceType path or SubscriptionTopic-resource-type search parameter in the active SubscriptionTopic source. FHIR-I WGM minutes for January 2022 also record that the FHIR-32783 name change was already applied when the group voted persuasive.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the current build no longer exposes the conflicting SubscriptionTopic.resourceTrigger.resourceType element name, and the later trigger refactor preserves the accepted resource element name semantics under SubscriptionTopic.trigger.resource.

Recommendation:
Keep this audit commit as-is. Future work should not reintroduce resourceType-named elements under SubscriptionTopic trigger/filter/shape structures; any additional SubscriptionTopic trigger-model changes should be handled under their own Jira issue such as FHIR-46492.
