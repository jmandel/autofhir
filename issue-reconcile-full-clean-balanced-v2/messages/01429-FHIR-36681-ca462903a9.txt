FHIR-36681: Clarify Practitioner qualification identifier notes

Issue request:
FHIR-36681 was a Published/Persuasive R5 clarification for Practitioner. It asked how to exchange a license identifier when qualification active status is unknown, how to choose between Practitioner.identifier and Practitioner.qualification.identifier, why Practitioner.qualification.identifier is repeatable, and it requested removing the misleading "in this role" wording from Practitioner.qualification.identifier.

Initial application:
The explicit FHIR-36681 implementation commit 6e58083f0879ea3b5ad74e25e7a10eb64f0b0ab2 removed "in this role" from the Practitioner.qualification.identifier definition. The related FHIR-32493 note already allowed license/business identifiers in Practitioner.identifier, Practitioner.qualification.identifier, or both, and FHIR-32494 updated the Practitioner identifier search parameter to include both paths. Before this reconciliation, the current notes still did not explain the repeatable qualification.identifier cardinality and were ambiguous about unknown qualification status.

Additional context:
Practitioner is an active core resource in source/fhir.ini, so source/practitioner/practitioner-notes.xml feeds the current build. FHIR-34375 later added Practitioner.qualification.status as an optional element, which makes it safer to state that unknown status is omitted rather than implying qualification.identifier itself carries status. PA May 2022 WGM minutes record FHIR-36681 as persuasive 7-0-0 and FHIR-36680 as a duplicate search-related item. No conflicting Zulip or Confluence evidence was found.

AutoFHIR reconciliation:
Updated the Practitioner notes to clarify that business identifiers may appear in either or both identifier locations; Practitioner.identifier does not by itself convey qualification details beyond the identifier's own metadata; known qualification status, validity period, issuer, or type should be represented in Practitioner.qualification child elements; unknown qualification status should be omitted; multiple qualification identifiers can represent certifying-body and internal-system identifiers; profiles may constrain that cardinality; and the Practitioner identifier search parameter includes both paths.

Recommendation:
Keep this source fix. It completes the published clarification without changing conformance cardinalities or bindings, and it aligns the notes with the existing definition, search parameter, and later optional qualification.status element.
