FHIR-36752: Audit removal of all-media-types ValueSet

Issue request:
FHIR-36752 was Published/Persuasive for R5 and asked Vocab to delete the redundant FMM0 valueset-all-media-types page/source, replacing use of it with the existing normative mimetypes ValueSet.

Initial application:
The issue was applied by git commit a8ba98e51b, which deleted source/datatypes/valueset-all-media-types.xml and removed the all-media-types entry from source/fhir.ini. The current source no longer contains tracked references to all-media-types.

Additional context:
The Vocab minutes show the issue moved to resolved-change-required on 2022-08-22, and the 2022-08-29 follow-up noted that deleting the ValueSet would require checking/changing the Expression datatype binding. Current source/datatypes/expression.xml binds ExpressionLanguage to http://hl7.org/fhir/ValueSet/mimetypes, and current source/fhir.ini actively includes terminologies/valueset-mimetypes.xml.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The obsolete all-media-types ValueSet is absent from current build scope, and the remaining MIME type binding points at the active mimetypes ValueSet.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source work is needed for FHIR-36752 unless a future Vocab decision changes the MIME type ValueSet itself.
