FHIR-6034: Audit NDF-RT link repair

Issue request:
FHIR-6034 was a Published/Persuasive DSTU1 technical correction asking that the Known Systems / Code Systems table stop linking NDF-RT (National Drug File - Reference Terminology) through http://hl7.org/fhir/ndfrt because that page returned 404.

Initial application:
The issue was applied in Subversion revision 5524, represented in git as e62110a2d2ffe726d9ac4e7be253c5d01b8e0d7c, which changed source/terminologies-systems.html from the broken http://hl7.org/fhir/ndfrt link to an NLM UMLS NDFRT source URL.

Additional context:
The active terminology navigation includes source/hierarchy.xml's Code Systems page entry for source/terminologies-systems.html. Later terminology decisions changed the same row: FHIR-35800 updated the NDF-RT source link and added MED-RT replacement guidance, and FHIR-39156 then removed the NDF-RT row from the current External Code Systems table because NDF-RT is no longer maintained and has been replaced by MED-RT. The current source has no http://hl7.org/fhir/ndfrt occurrence under source/, source/terminologies-systems.html now lists MED-RT with THO guidance, and the remaining NDF-RT mention in source/valueset/valueset-notes.xml points to https://terminology.hl7.org/NDFRT.html, which resolves successfully.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The originally broken link is absent from the current build source, the Jira-tagged application commit is present in history, and later published terminology work removed the affected NDF-RT table row rather than requiring another core edit.

Recommendation:
Keep this no-change audit commit. If maintainers want http://hl7.org/fhir/ndfrt itself to stop returning 404, that is a web redirect or terminology-site hosting concern rather than a current FHIR core source correction for this issue.
