FHIR-36828: Audit Device gateway rename

Issue request:
FHIR-36828 was a Published/Persuasive R5 OO change request to replace the Device.link backbone with Device.gateway 0..* CodeableReference(Device), described as the linked device acting as a communication/data collector, translator, or controller for the current device.

Initial application:
The Jira-tagged source commit 3932ce4be6 replaced Device.link with Device.gateway in source/device/structuredefinition-Device.xml, changed the type from BackboneElement to CodeableReference(Device), and removed the link.relation/link.relatedDevice backbone structure. Later R5 work in FHIR-37614 refined the Device.gateway definition and added guidance about when Observation.gatewayDevice should be used instead.

Additional context:
Device is active in source/fhir.ini. The current R6 source no longer has an active Device.link or Device.gateway element after XML comments are stripped. That is intentional later history, not a missed FHIR-36828 application: FHIR-32565 approved moving Device.mode, Device.cycle, Device.duration, Device.gateway, and Device.endpoint into extensions; FHIR-48923 removed endpoint and gateway from the core Device StructureDefinition; and FHIR-47326 created the replacement device-gateway extension in the FHIR Extension Pack with CodeableReference(Device) and Device/Observation contexts. Current Device narrative and fhir.ini R5-to-R6 mapping also identify Device.gateway as removed from core and moved to an extension.

AutoFHIR reconciliation:
This commit makes no source change. Reintroducing Device.gateway into core would reverse the later R6 removal decision, while editing the Extension Pack is outside this FHIR-core worker branch. The current core source is correct for FHIR-36828 when the later issue family is considered.

Recommendation:
Keep this audit commit as-is. No FHIR-core follow-up is needed for FHIR-36828; any future changes to the replacement gateway representation should be handled through the FHIR Extension Pack device-gateway extension or a new OO/FM G decision.
