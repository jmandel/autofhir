FHIR-6313: Audit QuestionnaireResponse boundary guidance

Issue request:
FHIR-6313 was a Published/Persuasive with Modification DSTU1 clarification for QuestionnaireAnswers asking when Observation versus QuestionnaireAnswers should be used, whether constraints should force Observation for true observations, and how to avoid analysis problems when questionnaire answers contain data that could also be represented as other resources. The accepted resolution was to add guidance that data can exist both in QuestionnaireAnswers and in resources such as Patient, FamilyMemberHistory, AllergyIntolerance, MedicationStatement, and Observation, with the original questionnaire answer retained for traceability.

Initial application:
The issue appears to have been applied by git commit cacb4626a3, which added the requested paragraph to source/questionnaire/questionnaire-notes.xml using the then-current QuestionnaireAnswers name. The current build later renamed QuestionnaireAnswers to QuestionnaireResponse and retained the same guidance in source/questionnaire/questionnaire-notes.xml.

Additional context:
Questionnaire and QuestionnaireResponse are active resources in source/fhir.ini. Later refactoring in 52dbc1c478 preserved the paragraph, updated names and links for QuestionnaireResponse, and added the optional Provenance traceability note. Current QuestionnaireResponse notes also advise extraction from completed QuestionnaireResponses into more standardized resources for search. Related Jira FHIR-7238 cites the same Questionnaire boundary clarification, while FHIR-3819 and FHIR-6199 are broader Observation/DiagnosticReport boundary context rather than independent decisions for this seed.

AutoFHIR reconciliation:
No source change was made. The active Questionnaire notes already state that data may exist in both QuestionnaireResponse and other resources, list the same destination resources requested in the resolution, preserve the traceability point, and include the weight-to-Observation example with Observation.code and Observation.valueQuantity.

Recommendation:
Keep this no-change audit commit. The current source satisfies FHIR-6313 without adding duplicate prose to Observation or QuestionnaireResponse pages; future work should only revisit if the Questionnaire boundary section is moved or if work-group review asks for different extraction/Provenance guidance.
