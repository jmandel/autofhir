FHIR-19442: Remove stale @all redirect

Issue request:
FHIR-19442 was a Published FHIR-core terminology-service change request, resolved Not Persuasive with Modification and applied for R5. It asked whether the "Operations across all value sets" section belonged elsewhere and whether the special http://hl7.org/fhir/ValueSet/@all value set should be an operation; the final decision was to remove the section because the feature was very limited, server-specific, and did not support interoperability.

Initial application:
The Jira-tagged historical commit 9500b398d1 removed the "Operations across all value sets" section and its terminology-service.html#all anchor from source/terminology-service.html. Current terminology-service.html still has no @all section, but the checked-in top-level publish.ini [redirects] section still advertised http://hl7.org/fhir/ValueSet/@all as a "Magic ValueSet Id" pointing to the deleted terminology-service.html#all anchor.

Additional context:
The terminology-service page is active in the current source through source/hierarchy.xml and source/documentation.html, and publish.ini is the active top-level publishing configuration rather than generated publish/ output. Vocab minutes and the Jira comments confirm the work group decision to remove the section while allowing implementations to keep custom terminology-server behavior. Later Zulip discussion confirms the current interpretation: @all is no longer defined in R5+ and the committee did not believe in the exposed functionality.

AutoFHIR reconciliation:
Removed the stale http://hl7.org/fhir/ValueSet/@all redirect from publish.ini so current publication metadata no longer defines or points to the removed magic ValueSet URL. No terminology-service narrative change was needed because the original section is already absent from the active source page.

Recommendation:
Keep this source fix. Any future global concept-search or cross-CodeSystem feature should be handled by a new work-group decision rather than by retaining the old @all redirect.
