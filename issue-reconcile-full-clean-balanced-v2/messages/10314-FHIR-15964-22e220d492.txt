FHIR-15964: Audit ele-1 id-only enforcement

Issue request:
FHIR-15964 was a Published/Persuasive FHIR-core change request from STU3, applied for R5, reporting that an IG contained an element with only an XML id attribute (`<package id="foo"/>`) and the validator did not reject it. The accepted resolution was to enforce that an element with only id is invalid.

Initial application:
No FHIR-15964-tagged source commit was found in the current repository history. The relevant common Element invariant was already shaped to ignore Element.id when testing for substantive content, and FHIR-I minutes from 2019-12-02 record the issue as "Already applied by tooling update." Related ele-1 history includes the 2018 correction from FHIRPath `|` to boolean `or`, but that commit was not explicitly tagged to this Jira.

Additional context:
A 2022 Zulip thread reopened the question because of normative-break concerns; Lloyd McKenzie replied that the current ele-1 invariant already fixed the issue with `hasValue() or (children().count() > id.count())`. Later FHIR-43103 clarified the human wording to say "or both," and FHIR-26565 added the empty Parameters exception; neither later change permits ordinary elements whose only content is Element.id.

AutoFHIR reconciliation:
Made no source change. The active datatype source `source/datatypes/element.xml` defines ele-1 as `hasValue() or (children().count() > id.count()) or $this is Parameters`, so an element whose only child/property is Element.id fails the invariant. The companion XML XPath is `@value|f:*|h:div|self::f:Parameters`, which also does not count an XML `id` attribute as content. `source/fhir.ini` lists Element as an active infrastructure type, so this source is in current build scope.

Recommendation:
Keep this audit commit as-is. The current spec source already expresses the intended rule; if a current validator still accepts id-only elements outside the empty Parameters exception, that should be handled as validator/tooling follow-up rather than by changing the FHIR source.
