FHIR-18799: Correct immunization eligibility spelling

Issue request:
FHIR-18799 was a Published/Persuasive STU3 technical correction for the FHIR-core terminologies value set table entry immunization-program-eligibility. The accepted request was to correct the description wording from "patient's elibigility" to "patient's eligibility" and preserve the intended phrase "vaccination program."

Initial application:
The legacy value set source appears to have been corrected by git commit 3711daf34c0bfd80da9afe8a6c468dcb2cc37d6e, which changed source/immunization/valueset-immunization-program-eligibility.xml from "elibigility" to "eligibility". That legacy value set file is no longer present in current core source, but the current active Immunization StructureDefinition still carries a binding definition for ProgramEligibility.

Additional context:
source/fhir.ini lists immunization as an active resource, and source/immunization/structuredefinition-Immunization.xml currently binds Immunization.programEligibility.programStatus to http://terminology.hl7.org/ValueSet/immunization-program-eligibility. The active binding-definition text had drifted to "vaccation program", so the current built core source still failed to match the accepted "vaccination program" wording even though the original "elibigility" typo had been fixed. Jira, Zulip, and Confluence searches found no later decision requiring different wording.

AutoFHIR reconciliation:
Corrected the active ProgramEligibility binding-definition in source/immunization/structuredefinition-Immunization.xml from "vaccation program" to "vaccination program". The change is limited to the immunization-program-eligibility wording governed by this issue.

Recommendation:
Keep this source fix as-is for FHIR-18799. Any separate spelling cleanup for neighboring VaccineFundingProgram text should be handled under a separate tracker because no final Jira decision tied that text to this issue.
