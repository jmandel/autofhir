FHIR-31657: Audit ResearchSubject progress approval

Issue request:
FHIR-31657 was a Published/Persuasive BR&R technical correction for R5 asking to approve the already-balloted creation of the ResearchSubject progress attribute from the FHIR-23028 work and to make ResearchSubject.status refer only to publication status, following the ResearchStudy pattern.

Initial application:
The progress model was first implemented before final approval by afae9447904fefafb8605fbe0786232a4fdd7c89, which added ResearchSubject.progress in the pre-StructureDefinition spreadsheet source. The status split and progress refinements were then applied in 85a2ee09a39be6c5ae5b6a97eec3d21f46970051 for Jira #26828, #31689, and #31690. R5 publication evidence shows ResearchSubject.status bound to PublicationStatus and ResearchSubject.progress present with type, subjectState, startDate, and endDate.

Additional context:
FHIR-23028 is the original discontinuation/progress request and its comments say FHIR-31657 addressed the outstanding process points. FHIR-31689 and FHIR-31690 are the same ResearchSubject progress/status change family and are already represented on the combined branch. Later R6 Applied issues FHIR-43561 and FHIR-44837 replaced the R5 progress backbone with ResearchSubject.subjectState and ResearchSubject.subjectMilestone, and source/fhir.ini explicitly maps the R5 ResearchSubject.progress elements to those current elements.

AutoFHIR reconciliation:
This commit intentionally makes no source change. ResearchSubject is active in source/fhir.ini, current source already separates publication status from subject progression, and the approved R5 progress capability is preserved under the current R6 subjectState/subjectMilestone structure with R5-to-R6 migration mappings.

Recommendation:
Keep this no-change audit commit. Revisit only if a future ResearchSubject refactor removes subjectState/subjectMilestone or drops the R5 progress migration mappings; otherwise adding a legacy progress element back to current R6 source would reverse later WG-approved changes.
