FHIR-25936: Add ingredient wording to Medication glossary

Issue request:
FHIR-25936 was Published/Persuasive for R5 and asked Pharmacy to update the Medication definition by adding "including ingredients" to the sentence describing identification and definition of a medication.

Initial application:
No prior commit explicitly mentioning FHIR-25936 was found on the relevant source paths. The active Medication StructureDefinition already contains the approved wording in both the resource description and the Medication element definition, introduced when the XML StructureDefinition source was created in git commit 33b409a4b6d544598262f2f074ebb4b6dc466157. The separate glossary page source was later reformatted in FHIR-24866 and still carried the older pre-R5 Medication sentence without the ingredient phrase.

Additional context:
Medication is an active current resource in source/fhir.ini, and source/hierarchy.xml includes source/help.html as the current Glossary #1 page, so the stale glossary wording is in build scope rather than an unused artifact. Later Medication issue FHIR-36499 clarified Medication.ingredient narrative and confirms that ingredient-focused Medication guidance remains current, but it is not a separate decision made here. Direct Zulip and Confluence searches for FHIR-25936 found no conflicting community record; a related Zulip implementer thread quoted the current StructureDefinition wording and did not contradict it.

AutoFHIR reconciliation:
Updated source/help.html so its Medication glossary definition also says the Medication resource is used for identification and definition of a medication, including ingredients. No other source changes were needed because the active StructureDefinition and Medication ingredient narrative already carry the approved meaning.

Recommendation:
Keep this commit as-is. It closes the remaining current-source inconsistency for FHIR-25936 without duplicating or broadening the Medication guidance beyond the published Jira resolution.
