FHIR-31023: Fix Specimen collection procedure example

Issue request:
FHIR-31023 was a Published/Persuasive OO R4-to-R5 change request asking for a way to link a lab Specimen to the surgery or other Procedure during which it was collected. The approved motion added Specimen.collection.procedure as a 0..1 Reference(Procedure) and renamed Specimen.processing.procedure to Specimen.processing.method.

Initial application:
The issue was applied before this reconciliation. Commit aefdd75200eeedf8617971a57efa2e67003bf1d9 added Specimen.collection.procedure to source/specimen/structuredefinition-Specimen.xml as Reference(Procedure), renamed Specimen.processing.procedure to Specimen.processing.method, updated the processing value set name, and updated an example using the renamed processing element.

Additional context:
Specimen is an active current-build resource in source/fhir.ini, and source/specimen/list-Specimen-examples.xml includes specimen-example-liver-biopsy as an active example. Later issue FHIR-37870 added a procedure search parameter for Specimen.collection.procedure, and later issue FHIR-45505 added the spm-1 invariant that Specimen.collection.collector and Specimen.collection.procedure are not both present. Both of those related issues are already represented on the combined branch. The liver biopsy Specimen example was added later by FHIR-48715-related source history and used Specimen.collection.procedure as coded content while also carrying collection.collector, which contradicted the FHIR-31023 Reference(Procedure) model and the later FHIR-45505 invariant.

AutoFHIR reconciliation:
This commit fixes the active liver biopsy Specimen example. It turns collection.procedure into a Reference to a contained Procedure resource that carries the liver biopsy code, subject, occurrence, and performer, and removes collection.collector so the example complies with spm-1 while still showing the requested Procedure link.

Recommendation:
Keep this source fix. It preserves the approved FHIR-31023 model, avoids changing the authoritative Specimen element definitions, and only corrects an active example that had drifted from the Reference(Procedure) semantics. No further core follow-up is needed for FHIR-31023 unless OO later changes the collector/procedure invariant or chooses to add a standalone liver biopsy Procedure example.
