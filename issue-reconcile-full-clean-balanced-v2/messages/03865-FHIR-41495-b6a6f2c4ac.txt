FHIR-41495: Audit Quantity comparator example encoding

Issue request:
FHIR-41495 was an Applied/Persuasive FHIR-core technical correction for R6. It reported that the Quantity datatype examples on datatypes-examples.html showed the greater-than comparator as HTML-encoded text in the XML and JSON examples, and asked that the comparator value display as the literal > code.

Initial application:
The issue was applied by Git commit e5b949659a2da06a1af0a2816f7d6ebfb70ce7ba, linked from Jira through HL7/fhir#3898. That commit changed source/datatypes-examples.html so the displayed XML and JSON Quantity comparator examples use &gt; in the HTML source instead of &amp;gt;, causing the rendered examples to show the literal > comparator.

Additional context:
The page is in current build scope through the active datatypes type-page mapping in source/fhir.ini. The originating Zulip thread records Grahame Grieve confirming the escaped comparator was an error and Elliot Silver filing FHIR-41495 and FHIR-41496. FHIR-I minutes on 2024-01-22 changed FHIR-41495 to a technical correction. The related FHIR-41496 anchor issue is already represented on the combined branch by commit 9621268e88290bba77426ca890f9d28dbd185f8c and is not duplicated here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current combined branch already has source/datatypes-examples.html lines 752-765 with &lt;comparator value="&gt;" /&gt; for XML and "comparator" : "&gt;" for JSON, and no remaining &amp;gt; comparator encoding in that Quantity example.

Recommendation:
Keep this empty no-change audit commit as-is. No further FHIR-core source work is needed for FHIR-41495 unless a future rendered build shows a regression in the displayed Quantity comparator examples.
