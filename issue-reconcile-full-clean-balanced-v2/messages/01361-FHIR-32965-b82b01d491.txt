FHIR-32965: Audit DefinedParameters absent-result support

Issue request:
FHIR-32965 was a Published/Persuasive R5 CDS change request asking for evaluation results that are null or otherwise absent to be represented in Parameters by allowing the dataAbsentReason extension in the DefinedParameters profile rather than omitting the parameter or using string placeholders such as "null".

Initial application:
The supporting DefinedParameters profile was introduced by FHIR-32963 in commit 272e3fb71ecb0d87630a48101b00015f0f18b038. FHIR-32965 itself was applied by commit 12ad078437bbe021259be0e479dfa2ceeb986f92, which added a Parameters.parameter.value[x] element and a Parameters.parameter.value[x].extension:dataAbsentReason slice bound to http://hl7.org/fhir/StructureDefinition/data-absent-reason. Jira also records that application and PR HL7/fhir#2635.

Additional context:
The current source keeps Parameters as an active resource in source/fhir.ini, and source/parameters/implementationguide-Parameters-cqf.xml references StructureDefinition/definedparameters. The current DefinedParameters differential still contains the dataAbsentReason slice with max 1 and mustSupport true. Jira, Zulip, and Confluence searches found no later issue or community record reversing or narrowing the FHIR-32965 decision. FHIR-32963 is a same-profile background issue but was not independently reconciled here because this seed only requires checking the added absent-result slice.

AutoFHIR reconciliation:
No source change was made. The current build-scope source already carries the requested dataAbsentReason support in the DefinedParameters profile, and adding duplicative narrative to the Clinical Reasoning Using Expressions page would not change implementer obligations.

Recommendation:
Keep this no-change audit commit. Revisit only if the work group wants a separate narrative example for absent expression results or a broader review of how the DefinedParameters profile is surfaced, neither of which is required by the published FHIR-32965 resolution.
