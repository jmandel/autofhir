FHIR-39508: Audit SupplyRequest definition migration

Issue request:
FHIR-39508 was a Published/Persuasive R5 Orders and Observations change request asking to update the SupplyRequest root definition from "A record of a request for a medication, substance or device used in the healthcare setting." to "A record of a request to deliver a medication, substance or device used in the healthcare setting to a particular destination for a particular person or organization." Jira records the resolution as "Make proposed change" with an 8-0-0 vote.

Initial application:
The issue was applied before R5 publication. Commit 27bf34f71215b699369415aa0d89d0c5caf3dac1, titled "FHIR-39508", changed source/supplyrequest/structuredefinition-SupplyRequest.xml so the SupplyRequest root element definition uses the requested delivery/destination/person-or-organization wording. The retained local SupplyRequest StructureDefinition still contains that approved root element definition.

Additional context:
FHIR-24936 had previously changed the top-level StructureDefinition.description for SupplyRequest to non-patient-specific healthcare-product wording, so the different description value in the current XML is not an unmodified copy of the old FHIR-39508 text and should not be overwritten by this issue. FHIR-39509, FHIR-39510, and FHIR-39511 are neighboring SupplyRequest issues from the same 2022 OO work package and are already represented on the combined branch. Later, commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed SupplyRequest and related immature OO resources from the active core resource/work-group lists and pointed core narrative to the OO Incubator IG. Current source/fhir.ini has no active supplyrequest entry, while the current HL7/oo-incubator SupplyRequest resource source contains the same approved FHIR-39508 definition.

AutoFHIR reconciliation:
This empty audit commit makes no core source change. The requested definition was historically applied to the retained local SupplyRequest source, there is no active core source occurrence of the old definition to fix, and current active SupplyRequest resource ownership is outside the FHIR core build in HL7/oo-incubator, where the authoritative StructureDefinition also has the approved wording.

Recommendation:
Keep this external-repo audit commit as-is. Do not edit dormant core SupplyRequest files for FHIR-39508; future SupplyRequest definition changes should be made in the OO Incubator source unless core re-adopts the resource into the active build.
