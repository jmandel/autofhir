FHIR-34171: Audit ValueSet scope cleanup

Issue request:
FHIR-34171 was a Published R5 Vocabulary change request, resolved Persuasive with Modification, after asking to remove ValueSet.scope and its subcomponents because implementers were using ValueSet.description for the same purpose. The final resolution narrowed the R5 change to updating the ValueSet.scope short/definition so scope would further clarify ValueSet.description.

Initial application:

The related FHIR-35988/FHIR-35989 compromise was then applied by f564419fa5acd52f22b74a5ab4e0452b4091d981, updating ValueSet.description's comment and removing ValueSet.scope.focus.

Additional context:
source/fhir.ini lists ValueSet as an active resource, so source/valueset/structuredefinition-ValueSet.xml is the authoritative current source for this check. Current source no longer contains ValueSet.scope at all: git commit 40306e5cd9c1b1e3eb6f115de16a8da3aa13a351 removed ValueSet.scope and all remaining subelements for the R6 terminology cleanup. FHIR-35988 and FHIR-35989 already have no-change audit commits on the combined branch, FHIR-53122 is a later FHIR-extensions resolved-change-required request for a replacement extension rather than an applied core change, and FHIR-54123 is still Triaged.

AutoFHIR reconciliation:
