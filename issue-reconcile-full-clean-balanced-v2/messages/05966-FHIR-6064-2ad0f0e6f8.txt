FHIR-6064: Audit ClinicalImpression RiskAssessment links

Issue request:
FHIR-6064 was a Published/Persuasive Patient Care change request raised against DSTU1 ClinicalImpression. It asked that RiskAssessment be an allowed resource for ClinicalImpression.investigations.item and that prognosis be able to point to a RiskAssessment.

Initial application:
The investigation side appears to have been applied just before the Jira-tagged SVN #9058 commit: git commit ca8df34006df02f9b2a896eaf41a72e1d418fe9d added RiskAssessment to ClinicalImpression.investigations.item in the old spreadsheet source. The Jira-commented SVN #9058 commit, 127b8fa2717d9a7b08169daaf955d8a9c3ec9aa5, included #6064 in its subject and split prognosis into prognosisCodeableConcept plus prognosisReference, with prognosisReference typed as Reference(RiskAssessment).

Additional context:
Later Patient Care decisions changed the artifact surface. FHIR-18860 removed ClinicalImpression.investigation and made supportingInfo the broad Reference(Any) home for investigation results. FHIR-46596 renamed ClinicalImpression to ClinicalAssessment. FHIR-50412 later collapsed the split prognosis fields to a single ClinicalAssessment.prognosis CodeableReference that still targets RiskAssessment. Finally, commit fad1b9cf84ef652e88947e1a13b026c62f95334e removed ClinicalAssessment from the active fhir.ini build-scope lists, leaving both ClinicalImpression and ClinicalAssessment source folders as inactive remnants in this checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The inactive ClinicalImpression source still has prognosisReference targeting RiskAssessment and supportingInfo as Reference(Resource) for investigation results; the inactive ClinicalAssessment source has prognosis as CodeableReference targeting RiskAssessment and supportingInfo as Reference(Resource). The current active build has no ClinicalImpression or ClinicalAssessment resource entry to correct.

Recommendation:
Keep this external-repo/build-scope audit as-is for the current core build. If Patient Care or FMG reintroduces ClinicalAssessment/ClinicalImpression into source/fhir.ini, verify the active source preserves RiskAssessment for prognosis and continues to allow RiskAssessment as supporting information/investigation evidence.
