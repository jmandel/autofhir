FHIR-41281: Audit removed MedicationKnowledge search parameters

Issue request:
FHIR-41281 was Applied/Persuasive for R6 as a Pharmacy technical correction. It asked that the MedicationKnowledge `packaging-cost` and `packaging-cost-concept` SearchParameter FHIRPath expressions use the correct polymorphic casts, with the reporter correcting `packaging-cost` from `Quantity` to `Money`.

Initial application:
The issue was partly applied before this reconciliation by two issue-tagged commits. Commit 7b36920b056b6c8f1b25e9ed0553b6d5801a8be4 added the two missing SearchParameter expressions and build path extensions, initially using `Quantity` for `packaging-cost`. Commit b505fe06fbd005aca4dc72f6de4bd491ba2f1f7c then changed the normative `packaging-cost` SearchParameter expression to `MedicationKnowledge.packaging.cost.cost as Money`.

Additional context:
MedicationKnowledge is no longer an active current-build resource. Commit 5a4307d78b0209f61bbc68d582c1e190b3aaee5c removed `MedicationKnowledge` from the active `source/fhir.ini` resource list and related generated-resource metadata, while leaving inactive source files behind. The current build URL for `medicationknowledge.html` returns 404. The inactive bundle still has a stale build-only path extension saying `as Quantity`, but that file no longer feeds a current MedicationKnowledge page or current SearchParameter artifact.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing the inactive MedicationKnowledge search-parameter bundle would not correct the current FHIR build, and the active current specification no longer publishes these MedicationKnowledge search parameters.

Recommendation:
Keep this audit commit as-is for the current core build. If MedicationKnowledge is restored to core or moved to another maintained specification, review the inactive search-parameter bundle and ensure the build path extension for `packaging-cost` is also changed to `MedicationKnowledge.packaging.cost.cost as Money` before republishing the artifact.
