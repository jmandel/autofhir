FHIR-5823: Audit ClinicalAssessment status migration

Issue request:
FHIR-5823 was a Published/Persuasive with Modification DSTU1 Patient Care change request for the then Clinical Assessment / ClinicalImpression resource. It requested a workflow status element with at least entered-in-error, in-progress, and completed, and the approved resolution was to add status with those three codes.

Initial application:
The Jira comment records SVN 4976. The corresponding git-svn commit e4a78a43c53ab67becc8da30fb718eb97e5ad539 explicitly mentions #5823 and added ClinicalAssessment.status as 1..1 code with in-progress, completed, and entered-in-error. A same-day follow-up, ba8e9a7f5145cda0851ffb1283f65658d1b8b0c9, applied the same status change after ClinicalAssessment was renamed to ClinicalImpression.

Additional context:
Later Patient Care workflow work changed the status vocabulary but not the core requirement to have a required status. FHIR-14446 aligned ClinicalImpression.status with a subset of Event.status, specifically entered-in-error, completed, and in-progress. FHIR-22730 later changed the ClinicalImpression.status binding to the existing event-status value set so additional lifecycle codes such as on-hold and stopped could be used. FHIR-22841 separately confirmed entered-in-error status handling. FHIR-46596 renamed ClinicalImpression to ClinicalAssessment for R6, and commit fad1b9cf84ef652e88947e1a13b026c62f95334e then removed ClinicalAssessment from active core fhir.ini registrations while source/ballot-intro.html pointed ClinicalAssessment to the Patient Care incubator IG.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The seed request was historically applied, the retained core ClinicalImpression and ClinicalAssessment source still shows a required status element, and the current active core build no longer publishes either ClinicalImpression or ClinicalAssessment. The current PC incubator ClinicalAssessment artifact also exposes ClinicalAssessment.status as 1..1 code with a required event-status binding.

Recommendation:
Keep this external-repo audit as-is for FHIR core. Do not edit the inactive core ClinicalImpression or ClinicalAssessment directories for FHIR-5823; any future changes to the maintained ClinicalAssessment resource should be made in the Patient Care incubator source while preserving a required status element.
