FHIR-41428: Audit AI/ML device scope wording

Issue request:
FHIR-41428 was an Applied/Persuasive R6 OO change request asking to clarify in the Device and DeviceDefinition scope statements that software includes algorithms, artificial intelligence, machine learning, and similar software-based device forms.

Initial application:
The OO 2023-06-12 minutes record the 10-0-0 motion for FHIR-41428. Source commit 9876b481748f91838aa9c35a7ea6f84c29186af3 applied the issue by adding a "Software as a device" AI/ML paragraph to source/device/device-introduction.xml, but did not update DeviceDefinition in that commit.

Additional context:
Device and DeviceDefinition are both active R6 resources in source/fhir.ini. Later Applied issues FHIR-38951 and FHIR-51702, with the same disposition, explicitly directed editors to remove the AI/ML paragraph from Device Scope and Usage and add/update the Software section in DeviceDefinition instead. Current DeviceDefinition source includes the SaMD/DTx, algorithms, AI, and ML wording; current Device source still states that Device covers software applications/algorithms and points to DeviceDefinition for detailed device categories. No directly relevant Zulip thread was found that conflicts with this Jira/source history.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing the removed AI/ML paragraph on the Device page would contradict the later Applied FHIR-38951/FHIR-51702 decisions, while the current DeviceDefinition Software section carries the clarifying AI/ML content requested by FHIR-41428.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed unless OO wants to reverse the later FHIR-38951/FHIR-51702 decision and duplicate the SaMD/AI/ML wording back onto the Device page.
