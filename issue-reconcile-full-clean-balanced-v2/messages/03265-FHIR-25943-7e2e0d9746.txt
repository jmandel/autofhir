FHIR-25943: Audit RegulatedAuthorization holder wording

Issue request:
FHIR-25943 was Published/Persuasive for R5 and asked that RegulatedAuthorization.holder stop implying only a drug Marketing Authorization Holder, noting that regulated authorizations can cover licence holders beyond organizations in some real-world cases.

Initial application:
The issue was applied in git commit 5411501c7d637811fdd399d93ab67c684c5b3abf, which changed the then-active RegulatedAuthorization spreadsheet wording from "Marketing Authorization Holder" to "The organization that holds the granted authorization". The current build now uses source/regulatedauthorization/structuredefinition-RegulatedAuthorization.xml rather than the retired spreadsheet source.

Additional context:
BRR's 2020-05-05 minutes record that FHIR-25943 and the related subject-reference issue FHIR-25941 were accepted 9-0-0, with the explicit note that the holder reference did not need to change from Organization. Later Published issue FHIR-31844 re-clarified the same element and established the current wording: "The organization that has been granted this authorization, by some authoritative body (the 'regulator')." The active fhir.ini entries keep RegulatedAuthorization in the current build, and current source no longer uses "Marketing Authorization Holder" as the element short/definition for RegulatedAuthorization.holder.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative StructureDefinition already removes the misleading Marketing Authorization Holder wording while preserving the Organization target profile that BRR explicitly chose not to change. Changing the target profile or replacing the later FHIR-31844 wording would conflict with later published context rather than reconcile FHIR-25943.

Recommendation:
Keep this audit commit as-is. Revisit only if BRR opens a new tracker to broaden RegulatedAuthorization.holder beyond Organization; FHIR-25943 itself is already represented correctly in the current source.
