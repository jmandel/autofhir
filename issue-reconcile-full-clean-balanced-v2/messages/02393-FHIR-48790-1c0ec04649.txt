FHIR-48790: Audit moved MPHO biologicalSourceEvent wording

Issue request:
FHIR-48790 is an Applied/Persuasive OO change request for the BiologicallyDerivedProduct Medical Product of Human Origin profile. It asked that the `.biologicalSourceEvent.value` short/definition stop saying "Unique identifier of the MPHO item" and instead say "Unique identifier of the donation, collection or pooling event from which the MPHO item was derived", because the event identifier may be shared by multiple MPHO items.

Initial application:
The issue was applied in core by commit abdceedb5a8d97f5e86445081845d6ddfa3b4e6d, whose subject references FHIR-48790 and whose patch changed the MPHO profile source. The patch changed the old MPHO-item wording in source/biologicallyderivedproduct/structuredefinition-profile-medicalproductofhumanorigin.xml to the requested donation/collection/pooling wording.

Additional context:
The MPHO profile is no longer a current core build artifact. The active BiologicallyDerivedProduct resource remains in source/fhir.ini, but current core source has no StructureDefinition/medicalproductofhumanorigin source or IG reference; source/biologicallyderivedproduct/biologicallyderivedproduct-introduction.xml now says the Medical Product of Human Origin profile was moved to the OO Incubator IG and is still under development. The current OO Incubator profile source at HL7/oo-incubator input/fsh/Profile-MedicalProductOfHumanOrigin.fsh carries the requested wording on biologicalSourceEvent.value. The base core BiologicallyDerivedProduct.biologicalSourceEvent comment also already explains that a single biologicalSourceEvent identifier may appear on multiple products.

AutoFHIR reconciliation:
This commit makes no source change in FHIR core. The only profile element named by the issue now belongs to the external OO Incubator IG, and the migrated external source already contains the requested biologicalSourceEvent.value wording.

Recommendation:
Keep this external-repo audit commit as-is. No FHIR core source edit is appropriate unless the MPHO profile is moved back into core; maintainers of the OO Incubator profile should preserve the current biologicalSourceEvent.value wording if that profile changes.
