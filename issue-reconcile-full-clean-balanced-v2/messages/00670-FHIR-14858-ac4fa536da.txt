The FHIR Extension Pack checkout contains no OccupationalData or ODH PHIN VADS value-set definitions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Any remaining OccupationalData value-set XML under source/occupationaldata is out of the current build, so editing those files would not correct the current FHIR core specification. The seed is therefore reconciled as external to the current core build rather than as a current-source terminology fix.

Recommendation:
Keep this audit commit as-is. If ODH/PHIN VADS terminology needs current maintenance, perform that work in the active ODH implementation guide or other external source of truth, not in the retired core OccupationalData remnants.
