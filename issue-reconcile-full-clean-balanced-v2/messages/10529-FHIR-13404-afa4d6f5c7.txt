FHIR-13404: Audit Health Canada NPN URI registration

Issue request:
FHIR-13404 was a Published/Persuasive with Modification FHIR-core change request for STU3. It asked to add http://hl7.org/fhir/sid/ca-hc-npn as the Health Canada Natural Product Number code system URI and also asked for http://hl7.org/fhir/ValueSet/ca-hc-npn; the accepted resolution was to add the URI but not generally add national value sets to the FHIR specification.

Initial application:
The issue was applied by svn 14482 / git 54f9e4d, which added a Health Canada Natural Product Number row for http://hl7.org/fhir/sid/ca-hc-npn to source/terminologies-systems.html. No ca-hc-npn value set was added, consistent with the resolution. A later related correction, FHIR-30280, fixed the row's OID from the DIN OID to 2.16.840.1.113883.5.1107 before the row was removed from the core page.

Additional context:
FHIR-37853 later made HL7 Terminology the authoritative source for external terminology details and removed many external rows, including ca-hc-npn, from the active core Code Systems page. The active source/terminologies-systems.html and source/identifier-registry.html pages now direct readers to HL7 Terminology/THO for external code systems and identifier systems. THO 7.1.0 contains NamingSystem-v3-hc-npn with the original FHIR URI maintained for backward compatibility and the current preferred CodeSystem URL of http://terminology.hl7.org/CodeSystem/v3-hc-npn; the THO package does not contain a ca-hc-npn ValueSet.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Re-adding the old national external-code-system row or adding the originally requested national value set would conflict with later source-of-truth policy and with FHIR-13404's accepted resolution.

Recommendation:
Keep this audit commit as-is. Future updates to Health Canada NPN metadata should be handled in THO/UTG, while FHIR core should continue to point implementers to THO instead of maintaining a duplicate national terminology row.
