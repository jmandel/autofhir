FHIR-13330: Audit ISO 3166 alpha-2 ValueSet

Issue request:
FHIR-13330 was Published/Persuasive for STU3 after the Vocabulary WG agreed to add a core ValueSet for ISO 3166 Part 1 two-letter country codes, using the existing urn:iso:std:iso:3166 code system and motivated by interoperable bindings such as national Address.country profiles.

Initial application:
No git commit was found that names FHIR-13330 directly. The Jira comments say it was defined as part of the ISO 3166 changes, and git commit 4c41b4e23383efa8df22cf99fdc0511105015c5b ("rework ISO 3166") added source/terminologies/valueset-iso3166-1-2.xml plus the active source/fhir.ini valueset registration. The initial source was an extensional alpha-2 list.

Additional context:
The 2018-02-08 Vocab minutes record the same 8-0-1 motion: retain urn:iso:std:iso:3166 for ISO 3166 Part 1 legacy use and create a ValueSet resource for alpha-2 codes. Later FHIR-37971 refined this same ValueSet from a fixed enumeration to an intensional regex filter, and FHIR-39157 records the later expansion/tooling correction; these later decisions do not undo the seed request.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build-scope source/fhir.ini still registers iso3166-1-2, source/terminologies/valueset-iso3166-1-2.xml defines the ISO 3166 Part 1 2-letter ValueSet, and its compose includes urn:iso:std:iso:3166 filtered with [A-Z]{2}. The current build surface exposes http://hl7.org/fhir/ValueSet/iso3166-1-2 with the same filter.

Recommendation:
Keep this no-change audit commit. FHIR-13330 is already correctly represented in core; any future work on ISO 3166 URI policy, CLD style, or terminology-server expansion behavior should remain under the later dedicated trackers rather than reopening this seed.
