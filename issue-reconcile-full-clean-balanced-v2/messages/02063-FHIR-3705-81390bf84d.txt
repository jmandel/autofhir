FHIR-3705: Audit Immunization patient rename

Issue request:
FHIR-3705 was a Published/Persuasive FHIR-core Immunization change request from the PHER work group. It asked to rename Immunization.subject to Immunization.patient because the only reasonable subject target for Immunization was Patient, matching the broader naming guideline to use patient when Patient is the only target.

Initial application:
The change appears to have been applied in git commit 64fbbf28ef27948a7944954073c8df878bac2bc9 on 2015-02-13, whose subject explicitly included "[#3705] Immunization.Subject renamed to Patient". That commit renamed the element, examples, and the then-source search row from Immunization.subject/subject to Immunization.patient/patient. No existing commit with Issue-Reconcile-Key: FHIR-3705 was found on the combined branch before this audit.

Additional context:
Immunization is an active resource in source/fhir.ini. The current authoritative StructureDefinition source has element id/path Immunization.patient, cardinality 1..1, and Reference(Patient), with a committee note carrying #3705. The current Immunization search parameter bundle defines Immunization-patient and no Immunization-subject search parameter. Later related issue FHIR-7897 supports that outcome by recording the pattern that resources with a patient element should have patient search parameters and not duplicate subject search parameters. FHIR-3706 is the same naming-change family for ImmunizationRecommendation, but it is a separate artifact and is not decided by this seed audit. Zulip and Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped source already reflects the requested rename and the adjacent current search-parameter surface is consistent with later Jira guidance.

Recommendation:
Keep this empty audit commit as-is. No FHIR core source follow-up is needed for FHIR-3705 unless a future work-group decision changes the patient-vs-subject naming policy.
