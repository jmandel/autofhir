Additional context:
FHIR-48393 was later Applied/Persuasive for R6 and explicitly removed ShareableActivityDefinition, ShareableLibrary, and related Shareable/Publishable profiles from the base specification because those profiles moved to CRMI. Current Clinical Reasoning and Shareable pattern narrative directs implementers to CRMI for Shareable, Publishable, Computable, and Executable profiles. Community searches found no FHIR-32637-specific contradiction; the related CDS agenda for FHIR-48393 records the broader rationale that base FHIR should not carry resource profiles.

AutoFHIR reconciliation:

Recommendation:
Keep this no-change audit as-is for core FHIR. If the current ShareableActivityDefinition profile needs adjustment, do that in CRMI rather than restoring the profile in this repository.
