FHIR-28598: Audit MedicationKnowledge status wording

Issue request:
FHIR-28598 was a Published/Persuasive with Modification Pharmacy change request raised against R4 and applied for R5. It asked to clean up MedicationKnowledge.status so it described whether the medication referred to by the MedicationKnowledge was in active use within a drug database or inventory system, and to update the definitions of the corresponding status codes.

Initial application:
The issue was applied before this reconciliation. Git commit 7453f87bfcb5eeba6020113412508cb95e5d4f0a changed source/medicationknowledge/structuredefinition-MedicationKnowledge.xml to the requested drug-database/inventory wording, and git commit 353a04689ac043c554bac32cf7a6bf9c5425dc99 added source/medicationknowledge/codesystem-medicationknowledge-status.xml with matching active, entered-in-error, and inactive definitions.

Additional context:
Later Pharmacy issue FHIR-32801 made MedicationKnowledge a MetadataResource so it could follow canonical and metadata resource patterns. The combined branch already contains commit 7161c9a41e0b10197fc857580413a05e5cdfcc92 for FHIR-32801, which intentionally changed the authoritative MedicationKnowledge.status element to publication-status lifecycle semantics. FHIR-42901 and FHIR-45285 are later same-family decisions reinforcing CanonicalResource/MetadataResource compatibility. The old MedicationKnowledge status code system still contains the FHIR-28598 code definitions, but the current authoritative status binding is http://hl7.org/fhir/ValueSet/publication-status; the checked-in SVG still shows old wording and binding but is generated-looking and should be regenerated rather than hand-edited.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reapplying FHIR-28598 to MedicationKnowledge.status would reintroduce pre-MetadataResource medication inventory semantics that have been superseded for the active status element. The source that remains relevant to FHIR-28598's original status-code cleanup already contains the requested code definitions.

Recommendation:
Keep this audit commit as-is. Do not restore the old drug database/inventory wording to the active MedicationKnowledge.status element unless the Pharmacy work group reopens the MetadataResource decision. If generated diagrams or obsolete status terminology pages are still emitted, handle that as a separate generation or terminology-retirement cleanup rather than as FHIR-28598.
