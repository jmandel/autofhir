Issue request:
FHIR-55444 was Applied/Persuasive with Modification for R6 and requested removal of the deprecated ServiceRequest.specimen element once the ServiceRequest specimenSuggestion extension was available in the Extension Pack.

Initial application:
The change was applied before this reconciliation by PR #4006. Commit f22405098ca56696b5de3ef2359acb6e4333a661 removed the ServiceRequest.specimen element from source/servicerequest/structuredefinition-ServiceRequest.xml, and merge commit 9b0678c6a634bd26937fe5a8e806a9456e3340dd also removed the now-unreferenced contained specimen and specimen reference from source/servicerequest/servicerequest-example-lipid.xml while adding an R6 release-note block.

Additional context:
FHIR-34206 created the replacement specimenSuggestion concept and the Extension Pack checkout contains input/definitions/ServiceRequest/StructureDefinition-servicerequest-specimenSuggestion.xml. OO minutes on 2026-02-24 and 2026-03-06 connect this removal to FHIR-55444 and to the broader deprecated-element cleanup tracked by FHIR-53722/FHIR-55566. The active source/fhir.ini resources list includes servicerequest=ServiceRequest, so the checked ServiceRequest source is in current build scope. source/servicerequest/servicerequest.svg still contains a stale diagram link for ServiceRequest.specimen, but this is a generated-looking SVG artifact and the authoritative StructureDefinition and narrative source are correct.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current ServiceRequest StructureDefinition no longer defines ServiceRequest.specimen, the lipid example no longer uses it, current notes direct implementers to Specimen.request or the specimenSuggestion extension, and the replacement extension exists outside core in the Extension Pack.

Recommendation:
Keep this no-change audit as-is for core FHIR. Do not make an issue-specific source edit solely to source/servicerequest/servicerequest.svg; if that diagram is still used, it should be refreshed through the normal diagram generation/build maintenance path.
