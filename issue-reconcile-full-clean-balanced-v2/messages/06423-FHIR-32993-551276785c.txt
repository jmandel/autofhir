FHIR-32993: Audit BDP collection procedure extension

Issue request:
FHIR-32993 is a Published/Persuasive with Modification FHIR-core OO change request, raised against R4 and applied for R5, asking to add a way to link BiologicallyDerivedProduct.collection to the Procedure used to extract or produce the product. The accepted resolution was to add Procedure to the collection backbone via an extension rather than a mandatory core backbone element.

Initial application:
The issue was applied before this reconciliation. Commit b29cb4fc7a added StructureDefinition/biologicallyderivedproduct-collection-procedure and listed it in the BiologicallyDerivedProduct core implementation guide, commit 20ca25e23a corrected the extension value type to Reference(Procedure), and the Jira points to PR 1912/commit 07dd1f7063 in the same application branch. Later core commit dd468d4f17 removed the R5 extension definitions from the core source tree as part of the broader move of extensions out of R5 core source.

Additional context:
The current source/fhir.ini actively includes BiologicallyDerivedProduct as a build-scope resource. Current core source no longer owns the collection-procedure extension definition, but it still carries the historical release-note line for the R5 standard extension and the OID registry mapping. The current Extension Pack checkout contains input/definitions/BiologicallyDerivedProduct/StructureDefinition-biologicallyderivedproduct-collection-procedure.xml with context BiologicallyDerivedProduct.collection and value Reference(Procedure), limited to FHIR 4.0 through 5.0 and with replacement text directing R6 users to biologicallyderivedproduct.collection.procedure. Later related issues FHIR-44575 and FHIR-45637 are already represented on the combined branch: FHIR-44575 audited the R6 core element, and FHIR-45637 audited extension cleanup as external to core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The FHIR-32993 R5 extension is not missing from the current core checkout; it has moved to the Extension Pack, while current build-scope core source contains BiologicallyDerivedProduct.collection.procedure Reference(Procedure) 0..1 for R6 and therefore preserves the same implementer capability in the current resource model.

Recommendation:
Keep this audit commit as-is. No further core FHIR source work is needed for FHIR-32993; any future metadata adjustment to the legacy extension should be handled in HL7/fhir-extensions and coordinated with the already-published FHIR-45637 external-repo audit.
