FHIR-37441 was a Published/Persuasive R5 Clinical Genomics change request for MolecularSequence. It asked to replace the independent reference sequence representations (CodeableConcept, MolecularSequence reference, and string) with a single choice element, referenceSequence[x].

Initial application:

That commit removed MolecularSequence.relative.reference.referenceSeqId, referenceSeqPointer, and referenceSeqString from source/molecularsequence/structuredefinition-MolecularSequence.xml and added MolecularSequence.relative.reference.referenceSequence[x] with CodeableConcept, string, and Reference(MolecularSequence) types. PR #1943 was merged as 6251965e3c7b560768d498941a0ccc7a38cdc7de. Zulip discussion and the CG 2022-05-31 minutes show the choice proposal was discussed and then passed in the block vote.

Additional context:
FHIR-37486 later renamed the same MolecularSequence area, including referenceSequence[x] to startingSequence.sequence[x], so the exact element name changed after FHIR-37441 while preserving the choice-model intent. In R6, FHIR-51227 approved replacing the legacy MolecularSequence resource with MolecularDefinition. Current source no longer has source/molecularsequence or source/msq files; the active resource configuration does not list molecularsequence, and the remaining diagnostics page text says MolecularSequence has been replaced by MolecularDefinition.

Recommendation:
Keep this audit commit as-is for FHIR-37441. No core follow-up is needed for the referenceSeq choice request; any further MolecularDefinition or MolecularSequence-retirement work should be handled under the later R6 replacement trackers.
