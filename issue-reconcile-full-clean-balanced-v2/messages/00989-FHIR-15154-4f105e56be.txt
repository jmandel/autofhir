FHIR-15154: Audit Composition attester RelatedPerson support

Issue request:
FHIR-15154 is a Published/Persuasive FHIR-core Composition change request for STU3. It asked to add RelatedPerson as an allowed reference target for Composition.attester.party for caregiver or representative attestation use cases, while explicitly leaving DocumentReference alignment to a separate ticket.

Initial application:
No current commit explicitly mentions FHIR-15154, but the Jira comments state the work was already done. The same-change-family Jira FHIR-12289 records svn revision 13104, which maps to git commit 04fb3079bd44513f51cffc189ec0828259a77715; that commit changed the Composition spreadsheet source for Composition.attester.party from Reference(Patient|Practitioner|PractitionerRole|Organization) to Reference(Patient|RelatedPerson|Practitioner|PractitionerRole|Organization).

Additional context:
The current build has composition=Composition as an active resource in source/fhir.ini. The current Composition StructureDefinition source already lists http://hl7.org/fhir/StructureDefinition/RelatedPerson as a targetProfile for Composition.attester.party. The earlier FHIR-12289 issue asked for the same target on the same element, and the Zulip thread that led to FHIR-15154 confirms the request originated because STU3/current build did not yet support RelatedPerson at the time. Searches found no conflicting later Jira, Zulip, or Confluence evidence that would remove RelatedPerson from Composition.attester.party.
