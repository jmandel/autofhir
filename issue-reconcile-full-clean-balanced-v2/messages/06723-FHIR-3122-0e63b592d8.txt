FHIR-3122: Audit Encounter priority code system correction

Issue request:
FHIR-3122 was a Published/Persuasive PA change request for the Initial Draft Encounter resource. It reported that the ValueSet used by Encounter.priority, http://hl7.org/fhir/vs/encounter-priority, had been copied from the diet value set and incorrectly declared its code system as http://hl7.org/fhir/diet; it asked for that system to become an Encounter Priority URL.

Initial application:
The Jira comments say the issue was updated as part of tracker #2968. Git history confirms commit 1cf591a5ee changed the old source/encounter/valueset-encounter-priority.xml name from Diet to Encounter Priority and changed the copied diet system to an Encounter priority URL, and commit 7e4c173af1 corrected that URL to http://hl7.org/fhir/encounter-priority.

Additional context:
FHIR-2968 is the directly related Published tracker for the same copied Diet value-set problem. Later history moved the specification away from the local encounter-priority value set entirely: commit 21e6def5bf deleted source/encounter/valueset-encounter-priority.xml and source/encounter/codesystem-encounter-priority.xml and changed the Encounter.priority binding to v3 ActPriority. The current active Encounter resource source now binds Encounter.priority to http://terminology.hl7.org/ValueSet/v3-ActPriority, and current tracked source has no encounter-priority or http://hl7.org/fhir/diet reference for Encounter.priority.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original bad code-system URL is not present in the current build-scope Encounter source, and the old local Encounter Priority value set requested by the issue no longer exists in current source.

Recommendation:
Keep this no-change audit commit. No current FHIR core source correction is needed for FHIR-3122 unless a future work group decision reintroduces a local Encounter.priority value set.
