FHIR-12484: Audit moved ImmunizationRecommendation targetDisease change

Issue request:
FHIR-12484 was a Published/Persuasive FHIR-core PHER change request from DSTU2 asking ImmunizationRecommendation to support anticipated vaccinations known only by target disease. The approved resolution added recommendation.targetDisease, changed recommendation.vaccineCode from required to optional, and required each recommendation to have at least one of vaccineCode or targetDisease.

Initial application:
The change was applied in core before this reconciliation. Commit ebec85a82e70b6dd6ca073cd464927b015d17fff added targetDisease and the vaccineCode-or-targetDisease invariant, and commit 97be2c963f added an example containing targetDisease without vaccineCode. Before the resource was later removed from core, source/immunizationrecommendation/structuredefinition-ImmunizationRecommendation.xml carried imr-1, vaccineCode 0..*, and targetDisease 0..*.

Additional context:
FHIR-17773 later changed targetDisease from the original 0..1 proposal to 0..* for multi-disease vaccines such as MMR, so the repeated cardinality is an intentional later decision rather than incomplete application of FHIR-12484. The current core build no longer contains ImmunizationRecommendation in source/fhir.ini; commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed ImmunizationRecommendation and ImmunizationEvaluation from active core source and changed surviving core narrative links to the HL7 Immunization Incubator IG. The current external StructureDefinition at build.fhir.org/ig/HL7/immunization-incubator still has recommendation.vaccineCode 0..*, recommendation.targetDisease 0..*, and imr-1 requiring vaccineCode or targetDisease.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the FHIR core checkout. The requested core source change was historically applied, and the current authoritative ImmunizationRecommendation artifact is outside the active core build.

Recommendation:
Keep this empty audit commit as-is for core reconciliation. If future edits are needed, they should be made in the Immunization Incubator IG source after PHER review; no current FHIR-core source correction is indicated for FHIR-12484.
