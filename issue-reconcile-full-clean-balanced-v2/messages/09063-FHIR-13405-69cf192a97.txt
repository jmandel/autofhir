FHIR-13405: Audit IG grouping wording

Issue request:
FHIR-13405 was Published/Persuasive for FHIR-core ImplementationGuide. It reported that the ImplementationGuide structure descriptions mentioned ".page.package" twice and asked whether that obsolete/unclear wording was intentional; the accepted resolution changed the definition.package short text to "Grouping used to present related resources in the IG" and changed definition.package.name from references to resource/page package paths to a human-readable package title description.

Initial application:
The issue was applied in git-svn commit 85d8afaee8dad1b92ae7b2fdbf8c2efb8e3be90d, whose message says "GF#13405 - fix IG definitions" and whose svn id is build@14478, matching the Jira comment. That commit updated the then-authoritative ImplementationGuide spreadsheet by replacing the old ".page.package" and ".resource.package" wording with the accepted short and definition text.

Additional context:
The current build no longer uses the old STU3 spreadsheet source. ImplementationGuide is active in source/fhir.ini, and the active StructureDefinition now uses ImplementationGuide.definition.grouping and ImplementationGuide.definition.grouping.name. Later Published/Persuasive issue FHIR-19243 renamed ImplementationGuide.definition.package to grouping and ImplementationGuide.definition.resource.package to groupingId to avoid confusion with NPM packages. The combined branch already contains 784d7b576b8c95b5f3d198e7062e5667464fe030 for FHIR-19243, which removed remaining stale package-era wording from the current ImplementationGuide source and fhir.ini.
