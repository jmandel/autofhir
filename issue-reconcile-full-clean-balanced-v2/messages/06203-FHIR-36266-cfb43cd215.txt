FHIR-36266: Audit TestReport wording migration

Issue request:
FHIR-36266 was a Published/Persuasive FHIR-core technical correction for R5. It asked that the TestReport.identifier definition and TestReport.name short/definition refer to the TestReport itself instead of incorrectly saying the external identifier or informal name belonged to the executed TestScript.

Initial application:
The issue was applied by PR HL7/fhir#1768. Commit 7c18d5d967064b243fc662d289aaf171b229df87 changed source/testreport/structuredefinition-TestReport.xml from "TestScript" to "TestReport" for TestReport.identifier and TestReport.name, and the R5 checked history now contains the corrected TestReport wording.

Additional context:
Current core source no longer owns the TestReport resource definition. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed TestReport and TestScript from the active source/fhir.ini resource list and deleted source/testreport; source/fhir.ini now points to the FHIR Testing IG as an additional IG, and source/ballot-intro.html links TestReport there. The current Testing IG StructureDefinition-TestReport JSON also uses "TestReport" for identifier and name. Older tools/history release snapshots still show the pre-R5 wording for R4/R4B, but those historical artifacts are not current-build source corrections.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source was edited because the R5 correction is already represented, the current core build no longer includes TestReport as an active resource, and the current external Testing IG copy has the corrected wording.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-36266; any future TestReport wording maintenance belongs with the FHIR Testing IG rather than this core checkout.
