FHIR-24993: Audit QuestionnaireResponse repeating answers

Issue request:
FHIR-24993 was Published with a Persuasive resolution for FHIR-core QuestionnaireAnswers. It asked to clarify that repeated answers to a repeating question in QuestionnaireResponse are represented as one question item with multiple answer elements, not as multiple sibling question items each carrying one answer.

Initial application:
The issue was applied by git 0aae65acbdcf90f2dbcc5ba3b0c0a8493f7c1d60, which added the QuestionnaireResponse.item comment saying that repeating group items use separate item repetitions but repeating questions use a single question item with potentially multiple answers. That text remains in the active QuestionnaireResponse StructureDefinition source, with later wording refinements.

Additional context:
QuestionnaireResponse is active in source/fhir.ini. The originating Zulip thread records the exact ambiguity and Lloyd McKenzie's statement that option one is the rule. FHIR SDC minutes for 2019-12-05 list FHIR-24993 as persuasive. Later Published issue FHIR-33335 strengthened the same rule by adding qrs-2, an invariant whose human text says repeated answers are combined in the answers array of a single item; later issue FHIR-38853 retained and refined the group/question wording, and Applied issue FHIR-55973 only further constrained repeated answers to be distinct.

AutoFHIR reconciliation:
No source change is needed. Current active source already carries the requested clarification in QuestionnaireResponse.item, and the later qrs-2 invariant makes the requested representation enforceable for repeated question answers. Adding more prose would be redundant and would risk drifting from the existing StructureDefinition guidance.

Recommendation:
Keep this empty audit commit as-is. No follow-up core source work is recommended for FHIR-24993 unless the work group decides to change the underlying QuestionnaireResponse repeat model in a future issue.
