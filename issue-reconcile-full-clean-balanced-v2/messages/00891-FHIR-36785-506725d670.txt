FHIR-36785: Audit ImagingSelection code wording

Issue request:
FHIR-36785 was a Published, Persuasive with Modification R5 Imaging Integration change request to update ImagingSelection.code short to "Imaging Selection purpose text or code", update its definition to "Reason for referencing the selected content.", and also remove the Observation-derived Requirements and Comments text from ImagingSelection.code.

Initial application:
The June 2022 Imaging changes merged as c138fb1b9ed930251866ab1da3be7d524b3fb1d4 applied the requested short and definition in source/imagingselection/structuredefinition-ImagingSelection.xml, but the implementation still left the old Observation-derived comment and requirements in place at that time.

Additional context:
ImagingSelection remains an active built resource in source/fhir.ini. A later Applied R6 issue in the same ImagingSelection.code/category family, FHIR-48095, explicitly replaced the FHIR-36785 definition with "Identifies the type of imaging selection.", replaced the Observation-derived requirements with ImagingSelection-specific requirements, and removed the Observation-derived comment. Current authoritative XML matches that later decision, and the Event mapping exception file was updated to the same definition. A checked-in imagingselection.svg title still contains the older FHIR-36785 definition, but that is a generated-looking diagram artifact rather than the authoritative source for the element definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reapplying the original R5 definition now would undo the later Applied R6 decision, while the only remaining seed-requested cleanup not reflected literally is superseded by the later ImagingSelection-specific requirements text.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-36785 unless the Imaging Integration work group chooses to reopen the later FHIR-48095 wording.
