Issue request:
FHIR-17176 was a Published/Persuasive with Modification Imaging Integration request to add ImagingStudy.description as a 0..1 summary string for the image-manager-supplied study description, with DICOM Study Description (0008,1030) mapping and without using ImagingStudy.note for that meaning.

Initial application:
The request was applied in SVN 14695, represented in git as c5f22292a1056857e00a3a4c93ca2c4ffd1fa905, which added ImagingStudy.description to the old imagingstudy spreadsheet and moved the DICOM Study Description mapping off ImagingStudy.note. The 2021 source refactor carried the element into the current StructureDefinition source.

Additional context:
FHIR-12269 is the cited DICOM mapping tracker and explicitly says study-level description, if present, maps to (0008,1030), while note maps separately to (0040,0280). Later applied R6 issues FHIR-47672 and FHIR-47520 clarified the ImagingStudy.description wording and DICOM tag mapping labels without reversing the FHIR-17176 structural decision. ImagingStudy is active in source/fhir.ini, so source/imagingstudy/structuredefinition-ImagingStudy.xml is in current build scope.

AutoFHIR reconciliation:
