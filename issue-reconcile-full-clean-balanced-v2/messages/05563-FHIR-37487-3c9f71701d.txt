FHIR-37487: Audit SupplyDelivery BDP stock distribution

Issue request:
FHIR-37487 was Published/Persuasive for R5 by OO and asked to support stock distribution of biologically derived products using SupplyDelivery. The request proposed adding the biologicallyderivedproduct supply item type code, making SupplyDelivery.suppliedItem repeat, allowing multiple item[x] values under a suppliedItem, and allowing itemReference to target BiologicallyDerivedProduct.

Initial application:
The issue was applied before this reconciliation. Commit eea4f7198638823586424ed88baa0a7999e0a23a initially made suppliedItem and item[x] repeating and added the BiologicallyDerivedProduct target. Commit 4da15bbc38c273025d4e0ed973a63bcede9afa6f added the SupplyDelivery BDP terminology, examples, and description updates alongside FHIR-37742. Follow-up commit b26275e8e6b924481251a7423a0bf33f7869c9cc changed SupplyDelivery.suppliedItem.item[x] back to max 1, and the R5 published profile retained suppliedItem max * with item[x] max 1.

Additional context:
SupplyDelivery is no longer an active FHIR-core resource in this branch. Commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed supplydelivery and supplyrequest from source/fhir.ini and current core narrative pages point readers to the OO incubator SupplyDelivery artifact. The current OO incubator StructureDefinition and R5 published profile both carry the biologicallyderivedproduct code/target support and use repeated suppliedItem entries to reference each BDP in a consignment; the active BDP module text says each BDP is referenced in the SupplyDelivery resource.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing source/supplydelivery in this checkout would touch historical/out-of-build source, and the current core build no longer publishes a core SupplyDelivery profile. The remaining semantics for any desired item[x] cardinality change belong in the OO incubator artifact, not in this FHIR-core branch.

Recommendation:
Keep this external-repo audit commit as-is for FHIR-core. If OO wants to revisit whether SupplyDelivery.suppliedItem.item[x] should repeat despite the R5 and OO incubator shape, file or apply that follow-up in the OO incubator source; no current FHIR-core source edit is appropriate for FHIR-37487.
