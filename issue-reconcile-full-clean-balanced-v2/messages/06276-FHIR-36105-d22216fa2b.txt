FHIR-36105: Audit Boolean item controls

Issue request:
FHIR-36105 was a Published/Persuasive FHIR-core Questionnaire clarification asking that questionnaire-itemControl check-box and radio-button text make clear those controls can also guide items of type boolean, and that the Questionnaire Boolean-answer guidance be updated.

Initial application:
The issue was applied in git commit 687e88f506 ("FHIR-36105 - clarify boolean controls"), which updated the then-core questionnaire-item-control CodeSystem definitions for check-box and radio-button and updated source/questionnaire/questionnaire-notes.xml to mention traditional check-box controls in the Boolean guidance.

Additional context:
Questionnaire remains an active core resource in source/fhir.ini, and the current source/questionnaire/questionnaire-notes.xml still contains the Boolean-answer guidance added for this issue. The questionnaire-item-control CodeSystem and ValueSet were later removed from core by dd468d4f17 ("remove extensions from R5 source") and now live in the FHIR Extension Pack; the migrated CodeSystem there retains the FHIR-36105 check-box and radio-button definitions. The SDC minutes for 2022-03-10 record the FHIR-36105 persuasive decision, and no conflicting Zulip or Confluence discussion was found.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current core build source already contains the requested Boolean guidance, while the item-control terminology portion is no longer owned by this checkout and is already correct in the Extension Pack. Reintroducing or duplicating the CodeSystem text in core would be out of build scope and would create maintenance drift.

Recommendation:
Keep this no-change audit commit as-is. If future work changes itemControl wording, apply it in the Extension Pack or SDC-owned guidance rather than restoring retired core source files.
