FHIR-7816: Audit removed v2 validity period mapping

Issue request:
FHIR-7816 was a Published/Persuasive Pharmacy change request from the 2015 May DSTU QA process. It asked to remove the HL7 v2 mapping for MedicationPrescription.dispense/validityPeriod because RXD-3/RXD-19 do not express the prescription validity window.

Initial application:
The issue appears to have been applied in SVN-migrated commit 651364cb098a623c36afc1d6b9d56578507d897c, which removed `v2 Mapping = RXD-3-Date/Time Dispensed ? / RXD-19-Substance Expiration Date` from `MedicationOrder.dispenseRequest.validityPeriod` as part of tracker #7816 and related medication mapping cleanup. The current resource lineage is MedicationPrescription to MedicationOrder to MedicationRequest.

Additional context:
`source/fhir.ini` keeps `medicationrequest=MedicationRequest` active and records that MedicationPrescription became MedicationRequest. Current `source/medicationrequest/structuredefinition-MedicationRequest.xml` defines `MedicationRequest.dispenseRequest.validityPeriod` with Script 10.6 and RIM mappings only; source search finds no RXD-19/Substance Expiration Date v2 mapping on MedicationRequest. Community searches found no Zulip or Confluence evidence contradicting the Jira/source result.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already preserves the requested removal, and changing unrelated v2 mappings would exceed FHIR-7816.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed unless a future Pharmacy decision reopens MedicationRequest v2 mapping for prescription validity.
