FHIR-19348: Audit EBM draft resources

Issue request:
FHIR-19348 was a Published/Persuasive CDS change request raised against STU3. It asked to add draft Evidence-Based Medicine resources from the resource proposals for ResearchDefinition, ResearchElementDefinition, EffectEvidenceSynthesis, and RiskEvidenceSynthesis, with the Jira description noting that FMG discussion renamed ResearchDefinition to Evidence and ResearchElementDefinition to EvidenceVariable.

Initial application:
The issue was applied in the historical source by GF#19348 commit 7392c35bfb48152f5c542b7c5fe834016cd327d6 and merge commit ad0fad49508d67c14f892f8bd846e5d61e9db2d5, which added source folders, examples, spreadsheets, fhir.ini entries, hierarchy/resource list updates, and status-code changes for Evidence, EvidenceVariable, EffectEvidenceSynthesis, and RiskEvidenceSynthesis. No current source change is needed to re-apply that historical addition.

Additional context:
Later Published/Persuasive CDS decisions revised this same EBM family for R5. FHIR-24432 approved Evidence and EvidenceVariable as the ongoing draft resources while removing older draft resources, and FHIR-26967 explicitly recorded that EffectEvidenceSynthesis and RiskEvidenceSynthesis had been replaced by Evidence, were no longer used, and should be listed as removed resources with their source folders deleted. The current build follows that later state: source/fhir.ini has active resources for evidence and evidencevariable, lists EffectEvidenceSynthesis and RiskEvidenceSynthesis in [removed-resources], and the Clinical Reasoning Evidence and Statistics page documents Evidence and EvidenceVariable as current EBM resources.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. The seed issue's requested draft-resource addition was applied historically, and the apparent absence of two of the four original draft resources is the result of later final CDS decisions rather than a missing application of FHIR-19348.

Recommendation:
Keep this no-change audit commit as-is. Do not restore EffectEvidenceSynthesis or RiskEvidenceSynthesis to the current core build for FHIR-19348; any future change to that family should be evaluated under a new CDS decision because the current source already reflects the later approved EBM resource model.
