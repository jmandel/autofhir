FHIR-28283: Fix CQL UCUM system URI

Issue request:
FHIR-28283 was a Published/Persuasive FHIR-core CDS change request for R5 asking to add text, similar to the FHIRPath Quantity appendix, describing implicit conversion of UCUM definite-duration time-valued units to CQL calendar duration units in the Clinical Reasoning Using CQL/Using Expressions discussion.

Initial application:
The Jira comments cite commit c7660fc81c9a286d9f1db2210560f4d16a29a00f and HL7/fhir#2834. That commit added the requested Use of FHIR Quantity subsection, conversion table, and example to source/clinicalreasoning-topics-using-expressions.html, but introduced a typo in the UCUM canonical system URI as http://unitsofmeausure.org.

Additional context:
source/clinicalreasoning-topics-using-expressions.html is in the current build scope through the Clinical Reasoning hierarchy and module page. The FHIRPath appendix named by the Jira resolution uses the correct http://unitsofmeasure.org URI and the same conversion concept. Community and Confluence checks found no final core decision that supersedes the requested FHIR-specific Quantity-to-calendar-duration mapping.

AutoFHIR reconciliation:
This commit corrects only the misspelled UCUM canonical system URI in the issue-added Clinical Reasoning/CQL text, changing it to http://unitsofmeasure.org while leaving the already-applied conversion guidance intact.

Recommendation:
Keep this source fix as-is. It preserves the applied FHIR-28283 guidance and removes a misleading canonical URI that could otherwise cause implementers to use a non-existent UCUM system URL.
