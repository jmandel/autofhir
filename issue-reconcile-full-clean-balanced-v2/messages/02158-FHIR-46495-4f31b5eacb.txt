FHIR-46495: Audit subscription management styles

Issue request:
FHIR-46495 was an Applied/Persuasive FHIR-core change request to synchronize R6 subscription documentation with Backport IG work by describing in-band/client-managed and out-of-band/server-managed subscription styles. The requested scope was the Subscriptions Framework workflow, subscription-management description, conformance expectations, and Subscription resource wording so the resource was not presented as only client-created.

Initial application:
The requested work was applied before this reconciliation by git commit d51aae543e, which explicitly names FHIR-46495 and updates source/subscriptions.html, source/subscription/subscription-introduction.xml, source/subscription/subscription-notes.xml, the Subscription example, and the Subscription structure definition. That commit is already an ancestor of the current worker branch, master, and the combined branch.

Additional context:
FHIR-43505 and FHIR-43514 are the Backport IG change decisions that FHIR-46495 asked to carry into R6. The 2024-08-05 FHIR-I minutes confirm the group chose the terms In-band Subscription Management and Out-of-band Subscription Management and did not intend a substantive relaxation such as removing the existence of a Subscription. Current source matches that context: the framework page describes both workflow styles, splits conformance requirements, and explains error-management responsibility for out-of-band management; the Subscription resource page no longer depends on a subscriber-created-only model and links management/error details back to the framework page.

AutoFHIR reconciliation:
This audit commit intentionally makes no source changes. The current source already conveys the requested distinction and related conformance/error-management responsibilities, and additional wording would be redundant rather than a necessary specification correction.

Recommendation:
Keep this no-change audit commit as-is. No FHIR-core follow-up is needed for FHIR-46495 unless the work group later decides to further refine the subscription-management terminology or conformance model.
