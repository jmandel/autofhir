FHIR-31677: Audit DetectedIssue category value set

Issue request:
FHIR-31677 was Published/Persuasive for R5 and asked to update the Detected Issue Category value set so it also included v3 ActCode concepts where concept is-a _ClinicalActionDetectedIssueCode. The motivating use case was CAREGAP for the DEQM Gaps In Care DetectedIssue profile.

Initial application:
No source commit directly tagged FHIR-31677 was found. The Jira comments say the issue was added in FHIR-39309, and commit b0e4d55a7158f6dcfb787c29d3971dfdd6db31ec (J#39309) applied that same request by adding an _ClinicalActionDetectedIssueCode include to source/detectedissue/valueset-detectedissue-category.xml.

Additional context:
FHIR-39458 was later Applied/Persuasive for R6 and decided that DetectedIssue.code should not be bound to the same value set as DetectedIssue.category. It directed the category value set to include only category codes and a new code value set to carry the detailed detected issue codes. Commit 34181b9f2184a72b527d9f5b26c234c0c07669ed implemented that split by binding DetectedIssue.code to http://hl7.org/fhir/ValueSet/detectedissue-code, moving the _ClinicalActionDetectedIssueCode include there, and restricting DetectedIssueCategory to FOOD, DRUG, ALGY, and DUPTHPY. UP-175 and UP-358 explain that CAREGAP and CODINGGAP are ActCode descendants under _ClinicalActionDetectedIssueCode.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped DetectedIssue resource is active in source/fhir.ini, source/detectedissue/structuredefinition-DetectedIssue.xml binds DetectedIssue.category to detectedissue-category and DetectedIssue.code to detectedissue-code, and source/detectedissue/valueset-detectedissue-code.xml includes _ClinicalActionDetectedIssueCode. Re-adding that include to detectedissue-category would undo the later FHIR-39458 decision.

Recommendation:
Keep this no-change audit as-is. If a profile still needs R4/R5-compatible CAREGAP behavior, address that in the relevant profile or version-specific guidance rather than changing the current core category value set unless CDS explicitly reverses FHIR-39458.
