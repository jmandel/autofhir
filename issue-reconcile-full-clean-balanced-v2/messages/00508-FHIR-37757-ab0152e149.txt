FHIR-37757: Audit GenomicStudy methodType binding

Issue request:
FHIR-37757 is a Published Clinical Genomics R5 change request resolved Persuasive with Modification. It asked to add terminology support for GenomicStudy.analysis.methodType; the final resolution requested a CodeSystem and ValueSet for example method-type codes drawn from NCBI-GTR method category, major method category, and primary methodology lists.

Initial application:
The issue was first partially applied in commit f2532f7b92fa by adding FISH, karyotyping, and MSI examples to the GenomicStudy.analysis.methodType definition. The full terminology application followed on the genomicStudy_terminologyBinding branch: c75c654f6beb added the methodType ValueSet source and element binding, 49a719de5b73 renamed the ValueSet file with its XML extension, bbf996d07c52 split the local CodeSystem from the ValueSet, and PR #2116 merged the terminology-binding branch in ff7c5cbbec68.

Additional context:
The retained GenomicStudy source still has the requested example binding to http://hl7.org/fhir/ValueSet/genomicstudy-methodtype, with corresponding CodeSystem and ValueSet files whose description and implementation notes cite NCBI-GTR as the source for the example method-type terms. The R5 published StructureDefinition and release5 history artifacts expose the same binding. Current source/fhir.ini no longer includes GenomicStudy in the active resource/build-scope entries after the 2025 remove-additional-resources change, so editing retained GenomicStudy source would not be a current-build correction. FHIR-37758 and FHIR-37759, the adjacent terminology-binding issues for changeType and input/output data format, are already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested R5 change is already present in retained source and the published R5 artifact, and the artifact is outside current core build scope.

Recommendation:
Keep this audit commit as-is. Do not edit the inactive core GenomicStudy source for this issue unless GenomicStudy is reintroduced to the current build; if that happens, preserve the existing methodType CodeSystem, ValueSet, NCBI-GTR attribution, and example binding unless the Clinical Genomics work group makes a newer terminology decision.
