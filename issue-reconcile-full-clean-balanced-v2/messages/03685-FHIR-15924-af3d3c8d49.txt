FHIR-15924: Audit care-gap DetectedIssue code

Issue request:
FHIR-15924 was a Published/Persuasive CDS change request raised against STU3 and applied for R5. It asked for a gap-in-care code in ActCode and the Detected Issue Category value set, with the resolution to add the DetectedIssue code via harmonization.

Initial application:
The terminology prerequisite was implemented in UTG proposal UP-175, which added CAREGAP as a descendant of _ClinicalActionDetectedIssueCode in v3 ActCode and made that parent active. FHIR-39309 then applied the FHIR-side value-set update in commit b0e4d55a7158f6dcfb787c29d3971dfdd6db31ec by adding _ClinicalActionDetectedIssueCode to source/detectedissue/valueset-detectedissue-category.xml; Jira comments on FHIR-15924 record that DetectedIssueCategory then included CAREGAP and completed the issue as applied.

Additional context:
FHIR-39458 later made an Applied/Persuasive R6 decision that DetectedIssue.category and DetectedIssue.code should not share the same broad value set. Commit 34181b9f2184a72b527d9f5b26c234c0c07669ed implemented that later decision by restricting DetectedIssueCategory to category-level codes and creating DetectedIssueCode for detailed detected issue codes, including the _ClinicalActionDetectedIssueCode branch where CAREGAP belongs. The combined branch already contains no-change audits for the closely related FHIR-27910 and FHIR-31677 requests, so this commit does not duplicate those decisions.

AutoFHIR reconciliation:
This is an empty no-change audit commit. Current source/fhir.ini lists DetectedIssue as an active resource, DetectedIssue.category binds to the restricted Detected Issue Category value set, and DetectedIssue.code binds to the Detected Issue Code value set that includes _ClinicalActionDetectedIssueCode. Re-adding CAREGAP to the category value set would contradict the later FHIR-39458 split.

Recommendation:
Keep this audit commit as-is. Do not change core source for FHIR-15924 unless the work group reverses FHIR-39458; implementations that need the care-gap concept should use v3 ActCode CAREGAP as a detailed DetectedIssue.code.
