FHIR-34388: Audit PATCH history conflict

Issue request:
FHIR-34388 is Published/Persuasive for R5 and asked whether the Bundle history rule should mention PATCH where it said that PUT or POST history entries SHALL contain a resource. The recorded resolution was to change the sentence to say PUT, PATCH or POST.

Initial application:
The request was applied in git commit 27121ee5c4bca5fb4eae4bc20fff012202eea5ce, which changed source/bundle/bundle-notes.xml so the Bundle history narrative now says that POST, PATCH, or PUT entries include a resource. The Bundle resource is active in source/fhir.ini, so source/bundle/bundle-notes.xml feeds the current build.

Additional context:
FHIR-19620 is also Published/Persuasive and records the more specific decision that PATCH interactions create history entries but are represented as PUT in history Bundles, with an invariant prohibiting entry.request.method PATCH when Bundle.type is history. Current source still contains that bdl-14 invariant and the HTTP history page still says a PATCH interaction is represented as PUT. The 2018 Zulip discussion linked to FHIR-19620 supports that representation, while the later FHIR-34388 Zulip thread and FHIR-I minutes support the narrower wording change. FHIR-50118 is a later Triaged issue about bdl-3b wording/expression mismatch, but it is not final and does not resolve the PATCH conflict.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current source already contains the literal FHIR-34388 wording, but accepting it as the current conformance rule would require reversing or narrowing the still-published FHIR-19620 invariant and HTTP history guidance. That is a work-group decision, not a safe automated reconciliation.

Recommendation:
Keep this human-review audit record and ask FHIR-I to decide whether history Bundle entries may use entry.request.method PATCH. If yes, remove or revise bdl-14 and update the HTTP history text. If no, remove PATCH from the Bundle history resource-inclusion sentence and align bdl-3b/profile wording with the PUT-as-history representation.
