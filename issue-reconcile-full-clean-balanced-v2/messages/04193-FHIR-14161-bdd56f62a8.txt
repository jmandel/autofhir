FHIR-14161: Audit ResearchStudy phase value set

Issue request:
FHIR-14161 was Published/Persuasive for STU3 and requested that, because a new ResearchStudy.phase element was being added to ResearchStudy, the associated value set also be added. Jira records the change as made and published in the Dec 2017 FHIR ballot.

Initial application:
No current git commit explicitly tagged FHIR-14161 was found, but the November 2017 ResearchStudy update commit 61b5fa557635a9d272e7508b2c7e139a895be930 added ResearchStudy.phase with the ResearchStudyPhase binding and explicit phase codes in the then-authoritative ResearchStudy spreadsheet. Historical checked-in release artifacts show the value set present in the R4 publication surface as http://hl7.org/fhir/ValueSet/research-study-phase.

Additional context:
ResearchStudy is active in the current build through source/fhir.ini, and the current authoritative StructureDefinition source still has ResearchStudy.phase as a 0..1 CodeableConcept bound to a research-study-phase value set. Later same-family decisions changed details of that binding: FHIR-14288 lowered the old clinicaltrials.gov/US-realm binding strength for STU3, FHIR-49963 later explicitly restored Preferred strength for R6, and FHIR-50710 moved ResearchStudy.phase to the THO value set http://terminology.hl7.org/ValueSet/research-study-phase and removed retired core terminology definitions. FHIR-14288 and FHIR-50710 are already represented by separate combined-branch reconciliation commits.

AutoFHIR reconciliation:
This audit commit makes no source change. The current core source already satisfies the FHIR-14161 requirement at the current-build level: the element exists and is bound to the current THO ResearchStudy phase value set. Re-adding the retired core ValueSet XML would conflict with the later FHIR-50710 THO migration, and changing binding strength would duplicate or contradict later issue decisions.

Recommendation:
Keep this no-change audit. Future work should not reintroduce the old core research-study-phase ValueSet for FHIR-14161; any new change to the phase terminology should be handled as a new BR&R/THO decision or under the later controlling ResearchStudy binding issues.
