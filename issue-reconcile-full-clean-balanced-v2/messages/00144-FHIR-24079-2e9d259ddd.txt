FHIR-24079: Audit primitive-extension JSON examples

Issue request:
FHIR-24079 was a Published FHIR-core change request with resolution Not Persuasive with Modification for ActivityDefinition and PlanDefinition generated JSON examples. The reporter noted timingTiming._event primitive extensions without a parallel timingTiming.event array containing null, and the final resolution asked to clarify JSON primitive array handling as two equal length arrays and correct the generated examples to include event: [ null ].

Initial application:
No prior source commit or combined-branch audit commit was found for FHIR-24079. The affected ActivityDefinition and PlanDefinition artifacts are active resources in source/fhir.ini, but the examples themselves are XML source and the complained-about JSON examples are generated by the build. Jira and Zulip discussion from Bryn Rhodes identified the original symptom as a serialization/tooling question rather than hand-authored JSON example source.

Additional context:
FHIR-32806 is a later Published FHIR-I decision for the same JSON primitive array null-handling rule. It resolved that when a JSON element array and its _element array differ in length, implementations SHALL infer null suffixes in the shorter array; current source/json.html also says arrays containing only null elements SHOULD be omitted entirely. That later rule means a generated timingTiming object with _event and an omitted all-null event array is now conformant, even though FHIR-24079's earlier resolution text requested an explicit event: [ null ] array.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current JSON chapter already contains the later FHIR-32806 null-suffix/all-null omission rule, and the active ActivityDefinition/PlanDefinition examples remain XML inputs whose JSON surface is generated under that rule. Requiring equal-length arrays for all-null primitive values here would reverse the later FHIR-I clarification.

Recommendation:
Keep this audit commit as-is. Do not force event: [ null ] into these generated JSON examples unless the work group reopens or revises the current FHIR-32806 JSON null-array guidance.
