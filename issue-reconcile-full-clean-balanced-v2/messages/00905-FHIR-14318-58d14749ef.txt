FHIR-14318 was a Published FHIR-core Observation change request, resolved Persuasive with Modification, asking to add a "StructuralVariant" profile under the STU3 Observation-genetics profile with Sequence linkage, LOINC-coded structural variant assessment/method/copy-number/location components, and related component groups. The accepted resolution said this was already applied using the DescribedVariant profile in the Genomics Reporting IG.

Initial application:
No FHIR-core git commit found in this checkout mentions FHIR-14318, and current core build configuration has active Observation and DiagnosticReport resources but no active Observation-genetics/StructuralVariant profile entry. The old Observation-genetics material remains only in historical release snapshots and retired/deprecated extension-pack definitions. The substantive application was in the external Genomics Reporting IG: the historical DescribedVariant page existed in the STU1 ballot, related component-group Jira issues cite HL7/genomics-reporting commit 04af6e5, and the current IG's Variant profile is the successor for this content.

Additional context:
Current core Observation and DiagnosticReport narrative tells implementers to use the Genomics Reporting IG for structured genomic data, and the current Genomics Reporting IG states that prior STU3/R4 Observation-genetics profiles largely map to its Variant profile. The current Variant profile carries the key requested semantics: Observation.code 69548-6, method binding, valueCodeableConcept, component slices for copy-number 82155-3, inner-start-end 81302-2, outer-start-end 81301-4, variation-code 81252-9, genomic-source-class, and allelic-state. Related FHIR-14319, FHIR-14320, FHIR-14322, and FHIR-14323 are FHIR-genomics-reporting issues in the same component-group family, so they are external background rather than additional FHIR-core decisions in this run.
