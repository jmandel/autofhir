FHIR-19289: Audit Claim example label

Issue request:
FHIR-19289 was Published with a Persuasive resolution. It asked to change the Claim examples list so the professional example was described as a Professional service claim rather than a Pharmacy service claim.

Initial application:
The 2018Sep rendered Claim examples page showed claim-example-professional with the duplicate text "Simple Pharmacy Service Claim" while claim-example-pharmacy also used that text. No git commit explicitly mentioning FHIR-19289 was found in the current source history. The current list source was recreated during the 2021 build-source rework with claim-example-professional already labeled "Simple Professional Service Claim".

Additional context:
Claim is an active resource in source/fhir.ini. The current source keeps two distinct examples: claim-example-professional has Claim.type code professional and the list text "Simple Professional Service Claim", while claim-example-pharmacy has Claim.type code pharmacy and the list text "Simple Pharmacy Service Claim". The current build renders those two labels distinctly. No relevant Zulip or Confluence discussion was found that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies the requested correction for the professional example, and changing the separate pharmacy example would incorrectly erase a distinct pharmacy example.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-19289 unless the FM work group later decides to retire or rename the separate pharmacy service example.
