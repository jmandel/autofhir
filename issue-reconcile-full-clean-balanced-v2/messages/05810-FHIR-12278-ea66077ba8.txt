FHIR-12278: Audit ICD combination syntax handoff to THO

Issue request:
FHIR-12278 was Published/Persuasive with Modification for DSTU2 and asked FHIR to document the ISO 21090 ICD combination syntax as a base part of the ICD-10 code system. The accepted resolution was to document ICD dual/multiple coding, including dagger-asterisk use cases, display guidance for expressions, and applicability to ICD-9, ICD-10, ICD-O, and variants.

Initial application:
The issue was historically applied in core. SVN-derived commit 7e7c737ad added a note to source/terminologies-systems.html that ICD dual coding uses two ICD-10 codes separated by a space such as "J21.8 B95.6". Commit 256d5061c expanded this into source/icd.html with a dedicated Dual Coding section, rationale bullets, the J21.8/B95.6 example, and review notes matching the Jira comments.

Additional context:
FHIR-13210 later refined the same ICD multiple-coding guidance to preserve modifier characters such as +, *, and ! where present. FHIR-35933 then moved the Using X external code-system pages, including source/icd.html, from FHIR core to HL7 Terminology (THO). The current core build keeps the active terminologies-systems.html row for ICD, but that row now links implementers to https://terminology.hl7.org/ICD.html and states that the THO Using ICD-[x] page has the details.

AutoFHIR reconciliation:
This audit commit intentionally makes no FHIR core source change. The current core source correctly delegates detailed ICD usage rules to THO, and the current THO ICD page preserves the FHIR-12278 substance by documenting ICD dual/multiple coding as a Coding.code expression, including the space-separated "J21.8 B95.6" form and the relationship to dagger/asterisk syntax.

Recommendation:
Keep this empty external-repo audit commit. Do not restore the deleted core source/icd.html page or duplicate the ICD combination-syntax prose in FHIR core. Future changes to this guidance should be made in THO/UTG, while FHIR core should continue to maintain only the link to the authoritative THO page unless the Vocabulary WG decides otherwise.
