FHIR-13051: Audit TestScript client scope outside core

Issue request:
FHIR-13051 was Published/Persuasive for DSTU2 by FHIR-I. It asked whether TestScript was exclusively for testing FHIR servers, because the then-current definition described tests against a FHIR server implementation; the accepted fix was to clarify that TestScript can test a FHIR server or client implementation.

Initial application:
The issue was applied in core while TestScript was still a core resource. Commit b0311014b4ee5eac7e635a266111d3d0c8ef7082, matching Jira's svn revision 12798 comment, changed source/testscript/testscript-spreadsheet.xml from "A structured set of tests against a FHIR server implementation" to "A structured set of tests against a FHIR server or client implementation." The same commit also touched List text, but the TestScript definition change is the relevant FHIR-13051 application.

Additional context:
Current core source no longer has an active TestScript resource. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testscript, TestScript/TestPlan/TestReport resource entries, work-group entries, security categories, FMM entries, mappings, and proposal-status entries from source/fhir.ini, and added the FHIR Testing IG pointer. Current source/fhir.ini lists the Testing IG, source/implsupport-module.html directs testing resources there, and git ls-files source/testscript returns zero files. The current HL7/fhir-testing-ig source at 3fa8dc91 still carries the FHIR-13051 wording in StructureDefinition-TestScript.xml. Later FMG minutes reviewing TestScript for FMM4 noted that the 4.0.1 TestScript page clarified "server or client implementation" and discussed whether scope might expand beyond FHIR, without reversing the client/server clarification.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. FHIR-13051 was historically applied, and the current authoritative TestScript StructureDefinition source is maintained outside this core checkout in HL7/fhir-testing-ig, where the requested server-or-client wording is present. The remaining core references are either generic or point readers to the external Testing IG.

Recommendation:
Keep this core audit as an external-repo decision. Do not reintroduce source/testscript to core for FHIR-13051; future TestScript definition or scope changes should be handled in HL7/fhir-testing-ig, with core links updated only if the Testing IG location changes.
