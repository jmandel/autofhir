FHIR-40308: Audit BDP property type expansion

Issue request:
FHIR-40308 was an Applied/Persuasive OO technical correction for R6 reporting that ValueSet/biologicallyderived-product-property-type-codes could not be expanded because the publication tooling could not support CodeSystem http://hl7.org/fhir/biologicallyderived-product-property-type-codes.

Initial application:
No git commit explicitly mentions FHIR-40308. The preceding FHIR-38365 link fix was applied in commit 5ead0fbf61, and the expansion failure appears to have been resolved later by commit 1d62083442 for FHIR-49688, which changed source/biologicallyderivedproduct/codesystem-biologicallyderived-product-property-type-codes.xml from content="example" back to content="complete" because BDP code systems were not expanding when marked as example.

Additional context:
The BiologicallyDerivedProduct resource is active in source/fhir.ini, so the source/biologicallyderivedproduct terminology files are current build inputs. Current source has the property-type CodeSystem content marked complete and the ValueSet compose includes that system. The rendered CI build page no longer contains the reported expansion error and includes the expected four codes. Later related Jira issues FHIR-49979, FHIR-53477, FHIR-55000, and FHIR-55252 discuss replacing or moving the local ISBT-related code systems, but they are Resolved - change required or Triaged rather than Applied/Published in this default run scope.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The seed expansion problem is no longer present in current source or the CI build surface, and changing the local CodeSystem now would pre-empt the separate THO/ISBT migration decisions that are still being tracked outside this applied/published seed.

Recommendation:
Keep this no-change audit for FHIR-40308. Handle the longer-term question of whether these local code systems should remain complete, become fragments, or move to HTA/ISBT canonical terminology through the later dedicated issues, especially FHIR-49979/FHIR-53477/FHIR-55000, when that broader scope is ready to apply.
