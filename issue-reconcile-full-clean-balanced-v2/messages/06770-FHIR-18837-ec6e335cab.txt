FHIR-18837: Audit ServiceRequest subject wording

Issue request:
FHIR-18837 was a Published FHIR-core-ServiceRequest change request, resolved Persuasive with Modification for STU3, asking that the ServiceRequest.subject short description stop saying only "Individual" because the allowed subject types include Patient, Group, Location, and Device. The approved resolution was to change the wording to "Individual or Entity...".

Initial application:
The Jira comment cites commit a09f8c740b6273d05dba437043a1ff1464fa2970. That commit changed source/servicerequest/servicerequest-spreadsheet.xml from "Individual the service is ordered for" to "Individual or Entity the service is ordered for". Later source refactors, including 33b409a4b6 and c69d71aa21, carried that wording into source/servicerequest/structuredefinition-ServiceRequest.xml.

Additional context:

The ServiceRequest mapping exception file also preserves the same resource-specific short text.
