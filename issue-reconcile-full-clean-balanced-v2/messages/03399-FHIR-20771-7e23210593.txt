FHIR-20771: Audit Person demographic additions

Issue request:
Published/Persuasive PA issue FHIR-20771 asked to add Person.deceased, Person.maritalStatus, and Person.communication for Person master-index and cross-role demographic use cases. The final resolution added maritalStatus as a native property, referenced FHIR-29820 for deceased, and added communication as on Patient/RelatedPerson with guidance that Person.communication should not directly update practitioner resources because the concepts have different purposes.

Initial application:
The issue was applied before this reconciliation. Commit 1bf9c6c3a6 added Person.deceased[x], Person.maritalStatus, Person.communication, and the communication subelements to source/person/structuredefinition-Person.xml. Commit d6853ff75e then applied the related FHIR-29820 deceased-search-parameter part by adding Person-deceased and Person-death-date to source/person/bundle-Person-search-params.xml.

Additional context:
Earlier no-change decisions FHIR-17318 and FHIR-17319 had rejected deceased and maritalStatus on Person, but the 2021 PA WGM minutes and later Published Jira disposition superseded that earlier position for the R5 build. source/fhir.ini lists Person as an active approved resource, so source/person/structuredefinition-Person.xml and the Person search-parameter bundle are current build-scope source.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Current source/person/structuredefinition-Person.xml already contains Person.deceased[x], Person.maritalStatus, Person.communication, Person.communication.language, and Person.communication.preferred, including the requested note that Person.communication should not be used to update linked practitioner resources. Current source/person/bundle-Person-search-params.xml also contains the related deceased search parameters requested by FHIR-29820.

Recommendation:
Keep this no-change audit commit as-is. No further FHIR core source work is recommended for FHIR-20771 unless PA later reopens the Person/Practitioner communication semantics or requests additional Person search parameters beyond the decided deceased search support.
