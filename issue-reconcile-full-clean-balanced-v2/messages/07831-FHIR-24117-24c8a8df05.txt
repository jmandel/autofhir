FHIR-24117: Audit Questionnaire help display category removal

Issue request:
FHIR-24117 is a Published FHIR-core Questionnaire change request, resolved Persuasive, asking to resolve the overlap where both questionnaire-display-category and questionnaire-item-control had a help code. The approved resolution was to remove help from display-category while leaving designers free to render help text inline, as a flyover, or as a help-button launchable blob.

Initial application:
The issue was applied in core by commit 17fa4f6e5e, which deleted the help concept from source/questionnaire/codesystem-questionnaire-display-category.xml. That change reversed the earlier FHIR-17208/GF#17208 addition of help to display-category while preserving questionnaire-item-control help as the UI-control mechanism.

Additional context:
The current core build still includes Questionnaire as an active resource, but the specific Questionnaire extension and terminology artifacts targeted by this issue were later removed from core by dd468d4f17 and now live in the FHIR Extension Pack. Current core source has no questionnaire-display-category code system file and no active fhir.ini entry for it; only examples/conversion helpers reference the canonical. The local Extension Pack source has questionnaire-display-category with instructions, security, and legal only, and questionnaire-item-control still has help. Zulip discussion around the issue and later displayCategory questions supports using itemControl=help for help-button rendering; Confluence searches found no conflicting minutes.

AutoFHIR reconciliation:
This is an empty audit commit. No core source was changed because the source-changing part of FHIR-24117 was already applied, the current authoritative terminology source is outside this FHIR core checkout, and that Extension Pack source already reflects the approved separation between displayCategory and itemControl.

Recommendation:
Keep this audit commit as-is for core reconciliation. If future changes are needed to questionnaire-display-category or questionnaire-item-control, make them in the FHIR Extension Pack rather than reintroducing retired core terminology source files.
