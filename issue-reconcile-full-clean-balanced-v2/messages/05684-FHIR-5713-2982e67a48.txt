FHIR-5713: Audit Appointment proposed status support

Issue request:
FHIR-5713 was Published/Persuasive for DSTU1 and asked to add a new Appointment.status code "proposed" because "pending" represented a later appointment lifecycle state. The final resolution said to add the proposed status, update Appointment usage notes, and add invariants so optional start/end date-times could be handled.

Initial application:
The change appears to have been applied by historical commit 44a2cf49ea, which added the proposed status, changed Appointment.start and Appointment.end to 0..1, added the app-2/app-3 invariants, and updated Appointment usage notes as part of the Appointment/AppointmentResponse reconciliation. Commit 8db2dceb19 then corrected app-3 for tracker 6938 so the missing start/end exception used proposed and cancelled rather than the earlier planned/pending wording.

Additional context:
FHIR-5702 is background only: it requested a proposed Encounter status but was later closed no-change, supporting the decision to model planned follow-up through Appointment rather than Encounter. FHIR-6938 is the same change family and relied on FHIR-5713's proposed status to support unscheduled planned encounters. FHIR-18824 later added waitlist as another status allowed to omit start/end, so the current app-3 text and expression properly include waitlist in addition to the original proposed/cancelled rule.

AutoFHIR reconciliation:
No source change was made. Current build-scope Appointment source already has the proposed status code and definition, Appointment.status short text includes proposed, current Appointment workflow notes and the proposed example show proposed usage, and app-3/start/end cardinalities still support appointments whose date-times are not yet known.

Recommendation:
Keep this no-change audit commit. The current source satisfies FHIR-5713 after later same-family refinements; future changes to planned or waitlisted appointment semantics should be handled under their own trackers rather than by re-opening this DSTU1 proposed-status issue.
