FHIR-12390: Audit SNOMED implicit ConceptMaps

Issue request:
FHIR-12390 was a Published/Persuasive Vocabulary change request asking FHIR to expose SNOMED CT Simple Map and Association Reference Set content as implicit ConceptMaps, using SNOMED CT implicit URLs such as fhir_cm and relationship mappings for historical association reference sets.

Initial application:
The request was initially applied in git-svn commit 9b6379be0c869eb42a77321992b93aa7aa30874a, SVN revision 10491, which added an "Implicit Concept Maps" section to source/snomedct.html with Association Reference Set mappings and a ?fhir_cm=[sctid] template. The Jira comment records the same SVN revision.

Additional context:
The old source/snomedct.html page is no longer part of the current core build. FHIR-35933 intentionally migrated the "Using external code systems with FHIR" pages to HL7 Terminology, and commit 81e5862f203fdb8a03e9c943a7cf455aba8973f4 deleted source/snomedct.html while leaving source/snomedct-usage.html as a core usage-summary page. The combined branch already contains an audit commit for FHIR-35933. Later ConceptMap-specific work, FHIR-38110 and FHIR-39266, added and refined the active ConceptMap resource notes so current core source explains implicit concept map URI behavior and links to the THO SNOMED CT implicit ConceptMap patterns. The current THO SNOMED CT page contains the detailed Association Reference Set, Simple Map Reference Set, and ?fhir_cm=[sctid] template guidance.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No core source edit is needed because the current specification already conveys the FHIR-12390 behavior through the active ConceptMap notes and the authoritative THO SNOMED CT page. Re-adding the deleted core SNOMED CT page or duplicating the THO text in source/snomedct-usage.html would conflict with the later FHIR-35933 migration and create maintenance drift.

Recommendation:
Keep this audit commit as-is. Future changes to the detailed SNOMED CT implicit ConceptMap URL patterns should be handled in HL7 Terminology/UTG or, only for generic FHIR behavior, in the ConceptMap resource notes.
