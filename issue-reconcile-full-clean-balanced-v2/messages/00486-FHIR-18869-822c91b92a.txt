FHIR-18869: Audit externalized ImmunizationEvaluation scope

Issue request:
FHIR-18869 was Published/Persuasive with Modification for STU3. The reporter asked to change ImmunizationEvaluation.immunizationEvent from 1..1 to 1..* so multiple vaccination records could be referenced for a series such as hepatitis B, but the accepted resolution rejected that cardinality change and instead required clearer documentation that ImmunizationEvaluation evaluates a single immunization event while ImmunizationRecommendation conveys overall patient status relative to a series.

Initial application:
The issue was applied in core by git commit f88e5c60401ca9b52089683e3a52912c3c3531ae, whose message was "GF#18866 & #18869". That commit updated source/immunizationevaluation/immunizationevaluation-introduction.xml to add a Boundaries and Relationships paragraph saying ImmunizationEvaluation is focused on evaluation of a single vaccine administration event, that a three-dose hepatitis B series would have separate ImmunizationEvaluation instances for the other doses, and that ImmunizationRecommendation conveys overall patient status. It did not change the immunizationEvent cardinality, which matches the Jira resolution with modification.

Additional context:
The current core branch no longer builds ImmunizationEvaluation. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed source/immunizationevaluation and deleted the active source/fhir.ini resource, workgroup, security, FMM, type-code, and status entries for ImmunizationEvaluation. Current core narrative pages point ImmunizationEvaluation to the HL7 Immunization Incubator IG, and that external continuous build still contains the single-event clarification and shows ImmunizationEvaluation.immunizationEvent as 1..1.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical core application matches the accepted FHIR-18869 resolution, and the current core checkout has no active ImmunizationEvaluation resource definition to edit.

Recommendation:
Keep this external-repo audit commit for core. No core follow-up is needed for FHIR-18869 unless ImmunizationEvaluation returns to the core build; the current external Immunization Incubator publication surface already reflects the accepted single-event clarification.
