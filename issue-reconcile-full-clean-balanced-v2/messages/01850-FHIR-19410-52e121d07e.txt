FHIR-19410: Audit Provenance activity role-code removal

Issue request:
FHIR-19410 was Published with resolution Persuasive. It asked to remove v3 ParticipationType role/function codes from the Provenance activity type value set because codes such as transcriber describe participation roles, and concepts such as legally authenticated describe states rather than actions; the accepted resolution specifically said the value set should not include v3 participation types and left future activity vocabulary work open.

Initial application:
The issue was initially applied before this reconciliation by git commit d417c5d674f23099e6f3e481c34e0100c7aa5a66, which changed the then-current source/provenance/valueset-provenance-activity-type.xml by commenting out the http://terminology.hl7.org/CodeSystem/v3-ParticipationType include with a GF#19410 note. Later same-file history moved the value set to source/terminologies/valueset-provenance-activity-type.xml, added ISO lifecycle and broader activity candidates, and continued to leave v3 ParticipationType out.

Additional context:
A 2020 Zulip comment from Lloyd McKenzie said the initial application had only removed the participation codes and still left other questionable state/status vocabularies. Later final same-artifact decisions resolved that current-state concern: FHIR-23712 temporarily broadened the value set, but FHIR-32517 later changed Provenance.activity to an example binding and reduced ProvenanceActivityType to representative ISO 21089 lifecycle examples. FHIR-55798 and FHIR-55797 then refined the description and added destroy while preserving the ISO example model. Related issues FHIR-22104, FHIR-23712, and FHIR-32517 are already represented on the combined branch and should not be duplicated here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source has Provenance as an active resource, binds Provenance.activity with strength example to http://hl7.org/fhir/ValueSet/provenance-activity-type, and the current value set includes only representative ISO 21089 lifecycle activity codes. It does not include v3 ParticipationType, DocumentCompletion, ActStatus, event-status, object-lifecycle-events, or the other historical role/state/status includes that made the value set incoherent.

Recommendation:
Keep this audit commit as-is. No core FHIR source change is recommended for FHIR-19410; any future expansion or replacement of ProvenanceActivityType should be handled by a new Security WG issue rather than by reopening the removed-participation-code request.
