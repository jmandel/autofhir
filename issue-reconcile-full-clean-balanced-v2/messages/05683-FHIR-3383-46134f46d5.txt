FHIR-3383: Audit medication search parameter naming

Issue request:
FHIR-3383 was a Published/Persuasive FHIR-core Pharmacy change request for DSTU1. It asked to unify the early MedicationAdministration `whengiven`, MedicationStatement `when-given`, and related prescription written-date search parameter naming.

Initial application:
No commit explicitly tagged FHIR-3383 was found. Historical source shows the inconsistency existed in the issue-era spreadsheets, and later pharmacy/source refactors removed it: commit 2052f0891c changed MedicationAdministration.whenGiven and the `whengiven` search parameter to effectiveTime/effectivetime, later pharmacy work removed MedicationStatement.whenGiven examples, and current generated search-parameter bundle sources now use MedicationAdministration `date`, MedicationStatement `effective`, and MedicationRequest `authoredon`.

Additional context:
MedicationAdministration, MedicationStatement, and MedicationRequest are active current build resources in source/fhir.ini. MedicationPrescription/MedicationOrder is no longer a current resource; the current build maps MedicationOrder to MedicationRequest and MedicationOrder.dateWritten to the authoredOn lineage. Current all-source checks found no `whengiven`, `when-given`, `datewritten`, or `date-written` search parameter in the active medication administration/statement/request sources; remaining hits are a historical comment, compatibility mapping, generated history text, or unrelated VisionPrescription/library content.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The current build already avoids the inconsistent search parameter names that FHIR-3383 targeted, and changing active search parameter names now would be a new compatibility-impacting decision rather than applying the DSTU1 cleanup.

Recommendation:
Keep this audit as-is. No core source follow-up is needed for FHIR-3383 unless the Pharmacy work group wants a new, separate harmonization of modern medication search parameter names.
