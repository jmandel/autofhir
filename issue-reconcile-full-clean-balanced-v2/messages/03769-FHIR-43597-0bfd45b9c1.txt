FHIR-43597: Audit vitals device qualifier clarification

Issue request:
FHIR-43597 is an Applied/Persuasive FHIR-core Observation change request from OO asking that vital-signs device qualifier notes be clarified. The reported problem was that rows such as "8887-2 - Heart rate device type MAY be included as an additional observation" could imply a sibling Observation, hasMember relationship, or panel member instead of a component; the final Jira comments say the question concerned measurement devices and that adding "component" to the additional passages closed the issue for the submitter.

Initial application:
No source commit on the searched history explicitly mentions FHIR-43597. The relevant current text appears to have been applied through the related vitals-table clarification commit f5ab9c158d for FHIR-32787, which changed the affected table rows from "additional observation(s)" to "additional component observation(s)" after FHIR-43597 was filed.

Additional context:
The Observation resource and the core vitals IG are active build inputs, so the vitals introduction page is in current build scope. FHIR-46418 had already reworked the vital-signs profile page, and FHIR-32787 later clarified the table's component-observation wording. OO's 2025-10-23 Confluence minutes list FHIR-43597 in the final block vote as Persuasive and record the 8-0-2 motion; Zulip searches found no conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already says the heart-rate, body-temperature, and blood-pressure qualifier codes may be used as additional component observations, which resolves the ambiguity described in the Jira without adding redundant or unvoted guidance about Observation.device, supportingInfo, or preconditions.

Recommendation:
Keep this audit commit as-is. If OO wants broader future guidance distinguishing measurement devices, implanted/influencing devices, preconditions, and linked observations, that should be handled in a new scoped Jira rather than as further application of FHIR-43597.
