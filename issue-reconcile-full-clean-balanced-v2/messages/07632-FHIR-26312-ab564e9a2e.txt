FHIR-26312: Audit Questionnaire enableWhen repetition clarification

Issue request:
FHIR-26312 was a Published FHIR-core Questionnaire change request, resolved Persuasive with Modification for R5, asking whether enableWhen can point from outside a repeating group to a linkId inside that repeating group. The accepted resolution was to clarify that ambiguous references to repeated question occurrences are not permitted, that multi-answer questions satisfy enableWhen if any answer matches, and that enableWhenExpression should be used when authors need more precise repeated-answer logic.

Initial application:
The issue was applied by commit 5665c38fcfbab7630b6f50f421947fcf41581117, which added the repeated-question ambiguity/error guidance to Questionnaire.item.enableWhen.question and the multiple-answer/enableWhenExpression guidance to Questionnaire.item.enableWhen.answer[x]. The active current Questionnaire source still contains those clarifications; later source restructuring preserved the wording.

Additional context:
The originating Zulip thread records that the pre-existing nearest-repetition behavior was unclear and probably not useful for references into repeating groups, with Lloyd McKenzie recommending enableWhenExpression for such cases. The SDC minutes for 2020-04-30 record the work group intent to disallow the ambiguous case while pointing to enableWhenExpression. FHIR-26993 is a same-change-family clarification for multiple enableWhen clauses and is already represented on the combined branch, so this commit does not duplicate it.

AutoFHIR reconciliation:
This audit commit makes no source change. source/fhir.ini includes Questionnaire as an active resource, and source/questionnaire/structuredefinition-Questionnaire.xml already states that ambiguous same-linkId repeated question references are an error, recommends enableWhenExpression for such situations, and states that multiple answers satisfy enableWhen when any answer matches.

Recommendation:
Keep this no-change audit commit as-is. The current core source already conveys the FHIR-26312 decision; any future work should be limited to editorial cleanup such as the existing misspelling of "equadistant" unless the work group chooses to revisit the nearest-repetition rule itself.
