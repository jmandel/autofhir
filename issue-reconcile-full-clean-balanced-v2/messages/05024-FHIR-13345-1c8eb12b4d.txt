FHIR-13345: Remove stale Organization alias extension note

Issue request:
FHIR-13345 was Published/Persuasive for STU3 by Patient Administration and requested removal of the standard alias-name extensions for Organization and Location because both resources had alias elements.

Initial application:
The issue appears to have been applied by git commit ca3ede7696342ef6934f7a100c37d31093bfc23a, which removed alias search rows from the Organization and Location extension spreadsheets while preserving/adding the resource-level alias handling. Current source no longer contains active organization-alias or location-alias extension definitions, and Organization.alias and Location.alias are active resource elements.

Additional context:
FHIR-9624 and FHIR-9625 are the earlier Published/Persuasive decisions establishing Location.alias and Organization.alias as 0..* string elements included in the name search parameters. Organization and Location are active resources in source/fhir.ini. The public CI profile and definitions pages strip build-only committee notes and already show the correct Organization.alias guidance, but the active Organization source still retained a build committee note on Organization.name telling editors to use an extension "alias" instead.

AutoFHIR reconciliation:
This commit removes only the stale build committee note from source/organization/structuredefinition-Organization.xml. It leaves the active Organization.alias and Location.alias elements and their name search parameters unchanged, and it does not touch historical release snapshots under tools/history.

Recommendation:
Keep this source cleanup. The current public specification behavior was already aligned with FHIR-13345, and this change prevents stale internal source guidance from continuing to reference a standard alias extension that the issue removed.
