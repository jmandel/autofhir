FHIR-12582: Audit conditional assert guidance

Issue request:
FHIR-12582 was a Published/Persuasive with Modification DSTU2 FHIR-core TestScript change request asking for a way to conditionally execute an assert based on prior assert results within one operation. The accepted resolution was to add R4 Testing FHIR page language describing conditional asserts and the current workaround.

Initial application:
The issue was applied by git commit eefe2ea34770cfac3e3b14aabc549efe855a4101, "GF 12582", which added a Conditional Asserts subsection to source/testing.html explaining that native TestScript execution does not conditionally evaluate asserts, that warningOnly=true is the current workaround, and that external Rules engine support may be provided by an implementation guide.

Additional context:
Current core no longer builds local TestScript/TestReport/TestPlan resources or source/testing.html. Git commit f9a44787c45071394532c7c2ee94d76f30f47387 removed the testing resources from source/fhir.ini and deleted source/testing.html while adding the active testing additional-IG mapping. The current core source points TestScript-related links to https://build.fhir.org/ig/HL7/fhir-testing-ig, and the HL7/fhir-testing-ig source at commit 3fa8dc91c003f7cf83b281a1f553cb1d82caa15c preserves the Conditional Asserts guidance in input/pagecontent/testing.xml.
