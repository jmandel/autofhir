FHIR-37571: Audit Measure evaluate rename

Issue request:
FHIR-37571 was Applied/Persuasive with Modification for R6 and asked CQI to rename the core Measure/$evaluate-measure operation to a clearer use-case-specific name. The accepted modification chose Measure/$evaluate following the DEQM pattern, and required the description: "The $evaluate operation processes the given Measure(s) to produce the corresponding MeasureReport(s). This operation expects that Measure resources used have a computable representation."

Initial application:

Follow-up commit 0f0999d570b2f7cf6aa172b85cd28f8bcda11611 copied additional existing $evaluate-measure semantics into the new $evaluate operation.

Later Applied issue FHIR-50484 further aligned base FHIR Measure/$evaluate with the DEQM operation and corrected current $evaluate request examples; it is already represented on the combined branch by commit 73201e801807df3320a1cbb316522a1ccb7039d8, so this audit does not duplicate that issue. FHIR-50486 was resolved no-change because $evaluate-measure had already been deprecated. Exact Zulip and Confluence searches for FHIR-37571 found no conflicting community record.
