FHIR-35932: Audit identifier registry migration

Issue request:
FHIR-35932 was a Published/Persuasive with Modification R5 FHIR-I change request to remove the core Known Identifier Systems registry table after its records were migrated to HL7 Terminology, and to replace the page text with guidance that HL7 Terminology actively curates Identifier systems, that pre-release THO URIs are mandatory for the corresponding FHIR release, and that unlisted shared identifier systems follow the HL7 terminology authority process.

Initial application:
The issue was applied before this reconciliation by f40fc710c34b0106cdc391d3ef696f746e83749c, which removed the old local table and <%identifierlist%> include from source/identifier-registry.html and replaced the page body with the THO/UTG migration guidance. Later source history refined the same page without reversing the migration: 71f5602acf06ad7fe0f46052ca1c6b477311c1ae replaced the former HL7 Terminology Authority reference with the current TSMG policy link, and later formatting/status commits preserved the THO delegation.

Additional context:
UP-285 is the matching implemented UTG/THO proposal: it created identifier system records from the former FHIR identifier registry, added them to the THO identifier rendering manifest, and renamed the THO tabs for external identifier systems. FHIR-I minutes for 2022-02-07 record the 22-0-0 Persuasive with Modification vote for FHIR-35932, and Terminology Authority minutes for 2022-05-05 record the identifier-system policy discussion and the move toward THO as the single source of truth. The current source keeps identifier-registry.html in the FHIR build/navigation but uses it as a guidance/transition page rather than a local registry table. Related combined-branch audits for FHIR-37494, FHIR-42959, and FHIR-35933 already cover adjacent table-column, Identifier.system, and external terminology migration concerns.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped source/identifier-registry.html no longer contains the old identifier systems table or stale registration instructions, links directly to the THO identifier registry, and contains the accepted SHOULD/SHALL conformance language plus the later TSMG policy reference. Updating nearby links that point to this retained guidance page would be optional wording polish rather than a necessary FHIR-35932 source correction.

Recommendation:
Keep this audit commit as-is. Future changes to individual identifier system records or their display should be handled in THO/UTG; FHIR core only needs follow-up if a later work-group decision changes the retained guidance page or the TSMG policy relationship.
