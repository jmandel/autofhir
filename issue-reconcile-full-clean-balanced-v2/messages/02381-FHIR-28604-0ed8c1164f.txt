FHIR-28604: Audit MetadataResource common elements

Issue request:
FHIR-28604 was a Published/Persuasive with Modification CDS change request for R5. It asked to add topic, author, editor, reviewer, endorser, and relatedArtifact as common MetadataResource elements, update the MetadataResource table to list the right set, and add Citation guidance because Citation captures responsible individuals differently.

Initial application:
The issue was applied in commit ce1c547c3e0efad3f685b437c8000c50585c2580, which added the requested MetadataResource differential elements and related MetadataResource search parameters. The Citation-specific guidance was later present in the former core Citation source: the Citation.author/editor/reviewer/endorser comments explained that those elements used ContactDetail and did not support detailed contributor identifiers, directing detailed contributorship data to Citation's richer contributorship modeling.

Additional context:
MetadataResource is an active interface in source/fhir.ini, and the current source/metadataresource/structuredefinition-MetadataResource.xml still contains all six requested common elements with the requested cardinalities and types. The current MetadataResource introduction lists active core implementers and external implementers. Citation is no longer an active core resource: commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/citation and the active Citation fhir.ini entries, while current core narrative points to the Evidence Based Medicine on FHIR IG for Citation. Confluence minutes record the 2021-03-15 FHIR-I vote approving FHIR-28604 after the 2021-03-08 concern that definitions and implementer lists needed cleanup.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current in-scope core source already carries the requested MetadataResource common elements and table input, and there is no longer an in-build core Citation resource where the historical Citation-specific note should be maintained.

Recommendation:
Keep this audit as-is for FHIR-core. Do not add redundant MetadataResource prose or restore Citation source files in core; any future Citation-specific mapping guidance belongs in the Evidence Based Medicine on FHIR IG or another current Citation source-of-truth.
