FHIR-12050: Audit Subscription examples

Issue request:
FHIR-12050 was a Published/Persuasive DSTU2 correction for the Subscription page. The Jira reported that embedded Subscription examples were invalid because they omitted required reason/status content and used channel.url where channel.endpoint was expected, and it asked that the embedded examples be fixed and preferably sourced from standalone examples that validate in the build.

Initial application:
The Jira snapshot records svn revision 10284 as the application. In git history this is commit 003170b11d95c3e9572481a2ba6148fadbd12664, whose message includes #12050 and whose Subscription patch changed the embedded channel destination fields from url to endpoint, wrapped formerly partial snippets as Subscription fragments, and made the examples build-fragment aware. No separate modern git commit mentions the full FHIR-12050 key.

Additional context:
The current build has moved beyond the DSTU2/DSTU3 embedded example prose that FHIR-12050 targeted. source/fhir.ini lists Subscription as an active resource, and source/subscription/list-Subscription-examples.xml now points to standalone Subscription/example and Subscription/admission resources. The current narrative no longer contains the old freetext JSON Subscription fragments. The current example resources include status and reason, and the admission example uses endpoint rather than url for the rest-hook destination. The current R6 Subscription model is topic-based, so exact DSTU2 prose and element shape cannot be expected to match, but the invalid example defect described by the Jira is not present.
