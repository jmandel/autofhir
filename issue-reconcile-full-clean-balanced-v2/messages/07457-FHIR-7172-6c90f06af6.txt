FHIR-7172: Audit NutritionOrder parenteral scope

Issue request:
FHIR-7172 was a Published/Persuasive with Modification OO change request asking whether NutritionOrder included hyperalimentation/parenteral nutrition and requesting clarification that it does not, plus scope text about physician/dietitian population of nutrition orders and profile variation.

Initial application:
The issue was applied in git commit 65afef74325d40bc76731f4fe954951ebe0e3064, which added NutritionOrder scope text excluding parenteral (IV) nutrition, added enteral/supplement explanatory text, and clarified that different providers could populate simple or more detailed orders. Current NutritionOrder is active in source/fhir.ini and the same source file still carries that semantic content.

Additional context:
The Jira resolution explicitly points to Pharmacy issue FHIR-8203 for the complementary parenteral-nutrition placement. FHIR-8203 is Published/Persuasive with Modification and was applied in commit 1035927e2bb56676468ca554f2325536de2c059d, with the current MedicationRequest introduction still including total parenteral nutrition and excluding particular diets. Later FHIR-15943 was Resolved - No Change after noting NutritionOrder already limited itself and kept parenteral nutrition out of scope. A 2019 Zulip implementer discussion likewise quoted the NutritionOrder boundary and treated TPN as outside NutritionOrder. No Confluence references for FHIR-7172 or FHIR-8203 were found.

AutoFHIR reconciliation:
No source change was made. The active NutritionOrder introduction and boundaries already say NutritionOrder does not cover parenteral (IV) nutrition, point to MedicationRequest for parenteral nutrition, and explain that practitioners with different scopes may populate simple or detailed nutrition orders.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source follow-up is needed for FHIR-7172 unless the work group later reopens the boundary between nutrition and medication orders.
