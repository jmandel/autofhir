Issue request:
FHIR-56057 was a Published FHIR-extensions / FHIR-I change request, resolved Persuasive with Modification, saying questionnaire-choiceOrientation should not be limited by a context expression because the extension is meaningful whenever a questionnaire item has a constrained list of permitted answers. The accepted resolution was to remove the context expression and add explanatory description text rather than over-constraining the extension to answerOption, answerValueSet, or answerExpression.

Initial application:
The issue was initially applied in the FHIR Extension Pack by commit aad7382, which removed the then-current questionnaire-choiceOrientation contextInvariant and added the constrained-list explanatory note. That commit is in the Extension Pack master history.

In commit order, the Extension Pack later received FHIR-52745 commit 424aae2 and FHIRPath fix a7598a2, which reintroduced a broader contextInvariant.
