Issue request:
FHIR-24627 is an Applied/Persuasive FHIR-core Measure change request from CQI. The original description asked for an example of a cohort definition measure and measure report, but the updated April 2025 disposition requires adding an example of a cohort measure and explicitly says it does not include moving the CohortMeasure profile into base FHIR.

Initial application:
The issue appears to have been applied by commit 4fef8cffd5dfcc276d99e09dfd481556eedeeb70, which added source/measure/measure-hybrid-hospital-wide-mortality.xml and registered it in source/measure/list-Measure-examples.xml. That change was merged through HL7/fhir PR #3900 in merge commit 053a927a4ec6fb0e934be0ffe3d1d22e9ac7d455.

Additional context:
source/fhir.ini keeps Measure and MeasureReport as active resources, so the Measure example list and source/measure example are in current build scope. The current Measure example uses measure-scoring code cohort and an initial-population group. Its own description says the logic is not an electronic clinical quality measure and will not produce measure results, which is consistent with the narrowed disposition and argues against inventing a companion MeasureReport now. A source search found no active CohortMeasure profile in core source, matching the Jira note that moving the profile into base FHIR was removed from scope.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the current build-scope Measure source already satisfies the final FHIR-24627 request, while adding a MeasureReport example or CohortMeasure profile would exceed the current Jira disposition.
