FHIR-22787: Audit Parameters Meta value choice

Issue request:
FHIR-22787 was a Published/Persuasive FHIR-I change request raised against STU3 and applied for R5. It asked to add Meta to Parameters.parameter.value[x] because Resource metadata OperationDefinitions used parameters of type Meta while the Parameters StructureDefinition did not list Meta as an allowed value[x] type.

Initial application:
No git commit explicitly mentioning FHIR-22787 or tracker id 22787 was found. The same underlying defect had already been handled through the tightly related FHIR-20487/GF#20487 correction, where commit 0dd70c3172 added Meta to the wildcard/open-type list. Later source rework commits 33b409a4b6 and c69d71aa21 carried Meta into the checked-in Parameters StructureDefinition, where it remains in the Parameters.parameter.value[x] type list.

Additional context:
Parameters is an active infrastructure resource in source/fhir.ini, so source/parameters/structuredefinition-Parameters.xml is current build input. The old Resource $meta, $meta-add, and $meta-delete operation definitions that motivated the report are no longer owned as core operation-definition source here; the current ballot intro links those operations to the API incubator IG. A closely related audit for FHIR-20487 is already published on the combined branch, so this commit intentionally does not duplicate that issue. The referenced Zulip thread and Confluence/Jira neighborhood checks did not reveal a later conflicting decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core Parameters StructureDefinition already includes <code value="Meta"/> under Parameters.parameter.value[x], satisfying the requested valueMeta allowance in an active build-scope source file.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-22787; future work on the externally hosted Resource metadata operation definitions, if any, should be handled in the owning IG rather than by editing core Parameters.
