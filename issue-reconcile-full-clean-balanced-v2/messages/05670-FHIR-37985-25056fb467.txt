Issue request:
FHIR-37985 was Published/Persuasive for R5 after reporting that entering any search criteria on the FHIR Implementation Guide Registry found no implementation guides, and suggested sending users directly to the FHIR Package Registry homepage.

Initial application:
No source commit mentioning FHIR-37985 was found. The closest application history is HL7/fhir#2401 / commit bc0c3d8207a, associated with FHIR-16526, which replaced the obsolete Confluence IG link on source/index.html with a curated IG-registry link plus a direct https://registry.fhir.org/ package-registry link and updated the shared navbar registry entries.

Additional context:
source/index.html is an active build page in publish.ini, and tools/templates/newnavbar.html is the shared navbar template used broadly by the build. The current homepage also includes https://packages2.fhir.org/xig as an all-IG index. Changing all curated IG-registry links to the package registry root would be broader than the Jira evidence and would remove a distinct curated-list entry that currently works.

Recommendation:
