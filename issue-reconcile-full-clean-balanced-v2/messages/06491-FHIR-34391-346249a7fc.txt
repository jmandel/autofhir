FHIR-34391: Audit questionnaire quantity unit guidance

Issue request:
FHIR-34391 was a Published/Persuasive FHIR-core Questionnaire correction. It reported that the Questionnaire item-type value set described type "quantity" as using http://hl7.org/fhir/StructureDefinition/questionnaire-unit even though that extension is limited to integer and decimal items, and asked for the quantity definition to point instead to questionnaire-unitOption and questionnaire-unitValueSet.

Initial application:
The issue was applied in git commit 2b05abaa32 on the Questionnaire-fixes line, changing source/questionnaire/codesystem-item-type.xml for the item-type "quantity" concept from questionnaire-unit to questionnaire-unitOption and questionnaire-unitValueSet. The same source was later refined by FHIR-28132 in e096aeb964, which added the matching integer/decimal questionnaire-unit guidance and changed the quantity wording to say the selected units constrain Quantity.code and Quantity.system.

Additional context:
The current build has Questionnaire active in source/fhir.ini, has the active item-type value set entry at source/fhir.ini:1308, and source/questionnaire/valueset-item-type.xml composes http://hl7.org/fhir/item-type from the neighboring code system. The current quantity definition in source/questionnaire/codesystem-item-type.xml still references questionnaire-unitOption and questionnaire-unitValueSet, while the integer and decimal definitions use questionnaire-unit. The current Extension Pack definitions confirm questionnaire-unit is constrained to integer/decimal items and questionnaire-unitOption/questionnaire-unitValueSet are constrained to quantity items. Later FHIR-37468 and FHIR-41195 changed the datatype wording toward SimpleQuantity without reversing the unit-extension guidance. FHIR-I SDC minutes for 2021-12-02 list FHIR-34391 as Persuasive, and searches found no contrary Zulip or Confluence evidence.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source hunk is necessary because the current authoritative source already implements the FHIR-34391 correction and no current source file under source/ still contains the obsolete quantity guidance that pointed to questionnaire-unit.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-34391; any future changes to the extension definitions themselves would belong to the Extension Pack or a new tracker.
