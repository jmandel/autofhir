FHIR-33129: Audit BodyStructure location restructuring

Issue request:
FHIR-33129 was a Published/Persuasive with Modification OO change request for R5 asking to eliminate BodyStructure.location and BodyStructure.locationQualifier and replace them with includedStructure 1..* and excludedStructure 0..* backbone elements. Each backbone was to carry structure 1..1, laterality 0..1, and qualifier 0..* so BodyStructure could describe one or more meaningful anatomical locations with separated laterality and other qualifiers.

Initial application:
The application history shows the request was implemented before this reconciliation. Commit a67549d981 added BodyStructure.includedStructure and BodyStructure.excludedStructure and updated examples from location/locationQualifier to includedStructure.structure, laterality, and qualifier. Jira then records 3b71a9e220 as the applied build commit for short description corrections. A follow-up correction in PR #1564 removed the remaining top-level BodyStructure.location from the StructureDefinition in 2be93943a1 and removed the obsolete BodyStructure-location search parameter in 0d176cd4f, which Jira records as the corrected re-application.

Additional context:
BodyStructure is actively in the current core build through source/fhir.ini. Current source has includedStructure 1..* with structure 1..1, laterality 0..1, qualifier 0..*, and excludedStructure 0..* using the includedStructure content reference. Current examples use includedStructure rather than location/locationQualifier, and current search parameters expose included-structure and excluded-structure instead of the old location search parameter. The only remaining BodyStructure.location and BodyStructure.locationQualifier strings found in source are the R4-to-R6 deleted-element migration notes in source/fhir.ini, not active resource elements. Confluence OO WGM minutes for 2021-09-20 record the Body Structure proposal and the motion to accept Proposal 1 after modification, 15-0-6. Later BodyStructure issues, including FHIR-38646, refined narrative around the included/excluded model but did not reverse this structural change.

AutoFHIR reconciliation:
No source change was made. The current authoritative BodyStructure StructureDefinition, examples, and search parameter bundle already carry the approved FHIR-33129 restructuring, and the old element names only remain where appropriate as cross-version migration metadata.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-33129 unless a future work group decision reopens the broader BodyStructure model or the cross-version migration notes.
