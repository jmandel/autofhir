FHIR-13890: Confirm AdverseEvent group subject support

Issue request:
FHIR-13890 was a Published/Persuasive Patient Care STU3 change request asking for AdverseEvent.subject to include Group, for cases such as adverse events affecting a cage of rats, a team of people, or a herd of cows. The accepted resolution also asked for a usage note: if AdverseEvent.resultingCondition differs among members of the group, then use Patient as the subject.

Initial application:
The request was explicitly applied in historical commit 32b35437cc8daef171fb42950801c6a39d6f918b, whose subject includes "#13890 - add AdverseEvent.subject Reference(Group)". That commit changed the then-authoritative AdverseEvent spreadsheet source from Reference(Patient|ResearchSubject|Practitioner|RelatedPerson) to Reference(Patient|Group|Practitioner|RelatedPerson), added the requested group usage note, and recorded GF#13890 in committee notes.

Additional context:
AdverseEvent remains in current build scope through source/fhir.ini. The current XML StructureDefinition carries GF#13890 forward on AdverseEvent.subject, includes Group as a target profile, and retains the usage note with resultingCondition updated to the current element name resultingEffect. Later same-area decisions did not reverse the Group support: FHIR-13893 made the subject required, FHIR-13891 and FHIR-40657 removed ResearchSubject from the target list, and J#34316 renamed resultingCondition/resultingEffect while preserving the note's meaning. A community search found no conflicting Zulip or Confluence evidence.

AutoFHIR reconciliation:
This audit commit makes no source change because the current authoritative source already implements the requested correction. AdverseEvent.subject is in the active AdverseEvent resource source, includes Reference(Group), and says that if AdverseEvent.resultingEffect differs among members of the group, Patient should be used as the subject.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source work is needed for FHIR-13890 unless a future Patient Care decision intentionally changes the AdverseEvent.subject target profiles or group usage guidance.
