FHIR-15643: Audit Immunization subpotency rename

Issue request:
FHIR-15643 was Published/Persuasive for the PHER-owned Immunization resource. It asked to reverse Immunization.isPotent to Immunization.isSubpotent so the element name matches subpotentReason, while preserving the rule that a missing value means the dose is assumed potent.

Initial application:
The change was approved on the 2018-06-14 PH WG call and applied in git commit 3161b27852, which changed the Immunization spreadsheet row from Immunization.isPotent to Immunization.isSubpotent and updated Immunization examples from isPotent to isSubpotent.

Additional context:
Immunization is active in the current build through source/fhir.ini. The current StructureDefinition source is the post-spreadsheet authoritative artifact and contains Immunization.isSubpotent with the original missing-value meaning, plus an imm-2 constraint tying subpotentReason to isSubpotent=true. Current source/immunization has no isPotent matches. PH WG Confluence minutes confirm the same vote and intended rename; Zulip search found only the tracker bot notification and no conflicting substantive discussion.

AutoFHIR reconciliation:
This audit commit makes no source change because the current active Immunization source already implements the requested rename and missing-value semantics.

Recommendation:
Keep this no-change audit commit as-is. No additional core FHIR source work is needed for FHIR-15643.
