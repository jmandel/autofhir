FHIR-17621: Audit job title extension relocation

Issue request:
FHIR-17621 was Published/Persuasive with Modification for Patient Administration. Although the title asked for a PractitionerRole roleTitle element, the accepted resolution required a new standard jobTitle extension: CodeableConcept 0..1 with an example value set, available on both PractitionerRole and Practitioner, and defined as a job title that may be independent of role.

Initial application:
The issue was applied in core by c2d19685c9, which added source/practitioner/structuredefinition-extension-practitioner-job-title.xml plus the supporting CodeSystem and ValueSet and registered the extension in the Practitioner implementation guide. That source used Practitioner and PractitionerRole contexts, a CodeableConcept value, and an example PractitionerJobTitle binding. Later, dd468d4f17 removed the standard extension source files from core as part of the broad R5 extension source relocation.

Additional context:
The current core history page states that all extensions moved to the hl7.fhir.uv.extensions package, still published as part of the specification but released more often. Current core has no active practitioner-job-title source files beyond retained canonical OID entries. The Extension Pack checkout contains the active practitioner-job-title StructureDefinition, ValueSet, and CodeSystem with PA ownership, Practitioner and PractitionerRole context, CodeableConcept value, example binding, and the example codes named in the Jira resolution. The same PA minutes also identify FHIR-15607 as the duplicate/same-change-family title request.
