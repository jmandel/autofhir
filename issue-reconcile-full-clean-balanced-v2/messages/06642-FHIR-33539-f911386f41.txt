FHIR-33539: Audit SDC FHIRPath additions

Issue request:
FHIR-33539 was an Applied/Persuasive FHIR-core change request to propagate selected SDC FHIRPath variables and functions into core: add weight() (the SDC ordinal() successor) to the core FHIRPath page, add QuestionnaireResponse-specific FHIRPath additions including %questionnaire and %qItem, and add FHIRPath-page notes pointing to QuestionnaireResponse and SubscriptionTopic guidance. The Jira resolution text also mentioned answers(), but the related SDC decision FHIR-37508 removed answers() before the core source application.

Initial application:
The source application appears to be commit 9ea8288fce31691fc55497b9b1f3f289292cace8, which added the FHIRPath page cross-references, the weight() function, and the QuestionnaireResponse FHIRPath Additions section with %questionnaire and qitem. Later QA/history refined that content, including c23512f0f168cafe81d9dbff149e3bee23dce8af adding the missing percent prefix so the variable is now %qitem. No prior commit on the combined branch carried Issue-Reconcile-Key: FHIR-33539 before this audit.

Additional context:
FHIR-37508 is a Published/Persuasive with Modification SDC issue that explicitly removed answers() as not useful given its limitations and renamed ordinal() to weight(). Current SDC source now lists %questionnaire, %qitem, and weight(), but not answers(), and its change log cites FHIR-37508 for dropping answers(). The FHIR-I WGM minutes for the FHIR-33539 vote record adding ordinal/weight to core FHIRPath, adding questionnaire-related items to QuestionnaireResponse, and adding links, which aligns with the current core text without reintroducing answers(). The current fhir.ini keeps QuestionnaireResponse as an active resource, so source/questionnaireresponse/questionnaireresponse-notes.xml remains in build scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding answers() now would conflict with the final SDC removal decision and with the current SDC expression guidance that FHIR-33539 was intended to propagate. The current core source already contains the surviving FHIR-33539 content: FHIRPath links to QuestionnaireResponse and SubscriptionTopic, a core weight() function, and QuestionnaireResponse-specific %questionnaire/%qitem guidance.

Recommendation:
Keep this audit commit as-is. If the work group wants an answers()-like helper in core despite FHIR-37508, it should be raised as a new FHIR-I decision rather than inferred from the stale FHIR-33539 resolution wording.
