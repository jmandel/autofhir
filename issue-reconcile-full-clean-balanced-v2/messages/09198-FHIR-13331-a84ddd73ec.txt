FHIR-13331: Audit StructureDefinition.type logical model fix

Issue request:
FHIR-13331 was a Published FHIR-core StructureDefinition change request, resolved Persuasive with Modification for STU3. It said the then-current StructureDefinition.type definition as code with an extensible binding did not work for logical models, and the final resolution required changing sdf-11 so it no longer forced the root path for logical models plus adding logical-model guidance tying the first element path/type name to the last part of the logical model canonical/type URL.

Initial application:
The issue was applied before this reconciliation. Git-svn commit 55ebc20f189e7dd4efc817a098fd7c82386b2a43, `#13331 - fix sdf-11 for logical models`, added the logical-model type-name/tail-of-URL guidance to the StructureDefinition spreadsheet and changed sdf-11 from `snapshot.empty() or snapshot.element.first().path = type` to `kind != 'logical' implies snapshot.empty() or snapshot.element.first().path = type`. A later source-history commit, 52f82f6efccdd925b78353aadd1b0d5b61e022aa, changed StructureDefinition.type from code to uri, added relative/absolute URL wording, and changed the StructureDefinition type search parameter from token to uri; although that commit was tagged GF#15660 for an unrelated Questionnaire Jira, it carried the remaining StructureDefinition.type representation requested by FHIR-13331 into the source before the current XML source rework.

Additional context:
StructureDefinition is an active current-build resource in source/fhir.ini. The current source/structuredefinition/structuredefinition-StructureDefinition.xml has StructureDefinition.type as uri, says non-absolute references are relative to http://hl7.org/fhir/StructureDefinition while absolute URLs are required for logical models, excludes logical models from sdf-11, and retains later FHIR-33065 wording that logical-model type SHALL be a fully specified URL and the type name SHOULD start with the final URL path segment. The current StructureDefinition-type search parameter is also uri. FHIR-13354 is a Duplicate that points back to FHIR-13331. FHIR-25777 later confirmed that FHIR-13331 was applied in R4 but not STU3 and is already represented on the combined branch as a no-change current-build audit; FHIR-33065 is also already represented and clarifies the same logical-model URL wording. Zulip and Confluence evidence found no conflicting later decision.
