FHIR-5998: Audit ImagingStudy coded element status

Issue request:
FHIR-5998 was Published/Persuasive with Modification for DSTU1. The request objected that ImagingStudy used code or Coding for procedure, laterality, bodySite, modalityList, and series.modality where CodeableConcept would better support vocabulary mapping; the final resolution narrowed the change to make ImagingStudy.procedure a Reference(Procedure) and keep modalityList and series.modality as Coding with an extensible DICOM CID binding.

Initial application:
The historical source shows explicit application commits for the seed: 063cfba117 changed imagingstudy.procedure to refer to Procedure, and 07e0134515 fixed the modality bindings and added the DICOM modality value set. A later cleanup commit, 2a416c3e03, continued the same ImagingStudy/ImagingObjectSelection change family. Those changes were made against the old spreadsheet source before ImagingStudy was migrated to the current StructureDefinition XML source.

Additional context:
ImagingStudy is an active current-build resource in source/fhir.ini, and the authoritative current source is source/imagingstudy/structuredefinition-ImagingStudy.xml. Later final R5/R6 Imaging Integration decisions intentionally moved beyond the DSTU1 resolution: FHIR-36120 was Published/Persuasive and changed ImagingStudy.modality and ImagingStudy.series.modality from Coding to CodeableConcept and ImagingStudy.series.bodySite to CodeableReference(BodyStructure); commit 1891df8e49 applied those datatype changes. FHIR-38673 and FHIR-50894 temporarily moved procedure semantics away from a direct Procedure reference, but FHIR-53025 was Applied/Persuasive and re-established ImagingStudy.procedure as Reference(Procedure) for performed procedures. The current source reflects those later decisions: modality and series.modality are CodeableConcept with extensible DICOM CID 33 bindings, procedure is Reference(Procedure), bodySite is CodeableReference(BodyStructure), and separate laterality has been removed by later R6 work.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source is correct when FHIR-5998 is interpreted together with the later final Jira decisions and current build scope; reverting modality back to Coding/CID29 or changing procedure away from Reference(Procedure) would contradict newer applied or published decisions.

Recommendation:
Keep this no-change audit commit. Future work should use the later R5/R6 ImagingStudy issues, especially FHIR-36120 and FHIR-53025, as the controlling decisions for current datatype and procedure semantics rather than treating the literal DSTU1 FHIR-5998 resolution as the current target.
