FHIR-50529: Audit TestScript constraints outside core

Issue request:
FHIR-50529 was Applied/Persuasive with Modification for R6. It asked to replace the confusing duplicated TestScript assert constraints tst-5, tst-6, and tst-18 with separate constraints: one requiring a singular assertion function across the full set of assertion-function elements and another preventing operator/value from being used with minimumId, navigationLinks, or validateProfileId.

Initial application:
The approved change was applied by PR #3607. Commit 38cce304a2 updated source/testscript/structuredefinition-TestScript.xml and invariant tests, adding the singular-assertion and operator/value restrictions to setup, test, and common assert elements as tst-7/tst-8, tst-13/tst-14, and tst-20/tst-21. Merge commit 560a86e3f9 records PR #3607 as merged on 2025-08-25.

Additional context:
Current core no longer contains active TestScript source. Commit f9a44787c4 removed TestScript, TestReport, and TestPlan source entries from source/fhir.ini and added an additional-ig-list pointer to the FHIR Testing IG. Current source/ballot-intro.html links TestScript to the Testing IG, and the current Testing IG package contains the approved split constraints for setup, test, and common assert.

AutoFHIR reconciliation:
