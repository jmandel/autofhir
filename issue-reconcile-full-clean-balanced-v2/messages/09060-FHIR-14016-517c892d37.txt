FHIR-14016: Audit minValue instant exclusion

Issue request:
FHIR-14016 was a Published FHIR-core STU3 change request resolved Persuasive. It said http://hl7.org/fhir/StructureDefinition/minValue should not allow instant because instant is not an allowed Questionnaire.item type, and the resolution was to remove instant from minValue.

Initial application:
The Jira comment records SVN revision 13417. In the Git import, commit 0b586a8c2aaa304dea8405399295d7ba692acb7f applied the request on 2018-03-13 by removing instant from the minValue row in source/profiles/element-extensions-spreadsheet.xml, changing the old type list from date|dateTime|time|instant|decimal|integer to date|dateTime|time|decimal|integer.

Additional context:
FHIR-14017 was the paired STU3 Published issue for the same minValue extension and added Quantity support; it is already represented on the combined branch. FHIR-27914 was a later Published R5 decision for the minValue/maxValue extension family; it confirmed Questionnaire.item supports Quantity but not instant, aligned both extensions to date/dateTime/time/decimal/integer/Quantity, and is also already represented on the combined branch. Current core no longer carries the minValue extension definition row after dd468d4f1799dd79819315b211588ef1cf4586e0 removed R5 extension definitions from core; the current authoritative definition lives in the FHIR Extension Pack. The separate core ElementDefinition.minValue[x] element still allows instant for elements whose own type is instant, but that is not the Questionnaire.item minValue extension requested by this issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Extension Pack source input/definitions/Questionnaire/StructureDefinition-minValue.xml constrains Extension.value[x] to date, dateTime, time, decimal, integer, and Quantity, with no instant. The active core element-extensions spreadsheet has no minValue row to edit, and the core Questionnaire notes only link to the external extension definition through [%extensions-location%].

Recommendation:
Keep this audit commit as-is. No current core source change is needed for FHIR-14016; do not remove instant from the separate ElementDefinition.minValue[x] base element, and do not reintroduce duplicate core extension rows. Revisit only if a future work-group decision changes the Questionnaire.item answer types or moves these extensions back into core.
