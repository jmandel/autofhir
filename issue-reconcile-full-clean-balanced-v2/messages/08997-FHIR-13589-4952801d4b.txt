Issue request:
FHIR-13589 was a Published/Persuasive FHIR-core overview issue asking to adjust the Architect's Introduction performance bullet because the old text said FHIR resources were "lean and optimized for exchange across the network," which overstated bandwidth optimization relative to FHIR's human-readable XML/JSON design.

Initial application:
The Jira comment records application in svn 14492. In git history this maps to commit 735fbdf0b5, which changed source/overview-arch.html from saying resources were "lean and optimized" to saying they are "lean and suitable" while explicitly noting that FHIR favors simplicity and human readability over compactness, with highly optimized formats available for bandwidth-sensitive contexts.

Additional context:
source/hierarchy.xml actively includes source/overview-arch.html as the Architect's Introduction page, so the relevant source is in the current build scope. Current source no longer contains the overstated "optimized for exchange across the network" claim in the overview page.
