FHIR-33944: Add tx-resource to CodeSystem validation

Issue request:
FHIR-33944 was Applied/Persuasive for R6 by Vocabulary and asked to formally document an optional tx-resource input parameter for $validate-code on both CodeSystem and ValueSet and for ValueSet $expand. The accepted definition lets clients pass additional ValueSet or CodeSystem resources needed to process a supplied value set or related terminology input, with client-provided resources used preferentially unless the server detects a conflict with known resources.

Initial application:
The issue appears to have been partially applied by commit 4cd9f00b61, which added tx-resource to source/valueset/operationdefinition-ValueSet-expand.xml and source/valueset/operationdefinition-ValueSet-validate-code.xml as part of a broader ValueSet operation-parameters change. That commit did not change source/codesystem/operationdefinition-CodeSystem-validate-code.xml, so the current CodeSystem $validate-code operation still lacked the accepted parallel parameter.

Additional context:
CodeSystem and ValueSet are active resources in source/fhir.ini, and source/codesystem/list-CodeSystem-operations.xml includes OperationDefinition/CodeSystem-validate-code, so the missing CodeSystem operation definition is in current build scope. FHIR-30277 is a duplicate/background request for passing included value sets to $expand, while submitted FHIR-55497 later observes that tx-resource and other ValueSet validation parameters are still absent from CodeSystem operations but is broader and unresolved. Confluence Vocabulary WGM minutes for 2023-05-10 list FHIR-33944 among the terminology-service trackers discussed with FHIR-I and point to the Jira resolution; a 2024 Zulip terminology thread confirms implementers were relying on FHIR-33944 for tx-resource documentation and does not contradict the accepted scope.

AutoFHIR reconciliation:
This commit adds the missing optional tx-resource input parameter to CodeSystem/$validate-code, using Resource type with CodeSystem and ValueSet target profiles. The documentation is adapted from the accepted ValueSet wording so it refers to the supplied code system in the CodeSystem operation context while preserving the approved conflict and preferential-use semantics.

Recommendation:
Keep this source change. It completes the missing CodeSystem portion of the applied FHIR-33944 decision without taking on the unresolved broader parameter alignment requested by FHIR-55497.
