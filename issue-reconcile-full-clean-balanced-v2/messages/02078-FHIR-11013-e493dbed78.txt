FHIR-11013: Audit PGx genomics examples

Issue request:
FHIR-11013 was a Published/Persuasive Clinical Genomics change request from the DSTU2 ballot asking to discuss, clarify, and create pharmacogenomics examples for diplotype, genotype, and haplotype usage. The accepted resolution said examples and explanatory CG guidance would be added for Sequence, Observation-genetics, DiagnosticReport-genetics, and DiagnosticRequest-genetics.

Initial application:
The issue was applied by commit b2b49e7e2b, whose message explicitly resolves #11013 and related CG example trackers. That commit added PGx examples for DiagnosticReport, DiagnosticRequest, Observation diplotype/haplotype/phenotype, and Sequence, plus TPMT examples and genomics.html guidance.

Additional context:
Those DSTU2/R3-era clinical genomics core artifacts did not remain the current design. Later history, especially 3cfe12f1b4, removed outdated Observation, DiagnosticReport, and ServiceRequest genomics artifacts and streamlined genomics.html. Current build scope has MolecularSequence commented out and MolecularDefinition active, and source/hierarchy.xml still includes the active Genomics Implementer Guidance page. The current MolecularDefinition source and example list contain active genotype, haplotype, CYP2C19, and Pgx-var examples, while genomics.html points implementers to the Genomics Reporting IG and Molecular Definition IG for structured sequence, allele, variation, haplotype, and genotype profiles.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing the original DSTU2 DiagnosticRequest/Observation-genetics examples would revive retired/outdated artifacts, while the current active source already provides modern PGx/genotype/haplotype explanatory coverage and examples in the resource family that replaced the old Sequence/MolecularSequence representation.

Recommendation:
Keep this audit commit as-is. Future substantive PGx reporting guidance should be handled in the Genomics Reporting or Molecular Definition IGs, or through a new Clinical Genomics work-group decision for current R6 core artifacts, not by restoring the old FHIR-11013 examples.
