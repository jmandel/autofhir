FHIR-47242: Audit NutritionProduct search parameters

Issue request:
FHIR-47242 was an Applied, Persuasive with Modification R6 OO change request asking for additional NutritionProduct search parameters. The accepted disposition kept the existing lotNumber and identifier parameters, added a search over ingredients.item, added instance.expiry as a search parameter named "expiration-date" with expression NutritionProduct.instance.expiry, and declined characteristics.type, characteristics.value, and instance.biologicalSourceEvent as standard search parameters.

Initial application:
The issue was applied in git commit d0f9f0cb92, which added NutritionProduct-ingredient-item and NutritionProduct-expiration-date to source/nutritionproduct/bundle-NutritionProduct-search-params.xml. A same-day follow-up commit bc72f4cfc3 corrected expiration-date from the non-FHIR SearchParameter type dateTime to date. The NutritionProduct resource is active in source/fhir.ini, so the resource folder and its search-parameter bundle are in current build scope.

Additional context:
OO HCP minutes from 2024-10-28 record discussion of FHIR-47242 and confirm the expiration-date naming for NutritionProduct.instance.expiry with a 9-0-2 vote. The current source also keeps the previously existing lot-number and identifier parameters and does not add the rejected characteristics or biologicalSourceEvent parameters. Later status-only work changed the NutritionProduct search parameters to normative without changing the FHIR-47242 semantics.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current source already contains the two accepted search parameters: ingredient-item with expression NutritionProduct.ingredient.item.concept, matching the CodeableReference token-search pattern, and expiration-date with expression NutritionProduct.instance.expiry and type date.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source work is needed for FHIR-47242 unless a future work group decision changes which NutritionProduct characteristics should be standard search parameters.
