FHIR-33990: Audit DiagnosticReport study search parameter

Issue request:
FHIR-33990 was a Published, Persuasive with Modification R4 change request from Orders & Observations, applied for R5. It asked to add a DiagnosticReport search parameter for the former imagingStudy element; the final decision changed the name to "study" and requested a reference search that could cover ImagingStudy and GenomicStudy.

Initial application:
No prior source commit explicitly tagged FHIR-33990 was found. The effective R5 application appears in nearby DiagnosticReport/GenomicStudy history: commit 5dff1ff5ad added SearchParameter DiagnosticReport-study with code "study" and expression DiagnosticReport.study, and changed the DiagnosticReport element from the former imagingStudy/labStudy split to generic DiagnosticReport.study with ImagingStudy and GenomicStudy targets.

Additional context:
DiagnosticReport and ImagingStudy are active current-build resources in source/fhir.ini, and the R4-to-R6 map records DiagnosticReport.imagingStudy as DiagnosticReport.study. GenomicStudy is no longer an active core resource in the current fhir.ini after later source history removed additional resources and incubator-bound material. FHIR-54164 records the resulting DiagnosticReport.study mismatch after GenomicStudy target removal, and FHIR-57361 keeps the generic study name while noting GenomicStudy has moved to Incubator. FHIR-37802, the same GenomicStudy/DiagnosticReport change family, is already represented on the combined branch and reconciled the remaining current narrative guidance.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current active DiagnosticReport search-parameter source already contains DiagnosticReport-study with code "study" and expression DiagnosticReport.study. The current authoritative DiagnosticReport.study definition targets ImagingStudy only, which is consistent with later removal of GenomicStudy from active core build scope; restoring the old GenomicStudy target or adding a separate imaging-study parameter would conflict with later decisions and current source configuration.

Recommendation:
Keep this audit commit as-is. Future work should only restore or extend DiagnosticReport.study search semantics for GenomicStudy if a new work-group decision brings GenomicStudy or an explicit external target relationship back into the active core build; otherwise the current core source correctly preserves the FHIR-33990 search parameter under the later R6 context.
