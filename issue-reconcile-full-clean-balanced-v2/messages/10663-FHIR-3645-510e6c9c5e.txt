FHIR-3645: Audit obsolete profile invariant display

Issue request:
FHIR-3645 was a Published/Persuasive DSTU1 FHIR-core change request asking why an invariant was not showing up in profile views or generated XML for the C-CDA Cognitive Status Result Observation profile, specifically the AdditionalInterpretationCodes extension.

Initial application:
No Jira-tagged source commit was found, but commit 378a21f1b1aff7c469b88311149026829f7e3779, three days after issue creation and before Jira resolution, made invariants structure-specific in the spreadsheet parser and fixed the C-CDA Cognitive Status Result invariant source. The C-CDA sheet's invariant tab was renamed to CCDACognitiveStatusResult-Inv, its named range was pointed at that sheet, and the invariant context/XPath was changed so the constraint attached to Observation rather than an extension URL fragment.

Additional context:
The affected profile was historical DSTU1 C-CDA-on-FHIR material. Current source/observation contains no C-CDA cognitive-status profile files, source/igs.xml has the C-CDA IG entry commented out, and the only current source/fhir.ini mention is a legacy [tla] abbreviation alias rather than an active profile source. Commit 1a42f96ce66945f26c26a41ab182f0a5fd7fbbcf later removed the C-CDA Observation profile spreadsheet and introduction files as part of old profile cleanup. Current active Observation StructureDefinition XML sources represent invariants as constraint elements.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical source/tooling work that FHIR-3645 requested was applied in 2014, and the affected C-CDA profile is no longer an active current-build artifact to repair.

Recommendation:
Keep this audit commit as-is. Do not reintroduce or edit the old C-CDA Cognitive Status Result profile in core; any future work should be based on a current active artifact or a new work-group decision.
