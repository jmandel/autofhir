FHIR-8575: Audit adjudication definitions

Issue request:
FHIR-8575 was a Published/Persuasive Financial Management correction raised against DSTU1 because the rendered Adjudication Codes value set had an empty Definition column. Jira records the accepted resolution as addressed in STU3.

Initial application:
No commit explicitly mentions FHIR-8575. The relevant historical source already carried inline concept definitions before commit 98b59306cf generated a separate CodeSystem resource for the adjudication concepts, and the pre-UTG-removal CodeSystem source included definitions for submitted, copay, eligible, deductible, unallocdeduct, eligpercent, tax, and benefit.

Additional context:
The current build keeps ClaimResponse active in source/fhir.ini, and source/claimresponse/valueset-adjudication.xml is therefore in build scope. The current value set no longer owns inline code definitions; it composes http://terminology.hl7.org/CodeSystem/adjudication. Commit 5c0494aacf removed the core CodeSystem as part of moving UTG/THO content out of the core build, and current THO plus build.fhir.org expansion evidence shows that the adjudication codes have definitions and the rendered value set displays them.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding duplicate concept definitions back into the core ValueSet would conflict with the current source-of-truth split between core and HL7 Terminology, while the current rendered value set already satisfies the Jira request.

Recommendation:
Keep this audit commit as-is. Revisit only if the build stops expanding the THO adjudication code system with definitions or if terminology ownership changes; otherwise no FHIR-core source follow-up is needed.
