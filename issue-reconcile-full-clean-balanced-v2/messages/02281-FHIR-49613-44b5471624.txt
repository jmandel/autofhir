FHIR-49613: Anchor BiologicallyDerivedProduct notes

Issue request:
FHIR-49613 is Applied/Persuasive for FHIR-core BiologicallyDerivedProduct. It asked that BiologicallyDerivedProduct and BiologicallyDerivedProductDispense h2 sections use stable named anchors instead of generated numeric section anchors, and that hardcoded numeric fragment links such as the module page link to BiologicallyDerivedProduct boundaries be replaced.

Initial application:
The issue was initially applied by HL7/fhir#3275. Commit 31d076e changed the Biologically Derived Product module link from a numeric BiologicallyDerivedProduct section fragment to #bnr, and merge 2e682e0 brought in stable #scope and #bnr anchors for the BiologicallyDerivedProduct and BiologicallyDerivedProductDispense introduction sections.

Additional context:
BiologicallyDerivedProduct remains an active core resource in source/fhir.ini, while BiologicallyDerivedProductDispense is no longer listed as an active core resource and the current BiologicallyDerivedProduct text points readers to the OO Incubator IG for it. Later BDP work added a new BiologicallyDerivedProduct Notes h2 without a stable h2 anchor, and the R6 ballot note added a hardcoded numeric link to that Notes section.

AutoFHIR reconciliation:
This commit adds the missing #notes anchor before the active BiologicallyDerivedProduct Notes h2 and changes the ballot-note link from biologicallyderivedproduct.html#8.25.5 to biologicallyderivedproduct.html#notes. No BiologicallyDerivedProductDispense source change is made because its relevant current core introduction anchors are already stable and the resource is not active in the core build.

Recommendation:
Keep this source fix. It completes the FHIR-49613 stable-anchor requirement for the current core BiologicallyDerivedProduct page without changing BDPDispense out-of-build source or unrelated numeric links on other resources.
