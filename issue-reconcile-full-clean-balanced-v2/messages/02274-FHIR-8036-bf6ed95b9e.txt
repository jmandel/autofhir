FHIR-8036: Audit retired genetics assessed-condition extension

Issue request:
FHIR-8036 was a Published/Persuasive FHIR-core Observation change request from the 2015 May ballot. It asked the specification to define the meaning of "condition context" for the genetics assessed-condition extension. The accepted resolution says the context is a diagnosed condition in the patient that may have a pertinent association with a condition being tested for, and that AssessedCondition is a Reference to Condition.

Initial application:
No meaningful FHIR-8036-tagged source commit was found in the current core history. Historical R4B source for source/diagnosticreport/structuredefinition-extension-DiagnosticReport-geneticsAssessedCondition.xml retained the older "condition context for genetic testing" wording while constraining value[x] to Reference(Condition). The Jira issue later records Kevin Power's 2022 note that the extension was removed in R5.

Additional context:
The current FHIR core source has active DiagnosticReport and Observation resources, but no current build input or checked-in current source reference for DiagnosticReport-geneticsAssessedCondition, geneticsAssessedCondition, or the old extension URL outside historical release snapshots. Current DiagnosticReport and Observation genomics guidance points readers to the Genomics Reporting IG and GenomicStudy instead. A retired/deprecated copy of DiagnosticReport-geneticsAssessedCondition exists in the separate FHIR Extension Pack, with its standards-status reason saying it has been replaced by the Genomics Reporting Guide; that repository is outside this core reconciliation target.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. The current core build no longer owns or publishes the old extension, so adding wording in this repository would not correct a current built artifact. Any future clarification of the retired extension-pack copy belongs in the FHIR Extension Pack, not in this core combined branch.

Recommendation:
Keep this audit commit as-is for FHIR core. No current core follow-up is recommended. If maintainers want historical clarity for the retired extension-pack artifact, handle that as a separate Extension Pack decision because the authoritative remaining source is outside this repository.
