FHIR-18136: Audit VerificationResult primary source rename

Issue request:
FHIR-18136 was a Published/Persuasive Patient Administration change request for VerificationResult. It asked to update VerificationResult.primarySource.organization so the primary source could be either an Organization or Practitioner, and to rename the element to who because it would no longer be organization-specific.

Initial application:
The request was applied in core by git commit ffe009e9cf00c81dc11cf81d1045b641b0d9a7bb, whose subject explicitly includes GF#18136. At that time VerificationResult was an active resource in source/fhir.ini, and the commit changed source/verificationresult/verificationresult-spreadsheet.xml from VerificationResult.primarySource.organization with type Reference(Organization) to VerificationResult.primarySource.who with type Reference(Organization|Practitioner) and short/definition text "Reference to the primary source".

Additional context:
Patient Administration's 2018 Baltimore minutes record the accepted 6-0-0 disposition for this exact request. A later PA call also approved PractitionerRole reference additions for several elements, including VerificationResult.primarySource.who. VerificationResult is no longer an active resource in this FHIR core checkout: current source/fhir.ini has no active verificationresult resource entry, source/verificationresult is absent, and commit 71567db3ee039ac6977be5f96a7e013896569a36 removed the core resource source while current history and ballot text point to the HL7 Admin Incubator copy. The current Admin Incubator StructureDefinition contains VerificationResult.primarySource.who as Reference(Organization|Practitioner|PractitionerRole), and residual core model-definition content also uses primarySource.who rather than primarySource.organization.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The requested rename and Practitioner reference were applied historically, the current core build has no authoritative VerificationResult resource source to edit, and the current moved/external representation preserves the requested semantics, with the later PractitionerRole expansion layered on top.

Recommendation:
Keep this audit commit as-is. No current core follow-up is needed for FHIR-18136; any future changes to the live VerificationResult resource should be made in the HL7 Admin Incubator source unless the resource is reintroduced to the core build.
