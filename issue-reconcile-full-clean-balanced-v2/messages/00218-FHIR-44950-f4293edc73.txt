FHIR-44950: Audit removed ImmunizationRecommendation status wording

Issue request:
FHIR-44950 was Applied/Not Persuasive with Modification for PHER after being raised against R5 ImmunizationRecommendation. The issue asked to resolve the mismatch between the immunization-recommendation-status code "complete" and ImmunizationRecommendation.recommendation.forecastStatus usage. The approved resolution renamed the series-level code to "seriescomplete", added "agedout", updated the "due" definition, broadened the ImmunizationRecommendation.recommendation comment to cover whole-series recommendations when no administration is recommended, and updated ImmunizationRecommendation narrative scope/boundaries text.

Initial application:
The FHIR-core portion was partially applied in commit 26bcd914e62b5e614c63e70c5af39af7f4b50c74, which updated source/immunizationrecommendation/immunizationrecommendation-introduction.xml, added the ImmunizationRecommendation diagram PNG, and changed the ImmunizationRecommendation.recommendation comment in source/immunizationrecommendation/structuredefinition-ImmunizationRecommendation.xml. Jira later records that the UTG portion was applied through UP-580; UP-580 is Proposal Implemented and states that it retires/replaces "complete" with "seriescomplete", adds "agedout", and updates "due" based on FHIR-44950.

Additional context:
The current FHIR-core build no longer contains ImmunizationRecommendation or its local immunization-recommendation-status value set source. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed ImmunizationRecommendation and ImmunizationEvaluation, including their active source/fhir.ini resource, work group, compartment, FMM, abbreviation, standards-status entries, StructureDefinitions, narrative files, examples, search parameters, and immunization recommendation value sets. The current source/fhir.ini active resources list contains immunization=Immunization but no immunizationrecommendation entry, source/immunizationrecommendation is absent, and build.fhir.org now returns 404 for the old valueset-immunization-recommendation-status.html page. Related ImmunizationRecommendation issues FHIR-47040 and FHIR-48726 have already been audited on the combined branch with the same resource-removal context.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing source/immunizationrecommendation or the deleted value set files would reverse a later current-build removal, while changing unrelated residual references such as diagrams or cross-version mapping lines would not implement the FHIR-44950 request. Any current terminology source-of-truth follow-up belongs outside this FHIR-core checkout through UTG/THO rather than through core source files.

Recommendation:
Keep this audit commit as-is for the current core build. If ImmunizationRecommendation is reintroduced in FHIR core, carry forward the FHIR-44950 narrative/comment changes from commit 26bcd914e62b5e614c63e70c5af39af7f4b50c74 and ensure the corresponding terminology remains aligned with UP-580. Any stale references to the deleted resource should be handled as separate removal-cleanup work, not as this issue's reconciliation.
