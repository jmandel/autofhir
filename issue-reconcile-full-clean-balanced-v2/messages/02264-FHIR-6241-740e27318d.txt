FHIR-6241: Audit ImagingStudy retrieve URI wording

Issue request:
FHIR-6241 was Published/Persuasive for DSTU1 by Imaging Integration. It reported that the ImagingStudy short description "Retrieve URI (0008,1190)" was confusing and asked for a functional description such as where the referenced content is available; the accepted resolution was to update short descriptions to provide a functional description while identifying the related DICOM attribute name and tag.

Initial application:
The issue was applied in git-svn revision 5643, commit 99414ea80b156a262edd01d37c074a556a789ef9, which changed the then-current ImagingStudy spreadsheet short text from "Retrieve URI (0008,1115 > 0008,1190)" to "Location of the referenced instance(s) (0008,1115 in 0008,1190)" and changed the definition to "URI/URL specifying the location of the referenced series using WADO-RS".

Additional context:
Later ImagingStudy changes superseded the original direct retrieve-URI element. FHIR-10268 replaced ImagingStudy.url and ImagingStudy.series.url with baseLocation structures for multiple retrieval URLs and URL types, and FHIR-12235 then replaced baseLocation with ImagingStudy.endpoint and ImagingStudy.series.endpoint references to Endpoint. In the current build, source/fhir.ini actively includes ImagingStudy, while ImagingManifest is only listed under deleted resources; the active ImagingStudy StructureDefinition has functional endpoint short descriptions and implementation-note links, and no active ImagingStudy source still contains "Retrieve URI" or the DICOM tag 0008,1190 wording from FHIR-6241. FHIR-47660 later refined the same current endpoint descriptions and is already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active ImagingStudy source no longer exposes the confusing Retrieve URI short name, and its endpoint descriptions now describe network services that provide study or series access. Editing deleted ImagingManifest spreadsheet remnants or reintroducing 0008,1190 text into current endpoint descriptions would not improve the current build and could conflict with later endpoint-based decisions.

Recommendation:
Keep this audit commit as-is. No current FHIR core source change is needed for FHIR-6241; future ImagingStudy access wording should be handled through the endpoint model and the later ImagingStudy endpoint trackers rather than by reviving the DSTU1 retrieve-URI element.
