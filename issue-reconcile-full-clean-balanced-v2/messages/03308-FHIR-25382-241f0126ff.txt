FHIR-25382: Audit medication definition version/status elements

Issue request:
FHIR-25382 was Published/Persuasive for R5. It asked BR&R to add business-level version elements to MedicinalProduct/RegulatedMedicinalProduct and SubstanceSpecification, and to add a product status element while noting that SubstanceSpecification.status already existed.

Initial application:
The request was applied in git commit f852670ecf29ab9e19b3b2111bc5cca817b693b3, which added MedicinalProductDefinition.version, MedicinalProductDefinition.status, and SubstanceDefinition.version to the then-active spreadsheet sources. The named Jira artifacts have since been represented in the current build as MedicinalProductDefinition and SubstanceDefinition.

Additional context:
source/fhir.ini lists medicinalproductdefinition and substancedefinition as active resources, and marks MedicinalProductDefinition normative/approved and SubstanceDefinition approved. Later Published BR&R decisions FHIR-31790 and FHIR-31830 superseded the original optional status shape by requiring these status elements to be code, required, modifier elements bound to PublicationStatus.

AutoFHIR reconciliation:
No source change was made. Current authoritative StructureDefinition sources already contain MedicinalProductDefinition.version 0..1 string, SubstanceDefinition.version 0..1 string, and status elements on both resources. The status elements intentionally differ from FHIR-25382's original optional product status request because later final Jira decisions made them required coded modifier elements.

Recommendation:
Keep this audit commit as-is. No follow-up in core FHIR is needed for FHIR-25382 unless BR&R reopens the later required-status decisions.
