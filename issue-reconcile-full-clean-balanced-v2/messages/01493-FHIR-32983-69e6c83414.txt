FHIR-32983: Audit cited artifact status codes

Issue request:
FHIR-32983 was a Published CDS change request with a Persuasive with Modification resolution to add accepted, approved, and created to the CitedArtifactStatusType code system and value set used by Citation.citedArtifact.currentState and Citation.citedArtifact.statusDate.activity, with definitions more explanatory than the display names.

Initial application:
The request was applied before this reconciliation in git commit 2604ce005b048a78ece942b4b995dd6d4be735ce, which added created, accepted, and approved plus expanded definitions to source/citation/codesystem-cited-artifact-status-type.xml. The R5 checked-in history still contains those codes, and CDS/COKA Confluence notes from July 1, 2021 record the definitions developed to apply FHIR-32983.

Additional context:
FHIR-32322 was the broader Citation value-set request from which this status-type work was split. FHIR-34446 later changed the same status family by adding the unknown status. FHIR-39632 then moved many CDS/Citation terminology definitions, including cited-artifact-status-type, out of core and into THO. A later core cleanup removed the Citation resource from the FHIR core build and changed core narrative to point to the Evidence Based Medicine on FHIR IG. Current source/fhir.ini has no active Citation or cited-artifact-status-type build entry, and the current core checkout has no active source for the cited-artifact-status-type CodeSystem or ValueSet outside OID and historical release records.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR core source is not the authoritative build location for Citation.citedArtifact or the cited artifact status terminology. The current THO source for http://terminology.hl7.org/CodeSystem/cited-artifact-status-type includes created, accepted, and approved with the requested explanatory definitions, and the current HL7/ebm Citation StructureDefinition source binds Citation.citedArtifact.currentState and Citation.citedArtifact.statusDate.activity to the THO value set.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-32983; future changes to these codes should be handled in THO and, for Citation bindings, the EBM IG source rather than by reintroducing core Citation terminology files.
