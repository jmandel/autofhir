The same commit also added the neighboring FHIR-32804 `MedicationDispense.recorded` element.

Additional context:
MedicationDispense is an active resource in `source/fhir.ini`, so `source/medicationdispense/structuredefinition-MedicationDispense.xml` is current build-scope source. Later FHIR-49940 uses `statusChanged` in the cancelled-dispense example, confirming the element remains the intended place to record the cancellation date.
