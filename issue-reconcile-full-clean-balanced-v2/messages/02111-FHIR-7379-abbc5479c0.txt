FHIR-7379: Audit Composition document-boundary wording

Issue request:
FHIR-7379 was a Published/Persuasive Structured Documents change request for the Composition resource. It asked the opening Composition wording to be explicit that Composition establishes context and defines the document structure, but that the complete document content is held in a Bundle containing the Composition and other resources.

Initial application:
The Jira records the decision as accepted with a 2015 svn revision 6205 application note. The current git history does not contain a FHIR-7379-tagged commit, but current build-scope Composition source retains the intended distinction: Composition establishes context and provides document structure, while the full document content is expressed by a Bundle containing the Composition and its entries.

Additional context:
FHIR-14723 later became Published/Persuasive and corrected the too-absolute phrase that Composition does not contain content, because Composition can contain narrative content. The combined branch already contains a FHIR-14723 reconciliation commit, and later FHIR-13426 and FHIR-25438 commits generalized the same Composition wording from clinical document-only phrasing to package/author-traceability language. No directly relevant Zulip or Confluence evidence was found that conflicts with Jira and source history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active Composition source already says Composition groups information into a coherent package that establishes context, that when used as a FHIR document it provides the document structure, that full document content is expressed in a Bundle containing the Composition and entries, and that a Composition alone does not constitute a document. Re-adding the old absolute "does not contain content" wording would conflict with the later FHIR-14723 clarification.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-7379 unless the work group reopens the broader Composition/document boundary after the later FHIR-14723, FHIR-13426, or FHIR-25438 decisions.
