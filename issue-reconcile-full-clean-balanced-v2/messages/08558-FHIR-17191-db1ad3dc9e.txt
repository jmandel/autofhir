FHIR-17191: Audit mapping grammar link

Issue request:
FHIR-17191 was a Published/Persuasive STU3 correction reporting that the ANTLR mapping grammar URL http://hl7.org/fhir/2018Jan/mapping.g4 was broken from the mapping-language page. The requested resolution was to fix the broken link.

Initial application:
The issue was initially applied in svn revision 14431, preserved as git commit 83a6890014a2d1cc1811f8e66c2a0ba9efe7773b, which removed the introductory link to mapping.g4 from source/mapping-language.html. The grammar file itself had already been added under images/mapping.g4 with a publish.ini mapping in fffa6cd98dda7c737733f0fb352a4c69c790053e, and later commit 7b1914afeb19a274f6a9806ebb3a214165189356 updated the formal grammar section to point at mapping.g4.

Additional context:
Current source still links the formal grammar section to mapping.g4, and publish.ini lists mapping.g4 in the [images] section so the build publishes images/mapping.g4 at the linked output path. The current CI build serves both mapping-language.html with the mapping.g4 link and mapping.g4 itself with HTTP 200. Zulip discussion shows the same broken-link report that became FHIR-17191 and older mapping-language discussion pointing to the grammar's historical images/mapping.g4 source path. Confluence searches found no conflicting work-group record.

AutoFHIR reconciliation:
This commit makes no source change. The current source/build relationship already satisfies the issue: the mapping-language page has a grammar link, the grammar file is in build scope through publish.ini, and the published target resolves.

Recommendation:
Keep this audit commit as-is. No current FHIR core source change is needed unless future build tooling stops publishing images/mapping.g4 to mapping.g4.
