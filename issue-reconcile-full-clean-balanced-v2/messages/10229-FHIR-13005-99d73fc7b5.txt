Issue request:
FHIR-13005 was Published/Persuasive as an OO technical correction for DSTU2. It reported that unused Task extensions were mistakenly generated with Observation/Observation.bodySite contexts, with the related URL pointing at extension-task-bodyposition.html, and proposed removing those extensions because Task did not use them.

Initial application:
The historical application is commit 6ec892056b4b8979e583805c849557c36bbc33b6 (`{#13005} corrected context for extensions`, 2017-03-13). That commit removed the bodyPosition, !anatomicalLocation, and !directionality rows with Observation contexts from source/task/task-extensions-spreadsheet.xml.

Additional context:
Task is still an active core resource in source/fhir.ini, but the active profile list no longer includes source/task/task-extensions-spreadsheet.xml and the current source/task folder has no Task bodyPosition, anatomicalLocation, or directionality extension definitions. Later core refactors removed the old Task extension source files, and the surviving body-position definition is the Extension Pack's observation-bodyPosition extension, scoped to Observation through FHIR 5.0 and Specimen.collection rather than to Task. Historical copies under tools/history are past release artifacts, not current build inputs.
