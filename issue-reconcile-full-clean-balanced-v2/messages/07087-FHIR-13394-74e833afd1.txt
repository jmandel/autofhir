FHIR-13394: Audit BodyStructure morphology application

Issue request:
FHIR-13394 was a Published/Persuasive with Modification OO change request for STU3 asking for BodySite/BodyStructure to distinguish the represented thing from its body location: rename BodyStructure.code to BodyStructure.location, add BodyStructure.morphology 0..1 with short "Kind of structure" and an example SNOMED CT morphologic abnormality binding, rename BodyStructure.qualifier to BodyStructure.locationQualifier, and add V2 mappings.

Initial application:
The issue was preapplied in the old spreadsheet source before current XML StructureDefinition source was introduced. Git history shows cc0dad0855 preapplied #13394/#13396 by changing BodyStructure.code to BodyStructure.morphology, retaining BodyStructure.location, renaming BodyStructure.qualifier to BodyStructure.locationQualifier, and tagging the morphology row with #13394. Git history also shows 341df2e7a6 added the requested V2 mappings for GF#13394.

Additional context:
The current build has BodyStructure active in source/fhir.ini. Later applied/published BodyStructure decisions intentionally changed the shape: FHIR-33129 replaced top-level location/locationQualifier with includedStructure/excludedStructure backbone elements, and FHIR-48110 moved morphology into BodyStructure.includedStructure.morphology. Related issue FHIR-13396, and later issues FHIR-33129 and FHIR-48110, are already represented on the combined branch, so this audit does not publish duplicate decisions for them.
