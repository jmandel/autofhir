FHIR-31809: Audit Ingredient strength clarification

Issue request:
FHIR-31809 was a Published FHIR-core MedicinalProductIngredient change request resolved as Persuasive with Modification for R5. The ballot commenter asked how a product could remain the same product if the same substance appeared to have different strengths in different countries; the disposition was to explain that the repetitions are representations of a single strength, not different strengths.

Initial application:
The issue appears to have been applied before reconciliation. Git commit 7f8ca2e76b added the clarification to source/ingredient/structuredefinition-Ingredient.xml, and commit 464b98e6e7 carried the same change forward while applying nearby Ingredient clarifications. The current active source still defines Ingredient.substance.strength as allowing repeated representations that are mathematically equivalent representations of a single strength.

Additional context:
The current build scope maps the old MedicinalProductIngredient artifact to Ingredient in source/fhir.ini and marks Ingredient active. Later Published issue FHIR-39134 revisited presentation, concentration, and multiple Ingredient strengths, and was applied by expanding examples rather than reversing the FHIR-31809 definition. BRR Confluence minutes reference the FHIR-31809 reconciliation discussion, and targeted Zulip searches did not find conflicting discussion.

AutoFHIR reconciliation:
No source change was made. The current source already contains the requested clarification in the authoritative StructureDefinition, and current examples provide adjacent context for presentation, concentration, reference strength, and repeated strength measurements.

Recommendation:
Keep this empty audit commit as-is. If the work group later wants to refine the exact phrase "mathematically equivalent" in light of measurement-point examples from FHIR-39134, that should be handled as a separate wording review rather than a missing application of FHIR-31809.
