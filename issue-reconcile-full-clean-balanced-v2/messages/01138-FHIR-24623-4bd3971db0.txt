FHIR-24623: Audit periodDuration extension support

Issue request:
FHIR-24623 was Published/Persuasive for the CQI Measure resource. It asked FHIR core to support expressing Measure.effectivePeriod with an anchor date/time and duration/range, and the later Jira comment narrowed the application path to a general Period extension that carries a Duration rather than adding Measure-specific child elements.

Initial application:
The issue was applied before this reconciliation by the J#24623 commits 6cdb0d85a3 and 0b6b322dd1, merged by PR #2263 as 0326a4cfa4. Those commits added an artifact periodDuration extension row for Period and added the Clinical Reasoning module link that explains it as allowing a period to be specified using a start date and duration.

Additional context:
The upstream FHIR-us-qm issue FHIR-21988 is the background IG decision that requested the R5 core tracker. Core later removed most extension definitions from the R5 source in dd468d4f17, and the periodDuration definition now lives in the FHIR Extension Pack as StructureDefinition-artifact-periodDuration with context Period and value Duration. The current active core Measure source still defines Measure.effectivePeriod as type Period, and the current Clinical Reasoning module links to the Extension Pack artifact-periodDuration page.

AutoFHIR reconciliation:
No source change was made. The current core source and Extension Pack definition already provide the requested representation: Measure.effectivePeriod is a Period, Period can carry the artifact-periodDuration extension, and core narrative points implementers to that extension. Reintroducing a core-local extension definition or adding Measure-only wording would duplicate the generic Period extension and conflict with the current extension-pack source ownership.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed unless the work group wants new Measure-specific guidance beyond the generic Period extension, in which case that should be handled as a new decision rather than as completion of FHIR-24623.
