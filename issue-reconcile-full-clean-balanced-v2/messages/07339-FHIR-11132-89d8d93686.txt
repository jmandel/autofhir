FHIR-11132: Audit ServiceRequest supportingInfo AOE guidance

Issue request:
FHIR-11132 was a Published, Not Persuasive with Modification OO change request asking whether DiagnosticRequest could carry ordering/collection question information such as pregnancy or fasting status. The accepted disposition was that Request.supportingInfo was intended for this information, with AOE alternate names/comments added and cardinality handled by the related cardinality tracker.

Initial application:
No current commit explicitly mentioning FHIR-11132 was found. The requested AOE guidance existed in DSTU2 DiagnosticRequest generated/profile artifacts, the DiagnosticRequest element was later renamed from supportingInformation to supportingInfo by the request-pattern work, and DiagnosticRequest/ProcedureRequest content was subsequently merged into the active ServiceRequest lineage.

Additional context:
ServiceRequest is the current active OO request resource in source/fhir.ini; DiagnosticRequest, ProcedureRequest, and ReferralRequest are retired or merged into ServiceRequest. The current ServiceRequest.supportingInfo source has the AOE aliases, max 0..*, and clinical-context wording requested by FHIR-11132, while later decisions FHIR-37355 and FHIR-31589 intentionally refined the type and clarified that supportingInfo is existing context rather than instructions/questions to perform.

AutoFHIR reconciliation:
This audit commit makes no source change because the active ServiceRequest StructureDefinition already conveys the requested rule: AOE/order-entry information belongs in supportingInfo when it is existing clinical context, and the element is repeatable. Adding more prose would duplicate current source and risk conflicting with the later FHIR-31589 boundary between supportingInfo and orderDetail.

Recommendation:
Keep this no-change audit. Further work is only needed if OO wants a new semantic change to how ServiceRequest distinguishes existing supporting information from questions or instructions to be gathered, which would be outside the FHIR-11132 disposition.
