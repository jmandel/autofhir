FHIR-11011: Audit retired Sequence quality type

Issue request:
FHIR-11011 was a Published/Persuasive DSTU2 Clinical Genomics change request asking to allow a type element under Sequence.quality. The resolution said to add Sequence.quality.type as a code with three choices: indel, snp, or unknown.

Initial application:
The issue was applied before this reconciliation by git commit 36543afd42c3489e5436c1c33a2a6988f7e36c31, whose subject explicitly references #11011 and whose source/sequence/sequence-spreadsheet.xml and .sheet.txt patch added Sequence.quality.type as a 1..1 code bound to qualityType with INDEL, SNP, and UNKNOWN codes.

Additional context:
Sequence was later replaced and retired from current core build scope. Current source/fhir.ini does not include Sequence in the active [resources] list and lists Sequence under [removed-resources]. The later MolecularSequence line is also commented out in current build metadata, while current diagnostics guidance says MolecularSequence has been replaced by MolecularDefinition and points to the current MolecularDefinition/GenomicStudy material. Current MolecularDefinition source has no Sequence.quality-style quality backbone to receive this historical element.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the requested Sequence.quality.type change was historically applied and the affected Sequence/MolecularSequence artifact is outside the current core build scope.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-11011 unless the Clinical Genomics work group reintroduces a current-build sequence quality backbone that needs the historical INDEL/SNP/UNKNOWN quality type semantics reviewed.
