FHIR-20202: Audit operation endpoint count

Issue request:
FHIR-20202 was Published/Persuasive for the FHIR-core operations page. It reported that the execution section said operations could be invoked on four endpoint types while the list contained only three, and the accepted correction was to change the count to "three" because operations on _history had been removed.

Initial application:
No explicit FHIR-20202-tagged source commit was found. The relevant operations source was nevertheless corrected by git commit 142ad7624ca77d81a9463a6ddbd278f521a109da, which changed source/operations.html from "four types" to "three types" while leaving the three endpoint bullets. That commit was recorded for FHIR-19523, FHIR-22702, and FHIR-23809; FHIR-23809's Jira text includes the same operations-page typo.

Additional context:
The current source/operations.html page is an active root narrative page linked from current documentation, REST API, exchange, and workflow pages. Its execution section now says "three types" and lists base, resource type, and resource instance endpoints. source/history.html also records GF#17258 as removing support for operations on historical resources, so restoring a fourth _history endpoint would be wrong. Later same-change-family Jira issues FHIR-25261 and FHIR-33083 are already represented on the combined branch with their own Issue-Reconcile-Key commits, so they are not duplicated here. Zulip and Confluence searches found no conflicting discussion.
