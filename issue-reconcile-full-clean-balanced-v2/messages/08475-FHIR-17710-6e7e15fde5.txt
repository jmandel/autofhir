FHIR-17710: Audit mapping log examples

Issue request:
FHIR-17710 was a Published/Persuasive FHIR-I correction for STU3 asking that the FHIR Mapping Language documentation include an example of a log statement because the existing "Each source can include a log statement" text was not complete enough; Jira's application comment says "has been added."

Initial application:
No commit explicitly mentions FHIR-17710. The underlying log statement syntax had already been introduced by FHIR-17032 in git commit d9c2be4be8, and the December 2018 mapping-language review added an inline source-statement example containing `log value` shortly before FHIR-17710 was resolved. Later FHIR-20841 normalized embedded FHIRPath expressions to parentheses, giving the current `log (value)`, `log ('not handled yet')`, and `log (src.field)` examples.

Additional context:
`source/hierarchy.xml` includes `mapping-language.html` under Implementation Support, and `source/fhir.ini` lists StructureMap as an active resource. The active StructureMap definition also has `StructureMap.group.rule.source.logMessage`, confirming the log statement is still part of the current build. FHIR-39486 later declined renaming log to trace but added a note documenting equivalence to FHIRPath `trace()`.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current mapping-language source already explains where `log` belongs, shows it embedded in a source statement, gives literal and FHIRPath examples, and explains execution order and output.

Recommendation:
Keep this audit commit as-is. Any future desire for a longer executable tutorial should be raised as a new mapping-language improvement, not as unfinished application of FHIR-17710.
