FHIR-13309: Audit AdverseEvent subject practitioner targets

Issue request:
FHIR-13309 was a Published, Persuasive with Modification STU3 Patient Care change request asking for AdverseEvent.subject to support people harmed in non-patient adverse-event scenarios. The original request proposed Practitioner and Person; the accepted resolution was to add Practitioner and RelatedPerson as AdverseEvent.subject reference targets.

Initial application:
The request was applied in two historical commits. Commit 4ba2f79300a5dafab68929190a64981e03a3d478 first changed the legacy AdverseEvent spreadsheet from Reference(Patient|ResearchSubject) to Reference(Patient|ResearchSubject|Practitioner|Person). Commit 0d80e1599c3bb751de22b8dc8fb6fa951b014c09 then applied the modification by replacing Person with RelatedPerson in the spreadsheet and sheet text. No prior reconciliation commit for FHIR-13309 was present on the combined branch.

Additional context:
AdverseEvent is active in the current build configuration and marked normative. Related Published issue FHIR-13308, already represented on the combined branch, removed Medication and Device from AdverseEvent.subject. Related Published issue FHIR-14759, also already represented on the combined branch, explains the current Group target and mandatory subject requirement. Later Applied issue FHIR-40657 removed ResearchSubject from AdverseEvent.subject, which explains why the current target list no longer includes the STU3-era ResearchSubject target. Later Triaged issue FHIR-54065 asks about adding CareTeam or Organization but is not a final decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scoped StructureDefinition already allows AdverseEvent.subject to reference Practitioner and RelatedPerson, does not allow Person, and remains consistent with the accepted modification and later subject-target decisions.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core follow-up is needed for FHIR-13309 unless a future final work-group decision, such as a resolved form of FHIR-54065, changes AdverseEvent.subject targets.
