FHIR-7439: Audit extensibility typo fix

Issue request:
FHIR-7439 was a Published/Persuasive FHIR-core technical correction for the 2015May extensibility page. It asked to correct the typo "diffferent" in the rule for extensions that are not safe to ignore and to make clear that such extensions are represented using Modifier Extensions.

Initial application:
Jira records the resolution as "fix" with a comment pointing to svn revision 5352. Git history contains b60749f81a7878771801b42761a804ccb5e7c04a, "#7439 - fix typo", which changed source/extensibility.html from "must be represented diffferent" to "must be represented diffferently, using ... a Modifier Extension".

Additional context:
The current build still uses source/extensibility.html for the Extension type page through the active source/fhir.ini type-page mapping. Later source edits have strengthened the wording to a SHALL and currently say that an extension that is not safe to ignore SHALL be represented using a Modifier Extension rather than an extension element. No directly relevant Zulip or Confluence evidence was found that would change the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original typo has already been removed from the active source, and the current wording preserves the requested implementer-facing meaning.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-7439 unless a future work group issue reopens the broader Modifier Extension guidance.
