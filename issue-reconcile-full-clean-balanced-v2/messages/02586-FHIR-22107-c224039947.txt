That spreadsheet source has since been replaced by source/adverseevent/structuredefinition-AdverseEvent.xml, and the current StructureDefinition already contains max 1 plus the GF#22107 note for AdverseEvent.suspectEntity.causality.

Additional context:
AdverseEvent and Library are active resources in source/fhir.ini. Patient Care minutes for 2019-08-29 list the GF#22107 AdverseEvent cardinality tracker, and direct Zulip searches found no conflicting discussion.

Changed the FHIR model-definition Library so AdverseEvent.SuspectEntity.causality is a scalar FHIR.AdverseEvent.Causality element instead of a list, and refreshed the embedded model-info attachment in source/library/library-fhir-model-definition.xml to match the readable content file. No change was needed to the AdverseEvent StructureDefinition or diagram because they already show 0..1.

Recommendation:
Keep this commit as-is. It completes the remaining current-build model metadata for the Published FHIR-22107 decision while preserving the already-correct authoritative AdverseEvent definition.
