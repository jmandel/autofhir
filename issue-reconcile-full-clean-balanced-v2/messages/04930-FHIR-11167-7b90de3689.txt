FHIR-11167: Audit ClinicalImpression plan removal

Issue request:
FHIR-11167 was a Published Patient Care change request for DSTU2 ClinicalImpression. It asked to remove ClinicalImpression.plan and remove scope wording that said ClinicalImpression covered actions taken during or planned as a result of the clinical assessment.

Initial application:
The change was historically applied in git commit bd9f60dbffee762fd2b3e49ee2e07e232b9685a9. That commit removed ClinicalImpression.plan from the authored spreadsheet, removed the plan entry from the ClinicalImpression example, and changed the scope paragraph to omit the planned-actions phrase. Current inactive ClinicalImpression and ClinicalAssessment structure sources have no plan or action element.

Additional context:
FHIR-7185 later reaffirmed that ClinicalImpression.plan had already been removed because the later-created plan should point back to the earlier clinical impression. FHIR-46596 then renamed ClinicalImpression to ClinicalAssessment in commit 670d3a407a962cdde0ef1136fbcdea045b124f19. Commit fad1b9cf84ef652e88947e1a13b026c62f95334e removed ClinicalAssessment from source/fhir.ini's active resource configuration and changed the Clinical Summary module to link to the PC incubator ClinicalAssessment profile instead of a core-built resource. FHIR-11168 has already been audited on the combined branch and reached the same build-scope conclusion for the adjacent action element.

AutoFHIR reconciliation:
This empty audit commit makes no source change because neither ClinicalImpression nor ClinicalAssessment is active in the current core build. Editing the remaining inactive source/clinicalimpression or source/clinicalassessment files would not correct the built specification; any future ClinicalAssessment wording cleanup belongs with the PC incubator artifact or with a deliberate core reintroduction.

Recommendation:
Keep this audit commit as-is for the current core build. If Patient Care reintroduces ClinicalAssessment into core or updates the PC incubator artifact, review the inactive care-plan narrative together with FHIR-11167 and FHIR-11168 so the assessment-versus-plan boundary remains explicit.
