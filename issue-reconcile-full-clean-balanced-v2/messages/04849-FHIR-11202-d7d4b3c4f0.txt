FHIR-11202 was Published with resolution Persuasive with Modification for the DSTU2 Flag resource. It asked that Flag.code support both machine processing and human readability by changing the short description from "Message to display to user" to wording consistent with the existing definition, resolved as "coded or textual message to display to user".

Initial application:

The current StructureDefinition source retains that wording on Flag.code and keeps the matching definition about the coded value or textual component.

Community searches found no direct FHIR-11202 Zulip or Confluence record and no conflicting later decision; a pre-issue Zulip implementers thread confirmed the definition already directed textual flag content to Flag.code.text.
