FHIR-11396: Audit benefit exclusion indicators

Issue request:
FHIR-11396 was a Published/Persuasive Financial Management change request from the DSTU2 ballot asking for a 0..1 boolean negation indicator on ExplanationOfBenefit benefits to indicate a benefit is not covered under the plan. The final resolution expanded the request to add the indicator to both EligibilityResponse and EOB.

Initial application:
The current git history did not contain a commit message explicitly naming FHIR-11396, but the relevant source was applied before reconciliation: commit d1be564fe0a5fed4f38a2dbb1b4f5fc16f106a20 added boolean excluded rows to the legacy EligibilityResponse and ExplanationOfBenefit spreadsheets. The old EligibilityResponse row later became the current CoverageEligibilityResponse insurance item exclusion element, and the EOB row became the current ExplanationOfBenefit benefitBalance exclusion element.

Additional context:
CoverageEligibilityResponse and ExplanationOfBenefit are active current-build resources in source/fhir.ini, while source/fhir.ini maps the old EligibilityResponse name to CoverageEligibilityResponse. The old eligibilityresponse spreadsheet still exists as legacy evidence, but the current build source is the active CoverageEligibilityResponse StructureDefinition. Searches of Jira, Zulip, and Confluence found no later decision or community discussion changing the requested excluded-benefit semantics.

AutoFHIR reconciliation:
No source change was made. The current active StructureDefinitions already include CoverageEligibilityResponse.insurance.item.excluded and ExplanationOfBenefit.benefitBalance.excluded as 0..1 boolean elements with definitions saying true means the class/product/service is excluded from the plan and missing/false means it is included in coverage.

Recommendation:
Keep this empty audit commit as-is. No follow-up source work is needed for FHIR-11396 unless the Financial Management work group wants to revisit the location or wording of the existing excluded elements in a new issue.
