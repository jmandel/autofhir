FHIR-19462: Audit Claim procedure dateTime already applied

Issue request:
FHIR-19462 is a Published/Persuasive FM change request asking to make Claim.procedure.date a dateTime so a claim can capture both the date and time of a procedure. The Jira text also says the element might possibly be renamed, but the final resolution records the datatype request without requiring a rename.

Initial application:
The historical source shows Claim.procedure.date changed from date to dateTime in f3cb0d5ef0dc754dc1d8866c362618e196be8050, an older Claim cleanup commit that did not mention the Jira key. A later Claim batch commit, afb5ec66f68641293bb7950b6e0eeb118fa1444a, explicitly listed 19462 among the applied Claim items and preserved the dateTime datatype while cleaning the Claim.procedure.date wording and requirements. No existing combined-branch audit commit for FHIR-19462 was found before this reconciliation.

Additional context:
Claim is an active current-build resource in source/fhir.ini. The current authoritative Claim StructureDefinition source defines Claim.procedure.date as type dateTime and says "Date and optionally time the procedure was performed." The matching ExplanationOfBenefit procedure date is also dateTime, and published STU3, R4, and R5 Claim profiles all expose Claim.procedure.date as dateTime. Direct Zulip and Confluence searches for FHIR-19462 found no discussion or minutes that change the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build source already implements the requested datatype and supporting definition text for Claim.procedure.date. Renaming the element now would be a separate compatibility-breaking design decision and is not supported by the applied Jira record or later evidence reviewed here.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-19462 unless the FM work group opens a new issue specifically requiring a current-version rename or another semantic change to Claim.procedure.date.
