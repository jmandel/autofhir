FHIR-29559: Audit Task failed status definition

Issue request:
FHIR-29559 is an Applied FHIR-core Task change request with a Persuasive with Modification resolution. It asked to reword the Task status code `failed` so the definition does not imply that failure is non-terminal or limited to a specific error reason; the approved text was "The task was attempted but was not successful.  No further activity will occur for this task."
