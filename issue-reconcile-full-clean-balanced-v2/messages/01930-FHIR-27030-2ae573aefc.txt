FHIR-27030: Audit Medication manufacturer reconciliation

Issue request:
FHIR-27030 is Published/Persuasive with Modification for FHIR-core Medication. It asked Pharmacy to address confusion around the Medication and MedicationKnowledge manufacturer element by renaming it to sponsor and updating the definition to describe the organization responsible for manufacturing/registration to market the product in a jurisdiction, including Market Authorization Holder as an example.

Initial application:
The issue was applied in commit 1683ac64141af807564d62a28932d70133142fb3, which renamed Medication.manufacturer and MedicationKnowledge.manufacturer to sponsor, updated the corresponding search parameters, and changed Medication examples from manufacturer to sponsor. That original application is no longer the final current state because later commits refactored the same area.

Additional context:
Medication is active in source/fhir.ini, and current source/fhir.ini maps the old R4 Medication.manufacturer element to Medication.marketingAuthorizationHolder. FHIR-32759 is a later Published/Persuasive Pharmacy decision, already represented on the combined branch, that changed Medication.sponsor to Medication.marketingAuthorizationHolder after Pharmacy/BR&R discussion. FHIR-35858 is a later Published/Persuasive Pharmacy decision that corrected the MAH definition because the FHIR-32759 wording still described manufacturer. MedicationKnowledge.sponsor was later removed during the MedicationKnowledge definitional-element restructuring, and MedicationKnowledge is not currently listed as an active resource in source/fhir.ini [resources]. FHIR-27027 is the originating Immunization issue but was later Resolved - No Change by Public Health and does not require changing Medication.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Medication source defines Medication.marketingAuthorizationHolder, has the matching marketingauthorizationholder search parameter, and no longer exposes Medication.manufacturer or Medication.sponsor as current elements. Restoring sponsor or manufacturer-centered wording would conflict with later Pharmacy decisions rather than complete FHIR-27030. The remaining manufacturer hits are the R4-to-R6 version-diff mapping and archived Medication examples, not current authoritative Medication elements.

Recommendation:
Keep this no-change audit commit. No core source edit is recommended for FHIR-27030; future concerns about representing a distinct physical manufacturer should be handled through the later manufacturer-extension work rather than by changing Medication.marketingAuthorizationHolder.
