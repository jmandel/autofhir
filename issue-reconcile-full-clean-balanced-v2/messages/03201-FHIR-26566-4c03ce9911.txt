FHIR-26566: Audit Ingredient.function as already applied

Issue request:
FHIR-26566 is a Published/Persuasive BR&R change request for R5 asking to add Ingredient.function to support detailed ingredient functions such as antioxidant or alkalizing agent. The Jira description requested a CodeableConcept element with 1..* cardinality and records BR&R approval on 2020-03-24.

Initial application:
The issue was explicitly applied by git commit 35630a55b9ba1df679df5765243f01a2e4162512, "Added Ingredient.function FHIR-26566", which added Ingredient.function to the then-authoritative ingredient spreadsheet as CodeableConcept with 0..* cardinality. Later source refactoring moved the resource to source/ingredient/structuredefinition-Ingredient.xml and preserved that optional repeating cardinality; later commits added the example IngredientFunction binding and short-definition cleanup.

Additional context:
Ingredient is active in the current build via source/fhir.ini, and the current source contains Ingredient.function, its example value set/code system, and a token search parameter. The Jira description's 1..* wording does not appear to be a later lost constraint because the original FHIR-26566 implementation itself used 0..*. A same-day Zulip discussion confirms the intended model: an Ingredient is already in the context of a product or other thing it is part of, and function is in that same contextual model. Later Jira FHIR-55045 is only a Submitted/unresolved THO-migration candidate for Ingredient value sets and does not change the element or cardinality.

AutoFHIR reconciliation:
This audit commit makes no source change. The current active source already carries the requested Ingredient.function element and associated terminology/search surfaces, and changing the cardinality to 1..* now would be a new conformance change rather than reconciliation of a missed application.

Recommendation:
Keep this no-change audit as-is. Revisit only if BR&R opens a new final decision to make detailed Ingredient.function mandatory or to move IngredientFunction terminology to THO; otherwise the current optional repeating element is the durable applied state of FHIR-26566.
