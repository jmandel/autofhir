FHIR-46017 was an Applied FHIR-core Patient Administration change request, resolved Persuasive, asking for ExtendedContactDetail to indicate the languages a particular contact uses with zero-to-many cardinality. The approved resolution was to make the extension from FHIR-46016 available for ExtendedContactDetail as well.

Initial application:

Additional context:
The same source file also carries the FHIR-46016 Organization and OrganizationAffiliation contexts, and later Extension Pack QA changes retained the ExtendedContactDetail context while adding a version-specific-use annotation for startFhirVersion 5.0. The Extension Pack IG includes input/definitions/* as build input. The core FHIR checkout no longer owns the standard extension StructureDefinition source; it retains only the extension OID mapping.

AutoFHIR reconciliation:

Recommendation:
