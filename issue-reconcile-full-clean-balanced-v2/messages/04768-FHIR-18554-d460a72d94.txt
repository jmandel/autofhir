FHIR-18554: Audit ValueSet.date created-or-revised wording

Issue request:
FHIR-18554 was a Published FHIR-core ValueSet change request from the Vocabulary work group, resolved Persuasive with Modification for STU3. It asked to replace the ValueSet.date definition sentence "The date (and optionally time) when the value set was published." with "The date (and optionally time) when the value set was created or revised."

Initial application:
The Jira comment identifies git 4907f9bcb0b710cb2837a93a20c4b23210a37249. That terminology ballot documentation batch changed source/valueset/valueset-spreadsheet.xml so the ValueSet.date definition used "created or revised" rather than the old "published" wording. The source was later reworked into source/valueset/structuredefinition-ValueSet.xml.

Additional context:
FHIR-14672 later revisited the same ValueSet.date ambiguity and refined the already-applied FHIR-18554 wording to say the value set metadata or content logical definition (.compose) was created or revised, while also clarifying that the date differs from meta.lastUpdated. The active current source uses that later refined wording. A Zulip terminology topic noted the FHIR-18554 clarification question, and Confluence refs did not show a separate FHIR-18554 decision record that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the active ValueSet resource is in build scope and source/valueset/structuredefinition-ValueSet.xml already conveys that ValueSet.date is a created-or-revised date, not merely a publication date, with the later FHIR-14672 refinement preserved.

Recommendation:
Keep this audit commit as-is. No follow-up core FHIR edit is recommended for FHIR-18554; future work should avoid reverting the later FHIR-14672 precision.
