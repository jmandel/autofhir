FHIR-13123: Audit ICD-10-GM OID correction

Issue request:
FHIR-13123 was a Published/Persuasive Vocabulary change request raised against DSTU2 terminology systems content. It reported that the old ICD page and Code Systems table carried incorrect or misaligned ICD-10-GM and ICD-10-NL OIDs, noted that 1.2.276.0.76.5.409 was not a stable all-years ICD-10-GM OID, and asked the ICD-10-GM documentation to reflect German year-specific terminology/OID practice.

Initial application:
The Jira comment cites svn revision 1755, and the relevant git import is d75d919fc1, whose subject explicitly says "#13123 - fix for ICD-10 DE". That commit changed the old source/icd.html Germany row from the copied Netherlands OID to a link to the HL7 Germany code-system page and changed the Netherlands row away from the miscopied German OID; the follow-up d9bf7e4119 removed the explicit hl7.org/fhir/sid/icd-10-de URI from the core ICD variants row.

Additional context:
Later same-family decisions refined the ICD variant handling: FHIR-13723 added the German affiliate canonical URL to the old ICD page, FHIR-17771 recorded that the ICD-10-NL and ICD-10-DE OIDs had been reversed and were already fixed, FHIR-35933 intentionally removed the old FHIR-core source/icd.html external-code-system page and moved that detailed guidance to THO, and FHIR-41305 later corrected the current ICD URI row in source/terminologies-systems.html. Those related issues are already represented on the combined branch, so this audit does not republish them.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current build-scoped core source no longer publishes the old national ICD-10 variant OID table: source/terminologies-systems.html now lists only the generic ICD-9-CM and ICD-10 system identifiers, warns that external terminology content is convenience/non-authoritative, and points readers to HL7 Terminology for authoritative external code-system information; source/sid-icd-10.html describes only the international ICD-10 system. Searches found no current core source occurrence of the old icd-10-de/icd-10-nl rows or the disputed OIDs.

Recommendation:
Keep this empty audit commit as-is. The FHIR-core side of FHIR-13123 was applied historically and then superseded by the intentional THO migration; any future national ICD-10-GM URI/OID maintenance belongs in THO or German-affiliate terminology governance, not by restoring the retired core ICD variants table.
