FHIR-18452: Audit JSON/XML comparison note

Issue request:
FHIR-18452 was a Published FHIR-core JSON page change request, resolved Not Persuasive with Modification for R5. The ballot comment said XML examples in the JSON section made XML look primary, and the accepted action was to add a note explaining that XML examples are present for easy syntax comparison, not because XML has primacy or because JSON is expected to be derived from XML.

Initial application:
The issue was applied in commit a7026edb074d5100e871d93a03aaa02231cb1218, which removed the old in-page JSON/XML comparison section from source/json.html, added a concise note that XML examples are for comparison, and moved the full comparison guidance to the shared formats page. No prior Issue-Reconcile-Key commit for FHIR-18452 was present on the combined branch before this audit.

Additional context:
FHIR-I minutes from 2021-10-04 record the reopen motion and the 14-0-4 Not Persuasive with Modification resolution. Later source history moved the note below the new additional-resources subsection, but it remains before the XML comparison examples in the repeating and primitive sections. The active hierarchy includes json.html, and the shared resource-formats comparison now states that XML follows JSON closely, which reinforces that XML is not primary.

AutoFHIR reconciliation:
This is an empty audit commit. The current source already communicates the intended rule: XML snippets on the JSON page are comparison aids, the JSON examples are not dependent on XML primacy, and the detailed comparison lives on resource-formats.html.
