FHIR-45453: Audit SupplyRequest intent binding

Issue request:
Applied/Persuasive OO issue FHIR-45453 asked that SupplyRequest follow the Request.intent pattern. The final motion replaced the pre-applied SupplyRequest-specific intent value set/code system with the common RequestIntent value set used for ServiceRequest.intent and the Request pattern, including the directive code.

Initial application:
The issue was partially pre-applied in commit c44e1fb5a83d0e2f4ceed6fa94f5228e1a8b98e2, which added SupplyRequest.intent but bound it to a bespoke supplyrequest-intent value set. Commit 15f50a71de0796cd0db5d1c732b05f221ed7d82c added the FHIR-20604 immutability wording. Commit 92585cc68b2772bc849ff3b123dff45c7d9d4339 then implemented the final FHIR-45453 decision by deleting the bespoke supplyrequest-intent CodeSystem/ValueSet and rebinding SupplyRequest.intent to http://hl7.org/fhir/ValueSet/request-intent; commit 3665eb2b3a881f1f794e98b5838116dd6632265f updated the short display to include directive.

Additional context:
The current core checkout still contains the historical SupplyRequest source with SupplyRequest.intent as 1..1, required, and bound to request-intent; the request-intent CodeSystem includes directive. However, commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed SupplyRequest and other OO resources from active source/fhir.ini build registration. The current active SupplyRequest artifact is in the OO incubator continuous build, where StructureDefinition-SupplyRequest.json also shows SupplyRequest.intent bound to request-intent with directive in the short code list. OO Confluence minutes for 2024-05-07 record the FHIR-45453 administrative vote/reopen context and no Zulip evidence was found that contradicts the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change in FHIR core. The requested semantic change is already present in the remaining inactive core SupplyRequest source, and the resource is no longer an active core build artifact; the read-only OO incubator artifact also reflects the correct binding.

Recommendation:
Keep this audit commit as-is for FHIR core. If SupplyRequest intent binding changes are needed in the future, they should be handled in HL7/oo-incubator rather than by editing inactive core SupplyRequest source.
