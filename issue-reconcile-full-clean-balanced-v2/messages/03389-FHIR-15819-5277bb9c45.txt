FHIR-15819: Audit MedicationDispense category alignment

Issue request:
FHIR-15819 was a Published/Persuasive Pharmacy change request for STU3 asking that MedicationDispense.category be aligned with MedicationRequest.category after MedicationRequest.category had been relaxed to an example binding and broadened beyond a consumed/administered-location-only description.

Initial application:
The issue was applied in SVN build@13840, imported as git commit 3ca8aaddb2c50c08732cad49f8ab68f086ba8c83, which updated MedicationDispense.category source wording from the old location-only definition to broader category wording and added explanatory comment text. The current generated StructureDefinition source retains the important result: MedicationDispense.category has an example binding to the medicationdispense-category ValueSet and describes type/category use rather than a preferred location-only binding.

Additional context:
MedicationDispense and MedicationRequest are active resources in source/fhir.ini. Later Pharmacy decisions refined the same category family: FHIR-25555 broadened examples and removed discharge from the exemplar value sets, FHIR-51726 moved MedicationRequest category terminology back into core, and the already-published combined-branch FHIR-25555 reconciliation removed the remaining discharge concepts from active Medication category CodeSystems. FHIR-20420 also explicitly treated the preferred/example binding changes as no-change for diff reporting. FHIR-53306 is only Triaged and records future terminology cleanup context, not a final source-edit instruction for this seed.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current combined-branch source already satisfies FHIR-15819 at the semantic level: MedicationDispense.category is example-bound and no longer presents the element as only where medication is expected to be consumed or administered. Exact wording no longer matches MedicationRequest.category because later category terminology work changed the request and dispense wording independently, and forcing exact textual identity now would over-apply the 2018 issue.

Recommendation:
Keep this audit commit as-is. Do not make a FHIR-15819 source edit unless the Pharmacy work group opens a new final issue requiring MedicationDispense.category to use the exact current MedicationRequest.category prose; future terminology consolidation should proceed through the later Pharmacy/THO issues rather than this STU3 alignment tracker.
