FHIR-39534: Audit external THO pat-mt display update

Issue request:
FHIR-39534 was Published/Persuasive for Patient Administration after the R4B tracker asked how pat-dec differs from pat-mt in AppointmentCancellationReason. The accepted clarification was to update the display for code "pat-mt" to "Patient: No longer covered by insurance or other payers".

Initial application:
No current core source change was applied for this tracker because the authoritative CodeSystem had already moved out of core before the issue. Historical core source did contain the appointment-cancellation-reason CodeSystem with pat-mt displayed as "Patient: Member Terminated", but commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed UTG CodeSystem content from the core build in 2020. The actual terminology application is represented by UP-400, which was implemented in UTG/THO.

Additional context:
FHIR-39535 is the paired tracker in the same UP-400 terminology proposal for pat-mv. The active core Appointment resource remains in build scope and binds Appointment.cancellationReason to the core value set, but the value set only includes the external THO CodeSystem http://terminology.hl7.org/CodeSystem/appointment-cancellation-reason. Current THO publishes CodeSystem version 2.1.1 with pat-mt displayed as "Patient: No longer covered by insurance or other payers". PA WGM minutes record that the FHIR-39534 clarification would go to THO, and no conflicting Zulip discussion was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested display correction belongs to the external THO/UTG terminology source, and the current FHIR core source correctly references that external CodeSystem rather than carrying a duplicate local CodeSystem definition.

Recommendation:
Keep this external-repo audit commit as-is. No FHIR core follow-up is needed for FHIR-39534 unless the core build stops consuming the updated THO terminology; future display maintenance should be handled through THO/UTG.
