FHIR-26894: Audit MedicationDispense.partOf application

Issue request:
FHIR-26894 was a Published/Persuasive R4 Pharmacy change request asking for MedicationDispense.partOf to be better explained, questioning why the element was 0..* and limited to Procedure. The approved resolution kept cardinality 0..*, added MedicationAdministration as an allowed target, and explained that both a Procedure and a MedicationAdministration could trigger the dispense, while multiple procedures or multiple administrations were not expected.

Initial application:
The request was applied in commit 603de50396973db754fec17786a66ce29799296c, which changed the then-authoritative medicationdispense-spreadsheet.xml from Reference(Procedure) to Reference(Procedure | MedicationAdministration), updated the definition to mention medication administration, and added the cardinality rationale as element comment text. The January 2021 source migration commit 33b409a4b6d544598262f2f074ebb4b6dc466157 carried the same meaning into source/medicationdispense/structuredefinition-MedicationDispense.xml.

Additional context:
MedicationDispense is an active resource in source/fhir.ini. Current source/medicationdispense/structuredefinition-MedicationDispense.xml has MedicationDispense.partOf as 0..* Reference(Procedure, MedicationAdministration) with the requested definition and comment, and the active Event-pattern mapping exception file records the same intentional divergence. A May 2020 Zulip thread after the vote discussed a proposed dispense-session grouping use case and concluded Encounter/context was more appropriate, which does not conflict with the Jira resolution. Later Jira issues FHIR-54374 and FHIR-55418 raise R6 questions about this element, but they are Triaged/Submitted and unresolved, so they are background only for this applied R5 issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already reflects the published decision, and changing wording now would either be merely editorial or would anticipate unresolved R6 work-group decisions.

Recommendation:
Keep this no-change audit commit as-is for FHIR-26894. Revisit only if Pharmacy resolves FHIR-54374 or FHIR-55418 with a new R6 change to remove, retarget, or further rationalize MedicationDispense.partOf.
