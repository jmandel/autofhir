FHIR-8050: Audit NCPDP Medication mappings

Issue request:
FHIR-8050 was a Published/Persuasive Pharmacy change request from the DSTU1 era asking to add NCPDP mappings to Medication resources. The Jira record also documents the practical application: mappings for Medication and MedicationOrder were added on July 22, 2016, and the tracker was later closed because no additional mappings had been provided.

Initial application:
The explicit application is git commit e6bfd3ac62 ([#8050] NCPDP mapping for Medication and MedicationOrder), which added the NCPDP SCRIPT 10.6 mapping space and mappings in the Medication and MedicationOrder spreadsheet sources. Later source refactors moved those applied mappings into the current StructureDefinition XML, and the old MedicationOrder resource is represented in the current build as MedicationRequest.

Additional context:
The current build-scope authority lists MedicationAdministration, MedicationDispense, MedicationRequest, MedicationStatement, and Medication as active resources, and records MedicationOrder as renamed to MedicationRequest. Current active source retains SCRIPT 10.6 mappings for Medication and MedicationRequest. MedicationAdministration, MedicationDispense, and MedicationStatement still have no SCRIPT 10.6 mapping content, but the Jira closure explicitly says no additional mappings were provided, so inventing empty or new mappings for those resources would exceed the applied work-group decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source preserves the actually applied NCPDP mappings for Medication and MedicationOrder/MedicationRequest, and there is no source-backed or community-backed evidence of additional NCPDP mappings that should now be added to other active Medication-domain resources.

Recommendation:
Keep this audit commit as-is. If Pharmacy or NCPDP supplies additional mappings for MedicationAdministration, MedicationDispense, MedicationStatement, or other resources, handle that as new work rather than as a missing application of FHIR-8050.
