FHIR-12645: Audit CarePlan activity Task replacement

Issue request:
FHIR-12645 was a Published/Persuasive Patient Care change request for DSTU2. It asked to change CarePlan.activity.reference from ProcessRequest to Task because ProcessRequest was being reduced in scope and Task was the better target for CarePlan activities.

Initial application:
No git commit explicitly mentions FHIR-12645, but the 2017 FMG Zulip thread records that GF#12645 had been misapplied by removing ProcedureRequest instead of ProcessRequest. Git commit c0df469417 corrected the old CarePlan spreadsheet source by removing ProcessRequest from CarePlan.activity.reference while keeping Task and restoring ProcedureRequest. A follow-up workflow Zulip thread confirms that the current build included Task in the CarePlan activity reference types immediately after that correction.

Additional context:
CarePlan remains an active resource in source/fhir.ini, Task is active, and ProcessRequest is commented out with the deleted-resource note "ProcessRequest=approved use Task". The current authoritative CarePlan source now models the successor element as CarePlan.activity.plannedActivityReference, and its allowed targets include Task but not ProcessRequest. A direct source search found no remaining ProcessRequest reference under source/careplan.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope CarePlan definition already reflects the requested replacement, and editing would only restate or disturb an already-correct target list.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR follow-up is needed for FHIR-12645 unless a future Patient Care decision reopens which request resources CarePlan activity references should allow.
