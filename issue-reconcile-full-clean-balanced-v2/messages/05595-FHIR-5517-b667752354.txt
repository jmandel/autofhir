FHIR-5517: Audit pharmacy dose-rate guidance

Issue request:
FHIR-5517 was a Published Pharmacy change request, resolved Persuasive, asking to clarify the relationship between quantity and rate in the MedicationAdministration, MedicationDispense, MedicationPrescription, and MedicationStatement pharmacy resources, including what should happen when rate is not continuous.

Initial application:
No commit in current git history explicitly names FHIR-5517. The issue was created on 2015-01-19 and appears to have been applied in the next-day pharmacy ballot update commit abce09d8c1, which added the relevant dose/rate spreadsheet guidance: MedicationAdministration.dosage.quantity could represent the total amount for a non-instantaneous administration, MedicationAdministration.dosage.rate changes should be captured as distinct dosage repetitions rather than an average, and MedicationDispense/MedicationPrescription dosageInstruction comments said changing dose/rate courses required distinct dosage instructions. FHIR-5516 is an accidental duplicate resolved Not Persuasive/No Change.

Additional context:
The current build scope includes MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement in source/fhir.ini; MedicationPrescription has since become MedicationRequest. Later source refactors moved most prescription/dispense/statement dosing guidance into reusable Dosage and then DosageDetails. Already-published combined-branch reconciliations for FHIR-8502 and FHIR-7737 aligned the same rate-change family with the current R6 DosageDetails model, including MedicationAdministration distinct-rate events and MedicationRequest titration guidance.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Active source already conveys the FHIR-5517 clarification: MedicationAdministration.dosage.dose explains non-instantaneous administrations, MedicationAdministration.dosage.rate[x] explains distinct events for rate changes and not using average rate, Dosage.timing and Dosage.doseAndRate clarify dose/rate/duration relationships, Dosage.doseAndRate.rate[x] points changing rates to the containing dosage structure or changed request, and MedicationDispense/MedicationRequest/MedicationStatement use DosageDetails for structured dosage courses.

Recommendation:
Keep this empty audit commit. The current specification already preserves the accepted clarification in the active resource/datatype sources, and adding more prose for FHIR-5517 would duplicate existing Dosage/DosageDetails guidance. Revisit only if the DosageDetails model is changed again or if Pharmacy requests a new cross-resource editorial consolidation.
