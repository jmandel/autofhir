FHIR-19513: Audit ChargeItem move outside core

Issue request:
FHIR-19513 is a Published, Persuasive with Modification PA change request for R5 ChargeItem. It asked to rename ChargeItem.context to ChargeItem.encounter as 0..1 Encounter with the approved ChargeItem-specific definition and comment, include ChargeItem among the contexts for the workflow-episodeOfCare standard extension, update the EpisodeOfCare/context search parameter to read that extension, update Event-pattern mappings/examples, and not add reported[x].

Initial application:
The issue was applied in core by commits 8bce67534b and 68ccf7f675, merged through a2db0e8607. Those commits changed source/chargeitem/structuredefinition-ChargeItem.xml from ChargeItem.context to ChargeItem.encounter, updated the ChargeItem example, added/adjusted ChargeItem search parameters for context/encounter, and added ChargeItem to the workflow episodeOfCare extension context list.

Additional context:
The current core build no longer contains ChargeItem. Commit 71567db3ee removed ChargeItem and ChargeItemDefinition from source/fhir.ini and deleted source/chargeitem/*; source/modules-fragment.html now links ChargeItem to the HL7 admin-incubator IG instead. The FHIR Extension Pack checkout carries workflow-episodeOfCare with ChargeItem still listed as a context. The current HL7/admin-incubator ChargeItem source has ChargeItem.encounter and an encounter search parameter, while any remaining decision about carrying a context/EpisodeOfCare compatibility search parameter is outside the FHIR core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change and records an external-repo decision. Editing core would reintroduce or alter removed/out-of-build ChargeItem source rather than fixing the current FHIR build.

Recommendation:
Keep this audit commit as-is for core. If PA wants the historical context/EpisodeOfCare search parameter preserved for the incubator ChargeItem artifact, handle that follow-up in HL7/admin-incubator or the owning external package, not in this core repository.
