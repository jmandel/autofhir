FHIR-7504: Audit Condition history guidance

Issue request:
FHIR-7504 is a Published Patient Care change request, resolved Persuasive with Modification, asking how "history of" should be captured and directing that a usage note on Condition.code say the code may include concepts such as "history of X" and "good health" when useful or appropriate.

Initial application:
The request was applied in git commit b8fddd3c06 (#7504, #7618, #8360 - added usage notes), which added the requested "history of X" and "good health" sentence to source/condition/condition-notes.xml. The Condition notes were later restored after a source rework/deletion in commit 005f3df50a, preserving the same requested guidance in the current source.

Additional context:
Condition is active in source/fhir.ini, so source/condition/condition-notes.xml is in the current resource build scope. Later Condition-code decisions extended and constrained adjacent guidance: FHIR-8749 added "no known problems" text, FHIR-11077 added the separate "Assertions of Condition Absence" section, and FHIR-41624 left latent/history concerns to Condition.code or more specific coding/text rather than changing clinicalStatus. Zulip discussions found during reconciliation quote and interpret the current Condition.code guidance but do not identify a later decision that removes or reverses the FHIR-7504 rule.

AutoFHIR reconciliation:
This is an empty no-change audit commit. The current Condition notes already contain the requested usage note: "The Condition.code may also include such concepts as \"history of X\" and \"good health\", where it is useful or appropriate to make such assertions." Adding another element comment or duplicate paragraph would not change implementer understanding and would risk maintenance drift.

Recommendation:
Keep this audit as-is. No source follow-up is needed for FHIR-7504 unless Patient Care chooses to revisit the broader Condition/Observation boundary for medical-history questionnaire answers; that is a later policy question, not an unapplied FHIR-7504 source fix.
