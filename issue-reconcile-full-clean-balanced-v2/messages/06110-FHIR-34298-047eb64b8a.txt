FHIR-34298: Audit BiologicallyDerivedProduct usage text

Issue request:
FHIR-34298 was Published/Persuasive with Modification for R5 and asked to update the BiologicallyDerivedProduct Scope and Usage plus Boundaries and Relationships text using the resource proposal language. The approved modification was to make those documentation updates but not apply the three element-definition changes at the bottom of the tracker.

Initial application:
The requested narrative was applied before this reconciliation through HL7/fhir#1546, merged as 75a4d5c7de after commit 4ea992dd37 changed source/biologicallyderivedproduct/biologicallyderivedproduct-introduction.xml. That commit replaced the older brief scope and relationship list with the biological-entity clinical-application scope, examples, and Medication/NutritionProduct/Device/Specimen/Substance boundary bullets.

Additional context:
The BiologicallyDerivedProduct resource is active in source/fhir.ini, belongs to OO, and is normative, so its introduction XML is current build input. Later final BDP boundary decisions intentionally refined the same bullets: FHIR-36797 changed the Medication wording to "blood group specific", FHIR-36798 simplified the Specimen decision, FHIR-37979 refined the Specimen and Substance text, and FHIR-46604/FHIR-51842 refined the NutritionProduct boundary. Those later changes explain why the current source is not a byte-for-byte copy of the 2021 tracker text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current built source already includes the approved FHIR-34298 scope/examples and boundary categories, with later applied refinements that preserve or improve the intended rule; applying the original wording again would regress those later decisions.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-34298 unless a future work group decision changes the BiologicallyDerivedProduct boundaries again.
