FHIR-25514: Audit AllergyIntolerance clinicalStatus invariant removal

Issue request:
FHIR-25514 was a Published/Persuasive Patient Care change request for R5. It said the AllergyIntolerance ait-1 invariant required clinicalStatus whenever verificationStatus was not entered-in-error, which was inappropriate for negated/no-known-allergy records, and requested removing the invariant while adding guidance that clinicalStatus should be present only when verificationStatus is not entered-in-error and AllergyIntolerance.code is not negated.

Initial application:
The Jira-linked implementation commit a793a6b7db286814f69c9de8908c1f77bbfec526 removed clinicalStatus and verificationStatus from no-known-allergy examples, added the requested clinicalStatus comment to the AllergyIntolerance spreadsheet, recorded GF#25514 in the committee notes, and disabled the original clinicalStatus-required invariant row. The later source refactor 33b409a4b6d544598262f2f074ebb4b6dc466157 carried that application into the current StructureDefinition source.

Additional context:
AllergyIntolerance is an active current-build resource in source/fhir.ini. The current source/allergyintolerance/structuredefinition-AllergyIntolerance.xml has the requested clinicalStatus comment and no remaining ait-1 constraint or condition. The no-known-allergy examples remain without clinicalStatus. Later Published issue FHIR-28458 explicitly removed the remaining AllergyIntolerance invariant around refuted/entered-in-error status, so reintroducing any AllergyIntolerance clinicalStatus invariant would conflict with the later issue family. FHIR-26410 was implemented by the same a793a6b commit for related no-known-allergy guidance and is already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already implements the FHIR-25514 resolution and later related decisions do not require a seed-specific edit.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-25514 unless Patient Care makes a new decision to express negated AllergyIntolerance clinicalStatus expectations as a computable rule.
