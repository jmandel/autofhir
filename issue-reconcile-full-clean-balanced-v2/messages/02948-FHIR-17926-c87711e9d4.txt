FHIR-17926: Audit Claim facility search description

Issue request:
FHIR-17926 was Published/Persuasive with Modification for the FHIR-core Claim resource. The issue asked that the Claim facility search description change from a facility-responsibility phrasing to a description about where goods and services were provided; the recorded resolution says the description should read "Facilty providing goods and services".

Initial application:
The issue was applied in commit afb5ec66f68641293bb7950b6e0eeb118fa1444a as part of a larger Claim/ClaimResponse spreadsheet update. That commit changed the historical Claim facility search parameter description from "Facility responsible for the goods and services" to "Facility where the products or services were/are to be provided" and later source migration preserved that meaning in the current XML search-parameter bundle.

Additional context:
Claim is an active current-build resource in source/fhir.ini, and the authoritative current Claim search parameter source has Claim-facility with description "Facility where the products or services have been or will be provided". This wording is not an exact copy of the brief Jira resolution text, but it carries the same correction while also fitting current Claim semantics for claims, preauthorizations, and predeterminations. Searches found no Zulip or Confluence record that changes the Jira/source conclusion.

AutoFHIR reconciliation:
No source change was made. The current Claim-facility search description already conveys that the search parameter identifies the facility where the goods/products or services were or will be provided, so further editing would be redundant and could narrow the current prospective-use wording.

Recommendation:
Keep this no-change audit commit. Revisit only if Financial Management wants a broader editorial pass over Claim element definitions, because FHIR-17926 itself is already reflected in the current search parameter source.
