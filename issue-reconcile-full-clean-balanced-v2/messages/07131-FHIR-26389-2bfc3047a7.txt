FHIR-26389: Audit integer64 FHIRPath mapping

Issue request:
FHIR-26389 is a Published/Persuasive FHIR-core R5 issue asking that the FHIR primitive-to-FHIRPath mapping be updated after the addition of the FHIR integer64 primitive, including use of the FHIRPath System.Long type for the 64-bit integer mapping. Its resolution says to adjust the FHIRPath mapping table and use System.Long, while leaving FHIRPath and CQL specification work to their own trackers.

Initial application:
The issue was applied in source by commit a1a727070c2cd8bfed2507ea7ae0ad84f3e88a73, "FHIR-26389 Include integer64 in FHIRPath mapping", which added a FHIR.integer64 -> System.Long row to source/fhirpath.html. No earlier AutoFHIR reconciliation commit with Issue-Reconcile-Key: FHIR-26389 was present on the combined branch.

Additional context:
FHIR-26542 is the FHIRPath-side Applied/Persuasive decision that established a 64-bit System.Long type, and FHIR-28615 was later closed no-change because it duplicated that FHIRPath work. FHIR-28616 is a later Published FHIR-core issue asking for the same mapping-table coverage. FHIR-46522 later corrected the current R6 terminology surface by adding System.Long to the FHIRPath types CodeSystem; an existing combined-branch audit commit already represents FHIR-46522. The current FHIRPath page is in build scope through source/hierarchy.xml.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/fhirpath.html mapping table already maps FHIR.integer64 to System.Long, and current source/terminologies/codesystem-fhirpath-types.xml includes http://hl7.org/fhirpath/System.Long for the related FHIRPath type value set surface. Adding another source hunk would duplicate existing, build-scoped source behavior.

Recommendation:
Keep this no-change audit commit. The FHIR core source now satisfies FHIR-26389; future changes to the independent FHIRPath specification or to generated primitive profile output should remain with their own trackers rather than changing this already-correct mapping table.
