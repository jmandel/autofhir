FHIR-36131: Audit EvidenceVariable eligibility criteria changes

Issue request:
FHIR-36131 was Published/Persuasive with Modification for R5 and asked to change EvidenceVariable to support eligibility criteria. The accepted resolution was to proceed with Option 2 for complex characteristics and remove EvidenceVariable.characteristicCombination.

Initial application:
The issue was applied in commit 257b27a14fbae5c1bd725d3c46dfbbfcf5ed36df, which changed EvidenceVariable structure and examples, added the canonical metadata elements, reworked EvidenceVariable.characteristic, removed the top-level characteristicCombination element, and introduced the type/value and nested-combination characteristic model.

Additional context:
Current source no longer has the R5 EvidenceVariable.characteristic model because later Applied R6 issue FHIR-42886 intentionally removed EvidenceVariable.characteristic and replaced it with EvidenceVariable.definition as a CodeableReference to Group. FHIR-41583 separately expanded Group so it can carry definitional inclusion/exclusion criteria, combinationMethod/combinationThreshold, characteristic values, offsets, timing, and related criteria details. FHIR-37338 later confirmed that a remaining characteristic-combination request was no longer needed because Group changes satisfy the use case.

AutoFHIR reconciliation:
This audit commit makes no source change. Reintroducing the FHIR-36131 R5 characteristic elements, characteristicCombination machinery, or extra local eligibility-criteria prose into EvidenceVariable would conflict with the later final decisions that moved the current model to Group and left EvidenceVariable.definition as the link to that model.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-36131 unless the work group decides to revisit the later R6 EvidenceVariable/Group modeling decisions.
