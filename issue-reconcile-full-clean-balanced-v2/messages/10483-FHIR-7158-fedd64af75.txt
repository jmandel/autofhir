FHIR-7158: Audit Observation.specimen wording

Issue request:
FHIR-7158 was a Published FHIR-core Observation change request from OO, resolved Persuasive for DSTU1, asking to change the Observation.specimen comment from saying Observation resources "are often" used in contexts that track the specimen explicitly, such as Diagnostic Report, to saying they "may be" used in those contexts.

Initial application:
The issue was applied in the historical source. Commit ff6b620add (#7156,7158 edits to element descriptions and notes) changed source/observation/observation-spreadsheet.xml from "observation resources are often used in contexts that track the specimen explicitly" to "observation resources may be used in contexts that track the specimen explicitly" and added committee note 7158. The 2021 source rework moved that applied text and committee note into source/observation/structuredefinition-Observation.xml.

Additional context:
source/fhir.ini lists observation as an active resource, so source/observation/structuredefinition-Observation.xml is the current build-scope source for Observation.specimen. A later Applied/Persuasive with Modification OO issue, FHIR-50127, intentionally replaced the older specimen comment with current guidance that Observation.specimen SHOULD be used when an observation is performed on a specimen and that the specimen type SHOULD be consistent with anything implied by Observation.code. FHIR-50127 is already represented on the combined branch, so this reconciliation does not publish a duplicate FHIR-50127 decision. Direct Zulip and Confluence searches for FHIR-7158 found no conflicting community record.

AutoFHIR reconciliation:
No source files were changed. The exact 2015 "are often" wording is absent from the current source, the historical "may be" application is preserved in git history and committee notes, and the current source's different wording is explained by the later FHIR-50127 decision rather than by a missed FHIR-7158 application.

Recommendation:
Keep this audit commit as-is. No further core FHIR source work is recommended for FHIR-7158; future changes to Observation.specimen guidance should be handled under later OO decisions such as FHIR-50127 or new work-group trackers.
