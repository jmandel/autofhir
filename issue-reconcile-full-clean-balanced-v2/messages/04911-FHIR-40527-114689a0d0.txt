FHIR-40527 was a Published/Persuasive with Modification R5 OO issue asking to address QA findings for BiologicallyDerivedProductDispense by adding status, patient, and identifier search parameters, changing usageInstruction to string, and changing subject to patient.

Initial application:
The issue was initially applied before R5 publication. Commit 7ca454a878, merged by HL7/fhir#2758 as 5ff9d7dca1, renamed the resource element/search parameter from subject to patient and added the requested status and identifier search parameters. A follow-on R5 QA commit, 902ba6f126, changed usageInstruction from CodeableConcept to string.

Additional context:
A later final OO decision, FHIR-41413, changed BiologicallyDerivedProductDispense.patient back to subject with Reference(Patient | Group), added a subject search parameter, and retained the patient search parameter as subject.where(resolve() is Patient). The current core source also no longer builds BiologicallyDerivedProductDispense: source/fhir.ini has no active biologicallyderivedproductdispense resource entry, and commit 3b38b80cf2 removed the OO resources from active core lists while pointing module pages to the OO Incubator IG.

This empty audit commit makes no core source change. Recommendation:
Keep this audit commit as-is. Do not re-apply the obsolete subject-to-patient rename in core; any future BDPDispense corrections should be made in the OO Incubator IG if that external source diverges from current OO decisions.
