FHIR-23712: Audit Provenance activity type expansion

Issue request:
FHIR-23712 was Published with resolution Persuasive with Modification. It asked to broaden http://hl7.org/fhir/ValueSet/provenance-activity-type by replacing a limited representative set with object-lifecycle events, all DocumentCompletion, all DataOperation, an ObligationPolicy/ActCode subset, all ActStatus, and all FHIR event-status codes.

Initial application:
The request was applied before this reconciliation by git commit 4b5110aec85b16ae627e96a9bbfa7bf910c1b796, which created source/terminologies/valueset-provenance-activity-type.xml with inline FHIR-23712 comments and the broad include list requested by the Jira resolution. That commit also touched Provenance-related terminology and binding sources for the R5 build.

Additional context:
Later final Security WG issue FHIR-32517 reconsidered the same ProvenanceActivityType value set and found the broad grab-bag unsuitable for extensible binding because statuses are not events, codes overlap, and the set is too large and unstable. Its Published resolution changed Provenance.activity to an example binding and reduced ProvenanceActivityType to a small ISO 21089 lifecycle sample with narrative pointing implementers to other possible code systems. Git commit cd1c06923912f70a88c90d186ff3283b40e0403b applied that later decision, and subsequent Applied issues FHIR-55798 and FHIR-55797 refined the current example value set description and added destroy without restoring the FHIR-23712 broad includes. source/fhir.ini actively lists Provenance as a current resource, source/provenance/structuredefinition-Provenance.xml now binds Provenance.activity with strength example, and source/terminologies/valueset-provenance-activity-type.xml now describes an example value set of representative ISO 21089 lifecycle activity codes.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the FHIR-23712 includes would undo the later Published FHIR-32517 decision and conflict with the current example-bound sample design. The current source is correct when the original issue is read together with its later same-artifact decisions.

Recommendation:
Keep this audit commit as-is. Do not re-expand ProvenanceActivityType for FHIR-23712 unless Security WG explicitly reverses FHIR-32517 or creates a new value set for a broader Provenance activity vocabulary.
