FHIR-11234: Audit genomics interaction examples

Issue request:
FHIR-11234 was a Published/Persuasive DSTU2 Clinical Genomics request asking for full XML/JSON example sets showing how genomic resources interact, beyond the then-current figure. The resolution said to add PGx examples from FHIR-11013 and TPMT gene-mutation examples covering Observation-genetics and Sequence.

Initial application:
The issue was initially applied by commit b2b49e7e2bb0572d2de4ba7516e2c44df48751b2, which explicitly resolved #11234 along with related Clinical Genomics example trackers. That commit added PGx DiagnosticReport/DiagnosticRequest, Observation, and Sequence examples, TPMT Observation/Sequence examples, genomics images, and links from source/genomics.html.

Additional context:
The original DSTU2/R3-era Observation Genetics, DiagnosticReport Genetics, ServiceRequest/DiagnosticRequest, and Sequence/MolecularSequence example family is no longer the current core direction. FHIR-19440 and commit a2ab9957e885609f6ca43fa4896882177568d204 marked the old CG profiles/examples as being refactored toward the Genomics Reporting IG. Commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435 then removed the outdated clinical genomics artifacts, including the PGx and TPMT examples that originally satisfied this issue. FHIR-24863 later records that missing deprecation labels were no longer needed because the material was already fixed in R4/R5. Current source/fhir.ini keeps MolecularDefinition active and comments out MolecularSequence; current source/genomics.html points readers to the Genomics Reporting IG, current MolecularDefinition/molecular data-type work, and genomics use cases outside the retired core example family. Active MolecularDefinition examples now cover sequence, allele, haplotype, genotype, variation, and CYP2C19/HLA relationship patterns.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing the old PGx/TPMT Observation-genetics-to-Sequence examples into core would restore retired artifacts that later work deliberately deprecated and removed. The seed was applied historically, and the current build is correct for the present specification because it directs implementers to the maintained genomics artifacts and active MolecularDefinition examples rather than the obsolete DSTU2 example set.

Recommendation:
Keep this no-change audit as-is. If Clinical Genomics wants additional current examples of resource interaction, that work should target the Genomics Reporting IG or current MolecularDefinition/GenomicStudy-family artifacts rather than restoring retired core Observation-genetics, DiagnosticReport-genetics, or Sequence examples.
