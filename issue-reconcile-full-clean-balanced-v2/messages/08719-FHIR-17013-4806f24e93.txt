FHIR-17013: Audit BackboneElement modifierExtension wording

Issue request:
FHIR-17013 was a Published/Persuasive FHIR-core change request for the BackboneElement page in STU3. It asked to change the BackboneElement.modifierExtension short description from "Extensions that cannot be ignored" to "Extensions that cannot be ignored if unrecognized", clarifying that recognized modifier extensions may be ignored when their meaning is known and predetermined not to affect relevant processing.

Initial application:
The issue was applied by Jira-referenced svn revision 14307, now git commit 0d9b4892f4, which changed source/datatypes/backboneelement.xml to the requested "if unrecognized" wording. No broader source application was found for unrelated modifierExtension occurrences, consistent with the Jira related page pointing to BackboneElement.

Additional context:
Later Published/Persuasive issue FHIR-18039 directly revisited the FHIR-17013 wording and resolved to use "Extensions that cannot be ignored even if unrecognized" instead. Jira-referenced commit f646f1c443 applied that later wording, and the current active BackboneElement and BackboneType datatype sources both carry it. source/fhir.ini lists BackboneElement and BackboneType as active infrastructure types and normative artifacts. FHIR-18039 is already represented on the combined branch by audit commit a73f49d1f457374eb7f40b475e346d382e9ee632, so no duplicate related-issue commit is published here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source no longer matches the exact FHIR-17013 intermediate wording because a later final Jira decision refined it, and the current wording preserves the intended guardrail for unrecognized modifier extensions while following the later approved grammar.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-17013; any future change to the modifierExtension short description should be handled as a new work group decision and should consider FHIR-18039.
