FHIR-40303: Audit FHIRPath usage link externalization

Issue request:
FHIR-40303 was an Applied FHIR-I change request resolved Persuasive with Modification. It reported that the FHIRPath page wrongly stated that FHIRPath was used in SMART on FHIR CDS Hooks prefetch templates, even though the CDS Hooks change was only an outstanding PR. The accepted resolution was to avoid maintaining inverse usage claims directly in the core page, create an external Confluence page for FHIRPath usages/extensions, and link to it from the FHIRPath page.

Initial application:
The issue appears to have been applied by HL7/fhir PR #3797, specifically git commit d624d31444c9f4eb79f3ff3a85c4b62211060562, which replaced the direct CDS Hooks prefetch sentence in source/fhirpath.html with a link to the FHIRPath Usage and Extensions Confluence page. The combined branch did not already contain an Issue-Reconcile-Key audit commit for FHIR-40303.

Additional context:
source/fhirpath.html is the built page listed in publish.ini, and its current text lists core FHIR usages before pointing readers to the Confluence page for other usage patterns and extensions. FHIR-I minutes from 2024-12-09 record the same rationale: CDS Hooks FHIRPath prefetch work was still being tested and might take time to enter that specification, while inverse links from FHIR core should point to a Confluence page. The Confluence page created in 2025 includes CDS Hooks as one of the externally maintained usage examples. source/fhirpath.md still contains old CDS Hooks wording, but no build/reference search found a current use of that Markdown file, while publish.ini lists fhirpath.html as the built page.

Keep this audit commit as-is. No core source follow-up is needed for FHIR-40303 unless maintainers separately choose to retire or refresh the unreferenced source/fhirpath.md file, or the FHIR-I work group wants to change how the external Confluence usage page is maintained.
