FHIR-14765: Audit Medication serial-number support

Issue request:
FHIR-14765 was Published/Persuasive with Modification for STU3. It asked FHIR-core Medication to support medication serial numbers, driven by regulatory traceability needs, and the resolution was to support serial number, initially considering an attribute under the batch backbone element and the Device pattern.

Initial application:
The historical source commit 73c779d3aeb5a6120955eb499d67727c2fdfdf47 (TR #14765) applied the issue in the then-active Medication spreadsheet by adding Medication.batch.serialNumber 0..1 string and adding a serial-number search parameter on Medication.batch.serialNumber. No prior Issue-Reconcile-Key commit for FHIR-14765 was found on the combined branch.

Additional context:
Medication is an active current-build resource in source/fhir.ini. Later Published issue FHIR-17841 intentionally removed Medication.batch.serialNumber, added Medication.identifier 0..* Identifier, and clarified that serial number would be included as an identifier; that issue is already represented on the combined branch by commit 012128412efb823be129d952b5113115cc8e64e8. Later Applied issue FHIR-47622 refined the current R6 model by renaming the batch backbone to Medication.instance and adding Medication.instance.identifier for physical-instance identifiers such as serial numbers; that issue is already represented on the combined branch by commit 6b4f960128acaeaaa8484b46d7ef6b47ef85440f. FHIR-54379 is a related Resolved - change required search-parameter correction, but it is outside this default Applied/Published reconciliation scope and the current source already points the serial-number search parameter at Medication.instance.identifier.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active Medication source supports the seed request through Medication.instance.identifier, describes it as the physical-instance identifier typically used for a serial number, distinguishes it from Medication.identifier business identifiers, and has the serial-number search parameter mapped to Medication.instance.identifier.

Recommendation:
Keep this no-change audit commit as-is for FHIR-14765. Do not reintroduce Medication.batch.serialNumber; the current instance.identifier model reflects later final Pharmacy work-group decisions and the related reconciled commits already on the combined branch.
