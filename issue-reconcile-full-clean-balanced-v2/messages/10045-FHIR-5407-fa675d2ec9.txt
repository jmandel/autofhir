Issue request:
FHIR-5407 was a Published/Persuasive DSTU1 technical correction for FHIR-core-toc. The ballot comment reported that Encounter appeared as section 1.13 between the EHR FM map and Data Types in the table of contents while linking to the Encounter resource, and the resolution was to fix the navigation as described.

Initial application:
The issue was applied in git commit 7aeb35d87793846d4b6c93815dfb4e727db2cf06, whose message is "#5407 - fix toc" and whose git-svn-id records SVN build revision 3988. That patch removed the accidental `<page type="resource" resource="Encounter">` wrapper from the old source/heirarchy.xml introductory TOC section and restored the intended resource-definition pages before Data Types.
