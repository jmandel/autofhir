FHIR-41254: Record external TestScript search parameter audit

Issue request:
FHIR-41254 is Applied/Persuasive for FHIR-core-TestScript. It asked to add the missing simple TestScript search parameters artifact, phase, and conformance because the composite parameters TestScript.scope-artifact-conformance and TestScript.scope-artifact-phase referenced those subparts but the subpart SearchParameter definitions did not exist.

Initial application:
The issue was directly applied in HL7/fhir commit e1304f6043117c133873fc28b7d68d3a6856ac62, linked from the Jira comment as PR 3003, which added TestScript-artifact, TestScript-conformance, and TestScript-phase to source/testscript/bundle-TestScript-search-params.xml. The adjacent FHIR-27007 history explains the same TestScript.scope search family that made those composite parameters meaningful.

Additional context:
The current core build no longer has an active TestScript resource or source/testscript directory. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed the testing resources from source/fhir.ini and deleted source/testscript while adding an additional-ig-list entry for the Testing IG; current ballot-intro.html also points TestScript to the HL7/fhir-testing-ig publication. The successor HL7/fhir-testing-ig source currently contains the simple artifact, conformance, and phase search parameters and the two composite parameters reference them.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. FHIR-41254 was applied while TestScript was still a core resource, and the current authoritative TestScript search-parameter source lives outside this checkout and already carries the requested definitions.

Recommendation:
Keep this empty external-repo audit commit as-is for core. Future TestScript search-parameter corrections should be made in HL7/fhir-testing-ig rather than reintroducing source/testscript content or stale search parameter definitions to the core build.
