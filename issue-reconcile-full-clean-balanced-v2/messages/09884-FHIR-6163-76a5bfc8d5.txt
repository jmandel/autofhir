FHIR-6163: Audit JSON comments example request

Issue request:
FHIR-6163 was a Published/Persuasive DSTU1 FHIR-core JSON-page clarification asking for explicit examples or references because the page described a special `fhir_comments` JSON property but the reporter could not find examples. The recorded resolution says this was fixed by showing comments in JSON, with many examples, in SVN revision 6388.

Initial application:
The Jira-recorded application is present in git as 82c53fe2e6195e27e1450eda8c1d0a923836be61 (`#6163 - comments in json examples`, svn build@6388). That commit changed the DSTU1-era tooling/validation path to emit and accept `fhir_comments` in generated JSON examples, while the JSON narrative already documented the special property.

Additional context:
The original request was superseded by later final JSON-format decisions. FHIR-10656 was Published/Persuasive and explicitly removed comments from the JSON format because the special comments property created operational difficulties and drew ITS work-group objections; commit 75b64c909db45b251281f7d6129bfbe42a3336cd removed the `fhir_comments` prose and related canonicalization/primitive wording from `source/json.html`. FHIR-17005 later clarified the current text to say `//` is only used in the specification's displayed format and comments are not valid JSON instances. Community and Confluence evidence found no contrary final decision; later Zulip discussion continues to distinguish authoring/rendering comments from native FHIR JSON instances.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active JSON format page is in build scope via `source/hierarchy.xml` and already says comments SHALL NOT appear in JSON instances. Re-adding `fhir_comments` examples would contradict the later published removal decision; the only current `fhir_comments` hits found in `source/` are invariant-test JSON files, not the JSON format narrative or current example guidance.

Recommendation:
Keep this audit commit as-is. Do not reintroduce `fhir_comments` examples for FHIR-6163 unless a new work-group decision reverses FHIR-10656/FHIR-17005 and restores a valid JSON comment mechanism.
