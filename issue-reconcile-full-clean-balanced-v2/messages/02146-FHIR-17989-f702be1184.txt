FHIR-17989: Audit PaymentNotice recipient description

Issue request:
FHIR-17989 was a Published/Persuasive with Modification Financial Management change request raised against STU3 PaymentNotice. It asked to change PaymentNotice.target to PaymentNotice.recipient and to make the short description identify the notice receiver.

Initial application:
No current-history commit uses the literal FHIR-17989 key, but the Jira-era GF#17989 batch commit f369c813fb40cd39c0db46336b2b3186f496fb47 applied this issue family to the then-authoritative PaymentNotice spreadsheet and example. That commit changed the example from target to recipient and changed the spreadsheet element from PaymentNotice.target with short "Insurer or Regulatory body" to PaymentNotice.recipient with short "Party being notified" and definition "The party who is notified of the payment status." The 2021 source rework commit 33b409a4b6d544598262f2f074ebb4b6dc466157 carried that recipient element and wording into the current StructureDefinition source.

Additional context:
PaymentNotice is active in the current build through source/fhir.ini. The only current PaymentNotice.target occurrence found in source is the version-difference mapping PaymentNotice.target=PaymentNotice.recipient, not a live element definition. The closely related FHIR-19495 also requested the target-to-recipient cleanup and is already represented on the combined branch by audit commit d22c1340f45662a1cf14c2d447a99e772b256059. No relevant Zulip or Confluence evidence was found that changes the Jira/source/history conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative PaymentNotice source already has PaymentNotice.recipient, the current example uses recipient, and the short/definition "Party being notified" / "The party who is notified of the payment status" conveys the same notice-receiver meaning as the Jira resolution without needing an exact wording-only replacement.

Recommendation:
Keep this audit commit as-is. No additional core FHIR source work is needed for FHIR-17989; changing the short to the exact Jira phrase "Notice receiver" would be editorial churn rather than a necessary semantic correction.
