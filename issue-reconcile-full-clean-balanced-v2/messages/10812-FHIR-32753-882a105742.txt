Initial application:
No current git commit was found with an explicit FHIR-32753 subject for the SubscriptionTopic source. Additional context:

A later SubscriptionTopic model change, FHIR-46492, collapsed resourceTrigger and eventTrigger into trigger and moved canFilterBy under trigger; source/fhir.ini retains aliases from the older R5 path names to the current trigger paths. Community searching found the subscription block-vote Zulip thread listing FHIR-32753 and no Confluence references that changed the Jira/source conclusion.
