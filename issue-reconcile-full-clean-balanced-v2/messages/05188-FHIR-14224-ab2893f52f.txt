FHIR-14224: Audit Patient generalPractitioner PractitionerRole target

Issue request:
FHIR-14224 was Published/Persuasive for the Patient resource. It asked that Patient.generalPractitioner allow Reference(PractitionerRole) in addition to Practitioner and Organization so a patient's GP can be identified in the context of a specific organization.

Initial application:
The issue was applied in historical commit 639fc8d6894a249ee6aa560825015e77c6d767a2, which changed the old Patient spreadsheet row from Reference(Organization|Practitioner) to Reference(Organization|Practitioner|PractitionerRole). The 2021 source rework preserved that result in the current StructureDefinition source.

Additional context:
Patient is active in source/fhir.ini, so source/patient/structuredefinition-Patient.xml is in current build scope. The linked Zulip consultation thread records the PA work group asking for community feedback and includes support or non-blocking feedback. Related FHIR-14442 relied on the FHIR-14224 decision and updated explanatory comments for multiple general practitioners; it is a separate comment-guidance issue rather than a separate target-profile fix for this audit.

AutoFHIR reconciliation:
No source change was made. Current Patient.generalPractitioner already includes targetProfile entries for Organization, Practitioner, and PractitionerRole, and no current Patient source text was found that still limits the element to only Practitioner or Organization.

Recommendation:
Keep this no-change audit commit. No follow-up is needed for FHIR-14224 in the core Patient source; do not add redundant prose unless a future issue identifies a concrete ambiguity.
