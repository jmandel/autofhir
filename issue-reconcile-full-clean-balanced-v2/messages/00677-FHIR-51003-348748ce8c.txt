FHIR-51003: Audit SupplyRequest wording correction

Issue request:
FHIR-51003 was an Applied/Persuasive OO technical correction for the SupplyRequest Boundaries and Relationships text. It asked to fix "an Task" to "a Task" and clarify that messaging or workflow service use applies regardless of whether the request is explicit or implicit.

Initial application:
The issue was applied in git commit 5498dd181e, which changed source/supplyrequest/supplyrequest-introduction.xml from "an Task" to "a Task" and replaced "where the request is explicit or implicit" with "regardless of whether the request is explicit or implicit." OO minutes for 2025-05-30 also record FHIR-51003 as discussed, wording adjusted, and to be fixed.

Additional context:
A later Applied issue, FHIR-46342, replaced the broader SupplyRequest Boundaries and Relationships paragraph to add fulfillment guidance. That later approved text retained the corrected "Task" article and the explicit-or-implicit messaging/workflow meaning in a new sentence. After that, commit 3b38b80cf2 removed SupplyRequest and related OO resources from the active core fhir.ini build lists and updated core narrative links to point to the OO incubator SupplyRequest page; build.fhir.org/supplyrequest.html now returns 404.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The FHIR-51003 typo was applied, the later FHIR-46342 rewrite still conveys the same explicit-or-implicit rule without the original grammar error, and SupplyRequest is no longer an active core resource page in the current build, so editing the stale core SupplyRequest source would not improve the current specification.

Recommendation:
Keep this audit commit as-is. If future wording changes are needed for SupplyRequest after its move out of core, handle them in the OO incubator source rather than in inactive core SupplyRequest files.
