FHIR-3484: Audit MedicationDispense daysSupply

Issue request:
FHIR-3484 was a Published/Persuasive FHIR-core Pharmacy change request for MedicationDispense. It noted that the MedicationDispense dispense-event documentation referred to days supply, but the then-current model had no corresponding days supply element, unlike MedicationPrescription.dispense.expectedSupplyDuration.

Initial application:
No commit explicitly mentioning FHIR-3484 was found. The requested model change appears to have been applied implicitly in the historical source by commit abce09d8c1edffa07e8bd6fbdf60eaa097da3d91 ("Pharmacy updates based on recent ballot."), which added MedicationDispense.daysSupply to the old MedicationDispense spreadsheet. The later 2021 source rework preserved the element in the current StructureDefinition source.

Additional context:
MedicationDispense is active in the current build via source/fhir.ini. The current authoritative source defines MedicationDispense.daysSupply as 0..1 SimpleQuantity with the definition "The amount of medication expressed as a timing amount." MedicationRequest.dispenseRequest.expectedSupplyDuration also remains present, so the parallel prescription/dispense modeling concern from the issue is no longer a gap. Related searches found FHIR-5165 as a separate datatypes/Quantity policy issue that mentioned MedicationDispense.daysSupply only as one of many Quantity uses, and FHIR-45153 as a later adjacent MedicationDispense fillNumber addition after daysSupply; neither changes the FHIR-3484 conclusion.
