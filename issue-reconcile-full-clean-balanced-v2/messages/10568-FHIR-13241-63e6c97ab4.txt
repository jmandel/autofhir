FHIR-13241 was a Published/Persuasive FHIR-core STU3 change request asking for useful anchors on the Quantity specializations and constraints listed under datatypes.html Defined Variations on Quantity, especially links such as Duration and Money.

Initial application:
The issue appears to have been applied in git commit 3c0c1b50ccc0a1ed836669729337090a8fb9851a, which fixed stale lower-case Duration links in ElementDefinition source rows by changing datatypes.html#duration to datatypes.html#Duration. The Jira comments record svn revision 12618 as the applied fix.

A related earlier Published issue, FHIR-12805, concerned lower-case links from the generated allTypes diagram to these same Quantity specializations; current diagram source now uses the canonical uppercase type names.

Recommendation:
