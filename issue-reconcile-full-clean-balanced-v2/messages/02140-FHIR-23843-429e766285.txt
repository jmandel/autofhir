FHIR-23843: Audit Encounter careTeam reference

Issue request:
FHIR-23843 was Published/Persuasive for R5. It requested moving the CareTeam/Encounter relationship off CareTeam.encounter by adding Encounter.careTeam 0..* Reference(CareTeam), with the CareTeam.encounter attribute removed by the companion PC work.

Initial application:
The issue was applied by git commit a573cb7b56ddd13c798c3cc8242784754ed5a5ea, which added Encounter.careTeam to source/encounter/structuredefinition-Encounter.xml with the requested 0..* cardinality, Reference(CareTeam) type, short description, and definition. FHIR-32767 then added the Encounter careteam SearchParameter in git commit 45876e6ccd3cab51b4108cdd444ccd2038a152a0, and a later AutoFHIR commit on the combined branch corrected that search parameter's copied canonical URL.

Additional context:
FHIR-23029 is the PC-side companion issue and removed CareTeam.encounter. LHS February 2020 minutes recorded that Encounter should reference CareTeam instead of CareTeam referencing Encounter and that the PA work was still pending. PA June 2022 minutes revisited FHIR-23843, noted that Patient Care had removed its portion, and concluded that the Encounter reference to CareTeam still needed to be applied. Current CareTeam narrative now says CareTeam can be referenced by EpisodeOfCare, Encounter, or CarePlan.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Current build-scope source already contains Encounter.careTeam 0..* Reference(CareTeam), the associated Encounter-careteam search parameter points at Encounter.careTeam with its corrected URL, and CareTeam no longer contains the reverse CareTeam.encounter element.

Recommendation:
Keep this audit commit as-is. No further core source change is indicated for FHIR-23843; the separate FHIR-32767 audit/source-fix commit should remain the audit record for the search-parameter URL correction.
