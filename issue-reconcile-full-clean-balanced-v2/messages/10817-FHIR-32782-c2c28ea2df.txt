FHIR-32782: Audit R5 SearchParameter package restoration

Issue request:
FHIR-32782 was a Published/Persuasive FHIR-I technical correction for FHIR-core SearchParameter, raised against the 2021May R5 core package and applied for R5. It reported that the package exposed only about 25 SearchParameter definitions and that the definitions present were experimental, where roughly 1,400 SearchParameters were expected. The Jira resolution says this was likely the same issue as FHIR-32107 in R4B.

Initial application:
No source commit explicitly mentioning FHIR-32782 was found. The issue appears to have been handled as the R5 instance of the FHIR-32107 package tooling problem: FHIR-I minutes on 2021-12-06 record FHIR-32782 as a technical correction to fix in R5, and the older FHIR-32107 minutes identify the underlying defect as a tooling issue. Current published R5 packages no longer show the reported failure: hl7.fhir.r5.core contains 1,244 SearchParameter files with 1,143 explicit experimental=false, and hl7.fhir.r5.search contains 2,011 SearchParameter files with 1,891 explicit experimental=false.

Additional context:
FHIR-32107 is the same-change-family R4B issue and is audited separately. FHIR-26430 and FHIR-36879 are related definition/clarification issues that explain why some search-result and HTTP controls are intentionally not SearchParameter resources; they do not reopen the broad package-count defect. FHIR-39010 later introduced the separate search-parameter package for R5 and later, so the modern R5/R6 package split is an expected later package-output change.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Current source/fhir.ini keeps SearchParameter active in the current build, current source has 147 resource search-parameter bundle files with 2,077 SearchParameter entries and no experimental=true source flag, and published R5/R6 package checks show that the old package-generation failure is already resolved.

Recommendation:
Keep this audit as-is. Do not change current core SearchParameter source for FHIR-32782; the issue targeted a historical R5 package-generation failure, and current source/package artifacts already satisfy the intended correction. New package regressions should be filed with current package URLs and counts.
