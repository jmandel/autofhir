FHIR-12180: Audit primitive extension base paths

Issue request:
FHIR-12180 was Published/Persuasive for DSTU2 and asked the build to correct primitive type profile ElementDefinition.base.path values. The cited example was string.profile.xml, where string.extension had an incorrect base.path of string.extension and should instead have Element.extension.

Initial application:
Jira records svn revision 10025 as the application. In this Git history that is commit 82e1ca4af69d33f527a180c7bfa003e811feb4c0, whose subject names Tasks 12180, 12182, and 12179. The relevant generator hunk in ProfileGenerator.makeExtensionSlice changed generated extension slice base paths from path + ".extension" to the shared Element.extension base, which directly addresses this issue's request. That historical Java generator source is no longer present in the current checkout after later build-tool refactoring.

Additional context:
Current build scope still includes the primitive/datatype inputs through source/fhir.ini and source/datatypes/primitives.xml, but the per-primitive StructureDefinition profile files are generated rather than checked in as string.profile.xml-style source files. A current CI-build check of representative primitive StructureDefinition JSON files, including string.profile.json and the other primitive profile filenames, showed each primitive extension element has base.path Element.extension. Related FHIR-12179 and FHIR-12182 were applied by the same historical commit, but they concern snapshot constraint inheritance and element.id behavior and are not decided by this seed audit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical build-generator fix was applied, the current source inputs remain in build scope, and the current generated primitive profiles already carry the requested Element.extension base path.

Recommendation:
Keep this audit commit as-is. Revisit only if a future publisher/build regression again emits primitive extension elements whose base.path points to the primitive-specific extension path instead of Element.extension.
