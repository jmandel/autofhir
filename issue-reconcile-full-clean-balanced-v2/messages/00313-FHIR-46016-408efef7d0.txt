FHIR-46016: Audit organization communication extension in Extension Pack

Issue request:
FHIR-46016 was an Applied FHIR-core Patient Administration change request, resolved Persuasive with Modification, asking for a way to indicate languages an Organization or OrganizationAffiliation can use to conduct business. The approved approach was to use the existing location-communication standard extension, widen its applicability to Location, Organization, and OrganizationAffiliation, and change the extension cardinality to 0..*; the application comment concluded this could be done by adding contexts to the existing extension rather than creating a replacement.

Initial application:
The original core location-communication extension was added for Location by FHIR-25302, then core commit dd468d4f17 removed standard extension definitions from the R5 core source. The relevant current source moved to the FHIR Extension Pack, where commit 329b91da5d9586173eec0f68430f3a68e40cb42d applied FHIR-46016 and FHIR-46017 by adding Organization, OrganizationAffiliation, and ExtendedContactDetail contexts to input/definitions/Location/StructureDefinition-location-communication.xml and changing Extension.max from 1 to *.

Additional context:
The Extension Pack IG includes input/definitions/* as build input, and the current location-communication source remains active with Location, Organization, and OrganizationAffiliation contexts and Extension.max="*". Later Extension Pack QA commits only adjusted metadata, version-specific-use annotations, status, and binding details without reversing the Organization or OrganizationAffiliation applicability. The core FHIR checkout now contains only the retained OID mapping for this extension, not the authoritative StructureDefinition source.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The requested change is already present in the external HL7/fhir-extensions source of truth, and editing the current HL7/fhir core checkout would either be redundant or out of build scope for the extension definition.

Recommendation:
Keep this external-repo audit as-is. If future review finds another issue with the language-communication extension, apply that work in HL7/fhir-extensions; no follow-up core source change is needed for FHIR-46016 based on the current evidence.
