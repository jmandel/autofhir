FHIR-6260: Audit retired genetics standard links

Issue request:
FHIR-6260 was a Published/Persuasive Clinical Genomics issue for the DSTU1 FHIR-core Observation Standard Profile for Genetics. It asked for links or references to genetic standards and resources, with the final resolution stating that the links had been added.

Initial application:
No explicit Jira-tagged source commit for FHIR-6260 was found. Git history shows the old source/observation/observation-genetics-introduction.xml gained a "Genetic Standards and Resources" section listing dbSNP, ClinVar, COSMIC, RefSeq, ENSEMBL, HGNC, HGVS, Sequence Ontology, and LOINC, and the later observation genetics profile source carried that material forward.

Additional context:
The old Observation genetics profile is no longer part of current FHIR core. In 2020, core removed outdated clinical genomics artifacts under Observation, DiagnosticReport, and ServiceRequest, including the observation genetics introduction/profile and associated valuesets, and streamlined genomics.html toward the Genomics Reporting Implementation Guide. Current source/fhir.ini has no active observation-genetics profile entry, while Observation remains active and MolecularDefinition is the current Clinical Genomics resource. Current Observation notes and the Genomics page direct readers to the Genomics Reporting IG for structured genomic reporting.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing the old DSTU1 standards/resources list into current core would revive out-of-build content and duplicate material that now belongs in current Clinical Genomics guidance and implementation guides rather than in the retired Observation genetics profile.

Recommendation:
Keep this no-change audit commit. If the Clinical Genomics Work Group wants richer links to current genomics standards, handle that as new work in the Genomics Reporting IG or current build-scoped Clinical Genomics artifacts, not as a FHIR-6260 core fix.
