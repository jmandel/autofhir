FHIR-5271: Audit dosage SIG wording

Issue request:
FHIR-5271 was a Published Pharmacy change request from the DSTU1 ballot, resolved Persuasive, asking to update MedicationPrescription.dosageInstruction.text/additional-instruction wording. The accepted wording clarified that free text dosage instructions can be used when instructions are too complex to code and may still be present for human display when coded instructions are present, because this is the prescription SIG surface.

Initial application:
The issue appears to have been applied before this reconciliation by git commit d406f9a2c0, which updated Pharmacy resources based on ballot resolutions and added the accepted sentence to the then-current MedicationPrescription.dosageInstruction.text spreadsheet row. Later source history renamed MedicationPrescription/MedicationOrder to MedicationRequest and factored dosageInstruction details into reusable Dosage and, for R6 MedicationRequest, DosageDetails.

Additional context:
Current source/fhir.ini keeps MedicationRequest, Dosage, and DosageDetails in active build scope and records that MedicationPrescription became MedicationRequest. Later Pharmacy decisions refine the same dosage text family: FHIR-39319 says Dosage.text is a complete free-text dosage/SIG representation, and FHIR-54014 makes DosageDetails.renderedInstruction mandatory so full dosage intent is always communicated. The active MedicationRequest notes now point implementers to required DosageDetails.renderedInstruction for the full human-readable instructions while preserving Dosage.text as complete SIG text for individual Dosage entries.

AutoFHIR reconciliation:
This is an empty audit commit. The current active source already conveys the FHIR-5271 rule through Dosage.text, DosageDetails.renderedInstruction, and MedicationRequest dosage notes. Restoring the old MedicationPrescription-specific sentence or adding redundant local prose would be less accurate for the current R6 dosage model and could duplicate later Pharmacy decisions.

Recommendation:
Keep this no-change audit as-is. Revisit only if Pharmacy changes the R6 DosageDetails/renderedInstruction model or reopens SIG guidance; no current FHIR core source edit is needed for FHIR-5271.
