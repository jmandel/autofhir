FHIR-20630: Audit meta operation reference status

Issue request:
FHIR-20630 was Published with resolution Persuasive for FHIR-core BaseResource. The requester noted that Resource.html#tag-updates described special handling for updates to meta tags and asked for the final sentence to reference the $meta operations for fuller support; the accepted resolution was to add that reference.

Initial application:
The issue was initially applied by commit 33ef5f515ec36018d09d933b30e47d0cce23a982, "Reference to $meta", submitted through the Jira-linked PR 1934. That commit added a sentence to source/resource/resource-notes.xml saying that a client can retrieve current tags using the Resource $meta operation.

Additional context:
Resource is active current-build infrastructure/normative content in source/fhir.ini, and source/resource/resource-notes.xml is the active Resource narrative source. A later broad R6 normative cleanup, commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd, removed the FHIR-20630 sentence, removed Resource.$meta/$meta-add/$meta-delete from the Resource operation list, and deleted the core OperationDefinition source files. Current source/ballot-intro.html lists these Resource meta operations as moved to the API Incubator, but the linked build.fhir.org API Incubator operation pages currently return 404 and the HL7/api-incubator-ig repository only has incoming meta examples, not published operation definitions. The later R6 Jira FHIR-53185 asks this same tag-updates section to mention $meta-add and $meta-delete, but it is still Triaged/Unresolved. Security-related FHIR-20631 was retracted/no-change and Security minutes noted it should be closed by FHIR-20630.

AutoFHIR reconciliation:
This commit intentionally makes no source change and records a human-review decision. Restoring the old core link would point to a removed page, and adding a new external API Incubator reference would be premature while the target operation definitions are not present and the current R6 tracker for this section remains unresolved.

Recommendation:
Use FHIR-53185 or a work-group review to decide the current R6 wording once the API Incubator $meta, $meta-add, and $meta-delete definitions are published and stable. If that review confirms the old FHIR-20630 intent still applies in R6, update source/resource/resource-notes.xml#tag-updates with valid links to the published operation definitions rather than resurrecting the removed core resource-operation-meta.html link.
