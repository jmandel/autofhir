FHIR-32864: Audit medication reconciliation list guidance

Issue request:
FHIR-32864 was Published/Persuasive for R5. It asked to add a new Medications Module overview section explaining how to use Pharmacy resources when addressing medication reconciliation, based on proposed wording from the Pharmacy Medication Reconciliation List / Medication List Guidance work.

Initial application:
The issue appears to have been applied by commit ece63351c6107ee2d837bd8bdc64871ad186dc4c, later merged by 0491ec11c00a0d5e60030e84ffd191391dad9e5b. That commit explicitly mentioned FHIR-32864 and added the Medication Reconciliation List section to source/medications-module.html. Current source still contains that section and uses the current core resource name MedicationStatement where the original R5-era patch used MedicationUsage.

Additional context:
source/medications-module.html is the active Medications module page listed in source/hierarchy.xml, with MedicationRequest, MedicationAdministration, MedicationDispense, MedicationStatement, Medication, and Immunization as child resources, and the medication resources are active in source/fhir.ini. Pharmacy Confluence records show the Medication List Guidance project and a January 2022 Pharmacy WGM tracker review including FHIR-32864. A relevant Zulip thread supports the same contextual guidance: medication list and reconciliation scenarios vary by use case and can involve List plus multiple medication resources rather than a single universal pattern. Later page work, including FHIR-53486, reorganized nearby module content without removing or contradicting the FHIR-32864 guidance.

AutoFHIR reconciliation:
Made no source change. The current source already has a dedicated Medication Reconciliation List section that covers the reconciliation process, common transition-of-care contexts, source medication information, representation with MedicationRequest, MedicationDispense, MedicationAdministration, and MedicationStatement, context-dependent variation, and patient/clinician availability. Additional prose would restate existing guidance rather than fixing a current-spec defect.

Recommendation:
Keep this empty audit commit as-is. No core source follow-up is needed for FHIR-32864 unless the Pharmacy work group later decides to revise the medication list guidance more broadly.
