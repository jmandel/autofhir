FHIR-49803: Audit Vital Signs FMM levels

Issue request:
FHIR-49803 was Applied/Persuasive for R6 after the Orders and Observations vote on 2025-01-28. It requested the Vital Signs StructureDefinition profiles be set to FMM 4, except the Vital Signs Panel profile, which should be FMM 3.

Initial application:
The source application appears in commit e310a0cfa367251d83d375ce0ca75c3286ef3473, merged by 67f1afa39d79c7246d74b47c8ac545abd018c4a1 in PR #3327. That implementation changed the eleven Observation Vital Signs profile StructureDefinition FMM extensions: vitalsigns and the specific vital sign profiles to 4, and vitalspanel to 3.

Additional context:
Observation is an active resource in source/fhir.ini, and source/observation/list-Observation-packs.xml includes ImplementationGuide/Observation-vitalsigns. That implementation guide references the eleven Vital Signs StructureDefinition profiles checked here. The guide itself still has package-level FMM 5 metadata, but it is not one of the StructureDefinition profiles named by the Jira request; later source history touched that guide for status-page metadata without changing the profile FMM application. Targeted Zulip and Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
This audit commit makes no source change because the current build-scope profile sources already match the applied decision: vitalsigns, bmi, bodyheight, bodytemp, bodyweight, bp, headcircum, heartrate, oxygensat, and resprate are FMM 4, and vitalspanel is FMM 3.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-49803 unless the work group separately decides to change package-level Observation-vitalsigns guide metadata.
