FHIR-12173: Audit questionnaire optionExclusive extension

Issue request:
FHIR-12173 was a Published/Persuasive DSTU2 Questionnaire request to add a standard extension on Questionnaire.item.option for an exclusive multiple-choice option, such as "None of the above".

Initial application:
SVN #10502 appears in git as b3c368f1b1 "SVN #10468, #12173"; it added optionExclusive to source/questionnaire/questionnaire-extensions-spreadsheet.xml with the "Option is exclusive" definition. Later Questionnaire option naming changed to answerOption, and the current extension definition uses that context.

Additional context:
The active core build still includes Questionnaire, but core no longer carries the individual Questionnaire extension StructureDefinitions. Git dd468d4f17 removed those extension source files from R5 core, including structuredefinition-extension-questionnaire-optionExclusive.xml. The current definition now lives in the FHIR Extension Pack at input/definitions/Questionnaire/StructureDefinition-questionnaire-optionExclusive.xml and retains the requested boolean semantics, canonical URL, OID, and answerOption context. FHIR-19377 later made questionnaire-optionExclusive not a modifier; the current Extension Pack file has no isModifier override. SDC-related FHIR-18259 asked for examples/guidance, which is outside this core checkout and is linked from the extension comment.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Adding the extension back into core would duplicate an artifact that has moved to the Extension Pack, and the Extension Pack source already satisfies the requested extension definition for the current build family.

Recommendation:
Keep this external-repo audit commit as-is. If future clarification is needed for optionExclusive behavior, make it in the FHIR Extension Pack or SDC guidance rather than reintroducing the core extension source.
