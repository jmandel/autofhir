FHIR-3015: Audit Questionnaire subject scope

Issue request:
FHIR-3015 was a Published FHIR-core Patient Care change request with a Persuasive with Modification resolution. It asked whether Questionnaire/QuestionnaireAnswers subject should be limited to Patient|RelatedPerson when questionnaires could be about devices, medications, organizations, practitioners, and other resources; the recorded resolution was to change the subject from Patient|RelatedPerson to Any, with comments clarifying that Questionnaire itself is a form definition and subject-specific answers belong on QuestionnaireAnswers/QuestionnaireResponse.

Initial application:
No explicit FHIR-3015-tagged source commit was found. The issue appears to have been applied in the early Questionnaire split: commit 54ddc30bbb split Questionnaire into Questionnaire and QuestionnaireAnswers and applied outstanding Questionnaire change requests, removing the old Questionnaire.subject Reference(Patient|RelatedPerson) row and creating QuestionnaireAnswers.subject as Resource(Any) with text saying the subject could be a patient, organization, practitioner, device, etc. Later, FHIR-6044 added Questionnaire.subjectType because QuestionnaireAnswers.subject was already Reference(Any), and the QuestionnaireAnswers to QuestionnaireResponse rename preserved that model.

Additional context:
The current build includes both Questionnaire and QuestionnaireResponse as active resources in source/fhir.ini. Current Questionnaire has Questionnaire.subjectType 0..* with the comment "If none are specified, then the subject is unlimited." Current QuestionnaireResponse.subject is Reference(Resource) with definition text that examples patient, organization, practitioner, device, etc., and FHIR-11004 added the clarifying comment that a Questionnaire.subjectType limits the referenced resource when present. No current build-scope Questionnaire/QuestionnaireResponse source still defines Questionnaire.subject or restricts QuestionnaireResponse.subject to Patient|RelatedPerson.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already represents the FHIR-3015 outcome: Questionnaire is subject-independent, QuestionnaireResponse.subject is unrestricted Any/Resource, and optional Questionnaire.subjectType provides an author-declared constraint rather than a base-spec limitation.

Recommendation:
Keep this no-change audit commit as-is. Related subjectType and section/item-subject work should remain separate audits or issue decisions because FHIR-3015's base subject limitation is already resolved in current source.
