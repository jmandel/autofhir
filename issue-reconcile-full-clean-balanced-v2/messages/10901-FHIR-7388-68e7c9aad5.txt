FHIR-7388: Audit document presentation wording

Issue request:
FHIR-7388 was a Published FHIR-core documents issue, resolved Persuasive with Modification, asking to soften the DSTU1 statement that document content and presentation "cannot change" to say they cannot change substantially in a way that changes clinical meaning. The reporter noted tension with stylesheet guidance that allowed alternate stylesheets.

Initial application:
The issue was applied in git commit 680c9f5b1460104c5dc910df5b59d0d2a61fc8f7, matching the Jira comment for svn revision 6448, by changing source/documents.html to say the directly referenced content and document presentation cannot change substantially if that changes the clinical meaning of the content. A nearby earlier commit for #7946 had already narrowed the old phrase from the set/order of attested resources to directly referenced content.

Additional context:
The current source/documents.html page is a build-scope top-level documents page linked from the documentation index. Later final document-page decisions, especially FHIR-36636, removed the old immutable-document paragraph and replaced it with guidance that changes to a document Bundle may risk invalidating attestation and that implementations should define permitted update policies. FHIR-38927 and FHIR-38930 further refined that language by removing overbroad "frozen" and "document immutability" terminology. The current stylesheet section separately states that a stylesheet SHALL NOT alter presentation in a way that changes clinical meaning, which addresses the contradiction FHIR-7388 identified.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source no longer contains the unsoftened "cannot change" sentence, no longer contains the FHIR-7388 sentence in the obsolete immutable-document paragraph, and still preserves the clinically meaningful presentation limit in the stylesheet rules plus the attestation-risk guidance.

Recommendation:
Keep this audit commit as-is. Reintroducing the exact 2015 wording would conflict with later Published FHIR-I decisions that intentionally replaced the old immutability paragraph with more nuanced policy guidance.
