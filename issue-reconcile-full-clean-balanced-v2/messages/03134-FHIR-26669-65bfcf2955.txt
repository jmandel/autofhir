FHIR-26669: Align medicinal product classification ModelInfo

Issue request:
FHIR-26669 was Published/Persuasive for R5 and asked BR&R to rename MedicinalProductDefinition.productClassification to MedicinalProductDefinition.classification, eliminating the redundant "product" wording from the element name.

Initial application:
The issue was applied in commit d2e6d81f27044374ce30401b189d3de9cd0d5a4d, merged by PR #870, which renamed the medicinal product definition spreadsheet row and the example XML from productClassification to classification. The current MedicinalProductDefinition StructureDefinition, examples, and search-parameter expression already use MedicinalProductDefinition.classification, but the active FHIR ModelInfo Library payload still exposed the old productClassification member.

Additional context:
source/fhir.ini keeps MedicinalProductDefinition and Library active, source/library/list-Library-examples.xml lists Library/FHIR-ModelInfo, and publish.ini publishes source/library/library-fhir-model-definition-content.xml. The ModelInfo file is labeled version 6.0.0 and has been reconciled by neighboring AutoFHIR commits as a current specification surface. BR&R minutes from 2020-05-05 record the 9-0-0 decision to eliminate the product tautology; no Zulip or Confluence search found a later conflicting decision.

AutoFHIR reconciliation:
Renamed the stale ModelInfo element from productClassification to classification in source/library/library-fhir-model-definition-content.xml and regenerated the embedded base64 payload in source/library/library-fhir-model-definition.xml. No MedicinalProductDefinition resource-source change was needed because the authoritative StructureDefinition, examples, and search expression already use classification.

Recommendation:
Keep this source fix as-is. It completes the already-applied FHIR-26669 rename in the active ModelInfo publication surface without attempting broader cleanup of historical MedicinalProduct* ModelInfo class names that are outside this issue's requested element rename.
