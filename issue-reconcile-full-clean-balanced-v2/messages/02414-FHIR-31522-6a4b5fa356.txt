FHIR-31522: Audit ProdCharacteristic removal

Issue request:
FHIR-31522 was a Published/Persuasive technical correction for the R4B ProdCharacteristic datatype page. The reported defect was that the ProdCharacteristic definition and comments used MarketingStatus wording about medicinal product market availability, even though ProdCharacteristic described product physical characteristics.

Initial application:
No Jira-tagged FHIR-31522 implementation commit was found. The same editor who confirmed the cut-and-paste error removed ProdCharacteristic from the active build in git commit 7333cb0ead shortly after the Jira comment, deleting the datatype spreadsheet and page fragments and commenting the type/page/maturity entries in source/fhir.ini.

Additional context:
FHIR-31700 separately recorded that ProdCharacteristic should not be described as a new medication-definition special datatype and was applied by removing that ballot-intro reference. DeviceDefinition-related issues FHIR-26424 and FHIR-30274 show the remaining use of ProdCharacteristic was replaced by DeviceDefinition.property. Current source has no source/prodcharacteristic page or source/datatypes/prodcharacteristic.xml; the active fhir.ini entries for ProdCharacteristic remain commented. The only remaining current-source mentions are a history note and a CQL Library example model-info file, neither of which carries the erroneous MarketingStatus definition text or activates the datatype page.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build no longer publishes the ProdCharacteristic datatype page or spreadsheet that contained the erroneous wording. Reintroducing or rewriting a removed datatype page would be outside the current build scope and would not improve the current specification.

Recommendation:
Keep this no-change audit commit as-is. If future work addresses the CQL Library model-info example, review that separately because it is not the source page/definition defect resolved by FHIR-31522.
