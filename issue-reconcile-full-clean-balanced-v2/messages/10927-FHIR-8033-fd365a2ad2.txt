FHIR-8033: Audit genomic source class ownership

Issue request:
FHIR-8033 was a Published/Persuasive Clinical Genomics FHIR-core Observation change request for the old geneticsGenomicSourceClass extension. It asked to define the ambiguous "source"/"genomic class" wording and consistently use that meaning; the resolution clarified genomic source class as the source of the tissue sample used to determine the sequence and recorded the LOINC answer list.

Initial application:
No explicit core commit mentioning FHIR-8033 was found. Historical DSTU2 generated artifacts show the issue was applied to the old geneticsGenomicSourceClass definition as "category of source of tissue sample used to determine the sequence" with the LOINC answer list. Later STU3/R4 historical artifacts used the renamed observation-geneticsGenomicSourceClass canonical and the shorter "Source of sample used to determine the sequence in sequencing lab" wording with LOINC code 48002-0.

Additional context:
Current core source has no active geneticsGenomicSourceClass or observation-geneticsGenomicSourceClass definition and source/fhir.ini does not list the old Observation genetics profile or extension as an active profile source. Core history removed the outdated clinical genomics artifacts in 2020. The only current canonical definition found is in HL7/fhir-extensions, where the extension is retired/deprecated and directs implementers to the Genomics Reporting Guide. The combined branch already contains a related FHIR-11137 external-repo audit for the same current ownership boundary.
