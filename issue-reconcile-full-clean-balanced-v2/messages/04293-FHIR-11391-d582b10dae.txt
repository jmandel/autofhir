FHIR-11391: Audit EOB package-code terminology

Issue request:
FHIR-11391 was a Published/Persuasive with Modification Financial Management change request from the DSTU2 ballot asking for a consistent ExplanationOfBenefit term for DRG, bundle, or equivalent package billing codes. Although the description discussed adding packageCode near service line items, the final resolution narrowed the applied request to renaming the diagnosis drg element to packageCode.

Initial application:
The request was applied in historical commit d06f8787e6 ("Tracker #11375, 11376, 11391, 11392"), which changed the then-authoritative ExplanationOfBenefit spreadsheet source from ExplanationOfBenefit.diagnosis.drg to ExplanationOfBenefit.diagnosis.packageCode and updated its short, definition, and requirements text.

Additional context:
ExplanationOfBenefit is an active current resource in source/fhir.ini. The current authoritative XML source no longer has either ExplanationOfBenefit.diagnosis.drg or ExplanationOfBenefit.diagnosis.packageCode; instead it has the root element ExplanationOfBenefit.diagnosisRelatedGroup with package billing code wording. That later shape matches Published FHIR-29688, which explicitly requested adding diagnosisRelatedGroup at the Claim, ClaimResponse, and ExplanationOfBenefit roots and removing resource.diagnosis.packageCode, and was applied by commit acb64eec3c. source/fhir.ini also records ExplanationOfBenefit.diagnosis.packageCode as removed in the R4-to-R6 change map.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing diagnosis-level packageCode, or editing the current root diagnosisRelatedGroup back toward the 2016 interim term, would conflict with the later final FHIR-29688 decision. The obsolete drg element is absent, and the current EOB source preserves the package-code concept through the later approved root element.

Recommendation:
Keep this no-change audit commit. No FHIR core source follow-up is needed for FHIR-11391 unless the work group separately reopens the later FHIR-29688 root diagnosisRelatedGroup model decision.
