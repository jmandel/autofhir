FHIR-8843: Audit Appointment V2 mapping corrections

Issue request:
FHIR-8843 was a Published/Persuasive PA change request for DSTU2 asking to correct Appointment's HL7 V2 mappings: ARQ-11.2 should not map directly to Appointment.end, ARQ-11 components should feed requestedPeriod, ARQ-7 should not remain on Appointment.reason and was then directed to appointmentType, and requestedPeriod needed an RIM mapping.

Initial application:
The issue was applied in 0d8362807391a5d3c760d94582a8087e19adad6a against the historical Appointment spreadsheet source, removing ARQ-11.2 from Appointment.end, adding ARQ-11 to Appointment.requestedPeriod, adding the requestedPeriod RIM map, and moving ARQ-7 off Appointment.reason. The spreadsheet source was later converted into source/appointment/structuredefinition-Appointment.xml, which is in build scope because source/fhir.ini actively lists appointment=Appointment.

Additional context:
FHIR-7875 first added SCH-7 to Appointment.reason; FHIR-13861 later made ARQ-7/SCH-7 map to Appointment.appointmentType and ARQ-8/SCH-8 to Appointment.serviceType; FHIR-41607, an Applied R6 PA decision, subsequently removed the core Appointment.appointmentType V2 mapping and mapped ARQ-7/SCH-7 with Appointment.serviceType because the V2 fields are user tables and the core mappings were confusing. A 2017 QA RIM mapping commit changed requestedPeriod's RIM map from the issue's wording to the relative .activityTime form, and R4/R5 published Appointment profiles already carry that relative RIM map.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Current Appointment source has no ARQ-11.2 map on Appointment.end, maps Appointment.requestedPeriod to ARQ-11, maps Appointment.reason only to AIS-3, and reflects the later FHIR-41607 ARQ-7/SCH-7 serviceType decision.

Recommendation:
Keep this audit as-is. Do not re-add ARQ-7/SCH-7 to Appointment.appointmentType for FHIR-8843 because FHIR-41607 is a later final PA decision; revisit only if PA reopens the broader V2 appointment field alignment.
