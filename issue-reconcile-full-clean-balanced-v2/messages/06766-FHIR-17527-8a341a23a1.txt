FHIR-17527 was Published/Persuasive with Modification for FHIR-core Specimen. It asked to extend the http://hl7.org/fhir/StructureDefinition/observation-bodyPosition extension so its Context of Use covered Observation and Specimen.collection, supporting subject position during specimen collection.

Initial application:
The issue was applied in the historical core source by commit 1e393840340e8a3496634052422cf0e9018e7d9b (GF#17527, GF#17380, GF#17526), which changed source/observation/observation-extensions-spreadsheet.xml from Observation-only context to Observation;Specimen.collection. The generated R4 history in tools/history/release4/extension-definitions.xml contains both Observation and Specimen.collection contexts; the older frozen release3 history remains Observation-only and is not a current-source target.

Additional context:
Core no longer owns the live observation-bodyPosition extension definition. Commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed extension definitions from R5 core source, including source/observation/structuredefinition-extension-observation-bodyPosition.xml. The current FHIR Extension Pack build includes input/definitions/* and its input/definitions/multiple/StructureDefinition-observation-bodyPosition.xml still carries a Specimen.collection context. Later FHIR-31355/FHIR-26071 work in the Extension Pack marks the Observation context as not for use past R5 and opened FHIR-51528 for unresolved core Observation modeling guidance; that related work does not require a FHIR-core source edit for this Specimen.collection context.

AutoFHIR reconciliation:

Recommendation:
Keep this audit commit as-is. Do not edit current FHIR core for FHIR-17527.
