FHIR-15105: Audit MedicationRequest reporting outcome

Issue request:
FHIR-15105 was Published with a Persuasive with Modification resolution for the STU3 MedicationStatement.status/taken concern. The request raised that combining MedicationStatement.taken into status lost the ability to distinguish patient-reported non-use from whether a medication should remain on the active medication list. The final resolution did not restore MedicationStatement.taken; it said the concern was handled by adding MedicationRequest reporting and information-source attributes, with remaining topics spun into separate trackers.

Initial application:
The seed itself was applied through the related Pharmacy tracker FHIR-19313, which explicitly added MedicationRequest.reported and MedicationRequest.informationSource and cites FHIR-15105 as background. Jira records commit 65133c5 for that work, and local history shows the GF 19313 source change adding the MedicationRequest narrative that reported external orders are informational and not authoritative, plus the reported boolean and informationSource element.

Additional context:
MedicationRequest and MedicationStatement are active current-build resources in source/fhir.ini. The current authoritative MedicationRequest StructureDefinition no longer has an element literally named reported because later FHIR-49863 renamed it to MedicationRequest.isRecordOfRequest and clarified that such an instance is a record of a request rather than the request/order itself. The current source still contains MedicationRequest.informationSource, guidance that reported external requests are non-authoritative, and an example combining isRecordOfRequest with informationSource. MedicationStatement source separately continues to describe medication use/reporting, not ordering.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already conveys the approved FHIR-15105 outcome: use MedicationRequest, not MedicationStatement.status/taken, to represent reported or external medication-request/order information that is not authoritative for dispensing or administration, and use informationSource to identify who provided that information.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-15105. FHIR-19313 is already independently audited on the combined branch, and FHIR-49863 is a later rename/clarification decision rather than part of this seed decision.
