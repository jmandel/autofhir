FHIR-11020: Audit AllergyIntolerance reaction certainty migration

Issue request:
FHIR-11020 was a Published/Persuasive with Modification DSTU2 AllergyIntolerance change request asking for a use case for AllergyIntolerance.reaction.certainty. Patient Care resolved that Reaction.certainty should be moved to an extension, at least for then.

Initial application:
The original application commit 68550659bae9230325fa334363c569fc10d9ceb1 marked AllergyIntolerance.reaction.certainty as moved out of the core resource spreadsheet, removed certainty values from core AllergyIntolerance examples, and added the certainty element and reaction-event-certainty binding to the AllergyIntolerance extension spreadsheet. Follow-up commit 5176090fead928103c618a284bb4b930a83ae97e updated the AllergyIntolerance STU note to refer to extension-allergyintolerance-certainty after the move.

Additional context:
AllergyIntolerance is active in the current core build, and its current StructureDefinition reaction backbone contains substance, manifestation, description, onset, severity, exposureRoute, and note, but no reaction.certainty element. The current FHIR Extension Pack contains StructureDefinition/allergyintolerance-certainty scoped to AllergyIntolerance.reaction, plus the reaction-event-certainty code system/value set. Later related audits for FHIR-11022 and FHIR-13459 are already present on the combined branch, and no Confluence evidence was found that conflicts with the Jira/source history.
