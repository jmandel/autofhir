FHIR-48333: Audit Citation language binding scope

Issue request:
FHIR-48333 was Applied/Persuasive for the FHIR-core Citation resource. It asked that Citation language elements stop using a preferred binding to http://hl7.org/fhir/ValueSet/languages and instead follow the normal language pattern: type code, required binding to http://hl7.org/fhir/ValueSet/all-languages, and an additional starter binding to http://hl7.org/fhir/ValueSet/languages.

Initial application:
The Jira comment points to HL7/fhir#3239. The PR merged as 40bf7639b6dc787c9c190fe6cad592e961ffdf84 with the summary "J#48333 changed the valueset for Citation for languages"; its branch commits 9070fa27695da6cf193340d55ddbc0a7c4d85522 and 9adfac2acb5dfcf563c7993efffd167026b32c46 changed source/citation/structuredefinition-Citation.xml so the Citation language elements used code plus a required all-languages binding with languages as a starter additional binding.

Additional context:
The originating Zulip thread identified Citation as the only current core exception to the all-languages pattern, and CDS minutes recorded a 21-0-1 vote to accept the suggested resolution. Later, commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/citation and its active build entries from core along with several other resources; the current source/fhir.ini resource list has no active Citation entry, and the current core tree has no source/citation directory. A read-only Extension Pack check found Citation-related extensions only, not a moved Citation resource definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. FHIR-48333 was applied while Citation was in core, and the current core build no longer contains a Citation resource or Citation language binding to correct. The remaining action is therefore an audit record that the issue is outside the current build scope.

Recommendation:
Keep this audit commit as-is for the current core branch. If Citation is reintroduced into core or maintained in another specification, carry forward the FHIR-48333 language pattern there: code type, required all-languages binding, and starter languages additional binding.
