FHIR-32719: Audit superseded ImagingStudy procedure type

Issue request:
FHIR-32719 was a Published/Persuasive with Modification R5 Imaging Integration request to replace the former ImagingStudy.procedure backbone with a 0..* CodeableReference so the performed procedure could be represented by either a Procedure reference or a procedure code, following the instructions recorded on the Imaging Integration Confluence page.

Initial application:
The issue was applied before this reconciliation. Commit 52a5df179457fea03c4c8e598133c470f4e1de38 changed source/imagingstudy/structuredefinition-ImagingStudy.xml from a BackboneElement with procedure.value[x] to ImagingStudy.procedure as CodeableReference, updated the binding strength, and included FHIR-32719 in its subject. FHIR-38673 later refined the R5 CodeableReference target from Procedure to PlanDefinition/ActivityDefinition.

Additional context:
Later Applied R6 decisions superseded the CodeableReference shape. FHIR-50894 removed the CodeableReference procedure element and moved performed-procedure semantics to ImagingStudy.partOf; FHIR-53025 then reverted that approach and explicitly required ImagingStudy.procedure to identify performed procedures as Reference(Procedure). The combined branch already contains the FHIR-53025 reconciliation commit 4f90e4dc1fc78b042d2991d0bcb589aeefed760e, and current source/fhir.ini actively includes imagingstudy=ImagingStudy.

AutoFHIR reconciliation:
Made no source change. Current active source intentionally defines ImagingStudy.procedure as 0..* Reference(Procedure), the procedure search parameter expression is ImagingStudy.procedure, the XR example uses Procedure/example, and targeted searches found no stale ImagingStudy.procedure CodeableReference/value/concept remnants in the ImagingStudy source.

Recommendation:
Keep this no-change audit. Do not reapply the FHIR-32719 CodeableReference model to the current build unless the work group explicitly revisits the later FHIR-50894/FHIR-53025 decision chain.
