Additional context:

The alias StructureDefinition is present in the FHIR Extension Pack as a CareTeam-scoped string extension with the requested canonical URL and definition. Later search found FHIR-53009, but it is a Submitted, unresolved FHIR-extensions request to change the alias value type, and FHIR-42838, which is a separate NDH IG issue outside FHIR-core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current in-build core search parameter already satisfies the FHIR-20012 request, and the alias extension's absence from core source is expected because the definition now belongs to the Extension Pack.

Recommendation:
Keep this audit commit as-is. Do not re-add the alias StructureDefinition to core; if FHIR-53009 is later accepted, handle that as Extension Pack work and reassess any downstream search-parameter expression typing then.
