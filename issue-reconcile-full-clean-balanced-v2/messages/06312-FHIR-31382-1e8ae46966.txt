FHIR-31382: Audit vital signs value definitions

Issue request:
FHIR-31382 is an Applied FHIR-core OO change request, resolved Persuasive with Modification for R6, asking that Vital Signs profile Observation.value[x] no longer imply blood pressure cuff size can be supplied as the observation value. The approved resolution replaces Observation.value[x] text with "The quantity for the vital sign being observed." and replaces Observation.component.value[x] text with "The value for the vital sign component being observed."

Initial application:
The Jira application comment points to commit e57230c51e. That commit changed source/observation/structuredefinition-profile-vitalsigns.xml by removing the old blood-pressure-cuff-size wording from both Observation.value[x] and Observation.component.value[x] and adding the approved replacement definitions.

Additional context:
The Vital Signs profile source is in current build scope: source/fhir.ini includes Observation as an active resource, and source/observation/implementationguide-Observation-vitalsigns.xml includes StructureDefinition/vitalsigns. The referenced Zulip thread supports the Jira concern because participants clarified that cuff size is a component or separate supporting observation, not the BP Observation.value[x]. OO WGM minutes for 2025-09-15 record FHIR-31382 as applied, and current source searches did not find the old misleading definition text in the Vital Signs StructureDefinition.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current source already contains the approved definitions at Observation.value[x] and Observation.component.value[x], while the remaining cuff-size narrative in the Vital Signs introduction is separate guidance about additional blood pressure component observations and does not recreate the misleading value[x] definition.

Recommendation:
Keep this no-change audit commit as-is. No FHIR-core source follow-up is needed for FHIR-31382 unless OO later decides to revise the broader blood-pressure component-observation guidance independently.
