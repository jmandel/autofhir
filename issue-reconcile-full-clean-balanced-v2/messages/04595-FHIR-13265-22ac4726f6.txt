FHIR-13265: Audit Identifier.use old code

Issue request:
FHIR-13265 was a Published/Persuasive STU3 FHIR-core datatypes change request from MnM asking for Identifier.use to include a code for formerly valid identifier values that should no longer be used. The approved resolution was to add code "old" with the definition "The identifier id no longer considered valid, but may be relevant for search purposes. E.g. Changes to identifier schemes, account merges, etc."

Initial application:
