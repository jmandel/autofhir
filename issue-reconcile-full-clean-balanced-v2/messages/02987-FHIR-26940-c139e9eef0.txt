FHIR-26940: Audit SubstanceDefinition representation type wording

Issue request:
FHIR-26940 was Published/Persuasive for R5 by BRR. It asked to change SubstanceDefinition.structure.representation.type from a structural-representation-only definition to wording that also covered techniques used to derive analytical characterization of the substance, such as x-ray, HPLC, NMR, peptide mapping, and ligand binding assay.

Initial application:
The request appears to have been applied in the 2020 SubstanceDefinition spreadsheet source even though the implementation commit did not mention FHIR-26940 directly: commit ae0d9e06 changed representation-related definitions to include characterization and changed representation.type to include the analytical characterization technique examples requested by the Jira. The current XML source no longer contains that full 2020 wording because later BRR decisions revised the model.

Additional context:
SubstanceDefinition is an active current-build resource in source/fhir.ini. FHIR-32115 was later Published/Persuasive and explicitly removed the characterization-technique half of the SubstanceDefinition.structure.representation.type definition because it duplicated SubstanceDefinition.structure.technique. FHIR-39596 was later Published/Persuasive with Modification and separated characterization into SubstanceDefinition.characterization, leaving structure.representation.type as structural representation only and characterization.technique as the place for characterization techniques such as HPLC. A prior combined-branch FHIR-39596 reconciliation also removed characterization-specific remnants from the structure technique terminology. BRR minutes for 2020-07-28 confirm the original FHIR-26940 approval, and searches found no conflicting Zulip or Confluence discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source is correct after the later published issue family: SubstanceDefinition.structure.representation.type now says only "The kind of structural representation (e.g. full, partial)," while SubstanceDefinition.structure.technique and SubstanceDefinition.characterization.technique carry the technique/characterization concepts that superseded the original placement requested by FHIR-26940.

Recommendation:
Keep this empty audit commit. Do not restore the FHIR-26940 characterization-technique wording to representation.type; doing so would conflict with FHIR-32115 and FHIR-39596. Future characterization terminology work, if needed, should be raised as a separate BRR terminology issue rather than reopening this representation.type definition.
