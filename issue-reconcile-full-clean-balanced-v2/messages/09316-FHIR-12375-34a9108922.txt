Additional context:

AutoFHIR reconciliation:
Changed source/modules-list.html so the link to exchange-module.html is labeled "Exchange", matching source/exchange-module.html, source/modules-fragment.html, source/foundation-module.html, and the current module structure while preserving the existing exchange-oriented description.

Recommendation:
Keep this source fix. It does not reopen the historical Linked Data rename; it removes the remaining stale label after the later Exchange-module rework so the current overview is internally consistent.
