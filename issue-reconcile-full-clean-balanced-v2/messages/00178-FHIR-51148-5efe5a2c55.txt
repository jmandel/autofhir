FHIR-51148: Fix MedicationRequest allergy reason example

Issue request:
FHIR-51148 was an Applied/Persuasive Pharmacy change request for R6 asking to add AllergyIntolerance as an allowed MedicationRequest.reason reference target and to include clinical examples using AllergyIntolerance as the reason for a doNotPerform or alternative medication request.

Initial application:
The issue had already been partly applied before this reconciliation: d86923e778 added AllergyIntolerance to MedicationRequest.reason.targetProfile, and 7d10e89f2c added the medicationrequest0349 and medicationrequest0350 examples and list entries. Those changes were merged through HL7/fhir#3896.

Additional context:
source/fhir.ini lists MedicationRequest as an active built resource, with active maturity/work-group metadata, so source/medicationrequest examples feed the current build. Pharmacy meeting notes from 2025-06-19 and 2025-06-30 support using MedicationRequest.reason for AllergyIntolerance and for the alternative-therapy text reason, while keeping broader premedication/alternative-therapy intent work separate. FHIR-47856 is related background because it confirmed .reason is the place to express doNotPerform reasons, but this commit does not independently decide that broader tracker.

AutoFHIR reconciliation:
This commit keeps the already-applied AllergyIntolerance targetProfile and example set, and fixes the medicationrequest0350 example so all three reasons use the current R6 MedicationRequest.reason CodeableReference shape. It replaces the retired reasonCode element with reason.concept.text and corrects the SNOMED coding display from an invalid Coding.text child to Coding.display.

Recommendation:
Keep this commit as-is. The source now reflects the Applied FHIR-51148 decision without adding speculative new clinical examples or taking over the separate intent/doNotPerform work.
