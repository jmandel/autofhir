FHIR-7044: Audit AllergyIntolerance category other code

Issue request:
FHIR-7044 was a Published/Persuasive with Modification Patient Care issue for the DSTU1 AllergyIntolerance category value set. It asked whether the category code list was complete for substances such as latex that were not food or medication and resolved to add "other" as a category code.

Initial application:
The request was applied historically in git-svn commit a30496dcda9c86251cf286f1636c23e570a80113, whose subject explicitly lists #7044 and says "code Other is added to the category." The patch added an "other" row with definition "Other substances that are not covered by any other category" to the AllergyIntolerance spreadsheet source, and the release2 generated valuesets history shows food, medication, environment, and other for allergy-intolerance-category.

Additional context:
AllergyIntolerance remains an active current-build resource in source/fhir.ini. The current authoritative AllergyIntolerance category element is 0..* code with required binding to ValueSet/allergy-intolerance-category, and its short description lists food, medication, environment, and biologic. The current complete CodeSystem has those four concepts only; its environment definition covers "any substance not already classified as food, medication, or biologic." Later Patient Care decisions revisited the same gap: FHIR-10262 declined a substance category, added biologic, and noted that the build's earlier other code was removed; FHIR-10760 directly proposed substance and other for rubber or animal hair, but resolved instead to broaden environment to cover those cases. FHIR-20049 later concluded an other category was unnecessary because category is optional, and FHIR-45243 resolved a broader request to loosen the current binding as No Change. The Zulip design thread for AllergyIntolerance.category supports the current fixed required FHIR-defined category set used for searching, and no Confluence references for the seed or related core category issues were found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding "other" now would reverse later final Patient Care decisions and would make the current required value set conflict with the environment definition that was explicitly adopted to cover non-food, non-medication, non-biologic substances.

Recommendation:
Keep this audit commit as-is. No core source work is needed for FHIR-7044; any future expansion of AllergyIntolerance.category should come from a new Patient Care decision that explicitly supersedes FHIR-10262, FHIR-10760, FHIR-20049, and FHIR-45243.
