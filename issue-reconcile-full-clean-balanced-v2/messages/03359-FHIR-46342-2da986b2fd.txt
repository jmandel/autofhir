FHIR-46342: Audit SupplyRequest fulfillment link

Issue request:
FHIR-46342 was an Applied OO change request, resolved Persuasive with Modification for R6, asking to replace the SupplyRequest Boundaries and Relationships text so it links implementers from SupplyRequest fulfillment/execution handling to Task and the Fulfillment/Execution section of the Request pattern. Jira comments later confirmed the related BiologicallyDerivedProductDispense link cleanup.

Initial application:
The requested SupplyRequest source update was applied before this reconciliation. Commit b180545c6113d568d8f46f3ad6da789de54d367c replaced the Boundaries and Relationships paragraph in source/supplyrequest/supplyrequest-introduction.xml with the authorization, SupplyDelivery, Task.focus, messaging/workflow, and Request-pattern Fulfillment/Execution language. Commit b7edf24c9afc7a687ccac5df6bc98c93786199e7 then added the BiologicallyDerivedProductDispense link requested during QA. The current checked-in core source still contains that text, but that source is no longer an active core build input.

Additional context:
FHIR-45872 is the same change family's central Request-pattern issue and is already represented on the combined branch. FHIR-51003 corrected earlier wording in the same SupplyRequest paragraph and is also already represented. After FHIR-46342 was applied, commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed SupplyRequest, SupplyDelivery, DeviceDispense, and BiologicallyDerivedProductDispense from active core fhir.ini resource/workgroup/status lists and changed core narrative links to point to the HL7 OO Incubator IG. The current source/fhir.ini has no active SupplyRequest entry, build.fhir.org/supplyrequest.html returns 404, and the HL7/oo-incubator source now includes SupplyRequest as an IG resource with the same fulfillment guidance in input/pagecontent/StructureDefinition-SupplyRequest-intro.xml. Confluence OO minutes record the 2024-11-19 FHIR-46342 vote as Persuasive with Mod, 7-0-0. No Zulip discussion directly referencing FHIR-46342 was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The Jira-approved wording was already applied to the old core SupplyRequest source, and the current active SupplyRequest specification surface is owned by the external HL7/oo-incubator source, where the same Request-pattern Fulfillment/Execution link is present. Editing source/supplyrequest in core would modify inactive source rather than the current built specification.

Recommendation:
Keep this audit commit as-is for core FHIR. Future SupplyRequest wording changes should be made in HL7/oo-incubator, not in the inactive core source/supplyrequest files, unless SupplyRequest is brought back into the active core build.
