FHIR-19243: Remove stale IG package wording

Issue request:
FHIR-19243 was Published/Persuasive with Modification for FHIR-core ImplementationGuide. It asked to rename ImplementationGuide.definition.package to grouping to avoid confusion with NPM packages, and the resolution specifically renamed ImplementationGuide.definition.resource.package to ImplementationGuide.definition.resource.groupingId and called for updated descriptions.

Initial application:
The current source already has the structural rename: ImplementationGuide.definition.grouping and ImplementationGuide.definition.resource.groupingId are the active element paths. However, the Jira-commented commit 6c82a7d4e4ffc589bd92ae82c9e2db27abafdbb4 only touched IG publisher conversion code in this history, and no Git commit mentioning FHIR-19243 was found. Current source still retained package-era wording in grouping.name and grouping.description, and source/fhir.ini still mapped the R3 ImplementationGuide.package path to the removed ImplementationGuide.definition.package path.

Additional context:
FHIR-13405 introduced the pre-rename wording that used "package" for the grouping name/description; that wording became stale after FHIR-19243. The 2018 MnM/FHIR-I WGM minutes record the proposal to rename ImplementationGuide.definition.package to ImplementationGuide.definition.grouping alongside the multi-version IG work in FHIR-18050. Later grouping-related issues such as FHIR-25428/FHIR-28140 changed the description datatype to markdown, and FHIR-25458 kept grouping trial-use while evaluating a future organization approach; none of those later decisions restore the old package terminology. FHIR-25458 is already represented on the combined branch.

AutoFHIR reconciliation:
This commit updates the active ImplementationGuide StructureDefinition descriptions to use grouping terminology, corrects the groupingId comment to reference grouping.id, synchronizes the checked-in ImplementationGuide SVG tooltips with the same wording, and changes the source/fhir.ini R3 rename target from the removed ImplementationGuide.definition.package path to ImplementationGuide.definition.grouping. The ImplementationGuide resource is active in source/fhir.ini, and source/fhir.ini is a build configuration source, so these hunks affect current build inputs. The SVG edits are included only to keep the checked-in diagram surface consistent with the authoritative XML source change.

Recommendation:
Keep this commit as-is. It completes the package-to-grouping cleanup requested by FHIR-19243 without reopening broader IG organization questions that later issues handled separately.
