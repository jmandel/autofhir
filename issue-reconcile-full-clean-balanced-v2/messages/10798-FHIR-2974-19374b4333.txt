FHIR-2974: Audit current examples coverage

Issue request:
FHIR-2974 is a Published/Persuasive FHIR-core FHIR-I change request from the Initial Draft/DSTU1 era. It asked for an Examples tab for the old "Tags, Bundles, Compartments and Binary Resources" extras section so implementers could find XML and JSON examples for tags, bundles, compartments, and Binary resources.

Initial application:
The Jira comments record that references to existing examples should be added and cite svn revisions 3083 and 3084. Converted git history contains those applications as 2f90dba297ecb405b31de9bc7a6cd673872dd448 and 08db2f4f096142be620f434ef423284ef7f22aa5, both titled "{#2976} and {#2974}: add examples for tag list, bundles, binary resources". Revision 3083 wired an Examples child page into the old extras page hierarchy, and revision 3084 added source/extras-examples.html with tag/taglist, Bundle, and Binary example references.

Additional context:
The old FHIR-core-extras page and extras tab structure no longer exist in current source. Later source migration split the material into current active resource pages: Bundle, Binary, and CompartmentDefinition are active resources in source/fhir.ini and each has a list-*-examples.xml file. TagList/taglist was later retired when atom/taglist wrappers were replaced by native Bundle and resource metadata; current tag guidance is on the Resource page through Resource.meta.tag and the _tag search parameter. Related combined-branch audits for FHIR-2976 and FHIR-5667 already cover the retired TagList examples and stale extras title/tab structure.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build already has example lists for the active Bundle, Binary, and CompartmentDefinition resources, the old FHIR-core-extras page is gone, and reintroducing an Examples tab or TagList examples would be stale rather than corrective.

Recommendation:
Keep this no-change audit commit as-is. No current FHIR core source follow-up is needed for FHIR-2974 unless a future generated publication surface shows that the active resource example lists are not rendering as intended.
