FHIR-11147: Audit ActivityDefinition workflow ownership

Issue request:
FHIR-11147 was a Published/Persuasive with Modification DSTU2 request to move ActivityDefinition from the Clinical Decision Support work group to the workflow work group because ActivityDefinition supports broader workflow, order, catalog, and collaboration use cases beyond decision support.

Initial application:
No commit explicitly mentions FHIR-11147. The Jira comment says ActivityDefinition was recategorized as Workflow by Lloyd's changes. The closely related applied issue FHIR-10683 was implemented in SVN 11382 / git bd1507dafa96568bf37503ff029bbabe8c3d8be2, which updated CDS resource workflow mappings and added the ActivityDefinition sentence identifying it as a FHIR Workflow definition resource. Lloyd's later 2017 workflow-module update 6a96b06674a4d5b68f27d9dc43227505f3c703b1 strengthened the Workflow module's ActivityDefinition/PlanDefinition discussion.

Additional context:
The FHIR-11147 resolution did not approve transfer of resource ownership to a separate Workflow work group; it states that Workflow is a task force, not a specific working group that could own resources, and that CDS would coordinate with that task force. The current build keeps ActivityDefinition active, owned by CDS in fhir.ini and the StructureDefinition wg extension, while the ActivityDefinition introduction and Workflow pages present ActivityDefinition from the Workflow definition perspective. FHIR-11232 made the same request for both PlanDefinition and ActivityDefinition and has already been audited on the combined branch; FHIR-11148 made the sibling PlanDefinition request and has also already been audited.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The current source matches the final decision: CDS remains the responsible work group, and the workflow perspective is already represented in ActivityDefinition's introduction and in Workflow module/page content.

Recommendation:
Keep this audit commit as-is. Do not change ActivityDefinition's StructureDefinition workgroup metadata to a non-existent Workflow group for this issue; any future resource ownership transfer would need a new formal work-group/FM G decision. Further editorial changes to workflow or clinical reasoning presentation can be handled separately, but they are not required for FHIR-11147.
