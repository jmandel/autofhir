FHIR-7846: Audit MedicationStatement route v2 mapping removal

Issue request:
FHIR-7846 is a Published/Persuasive Pharmacy issue for the DSTU1 MedicationStatement v2 mapping page. It asked to remove the MedicationStatement route mapping to RXR-1-Route because MedicationStatement is a reported medication-use record rather than a v2 medication transaction concept where RXR-1 route would normally map.

Initial application:
The issue appears to have been applied during the DSTU QA process in git commit 5bb461af10, a batched v2 mapping update for MedicationDispense and MedicationStatement. That commit removed the historical MedicationStatement route v2 mapping line "RXR-1-Route" from the spreadsheet source along with neighboring MedicationStatement v2 mappings.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. The current authoritative source is source/medicationstatement/structuredefinition-MedicationStatement.xml, not the retired spreadsheet, and its MedicationStatement-specific v2 mappings contain only the mapping identity and a subject mapping to PID-3; there is no MedicationStatement route or RXR-1 mapping to remove. Current dosage details are represented through DosageDetails and the generic Dosage datatype still has a general Dosage.route RXR-1 mapping for dosage-bearing contexts, but FHIR-7846 was about the MedicationStatement resource-specific mapping and does not justify removing the generic datatype mapping.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current MedicationStatement source already omits the RXR-1 route v2 mapping requested by FHIR-7846, and changing the generic Dosage mapping would overreach the issue request.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-7846 unless a future Pharmacy decision explicitly revisits whether generic Dosage v2 mappings should be specialized or suppressed for MedicationStatement.
