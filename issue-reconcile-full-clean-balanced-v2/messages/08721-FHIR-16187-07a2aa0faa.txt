FHIR-16187: Audit Observation referenceRange type binding

Issue request:
FHIR-16187 was a Published/Persuasive OO change request raised against STU3 Observation. It asked to change the terminology binding strength for Observation.referenceRange.type from extensible to preferred so implementers could use appropriate standard clinical terminology for reference-range qualifiers.

Initial application:
The request appears to have been applied in the historical GF#16187 source commit 2ebd7c6f7fc99b6938d5a223685af7907288d11c, which changed the ObservationRangeMeaning binding row in source/observation/observation-spreadsheet.xml from extensible to preferred. The 2021 build-core source refactor 33b409a4b6d544598262f2f074ebb4b6dc466157 migrated the Observation definition into source/observation/structuredefinition-Observation.xml and preserved the preferred binding.

Additional context:
Observation is an active resource in source/fhir.ini, so source/observation/structuredefinition-Observation.xml is in current build scope. FHIR-11115 established the earlier split from referenceRange.meaning into type and appliesTo with type initially extensible; FHIR-16187 is the later binding-strength adjustment for that type element. The same ballot discussion mentioned FHIR-16185, FHIR-16186, and FHIR-16350, but those have separate dispositions and do not require a source change for this issue. ObservationDefinition.qualifiedValue.context currently uses the same value set with an extensible binding, but it is a separate resource/element and was not the element requested by FHIR-16187.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active Observation StructureDefinition already has Observation.referenceRange.type bound to http://hl7.org/fhir/ValueSet/referencerange-meaning with strength preferred, matching the published Jira resolution.

Recommendation:
Keep this empty audit commit as-is. No FHIR core source follow-up is needed for FHIR-16187 unless a future OO decision broadens the issue to other ObservationDefinition qualified-value elements.
