FHIR-26836: Audit removed HL7 v2 value set tab

Issue request:
FHIR-26836 was a Published/Persuasive technical correction against the R4 Terminologies > Value Sets page. It reported that the old HL7 V2 tab showed value set URI prefixes as http://terminology.hl7.org/CodeSystem/v2-*/* when they should have used http://terminology.hl7.org/ValueSet/v2-.

Initial application:
No commit explicitly mentioning FHIR-26836 was found. The relevant source appears to have been implicitly superseded before the issue was published: git commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed the HL7 v2 and HL7 v3 value-set tabs, including the v2VSIndex placeholder, from source/terminologies-valuesets.html as part of moving UTG content out of the core build. The first R4B draft commit c69d71aa213de86d55e0261339c15e4bacd509e6 likewise carried the page without the old tab.

Additional context:
The seed Jira's later comment says the typo was no longer relevant because R4B would point to terminology.hl7.org. FHIR-I minutes from 2021-02-22 record the tracker as a technical correction, and later FHIR-25896 clarified the same Value Sets page to say that value sets defined in HL7 Terminology outside the core specification are not listed in this table.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source/terminologies-valuesets.html page contains only the core valuesetslist placeholder and explanatory text excluding HL7 Terminology value sets outside core; source/hierarchy.xml and publish.ini keep the page in the current build, but the old HL7 v2 value-set tab and v2VSIndex placeholder are absent. Current source and the CI-build page do not contain the erroneous ValueSet-page prefix pattern from the Jira request.

Recommendation:
Keep this audit commit as-is. Reintroducing a local correction would be wrong because the source location that contained the typo no longer exists in the current build; any ongoing HL7 v2 value set URI behavior belongs to HL7 Terminology/THO, not to the core Value Sets page.
