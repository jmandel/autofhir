FHIR-47275: Audit ImagingStudy scope boundary

Issue request:
FHIR-47275 was Applied as Persuasive with Modification for R6 by Imaging Integration. It asked to clarify the overlap between ImagingStudy and ImagingSelection because both could appear to identify only part of a DICOM study, with the accepted resolution removing the statement that ImagingStudy may reference study subsets, clarifying the boundary text on both resource pages, and treating the detailed series/instance wording as all known study content rather than a clinical selection.

Initial application:
The issue was applied by git commit 41a56bc14a79c48331002fc4e745c744208335d5, linked from Jira via HL7/fhir#3221, which edited source/imagingstudy/imagingstudy-introduction.xml and source/imagingselection/imagingselection-introduction.xml. Later related ImagingStudy description commits, including FHIR-47662, FHIR-47664, and FHIR-47674, supplied the current known-series/count and Series/SOP Instance wording in the authoritative StructureDefinition source.

Additional context:
source/fhir.ini lists both ImagingSelection and ImagingStudy as active resources, so their source folders are current build scope. The September 2024 II minutes record the same FHIR-47275 actions and explicitly split the older use-case concern into FHIR-48402. FHIR-47619 is the same boundaries change family and resolves by reference to FHIR-47275, while later FHIR-54814 refined the same boundary paragraph by stating that ImagingSelection.derivedFrom references the ImagingStudy when the images were selected from it. A direct Zulip/key search found no conflicting discussion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current ImagingStudy prose says one ImagingStudy references one DICOM Study, can change as study information is added, and stores details of an entire DICOM Study; current ImagingSelection prose says it references a subset of a DICOM Study for a specific clinical purpose and is unlikely to change once created. The stale subset-permission text is absent, Observation guidance now distinguishes ImagingStudy from ImagingSelection by identified subsets, and the active StructureDefinition count/series definitions no longer support using ImagingStudy as a clinical subset selection.

Recommendation:
Keep this audit commit as-is. No FHIR-47275 source follow-up is needed in core; related applied issues such as FHIR-47619 and FHIR-48402 can be audited separately if desired, but they do not require another source change for this seed.
