FHIR-7207: Audit LOINC answer-list ValueSet guidance

Issue request:
FHIR-7207 was a Published, Not Persuasive with Modification DSTU1 Vocabulary change request objecting to ValueSet URLs for answer lists and asking that FHIR not rely on free-standing answer-list ValueSets without clearer guidance. The accepted resolution was to document how to refer to LOINC answer-list value sets.

Initial application:
The Jira comments record SVN revision 5714. The matching git-svn commit 3cf763faaf84d15ea710026a46b713fbbcf1648a added a Questionnaire source comment for the answer-list ValueSet element saying that LOINC defines useful value sets for questionnaire answers and linking to LOINC Answer Lists. Later source migration kept that guidance in the current StructureDefinition source.

Additional context:
Questionnaire is an active current-build resource in source/fhir.ini. The current terminology page still lists Questionnaire.item.answerValueSet as the place where answers to questions can come from a value set, while the authoritative Questionnaire source now uses the modern answerValueSet name and links to the THO LOINC page rather than the old core loinc.html anchor. Related Questionnaire answer-list audits already on the combined branch confirm that ValueSet-based, contained, and reusable answer choices remain current behavior. Later LOINC-answer-list issues such as FHIR-9687 and FHIR-49027 concern separate cleanup of bogus answer-list code systems or example URLs, not the FHIR-7207 documentation request.

AutoFHIR reconciliation:
This audit intentionally makes no source change. The active current source already documents LOINC answer-list ValueSets on Questionnaire.item.answerValueSet and explains when answerValueSet, inline answerOption, contained ValueSets, and version-specific ValueSet references are used, so additional prose would be redundant and could drift from the maintained Questionnaire guidance.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source follow-up is needed for FHIR-7207 unless a future Vocabulary or FHIR-I decision changes how LOINC publishes or identifies answer-list ValueSets.
