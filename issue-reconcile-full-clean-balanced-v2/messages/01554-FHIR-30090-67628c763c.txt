Issue request:
FHIR-30090 was a Published/Persuasive Pharmacy change request raised against R4 and applied for R5. It asked to add MedicationKnowledge.administrationGuideline.administrationTreatment as a 0..1 CodeableConcept for the drug administration procedure or treatment type the guideline applies to, with an example SNOMED CT descendants-of-18629005 value set.

Initial application:
The grouped MedicationKnowledge application commit 1683ac64141af807564d62a28932d70133142fb3 added administrationTreatment while applying the related R5 refactor from administrationGuideline to indicationGuideline/dosingGuideline. The follow-up commit bd0883f3912523b0e63ae2a99a8a3a5b353c50a2 corrected the nesting so the element became MedicationKnowledge.indicationGuideline.dosingGuideline.administrationTreatment. The surviving stale source has the requested 0..1 CodeableConcept element, but it does not carry the requested example binding.

Additional context:
MedicationKnowledge is no longer an active resource in the current core build. Commit 5a4307d78b0209f61bbc68d582c1e190b3aaee5c removed MedicationKnowledge from source/fhir.ini resource/build entries, while leaving some orphaned source files and metadata. The current CI build returns 404 for medicationknowledge.profile.json, and the FHIR Extension Pack checkout does not contain a maintained MedicationKnowledge resource source file. Catalog minutes from February and March 2021 record that the MedicationKnowledge change batch, including FHIR-30090, had been accepted and applied by Pharmacy.
