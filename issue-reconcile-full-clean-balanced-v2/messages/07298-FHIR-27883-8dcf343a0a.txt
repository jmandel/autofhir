FHIR-27883: Audit CQL expression media types

Issue request:
FHIR-27883 was a Published/Persuasive with Modification FHIR-core issue for R5 asking to add the CQL expression-language media types to ExpressionLanguage after CQL introduced an identifier media type for references to library definitions. Its final resolution changed the requested dotted names to IANA-registered dashed media types, required text/cql-identifier and text/cql-expression in the FHIR MIME type expansion, and required ExpressionLanguage to draw from the BCP 13 MIME type code system rather than a FHIR-specific expression-language code system.

Initial application:
The issue was explicitly applied by commit 450cf3e64ae3d71ae6c027d39327311afdfc1986, which cites J#27883 and added source/datatypes/valueset-expression-language.xml as a BCP 13-based value set while removing the generated ExpressionLanguage code-system approach. That first application used the then-requested text/cql.identifier code.

Additional context:
The originating Zulip thread confirms the reason for the change: Measure and PlanDefinition content needed a way to distinguish references to named CQL definitions from inline CQL, and Grahame Grieve directed the value set to reference urn:ietf:bcp:13 instead of an internal code system. FHIR-I minutes from 2021-01-04 record the final Persuasive with Modification vote, including the already-removed code system, changing the existing value set, and adding two FHIR MIME type expansion items. Later Published issue FHIR-36496 corrected the dotted CQL media type to text/cql-identifier and added text/cql-expression, matching the final IANA registration language now recorded on FHIR-27883. FHIR-36705 later aligned Expression.language maxBinding to the all-media-types value set and is already represented on the combined branch.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the current build-scoped ExpressionLanguage value set includes text/cql, text/fhirpath, text/x-fhir-query, text/cql-identifier, and text/cql-expression from urn:ietf:bcp:13; the old dotted CQL media types and expression-language code system are absent from current source; source/fhir.ini keeps the MIME type value set active; and the active Expression datatype spreadsheet binds Expression.language through valueset-expression-language with the current all-media-types max binding.

Recommendation:
Keep this audit commit as-is. The current source already reflects the final FHIR-27883 decision as refined by FHIR-36496 and FHIR-36705, so reopening the seed would risk reintroducing obsolete dotted media types or duplicating already-applied terminology work.
