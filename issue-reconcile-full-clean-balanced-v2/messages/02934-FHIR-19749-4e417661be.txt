FHIR-19749: Audit MedicationDispense.receiver Location support

Issue request:
FHIR-19749 was a Published FHIR-core Pharmacy change request for MedicationDispense.receiver, raised against STU3 and applied for R5. The request asked to allow Organization and HealthcareService for aged-care delivery scenarios, but the approved Persuasive with Modification resolution was to add Location instead.

Initial application:
The Jira records application by commit aa42e5dcc1e780bf1fa001dc784d2801f6d3b1d4 on 2019-02-18. That merge changed the then-authoritative medicationdispense-spreadsheet.xml receiver type from Reference(Patient|Practitioner) to Reference(Patient|Practitioner | RelatedPerson | Location) and updated the short and long definitions to describe delivery location use.

Additional context:
MedicationDispense is an active resource in source/fhir.ini, and the current generated/source StructureDefinition carries the receiver element in source/medicationdispense/structuredefinition-MedicationDispense.xml. Later applied source history added Group (FHIR-41408) and Organization (FHIR-50109) to the same receiver target list; FHIR-50109 is already represented on the combined branch, so this audit does not duplicate it. Pharmacy meeting minutes for 2018-12-17 match the Jira resolution and record the motion to add Location rather than Organization or HealthcareService for FHIR-19749. Zulip and direct Confluence Jira-reference searches found no conflicting FHIR-19749 discussion.

AutoFHIR reconciliation:
No source change was made. The current active receiver definition includes Location as a target profile and says the receiver may be where medication was delivered, satisfying the approved FHIR-19749 resolution. The later Organization support is governed by FHIR-50109 rather than by this seed issue.

Recommendation:
Keep this audit commit as-is. No FHIR-core source follow-up is needed for FHIR-19749 unless the Pharmacy work group separately revisits the broader HealthcareService/Organization question under another applied issue.
