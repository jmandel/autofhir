FHIR-11207: Audit AllergyIntolerance entered-in-error note

Issue request:
FHIR-11207 was a Published/Persuasive Patient Care clarification for AllergyIntolerance from DSTU2. It asked to replace wording that said allergies with status "entered-in-error" were inactive allergies with wording that says the allergy or intolerance statement was entered by mistake and is invalid.

Initial application:
The issue was applied in git commit e7c9c0d32a1b91ac406c98fd0a2441fec2c625fb, which replaced the old inactive-allergies sentence in source/allergyintolerance/allergyintolerance-notes.xml with the requested invalid-statement wording. Commit ed170ff0754268f2a677a011f9d432d1328415f0 later split the old combined status into verificationStatus and clinicalStatus in that note as part of FHIR-11151, and commit fd29fa2cbf5790eb72afa4ee2027327b4af2e397 made only grammar updates.

Additional context:
source/fhir.ini actively lists allergyintolerance=AllergyIntolerance, so the AllergyIntolerance source remains in current build scope. The current narrative says verificationStatus "entered-in-error" means the allergy or intolerance statement was entered by mistake and is invalid. The StructureDefinition also records entered-in-error through AllergyIntolerance.verificationStatus, says clinicalStatus should be present only when verificationStatus is not entered-in-error and the code is not negated, and labels verificationStatus as the modifier for refuted/entered-in-error validity. Related FHIR-11206 and FHIR-11151 explain the same status-family cleanup and do not require additional seed-source changes.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The obsolete inactive-allergies wording is gone from build-scope AllergyIntolerance source, and the current source communicates the requested semantics without adding redundant prose.

Recommendation:
Keep this audit commit as-is. No further core FHIR source work is needed for FHIR-11207 unless Patient Care later chooses to reopen broader AllergyIntolerance status guidance.
