FHIR-15830: Audit logical model type publisher fix

Issue request:
FHIR-15830 was a Published/Persuasive FHIR-core change request from STU3 reporting that the IG Publisher emitted unresolved-reference errors when an ElementDefinition.type.code contained the absolute URI of another logical model, even though the intended modeling was an embedded logical-model type rather than a Reference.

Initial application:
The Jira comments record that the reporter confirmed the error was fixed in the same-day build and Grahame identified svn revision 13543. The corresponding git-svn commit is 25b1e21b49d7b43a8ae1abcac29f9e14ddc39f5b, "improve support for logical model type references", which changed the old in-repository Java validation, element model, FHIRPath, ShEx, and IG Publisher helper code to resolve absolute StructureDefinition URLs instead of always prefixing the core StructureDefinition namespace.

Additional context:
The underlying specification allowance came from FHIR-12245, which changed ElementDefinition.type.code to URI and allowed absolute URLs in logical models. Current active source still reflects that rule: ElementDefinition.type.code says absolute URLs are only allowed in logical models, StructureDefinition has the sdf-19 constraint limiting custom type codes to logical models, and its type-code binding description includes logical model types. The old Java IG Publisher/implementation paths touched by svn revision 13543 are no longer active files in this FHIR checkout, so any remaining publisher behavior would belong to the current external tooling repository rather than this spec source tree.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical fix was applied to the relevant publisher/tooling implementation, and the current FHIR source already preserves the logical-model type-code semantics needed by the issue.

Recommendation:
Keep this audit commit as-is. If a modern IG Publisher regression is reported, handle it in the current IG Publisher/FHIR Java tooling project; no FHIR core source edit is indicated for FHIR-15830.
