FHIR-13864: Audit search-parameters download generation

Issue request:
FHIR-13864 was a Published/Persuasive FHIR-core SearchParameter correction for STU3. It reported that build.fhir.org/search-parameters.xml, and the equivalent JSON download, were out of date because generated SearchParameter instances did not include the SearchParameter comparator or modifier elements.

Initial application:
The Jira comment identifies SVN revision 14532. In the Git history this is commit f25a484e20387684e12152c5625b387c453dd71f, "GF#13864 + GF#16001 + GF#17481 - fix errors generating search parameters," which changed the search-parameter generation code to add generated comparator and modifier declarations and updated the SearchParameter model/source spreadsheet.

Additional context:
SearchParameter remains an active resource in source/fhir.ini, and the current SearchParameter StructureDefinition still defines both SearchParameter.comparator and SearchParameter.modifier. However, FHIR-20470 later reached Published/Persuasive and specifically removed generated AND/OR and modifier declarations from core SearchParameter instances so those base definitions could be constrained by IGs and capability statements. Its implementation commit, 50c62d61d20ddacb5f2cfe86a5101bb5dbadaf41, left generated comparators in place but disabled generated modifiers.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current generated build download includes comparator elements, while modifier elements are absent in a way explained by the later FHIR-20470 decision rather than by an unapplied part of FHIR-13864.

Recommendation:
Keep this no-change audit. If the work group wants core SearchParameter downloads to declare modifier support again, that should be a new or reopened decision revisiting FHIR-20470 rather than a source fix for this STU3 tracker.
