FHIR-55796: Audit Provenance verify example

Issue request:
FHIR-55796 was an Applied/Persuasive with Modification R6 Security WG change request for FHIR-core Provenance. It noted that the example Provenance.activity ValueSet includes verify and that, like delete, a verification-only Provenance can be unclear about Provenance.target equaling Provenance.entity.what when the verification evidence is held in the Provenance. The final resolution was to add a Verify example following the Remove/Delete example.

Initial application:
The issue was applied before this reconciliation by commit 1b721a8ea9cdce4b9a14ebfb5e8c0f21e68099c8, "FHIR-55796 - Provenance of verify," which added a Provenance verification example with activity code verify and matching target/entity.what references. The change was included in merged PR HL7/fhir#4066. A later same-PR commit, ca28eb99e94284bd0f890882396c0aa9f372ba16 for FHIR-54833, renamed the file to source/provenance/provenance-example-verify.xml, changed the resource id to example-verify, and inserted the build-scoped source/provenance/list-Provenance-examples.xml entry for Provenance/example-verify.

Additional context:
source/fhir.ini has an active provenance=Provenance resource entry, so the source/provenance example file and examples List are in current build scope. Security WG minutes for 2026-03-30 list FHIR-55796 in the FHIR Core Block Vote 1 table with the same resolution and record the remaining block motion passing 7-0-0. The adjacent patient-merge Provenance example from FHIR-56165 is already represented by a separate AutoFHIR audit commit on the combined branch; it is context for the verification example's patient-merge scenario but does not change the FHIR-55796 request. Direct Zulip searches for FHIR-55796 and Provenance verify/patient-merge terms found no conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already contains source/provenance/provenance-example-verify.xml with Provenance.activity code verify and matching Provenance.target and Provenance.entity.what references, and source/provenance/list-Provenance-examples.xml exposes it as Provenance/example-verify.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-55796 unless future Security WG review wants a different verification scenario or additional narrative beyond the approved example.
