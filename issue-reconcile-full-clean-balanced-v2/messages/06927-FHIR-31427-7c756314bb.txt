Initial application:

Additional context:
FHIR-29636 is the earlier Task.basedOn/Task.focus clarification that added the current Task.basedOn usage note and Task.focus definition, so FHIR-31427 should be interpreted as a cleanup to that same definition family rather than a new semantic change. Later R6 Task.focus changes, including FHIR-33388 and FHIR-49108, made focus a repeatable backbone with value[x] Reference/canonical support, but current Task prose still consistently talks about Task.focus as the high-level focus element and the FHIR-31427 example remains a Reference-to-request-resource case.

Recommendation:
