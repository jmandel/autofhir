FHIR-39574: Audit GenomicStudy markdown externalization

Issue request:
FHIR-39574 was Published/Persuasive for R5 and asked Clinical Genomics to change GenomicStudy.description from string to markdown, then add implementation guidance showing how genomic strings such as CYP2D6 star alleles can be escaped or delimited so markdown rendering does not remove clinically meaningful characters.

Initial application:
The request was applied in core before R5 publication. Commit e483c823055be8fcdd9e5fb54338a6ff11db4a2f changed source/genomicstudy/structuredefinition-GenomicStudy.xml from string to markdown and added source/genomicstudy/genomicstudy-notes.xml guidance with the three requested example approaches. PR #2654 merged that application as 62915e19f23eaf19010cfbaeff0ea74a182e0598.

Additional context:
Current core no longer builds GenomicStudy as an active resource. The active source/fhir.ini no longer lists GenomicStudy, and commit fad1b9cf84ef652e88947e1a13b026c62f95334e removed GenomicStudy from the active resource, work-group, FMM, status, and abbreviation registries while changing core module pages to point at the Clinical Genomics incubator IG. The current external cg-incubator package still exposes GenomicStudy.description as markdown, but its packaged profile does not contain the R5 core implementation-note examples.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Editing source/genomicstudy would not affect the current core build, and adding redundant core narrative beside the external incubator link would not correct the external GenomicStudy profile. The remaining preservation question for the markdown examples belongs to the Clinical Genomics incubator IG, not this core checkout.

Recommendation:
Keep this external-repo audit commit for the core reconciliation. If the work group wants the FHIR-39574 examples to remain visible for current GenomicStudy users, file or apply a follow-up in the HL7/cg-incubator source to restore the Handling markdown guidance; no core source edit is warranted unless GenomicStudy returns to the active core build.
