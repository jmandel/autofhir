FHIR-37971: Audit ISO 3166 2-letter value set CLD

Issue request:
FHIR-37971 was Published/Persuasive for R5 by Vocabulary. It reported that the ISO 3166 Part 1 2-letter value set was defined extensionally while the neighboring 3-letter and numeric ISO 3166 value sets were intensional, and asked for the 2-letter CLD to include codes from urn:iso:std:iso:3166 where code matches the regex [A-Z]{2}.

Initial application:
The issue was applied by git commit 6331a8ed4511453b1ab875cdaeab1588febe3f70, "Applied FHIR-37971", which removed the fixed country-code enumeration from source/terminologies/valueset-iso3166-1-2.xml and replaced it with a ValueSet.compose.include.filter on code regex [A-Z]{2}.

Additional context:
source/fhir.ini actively includes iso3166-1-2=terminologies\valueset-iso3166-1-2.xml, so the inspected XML is in the current build. The source now matches the same intensional pattern used by valueset-iso3166-1-3.xml and valueset-iso3166-1-N.xml. The Jira resolution text contains a likely URL typo naming iso3166-1-3, but the issue description, Vocab tracker-call comment, Confluence minutes, and implementation commit all identify the 2-letter value set as the intended target. FHIR-39157 is a later same-family Applied issue about erroneous expansion output from the terminology server; its final resolution says that tooling/publication, not this source CLD, was resolved.
