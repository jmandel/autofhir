FHIR-47276: Audit async-bundle format migration

Issue request:
FHIR-47276 was Applied/Persuasive for FHIR-core async-bundle. It asked to clarify that the first entry of the completed async Bundle is the outcome of the requested FHIR operation, not the initial kick-off response, and to identify the relevant Bundle.entry[0].response and resource fields.

Initial application:
The issue was applied in HL7/fhir PR #3211, merged as 2d3dbef772b8185b722a8b6d7279aa25ff58306d. The implementation commit 38182bb49ab298faceb8522ec6686df7ba7cf854 changed source/async-bundle.html by adding the requested FHIR-operation outcome paragraph, field list, and note distinguishing it from the initial 202 Accepted kick-off response.

Additional context:
FHIR-47277 subsequently changed the same status-response paragraph's SHOULDs to SHALLs from a branch that still contained the old "outcome of the kick-off request" sentence, leaving both the new FHIR-47276 clarification and the stale sentence in source/async-bundle.html before the page was removed from core. Commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd later deleted source/async-bundle.html during R6 normative changes and changed core async pages to delegate detailed async patterns to the API Incubator. The current FHIR core checkout no longer contains the detailed async-bundle text, while HL7/api-incubator-ig contains input/pagecontent/async-bundle.html with the FHIR-47276 clarification and the stale follow-on sentence. The current rendered API Incubator URL used by core returns 404, so publication/link cleanup also belongs to that external path.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source was changed because restoring or editing source/async-bundle.html would reintroduce a page that is no longer in the current core build scope, and the remaining text cleanup for FHIR-47276 belongs in the API Incubator source/publication path.

Recommendation:
Keep this audit as-is for FHIR core. Follow up in the API Incubator repository/publication process to remove the stale "outcome of the kick-off request" sentence from input/pagecontent/async-bundle.html after the FHIR-47276 clarification, and to repair the current API Incubator rendered links if that IG remains the intended home for the detailed async patterns.
