FHIR-14745: Audit performer function description

Issue request:
FHIR-14745 was a Published/Persuasive Pharmacy change request for STU3 MedicationAdministration. It asked to improve MedicationAdministration.performer.function because the old description, "Who performed the administration and what they did," described the performer backbone/actor rather than the function; the final resolution was to change the description and definition to match workflow.

Initial application:
The Jira comment records application in git commit 73c779d3aeb5a6120955eb499d67727c2fdfdf47. That commit changed the MedicationAdministration spreadsheet source for performer.function from "Who performed the administration and what they did" / "Distinguishes the type of performer in the administration" to "Type of performance" / "Distinguishes the type of involvement of the performer in the medication administration," while separately clarifying performer and performer.actor.

Additional context:
MedicationAdministration remains an active current-build resource in source/fhir.ini. The current StructureDefinition source keeps MedicationAdministration.performer.function as a CodeableConcept with short "Type of performance," a definition about the type of involvement of the performer, and a binding description about the role an individual played. The current Event pattern also uses "Type of performance" for Event.performer.function. Later same-element ballot issue FHIR-46960 asked whether the short should instead say "type of performer" or "type of role" and was resolved Not Persuasive/Resolved - No Change because Pharmacy wanted to keep the inherited Event-pattern wording in sync.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source no longer has the stale "who performed" description on performer.function, preserves the applied FHIR-14745 clarification, and is consistent with the later no-change decision for the same wording.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-14745 unless a future work-group decision reopens FHIR-46960 or otherwise changes the Event-pattern wording.
