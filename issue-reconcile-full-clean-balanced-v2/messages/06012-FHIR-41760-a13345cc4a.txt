FHIR-41760: Audit MedicationStatement author element

Issue request:
FHIR-41760 was an Applied/Persuasive Pharmacy R5/R6 issue asking whether MedicationStatement.informationSource should be broadened to mean asserter or author, or whether a separate asserter/author element should be added. The final resolution states that informationSource is the source of the information, not the author, and that MedicationStatement.author should be added because the author can be important enough to appear on the resource.

Initial application:
The issue was applied by git commit 6f3b7f9adb474ef110338f51ec20bc616ef73f12, which added MedicationStatement.author to source/medicationstatement/structuredefinition-MedicationStatement.xml as a 0..1 Reference to Practitioner, PractitionerRole, Organization, Patient, RelatedPerson, or Device. The combined branch already contains that source commit but did not contain an AutoFHIR Issue-Reconcile-Key audit commit for FHIR-41760.

Additional context:
FHIR-5508 is the earlier Pharmacy decision that added MedicationStatement.informationSource instead of author for medication reconciliation source tracking. FHIR-41760 is a later and more specific decision that preserves that meaning while adding a distinct author element. FHIR-41500 and the existing AutoFHIR reconcile commit on the combined branch further updated informationSource wording to "Who or what" after Device and Group became allowed information-source targets.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active MedicationStatement StructureDefinition contains both the requested author element and the separate informationSource element with non-author semantics.

Recommendation:
Keep this audit commit as-is. No additional core source work is needed for FHIR-41760 unless Pharmacy later changes the author target profiles or asks to add narrative beyond the authoritative element definitions.

Issue-Reconcile-Decision: no-change
