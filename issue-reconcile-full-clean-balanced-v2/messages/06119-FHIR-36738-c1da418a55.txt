FHIR-36738 was a Published/Persuasive FHIR-core clarification for R5 asking that modifier-extension documentation explain how to define a modifier extension and that StructureDefinition documentation explain how root ElementDefinition entries carry type-wide characteristics such as cardinality and definition text.

Initial application:

Additional context:
