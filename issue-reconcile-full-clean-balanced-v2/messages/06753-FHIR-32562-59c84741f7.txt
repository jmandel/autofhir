FHIR-32562: Audit Device.type multiple-type clarification

Issue request:
FHIR-32562 is a Published FHIR-core Device change request resolved Persuasive with Modification for R5. It asked for Device.type to better explain when a device should send multiple type repetitions rather than multiple codings in one repetition, with the approved clarification that multiple device types are used when a device is categorized in more than one context, such as a hybrid gateway/sensor device.
