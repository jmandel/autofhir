FHIR-47280: Audit subscription terminology disambiguation

Issue request:
FHIR-47280 is Applied/Persuasive with Modification for R6. It reported that subscription-related pages used overlapping terms such as Subscriptions, Subscriber, Subscription resource, Subscription Framework, active Subscription, and SubscriptionTopic in ways that made the text harder to parse. The approved resolution was to consolidate terminology where possible, update relevant headings and resource-page wording, add relevant terms to the FHIR Glossary, and add a disambiguation glossary to the Subscription Framework page.

Initial application:
The issue was applied before this reconciliation in git commit fc659be95edf49f9c1bcc4dfb2f9a631ea45e06a, linked from Jira through HL7/fhir#3967. That commit added glossary entries for Subscription Framework, Subscriber, and Subscription Provider in source/help.html and added a Subscription Terminology Disambiguation section to source/subscriptions.html. It also reworked the Subscription Framework page prose so resource names and actor terms are more explicit. The combined branch already contains that source commit, but did not contain an Issue-Reconcile-Key audit commit for FHIR-47280.

Additional context:
The active core build includes Subscription, SubscriptionStatus, and SubscriptionTopic as FHIR-owned resources in source/fhir.ini, and source/subscriptions.html is the current Subscription Framework narrative page. FHIR-I minutes for 2025-03-31 record the Subscriptions block vote, including FHIR-47280, approved 17-0-0. A later separate reconciliation for FHIR-47282 used the Subscription Provider actor term from this issue to complete one notification sentence, so the current page now aligns its actor wording with the disambiguation glossary. Zulip searches found the block-vote announcement but no separate substantive discussion that changed the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/subscriptions.html already contains the requested disambiguation glossary and formatting guidance, current source/help.html contains the added FHIR Glossary terms, and the active subscription resource family remains in build scope. Remaining title-cased workflow headings such as "Creating a Subscription - In-Band Managed" are not a material defect because the nearby prose and linked resource references make clear when the Subscription resource is meant, and the disambiguation section explicitly notes that headings use title casing rather than the capitalization conventions.

Recommendation:
Keep this audit commit as-is. No additional core source edit is needed for FHIR-47280 unless the work group later identifies a specific remaining ambiguous term whose current wording changes implementer understanding rather than just being optional editorial cleanup.
