FHIR-7398: Audit basic-resource-type terminology wording

Issue request:
FHIR-7398 was a Published/Persuasive FHIR-I DSTU1 correction asking for the confusing generated wording "This value set defines its own terms in the system http://hl7.org/fhir/basic-resource-type" to be addressed because the link was broken and the terminology guidance in section 6.3.6 did not clearly explain how systems should be chosen or defined.

Initial application:
No git commit was found that explicitly mentions FHIR-7398. The Jira comment from 2015-08-21 says the boilerplate sentence had been changed and that the link would work when DSTU was posted. Nearby history shows the Basic resource type value set continued to be maintained, then later source refactors removed inline ValueSet.codeSystem content and moved the Basic code system reference to the THO CodeSystem URL, so the current source no longer contains the broken URL or the old "value set defines its own terms" wording.

Additional context:
The current build-scope terminology pages distinguish code systems from value sets and direct users to THO/TSMG for system selection. A later 2025 Zulip thread and Jira issues FHIR-52924, FHIR-52925, and UP-734 concern retiring/removing the basic-resource-type code system and replacing the Basic example's use of it; those are separate later-change work items and are not Applied/Published in this default reconciliation scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative source already satisfies the 2015 request: the old broken system URL is absent from current source, the Basic value set points at the THO CodeSystem URL, and the terminology narrative now contains the requested guidance for code-system selection.

Recommendation:
Keep this audit commit as-is for FHIR-7398. Track FHIR-52924, FHIR-52925, and UP-734 separately if the work group wants to retire basic-resource-type or update the Basic example; those later decisions should not be folded into this old broken-link/boilerplate audit.
