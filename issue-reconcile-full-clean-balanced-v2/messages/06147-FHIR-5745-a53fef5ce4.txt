FHIR-5745: Audit Questionnaire extension generalization

Issue request:
FHIR-5745 was a Published/Persuasive FHIR-core Questionnaire issue asking that SDC-specific text/display extensions, such as help text and text displayed after a group or question, be moved to the generic Questionnaire extensions profile and represented as distinct extensions rather than as name-value pairs.

Initial application:
The Jira comments identify SVN #4165 as pre-applied. Git commit e4f5c0d73d001a82fba48ff47d65a7154166c19c is that git-svn application and explicitly says it moved SDC extensions to common Questionnaire extensions and refactored the design; its patch replaced SDC additionalGroupText/additionalQuestionText name-value structures in the SDC conversion with separate Questionnaire extension URLs such as instruction, security, trailing, and units.

Additional context:
Questionnaire is an active current resource in source/fhir.ini. Later Questionnaire refactoring moved the old per-purpose text extensions into the display-item/displayCategory model, where Questionnaire.item.text carries display content and questionnaire-displayCategory classifies display text. The current FHIR core checkout no longer defines the Questionnaire extension StructureDefinitions directly after the R5 extension removal, while the FHIR Extension Pack now contains generic Questionnaire display/rendering extensions such as questionnaire-displayCategory, questionnaire-supportLink, and questionnaire-supportHyperlink. The old SDC name-value extension names additionalGroupText and additionalQuestionText are not present in current core or the Extension Pack.

AutoFHIR reconciliation:
This audit intentionally makes no source change. The current source already satisfies the seed issue at the current-build level: generic display text is represented by Questionnaire display items and generic Questionnaire extensions, not by SDC-specific name-value extension structures, and the extension definitions are maintained in the Extension Pack rather than in the core source checkout.

Recommendation:
Keep this no-change audit commit. No FHIR core source fix is needed for FHIR-5745. If future work revisits Questionnaire rendering extensions, make changes in the Extension Pack or current Questionnaire display-category model rather than resurrecting the retired SDC name-value pattern.
