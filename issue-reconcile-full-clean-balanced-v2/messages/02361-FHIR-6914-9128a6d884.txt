FHIR-6914: Audit removed Composition List guidance

Issue request:
FHIR-6914 was a Published/Persuasive DSTU1 Structured Documents change request for FHIR-core Composition. It asked to omit the sentence "Note that the most common resource to use for the content of a section is the List resource" because a prior ballot resolution made List the only resource usable for Composition sections and the sentence was misleading.

Initial application:
No source commit mentioning FHIR-6914 was found. The Jira comments say the sentence was "already removed per #7404", and git history confirms commit 749c4dd88234688f57191d3d0b4d62bdc525b87d (#7404 - update documentation) removed that exact List-resource sentence from source/composition/composition-introduction.xml and removed adjacent narrative-only List guidance from source/composition/composition-notes.xml.

Additional context:
FHIR-7404 is itself Published/Persuasive with Modification and resolved the related document narrative question by moving narrative into Composition sections and inlining relevant List behavior into Composition.section. The current Composition resource is active in source/fhir.ini, and the current source describes section entries as references to resources without recommending List as the common/default section-content resource.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested misleading sentence is absent from current build-scoped Composition source, and adding or removing additional List-related prose would go beyond FHIR-6914.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-6914 unless the work group reopens the broader Composition/List narrative model.
