FHIR-12246: Audit vital signs US Core alignment

Issue request:
FHIR-12246 was a Published/Persuasive OO change request for FHIR-core Observation, raised in DSTU2, to align the core Observation Vital Signs profiles with the US-Core vital-sign profile. The disposition asked to replace Argonaut, DAF, and US-Core profile references with core resource links and listed specific vital-sign changes, including oxygen saturation, body length, head circumference, and removing mean blood pressure from the mandatory profile set.

Initial application:
The change was pre-applied in git commits 0d2d645db323246e3c7f844058f4fbf4dcbf62a9, 00682120489c039f986a06f735a6d98f9ffe20d9, and follow-up 7f5590e232fecd512aa73c548d18d6b69282ad8d. Those commits rewrote the old vital-sign profile introduction/spreadsheet, moved the profile references toward core resource references such as Reference(Patient), added examples/profile material including body length, and adjusted cardinality. Later source refactors removed the spreadsheet source but carried the vital-sign profile definitions into the current XML StructureDefinition and ImplementationGuide inputs.

Additional context:
Later final decisions supersede parts of the original DSTU2 disposition. FHIR-17394 changed the head-circumference and oxygen-saturation magic-value codes back to methodless LOINC codes 9843-4 and 2708-6; its linked Zulip discussion supports methodless oxygen saturation for cross-realm/profile consistency. FHIR-46418 reworked the R6 vital-sign profiles so Observation.code contains the actual vital-sign code, with profile-specific preferred value sets; the current Body Height profile and value set explicitly include body length. FHIR-11989 and FHIR-12233 provide the surrounding DAF/US-Core relationship background, but do not require changing the current core source. The remaining Argonaut/DAF link is a historical provenance note, not an active profile constraint.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current build-scoped source has Observation active in source/fhir.ini, the vitalsigns ImplementationGuide references the current profile StructureDefinitions, Observation.subject targets the core Patient resource, the oxygen saturation and head circumference profiles use later-approved methodless codes, and body length is represented through the bodyheight profile/value set and example. Reinstating the seed's older 8287-5/59408-5 details or a separate body-length profile would conflict with later applied OO decisions.

Recommendation:
Keep this no-change audit commit as-is. Do not reopen the DSTU2 US-Core/DAF alignment in core unless a new work-group decision asks to change the current R6 vital-sign profile model or to remove the historical provenance note.
