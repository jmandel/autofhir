FHIR-7841: Audit Medication ingredient v2 mapping

Issue request:
FHIR-7841 was a Published/Persuasive Pharmacy clarification from the 2015May DSTU1 ballot for the Medication HL7 v2 mapping. It asked to remove the leading "if substance:" qualifier from the Medication ingredient/item mapping so RXC-2 Component Code applies directly, while retaining the separate "if medication" mapping to RXO/RXE/RXD/RXG/RXA fields.

Initial application:
The issue was historically applied in commit 651364cb098a623c36afc1d6b9d56578507d897c, whose subject explicitly includes tracker item 7841. That commit changed the old source/medication/medication-spreadsheet mapping from "if substance: RXC-2-Component Code  if medication: ..." to "RXC-2-Component Code  if medication: ..." in both the sheet text and XML spreadsheet source.

Additional context:
Medication is an active current-build resource in source/fhir.ini, and the current generated StructureDefinition source preserves the requested substance qualifier removal on Medication.ingredient.item. A later FHIR-36396 reconciliation touched the same v2 map only to remove an erroneous field-description hyphen, leaving the FHIR-7841 semantic change intact. Targeted Zulip and Confluence searches found no conflicting community or work-group evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already says "RXC-2 Component Code  if medication: ..." for Medication.ingredient.item and no longer contains the stale "if substance:" qualifier.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-7841 unless Pharmacy later changes the Medication ingredient/item v2 mapping semantics.
