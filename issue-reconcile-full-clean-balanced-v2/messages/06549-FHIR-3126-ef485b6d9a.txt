FHIR-3126: Audit Questionnaire group heading rename

Issue request:
FHIR-3126 was a Published/Persuasive Patient Care change request for DSTU1 asking to rename Questionnaire Group.header to Group.title so a group heading/name would be clearer and better differentiated from group text. The Jira comments record Patient Care approval on 2014-05-29.

Initial application:
No git commit found explicitly names FHIR-3126, but commit 54ddc30bbb updated the active Questionnaire spreadsheet in the DSTU1 era, changing Questionnaire.group.header to Questionnaire.group.title and changing the definition from text displayed above group contents to a name displayed for the group. The same commit split QuestionnaireAnswers out and introduced QuestionnaireAnswers.group.title alongside group.text, which matches the Jira's related artifacts.

Additional context:
FHIR-8986 later made the published Questionnaire model combine groups and questions into recursive items. Commit 52dbc1c478 applied that later decision, removing Questionnaire.group.title in favor of Questionnaire.item.text and changing QuestionnaireResponse.group.title to QuestionnaireResponse.item.text. In the current build, Questionnaire and QuestionnaireResponse are active resources, the live source has no Questionnaire.group.header element, and the current Questionnaire.item.text definition/comment explicitly distinguish a short section heading from detailed instructions or display text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested rename was applied historically, and later published source refactoring superseded the old Group element names without reintroducing the header/text ambiguity.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed unless a future compatibility-map review wants to revisit historical conversion aliases; the current built specification already conveys the intended group-heading semantics.
