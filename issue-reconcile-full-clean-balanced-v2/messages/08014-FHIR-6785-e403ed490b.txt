FHIR-6785: Audit ValueSet multi-system warning

Issue request:
FHIR-6785 was a Published FHIR-core ValueSet change request from the vocabulary work group, resolved Persuasive with Modification for DSTU1. It objected that value sets selecting codes from more than one code system could undermine interoperability, and the accepted resolution was to add a best-practice note that value sets crossing systems should be created with care to avoid definitional confusion.
