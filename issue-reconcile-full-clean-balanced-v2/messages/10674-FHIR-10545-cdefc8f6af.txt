Initial application:

Current source no longer contains HSPC guide files.

The current FHIR core source links readers to the external IG Registry, but does not maintain an active HSPC registry entry. Recommendation:
Keep this audit commit as-is. If the HSPC registry entry needs to be restored or adjusted in the future, handle that in the IG registry/HSPC publication source rather than the current FHIR core checkout.
