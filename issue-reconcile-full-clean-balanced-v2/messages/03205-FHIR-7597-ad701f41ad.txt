FHIR-7597: Audit Provenance activity action support

Issue request:
FHIR-7597 was a Published/Persuasive FHIR-core Provenance change request from the DSTU1 ballot asking whether Provenance was missing a way to reference the action performed on the entity/target, or whether a default create action was implied. The final Jira resolution says the issue was resolved by adding Provenance.activity.

Initial application:
No exact FHIR-7597 issue-keyed source commit was found. The closest historical application is git commit 6c026c5064671ebbd76e4679a2e250ea2074e89d, "staging for Provenance improvements ballot comment resolution", which added a Provenance.activity row to the then-authoritative source/provenance/provenance-spreadsheet.xml with CodeableConcept type, ProvenanceActivity binding, and short text "Activity that occurred." Later source migrations carried that element into the current source/provenance/structuredefinition-Provenance.xml.

Additional context:
source/fhir.ini actively lists provenance=Provenance, so the current Provenance StructureDefinition is in build scope. The current source defines Provenance.activity as a 0..1 CodeableConcept, binds it to http://hl7.org/fhir/ValueSet/provenance-activity-type, and says it is the activity that occurred. Later already-published reconciliation work for FHIR-13013, FHIR-53917, and FHIR-55410 refined the activity value set, removal/replace semantics, and activity wording; none of those later decisions remove the action-capturing element requested by FHIR-7597.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build already contains the required Provenance.activity element and related guidance/codes for create, update, removal, replacement, and other provenance activities. Adding redundant local prose for a 2015 ballot question would not change implementer understanding and would increase maintenance drift.

Recommendation:
Keep this no-change audit commit. No core source follow-up is needed for FHIR-7597 unless the Security WG wants a new, broader change to Provenance activity semantics, which would be a separate tracker from this already-published DSTU1 issue.
