FHIR-17592: Audit AllergyIntolerance onset search removal

Issue request:
FHIR-17592 was a Published FHIR-core Patient Care change request against AllergyIntolerance. The submitter initially thought the existing onset search parameter targeted the choice element AllergyIntolerance.onset and asked for an as(dateTime) FHIRPath cast; after discussion, the final Not Persuasive with Modification resolution was to remove the existing AllergyIntolerance.reaction.onset search parameter and not add any new AllergyIntolerance.onset search parameters.

Initial application:
The issue was explicitly applied by HL7/fhir commit 1f77a6e14e528ce5275d0ab0af27c2d4b56425f4, which changed the old AllergyIntolerance spreadsheet search-parameter row from onset to !onset. The later source rework in 33b409a4b6d544598262f2f074ebb4b6dc466157 removed the spreadsheet and introduced source/allergyintolerance/bundle-AllergyIntolerance-search-params.xml without carrying forward an onset search parameter.

Additional context:
AllergyIntolerance is an active core resource in source/fhir.ini, so the search-parameter bundle in source/allergyintolerance is in current build scope. Current source still defines the AllergyIntolerance.onset[x] and AllergyIntolerance.reaction.onset elements, but the active SearchParameter bundle lists AllergyIntolerance search parameters without onset, onset-date, onset-age, onset-info, or reaction-onset. Jira searches surfaced older element-modeling issues and a later triaged reaction.onset modeling suggestion, but no final later decision requiring an AllergyIntolerance onset search parameter.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already reflects the final FHIR-17592 resolution: there is no active AllergyIntolerance search parameter over AllergyIntolerance.reaction.onset and no replacement search parameters over AllergyIntolerance.onset.

Recommendation:
Keep this audit commit as-is. Revisit only if Patient Care makes a new final decision to add one or more AllergyIntolerance onset search parameters; FHIR-54072 is currently only a separate triaged modeling question and does not change this reconciliation.
