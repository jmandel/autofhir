FHIR-7822: Audit MedicationAdministration v2 refusal mapping

Issue request:
FHIR-7822 was a Published/Persuasive Pharmacy change request from the DSTU1 QA process asking the MedicationAdministration not-given reason v2 mapping to add RXA-18 Substance/Treatment Refusal Reason and remove RXA-20 Completion Status='NA' from that reason mapping.

Initial application:
The request was applied in commit 651364cb09, a DSTU-era batch commit for medication v2 mapping tracker items. That patch changed MedicationAdministration.reasonNotGiven from RXA-9 Administration Notes:RXA-20 Completion Status='NA' to RXA-9 Administration Notes / RXA-18 Substance/Treatment Refusal Reason.

Additional context:
MedicationAdministration is active in the current build through source/fhir.ini. Later refactoring moved the not-given reason concept from MedicationAdministration.reasonNotGiven to MedicationAdministration.statusReason while preserving the RXA-9/RXA-18 v2 mapping, and later cleanup only normalized hyphenation in RXA labels. The current MedicationAdministration.status element separately maps to RXA-20 Completion Status, so RXA-20 remains represented as status rather than as the reason-not-given mapping requested by this issue.

AutoFHIR reconciliation:
No source change was made. The current authoritative StructureDefinition source already has MedicationAdministration.statusReason mapped to RXA-9 Administration Notes / RXA-18 Substance/Treatment Refusal Reason, with no RXA-20 dependency in that element's v2 mapping.

Recommendation:
Keep this audit commit as-is. The current build-scope source matches the published Jira disposition, and re-adding RXA-20 to statusReason would undo the requested mapping separation.
