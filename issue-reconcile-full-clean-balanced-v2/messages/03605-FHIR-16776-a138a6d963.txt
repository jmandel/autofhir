FHIR-16776: Audit SDC expression example alignment

Issue request:
FHIR-16776 was a Published/Persuasive with Modification STU3 CDS change request for Clinical Reasoning module section 14.3.0.7. The reporter asked when the PHQ-9 Questionnaire fragment's cqif-cqlExpression/CalculateTotalScore expression was executed; the approved resolution said the example would be updated based on alignment efforts with SDC.

Initial application:
The Jira comment cites SVN 14073. The corresponding git-svn commit 3dc81b908557be64248363dc4e5bbf5ed5213965 explicitly mentions GF#16776 and GF#16780 and changed ActivityDefinition and PlanDefinition dynamicValue elements and examples to use the Expression datatype, but did not alter the PHQ-9 Documentation Template fragment itself. A later untagged Clinical Reasoning review commit, 7fb13bf1654f19e63d117420b4bcdf0deb69888c, converted that fragment from cqlExpression wording to cqf-expression/valueExpression while leaving the example in place.

Additional context:
Later final CDS decisions changed how this area should be represented. FHIR-21005 concluded the CQIF Questionnaire profile and its single score-calculation example were technically insufficient because cqf-expression calculates the value for the current attribute, not the corresponding QuestionnaireResponse answer, and directed readers to SDC. FHIR-30204 then required eliminating CQF Questionnaire. Commit bc30255627a58b5e899f1afd7a087806ab48ac23 removed the CQF Questionnaire/PHQ-9 fragment from source/clinicalreasoning-knowledge-artifact-representation.html and replaced it with an SDC reference. Current core source no longer contains the CalculateTotalScore example or cqif-cqlExpression outside historical release files, and the extension-pack cqf-expression definition points questionnaire users to SDC guidance.
