FHIR-5440: Audit ProcessResponse status application

Issue request:
FHIR-5440 is a Published FHIR-core/FM ProcessResponse change request from the January 2015 ballot. It asked that status be a property of the underlying resource and a status search parameter, with the related comment that StatusRequest and StatusResponse should not exist as separate resources. The final Persuasive with Modification resolution says status had already been added to all FM resources for STU3.

Initial application:
No Jira-keyed source commit for FHIR-5440 was found. History shows the relevant source path was first moved from StatusResponse to ProcessResponse in 2015, then a 2016 cleanup commit explicitly added status to EligibilityResponse, EnrollmentResponse, ProcessRequest, and ProcessResponse. The retained ProcessResponse spreadsheet source includes ProcessResponse.status and a status search parameter.

Additional context:
The latest combined branch does not build ProcessResponse: source/fhir.ini comments ProcessRequest and ProcessResponse out of the active resource and workgroup lists, lists ProcessResponse with removed resources, and records that ProcessResponse should use Task instead. FHIR-5439 is the matching ProcessRequest ballot comment with the same request and resolution, but it was used only as background for this ProcessResponse audit. Zulip and Confluence searches found no directly relevant or conflicting community records.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active FM resources on the combined branch all have status elements and status search parameters, and the retired ProcessResponse source already contains the historical status artifacts. Editing out-of-build ProcessResponse files or adding redundant prose would not change the current specification.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed unless the FM work group reintroduces ProcessResponse or identifies an active FM resource that lacks the expected status element or status search parameter.
