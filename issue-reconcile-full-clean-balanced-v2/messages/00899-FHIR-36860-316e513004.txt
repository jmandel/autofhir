FHIR-36860: Audit PlanDefinition EvidenceVariable subject target

Issue request:
FHIR-36860 was Published/Persuasive for R5 by the CDS work group. It asked to allow PlanDefinition.subjectReference to directly reference Group or EvidenceVariable so PlanDefinition could identify fully expressed eligibility criteria without wrapping EvidenceVariable in Group.characteristic.valueReference.

Initial application:
Commit e9f3c9466a initially applied the issue by adding EvidenceVariable as a Reference target on PlanDefinition.subject[x]. Commit 2db979fab6, explicitly titled as a correction for the same Jira, moved EvidenceVariable from subjectReference to subjectCanonical. Later commit 3cef25612a for FHIR-37485 moved only non-canonical product definition resources from canonical to Reference and left canonical(EvidenceVariable) in place; the current combined branch also includes FHIR-37485 prose cleanup in 53a0a5eaa3.

Additional context:
PlanDefinition is active and approved in source/fhir.ini. The current PlanDefinition.subject[x] source allows CodeableConcept, Reference(Group plus product definition resources), and canonical(EvidenceVariable), with prose stating that canonical references are limited to EvidenceVariable. FHIR-37485 confirms the relevant later split between Reference targets for non-canonical resources and canonical targets for EvidenceVariable. FHIR-39385 was retracted after a publisher issue and includes the relevant guidance that EvidenceVariable should use subjectCanonical. No Zulip or Confluence search found a conflicting community decision for FHIR-36860.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already provides the direct PlanDefinition-to-EvidenceVariable subject path through subjectCanonical, which is the corrected application of FHIR-36860 for a canonical resource and avoids reintroducing the earlier corrected Reference(EvidenceVariable) target.

Recommendation:
Keep this no-change audit as-is. If CDS wants PlanDefinition.subjectReference to also accept Reference(EvidenceVariable) in addition to subjectCanonical, that would be a new work-group decision because the same Jira's source history explicitly corrected the target to canonical and later subject[x] decisions preserved that shape.
