FHIR-34446: Audit cited artifact status value set move

Issue request:
FHIR-34446 was a Published/Persuasive R5 CDS change request for Citation. It asked to align Citation.citedArtifact.currentState with Citation.status and other FHIR Resource.status values by adding the PublicationStatus codes retired and unknown to the CitedArtifactStatusType value set, while leaving the CitedArtifactStatusType code system itself unchanged.

Initial application:
The request was applied for R5. Commit 9130cf3988b8a135ec0def184962ad2b7a1c02a5, merged through HL7/fhir#2261, changed source/citation/valueset-cited-artifact-status-type.xml so the value set included all codes from http://terminology.hl7.org/CodeSystem/cited-artifact-status-type plus selected http://hl7.org/fhir/publication-status concepts retired and unknown. The same commit also pruned generated narrative from the local code system source and added unknown to the CitedArtifactStatusType code system, but the operative value set composition satisfied the Jira resolution.

Additional context:
Later history moved the relevant terminology and resource out of the current core build. FHIR-39632 removed source/citation/codesystem-cited-artifact-status-type.xml and source/citation/valueset-cited-artifact-status-type.xml from core as part of moving code system definitions out of the base specification. Current source/fhir.ini has no active Citation resource entry, no tracked source/citation files, and only a commented related-artifact-type-expanded entry. Current Clinical Reasoning and MetadataResource pages link Citation to the Evidence Based Medicine on FHIR IG and explicitly state that Citation was moved from the FHIR specification to that IG. FHIR-36332 has already been audited on the combined branch as an external-repo Citation move issue and is related only as background.

AutoFHIR reconciliation:
No source files were changed. The historical R5 core source already applied the requested value set composition, and the current core checkout no longer has the authoritative Citation resource or CitedArtifactStatusType value set to edit. Reintroducing source/citation or changing stale OID remnants would be outside current build scope.

Recommendation:
Keep this audit commit as-is for FHIR core. If the current Citation artifact or CitedArtifactStatusType value set needs revalidation, perform that work in the Evidence Based Medicine on FHIR IG or other repository that now owns Citation/its terminology, not by resurrecting removed core source.
