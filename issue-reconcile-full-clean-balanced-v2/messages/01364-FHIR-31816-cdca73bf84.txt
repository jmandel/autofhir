FHIR-31816: Remove specifiedSubstance from ModelInfo

Issue request:
FHIR-31816 was Published/Persuasive with Modification for the BR&R MedicinalProductIngredient/Ingredient model. It reported that specifiedSubstance should not repeat because a single ingredient cannot have multiple substances; the final disposition was to change and simplify this modeling area for R5.

Initial application:
The Jira comments say the change was applied in the R4B branch and main build. The explicit Jira-tagged implementation commit on the current history, 5730009f8bc3d8edcbaba2bbf979741b55017c7b, changed Ingredient.substance from 0..1 to 1..1 and removed Ingredient.specifiedSubstance from the Ingredient StructureDefinition, examples, and Ingredient search parameters. The current source/ingredient/structuredefinition-Ingredient.xml keeps Ingredient.substance as exactly 1..1 and has no Ingredient.specifiedSubstance element.

Additional context:
MedicinalProductIngredient is now mapped to Ingredient in source/fhir.ini, while Ingredient and Library are both active current-build resources. The active Library examples include source/library/library-fhir-model-definition-content.xml as the FHIR ModelInfo XML, and that ModelInfo still exposed the old MedicinalProductIngredient.specifiedSubstance list plus its backbone class. BR&R minutes for 2021-10-05 confirm the FHIR-31816 vote and summarize that the Substance/SpecifiedSubstance model was simplified. A 2020 Zulip thread explains the earlier rationale for keeping a single plain substance while trying to model fully specified alternatives; that background is consistent with the later simplification rather than a reversal. FHIR-31876 is in the same implementation family and already has a separate reconcile audit commit on the combined branch.

AutoFHIR reconciliation:
Removed the stale MedicinalProductIngredient.specifiedSubstance element and the now-unreferenced MedicinalProductIngredient.SpecifiedSubstance ModelInfo class from source/library/library-fhir-model-definition-content.xml. No Ingredient StructureDefinition, example, or search-parameter edits were needed because those build-scoped source files already reflect the applied modeling change.

Recommendation:
Keep this commit as-is. It completes the applied FHIR-31816 change for the current build's ModelInfo example without broad regeneration of unrelated stale ModelInfo content; remaining old MedicinalProduct* model metadata should be handled only by Jira-specific reconciliations.
