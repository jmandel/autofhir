FHIR-7587: Audit Observation body site simplification

Issue request:
FHIR-7587 is a Published/Persuasive with Modification OO DSTU1 change request for Observation. It asked to remove the Observation.bodySite[x] choice between CodeableConcept and BodySite resource reference, handle BodySite resource references through a standard extension as part of FHIR-6253, and create a laterality extension for use where needed.

Initial application:
No current-source commit explicitly mentions FHIR-7587. Local history shows the preceding FHIR-3600/#3600 work added bodySite[x] as CodeableConcept|Reference(BodySite), then commit 4e55d97ce3 (#6253) removed Reference(BodySite) from Observation.bodySite and made the element a plain CodeableConcept for OO resources. Later published decisions such as FHIR-10735 and FHIR-16137 confirmed the intended pattern that a simple code remains core and more detailed BodySite/BodyStructure representation is handled by extension or later explicit elements.

Additional context:
Observation and BodyStructure are active current-build resources in source/fhir.ini. The current Observation source has Observation.bodySite as a deprecated 0..1 CodeableConcept, Observation.bodyStructure as a 0..1 CodeableReference(BodyStructure), and obs-8 enforcing that bodySite and bodyStructure are mutually exclusive. Observation search parameters also deprecate body-site and provide body-structure code/reference searches. The FHIR Extension Pack now owns the bodySite extension and the newer observation-structureLaterality extension; those external definitions are read-only evidence for this core reconciliation. Later applied core work FHIR-34894 and FHIR-53203 superseded the old extension-only implementation by adding bodyStructure directly and then converting it to CodeableReference while deprecating bodySite.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source no longer contains the BodySite reference choice FHIR-7587 objected to, and the current bodyStructure/extension-pack model preserves the intended ability to represent detailed body location and laterality without reintroducing Observation.bodySite[x].

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-7587; any future changes to the Extension Pack laterality extension or broader BodyStructure modeling should be tracked under their newer issue keys rather than reopening this DSTU1 Observation issue.
