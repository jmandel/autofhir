FHIR-14373: Audit immunization modifier flags

Issue request:
FHIR-14373 was Published/Persuasive with Modification for STU3 and asked Public Health to review the immunization-related resources for correct isModifier use. The final decision was that Immunization.primarySource should not be a modifier, while ImmunizationEvaluation.status and ImmunizationRecommendation.recommendation.forecastStatus should be modifiers.

Initial application:
The issue appears to have been applied before this reconciliation in the old spreadsheet-based source rather than by a commit mentioning FHIR-14373. The February 2018 immunization update touched the ImmunizationEvaluation and ImmunizationRecommendation spreadsheets, and the April 2018 follow-up added modifier reasons for ImmunizationEvaluation.status and ImmunizationRecommendation.recommendation.forecastStatus. The R5 StructureDefinitions show both requested elements with isModifier=true and modifier reasons.

Additional context:
In the current R6 source, source/fhir.ini actively lists Immunization but no longer lists ImmunizationEvaluation or ImmunizationRecommendation. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed ImmunizationEvaluation and ImmunizationRecommendation source directories and their fhir.ini entries. The current Immunization source leaves Immunization.primarySource as a normal boolean and has no evidence that FHIR-14373 intended it to be a modifier.

AutoFHIR reconciliation:
This audit commit makes no source change. The only remaining active current-build resource from the issue family already matches the issue decision for Immunization.primarySource, and the two elements that were supposed to be modifiers belonged to resources that have since been removed from the current build after having the requested flags in historical definitions.

Recommendation:
Keep this no-change audit as-is. Do not reintroduce or edit ImmunizationEvaluation or ImmunizationRecommendation in core for this STU3-era issue; any future work on those concepts should follow the later resource-removal decision path rather than this modifier audit.
