FHIR-11318: Audit genetics LOINC code reconciliation

Issue request:
FHIR-11318 was a Published/Persuasive Clinical Genomics issue against the DSTU2 FHIR-core profiles page. It asked for the missing LOINC codes to be added to the genetics reporting extensions, while preserving the resolution distinction that Observation.component is for knowledge-based variant interpretations and extensions carry genetics information.

Initial application:
The request was applied in git commit 670910b3f7100538bcc38b0cd3bb8f94abadd2e9, "#11318 add missing links about LOINC codes for extensions in genetic reporting", which updated source/observation/observation-genetics-profile-spreadsheet.xml. The applied spreadsheet text added LOINC links for the genetics extension descriptions, including 51958-7, 48004-6, 48003-8, 48019-4, 48005-3, 48006-1, 48018-6, 47999-8, 48008-7, 53034-5, 81258-6, and 48002-0.

Additional context:
The old Observation-genetics profile is no longer part of the current core build: source/fhir.ini has no active genetics profile entry and source/observation/list-Observation-packs.xml lists only the Observation vital signs pack. Commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435 later removed outdated Clinical Genomics profiles, extensions, and examples under Observation, DiagnosticReport, and ServiceRequest and redirected genomics guidance toward the Genomics Reporting IG. Clinical Genomics minutes in January 2019 recorded the plan to move Observation-Genetics profile content to the Genomics Reporting IG to remove redundancy. The FHIR Extension Pack now contains the retired/deprecated observation-genetics extensions, marked as replaced by the Genomics Reporting Guide, and their definitions still include the LOINC links.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing the retired Observation-genetics profile in core would be out of build scope, and the current moved/deprecated extension definitions already preserve the LOINC information that FHIR-11318 requested.

Recommendation:
Keep this no-change audit commit. Any future work on these retired genetics extensions should be handled in the FHIR Extension Pack or the Genomics Reporting IG, not by restoring obsolete Observation-genetics profile source to core.
