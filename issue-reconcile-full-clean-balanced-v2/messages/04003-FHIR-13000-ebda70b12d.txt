FHIR-13000: Audit MedicationStatement effective timing guidance

Issue request:
FHIR-13000 was a Published/Persuasive with Modification Pharmacy change request raised and applied for DSTU2. It asked for additional guidance on populating effectiveTime/effective date wording, specifically to make MedicationStatement.effective[x] use present and past tense consistent with the MedicationStatement taken wording.

Initial application:
The Jira application comment points to fhir-svn commit d27f7663ee1951aafb30c6ed4e219c9794dd6fd8. That commit changed only the MedicationStatement spreadsheet sources: the effective[x] short description became "The date/time or interval when the medication is/was/will taken" and the definition became "The interval of time during which it is being asserted that the patient is/was/will be taking the medication ( or was not taking, when the MedicationStatement.taken element is No)." No historical source change for this issue touched MedicationAdministration, MedicationDispense, or MedicationPrescription/MedicationRequest.

Additional context:
The current build uses XML StructureDefinition sources, and source/fhir.ini lists MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement as active resources. MedicationPrescription has since become MedicationRequest, and MedicationAdministration.effective[x] is historical rename metadata for the current MedicationAdministration.occurrence[x]. Later published MedicationStatement issues corrected the obsolete taken/status wording: FHIR-31573 decided that MedicationStatement.effective[x] should refer to adherence for taking/not-taking, and FHIR-22109 is already represented on the combined branch as a no-change audit for removed-element wording. FHIR-54453 is a later Triaged, unresolved R6 question about the Timing type on MedicationStatement.effective[x], so it is background rather than a final source-edit decision.

AutoFHIR reconciliation:
This audit commit makes no source change. The active MedicationStatement StructureDefinition already preserves the FHIR-13000 tense guidance with clearer grammar: "The date/time or interval when the medication is/was/will be taken" and "The interval of time during which it is being asserted that the patient is/was/will be taking the medication (or was not taking, when the MedicationStatement.adherence element is Not Taking)." The same wording is mirrored in the MedicationStatement event mapping exception. Adding new parallel prose to the other medication resources would go beyond the Jira-commented application and would be redundant rather than a necessary current-spec correction.

Recommendation:
Keep this no-change audit. The current source satisfies FHIR-13000 after later MedicationStatement/adherence decisions. Revisit only if the unresolved FHIR-54453 Timing question reaches a final Pharmacy decision requiring a separate update to MedicationStatement.effective[x].
