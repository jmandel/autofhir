FHIR-5555: Audit ValueSet include valueSet clarification

Issue request:
FHIR-5555 was a Published/Persuasive DSTU1 FHIR-core ValueSet request to clarify ValueSet.compose.import: the URI should be absolute, should be a logical reference to ValueSet.url rather than a search or $expand URL, and expansion should resolve and expand imported value sets recursively with includes and excludes applied predictably.

Initial application:
The issue was applied in svn revision 4579, preserved as git commit 2cdbc5b35a66ab715da349dd043931559bae87f4, which added ValueSet import URI wording and an expansion process that found referenced value sets by ValueSet.url, expanded them, and then applied include/exclude processing. Later history carried this forward when the old compose.import element was refactored.

Additional context:
FHIR-9535 moved ValueSet.compose.import into ValueSet.compose.include.valueSet and documented how multiple referenced value sets form intersections within one include, while multiple includes form unions. FHIR-9828 corrected the historical ValueSet.uri wording to ValueSet.url. FHIR-18075 fixed a stale narrative reference to the removed compose.import name. FHIR-5784 records a no-change decision that a separate URI-vs-Reference split was not needed and points back to FHIR-5555. ValueSet remains an active build resource in source/fhir.ini.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build-scoped source already expresses the applicable rule at ValueSet.compose.include.valueSet: it is a canonical/absolute URI reference to ValueSet.url, can be logical/direct/implicit rather than necessarily an actual FHIR ValueSet resource, and referenced definitions must be clear about version resolution. The current Value Set Expansion narrative says to find referenced value sets by ValueSet.url, expand them with $expand using compose.include.valueSet, handle this recursively, intersect referenced value set result sets within an include, union includes, and process excludes by removing matching codes.

Recommendation:
Keep this audit commit as-is. A source edit would either restore obsolete compose.import terminology or duplicate guidance that is already present in the authoritative ValueSet structure definition and expansion narrative after later ValueSet refactors.
