FHIR-12659: Audit Practitioner qualification binding

Issue request:
FHIR-12659 was a Published FHIR-core Practitioner change request asking to replace the example value set for Practitioner.qualification with US provider taxonomy codes. The final Persuasive with Modification resolution rejected the taxonomy-code proposal and instead directed the binding to HL7 v2 table 0360 Degree/License/Certificate.

Initial application:
The original source application appears in git commit 8e2188474050f1040164af85bb5382ac2d74059c, whose subject includes Tracker#12659. That commit changed the old Practitioner spreadsheet binding for Qualification from valueset-anzsco-occupations to http://hl7.org/fhir/ValueSet/v2-2.7-0360 and added a Practitioner example coding from v2 table 0360. Later terminology migration commits kept the same semantic binding while moving the canonical URL to terminology.hl7.org and then to the unversioned http://terminology.hl7.org/ValueSet/v2-0360 form now used by current source.

Additional context:
Practitioner is an active resource in source/fhir.ini, so source/practitioner/structuredefinition-Practitioner.xml is in the current build scope. The current Practitioner.qualification.code binding has strength example and valueSet http://terminology.hl7.org/ValueSet/v2-0360, and the main Practitioner example uses http://terminology.hl7.org/CodeSystem/v2-0360/2.7 with code BS. Jira search surfaced FHIR-8513 as an older duplicate/broader Practitioner.qualification issue, but it is not needed to decide this seed. Zulip and Confluence searches found no work-group discussion or minutes that conflict with the Jira resolution and source history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already reflects the final modified resolution, and changing it to US taxonomy codes now would contradict the Published Jira disposition.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-core unless a later, separate PA decision requests a different Practitioner.qualification.code binding.
