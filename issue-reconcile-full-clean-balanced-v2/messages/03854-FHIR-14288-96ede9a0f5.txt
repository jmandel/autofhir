FHIR-14288: Audit ResearchStudy phase binding

Issue request:
FHIR-14288 was Published/Persuasive for STU3 and requested changing the ResearchStudy.phase / ResearchStudyPhase binding from Preferred to Example because the then-bound clinicaltrials.gov value set was considered US-realm terminology. Jira records the change as made and published in the Dec 2017 FHIR ballot.

Initial application:
The current source history no longer exposes a direct FHIR-14288-tagged implementation commit, but the ResearchStudy.phase binding was Example before later R6 ResearchStudy work. Current source/fhir.ini keeps ResearchStudy in the active build, and the current authoritative StructureDefinition source now binds ResearchStudy.phase at Preferred strength to http://terminology.hl7.org/ValueSet/research-study-phase.

Additional context:
FHIR-49963 is a later Applied/Persuasive BR&R decision for R6 that explicitly asked to change ResearchStudy.phase binding strength to Preferred, with BR&R minutes recording an 8-0-0 vote. Commit bdccf9c6e437285da52c1f55063087ab17b11a80 applied that later decision by changing ResearchStudy.phase from Example to Preferred and changing the value set family. FHIR-50710 then moved the ResearchStudy.phase binding URL to the THO value set without changing the Preferred strength; an existing combined-branch reconciliation commit already completed related THO cleanup for FHIR-50710.

AutoFHIR reconciliation:
This audit commit makes no source change. The current Preferred binding is intentional later WG-approved R6 content, not an unapplied remnant of the STU3 clinicaltrials.gov issue. Reverting it to Example for FHIR-14288 would conflict with FHIR-49963 and the current THO migration context.

Recommendation:
Keep this no-change audit. Future work should treat FHIR-49963 and FHIR-50710 as the controlling current-build decisions for ResearchStudy.phase unless BR&R opens a new issue to lower the THO research-study-phase binding strength.
