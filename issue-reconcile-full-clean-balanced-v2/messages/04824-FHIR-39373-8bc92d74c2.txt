FHIR-39373: Audit repeated search parameter guidance

Issue request:
FHIR-39373 was Published/Persuasive with Modification for R5 by FHIR-I. It asked the Search page's "Searching Multiple Values (joining with AND or OR)" section to define repeated search parameter behavior, including AND behavior for repeated parameters, scalar/array and simple/complex matching cases, repeated complex elements such as Patient.given, and date/range guidance so ge/le combinations are not misread as starts-after/ends-before constraints.

That commit added Search Test Basics, Matching and Cardinality, Matching and Sub-Elements, a repeated Patient given-name example in the multi-value section, an illustrative scalar/array/simple/complex join table, and additional date/range clarification. No Issue-Reconcile-Key commit for FHIR-39373 existed on the combined branch before this audit.
