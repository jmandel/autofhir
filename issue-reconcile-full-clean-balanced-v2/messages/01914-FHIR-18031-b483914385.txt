FHIR-18031: Audit VisionPrescription summary elements

Issue request:
FHIR-18031 was a Published/Persuasive FHIR-core change request from the FM work group, raised for STU3 and applied for STU3. It asked to add VisionPrescription.status, patient, prescriber, dateWritten, created, and reason to the resource summary.

Initial application:
The request appears to have been applied in commit 9c9403324df70351bf59981a05828a59d6b2b723, whose subject explicitly lists GF#18031 with related VisionPrescription work. The old VisionPrescription spreadsheet changed status, created, patient, dateWritten, and prescriber to Summary=Y, added the created element, and in the same application stream disabled VisionPrescription.reason[x] as !VisionPrescription.reason[x] for FHIR-19464. Later source rework carried the surviving summary flags into the current StructureDefinition XML.

Additional context:
FHIR-19464 is a Published/Persuasive with Modification VisionPrescription issue resolved to remove the reason code element, so it governs the reason portion of the older summary request. A separate AutoFHIR audit commit for FHIR-19464 is already present on the combined branch. VisionPrescription is active in the current build and is now assigned to OO in fhir.ini. Direct Jira-key Zulip and Confluence searches found no community record conflicting with the Jira/source-history conclusion; broader VisionPrescription summary hits did not affect this seed decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active source/visionprescription/structuredefinition-VisionPrescription.xml already marks VisionPrescription.status, created, patient, dateWritten, and prescriber as isSummary=true. The requested reason element is absent from current VisionPrescription source because the related published FHIR-19464 decision removed it, so adding a summary flag or recreating the element would be wrong.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-18031 unless a future work group issue reintroduces a VisionPrescription reason element or changes which VisionPrescription elements should be summary.
