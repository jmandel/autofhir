FHIR-26967: Remove retired Evidence Synthesis ModelInfo entries

Issue request:
FHIR-26967 was a Published CDS change request, applied for R5, asking to remove the unused EffectEvidenceSynthesis, RiskEvidenceSynthesis, and Statistic resource artifacts and to fix the then-current Statistic and OrderedDistribution datatype page linking.

Initial application:
Commit 990b2a3dc9b66819a3d8e6bc880c55dded7fc294 appears to have applied the original cleanup by adding the then-needed fhir.ini datatype page mappings, adding EffectEvidenceSynthesis and RiskEvidenceSynthesis to [removed-resources], deleting their resource-name-tracker rows, and deleting the old resource folders and Statistic resource folder.

Additional context:
Later CDS decisions FHIR-31564 and FHIR-31866 removed Statistic and OrderedDistribution as standalone datatypes, so the old fhir.ini type-page mappings are no longer expected in the current build. The current build configuration still lists Library as an active resource and includes Library/FHIR-ModelInfo as an example, but that ModelInfo content still exposed EffectEvidenceSynthesis and RiskEvidenceSynthesis as retrievable FHIR 6.0.0 resources. Historical release notes, removed-resource lists, old-type terminology, and migration notes that mention the retired resources are intentional context and were left unchanged.

AutoFHIR reconciliation:
Removed the retired EffectEvidenceSynthesis and RiskEvidenceSynthesis ModelInfo class definitions, nested class definitions, and Resource choices from source/library/library-fhir-model-definition-content.xml, then regenerated the embedded base64 content in source/library/library-fhir-model-definition.xml so the published Library example matches the corrected ModelInfo content.

Recommendation:
Keep this source fix. The current build no longer publishes the old resource folders or standalone Statistic/OrderedDistribution datatype pages, and this commit removes the remaining active current-model surface that could mislead CQL users into treating the retired Evidence Synthesis resources as current FHIR resources.
