FHIR-35974: Audit trimmed SearchParameter processing modes

Issue request:
FHIR-35974 was Published/Persuasive with Modification for R5 SearchParameter. It asked to trim the old xPathUsage/renamed usageMode code set: the description identifies nearby and distance as unsupported generic modes and questions other, while the final resolution keeps other and says to remove location/distance. Because the historical code system had nearby and distance but no location code, location appears to be a resolution-wording slip for nearby.

Initial application:
No local source commit explicitly mentions FHIR-35974. The Jira comment says it is the same as FHIR-34467 and cites PR 1964. Commit 1a0b67ee41 (FHIR-34467) removed the nearby and distance concepts from source/searchparameter/codesystem-search-xpath-usage.xml while leaving normal, phonetic, and other.

Additional context:
SearchParameter is active in source/fhir.ini, and the old SearchParameter.xpathUsage element is mapped to SearchParameter.processingMode. Later rename commits changed search-xpath-usage to search-processingmode and updated the StructureDefinition binding, so the current source represents the same trimmed code set under the new processingMode name. FHIR-I minutes for 2022-04-25 record the FHIR-35974 vote to remove the unsupported spatial codes and keep other.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. Current source/searchparameter/codesystem-search-processingmode.xml contains only normal, phonetic, and other, source/searchparameter/structuredefinition-SearchParameter.xml advertises processingMode as normal | phonetic | other with a required binding to ValueSet/search-processingmode, and a targeted source search found no remaining nearby/distance processing-mode concepts.

Recommendation:
Keep this audit commit as-is. The current core source already reflects the final FHIR-35974 decision after the FHIR-34467 implementation and subsequent rename; no additional core edit is needed unless the work group later changes the retained other mode.
