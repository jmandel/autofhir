FHIR-12227: Audit CapabilityStatement conformance expectation

Issue request:
FHIR-12227 was a Published/Persuasive FHIR-core change request asking the conformance rules page to clarify that assertions of FHIR conformance without a ConformanceStatement instance have limited utility, and that capabilities that cannot be described by a ConformanceStatement cannot be considered FHIR conformant.

Initial application:
The issue was applied in commit 3d7763fc7d0a1a1921562cf73de46c53197d669e on 2016-11-04, matching Jira's svn @10126 comment and adding the requested paragraph to source/conformance-rules.html, with the then-current resource name later updated to CapabilityStatement.

Additional context:
Later published issues refined the same paragraph without reversing the seed: FHIR-16084 replaced the second sentence with the affirmative rule that systems can only claim FHIR conformance for functionality described in the applicable CapabilityStatement; FHIR-18040 added the CapabilityStatement link; FHIR-18041 struck the awkward standalone "limited utility" sentence; and FHIR-19575 added the current REST/non-server clarification plus a testability statement for assertions made without a CapabilityStatement. The current source/conformance-rules.html page is in build scope through source/hierarchy.xml and cross-links from current source pages.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/conformance-rules.html already conveys the seed's implementer-facing rule using current resource naming and later work-group-approved wording: FHIR conformance claims are limited to functionality described in an applicable CapabilityStatement, RESTful servers must provide one on request, and formal conformance assertions without one have little meaning because they cannot be tested or verified.

Recommendation:
Keep this audit commit as-is. The current specification is correct for FHIR-12227 after the later CapabilityStatement wording decisions, and the related later issues already have reconcile records on the combined branch.
