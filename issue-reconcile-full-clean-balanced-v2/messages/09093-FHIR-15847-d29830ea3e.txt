FHIR-15847: Audit time-offset modifier removal

Issue request:
FHIR-15847 was a Published/Persuasive OO change request asking to leave the Observation time-offset extension without an isModifier flag. The resolution states that the extension is not a modifier because its value or absence does not make the containing Observation.component unsafe to interpret under the modifier-extension definition.

Initial application:
The request was pre-applied in git commit b437a5fdc0b21d669e05f8854231006deac215f7, whose subject explicitly mentions GF#15847. That commit removed the populated Is Modifier cell from the time-offset row in source/observation/observation-extensions-spreadsheet.xml while adding the new Modifier Reason column.

Additional context:
The current FHIR core checkout no longer has an active source definition for this extension; source/fhir.ini has no observation-timeOffset entry and source only retains the canonical OID mapping. Historical R4/R4B bundles show the extension as non-modifier, while the archived STU3 history still reflects the already-published STU3 artifact. The current FHIR Extension Pack source at input/definitions/Observation/StructureDefinition-observation-timeOffset.xml defines the extension without any isModifier element.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The authoritative current sources already satisfy the issue: core has no active time-offset extension definition to fix, and the moved Extension Pack definition is not marked as a modifier.

Recommendation:
Keep this audit commit as-is. No current core follow-up is needed for FHIR-15847; do not edit archived release history to rewrite a past publication. If future work revisits this extension, review the Extension Pack source rather than the retired core spreadsheet.
