FHIR-15923: Audit RDF contained resource examples

Issue request:
FHIR-15923 was a Published/Persuasive FHIR-core RDF issue asking the RDF description page to show how contained resources are represented, not merely mention that contained resources exist. The recorded resolution was to document the behavior by copying from one of the examples.

Initial application:
The issue was applied by SVN revision 14465, mirrored in Git as 951a0b4803dce99a5c63bca4b062301c7758feb4, with the subject "GF#15923 - document contained resources in RDF". That commit added a Representing Inline Resources section to source/rdf.html, listed Bundle.entry.resource, DomainResource.contained, and Parameters.parameter.resource, and included a Turtle snippet for DomainResource.contained.

Additional context:
The RDF page is active build content: source/hierarchy.xml lists rdf.html as the RDF Definition page and publish.ini has an rdf.html entry. Later RDF-page work, especially the 2022 FHIR-37937..FHIR-37941 updates and the 2025 W3C issue #170 rewrite, replaced the original anonymous-node snippet with a fuller Inline Resources section covering Bundle membership, DomainResource.contained, local # references, fhir:l links, known parent URLs, and relative contained-resource URIs. A direct Zulip/Confluence search for FHIR-15923 found no conflicting community record; an older #dotnet rdf/turtle thread confirms the same contained-resource local-reference model.

AutoFHIR reconciliation:
No source change was made. This satisfies the published issue at a more complete level than the original 2018 application.

Recommendation:
