FHIR-17572: Audit Goal.target cardinality reconciliation

Issue request:
FHIR-17572 was a Published/Persuasive Patient Care change request for Goal that asked how to represent a blood pressure goal with systolic and diastolic targets. The approved resolution made Goal.target 0..* and required text explaining that repeated targets support component observations such as blood pressure, plus a note that all targets on one Goal must be met for the overall Goal to be met.

Initial application:
The Jira comment cites Git commit ef05a01a0bea. That commit changed the then-authoritative source/goal/goal-spreadsheet.xml Goal.target cardinality from 0..1 to 0..*, added the requested blood-pressure requirements text, added the all-targets-must-be-met comment, and tagged the element with GF#17572. The later source rework in 33b409a4b6d carried those values into source/goal/structuredefinition-Goal.xml.
