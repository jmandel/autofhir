FHIR-30099: Audit ValueSet profile migration

Issue request:
FHIR-30099 was a Published, Persuasive with Modification Vocab change request for ValueSet in R5. It asked to add Value Set Definition compliant and CPG shareable/publishable/computable/executable ValueSet profiles to core; the final resolution narrowed the immediate work to adding only the VSD-P profile, with the CPG profiles to continue separately.

Initial application:
The issue was applied in the R5 source history by 633035c38a, which added a VSD aligned ValueSet StructureDefinition, followed by commits that made it appear in the ValueSet core IG. This matches the Jira comments that only VSD-P was added at that time.

Additional context:
Later Vocab decisions changed the target state. FHIR-37923, Published/Persuasive for R5, explicitly removed the VSD aligned ValueSet profile because the shareable, publishable, computable, and executable profile family existed. FHIR-37959, Applied/Persuasive for R6, then moved the shareable/publishable/computable/executable profiles out of FHIR core and into CRMI while keeping the canonical profile URIs unchanged. Current source reflects that later state: the ValueSet core IG has no profile resources, and the active shareable/publishable pattern pages point implementers to CRMI.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing the old VSD aligned ValueSet profile or adding the migrated ValueSet profiles back to the core IG would contradict later applied/published Vocab decisions.

Recommendation:
Keep this audit commit as-is. Future work about the shareable, publishable, computable, or executable ValueSet profiles should be handled in CRMI or through a new core tracker that explicitly reverses FHIR-37923/FHIR-37959.
