FHIR-14015: Audit ContactPointSystem URL wording

Issue request:
FHIR-14015 was a Published/Persuasive with Modification STU3 change request asking that the ContactPointSystem URL code definition not imply only personal contacts. The accepted resolution was to update the definition as suggested with Ewout Kramer's caveat that an organization's own web site belongs in Organization.telecom, not Organization.contact.telecom.

Initial application:
The issue appears to have been applied in SVN revision 14475, now git commit 572d2ff11aad7b27cb6536ceb5b4914c47bf9638, which changed source/datatypes/contactpoint.xml for contact-point-system/url from "various personal contacts" to "various institutional or personal contacts including web sites". The current source still carries that applied wording.

Additional context:
source/fhir.ini actively includes the datatypes definitions, and source/datatypes/contactpoint.xml contains the contact-point-system worksheet, so this is the authoritative current source location for the code definition. A later related issue, FHIR-36033, was Resolved - No Change and quoted this same URL definition as already covering messenger URLs, so it reinforces rather than reverses the FHIR-14015 wording. Confluence and Zulip searches found no directly relevant conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped ContactPointSystem URL definition already says the URL system is for institutional or personal contacts and explicitly includes web sites, which satisfies the accepted FHIR-14015 request and Ewout's Organization.telecom caveat.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed in core for FHIR-14015 unless a future work group decision changes the semantics of ContactPoint.system=url.
