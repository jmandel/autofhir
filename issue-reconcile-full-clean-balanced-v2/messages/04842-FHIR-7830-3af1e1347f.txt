FHIR-7830: Audit MedicationDispense daysSupply V2 mapping

Issue request:
FHIR-7830 is a Published/Persuasive Pharmacy change request raised against DSTU1 for MedicationDispense. The original request proposed filling the blank MedicationDispense.daysSupply HL7 V2 mapping with RXD-12 Total Daily Dose, but later Jira discussion corrected that target: Scott Robertson explained that RXD-12 was incorrect and daysSupply should map to TQ1.6/TQ1-6 for current V2 versions, with ORC.7.3/ORC-7.3 noted for versions before V2.5 and ORC.7/ORC-7 backward compatibility through V2.6. The carried 2017 Pharmacy vote was to include the current V2 mapping at minimum and, if possible, the previous-version mapping as comments.

Initial application:
The issue was initially applied in SVN/Git commit 7975773ab18e3799e0e0d5223493e46cb2ea3b3a, whose message cites TR#7830 and SVN revision 10662. That commit replaced the then-current MedicationDispense.daysSupply V2 map value RXD-12-Total Daily Dose in the MedicationDispense spreadsheet source with the detailed TQ1.6, ORC.7.3, TQ1.6.1, and ORC.7 wording requested in the later Jira comments.

Additional context:
MedicationDispense is active in source/fhir.ini, and the current authoritative source is source/medicationdispense/structuredefinition-MedicationDispense.xml. That StructureDefinition declares the HL7 V2 mapping identity and currently maps MedicationDispense.daysSupply to TQ1-6 Timing/Quantity Segment Service Duration, includes the pre-V2.5 ORC-7.3 Duration component explanation, includes the TQ1-6.1 quantity guidance, and records ORC-7 backward compatibility through V2.6. A later Published/Persuasive issue, FHIR-36388, corrected the punctuation convention from TQ1.6/ORC.7 to TQ1-6/ORC-7 without changing the substance of the FHIR-7830 mapping, and that issue is already represented on the combined branch.

AutoFHIR reconciliation:

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed in core FHIR for FHIR-7830 unless Pharmacy later decides to change the substantive V2 mapping for MedicationDispense.daysSupply.
