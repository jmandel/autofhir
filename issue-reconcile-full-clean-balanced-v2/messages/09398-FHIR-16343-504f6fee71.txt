FHIR-16343: Audit HTTP charset correction

Issue request:
FHIR-16343 was a Published/Persuasive FHIR-core HTTP page correction for STU3. It said the RESTful API page incorrectly claimed that the HTTP specification defined a default ISO-8859-1 character encoding, even though that rule only applied to text media types and had been removed from the later HTTP specification; the requested correction was to remove or fix that language.

Initial application:
The issue was applied in source/http.html by git-svn commit eaa7a5f5e9ab41d2c4a9088649e5dc1f2f8e9f23, matching the Jira comment for svn revision 14172. That commit removed the ISO-8859-1/default-charset paragraph and replaced it with UTF-8 guidance that made the charset MIME parameter optional rather than required.

Additional context:
The current source/http.html page is still the active RESTful API HTTP source page and no longer contains the challenged ISO-8859-1/default-charset assertion. A directly relevant 2018 Zulip thread records Luis Maas explaining the same RFC 2616/RFC 7231 concern shortly before the Jira was filed. Earlier FHIR-3777 raised a similar HTTP UTF-8 concern but was Resolved - No Change; FHIR-16343 later supplied the narrower accepted correction. Later Published issue FHIR-35811 and commit 4ccbcfe84ecfa7e9fffc20efa054d198c72 refined the FHIR-16343 replacement sentence to avoid implying that application/fhir is itself a valid MIME type.

AutoFHIR reconciliation:
No source change was made. Current source/http.html says UTF-8 encoding SHALL be used for FHIR instances and that a MIME type parameter may specify it but is not required, which preserves the applied FHIR-16343 correction without reintroducing the incorrect HTTP ISO-8859-1 default. The XML and JSON format pages are also consistent about UTF-8.

Recommendation:
Keep this no-change audit commit as-is. No current FHIR-core source fix is needed for FHIR-16343; any future work should only revisit the broader media-type registration policy if a new work-group decision changes the charset requirements.
