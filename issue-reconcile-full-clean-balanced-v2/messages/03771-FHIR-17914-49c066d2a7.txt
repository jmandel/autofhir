FHIR-17914: Audit Encounter participant PractitionerRole support

Issue request:
FHIR-17914 was a Published/Persuasive PA change request from the STU3 ballot asking that Encounter.participant.individual be allowed to reference PractitionerRole in addition to Practitioner, so an encounter participant could identify the practitioner acting in an organization/team role such as a German ASV team.

Initial application:
The change appears to have been applied by commit 4d97d1578cc45c26fca1afc6fccef344eb8b2fce, whose subject includes GF#17914. In that historical Encounter spreadsheet source, Encounter.participant.individual changed from Reference(Practitioner|RelatedPerson) to Reference(Practitioner|PractitionerRole|RelatedPerson).

Additional context:
FHIR-22696 later renamed Encounter.participant.individual to Encounter.participant.actor for R5 and broadened the participant actor set to Patient, Group, Practitioner, PractitionerRole, RelatedPerson, Device, and HealthcareService. The current fhir.ini maps the old Encounter.participant.individual path to Encounter.participant.actor, and Encounter remains an active resource in the build. Zulip and PA minutes confirm the ASV-team PractitionerRole use case and the PA vote for the original request.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current Encounter StructureDefinition already includes PractitionerRole as a targetProfile for Encounter.participant.actor, so the current specification preserves the requested capability after the later element rename.

Recommendation:
Keep this audit commit as-is. No core FHIR follow-up is needed for FHIR-17914 unless a future work group decision changes the Encounter participant actor target set.
