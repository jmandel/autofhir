FHIR-3511: Audit ValueSet expansion definition

Issue request:
FHIR-3511 was a Published/Persuasive Vocabulary change request against FHIR-core ValueSet for DSTU1. It reported that the ValueSet.expansion definition only said "When value set is an expansion" and asked for more detail. The final resolution was to improve the definition.

Initial application:
The Jira comments say the change was applied on 29-Sept-2014 in SVN revision 2925. Git-svn commit 009a24e89282b9ef02ddcb91e8a721cf1733189d, "Clarify definition of ValueSet.expansion (task 3511)", changed the ValueSet spreadsheet short definition to "Used when the value set is \"expanded\"" and added a full definition plus comment explaining that an expansion is an enumerated collection of codes ready for data entry or validation. The 2021 source rework commit 33b409a4b6d544598262f2f074ebb4b6dc466157 carried that wording into the active StructureDefinition source.

Additional context:
The current build scope is active: source/fhir.ini lists valueset=ValueSet under [resources], and ValueSet remains a current normative resource. Later ValueSet expansion changes, including identifier, contains.version, property, and parameter clarifications, do not reverse the FHIR-3511 base ValueSet.expansion definition. No relevant Zulip or Confluence record was found that conflicts with the Jira/source history.
