FHIR-14118: Audit v2 table versioning migration

Issue request:
FHIR-14118 is Published/Persuasive. It asked why FHIR's v2 table 0131 value set included codes that were deprecated in v2.3 and requested either active-only imports or an explicit statement that the displayed v2 table codes were intentionally available for FHIR use. The accepted Vocab resolution was to make FHIR's v2 table code system/value set rendering version-specific and consistent with the declared v2 table version.

Initial application:
Git commit a89dad7cf7d547ea0084aaf17d9ebb7033be58f6 applied the issue as svn revision 13458, adding a generated v2 table expansion include to source/v2/template-tbl.html and updating the v2 value set/import tooling and expansion cache. There is no evidence that the current core source missed an additional FHIR-14118 source location.

Additional context:
The old source/v2 table machinery is no longer in the core build; git commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed UTG content from core, and the latest combined source has no source/v2 directory. Current core still references the external THO code system http://terminology.hl7.org/CodeSystem/v2-0131 in examples and resource-local value sets, but the active Patient.contact.role binding points to relatedperson-relationshiptype, Patient Contact Relationship is retired/deprecated, and relatedperson-relationshiptype enumerates only the selected v2-0131 codes E, O, and U. Later Jira records FHIR-32232 and FHIR-39206 describe a continuing deprecated-code display/expansion concern in THO/UTG terminology metadata, but FHIR-32232 remains Triaged and FHIR-39206 is Duplicate rather than an applied core decision.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The applied FHIR-14118 source change belonged to the former core v2 table renderer, which has since moved out of current core build scope; the current core source does not need a new edit to restate version-specific v2 table behavior or to duplicate unresolved THO terminology work.

Recommendation:
Keep this audit commit as-is. If the current v2-0131 deprecated-code expansion behavior still needs correction, pursue it through the active THO/UTG path represented by FHIR-32232 or a UP ticket, rather than changing core FHIR source for this already-applied STU3 issue.
