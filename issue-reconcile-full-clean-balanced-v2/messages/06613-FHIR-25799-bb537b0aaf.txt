FHIR-25799: Audit DeviceUsage DeviceDefinition guidance outside core

Issue request:
FHIR-25799 was a Published/Persuasive OO change request for R5 asking to improve DeviceUseStatement.device after DeviceDefinition was introduced. The approved resolution said to update .usageStatus with at least InUse and DoNotUse, then add text on .device saying that actual use should reference Device while non-use should reference DeviceDefinition when more than a code is needed; no invariant was requested.

Initial application:
No prior AutoFHIR audit commit for FHIR-25799 was present on the combined branch. Source history shows the DeviceUseStatement/DeviceUsage structure was reworked in commit 33b409a4b6 with DeviceUseStatement.device already modeled as CodeableReference(Device | DeviceDefinition). Commit 0763661ef79399537866358e94efadccc2577c4a, whose subject was "27868 25799", later added the required usageStatus binding but did not add the requested explanatory text on .device.

Additional context:
DeviceUseStatement was renamed to DeviceUsage for R5, and later current core changed ownership/build scope. The current source/fhir.ini active resources list no longer includes DeviceUsage; only a historical rename map DeviceUseStatement=@DeviceUsage remains. Commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed DeviceUsage and other OO resources from core build metadata and changed current Device/DeviceAssociation narrative links to the OO Incubator IG. The current core CI page for deviceusage returns 404, while the OO Incubator StructureDefinition-DeviceUsage artifact is reachable and still has DeviceUsage.device as CodeableReference(Device | DeviceDefinition) without the FHIR-25799 guidance text. Later already-audited issues FHIR-32829 and FHIR-40533 also found DeviceUsage is now outside current core build scope.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no core source change. Editing source/deviceusage/structuredefinition-DeviceUsage.xml would only change a retained out-of-build core file, not the current built FHIR core specification. The unresolved part of FHIR-25799, if OO still wants it preserved, belongs in the OO Incubator IG source that now owns DeviceUsage.

Recommendation:
Keep this external-repo audit as-is for core FHIR. Follow up in the OO Incubator IG to decide whether DeviceUsage.device should gain the voted guidance about Device for use, DeviceDefinition for non-use, and code-only fallback; no current core source edit is appropriate unless DeviceUsage returns to the core build.
