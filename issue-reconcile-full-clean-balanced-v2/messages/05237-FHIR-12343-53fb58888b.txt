FHIR-12343: Audit Endpoint.address service-base wording

Issue request:
FHIR-12343 was a Published/Persuasive Patient Administration change request for DSTU2 asking Endpoint.address to be clarified as the service base URL only, without parameters, sub-services, or resource-specific path segments; its resolution said the description and notes would be updated to clarify that intent.

Initial application:
No current git commit explicitly mentions FHIR-12343. The WADO-RS Endpoint example with a base-only address was added in historical Endpoint/imaging example work, and the current StructureDefinition source already contains the requested base-address comment as of the post-R4B source rework; later commits only preserved or escaped that wording.

Additional context:
Endpoint is an active core resource in source/fhir.ini. The current endpoint example list includes endpoint-example-wadors, whose address is the base https://pacs.hospital.org/wado-rs. Later ImagingStudy endpoint notes and applied R6 issues in the same DICOM endpoint family state that retrieval URLs are constructed by appending paths or query parameters to Endpoint.address, which reinforces rather than conflicts with the seed decision. Direct Zulip and Confluence searches found no discussion that changes the Jira/source conclusion.
