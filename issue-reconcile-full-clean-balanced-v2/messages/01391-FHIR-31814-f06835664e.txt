FHIR-31814: Audit allergenic indicator invariant

Issue request:
FHIR-31814 was a Published/Persuasive BR&R change request for R5 saying Ingredient.allergenIndicator/allergenicIndicator describes a substance property, not an ingredient property, and asking that if the element remains available for coded substances it should have an invariant limiting use to that case. The accepted resolution was to add the invariant.

Initial application:
The change was applied before this reconciliation in Rik Smithies' February 2022 Ingredient commits, especially 464b98e6e7, which added invariant ing-1 to Ingredient and expanded the Ingredient.allergenicIndicator definition. Earlier same-family commit 2e1674b1a6 carried the same FHIR#31814 application. Later source history refined, rather than reversed, the result: a75aa13680c updated the FHIRPath during BRR invariant QA, and 41d2b22c8d corrected spelling in the human-readable text.

Additional context:
Ingredient is an active draft resource in source/fhir.ini, and SubstanceDefinition is active/approved and is the target profile for Ingredient.substance.code when represented by reference. The current Ingredient source uses CodeableReference(SubstanceDefinition), carries the ing-1 condition on the relevant substance elements, and separately notes that allergen information belongs on SubstanceDefinition when a SubstanceDefinition reference is used. FHIR-31839 touched the same element's meaningWhenMissing in the same historical commit family and is already represented on the combined branch, so it was not decided again here. Community searches found no FHIR-31814-specific Zulip or Confluence decision that conflicts with the Jira/source history; one earlier Zulip Ingredient thread merely raised the question of why Ingredient had allergenicIndicator.

AutoFHIR reconciliation:
This is an empty no-change audit commit. The current source already implements the accepted decision: Ingredient.allergenicIndicator may be used with a coded substance, but invariant ing-1 prevents using allergenicIndicator=true when Ingredient.substance.code is a reference to SubstanceDefinition, and the definition directs that allergen information to SubstanceDefinition in that case.

Recommendation:
Keep this audit commit as-is. No FHIR core source change is needed unless BR&R makes a later substantive decision to move or remodel allergen status on SubstanceDefinition.
