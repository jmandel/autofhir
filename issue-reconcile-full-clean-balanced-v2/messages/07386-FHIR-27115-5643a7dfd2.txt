FHIR-27115: Audit event-basedOn context migration

Issue request:
FHIR-27115 was Published/Persuasive for R5. It reported that the event-basedOn extension had context limited to Condition even though it should apply to event resources, at least those without a native basedOn element, and the approved resolution was to expand the extension context beyond Condition.

Initial application:
The issue was applied in core by 2aaccf071c30f8c22a283f5e9113c907e9a52bdb, which changed source/profiles/event-extensions-spreadsheet.xml from Condition-only to a broader event-resource context list. A second same-key commit, 6616e51d37fe83bbfebcdb574deb3ccc2cae86a3, changed unrelated profiling guidance and does not affect this extension decision.

Additional context:
Current core no longer carries the event-basedOn extension definition as a build input: source/fhir.ini still lists the event-pattern extensions spreadsheet, but a focused current-source search finds event-basedOn only in source/oids.ini, and dd468d4f1799dd79819315b211588ef1cf4586e0 removed extension definitions from the R5 source. The current authoritative definition is in the FHIR Extension Pack, where StructureDefinition-event-basedOn.xml lists multiple event contexts including Composition. Later FHIR-49697 intentionally removed DetectedIssue from the allowed contexts, so that omission should not be treated as an unapplied part of FHIR-27115.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The core source is not missing a current build-scope edit for FHIR-27115: the original core correction happened before R5 publication, the definition subsequently moved to the Extension Pack, and the current Extension Pack source preserves the expanded context set as modified by later decisions.

Recommendation:
Keep this audit commit as-is. Any future disagreement about event-basedOn contexts or validator precedence, such as the unresolved FHIR-56195 discussion, should be handled in the FHIR Extension Pack and/or validator workflow rather than by restoring the extension definition to core.
