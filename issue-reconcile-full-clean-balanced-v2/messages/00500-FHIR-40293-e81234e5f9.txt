FHIR-40293: Audit AuditEvent on-behalf extension

Issue request:
FHIR-40293 was a Published Security WG change request, resolved Persuasive with Modification for R5. It asked for a core extension allowed on AuditEvent.agent so an AuditEvent agent can identify the organization or other actor on whose behalf it acted: agent-onbehalfOf 0..1 Reference to Organization, Practitioner, PractitionerRole, CareTeam, or Patient.

Initial application:
No Jira-keyed FHIR core commit was found for FHIR-40293, and current core source does not contain a duplicate auditevent-OnBehalfOf definition. The apparent application is Extension Pack commit 71471775152ef25e4e333d4d6ead80c3df7a4741, authored by the issue assignee after the vote, which added StructureDefinition-auditevent-OnBehalfOf.xml with context AuditEvent.agent, max 1, and a Reference value to the requested actor resources plus RelatedPerson.

Additional context:
Security WG minutes from 2023-02-13 record approval of option 4, the extension approach, by a 6-0-0 vote. Current FHIR core history says all extensions moved to the hl7.fhir.uv.extensions package and are still published as part of the specification. The Extension Pack source is therefore the authoritative current home for this extension, and later Extension Pack maintenance kept the same semantics while cleaning metadata.

AutoFHIR reconciliation:
This commit intentionally makes no source change. AuditEvent is active in current core, but the requested extension already exists in the Extension Pack with the approved AuditEvent.agent context and cardinality; adding a duplicate core source definition or redundant AuditEvent prose would conflict with the current extension-pack split rather than improve implementer understanding.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed unless the Security WG separately decides to revise the Extension Pack definition, such as narrowing or documenting the extra RelatedPerson target that is broader than the original Jira resolution but not inconsistent with the approved on-behalf-of concept.
