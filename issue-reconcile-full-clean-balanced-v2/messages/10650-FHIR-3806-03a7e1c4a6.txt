FHIR-3806: Audit legacy Profile search criteria tooling

Issue request:
FHIR-3806 was Published/Persuasive for DSTU1 and asked to extract Profile searchCriteriaDefinition content from profile spreadsheets so it would show up in the specification. The Jira comments record Grahame Grieve's 2015 statement that he thought the work was already done.

Initial application:
No source commit explicitly tagged FHIR-3806 was found. The same legacy tooling area had already been changed by svn/git commit 954b8519e8178994d2bb3c1bb94188400f36356b for FHIR-3673, which added the profile.search template hook and PageProcessor rendering for Profile structure search parameters. The related FHIR-3626 implementation in commit 8a793e752a71c734c9b4a1278998324d9ffde277 then introduced SearchParameter as a separate resource and spreadsheet-backed specification artifact, moving the relevant search-criteria definitions out of Profile.

Additional context:
The current build no longer has an active Profile resource: source/fhir.ini lists SearchParameter and StructureDefinition as active resources, while Profile appears only under [removed-resources]. The current SearchParameter source defines the resource, its base/code/type/expression elements, extension-search guidance, registry/list inputs, and example SearchParameter instances. Later FHIR-10376 again touched profile search-parameter rendering for DSTU2, but the current R6 source surface is SearchParameter, not DSTU1 Profile.searchCriteriaDefinition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing legacy Profile searchCriteriaDefinition tooling would be out of current build scope, and the active SearchParameter resource already supplies the current specification mechanism for custom and extension search parameter definitions.

Recommendation:
Keep this audit commit as-is. No FHIR core source change is needed for FHIR-3806 unless a human identifies a current SearchParameter rendering defect separate from the obsolete DSTU1 Profile spreadsheet extraction request.
