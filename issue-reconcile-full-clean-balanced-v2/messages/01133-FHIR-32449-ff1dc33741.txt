FHIR-32449 was a Published/Persuasive Security work group change request for R5 asking that AuditEvent.agent provide some expectation that the actor is identified. The final Jira resolution was to make AuditEvent.agent.who 1..1.

Initial application:

The current line blame still attributes the active min value to that Jira-tagged commit.

Additional context:
AuditEvent is an active resource in source/fhir.ini, so source/auditevent/structuredefinition-AuditEvent.xml is in the current build scope. The current AuditEvent.agent.who element is Reference 1..1 and explains that user IDs and names are represented through who.identifier and who.display. The related FHIR-32472 discussion removed the separate agent.name concept in favor of who.display, which supports the current model rather than requiring additional local text.

Keep this no-change audit commit as-is. No follow-up core source change is needed for FHIR-32449 unless the Security work group later reopens the cardinality decision.
