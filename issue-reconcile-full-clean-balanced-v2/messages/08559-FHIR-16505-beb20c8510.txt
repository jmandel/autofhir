FHIR-16505: Audit ElementDefinition version diff tab

Issue request:
FHIR-16505 was a Published/Persuasive STU3-era FHIR-core change request asking to fix the ElementDefinition page because it showed an "R2 Diff" tab but no "R3 Diff" tab.

Initial application:
No commit explicitly mentioning FHIR-16505 was found. The nearby source history shows the global diff page was changed from R2 to R3 wording before the tracker was created, and the later same-family FHIR-17721 records the datatype-page R2/R3 tab issue as already fixed by March 2019.

Additional context:
The current build has moved on from the STU3/R4 comparison context. ElementDefinition is active in source/fhir.ini, and the current datatype/resource templates use a release-neutral "Version Diff" tab with current R5, R4B, and R4 comparison links rather than an R2 or R3-specific tab. A later R5 tracker, FHIR-39183, confirms that stale "R3 Diff" labels became incorrect once R4 was the comparison baseline.

AutoFHIR reconciliation:
This audit commit makes no source change. Restoring or adding an R3-specific ElementDefinition tab in the current R6 build would be stale; the current rendered page already exposes the version-diff section and current comparison baselines.

Recommendation:
Keep this no-change audit. Do not add an R3 diff tab to the current build unless a new work-group decision explicitly asks to restore historical comparison surfaces.
