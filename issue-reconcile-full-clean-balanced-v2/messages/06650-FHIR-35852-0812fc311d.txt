FHIR-35852: Audit Bundle summary nested-resource guidance

Issue request:
FHIR-35852 was a Published FHIR-core Feed change request, resolved Not Persuasive with Modification for R5. It asked whether Bundle summary behavior was inadequate for document use, including whether _summary should traverse nested resources such as Bundle.entry.resource. FHIR-I kept the Bundle summary design and decided to add an STU statement that when a summary element is itself a nested Resource, the conveyed resource is expected to be expressed in summary form, with Bundle.entry.resource as the typical example.

Initial application:
The issue was applied by git commit 3ce7fc3906, which added the requested STU note to source/bundle/bundle-notes.xml. Commit 30c5d5f934 later line-wrapped that text and added adjacent explanatory Bundle summary prose from the same source area, and commit 23a31a590b adjusted the STU-note macro form. The current source still contains the applied text.

Additional context:
FHIR-I minutes on 2022-04-25 recorded the question and assigned creation of a Zulip discussion; the #conformance Zulip thread discussed contained and nested summary resources, including Bundle.entry.resource; and the 2022-05-02 minutes record the final Not Persuasive with Modification vote. source/fhir.ini actively lists bundle=Bundle, so source/bundle/bundle-notes.xml is in build scope. A later search found no superseding FHIR-core Jira or community decision that changes the seed conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active Bundle notes already state that all Bundle elements are summary and include the requested STU guidance that nested Resource-valued summary elements should convey their resources in summary form. Current Bundle structure source has only true isSummary flags and no false isSummary flags, matching the decision to retain the Bundle summary designation.

Recommendation:
Keep this audit commit as-is. No follow-up source edit is needed unless FHIR-I later reopens the broader question of how _summary applies to nested resources or Bundle-specific document summaries.
