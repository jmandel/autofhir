FHIR-5163: Audit resource pattern hierarchy resolution

Issue request:
FHIR-5163 is a Published/Persuasive with Modification DSTU1 ballot comment asking whether FHIR should define formal relationships between resources, potentially through shallow hierarchy or abstract resources. The final resolution says this intent is addressed by pattern work using logical models such as workflow Request, Event, and Definition patterns; R4 would make these more computable and may introduce other useful patterns such as W5; pattern use should remain flexible and not mandatory by default.

Initial application:
