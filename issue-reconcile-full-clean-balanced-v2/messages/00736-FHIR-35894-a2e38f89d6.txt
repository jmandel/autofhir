FHIR-35894: Remove stale maxDosePerPeriod example guidance

Issue request:
FHIR-35894 was Published/Persuasive for R5 by Pharmacy. It asked how to represent multiple maximum doses per period, such as PCA limits over 1 hour and 4 hours, and resolved to make Dosage.maxDosePerPeriod repeatable with guidance that repeated period denominators should differ.

Initial application:
Commit b9257918056a31ebdc080627432cc94db78637e0 explicitly included FHIR-35894 and changed source/datatypes/dosage.xml so Dosage.maxDosePerPeriod cardinality became 0..*. The R5.0.0 source contains that repeatable cardinality. The denominator comment requested in Jira was not found as separate current text, but later source changes superseded the Ratio-denominator representation.

Additional context:
The current build has since incorporated the R6 Dosage refactor from the same max-dose family, especially FHIR-51540, replacing the old direct Dosage.maxDosePerPeriod example pattern with DosageDetails/DosageSafety. Current authoritative source defines DosageSafety.doseLimit as 0..* with scope=period and an explicit period element, and dosage narrative says DosageSafety can represent multiple limits. source/dosage-examples.html is in active Dosage documentation scope via the active Dosage datatype and dosage page, but Example 2 still named the removed Dosage.maxDosePerPeriod element and adjacent old asNeededBoolean name.

AutoFHIR reconciliation:
This commit updates Example 2's structure guidance to use the current Dosage.asNeeded element and removes the stale Dosage.maxDosePerPeriod bullet, leaving the existing MedicationRequest.dosageInstruction.safety.doseLimit period-limit guidance as the correct current representation for the weekly maximum.

Recommendation:
Keep this source fix. It preserves the issue's implementer intent in the current R6 model without reintroducing obsolete R5 element names. Do not add the old denominator wording to current Dosage text unless Pharmacy separately decides to constrain duplicate DosageSafety.doseLimit periods; current FHIR-51540-era guidance intentionally allows multiple dose limits and can distinguish period-scoped limits with the doseLimit.period element.
