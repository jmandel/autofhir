FHIR-26635: Audit SubstanceDefinition structure technique rename

Issue request:
FHIR-26635 was Published/Persuasive for R5. BRR approved renaming SubstanceDefinition.structure.sourceCoding to SubstanceDefinition.structure.technique and updating the definition to describe the method used to elucidate the structure or characterization of the drug substance, with examples including X-ray, HPLC, NMR, peptide mapping, and ligand binding assay.

Initial application:
The issue was directly applied in git commit 3885120c62, which renamed the old spreadsheet row from SubstanceDefinition.structure.sourceCoding to SubstanceDefinition.structure.technique and replaced the old "source of information" wording with the requested technique definition and examples. The current XML source was produced by later source refactoring and carries the renamed SubstanceDefinition.structure.technique element.

Additional context:
SubstanceDefinition is active in source/fhir.ini, and BRR owns the resource in the current build configuration. A later Published/Persuasive with Modification issue, FHIR-39596, separated characterization details into SubstanceDefinition.characterization and removed characterization-specific remnants such as HPLC from the structure technique terminology. That later issue is already represented on the combined branch by commit 670d087b4d, so the current structure.technique wording is intentionally structure-only while SubstanceDefinition.characterization.technique carries the HPLC characterization example.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build input no longer contains SubstanceDefinition.structure.sourceCoding, defines SubstanceDefinition.structure.technique with the structure technique value set, and preserves the later FHIR-39596 separation between structure and characterization terminology.

Recommendation:
Keep this audit commit as-is. No additional core source change is recommended for FHIR-26635; reintroducing HPLC or "characterization" under structure.technique would conflict with the later FHIR-39596 decision.
