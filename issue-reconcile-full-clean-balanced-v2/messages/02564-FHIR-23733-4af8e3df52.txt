FHIR-23733: Confirm Medication ingredient strength basis

Issue request:
FHIR-23733 is a Published/Persuasive with Modification Pharmacy change request for R5. It asked Medication.ingredient.item[x] to support the substance that is the basis of strength by replacing the old "actual ingredient or content" wording with language saying the ingredient is the substance or medication that ingredient.strength relates to, represented as a code or as a Substance or Medication resource.

Initial application:
The issue was applied in Melva Peters' 2019-09-20 commit 2933d19faad5a9c3da59470ac68ba7222b4495d7, which changed the then-authoritative Medication spreadsheet row for Medication.ingredient.item[x]. The Medication source was later migrated into source/medication/structuredefinition-Medication.xml by the core build-source refactor, preserving the same basis-of-strength meaning.

Additional context:
The current build configuration has Medication active in source/fhir.ini. Later Medication/Substance work refined the representation without reversing FHIR-23733: FHIR-43166 added SubstanceDefinition as a Medication.ingredient.item target when substance definitions moved out of Substance, and the already-published FHIR-48405 reconciliation updated the Medication.ingredient.item prose to mention SubstanceDefinition while retaining Substance and Medication. FHIR-53236 is only Triaged and asks whether the remaining Substance target is still needed, so it is not a final decision that would justify changing the seed result.

AutoFHIR reconciliation:
No source change was made. The latest combined branch already defines Medication.ingredient.item as "The ingredient (substance or medication) that the ingredient.strength relates to" and says it may be represented as a code or as Substance, SubstanceDefinition, or Medication. That active StructureDefinition source satisfies the FHIR-23733 request after the later SubstanceDefinition refinement.

Recommendation:
Keep this no-change audit commit. Do not add duplicate local prose for basis of strength; revisit only if FHIR-53236 or another future Pharmacy decision changes the allowed Substance/SubstanceDefinition target model.
