FHIR-12232: Audit JSON Schema generation repairs

Issue request:
FHIR-12232 was a Published/Persuasive FHIR-core DSTU2 change request reporting invalid generated JSON Schemas: wrong boolean typing, missing base resources such as DomainResource, extension property naming problems, missing # fragments for external schema references, blank inheritance references, dotted element names, ResourceList/ResourceContainer inconsistency, untyped extension arrays, and missing code binding support. The Jira request said fixes would be checked into trunk, and the later Jira comment says the issue was fully resolved during the 2018 January WGM.

Initial application:
The issue has an explicit historical application commit: 2f573be67f84dc9fc721df2d62cd5b2e956c74ff, titled "Fixed JSON Schema generation issues", links the old GForge tracker item 12232 and changed the old in-repository JSON Schema generator to include base resources, normalize dotted names in schema file names, use ResourceContainer-style external references, and emit a ResourceList schema. Later January 2018 "fix json schema" commits 4757010487355c7ad9910dc788395f5a1d37d167 and 05bfe5879059bdbd9f7dee5594f67ec819c8c85e further repaired the old generator by excluding abstract resources from ResourceList branches, adding resourceType discriminator/required behavior, updating single-schema publication wiring, and updating downloads text.

Additional context:
The old Java SchemaGenerator touched by the historical fixes was removed from this core checkout in 2021 when the build switched to the Gradle Kindling dependency. Current build-scoped source still exposes the generated JSON Schema through source/downloads.html and source/validation.html, both active through publish.ini and source/hierarchy.xml. A current build.fhir.org fhir.schema.json.zip check shows one draft-06 schema with 704 definitions; ResourceList has only internal #/definitions references, no Resource or DomainResource abstract branches, one Parameters branch, and concrete resources require resourceType consts. Spot checks also found primitive extension sibling names such as _active, typed extension arrays, choice names without dots, and at least some code-valued enum generation. Closely related JSON Schema issues FHIR-13218, FHIR-14210, and FHIR-17696 are already represented on the combined branch and should not be duplicated here.
