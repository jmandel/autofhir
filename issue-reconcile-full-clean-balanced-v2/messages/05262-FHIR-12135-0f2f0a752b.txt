FHIR-12135: Audit Location bed-space terminology

Issue request:
FHIR-12135 was a Published/Persuasive Patient Administration change request for DSTU2 Location terminology. It asked to change the location-physical-type code bd definition from "A space that is allocated for sleeping/laying on." to "A space that is allocated for sleeping/laying on. This is not the physical bed/trolley that may be moved about, but the space it may occupy."

Initial application:
The issue was applied in commit 6b1a596ff1, whose subject names tracker 12135. That commit changed source/location/codesystem-location-physical-type.xml so code bd kept display "Bed" but gained the requested clarification that it is not the movable physical bed or trolley.

Additional context:
The current Location resource remains in build scope through source/fhir.ini, and Location.form binds to http://hl7.org/fhir/ValueSet/location-form. The current source/location/valueset-location-form.xml composes that value set from http://terminology.hl7.org/CodeSystem/location-physical-type. The old core CodeSystem source was later deleted by 5c0494aacf, "Phase 1 removing UTG Content from core build", so the code definition is now maintained in HL7 Terminology rather than as a core source file. The current THO CodeSystem-location-physical-type JSON has code bd display "Bed" with the exact accepted definition. The linked Zulip thread supports the same meaning: the Location is the bed place/space, while the movable bed itself is more like a Device. No Confluence reference or conflicting community record was found.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No core source hunk is needed because the active FHIR core Location binding points to THO, and the current THO definition already preserves the FHIR-12135 clarification.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-12135; any future change to the bd definition should be made through the terminology/THO maintenance path rather than by recreating a core CodeSystem source file.
