FHIR-6043: Audit Questionnaire populate subject type

Issue request:
FHIR-6043 was a Published/Persuasive FHIR-core Questionnaire correction from DSTU1. It asked that the Questionnaire.$populate subject input parameter be typed as Reference(Any), not Any, because callers should identify the subject resource by reference rather than supply the actual resource instance.

Initial application:
The Jira comments cite SVN #5941. In the git-svn history this is commit 26e8b597d5034f4372a848e5660a88268f4b664c, whose patch changed the then-active Questionnaire spreadsheet populate.subject row from Any to Reference while keeping the subject documentation that the resulting QuestionnaireAnswers/QuestionnaireResponse instance references the supplied subject.

Additional context:
Questionnaire and OperationDefinition are active resources in source/fhir.ini, but the current core Questionnaire operation list is empty. Later Published core issue FHIR-19606 intentionally moved the Questionnaire populate operations to the SDC implementation guide and added current Questionnaire narrative pointing readers to SDC for population-related advanced capabilities. The only remaining core surfaces found for Questionnaire-populate are an OperationDefinition derived-operation example and example populate request payload; both already represent subject as a Reference.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. The historical correction was applied, the authoritative core populate operation source was later removed from the current build by FHIR-19606, and the remaining current core examples do not say or imply that subject is an inline Any resource.

Recommendation:
Keep this audit commit as-is for FHIR-6043. Any future changes to the live Questionnaire-populate operation definition should be handled in the SDC IG issue path, while core should continue to avoid reintroducing a local Questionnaire.$populate operation definition unless the work group makes a new core-scope decision.
