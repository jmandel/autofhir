Issue request:
FHIR-11014 was a Published/Persuasive Clinical Genomics change request for the DSTU2 FamilyHistory area asking to add a genetics pedigree example. The resolution said to improve examples by replacing the visible "todo" text, correcting the v3 RoleCode usage, and completing the pedigree tree.

Initial application:
The issue was explicitly applied in git commit 214db1d0b45d4e107d4a12241b50446f50971948, which changed source/list/list-example-familyhistory-genetics-profile.xml for #11014 by removing the active To do narrative, adding display text for parent references, and changing the relatives/relationships to a complete simple pedigree. Later commit d1f387ce5e71114e7369ac9dd345022ded36edd0 updated that example from the old hl7.org/fhir/v3 RoleCode URL to the current terminology.hl7.org CodeSystem URL.

Additional context:
FamilyMemberHistory and List are both active current-build resources in source/fhir.ini. The genetics example is listed in source/list/list-List-examples.xml and linked from source/familymemberhistory/familymemberhistory-examples-header.xml, so the example is still part of the current source surfaces. FHIR-11139 separately changed the FamilyMemberHistory scope text to link to the genetic profile rather than the example, and FHIR-11138 added a separate double-cousin pedigree example; neither changes the FHIR-11014 simple pedigree decision. A 2017 Zulip implementers thread discussed how to read the pedigree extensions and did not identify a conflicting WG decision.
