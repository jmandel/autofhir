FHIR-14891: Audit Organization payer/insurer wording

Issue request:
FHIR-14891 was Published with a Persuasive with Modification resolution for STU3. The ballot comment asked that Practitioner and Organization definitions include payer/insurer, but the final resolution specifically directed the Organization resource description to include payer/insurer in the examples list.

Initial application:
The issue was applied in git commit acfae63649, which updated the then-authoritative Organization spreadsheet description from an examples list ending with healthcare practice groups to one that included payer/insurer. No separate Practitioner source change was made in that issue-specific commit, consistent with the final resolution focusing on Organization.

Additional context:
The current build actively includes both Organization and Practitioner in source/fhir.ini. Later applied issue FHIR-26381 intentionally shortened the Organization StructureDefinition description/definition and moved the example list, including payer/insurer, to the Organization Scope and Usage narrative. Current Organization source also includes insurer/payer examples. Community searches for FHIR-14891 with payer/insurer terms found no relevant Zulip or Confluence evidence that conflicts with the Jira/source history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active Organization page already tells implementers that Organizations include payer/insurer, and re-adding the examples list to the canonical StructureDefinition definition would reverse the later FHIR-26381 refactor rather than fix a current semantic omission. Practitioner remains unchanged because payer/insurer is an organization type in the accepted resolution; Practitioner already covers individuals involved in healthcare or related services, including funders in its purpose.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-14891 unless the PA work group later wants a new, broader change to duplicate organization examples back into conformance definitions or add explicit payer staff examples to Practitioner.
