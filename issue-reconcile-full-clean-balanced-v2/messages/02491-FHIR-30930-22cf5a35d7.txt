FHIR-30930: Correct contraindication applicability wording

Issue request:
FHIR-30930 was Applied/Persuasive for R5 by BRR to support boolean logic in ClinicalUseIssue indications. The accepted request added a top-level library canonical(Library) element and Expression-valued applicability elements under indication and contraIndication/contraindication so CQL or other expressions can say when the clinical use issue applies.

Initial application:
No git commit mentioning FHIR-30930 was found. That application carried the requested structure into the renamed ClinicalUseDefinition resource, but copied the indication short/definition text into the contraindication applicability element.

Additional context:
FHIR-30202 was the earlier nested-indication proposal and was retracted/replaced by FHIR-30930. BRR minutes for 2021-03-02 record acceptance of FHIR-30930 at 22-0-0. Zulip searches for the issue's ClinicalUseIssue/applicability/CQL terms found no conflicting discussion.

AutoFHIR reconciliation:
