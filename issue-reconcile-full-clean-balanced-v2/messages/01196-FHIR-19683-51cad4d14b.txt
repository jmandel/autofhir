FHIR-19683: Audit ImagingStudy PractitionerRole references

Issue request:
FHIR-19683 was a Published/Persuasive with Modification II change request asking to allow PractitionerRole as a possible reference for ImagingStudy.referrer and ImagingStudy.interpreter, update mappings and examples, add search parameters for both elements, and raise the broader practitioner-versus-PractitionerRole search question on Zulip.

Initial application:
The request appears to have been applied in commit 710e005513, which changed the then-authoritative ImagingStudy spreadsheet so referrer and interpreter used Reference(Practitioner|PractitionerRole) and populated the referrer and interpreter reference search parameters. Later source rework commits carried those definitions into source/imagingstudy/structuredefinition-ImagingStudy.xml and bundle-ImagingStudy-search-params.xml.

Additional context:
ImagingStudy is active in the current build. Current source keeps PractitionerRole on ImagingStudy.referrer, and the current series performer actor element, which is the surviving performer/practitioner surface in ImagingStudy, also allows PractitionerRole. Current source also has active referrer and performer reference search parameters. FHIR-38922 was later Published/Persuasive and removed ImagingStudy.interpreter plus its search parameter because interpreter belongs on associated DiagnosticReport or Composition resources, so re-adding interpreter would contradict a later final II decision. FHIR-19688 records the broader indirect Practitioner search concern, but it remains Waiting for Input and unresolved.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The remaining current ImagingStudy references that correspond to this issue already allow PractitionerRole, the relevant reference search parameters are present, and the removed interpreter element/search parameter should stay absent under the later FHIR-38922 decision. Adding a redundant PractitionerRole example now would not change conformance or fix a misleading current source location.

Recommendation:
Keep this no-change audit as-is. Do not reintroduce ImagingStudy.interpreter for FHIR-19683; any future work should happen through the unresolved search-design issue FHIR-19688 or a new work-group decision if examples are considered publication-critical.
