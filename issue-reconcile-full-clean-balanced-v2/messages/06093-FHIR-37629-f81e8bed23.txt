FHIR-37629: Audit search of-type typo fix

Issue request:
FHIR-37629 was a Published/Persuasive FHIR-core technical correction for the core search page. It reported that the token search example used GET [base]/Patient?identifier:otype=... and requested replacing the misspelled :otype modifier with the correct :of-type modifier for the Patient identifier example.

Initial application:
No source commit explicitly mentioning FHIR-37629 was found. The same typo family was already represented by FHIR-33422, and commit 38cfead26dd23a4261c1cfabe88975e5133d6fb5, "Apply FHIR-33422", changed the affected source/search.html summary-table example from identifier:otype to identifier:of-type for both GET and POST displays after FHIR-37629 was resolved.

Additional context:
The current source/search.html page is the active core search page, with source/fhir.ini's [search-rules] comments explicitly pointing maintainers to the search.html summary table. The page now defines the of-type modifier and uses identifier:of-type in both the detailed token-search example and the summary-table example. FHIR-33422 and FHIR-37690 are the same typo family and are already represented on the combined branch, so this commit does not duplicate their decisions. A 2020 Zulip implementers thread also identified identifier:otype as a typo and confirmed the correct modifier spelling is of-type; no direct FHIR-37629 Confluence or Zulip reference was found.
