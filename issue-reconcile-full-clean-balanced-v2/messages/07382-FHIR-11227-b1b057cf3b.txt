Issue request:
FHIR-11227 was a Published/Persuasive DSTU2 technical correction for FHIR-core DiagnosticReport. It asked that the Diagnostic Report Status note say individual data items should be final or appended, not final or amended, because the relevant status wording used appended.

Initial application:

Additional context:
DiagnosticReport remains an active resource in source/fhir.ini, so source/diagnosticreport/diagnosticreport-notes.xml is in current build scope. A same-family status alignment issue, FHIR-10344, was applied in the same 2016 status cleanup area, and current status terminology includes amended/corrected/appended distinctions, but no later evidence found during this bounded check reverses FHIR-11227's specific typo correction. Direct Zulip and Confluence searches for FHIR-11227 found no conflicting discussion.

AutoFHIR reconciliation:
No source change was made. The current active DiagnosticReport notes already say that a report should not be final until all individual data items reported with it are "final or appended," matching the published issue request and historical application.

Keep this empty audit commit as-is. Any broader reconsideration of DiagnosticReport and Observation status semantics should be handled under the later status-alignment issue family rather than reopening this completed typo correction.
