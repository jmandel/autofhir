FHIR-18362: Clarify unrecognized extension handling

Issue request:
FHIR-18362 was Published/Persuasive with Modification for N-Infra #50. It objected that recommendations to ignore unrecognized non-modifier extensions could be read as not storing or displaying them, and its final resolution replaced that guidance with a rule that applications SHOULD NOT reject instances with unrecognized non-modifier extensions, SHOULD preserve them when possible, and ignore them only when preservation is not possible.

Initial application:
Commit acbede90b7f03015ad54c2a1383b13d92a6bc6ec changed source/extensibility.html's exchange-rule bullet to the Jira resolution text. That initial application did not update the nearby Summary: Handling extensions bullet, which still told readers to "ignore other extensions" with only the FHIR-17699 modifier-extension exception.

Additional context:
The affected file is the active FHIR-core extensibility narrative page identified by Jira's related page and linked from current source navigation. FHIR-17699 is a same-page published clarification requiring the non-modifier guidance to preserve the special handling of modifier extensions. FHIR-I minutes from 2019-04-15 record that the group agreed to clarify that extensions should not be ignored, but can be ignored when processing is not possible. A 2021 Zulip thread shows implementers still quote the Summary section as guidance on unrecognized extensions, so leaving the old summary phrase in place could keep the ambiguity FHIR-18362 intended to remove.

AutoFHIR reconciliation:
Updated only the Summary: Handling extensions bullet in source/extensibility.html. The new wording says to read and process known extensions, preserve unrecognized non-modifier extensions when possible, ignore them only if preservation is not possible, and continue treating unrecognized modifier extensions as requiring the special handling described above.

Recommendation:
Keep this commit. It completes the published FHIR-18362 clarification in the current core extensibility page while preserving FHIR-17699's modifier-extension distinction; no broader extension-policy change is intended.
