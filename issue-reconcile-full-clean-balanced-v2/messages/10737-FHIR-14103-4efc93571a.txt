FHIR-14103: Correct identifier modifier definition

Issue request:
FHIR-14103 was Published as Persuasive with Modification for STU3. It asked for logical-reference search support by adding a reference search modifier, :identifier, that matches Reference.identifier, and for the search page to clarify that chaining, reverse chaining, and includes are only defined for references with explicit resolvable reference values rather than logical-only identifiers.

Initial application:
The issue was initially applied in git-svn commit 50ab308d337b68e176336b281e7179a935140d7a, corresponding to SVN revision 13428, which added :identifier prose and examples to source/search.html. Later search-page work retained and refined that rule, including FHIR-29410/FHIR-37424 identifier-chain clarification and FHIR-45252 non-Reference reference clarification. The current source/search.html text already distinguishes :identifier from chaining and says :identifier searches Reference.identifier.

Additional context:
The active search page links to the search-modifier-code CodeSystem as the authoritative modifier code system, and the active search-modifier-code ValueSet includes that CodeSystem. The CodeSystem's identifier concept still said the modifier applied to "the identifier on the resource, not the reference," which conflicts with the current search page, the original FHIR-14103 resolution, and later FHIR-29410/FHIR-37424 decisions that .identifier chaining searches the referenced resource while :identifier searches Reference.identifier.

AutoFHIR reconciliation:
Updated source/searchparameter/codesystem-search-modifier-code.xml so the identifier modifier definition says it applies to Reference.identifier instead of Reference.reference. No broader search-page wording was changed because later applied issues already carry the current chaining/include/canonical guidance.

Recommendation:
Keep this commit as-is. The edit fixes an active terminology definition that would otherwise mislead implementers about :identifier semantics while preserving later work-group decisions about chaining, includes, and canonical/non-Reference references.
