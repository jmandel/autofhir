FHIR-3532: Audit site search replacement

Issue request:
FHIR-3532 was a Published/Persuasive FHIR-core issue asking to address slow page loads and unusable specification search caused by the Google-powered "Search the FHIR Specification" function being blocked in some countries and regions. The Jira comments record that an inbuilt search replacement was needed and that the issue was applied in svn revision 7140 for DSTU1.

Initial application:
The historical application is present in git as commit 35b5a246572b0888bd84c0c8b89efe522e5bfd3b, whose subject is "#3532 - search related changes" and whose git-svn-id is build@7140. That commit replaced the old navbar Google-search placeholder with a generated search header/footer that linked to http://hl7.org/fhir/search.cfm instead of embedding the Google Custom Search JavaScript.

Additional context:
The old Java WebMaker implementation that emitted "Search the FHIR Specification" loaded http://www.google.com/jsapi and a Google CustomSearchControl, but that path is no longer present in the current build sources. Current shared templates use the publisher-supplied [%search-location%] link in the header, footer, and home page; the active CI-build search page is listed in publish.ini and source/hierarchy.xml and uses a DuckDuckGo iframe for build.fhir.org rather than Google Custom Search. Remaining current Google hits are unrelated examples/references or stale CSS selectors and do not load a blocked Google search service.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build source already satisfies the applied issue by avoiding the old Google Custom Search page-load dependency, and removing harmless leftover CSS selectors or unrelated Google references would not improve the specification behavior.

Recommendation:
Keep this audit commit as-is. If HL7 wants a fully self-hosted search experience rather than the current search-location/CI-search behavior, that would be a new site-platform decision, not remaining unapplied work from FHIR-3532.
