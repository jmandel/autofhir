FHIR-7759: Audit IG extension boundary clarity

Issue request:
FHIR-7759 was a Published/Persuasive FHIR-core clarification from the DSTU1 ballot asking that implementers be able to tell where core extensions ended and DAF or QICore extensions began, with an area for each defining body to describe extensions and make them reachable from profile publication.

Initial application:
No current commit explicitly mentions FHIR-7759. The issue was applied through the 2015 IG publishing reorganization rather than a Jira-tagged source patch: DAF and other IG content were moved out of resource-local core source into guide directories, the generated IG links were adjusted to subdirectories, and the profile/extension registry pages began listing implementation guides that define profiles and extensions.

Additional context:
The current R6 core source already distinguishes base/core content from IG content. The profiling page says core declares the common platform and base extensions, while implementation guides define additional profiles and extensions for particular contexts. The extensibility rules point implementers to the FHIR Extension Pack, implementation guides, registries, and extension publisher/contact metadata. The current build configuration has no active DAF or QICore profile/extension definitions in the core [profiles] or [extensions] sections, and the old DAF/QICore IG entries are commented out while the FHIR Extension Pack and current IG links are separate. Community searches found no Zulip or Confluence record contradicting the Jira/source/history conclusion.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Adding more prose to the core profiling page would duplicate current guidance and could imply that old DAF/QICore material should be re-owned by core, contrary to the publishing-paradigm resolution and current IG/Extension Pack split.

Recommendation:
Keep this audit commit as-is. Future DAF, QICore, or Extension Pack content problems should be handled in those IGs or their current repositories, not as a core source correction for FHIR-7759, unless a specific current core page becomes misleading.
