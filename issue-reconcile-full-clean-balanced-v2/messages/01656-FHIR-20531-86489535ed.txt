Initial application:

Additional context:
The current core source still builds Provenance as an active resource and its narrative says that multiple activities against one target are recorded as independent Provenance records. The current StructureDefinition has the activity-level Provenance.location element, but no Provenance.agent.location element or agent-location extension source. The 2021 source rework deleted the Provenance extension spreadsheet and introduced StructureDefinition XML for Provenance without migrating the historical agent-location extension. The FHIR Extension Pack checkout, which now contains moved core extensions, has no Provenance.agent location extension evidence. FHIR-32450 is a later AuditEvent-specific agent location decision and is already represented on the combined branch; it does not provide a Provenance extension.
