FHIR-31818: Clarify reference strength measurement point

Issue request:
FHIR-31818 was a Published/Persuasive FHIR-core BRR change request against MedicinalProductIngredient asking what measurementPoint means and requesting examples. The accepted resolution was to improve documentation, with the change applied for R5.

Initial application:
The R5 application happened in Ingredient after MedicinalProductIngredient was replaced by Ingredient. Commits 72c7bcfe and 464b98e6 explicitly mentioned FHIR#31818 and added the inhaler/point-of-aerosolization explanation to Ingredient.substance.strength.measurementPoint. That left the parallel Ingredient.substance.strength.referenceStrength.measurementPoint row with the original terse definition.

Additional context:
source/fhir.ini lists Ingredient as an active current-build resource and maps the historical MedicinalProductIngredient artifact to Ingredient. The old MedicinalProductIngredient source contained both specifiedSubstance.strength.measurementPoint and specifiedSubstance.strength.referenceStrength.measurementPoint, so the reference-strength row is in the same artifact family rather than an unrelated new feature. FHIR-31819 separately improved the referenceStrength parent definition, and later strength datatype changes did not address measurementPoint wording. Zulip and Confluence searches found no WG/community evidence that narrows FHIR-31818 to only the non-reference-strength row.

AutoFHIR reconciliation:
This commit applies the same already-approved explanatory measurementPoint wording to Ingredient.substance.strength.referenceStrength.measurementPoint, the remaining active parallel source location.

Recommendation:
Keep this source fix. It completes the documented FHIR-31818 clarification in the active Ingredient resource without changing cardinality, datatypes, bindings, or conformance semantics.
