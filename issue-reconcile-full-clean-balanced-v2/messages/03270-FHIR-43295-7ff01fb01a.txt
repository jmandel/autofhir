FHIR-43295: Audit RESTful linking clarification

Issue request:
FHIR-43295 was an Applied/Persuasive with Modification FHIR-I change request for R6 asking to clarify that document and message Bundle "must link" requirements are satisfied through RESTful references, not through arbitrary business-identifier resolution. The approved resolution required messaging text to describe a connected graph using Reference.reference, canonical, or URI links including MessageHeader, and document text to say supporting-information references SHALL use Reference.reference, canonical, or URI.

Initial application:

Current source still contains that substantive wording: messaging.html requires a connected graph of RESTful references including MessageHeader, and documents.html requires the composition/supporting-information graph to use Reference.reference, canonical, or URI references.
