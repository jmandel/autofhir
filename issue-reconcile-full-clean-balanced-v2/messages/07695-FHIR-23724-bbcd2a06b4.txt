FHIR-23724: Audit Group membership basis

Issue request:
FHIR-23724 was Published with a Persuasive with Modification resolution asking to replace Group.actual with a required code element that distinguishes definitional groups from enumerated groups and to remove the old constraint that only permitted members when Group.actual was true.

Initial application:
Commit f02cddf023a4461f3a78f7e71cd870771a8b0b7d explicitly applied FHIR-23724 by replacing Group.actual with Group.membership, adding the required group-membership-basis CodeSystem and ValueSet, updating examples/search parameters, and removing the grp-1 member/actual constraint.

Additional context:
The Group resource is active in source/fhir.ini. Later applied Group work for FHIR-41583 added the current third Group.membership code, conceptual, and relaxed Group.type with an invariant; FHIR-41487 subsequently dropped the ActualGroup and GroupDefinition profiles. Those later decisions refine the same artifact but do not undo the FHIR-23724 distinction between characteristic-defined and enumerated membership.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/group/structuredefinition-Group.xml already defines Group.membership as 1..1 code bound required to the group-membership-basis ValueSet, its definitional and enumerated definitions preserve the FHIR-23724 semantics, and the obsolete Group.actual element and member-only-when-actual constraint are absent.

Recommendation:
Keep this audit commit as-is. No further FHIR core change is needed for FHIR-23724 unless a future work group decision revisits the later conceptual membership model.
