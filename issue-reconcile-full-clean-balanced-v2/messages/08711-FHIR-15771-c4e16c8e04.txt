FHIR-15771: Audit canonical reference search wording

Issue request:
FHIR-15771 was a Published/Persuasive FHIR-I STU3 change request about StructureDefinition.valueset being a reference search parameter even though StructureDefinition.snapshot.element.binding.valueSet is a uri/canonical. The accepted resolution was not to change the search parameter type, but to clarify the reference search-type prose so that canonical URLs are valid reference-search inputs.

Initial application:
The issue was applied in git-svn commit 1110a6d071eecfb8e495cea77246e3df62545588 / SVN r14045, which changed source/search.html to say that the [url] reference-search form may identify a resource by absolute location or by canonical URL. The current StructureDefinition search parameter bundle still defines StructureDefinition-valueset as type reference over StructureDefinition.snapshot.element.binding.valueSet.

Additional context:
Later search-page work retained and expanded the same interpretation: FHIR-36715 corrected the canonical URL wording and added versioned canonical syntax, while FHIR-29410/FHIR-37424 added a Canonical Identifiers section that explicitly says canonical-reference searches use the reference search type. The current source/fhir.ini includes SearchParameter and StructureDefinition as active resources, so the checked source is in current build scope. Exact-key Zulip and Confluence searches found no conflicting community discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source already satisfies the final Jira decision: source/search.html permits canonical URLs and versioned canonical syntax for reference search parameters, and source/structuredefinition/bundle-StructureDefinition-search-params.xml correctly keeps StructureDefinition-valueset as a reference search parameter.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-15771 unless the work group later changes the broader canonical search model; the current specification matches the published resolution and later clarifications.
