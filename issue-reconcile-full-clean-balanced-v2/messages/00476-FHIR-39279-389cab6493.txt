FHIR-39279: Audit VisionPrescription OO ownership

Issue request:
FHIR-39279 was a Published FHIR-core change request for the R4-era VisionPrescription resource. The request asked to drop VisionPrescription because DeviceRequest examples could cover vision orders, but the final Not Persuasive with Modification resolution for R5 was to retain the resource and move ownership/custodianship from Financial Management to Orders and Observations.

Initial application:
The issue appears to have been applied by commit 47a373597dc7b1c66918744f49ec1a241ac0dd56, which changed source/fhir.ini from visionprescription=fm to visionprescription=oo. Current build configuration still includes VisionPrescription as an active resource and assigns its work group to OO; the StructureDefinition also carries the OO work group extension and OO publisher contact.

Additional context:
FMG minutes referenced by Jira describe FHIR-39279 as changing ownership of Vision Prescription from FM to OO and state that any editor from FM or OO could make the R5 change. OO minutes and DeviceRequest source keep the DeviceRequest lens examples as illustrations of overlap while still saying VisionPrescription has specific lens details. Later related Jira FHIR-26948 was resolved No Change with the note that VisionPrescription is staying as a separate resource, so no later final decision found in this bounded search supersedes retention.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Removing VisionPrescription would contradict the final FHIR-39279 resolution and later related evidence; adding more prose would be redundant because the authoritative build metadata and nearby DeviceRequest/VisionPrescription narrative already express the current state.

Recommendation:
Keep this no-change audit commit as-is. Revisit only if a later Applied or Published tracker explicitly retires VisionPrescription or changes its OO ownership; no such final core issue was found in this reconciliation.
