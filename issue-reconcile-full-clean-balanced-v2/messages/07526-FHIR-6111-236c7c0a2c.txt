FHIR-6111: Audit enteral formula rate adjustment disposition

Issue request:
FHIR-6111 is a Published FHIR-core NutritionRequest/NutritionOrder change request resolved Persuasive with Modification. It asked to change the rate-change/rateAdjustment datatype from Quantity to a rate representation because rate adjustments can require arbitrary volume-over-time expressions, and its final resolution says to use FHIR-6100 for disposition.

Initial application:
The issue was pre-applied with FHIR-6100 in historical NutritionOrder commits. Commit 6497963440 changed the spreadsheet so enteralFormula.rate was Quantity and rateAdjustment was Ratio, and commit 9a331d0ab4 then replaced the separate rate/rateAdjustment shape with repeating enteralFormula.administration and administration.rate[x] typed Quantity|Ratio. The current StructureDefinition source retains committee notes for #6100/#6111 on the administration and rate elements.

Additional context:
FHIR-6100 supplied the controlling disposition: create a repeating administration complex element with quantity, rate, and schedule. The resource name later changed to NutritionRequest and back to NutritionOrder, and source/fhir.ini currently lists nutritionorder=NutritionOrder as an active resource. Current notes explain that varying rate or quantity over time is represented by repeating enteralFormula.administration, not by a separate rateAdjustment element.

AutoFHIR reconciliation:
No source change was made. The current active source already satisfies FHIR-6111 by removing the old rateAdjustment element and representing rate changes with repeated administration entries whose rate[x] can be Quantity or Ratio.

Recommendation:
Keep this audit commit as-is. The current specification implements the approved issue-family outcome; no additional core source edit is needed.
