FHIR-49688: Audit BDP terminology metadata

Issue request:
FHIR-49688 was an Applied/Persuasive FHIR-core technical correction for R6 asking that BiologicallyDerivedProduct and BiologicallyDerivedProductDispense value sets use consistent maturity and flag metadata: remove experimental flags, remove immutable flags from the BDP category/product/status value sets, set the affected value sets to maturity level 1, and fix the discarded BiologicallyDerivedProduct status code casing.

Initial application:
There was no prior AutoFHIR reconciliation commit for this issue. The Jira was applied in source by aa3c7a15e5, which set the affected value sets and related code systems to FMM 1/informative metadata, changed immutable true values to false, and changed the BDP status code from Discarded to discarded. Follow-up commits b9034f9085 and 1d62083442 harmonized active status/version metadata and restored the affected code systems to complete after example content prevented value set expansion.

Additional context:
The current build actively includes BiologicallyDerivedProduct, while BiologicallyDerivedProductDispense was removed from active core build configuration by 3b38b80cf2 and the active BDP introduction now says that resource moved to the OO Incubator IG. The later related FHIR-49979 records that the experimental element was intentionally left as false because of tooling and raises a separate, still Resolved - change required question about ISBT-related code system completeness and canonical URLs; that later question is not in this run's Applied/Published source-edit scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active BDP value set sources now carry FMM 1, are not experimental, and are not immutable where FHIR-49688 targeted immutability; the BDP status code system has the lowercase discarded code. The out-of-build BDPDispense source copies also have the requested non-experimental/FMM 1 metadata, but they no longer define current core build output.

Recommendation:
Keep this audit commit as-is for FHIR-49688. Revisit the separate code-system-completeness/canonical-url work under FHIR-49979 only when that issue reaches an Applied/Published state or is otherwise explicitly brought into scope.
