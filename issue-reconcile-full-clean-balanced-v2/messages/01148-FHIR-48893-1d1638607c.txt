Issue request:
FHIR-48893 was an Applied/Persuasive with Modification FHIR-core ClinicalUseIssue change request from BRR for R6. It asked for ClinicalUseDefinition invariants ensuring that each detailed backbone element can appear only when the required type code has the corresponding value, while not making the matching backbone mandatory.

Initial application:
The source history contains git commit 9fe57dc4a4d, whose subject explicitly includes FHIR-48893. That commit added cud-2 through cud-6 to source/clinicalusedefinition/structuredefinition-ClinicalUseDefinition.xml, one constraint each for contraindication, indication, undesirableEffect, interaction, and warning. The same commit also included unrelated FHIR-31520 comorbidity wording, which is not decided here.

Additional context:
