Issue request:
FHIR-5225 was a Published/Persuasive DSTU1 ballot clarification asking that overview-dev section 1.9.1.2 not be headed "Example: Patient" and instead use a more generic resource-oriented heading because the patient example introduced general resource attributes.

Initial application:

Additional context:
The active current build still includes overview-dev.html through publish.ini and the source hierarchy. Later source history for FHIR-11033 clarified the same introductory section's resource type versus resource instance language and changed the heading to "Example Resource Instance". Searches for directly relevant Zulip and Confluence discussion found no conflicting community guidance.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current heading is generic, no longer patient-specific, and accurately describes the section's patient JSON as an example resource instance while preserving the general attribute explanation below it.

Recommendation:
Keep this no-change audit as-is. Replacing the current heading with "Resource Definitions" would be less precise now because the canonical Resource Definitions material lives on formats.html/resource-related pages, while this overview section is specifically an example instance in the developer introduction.
