FHIR-40278: Audit EvidenceReport author Person removal

Issue request:
FHIR-40278 was a Published/Persuasive FHIR-core CDS change request for R5 stating that Person is never allowed as a participant actor target and that EvidenceReport author must use role-specific human targets. The accepted disposition was to replace Person in the EvidenceReport author element with Patient, Practitioner, PractitionerRole, and RelatedPerson, or alternatively remove EvidenceReport.

Initial application:
Commit 5aaea4cd29083bcdc02bbcc54b710015b18d5137 explicitly applied FHIR-40278 to source/evidencereport/structuredefinition-EvidenceReport.xml by replacing the Person target on EvidenceReport.section.author with Patient, Practitioner, PractitionerRole, and RelatedPerson. That superseded the narrower FHIR-34883 request that had asked for Practitioner in the same element.

Additional context:
FHIR-31867 later deprecated EvidenceReport and the current R6 source removed the source/evidencereport folder. Current source/fhir.ini no longer contains active EvidenceReport entries, source/history.html identifies EvidenceReport as removed, and current CDS narrative says the prior EvidenceReport resource has been replaced by an EvidenceReport Profile of Composition in the EBM IG.

AutoFHIR reconciliation:
This audit commit makes no source change. The historical FHIR-40278 edit was applied while EvidenceReport still existed, and the current build now satisfies the issue by not carrying the EvidenceReport resource at all.

Recommendation:
Keep this audit commit as-is. No current core source edit is needed for FHIR-40278; if the EBM IG's EvidenceReport Composition profile has comparable author-target constraints, that should be reviewed in that external IG rather than in core.
