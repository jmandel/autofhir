FHIR-20194: Audit OperationDefinition canonical URL wording

Issue request:
FHIR-20194 was a Published FHIR-core change request with Persuasive with Modification resolution. It observed that operation definition pages described examples such as http://hl7.org/fhir/OperationDefinition/Resource-validate and http://hl7.org/fhir/OperationDefinition/Patient-everything as an "official URL" even though canonical URLs are not guaranteed to resolve directly; the approved resolution was to say "canonical URL" and rely on the canonical resolution guidance.

Initial application:
The issue was explicitly applied in git commit 6b0a5cd0facd39e897a6f470f78192b5a79150f2, which changed tools/templates/template-profile.html from "The official URL for this profile is:" to "The canonical URL for this profile is:". Current blame for that active template line points to the FHIR-20194 commit. No separate current source application was found for an operation-definition-specific phrase, but the current active source no longer contains the reported "official URL for this operation definition" wording.

Additional context:
OperationDefinition is an active resource in source/fhir.ini, and current operation definition XML sources continue to expose canonical url elements for operations. Searches of current active source excluding release-history, publish, temp, and tmp artifacts found no "official URL for this operation definition" or "official URL for this profile" wording. Historical release archives under tools/history still preserve old published release text and are not current-build source. Jira search found only FHIR-20194 plus an unrelated FHIR-ips issue for the exact OperationDefinition/canonical/official URL combination, and Zulip/Confluence searches found no direct FHIR-20194 discussion or conflicting work-group decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already uses canonical URL terminology in the applied template location and does not retain the operation-definition official-URL wording that FHIR-20194 asked to correct.

Recommendation:
Keep this audit commit as-is. Do not edit historical release archives. If a future rendered current operation page reintroduces "official URL" wording for operation definitions, trace the renderer that emits that page rather than changing OperationDefinition canonical url values.
