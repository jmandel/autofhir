FHIR-46568: Audit Specimen.subject NutritionProduct target

Issue request:
FHIR-46568 was an Applied/Persuasive OO change request asking whether Specimen.subject should allow NutritionProduct for use cases such as testing pasteurized milk represented as a NutritionProduct. The approved motion was to add NutritionProduct as a target choice for Specimen.subject to enable a nutrition product to be tested.

Initial application:
The issue was already applied in source before this reconciliation. Git history shows 5deb61ebacaec61d6988e6f4da0846956c6c564e adding the NutritionProduct targetProfile to source/specimen/structuredefinition-Specimen.xml for jdlnolen-FHIR-46568; the Jira comment points to PR merge/branch commit a03faa16daf298129f0745944313e21a0e0569d1 as the build application.

Additional context:
Specimen is an active resource in source/fhir.ini, and NutritionProduct is also active in the current resource list and abbreviation map. Current source includes NutritionProduct in Specimen.subject. Later Specimen refactoring added Specimen.focus and retained the NutritionProduct subject target, so the requested target choice was not lost. OO minutes for 2024-08-12 record that FHIR-46568 was voted on and that no additional NutritionProduct or BiologicallyDerivedProduct references were needed; related FHIR-46604/FHIR-46613 boundary tickets clarify the NutritionProduct versus BiologicallyDerivedProduct human-milk scope without changing the Specimen.subject target decision.
