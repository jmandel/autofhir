FHIR-7663: Audit common data exchange guide

Issue request:
FHIR-7663 was a Published/Persuasive FHIR-core change request asking for guidance on how common healthcare data types, such as billing data, laboratory results, problem lists, and encounter diagnoses, should be represented without forcing implementers to infer this from individual resource pages. The accepted resolution was to do this as part of resourceguide.html.

Initial application:
The historical implementation is commit bb5e3f2a9fcb50aecda21994cda00fdc6981b0c8, the git-svn revision 6741 commit whose subject says "#7663 & #5374 - draft resource guide". That commit added the "Where to find common concepts" table to source/resourceguide.html, including Laboratory Results, Clinical Diagnosis, and other common clinical concept mappings.

Additional context:
The current source still builds resourceguide.html: publish.ini lists resourceguide.html and source/hierarchy.xml includes the Resource Guide page. Later FHIR-43371 clarified that this page is intentionally a subset of common clinical terms, not a full list of all FHIR resources, and updated the intro accordingly. Broader Resource Guide completion issues FHIR-7477, FHIR-7290, and FHIR-7038 are already represented on the combined branch, so this audit does not duplicate those decisions.

AutoFHIR reconciliation:
This commit makes no source change. The current source already contains the resource guide table that implements the FHIR-7663 request at the level now intended for the page, and adding a new exhaustive billing/problem-list catalog would conflict with the later decision to keep the page scoped as a subset guide.

Recommendation:
Keep this no-change audit. Future additions to the common-concepts table should be made through a new work-group decision for specific concept coverage, rather than reopening the broad 2015 request.
