FHIR-31508: Audit MedicationStatement partOf reversal

Issue request:
FHIR-31508 was a Published/Persuasive Pharmacy change request raised against R4 MedicationStatement/MedicationUsage. It asked how a medication usage statement could sensibly be part of a MedicationAdministration, MedicationStatement, or MedicationDispense, and its resolution was to remove the .partOf attribute and use basedOn or derivedFrom for the existing use cases instead.

Initial application:
The request was applied in git commit 7453f87bfcb5eeba6020113412508cb95e5d4f0a, whose subject included FHIR-31508. That commit removed MedicationUsage.partOf from source/medicationusage/structuredefinition-MedicationUsage.xml, removed the MedicationUsage part-of search parameter, and removed example partOf content.

Additional context:
FHIR-36001 was later Published/Persuasive and explicitly says FHIR-31508 overlooked a use case where MedicationUsage is part of a procedure; its resolution restored partOf constrained to Procedure. FHIR-38690 was later Published/Persuasive and added a MedicationUsage-to-MedicationUsage parent/child use case with examples. FHIR-38682 then renamed MedicationUsage back to MedicationStatement, so the current active source is MedicationStatement. The current R6 source/fhir.ini lists medicationstatement as an active resource, and source/medicationstatement/structuredefinition-MedicationStatement.xml now intentionally has MedicationStatement.partOf as Reference(Procedure|MedicationStatement). FHIR-57403 has since been Submitted asking whether to explain or remove this element, but it is unresolved and does not provide a final source-edit decision.

AutoFHIR reconciliation:
This commit makes no source change. Removing MedicationStatement.partOf now would undo the later final decisions in FHIR-36001 and FHIR-38690 rather than complete FHIR-31508.

Recommendation:
Keep this audit commit as-is. Revisit the element only if Pharmacy resolves FHIR-57403 or another final tracker with new instructions about explaining or removing MedicationStatement.partOf.
