FHIR-13934: Audit Questionnaire reference profile guidance

Issue request:
FHIR-13934 was a Published/Not Persuasive with Modification FHIR-core Questionnaire change request from STU3, applied for R5, asking to promote the questionnaire allowedProfile extension into core as Questionnaire.item.profile for reference items. The final decision declined a core element, kept guidance in SDC, and asked that core Questionnaire-related extensions point implementers to SDC guidance.

Initial application:
The linked Zulip discussion records the compromise: limiting reference answers by profile is useful but too narrow for a core element, the existing extension should be used, and documentation should make filtering options clearer. Core commits ca66dbfb43 and 15a7574205 applied that direction by adding SDC guidance links to Questionnaire-specific extension definitions and to other extension definitions with Questionnaire guidance.

Additional context:
Questionnaire remains an active core resource, but current source/fhir.ini no longer registers the old Questionnaire extension definition files as active core profiles. Commit dd468d4f17 removed Questionnaire extension definitions from the R5 source, and the current FHIR Extension Pack source contains questionnaire-referenceProfile with Questionnaire.item and ElementDefinition context, a canonical StructureDefinition value, and an SDC behavior link. Current core Questionnaire prose already points to SDC and notes that SDC extensions cover min, max, type.targetProfile and constraint.

AutoFHIR reconciliation:
This empty commit intentionally makes no source change. Adding Questionnaire.item.profile would contradict the final Jira decision, and reintroducing or editing the questionnaire-referenceProfile definition in core would duplicate an artifact now maintained in the Extension Pack; the current core and Extension Pack sources already convey the intended implementation path.

Recommendation:
Keep this audit commit as-is. Future changes to the reference-profile extension itself should be made in the FHIR Extension Pack and coordinated with SDC guidance, not by adding a core Questionnaire element.
