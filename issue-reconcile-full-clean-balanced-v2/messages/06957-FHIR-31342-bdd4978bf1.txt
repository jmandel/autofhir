FHIR-31342: Audit extension SearchParameter expressions

Issue request:
FHIR-31342 was a Published/Persuasive technical correction for FHIR-core SearchParameter. It reported R4 package SearchParameter resources for CodeSystem, ValueSet, and Patient extension search parameters that had XPath but no FHIRPath expression, and asked either to remove the draft parameters or provide FHIRPath expressions.

Initial application:
The issue was applied by PR #2143 in commit 5db7e943dfc9a252dac37ec83139206754e9dc95, which added FHIRPath expressions to the listed core source SearchParameter XML files and included the Patient age companion search parameter. Later source history removed XPath usage from those files in commit 88a1f3d6bd60f7618ae140179b008ac5686e8a08.

Additional context:
The current core build no longer contains the listed SearchParameter source files; commit b7e37c11e1a1480180a2265381dac9c31e443ce1 deleted them while linking resource search pages to the search parameter registry. The authoritative current core SearchParameter definition contains expression and processingMode but no xpath element, and fhir.ini records SearchParameter.xpath as removed. The corresponding extension SearchParameter definitions now live in the FHIR Extension Pack, where each listed parameter has an expression and no xpath.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current FHIR core source has no remaining XPath-only version of the listed SearchParameters, and the extension-pack copies preserve the resolved FHIRPath expressions outside this repository.

Recommendation:
Keep this no-change audit commit. No core follow-up is needed for FHIR-31342 unless a future build reintroduces XPath-only SearchParameter definitions; any future adjustments to these extension search parameters should be made in the FHIR Extension Pack, not by restoring retired core files.
