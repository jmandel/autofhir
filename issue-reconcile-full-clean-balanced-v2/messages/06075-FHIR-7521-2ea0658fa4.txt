FHIR-7521: Correct current ICD-9-CM system URL references

Issue request:
FHIR-7521 is a Published/Persuasive Vocabulary change request for the DSTU1 terminology systems page. It asked to sort out the correct URLs for the various ICD-9 versions because the page was confused about them; the Jira resolution was "approved as edited" with svn revision 6372 recorded as the application point.

Initial application:
Historical git-svn commit e2e7b1ea09020c8286800fc4fc62451eb5df21e7 applied FHIR-7521 together with FHIR-6629 in svn revision 6372. That commit changed source/terminologies-systems.html from a single http://hl7.org/fhir/sid/icd-9 row to ICD-9-CM root, diagnosis, and procedure URIs, establishing that the old root ICD-9 wording was not the intended final table content.

Additional context:
FHIR-8903/FHIR-8904 later fixed and audited the old ICD-9-CM diagnosis URI typo, and FHIR-20193/FHIR-41305 later reworked the current ICD row after the detailed local ICD rows were collapsed into THO guidance. FHIR-41305 specifically reaffirmed that the current URI column should show http://hl7.org/fhir/sid/icd-9-cm and http://hl7.org/fhir/sid/icd-10. Current THO NamingSystem records also identify http://hl7.org/fhir/sid/icd-9-cm as the preferred URI for active ICD-9-CM diagnosis/procedure code systems. The active Code Systems page already showed that URI, but its linked ICD-9 detail page and one active ServiceRequest example still used the older http://hl7.org/fhir/sid/icd-9 form.

AutoFHIR reconciliation:
This commit updates source/sid-icd-9.html so the title, heading, and URL sentence identify ICD-9-CM and http://hl7.org/fhir/sid/icd-9-cm, matching the active Code Systems table. It also updates the active ServiceRequest lipid example's ICD-9-CM diagnosis coding system to http://hl7.org/fhir/sid/icd-9-cm. Retired/out-of-build ServiceDefinition, ClinicalAssessment, and ClinicalImpression examples were intentionally left unchanged.

Recommendation:
Keep this source fix. It completes the old FHIR-7521 correction in the current build without reopening the broader ICD terminology policy now maintained through THO. If any retired artifacts are revived, review their legacy ICD-9 URI examples separately at that time.
