FHIR-11376: Audit ClaimResponse package code rename

Issue request:
FHIR-11376 is a Published/Persuasive FM change request from the DSTU2 ballot asking to rename the `drg` attribute in diagnosis to `packageCode` for ClaimResponse, following the consistent-package-code naming decision recorded with FHIR-11375.

Initial application:
The Jira-tagged implementation commit d06f8787e6 (`Tracker #11375, 11376, 11391, 11392`) renamed `Claim.diagnosis.drg` to `Claim.diagnosis.packageCode` and made the parallel ExplanationOfBenefit rename in the historical spreadsheet sources. That commit did not add or retain a current `ClaimResponse.diagnosis.drg` or `ClaimResponse.diagnosis.packageCode` element.

Additional context:
ClaimResponse is an active resource in `source/fhir.ini`. The current ClaimResponse StructureDefinition has `ClaimResponse.diagnosisRelatedGroup` as a root `CodeableConcept` package billing code and no `ClaimResponse.diagnosis` package-code child. The later Published/Persuasive FM issue FHIR-29688 explicitly superseded the diagnosis-child location by adding `diagnosisRelatedGroup` at the root of Claim, ClaimResponse, and ExplanationOfBenefit and removing `resource.diagnosis.packageCode`; commit acb64eec3c applied that later decision to ClaimResponse.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the obsolete `drg` diagnosis attribute is absent and the current build already carries the later approved root-level DRG/package-code element.

Recommendation:
Keep this audit commit as-is. Do not reintroduce `packageCode` under `ClaimResponse.diagnosis`; if FM wants another modeling change, it should be handled as a new post-FHIR-29688 decision.
