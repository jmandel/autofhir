FHIR-39576: Audit moved immunization description scope

Issue request:
FHIR-39576 was a Published FHIR-core PHER change request resolved Persuasive with Modification for R5. It asked that ImmunizationEvaluation.description and ImmunizationRecommendation.recommendation.description use markdown instead of string, and the accepted disposition also said the ImmunizationRecommendation.recommendation.description short display and definition should read "Recommendation notes." and "Contains additional information about the recommendation."

Initial application:
The issue was applied in core by commit 1cd64a9e38375394799cf32aad59044410833f2f, which changed both requested .description element type codes from string to markdown in the ImmunizationEvaluation and ImmunizationRecommendation StructureDefinitions. The same commit also included unrelated FHIR-39442 immunization value set work. R5 published profiles confirm both affected elements are markdown, but the secondary ImmunizationRecommendation.recommendation.description short/definition text remained the older protocol wording.

Additional context:
FHIR-38714 established that converting optional string elements to markdown is considered compatible and led to this family of review issues. PHWG minutes for 2023-01-17 record the 23-0-0 motion for FHIR-39576 and make clear that the intended secondary wording applied to recommendation.description. Current core no longer defines ImmunizationEvaluation or ImmunizationRecommendation: commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed both resource source folders and active fhir.ini entries, while current module/history narrative links the resources to the external HL7 immunization-incubator IG. The only remaining core hits for these element names are non-authoritative compatibility mappings, narrative links, or stale workflow-warning suppressions, not current StructureDefinition source.

AutoFHIR reconciliation:
This commit intentionally makes no source change in FHIR core. The current build has no in-scope core StructureDefinition elements where the requested datatype or short/definition change can be applied, and editing stale generated/maintenance references would not change implementer-facing conformance. The relocated external incubator definitions already retain markdown for both affected elements; if the exact short/definition wording still matters, that follow-up belongs in the external immunization-incubator source rather than this core checkout.

Recommendation:
Keep this audit commit as-is for core. PHWG or the immunization-incubator maintainers should decide whether to update the relocated ImmunizationRecommendation.recommendation.description short/definition text; no FHIR-core source edit is warranted unless the resources are reintroduced into the core build.
