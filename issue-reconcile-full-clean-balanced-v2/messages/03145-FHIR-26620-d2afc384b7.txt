FHIR-26620: Audit NamingSystem example link fix

Issue request:
FHIR-26620 was a Published/Persuasive Vocabulary change request for R5. It reported that the NamingSystem examples page showed the third example as "Common US Driver's license identification" while the link pointed to namingsystem-registry.html, and the resolution agreed the example link/label mismatch needed to be fixed.

Initial application:
The issue was applied in commit 25159ea161eaed360cf05d040c52d38e80cdcbac, which included FHIR-26620 in a NamingSystem R5 change batch and changed the examples list entry description from "Common US Driver's license identification" to "Examples of naming systems for Common US identification" while leaving the registry example target intact. Later R5 history then removed the registry example from the active examples list entirely.

Additional context:
NamingSystem is active in source/fhir.ini, and source/namingsystem/list-NamingSystem-examples.xml is the current examples-list source for the active resource. FHIR-37889 determined that the NamingSystem registry and terminologies bundles should be removed to avoid confusion, and FHIR-40117 completed removal of the empty namingsystem-registry.xml file and the registry entry from the examples list. Current CI-rendered examples show only the code-system, identifier, and metadata examples, with no Common US Driver's license or registry row.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active NamingSystem examples source no longer contains the original mismatched description or registry example, and the rendered examples page links the remaining examples to their corresponding NamingSystem example pages.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-26620 in core; any separate concern about later metadata example details should be handled under a separate tracker rather than reopening the resolved driver-license/registry mismatch.
