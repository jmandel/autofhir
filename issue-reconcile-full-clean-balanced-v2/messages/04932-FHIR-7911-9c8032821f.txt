FHIR-7911: Audit MedicationStatement derivation link

Issue request:
FHIR-7911 is a Published/Persuasive with Modification Pharmacy change request from the DSTU1 ballot. It asked for a way to tell whether a MedicationStatement came from patient-reported information or from an underlying prescription/administration/dispense-style record, and the accepted resolution added MedicationStatement.supportingInformation as a 0..* Reference(Any) with likely references such as MedicationPrescription, MedicationDispense, Claim, Observation, and QuestionnaireAnswers.

Initial application:
The issue was applied in git commit 30268c3a5ac73f9b6472e930cdb9d11ee5c4c710, matching the Jira comment "svn 6623". That commit added MedicationStatement.supportingInformation to the then-authoritative MedicationStatement spreadsheet as 0..* Reference(Any) with the requested likely-reference comment.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. Later Published Pharmacy issue FHIR-11185 renamed supportingInformation to derivedFrom and kept the derivation link as the Reference(Any)-style element, while source/fhir.ini still maps MedicationStatement.supportingInformation to MedicationStatement.derivedFrom for version migration. Later FHIR-12536 and current narrative also explain that MedicationStatement may be derived from supporting information such as Claim, Observation, or MedicationRequest.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope StructureDefinition already has MedicationStatement.derivedFrom at 0..* Reference(Resource), which is the current representation of the same Any-resource link, and its definition/comment preserve the ability to link MedicationRequest, MedicationDispense, Claim, Observation, QuestionnaireResponse, or other supporting derivation resources.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-7911; changing the element name back to supportingInformation would contradict the later published FHIR-11185 rename and current migration metadata.
