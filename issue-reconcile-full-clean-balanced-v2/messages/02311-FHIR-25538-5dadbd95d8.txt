FHIR-25538: Audit MedicationAdministration scope update

Issue request:
FHIR-25538 was a Published/Persuasive with Modification Pharmacy change request for R5 asking to review and update the MedicationAdministration Scope and Usage text. The approved wording removed the awkward "record the capture of" phrase, changed "intra-venous adjustments" to intravenous infusions, added a note that medication-coated devices are not typically MedicationAdministration while medication delivered by an implanted medication pump is, and initially described the resource as covering medications and vaccines while referring vaccine treatment to Immunization.

Initial application:
The issue was applied by git commit a9dffd224e0795a95e525dd761215701cecf804b, which explicitly mentioned FHIR-25538 and updated source/medicationadministration/medicationadministration-introduction.xml with the approved medication-administration wording and pump-device note. The current active source retains those substantive changes in the MedicationAdministration Scope and Usage narrative.

Additional context:
MedicationAdministration is an active resource in source/fhir.ini. FHIR-25538 was split out of the broader duplicate tracker FHIR-24099, and Pharmacy minutes on 2020-01-20 record the MedicationAdministration-specific scope review text that became the Jira resolution. A later Published Pharmacy clarification, FHIR-32960, intentionally removed "and vaccines" from the opening sentence and aligned the MedicationAdministration/Immunization boundary so vaccine administrations point to Immunization while permitting MedicationAdministration for workflow reasons with an equivalent Immunization instance. That later clarification has already been reconciled on the combined branch by commit b7214bc5256739e402b4118bf12c9492f9291cbd.

AutoFHIR reconciliation:
This audit commit makes no source change. The current MedicationAdministration narrative already contains the FHIR-25538 wording changes that still apply, and the one apparent mismatch with the 2020 resolution, the omission of "and vaccines" from the opening sentence, is explained by the later final FHIR-32960 clarification rather than by an unapplied FHIR-25538 defect.

Recommendation:
Keep this audit commit as-is. Do not re-add "and vaccines" for FHIR-25538 unless the work group revisits FHIR-32960, because doing so would conflict with the later vaccine-boundary clarification already present in the active source.
