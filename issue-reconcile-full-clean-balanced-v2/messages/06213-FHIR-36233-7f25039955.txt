FHIR-36233: Audit enableWhen precision guidance

Issue request:
FHIR-36233 was a Published FHIR-core Questionnaire change request resolved Persuasive with Modification for R5. It asked for guidance on precision-difference comparisons in Questionnaire.enableWhen, and corresponding enableWhenExpression extension guidance including use of `.allTrue()` and enabled-with-warning handling when logic is indeterminate.

Initial application:
The Jira comment records core commit 63e843882c and SDC commit 79a3ed0. Core commit 63e843882c added the approved precision-difference paragraph to source/questionnaire/structuredefinition-Questionnaire.xml for Questionnaire.item.enableWhen. The current source and checked R5 history still contain that wording.

Additional context:
Questionnaire is an active, approved core resource in source/fhir.ini. The current core checkout does not define questionnaire-enableWhenExpression or sdc-questionnaire-enableWhenExpression; searches found only references from Questionnaire narrative/definitions and historical generated output. The Jira-referenced SDC commit 79a3ed0 modified HL7/sdc input/resources/StructureDefinition-sdc-questionnaire-enableWhenExpression.xml to add the expression-specific `.allTrue()` and warning guidance. Confluence SDC minutes show the issue was discussed on 2022-03-10 and accepted as persuasive with modification on 2022-04-14. The linked Zulip thread supplies the FHIRPath precision/empty-set rationale.
