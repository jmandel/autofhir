FHIR-18860: Remove ClinicalImpression investigation ModelInfo

Issue request:
FHIR-18860 was a Published/Persuasive Patient Care change request raised against STU3 ClinicalImpression.investigation and ClinicalImpression.supportingInfo. The accepted resolution removed the investigation element and clarified supportingInfo as information supporting the clinical impression that can contain investigation results.

Initial application:
Commit b49a4ed40ab67993992fc0877005234b145f07a9 applied the issue by marking the ClinicalImpression.investigation spreadsheet rows as removed, updating the supportingInfo definition, and commenting the example investigation block out. The current ClinicalImpression StructureDefinition source has no investigation element and its supportingInfo definition includes the investigation-results clarification.

Additional context:
This issue was discovered while reconciling the adjacent FHIR-18861 rename from the same b49a4ed commit. Library is an active resource in source/fhir.ini, and source/library/list-Library-examples.xml includes Library/FHIR-ModelInfo as a current example whose FHIR 6.0.0 XML payload is sourced from source/library/library-fhir-model-definition-content.xml and embedded in source/library/library-fhir-model-definition.xml. Before this reconciliation, that active ModelInfo payload still contained ClinicalImpression.investigation and the unreferenced ClinicalImpression.Investigation backbone class. Later ClinicalImpression issues confirm the removal context: FHIR-50411 was Resolved - No Change on adding DiagnosticReport-like structure to supportingInfo, and FHIR-50409 is a later Resolved - change required cleanup that discusses investigation wording but does not reinstate an investigation element.

AutoFHIR reconciliation:
Removed the stale ClinicalImpression.investigation ModelInfo element and the now-unreferenced ClinicalImpression.Investigation class from source/library/library-fhir-model-definition-content.xml, then regenerated the embedded payload in source/library/library-fhir-model-definition.xml. No ClinicalImpression resource-page source was changed because the supportingInfo definition and absence of investigation are already represented there.

Recommendation:
Keep this source fix. It aligns the active FHIR ModelInfo Library example with the already-applied FHIR-18860 resource model and leaves later FHIR-50409 wording work for its own applied/published workflow state.
