FHIR-37590: Audit custom SearchParameter code guidance

Issue request:
FHIR-37590 was Published/Not Persuasive with Modification for R5. It challenged search.html guidance that told servers to define search parameters starting with "-", noted that SearchParameter.name does not allow hyphens, and raised ambiguity with descending `_sort`; the approved resolution clarified that the URL label is SearchParameter.code, not SearchParameter.name, and changed the sentence to recommend custom SearchParameter codes starting with a hyphen.

Initial application:
The issue was applied by git commit 94e30939143f7cb4c22d5b624063f182b61d152e, which changed the active search conformance bullet in `source/search.html` from generic "search parameters" to "custom search parameters with codes" and used "hyphen ("-")" wording. No SearchParameter.name regex change was intended because Jira explicitly separated SearchParameter.name from SearchParameter.code.

Additional context:
FHIR-53569 later revisited the same hyphen-prefix guidance after implementers identified a real `_sort=-name` ambiguity. It was Applied/Persuasive with Modification for R6 and commit 8b4082caae2d890a9164d9119c7db8722a31f172 replaced the hyphen recommendation with organization-scoped alphanumeric prefix guidance in `source/search.html`. The combined branch already contains Issue-Reconcile-Key FHIR-53569 at 5a5c6a7140293d25b3ad74c28e7f248f20094d02, which completed that later decision by adding the approved Search Tests CapabilityStatement paragraph; publishing another FHIR-53569 commit here would be a duplicate.

AutoFHIR reconciliation:
Made no source change. The current active source preserves the FHIR-37590 name/code distinction, but the actual custom-code prefix policy is now governed by the later FHIR-53569 decision: custom search parameter codes should use an organization-scoped alphanumeric prefix and clients unfamiliar with a server's conventions must query CapabilityStatement naming conventions.

Recommendation:
Keep this no-change audit. Do not restore the R5 hyphen-prefix sentence from FHIR-37590, because it has been superseded by the later applied FHIR-53569 decision and by the existing combined-branch reconciliation for that issue.
