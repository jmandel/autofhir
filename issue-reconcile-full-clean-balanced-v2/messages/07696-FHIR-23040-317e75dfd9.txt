FHIR-23040: Audit ElementDefinition binding description wording

Issue request:
FHIR-23040 was a Published/Persuasive FHIR-I correction asking that ElementDefinition.binding.description stop saying "Human explanation of the value set" because the description explains the binding's intended code use, not the value set itself. The approved R5 request suggested the short text "Intended use of codes in the bound value set" while retaining the binding-focused long definition.

Initial application:
The request was applied before this reconciliation by commits 371c0b93c9 and de177bcf39, then merged by 86647c8abd in PR #1791. Those commits changed the build-scope ElementDefinition spreadsheet source at source/datatypes/elementdefinition.xml from "Human explanation of the value set" to "Intended use of codes in the bound value set".

Additional context:
ElementDefinition is an active datatype in source/fhir.ini, so source/datatypes/elementdefinition.xml is the authoritative current source. A later Applied/Persuasive vocabulary issue, FHIR-49693, deliberately revised the same short and long descriptions for R6 because a binding does not always have a concrete list of codes. Commit d2eb91e8ff changed the current source to "Guidance on the codes to be used" and "Free-text guidance on the codes that are appropriate for this element," plus a comment explaining ad-hoc descriptions, value-set context, and additional bindings.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The obsolete value-set-focused short text is absent from the current source, and the current FHIR-49693 wording preserves FHIR-23040's core correction by describing guidance for codes/bindings rather than a human explanation of the value set.

Recommendation:
Keep this audit commit as-is. Do not restore the exact FHIR-23040 replacement phrase, because the later approved FHIR-49693 wording is the current intended text for this active source.
