FHIR-12189: Audit ImagingStudy procedure split

Issue request:
FHIR-12189 was a Published/Persuasive with Modification DSTU2 Imaging Integration change request to clarify ImagingStudy.procedure by renaming the original procedure element to procedureReference, adding a separate procedureCode CodeableConcept with ProcedureCodeSequence as an alternate name and an example LOINC/RSNA Radiology Playbook binding, and adding a procedureCode search parameter with a note that Procedure.code is not searched.

Initial application:
The issue appears to have been applied in commit d6c6d61a72, whose subject explicitly references GF#12189. That commit changed the historical ImagingStudy spreadsheet source from ImagingStudy.procedure to ImagingStudy.procedureReference, added ImagingStudy.procedureCode with ImagingProcedureCode binding metadata, and updated related ImagingStudy narrative/examples. The current source no longer carries those old spreadsheet files, but the history shows the DSTU2 request was applied before later resource redesigns.

Additional context:
Later final ImagingStudy decisions changed the representation that FHIR-12189 introduced. FHIR-17427 clarified the procedureReference description, FHIR-19637 replaced procedureCode/procedureReference with a repeating procedure construct to support multiple performed procedures, FHIR-20166 updated the ImagingProcedureCode binding target while procedure codes were still represented, and FHIR-53025 now establishes the current R6 design: ImagingStudy.procedure is a repeating Reference(Procedure) for performed procedures, with the procedure search parameter targeting ImagingStudy.procedure. The current build actively includes ImagingStudy, and source/fhir.ini records the historical procedureCode/procedureReference merge into procedure.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative ImagingStudy StructureDefinition has ImagingStudy.procedure 0..* Reference(Procedure), the active procedure search parameter points at ImagingStudy.procedure, and no active ImagingStudy.procedureCode or ImagingStudy.procedureReference element remains to update. Reintroducing the literal DSTU2 split would conflict with later accepted ImagingStudy decisions and already-published related reconciliations.

Recommendation:
Keep this audit commit as-is. Do not restore the obsolete procedureCode/procedureReference split in current core; any future desire to search performed procedure codes should be handled through a new current-version work-group decision rather than by replaying the DSTU2 wording.
