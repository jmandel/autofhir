FHIR-31354: Audit Bundle fullUrl exception wording

Issue request:
FHIR-31354 was Published with a Persuasive with Modification resolution for R5. It asked to clarify Bundle.entry.fullUrl because batch Bundles with GET/search-style entries can have no entry resource identity to name, and the old POST/operation wording did not list the intended batch or transaction exceptions clearly.

Initial application:
The issue was applied in a026c2f242db04aea462f660655cbff949f00026, which replaced the older "fullUrl can be empty on a POST" and unidentified-operation text in source/bundle/structuredefinition-Bundle.xml with create, operation, and search/history exception bullets. That initial application covered the ElementDefinition but later review found the wording ambiguous enough to need correction.

Additional context:
Bundle is an active resource in source/fhir.ini, and source/bundle/structuredefinition-Bundle.xml plus source/bundle/bundle-notes.xml are the authoritative current Bundle sources checked here. FHIR-43106 later clarified that the FHIR-31354 exception only applies when the Bundle is a batch or transaction request or response and the entry is a create, a non-single-resource operation, or a search/history case; c3a11dc9db104fae1e5355ff962f186f09bf4fa2 applied that to Bundle.entry.fullUrl, and 74c0b5c778000e771852a94cadcca2e0aaff2526 reconciled the related narrative and bdl-15 invariant. FHIR-43101 changed only the adjacent fullUrl/resource-id matching comment.

AutoFHIR reconciliation:
No source change was made. The current source already states the FHIR-31354/FHIR-43106 rule at Bundle.entry.fullUrl, the Bundle narrative now points to the same exceptions, and stale POST-only wording is absent from the authoritative Bundle source checked for this issue.

Recommendation:
Keep this empty audit commit as-is. The seed issue is represented by current source after the later FHIR-43106 correction, and adding new wording for FHIR-31354 would duplicate or risk drifting from the already-aligned Bundle.entry.fullUrl definition and Bundle narrative.
