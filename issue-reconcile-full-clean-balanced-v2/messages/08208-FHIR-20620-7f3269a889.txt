FHIR-20620: Audit external operations-tab tooling request

Issue request:
FHIR-20620 was a Published/Persuasive with Modification FHIR-core Questionnaire change request. It asked for publication tooling support so a Questionnaire Operations tab could point readers to externally defined SDC operations, because the body text links to SDC but newcomers may not find the operations easily. The final Jira disposition was to move the request to HL7/kindling#115.

Initial application:
No FHIR source commit mentioning FHIR-20620 was found. Current core source keeps Questionnaire active in source/fhir.ini, contains an empty source/questionnaire/list-Questionnaire-operations.xml, and already includes body text pointing readers to the Structured Data Capture Questionnaire IG for guidance, extensions, and operations. The current source does not contain operations-intro.xml, operations-notes.xml, or another source convention that would make an external Operations tab source-only change effective.

Additional context:
The originating Zulip thread records that the requested usability improvement needed publication tooling support. FHIR-I/SDC minutes in 2020 treated the proposal as a tooling issue, and 2023 FHIR IG Authoring minutes approved the persuasive-with-modification outcome by adding HL7/kindling#115. That Kindling issue remains open and approved, and searches did not find the proposed operations-intro/operations-notes support implemented in Kindling or this FHIR source checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Implementing the requested tab behavior requires publisher/Kindling changes outside the HL7/fhir source checkout; adding speculative Questionnaire source files now would either be ignored by current tooling or encode an unapproved convention.

Recommendation:
Keep this audit commit as an external-repo decision for core FHIR. If the usability improvement is still desired, implement or close HL7/kindling#115 first, then add the corresponding Questionnaire source content only after the tooling defines a supported convention.
