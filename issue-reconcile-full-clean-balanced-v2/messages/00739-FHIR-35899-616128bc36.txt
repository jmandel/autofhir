FHIR-35899: Audit MedicationStatement last administration timing

Issue request:
FHIR-35899 was a Published Pharmacy change request for R5, resolved Not Persuasive with Modification, asking whether MedicationUsage needed a new dateOfLastAdministration element to store the last time a medication was given. The accepted resolution was to use effectiveDateTime for the last time the medication was taken or administered and update definition/comment text to clarify that use case.

Initial application:
The historical source commit 0e463239a18c2754e691aecf97c70119c5891b41 was tagged with FHIR-37372, FHIR-35899, and FHIR-36001. That commit changed MedicationUsage source/schema metadata and added partOf, but did not update the effective[x] comment with the FHIR-35899 effectiveDateTime clarification.

Additional context:
The former R5 MedicationUsage source has since been normalized back to the active current MedicationStatement resource. source/fhir.ini lists medicationstatement=MedicationStatement and MedicationStatement=mst, so MedicationStatement is the in-build location for this guidance now. The closely related FHIR-37372 reconciliation commit 16ecd8d1fd9996fe38850f94da6a80c40f1f5ff0 is already on the combined branch and updated MedicationStatement.effective[x] and the Event mapping exception copy to say that effectiveDateTime can document an exact date/time when the medication was taken or administered, and that a usage period plus a distinct last administration date/time uses two separate MedicationStatement resources.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active MedicationStatement source already conveys the FHIR-35899 resolution, and adding a new element or duplicating nearby prose would be contrary to the published disposition and redundant with the source-changing FHIR-37372 reconciliation.

Recommendation:
Keep this no-change audit commit for FHIR-35899. No further core source work is needed unless Pharmacy later wants to revisit the effective[x] modeling decision more broadly.
