FHIR-5282: Audit DiagnosticOrder resource wording

Issue request:
FHIR-5282 was a Published/Persuasive January 2015 OO ballot comment against the DiagnosticOrder resource page. It asked that the wording "A request for a diagnostic investigation service to be performed" become "A record of a request for a diagnostic investigation service to be performed" and its resolution explicitly says to see FHIR-5279.

Initial application:
The same historical application that resolved FHIR-5279 also resolved this companion resource-page request. Git commit d6259fa8e3 changed the DiagnosticOrder root long definition to "A record of a request for a diagnostic investigation service to be performed" and tagged the row with [#5279], matching FHIR-5282's instruction to follow FHIR-5279.

Additional context:
DiagnosticOrder and DiagnosticRequest are now removed current-build resources. Later Published issues FHIR-10295 and FHIR-11119 renamed DiagnosticOrder to DiagnosticRequest and then merged DiagnosticRequest with ProcedureRequest, and current source/fhir.ini records DiagnosticOrder as subsumed into ServiceRequest. The active ServiceRequest StructureDefinition now carries the broader "A record of a request for service..." description/definition and includes committee notes for [#5279][#11119].

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. FHIR-5282's requested resource-page wording was applied historically, and the current build no longer contains the DiagnosticOrder resource page that FHIR-5282 targeted.

Recommendation:
Keep this no-change audit as-is. No core source follow-up is needed for FHIR-5282; any future adjustment should be handled as a ServiceRequest/workflow wording decision rather than a DiagnosticOrder page correction.
