FHIR-8598: Audit Observation comparator typo

Issue request:
FHIR-8598 was a Published/Persuasive DSTU1 technical correction for FHIR-core Observation asking to fix the inclusive extension comparator typo by using <= and >= instead of =< and =>.

Initial application:
No git commit explicitly names FHIR-8598. The same Observation.referenceRange extension work was introduced by 138fd1fb87 for #8551 with the bad escaped strings =< and => in source/observation/observation-extensions-spreadsheet.xml, and 8cd2c2332e immediately corrected those strings to <= and >= while also narrowing the extension context. FHIR-8551's later Published resolution ultimately directed inclusive reference range text and no inclusive/exclusive extension.

Additional context:
The current build includes Observation as an active resource in source/fhir.ini, but there is no active Observation extension spreadsheet or inclusive-flag source in either core or the Extension Pack. A later Applied issue, FHIR-51566, replaced the old extension concern in R6 by changing Observation.referenceRange.low and .high to Quantity and constraining Quantity.comparator directly, preserving inclusive defaults.

AutoFHIR reconciliation:

Recommendation:
Keep this no-change audit commit. Do not resurrect or edit the obsolete inclusive-flag extension; any future changes should be handled through the current Observation.referenceRange Quantity comparator model and the FHIR-51566 issue family.
