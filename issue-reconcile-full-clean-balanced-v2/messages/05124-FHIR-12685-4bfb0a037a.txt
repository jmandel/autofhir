FHIR-12685: Audit Account parent linkage

Issue request:
FHIR-12685 was Published with a Persuasive with Modification resolution for DSTU2/R4-era Account to add a child-to-parent account link, `partOf 0..1 Reference(Account)`, so multiple child Accounts can be subsumed by a parent Account, and to remove the old Account.balance to avoid ambiguity about balance effects across linked accounts.

Initial application:
The issue was explicitly applied in git commit 31a1a93cd9d77a9c85124688f199fb32ffd3b571, which added `Account.partOf` to the historical Account spreadsheet source and removed the old single Money `Account.balance` from the spreadsheet, examples, and balance search parameter. Later source rework commits carried that applied `partOf` element into `source/account/structuredefinition-Account.xml` before later Account relationship tickets changed its representation.

Additional context:
Account is an active build resource in `source/fhir.ini`. The current R6 source no longer uses the literal `partOf` name, but `source/fhir.ini` maps R4 `Account.partOf` to current `Account.parent`, and `source/account/structuredefinition-Account.xml` defines `Account.parent` as `0..1 Reference(Account)` with hierarchy metadata and a matching `Account-parent` search parameter. Later final Account decisions explain the evolution: FHIR-20994 asked for multiple parent relationships, FHIR-20997 superseded that with a general related-account backbone, and FHIR-44682 then replaced `relatedAccount` with `Account.parent` plus `Account.guarantor.account`. FHIR-20972 later reintroduced Account.balance with calculated-balance semantics, so the FHIR-12685 balance removal is no longer the current controlling decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Account source still satisfies the seed's required child-to-parent account linkage through the renamed `Account.parent` element, and the apparent balance mismatch is explained by later Published/Applied Jira decisions rather than an unapplied part of FHIR-12685.

Recommendation:
Keep this audit commit as-is. Do not re-add the old `partOf` name or remove current `Account.balance` under FHIR-12685; any future Account relationship or balance changes should be handled under later targeted Jira decisions.
