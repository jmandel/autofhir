FHIR-5701: Audit MedicationStatement not-taken rename

Issue request:
FHIR-5701 was a Published Pharmacy change request with resolution Persuasive with Modification. It said MedicationStatement.wasNotGiven was copied from MedicationAdministration terminology and should use taking language instead; the approved resolution changed wasNotGiven to wasNotTaken and reasonNotGiven to reasonNotTaken.

Initial application:
No git commit explicitly names FHIR-5701, but commit d406f9a2c0, made immediately after the 2015 Pharmacy ballot-resolution vote, changed the old MedicationStatement spreadsheet and examples from wasNotGiven/reasonNotGiven to wasNotTaken/reasonNotTaken. Later DSTU/STU history continued to revise that model through notTaken/taken status guidance before the old element was removed.

Additional context:
FHIR-8009 is the same ballot change family and records that the prior ballot comment was persuasive for the wasNotTaken/reasonNotTaken rename. FHIR-8010 and FHIR-12470 later adjusted the status plus wasNotTaken/notTaken interpretation. Still later Published Pharmacy decisions, especially FHIR-19468, FHIR-19470, FHIR-38682, and FHIR-39271, moved taking/not-taking semantics into MedicationStatement.adherence while keeping MedicationStatement as the active resource.

AutoFHIR reconciliation:
This commit makes no source change. MedicationStatement is active in source/fhir.ini, and the current authoritative source has no current MedicationStatement.wasNotGiven or MedicationStatement.reasonNotGiven element; it uses MedicationStatement.adherence, including the not-taking code and adherence.reason, for current use/non-use semantics.

Recommendation:
Keep this no-change audit commit. The requested rename was historically applied, and the current build is correct after later Pharmacy decisions superseded the old wasNotTaken element with the adherence backbone rather than restoring any wasNotGiven terminology.
