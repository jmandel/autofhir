FHIR-7211: Audit f202 temperature coding

Issue request:
FHIR-7211 was a Published/Persuasive with Modification OO change request for the DSTU1 Observation f202 temperature example. It objected that the example showed SNOMED CT oral-temperature and LOINC body-temperature codings together in Observation.code, noted that LOINC has a specific oral-temperature code 8331-1, and resolved to fix the example while clarifying that FHIR core is international and not limited to LOINC.

Initial application:
No source commit found during this reconciliation explicitly names FHIR-7211 or core #271. The same source change appears to have been applied by git commit 474be19befc8b8882da2b23a826dd0e2106a1538, which explicitly lists the linked same-change-family issue FHIR-7231 and changes the exact f202 example: it replaces SNOMED CT 415945006 in Observation.code with a local acme.lab BT coding, keeps LOINC 8310-5, and changes the body site to Oral cavity.

Additional context:
FHIR-7231 is the same 2015May f202 temperature concern and its Jira comment says "See also #271", linking back to FHIR-7211. FHIR-7231's accepted resolution says to avoid SNOMED-only Observation.code examples by adding LOINC translations or making the code local. Current source/fhir.ini lists Observation as an active resource, so the f202 example is a current build input. Current f202 has LOINC 8310-5, local BT, and LOINC 8331-1 in Observation.code, and the original SNOMED CT 415945006 coding is absent. Direct Zulip and Confluence searches for FHIR-7211 found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already fixes the f202 example in the way requested by FHIR-7211/FHIR-7231: the old mismatched SNOMED oral-temperature Observation.code coding is gone, LOINC codings including 8331-1 are present, and the remaining SNOMED CT content is not a SNOMED-only replacement for the vital-sign code.

Recommendation:
Keep this no-change audit commit. Do not use FHIR-7211 to remove all SNOMED CT from f202; that would exceed the issue's international-scope resolution and should require a separate OO decision.
