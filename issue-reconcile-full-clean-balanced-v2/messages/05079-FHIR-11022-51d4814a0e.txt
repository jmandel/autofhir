FHIR-11022: Audit AllergyIntolerance certainty unknown clarification

Issue request:
FHIR-11022 was Published/Persuasive with Modification for the DSTU2 AllergyIntolerance resource. It asked how the AllergyIntolerance.reaction.certainty code "unknown" differed from simply omitting the optional certainty element; the accepted resolution was to define unknown as an explicit assertion that certainty is not known and to add a usage note distinguishing missing certainty from an explicit unknown assertion.

Initial application:
The requested clarification was applied in historical core commit 87f224c94cabbf01ee3789f815f26c69d05608d4, which updated the reaction-event-certainty unknown code definition and added the requested AllergyIntolerance.reaction.certainty usage note with GF#11022 committee notes. The unknown code itself came from the earlier FHIR-10369 change family.

Additional context:
FHIR-11020, decided in the same Patient Care ballot block, subsequently moved AllergyIntolerance.reaction.certainty out of the base resource into an extension. Current core AllergyIntolerance remains active in source/fhir.ini, but current core source uses AllergyIntolerance.verificationStatus for resource-level certainty and no longer contains reaction.certainty or the allergyintolerance-certainty extension definition. The old extension and reaction-event-certainty terminology were removed from core in the R5-era extension cleanup and now live in the FHIR Extension Pack, where the current CodeSystem still defines unknown as an explicit assertion that certainty is not known and the current extension still carries the missing-vs-unknown usage note.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. Re-adding the DSTU2 reaction.certainty note to current core AllergyIntolerance would be obsolete, while the authoritative moved extension/terminology source already preserves the FHIR-11022 clarification.

Recommendation:
Keep this audit commit as-is. No current core follow-up is needed for FHIR-11022; future changes to the old certainty extension or reaction-event-certainty codes should be made in the FHIR Extension Pack rather than reintroduced into core.
