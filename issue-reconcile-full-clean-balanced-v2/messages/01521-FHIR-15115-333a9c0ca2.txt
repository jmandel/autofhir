FHIR-15115: Audit Consent.category codelist decision

Issue request:
FHIR-15115 was a Published/Persuasive STU3 Consent change request asking to move Consent.category to extensible codelists for regional variance and to avoid category-by-scope invariants; the recorded resolution was to create the consent.category vocabularies as extensibles without invariants.

Initial application:
No Jira-keyed HL7/fhir commit for FHIR-15115 was found. Historical Consent source before the later FHIR-31903 change had Consent.category as 1..* with an extensible binding to ValueSet/consent-category, while the old Consent.scope model and active scope-conditioned constraints still existed.

Additional context:
FHIR-13884 is the earlier same-family request for separate Consent.category codelists by Consent.scope and was resolved no-change as overridden by a later CR. FHIR-31903 is the later Published/Persuasive R5 decision that eliminated Consent.scope, changed Consent.category to 0..* with an example binding, and folded scope codes into the category value set. Zulip discussion for FHIR-31903 records the rationale that consent categorization is jurisdiction- and implementation-specific and should be guided by profiles/IGs rather than universal core invariants.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current Consent resource is active in source/fhir.ini; its authoritative StructureDefinition has Consent.category as 0..* CodeableConcept with an example binding to consent-category-example, and source/fhir.ini records Consent.scope as merged with Consent.category. The current value set includes both scope and consent category code systems, and no active category-by-scope invariant remains. Reverting the binding to extensible would undo the later FHIR-31903 published decision rather than complete FHIR-15115.

Recommendation:
Keep this audit as-is. If the work group wants Consent.category strengthened again, that should be handled as a new post-FHIR-31903 policy decision rather than as a cleanup for FHIR-15115.
