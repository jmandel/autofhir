Initial application:

The current XML StructureDefinition source was introduced later by commit 33b409a4b6d544598262f2f074ebb4b6dc466157 with the same document element and DocumentReference target.

Additional context:
SubstanceDefinition is an active current-build resource in source/fhir.ini. In FHIR StructureDefinition source, a link to a DocumentReference resource is represented as type Reference with targetProfile http://hl7.org/fhir/StructureDefinition/DocumentReference, so the current source correctly implements the Jira request even though the rendered type is not a literal element type named DocumentReference. BRR minutes for 2020-07-21 confirm that only FHIR-26882 was addressed in that meeting. A later Zulip implementer thread about SubstanceDefinition.structure.representation.document confirmed the schema/build distinction: the element is a Reference to a DocumentReference instance and FHIRPath access to DocumentReference content requires resolve().

This commit intentionally makes no source change.
