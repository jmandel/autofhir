FHIR-15023: Align two-doctor Appointment example index

Issue request:
FHIR-15023 was a Published/Persuasive PA change request asking to clean up the doctor-to-doctor Appointment example for a meeting about a patient where the patient is not present; the resolution specifically noted that this example should not be a walk-in appointment and should be made more realistic.

Initial application:
The issue was partially applied by git commit 162ff70abb76ded31d0552c589956802ea0d7f38, which changed source/appointment/appointment-example2doctors.xml from a WALKIN/MRI example to a FOLLOWUP/ultrasound example. That commit did not update source/appointment/list-Appointment-examples.xml, so the active examples list still described Appointment/2docs as an MRI-results appointment.

Additional context:
Appointment is an active resource in source/fhir.ini, and source/appointment/list-Appointment-examples.xml is the active Appointment examples list entry for Appointment/2docs. FHIR-14804 is background because it first relied on this example to show an appointment between practitioners about a patient; FHIR-22696 later refined that representation by adding Appointment.subject and making the patient a subject, not a participant. Current source already reflects the later subject/participant model, and PA minutes and community searches revealed no conflicting direction for FHIR-15023.

AutoFHIR reconciliation:
This commit updates the active Appointment examples list description for Appointment/2docs from MRI results to ultrasound results so the generated example index matches the cleaned-up current example content.

Recommendation:
Keep this source fix. It is narrowly scoped to a stale source description left behind by the original application and does not reopen the later FHIR-22696 subject/participant design.
