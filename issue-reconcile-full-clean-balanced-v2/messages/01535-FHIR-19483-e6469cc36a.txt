FHIR-19483: Audit Coverage copay value choice

Issue request:
FHIR-19483 was a Published/Persuasive Financial Management change request asking that Coverage co-pay amount be changed to a choice of SimpleQuantity, for percentage, or Money.

Initial application:
The request was applied in commit 7fbe7046270ff6857644a6af63207642576dc7ef, which changed the historical Coverage spreadsheet from Coverage.copay.value typed as Quantity to Coverage.costToBeneficiary.value[x] typed as SimpleQuantity|Money and added a Coverage example using valueMoney. The spreadsheet source was later refactored into the current StructureDefinition source, preserving the requested choice.

Additional context:
Coverage is an active resource in source/fhir.ini. The current authoritative source defines Coverage.costToBeneficiary.value[x] with a Quantity type profiled as SimpleQuantity and a Money type, and its comment explains that the amount may be a percentage or fixed currency amount. Later FHIR-27024 changed the same element's cardinality and added an invariant allowing an exception without a value, but it did not alter the SimpleQuantity|Money type choice requested by FHIR-19483. Jira/Zulip/Confluence searches found no later conflicting community guidance for this issue.
