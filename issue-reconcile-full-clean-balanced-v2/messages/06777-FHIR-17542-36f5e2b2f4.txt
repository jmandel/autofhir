FHIR-17542: Audit OO extension camelCase names

Issue request:
FHIR-17542 was a Published/Persuasive OO change request for STU3 asking to update all OO extension names to camelCase for consistency. The Jira comment gave Observation examples to change from focus-code, time-offset, sequel-to, gateway-device, and specimen-code to focusCode, timeOffset, sequelTo, gatewayDevice, and specimenCode.

Initial application:
The change appears to have been pre-applied in git commit 7746262ec15c5fb2f931148ad148df6875aebaeb, titled "GF#17542 update all OO extensions to camelCase". That commit updated Observation, Device, DeviceUseStatement, Specimen, and shared extension spreadsheet/source references, including changing Observation extension links and definitions to camelCase.

Additional context:
Current core no longer contains the Observation StructureDefinition extension source files; commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed those extension definitions from the R5 core source. The current core source retains only camelCase OID entries for the cited Observation extension URLs, while the FHIR Extension Pack now contains the active/retired OO extension definitions with camelCase ids, urls, and fixedUri values. The only active current-source hit for the old string focus-code is ResearchStudy-focus-code, a search parameter code, not an OO extension URL or definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested OO extension rename is already reflected in current in-scope core references and in the Extension Pack source that now owns the cited extension definitions, and no active current source still defines or links the cited Observation extensions under the old hyphenated names.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-17542 unless a future Extension Pack review identifies a specific non-camelCase OO extension definition outside the examples checked here.
