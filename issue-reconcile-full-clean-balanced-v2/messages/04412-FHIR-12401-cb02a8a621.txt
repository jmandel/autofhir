FHIR-12401: Audit MedicationRequest dosage timing examples

Issue request:
FHIR-12401 was a Published FHIR-core Pharmacy change request, resolved Persuasive with Modification, asking for MedicationRequest dosageInstruction examples using days of week and morning/noon/night or time-of-day style timing. The accepted resolution was to add representative MedicationRequest examples for the related Timing changes from TR 12201, TR 12352, and TR 10478 and clarify occurrence/period-duration use.

Initial application:
The Jira comments record that examples were added, and git commit 8175cd268621dabb43c4f0dd0bf689fa0743e633 (svn r11184) applied TR#12401 by adding MedicationRequest examples medrx0333, medrx0334, and medrx0335 plus the examples header/spreadsheet. Later source history refactored the examples for current Dosage and R5 MedicationRequest syntax but retained those three example concepts.

Additional context:
MedicationRequest is an active resource in source/fhir.ini. Current source includes medrx0333 with Timing.repeat.when=MORN, medrx0334 with Timing.repeat.dayOfWeek=mon plus daily frequency/period, medrx0335 with Timing.repeat.timeOfDay=09:00:00, and both the current examples list and examples header expose those examples. FHIR-12460 was the linked invariant issue that made these combinations valid; FHIR-12201, FHIR-12352, and FHIR-10478 are Timing datatype changes that the seed examples illustrate. Community searches found only a bot tracker announcement and no conflicting WG minutes or Zulip rationale.

AutoFHIR reconciliation:

Adding further variants for every EventTiming code would be redundant example expansion rather than a necessary current-spec correction.

Recommendation:
