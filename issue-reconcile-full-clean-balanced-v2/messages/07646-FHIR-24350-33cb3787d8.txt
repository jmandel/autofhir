FHIR-24350: Audit SubscriptionTopic filter default

Issue request:
FHIR-24350 is Published/Persuasive with Modification for R5 and asked that Topic.canFilterBy.matchType explicitly state the default behavior when the element is not populated. The accepted resolution was to rename matchType to modifier, make it optional, and define the missing case as search without a modifier.

Initial application:
The issue-tagged commit c28bb50bd49d88fdafe62b24a14d4f3f44c7930b added SubscriptionTopic filter documentation that said a missing search modifier defaults to =, meaning no modifier. FHIR-23738 later documented the Argonaut subscription branch merge and explicitly listed FHIR-24350 as the source for adding the Defining Filters for Subscriptions section, while the FHIR-24350 Jira comment records that the change was verified in R4B and R5.

Additional context:
The current resource is active as subscriptiontopic=SubscriptionTopic in source/fhir.ini, and later source evolution moved canFilterBy under SubscriptionTopic.trigger. FHIR-39026 revisited the same defaulting/equality area for R5 and resolved it by making canFilterBy match SearchParameter with separate comparator and modifier elements rather than by requiring the modifier; the combined branch already contains an FHIR-39026 audit commit. FHIR-50614 later broadened modifier values for :type resource-type use and is also already represented on the combined branch. Community searches found no contradictory FHIR-24350 discussion; Confluence minutes confirm deferral until Argonaut SubscriptionTopic changes and then application of the already-agreed change, and a subscriptions Zulip thread records the model rename away from matchType.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Current active source already has SubscriptionTopic.trigger.canFilterBy.modifier optional, separates comparators from modifiers, states that absent modifier listings do not imply modifier support, and the SubscriptionTopic narrative explicitly says that if no comparator or modifier is provided, the comparison is the default = match. That preserves the accepted FHIR-24350 meaning: a filter without a modifier is a normal search without a modifier.
