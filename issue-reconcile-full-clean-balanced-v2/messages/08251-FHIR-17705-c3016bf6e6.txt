FHIR-17705: Fix SNOMED concept-domain mapping link

Issue request:
FHIR-17705 was a Published/Persuasive FHIR-core issue for the mappings page. It reported that the SNOMED CT Concept Domain Binding and SNOMED CT Attribute Binding links on mappings.html were broken or unhelpful, and the accepted request was to use SNOMED's stable shortlinks http://snomed.org/conceptdomainbinding and http://snomed.org/attributebinding.

Initial application:
The historical Jira-tagged application was commit 922dc896f3 ("GF#17705 - fix SNomed Links"). That commit updated the SNOMED attribute binding mapping to http://snomed.org/attributebinding, but it only added an explicit link for the concept-domain mapping while leaving both its formal URL and link at http://snomed.info/conceptdomain.

Additional context:
The linked 2018 Zulip thread confirms the issue was about the two mappings.html SNOMED binding links. A related implementers thread notes that the existing links were defaulting to a logical namespace and were not final. source/mappingSpaces.xml is the mappings-page mapping-space source, and source/fhir.ini lists Condition and Observation as active resources; the active Condition and Observation StructureDefinition sources and Observation vital-sign profiles declared the same stale SNOMED concept-domain URI, so leaving them unchanged would keep the generated conformance mapping identity inconsistent with the fixed mapping-space URL.

AutoFHIR reconciliation:
This commit changes the SNOMED CT Concept Domain Binding URL and link in source/mappingSpaces.xml to http://snomed.org/conceptdomainbinding, and updates the matching sct-concept mapping URI in active Condition/Observation StructureDefinition sources. The already-correct SNOMED attribute binding shortlink was left unchanged, and out-of-scope historical release artifacts were not edited.

Recommendation:
Keep this commit as-is. It completes the previously partial FHIR-17705 application and keeps the active mapping page and conformance mapping declarations aligned with the SNOMED shortlink requested by the published Jira issue.
