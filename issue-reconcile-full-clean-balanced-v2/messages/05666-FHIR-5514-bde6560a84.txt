FHIR-5514: Audit MedicationRequest medication wording

Issue request:
FHIR-5514 is a Published/Persuasive DSTU1 Pharmacy change request for MedicationPrescription.medication and MedicationPrescription.dispense.medication. It asked to replace the older either/or definition with wording clarifying that the element identifies the medication and may point to a Medication resource whose content may be detailed or code-only, and it also asked for examples of both forms.

Initial application:
No current git commit explicitly tagged FHIR-5514 was found. The requested wording was already present in the imported R2-era MedicationOrder source for both MedicationOrder.medication[x] and MedicationOrder.dispenseRequest.medication[x]. Later history removed MedicationOrder.dispenseRequest.medication[x], renamed MedicationOrder to MedicationRequest, and Pharmacy QA adjusted the active medication definition from "being administered" to "being requested" for the request resource context.

Additional context:
The current build no longer has MedicationPrescription as an active resource; source/fhir.ini lists medicationrequest=MedicationRequest and notes that MedicationPrescription became MedicationRequest. Current MedicationRequest has MedicationRequest.medication as a CodeableReference(Medication) and has no MedicationRequest.dispenseRequest.medication element. Current examples include both a Medication reference and a coded concept for MedicationRequest.medication. Zulip and Confluence searches found no directly relevant FHIR-5514 discussion or minutes that would change this interpretation.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Changing the active definition back to "being administered" would make MedicationRequest less correct, and reintroducing dispenseRequest.medication would reverse a later removal. The current source preserves the issue's implementer-facing clarification where it still applies.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source follow-up is needed for FHIR-5514 unless the Pharmacy work group separately decides to revise the modern MedicationRequest wording or examples.
