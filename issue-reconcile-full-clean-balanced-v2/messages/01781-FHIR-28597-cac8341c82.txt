FHIR-28597: Align MedicationKnowledge guideline ModelInfo

Issue request:
FHIR-28597 was a Published/Persuasive Pharmacy change request, raised against R4 and applied for R5, asking to pull a medication's indications out of MedicationKnowledge.administrationGuideline and make the administration guideline content a child of the indication relationship.

Initial application:
The primary MedicationKnowledge StructureDefinition was initially changed by commit 1683ac64141af807564d62a28932d70133142fb3, which replaced the old administrationGuideline subtree with indicationGuideline while applying a group of Pharmacy trackers including FHIR-28597. Follow-up commits bd0883f3912523b0e63ae2a99a8a3a5b353c50a2 and 5af327bef84d35d0b85e3535c304cc9090d4d898 finalized the sibling dosingGuideline structure and wording. The active StructureDefinition is now correct, but the active FHIR ModelInfo Library example still exposed the old administrationGuidelines subtree.

Additional context:
FHIR-30093 refined the exact R5 shape by naming the new indication backbone IndicationGuideline, renaming AdministrationGuideline to DosingGuideline, and making indication repeatable; FHIR-30092 and neighboring Pharmacy decisions added treatmentIntent, administrationTreatment, and patientCharacteristic details to that same refactored subtree. The Library resource is active in source/fhir.ini, the examples page lists the FHIR Model Definition, and publish.ini copies source/library/library-fhir-model-definition-content.xml, so the stale ModelInfo file is current build-scoped source rather than an obsolete generated artifact.

AutoFHIR reconciliation:
Updated source/library/library-fhir-model-definition-content.xml so the FHIR 6.0.0 ModelInfo now models MedicationKnowledge.indicationGuideline, MedicationKnowledge.IndicationGuideline.DosingGuideline, its dosage and patientCharacteristic children, and no longer exposes MedicationKnowledge.administrationGuidelines or AdministrationGuidelines. Refreshed the embedded base64 data in source/library/library-fhir-model-definition.xml so the Library resource and readable ModelInfo content remain synchronized. No change was needed to the authoritative MedicationKnowledge StructureDefinition.

Recommendation:
Keep this source fix. It completes FHIR-28597 across the active ModelInfo surface while preserving the later Pharmacy decisions that define the current indicationGuideline/dosingGuideline structure; broader ModelInfo regeneration or unrelated MedicationKnowledge cleanup should use separate Jira decisions.
