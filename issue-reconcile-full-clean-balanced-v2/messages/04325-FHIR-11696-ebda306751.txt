FHIR-11696: Audit PlanDefinition action prefix/title clarification

Issue request:
FHIR-11696 was a Published CDS change request for FHIR-core PlanDefinition. It asked whether the old PlanDefinition.actionDefinition.label and PlanDefinition.actionDefinition.title elements should be collapsed because their distinction was unclear. The final Persuasive with Modification resolution kept both concepts and required clarifying documentation: the label-like element identifies or labels the action within context, while title describes the action.

Initial application:
The issue appears to have been applied in commit 6033e337f72c17058027423db9901c1893099510, which explicitly references J#11696 and clarified the PlanDefinition action prefix definition from just "A user-visible prefix for the action" to "A user-visible prefix for the action. For example a section or item numbering such as 1. or A." The action title definition already said it was the textual description of the action displayed to a user.

Additional context:
Before the explicit FHIR-11696 clarification, FHIR-13412 renamed PlanDefinition.action.label to PlanDefinition.action.prefix and left title in place for consistency with other FHIR resources. That rename is already represented on the combined branch by a separate FHIR-13412 audit commit. Current source has no PlanDefinition.action.label element; the active PlanDefinition resource is built from source/plandefinition/structuredefinition-PlanDefinition.xml, and its action.prefix and action.title definitions convey the intended distinction.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding more prose would be redundant with the current prefix definition, current title definition, and the later element naming that avoids the original label/title ambiguity.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-11696 unless a future CDS work-group decision changes the relationship between action.prefix, action.title, and action.linkId.
