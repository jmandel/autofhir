FHIR-14017: Audit minValue Quantity support

Issue request:
FHIR-14017 was a Published FHIR-core change request resolved Persuasive for STU3. It asked for http://hl7.org/fhir/StructureDefinition/minValue to allow Quantity as an Extension.value[x] type because Quantity is an allowed questionnaire item answer type, with a note that Quantity validation may be hard to implement.

Initial application:
No explicit Git commit mentioning FHIR-14017 was found in the current source history; the Jira comment points to an SVN-era revision. The active core source later showed the request still missing until commit 115e85b1ea, merged by HL7/fhir PR #1328 for FHIR-27914, changed the minValue extension row from date|dateTime|time|decimal|integer to date|dateTime|time|decimal|integer|Quantity.

Additional context:
FHIR-14016 is the paired Published STU3 decision that removed instant from minValue because Questionnaire.item does not allow instant. FHIR-27914 was a later Published R5 decision for the same minValue/maxValue extension family; it added Quantity to both minValue and maxValue and removed instant from maxValue. The combined branch already contains a FHIR-27914 audit commit, so this commit does not duplicate that decision. Current core no longer carries the minValue/maxValue extension definition rows after dd468d4f17 moved R5 extension definitions out of core; the authoritative current definitions live in the FHIR Extension Pack.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR Extension Pack definition input/definitions/Questionnaire/StructureDefinition-minValue.xml includes Quantity in Extension.value[x], and the current core ElementDefinition.minValue[x] row also includes Quantity and explains Quantity comparison as a canonical minimum. The active core element-extensions spreadsheet contains no minValue row to edit.

Recommendation:
Keep this audit commit as-is. No current core source change is needed for FHIR-14017; do not reintroduce the retired core extension row, and only revisit the Extension Pack if a later work-group decision changes the allowed Questionnaire.item answer types or Quantity comparison guidance.
