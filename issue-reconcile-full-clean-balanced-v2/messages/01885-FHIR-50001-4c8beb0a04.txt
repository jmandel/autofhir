FHIR-50001: Audit ServiceRequest.replaces RequestOrchestration support

Issue request:
FHIR-50001 is an Applied OO change request, resolved Persuasive with Modification, asking that ServiceRequest.replaces be able to reference RequestOrchestration for grouped-order replacement workflows. The recorded resolution expanded ServiceRequest.replaces to a request-type list that included RequestOrchestration; it also listed SupplyRequest and noted other changes would be handled by separate JIRAs.

Initial application:
The issue appears to have been applied by upstream commit 0fb7e5cd6bf2cbed816e1a9434c53e586590cccc, linked from Jira via PR #3532, which added RequestOrchestration and the other listed request targets to source/servicerequest/structuredefinition-ServiceRequest.xml. The current source still carries the substantive FHIR-50001 target, RequestOrchestration, on ServiceRequest.replaces.

Additional context:
A later core-source cleanup, 3b38b80cf23f9cbb306fab8fcedb293315478c32, removed SupplyRequest from ServiceRequest.replaces while removing SupplyRequest and other OO resources from the active core build and pointing to the OO incubator. Current source/fhir.ini still lists ServiceRequest and RequestOrchestration as active resources, but has no active SupplyRequest entry. Later OO issue FHIR-54619, resolved Resolved - change required and applied in source, aligned ServiceRequest.basedOn and ServiceRequest.replaces to the current nine-entry target list: ServiceRequest, DocumentReference, MedicationRequest, RequestOrchestration, CarePlan, DeviceRequest, CommunicationRequest, NutritionOrder, and VisionPrescription. That later decision confirms that re-adding SupplyRequest to current core ServiceRequest.replaces would be inconsistent with current build scope and later WG intent.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because source/servicerequest/structuredefinition-ServiceRequest.xml already permits ServiceRequest.replaces to reference RequestOrchestration, and the remaining difference from the original FHIR-50001 resolution is explained by the later removal of SupplyRequest from core build scope and FHIR-54619's aligned target list.

Recommendation:
Keep this audit commit as-is for FHIR-50001. Revisit only if OO decides that the external/incubator SupplyRequest artifact should again be referenceable from core ServiceRequest.replaces, or if FHIR-54619's later alignment decision changes before publication.
