Issue request:
FHIR-30207 was a Published/Persuasive with Modification FHIR-I change request for R5 asking to allow request-doNotPerform semantics on Task. The approved resolution added Task.doNotPerform, added usage guidance limiting do-not-perform Tasks to tightly time-bounded or process-phase-bounded actions that can be satisfied by a single non-action, added Task-versus-other-Request guidance, and asked for example instances.

Initial application:
The issue was applied in source history. Commit 83ebedf323 added Task.doNotPerform and the Task-versus-other-Requests notes. Commits c768ced254 and de2c17227d added and registered Task/cpg-example-1 as a doNotPerform example. Commits 01d32422f1 and 74ddfcc3b5 corrected Task.doNotPerform to a boolean modifier element. The resulting source is included in the v5.0.0 tag, matching the Jira applied-for R5 publication path.

FHIR-43446 later aligned the workflow mapping to Request.doNotPerform and is already represented on the combined branch by e5d7dc427853c257537a9ab828e84fa525d088b9.
