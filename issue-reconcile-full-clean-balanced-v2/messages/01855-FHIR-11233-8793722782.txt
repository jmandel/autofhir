FHIR-11233: Audit retired Sequence coordinate-system notes

Issue request:
FHIR-11233 was a Published/Persuasive Clinical Genomics change request for the DSTU2 FHIR-core Sequence resource. It asked for a section explaining Sequence.coordinateSystem, including 0-based versus 1-based numbering, inclusive starts, exclusive 0-based ends, inclusive 1-based ends, and examples so Sequence users could understand genomic coordinate windows.

Initial application:
The issue was historically applied by commit a26b8894d0c1ab993ffd7d6d0e4d4d0e4ba40c27, "#11233 #11238 Add description notes on Sequence resource page for coordinateSystem and referenceSeq.strand," which added the requested Sequence Coordinate System note to source/sequence/sequence-notes.xml. A same-day coordinate-family commit, d830ddede2fa70d5f6ccca85e723caa4a2c7a7bf, also updated Sequence.coordinateSystem and coordinate start/end definitions with the same inclusive/exclusive rules.

Additional context:
The original Sequence source is no longer part of the current build. Current source/fhir.ini lists Sequence under removed resources, has MolecularSequence commented out, and gives active Clinical Genomics ownership/status to moleculardefinition. Later R6 work, including FHIR-51227, replaced MolecularSequence with MolecularDefinition; source/molecularsequence was deleted and remaining MolecularSequence references were removed. Current MolecularDefinition uses a different coordinateInterval model with CodeableConcept coordinate-system examples such as 1-based character counting and 0-based interval counting, plus links to external Molecular Definition profiles, rather than the old integer Sequence.coordinateSystem element.

AutoFHIR reconciliation:
This commit intentionally makes no source change. FHIR-11233 was applied to the then-current Sequence notes and the affected Sequence resource has since been retired from the current build. Mechanically copying the 2016 Sequence prose into MolecularDefinition would be a new model-porting decision, not a reconciliation of the published DSTU2 Sequence issue.

Recommendation:
Keep this audit commit as-is. No current FHIR-core source follow-up is needed for FHIR-11233; if implementers find MolecularDefinition coordinateInterval semantics ambiguous, open or apply a MolecularDefinition-specific Clinical Genomics issue rather than resurrecting retired Sequence wording.
