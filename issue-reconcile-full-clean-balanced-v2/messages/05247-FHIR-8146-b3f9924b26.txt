FHIR-8146: Audit AllergyIntolerance criticality wording

Issue request:
FHIR-8146 was a Published/Persuasive DSTU1 Patient Care change request for DAF AllergyIntolerance asking for wording that distinguishes allergy/intolerance criticality from reaction severity, because a severe reaction such as a rash is not necessarily life-threatening.

Initial application:
The issue appears to have been applied in git commit a30496dcda9c86251cf286f1636c23e570a80113, whose subject explicitly includes #8146 and says usage notes were added to AllergyIntolerance. That patch added a "Use of AllergyIntolerance.criticality" section to source/allergyintolerance/allergyintolerance-notes.xml with the approved distinction and examples.

Additional context:
AllergyIntolerance is an active current-build resource in source/fhir.ini and is assigned to Patient Care. The current AllergyIntolerance notes still state that criticality is the likelihood the allergy/intolerance could result in significant harm, while severity is the degree of manifestation of a reaction symptom, and keep the moderate breathing difficulty/high criticality versus severe rash/low criticality examples. The current StructureDefinition also distinguishes AllergyIntolerance.criticality from AllergyIntolerance.reaction.severity. Related FHIR-7908 supplied essentially the same approved wording for where systems should map a single severity-like notion, and later FHIR-12177 added more criticality-vs-severity guidance on the criticality element; FHIR-12177 is already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active AllergyIntolerance source already preserves the requested usage-note distinction, and later related guidance supports rather than reverses the seed issue's distinction.

Recommendation:
Keep this no-change audit commit as-is for FHIR-8146. Do not add duplicate explanatory prose unless Patient Care publishes a later superseding issue that changes the criticality model or removes the current notes.
