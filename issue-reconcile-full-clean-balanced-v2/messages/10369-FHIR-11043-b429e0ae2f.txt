Initial application:

That implementation commit also mentioned FHIR-11038, but that issue concerns an unrelated LDL-calculated Observation extension cleanup.

Additional context:
The old DeviceMetricObservation profile and observation-example-satO2.xml were later removed in commit 0c4fafcc6c. Observation remains an active current-build resource in source/fhir.ini, and the current DeviceMetric-focused Observation example uses the ISO/IEEE 11073 URI. A current-source search found no RTMMS URL in code-system or valueSetUri positions; remaining RTMMS occurrences are descriptive hyperlinks or historical generated files, not active coding systems. Jira search found the seed as the only core DeviceMetricObservation/satO2 RTMMS hit, Zulip only had a tracker bot notification, and Confluence had no relevant hits.

Recommendation:
