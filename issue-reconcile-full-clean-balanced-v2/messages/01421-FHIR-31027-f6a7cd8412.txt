FHIR-31027: Audit Condition body structure guidance

Issue request:
FHIR-31027 was Published with resolution Not Persuasive with Modification. The submitter asked to generalize the condition-related extension so BodyStructure and Specimen could reference a related Condition; Patient Care instead kept condition-related scoped to Condition, agreed no new extension was needed, directed use of the existing bodySite/BodyStructure reference extension, and resolved to update the Condition.bodySite textual comments while keeping the element named Condition.bodySite.

Initial application:
The issue was initially applied by fae49f4994c73b7ac34fc53bde6373fa50928ab4, which added the J#31027 committee note to Condition.bodySite and changed the comment from the old BodySite-resource wording to BodyStructure-oriented extension guidance. A later link-maintenance commit, c3432543e2b93c3befc06f628938d37e6c1f1f02, rewrote the broken extension-bodysite.html link to the canonical bodySite extension URL after extension registry moves.

Additional context:
A later Applied Patient Care issue, FHIR-39630, superseded the old extension-comment approach by adding Condition.bodyStructure 0..1 Reference(BodyStructure), adding con-4 to prevent simultaneous Condition.bodySite and Condition.bodyStructure use, and explicitly resolving to remove the Condition.bodySite comment that referenced the standard extension. The current core build scope includes Condition and BodyStructure as active resources in source/fhir.ini. The condition-related and bodySite extension definitions now live in the FHIR Extension Pack; bodySite remains a BodyStructure reference extension with Condition.bodySite context, and later extension-pack issues tightened that context and added Specimen.collection.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source is correct after the later FHIR-39630 decision: Condition.bodySite now has only the non-implicit-code comment, Condition.bodyStructure provides the BodyStructure reference directly, and re-adding the old extension guidance would conflict with the later approved model. The condition-related extension remains scoped to Condition in the extension pack, consistent with FHIR-31027's no-generalization decision.

Recommendation:
Keep this audit commit as-is. Do not re-generalize condition-related in core and do not restore the old Condition.bodySite extension comment. Any future context changes for the bodySite extension should be handled in the FHIR Extension Pack, but current extension-pack evidence already includes Condition.bodySite and Specimen.collection contexts.
