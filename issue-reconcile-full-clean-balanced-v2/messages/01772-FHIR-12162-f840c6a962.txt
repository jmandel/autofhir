FHIR-12162: Audit Bundle document identifier support

Issue request:
FHIR-12162 was Published with a Persuasive with Modification resolution for DSTU2. It asked to add Bundle.identifier 0..1 as a persistent, version-specific identifier for document Bundles because Bundle.id can change when a document moves between servers.

Initial application:
The request was applied by svn revisions 10242/10243, visible in git as 88db4c7805d907c61bc750d3694adeaadb784063, which changed the document narrative from Bundle.id to Bundle.identifier. The current source also defines Bundle.identifier as a persistent Identifier and maps it to ClinicalDocument.id.

Additional context:
FHIR-12054 raised the overlapping document identifier/date/version problem two days earlier and now relies on the same Bundle.identifier outcome. The active current build includes Bundle in source/fhir.ini, and the active documents page describes Bundle.identifier as the mandatory document identifier.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the current Bundle and document sources already contain the persistent document identifier semantics requested by FHIR-12162.

Recommendation:
Keep this audit commit as-is. No further core work is needed for the Bundle identifier portion unless a future work group decision changes document identity semantics.
