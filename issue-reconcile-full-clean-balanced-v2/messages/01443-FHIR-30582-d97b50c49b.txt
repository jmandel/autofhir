FHIR-30582: Audit MedicationUsage transition note

Issue request:
FHIR-30582 was a Published/Persuasive Pharmacy change request for R5 asking the MedicationUsage introduction to say that MedicationUsage had previously been MedicationStatement, to help readers moving from R4 to R5.

Initial application:
The request was applied in commit 42836913756268f7acc692dbe8c37a45e4f00914 by adding "The MedicationUsage resource was previously known as MedicationStatement." to source/medicationusage/medicationusage-introduction.xml. Pharmacy WGM minutes also record the 19-0-0 approval for this exact note.

Additional context:
Later R5 work replaced that transition sentence with adherence guidance (FHIR-36701), and then FHIR-38682 renamed the resource back from MedicationUsage to MedicationStatement. FHIR-38873 and FHIR-43084 addressed the resulting naming/redundant-note cleanup. The current source/fhir.ini and hierarchy.xml actively build MedicationStatement, not MedicationUsage, and current source no longer contains a "previously called/known" MedicationStatement sentence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the FHIR-30582 note to the current MedicationStatement introduction would contradict the later rename-back decision and would recreate the redundant "MedicationStatement was previously called MedicationStatement" problem that later trackers removed.

Recommendation:
Keep this audit commit as-is. No current core source edit is needed for FHIR-30582; if historical R5 publication pages are republished, use the later redundant-note cleanup trackers rather than reviving the original MedicationUsage transition note.
