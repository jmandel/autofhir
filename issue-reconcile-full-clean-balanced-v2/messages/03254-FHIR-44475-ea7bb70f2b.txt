FHIR-44475: Align ActorDefinition actor type descriptions

Issue request:
FHIR-44475 was Applied with a Persuasive with Modification resolution to extend ActorDefinition actor types beyond the former person/system split. The approved code family covered software systems and non-system actors such as individuals, patients, practitioners, related persons, physical devices, collectives, care teams, groups, healthcare services, and organizations.

Initial application:
PR 3299 applied the issue in commit 21ec201162 by updating ActorDefinition and ExampleScenario actor type text and examples. Later commits moved the detailed hierarchy into ActorDefinition-owned terminology, and the current source already has ActorDefinition in active build scope. However, the current ActorDefinition.type binding and the actor type/code CodeSystem and ValueSet descriptions still described the vocabulary as only "system or human", contradicting the expanded actor categories.

Additional context:
FHIR-50087 later changed the modeling approach by keeping ActorDefinition.type as a required high-level code set of person, system, collective, and other, while adding ActorDefinition.category for detailed non-system actor categories. Current source reflects that split, and 2025 FHIR-I minutes confirm ExampleScenario.actor.type should use the same tight four-code value set. Because FHIR-50087 remains Resolved - change required and is not in this run's Applied/Published source-edit scope, this commit does not change the category binding strength or THO ownership.

AutoFHIR reconciliation:
Updated the active ActorDefinition StructureDefinition binding description and the paired actor-type and actor-code CodeSystem/ValueSet descriptions so high-level actor type text no longer says only system or human, and the detailed code vocabulary is described as non-system actor categories.

Recommendation:
Keep this source fix. Handle the remaining FHIR-50087 THO move and any category binding-strength adjustment separately when that issue is in scope for application.
