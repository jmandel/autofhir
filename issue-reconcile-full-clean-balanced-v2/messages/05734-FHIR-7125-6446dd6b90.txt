FHIR-7125: Audit Procedure.outcome text guidance

Issue request:
FHIR-7125 was Published/Not Persuasive with Modification for the DSTU1 Procedure resource. The commenter objected that Procedure.outcome should not force hard coded outcomes and noted that outcome might be unknown or overlap fuller procedure/report narrative. The final Patient Care decision kept the coded element but required a usage note that text-only outcomes can be carried in CodeableConcept.text, and clarified that Procedure.outcome was not intended to replace a full diagnostic report section associated with the procedure.

Initial application:
The issue appears to have been applied in historical commit 512b2462e3, whose message includes #7125 and whose Procedure spreadsheet hunk added the Procedure.outcome comment "If outcome contains the narrative text only, it can be captured using the CodeableConcept.text." The current XML source is generated/refactored from that older spreadsheet history, and the same text guidance is still present in the current authoritative Procedure StructureDefinition.

Additional context:
Procedure is an active current-build resource in source/fhir.ini. Later Applied issue FHIR-40516 changed Procedure.outcome from CodeableConcept 0..1 to CodeableReference(Observation) 0..* while keeping the simple concept/text branch, an example-strength outcome value set, and a short-term outcome comment; it is already represented on the combined branch by an Issue-Reconcile-Key commit. Later Applied issue FHIR-47823 added ventilator-setting Observation guidance to the same comment. These later decisions refine the element but do not undo FHIR-7125's text-only guidance or require removing the example coded outcome binding.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active Procedure StructureDefinition already says text-only outcome narrative can use CodeableConcept.text, Procedure.outcome is bound only with example strength, and fuller report material is represented separately by Procedure.report references. The current source therefore satisfies the FHIR-7125 resolution without adding redundant prose.

Recommendation:
Keep this no-change audit as-is for FHIR-7125. Do not remove the example outcome coding or duplicate the text guidance elsewhere; any future changes to Procedure.outcome should be considered through the later Procedure outcome issue family rather than this DSTU1 clarification.
