FHIR-12312: Audit codesystem-deprecated removal

Issue request:
FHIR-12312 was a Published/Persuasive FHIR-core CodeSystem change request from Vocab. It asked to remove the http://hl7.org/fhir/StructureDefinition/codesystem-deprecated extension because deprecation should be represented with the http://hl7.org/fhir/concept-properties property system, and to document that property URL mechanism clearly.

Initial application:
The issue was applied by git-svn commit 03c14a7fcf8ae612f0fcb6c59edb2c55924f3794, matching Jira's svn revision 13899 comment. That commit removed the deprecated extension row from the CodeSystem extension spreadsheet and added type information to the concept-properties URL table on the CodeSystem notes page. Later source refactoring removed the old spreadsheet file entirely.

Additional context:
The current build includes the concept-properties CodeSystem via source/fhir.ini, defines the deprecated/deprecationDate concept properties in source/codesystem/codesystem-concept-properties.xml, and explains the full http://hl7.org/fhir/concept-properties#... URI pattern and reuse expectations in source/codesystem/codesystem-notes.xml. Searches of active source and the FHIR Extension Pack found no codesystem-deprecated extension definition or current references; remaining hits are only historical Release 3 material under tools/history. Confluence Vocab block-vote records also list tracker 12312 as Persuasive.

Recommendation:
