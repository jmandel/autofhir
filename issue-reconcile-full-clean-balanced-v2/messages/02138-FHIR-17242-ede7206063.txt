FHIR-17242: Audit BCP 195 security guidance

Issue request:
FHIR-17242 was a Published FHIR-core Security change request, resolved Persuasive with Modification for STU3, asking the Security page/checklist to recommend IETF BCP 195 when TLS is used and to warn that future FHIR revisions would likely deprecate TLS versions before TLS 1.2.

Initial application:
The issue was applied in 95ee245e72 as part of a Security narrative update that added the BCP 195 recommendation and explanatory TLS-version guidance to source/security.html. The safety checklist later carried the same recommendation in source/safety.html, and the checked-in safety checklist CodeSystem source now includes the corresponding use-tls-per-bcp195 concept.

Additional context:
FHIR-33937 is a later Published Security decision for the same paragraph. It found the copied TLS 1.2/lower-version explanation stale after BCP 195 changed, and its Jira comments/resolution favored keeping the BCP 195 reference while deleting the restatement so FHIR would not have to track changing IETF BCP details. Current combined-branch source/security.html follows that later decision: it recommends BCP 195 without restating TLS-version details.

AutoFHIR reconciliation:
No source change was made. The current build-scope sources already contain the BCP 195 recommendation in the Security communications section and the Security Related Safety Checks checklist, and the only missing original detail is intentionally superseded by FHIR-33937 rather than a current defect.

Recommendation:
Keep this audit commit as-is. Do not restore the older TLS 1.2 deprecation/protocol-version prose for FHIR-17242; if TLS protocol guidance needs more detail, handle it as a fresh Security WG decision that can track the current IETF BCP 195 text.
