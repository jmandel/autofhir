FHIR-17435: Audit MedicationRequest dosage route example

Issue request:
FHIR-17435 was a Published Pharmacy change request for STU3 asking why MedicationRequest kept route and additionalInstruction on repeatable dosageInstruction rather than moving them to MedicationRequest. The final disposition was Not Persuasive with Modification: no resource model change, but create an example.

Initial application:
The issue was applied by historical commit 0b594bda3d8e7a564559f79d4ef72577c4e25d34, "GF 17435: added example for MedicationRequest", which added source/medicationrequest/medicationrequest0339.xml and listed it as a MedicationRequest example for a kit containing two dosage forms. Later source refactors preserved the example in the current MedicationRequest build.

Additional context:
The Jira comments and linked Zulip thread show the core rationale: uncommon but real cases exist where a single product package has different dosage forms, routes, and potentially additional instructions, such as a vaginal tablet plus topical cream. Current source/fhir.ini keeps MedicationRequest in the active resource set and Dosage/DosageDetails in the active datatype set. The current MedicationRequest source also now uses a single DosageDetails entry, with the example representing separate components for the two package parts rather than requiring a resource-level route.

AutoFHIR reconciliation:
No source change was made. The active example already demonstrates the accepted model with a Vagistat kit MedicationRequest whose dosageInstruction contains separate component instructions and routes for the vaginal tablet and topical cream, and source/medicationrequest/list-MedicationRequest-examples.xml lists that example as "Request for a product that contains multiple dosage forms." Adding more prose or moving elements would contradict the final Jira disposition and would be redundant with the existing example.

Recommendation:
Keep this audit commit as-is. No current core source change is recommended unless the Pharmacy WG opens a new tracker specifically requesting an additional example that also populates coded Dosage.additionalInstruction for the kit scenario.
