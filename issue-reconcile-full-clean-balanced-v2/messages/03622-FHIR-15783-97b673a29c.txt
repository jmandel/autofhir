FHIR-15783: Audit ResearchStudy and ResearchSubject scope usage

Issue request:
FHIR-15783 is a Published/Persuasive BRR change request for STU3. It asked for the Scope and Usage sections for ResearchStudy and ResearchSubject to be made more descriptive, including clearer intended use, out-of-scope boundaries, and whether the resources should be understood as event or request resources from a FHIR Workflow perspective.

Initial application:
The Jira comments record that BRR agreed revised wording on 2018-10-23 and Julie Evans applied it to the current build on 2018-11-15. Git history does not tag FHIR-15783 directly, but commit cf0ceda05d on 2018-11-07 removed the generic HL7 mission paragraph from both ResearchStudy and ResearchSubject introduction pages and replaced it with resource-specific Scope and Usage text. That commit is the matching implementation event for the Jira-applied wording.

Additional context:
ResearchStudy and ResearchSubject are active build resources in source/fhir.ini. The current ResearchStudy introduction still identifies ResearchStudy as a definition resource from a FHIR workflow perspective and gives concrete study-use bullets. The current ResearchSubject introduction has been substantially refined by later BRR decisions, including FHIR-29259, FHIR-44838, FHIR-46449, and FHIR-53229, and now describes the subject/object scope, retrospective-study inclusion, common uses, state/milestone guidance, and the explicit boundary that defining permissible subject workflows is out of scope for the resource. FHIR-38076 later refreshed ResearchStudy front matter without reversing the FHIR-15783 scope clarification. Corrected Jira/Zulip/Confluence searches found no conflicting community record for FHIR-15783.
