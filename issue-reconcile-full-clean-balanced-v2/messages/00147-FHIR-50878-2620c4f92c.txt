FHIR-50878: Audit MolecularDefinition profile links

Issue request:
FHIR-50878 was an Applied/Persuasive Clinical Genomics change request asking that the MolecularDefinition Boundaries and Relationships text add hyperlinks to the Molecular Definition Data Types Implementation Guide and its relevant profiles, with the final resolution calling out the work-in-progress nature of that guide.

Initial application:
The change was applied before this reconciliation on branch ak-FHIR-50878 and merged by HL7/fhir pull request #3506 in commit 66f7b3563ed9602ba9abdb6cf15cfd0004f8501a. The implementation replaced the MolecularDefinition Boundaries and Relationships paragraph with links to the Molecular Definition Data Types IG and the Sequence, Allele, Variation, Haplotype, and Genotype profile pages, plus links to Observation and GenomicStudy in the following paragraph.

Additional context:
FHIR-50576 was the original broader ballot comment and was split so Devices could handle DeviceAlert while Clinical Genomics handled MolecularDefinition here. A committers Zulip thread discussed the caution around linking from core to an unpublished/CI IG, and the later Clinical Genomics Zulip and Confluence records show the proposed disposition for FHIR-50878 was to add the links while describing the IG as work in progress. The current source also repeats the same IG/profile link set on the genomics guidance page.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active fhir.ini resource list includes MolecularDefinition, and the current MolecularDefinition introduction already contains the requested IG link, direct profile links, and work-in-progress caveat, so another edit would be redundant for this issue.

Recommendation:
Keep this audit commit as-is. If the Molecular Definition Data Types IG later receives a stable publication URL, update these links through a separate maintenance issue rather than reopening this applied hyperlink reconciliation.
