FHIR-12468: Audit MedicationAdministration reason alignment

Issue request:
FHIR-12468 was a Published/Persuasive Pharmacy change request for DSTU2 asking MedicationAdministration to mirror MedicationStatement by renaming reasonGiven to reasonGivenCodeableConcept, renaming reasonReference to reasonGivenReference, and ordering the given-reason elements together after the not-given elements.

Initial application:
The issue was applied by git-svn commit 805a87d6445447d15f8df95750cdebdf698056e5, which renamed the MedicationAdministration reason fields and changed their order in the spreadsheet source. A later Published Pharmacy harmonization, FHIR-12842, was applied by 3e6ab010725e97201494594d25960f3a4ebbb7df and intentionally renamed those intermediate fields to the broader reasonCode and reasonReference pattern across pharmacy resources.

Additional context:
MedicationAdministration is active in source/fhir.ini. The current build source no longer has separate reasonCode/reasonReference elements; it uses MedicationAdministration.reason as a CodeableReference with Condition, Observation, DiagnosticReport, and Procedure targets, and fhir.ini records that MedicationAdministration.reason merged reasonCode and reasonReference with aliases to reason.concept and reason.reference. MedicationStatement.reason uses the same CodeableReference pattern, so the current model preserves the issue's alignment goal even though later R5/R6 modeling changed the literal element names.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding back the DSTU2-era reasonGiven names or separate reasonReference element would contradict the later Pharmacy harmonization and current CodeableReference model, while the active source already supports both coded and referenced reasons in the aligned location.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-12468; future work should treat FHIR-12842 and the CodeableReference migration as the current interpretation of the original alignment request.
