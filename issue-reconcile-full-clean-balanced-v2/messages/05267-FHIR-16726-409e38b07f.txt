Issue request:
FHIR-16726 is a Published/Persuasive FHIR-core CodeSystem ballot issue from the 2018-May Core Norm Conformance ballot. It asked for Purpose and Use Context to be more clearly distinguished and said examples would be helpful; the accepted resolution was to copy examples from ValueSet.

Initial application:
No explicit source commit mentioning GF#16726/FHIR-16726 was found. The Jira comment says the work was done under another task, and git history shows svn revision 14770 (f82e3c73beeeeed5c68cbcae84004e5952ae3f01) applied the sibling GF#16794 and GF#16759 ValueSet/ConceptMap example changes without touching CodeSystem. Current CodeSystem source already had a summary example with useContext from earlier history, but the built CodeSystem/example did not include the ValueSet-style purpose/useContext distinction.

Additional context:
CodeSystem is an active current-build resource in source/fhir.ini, and source/codesystem/list-CodeSystem-examples.xml lists CodeSystem/example as the simple CodeSystem example. Current source/codesystem/structuredefinition-CodeSystem.xml distinguishes useContext as the contexts the content is intended to support from purpose as why the code system is needed/designed. FHIR-16794 and FHIR-16759 are the parallel ValueSet and ConceptMap issues from the same ballot family and are already represented on the combined branch. Zulip and Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
This commit adds the ValueSet-style age useContext, US jurisdiction, and explicit purpose to source/codesystem/codesystem-example.xml so the current built CodeSystem example shows the requested distinction in the CodeSystem artifact itself.

Recommendation:
Keep this source fix as-is. It is a narrow completion of the published CodeSystem resolution; no further work is needed unless the Vocabulary WG wants different example wording.
