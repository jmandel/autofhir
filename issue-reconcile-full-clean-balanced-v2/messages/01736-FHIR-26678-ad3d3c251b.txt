FHIR-26678: Audit Condition onsetPeriod clarification

Issue request:
FHIR-26678 was a Published FHIR-core Condition change request resolved as Persuasive with Modification. It asked Patient Care to clarify that Condition.onsetPeriod does not mean a progressive onset interval; the approved comment says Period generally conveys an imprecise onset that occurred within the time period and is not the transition period before diagnosis.

Initial application:
The issue was applied by git commit 50ad212e27, "J#26678 clarify Condition.onsetPeriod", which updated source/condition/condition-spreadsheet.xml with the approved Period comment. A later source rework, 33b409a4b6, carried the same phrase into the current StructureDefinition-based Condition source.

Additional context:
Condition is an active resource in source/fhir.ini, and the current source/condition/structuredefinition-Condition.xml comment for Condition.onset[x] includes the FHIR-26678 wording. Later same-element decisions FHIR-32477 and FHIR-42978 added Range and event/situation clarification around the same comment while preserving the Period interpretation. The linked Zulip thread confirms the original ambiguity and Lloyd McKenzie's answer that onsetPeriod means the onset occurred sometime within the period; the PC minutes page references the issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Condition source already conveys the approved rule for onsetPeriod, and adding another local restatement would be redundant.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed for FHIR-26678 unless a future Patient Care decision changes the meaning of Condition.onsetPeriod.
