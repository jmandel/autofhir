FHIR-28605: Audit gender identity non-disclose wording

Issue request:
FHIR-28605 was a Published/Persuasive PA technical correction for R5 asking that the gender-identity value set's non-disclose wording use "their gender identity" instead of "his gender identity".

Initial application:
The issue was applied by git commit 5717fbdcb8ef57518606578a52d5e83ac6d1031e, which changed source/patient/codesystem-gender-identity.xml for the non-disclose concept from "the individual does not wish to disclose his gender identity" to "the individual does not wish to disclose their gender identity". PA minutes on 2021-08-11 record the issue as persuasive with a 3-0-0 vote.

Additional context:
The old core gender-identity CodeSystem/ValueSet source is no longer part of the current core build. FHIR-38639 later removed source/patient/codesystem-gender-identity.xml because the value set had moved to THO and referenced non-FHIR code systems, and a later cleanup removed source/patient/valueset-gender-identity.xml from core. Current core source/fhir.ini has no active gender-identity CodeSystem or ValueSet entry, source/oids.ini only retains the THO value set URL, and the current THO value set no longer includes the old non-disclose code.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested wording fix was applied before the obsolete core CodeSystem was removed, and the current authoritative terminology source no longer contains the stale "his gender identity" text or the old non-disclose concept.

Recommendation:
Keep this audit commit as-is. No FHIR-core follow-up is needed for FHIR-28605; any future changes to the current gender-identity terminology should be handled in THO or the appropriate external terminology source rather than by restoring obsolete core source files.
