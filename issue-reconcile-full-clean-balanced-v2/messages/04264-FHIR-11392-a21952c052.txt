FHIR-11392: Audit EOB diagnosis package code rename

Issue request:
FHIR-11392 was a Published/Persuasive Financial Management change request from the DSTU2 ballot asking to rename the ExplanationOfBenefit Diagnosis `drg` attribute to `packageCode`.

Initial application:
The request was applied in historical commit d06f8787e6 ("Tracker #11375, 11376, 11391, 11392"), which changed `ExplanationOfBenefit.diagnosis.drg` to `ExplanationOfBenefit.diagnosis.packageCode` and updated the short, definition, and requirements in the then-authoritative EOB spreadsheet source.

Additional context:
ExplanationOfBenefit is an active current resource in `source/fhir.ini`. The current authoritative XML source no longer has either `ExplanationOfBenefit.diagnosis.drg` or `ExplanationOfBenefit.diagnosis.packageCode`; instead it has the root element `ExplanationOfBenefit.diagnosisRelatedGroup`. That later shape matches Published FHIR-29688, which explicitly requested adding `diagnosisRelatedGroup` at the Claim, ClaimResponse, and EOB roots and removing `resource.diagnosis.packageCode`, and was applied by commit acb64eec3c. `source/fhir.ini` also records `ExplanationOfBenefit.diagnosis.packageCode` as removed in the R4-to-R6 change map.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing a diagnosis-level `packageCode` would conflict with the later final FHIR-29688 decision, while the obsolete `drg` element requested by FHIR-11392 is absent from current EOB source.

Recommendation:
Keep this no-change audit commit. No FHIR core source follow-up is needed for FHIR-11392 unless the work group separately reopens the later FHIR-29688 model decision.
