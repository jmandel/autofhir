FHIR-7630: Clarify Procedure bodySite target definition

Issue request:
FHIR-7630 was a Published Patient Care change request with resolution Not Persuasive with Modification. It asked to rename Procedure/ProcedureRequest.bodySite to targetBodySite because other body sites, such as approachBodySite, can also be associated with a procedure. The approved decision kept the element name but required the short description and full definition to reflect the focal/target body site, added approachBodySite as an extension, and corrected the RIM mapping to targetSiteCode rather than approach.

Initial application:
The issue was historically applied with related body-site work in git commit 27f73740e4afc943ade51df795872e6e5c3865ee, whose subject explicitly cites #7630 and #7124. That commit changed Procedure.bodySite's short text from "Precise location details" to "Target body sites" and kept the RIM mapping as .targetSiteCode, but it left the full definition as generic anatomical-location text, so one explicit part of the FHIR-7630 resolution remained under-applied.

Additional context:
Procedure is active in source/fhir.ini and source/procedure/structuredefinition-Procedure.xml is the current authoritative resource definition. ProcedureRequest has since become ServiceRequest, whose current bodyStructure definition already says the site is the target site and maps to targetSiteCode. The old approachBodySite/targetBodySite extension names have moved forward as FHIR Extension Pack BodyStructure extensions, including procedure-approachBodyStructure and procedure-targetBodyStructure, so no core extension source edit is needed for this issue.

AutoFHIR reconciliation:
This commit updates the in-scope Procedure.bodySite full definition to say it is the target body site(s) where the procedure was performed, while preserving the existing short text, cardinality, example, binding, and RIM targetSiteCode mapping.

Recommendation:
Keep this source change. It completes the remaining FHIR-7630 resolution gap in the current core build without reintroducing retired ProcedureRequest or core extension artifacts; any future changes to approach/target BodyStructure extensions should be made in the FHIR Extension Pack.
