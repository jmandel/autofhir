FHIR-14726: Audit CodeSystem resource definition

Issue request:
FHIR-14726 was a Published/Persuasive STU3 Vocabulary technical correction for FHIR-core CodeSystem. It identified that the CodeSystem resource definition had incorrectly copied ValueSet wording about codes drawn from one or more code systems, and the final accepted wording was: "The CodeSystem resource is used to declare the existence of and describe a code system or code system supplement and its key properties, and optionally define a part or all of its content."

Initial application:
The issue was applied by git-svn commit 04bb1e9d0e8a53fc60f7bb808e88ff75dbb12f3a, svn revision 13150, with subject "GF#14726 - Fix CodeSystem resource definition." That commit changed the historical CodeSystem spreadsheet and the terminology module title. The later source rework carried the accepted wording into source/codesystem/structuredefinition-CodeSystem.xml.

Additional context:
The linked Zulip thread #terminology > Code System Definition confirms the copy/paste error and records the same final wording after discussion. FHIR-13450 and FHIR-14242 are duplicate reports of the same incorrect CodeSystem definition. Later FHIR-39044 clarified surrounding Scope and Usage text on the CodeSystem page but did not reverse or replace the FHIR-14726 resource definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. CodeSystem is active in source/fhir.ini, and the current active StructureDefinition source plus the terminology module resource list already contain the accepted FHIR-14726 wording. The old incorrect sentence is absent from current CodeSystem source; remaining matches are appropriate ValueSet text or archived release3 history under tools/history.

Recommendation:
Keep this no-change audit commit as-is. No FHIR-core source follow-up is needed for FHIR-14726 unless the Vocabulary work group separately chooses to rewrite broader introductory prose for CodeSystem.
