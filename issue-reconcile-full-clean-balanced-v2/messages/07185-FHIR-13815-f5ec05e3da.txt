FHIR-13815: Audit ValueSet purpose clarification

Issue request:
FHIR-13815 was Published/Persuasive with Modification for STU3. It asked to clarify that a Coding.system is a code system, not a value set, and that value sets provide codes for use in a specific context while code systems define code meaning. The resolution called for added documentation in Coding, Using Codes in Resources, and, if possible, ValueSet resource documentation.

Initial application:
The issue was applied by SVN revision 13457, mirrored as git commit 5330c3c2ad49a97722ab121f48296c2c34e4f890, which updated source/datatypes.html and source/terminologies.html with the requested CodeSystem-vs-ValueSet distinction. Current git blame shows the same substantive wording still present after later formatting and editorial refactors.

Additional context:
The original Zulip thread confirms the implementer confusion: a Patient.marital-status Coding used a ValueSet as system and participants agreed documentation should make the distinction clearer. The current active ValueSet StructureDefinition now also states that a ValueSet specifies codes from one or more code systems for use in a particular context and documents ValueSet.useContext. Later related issues FHIR-16379 and FHIR-16497 touched the same definition/typo family and are already represented on the combined reconciliation branch, so this commit does not duplicate them.

AutoFHIR reconciliation:
