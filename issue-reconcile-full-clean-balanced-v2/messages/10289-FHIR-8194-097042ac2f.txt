FHIR-8194: Audit retired QICore extension page readability

Issue request:
FHIR-8194 was a Published/Persuasive FHIR-core DSTU1 change request for the May 2015 QICore page http://www.hl7.org/FHIR/2015May/extension-adverseevent-qicore-cause.html. It said the generated AdverseEvent QICore cause extension documentation was unreadable; comments clarified that the snapshot table should not expose confusing url/value[x] rows for the complex extension and that the AdverseEvent.cause.item and cause.certainty data types were not visible. Jira records the resolution as fixed and the application comment as checking after version 5328.

Initial application:

That commit changed the old QICore AdverseEvent profile spreadsheet around AdverseEvent-cause.item and AdverseEvent-cause.certainty, including the complex extension child-row markers and extension fragment names, and changed ProfileUtilities so extension URLs link to the generated extension definition page.
