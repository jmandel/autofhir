FHIR-5190: Audit Person link wording reconciliation

Issue request:
FHIR-5190 was a Published/Persuasive PA change request from the January 2015 ballot for FHIR-core Person/RelatedPerson. It asked that the Person linking section change "The link element is used to related resources under a common person record" to "The link element is used to relate resources under a common person record."

Initial application:
The requested wording was applied in git commit dc2afae9f6e31b220e90a9d948c46e3743363e68, which explicitly lists tracker 5190 among Person ballot reconciliation changes and changes source/person/person-notes.xml from "used to related resources" to "used to relate resources."

Additional context:
Person and RelatedPerson are active resources in source/fhir.ini. The current built Person notes contain "The person.link element is used to relate resources under a common person record." Later Published issue FHIR-17399 changed the local wording from generic "link" to "person.link" while preserving the corrected verb and resolving a separate RelatedPerson linking clarification. Zulip and Confluence searches found no FHIR-5190-specific community or minutes evidence that conflicts with the Jira/source history.

AutoFHIR reconciliation:
No source change was made. The authoritative current Person narrative already carries the requested correction, and the later "person.link" wording is a valid clarification rather than a regression from FHIR-5190.

Recommendation:
Keep this audit commit as-is. No follow-up source edit is needed for FHIR-5190 unless a future PA decision reopens the broader Person linking guidance.
