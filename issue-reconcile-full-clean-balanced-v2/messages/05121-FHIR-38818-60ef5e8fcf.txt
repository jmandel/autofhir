FHIR-38818: Audit SupplyDelivery relocation

Issue request:
FHIR-38818 was an Applied/Persuasive with Modification OO change request to clarify that SupplyDelivery covers shipment/dispatch as well as receipt/reception. The approved disposition required SupplyDelivery.status to be 1..1, added a required summary SupplyDelivery.stage element with an extensible stage value set, relaxed SupplyDelivery.type to extensible, added sample use cases and shipment-stage guidance, changed the resource short definition to "Record of movement of supplies from one location to another", and moved dispatch/reception core profiles into separate Jira FHIR-45506.

Initial application:
The issue was applied in current source history by acfe1809cf, which removed the draft dispatch/receipt profiles from the SupplyDelivery implementation guide, changed SupplyDelivery.stage from Coding to CodeableConcept, and adjusted the implementer note. Earlier 2023 source already contained the required status cardinality, stage element, stage value set, type extensible binding, sample use cases, and movement-focused short definition. Later SupplyDelivery commits, including FHIR-42947 and FHIR-45506, refined related narrative without reversing FHIR-38818.

Additional context:
SupplyDelivery is no longer an active core resource in this checkout. Commit 3b38b80cf2 removed supplydelivery, supplyrequest, and related OO resources from source/fhir.ini and changed active core pages to point to the OO Incubator IG. Current source/fhir.ini has no SupplyDelivery build entry, while active module pages link to https://build.fhir.org/ig/HL7/oo-incubator/StructureDefinition-SupplyDelivery.html. The external HL7/oo-incubator source carries the FHIR-38818 semantics: stage is 1..1 CodeableConcept with extensible binding and the introduction describes dispatch, receipt, sample use cases, and the one-resource/multiple-stage approach.

AutoFHIR reconciliation:
This commit intentionally makes no source change in FHIR core. Editing source/supplydelivery would not affect the current core build because the resource is no longer active there, and the current built core already delegates SupplyDelivery to the OO Incubator IG.

Recommendation:
Keep this audit commit as-is for core reconciliation. Any future corrections to SupplyDelivery stage semantics or dispatch/reception narrative should be made in HL7/oo-incubator rather than this FHIR core checkout; FHIR-45506 and FHIR-42947 should be reviewed separately if their external IG migration needs a dedicated audit.
