FHIR-12757: Audit C-CDA FormatCode updates

Issue request:
FHIR-12757 was a Published/Persuasive SDWG change request for DSTU2 asking to update the DocumentReference FormatCode value set from the IHE/CDA format-code list for new C-CDA R2.1 codes and to add "(aka C32)" to the xphr description.

Initial application:
The C-CDA R2.1 code addition appears to have been applied first by git b07ae74b6f, which added the structuredBody and nonXMLBody 2.1 codes under GF#12788. The FHIR-12757 block-vote commit 94e532a611 then refreshed the same in-core DocumentReference formatcodes value set and changed xphr from "HL7 CCD Document" to "Personal Health Records. Also known as HL7 CCD and HITSP C32".

Additional context:
Later format-code work moved responsibility out of a hand-maintained core value set: FHIR-13950 and FHIR-14003 led to use of IHE-published format code terminology and the correct value-set OID, FHIR-14104/UP-241 established HL7-managed document format codes in THO, and git 6f1b3314e9 deleted the core valueset-formatcodes.xml file while rebinding DocumentReference.content.profile.value[x] to http://terminology.hl7.org/ValueSet/v3-HL7FormatCodes. Current cached THO/IHE packages include the requested C-CDA 2.1 HL7 codes and the xphr definition with HITSP C32 wording.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The active DocumentReference source already binds the relevant element to the THO ValueSet, and the authoritative terminology dependency already contains the requested codes and description.

Recommendation:
Keep this no-change audit. Future FormatCode additions or display/definition corrections should be made in THO or the IHE FormatCode package, not by resurrecting the removed in-core value set.
