FHIR-31777: Clarify APD dose form concepts

Issue request:
FHIR-31777 was a Published/Persuasive FHIR-core BRR clarification for the R4 MedicinalProductPharmaceutical artifact, applied for R5, asking for clearer usage notes explaining how administrableDoseForm and unitOfPresentation differ and relate when examples such as tablet can appear code-like in both areas.

Initial application:
The R4 artifact was refactored into the active AdministrableProductDefinition resource before final application. Commit fbfbf287b1 updated AdministrableProductDefinition.administrableDoseForm and unitOfPresentation descriptions as part of the APD documentation reconciliation, but its message appears to typo the Jira key as FHIR#3177 and did not include the later BRR note that AdministrableDoseForm may be the same as ManufacturedDoseForm.

Additional context:
source/fhir.ini keeps AdministrableProductDefinition in the current build and maps MedicinalProductPharmaceutical to AdministrableProductDefinition. BRR minutes from 2021-10-28 record the follow-up instruction for FHIR-31777 to add that AdministrableDoseForm may be the same as ManufacturedDoseForm. No directly relevant Zulip discussion or conflicting Confluence record was found.

AutoFHIR reconciliation:
Updated the active AdministrableProductDefinition StructureDefinition source. The administrableDoseForm definition now says it can be the same as the manufactured dose form when no reconstitution or processing is needed, and the unitOfPresentation definition now explicitly identifies it as the countable presentation item rather than the product dose form.

Recommendation:
Keep this clarification as-is. It is a narrow non-substantive source fix in the active build input and completes the missing part of the published BRR documentation decision without changing cardinalities, bindings, or examples.
