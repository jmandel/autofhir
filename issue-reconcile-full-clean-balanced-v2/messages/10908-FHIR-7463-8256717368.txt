FHIR-7463: Audit patient compartment example casing

Issue request:
FHIR-7463 was a Published FHIR-core technical correction from the 2015May/DSTU1 ballot. It asked to change the search page example for procedures in a patient compartment from `GET [base]/Patient/23/Procedure?...` to lowercase `GET [base]/patient/23/Procedure?...`. The Jira resolution was Persuasive with Modification and explicitly says to resolve the issue per FHIR-7464.

Initial application:
No git commit explicitly mentioning FHIR-7463 was found for `source/search.html`. The Jira comments say "see 7464" and "already applied". FHIR-7464 records svn revision 5671, which is git commit ac324ca8a1a86de1d9990a1288aff1720fc0ab6a, `#7464 - compartment documentation improvements`; that commit changed lowercase `/patient` compartment-search examples to uppercase `/Patient` and removed obsolete compartment URI presentation.

Additional context:
FHIR-7464 is already represented on the combined branch by commit 17f92bd74f5ee2b784f94bfe6e2a0b2362b858cd, which audited the same URL-casing policy and concluded the current source is correct. Current `source/search.html` is the active search-page source and still uses uppercase `GET [base]/Patient/23/Procedure?...` for the exact example raised by FHIR-7463. A current source search found no lowercase `[base]/patient` endpoint examples, and Zulip/Confluence searches found no community evidence contradicting the FHIR-7464 decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Although FHIR-7463's proposed wording asked for lowercase `patient`, its final disposition delegates to FHIR-7464, whose accepted rule is uppercase `/Patient` in all cases. Changing the current example to lowercase would reintroduce the ambiguity that the linked resolution closed.

Recommendation:
Keep this audit commit as-is. No FHIR-core source follow-up is needed for FHIR-7463; future compartment URL casing changes should be handled by a new work-group decision rather than by resurrecting the superseded lowercase proposal.
