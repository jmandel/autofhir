FHIR-6048: Audit Signature device signer support

Issue request:
FHIR-6048 is a Published/Persuasive Security change request for FHIR core datatypes/Provenance. It asked that digital signatures be allowed to reference Device resources because a CDS service signing a recommendation could only otherwise be represented by a URI. The approved resolution was to add Device to Signature.who as an allowed resource.

Initial application:
The issue appears to have been applied by commit 7680a21d741140fb7104da32f2a217d2b0b25d2e on 2015-08-22, whose subject explicitly references #6048. That commit changed Signature.who[x] from uri|Reference(Practitioner|RelatedPerson|Patient) to uri|Reference(Practitioner|RelatedPerson|Patient|Device|Organization). Later Signature datatype refactors changed the element from who[x] to who and removed the URI choice, while retaining Device in the allowed Reference target list.

Additional context:
Current source/fhir.ini lists Signature as an active datatype and marks it normative, so source/datatypes/signature.xml is in current build scope. The current Signature.who type is Reference(Practitioner|PractitionerRole|RelatedPerson|Patient|Device|Organization), so it still includes Device and also reflects later unrelated additions such as PractitionerRole. Jira neighborhood searches found FHIR-6048 as the relevant issue for Signature/Device signer support; FHIR-9533 and FHIR-9563 are separate Signature datatype changes and do not change this decision. Zulip and Confluence searches found no direct FHIR-6048 discussion or conflicting work-group evidence.

AutoFHIR reconciliation:
No source change was made. The current active Signature datatype source already satisfies the requested Device allowance for Signature.who, and editing it would either be redundant or risk disturbing later accepted target-list changes.

Recommendation:
Keep this empty audit commit as-is. No core source follow-up is needed for FHIR-6048 unless a future Security work-group decision changes the Signature.who target resources.
