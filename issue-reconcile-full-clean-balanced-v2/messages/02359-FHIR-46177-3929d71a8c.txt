Initial application:

Additional context:
The current combined-branch source defines http://hl7.org/fhir/ValueSet/languages as Common Languages and includes the 19 requested seed concepts: bg, bs, cs, da, et, ga, hu, is, kk, lt, lv, mk, mt, ro, sk, sl, sq, tr, and uk. FHIR-46178 is a tightly related follow-up about Common Languages typos and German translations; it is already represented on the combined branch, so this commit intentionally does not duplicate it. FHIR-49796 later reorganized the same ValueSet while preserving the FHIR-46177 additions.
