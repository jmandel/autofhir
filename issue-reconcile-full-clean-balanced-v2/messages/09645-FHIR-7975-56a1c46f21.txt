FHIR-7975: Audit Provenance entity search parameters

Issue request:
FHIR-7975 was a Published/Persuasive DSTU1 FHIR-core Provenance change request asking to add `entity` and `entitytype` query parameters for Provenance. The recorded resolution was to add the search parameters as suggested.

Initial application:
The issue was applied in git commit 4f363ad0bd, corresponding to SVN revision 5534 cited in Jira. That commit changed the Provenance spreadsheet Search tab to add the requested `entity` and `entitytype`/later `entity-type` rows over `Provenance.entity.reference` and `Provenance.entity.type`.

Additional context:
Later Provenance modeling decisions changed the relevant source shape. In particular, FHIR-9996 was Published/Persuasive with Modification and directed the spec to change `Provenance.entity.reference` to a Reference(Any) and remove `Provenance.entity.display` and `Provenance.entity.type`. Commit d6bec27176 implemented that by marking `Provenance.entity.type` and the `entity-type` search parameter inactive and changing `entity` from a URI search to a reference search. The current active Provenance resource is in build scope through `source/fhir.ini`, and its current search-parameter bundle contains `entity` on `Provenance.entity.what` while no current `Provenance.entity.type` element exists.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding an `entitytype`/`entity-type` search parameter would refer to a removed element and would conflict with the later published Provenance model; the surviving `entity` query parameter is present on the current entity reference element.

Recommendation:
Keep this audit commit as-is. No current core source fix is needed for FHIR-7975; any future request for an entity type search parameter would need a new work-group decision against the current Provenance model.
