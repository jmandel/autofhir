FHIR-31681: Align ResearchStudy comparisonGroup metadata

Issue request:
FHIR-31681 was a Published FHIR-core BRR change request, resolved Persuasive for R5, asking to change the ResearchStudy arm attribute name to comparisonGroup after the work group rejected making arm an extension and clarified that the concept is broader than clinical trial arms.

Initial application:
The active ResearchStudy resource source already uses ResearchStudy.comparisonGroup, has an arm alias and explanatory comment, and no longer defines ResearchStudy.arm. The rename appears to have been applied in git commit d7dbd7689b50ed517e3900c4512399c2cf62d466, which renamed the ResearchStudy.arm backbone and its then-current children to comparisonGroup without naming FHIR-31681 in the subject. A later commit, 9175459a6ea354d82e8b09ca90574344bbe333d6, mentioned #31681 but only changed unrelated ResearchStudy target profiles, so it is not the substantive arm rename application.

Additional context:
ResearchStudy is active in source/fhir.ini, and later ResearchStudy refactors changed the comparisonGroup child shape, including current targetNumber, actualNumber, eligibility, observedGroup, name, and description children. The active FHIR ModelInfo Library example is also build-scoped: Library is an active resource, list-Library-examples.xml lists Library/library-fhir-model-definition, library-examples-header.xml links library-fhir-model-definition-content.xml, and publish.ini copies that readable XML content. That ModelInfo surface still exposed ResearchStudy.arm and ResearchStudy.Arm. The R4-to-R6 change map also still treated ResearchStudy.arm as deleted rather than renamed.

AutoFHIR reconciliation:
Updated source/fhir.ini so the R4-to-R6 change metadata maps ResearchStudy.arm, arm.name, and arm.description to the current comparisonGroup paths while leaving arm.type deleted because the current R6 ResearchStudy no longer has comparisonGroup.type. Updated source/library/library-fhir-model-definition-content.xml so the active FHIR ModelInfo example exposes comparisonGroup and ResearchStudy.ComparisonGroup using the current child shape, and refreshed the embedded base64 payload in source/library/library-fhir-model-definition.xml so both Library representations remain synchronized.

Recommendation:
Keep this commit as-is. It completes the FHIR-31681 rename across the current build-scoped migration metadata and ModelInfo Library surfaces; any broader regeneration of the whole FHIR ModelInfo or cleanup of unrelated ResearchStudy R5-to-R6 change-map rows should be handled under separate Jira decisions.
