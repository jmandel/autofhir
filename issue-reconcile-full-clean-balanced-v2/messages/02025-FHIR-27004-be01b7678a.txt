FHIR-27004: Audit vital signs ounce-unit resolution

Issue request:
FHIR-27004 is an Applied FHIR-core Observation change request from OO, resolved Not Persuasive with Modification for R6. It originally asked to relax core vital-signs unit requirements so a standard converted unit could be carried in the ISO 21090 PQ translation extension while preserving source units; the final resolution instead added oz_av to the units value set rather than relaxing the body-weight profile requirement.

Initial application:
No FHIR-27004-labeled source commit was found in the local git history. The FHIR-27004 Jira comments point to the follow-up FHIR-49972 issue and say FHIR-49972 applied git 90f6f81f6c. That commit added '[oz_av]' to ucum-vitals-common and ucum-bodyweight, and follow-up commit 8515a4fcf4 added the missing '[oz_av]' bodyweight binding summary and binding description references.

Additional context:
The #implementers Core vitals Units Zulip thread shows the original concern about preserving source units, including real weight-in-oz data, and the intermediate suggestion to add oz_av to the value set. FHIR-43353 later relaxed the general VitalSigns profile valueQuantity/component.valueQuantity binding to preferred for ucum-vitals-common, but FHIR-27004's final body-weight-specific resolution was the narrower ounce addition. Current source/fhir.ini keeps Observation active in the build, and FHIR-39153 confirms ucum-bodyweight and ucum-vitals-common were not migrated out of core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current bodyweight profile still has a required binding to http://hl7.org/fhir/ValueSet/ucum-bodyweight and now lists '[oz_av]' in its binding description, while both the bodyweight and common vital-signs UCUM value-set sources include '[oz_av]'. That matches the final FHIR-27004 disposition without adding the broader translation-extension relaxation that the WG did not approve.

Recommendation:
Keep this no-change audit commit as-is. If a future work group wants a broader translation-extension rule for vital signs source units, that should be handled as a new or explicitly reopened issue rather than as remaining FHIR-27004 work.
