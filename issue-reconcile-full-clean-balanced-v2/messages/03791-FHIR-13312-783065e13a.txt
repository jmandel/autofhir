FHIR-13312: Audit AdverseEvent event binding

Issue request:
FHIR-13312 was Applied/Persuasive with Modification for STU3 AdverseEvent. It objected that AdverseEvent.event was bound, even as an example, to SNOMED CT Clinical Findings and asked for the current clinical-findings binding to be removed because the element should capture the event rather than the resulting harm.

Initial application:
No git commit in the current history was found that mentions FHIR-13312 directly. The later Jira comments state that the issue was resolved with FHIR-22746, whose implementation commit e07c2ff1ac898dde0686f31a089dd8fb9bbfb14e renamed AdverseEvent.event to AdverseEvent.code and replaced the old clinical-findings binding with the AdverseEvent Type value set. FHIR-22746 is already represented on the combined branch by cba15be3cc8aa1f54e8c67a37a472c6f87c3cdfa, so this reconciliation does not publish a duplicate related-issue audit.

Additional context:
source/fhir.ini lists adverseevent as an active resource, so source/adverseevent is in current build scope. The current StructureDefinition has AdverseEvent.code, not AdverseEvent.event, with event-only wording and an example binding to ValueSet/adverse-event-type. The current AdverseEvent Type value set no longer defines all SNOMED CT Clinical Findings; it includes serious reportable event descendants and the explicit fall concept. A clinical-findings binding remains on AdverseEvent.resultingEffect, which is the separate element for effects/harm due to the event and is consistent with FHIR-13312's event-versus-harm distinction.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current authoritative source already removes the inappropriate Clinical Findings binding from the event/code element and keeps Clinical Findings only where harm/effect is represented.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core source follow-up is needed for FHIR-13312 unless a future terminology review decides to further revise the AdverseEvent.code example value set.
