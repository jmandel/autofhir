FHIR-29636: Remove stale Task.reason example guidance

Issue request:
FHIR-29636 was a Published FHIR-core Task clarification with resolution Persuasive with Modification. It asked to clarify Task.basedOn and Task.focus, add usage guidance distinguishing authorization from reason, update Task.focus to say it is the request being fulfilled or resource being manipulated, and replace the old Task.reason guidance with guidance that reason is typically absent for "please fulfill" Tasks because the reason is conveyed on the request in Task.focus.

Initial application:
The Jira-tagged source commit 0a661c71ff updated the Request pattern spreadsheet and Task StructureDefinition for Task.basedOn, Task.focus, and the then-current Task.reasonCode guidance. The later FHIR-31427 commit 98e442708f corrected stale names and examples in the Task.basedOn definition. A separate later Task.reason merge, FHIR-25255 in fbb011b3a9, converted reasonCode/reasonReference to Task.reason but preserved the superseded reason guidance as literal text values in three Task examples.

Additional context:
Task is an active resource in source/fhir.ini and task-example1, task-example5, and task-example6 are active Task examples in source/task/list-Task-examples.xml. Current Task StructureDefinition and request mapping exception source already carry the approved FHIR-29636 wording for Task.basedOn, Task.focus, and Task.reason. The linked Zulip thread captures the reporter's concern, and FHIR Workflow minutes record the eventual Persuasive with Modification vote. Later OO minutes note that Task.basedOn/Task.focus remains an area of discussion for downstream COW work, but they do not provide a final core reversal.

AutoFHIR reconciliation:
Removed the stale Task.reason blocks from task-example1, task-example5, and task-example6. These examples are "fulfill" Tasks with Task.focus pointing at ServiceRequest/lipid, so publishing the superseded guidance as example data contradicted the accepted Task.reason usage note and could mislead implementers.

Recommendation:
Keep this source fix. It removes obsolete example guidance while leaving the approved authoritative definitions unchanged. Future work-group review may further clarify Task.basedOn and Task.focus for COW or other workflow guidance, but that is separate from completing FHIR-29636.
