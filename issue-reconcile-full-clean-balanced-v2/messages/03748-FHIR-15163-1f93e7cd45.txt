FHIR-15163: Audit PlanDefinition type values

Issue request:
FHIR-15163 is a Published/Persuasive CDS change request for PlanDefinition raised in STU3. It asked to remove the generic plan-definition-type code protocol, add clinical-protocol with the definition "Defines a desired/typical sequence of clinical activities including preconditions, triggers and temporal relationships", add workflow-definition with the definition "Defines the steps for a group of one or more systems in an event flow process along with the step constraints, sequence, pre-conditions and decision points to complete a particular objective", and update the PlanDefinition.type definition to a high-level category that distinguishes interested systems.

Initial application:
The issue was initially applied in SVN 13290, represented in git by a1cc4ed53f2d5cbc4633b5869d6c58d983fc81ef, whose message names GF#15163. That commit changed the PlanDefinition protocol example from protocol to clinical-protocol and updated the old PlanDefinition spreadsheet source. Current generated/transformed source preserves the requested PlanDefinition.type definition wording and the workflow-definition concept through the active PlanDefinition StructureDefinition and its THO value set binding. The old local core value set source was later removed when this terminology moved to THO.

Additional context:
FHIR-23876 is a later Applied/Persuasive CDS decision on the same PlanDefinition type artifact. It determined that clinical-protocol was too narrow and that protocol should be available for lab, technical, study, and other non-clinical protocols; UP-655 implemented the protocol addition in THO. The combined branch already contains the FHIR-23876 reconciliation commit 48800791108c29d64806ea95c093c6c5c0f41f74, which fixed the remaining active PlanDefinition protocol example. Current THO PlanDefinitionType includes protocol, clinical-protocol, and workflow-definition, so re-removing protocol in core would conflict with the later decision rather than complete FHIR-15163.

AutoFHIR reconciliation:
This commit intentionally makes no source change. PlanDefinition is an active resource in source/fhir.ini, PlanDefinition.type has the requested high-level definition and binds to the THO plan-definition-type value set, and there is no active local core PlanDefinition type value set source to edit. The current use of protocol is explained by the later FHIR-23876/UP-655 decision family.

Recommendation:
Keep this no-change audit as-is. Do not reapply FHIR-15163 by removing protocol from current core source; any future PlanDefinitionType code maintenance should proceed through THO/UTG and should consider both FHIR-15163 and the later FHIR-23876 broadening.
