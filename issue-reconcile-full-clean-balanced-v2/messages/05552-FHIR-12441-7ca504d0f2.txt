FHIR-12441: Audit clinical trial extension removal

Issue request:
FHIR-12441 was a Published Patient Administration change request, resolved Persuasive with Modification, asking that the Patient clinical trial extension not be defined around the US-specific NCT/ClinicalTrials.gov registry identifier. The final resolution was not to remodel the extension with Identifier, but to remove it because ResearchSubject had been approved.

Initial application:
The issue appears to have been applied by git commit 08d6684526b70e7455a1833ca8a98d848339bb74, which removed the clinicalTrial, clinicalTrial.NCT, clinicalTrial.period, and clinicalTrial.reason rows from source/patient/patient-extensions-spreadsheet.xml. Current source no longer contains an official http://hl7.org/fhir/StructureDefinition/patient-clinicalTrial definition in the Patient extension source, and the current Patient/ResearchSubject build configuration keeps ResearchSubject active.

Additional context:
The current source still has an active extensibility tutorial example using http://example.org/fhir/StructureDefinition/patient-clinicalTrial and an NCT slice. That example is not the removed HL7 core extension. Later Published trackers FHIR-18387 and FHIR-18391 intentionally revisited the same tutorial example: FHIR-18387 added a note that the extension is for example purposes only and that most clinical trial participation should use ResearchStudy, possibly via workflow-researchstudy; FHIR-18391 corrected the example's reason value. A later link-fix commit updated the workflow-researchstudy URL to the extension-pack location.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The official Patient clinical trial extension requested by FHIR-12441 has already been removed, ResearchSubject is active, and the remaining tutorial-only example is explicitly scoped as non-normative/example.org guidance with a ResearchStudy pointer. Changing that tutorial under FHIR-12441 would go beyond the issue's applied resolution and could duplicate the later FHIR-18387 decision.

Recommendation:
Keep this audit commit as-is. If the work group wants the extensibility tutorial example itself modernized or replaced, handle that through a separate FHIR-I/extensibility tracker rather than reopening FHIR-12441, because the FHIR-12441 core extension removal is already complete.
