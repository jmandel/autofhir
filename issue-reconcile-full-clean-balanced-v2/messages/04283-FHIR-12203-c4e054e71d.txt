FHIR-12203: Audit medication supportingInformation elements

Issue request:
FHIR-12203 was a Published/Persuasive Pharmacy change request from DSTU2 asking to add supportingInformation references for MedicationOrder, MedicationDispense, and MedicationAdministration so context such as patient height and weight could travel with medication workflow resources. The recorded vote on 2016-10-17 agreed to add supportingInformation to MedicationOrder, while the issue metadata and summary also identify MedicationDispense and MedicationAdministration.

Initial application:
The issue was applied in the 2016 SVN-imported source history. Commit 1d00edee4413c641918bdf96071c2407902bc4c3 explicitly mentions #12203 and added 0..* Reference(Any) supportingInformation to MedicationOrder and MedicationAdministration; the immediately following build-fix commit 86d5096cf0dd17e3c4773f306cbe0e6d2b2c97ec added the parallel MedicationDispense supportingInformation row. Commit 7387b2894c026dce7c36229cd84b90e883d6e5cb then renamed MedicationOrder to MedicationRequest while preserving the resource content.

Additional context:
The current build actively includes MedicationAdministration, MedicationDispense, and MedicationRequest in source/fhir.ini. The authoritative StructureDefinition sources contain MedicationAdministration.supportingInformation, MedicationDispense.supportingInformation, and MedicationRequest.supportingInformation, each as 0..* Reference(Resource), which is the current representation of Reference(Any). The 2021 source rework commit 33b409a4b6 preserved all three elements in the current StructureDefinition XML sources. Jira search found only FHIR-12203 for this exact medication supportingInformation request, and Zulip/Confluence searches found no directly relevant later reversal or conflicting work-group record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active specification already carries the requested supportingInformation capability on the renamed MedicationRequest resource and on MedicationDispense and MedicationAdministration.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-12203 unless the Pharmacy work group later chooses to revise the semantics of these existing supportingInformation elements.
