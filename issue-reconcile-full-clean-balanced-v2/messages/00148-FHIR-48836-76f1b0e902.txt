Issue request:
FHIR-48836 was Applied/Persuasive for R6 by Vocabulary. It asked to update CodeSystem.concept.property.code so a concept property code may either reference CodeSystem.property.code or, when there is no corresponding CodeSystem.property.code, use a well-known code from http://hl7.org/fhir/concept-properties.

Initial application:

The related FHIR-41678 application, efa0467397d742ec92a3479603347989bccd26d6, had already added narrative guidance that absent CodeSystem.property declarations, concept property codes matching the defined concept-properties codes should be assumed to refer to that code system.

Additional context:

The originating Zulip discussion shows the validator error and the requested WG-approved qualification. Vocabulary minutes for 2025-07-28 record FHIR-48836 as resolved change required. AutoFHIR reconciliation:
