FHIR-11182: Audit Medication dose-form carton wording

Issue request:
FHIR-11182 was a Published/Persuasive Pharmacy change request from DSTU2 asking to remove "carton" from the Medication.product.form description/examples because a carton is packaging, not a medicinal product form.

Initial application:
The issue was applied in git commit 6b3299e7a1, which changed the Medication product form short label and definition from "powder | tablets | carton" / "Powder; tablets; carton" to "powder | tablets | capsule" / "Powder; tablets; capsule" in the then-current Medication spreadsheet source.

Additional context:
The current build has Medication as an active resource in source/fhir.ini and now represents the element as Medication.doseForm in source/medication/structuredefinition-Medication.xml. That active source still says "powder | tablets | capsule +" and "Powder; tablets; capsule." Remaining current uses of "carton" in Medication-related files describe package displays or medication definition packaging, which is consistent with the Jira request. FHIR-9142 is a supporting earlier clarification about the Medication form context and does not reintroduce carton as a dose form. Zulip and Confluence searches found no conflicting discussion or minutes.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the active Medication dose-form source already preserves the FHIR-11182 correction, and the remaining carton references are packaging contexts rather than medicinal product form examples.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-11182 unless future Pharmacy review changes the Medication.doseForm examples or packaging model.
