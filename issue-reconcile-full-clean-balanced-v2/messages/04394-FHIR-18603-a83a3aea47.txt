FHIR-18603: Audit CodeSystem identifier business wording

Issue request:
FHIR-18603 was a Published/Persuasive STU3 vocabulary clarification for FHIR-core CodeSystem. It asked to change CodeSystem.identifier short text from "Additional identifier for the code system" to "Additional identifier for the code system (business identifier)" so it aligned with the same element in ValueSet.

Initial application:
The Jira comment points to git 4907f9bcb0b710cb2837a93a20c4b23210a37249. That October 2018 terminology ballot documentation commit touched the then-authoritative CodeSystem spreadsheet source and carried the parenthetical business-identifier wording for CodeSystem.identifier.

Additional context:
CodeSystem and ValueSet are active resources in source/fhir.ini. The current source has been refactored from spreadsheets into StructureDefinition XML, and the 2021 source-conversion commit 33b409a4b6 preserved the CodeSystem.identifier short text as "Additional identifier for the code system (business identifier)" alongside ValueSet.identifier as "Additional identifier for the value set (business identifier)". A related earlier Published issue, FHIR-16464, and its terminology Zulip clarification establish the same correction and confirm that "code system" rather than "value set" was intended for CodeSystem.identifier. No FHIR-18603 Zulip or Confluence evidence was found that changes that conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope CodeSystem StructureDefinition already contains the requested business-identifier wording, and the parallel ValueSet source still contains the corresponding wording that FHIR-18603 wanted to align with.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-18603 unless a future terminology decision changes the canonical-resource identifier wording across CodeSystem and ValueSet together.
