FHIR-33127: Audit RxNorm display guidance ownership

Issue request:
FHIR-33127 was Published/Persuasive for R5 and asked the Vocabulary work group to verify whether the RxNorm "Correct RxNorm Display" guidance needed updating because the example SQL only named SCD and SBD term types while RxNorm also has pack term types such as GPCK and BPCK. The accepted wording changed the lead-in so the SQL is explicitly only an example for two available term types.

Initial application:
The request was applied in core by commit 0bcb947d8488b993d882cc96e556cb3d1e84a94e, which changed source/rxnorm.html to say that the SQL below finds the display for two of the available term types. No current source/rxnorm.html remains in this checkout.

Additional context:
The Jira comments and Vocabulary minutes said the page would move to THO and the fixes would happen there. FHIR-35933 later removed the external terminology "Using X with FHIR" pages from core and changed active core terminology pages to point to HL7 Terminology, including https://terminology.hl7.org/RxNorm.html. The current THO English RxNorm page contains the FHIR-33127 wording, while current core source only retains links to THO from active terminology pages.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no FHIR-core source change. The current build no longer owns the RxNorm guidance page; core points readers to THO, and the external THO page already carries the accepted clarification.

Recommendation:
Keep this audit commit as-is for FHIR core. If the RxNorm guidance needs further content cleanup, including the duplicated introductory sentence inherited by THO, it should be handled in the HL7 Terminology/UTG source of truth rather than in this FHIR-core checkout.
