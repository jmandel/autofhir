FHIR-13393: Audit Condition targetBodySite removal

Issue request:
FHIR-13393 was Published/Persuasive for STU3 by Patient Care. It asked to clarify or remove the Condition targetBodySite extension because it existed without a useful definition and its distinction from the body-site-instance extension was unclear; the approved resolution was to remove extension-condition-targetbodysite.html.

Initial application:
No explicit source commit mentioning FHIR-13393 was found. Historical Condition extension spreadsheet snapshots before the R4B/source rework still contained a !targetBodySite row with mostly blank descriptive fields, matching the Jira concern that the extension lacked definition. The subsequent source rework commits 33b409a4b6 and c69d71aa21 deleted source/condition/condition-extensions-spreadsheet.xml and replaced it with explicit Condition extension StructureDefinitions, but no condition-targetBodySite StructureDefinition or Condition IG reference was carried forward.

Additional context:
Current source/fhir.ini keeps Condition in the active [resources] list, so source/condition is in build scope. The current source/condition directory has no Condition extension files beyond an empty Condition-core IG shell, and a focused search of the core checkout and the FHIR Extension Pack found no condition-targetBodySite canonical. The only current targetBodySite text in active Condition source is a RIM mapping value on Condition.bodySite, not an extension definition. build.fhir.org currently returns 404 for extension-condition-targetbodysite.html. A contemporaneous Zulip thread shows the same rationale as Jira: participants noted overlap with body-site-instance, and Lloyd McKenzie filed GF#13393 because targetBodySite was not defined and had no clear distinct use case.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The requested extension is already absent from the current build source and from the Extension Pack, and adding replacement wording would not remove anything or clarify a current active artifact.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core follow-up is needed for FHIR-13393 unless a future work group decision intentionally reintroduces a Condition-specific target body structure extension.
