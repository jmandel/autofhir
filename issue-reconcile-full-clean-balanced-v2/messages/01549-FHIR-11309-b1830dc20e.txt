FHIR-11309: Audit retired Sequence type clarification

Issue request:
FHIR-11309 was a Published/Persuasive DSTU2 Clinical Genomics change request for the old FHIR-core Sequence resource. It asked to correct Sequence.type so the AA, DNA, and RNA choices were described as amino acid sequence, DNA sequence, and messenger/RNA sequence instead of the ambiguous "Amino acid / cDNA transcript / RNA variant" wording.

Initial application:
The historical source shows the issue was applied in commit 5ab7990995a9c5fbfdd33e99aa5e7b2aa72a7816, whose subject explicitly mentions #11309 and #11310. That commit changed source/sequence/sequence-spreadsheet.xml so Sequence.type moved from "Amino acid / cDNA transcript / RNA variant." to "Amino Acid Sequence/ DNA Sequence / RNA Sequence".

Additional context:
The current core build no longer has an active Sequence resource: source/fhir.ini lists Sequence under [removed-resources], MolecularSequence is commented in the current classification sections, and the Diagnostics module says MolecularSequence has been replaced by MolecularDefinition linked to the Clinical Genomics incubator content. The successor MolecularDefinition material in this checkout separates broad moleculeType examples (DNA, RNA, amino acid) from more specific classifications such as mRNA or siRNA, so there is no current contradictory core wording to repair. Community searches found later MolecularSequence/MolecularDefinition discussion but no FHIR-11309-specific reversal or active-core requirement to preserve the retired DSTU2 Sequence.type prose.

Recommendation:
