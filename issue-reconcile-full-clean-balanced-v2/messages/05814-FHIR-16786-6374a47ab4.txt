FHIR-16786: Audit ValueSet resource instance wording

Issue request:
FHIR-16786 was a Published/Persuasive, non-substantive Vocab change request from the STU3 cycle asking the ValueSet definition to say "A ValueSet resource instance specifies a set of codes" rather than "A ValueSet resource specifies a set of codes", and more generally to keep the resource definition/resource instance distinction clear.

Initial application:
The issue was applied in git commit 25cd575210810aef4e6fd1939a51821113bc035e, matching the Jira comment for svn revision 14727. That commit changed the ValueSet spreadsheet definition from "A ValueSet resource specifies" to "A ValueSet resource instances specifies"; the grammar was corrected shortly afterward in commit 3711daf34c0bfd80da9afe8a6c468dcb2cc37d6e to "A ValueSet resource instance specifies".

Additional context:
ValueSet remains an active current-build resource in source/fhir.ini and is owned by the vocab work group. The current generated/source StructureDefinition carries the corrected wording in both the resource description and the ValueSet root element definition. A source search of the current ValueSet material found no remaining active occurrence of the exact stale phrase "A ValueSet resource specifies a set of codes" that would change implementer understanding.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative ValueSet source already contains the requested "resource instance" wording, and nearby narrative uses the value set definition/resource instance distinction without reintroducing the original ambiguity.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source work is recommended for FHIR-16786 unless a future terminology work group review identifies a separate, more specific ValueSet definition/instance ambiguity.
