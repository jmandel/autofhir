FHIR-19848: Audit Device maintenance responsibility location

Issue request:
FHIR-19848 was an Applied OO change request for STU3 asking to support CDA maintaining.Person in FHIR by adding a Device HL7 extension for a maintenance person. The final Persuasive with Modification resolution explicitly said there would be no core Device resource change and instead approved extensions for `maintenanceResponsibility` with person and organization subparts plus `lastMaintenanceTime`.

Initial application:
No Jira-tagged FHIR core commit for FHIR-19848 was found, which is consistent with the issue comments saying not to change the core resource. The applied source change appears in the FHIR Extension Pack: commit 0737edd33c8c1665e7cb5e2eae08e54896850e24 added `device-maintenanceresponsibility` and `device-lastmaintenancetime` for FHIR-19846, FHIR-19847, and FHIR-19848. Current core retains only OID registry entries for those extension URLs.

Additional context:
Global extensions moved out of the core specification after R5 and are maintained in the FHIR Extension Pack. Later Extension Pack issue FHIR-44336 changed the maintenance-responsibility individual slice from `person`/Reference(Person) to `participant`/Reference(Patient | RelatedPerson | Practitioner | PractitionerRole). OO minutes from 2025-07-07 record that FHIR-19848 should now be obsolete because of DeviceAssociation, and later core issue FHIR-51494 added the `maintainer` relationship code to build-scoped DeviceAssociation terminology. FHIR-51495 then updated the Extension Pack extension to say to use DeviceAssociation.relationship=`maintainer` after R5.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. The requested extension source belongs to `/home/jmandel/work/fhir-extensions`, where it already exists and has been updated by later Extension Pack decisions; the current core build-scoped replacement path is DeviceAssociation.relationship with the `maintainer` code, which is already present and separately audited on the combined branch for FHIR-51494.

Recommendation:
Keep this external-repo audit commit. Do not add a Device maintenance person extension back into core. Any future edits to `device-maintenanceresponsibility` or `device-lastmaintenancetime` should be handled in the FHIR Extension Pack, while R6+ core usage should continue to use DeviceAssociation.relationship=`maintainer`.
