FHIR-6103: Confirm enteral feeding notes guidance

Issue request:
FHIR-6103 was Published with resolution Persuasive. It asked for NutritionRequest/NutritionOrder notes guidance explaining how to use the resource for continuous versus bolus enteral feeding because the distinction was not obvious from the examples alone.

Initial application:
The issue appears to have been applied in git commit 5609ec13c8, "#6103, #7178 add notes to NO," which replaced placeholder NutritionOrder notes with an "Enteral continuous vs intermittent tube feedings" section. That source note linked enteral bolus and continuous/cycled examples and explained that continuous feeding uses rate and maximum volume elements while intermittent/bolus feeding uses quantity and schedule elements.

Additional context:
NutritionOrder is active in the current build through source/fhir.ini. The current source/nutritionorder/nutritionorder-notes.xml still contains the requested guidance, now linking the bolus and cycled enteral feeding examples and using current element paths after the already-published FHIR-36665 reconciliation commit 2a280d7674. The StructureDefinition contains the referenced enteralFormula.administration.rate[x], enteralFormula.maxVolumeToAdminister, enteralFormula.administration.quantity, and enteralFormula.administration.schedule elements. FHIR-7178 was applied by the same 2015 note commit but concerns broader provider-order versus dietary-system guidance, so it was treated only as context.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current NutritionOrder notes section already gives implementers the continuous-versus-intermittent/bolus enteral feeding guidance requested by FHIR-6103, and adding more prose would be redundant.

Recommendation:
Keep this no-change audit commit. No follow-up source work is needed for FHIR-6103 unless the work group later wants to revise the clinical wording of the existing NutritionOrder note.
