FHIR-11311: Audit retired Sequence referenceSeq definition

Issue request:
FHIR-11311 was a Published Clinical Genomics change request for the DSTU2 Sequence resource, resolved Persuasive. It asked to change the Sequence.referenceSeq definition from "A reference sequence is a sequence that is used to represent an allele or variant" to the HGVS-style wording "a sequence file that is used as a reference to describe variants that are present in a sequence analyzed."

Initial application:
The issue was explicitly applied in historical commit e6265cbcc05d58d02553c387ca007c9011b779d0, "#11311 modify definition of Sequence.referenceSeq", which changed source/sequence/sequence-spreadsheet.xml to "A sequence that is used as a reference to describe variants that are present in a sequence analyzed." I found no current active source containing the old definition.

Additional context:
The original Sequence resource no longer exists in the current build. FHIR-19453 renamed Sequence to MolecularSequence in commit 78abae0217bc20d5f1be80d0d32224d679432862 and added Sequence to the removed-resources list. Later, FHIR-51227 replaced legacy MolecularSequence with MolecularDefinition; commit 29050fea9fdbbb36b71a97a37d52229e5368d4ee removed MolecularSequence from active fhir.ini resource metadata and commented out remaining MolecularSequence entries. Current source/fhir.ini does not list Sequence or MolecularSequence in [resources], lists Sequence under [removed-resources], and source/diagnostics-module.html says MolecularSequence has been replaced by MolecularDefinition. Current MolecularDefinition uses a different representation model and has no referenceSeq element to receive the old DSTU2 definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested definition was applied to the legacy Sequence source, and the affected Sequence.referenceSeq element is outside the current build. Translating the historical HGVS wording into MolecularDefinition would be a new model decision rather than completing FHIR-11311.

Recommendation:
Keep this audit commit as-is. Do not resurrect inactive Sequence source or back-port the old referenceSeq wording into MolecularDefinition without a new Clinical Genomics decision that targets the current MolecularDefinition model.
