FHIR-6238: Audit ImagingStudy DICOM scope clarification

Issue request:
FHIR-6238 was a Published/Persuasive DSTU1 ImagingStudy clarification asking whether WADO-RS was equivalent to the then-current phrases "DICOM contexts" and "DICOM constructs", or whether the specification should link to the relevant DICOM material. The resolution was to update the Scope definition to clarify the relationship.

Initial application:
The issue was applied by svn/git-svn revision 5644, now git commit 6823a9388a1370a5f0e577294b1fc708b78f0164, which replaced the ambiguous ImagingStudy scope paragraph about "DICOM contexts" and "equivalent DICOM constructs" with text saying ImagingStudy elements mirror DICOM attributes and linking to DICOM PS3.3.

Additional context:
ImagingStudy is active in the current build through source/fhir.ini. The current ImagingStudy scope no longer contains the ambiguous phrases and now explains that ImagingStudy describes a single DICOM imaging study, maps elements to DICOM attributes, links DICOM Parts 3, 4, and 6, and distinguishes DICOMweb search/retrieve services from the FHIR resource. A remaining "DICOM constructs" phrase is only in imagingmanifest, which source/fhir.ini lists under removed-resources rather than as the active ImagingStudy artifact. Later ImagingStudy work such as FHIR-47626 and FHIR-47660 refined the same area without reintroducing the ambiguity.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active ImagingStudy source already satisfies the requested clarification, and editing removed ImagingManifest text or adding redundant ImagingStudy prose would not improve the current built specification.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-6238 unless the work group separately wants to clean up removed-resource source files outside the current build.
