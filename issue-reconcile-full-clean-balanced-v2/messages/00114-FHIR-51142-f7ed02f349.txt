FHIR-51142: Audit Observation molecular reference

Issue request:
FHIR-51142 was Applied as Persuasive for R6. It asked O&O to update Observation references that pointed to MolecularSequence so they would also point to MolecularDefinition, reflecting the Clinical Genomics replacement plan.

Initial application:
FHIR-51142 was initially applied by 47d444fea4 and merged in PR #3525 as 8250b2c8a3. That commit added MolecularDefinition beside MolecularSequence in Observation.value[x], Observation.component.value[x], hasMember/derivedFrom target profiles, and the related comments.

Additional context:
FHIR-51227 then broadened the replacement from an Observation-only update to retirement of MolecularSequence and replacement by MolecularDefinition. Subsequent additional-resource work moved MolecularDefinition out of the active core resource set, and FHIR-53610 removed the orphaned Observation.valueReference, Observation.component.valueReference, and reference search-parameter remnants after MolecularSequence was removed. The current combined branch still has a stale generated-looking Observation SVG mentioning MolecularSequence, but the authoritative Observation StructureDefinition and search-parameter bundle no longer do.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Re-adding a direct Observation reference to MolecularDefinition would contradict the later additional-resource/FHIR-53610 cleanup, and there is no remaining authoritative MolecularSequence target in Observation to replace.

Recommendation:
Keep this audit as-is. If Clinical Genomics and O&O later decide on a profile, extension, or additional-resource mechanism for referencing MolecularDefinition from Observation, handle that as new work; do not reapply the old core valueReference target from FHIR-51142 in the current core source.
