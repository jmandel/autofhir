FHIR-41380: Correct remaining MedicationAdministration occurrence typo

Issue request:
FHIR-41380 was an Applied/Persuasive Pharmacy technical correction asking that the misspelled MedicationAdministration.occurence[x] name and related documentation/schema text be corrected to occurrence.

Initial application:
The issue was mostly applied by prior FHIR-41380 commits: c69c422d0f corrected the StructureDefinition element/path, search parameter path/expression, examples, and invariant test XML from occurence to occurrence; 06be37444a corrected the MedicationAdministration event mapping resourcePath; and 0a2bd71a29 corrected the MedicationAdministration notes table wording.

Additional context:
MedicationAdministration is active in the current build via source/fhir.ini. Current source already uses MedicationAdministration.occurrence[x] in the StructureDefinition, search parameter bundle, examples, notes, and event mapping resourcePath. The remaining MedicationAdministration.occurence[x] text in source/fhir.ini is in the [r5-r6-changes] compatibility mapping and intentionally records the old misspelled R5 path as a redirect/rename alias to the corrected R6 path. Pharmacy minutes recorded FHIR-41380 as a 7-0-0 carried technical correction, and a later Zulip thread says the typo had already been corrected for the next release. One active MedicationAdministration event-mapping exception prose string still misspelled "occurrence" as "occurence".

AutoFHIR reconciliation:
This commit corrects the remaining active MedicationAdministration mapping-exception prose typo from "occurence" to "occurrence". It intentionally leaves the fhir.ini R5-to-R6 alias unchanged because that entry preserves cross-version mapping from the historical misspelled path to the corrected current path.

Recommendation:
Keep this commit as-is. The current core MedicationAdministration source now uses the corrected occurrence spelling in active resource content, while retaining the intentional backward-compatibility alias for the old R5 spelling.
