FHIR-24085: Audit ValueSet.description aliases

Issue request:
FHIR-24085 was Published/Persuasive for R5 by Vocab. It asked to remove "scope" and "purpose" as alternate names for ValueSet.description because ValueSet.purpose already exists and ValueSet.scope had been separately proposed/approved.

Initial application:
The requested alias removal appears in the R5 VSD Profile application history. Commit 9fca6ca36f explicitly listed FHIR-24085 and removed <alias value="Scope"/> and <alias value="Purpose"/> from ValueSet.description; that commit was reverted by 5161923416, and commit 054eabf311 reapplied the same ValueSet change shortly afterward.

Additional context:
ValueSet is an active resource in source/fhir.ini, so source/valueset/structuredefinition-ValueSet.xml is build-scope source for the current specification. Confluence VSDP minutes on 2020-09-08 record the disposition to remove both alternate names, and Vocab WG minutes on 2020-09-17 record the vote approving the documented resolution. FHIR-25272 and FHIR-25273 are related VSD scope/description/purpose work, but this audit only decides the already-applied alias-removal request in FHIR-24085.

AutoFHIR reconciliation:
No source change was needed. Current ValueSet.description has no alias entries, while the remaining ValueSet aliases are for other elements and do not reintroduce Scope or Purpose as alternate names for description.

Recommendation:
Keep this no-change audit commit as-is. Revisit only if a future Vocab decision asks for different ValueSet.description naming guidance or a broader review of the VSD scope/description/purpose family.
