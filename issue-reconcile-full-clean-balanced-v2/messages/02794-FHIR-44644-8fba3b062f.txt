FHIR-44644: Audit Identifier.system registry note

Issue request:
FHIR-44644 was an Applied FHIR-core datatypes clarification, resolved Persuasive with Modification for R6, asking that Identifier.system call out that standard identifier-system URIs must be used when defined. The accepted wording names the FHIR specification, Terminology.hl7.org, and HL7 affiliates as sources of identifier systems and points to identifier-registry.html for specific rules.

Initial application:
The requested wording appears to have been applied by Jira-tagged commits 1750c4b0015c3def5b500a3e91c9280c9d2a42f3 and 4aa564f12654dc883112ff56c3b9ca271dea615e, both titled "FHIR-44644 Identifier.system notes". The first added the new Identifier.system comment text, and the second preserved that text while normalizing the spreadsheet XML.

Additional context:
source/fhir.ini lists Identifier as an active datatype, and the default datatype page mapping sends datatypes not otherwise overridden to datatypes.html, so source/datatypes/identifier.xml is build-scoped authoritative source for this comment. PA and FHIR-I Confluence records show the concern that identifier-registry.html was too hidden and the FHIR-I 2024-05-13 vote accepting FHIR-44644. Related FHIR-48692 is a later, broader Resolved - change required identifier-guidance issue; it adds request/event pattern notes and still asks separately to link identifier elements, but it is not Applied/Published in this run scope and does not supersede the FHIR-44644 Identifier.system wording.

AutoFHIR reconciliation:
No source change was made. The current Identifier.system comment already contains the accepted normative reminder and registry link: "Identifier.system is always case sensitive. The FHIR specification, terminology.hl7.org and HL7 affiliates (for identifiers specific to their jurisdiction) define identifier systems that SHALL be used for certain types of identifiers. Specific rules can be found [here](identifier-registry.html)". The lowercase terminology.hl7.org differs only as a URL-style rendering and does not change the approved meaning.

Recommendation:
Keep this no-change audit commit. Future work on the broader identifier usage notes should proceed under FHIR-48692 or a successor once that work is Applied/Published; it should not reopen FHIR-44644 unless the active Identifier.system comment loses the registry requirement or link.
