FHIR-8904: Audit ICD-9 diagnosis URI typo

Issue request:
FHIR-8904 is a Published/Persuasive vocab technical correction for DSTU1/DSTU2 asking to correct the ICD-9-CM diagnosis system URI from http://hl7.org/fhir/sid/icd-9-cm/diagosis to http://hl7.org/fhir/sid/icd-9-cm/diagnosis. The issue also suggested OID 2.16.840.1.113883.11.15931, but the Jira comment records that this is the value set OID, not the code system OID.

Initial application:
The typo appears to have been applied by the immediately related historical commit 9eff2268e4 (#8903 - correct icd9 url), which replaced diagosis with diagnosis in source/terminologies-systems.html and source/namingsystem/namingsystem-terminologies.xml and populated the ICD-9-CM diagnosis/procedure code system OIDs. FHIR-8904's own comment says the typo was already fixed and rejects the submitted OID as the wrong identifier type.

Additional context:
Later terminology maintenance changed the surrounding source. Commit 3e1ab0a91d introduced an ICD page and removed the old diagnosis/procedure-specific ICD-9-CM row from source/terminologies-systems.html, and FHIR-41305/commit 11181dd489 later corrected the current ICD URI column to show the ICD-9-CM and ICD-10 root URIs. The active current source page is linked from the terminology module and hierarchy, points implementers to THO for authoritative external terminology details, and no longer contains either the misspelled URI or the diagnosis-specific URI.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build source has no occurrence of the misspelling, the old diagnosis-specific row is no longer part of the core terminology table, and applying the value set OID from the issue would be incorrect for a code system URI/OID table.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-8904 unless the terminology work group separately decides to reintroduce diagnosis/procedure-specific ICD-9-CM rows or migrate additional ICD identifier detail from THO back into core.
