FHIR-5892: Audit medication package form codes

Issue request:
FHIR-5892 was a Published/Persuasive Pharmacy DSTU1 correction. It reported that medication-package-form-codes did not differ from medication-form-codes, even though the package code set should contain packaging/container concepts such as bottle, vial, and carton. The accepted resolution was to fix the Medication.package.container binding/value set so it included SNOMED CT codes where concept is-a 408102007.

Initial application:
The issue appears to have been applied in historical commit 534313123abc479f1c95a22956d9992582f9743c, whose subject explicitly includes 5892 and whose patch changed source/medication/valueset-medication-package-form-codes.xml from the copied route/form ancestor 284009009 to the package-form ancestor 408102007. The same commit batch also covered closely related DSTU1 Medication package-form tracker items.

Additional context:
Medication remains an active current resource in source/fhir.ini, but the current Medication StructureDefinition no longer contains Medication.package.container. Current package information is represented by Medication.packageSize, and the old package-container terminology path was later reassessed by FHIR-12347 before GF #13879 removed the package.container element from Medication. The remaining package-form value-set source already composes SNOMED CT descendants of 408102007, and neighboring same-family audit commits are already present on the combined branch for FHIR-5993, FHIR-7266, FHIR-7746, FHIR-8063, and FHIR-8066.
