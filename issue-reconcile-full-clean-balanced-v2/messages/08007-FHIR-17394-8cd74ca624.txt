FHIR-17394: Audit methodless vital signs codes

Issue request:
FHIR-17394 was Published/Persuasive for STU3 and asked the Observation Vital Signs profile to stop using method-specific LOINC codes as the required vital-signs "magic value" codes: replace 8287-5 Head Occipital-frontal circumference by Tape measure with 9843-4 Head Occipital-frontal circumference, and replace 59408-5 Oxygen saturation in Arterial blood by Pulse oximetry with 2708-6 Oxygen saturation in Arterial blood.

Initial application:
The issue was explicitly applied by git commit ef9a121f91 ("GF#17394") on 2018-07-27. That commit changed the vital-signs table, the head-circumference example, the oxygen-saturation example, the then-current vital-signs spreadsheet source, and the then-current vital-signs result value set from the method-specific codes to the requested methodless codes.

Additional context:
Observation is an active resource in source/fhir.ini, and source/observation/implementationguide-Observation-vitalsigns.xml references the vital-signs introduction page plus the headcircum and oxygensat StructureDefinitions, so those files are current build-scope inputs. Later profile refactors, including FHIR-46418 and FHIR-32787 work, changed how the vital-signs profiles present category/code guidance and supplemental measurement codes, but they preserved the formal methodless codes for the head-circumference and oxygen-saturation profiles. The current source still mentions 59408-5 only as an optional more-specific oxygen-saturation measurement code, not as the required profile code, which matches the original Zulip rationale that methodless codes should identify the vital-signs concept while more-specific codes may also be carried.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current source already satisfies FHIR-17394: the vital-signs table lists 2708-6 and 9843-4, the formal oxygensat and headcircum profiles require/pattern those same methodless LOINC codes in Observation.code, the head-circumference example uses 9843-4, and no active source occurrence of 8287-5 remains.

Recommendation:
Keep this no-change audit commit as-is. No current FHIR-core source correction is needed for FHIR-17394; future changes to optional more-specific oxygen-saturation guidance should be handled under a separate issue if the work group wants to clarify the supplemental-code wording.
