FHIR-7152: Audit Observation issued provider availability

Issue request:
FHIR-7152 is a Published FHIR-core Observation clarification with a Persuasive with Modification resolution. It asked for Observation.issued to say that the date/time is when the observation was made available to providers, typically after review and verification, while other pre-verification timing use cases can be represented by extensions.

Initial application:
The requested wording was applied before this reconciliation. The clearest implementation event is git commit de360c9b20571d20454f1f559e459e873655bbb8, which is labeled #7149 but changed the Observation.issued spreadsheet definition from "The date and time this observation was made available" to "The date and time this observation was made available to providers, typically after the results have been reviewed and verified." Later source-format migration preserved the language in the current StructureDefinition XML.

Additional context:
Observation is active in source/fhir.ini, so source/observation/structuredefinition-Observation.xml is in the current build scope. A later Published issue, FHIR-9433, clarified Observation.issued and DiagnosticReport.issued; git commit 2bc0950a1e354c2a99db1fca80954166c25bc241 changed Observation.issued to "this version of the observation" and added the Meta.lastUpdated comment. That later decision explains why the current source is not an exact copy of FHIR-7152's older resolution text while still preserving its provider/review/verification rule.

AutoFHIR reconciliation:
No source files were changed. The current active Observation.issued definition already states that this version of the observation was made available to providers, typically after the results have been reviewed and verified, and its comment covers the distinction from resource metadata updates.

Recommendation:
Keep this no-change audit commit. Replacing the current wording with the older exact FHIR-7152 sentence would undo the later FHIR-9433 clarification, and no current core source fix is needed for FHIR-7152.
