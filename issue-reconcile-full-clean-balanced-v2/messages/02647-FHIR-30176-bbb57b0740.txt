FHIR-30176: Audit ClinicalUseDefinition ObservationDefinition references

Issue request:
FHIR-30176 was a Published/Persuasive BRR change request for R5 ClinicalUseIssue asking that indication, contraindication, undesirable effect, and interaction condition/effect elements be upgraded from CodeableConcept to CodeableReference(ObservationDefinition), so physiological characteristics such as creatinine clearance thresholds can be represented by ObservationDefinition.

Initial application:
The change was applied in git commit 447e322ee6dae0af815d4430df0bfbae89dc9209, whose message explicitly cites FHIR#30176 and says ObservationDefinitions were added as choices on affected attributes and search parameters. That commit changed the then-current ClinicalUseIssue StructureDefinition and search parameter bundle. Later FHIR#31847 history renamed ClinicalUseIssue to ClinicalUseDefinition; the ObservationDefinition target profiles moved with the resource.

Additional context:
The current build scope actively includes ClinicalUseDefinition in source/fhir.ini as a resource, work-group-owned resource, normative artifact, page code, and approved resource. BRR minutes on 2021-02-16 record the FHIR-30176 motion passing 16-0-1, and OO catalog minutes on 2021-02-26 and 2021-03-05 record FHIR-30176 as applied in the ClinicalUseIssue change set. Zulip searches found no directly relevant discussion that conflicts with the Jira and Confluence record.

AutoFHIR reconciliation:
No source change was made. The current ClinicalUseDefinition StructureDefinition already gives each requested element the single type CodeableReference with targetProfile http://hl7.org/fhir/StructureDefinition/ObservationDefinition: contraindication.diseaseSymptomProcedure, contraindication.diseaseStatus, contraindication.comorbidity, indication.diseaseSymptomProcedure, indication.diseaseStatus, indication.comorbidity, indication.intendedEffect, undesirableEffect.symptomConditionEffect, and interaction.effect. Current search parameters also retain the corresponding concept/reference split for the exposed condition/effect searches.

Recommendation:
Keep this empty audit commit as-is. The current specification already reflects the final FHIR-30176 decision, and changing the source would only duplicate the existing application. Future work should treat the ClinicalUseIssue name in this Jira as historical and inspect ClinicalUseDefinition for the current R6 build.
