FHIR-19733 was a Published/Persuasive FHIR-core terminology issue raised against STU3 and applied for R5. It reported that v2 table 0550 had an invalid whitespace code with display "External Jugular" and another garbled Unicode-looking code, apparently from an import problem.

Initial application:
No explicit FHIR-19733-tagged source commit was found. The old core v2 table source already had code JUGE for "Jugular, External" before commit 5c0494a removed source/v2 and the v2/v3 importers from the core build as part of moving UTG content out of core. Commit 02557a9 later reintroduced a tooling copy under tools/tx/v2/source.xml, also with JUGE, but that copy is not an active current core build input.

Additional context:
The current core terminology systems page directs code-system authority not listed in core to HL7 Terminology (THO), the UTG CI build, and TSMG. Zulip discussion confirms the 2018 report was treated as an import/source problem and that the 2025 remaining THO errors were handled through UTG. UP-681 is the implemented UTG proposal that removed the bad table 0550 whitespace and garbled codes from the external source of truth. FHIR-20386 is the broader same-family v2 code-system encoding issue already audited on the combined branch as external-repo.
