FHIR-15694: Audit Immunization primarySource optionality

Issue request:
FHIR-15694 was Published/Persuasive for the PHER-owned Immunization resource. It asked that Immunization.primarySource not be required, or otherwise allow unknown source information, because C-CDA Immunization Activity data often cannot populate the flag.

Initial application:
The same 2018-06-14 PH WG decision trail as FHIR-15643 resolved this issue by changing Immunization.primarySource cardinality to 0..1. Git commit 3161b27852 applied that by changing the old Immunization spreadsheet cardinality from 1..1 to 0..1.

Immunization is active in the current build through source/fhir.ini. The current StructureDefinition source has Immunization.primarySource min 0 and max 1. Later wording edits changed the description but did not reverse the optionality decision. The PH WG minutes confirm that future profiles can make the element required when appropriate.
