FHIR-7459: Audit common search parameter listing

Issue request:
FHIR-7459 was a Published/Persuasive DSTU1 clarification asking why `_text` and `_filter` were missing from the table of search parameters even though the all-resources search text said they applied broadly. The accepted resolution was to list them there; the Jira application comment records that `_text` was added and that `_filter` was not then treated as a search parameter in the same sense.

Initial application:
No local git commit explicitly references FHIR-7459. The Jira application comments are the best direct application record: `_text` had already been added by August 2015, while `_filter` was intentionally not listed at that time because its status differed from ordinary search parameters.

Additional context:
The current search source has since evolved. `source/search.html` lists all common parameters through the all-resources section and explicitly includes both `_filter` and `_text` in the summary table. `source/resource/bundle-Resource-search-params.xml` now defines `Resource-_filter`, and `source/domainresource/bundle-DomainResource-search-params.xml` defines `DomainResource-_text`. Later related decisions, including FHIR-26430, FHIR-39335, FHIR-42911, and FHIR-46404, formalized or corrected the same search-parameter family without reversing the current listing.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already satisfies the seed issue's durable intent, and adding new prose or removing `_filter` would conflict with later decisions that now treat `_filter` as a formal all-resource special SearchParameter.

Recommendation:
Keep this audit commit as-is. Future edits to `_text` or `_filter` should be handled under the later search-parameter trackers rather than reopening this historical DSTU1 clarification.
