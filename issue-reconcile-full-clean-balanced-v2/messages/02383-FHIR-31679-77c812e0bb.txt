FHIR-31679: Audit LOINC scale type wording

Issue request:
FHIR-31679 was a Published FHIR-core vocab change request about the LOINC scale type mapping table on the old Using LOINC with FHIR page. The reporter asked to allow FHIR string for the Nar scale type; the final Not Persuasive with Modification decision said markdown is a superset of string, so the applied clarification was to remove the question mark/parentheses from the Nar row and remove the parenthetical string question from the Nom row.

Initial application:
The R5 source application appears in git commit ade907ca5b1bc08efb093bc524c5b00bdc7fa5ac, "2nd batch of vocab R5 tickets," which explicitly listed FHIR-31679 and changed source/loinc.html so Nom mapped to CodeableConcept and Nar mapped to markdown without question marks.

Additional context:
Later Published issue FHIR-35933 moved the "Using external code system with FHIR" pages, including Using LOINC with FHIR, out of the FHIR core build and into HL7 Terminology. Its implementation commit 81e5862f203fdb8a03e9c943a7cf455aba8973f4 deleted source/loinc.html and changed source/terminologies-systems.html to link to https://terminology.hl7.org/LOINC.html. The current core checkout no longer contains the old data-elements table, and the active core source only delegates LOINC usage guidance to THO.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No core source edit is needed because the requested table wording was already corrected before R5 publication and the affected page is no longer part of the current FHIR core build.

Recommendation:
Keep this audit commit as-is. Future changes to detailed LOINC usage guidance should be handled in the terminology/THO source of truth, not by recreating or editing the retired FHIR-core loinc.html page.
