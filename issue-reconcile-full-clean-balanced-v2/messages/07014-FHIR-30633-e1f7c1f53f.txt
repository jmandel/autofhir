FHIR-30633: Audit retired Media device reference duplication

Issue request:
FHIR-30633 was a Published/Persuasive FHIR-core technical correction raised for R4 and applied for R5. It reported that the R4 Media.device eligible reference types listed Device twice.

Initial application:
No git commit explicitly mentions FHIR-30633. The duplicate appears to have come from the earlier DeviceComponent removal: commit 7fbb1fff1d9f70f28eb68f4d1251aa670bc889bc changed Media.device from Reference(Device|DeviceMetric|DeviceComponent) to Reference(Device|DeviceMetric|Device), leaving Device duplicated in the retained Media spreadsheet. By the time FHIR-30633 was filed, Media had already been removed from the active build by the Media-to-DocumentReference merge history.

Additional context:
FHIR-23567 merged Media into DocumentReference for R5, and commit 5c62f91cd81f150be72ad506c876e3cc20bd631d removed media=Media from source/fhir.ini's active [resources] list. Current source/history.html records Media as a removed R4B resource with DocumentReference or Observation as replacements. The retained source/media/media-spreadsheet.xml still has the duplicate, but source/media is no longer a current-build source target. The current successor DocumentReference.author targetProfile list contains Device only once. The related FHIR-26454 tooling request and its 2025 OO minutes say the same Media.device duplicate was overcome by events because DocumentReference.author only has one Device reference.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Editing source/media would modify an inactive, removed resource, while the current build no longer publishes Media and the active successor source does not carry the duplicate Device target.

Recommendation:
Keep this no-change audit as-is for core. Do not patch the retained Media spreadsheet or historical generated release metadata for the current build; if HL7 ever republishes or maintains an R4/R4B errata artifact for Media, remove the duplicate there as Reference(Device|DeviceMetric).
