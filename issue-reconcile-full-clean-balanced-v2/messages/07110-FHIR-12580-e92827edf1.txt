FHIR-12580: Audit Observation medication links

Issue request:
FHIR-12580 was a Published, Persuasive with Modification DSTU2 O&O request asking how to record post-administration medication effectiveness observations, initially suggesting an observations list on MedicationAdministration or MedicationRequest. The final disposition was not to add such a list; it directed implementers to create an Observation and link it to the MedicationAdministration or MedicationRequest, then noted the event partOf extension as the mechanism available at the time.

Initial application:
No source commit explicitly tagged FHIR-12580 was found; a search for the key only matched an unrelated historical SVN revision number. The relevant source history shows FHIR-9664 adding Observation.basedOn for links from an Observation to the plan, proposal, or order it fulfills, including MedicationRequest, and FHIR-14095 later moving Observation partOf from the event-partOf extension into the core Observation.partOf element with MedicationAdministration as an allowed target.

Additional context:
The current build has active Observation, MedicationAdministration, and MedicationRequest resources in source/fhir.ini. Observation.partOf is a core event relationship that can reference MedicationAdministration, while Observation.basedOn can reference MedicationRequest; the later Observation.focus element can also reference any Resource when the Observation is about another resource rather than simply fulfilling or being part of it. The old event-partOf extension now lives in the FHIR Extension Pack and is not the current core Observation mechanism.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already supports the approved Observation-side representation and avoids adding redundant reverse observation lists to MedicationAdministration or MedicationRequest.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-12580 unless O&O wants new, explicit narrative guidance about medication effectiveness observations; the conformance model already provides the necessary links.
