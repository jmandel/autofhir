FHIR-11242: Audit retired HLA example

Issue request:
FHIR-11242 was a Published/Persuasive Clinical Genomics change request from the DSTU2 cycle asking for a better HLA example, with resolution text saying to put the HLA usage example back in XML, replace the old example with new bundles, and modify the genomics implementation guide.

Initial application:
The request was applied in core by commits 134dcc3487 and d0a04fd9cb, which updated source/diagnosticreport/diagnosticreport-hla-genetics-results-example.xml and related DiagnosticReport spreadsheet/profile material for the HLA genotyping report example.

Additional context:
The affected DiagnosticReport HLA profile, extensions, and example were later deliberately removed from current core source by commit 3cfe12f1b4 as outdated clinical genomics artifacts. The current build still has DiagnosticReport as an active resource, but it no longer contains the old HLA DiagnosticReport example or HLAResult profile; the active genomics page now points implementers to the Genomics Reporting IG and current molecular-definition work, and HLA extension definitions appear in the FHIR Extension Pack rather than core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding or editing the retired DSTU2-era DiagnosticReport HLA bundle in core would reverse the later cleanup and would not fix a current build artifact. Current core already avoids the obsolete example while still providing active genomics guidance and current HLA-oriented MolecularDefinition/DocumentReference examples.

Recommendation:
Keep this audit commit as-is for the core reconciliation. Any future desire for a richer HLA reporting example should be handled in the Clinical Genomics IG or another current genomics artifact, not by restoring the removed core DiagnosticReport profile/example.
