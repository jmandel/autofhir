FHIR-17756: Audit Goal status split

Issue request:
FHIR-17756 was a Published Patient Care change request with a Persuasive with Modification disposition asking to replace the former combined Goal.status with Goal.lifecycleStatus, a 1..1 code with required binding to Goal Lifecycle Status, and Goal.achievementStatus, a 0..1 CodeableConcept with preferred binding to Goal Achievement Status.

Initial application:
The issue was applied by bb582cddb3fe ("GF#17756 Goal status replaced with lifecycleStatus and achievementStatus"), which changed the Goal spreadsheet, examples, achievement terminology, and status-code registry. Later source refactoring moved Goal to structuredefinition-Goal.xml and bundle-Goal-search-params.xml, but preserved the split elements and search parameters.

Additional context:
Goal is active in source/fhir.ini. Current source has Goal.lifecycleStatus with min 1, max 1, code type, required binding to ValueSet/goal-status, and Goal.achievementStatus with min 0, max 1, CodeableConcept type, preferred binding to ValueSet/goal-achievement. The old Goal.status element is absent from the current Goal source; the only Goal.status text hits are the distinct statusDate/statusReason names that later FHIR-53981 renamed. Later FHIR-55326 deliberately added the unknown lifecycle code, so the current lifecycle value set differs from the 2018 resolution for a known subsequent reason. Community searches found no Patient Care/Zulip/Confluence evidence conflicting with the Jira and source history.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The authoritative current Goal definition, Goal search parameters, terminology references, and examples already reflect the requested split, and the observed differences are later accepted changes rather than incomplete application of FHIR-17756.

Recommendation:
Keep this no-change audit commit as-is. No follow-up core source work is recommended for FHIR-17756; future work should evaluate only newer Goal status trackers such as FHIR-53981 or FHIR-55326 on their own merits.
