FHIR-41354: Audit CodeSystem usage wording

Issue request:
FHIR-41354 was an Applied FHIR-core CodeSystem issue resolved Not Persuasive with Modification. It asked why FHIR core CodeSystem pages did not list THO value sets, using device-status and THO ValueSet v2-0962 as the example, and the approved resolution was to clarify the generated heading from "This Code system is used in the following value sets:" to "This Code system is used in the following FHIR core-defined or referenced value sets:".
