FHIR-5241: Audit extension reading clarification

Issue request:
FHIR-5241 was Published/Persuasive for Jan 2015 Ballot Comment #118 against the FHIR-core extensibility page. It asked to clarify the confusing Summary wording "When reading elements, ignore other extensions, unless you want to read a particular extension" with guidance to read and process understood extensions and ignore others.

Initial application:
The Jira comments cite SVN revision 4505. Git commit ce8baad35f1728a0a523750f0784acec1d15efc1 is the git-svn import of that revision and changed source/extensibility.html from the confusing wording to "When reading elements, read and process the extensions you know and use, and ignore other extensions." No additional current source location still contains the original wording.

Additional context:
The current active FHIR-core extensibility page still carries the FHIR-5241 clarification, but it has been further refined by later Published/Persuasive with Modification issue FHIR-18362. Commit 244ccaebcb380689eb02c60a2ed641cf62b88370, already present on the combined branch for FHIR-18362, updates the same Summary bullet to say to read and process known extensions, preserve unrecognized non-modifier extensions when possible, ignore them only if preservation is not possible, and handle unrecognized modifier extensions specially. Direct Zulip and Confluence searches for FHIR-5241 found no conflicting community record.

AutoFHIR reconciliation:
Made no source change. The current source already satisfies FHIR-5241's clarification request, and reverting to the older literal "ignore other extensions" phrasing would conflict with the later FHIR-18362 clarification.

Recommendation:
Keep this empty audit commit as the FHIR-5241 reconciliation record. No FHIR-core follow-up is needed for this seed; future extension-handling edits should preserve the later FHIR-18362 preserve-if-possible rule.
