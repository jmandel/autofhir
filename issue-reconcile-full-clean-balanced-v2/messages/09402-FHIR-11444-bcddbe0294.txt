FHIR-11444: Audit home page width fix

Issue request:
FHIR-11444 was a Published FHIR-core index-page change request from the DSTU2-era 2016-09 publication. The reported problem was that the home page/diagram did not use the available page width; the final Persuasive with Modification resolution was to spend time improving it, and the Jira application note says it was fixed by changing div-9 to div-12.

Initial application:
The Jira-tagged source history does not contain an explicit FHIR-11444 commit, but the matching application is visible in nearby history. Commit 2e5325bdee changed source/index.html and related top-level pages from <div class="col-9"> to <div class="col-12"> with the message "QA on visual aspects of spec part #1 of change from col-9 to col-12." A later home-page-specific commit, 66f032b79d, made the same col-9 to col-12 change on source/index.html again after intervening edits and stated that there was no right-hand column on the home page.

Additional context:
The current R6 source/index.html is the current home page source and includes modules-fragment.html directly. The 2021 HTML-template update in d7b8dadc removed the old <div class="col-12"> wrapper and its closing tag from source/index.html, leaving no col-9 or col-12 wrapper to correct. Searches for FHIR-11444 and the page-width wording found no Zulip or Confluence evidence that changes the Jira/source-history conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The old requested width fix was applied in historical source, and the current home page no longer contains the obsolete col-9 layout that the Jira application note identified.

Recommendation:
Keep this audit commit as-is. Any future change to the current home-page diagram sizing or modules.css max-width would be a new responsive-design decision, not an unapplied FHIR-11444 reconciliation.
