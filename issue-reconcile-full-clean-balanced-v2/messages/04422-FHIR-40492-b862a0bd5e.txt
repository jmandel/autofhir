FHIR-40492: Audit inter-version resource bindings

Issue request:
FHIR-40492 was Published/Persuasive with Modification for R5. It asked to change SearchParameter.base, SearchParameter.target, OperationDefinition.resource, and GraphDefinition.node.type to use the new inter-version resource value set from FHIR-38800, add version-specific additional bindings, and document when cross-version bindings are used.

Initial application:
The issue was applied by git commit 9082a9058ae488744811761db09744036f308ffa, which changed the four named bindings and added current-version additional bindings. Immediate follow-up commits tightened and corrected the same application: 6ba28a62fc02ab39d84279e575608931a602f0a7 restored required binding strength, c8e676ed7029945ae371b876d2cf99ab688fd2a9 switched the affected elements to version-independent-all-resource-types and registered that value set, and 6491a8ae4e027cbc00f1cc6f7e436d3801f74574 corrected the additional binding tag form used by the current source.

Additional context:
SearchParameter and OperationDefinition are active current-build resources in source/fhir.ini, and their affected bindings now use http://hl7.org/fhir/ValueSet/version-independent-all-resource-types with an additional UI binding to http://hl7.org/fhir/ValueSet/all-resource-types documented as the R5-specific set. GraphDefinition was later removed from core source by the R6 normative changes and the conformance module now points to the API Incubator for GraphDefinition, so there is no current core GraphDefinition.node.type binding to edit. FHIR-51651 and FHIR-54000 are later same-area proposals, but FHIR-51651 is only Resolved - change required in this default run scope and FHIR-54000 is still Triaged, so neither supersedes the already-published FHIR-40492 application here.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current in-build SearchParameter.base, SearchParameter.target, and OperationDefinition.resource definitions already carry the inter-version binding and current-version additional binding required by FHIR-40492, and the only originally named artifact no longer in core build scope is GraphDefinition.

Recommendation:
Keep this no-change audit commit. Revisit the same source area only when a later final/applied issue such as FHIR-51651 or FHIR-54000 is in scope, or if the API Incubator GraphDefinition source needs a separate external review.
