FHIR-3120: Audit Questionnaire business version support

Issue request:
FHIR-3120 is a Published/Persuasive FHIR-core Questionnaire change request asking for a Questionnaire business version comparable to profiles and value sets, with a version that changes when form content changes rather than when metadata such as description, author, or status changes. Jira comments record Connectathon agreement to add version to core and PC approval on 2014-05-29, with the issue applied for DSTU1.

Initial application:
No commit with an explicit FHIR-3120 tag was found. The relevant early git-svn history is 54ddc30bbb, which split Questionnaire/QuestionnaireResponse and applied most outstanding Questionnaire change requests; its source/questionnaire/questionnaire-spreadsheet.xml diff added Questionnaire.version as a 0..1 string for the publisher-assigned business version that may remain the same when the resource is updated. Later refactors moved this into the current StructureDefinition source.

Additional context:
Questionnaire is an active build resource in source/fhir.ini. The current authoritative Questionnaire StructureDefinition defines Questionnaire.version as the business version of the questionnaire, includes URL+version guidance, and the active Questionnaire search-parameter bundle exposes a version search parameter over Questionnaire.version. General resource guidance describes business versions as distinct from record versions, and a 2024 #questionnaire Zulip thread continues to interpret Questionnaire.version as that business version. FHIR-26370 later added versionAlgorithm support for comparing versions but did not supersede the need for Questionnaire.version.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current build source already contains the requested Questionnaire business version element and its supporting search/discovery surface.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-3120 unless a separate work-group decision changes canonical-resource versioning guidance.
