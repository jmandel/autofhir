FHIR-34398: Audit URI version-search guidance removal

Issue request:
FHIR-34398 was a Published/Persuasive FHIR-I change request for R5 asking to remove search.html#uri guidance saying that URI search parameters for canonical resource URLs SHOULD support canonical-reference searches and automatically detect a piped |[version] suffix. The resolution specifically said to remove the quoted sentences because that behavior is not predictable, even though servers could still choose to support it.

Initial application:
The issue was applied by upstream commit 644133ce9f4e090ead029bac99b78fb69bdb7b2d, which removed the quoted URI-section sentence from source/search.html. Current source/search.html retains the URI search-type section as an active source page and the FHIR build configuration explicitly notes source/search.html as the maintained search-rules summary page.

Additional context:
The Zulip thread linked from the Jira confirms the distinction that ValueSet.url and other URL properties are URI searches and should use url plus version parameters rather than ValueSet?url=http://foo|v1, while canonical elements can use reference-style versioned canonical search. Later FHIR-37382 explicitly added [parameter]=[url]|[version] documentation only for reference search parameters associated with canonical elements, and FHIR-52936 later clarified that URI can be used with canonical/uri/url elements but reference is generally preferred for canonical because it can handle versioned canonical values. The current canonical-reference guidance in source/search.html#versions is therefore later intentional context, not stale URI-type guidance from FHIR-34398.

AutoFHIR reconciliation:
This commit makes no source change. The current URI section no longer contains the removed SHOULD language or a ValueSet?url=http://foo|v1-style recommendation; it only explains ordinary URI matching, :above/:below URL matching, and the later clarified relationship between URI, reference, and canonical search types.

Recommendation:
Keep this empty audit commit as-is. Do not remove the later canonical-reference version-search guidance under References and Versions unless a separate final Jira decision changes canonical/reference search behavior; it is outside the URI-type guidance removed by FHIR-34398.
