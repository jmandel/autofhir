FHIR-13341: Audit pharmacy extension removal

Issue request:
FHIR-13341 was a Published/Persuasive with Modification Pharmacy change request for STU3 asking to review all pharmacy resource extensions and remove those that were not appropriate. The final Pharmacy WG decision, voted John/Tim 2-0-2 on 2017-05-29, was to remove the core pharmacy resource extensions reviewed in May 2017 and require any future needed extensions to come through new FHIR trackers.

Initial application:
The issue was applied historically in three Jira-tagged commits. Commit daffd34b4bc382c49b942eb345b5444605747928 commented out Medication usualRoute and added the Pharmacy WG removal note. Commit 50d3565f94cc8c7302f4c80d91c22e35eb9e47be commented out MedicationDispense validityPeriod and MedicationStatement Prescriber with the same note. Commit 6e4237d72217fd04a626764f63d469dec9d5ee6e commented out the pharmacy-core extension rows including doseType, infuseOver, rateIncrement, rateIncrementInterval, rateGoal, minDosePerPeriod, maxDeliveryRate, maxDeliveryVolume, refillsRemaining, and body-site related entries.

Additional context:
Medication, MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement remain active core resources, and source/fhir.ini still has an active pharmacy-core profile spreadsheet. The current pharmacy extension spreadsheet contains profile metadata and headers but no active extension rows matching the FHIR-13341 removal list. A current active-source search for the original extension URLs/names finds no core definitions; the only matching current core lines are retained OID registrations for medicationdispense-refillsRemaining and medicationdispense-quantityRemaining, which are later FHIR-20469 artifacts. FHIR-20469 is already represented on the combined branch by d29cfbb5c867eb3b4f43fbdcb08de412161a0447 as an external-repo audit, and the current FHIR Extension Pack contains those later MedicationDispense extension definitions. FHIR-13619, an earlier clarification request for pharmacy-core-refillsremaining, was retracted because the extension had been removed. Zulip discussion in 2019 confirms Pharmacy understood the STU3 extensions as removed and directed implementers to file a new tracker for renewed need.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the FHIR-13341 removals are already reflected in current core source, and removing later FHIR-20469 OID registrations or external extension-pack definitions would exceed this seed and conflict with later Applied/Published work.

Recommendation:
Keep this audit commit as-is. Future changes to current MedicationDispense refills/quantity extension definitions should be made in HL7/fhir-extensions or through the already-audited FHIR-20469 path, not by reopening the completed FHIR-13341 core removal.
