FHIR-8047: Audit NPI identifier URI

Issue request:
FHIR-8047 was a Published/Persuasive PA change request from DSTU1 asking FHIR core to add a system URI for the US National Provider Identifier. The resolved URI was http://hl7.org/fhir/sid/us-npi.

Initial application:
The issue was applied in svn revision 6064, represented in git by c8797d9ce12b17c991437850da507680fa9e7a45, which added a NamingSystem registry entry for United States National Provider Identifier with URI http://hl7.org/fhir/sid/us-npi and OID 2.16.840.1.113883.4.6.

Additional context:
FHIR-37889 later removed the core NamingSystem registry bundles because the identifier and terminology registry content is authoritatively maintained in HL7 Terminology. Current core source keeps identifier-registry.html in the build hierarchy and directs implementers to terminology.hl7.org for active identifier systems. The current THO package contains NamingSystem/npi with the same requested URI as a preferred identifier, and current core examples use that URI in Practitioner/Bundle examples.

AutoFHIR reconciliation:
This audit commit makes no source change. Re-adding the removed core NamingSystem registry entry would contradict the later FHIR-37889 migration to THO, while the current core source and THO registry already preserve the requested NPI URI.

Recommendation:
Keep this no-change audit commit as-is. Future NPI identifier metadata corrections should be handled through THO/TSMG rather than by restoring retired core registry bundle content; no FHIR core source edit is needed for FHIR-8047.
