FHIR-18998: Audit InsurancePlan ownedBy short

Issue request:
FHIR-18998 was a Published/Persuasive PA change request asking to change the short display for insurancePlan.ownedBy from "Plan issuer" to "Product issuer" to align with other elements.

Initial application:
The issue was applied by commit ed4f6032d79236e09cd22f6d44afafe72a9c12b7, which changed source/insuranceplan/structuredefinition-InsurancePlan.xml so InsurancePlan.ownedBy had short value "Product issuer".

Additional context:
FHIR-24827 later split the former InsurancePlan content into InsuranceProduct plus a smaller InsurancePlan. The active current build includes both insuranceplan and insuranceproduct in source/fhir.ini, maps InsurancePlan.ownedBy to InsuranceProduct.ownedBy in the migration notes, and current source/insuranceproduct/structuredefinition-InsuranceProduct.xml retains the requested "Product issuer" short. The current InsurancePlan resource no longer has an ownedBy element.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested short is already present on the current active successor element, and changing the current InsurancePlan source would be impossible because the element moved out of that resource.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR core unless a future PA decision changes the InsuranceProduct/InsurancePlan split or renames the successor element again.
