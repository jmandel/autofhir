FHIR-31601: Audit ICD page migration to THO

Issue request:
FHIR-31601 was a Published, Persuasive with Modification Vocabulary change request for the FHIR-core ICD usage page. It asked to replace or remove the stale ICD-11 statement that said ICD-11 was scheduled for release in 2017; the recorded resolution was to update or remove date references as appropriate.

Initial application:
The issue appears to have been applied in ba29899f03, which added the Jira-requested ICD-11 release/history sentence to source/icd.html in the same commit that handled FHIR-35800. That source page was part of the old core "Using ICD-[X] Codes with FHIR" material at the time.

Additional context:
FHIR-35933 later moved the "Using external code system with FHIR" pages out of FHIR core and into HL7 Terminology/THO. Current core source no longer contains source/icd.html; the active terminology code systems page in source/hierarchy.xml and source/terminologies-systems.html directs implementers to https://terminology.hl7.org/ICD.html and states that THO is authoritative for external terminology guidance. The live THO ICD page still contains the post-FHIR-31601 ICD-11 sentence, so any further date modernization belongs in THO/UTG rather than this core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR core source does not contain the obsolete 2017 ICD-11 sentence or the old ICD page, and editing core would either duplicate external terminology guidance or recreate content that a later published decision deliberately moved to THO.

Recommendation:
Keep this external-repo audit for FHIR core. If the current THO wording about ICD-11 use beginning January 1, 2022 should be modernized, handle that as a THO/UTG content update rather than a FHIR-core source change.
