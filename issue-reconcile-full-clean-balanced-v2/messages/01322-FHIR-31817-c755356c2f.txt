FHIR-31817: Audit Ingredient presentation clarification

Issue request:
FHIR-31817 was a Published/Persuasive BR&R clarification request for the R4 MedicinalProductIngredient artifact, asking that the documentation explain what "units of presentation" actually are.

Initial application:
The old MedicinalProductIngredient artifact is mapped to the active Ingredient resource in the current build. Git history shows an explicit FHIR#31817 commit, 72c7bcfe69, adding the current unit-of-presentation sentence, and the current branch carries the same clarification through ancestor commit 464b98e6e7.

Additional context:
Ingredient is active in source/fhir.ini, while MedicinalProductIngredient is a redirect to Ingredient. Later FHIR-39134 discussion on concentration and presentation strength did not reverse this clarification; it added/examples maintained the distinction between presentation strength for per-item or consumer-facing expression and concentration strength for normalized calculation.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because source/ingredient/structuredefinition-Ingredient.xml already defines Ingredient.substance.strength.presentation[x] as the quantity of substance in the unit of presentation and explains that a unit of presentation is the quantity the item occurs in, such as a strength per tablet size rather than a normalized unitary denominator. The checked-in example also explains presentation versus concentration strength.

Recommendation:
Keep this no-change audit as-is. Any future work should be limited to a separate editorial cleanup if the work group wants to polish the existing wording; the published FHIR-31817 clarification is already represented in build-scoped source.
