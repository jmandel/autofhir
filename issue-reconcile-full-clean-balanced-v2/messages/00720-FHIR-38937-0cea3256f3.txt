FHIR-38937: Audit Citation classification search parameters

Issue request:
FHIR-38937 is a Published/Persuasive with Modification CDS change request raised for R5. It asked for a Citation category or code field to support filtering citations by domain, discipline, and similar classifiers. The accepted resolution did not add a narrow category element; it kept the existing Citation.classification backbone with type and classifier and requested search parameters for classification type and value.

Initial application:
The issue was explicitly applied in commit 5925247efc9f5a98fb4609b281131c49b47e00da, "J# 38937 Added more Citation search parameters". That commit added Citation-classifier, Citation-classification-type, and composite Citation-classification search parameters to source/citation/bundle-Citation-search-params.xml. The R5 published search page shows the same classifier, classification-type, and classification search parameters for Citation, confirming the R5 publication surface received the issue's requested search support.

Additional context:
Current core source no longer contains a build-scoped Citation resource or source/citation directory. Commit 71567db3ee039ac6977be5f96a7e013896569a36 intentionally removed Citation from source/fhir.ini, workgroup/status metadata, source/citation, and current metadata narrative now links Citation out to the EBM IG rather than to a core citation.html page. Confluence CDS/HEvKA archive page 104573270 independently records the February 20, 2023 project-management application work as "jira:FHIR-38937 - adding search parameters for the Citation.classification element". Bounded Zulip and Confluence key searches found no conflicting community evidence.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed: the R5 core issue was applied before publication, and the current core build has no Citation search-parameter source location where a FHIR-38937 edit could safely be made.

Recommendation:
Keep this audit commit as-is. Do not reintroduce Citation or its search parameters into current core for FHIR-38937; any future Citation-domain filtering changes should be handled in the artifact that currently owns Citation-related EBM guidance rather than as a core R6 source patch for this R5 issue.
