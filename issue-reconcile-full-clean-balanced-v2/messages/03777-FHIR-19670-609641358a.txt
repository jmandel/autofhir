FHIR-19670: Audit migrated LOINC data-elements guidance

Issue request:
FHIR-19670 was Published/Persuasive with Modification for STU3. It asked to add back text describing how LOINC codes and their properties can be represented as FHIR logical models after DataElement was removed, with the approved wording referring to StructureDefinition/logical models and adding the final period.

Initial application:
The issue was applied in git commit 187616469c368cdbdc5e2e0b7595b3af0c0db929, which edited the then-current source/loinc.html page and restored the LOINC and Data Elements section. The historical commit preserved the intended StructureDefinition/logical-model guidance, though it rendered the approved "its" as "it's".

Additional context:
FHIR-35933 and related THO proposal UP-289 later moved the Using X with FHIR external code system pages out of FHIR core and into HL7 Terminology. Commit 81e5862f203fdb8a03e9c943a7cf455aba8973f4 deleted source/loinc.html from the core build, and current source/terminologies-systems.html states that THO is authoritative for external terminology use while linking LOINC to https://terminology.hl7.org/LOINC.html. The current THO English LOINC page contains the migrated LOINC and Data Elements section.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. The authoritative detailed LOINC guidance is no longer maintained in this checkout, and the current core page already delegates the topic to THO; re-adding source/loinc.html or duplicating the section in core would conflict with the later migration decision.

Recommendation:
Keep this audit commit as-is for FHIR core. If the remaining "it's" versus "its" typo in the migrated LOINC and Data Elements paragraph needs cleanup, handle it in the THO/UTG source for the LOINC page rather than in the FHIR core repository.
