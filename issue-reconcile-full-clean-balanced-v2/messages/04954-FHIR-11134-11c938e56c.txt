FHIR-11134: Audit Questionnaire linkId clarification

Issue request:
FHIR-11134 was a Published/Persuasive with Modification PC issue raised against DSTU2. It asked to clarify linkId without renaming it: Questionnaire.item.linkId short definition should become "unique id for item in questionnaire", QuestionnaireResponse.item.linkId short definition should become "Pointer to specific item from Questionnaire", and both linkId elements should be 1..1.

Initial application:
The issue appears to have been applied in legacy source by git commit 76675fcc91938801ee4e8de9ec10d2c6e1949bc8 on 2016-11-15. That commit explicitly mentioned #11134 and changed Questionnaire.item.linkId and QuestionnaireResponse.item.linkId from 0..1 to 1..1, updated the two short names, and fixed examples to include linkId values. Later source refactors carried those element definitions into the current StructureDefinition XML files.

Additional context:
source/fhir.ini lists questionnaire and questionnaireresponse as active resources in the current build. Later related linkId decisions, including FHIR-38654 and FHIR-46191, added whitespace and validation guidance but did not reverse FHIR-11134's clarified purpose or mandatory cardinality; FHIR-46191 is already represented on the combined branch. Direct Zulip and Confluence searches for FHIR-11134 found no conflicting community record.
