FHIR-49802: Audit MPHO profile FMM migration

Issue request:
FHIR-49802 was an Applied/Persuasive OO change request for R6 asking that the MedicalProductOfHumanOrigin core profile maturity level be moved to FMM 1.

Initial application:
The request was applied by commit e310a0cfa367251d83d375ce0ca75c3286ef3473, merged by HL7/fhir#3327 as 67f1afa39d79c7246d74b47c8ac545abd018c4a1, changing source/biologicallyderivedproduct/structuredefinition-profile-medicalproductofhumanorigin.xml from structuredefinition-fmm 5 to 1.

Additional context:
Later OO decisions FHIR-52021 and FHIR-54998 concluded that the MPHO profile was not ready to remain in FHIR core and should move to the OO Incubator IG. Current core source has no active fhir.ini profile entry for medicalproductofhumanorigin, the BiologicallyDerivedProduct core ImplementationGuide no longer references StructureDefinition/medicalproductofhumanorigin, and the profile source file has been deleted from core. The successor HL7/oo-incubator FSH profile still carries structuredefinition-fmm = 1.

AutoFHIR reconciliation:
No source change was made. The requested FMM value was already applied while the profile was in core, and the current core build no longer contains or owns the profile source that would need an FMM edit.

Recommendation:
Keep this audit commit as-is. Future profile maturity changes should be made in HL7/oo-incubator, not in the core FHIR checkout, unless a later work-group decision moves the profile back into core.
