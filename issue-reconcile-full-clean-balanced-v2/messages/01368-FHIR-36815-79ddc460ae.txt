Initial application:

Later source updates also changed the Appointment.class binding to the current encounter-class value set. This reconciliation found that the build-scoped FHIR ModelInfo Library still exposed Location.physicalType and Encounter.Location.physicalType and omitted Appointment.class.

Additional context:

The THO location-physical-type code system now contains code vi/Virtual, so the current location-form value set includes the requested virtual code through its include. FHIR-57398 is a later Resolved - change required clarification for Location.form wording; it is not Applied/Published and is outside this default source-edit scope.
