FHIR-13289: Audit deprecationDate property URI

Issue request:
FHIR-13289 was a Published/Persuasive FHIR-core CodeSystem correction raised for STU3. It reported that generated v2 and v3 code systems were defining a dateTime concept property with code deprecated but URI http://hl7.org/fhir/concept-properties#deprecated, even though the property represented the deprecation date and should use deprecationDate.

Initial application:
The Jira application comment names svn revision 12611. The migrated git-svn commit 32744075fc34c3ddb366d6679391a6344eda2012 (#13289 - fix deprecated URL) changed the old R4 Java CodeSystemUtilities helper to emit code deprecationDate for date-valued deprecation properties and to recognize that property when determining deprecation. That old implementation path is no longer present in current source.

Additional context:
The current build includes source/codesystem/codesystem-concept-properties.xml through the active [codesystems] entry in source/fhir.ini. Current source defines both the deprecated legacy deprecated concept-property code and the preferred deprecationDate dateTime concept-property code, and the CodeSystem notes explain the http://hl7.org/fhir/concept-properties# prefix and show the deprecationDate table row. Related combined-branch reconciliation for FHIR-12312 already audited replacement of the old codesystem-deprecated extension with concept-properties, and FHIR-37849 already fixed later table/code-system drift around deprecated versus deprecationDate.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Active current source, current terminology inputs, and current implementation directories have no http://hl7.org/fhir/concept-properties#deprecated URI use for a deprecationDate property, while the authoritative concept-properties source and CodeSystem narrative now carry the correct deprecationDate URI convention.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-13289 unless a future generated v2/v3 terminology pipeline outside current build scope reintroduces a date-valued deprecated property URI.
