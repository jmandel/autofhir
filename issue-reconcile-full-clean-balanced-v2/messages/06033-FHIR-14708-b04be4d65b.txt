FHIR-14708: Audit subsumes outcome value set

Issue request:
FHIR-14708 was Published with a Persuasive with Modification resolution for STU3/Vocab. It asked that CodeSystem $subsumes outcome have a defined value set containing equivalent, subsumes, subsumed-by, and not-subsumed, that the outcome binding become required, and that the parameter documentation point to that value set.

Initial application:
The issue was applied by git-svn commit f87c99c1357a32232828f9aabba5ad15425ee6ce / SVN r14020, which added the ConceptSubsumptionOutcome binding, changed the outcome documentation to reference the concept-subsumption-outcome value set, and introduced the four-code concept-subsumption-outcome list in the CodeSystem spreadsheet source. The current refactored XML source preserves that application in source/codesystem/operationdefinition-CodeSystem-subsumes.xml and source/codesystem/valueset-concept-subsumption-outcome.xml.

Additional context:
The current build source has moved from the resolution's proposed subsumes-response name to the published concept-subsumption-outcome canonical, which appears in R4/R4B/R5 history and current OID registrations. FHIR-29119 later updated the code definitions, especially not-subsumed, without changing the four-code value set or the required binding. FHIR-34183 reported that this value set was briefly missing from the R4B branch and was fixed there; current source contains it. Community searches for FHIR-14708 and subsumes outcome value-set terms found no directly relevant contrary Zulip or Confluence record.
