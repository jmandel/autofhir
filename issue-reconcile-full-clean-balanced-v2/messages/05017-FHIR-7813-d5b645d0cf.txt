FHIR-7813: Audit MedicationRequest v2 RXC-2 mapping

Issue request:
FHIR-7813 is a Published/Persuasive Pharmacy change request for the DSTU1 MedicationPrescription v2 mapping table. It asked to change the Medication row from "RXE-2-Give Code / RXO-1-Requested Give Code / RXD-2-Dispense/Give Code" to "RXE-2-Give Code / RXO-1-Requested Give Code / RXC-2-Component Code" because the prescription resource should not map its ordered medication to the dispense field RXD-2.

Initial application:
The issue appears to have been applied in the September 2015 QA mapping commit 651364cb098a623c36afc1d6b9d56578507d897c, whose subject explicitly lists tracker item 7813 and whose patch changed MedicationOrder.medication[x] from RXD-2-Dispense/Give Code to RXC-2-Component Code. Later source migrations and release-history artifacts preserved that mapping through MedicationOrder and then MedicationRequest.

Additional context:
MedicationPrescription is no longer a current resource name; source/fhir.ini records that MedicationPrescription became MedicationRequest, and MedicationRequest is an active current-build resource. The current MedicationRequest.medication v2 map is "RXE-2-Give Code / RXO-1 Requested Give Code / RXC-2 Component Code". RXD mappings remain only on dispense-related or indication-related MedicationRequest elements, which does not conflict with the issue's Medication element request. Jira search found no other RXC-2/RXD-2 MedicationPrescription tracker beyond FHIR-7813, and Zulip/Confluence searches found no community evidence changing the conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source already carries the requested RXC-2 mapping on the successor MedicationRequest.medication element, and the old RXD-2 medication mapping is not present on that element.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed unless a future Pharmacy/V2 mapping review wants to reassess other dispense-related MedicationRequest v2 mappings, which are outside FHIR-7813.
