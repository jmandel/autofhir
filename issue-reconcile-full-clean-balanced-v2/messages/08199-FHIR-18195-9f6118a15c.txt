FHIR-18195: Audit generic note extension reconciliation

Issue request:
FHIR-18195 was a Published/Persuasive FHIR-core change request from STU3 asking whether a generic annotation extension should exist for Element. The voted resolution was to remove the current annotation/comment extensions and define a generic "note" annotation extension with broad context.

Initial application:
The Jira comment records the issue as applied in commit b3409464ad883b2120e929c03620eefe68d374c9. That commit rationalized the then-current annotation/comment extension spreadsheets for event, QuestionnaireResponse, StructureDefinition, CodeSystem, and ValueSet. The current core tree no longer contains the old event-note, questionnaireresponse-note, structuredefinition-annotation, codesystem-comment, or valueset-comment extension definitions.

Additional context:
FHIR core later removed extension definitions from the R5 source, and the current generic note extension source is maintained in the FHIR Extension Pack rather than this core checkout. The Extension Pack now defines http://hl7.org/fhir/StructureDefinition/note as an Annotation-valued extension, and later Published Extension Pack issues FHIR-44380, FHIR-44919, and FHIR-32915 govern its current scope. FHIR-44919 is especially important because it explicitly says not to set the context to Element, so restoring FHIR-18195's older broad-context wording in core would conflict with later final work-group direction.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The old core-specific annotation extension names are absent from current build-scoped core source, the replacement note extension is owned by the Extension Pack, and its non-Element context is supported by later Published Extension Pack decisions.

Recommendation:
Keep this audit commit as-is. Any future request to expand the note extension to PlanDefinition sub-elements or to Element generally should be filed and reconciled in the FHIR Extension Pack, and should account for FHIR-44919's explicit decision against Element context.
