FHIR-5939: Audit Composition example URI fixes

Issue request:
The Published/Persuasive FHIR-5939 change request reported that the Composition discharge summary integrated example used non-URI or malformed system values: www.loinc.org for the Composition type, nhi for a Patient identifier, sys for AllergyIntolerance reaction manifestation, and inconsistent or malformed SNOMED URLs.

Initial application:
The Jira comments said the issue was fixed in SVN 4744 and the LOINC detail in SVN 4758. The git-svn history confirms this: 64fc0a81b0 (build@4744) removed the non-URI Patient identifier system and changed the malformed SNOMED and sys values, while db55db7414 (build@4758) changed www.loinc.org to http://loinc.org in the same discharge summary source.

Additional context:
Composition is an active current-build resource in source/fhir.ini, and list-Composition-examples.xml still registers document-example-dischargesummary as the discharge summary example. The current source/composition/document-example-dischargesummary.xml contains http://loinc.org for the Composition type, http://snomed.info/sct for the medication SNOMED coding, and http://example.org/system for the AllergyIntolerance manifestation example; the obsolete Patient identifier system is no longer present. Searches found no remaining exact bad values in current source and no Zulip or Confluence evidence that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current active source already reflects the requested URI corrections, and the JSON/main examples mentioned in the Jira are generated from the same corrected example source.

Recommendation:
Keep this no-change audit commit as-is. No follow-up core source work is needed for FHIR-5939 unless a separate validation concern is raised about the example content beyond the original URI-system defects.
