FHIR-47537: Audit contained-resource chained search wording

Issue request:
FHIR-47537 was Applied/Persuasive with Modification for R6. It asked to change the search page statement "However, chained parameters will be evaluated inside contained resources" to a SHALL requirement. FHIR-I instead resolved to change "will" to "SHOULD" because the page is normative and many systems do not support a SHALL requirement.

Initial application:
The issue appears to have been applied by PR #3442 in commit 48bf8dfc355a30114d773dd999df18f345fe27cc, which changed source/search.html from "will be evaluated" to a conformance-highlighted "SHOULD be evaluated" sentence. The current combined branch already contains that wording in source/search.html.

Additional context:
FHIR-I minutes for 2025-01-13 record the same modification: the search page is normative, "will" could be changed to SHOULD, and the community treats "will" as optional; the motion passed 8-0-1. Corrected Zulip and Confluence searches found no contrary FHIR-47537 discussion, and a later Zulip hit merely quoted the current SHOULD wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active source/search.html page and the combined branch already match the final WG resolution, while changing the text to SHALL would contradict the applied Persuasive with Modification decision.

Recommendation:
Keep this no-change audit commit as-is. Revisit only if FHIR-I opens a later normative-change tracker to strengthen the requirement from SHOULD to SHALL.
