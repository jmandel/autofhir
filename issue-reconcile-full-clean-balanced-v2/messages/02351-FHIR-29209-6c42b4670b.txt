FHIR-29209: Audit event-resource realization guidance

Issue request:
FHIR-29209 was Published/Persuasive with Modification for R5 and asked how Clinical Reasoning PlanDefinition/ActivityDefinition could generate event resources such as Observation or RiskAssessment when ActivityDefinition.kind cannot name event resources directly. The accepted resolution was to add guidance from the definitional-artifacts discussion and link it from the PlanDefinition and ActivityDefinition realization topics.

Initial application:
The issue appears to have been applied by commit 5126624496f45455a6dbaf65bfc5c7d44f4f367e and PR HL7/fhir#2834. That commit added Event Resources guidance to ActivityDefinition and PlanDefinition narrative, updated ActivityDefinition.kind commentary, and expanded the Clinical Reasoning definitional-resources topic to say event resources should be represented through a Task with proposal intent and Task.focus set to the computed event resource.

Additional context:
FHIR Workflow minutes from 2021-01-11 record the same intent: the result should be a Task saying to store the Observation because the response remains a proposed request. The 2021-02-08 minutes record Bryn explaining the benefits of the Task approach. Later FHIR-49988 retained and generalized the Task realization strategy for PlanDefinition.action.definition references to definitional resources other than ActivityDefinition or PlanDefinition, so the current source should not be narrowed to only the original FHIR-29209 examples.

AutoFHIR reconciliation:
This commit intentionally makes no source change. ActivityDefinition and PlanDefinition are active resources in source/fhir.ini; their current realization narratives still contain the FHIR-29209 Event Resources guidance; ActivityDefinition.kind still explains the Request-only kind rule and Task.focus event-resource workaround; and the Clinical Reasoning definitional-resources page is linked from the current module page and contains the Task/proposal guidance. The later PlanDefinition text for other definitional resources is compatible with, not a regression from, FHIR-29209.

Recommendation:
Keep this no-change audit commit. No additional core source edit is needed for FHIR-29209 unless CDS later chooses to replace the Task.focus guidance with a different realization model.
