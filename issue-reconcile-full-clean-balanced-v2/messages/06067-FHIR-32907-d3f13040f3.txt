FHIR-32907: Add CareTeam as Specimen collector target

Issue request:
FHIR-32907 was a Published OO change request with a Persuasive with Modification resolution for patient-collected specimens. The accepted resolution said Specimen.collection.collector should use the same pattern as Observation.performer: Reference(Practitioner | PractitionerRole | Organization | CareTeam | Patient | RelatedPerson).

Initial application:
The Jira comment linked PR 1413 commit 037b22d as merged into the build; that GitHub commit was a merge into the FHIR-32907 branch, and local source history shows 06221389b5 added Patient to Specimen.collection.collector. The closely related FHIR-26922 application later added RelatedPerson in f2178d9b22, and FHIR-45470 later added Organization in 7326eeac41. Before this reconciliation, the current source had Organization, Practitioner, PractitionerRole, Patient, and RelatedPerson, but no CareTeam targetProfile for Specimen.collection.collector.

Additional context:
Current source/fhir.ini actively includes Specimen in the build, so source/specimen/structuredefinition-Specimen.xml is in scope. Current Observation.performer includes CareTeam among its allowed reference targets, matching the pattern named in the FHIR-32907 resolution. OO Confluence minutes record that FHIR-32907 was included in the September 2021 Specimen block vote and accepted on the main OO call. A corrected Zulip search found no direct FHIR-32907 discussion and no conflicting community evidence.

AutoFHIR reconciliation:
This commit adds the missing CareTeam targetProfile to the authoritative Specimen StructureDefinition and updates the checked-in Specimen SVG type display alongside that source change. It leaves search parameters and unrelated collector/performer elements unchanged because they do not carry collector targetProfile lists for this issue.

Recommendation:
Keep this commit as-is. It completes the published FHIR-32907 target reference set while preserving later Organization support from FHIR-45470 and the already-applied Patient/RelatedPerson support for self collection.
