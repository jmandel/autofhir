FHIR-37453: Audit yesnodontknow terminology references

Issue request:
FHIR-37453 was a Published/Persuasive Vocab technical correction raised against R4B and applied for R5. It reported that ValueSet/yesnodontknow referred to the missing terminology.hl7.org CodeSystem/v2-0136 and asked for the CLD to use the real yes/no CodeSystem, http://terminology.hl7.org/CodeSystem/v2-0532.

Initial application:
Commit d06598d8f7b1 applied FHIR-37453 by replacing the yes/no include in source/valueset/valueset-example-yesnodontknow.xml with explicit Y and N concepts from CodeSystem/v2-0532. A follow-up terminology QA commit, 7e10f14f4489, corrected the checked-in expansion to CodeSystem/v2-0532, and later metadata cleanup preserved the compose include as the existing THO ValueSet/v2-0136 rather than the missing CodeSystem/v2-0136.

Additional context:
The source value set is in build scope through source/valueset/list-ValueSet-examples.xml and uses the current yesnodontknow URL referenced by Questionnaire examples. The linked terminology Zulip thread clarified that v2-0136 is a ValueSet, not a CodeSystem, and that the broken state was treating v2-0136 as a code system. Vocab minutes for 2022-08-22 record FHIR-37453 as resolved change required and note that FHIR-27788, which had suggested removing the example value set, was reopened and rejected because the value set is used.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source no longer references http://terminology.hl7.org/CodeSystem/v2-0136 in valueset-example-yesnodontknow: the compose imports http://terminology.hl7.org/ValueSet/v2-0136, the expansion lists Y and N from http://terminology.hl7.org/CodeSystem/v2-0532, and URL checks confirm the imported ValueSet and v2-0532 CodeSystem exist while CodeSystem/v2-0136 does not.

Recommendation:
Keep this audit commit as-is. No core source fix is needed for FHIR-37453 unless the work group later chooses to replace the ValueSet import with explicit CodeSystem/v2-0532 concepts for style rather than correctness; the current source resolves the missing-CodeSystem problem without reintroducing FHIR-27788's rejected removal.
