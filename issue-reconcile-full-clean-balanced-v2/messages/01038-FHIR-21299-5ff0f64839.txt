FHIR-21299: Audit MeasureReport subject alignment

Issue request:
FHIR-21299 was a Published/Persuasive CQI change request for R5 asking MeasureReport.subject to support subject choices consistently with Measure.subject. The resolution agreed with consistent Measure/MeasureReport subject representation and noted that Measure.subject is inherited from MetadataResource, so the application needed publication-tooling care.

Initial application:
The applied upstream change is PR 2375. Commit a59ec1b9a0 added CareTeam, Device, Group, HealthcareService, Location, and Organization to MeasureReport.subject while retaining Patient, Practitioner, PractitionerRole, and RelatedPerson; commit 706986f282 corrected the malformed Organization targetProfile; merge 5fb43db826 brought those changes into the main source. No prior Issue-Reconcile-Key commit for FHIR-21299 was present on the combined branch.

Additional context:
source/fhir.ini actively lists measure and measurereport as current resources. Current Measure.subject[x] and the later Measure.group.subject[x] are CodeableConcept/Reference(Group) elements bound to participant-resource-types. Current MeasureReport.subject and MeasureReport.group.subject carry the aligned participant-style Reference target list: CareTeam, Device, Group, HealthcareService, Location, Organization, Patient, Practitioner, PractitionerRole, and RelatedPerson. Later FHIR-40422 added group-level subject support and kept the MeasureReport group subject aligned with the root subject. Direct Zulip and Confluence searches for FHIR-21299 found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative XML source already reflects the requested MeasureReport subject alignment, including the later group-level subject surface that depends on the same decision family.

Recommendation:
Keep this no-change audit commit as-is. Further source edits for FHIR-21299 would be redundant unless the work group separately changes the participant-resource subject model or chooses a broader MeasureReport subject target policy.
