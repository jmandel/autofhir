FHIR-11025: Audit AllergyIntolerance exposure-risk guidance

Issue request:
FHIR-11025 was a Published FHIR-core AllergyIntolerance change request with resolution Not Persuasive with Modification. It asked that a resource asserting the existence of an adverse-reaction risk and one asserting absence of such a risk be clearly differentiable. The accepted action was not to add a separate core assertion element, but to add a usage note that the substanceExposureRisk extension's exposureRisk component is a modifier of the substance.

Initial application:
The source history contains an explicit multi-issue application commit, 6225693f5e9ed809b62ef6ac5e5fe203e3d4f2b6, whose subject includes "#11025 AllergyIntolerance exposurerisk extension comment". That commit added the spreadsheet text "exposureRisk is a modifier of the substance" to the AllergyIntolerance extension source and also corrected the No Known Allergy SNOMED example code cited by the Jira resolution.

Additional context:
AllergyIntolerance remains an active core resource in source/fhir.ini, and current core AllergyIntolerance guidance still distinguishes positive and negated allergy/intolerance statements through AllergyIntolerance.code while pointing readers to the substanceExposureRisk extension as the structured alternative. Core no longer owns the extension definition: dd468d4f1799dd79819315b211588ef1cf4586e0 removed AllergyIntolerance extension definitions from R5 source, and the current FHIR Extension Pack definition for http://hl7.org/fhir/StructureDefinition/allergyintolerance-substanceExposureRisk contains the exposureRisk comment "exposureRisk is a modifier of the substance." Later FHIR-42977 refined the same extension text and invariant in the Extension Pack without changing the FHIR-11025 conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source is not missing an active build input for the FHIR-11025 usage note because the relevant StructureDefinition now lives in the Extension Pack, where the requested modifier note is present. Adding duplicate prose to core would restate external extension semantics and risk maintenance drift.

Recommendation:
Keep this no-change audit. Any future changes to the substanceExposureRisk extension definition should be made in the FHIR Extension Pack, but no follow-up is needed for FHIR-11025 because the historical action remains represented in the current authoritative extension source and core AllergyIntolerance guidance is not misleading.
