Issue request:
FHIR-17711 is a Published/Persuasive FHIR-core mapping-language change request, raised against STU3 and applied for R5, asking that the listed FHIR Mapping Language transforms match what the FHIR Validator actually supports. It specifically cited incomplete cast() support, undocumented dateOp behavior, and a desire for examples of each transform.

Initial application:
No source commit explicitly mentioning FHIR-17711 was found. The dateOp documentation concern was later split into FHIR-23937 and then FHIR-40645, and the current combined branch already has those audit/fix commits.

Additional context:
The Mapping Language page is active current-build source and StructureMap is an active resource with StructureMap.group.rule.target.transform required-bound to ValueSet/map-transform. Current source lists the concrete date/time transforms and documents their format codes, and CodeSystem/map-transform contains the same concrete transform codes. FHIR-17716, the sibling cast tooling issue, is already represented on the combined branch as a no-change tooling audit. Later issues FHIR-42980 and FHIR-54484 cover remaining TODO/example/function-documentation improvements, but FHIR-42980 is only Resolved - change required and FHIR-54484 is Triaged, so they are not source-edit scope for this applied/published seed.
