FHIR-16777: Audit ConceptMap cumulative targets

Issue request:
FHIR-16777 was a Published/Persuasive with Modification vocabulary issue against FHIR-core ConceptMap from the STU3 cycle. It asked what the existing note meant when it said that if there is more than one element for a source concept, the target statements are cumulative. The approved clarification was that, just as one element can have multiple targets, multiple elements simply aggregate their targets as if there was only one element.

Initial application:
The issue was applied by svn revision 14726, represented in git as 27cb6375aec6d40cc46b9ec8f2564f7dc023e100 ("GF#16777 - clarify note"). That commit replaced the ambiguous cumulative-target sentence in source/conceptmap/conceptmap-notes.xml with wording that says multiple occurrences of element with the same element.code aggregate their target elements as if there was only one element. The current source still contains that clarification.

Additional context:
ConceptMap is active in the current build through source/fhir.ini resource and work group entries. Later ConceptMap refactoring preserved the note, and the current StructureDefinition comment for ConceptMap.group.element remains consistent with the idea that a given concept may be mapped multiple times. Jira neighborhood search found only FHIR-16777 for the ConceptMap cumulative-target wording, and Zulip/Confluence searches found no directly relevant conflicting discussion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The authoritative current ConceptMap source already explains that duplicate source-concept elements are interpreted by aggregating their target elements into the same effective mapping, which resolves the ambiguity raised by the issue.

Recommendation:
Keep this no-change audit commit as-is. No specification correction is needed for FHIR-16777; any future editorial cleanup of the existing sentence's grammar should be handled separately because it does not change the approved cumulative-target semantics.
