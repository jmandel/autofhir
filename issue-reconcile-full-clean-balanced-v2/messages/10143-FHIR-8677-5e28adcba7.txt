FHIR-8677: Audit obsolete draft profile marking

Issue request:
FHIR-8677 is a Published/Persuasive FHIR-core DSTU1 change request asking that QI-Core profiles based on draft resources, and implementation guides such as EHRS, be marked as draft.

Initial application:
Jira comments record svn revision 6957. The matching git-svn commit af00949c039e6ee26443604d74778b6b5a61b8dd, "#8677 - allow marking profiles as draft + fix broken links", added profile-page draft-note template support and generated draft-note handling keyed from profile package status. That historical change applied the requested DSTU1-era build behavior.

Additional context:
The current core build no longer publishes the DSTU1 QI-Core or EHRS guide content from core. source/igs.xml keeps the ehrsrle and qicore IG entries commented out, and source/fhir.ini's active [profiles] list contains current core extension/profile spreadsheets without QI-Core or EHRS profile packages. Current profile templates use the shared standards-status/FMM table machinery instead of the old draft-note placeholder, and active draft core resources are separately listed in source/fhir.ini [draft-resources]. QI Core is now referenced as an external US IG at http://hl7.org/fhir/us/qicore rather than as a core-owned profile package.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR core source is not missing a draft marker for the historical QI-Core/EHRS artifacts because those artifacts are outside the current core build, and current active profiles/resources already have status rendering mechanisms.

Recommendation:
Keep this no-change audit commit. If a future review finds an incorrect draft/status label in QI-Core, EHRS, or another external IG, handle it in that IG's repository/publication process rather than in FHIR core.
