FHIR-16333: Audit binding strength guidance

Issue request:
FHIR-16333 was a Published/Persuasive FHIR-core vocab clarification for STU3 asking for additional formal guidance on binding strengths. The accepted resolution specifically required valueset-reference extension guidance for extensible bindings when a code falls outside the bound value set, and added that Example binding strength may use well-specified realm-specific value sets.

Initial application:
The issue was initially applied in git-svn commit 7aec658b3689440042c229c74d080b4d6c2520d5, matching the Jira comment for svn revision 14677. That commit changed source/terminologies.html by adding the realm-specific Example binding sentence and initial extensible-binding wording that outside codes are not additions to the bound value set. Follow-up terminology work in cc33213f906a949e5bb7ff4af5db1183810afe4a moved the valueset-reference guidance into an explicit note.
