FHIR-32060: Audit MedicationStatement status redesign

Issue request:
FHIR-32060 was a Published Pharmacy change request with resolution Persuasive with Modification. It asked to revise MedicationUsage.status by removing unknown, renaming completed to recorded, adding draft for implementation feedback, and noting that the redesigned statuses differ from prior MedicationStatement status semantics.

Initial application:
The requested source change was applied by 6cdd7b792e in September 2021, whose commit message included FHIR32060 without the hyphen. That commit changed the then-active MedicationUsage status CodeSystem and examples from completed to recorded, replaced unknown with draft, and updated MedicationUsage.status to recorded | entered-in-error | draft with a transition note. Later FHIR-38682 rename-back commits restored the active resource folder and fhir.ini entries to MedicationStatement while preserving the redesigned status model.

Additional context:
MedicationStatement is the active current-build resource in source/fhir.ini, and the current authoritative status files define recorded, entered-in-error, and draft with no completed or unknown status codes. FHIR-39271 later confirmed that MedicationStatement.status is now the status of recording the statement while MedicationStatement.adherence carries medication taking/not-taking meaning; that related issue is already represented on the combined branch by d5e940beb286, which also fixed residual rename-era wording in the same status files. FHIR-32858 is likewise already represented on the combined branch and supports the same status/adherence interpretation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active MedicationStatement StructureDefinition, status CodeSystem, and status ValueSet already satisfy FHIR-32060 after the historical application and the later FHIR-39271 cleanup, so additional wording or terminology edits would be redundant and could drift from the later published status/adherence decisions.

Recommendation:
Keep this audit commit as-is. No FHIR-32060 follow-up is needed in core unless the Pharmacy work group reopens the broader MedicationStatement status/adherence model; any such future work should start from the later FHIR-39271 and FHIR-32858 decisions rather than the pre-R5 MedicationUsage wording alone.
