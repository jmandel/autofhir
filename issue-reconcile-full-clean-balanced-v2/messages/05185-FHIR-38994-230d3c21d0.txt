FHIR-38994: Audit HTTP search method guidance

Issue request:
FHIR-38994 was a Published/Persuasive with Modification FHIR-I R5 clarification asking the HTTP page to match the Search page's GET/POST search-method guidance: replace the old POST form-encoding note with a pointer to the Search page's method-choice guidance, and add a 405 Method Not Allowed status-code entry telling clients to try the other search method when either GET or POST is unsupported.

Initial application:
The issue was applied in source history by f47290bddbd45abf5ead98478c1796e50bb8ea83, which replaced the search interaction note in source/http.html with a pointer to search.html#getvspost, added the requested 405 status-code entry for search errors, and added 404/405 to the search rows in the interaction summary table. That historical commit is already an ancestor of the current combined branch.

Additional context:
Later same-family issue FHIR-39137 reversed the cross-page ownership in a compatible way: it moved the detailed HTTP search transport guidance from source/search.html to source/http.html and left the Search page pointing to the HTTP page. The current build-scope pages still carry the substance FHIR-38994 requested: publish.ini lists http.html and search.html, source/hierarchy.xml nests Search under RESTful API, source/http.html now contains the GET/POST choice guidance plus the 405 rule, and source/search.html points Transport Protocols to http.html#search.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original requested edits were applied, and the later FHIR-39137 refactor leaves the current specification clearer than the literal FHIR-38994 link direction by keeping HTTP-specific method guidance on the HTTP page while maintaining a Search-page pointer.

Recommendation:
Keep this audit commit as-is. Future edits should be handled under newer search/HTTP tickets if the work group wants different GET/POST conformance language; reverting to the original FHIR-38994 cross-link would duplicate or weaken the current source structure.
