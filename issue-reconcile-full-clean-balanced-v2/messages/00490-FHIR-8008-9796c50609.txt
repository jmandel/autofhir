FHIR-8008: Audit IG layout guidance

Issue request:
FHIR-8008 was a Published, Persuasive with Modification FMG change request from the 2015 May ballot. It observed that each implementation-guide subpage had its own layout and asked that, before final DSTU publication, IG subpages have a small set of common headings. The accepted resolution was not to impose an immediate DSTU2 source change, but to solicit feedback about IG organization/content/formatting, apply that learning to some IGs, and then produce broader IG guidance.

Initial application:
No Jira-tagged FHIR-8008 source commit was found. The nearby source history instead shows broader IG infrastructure work in 2015 and later removal of the old in-core implementation-guide pages from active build inputs. In the current checkout, source/iglist.html and source/guides/ are absent, source/igs.xml is only the metadata list for the remaining core IG/package entries, and source/fhir.ini only has an additional external IG-list entry plus the normal ImplementationGuide resource build entry.

Additional context:
FMG revisited the tracker in 2021 and recorded that IG templates had addressed part of the issue and that the FHIR-I project on IG templates and tooling covered more of it, with no further action needed from FMG. Exact Zulip searches for the issue key, old tracker number, and common-heading phrase did not reveal a conflicting community decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current core FHIR source no longer contains the old DSTU-era IG subpage layout sources targeted by the comment, and the later FMG disposition places remaining layout consistency work in IG templates/tooling rather than in the core specification source.

Recommendation:
Keep this no-change audit. If future work needs enforceable common IG page headings or menus, it should be handled in the IG Publisher/template/tooling project or other current IG-governance artifacts, not by editing the current core FHIR source solely for this old DSTU1 tracker.
