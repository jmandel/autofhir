FHIR-33001: Audit replaces extension scope

Issue request:
FHIR-33001 was a Published FHIR-core change request, resolved Not Persuasive with Modification for R5, asking whether the http://hl7.org/fhir/StructureDefinition/replaces extension could be used on Practitioner and RelatedPerson. The approved resolution did not expand the context; it clarified that the extension is only for separate conformance resource instances superseded by the current instance.

Initial application:
The issue was applied in core before R5 by commit 717efcafe7e30a3ae02997bd0f38386229098110, merged as 4dd712a7214ecbd144a3018c92d88dfb8cb7268a, which changed the replaces extension definition in source/profiles/general-extensions-spreadsheet.xml from a generic replacing-resource description to "This indicates a separate conformance resource instance that is superseded by the current instance."

Additional context:
FHIR-I minutes on 2022-04-25 record the issue as "This extension can only be used with canonical resources" and Not persuasive with modification, 10-0-0. The core R5 history page says all extensions moved to the hl7.fhir.uv.extensions package, and commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed the old core extension rows. The current Extension Pack source for StructureDefinition/replaces carries the approved description and contexts only for conformance/canonical-style resources such as CapabilityStatement, StructureDefinition, OperationDefinition, Questionnaire, SearchParameter, and TestScript; it does not include Practitioner or RelatedPerson.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. The current core checkout no longer contains an active replaces extension definition to edit, and the current Extension Pack source already reflects the FHIR-33001 decision.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-33001 unless a future PA-owned change request adds a separate Practitioner or RelatedPerson replacement/linking mechanism.
