FHIR-19559: Audit superseded ImagingStudy scope wording

Issue request:
FHIR-19559 was Published as Persuasive with Modification for STU3 by Imaging Integration. It asked to clarify ImagingStudy Scope and Usage so an ImagingStudy references one DICOM Study and may reference a subset of that Study, with more than one ImagingStudy potentially referencing the same DICOM Study or different subsets.

Initial application:
The Jira comments say the change was pre-applied on 2018-10-29. Commit 131af0770a (GF#19559) implemented that application in source/imagingstudy/imagingstudy-introduction.xml by replacing the prior paragraph with the requested one-DICOM-Study plus subset wording.

Additional context:
ImagingStudy and ImagingSelection are both active current-build resources in source/fhir.ini. Later Applied issue FHIR-47275 directly revisited the same boundary because ImagingStudy and ImagingSelection both appeared to allow partial references to a DICOM Study. Its resolution removed the ImagingStudy subset permission and clarified that ImagingStudy stores details of an entire DICOM Study while ImagingSelection references a subset. Confluence WGM minutes record the same decision to modify ImagingStudy Scope by removing the last line and updating Boundaries and Relationships. Commit 41a56bc14a applied that later decision, and later FHIR-54814 wording preserved the ImagingStudy/ImagingSelection boundary.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already reflects the later governing decision: ImagingStudy Scope says one ImagingStudy resource SHALL reference one DICOM Study, notes that the resource can change as more information is added, and Boundaries and Relationships says ImagingSelection references subsets of a DICOM Study. Reintroducing the FHIR-19559 subset sentence would conflict with the later FHIR-47275 resolution.

Recommendation:
Keep this no-change audit as-is. Any future change to allow multiple ImagingStudy resources to represent different subsets of the same DICOM Study should be handled as a new Imaging Integration decision that explicitly revisits FHIR-47275.
