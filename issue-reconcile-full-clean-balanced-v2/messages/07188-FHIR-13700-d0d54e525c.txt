FHIR-13700: Audit ProcedureRequest reason short name

Issue request:
FHIR-13700 was a Published/Persuasive OO STU3 change request for ProcedureRequest asking to change the reason short name from "Explanation/Justification for test" to "Explanation/Justification for procedure or service".

Initial application:
The issue was applied before reconciliation by git commit 304407c44b6f, which changed both ProcedureRequest.reasonCode and ProcedureRequest.reasonReference short names in the then-authoritative ProcedureRequest spreadsheet source from "test" to "procedure or service".

Additional context:
ProcedureRequest was later renamed to ServiceRequest by FHIR-13867, and the active current build has ServiceRequest rather than ProcedureRequest. The current ServiceRequest source is in build scope through source/fhir.ini, and ServiceRequest.reason now carries the later FHIR-26674 wording: short "Reason or indication for requesting the service" with a definition that explicitly includes "procedure, lab test" examples. Searches found no remaining current source occurrence of the obsolete "Explanation/Justification for test" wording and no Zulip or Confluence evidence contradicting the Jira/source history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested correction was applied historically, carried through the ProcedureRequest to ServiceRequest rename, and later superseded by an applied OO wording update that still preserves the semantic correction by describing the reason for a service rather than a test-only reason.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-13700 unless a future work group decision reopens the ServiceRequest.reason wording.
