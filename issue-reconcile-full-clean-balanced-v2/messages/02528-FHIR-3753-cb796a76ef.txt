FHIR-3753: Audit ImagingStudy examples

Issue request:
FHIR-3753 was a Published/Persuasive with Modification DSTU1 Imaging Integration change request saying that ImagingStudy examples were not good enough, especially because build QA reported no example values for ImagingStudy search parameters such as uid/study, dicom-class, modality, bodysite, size, subject/patient, series, started, and accession. The final Jira resolution says these issues were resolved prior to STU3.

Initial application:
No prior AutoFHIR audit commit for FHIR-3753 was present on the combined branch. Git history shows the issue was applied directly before STU3 in 4e2c63f3e3, "Pre-Apply GF#3753 - making the ImagingStudy example complete, and adding RIM mapping", which added the proposed accession, identifier, modality, context, basedOn, referrer/interpreter, endpoint, procedure, reason, description, series endpoint/laterality/started/performer, SOP class, and title content to the then-current ImagingStudy example. The immediate a8b9e584da follow-up only pretty-printed that example.

Additional context:
ImagingStudy remains an active current-build resource in source/fhir.ini. The current source has a listed general example and a listed comprehensive X-ray example. The current examples have been refactored with the R5/R6 ImagingStudy model, but they still populate the active search-parameter surfaces, including based-on, body-site, body-structure, dicom-class, encounter, endpoint, identifier, instance, modality, patient/subject, performer, procedure, reason-concept, reason-reference, referrer, series, started, and status. Older DSTU1 search names such as study/uid/accession/size are either renamed, represented through current elements, or no longer active search parameters. FHIR-49907 later handled a separate R6 Imaging QA pass and is already represented on the combined branch.
