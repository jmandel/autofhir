FHIR-31633: Audit MedicationKnowledge status terminology

Issue request:
FHIR-31633 was a Published/Persuasive Pharmacy change request raised for R4 and applied for R5. It asked to fix MedicationKnowledge.status terminology by bringing the MedicationKnowledge status value set and code system back to FHIR core from THO.

Initial application:
The issue was applied in May 2021. Commit 7453f87bfc initially added MedicationKnowledge status terminology while also applying related Pharmacy changes, and commit 353a04689a explicitly titled "Fix FHIR-31633" created the FHIR-rooted CodeSystem/medicationknowledge-status and changed ValueSet/medicationknowledge-status to include that FHIR-rooted code system instead of the THO code system.

Additional context:
The current source still contains the FHIR-core MedicationKnowledge status CodeSystem and ValueSet in the active MedicationKnowledge resource folder. However, later Applied tracker FHIR-45285 deliberately changed MedicationKnowledge.status to the common publication-status value set so MedicationKnowledge conforms to CanonicalResource/MetadataResource interface requirements. FHIR-I minutes and FHIR-45284 record the interface-compatibility rationale, while the original Pharmacy minutes and Zulip terminology discussion support the original 2021 move of code-bound MedicationKnowledge status terminology out of THO and into FHIR core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring MedicationKnowledge.status to ValueSet/medicationknowledge-status would undo the later FHIR-45285 decision. Removing the retained FHIR-rooted MedicationKnowledge status terminology would exceed FHIR-31633, which was specifically about restoring that terminology to core. A generated-looking SVG still mentions the old MedicationKnowledgeStatusCodes binding, but the authoritative StructureDefinition source now carries the later publication-status binding and this audit does not edit diagram artifacts.

Recommendation:
Keep this audit commit as-is for FHIR-31633. Do not rebind MedicationKnowledge.status to the MedicationKnowledge-specific value set unless Pharmacy and FHIR-I explicitly reverse FHIR-45285. If stale generated diagrams or legacy unused MedicationKnowledge status artifacts need cleanup, handle that under FHIR-45285 or a separate human-reviewed tracker rather than this 2021 terminology-restoration issue.
