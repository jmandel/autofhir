FHIR-15934 was a Published, Persuasive with Modification STU3 FHIR-core Questionnaire issue asking to replace the confusing plural/singular Options and Option element names with clearer permitted-answer names. The approved resolution was to change them to answerOption and answerValueSet.

Initial application:
The issue appears to have been applied in SVN revision 13885, imported as git commit affcdd6a12958badf6ed093eb5079414b5e2d317. That commit explicitly says GF#15934 and updated Questionnaire spreadsheets, examples, and narrative from options/option to answerValueSet/answerOption. Later source rework commits preserved the renamed elements in the active StructureDefinition source.

Additional context:
Questionnaire is an active current-build resource. Searches for the old tags/paths found no remaining current Questionnaire source definitions or examples using the obsolete names outside that compatibility map. Direct Zulip and Confluence searches found no community evidence contradicting the Jira/source conclusion.
