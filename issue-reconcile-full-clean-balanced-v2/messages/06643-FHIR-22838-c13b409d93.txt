FHIR-22838: Correct Specimen role metadata

Issue request:
FHIR-22838 was Published/Persuasive with Modification for R5. The accepted OO motion added Specimen.combined as a 0..1 code for grouped/pooled specimens, added Specimen.role as a 0..* CodeableConcept with a preferred specimen-role value set derived from v2 table 0369 without H/G/L, added related terminology/examples, and clarified the then-current ServiceRequest.specimen comment.

Initial application:
The main source application was commit 3f94a76ece, which added Specimen.combined, Specimen.role, specimen-combined/specimen-role CodeSystem and ValueSet sources, examples, and the ServiceRequest.specimen comment. Commit 5cef2d9 later corrected the Specimen.role short and definition. Current source retained the intended elements, bindings, codes, and examples, but the applied metadata still had two copy/paste errors from the original source change: Specimen.combined used the PublicationStatus binding name and common-binding marker, and the specimen-role CodeSystem description said it provided the combined status of the specimen.

Additional context:
Specimen and ServiceRequest are active current-build resources in source/fhir.ini, and the corrected files are authoritative XML inputs under the active Specimen resource folder. Later applied ServiceRequest issues FHIR-34206, FHIR-48286, and FHIR-55444 deprecated and then removed ServiceRequest.specimen for R6, so this reconciliation intentionally does not restore or edit the old ServiceRequest.specimen comment. OO minutes confirm the FHIR-22838 motion and later review that the value set was in the build for ballot while THO migration was a separate vocabulary follow-up.

AutoFHIR reconciliation:
This commit corrects the active Specimen XML source metadata: Specimen.combined now names the SpecimenCombined binding and no longer carries the copied common-binding marker, and the specimen-role CodeSystem description now describes specimen role rather than combined status. No generated diagram files were edited.

Recommendation:
Keep this source fix. The core Specimen model and examples now match the published FHIR-22838 intent; any future THO migration or terminology URL policy work should be handled as a separate vocabulary/UTG task rather than by changing these core reconciliation edits.
