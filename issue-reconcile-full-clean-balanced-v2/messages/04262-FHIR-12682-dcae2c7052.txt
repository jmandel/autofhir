Later model changes added and renamed elements such as basedOn, replaces, groupIdentifier, intent, occurrence[x], authoredOn, informationProvider, about, encounter, reason, and note, so the exact DSTU2 order from FHIR-12682 is no longer the correct current ordering. The current StructureDefinition order is internally consistent, and the checked source examples preserve that order for the top-level elements they contain.
