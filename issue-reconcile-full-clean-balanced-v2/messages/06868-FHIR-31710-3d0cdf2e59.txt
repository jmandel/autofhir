FHIR-31710: Audit Bluebook example alignment

Issue request:
FHIR-31710 was a Published/Persuasive FHIR-core change request for the Bluebook Questionnaire and QuestionnaireResponse examples. It reported mismatched sex code capitalization, vitamin K dose linkIds, vitamin K dose answer value types, and requested the QuestionnaireResponse example to reference its Questionnaire so validation could catch these mismatches.

Initial application:
The issue was applied by commit b14ef4539d52882fe70340160e296928ff6ba56b ("FHIR-31710 - Fixed alignment of bluebook examples"), which changed the Questionnaire vitamin K dose linkIds from vitaminiK* to vitaminK*, replaced the QuestionnaireResponse display-only questionnaire element with the canonical Questionnaire URL, and changed the vitamin K dose answers from valueDate to valueDateTime. Later edits to these files were metadata, formatting, list, and invariant-test updates and did not reintroduce the reported mismatches.

Additional context:
Questionnaire and QuestionnaireResponse are active resources in source/fhir.ini, and the Bluebook examples remain listed in the current example lists. Confluence minutes record the issue as Persuasive, and bounded Zulip/Confluence searches found no conflicting discussion beyond the meeting/vote records. The Questionnaire still uses dateTime for the vitamin K dose questions, and the response now uses matching valueDateTime answers with valid date-only lexical values.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current source already has the QuestionnaireResponse.questionnaire canonical reference, uppercase sex code F, matching vitaminK dose linkIds, and valueDateTime answers matching the Questionnaire's dateTime item types.

Recommendation:
Keep this audit commit as-is. No follow-up core source change is needed for FHIR-31710 unless a future work group decision chooses to change the Bluebook vitamin K questions themselves from dateTime to date.
