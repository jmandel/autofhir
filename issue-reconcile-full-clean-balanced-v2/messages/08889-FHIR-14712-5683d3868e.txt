FHIR-14712: Audit extension usage rendering outside core

Issue request:
FHIR-14712 was an Applied FHIR-I change request with Persuasive with Modification disposition. It asked to add US Core, US Meds, and other usage references for the CapabilityStatement search-parameter-combination extension; the final resolution rejected manual per-extension lists and instead called for IG template/publisher rendering to link to an up-to-date cross-reference/statistics report and avoid misleading empty usage wording.

Initial application:
No core commit explicitly mentioning FHIR-14712 was found. The relevant extension used to exist in core under source/capabilitystatement/structuredefinition-extension-capabilitystatement-search-parameter-combination.xml, but the current core source no longer owns that StructureDefinition: commit dd468d4f17 removed extensions from the R5 source, and the current core checkout only retains the canonical URL in source/oids.ini. The extension definition is now maintained in the FHIR Extension Pack.

Additional context:
FHIR-I minutes show the work group discussing the empty Extension Pack usage rendering in April and May 2023, then approving FHIR-14712 as Persuasive with Mod at the May 2023 WGM. The current Extension Pack page for this StructureDefinition is built from HL7/fhir-extensions using hl7.extensions.template#1.0.0 and includes a "usages in the FHIR IG Statistics" link rather than a manually maintained US Core/US Meds list. A curl check of that current packages2 XIG URL returned 404 during this reconciliation; if that is still live, it is a package-server/template/rendering issue outside this core checkout.
