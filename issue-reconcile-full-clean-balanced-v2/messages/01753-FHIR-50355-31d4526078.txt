FHIR-50355: Audit ServiceRequest body site guidance

Issue request:
FHIR-50355 is an Applied/Persuasive-with-Modification OO R6 change request asking for clearer guidance on when to use ServiceRequest.bodySite versus ServiceRequest.bodyStructure. The approved resolution was to update the ServiceRequest.bodySite comment to say bodyStructure is preferred, to point coded use to bodyStructure.includedStructure.structure, and to keep laterality in bodyStructure.includedStructure.laterality rather than precoordination.

Initial application:
The issue was directly applied by commit 5fa034fbd0046c5854b323dc6d7ff37c5d6f7239, which replaced the ServiceRequest.bodySite comment with the Jira-approved text. OO WGM minutes on 2025-05-12 record the same motion and vote, including the rationale that the comment was the least disruptive place to highlight the distinction while ServiceRequest was already FMM 4.

Additional context:
Later OO issue FHIR-53203 changed the current model: ServiceRequest.bodyStructure became CodeableReference(BodyStructure) with the body-site example binding, ServiceRequest.bodySite was first deprecated and then removed from the active StructureDefinition, and an existing combined-branch audit commit already represents FHIR-53203. The current active source has no ServiceRequest.bodySite element to carry the old comment. It keeps ServiceRequest.bodyStructure as CodeableReference(BodyStructure) and the ServiceRequest notes point body-site/body-system representation to bodyStructure. Later FHIR-54843 and triaged FHIR-53826 show that broader bodySite/bodyStructure harmonization remains an active later discussion path, not a reason to restore the obsolete bodySite comment under this issue.

AutoFHIR reconciliation:
This commit is intentionally empty. The current source no longer has the ambiguous pair that FHIR-50355 tried to clarify, and reintroducing or duplicating the approved bodySite comment would conflict with the later applied removal of ServiceRequest.bodySite. Remaining broader guidance/cardinality work should stay with later bodyStructure issues.

Recommendation:
Keep this no-change audit commit as-is for FHIR-50355. Do not make a source edit for this issue unless a later work-group decision restores ServiceRequest.bodySite or explicitly asks to add ServiceRequest-specific bodyStructure guidance separate from the broader FHIR-54843 work.
