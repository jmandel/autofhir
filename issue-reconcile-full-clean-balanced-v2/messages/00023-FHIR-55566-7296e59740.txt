FHIR-55566: Audit OO deprecated element disposition

Issue request:
FHIR-55566 was Applied/Persuasive for R6 and asked OO to withdraw deprecated elements where applicable, specifically Observation.bodySite and ServiceRequest.specimen, or otherwise retain them without incorrect deprecated treatment.

Initial application:
There was no separate Jira-keyed source commit for FHIR-55566. Its ServiceRequest half was applied through FHIR-55444 in PR #4006: commit f22405098ca56696b5de3ef2359acb6e4333a661 removed ServiceRequest.specimen from the authoritative StructureDefinition and merge commit 9b0678c6a634bd26937fe5a8e806a9456e3340dd cleaned the lipid example and added release-note text. The Observation half was not supposed to remove Observation.bodySite because the element/resource was normative; current source keeps it with an explicit deprecated standards-status extension.

Additional context:
FHIR-53722 created the broader deprecated-element cleanup guidance and child tickets. FHIR-55444 is the applied ServiceRequest child ticket. FHIR-55441 later records the explicit no-change decision for Observation.bodySite: Observation is normative since at least R4, bodySite is only being deprecated as of R6, and the element should remain through the R6 lifecycle. The active source/fhir.ini resources list includes both observation=Observation and servicerequest=ServiceRequest, so the inspected source files are in current build scope. The Extension Pack checkout contains the servicerequest-specimenSuggestion replacement extension referenced by current ServiceRequest notes.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current source already reflects the correct split decision: Observation.bodySite remains present and deprecated, the Observation body-site search parameter is also marked deprecated, ServiceRequest.specimen is absent from the authoritative ServiceRequest StructureDefinition, and ServiceRequest narrative now points to Specimen.request or specimenSuggestion for relevant workflows.

Recommendation:
Keep this no-change audit as-is. The only observed residual ServiceRequest.specimen reference in core is a checked-in generated-looking SVG diagram, which should not receive an issue-specific source edit; regenerate diagram artifacts through normal build maintenance if they are in scope for publication review.
