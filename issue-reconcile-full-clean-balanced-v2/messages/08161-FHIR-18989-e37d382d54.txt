FHIR-18989: Audit Subscription tag removal

Issue request:
FHIR-18989 was Published with a Persuasive with Modification resolution for STU3 Subscription. It asked to remove the confusing Subscription.tag element, which had been described as a tag added to resources matching a subscription, and to add narrative explaining that Communication and/or AuditEvent could be used to track subscription notifications instead.

Initial application:
The Jira comment points to git 80086b8f22b9b182c473fbb7b7a446d7aafbd37c, which added a Tracking Subscription Notifications section describing AuditEvent and Communication use. Current history also shows the Subscription tag element is no longer present in the active Subscription source. Later Subscription framework work, notably ef0558f0c6008b9fd15ed93c302b484ab1c67f10, moved and retained the tracking guidance on the active subscriptions.html framework page.

Additional context:
The active build scope includes Subscription in source/fhir.ini and the current Subscription framework page now describes notifications through SubscriptionStatus and subscription-notification Bundles. Duplicate FHIR-18990 carries the same request but has Duplicate status and does not need a separate reconciliation commit. Source residue for the old subscription-tag code system/value set remains in unreferenced files and OID registry rows, but the current source has no Subscription.tag binding or prose reference and the current CI build returns no subscription-tag terminology pages.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current specification already implements the request: Subscription.tag is absent and source/subscriptions.html includes the requested AuditEvent/Communication tracking guidance.

Keep this no-change audit commit as-is. No Subscription source correction is needed for FHIR-18989; any future cleanup of obsolete, unpublished subscription-tag terminology source files should be handled as a separate terminology/build-scope question rather than as this tracker.
