FHIR-7269: Audit AddressUse definition as THO-owned

Issue request:
FHIR-7269 was a Published FHIR-core/vocab change request from the DSTU1 cycle. It asked to replace the v3 CodeSystem AddressUse description text "Uses of Addresses. Lloyd to supply more complete description" with a real definition; the final resolution was Persuasive with Modification, directing MnM to create a harmonization proposal to use the VSAC definition "The purpose for which a location is assigned the associated postal address".

Initial application:
No Jira-tagged FHIR-7269 source commit was found in the current core repository history. The stale wording is still visible in the copied 2019 v3 MIF data under tools/tx/v3/source.xml, both as the AddressUse entry in v3-CodeSystem and in the v3-AddressUse CONF concept. That file was introduced by 02557a9364 as copied vocabulary data after UTG content had already been removed from the core build.

Additional context:
Commit 5c0494aacfd0 removed the in-core v2/v3 terminology index pages and changed FHIR terminology narrative to point v3 code systems to terminology.hl7.org. Current source/terminologies-systems.html directs unresolved code system URIs to THO and the THO CI build, and source/terminologies-valuesets.html says value sets in HL7 Terminology outside the core specification are not listed in core. The current build no longer serves the old v3/CodeSystem/index.html or terminologies-v3.html pages. The current published THO CodeSystem-v3-CodeSystem artifact still carries the stale AddressUse definition, so the remaining defect is in THO/UTG-managed terminology, not in active core source.

AutoFHIR reconciliation:
This commit intentionally makes no source change in HL7/fhir. Editing tools/tx/v3/source.xml would patch a copied MIF artifact rather than the authoritative current terminology source, and it would not safely correct the published THO artifact that now owns v3 CodeSystem content.

Recommendation:
Keep this audit commit as-is for core. Follow up through UTG/THO to update CodeSystem-v3-CodeSystem code AddressUse to the approved VSAC wording; also review whether derived THO or extension-pack surfaces that repeat the old text should be regenerated or corrected from the same terminology source.
