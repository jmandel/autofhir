FHIR-45310: Audit OperationOutcome instance identifier extension

Issue request:
FHIR-45310 is Applied/Persuasive with Modification. It asked how an OperationOutcome recipient could receive an identifier useful for support and audit-log lookup, considering either X-Request-Id/X-Correlation-Id narrative or an OperationOutcome.issue identifier. The final resolution rejected X-Request-Id as not appropriate outside request/response situations and requested a new 0..1 string extension on OperationOutcome.issue with short "Unique id for issue occurrence", definition "A unique identifier for this particular occurrence of the issue in the source system", and audit-log traceability requirements.

Initial application:
No core FHIR source commit mentioning FHIR-45310 was found. The apparent application is in the HL7/fhir-extensions checkout: commit 0e90d0ca3705df6f6fc10264e69e511200f7b3d4 adds StructureDefinition-operationoutcome-instance-id.xml with URL http://hl7.org/fhir/StructureDefinition/operationoutcome-instance-id, context OperationOutcome.issue, value type string, max 1, and wording matching the Jira resolution.

Additional context:
The originating Zulip thread shows the practical support-ticket/audit-log need, the concern that OperationOutcome.id is transient, and Grahame's note that operationoutcome-message-id identifies the source message rather than the desired issue occurrence. FHIR-I minutes on 2024-04-29 record that X-Request-Id did not fit, and minutes on 2024-05-06 record the decision to add instanceId as a 0..1 extension. The current core OperationOutcome page links its Extensions tab to the Extension Pack, where the new extension is present in the CI build, so duplicating the extension source or adding rejected header guidance in core would be the wrong build surface.

This commit intentionally makes no core source change. It records that the requested source artifact belongs to the FHIR Extension Pack and has already been applied there; the core checkout is not the right place to add a duplicate OperationOutcome instance-id extension or X-Request-Id narrative.
