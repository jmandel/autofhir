FHIR-7004: Audit lifecycle status cleanup

Issue request:
FHIR-7004 was a Published FHIR-core/MnM DSTU1 change request with a Persuasive with Modification resolution. It reported that the May 2015 lifecycle table had many Status entries reading "Unknown - not stated by committee" and resolved to add that concern to QA criteria and address it before DSTU2 publication.

Initial application:
The Jira comment cites svn revision 5935. In git history, that revision is preserved as 5afc2790463eed7e4191e9ce13d5369b29b89537, which updated source/lifecycle.html by adding the note that resources omitted from the entered-in-error table have no explicit documentation for that case. The sibling lifecycle-table issue FHIR-7448 also records svn revision 5535, preserved as da3856859e16179bd5c47577e86dd68e2dda2bcf, which added ResourceValidator entered-in-error inference and QA hint logic so missing status handling surfaced during generation.

Additional context:
The current source/lifecycle.html page is still in build scope through source/hierarchy.xml and source/documentation.html. It no longer contains the obsolete "Unknown - not stated by committee" wording; instead, it describes lifecycle categories, uses generated status-code lists and an enteredInErrorTable placeholder, and keeps the note for resources omitted from the table. Existing combined-branch audits for FHIR-7448 and FHIR-7364 already cover the same lifecycle-table generation/QA family, so this audit does not duplicate those issue decisions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested cleanup and QA treatment were applied historically, current source and rendered CI output no longer expose the stale unknown-status rows, and adding redundant prose would not fix a current implementer-facing defect.

Recommendation:
Keep this audit commit as-is. Future lifecycle work should be resource-specific if a work group wants to change a particular status value set or entered-in-error mechanism; FHIR-7004 itself does not require a current core source edit.
