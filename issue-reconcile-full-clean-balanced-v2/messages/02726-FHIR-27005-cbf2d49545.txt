FHIR-27005: Audit Organization contact period

Issue request:
FHIR-27005 was a Published/Persuasive PA change request for R5 asking that Organization contacts be able to carry the period during which a contact fulfilled a role. Its final resolution says the request is satisfied by FHIR-29034 changing Organization.contact to 0..* ExtendedContactDetail, because ExtendedContactDetail has a period element.

Initial application:
The change was applied through the ExtendedContactDetail migration. Commit a9d7aa77e88c7070371eabb413aa4f91101d07fb changed Organization.contact from a BackboneElement to ExtendedContactDetail and explicitly referenced FHIR-27005. Commit 276625857dcd2e40ebf6e01ada8cf5e4c0d9b60b refined the Organization and ExtendedContactDetail narrative for the same change family. Commit e1320848bd2700338a2a11b634693d52f9fb8ad1 later kept the contact migration while removing deprecated top-level Organization telecom/address elements.

Additional context:
FHIR-29035 created the ExtendedContactDetail datatype with purpose, name, telecom, address, organization, and period fields. FHIR-29034 is already represented on the combined branch by no-change audit commit 05d270cd91a76b0b14e1a906810d5137bba4c28e, which records Organization.contact's migration to ExtendedContactDetail and lists FHIR-27005 as a supporting decision. PA minutes from 2021-12-01 state that the previous Organization/contact trackers addressed FHIR-27005. Zulip searches for the issue key and Organization.contact period terms found no conflicting discussion.

AutoFHIR reconciliation:
No source change was made. Organization is active in source/fhir.ini, ExtendedContactDetail is an active metadata datatype, current source/organization/structuredefinition-Organization.xml defines Organization.contact as 0..* ExtendedContactDetail, and source/datatypes/extendedcontactdetail.xml defines ExtendedContactDetail.period as 0..1 Period.

Recommendation:
Keep this no-change audit commit as-is. The current source already supports Organization contact periods through ExtendedContactDetail; adding a parallel Organization-specific period element or redundant prose would risk drift from the datatype source of truth.
