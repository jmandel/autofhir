FHIR-15568: Audit Resource References reason example

Issue request:
FHIR-15568 was a Published FHIR-core change request with a Persuasive with Modification resolution. It asked to replace a Resource References example that said a Condition referenced a Procedure as its "cause", because neither resource used that term. The accepted resolution chose option A: a Procedure references a Patient as subject and has a Condition as its reason, with no inherited subject context for the Condition.

Initial application:
The issue was applied in SVN revision 14243, represented in git as 4a1d157a612c3768fa5de98522667a5454205efe, which changed source/references.html from the old Condition/Procedure "cause" wording to the Procedure/Condition "reason" framing. That first edit accidentally left the second linked resource as Procedure; later published typo work, especially FHIR-19931 in commit c8d7378a9c00c8e8249b23a93c75d668ad86e626, corrected the example to link and name Condition.

Additional context:
source/references.html is the authoritative source page for the active Reference type page, as shown by source/fhir.ini's type-pages mapping reference=references. Related published typo issues FHIR-19931, FHIR-19526, FHIR-24048, and FHIR-37658 concern the same accidental Procedure-vs-Condition residue and already have audit commits on the combined branch. Later edits to the references page preserved the FHIR-15568 semantics. Zulip and Confluence searches found no conflicting discussion.
