FHIR-13645: Audit quantity search example parameter names

Issue request:
FHIR-13645 was a Published/Persuasive FHIR-I technical correction from STU3 asking to fix examples for quantity parameter searches on the core search page. The Jira points to the Search queries Zulip thread where the error was identified: the examples used Observation?value= even though the numeric Observation search parameter is value-quantity.

Initial application:
The issue was applied in git commit 0f538629f08e9fd07c1521eda8e66acb884d1f5c (svn revision 12773, "#13645 - fix typo"), which changed the quantity search examples in source/search.html from Observation?value=... to Observation?value-quantity=.... Later source refactors preserved the corrected parameter name in the active search narrative.

Additional context:
The Jira-linked Zulip topic confirms that Joel Francis reported the invalid Observation value search examples, Eric Haas identified value-quantity as the correct numeric Observation parameter, and GF#13645 was created for the typo. Current source/hierarchy.xml and publish.ini include search.html in the active build, and source/observation/bundle-Observation-search-params.xml defines Observation-value-quantity with code value-quantity and type quantity. Later quantity-search clarifications, including FHIR-13646 and FHIR-19597, adjusted adjacent semantics but do not change the FHIR-13645 correction; both are already represented on the combined branch and should not be republished here.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No current source change is needed to satisfy the Published FHIR-13645 request.
