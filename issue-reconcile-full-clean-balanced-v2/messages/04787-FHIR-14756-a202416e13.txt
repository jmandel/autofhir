FHIR-14756: Audit sex assigned at birth LOINC guidance

Issue request:
FHIR-14756 was a Published/Persuasive STU3 Patient issue asking the Patient Gender and Sex section to add that LOINC 76689-9 could be used when representing sex assigned at birth as an Observation.

Initial application:
The request was applied by git commit 42c4df50f2, which inserted the LOINC 76689-9 Observation sentence into source/patient/patient-notes.xml. The Patient resource is active in source/fhir.ini, so this narrative is in current build scope.

Additional context:
Later Patient Administration/Gender Harmony work changed the model and guidance for sex and gender exchange. FHIR-29673 added SPCU and RSG guidance and kept the 76689-9 concept during the transition. FHIR-39203 then explicitly moved recommendations for exchanging these concepts out of the FHIR base spec and into the Gender Harmony Implementation Guide. The current Patient source now points sex assigned at birth/RSG exchange guidance to that IG, while the active Patient sex-and-gender example still shows LOINC 76689-9 as the RSG type code.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring the old 2018 Observation sentence would duplicate or partially supersede the later Gender Harmony guidance, and would conflict with the later decision to avoid keeping those exchange recommendations in the FHIR base Patient narrative.

Recommendation:
Keep this audit commit as-is. If the work group wants the current Patient page to expose LOINC 76689-9 directly again, that should be a new Gender Harmony/Patient Administration decision rather than a replay of the STU3 wording.
