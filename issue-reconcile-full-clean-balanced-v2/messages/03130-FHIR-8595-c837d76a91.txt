FHIR-8595: Audit Provenance participant codes

Issue request:
FHIR-8595 was a Published/Persuasive Security WG change request from DSTU1 asking FHIR-core Provenance to add the assembler and composer participant-role codes, using definitions already present in HL7 v3 ParticipationFunction.

Initial application:
The issue was applied in 2015. Commit 1ca8cc96 added assembler and composer to the Provenance spreadsheet, and follow-up commit 102e7011 moved them from the wrong place into the Provenance agent-role value set with the requested definitions.

Additional context:
The old inline core vocabulary has since been refactored. Current Provenance remains an active build resource, and Provenance.agent.type is bound to http://hl7.org/fhir/ValueSet/participation-role-type. That active value set includes http://terminology.hl7.org/ValueSet/provenance-agent-type, whose THO code system http://terminology.hl7.org/CodeSystem/provenance-participant-type contains both assembler and composer. Later FHIR-32519 intentionally simplified the participation-role-type value set while preserving the provenance participant type codes including Assembler and Composer.

AutoFHIR reconciliation:
No source change was made. The current build-scope source already exposes the requested codes through the active Provenance.agent.type binding and THO terminology content, and current Provenance examples continue to use the assembler code from the same code system.

Recommendation:
Keep this no-change audit commit. A core source edit would either duplicate THO terminology or reintroduce retired inline vocabulary; future changes to the code definitions should be handled in THO rather than by editing core FHIR source.
