FHIR-38892: Audit removed ICAO sex or gender terminology

Issue request:
FHIR-38892 was a Published FHIR-core technical correction resolved Persuasive for R5. It reported that code M in ICAOSexOrGender had the wrong definition and should say that a value corresponding to male ('M') has been recorded; the final Jira resolution instead says InternationalEquivalentRecordedSexOrGender will be removed from the model, with comments noting the original M-definition correction became unnecessary because FHIR-39193 would remove the internationalEquivalent element.

Initial application:
The issue appears to have been applied before this reconciliation by core commit 2955956df2e4fcd1b456c4f0249f07ee6b6f2de7, titled FHIR-38892, FHIR-39193, which deleted source/patient/codesystem-international-civil-aviation-organization-sex-or-gender.xml and source/patient/valueset-international-civil-aviation-organization-sex-or-gender.xml. The same issue-tagged change family also includes Extension Pack commit bd62a3b5e6392bf1d7f21422ca4f9feb9b893196, which removed the internationalEquivalent slice from the current recordedSexOrGender extension source.

Additional context:
FHIR-39193 is a Published/Persuasive with Modification R5 issue whose resolution explicitly removed the internationalEquivilent element and deleted the ICAO value set and code system because they were only used by that extension property. It is already represented on the combined reconciliation branch by commit 05dcc6889b13562065378163a0c17291df01388c, so this commit does not separately decide FHIR-39193. Current core still has Patient examples and an OID assignment referencing the individual-recordedSexOrGender extension, but those references are not the removed internationalEquivalent slice or the ICAO terminology. Current searches of core source and the read-only Extension Pack input found no remaining ICAOSexOrGender, international-civil-aviation-organization-sex-or-gender, or internationalEquivalent source to correct.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The defective code definition no longer exists in the current FHIR core build source because the whole ICAO CodeSystem and ValueSet were removed as part of the final FHIR-38892/FHIR-39193 resolution path; the related extension slice is also absent from the repository that now owns the extension definition.

Recommendation:
Keep this no-change audit commit as-is. No current FHIR core source edit is needed for FHIR-38892; restoring or editing the obsolete ICAO CodeSystem would conflict with the later published FHIR-39193 decision that removed the only extension property that used it.
