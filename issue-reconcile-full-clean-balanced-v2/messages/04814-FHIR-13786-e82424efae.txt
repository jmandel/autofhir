FHIR-13786: Audit Practitioner classification removal

Issue request:
FHIR-13786 is a Published/Persuasive with Modification PA change request from STU3 asking why the Practitioner classification extension was scoped to a specific organization unit when Practitioner has no organization context, and resolving to remove that extension because PractitionerRole.specialty covers the organization/location-specific specialty concept.

Initial application:
The issue appears to have been applied in git commit 78b39f30cd, which changed the Practitioner extension spreadsheet row from classification to !classification and added the note that the extension was removed because practitioner role specialty provides this detail. The old spreadsheet was later removed during the R4B source refactor, so the current build no longer has a practitioner-classification source definition.

Additional context:
Current source/fhir.ini lists practitioner and practitionerrole as active PA resources. Current PractitionerRole.specialty text describes specialty as the practitioner's functional role at an organization or location, and Practitioner.qualification says those role specialties are not defined on Practitioner. Later Published PA issues FHIR-25033 and FHIR-32497 further clarified the same specialty-vs-qualification distinction and are already represented on the combined branch. Historical release bundles under tools/history still contain the old extension, but those are archived release artifacts rather than current build inputs. The FHIR Extension Pack checkout also has no practitioner-classification definition.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active specification has already removed the Practitioner classification extension and now conveys the requested modeling rule through PractitionerRole.specialty and Practitioner.qualification. Editing historical release archives or adding redundant current prose would not improve the current build.

Recommendation:
Keep this audit commit as-is. No current FHIR core source work is needed for FHIR-13786; any future specialty modeling changes should be handled through new PA tracker decisions rather than reviving the removed Practitioner extension.
