Issue request:
FHIR-17824 was a Published/Persuasive FHIR-core change request for STU3. It asked to delete the ISO 21090 and Questionnaire-specific ordinal value extensions and define a single general ordinalValue extension with contexts Coding, Questionnaire.item.answerOption, CodeSystem.concept, and ValueSet.compose.include.concept.

Initial application:
The issue was applied by git commit 74a9269071f19ec5a6b7c3fa2bb21e67fb3aa753, whose subject is "GF#17824 + GF#17823: rationalise ordinal value extensions" and which changed the general, ISO 21090, and Questionnaire extension spreadsheets and related notes. A direct current-source check found no obsolete questionnaire-ordinalValue, codesystem-ordinalValue, valueset-ordinalValue, iso21090-CO-value, or core ordinalValue extension IDs remaining in active core profile/questionnaire/FHIRPath source.

Additional context:
FHIR-17350 had first merged several ordinal-value extensions into an ISO 21090-based extension, and FHIR-17824 then replaced that with the general ordinalValue extension. Later FHIR-24672 renamed ordinalValue to itemWeight for R5, and FHIR-33540 moved CodeSystem and ValueSet weighting from extension contexts to the defined concept property itemWeight. Current core source references the itemWeight extension through the extension-location macro and defines the itemWeight concept property; the current extension definition source is now in the FHIR Extension Pack, where ordinalValue is retained as retired/deprecated with the FHIR-17824 contexts and itemWeight is active with later contexts.

Recommendation:
Keep this audit commit as-is. No core-source follow-up is needed for FHIR-17824; future changes to the active extension definition should be made in the FHIR Extension Pack, and future terminology weighting changes should account for the current CodeSystem concept property model.
