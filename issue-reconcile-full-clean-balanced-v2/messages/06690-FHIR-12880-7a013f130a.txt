FHIR-12880: Audit CodeSystem content-mode rename

Issue request:
FHIR-12880 was a Published/Persuasive vocab change request for DSTU2 asking to rename the CodeSystem search parameter from 'content' to 'content-mode' to avoid the reserved 'content' name and to correct the CodeSystemContentMode code/value set spelling from 'examplar' to 'example'. Jira records the change as pre-applied, with vote 5-0-0 on 2018-07-19.

Initial application:
The historical implementation is commit 8af489d8ea45084a8691733cdcef333bc563ea1f, imported from SVN revision 11349, which changed the CodeSystem spreadsheet search parameter name from content to content-mode and changed examplar/Examplar to example/Example. The current source has since been refactored from the spreadsheet into generated resource XML, but the semantic changes remain present.

Additional context:
CodeSystem remains an active resource in source/fhir.ini, so the CodeSystem search-parameter bundle and content-mode terminology files under source/codesystem are in current build scope. Later final decisions FHIR-39163 and FHIR-51110 refined the definition of the example code but did not reverse FHIR-12880's spelling correction or the search-parameter rename. FHIR-53375 is a later unresolved proposal about the example definition and is not a final source-edit decision.

AutoFHIR reconciliation:
This audit commit makes no source change because current source already uses SearchParameter code content-mode for CodeSystem.content, contains the CodeSystemContentMode code example rather than examplar, and no current source occurrence of the old CodeSystem content search parameter or examplar code was found.

Recommendation:
Keep this no-change audit commit as-is. Any future change to deprecate or replace the example content-mode code should be handled through a final later tracker such as FHIR-53375, not by re-opening FHIR-12880.
