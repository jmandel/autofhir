Issue request:
FHIR-11909 is a Published/Persuasive with Modification FHIR-core CodeSystem clarification asking that list-mode code "changes" be defined as "A point-in-time list that shows what changes have been made or recommended.  E.g. a discharge medication list showing what was added and removed during an encounter" rather than the earlier wording that was hard to distinguish from "working".
