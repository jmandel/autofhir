FHIR-40710: Audit valueset-systemName deprecation

Issue request:
FHIR-40710 is an Applied/Persuasive Vocabulary issue asking to deprecate http://hl7.org/fhir/StructureDefinition/valueset-systemName. The approved resolution was to add text to the extension description and definition so the extension page says it is deprecated and directs users to http://hl7.org/fhir/StructureDefinition/display for a code system name in a value set definition, with structuredefinition-standards-status=deprecated.

Initial application:
No FHIR-core commit explicitly mentions FHIR-40710. Core extension definitions were moved out of the R5 source by dd468d4f17, so the authoritative valueset-systemName StructureDefinition is no longer in this checkout. The FHIR Extension Pack applied the tracker in 2d8d6741385f by adding deprecated standards status plus the requested description/definition note, then follow-up commits removed the stale trial-use status, added a standards-status reason, marked the StructureDefinition retired, and corrected the work group to vocab.

Additional context:
The Jan. 29, 2024 Vocabulary WGM minutes record FHIR-40710 as voted persuasive, matching the Jira snapshot. FHIR-40712 was discussed in the same meeting and removed the related valueset-systemRef extension, but that is a separate extension decision and is not decided by this commit. Current core still has the historical Device Safety ValueSet use of valueset-systemName that the Jira comment explicitly called out; changing that use to display is not a safe reconciliation hunk because the display extension is scoped to canonical elements while ValueSet.compose.include.system is a uri.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source file was changed because the requested source of truth is maintained in the FHIR Extension Pack and is already carrying the deprecation text and standards-status metadata requested by FHIR-40710.

Recommendation:
Keep this audit commit as-is for FHIR-core reconciliation. If the work group wants to remove or replace the remaining Device Safety ValueSet usage, or broaden the display extension so it can validly annotate ValueSet.compose.include.system, that should be handled as a separate follow-up because FHIR-40710 only approved deprecating the extension definition.
