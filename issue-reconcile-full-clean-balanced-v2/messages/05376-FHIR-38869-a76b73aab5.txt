FHIR-38869: Audit RequestOrchestration behavior guidance

Issue request:
FHIR-38869 was a Published, Persuasive with Modification FHIR-I change request for R5. It asked for more complete RequestOrchestration behavior guidance: how clinician choices among options are recorded, how resulting requests/events track back to the source RequestOrchestration, whether chosen component requests keep intent=option, when the RequestOrchestration becomes complete, whether groupIdentifier groups requests inside an orchestration, and when to use each compound-request pattern.

Initial application:

Follow-up basedOn issues addressed the tracking question: FHIR-40631 has already been audited on the combined branch as no-change because current source permits RequestOrchestration for the requested OO resources, FHIR-40633 added MedicationRequest.basedOn support, FHIR-40634 added Appointment/Encounter support, and FHIR-40632 recorded a Public Health no-change decision for ImmunizationRecommendation.
