FHIR-6982: Audit retired genetics link

Issue request:
FHIR-6982 was a Published/Persuasive FHIR-core Observation change request from the 2015 May ballot. It reported that the link http://hl7.org/fhir/StructureDefinition/geneticsAssessedCondition from the old Observation genetics profile page was broken, and the accepted resolution says the link was fixed.

Initial application:
No FHIR-6982-tagged source commit was found in the current core history. Historical release artifacts show the old DSTU2-era StructureDefinition/geneticsAssessedCondition definition existed with Observation context and a Reference(Condition) value, while later source history used the renamed DiagnosticReport-geneticsAssessedCondition canonical. Commit e1268717aec2 repaired genetics profile search expressions to use canonical extension URLs, and commit 3cfe12f1b4 later removed the outdated core genomics profiles, extensions, and examples.

Additional context:
Current source/fhir.ini has active Observation and DiagnosticReport resources but no active genetics profile entry, and current core source has no non-history reference to geneticsAssessedCondition, DiagnosticReport-geneticsAssessedCondition, or the old observation-genetics-cg-prf-1a page. Current Observation and DiagnosticReport narrative points implementers to the Genomics Reporting IG and GenomicStudy instead. A related FHIR-8036 audit is already present on the combined branch and records the same extension family as outside current core. The remaining assessed-condition extension source is in the separate FHIR Extension Pack, where DiagnosticReport-geneticsAssessedCondition is retired/deprecated and explicitly replaced by the Genomics Reporting Guide.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. The broken DSTU1/DSTU2-era Observation genetics link is not part of the current core build, and editing this repository would not change an active core artifact. The only current source for the old extension family is outside this checkout and already carries retired/deprecated replacement guidance.

Recommendation:
Keep this audit commit as-is for FHIR core. No core follow-up is recommended. If maintainers discover a current rendering or package issue for the retired assessed-condition extension, handle it in the FHIR Extension Pack or in historical publication maintenance rather than in the current core build.
