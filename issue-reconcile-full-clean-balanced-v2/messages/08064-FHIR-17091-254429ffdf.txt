FHIR-17091: Audit batch independent-action wording

Issue request:
FHIR-17091 was a Published/Persuasive with Modification FHIR-core Feed change request from STU3. It asked that the Bundle.type code for batch clarify that batch actions are independent rather than a generalized transaction-style group of actions.

Initial application:
The issue was applied by git commit f966cc2f53ee0413b8b60d8fada314d615cb9bc0, which changed source/bundle/bundle-spreadsheet.xml from "processed by a server as a group of actions" to "processed by a server as a group of independent actions." Later source refactoring migrated the Bundle type code system into source/bundle/codesystem-bundle-type.xml while preserving that wording.

Additional context:
FHIR-18526 later requested the same clarification and its Jira comment records that the text had already been fixed. In the current build, source/fhir.ini actively lists bundle=Bundle, and source/bundle/codesystem-bundle-type.xml is the active Bundle Type CodeSystem source. Community and Confluence searches found no substantive conflicting guidance.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current CodeSystem definition for the batch code already says it is processed "as a group of independent actions," which satisfies the approved clarification in the current source.

Recommendation:
Keep this no-change audit commit as-is. No additional FHIR core source edit is needed unless a later work-group decision changes Bundle.type batch semantics.
