FHIR-30087: Audit profile comparison guidance

Issue request:
FHIR-30087 was a Published FHIR-core/FHIR-I change request, resolved Persuasive with Modification for R5, asking to remove stale text in profiling section 5.1.0.22 that said "Todo: bring this into the build" in a draft DAF/QICore comparison paragraph. The final resolution was to create a Confluence page about profile comparison and replace the sentences after "Profiles can be compared to determine their compatibility" with a link to that page.

Initial application:
The issue appears to have been applied by git commit d4d902c684e4d3f9ef16b0cf8b35b1251d2fc21b, "Update language around comparing profiles", which removed the DAF/QICore draft comparison and TODO wording from source/profiling.html and replaced it with a link to the HL7 Confluence "Comparing Profiles" page.

Additional context:
FHIR-I minutes from 2022-02-28 record the modified decision to point to a Confluence page with instructions for profile comparison and to replace the paragraph. A preceding Zulip thread shows the application question and Lloyd McKenzie's guidance to drop the retired DAF reference and avoid copying a comparison into the spec when linking to maintained profile comparison guidance would suffice. The linked Confluence page exists and says the FHIR Validator includes tooling to compare Capability Statements, profiles, value sets, and code systems.

AutoFHIR reconciliation:
No source change was made. The current build source at source/profiling.html retains the first sentence, removes the stale TODO/DAF/QICore draft text, and links to the created Confluence page, which is the substantive outcome requested by the final Jira resolution.

Recommendation:
Keep this audit commit as-is. Future work should only revisit this if the external Confluence page is intentionally retired or if FHIR-I decides that comparison tooling guidance must move from Confluence into normative/core source.
