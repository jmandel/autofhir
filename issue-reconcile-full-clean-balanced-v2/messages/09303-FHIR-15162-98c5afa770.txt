FHIR-15162: Audit Observation focus application

Issue request:
FHIR-15162 was Published/Persuasive with Modification for STU3 Observation. It asked to add Practitioner and PractitionerRole to Observation.subject for observations about clinicians, but the approved disposition instead promoted the focal-subject extension to a core Observation.focus/focalSubject element with Reference(Any) and added guidance discouraging Observation when a more specific resource already fits.

Initial application:
The change was applied in the same February-March 2018 Observation focus issue family: git d06b52856c added Observation boundary and subject/focus guidance under a commit mentioning GF#1443, GF#5162, and GF#14863; git 5c093b94a9 renamed the new element from focalSubject to Observation.focus; and git 2cf093cbf3 explicitly referenced GF#15162 while adding the trach-care example that records the child as Observation.subject and the mother/caregiver as Observation.focus.

Additional context:
FHIR-14443 and FHIR-14863 shared the same approved focal-subject/focus resolution, and the linked 2018 Zulip discussion shows OO deliberately moved away from making Observation.subject Reference(Any) because that would blur Observation's scope. FHIR-15825 later increased Observation.focus from 0..1 to 0..*, explaining the current cardinality. FHIR-29930 later aligned Observation.subject with DiagnosticReport.subject by adding Practitioner and several other subject targets, but not PractitionerRole. FHIR-40335 later preserved and clarified the subject/focus/device guidance. Observation is active in the current build through source/fhir.ini.

AutoFHIR reconciliation:
Made no source change. The current authoritative source already contains Observation.focus as a Reference(Resource) element, the subject/focus narrative guidance, and the GF#15162 trach-care example. Observation.subject's current inclusion of Practitioner is explained by later FHIR-29930, while the absence of PractitionerRole from Observation.subject is not a missed FHIR-15162 edit because FHIR-15162's final decision used Observation.focus for this class of use case.

Recommendation:
Keep this audit commit as-is. Do not add PractitionerRole to Observation.subject for FHIR-15162; any future PractitionerRole subject expansion would need a separate final OO decision because the applied seed resolution and later history support using Observation.focus when the observed person or entity differs from the record subject.
