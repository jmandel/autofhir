Issue request:
FHIR-13820 was Published/Persuasive with Modification for STU3 by Vocabulary. It asked ValueSet $expand to support explicit version parameters for the value set definition and code system versions. The final resolution added a 0..1 input parameter for the business version of the value set definition and explicitly did not add a code-system version parameter at that time.

Initial application:
