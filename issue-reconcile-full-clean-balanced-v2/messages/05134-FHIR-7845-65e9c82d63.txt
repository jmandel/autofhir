FHIR-7845: Audit MedicationStatement RXR-2 mapping removal

Issue request:
FHIR-7845 is a Published/Persuasive Pharmacy change request from the 2015 May DSTU QA cycle asking to remove the MedicationStatement dosage site v2 mapping to RXR-2 Administration Site because MedicationStatement is a reported medication-use record rather than a v2 medication transaction concept.

Initial application:
The issue was applied during the DSTU QA process. Git history shows commit 5bb461af1063efe577bac2b8b17b6992be7560bf explicitly included tracker item 7845 and removed the historical MedicationStatement.dosageInstruction.site v2 mapping value `RXR-2-Administration Site` from the MedicationStatement spreadsheet source.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. The old MedicationStatement.dosageInstruction.site element no longer exists after later dosage refactoring; current MedicationStatement.dosage is typed as DosageDetails and the current MedicationStatement StructureDefinition declares only one resource-level v2 element mapping, MedicationStatement.subject to PID-3. The generic Dosage datatype still has an RXR-2 mapping for Dosage.site, but that is not a MedicationStatement-specific resource mapping and changing it would affect other medication contexts where RXR-2 remains valid. Zulip and Confluence searches found no later community discussion contradicting the Jira/source conclusion, and the current rendered build page has no RXR-2 or Administration Site hit for MedicationStatement mappings.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current MedicationStatement source already reflects the FHIR-7845 decision by omitting the RXR-2 Administration Site mapping from MedicationStatement.

Recommendation:
Keep this audit commit as-is. No follow-up core source work is needed for FHIR-7845 unless a future Pharmacy work-group decision wants a new MedicationStatement-specific v2 mapping policy distinct from the generic Dosage datatype mappings.
