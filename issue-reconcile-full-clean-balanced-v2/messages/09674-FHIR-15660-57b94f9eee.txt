FHIR-15660: Audit Questionnaire unit choices

Issue request:
FHIR-15660 was a Published/Persuasive FHIR-core Questionnaire issue raised against STU3. It asked to allow a list of permitted units for numeric Questionnaire items, because some forms let users choose among units such as kg and pounds; the resolution also clarified that questionnaire-unit is only for integer and decimal items when converting answers into Quantity during extraction.

Initial application:
The issue was explicitly applied in git commit 6ad07d308d7e7e08a07ee5d136f849941d01ab7d, which corresponds to svn revision 13425 cited in the Jira comments. That commit updated the old core Questionnaire extensions spreadsheet to expand questionnaire-unit's definition for integer/decimal extraction and to add unit-option and unit-valueSet extension rows for quantity item unit choices. Later source rework and naming conventions carried those rows forward as questionnaire-unitOption and questionnaire-unitValueSet.

Additional context:
Questionnaire is still active in the core build, and the active item-type value set composes the Questionnaire item-type code system. Current core source now only has the canonical OID entries and item-type guidance that points quantity items to questionnaire-unitOption and questionnaire-unitValueSet, while decimal and integer still point to questionnaire-unit. Core commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed the Questionnaire extension StructureDefinitions from R5 core source, and the current FHIR Extension Pack source includes the authoritative definitions. Those Extension Pack definitions preserve the FHIR-15660 split: questionnaire-unit is constrained to integer/decimal Questionnaire items or ElementDefinition integer/decimal types, and questionnaire-unitOption/questionnaire-unitValueSet are constrained to quantity items or ElementDefinition Quantity types. Later related decisions FHIR-20394, FHIR-34391, and FHIR-37363 refined the same extension family and are already represented on the combined branch.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No core source change is necessary because the current build-scope core source and the authoritative Extension Pack definitions already implement the unit-list capability and the questionnaire-unit integer/decimal clarification requested by FHIR-15660.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-15660; future changes to questionnaire-unit, questionnaire-unitOption, or questionnaire-unitValueSet definitions should be made in the FHIR Extension Pack unless a new tracker asks for core narrative or terminology changes.
