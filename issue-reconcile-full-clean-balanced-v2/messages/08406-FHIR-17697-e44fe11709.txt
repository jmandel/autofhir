Additional context:
The current build source uses source/resource/operationdefinition-Resource-validate.xml for the Resource $validate operation, with Resource active in source/fhir.ini. Later issue FHIR-39526, already represented on the combined branch, explicitly added the validator parameters including `level` to $validate.

AutoFHIR reconciliation:

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-17697 unless the work group separately reopens the later FHIR-39526 `level` parameter naming or semantics.
