FHIR-17208: Audit Questionnaire display-category help history

Issue request:
FHIR-17208 was a Published FHIR-core Questionnaire change request, resolved Persuasive for STU3, asking for item-specific help associated with Questionnaire items. The approved resolution was to add a help code to the questionnaire-display-category extension with wording that help provides additional guidance on populating the containing item and may be rendered by fly-over, pop-up, button, link, or similar mechanisms.

Initial application:
The issue was applied in core by dccbce4bf6/GF#17208, matching Jira's svn revision 14070 comment. That commit added the help concept and the approved definition to source/questionnaire/codesystem-questionnaire-display-category.xml, which was then an active core terminology artifact.

Additional context:
A later final decision, FHIR-24117, was Published/Persuasive for R5 and explicitly resolved the overlap between questionnaire-display-category help and questionnaire-item-control help by removing help from display-category. Core commit 17fa4f6e5e applied that reversal, and dd468d4f17 later removed the Questionnaire extension terminology source files from the FHIR core checkout. Questionnaire remains an active core resource, but the display-category CodeSystem/ValueSet/extension are now maintained in the FHIR Extension Pack. The current Extension Pack display-category CodeSystem has instructions/security/legal only, while questionnaire-item-control still has help for help-button rendering. Zulip discussion before and after FHIR-24117 is consistent with using nested display items and itemControl=help rather than restoring a displayCategory help code.

AutoFHIR reconciliation:
This is an empty audit commit. No core source was changed because FHIR-17208 was initially applied, its display-category help code was later intentionally superseded by FHIR-24117, and the current external terminology source already reflects that later approved state.

Recommendation:
Keep this audit commit as-is. Do not reintroduce help into questionnaire-display-category in core; any future clarification of displayCategory or itemControl should be made against the Extension Pack source and should account for FHIR-24117's removal decision.
