FHIR-32542: Audit ConceptMap product explanation

Issue request:
FHIR-32542 was Published/Persuasive for R5 and asked for a better explanation of ConceptMap2.group.element.target.product, replacing the old additional-outcomes definition with wording that product is ConceptMap output providing additional values relevant to interpreting the mapping target.

Initial application:
The requested definition was applied in git commit 8623473ddf when ConceptMap2 was folded back into ConceptMap. The same issue family also produced the ConceptMap dependsOn/product usage-note work tracked by FHIR-31515, which is now present in the active ConceptMap notes.

Additional context:
ConceptMap is active in source/fhir.ini. Later R5 ConceptMap work, especially FHIR-40504 and its follow-ons, split mapping properties from additional source/target data attributes and intentionally reframed product values as output data attributes rather than properties or guidance about the map itself. The current source therefore no longer exactly matches the earlier FHIR-32542 sentence, but it preserves the approved product-as-output meaning and adds the explanatory example the Jira comments expected.

AutoFHIR reconciliation:
Made no source change. The current active StructureDefinition defines product as the output of a ConceptMap that provides additional target data values, and the ConceptMap notes explain dependsOn/product with a table example plus $translate behavior. Reverting the later wording to the earlier exact sentence would conflict with the later property/additionalAttribute clarification.

Recommendation:
Keep this audit commit as-is. The seed request is satisfied in current source; any future editorial cleanup of the later product wording should be handled separately from FHIR-32542 so it can account for the FHIR-40504 model split.
