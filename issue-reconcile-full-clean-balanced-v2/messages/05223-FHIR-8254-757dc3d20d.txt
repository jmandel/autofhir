FHIR-8254: Audit Goal observation link

Issue request:
FHIR-8254 was Published with a Persuasive with Modification disposition for the DSTU1 core Goal issue "CliniciansonFHIR: Goal - link to goal observation". The request was to link an Observation to the Goal it measures against; Jira comments say this needed an extension from Observation to Goal and was a specialization of FHIR-6019, with the final resolution recorded as "As per 6019".

Initial application:
No source commit was found that explicitly names FHIR-8254. The Jira comment cites SVN #6806, which maps to git commit 8bd3bd917d537625fad908b5f0f6277d113b941e. That commit added the original pertainsToGoal extension row, including Reference(Goal) and requirements saying it would typically link Observations capturing measurements to evaluate a Goal to the Goal being evaluated.

Additional context:
FHIR-6019 is the parent/same-change-family issue for the common extension. FHIR-13895 later renamed/moved the extension to resource-pertainsToGoal; all core extensions were later externalized to hl7.fhir.uv.extensions; and the current FHIR Extension Pack contains the active resource-pertainsToGoal definition. FHIR-53828, already represented on the combined branch, added the current Goal narrative note after Goal.outcome removal. FHIR-48360 later confirms that the existing resource-pertainsToGoal extension remains the WG-supported mechanism rather than a new first-class Goal/Observation reference. FHIR-57447 is only a Submitted OO follow-up for Observation-side awareness text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Goal source is in build scope and already tells implementers that resource-pertainsToGoal is used for resources such as Observation related to measurement, achievement, or progress toward the referenced Goal; the extension-pack definition supplies the Goal reference target and the usage note needed for the original Observation-to-Goal link.

Recommendation:
Keep this audit commit as-is. Do not add redundant Goal prose or pre-empt Observation-side text under FHIR-8254; if OO later approves FHIR-57447, reconcile that separate issue against Observation narrative and the Extension Pack definition.
