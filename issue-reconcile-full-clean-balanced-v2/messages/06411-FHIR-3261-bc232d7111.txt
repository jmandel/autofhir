FHIR-3261: Audit Questionnaire example conformance wording

Issue request:
FHIR-3261 was a Published/Persuasive Patient Care change request for the core Questionnaire page. It objected that the example text saying a Questionnaire "SHALL be stored and communicated as a whole" used a conformance requirement where only an example was intended.

Initial application:
No explicit FHIR-3261-tagged source commit was found. Git pickaxe history shows the questioned wording was introduced in 6bf66c167ce30cc7fe9398849a898c25880cdb92, then 54ddc30bbb4ff904ff5e5c0f7cce9088b15b19c6 changed the sentence one day after the issue was created by replacing "the Questionnaire SHALL be stored and communicated as a whole" with illustrative wording that capturing the data in a Questionnaire "would be most appropriate."

Additional context:
The current build includes Questionnaire as an active resource in source/fhir.ini, and the current qversusr narrative in source/questionnaire/questionnaire-notes.xml no longer contains the SHALL statement. Targeted Jira, Zulip, and Confluence searches found no later related decision or community record that changes this conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies the issue by presenting the physician-agreed form scenario as an example of when Questionnaire capture may be appropriate, not as a conformance requirement.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-3261 unless Patient Care wants a broader editorial rewrite of the Questionnaire-versus-resources guidance.
