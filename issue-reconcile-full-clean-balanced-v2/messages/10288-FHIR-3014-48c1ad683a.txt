FHIR-3014: Audit summary flag marker display

Issue request:
FHIR-3014 was Published with a Persuasive with Modification resolution for an Initial Draft complaint that the paragraph-sign-looking marker appeared at the end of several short descriptions. The resolved intent was to keep indicating summary membership, but make the marker clearer and move/document it with the table view rather than leaving it embedded at the end of XML-style descriptions.

Initial application:
The application is visible in SVN revision 3245, imported as git commit b120d06e7b5e898e498bdef1a4fd58a48bbf30fa. That commit explicitly says it removed the summary marker from the XML view and added the logical table legend/description, matching the Jira comment.

Additional context:
The current build documentation still exposes the summary indication through the logical table Flags column. source/documentation.html links both Conformance Rules and Resource Definitions, source/formats.html documents the Flags column and the Sigma flag as the summary-set indicator, and source/conformance-rules.html examples display the Sigma marker in the Flags column rather than after the description text. A current source search found no StructureDefinition short values containing the old paragraph marker or Sigma marker.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current source already preserves the useful summary indication while avoiding the reported placement at the end of short descriptions, so another wording or rendering change would be redundant and outside the issue's non-substantive scope.

Recommendation:
Keep this no-change audit. Revisit only if the generated publisher output again appends summary glyphs to ElementDefinition.short/description text instead of rendering them in the table Flags column.
