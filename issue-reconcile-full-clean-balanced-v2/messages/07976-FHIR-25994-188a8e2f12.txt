FHIR-25994: Fix registry footer copyright mark

Issue request:
FHIR-25994 was Published/Persuasive for a non-substantive R5 correction to the FHIR registry tooling page. The Jira reported that http://hl7.org/fhir/registry/ had an outdated header/footer, a footer question-mark symbol, and missing/current-spec menu behavior; the accepted resolution was to make tooling pages outside the core specification visually distinct, use the proper logo, remove the search button, and adjust the footer.

Initial application:
No Jira-tagged implementation commit for FHIR-25994 was found in the local git history. The current registry source already has the FHIR logo header, an empty registry-specific nav area with no search control, and a page-specific title/footer, while the Jira's September 2022 comment says the build registry looked correct and the validator page was gone. An untagged September 2022 commit touched this registry file for the HL7 logo width but left the footer's replacement-character copyright mark in place.

Additional context:
FHIR-I minutes from 2020-05-11 assigned the issue to the FHIR Product Director/Grahame because the page is under product-director control rather than ordinary FHIR-I specification ownership. The static page is in current build/publish scope through publish.ini's [html] source=tools/html entry, and no tools/html validator page remains. Quoted Zulip and Confluence full-text searches found no additional conflicting community discussion.

AutoFHIR reconciliation:
Changed tools/html/registry/index.html so the footer uses the ASCII HTML entity &copy; instead of the U+FFFD replacement character. This preserves the existing registry-specific header/nav/footer treatment while removing the visible garbled question-mark-style footer symbol that the Jira explicitly called out.

Recommendation:
Keep this source fix as-is. Further redesign or relocation of the registry/support tooling pages should remain a Product Director or work-group decision, but no additional core source change is needed for the published FHIR-25994 request.
