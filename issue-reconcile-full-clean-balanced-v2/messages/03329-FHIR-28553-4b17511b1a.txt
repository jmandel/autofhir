Issue request:
FHIR-28553 was a Published/Persuasive with Modification vocab change request asking that MED-RT be added to the FHIR Code Systems page, that NDF-RT information be updated because NDF-RT was no longer maintained, and that the Using MED-RT page explain MED-RT relationships to external code systems and when ConceptMap resources are needed.

Additional context:
source/terminologies-systems.html remains in the current core build through source/hierarchy.xml and publish.ini. Its current MED-RT row uses http://va.gov/terminology/medrt, links to NLM source documentation and THO's MEDRT usage page, and no longer contains an NDF-RT row. Later source history explains that state: FHIR-34074 corrected the MED-RT URI, FHIR-35800 updated the adjacent NDF-RT/MED-RT wording, FHIR-35933 moved the local external terminology usage pages out of core and linked the table to THO usage pages, and FHIR-39156 removed the retired NDF-RT row. Current THO pages preserve the FHIR-28553 MED-RT usage notes and the NDF-RT retirement note.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active core Code Systems page already satisfies the core part of the request, and the detailed MED-RT/NDF-RT usage guidance now lives on THO pages linked from core. Re-adding the removed core medrt.html page or the retired NDF-RT table row would conflict with later approved terminology maintenance.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-28553; future edits to detailed MED-RT or NDF-RT usage guidance should be made in THO unless a later core tracker explicitly changes the Code Systems page.
