FHIR-8438: Restore identifier systems documentation link

Issue request:
FHIR-8438 was a Published/Persuasive DSTU1 request to make identifier systems discoverable from the Documentation page or Systems page, because they had become buried under the data types page. The applying editor requested cross-reference between coding and identifier system pages and a primary Documentation page reference.

Initial application:
The issue was applied in svn revision 5912, imported as git commit 406f6e71752058c23aeabbdd9e0eff46c168d41f, which added Identifier Registry to source/documentation.html and cross-linked source/terminologies-systems.html and source/identifier-registry.html. A 2017 Documentation Index reorganization, commit ec7f976bd4e36e78630215dc696bc718b516b0ab, collapsed the Terminologies section to Code Systems and Value Sets and dropped the Identifier Registry link.

Additional context:
The identifier-registry page remains in current build scope through source/hierarchy.xml and now directs readers to HL7 Terminology for actively curated identifier systems after FHIR-35932. FHIR-37853 later removed the Code Systems page's identifier-system cross-reference because external code and identifier system source-of-truth content belongs in THO, so this reconciliation does not re-add that cross-reference. FHIR-53786 is a later unresolved/triaged proposal to rename and further revise the identifier registry page, so its requested label changes are not applied here.

AutoFHIR reconciliation:
Added a direct Known Identifier Systems link, with the same informative flag pattern as neighboring terminology links, under the Documentation Index Terminologies section in source/documentation.html.

Recommendation:
Keep this commit as-is. It restores the durable Documentation Index navigation requested by FHIR-8438 while respecting later THO migration decisions that removed detailed identifier-system listings and the old Code Systems page cross-reference.
