FHIR-11165: Audit retired ClinicalImpression code wording

Issue request:
FHIR-11165 was a Published/Persuasive Patient Care change request for the DSTU2-era ClinicalImpression resource. It asked to reword ClinicalImpression.code from the short description "Kind of impression performed" to "Kind of assessment performed" because a clinical impression is the outcome of a clinical assessment.

Initial application:
The request appears to have been applied by bd9f60dbffee762fd2b3e49ee2e07e232b9685a9 on 2016-10-28. That commit changed the ClinicalImpression spreadsheet short name and definition from "impression" to "assessment", and the checked-in release3 history now shows ClinicalImpression.code with short "Kind of assessment performed" and definition "Categorizes the type of clinical assessment performed.".

Additional context:
The current core build no longer has an active ClinicalImpression resource in source/fhir.ini, and the later ClinicalAssessment files are also not active in the core resource list. Current ClinicalImpression and ClinicalAssessment source files contain no ClinicalImpression.code or ClinicalAssessment.code element to reword. FHIR-46596 later renamed ClinicalImpression to ClinicalAssessment for R6, and the current resource guide points ClinicalAssessment to the external PC incubator IG rather than to a core resource page. Community searches found no FHIR-11165 Zulip or Confluence discussion and no conflicting rationale.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historic core artifact already carries the requested wording, and there is no current build-scope core ClinicalImpression.code element where the old short description could remain.

Recommendation:
Keep this audit commit as-is for core FHIR. If a current PC incubator ClinicalAssessment artifact reintroduces a code element, verify the wording in that external IG, but no current core source edit is indicated for FHIR-11165.
