FHIR-45339: Audit Observation value-string reconciliation

Issue request:
FHIR-45339 was Applied/Persuasive for R6 and asked to correct the invalid R5 Observation value-markdown search parameter by changing it to Observation-value-string, with an expression that originally included Observation.value.ofType(string) and Observation.value.ofType(CodeableConcept).text.

Initial application:
The source was partly applied before this reconciliation. Commit 02474e83d75 (FHIR-41002) renamed the surviving Observation-value-markdown entry to Observation-value-string and preserved the CodeableConcept.text arm, while commit 1582046563 later removed the duplicate Observation-value-string entry that had come from FHIR-41255.

Additional context:
Later Applied/Persuasive issue FHIR-52499 deliberately removed the CodeableConcept.text arm from Observation-value-string, relying instead on token :text behavior for CodeableConcept searches. Observation is an active resource in source/fhir.ini, so source/observation/bundle-Observation-search-params.xml is in current build scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source has exactly one Observation-value-string search parameter, no Observation-value-markdown search parameter, and no remaining ofType(CodeableConcept).text search expression, which is correct after applying FHIR-45339 together with the later FHIR-52499 decision.

Recommendation:
Keep this audit commit as-is. Do not re-add CodeableConcept.text for FHIR-45339 unless the work group reopens or supersedes FHIR-52499.
