FHIR-17889: Audit transaction reference rewrite wording

Issue request:
FHIR-17889 was a Published/Persuasive FHIR-core change request for STU3 asking the HTTP transaction processing rules to clarify when servers rewrite references after assigning ids in a transaction bundle. The accepted resolution changed the old "If the server assigns a new id ... as part of the processing rules above" wording to apply to resources with a POST method and to add a link to the Bundle uniqueness rules.

Initial application:
The issue was applied by git commit 2d798983db923914e9fa3ee8b630b59dfa9afc8b ("GF#17889 - not about ids in transaction"), which edited source/http.html to use the POST-method wording and added the bundle.html#bundle-unique link. The current source still contains that rule, with later wording from FHIR-34060 that names the FHIR create interaction while retaining the corresponding POST method.

Additional context:
source/http.html is an active page registered in publish.ini, and the linked bundle.html#bundle-unique anchor is present in source/bundle/bundle-notes.xml. FHIR-34060 later clarified the same transaction-processing section to use FHIR interaction names instead of only HTTP verbs, so the current "create (POST)" wording is a valid refinement rather than a regression. FHIR-27742 later concluded that no additional transaction fullUrl/reference clarification was needed beyond other resolved trackers. Direct Zulip and Confluence searches for FHIR-17889 found no conflicting community record.

AutoFHIR reconciliation:
This audit commit makes no source change because the current build-scope source already implements the published resolution: it identifies create (POST) entries as the ids that may be reassigned, requires same-bundle reference updates, leaves external references untouched, and links to the Bundle uniqueness rules.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is recommended for FHIR-17889 unless a work group later reopens the broader transaction reference-resolution wording.
