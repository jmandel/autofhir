FHIR-16806 was a Published/Persuasive STU3 Vocab change request for ValueSet.expansion.contains.contains. The ballot comment said the hierarchy was not defined and asked for an illustration of what nested contains is for and how it should be used; the recorded resolution was to add an example from an existing value set such as questionnaire.item.type.

Initial application:
The issue appears to have been applied by git-svn commit f82e3c73beeeeed5c68cbcae84004e5952ae3f01 / svn r14770, a bundled GF#16806 ValueSet/ConceptMap clarification commit. That commit moved the nested contains explanation into a dedicated Hierarchical Expansions section and linked an example of a hierarchical expansion, using the then-current valueset-example-hierarchical artifact rather than literally adding a questionnaire.item.type example.

Additional context:
FHIR-16814 had introduced the hierarchy extension/example family that the GF#16806 application linked. Later Published Vocab issues FHIR-30702 and FHIR-30703 intentionally removed valueset-expand-group, valueset-expand-rules, and the valueset-example-hierarchical artifact because the extensions were underspecified. The current active ValueSet source still defines the meaning and limits of nested contains, and the active ValueSet examples still include valueset-example-expansion, a prepared expansion with nested contains used to group codes for UI navigation.
