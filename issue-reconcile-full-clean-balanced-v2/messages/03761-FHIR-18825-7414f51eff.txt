Issue request:
FHIR-18825 was a Published/Persuasive with Modification Patient Administration change request, raised against STU3 and applied for STU3. It asked to open Appointment.indication's reference target set beyond existing Condition and Procedure to include Observation, and the approved disposition also added ImmunizationRecommendation.

Initial application:
The original application appears in commit 87ce43db92, whose subject includes GF#18825 and says Appointment indication supports Observation references. That same Appointment change family also renamed the old indication/reason split toward reasonCode/reasonReference, and the duplicate FHIR-18828 records that the coded-or-referenced Appointment indication request was handled as part of FHIR-18825.

Additional context:
FHIR-18829 and the later R5 CodeableReference refactor changed the current source shape from Appointment.indication/reasonReference into Appointment.reason as a CodeableReference. FHIR-48869 later added DiagnosticReport to Appointment.reason. ImmunizationRecommendation is no longer an active core resource in source/fhir.ini, and commit e073fb45ec removed ImmunizationRecommendation from Appointment.reason and Appointment.basedOn after removing ImmunizationRecommendation and ImmunizationEvaluation from the current core build. A stale generated-looking Appointment SVG still shows the older ImmunizationRecommendation target, but the authoritative StructureDefinition source no longer does.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Appointment is active in source/fhir.ini, and the current Appointment.reason StructureDefinition includes Observation in its targetProfile list alongside the current Condition, DiagnosticReport, and Procedure targets. Re-adding ImmunizationRecommendation would point at a resource removed from the active core build, and editing only the stale SVG/diagram artifact would not be an authoritative source correction for this issue.

Recommendation:
Keep this no-change audit commit as-is. No core source fix is needed for FHIR-18825; any future cleanup should regenerate or review stale diagram artifacts separately rather than reintroducing removed ImmunizationRecommendation references into Appointment.reason.
