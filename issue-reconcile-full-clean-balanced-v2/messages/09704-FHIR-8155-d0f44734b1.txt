FHIR-8155 was a Published/Persuasive FHIR-core ValueSet change request from the 2015May DAF ballot. It asked to fix generated ValueSet narrative that said a single CVX include used "other code systems," even though the CDC URL listed only CVX codes.

Initial application:
The issue was applied in svn revision 5971, represented in git by cdedb09f55bbf05c664b450ff53e6792b9e456ca, which changed the old Java NarrativeGenerator wording from "codes defined in other code systems, using the following rules" to clearer "codes from the following code systems" wording and fixed the include filter list initialization.

Additional context:
The original DAF CVX ValueSet source was later moved out of core source into the DAF guide area and then deleted from the repository in d451dd0741c0ea6435ebd305a93dea623c62a335.
