FHIR-7424: Audit ClinicalImpression assessment naming

Issue request:
FHIR-7424 was a Published / Not Persuasive with Modification Patient Care change request for DSTU1 ClinicalImpression. It asked to use ClinicalAssessment rather than ClinicalImpression and challenged the old rationale that ClinicalImpression avoided confusion with assessment tools. The final resolution kept the ClinicalImpression name but required the Scope and Usage section to clarify that an impression is a clinical summation and/or opinion formed as the outcome of the clinical assessment process, that ClinicalImpression may lead to a Condition, and that in FHIR an assessment is typically an instrument or tool used to collect patient information.

Initial application:
The issue was explicitly applied by ca8df34006df02f9b2a896eaf41a72e1d418fe9d, whose subject lists #7424 and which added the two requested Scope and Usage paragraphs to source/clinicalimpression/clinicalimpression-introduction.xml. The retained ClinicalImpression introduction still contains that clarification.

Additional context:
Later Patient Care decisions changed how the old no-rename decision should be read. FHIR-11290 was withdrawn after similar ClinicalImpression naming discussion, and FHIR-18859 was later Resolved - No Change after the submitter withdrew a similar concern. FHIR-46596 then superseded the old naming decision for R6 by renaming ClinicalImpression to ClinicalAssessment; that issue is already represented on the combined branch. FHIR-50192 later removed the invalid post-rename ClinicalAssessment-rather-than-ClinicalAssessment rationale from the successor StructureDefinition. The later fad1b9cf84 remove-additional-resources commit removed ClinicalAssessment from active source/fhir.ini resource entries and changed active core narrative to link the resource to the PC incubator, so neither ClinicalImpression nor ClinicalAssessment is currently an active core resource page.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The exact FHIR-7424 clarification is already present in the retained historical ClinicalImpression source, the successor ClinicalAssessment source no longer has the old name-rationale sentence, and current active core source does not build either resource as a core resource. Editing the retained ClinicalImpression StructureDefinition or out-of-build ClinicalAssessment source would not improve the current core specification and would risk conflicting with the later R6 rename and incubator move.

Recommendation:
Keep this empty audit commit as-is. No core source follow-up is needed for FHIR-7424; if the successor ClinicalAssessment artifact is maintained or reintroduced, preserve the distinction between assessment process/output and assessment instruments without reintroducing the obsolete ClinicalImpression-versus-ClinicalAssessment rationale.
