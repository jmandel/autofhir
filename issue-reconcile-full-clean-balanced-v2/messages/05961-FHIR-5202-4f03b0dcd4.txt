FHIR-5202: Audit EpisodeOfCare problem wording

Issue request:
FHIR-5202 is a Published/Persuasive PA change request from the January 2015 ballot for FHIR-core EpisodeOfCare. It asked to replace the EpisodeOfCare/Encounter boundary phrase "a specific problem/issue" with "problems/issues" because an episode can address multiple problems and the resource already allowed repeating condition-related content.

Initial application:
The issue appears to have been applied before this reconciliation by the March 25, 2015 source commit f659c3fbc16870414aac80f798d75afcb5480bf8, "Ballot reconciliation updates for EpisodeOfCare." Git pickaxe shows that commit removed the original "a specific problem/issue" wording from source/episodeofcare/episodeofcare-introduction.xml and added the requested "problems/issues" wording. The commit did not mention FHIR-5202 explicitly, but it is the direct historical source change for the requested text.

Additional context:
EpisodeOfCare is active in source/fhir.ini, and the relevant narrative file is in the active source/episodeofcare resource folder. Later source edits changed adjacent wording, including "patient" to "patient(s)," but they left the FHIR-5202 plural problem wording intact. A broader exact-wording Jira search also surfaced FHIR-3915, another Published EpisodeOfCare/Encounter boundary issue, but it concerns clarifying linkage direction and was not needed to decide the FHIR-5202 pluralization request.

AutoFHIR reconciliation:
No source change was made. The current source/episodeofcare/episodeofcare-introduction.xml already says the EpisodeOfCare container can link encounters "together for problems/issues," and source/episodeofcare/structuredefinition-EpisodeOfCare.xml still permits repeating reason/diagnosis condition-related content, so the current build source preserves the requested semantics.

Recommendation:
Keep this empty audit commit as-is. No FHIR core follow-up is needed for FHIR-5202 unless a future PA decision reopens the broader EpisodeOfCare/Encounter boundary wording.
