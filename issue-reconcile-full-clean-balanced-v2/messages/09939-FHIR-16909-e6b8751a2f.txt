FHIR-16909: Audit Bundle.fullUrl URI wording

Issue request:
FHIR-16909 was a Published FHIR-core/FHIR-I change request, resolved Persuasive with Modification, asking that Bundle.entry.fullUrl's short wording stop saying only "Absolute URL" while giving UUID/OID examples and instead say "URI for resource (URL server address or UUID/OID)".

Initial application:
The Jira records the application as "svn 14375". No current git commit with FHIR-16909 in the message was found, but the active Bundle source now defines Bundle.entry.fullUrl with type uri and a short description of "URI for resource (e.g. the absolute URL server address, URI for UUID/OID, etc.)", which preserves the requested URI/URL/UUID-OID distinction and fixes the stale parenthetical wording.

Additional context:
Bundle is an active build resource in source/fhir.ini. Later Bundle.fullUrl work, especially FHIR-31422 and FHIR-29271, refined the same area by adding the "e.g." examples and clarifying that Bundle.entry.fullUrl can be an arbitrary URI, so the current wording should not be rolled back to the narrower 2018 text. FHIR-26599 is related but still Waiting for Input, so it is not a final source-edit decision for this audit.
