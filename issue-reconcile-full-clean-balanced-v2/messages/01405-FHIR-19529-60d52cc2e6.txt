Issue request:
FHIR-19529 was a Published FHIR-core Contract change request, resolved Persuasive with Modification, asking Contract guidance to say that where the Consent resource applies, Consent should be used, and where a Contract exists for a consent directive and a Consent also exists, the Consent shall reference the Contract.

Initial application:
The issue appears to have been applied by commit 92de6d6cfb9cb5aa33e42a37f2a489b9e10b069f, whose "GF #19529" patch inserted the approved Consent/Contract sentence into source/contract/contract-introduction.xml. The current source still contains that sentence verbatim, and source/fhir.ini lists both Contract and Consent as active resources in the current build.

Additional context:
Current Consent source permits Consent.sourceReference to target Contract, so the direction required by the Jira resolution is supported by the resource model. A later FHIR-55563 branch removes Contract from R6, but that issue is only Resolved - change required and its implementation commit is on origin/Branch_55563, not an ancestor of this current source branch, so it is context rather than a current-build reversal of FHIR-19529.
