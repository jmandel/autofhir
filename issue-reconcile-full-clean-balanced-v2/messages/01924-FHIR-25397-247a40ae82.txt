FHIR-25397: Audit AdverseEvent encounter wording

Issue request:
FHIR-25397 was Published/Persuasive for the Patient Care AdverseEvent resource and requested that AdverseEvent.encounter use the short description "The Encounter associated with the start of the AdverseEvent", the same longer definition, and comments explaining that the associated encounter is where the event-triggering activity occurred rather than a later reporting encounter.

Initial application:
The Jira comment points to commit faf138c4d650f25e2afb3d1d86f7a8dfac2cd07b, which applied the requested AdverseEvent.encounter wording to the then-authoritative source/adverseevent/adverseevent-spreadsheet.xml. Later source refactoring in 33b409a4b6 moved AdverseEvent to source/adverseevent/structuredefinition-AdverseEvent.xml, preserving the text, and 086649a235 added the Event mapping exception file with the same AdverseEvent-specific wording.
