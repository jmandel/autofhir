FHIR-7570: Audit Provenance entity agent clarification

Issue request:
FHIR-7570 was a Published/Persuasive with Modification DSTU1 Security tracker asking to clarify how Provenance.entity.agent relates agents, source entities, and the Provenance activity. The accepted resolution was to add a note explaining that Provenance.entity.agent is for cases where the used entity is under different custodianship from the target and this agent provided access to that externally managed entity.

Initial application:
The requested note was applied in git commit 2522cb1492a0be6fa89becaaa0611cf6490cbd20, which updated the historical Provenance spreadsheet sources for CP 7570 and added the custodianship/provided-access comment on Provenance.entity.agent. Later source refactors imported and preserved that text in source/provenance/structuredefinition-Provenance.xml.

Additional context:
Provenance is an active current-build resource in source/fhir.ini, and the authoritative current StructureDefinition still carries the FHIR-7570 note on Provenance.entity.agent. A later Published tracker, FHIR-33228, changed the same element definition from "generated the entity" to "used the entity"; that later clarification is present and complements rather than reverses the FHIR-7570 note. Searches found no Zulip or Confluence evidence for FHIR-7570 that conflicts with the Jira/source/git conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already conveys the FHIR-7570 clarification in the active Provenance StructureDefinition, and adding more prose would be redundant.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-7570 unless the Security work group later decides to remove or remodel Provenance.entity.agent itself.
