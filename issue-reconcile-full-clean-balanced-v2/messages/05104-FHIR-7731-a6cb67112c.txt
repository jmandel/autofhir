FHIR-7731: Audit MedicationAdministration vaccine scope

Issue request:
FHIR-7731 was a Published/Persuasive with Modification Pharmacy DSTU1 clarification asking to replace MedicationAdministration Scope and Usage text that excluded vaccines. The accepted direction was to improve understanding of the vaccine boundary by saying the resource covered medication administration and by referring readers to Immunization for vaccine treatment, with Grahame's comment suggesting explicit mention of medications and vaccines.

Initial application:
The issue was explicitly applied in git commit 5555750a4cce94cd357c3178441d043caa13f1ca, whose message lists #7731 and #7732. That commit changed the active MedicationAdministration introduction from "with the exception of vaccines" to "all medications and vaccines" with an Immunization Resource/Profile reference, and it also updated the adjacent equivalent-Immunization wording for FHIR-7732.

Additional context:
MedicationAdministration and Immunization are active current-build resources in source/fhir.ini. Later Published Pharmacy issue FHIR-25538 retained the older "all medications and vaccines" scope sentence while refreshing MedicationAdministration definitions. Later Published Pharmacy issue FHIR-32960 then revisited the same inconsistency and clarified the current rule: Scope should direct vaccine administration to Immunization, while Boundaries allow MedicationAdministration for vaccination workflow or other reasons only when systems also create and expose an equivalent Immunization instance. FHIR-32960 is already represented on the combined branch by source-changing commit b7214bc5256739e402b4118bf12c9492f9291cbd, and FHIR-7732 is already represented there by an empty audit commit for the adjacent wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active MedicationAdministration page preserves the seed issue's key clarification by no longer excluding vaccines and by pointing vaccine treatment to Immunization; its boundary paragraph, aligned with the active Immunization page, reflects the later FHIR-32960 refinement. Reintroducing the literal "and vaccines" wording from the 2015 application would contradict the later approved clarification.

Recommendation:
Keep this empty audit commit as-is. No additional core source change is needed for FHIR-7731; the existing FHIR-32960 reconciliation should remain the current source authority for the MedicationAdministration/Immunization vaccine boundary.
