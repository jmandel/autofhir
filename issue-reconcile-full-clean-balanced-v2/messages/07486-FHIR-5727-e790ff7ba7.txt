FHIR-5727: Audit focal-subject modifier status

Issue request:
FHIR-5727 was a Published/Persuasive OO change request from DSTU1 asking that the Observation indirect target, later called focal-subject, be made a modifier extension because it changes interpretation of an Observation such as fetal heart rate in the mother's record.

Initial application:
The issue appears to have been applied in svn revision 7998, preserved as git commit 9d17fe9388, which changed the focal-subject row in source/observation/observation-extensions-spreadsheet.xml to mark it as a modifier. Related earlier work in FHIR-8379 renamed the confusing indirectTarget extension to focal-subject.

Additional context:
The current FHIR core build no longer carries the old extension as an active core definition. Observation is an active resource in source/fhir.ini, and the current authoritative source for Observation.focus marks the successor element isModifier=true with the reason that it changes who is the target of the observation. Later applied issue FHIR-37736 and commit 7a5dceb812 explicitly added that modifier flag to Observation.focus. The FHIR Extension Pack retains only a retired/deprecated observation-focusCode extension that directs users to Observation.focus, so no core source edit is needed for the retired extension.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current in-build core source already preserves the substance of FHIR-5727 by making Observation.focus, the current replacement for focal-subject/indirect target semantics, a modifier element.

Recommendation:
Keep this audit commit as-is for FHIR core. If the work group wants historical Extension Pack metadata for retired/deprecated observation-focusCode reviewed, that should be handled in the Extension Pack rather than by changing current core source.
