FHIR-7393: Audit List changes list wording

Issue request:
FHIR-7393 is a Published/Persuasive FHIR-I clarification for the core List resource, raised against DSTU1 section 6.1.4. It asked to remove the misleading phrase "The final mode -" from the List changes-list narrative and clarify that such lists can include added, deleted, and unchanged items while retaining the rule that a flag implying deletion SHALL be accompanied by the deleted element.

Initial application:
Commit 96be97f445754f44c0b4b221e698b98af635ff0d, the git-svn import of svn revision 5595, explicitly applied #7393 by changing "The final mode - a changes list" to "A changes list" in source/list/list-notes.xml. The same paragraph was then revised by the closely related FHIR-5308 application commit fef69018e60e6f10725d76622bfbd320e2ceb98a and later editorial QA commit 5eca64926ea59e8787586a606abb002475229daa, which explains why the current text does not exactly match the FHIR-7393 proposed wording.

Additional context:
The List resource is active in the current build via source/fhir.ini. Current source/list/list-notes.xml no longer contains "final mode" and still explains that a change list may include deleted items, with the deletion-flag safety rule retained. Later List guidance from FHIR-34442, already represented on the combined branch, changed related deleted-flag constraints but does not conflict with the FHIR-7393 clarification. Negative Zulip and Confluence searches found no community record that changes the Jira/source conclusion.
