FHIR-19955 was a Published/Persuasive technical correction for FHIR-core Conformance. It reported that the CapabilityStatement Schematron/XPath forms of cpb-16 and cpb-15 tested kind = instance even though the human text and FHIRPath expressions were for kind = requirements and kind = capability.

Initial application:
The issue was applied on the R4B line by commit 24acfad7c7, which changed the CapabilityStatement XPath constraints from instance to requirements/capability. The current mainline CapabilityStatement source did not carry that exact correction forward as XPath; instead commit 88a1f3d6bd removed XPath usage from ElementDefinition constraints before R5 publication.

CapabilityStatement is an active current resource in source/fhir.ini.
