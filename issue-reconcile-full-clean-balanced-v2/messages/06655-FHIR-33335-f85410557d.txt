FHIR-33335: Audit Questionnaire repeats guidance

Issue request:
FHIR-33335 was a Published FHIR-core change request with a Persuasive with Modification resolution. It asked for the base R5 QuestionnaireResponse profile to add a qrs-2 invariant requiring repeated question answers to be combined in one item's answer array, and for Questionnaire.item.repeats to explicitly distinguish repeating questions from repeating groups.

Initial application:
The Jira comments identify SDC pre-adoption followed by core commit 35809e0395. That core commit changed active Questionnaire and QuestionnaireResponse source files by rewriting Questionnaire.item.repeats guidance and adding the requested qrs-2 invariant to QuestionnaireResponse.item.

Additional context:
Questionnaire and QuestionnaireResponse are active resources in source/fhir.ini. The cited Zulip thread explains the expected model: repeating groups produce repeated items with the same linkId, while repeating questions remain a single item with multiple answers. The SDC minutes record the FHIR-33335 Persuasive with Modification vote. Later related decisions already represented on the combined branch refined the same area: FHIR-38853 clarified repeating-group/nesting guidance and FHIR-55973 made repeated question answers distinct while preserving the FHIR-33335 representation rule.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already contains qrs-2 with the requested FHIRPath expression, current Questionnaire.item.repeats text says repeating groups use multiple items with the same linkId and repeating questions use a single item with multiple answers, and later refinements do not undermine the original decision.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-33335 unless a future work group decision reopens the distinct-answer or repeating-group representation rules addressed by the later related issues.
