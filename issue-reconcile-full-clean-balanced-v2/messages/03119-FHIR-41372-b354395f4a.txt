FHIR-41372: Audit EventDefinition deprecation reversal

Issue request:
FHIR-41372 was Applied/Persuasive with Modification for R6 by the CDS work group. It asked to resolve the naming and boundary concern by deprecating EventDefinition in favor of SubscriptionTopic, leaving EventDefinition in place with a pointer to SubscriptionTopic as the preferred event-definition representation, and removing the prior implementation feedback question.

Initial application:
The issue was initially applied by commit 08d67eccc304ab6749d195a6837b0e848de3d299 from PR HL7/fhir#3864. That commit changed EventDefinition standards-status to deprecated/FMM 0 and replaced the earlier implementation feedback note with text saying EventDefinition had been deprecated in favor of SubscriptionTopic.

Additional context:
FHIR-41372 continued the deprecation direction already present in FHIR-21232. That direction was superseded shortly afterward by FHIR-53316, which was Applied/Persuasive for R6 and concluded that EventDefinition has use cases not covered by SubscriptionTopic. PR HL7/fhir#3943 removed the deprecation note, restored EventDefinition to normative/FMM 6, and added the current relationship explanation. The combined branch already contains a no-change audit commit for FHIR-53316.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source is correct because the later FHIR-53316 work-group decision supersedes FHIR-41372's deprecation outcome; reapplying the FHIR-41372 deprecation would make the current specification inconsistent with the later applied decision.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-41372 unless the work group reopens the EventDefinition/SubscriptionTopic boundary question again.
