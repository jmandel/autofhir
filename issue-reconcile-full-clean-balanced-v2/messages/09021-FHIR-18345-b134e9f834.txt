FHIR-18345: Audit extensibility example links

Issue request:
FHIR-18345 was a Published/Persuasive STU3 FHIR-core change request for the Extensibility page. It asked that all extension examples in the specification be linked to their definitions, because the page identified the patient-citizenship example as defined by the specification but did not equivalently link the earlier iso21090 EN-use example.

Initial application:
The issue was applied by Grahame Grieve's cd5231d416ef0145942d6a04f15d50d66640be98 commit, which Jira records as GH#cd5231d416. That commit edited source/extensibility.html to add a "see definition" link to the first iso21090 EN-use example and to the patient-citizenship example, linked the example canonical URLs, and removed the now-redundant sentence that only called out patient-citizenship.

Additional context:
source/fhir.ini maps the Extension type page to source/extensibility.html, so this narrative is part of the current core build. The current source still has definition links for both examples, now using the [%extensions-location%]StructureDefinition-... targets. The extension definitions themselves have moved out of core and are present in the FHIR Extension Pack, so their absence from core source is not a missing core change. Searches for FHIR-18345 in Zulip and Confluence found no directly relevant or conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Extensibility source already satisfies the applied issue by linking both example definitions, and adding more prose or relinking out-of-scope extension definitions would be redundant.

Recommendation:
Keep this empty audit commit as-is. No core follow-up is needed unless a future build change breaks [%extensions-location%] link generation for these Extension Pack definitions.
