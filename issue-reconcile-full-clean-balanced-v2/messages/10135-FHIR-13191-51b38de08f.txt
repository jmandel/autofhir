FHIR-13191: Audit history request wording

Issue request:
FHIR-13191 was a Published/Persuasive with Modification FHIR-I issue for STU3 asking the HTTP history interaction text to avoid implying that Bundle.entry.request.method always reports the original REST request verb. The accepted wording clarified that the request information describes the result of the interaction leading to the new version, allowing subscribers to distinguish newly created resources from updates to existing resources.

Initial application:
The issue was initially applied by SVN revision 12856, represented in git as 0617aa252793, which changed source/http.html from differentiating "create and update interactions" to differentiating newly created resources and updates to existing resources. That application touched the active HTTP history narrative source for http.html#history.

Additional context:
A later reconciliation for FHIR-7933, already represented on the combined branch, refined the same paragraph to align with current history Bundle rules. The current source now says the request describes the interaction, or an equivalent change outside the RESTful interface, that led to the new version. That later wording preserves FHIR-13191's accepted created-versus-updated distinction while making the facade/non-REST case clearer than the original proposed sentence. No directly relevant Zulip or Confluence record was found for FHIR-13191, and a stale-wording scan found no remaining active HTML source that still says the request differentiates REST create/update interactions.

AutoFHIR reconciliation:
Made no source change. The active source/http.html history section already conveys the accepted FHIR-13191 clarification, and changing it back to the exact Jira sentence would remove useful later clarification about equivalent non-REST changes.

Recommendation:
Keep this empty audit commit as-is. No further core source change is recommended for FHIR-13191 unless FHIR-I wants a new model-level change replacing request.method with an explicit created/updated/deleted event indicator.
