Issue request:
FHIR-6256 was Published/Persuasive with Modification for FHIR-core Provenance, raised against DSTU1. It asked Security to define Entity and explain how it differs from Agent, with examples, and the accepted resolution added W3C PROV-derived definitions for Target, Entity, Agent, and Activity to the Provenance introduction.

A follow-up QA commit, 1bd0700e1fea9a2e2a2c7c93cd0bcc31c9909037, adjusted capitalization and wording while preserving those definitions at that time.

Later Published issue FHIR-16051, already represented on the combined branch, intentionally removed the Target bullet from the W3C model list because Target is a FHIR Provenance concept rather than a W3C PROV model concept. Later Provenance decisions FHIR-23065, FHIR-55409, and FHIR-55410 refined the same explanatory text by clarifying .entity/.target input/output wording and updating Entity/Activity language.
