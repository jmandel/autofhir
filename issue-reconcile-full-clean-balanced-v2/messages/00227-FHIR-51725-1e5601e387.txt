FHIR-51725: Audit CompartmentDefinition param expectation

Issue request:
FHIR-51725 was Applied for R6 as Not Persuasive with Modification. The original request suggested invariants or warnings for CompartmentDefinition resources listed without param or documentation, but the final decision instead removed the non-computable documentation-membership sentence and clarified that resources listed with one or more .param elements are in the compartment while listed resources without .param are outside the compartment, with a note that _include, local convention, and operations such as $everything may still return outside resources.

Initial application:
The issue was applied before this reconciliation by git commit 1437864b65b76f69b8a3c6088a68f2e6704e50db, which changed source/compartmentdefinition/compartmentdefinition-introduction.xml to remove the CompartmentDefinition.resource.documentation inclusion sentence and add the approved param/no-param and outside-resource note. A later same-day cleanup commit 43747c8d2677f6fb34f73dc1454422feecdf17c8 only fixed the new list markup and nearby formatting.

Additional context:
FHIR-51603 had introduced the older resource.documentation sentence as part of clarifying search-parameter-based compartment inclusion, but the October 2025 Zulip discussion and November 2025 FHIR-I minutes record the later conclusion that no search parameter means not in the compartment and that non-compartment resources may still be returned or made available by include mechanisms, policy, or local convention. FHIR-51604 supports the same framing that HL7-defined CompartmentDefinition instances describe the official compartments while server-specific deviations are not computably represented. FHIR-51729 is a later same-artifact cleanup for unused CompartmentDefinition elements and is already represented on the combined branch.

AutoFHIR reconciliation:
No source change was made. The current build-scope CompartmentDefinition introduction already contains the approved R6 wording, source/fhir.ini actively includes CompartmentDefinition in the build, and a current source search found the old documentation-based membership sentence absent.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-51725 unless a separate work group decision changes how listed resources without .param should be interpreted.
