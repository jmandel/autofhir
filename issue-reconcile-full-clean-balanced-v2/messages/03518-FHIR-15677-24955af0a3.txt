FHIR-15677: Audit financial PractitionerRole reference updates

Issue request:
FHIR-15677 was Published/Persuasive for STU3 by Financial Management. It requested adding PractitionerRole, and in some cases Organization, to provider-like references across Claim, ClaimResponse, EligibilityRequest/Response, EnrollmentRequest/Response, ExplanationOfBenefit, PaymentNotice, PaymentReconciliation, ProcessRequest/Response, and VisionPrescription, while removing obsolete .organization or .requestOrganization elements where those roles were folded into the provider/request-provider reference.

Initial application:
The change was applied by git commit 9b28a51850883eb7f92e951742456b1d6b574ac8, "Tracker #15677", which updated the financial resource spreadsheets and examples. The historical patch shows the core mechanics, including replacing Claim.organization with Claim.provider in examples, adding PractitionerRole/Organization-capable provider references in the spreadsheets, and removing requestOrganization from response examples while using requestProvider for the responsible provider/requesting party.

Additional context:
The current build has renamed or retired some STU3 artifacts. EligibilityRequest/EligibilityResponse are now CoverageEligibilityRequest/CoverageEligibilityResponse, PaymentNotice.provider is now PaymentNotice.reporter, ClaimResponse.requestProvider and PaymentReconciliation.requestProvider/requestOrganization map to requestor, and ProcessRequest/ProcessResponse are commented out of the active resource list with guidance to use Task. EnrollmentResponse still has an organization element, but that is the active insurer element in the current StructureDefinition and is not the removed requestOrganization element from the Jira request.

AutoFHIR reconciliation:
No source change was made. Active current StructureDefinitions already include PractitionerRole on the relevant provider, enterer, payee party, careTeam provider, requestor/requestProvider, reporter, and prescriber references, include Organization where the Jira requested an organization-capable provider/requestor reference, and no obsolete requestOrganization elements remain in the current source. The build-scope check confirms the affected current resource files are active except ProcessRequest/ProcessResponse, which are intentionally out of the current build.

Recommendation:
Keep this audit commit as-is. The current core source satisfies FHIR-15677 after accounting for later resource and element renames; further source edits would be redundant and risk changing valid current elements such as EnrollmentResponse.organization.
