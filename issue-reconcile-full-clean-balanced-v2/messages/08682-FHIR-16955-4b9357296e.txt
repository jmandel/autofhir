FHIR-16955: Audit Excel whitespace normalization

Issue request:
FHIR-16955 was Published/Persuasive for the STU3 FHIR-core tooling request to convert non-breaking spaces and tabs into ordinary whitespace when processing Excel spreadsheet content, rather than allowing those hidden characters to interfere with trimming and parsing.

Initial application:
The Jira comment records svn 14523. In git history that is commit 6e138bd162989d4af9bc146155f9f69e1eed13e8, which changed the old in-repository XLSXmlParser.getColumn implementation from a plain trim() to trim().replace("\\t", "  ").replace("\\u00A0", " "). The adjacent commit 213590de6f6e23bd8d14f05cee02fe6e9272f0be also used GF#16955 for a spreadsheet comment correction, but the parser commit is the substantive application of this issue.

Additional context:
The current FHIR checkout no longer contains Java publisher/parser sources or XLSXmlParser.java. Current source delegates the build to the external org.hl7.fhir:kindling dependency in build.gradle.kts, with kindlingVersion=1.25.5-SNAPSHOT in gradle.properties. The current external org.hl7.fhir.utilities XLSXmlParser in hapifhir/org.hl7.fhir.core still contains the requested tab and U+00A0 replacement in getColumn. Confluence minutes from the 2018-07-30 FHIR Infrastructure call list tracker 16955 as Persuasive, and no conflicting Zulip or Confluence rationale was found.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The source-owned parser that FHIR-16955 modified was removed from this repository during later Java tooling refactors, and the active external parser used by the build retains the applied normalization behavior. Editing current spreadsheet XML or build configuration would not improve conformance to this issue.

Recommendation:
Keep this no-change audit commit. If future review wants broader Excel normalization beyond the original applied getColumn behavior, that follow-up belongs in the external Java tooling repositories (Kindling/org.hl7.fhir.core), not as a FHIR core source edit.
