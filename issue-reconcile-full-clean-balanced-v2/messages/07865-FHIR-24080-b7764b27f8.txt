FHIR-24080: Audit Questionnaire linkId examples

Issue request:
FHIR-24080 was Published/Persuasive and auto-approved for R5. It reported that generated Questionnaire JSON examples from the Questionnaire examples page, including many resource-definition questionnaires such as patient-questionnaire.json, omitted required Questionnaire.item.linkId values and should be updated so every item has a linkId.

Initial application:
No core repository commit was found that explicitly mentions FHIR-24080. The application appears in the published artifacts instead: the R4 examples-json package reproduces the reported problem, while the R5 examples-json package contains the relevant generated Questionnaire resources with no missing item.linkId values.

Additional context:
The current source keeps Questionnaire.item.linkId as 1..1 in source/questionnaire/structuredefinition-Questionnaire.xml, and all checked-in current Questionnaire XML examples under source/questionnaire have linkId on every item. The current build no longer publishes the old resource-definition generated questionnaire JSON files such as patient-questionnaire.json, so the original generated-output failure is outside the current build surface.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The R5 publication corrected the generated examples named by the issue, current authoritative Questionnaire examples are valid for linkId, and there is no current core source file that needs a linkId fix for FHIR-24080.

Recommendation:
Keep this no-change audit commit. Revisit only if the build reintroduces resource-definition questionnaire JSON outputs or a validator finds a current Questionnaire example item without linkId.
