FHIR-33120: Audit Immunization procedure extension location

Issue request:
FHIR-33120 was Published with a Persuasive with Modification resolution. It asked for a standard extension on Immunization to record the procedure associated with an immunization event, using CodeableReference so implementers could provide either a code or a reference to a Procedure, with no value set because procedure codes vary by location.

Initial application:
The request was applied in core by ef4b1ff22527c07e7cc9d3686921bf13044c5cd4, which added source/immunization/structuredefinition-extension-immunization-procedure.xml and wired it through the Immunization core package list. That applied source used the canonical http://hl7.org/fhir/StructureDefinition/immunization-procedure, Immunization context, CodeableReference value type, and Procedure target profile.

Additional context:
The core source later moved standard extension definitions out of the R5 source in dd468d4f1799dd79819315b211588ef1cf4586e0, deleting the Immunization procedure StructureDefinition from core and leaving only the core OID mapping. The current authoritative definition is in the FHIR Extension Pack at input/definitions/Immunization/StructureDefinition-immunization-procedure.xml; the Extension Pack implementation guide includes input/definitions/*, and the current file is active, has Public Health ownership, uses the Immunization context, and keeps CodeableReference targeting Procedure. FHIR-36059 is a duplicate/background request for a procedure code element and does not need a separate reconciliation commit here.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current core checkout is correct not to re-add the extension definition because the artifact now belongs to the FHIR Extension Pack, outside this FHIR core source tree.

Recommendation:
Keep this audit commit as-is for the core reconciliation. Any future changes to the Immunization procedure extension should be made in the FHIR Extension Pack, not by restoring the deleted core StructureDefinition.
