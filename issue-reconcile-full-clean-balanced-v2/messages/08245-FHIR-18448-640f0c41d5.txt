FHIR-18448: Add RDF syntax comparison guidance

Issue request:
FHIR-18448 was a Published/Persuasive FHIR-core issue from the STU3 ballot about inconsistent syntax comparisons. It asked why the JSON page had a "Comparison with XML" section without an equivalent XML section or RDF mention, and the accepted resolution was to add a shared differences tab, link format pages to it, move the JSON/XML comparison there, and add similar RDF guidance such as array-order handling and polymorphism.

Initial application:
Commit fb6236f76aef7e34c5874572f098f3a646dcc983 explicitly applied FHIR-18448 by creating source/resource-formats.html, adding it to publish.ini and source/hierarchy.xml, moving the JSON/XML comparison out of source/formats.html, and repointing source/json.html and source/xml.html to the new page. That application left the shared page titled as a JSON/XML comparison and did not add RDF comparison guidance or a reciprocal RDF page link.

Additional context:
The current build-scope source still lists resource-formats.html in publish.ini and under Resource Definitions in source/hierarchy.xml. Related history for FHIR-18452 moved the JSON/XML comparison out of the JSON page, and FHIR-18449 later updated the whitespace/signature text inside that comparison. Current source/rdf.html already contains detailed RDF guidance for ordered repeating elements, polymorphic properties, primitive literals, and the relationship between RDF, XML, and JSON, but the shared comparison page did not surface those differences.

AutoFHIR reconciliation:
This commit changes the active source/resource-formats.html comparison section to "Differences between syntaxes", keeps the existing JSON/XML comparison, and adds concise RDF difference guidance linked to the authoritative RDF sections for RDF lists, polymorphic properties, primitives, and FHIR-specific RDF terms. It also updates the JSON and XML page links to refer to the other FHIR syntaxes and adds a corresponding RDF page link to the shared comparison.

Recommendation:
Keep this source fix as-is. It completes the accepted FHIR-18448 scope without duplicating the full RDF page and should need no further work unless the work group later wants a more detailed matrix of syntax differences.
