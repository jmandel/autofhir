FHIR-10096: Audit repeat count fill-display comment

Issue request:
FHIR-10096 was a Published/Persuasive with Modification FHIR-core Pharmacy issue for MedicationOrder.dispenseRequest.numberOfRepeatsAllowed. It identified that the element definition counted refills/repeats as additional fills, while the comment still implied a total-fill value by saying to subtract 1 from displayed authorized refills; the requested correction was to express total authorized fills as numberOfRepeatsAllowed plus 1.

Initial application:
The issue was applied by git-svn commit 8c9815efa4c991d85f683d7a156c4ed5ebece1d6, which changed the MedicationOrder spreadsheet comment from "If displaying \"number of authorized refills\", subtract 1 from this number" to "If displaying \"number of authorized fills\", add 1 to this number" and tightened the definition wording. That source lineage was later renamed from MedicationOrder to MedicationRequest.

Additional context:
FHIR-8143 established the underlying rule that numberOfRepeatsAllowed excludes the original dispense. FHIR-13182 later changed the same element to unsignedInt and added explicit zero-refill guidance, and that issue is already represented on the combined branch. FHIR-14565 later declined renaming the element. MedicationRequest remains active in source/fhir.ini, and the current StructureDefinition still has the corrected authorized-fills comment.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because source/medicationrequest/structuredefinition-MedicationRequest.xml already says "If displaying \"number of authorized fills\", add 1 to this number," and a current-source search found no stale subtract-1 or authorized-refills comment for this element.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is recommended for FHIR-10096; the current comment correctly aligns display of total authorized fills with the additional-repeat count.
