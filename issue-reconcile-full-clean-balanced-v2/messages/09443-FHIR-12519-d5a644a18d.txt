FHIR-12519: Audit Request requester invariant

Issue request:
FHIR-12519 was Published/Persuasive for FHIR-core _Request in the workflow area. It reported that Request.requester inv-1 used an invalid XPath contains() expression involving agent/onBehalfOf and recorded the approved correction as the FHIRPath expression `(agent.resolve().empty()) or (agent.resolve() is Device) or (agent.resolve() is Practitioner) or onBehalfOf.exists().not()`.

Initial application:
The Jira comment records svn @11105. Git history maps that to 5c1a24e73bdb67c0666527e5e9788c1b19b5ef9f, `#12519 - updated Request.requestor invariant inv-1`, which changed the invariant expression to use agent.resolve(). A later unkeyed schematron cleanup, 759f5178356c92faad909caa6ed46aa17b92b10e, corrected the XPath from `contains(f:agent, ...)` to `contains(f:agent/f:reference/@value, ...)`. Related FHIR-12811 was later noted in Jira as a duplicate of this tracker and already done.

Additional context:
The Request logical model is an active current-build source under source/fhir.ini's [logical] section. Subsequent workflow-pattern changes removed the old Request.requester.agent/onBehalfOf backbone, and 14b69a1c6dd33918b20d53ffd6cfbab523f840ba removed the obsolete inv-1 row entirely. FHIR-13445 formally recorded that the invariant was no longer relevant because onBehalfOf was being dropped from the pattern. FHIR-15128 later confirmed that onBehalfOf should not be restored to core Request/Event patterns and is already represented on the combined branch by ed79f31e79a3d4d5b47cb390e2d27e6cea324247.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/request/request-spreadsheet.xml defines Request.requester as a direct Reference including PractitionerRole and Device, has no Request.requester.agent or Request.requester.onBehalfOf subelements, and contains no inv-1 expression or XPath needing correction.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the old inv-1 XPath or requester backbone; any future onBehalfOf change would require a new work-group decision that supersedes FHIR-13445 and FHIR-15128.
