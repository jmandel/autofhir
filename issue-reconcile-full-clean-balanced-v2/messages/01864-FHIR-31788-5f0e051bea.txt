FHIR-31788: Audit packaged product jurisdiction status

Issue request:
FHIR-31788 was Published with a Persuasive with Modification resolution for the R4 MedicinalProductPackaged ballot comment asking whose legalStatusOfSupply and marketingStatus assertions applied. The accepted change was to make LegalStatusOfSupply a 0..* backbone element, add an optional jurisdiction element, state that a missing jurisdiction means the jurisdiction is unknown in context, and extend the description around regulatory jurisdiction.

Initial application:
The PackagedProductDefinition source was the current R5 successor for the ballot artifact. Git history shows commit 920f713f5930dd8a4fd5510818b7abccfb7816e4 made legalStatusOfSupply a backbone for FHIR#31788, f9c5f6282fc5b3e90732c9ac59ce7ebae16bed4d temporarily removed it while nearby packaged product edits were in flight, and 08d35148dd0fa3866502882e1805fe34cb107da4 restored the backbone with jurisdiction. A follow-up commit, 70072108591e64757c33bbb8806f88b31302f48a, corrected the backbone cardinality to 0..* even though its subject typo says FHIR#1788.

Additional context:
PackagedProductDefinition is active in the current build configuration, while source/fhir.ini maps the old MedicinalProductPackaged name toward the newer packaged product definition family. The active MarketingStatus datatype already includes country and jurisdiction fields, so the marketingStatus half of the question is covered by its datatype rather than a PackagedProductDefinition-local backbone. BR&R WGM minutes noted this issue was already applied, and FHIR-36049 later proposed mirroring the same repeatable legal-status pattern onto MedicinalProductDefinition but was withdrawn with no change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source has PackagedProductDefinition.legalStatusOfSupply as 0..*, typed as BackboneElement, with legalStatusOfSupply.jurisdiction and a definition that says a missing jurisdiction is unknown in this context. Current MarketingStatus source has both country and jurisdiction elements explaining where marketing status applies.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-31788 unless BR&R later wants a purely editorial parent-element wording change; the conformance-significant structure and missing-jurisdiction semantics requested by the published issue are already present.
