FHIR-14330: Audit MeasureReport reporter application

Issue request:
FHIR-14330 was a Published/Persuasive STU3 CQI change request for FHIR-core MeasureReport. It asked to replace reportingOrganization with reporter and allow references to Practitioner, PractitionerRole, Location, Organization, and Group, with guidance that the relationship between reporter and reporting agencies would need additional arrangement-specific clarification.

Initial application:
The issue was applied in SVN 13290, now git commit a1cc4ed53f2d5cbc4633b5869d6c58d983fc81ef. That commit changed MeasureReport.reportingOrganization to MeasureReport.reporter and broadened the target types in the then-authoritative MeasureReport spreadsheet.

Additional context:
The current MeasureReport source is active in source/fhir.ini. It already defines MeasureReport.reporter with Practitioner, PractitionerRole, and Organization targets and retains committee-note guidance about the relationship between the reporter, reporting vendors, practitioners, providers, and organizations. The differences from the original STU3 requested type list are explained by later core decisions: FHIR-15913 and FHIR-38002 exclude Group because a Group is a subject/collection rather than an actor that can report, and FHIR-32985 moved location reporting to a first-class MeasureReport.location element instead of keeping Location on reporter. FHIR-31686 and FHIR-38002 also show later CQI consideration of multiple/additional reporters without requiring a current core cardinality change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source preserves the seed issue's substantive practitioner-reporter connection while reflecting later published/applied MeasureReport decisions for Group, Location, and reporter cardinality.

Recommendation:
Keep this no-change audit as-is. Do not re-add Group or Location to MeasureReport.reporter for FHIR-14330; any future need for multiple accountable practitioners or groups should proceed through a new CQI decision or the DEQM-specific follow-up path already identified by FHIR-38002.
