FHIR-7826: Audit MedicationAdministration v2 quantity mapping

Issue request:
FHIR-7826 was a Published/Persuasive Pharmacy change request from the DSTU1 May 2015 ballot asking that the MedicationAdministration quantity v2 mapping remove component references, changing the mapping from RXA-6-Administered Amount / RXA-7.1-Administered Units.code / RXA-7.3-Administered Units.name of coding system to RXA-6 Administered Amount / RXA-7 Administered Units.

Initial application:
The issue was applied in git commit 651364cb098a623c36afc1d6b9d56578507d897c, whose subject explicitly lists tracker item #7826 and whose patch changed the MedicationAdministration spreadsheet mapping to the requested simplified RXA-6/RXA-7 wording. The later 2021 source rework commit 33b409a4b6d544598262f2f074ebb4b6dc466157 converted the spreadsheet source into the current StructureDefinition and preserved the simplified mapping.

Additional context:
MedicationAdministration is an active resource in source/fhir.ini, so source/medicationadministration/structuredefinition-MedicationAdministration.xml is in current build scope. The element has since been named MedicationAdministration.dosage.dose rather than the older quantity wording, but the v2 mapping text at that element remains exactly the requested simplified wording. Zulip and Confluence searches for FHIR-7826 and the RXA-6/RXA-7 MedicationAdministration mapping found no conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative source already contains the requested RXA-6 Administered Amount / RXA-7 Administered Units mapping and no longer contains the component-level RXA-7.1/RXA-7.3 guidance that FHIR-7826 asked to remove.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-7826 unless a future Pharmacy decision revisits the MedicationAdministration v2 mapping itself.
