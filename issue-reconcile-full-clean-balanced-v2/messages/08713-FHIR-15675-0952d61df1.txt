FHIR-15675: Audit identical profile set definition

Issue request:
FHIR-15675 was a Published FHIR-core profiling clarification with Persuasive resolution. It reported that the original definition of identical profile sets was tautological because it said resources conforming to A also conform to B and then restated the contrapositive, and it suggested defining identical sets by saying all resources conforming to A also conform to B and all resources conforming to B also conform to A.

Initial application:
The Supporting Multiple Profiles section was originally added by FHIR-6085 in svn revision 6360. FHIR-15675 was applied in svn revision 14321, represented in git by bc42cabc7375d8121772cde649a612fc38b52f35, which replaced the tautological original wording in source/profiling.html with explicit set-equality wording for the resources conforming to A and B. The current line still blames to that FHIR-15675 application commit.

Additional context:
Current source/profiling.html is the active profiling narrative page for the related section and now defines identical sets as the same conforming-resource set, with the same non-conforming complement. Jira searches found only the originating FHIR-6085 profile-consistency issue and FHIR-15675 for this exact wording family, and quoted Zulip/Confluence searches found no conflicting community discussion or later work-group decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current spec no longer contains the tautological wording reported by FHIR-15675 and conveys the accepted symmetric set relationship. The remaining wording is slightly redundant, but changing it again would be editorial polish rather than a necessary semantic correction for the current build.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-15675 unless the work group wants a separate editorial cleanup of the sentence independent of this already-applied clarification.
