FHIR-5876: Audit AllergyIntolerance recorder definition

Issue request:
FHIR-5876 was Published/Persuasive with Modification for DSTU1 Patient Care. It asked why AllergyIntolerance.recorder was defined as the responsible person and requested a clearer definition: "Individual who recorded the record and takes responsibility for its content".

Initial application:
The issue was initially applied in SVN/git commit 2b23bf322d, which changed the old AllergyIntolerance spreadsheet definition for AllergyIntolerance.recorder from responsibility-only wording to the requested recorded-and-responsible definition. The current source no longer uses that spreadsheet, but the active StructureDefinition retains the same meaning.

Additional context:
AllergyIntolerance is an active resource in source/fhir.ini, so source/allergyintolerance/structuredefinition-AllergyIntolerance.xml is in current build scope. Later AllergyIntolerance recorder work kept the FHIR-5876 definition, added clarifying comments about recorder versus recordedDate, temporarily replaced recorder with participant, and then restored recorder. The later Applied FHIR-48804 decision refined the same definition to "takes responsibility for accurately recording its content" and added J#48804 to the committee notes. The unresolved FHIR-49653 tracker is related background but is still Triaged and does not override the applied source.

AutoFHIR reconciliation:
This audit commit makes no source change. The current active AllergyIntolerance.recorder definition already conveys the FHIR-5876 resolution, with later approved wording that clarifies responsibility for accurate recording rather than changing the core meaning.

Recommendation:
Keep this no-change audit as-is. No FHIR core source edit is needed for FHIR-5876 unless a future final Patient Care decision changes the recorder/asserter model.
