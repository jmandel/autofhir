XPath. Jira later records that the changes were applied, except for an eld-19 concern that was being handled separately.

A later applied reconciliation for FHIR-53414, already present on the combined branch, updated the same invariant for current R6 semantics by allowing name or code, handling timing choice elements, requiring data for data-* triggers, and requiring subscriptionTopic for subscription-topic triggers while keeping the XPath in valid exists(f:...) form.
