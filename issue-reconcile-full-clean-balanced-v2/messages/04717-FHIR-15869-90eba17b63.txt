FHIR-15869: Audit NamingSystem jurisdiction binding

Issue request:
FHIR-15869 was a Published/Persuasive with Modification vocab change request from STU3 asking to support state, province, and territory jurisdictions for NamingSystem.jurisdiction. The accepted resolution was to add ISO 3166-2 subdivision codes to the Jurisdiction value set, fix the ISO 3166 Part 2 and Part 3 descriptions on the ISO 3166 guidance page, and note that the value set also includes supra-national M49 regions.

Initial application:
The issue was applied by svn 14594, represented in git as ad0af898c247fb511ef472b0a603639ec3781f9d. That commit added urn:iso:std:iso:3166:-2 to source/terminologies/valueset-jurisdiction.xml, expanded the value set description with the ISO 3166 and M49 note, corrected source/iso3166.html Part 2 and Part 3 wording, and registered the ISO 3166 Part 2 and Part 3 URIs in the value set validator.

Additional context:
NamingSystem is active in source/fhir.ini and the current NamingSystem.jurisdiction definition binds extensibly to http://terminology.hl7.org/ValueSet/jurisdiction. Core no longer owns source/terminologies/valueset-jurisdiction.xml; it was removed in f9a44787c45071394532c7c2ee94d76f30f47387 after the terminology source moved out of core. The current THO Jurisdiction ValueSet includes urn:iso:std:iso:3166:-2 and the M49 region include, and the current THO ISO3166 guidance page describes Part 2 as subdivision codes and Part 3 as historical country names.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core binding points at the maintained THO value set that contains the requested subdivision codes and scope note, and the ISO 3166 guidance now has the requested Part 2 and Part 3 wording.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core follow-up is needed for FHIR-15869; future jurisdiction value set content changes should be handled in the terminology source of truth rather than by recreating a core ValueSet source file.
