FHIR-29944: Audit publisher steward supersession

Issue request:
FHIR-29944 was a Published/Persuasive vocab change request for R5 asking to remove the steward alternate name from ValueSet.publisher and remove comment wording implying publisher and steward were synonymous.

Initial application:
The original R5 application is visible in git commit b0172dd266, which mentions FHIR-29944 and removed the alias value="steward" from the then-current ShareableValueSet profile source. The current checkout no longer contains that old profile file, because shareable/publishable/computable/executable profiles were later migrated, but the historical application confirms the seed was not ignored.

Additional context:
A later final decision, FHIR-35987, is Published/Persuasive with Modification and explicitly says publisher is a synonym for steward for CanonicalResource-style publisher elements. Its resolution changed the short name to "Name of the publisher/steward (organization or individual)" and the definition to responsibility for release and ongoing maintenance. Vocab minutes tied the ValueSet steward cleanup to FHIR-35987 satisfying the definition of steward, and FHIR-I minutes record the 15-0-0 approval. The current active ValueSet source and notes now intentionally reflect that later decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Removing "steward" from ValueSet.publisher now would reapply the older FHIR-29944 request while contradicting the later FHIR-35987 resolution and the current ValueSet/VSD alignment narrative.

Recommendation:
Keep this audit commit as-is. If the work groups want publisher and steward separated again for ValueSet, that should be handled as a new tracker that explicitly revisits FHIR-35987 rather than as a delayed FHIR-29944 cleanup.
