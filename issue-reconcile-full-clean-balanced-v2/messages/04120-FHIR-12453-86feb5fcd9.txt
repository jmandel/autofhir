FHIR-12453: Audit MedicationAdministration mad-1 conjunction

Issue request:
FHIR-12453 was a Published Pharmacy change request raised against DSTU2 MedicationAdministration. It asked to change the mad-1 invariant wording from "SHALL have at least one of dosage.dose and dosage.rate[x]" to "or" because only one of dose or rate was intended to satisfy the invariant.

Initial application:
Jira comments record the issue as applied in SVN/git commit a437487f804c183e181dbec98864b65bf2a86923 (@10845). That commit changed the old MedicationAdministration spreadsheet invariant English from "dosage.dose and dosage.rate[x]" to "dosage.dose or dosage.rate[x]" while keeping the FHIRPath expression as dose.exists() or rate.exists().

Additional context:
MedicationAdministration is active current build scope through source/fhir.ini. The old spreadsheet source was later reworked into source/medicationadministration/structuredefinition-MedicationAdministration.xml, and the current mad-1 invariant is attached to MedicationAdministration.dosage with an expression using or. Later Published issue FHIR-27834 broadened the same invariant to say that when dosage is present it may be satisfied by dosage.text, dosage.dose, or dosage.rate[x]; that issue is already represented on the combined branch by bfef8b75ae7755ca19ab29717bb0f20b23c0afb3, so it is context only here. Direct Zulip and Confluence searches for FHIR-12453/mad-1 found no conflicting community evidence.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the active StructureDefinition already implements the published FHIR-12453 correction and the later FHIR-27834 refinement. Reverting to dose/rate-only wording would lose later approved text support.

Recommendation:
Keep this commit as-is. No FHIR core follow-up is needed for FHIR-12453 unless Pharmacy reopens the broader MedicationAdministration dosage invariant after FHIR-27834.
