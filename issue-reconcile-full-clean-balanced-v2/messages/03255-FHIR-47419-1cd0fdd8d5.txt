FHIR-47419: Audit Device UDI wording reconciliation

Issue request:
FHIR-47419 was an Applied/Persuasive R6 OO change request asking whether Device.udiCarrier and DeviceDefinition.udiDeviceIdentifier were sufficiently harmonized, because both had been described as "Unique Device Identifier (UDI) Barcode string" while Device had deviceIdentifierSystem and DeviceDefinition did not. The approved clarification updated Device UDI carrier wording, clarified DeviceDefinition.udiDeviceIdentifier as the DI/UDI-DI portion, added identifier-system elements in DeviceDefinition, and aligned the deviceIdentifierSystem long definition across Device and DeviceDefinition.

Initial application:
The request was applied through earlier source commits: 3cf635fa2b6 updated Device.udiCarrier short/long wording, d44784371677 applied PR #3573 for Device carrierAIDC/carrierHRF wording plus DeviceDefinition.udiDeviceIdentifier and identifier-system additions, and 3466769d5835 fixed the final Device.udiCarrier.deviceIdentifierSystem definition after a revert/reapply sequence. Current source already contains those changes in build-scoped Device and DeviceDefinition resource files.
