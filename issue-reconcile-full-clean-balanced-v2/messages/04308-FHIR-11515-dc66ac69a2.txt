FHIR-11515: Clarify ActivityDefinition medication example

Issue request:
FHIR-11515 was a Published/Persuasive CDS change request from the 2016 September CQF ballot asking for clearer documentation on profiling ActivityDefinition and on how dynamicValue paths get their target context when an activity category such as drug maps to an order resource.

Initial application:
The issue was initially applied in SVN 10927, represented in git by c03a8aca8404dc242356064fbc17b482dfc33d81, which explicitly said "#11515: Added profiling discussion to ActivityDefinition" and added the Profiling ActivityDefinition section. The current ActivityDefinition notes retain that profiling guidance and current applying guidance explains that ActivityDefinition.kind determines the target request resource.

Additional context:
The current build has ActivityDefinition as an active resource in source/fhir.ini, and the Clinical Reasoning module links the definitional resources topic that contains the medication dynamicValue example. Later refactors renamed the target resource from MedicationOrder to MedicationRequest and made ActivityDefinition.kind the element that identifies the resource being represented. The definitional resources example still showed the older category-based fragment and referred to ActivityDefinition dosage as dosageInstruction, which would undercut the issue's target-context clarification for current readers.

AutoFHIR reconciliation:
Updated source/clinicalreasoning-topics-definitional-resources.html so the medication ActivityDefinition fragment declares kind="MedicationRequest" instead of the old category="drug" and so the nearby prose names the current ActivityDefinition dosage element. This keeps the existing profiling section and examples while aligning the current page with the active StructureDefinition and the original issue intent.

Recommendation:
Keep this source fix. It is narrow, build-scoped, and directly addresses the remaining stale wording connected to FHIR-11515; no additional Jira issue from the omnibus SVN 10927 commit was decided here.
