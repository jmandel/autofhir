FHIR-40731: Audit external extension retirement

Issue request:
FHIR-40731 is Applied / Persuasive with Modification. The Vocabulary WG decided that the CodeSystem concept-comments extension should be retired because the standard CodeSystem concept property http://hl7.org/fhir/concept-properties#comment exists and is documented in the CodeSystem defined-properties section.

Initial application:
No prior FHIR-core reconciliation commit for FHIR-40731 was present on the combined branch, and current core history has no Jira-tagged core commit for this issue. The extension definition is not an active core build source; it lives in the FHIR Extension Pack. Extension Pack history shows commit 2d8d674 first changed the extension status to retired for a broader TI extension cleanup including FHIR-40731, and later commit 4417c8c represented the same R5+ prohibition as an active legacy extension with endFhirVersion 4.3 and explanatory text.

Additional context:
Core source/fhir.ini actively builds the CodeSystem resource and core extension spreadsheets but does not list StructureDefinition-codesystem-concept-comments as a current core profile source. Current core search finds only the canonical OID registry entry for this extension, which should remain a stable identifier mapping. The core CodeSystem narrative and concept-properties CodeSystem already define the standard comment property that the Jira resolution points to.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR-core source change and records an external-repo decision. The remaining extension definition and any choice between artifact status=retired versus active with version-specific-use belong to HL7/fhir-extensions, not this core checkout.

Recommendation:
Keep this audit commit as-is for FHIR core. If further action is desired, review HL7/fhir-extensions/input/definitions/CodeSystem/StructureDefinition-codesystem-concept-comments.xml to confirm that the current active/endFhirVersion representation is the intended way to express the Vocabulary WG's retirement decision for legacy FHIR versions.
