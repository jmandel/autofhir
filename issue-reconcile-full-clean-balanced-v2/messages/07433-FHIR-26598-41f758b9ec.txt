FHIR-26598: Audit corrected NDJSON sample

Issue request:
FHIR-26598 was a Published/Persuasive FHIR-I correction for the FHIR-core NDJSON page. The reporter noted that the sample wrapped two newline-delimited JSON resources in an outer JSON object, which is invalid NDJSON, and asked that the page show each resource object on its own line with no enclosing braces.

Initial application:
The Jira-tagged source commit 68fad5f12e1fcb13a116564726a3e99dec206360 removed the invalid outer braces from source/nd-json.html and left the two sample resource objects as separate lines inside the preformatted block. Current blame still attributes the sample block and both resource lines to that implementation commit.

Additional context:
FHIR-I minutes from 2020-05-11 record FHIR-26598 as a correction approved as persuasive, and the originating Zulip thread confirms the extra wrapping braces were a copy/paste error. The NDJSON page is current build source: source/hierarchy.xml lists nd-json.html under Resource Definitions, and source/documentation.html, source/downloads.html, and source/resource-formats.html link to the same page. A later same-page cleanup, FHIR-31425, is already represented on the combined branch and did not reintroduce the invalid sample shape.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/nd-json.html sample already shows valid NDJSON with one resource object per line and no enclosing object, and a search for the old malformed pre block found no match.

Recommendation:
Keep this no-change audit commit as-is. No further FHIR-core source work is indicated for FHIR-26598 unless a later issue changes the NDJSON page semantics beyond the sample correction.
