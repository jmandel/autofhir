FHIR-3433: Audit Practitioner communication search parameter

Issue request:
FHIR-3433 is a Published, Persuasive with Modification FHIR-core Practitioner request to make the practitioner's communication/language field searchable, motivated by finding practitioners who speak a patient's language. The Jira resolution and duplicated 2014 comment say the communication field would be added to Practitioner search parameters.

Initial application:
The issue was explicitly applied by git commit 8f110897205e897ef7f4d7932ef036b0e475f261, whose message says "Updated tracker #3433 Add language (communication) search parameter to Practitioner" and whose patch added a Practitioner Search row with code `communication`, type `token`, and expression `Practitioner.communication` to the historical practitioner spreadsheet.

Additional context:
Practitioner is an active current-build resource in source/fhir.ini. Current source carries the search parameter as `Practitioner-communication` with code `communication` and expression `Practitioner.communication.language`. Later Published PA decisions FHIR-26654 and FHIR-22114 reworked Practitioner.communication into a BackboneElement with a `.language` child and `.preferred` flag, added PractitionerRole.communication for patient-facing directory use, and updated the search parameter expression rather than removing it. Earlier no-change decisions such as FHIR-7628/FHIR-18820 confirm that Practitioner communication has intentionally differed from Patient communication, so the absence of a Practitioner search parameter named `language` is not a current source defect.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current Practitioner search parameter already indexes the language carried in `Practitioner.communication.language`, and the related PractitionerRole search parameter covers the later patient-facing role/directory semantics introduced by FHIR-26654.

Recommendation:
Keep this audit commit as-is. No FHIR-core source follow-up is needed for FHIR-3433 unless PA later decides to rename or alias the Practitioner search parameter; the current `communication` code is historically intentional and still build-scoped.
