FHIR-30280: Audit Health Canada NPN OID correction

Issue request:
FHIR-30280 was a Published/Persuasive vocabulary change request for R5. It asked that the OID associated with http://hl7.org/fhir/sid/ca-hc-npn on the Code Systems page be changed from the duplicate Health Canada DIN OID to 2.16.840.1.113883.5.1107.

Initial application:
The original ca-hc-npn row was added by git 54f9e4d with the duplicate 2.16.840.1.113883.5.1105 OID. Git ade907ca explicitly listed FHIR-30280 in a vocabulary R5 batch and changed source/terminologies-systems.html from 2.16.840.1.113883.5.1105 to 2.16.840.1.113883.5.1107 for that row.

Additional context:
FHIR-37853 later changed the same active Code Systems page to make HL7 Terminology the authoritative source of truth for external terminology information and removed the ca-hc-npn row along with other external rows lacking a local Using X With FHIR page. The current active core page no longer contains ca-hc-npn, and the remaining checked-in V3 terminology source records HC-NPN with OID 2.16.840.1.113883.5.1107 rather than the DIN OID.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The FHIR-30280 correction was applied before R5, and the current core source has no remaining stale ca-hc-npn row to correct.

Recommendation:
Keep this audit commit as-is. If future reviewers find a wrong ca-hc-npn OID in HL7 Terminology/THO, handle that in the THO/UTG source of truth rather than by reintroducing the removed external row to FHIR core.
