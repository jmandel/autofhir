FHIR-30313: Audit RelatedPerson health-scope wording

Issue request:
FHIR-30313 was a Published/Persuasive PA change request for RelatedPerson. It asked to broaden the RelatedPerson definition from people involved only in care to people involved in a patient's health or the care for a patient, so people relevant to health but not participating in care, such as sex partners or drug-injecting partners, are not excluded.

Initial application:
The request was applied by git commit 81f8b30cb34e87c76cffca4218d55c7c48d53799, which changed both the RelatedPerson StructureDefinition description and root element definition in source/relatedperson/structuredefinition-RelatedPerson.xml to include "involved in a patient's health or the care for a patient". That commit also noted it covered the closely related FHIR-25727 scope clarification.

Additional context:
RelatedPerson is an active current-build resource through source/fhir.ini. The current source still contains the FHIR-30313 health-scope wording in both authoritative definition locations. Later final RelatedPerson decisions intentionally changed adjacent wording: FHIR-41566 removed the "nor has a formal responsibility in the care process" clause, and FHIR-41559 changed "target of healthcare" to "primary target of healthcare" and added Patient.link boundary guidance. The 2022 PA WGM minutes record FHIR-30313 as related to FHIR-25727 and voted persuasive 14-0-1; Zulip searches found no direct seed-specific conflict.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current build source already preserves the FHIR-30313 substance, and the differences from the original requested full sentence are explained by later applied decisions.

Recommendation:
Keep this no-change audit commit. No FHIR-core follow-up is needed for FHIR-30313 unless a future work group decision revisits RelatedPerson's overall boundary with Patient, Practitioner, FamilyMemberHistory, or PersonalRelationship.
