FHIR-13723: Audit ICD-10-GM URL guidance

Issue request:
FHIR-13723 was a Published/Persuasive with Modification STU3 Vocabulary change request asking FHIR core to replace the old ICD-10-GM canonical URL http://hl7.org/fhir/sid/icd-10-de with http://fhir.de/CodeSystem/dimdi/icd-10-gm, and the final resolution was to note that URL on the ICD-X page.

Initial application:
The issue was applied in git commit 0e62a58596de, the svn revision 14619 cited in the Jira comment. That commit changed the old source/icd.html ICD-10 variants table so the Germany row listed http://fhir.de/CodeSystem/dimdi/icd-10-gm instead of only pointing readers to the HL7 Germany page. A preceding cleanup commit had already removed the old http://hl7.org/fhir/sid/icd-10-de row, so the requested canonical replacement was present in the historical core ICD page.

Additional context:
Later Vocabulary/TSMG work moved the Using External Code System pages from FHIR core to HL7 Terminology. FHIR-35933 removed source/icd.html from the core build and changed source/terminologies-systems.html to link to the THO ICD page; UP-289 implemented the THO side of that migration. Current FHIR core source therefore lists only the generic ICD-9/ICD-10 row and delegates ICD-X details to THO. The current THO 7.1.0 English ICD page still contains the Germany row with http://fhir.de/CodeSystem/dimdi/icd-10-gm and uses that URL in the German ICD-10-GM coding examples. A 2025 German Zulip thread suggests the German community now prefers http://fhir.de/CodeSystem/bfarm/icd-10-gm, but that is not a FHIR-core Jira decision and would need THO/German-affiliate follow-up rather than a core source edit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested ICD-10-GM URL was applied historically, the authoritative ICD-X usage page has since moved outside the core checkout, and the current core source correctly points implementers to THO for that external terminology guidance.

Recommendation:
Keep this empty audit commit as-is for FHIR core. If maintainers want to update the ICD-10-GM canonical from the DIMDI URL to a BfArM URL, handle that as a new THO or German-affiliate terminology governance change rather than by reintroducing ICD-X variant detail into FHIR core.
