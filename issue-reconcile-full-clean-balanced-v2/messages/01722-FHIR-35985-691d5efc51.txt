Initial application:
The first application changed ValueSet.baseDefinition from CanonicalResource to MetadataResource in dcc502e4, then d50f84210 (PR 2064, cited from Jira) added the requested MetadataResource elements to source/valueset/structuredefinition-ValueSet.xml and documented the keyword/topic decision. Later FHIR-39257 commit 320b4a6 removed the four redundant extension definitions from the core ValueSet implementation guide and source tree.

Additional context:
ValueSet is an active resource in source/fhir.ini, so source/valueset/structuredefinition-ValueSet.xml is in current build scope. Later FHIR-38680 refined the publisher-review/endorsement wording for MetadataResource-derived elements, and current ValueSet.topic is now deprecated in favor of useContext topic while still preserving FHIR-35985's keyword/search intent. The old extension definitions now live outside this core checkout in the FHIR Extension Pack; author, effectiveDate, expirationDate, and steward are retired/deprecated there, while valueset-keyWord is an extension-pack artifact with separate FHIR-43631 history.
