FHIR-29948: Audit code system selection guidance

Issue request:
FHIR-29948 was a Published/Persuasive Vocabulary change request for R5. It asked the R4 Choosing a system guidance to stop directing readers primarily to the old Code System Registry, FHIR community code system registry, and HL7 OID registry, and instead acknowledge terminology.hl7.org, HTA, and UTG processes for selecting CodeSystem system URLs.

Initial application:
The issue was first applied in commit b0172dd266bc5061422826c714e77a6d3c559296, which replaced the old registry/OID bullet list in source/terminologies.html with THO, HTA, UTG, and example-code-system guidance. Commit 633035c38a681771dd842aabf6a90f9321529267 then adjusted the FHIR-29948 wording after Vocabulary co-chair review.

Additional context:
The same source section remains in build scope as the active Using Codes page. Later source history changed the surrounding terminology guidance: FHIR-35933 moved external code-system usage authority toward THO, and commit 71f5602acf06ad7fe0f46052ca1c6b477311c1ae intentionally aligned Choosing a system with prevailing TSMG policy by replacing former HTA references and the detailed HTA/UTG bullets with the current concise THO/TSMG policy rule. Confluence minutes around the task force show the FHIR-29948 text was reviewed as R5 draft material and that later work separated HTA process material from the core-page text.

AutoFHIR reconciliation:
This audit commit makes no source change. Current source/terminologies.html says that when a code system is listed in THO, the canonical CodeSystem URL SHALL be used, and otherwise the TSMG Terminology Expectations in FHIR process SHALL be followed. That preserves the durable intent of FHIR-29948 under the current governance model without restoring obsolete HTA/UTG process detail.

Recommendation:
Keep this no-change audit. Future changes to the exact TSMG/THO process link or to the amount of local explanatory prose should be handled as a new Vocabulary/TSMG policy decision rather than as further FHIR-29948 reconciliation.
