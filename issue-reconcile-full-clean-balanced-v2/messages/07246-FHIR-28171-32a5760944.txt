FHIR-28171 is a Published/Persuasive FHIR-I technical correction for R5 reporting that the CodeableReference datatype displayed in UML as "DataType", with MedicinalProductDefinition cited as the related current-build page.

Initial application:

Earlier R5 UML tooling history also treated CodeableReference as reference-like in UML, but that Java tooling no longer lives in this current core checkout.

Additional context:

The current build.fhir.org MedicinalProductDefinition SVG renders impurity as CodeableReference; the remaining DataType label in that SVG is for an unrelated choice element value[x]. Zulip evidence points to the same bug report and a follow-on FHIR-28430 reference-list concern, while Confluence search found no FHIR-28171 minutes or conflicting decision.
