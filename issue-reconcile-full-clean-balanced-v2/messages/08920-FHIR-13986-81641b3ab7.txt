FHIR-13986: Audit List entry date decision

Issue request:
FHIR-13986 is a Published/Not Persuasive with Modification FHIR-core List change request raised for STU3. It asked to rename `List.entry.date` to `List.entry.dateAdded` to prevent readers from using it as the date an entry was deleted; the final resolution instead added a constraint limiting entry dates to working lists and removed the usage note, with Jira recording svn revision 13880 as the application.

Initial application:
No Jira-keyed FHIR-13986 git commit was found in the current repository history. Historical List source carried the resulting lst-3 invariant, `mode = 'working' or entry.date.empty()`, through the R4B/current-source refactor, while `List.entry.date` kept the definition "When this item was added to the list." FHIR-17745 later corrected only the human text of that same invariant.

Additional context:
FHIR-34442 is a later Published/Persuasive with Modification List decision that explicitly says the FHIR-13986 use-case spectrum was incomplete and resolves to drop both lst-2 and lst-3. The FHIR-I March and May 2022 minutes identify FHIR-13986 as related background and then approve removing lst-2/lst-3. Commit f2d052d532 removed those constraints from the active List StructureDefinition, and the combined branch already has separate audit/source commits for FHIR-17745 and FHIR-34442.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active List source has no lst-3 restriction to edit or restore, still defines `List.entry.date` as the date the item was added to the list, and includes the later replacement deleted-flag guidance. Reintroducing the FHIR-13986 constraint or renaming the element would contradict the later published FHIR-34442 decision and would be a breaking change unsupported by the current issue family.

Recommendation:
Keep this no-change audit. Do not make further FHIR-13986 source edits unless the work group reopens the later FHIR-34442 policy and decides to restore a date/mode restriction or rename the element in a future release.
