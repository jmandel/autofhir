FHIR-11313: Audit retired Sequence variant clarification

Issue request:
FHIR-11313 was a Published FHIR-core Sequence change request, resolved Not Persuasive with Modification for DSTU2, asking for clearer Sequence.variant guidance and examples. The accepted clarification said the variant definition came from Sequence Ontology, that variants could represent some complex variation with a CIGAR string, and pointed to a complex-variant example.

Initial application:
The issue appears to have been applied by git commit fb0ea8d18e, which explicitly mentioned #11313 and replaced the legacy Sequence.variant definition in source/sequence/sequence-spreadsheet.xml with Sequence Ontology, amino-acid/nucleic-change, complex-mutation, segment-variation, and CIGAR wording. The 2018 rename commit 78abae0217 carried the same concept forward when Sequence became MolecularSequence and registered the sequence-complex-variant example.

Additional context:
The legacy Sequence artifact is not part of the current build: source/fhir.ini lists Sequence under removed resources, comments out molecularsequence for CG, and maps CG to moleculardefinition; diagnostics-module.html says MolecularSequence has been replaced by MolecularDefinition. Later Published CG issue FHIR-37414 removed MolecularSequence.relative.edit.cigar and the CIGAR value from the complex-variant example, the old complex-variant example was later deleted, and the MolecularSequence folder was removed in 2025. Current MolecularDefinition source instead models molecular sequence differences with relative edit operations and profiles for sequence, allele, and variation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring the old Sequence.variant text, CIGAR element, or complex-variant example would be out of build scope and would conflict with later published MolecularSequence/MolecularDefinition evolution; the current source already reflects the applicable present-day rule after the issue family and resource refactors.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-11313; future molecular variation example changes should be handled as new CG/MolecularDefinition work rather than resurrecting retired Sequence.variant or CIGAR guidance.
