FHIR-31369: Audit Statistic category application

Issue request:
FHIR-31369 was Published/Persuasive with Modification for R5. It asked to add Statistic.category with cardinality 0..1, datatype CodeableConcept, short "Associated category for categorical variable", a definition explaining that the category identifies which category a categorical measured variable statistic reports, and a comment about simple strings and matching EvidenceVariable.category.name.

Initial application:
The Jira comment says the issue was applied to R5 by HL7/fhir#1164. Git history shows commit 2bc640fae8 ("J#31369 and J#31493") added the requested row to the then-current source/datatypes/statistic.xml spreadsheet with the approved 0..1 CodeableConcept shape and requested short, definition, and comment.

Additional context:
FHIR-31866 later removed Statistic as a standalone datatype and reincorporated its elements into the active Evidence resource. The current build has Evidence enabled in source/fhir.ini, and source/evidence/structuredefinition-Evidence.xml now carries the element as Evidence.statistic.category. FHIR-48987 later changed the definition/comment wording from measuredVariable to outcome-specific text, which is an applied later CDS decision rather than a FHIR-31369 omission. Confluence evidence confirms the original string-vs-CodeableConcept discrepancy was intentionally resolved as CodeableConcept; targeted Jira/Zulip searches found no conflicting final decision or missing binding/example tracker that changes this seed decision.

This audit commit makes no source change. The active current source already contains Evidence.statistic.category with min 0, max 1, type CodeableConcept, the requested short, and the category definition/comment as refined by the later applied FHIR-48987 wording.
