FHIR-5392: Audit Provenance W3C definition

Issue request:
FHIR-5392 was a Published/Persuasive with Modification DSTU1 Security ballot issue asking to replace the Provenance resource's original narrow definition with W3C PROV wording and to acknowledge that provenance statements can indicate clinical significance for authenticity, reliability, trustworthiness, integrity, and lifecycle stage.

Initial application:
The issue was applied by historical commit 5c0d5519e3, which changed the Provenance spreadsheet root definition from the old "activity that led to the creation of a set of resources" text to the approved W3C/clinical-significance wording. The current XML StructureDefinition descends from the later source conversion and retains that wording in both the resource description and the root element definition.

Additional context:
Provenance is active in the current build through source/fhir.ini. A later 2018 Security WG commit rewrote the separate provenance-introduction.xml scope paragraph to summarize create/revise/delete/sign use cases and quality/reliability/trustworthiness assessment, but it did not remove or contradict the authoritative root definition. No directly relevant Zulip or Confluence evidence was found for FHIR-5392 or the clinical-significance phrase.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scope StructureDefinition already carries the approved FHIR-5392 text, and adding the same clinical-significance prose to the separate narrative introduction would be redundant rather than a necessary correction.

Recommendation:
Keep this no-change audit as-is. Revisit only if the resource page generation stops surfacing the root StructureDefinition definition or if the Security WG wants a new editorial change to duplicate the clinical-significance language in narrative prose.
