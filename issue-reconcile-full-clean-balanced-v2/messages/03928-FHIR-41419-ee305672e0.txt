FHIR-41419: Audit Group characteristic binding fix

Issue request:
FHIR-41419 is Applied/Persuasive with Modification for FHIR-core Group. It asked to remove the broken example binding named GroupCharacteristicValue from Group.characteristic.value[x] because values depend on the characteristic code, and to add a usable example ValueSet for Group.characteristic.code.

Initial application:
The requested change was applied before this reconciliation in March 2025 history. Commit 191fa02f0491ac1c45c574c4cc95daef019aa472 explicitly lists FHIR-41419, removes the binding block from Group.characteristic.value[x], adds the http://hl7.org/fhir/ValueSet/example-characteristic-codes binding to Group.characteristic.code, and creates the Group example characteristic codes ValueSet. Commit 0e115c86c96da9921b9f9610b020fba08dbc210c then adds that ValueSet to source/fhir.ini's active [valuesets] list.

Additional context:
FHIR-I minutes from 2024-08-19 record the 7-0-0 decision to remove the Group.characteristic.value[x] ValueSet binding and create an example ValueSet for Group.characteristic.code. Zulip discussion shows the same background concern about Group bindings without value sets and also records Lloyd McKenzie's view that Group.characteristic.value can legitimately be anything, supporting removal rather than creation of a broad value binding. Current source still has a lone GroupCharacteristicValue entry in source/bindings.ini, but git grep finds no current authoritative StructureDefinition, narrative, or ValueSet use of that name outside the registry line.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped Group StructureDefinition has no binding under Group.characteristic.value[x], Group.characteristic.code is bound to the active example-characteristic-codes ValueSet, and source/fhir.ini includes the ValueSet in the active [valuesets] section.

Recommendation:
Keep this audit commit as-is. The applied source already matches the WG decision, so reopening FHIR-41419 for another source change would risk adding redundant or over-broad characteristic value guidance.
