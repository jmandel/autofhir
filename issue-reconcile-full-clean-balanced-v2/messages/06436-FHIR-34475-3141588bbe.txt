FHIR-34475: Audit derivation-reference extension location

Issue request:
FHIR-34475 was a Published FHIR-core change request, resolved Persuasive with Modification for R5, asking for a core extension originally proposed as annotation-reference and finally named derivation-reference. The accepted design was a 0..* Element/Resource-context extension with reference, path, offset, and length children, plus a constraint preventing length without offset.

Initial application:
The issue was initially applied in core by c40e1884516595dfcbf61825390227448516ab29, which added source/structuredefinition/structuredefinition-extension-structuredefinition-derivation-reference.xml with the accepted name, Resource and Element contexts, the reference/path/offset/length slices, and the der-1 constraint. A later core-wide cleanup, dd468d4f1799dd79819315b211588ef1cf4586e0, removed extension definitions from the R5 core source, including this one.

Additional context:
FHIR-I minutes and the linked Zulip thread confirm the approved scope: the extension should point from generated resources/elements back to text content in a referenced resource using path and offset, and the post-vote discussion explicitly restored Resource-level context. The current HL7/fhir core checkout no longer contains a derivation-reference StructureDefinition under source; it only retains the OID registration in source/oids.ini. The active StructureDefinition now lives in the FHIR Extension Pack checkout at input/definitions/multiple/StructureDefinition-derivation-reference.xml and matches the issue-family intent.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The requested extension is maintained outside the current HL7/fhir source checkout in HL7/fhir-extensions, so changing core source would either reintroduce an out-of-scope extension definition or duplicate the Extension Pack source of truth.

Recommendation:
Keep this audit commit as-is for the core reconciliation. If future review finds wording or cardinality changes are needed for derivation-reference, perform that work in the FHIR Extension Pack rather than in the core FHIR checkout.
