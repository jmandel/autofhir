FHIR-8848: Audit SearchParameter examples

Issue request:
FHIR-8848 was Published with a Persuasive correction for FHIR-core SearchParameter, raised in DSTU1 and applied for DSTU2. The issue reported that the first SearchParameter example was described as searching an extension when it did not, and that the second example had an invalid XPath.

Initial application:
The issue appears to have been applied in the source history by commit 1baf6d5e61, matching the Jira comment's SVN revision 7177. That commit changed the general SearchParameter example description from "General example for searching on an extension" to "General example" and changed the extension example XPath from a bare participation-agreement StructureDefinition URL to an XPath selecting that extension.

Additional context:
SearchParameter is an active current resource in source/fhir.ini, and source/searchparameter/list-SearchParameter-examples.xml includes both the general and extension examples. Later source evolution removed SearchParameter.xpath entirely from this example, and FHIR-27095 later corrected the same extension example's FHIRPath to Patient.extension('http://example.org/fhir/StructureDefinition/participation-agreement').value. FHIR-27095 is already represented on the combined branch by commit 71a9a541ae654fc135c5ace73890dae59a0366e7, so this seed audit should not duplicate that issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current examples no longer describe the general example as an extension search, the active extension example now searches a Patient extension that references DocumentReference, and the reported invalid XPath is no longer present because the current SearchParameter example uses FHIRPath expression instead of XPath.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-8848; any future changes to the SearchParameter extension example should be tracked under a newer issue rather than reopening this already-applied DSTU2 correction.
