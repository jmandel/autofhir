FHIR-13534: Audit retired DocumentManifest scope broadening

Issue request:
FHIR-13534 was a Published/Persuasive with Modification STU3 change request for DocumentManifest. It observed that the introduction and scope described collections of DocumentReference resources even though DocumentManifest.content allowed a broader payload, and the final decision was to broaden the introduction to a manifest of any FHIR resource types while still noting DocumentReference as a prime use.

Initial application:
The issue appears to have been applied in git commit 94e532a611046fcdc40df2d7d28457eeb7dad3a6, whose message names the San Diego WGM DocumentManifest block vote and includes GF#13534. That commit changed source/documentmanifest/documentmanifest-introduction.xml from "a set of DocumentReference resources" to "a set of Resources," added that the DocumentManifest use of "document" is broader than formal FHIR documents or DocumentReference resources, and stated that DocumentManifest can bring clinical context grouping to a broader set of Resources.

Additional context:
The same block-vote commit also applied FHIR-12655 by removing the attachment-specific content model and simplifying DocumentManifest around resource references. Later Published issue FHIR-33021 warned that DocumentManifest might be retired because IHE MHD had moved to List, and the current source reflects that later path: source/fhir.ini has no active documentmanifest resource entry, comments the old workgroup/TLA/status entries, marks DocumentManifest as dropped, and maps the old type to List; source/history.html records DocumentManifest as removed with "use List." Git commit ea941737076615e7e2772299c80c63e1490f2e93 deleted the DocumentManifest source files, and FHIR-39006 moved XDS-related examples and mappings to List.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested broadening was applied to the historical DocumentManifest introduction, and the current build no longer has an authoritative DocumentManifest resource page, StructureDefinition, or content element to amend. Reintroducing or further editing DocumentManifest prose in current core would contradict the later retirement path rather than reconcile FHIR-13534.

Recommendation:
Keep this audit commit as-is for FHIR-13534. If a current manifest-like collection needs new guidance, raise or use a current-release tracker against List or another active resource instead of reviving the retired DocumentManifest narrative.
