Initial application:
The issue resolution says the fields were renamed in revision 7871 and subsequently. Git commit 7089931fcdcdea92b62c147d3d4966315566c14f is that revision in this repository and shows the codeSystem/codeSystemVersion to system/version rename across ConceptMap example and spreadsheet source.

Additional context:
FHIR-9540 requested the same system/version rename and was later resolved as already done. FHIR-9726 itself records that the ConceptMap.group reorganization changed the effective names to group.source, group.sourceVersion, group.target, and group.targetVersion. Later Published issue FHIR-25925 intentionally removed sourceVersion/targetVersion and made group.source and group.target canonical(CodeSystem), matching the current structuredefinition-ConceptMap.xml. ConceptMap is active in the current build through source/fhir.ini, and source/conceptmap contains no remaining codeSystem/codeSystemVersion ConceptMap elements. Zulip and Confluence searches found no directly relevant conflicting community record.

AutoFHIR reconciliation:
This empty audit commit makes no source change because FHIR-9726 was historically applied and the current ConceptMap source reflects later approved modeling changes rather than the obsolete element names.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-9726; any future change to ConceptMap source/target version modeling should be handled by a new terminology work group decision.
