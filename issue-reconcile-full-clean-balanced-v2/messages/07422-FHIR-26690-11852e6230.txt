FHIR-26690: Audit RelatedArtifact publication fields

Issue request:
FHIR-26690 was Published with a Persuasive with Modification resolution for R5. It requested adding RelatedArtifact.publicationStatus 0..1 code with a required PublicationStatus binding and RelatedArtifact.publicationDate 0..1 date, for informational publication metadata about referenced artifacts and with guidance not to populate them when the RelatedArtifact points to a FHIR resource.

Initial application:
The issue was applied by git commit 8e8720183bd9044c22875a57ffb12babf230c0ff, which added the two rows and the RelatedArtifactPublicationStatus binding to source/datatypes/relatedartifact.xml. The current build still uses RelatedArtifact as an active metadata datatype through source/fhir.ini and the metadatatypes pages, so the spreadsheet source remains the relevant core source location.

Additional context:
Later R6 issue FHIR-50010 is Applied/Persuasive and explicitly directed removal of RelatedArtifact.publicationDate and RelatedArtifact.publicationStatus while simplifying the datatype, adding artifact[x], adding usage constraints, reducing relationship types, and adding usage guidance. FHIR-I minutes for 2025-04-07 record the FHIR-50010 persuasive vote. The current source reflects that later decision: source/datatypes/relatedartifact.xml now defines artifact[x] and related constraints/guidance rather than the two publication fields, while source/fhir.ini records the fields as R5-to-R6 removals. Companion issue FHIR-26689 concerned R4/FHIR-us-qm extensions and is outside this core R6 reconciliation.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing publicationStatus or publicationDate into core RelatedArtifact would undo the later Applied R6 simplification decision rather than complete FHIR-26690.

Recommendation:
Keep this audit as-is for core. If publication metadata for R4 quality-measure usage needs further review, handle it in the appropriate IG or extension-pack scope rather than in the current core RelatedArtifact datatype.
