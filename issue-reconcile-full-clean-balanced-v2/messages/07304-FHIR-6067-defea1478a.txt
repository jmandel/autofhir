Issue request:
FHIR-6067 is a Published FHIR-core change request with resolution Persuasive with Modification. It asked to split the original Supply resource; the final resolution says Supply was split into SupplyRequest and SupplyDelivery, both remaining Draft resources, with follow-up trackers for adjacent scope questions.

Initial application:
The issue appears to have been applied before this reconciliation. Git commit 1594fb6cad29ec60b476d6167a1f7bf6a810291b is explicitly titled "#6067Split Supply into SupplyRequest and SupplyDelivery" and added SupplyRequest and SupplyDelivery entries to source/fhir.ini plus related resource metadata. The Jira resolution also says the split was pre-applied.

Additional context:
The current core build no longer includes Supply, SupplyRequest, or SupplyDelivery as active resources. source/fhir.ini lists only the old Supply resource under [removed-resources], and SupplyRequest/SupplyDelivery have no active [resources] entries. Later commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed the OO supply resources from core build configuration and retargeted core narrative links to the HL7 OO Incubator continuous build. Current source pages such as workflow-module.html, resourceguide.html, and ballot-intro.html now point to https://build.fhir.org/ig/HL7/oo-incubator/StructureDefinition-SupplyRequest.html and StructureDefinition-SupplyDelivery.html. Those pages identify the external source as https://github.com/HL7/oo-incubator/.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. Restoring or editing core SupplyRequest/SupplyDelivery definitions would be out of build scope for the current core specification; any definition-level follow-up now belongs in the OO Incubator repository, while core already points readers there.

Recommendation:
Keep this empty audit commit as-is. Do not reintroduce Supply, SupplyRequest, or SupplyDelivery into core for FHIR-6067. If future review finds stale links or needed content changes, update core links only when the OO Incubator URL changes and make resource-definition changes in HL7/oo-incubator.
