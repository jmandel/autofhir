FHIR-28349: Audit Ingredient comment application

Issue request:
FHIR-28349 was Published/Persuasive with Modification for FHIR-core MedicinalProductIngredient/Ingredient. It asked to add a note element for additional information about a particular ingredient component, such as removal during processing or adjustment for loss on drying. The final resolution kept the markdown 0..1 capability, and Jira comments record that the applied element name should be Ingredient.comment rather than Ingredient.note or Ingredient.description.

Initial application:
The issue was applied before this reconciliation. Commit 6c2a9ba943 first added the requested markdown 0..1 content as Ingredient.description. Jira comments then recorded the naming concern, FHIR-I approval for using comment, and full application with the name comment; commit 24da22b3ea renamed the element to Ingredient.comment, and commit 701913e842 added the build suppression confirming this non-Annotation comment element was intentional.

Additional context:
Ingredient is active in the current build through source/fhir.ini, and fhir.ini also maps the old MedicinalProductIngredient artifact name to Ingredient. The current source/ingredient/structuredefinition-Ingredient.xml contains Ingredient.comment with markdown type, cardinality 0..1, and the examples from the Jira request. suppressed-messages.txt contains the Ingredient.comment Annotation-warning suppression. The earlier FHIR-31810 decision removed the old Ingredient.description element; an existing combined-branch audit for FHIR-31810 confirms that later FHIR-28349 intentionally added a separate comment element rather than restoring description.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the authoritative current core source already implements the final WG outcome for FHIR-28349, including the approved element name, type, cardinality, and build warning suppression.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-28349 unless the work group later reopens the naming/modeling question; any future change should preserve the distinction from the removed Ingredient.description element.
