FHIR-3715: Audit Procedure used supplies support

Issue request:
FHIR-3715 was a Published Patient Care change request with a Persuasive with Modification resolution asking how to represent supplies used during a procedure. The accepted resolution called for an optional repeating used element on Procedure that could carry either a code or references to Device, Medication, or Substance, and noted device wording should distinguish supplies from implanted or removed focal devices.

Initial application:
The issue was applied in SVN r4981, imported as git commit f734eb20e9cea5803c519475780be919724f148f, which added Procedure.used as 0..* Reference(Device|Medication|Substance) with the short "Items used during procedure" and a definition for medications, devices, and substances. Later Procedure.used history refined that initial application without removing the seed intent.

Additional context:
FHIR-9821 later split the element into usedCode and usedReference to satisfy the code-or-reference part of the same design. R5/R6 source now represents that pair as Procedure.used CodeableReference, with fhir.ini mapping both Procedure.usedCode and Procedure.usedReference to Procedure.used. FHIR-22800 added BiologicallyDerivedProduct as another material target. FHIR-31539 confirms the R5 CodeableReference form was already the accepted current-state expression. Community searches found no FHIR-3715-specific contradiction; hits were later Procedure.used discussions and notifications.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Procedure is an active resource in source/fhir.ini, and the active Procedure StructureDefinition already has Procedure.used 0..* CodeableReference(Device|Medication|Substance|BiologicallyDerivedProduct), an item-used definition, an example binding for codes, and notes explaining incidental devices such as scalpels, gauze, and endoscopes versus focal devices handled by Procedure.focalDevice.manipulated.

Recommendation:
Keep this audit as-is. The current source conveys the requested supplies-used capability through the authoritative Procedure definition and nearby notes; adding redundant prose would not change implementer understanding and would increase maintenance drift.
