FHIR-17506: Audit Provenance agent type terminology

Issue request:
FHIR-17506 was Published/Persuasive for STU3 and asked that the Provenance.agent.type value set include HL7 v3 ParticipationType concepts while properly attributing the existing Provenance agent vocabulary to W3C PROV.

Initial application:
No current git commit explicitly mentioning FHIR-17506 was found. The active Provenance source now binds Provenance.agent.type to http://hl7.org/fhir/ValueSet/participation-role-type, and the relevant value set history shows the Security WG later applying the Provenance agent vocabulary through the participation-role-type value set rather than through a FHIR-17506-tagged change.

Additional context:
Later Published issues changed the same terminology family. FHIR-22494 aligned Provenance.agent.type with AuditEvent.agent.type and the ParticipationRoleType value set. FHIR-28218 corrected the moved Provenance participant value set canonical to the THO http://terminology.hl7.org/ValueSet/provenance-agent-type URL. Most importantly, FHIR-32519 explicitly changed Provenance.agent.type to a Preferred binding and directed removal of RoleCode, RoleClass, and ParticipationType from the value set, leaving only the THO Provenance participant value set and DICOM Audit codes. Existing combined-branch audit commits already represent FHIR-22494 and FHIR-32519.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source is consistent with the later FHIR-32519 decision: Provenance.agent.type remains bound to participation-role-type, whose source composes THO provenance-agent-type and DICOM Audit codes and no longer includes v3 ParticipationType directly. Reintroducing v3 ParticipationType for FHIR-17506 would reverse a later Published Security WG decision.

Recommendation:
Keep this audit commit as-is. Do not add v3 ParticipationType back to Provenance.agent.type unless the Security WG opens a new terminology change that supersedes FHIR-32519 and the THO Provenance participant terminology.
