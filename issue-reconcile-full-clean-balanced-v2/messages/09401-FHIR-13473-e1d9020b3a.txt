FHIR-13473: Audit extension JSON template slicing text

Issue request:
FHIR-13473 was a Published/Persuasive STU3 FHIR-core correction asking for strange generated text in extension-definition JSON templates to be removed. The reported output showed an empty Extension.extension array rendered as `// sliced by value:url in the specified orderOpen` with confusing brackets, and the comments clarified that the problem applied to all extension pages rather than only the example 11179/DataElement page.

Initial application:
The issue was applied in svn revision 12694, now visible in git as be4ab1e77319083d7653c1ba5e02c1c5ee3deff9 (`#13473 - clean up json slicing text`). That commit changed the old in-repository JsonSpecGenerator so empty sliced content closes the array on the same line and so slicing text includes punctuation instead of concatenating the rule display directly onto `order`.

Additional context:
The old in-repository generator source was deleted in 2021 when publishing moved to the Kindling dependency. The current build declares `org.hl7.fhir:kindling` in build.gradle.kts and `kindlingVersion=1.25.5-SNAPSHOT` in gradle.properties; current Kindling JsonSpecGenerator retains the applied FHIR-13473 logic. The current core extension template only injects the generated `<%json%>` block and does not contain the bad text, and exact searches of current core source and the read-only extension-pack checkout found no active occurrence of `specified orderOpen` or `sliced by value:url` requiring a FHIR source edit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical application matches the Jira request, the current build path delegates JSON-template generation to Kindling where the fix is present, and no current in-scope FHIR source carries the reported malformed template text.

Recommendation:
Keep this audit commit as-is. If malformed extension JSON templates reappear in generated output, investigate and fix HL7/kindling or the publisher dependency rather than editing FHIR narrative/template files in this checkout.
