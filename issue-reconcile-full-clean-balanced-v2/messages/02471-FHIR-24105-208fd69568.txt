FHIR-24105: Audit medication supportingInformation descriptions

Issue request:
FHIR-24105 was Published/Persuasive for R5 and asked why MedicationAdministration.supportingInformation and MedicationDispense.supportingInformation exist in core when the descriptions did not explain their purpose. The Pharmacy WG decided the elements were part of the 80% and resolved to keep them while updating the MedAdmin and MedDispense descriptions with better examples.

Initial application:
The Jira comment records the work as committed on 2019-12-12 in HL7/fhir commit 80c2f73ea490c414129d8406d6d00d4e94af04c0. That commit expanded the old medicationadministration and medicationdispense spreadsheet definitions with the heart-rate-at-administration example and the lab-test/weight-before-dispense example. The later R5 source rework in 33b409a4b6d544598262f2f074ebb4b6dc466157 moved those descriptions into the current StructureDefinition XML source.

Additional context:
source/fhir.ini actively includes medicationadministration and medicationdispense as current resources. Current MedicationAdministration.supportingInformation describes height/weight and a conditional heart-rate administration scenario, and current MedicationDispense.supportingInformation describes lab-test and patient-weight documentation before dispensing. Pharmacy meeting minutes from 2019-11-25 confirm the WG found inpatient and outpatient use cases and chose to leave the elements in. Direct Zulip searches found no issue-specific or conflicting community discussion. Other Jira keys in the 80c2f73 commit concern separate pharmacy changes and were not decided here.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the current active source already contains the explanatory examples required by FHIR-24105, and further wording cleanup would be editorial rather than required to preserve the WG decision.

Recommendation:
Keep this audit commit as-is. If a future Pharmacy WG review wants to polish wording such as the nested quote example or spelling of heartrate, handle that as a separate editorial tracker rather than as unfinished FHIR-24105 work.
