FHIR-11338: Audit Goal outcome wording

Issue request:
FHIR-11338 was a Published/Persuasive DSTU2 Patient Care change request for FHIR-core Goal. It asked to clarify the Goal.outcome short description from "What was end result of goal?" to the accepted wording "What result was achieved regarding the goal?"

Initial application:
The issue was applied in commit f39dde8e171836d3345715f788c746e0a1624492, which changed the Goal spreadsheet source short name for Goal.outcome to the accepted wording. Later source rework carried that wording into the current StructureDefinition source when Goal.outcome still existed.

Additional context:
Goal is still an active resource in source/fhir.ini, but the current source no longer exposes Goal.outcome as an active element. FHIR-37262 was later Applied with a resolution to remove Goal.outcome and use the resource-pertainsToGoal extension instead; commit 0d8e3756353bd8c0e93994eea043a54216ae2f37 commented out the Goal.outcome element in source/goal/structuredefinition-Goal.xml. FHIR-53828 then confirmed the R6 replacement guidance by adding Goal narrative notes that point implementers to resource-pertainsToGoal for resources such as Observation that measure, achieve, or track progress toward a goal. FHIR-54318 is a duplicate of that later migration-guidance issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. There is no active Goal.outcome short description in the current build that still needs the FHIR-11338 wording, and the old commented block already has the accepted text. Adding more prose for FHIR-11338 would duplicate the newer R6 extension guidance rather than correct current implementer-facing content.

Recommendation:
Keep this audit commit as-is for FHIR-11338. Any future change to restore or further explain goal outcome modeling should be handled under the later R6 Goal outcome/removal decisions, not as additional work for this DSTU2 wording clarification.
