FHIR-13844: Audit SNOMED CT time-version guidance

Issue request:
FHIR-13844 was a Published/Persuasive FHIR-core Vocabulary issue for STU3. It asked the "Using SNOMED CT with FHIR" Version issues text to make explicit that SNOMED CT version-specific URI values can include a UTC time part, rather than only a YYYYMMDD release date.

Initial application:
The issue was initially applied in git commit 1c78b00bec05517930a344e47fe16f8da21d4786 / svn r13448, which added a note to source/snomedct.html that time may appear in the version in YYMMDDThhmmssZ format. The same section was immediately refined by neighboring SNOMED CT URI commits and retained by the later FHIR-15721 SNOMED-on-FHIR group review commits.

Additional context:
A later Published/Persuasive page update, FHIR-17649, removed the timestamp sentence while applying SNOMED International/SNOMED-on-FHIR requested updates to the same page. Vocab minutes on 2018-10-11 then recorded that SNOMED CT version identification and time parts in the URI needed further discussion. In R5, FHIR-35933 and UP-289 moved the external-code-system "Using X" pages from FHIR core to HL7 Terminology (THO), and source/snomedct.html was deleted from this repository. Current FHIR core source keeps only the SNOMED CT usage summary and links from terminologies-systems.html to https://terminology.hl7.org/SNOMEDCT.html for authoritative guidance.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No FHIR core source was changed because the page named by FHIR-13844 is no longer in the current FHIR build, and adding partial SNOMED CT version guidance to the remaining core summary/link pages would duplicate or override the THO-owned page.

Recommendation:
Keep this core audit commit as-is. If the FHIR-13844 clarification should still be carried forward, handle it as THO/UTG work against the current SNOMEDCT.html Versions section, with explicit review of the FHIR-17649 removal and the 2018-10 Vocab note that time parts needed further discussion.
