Issue request:

Initial application:
The issue was applied in commit dfe20c1cb32be225c03639320b6c377955889f20, which changed source/observation/observation-spreadsheet.xml from extension-Observation-focusCode.html to extension-observation-focuscode.html. That spreadsheet source was later removed when Observation moved to structuredefinition-Observation.xml for the R4B/current build source.

Additional context:
Observation is an active resource in source/fhir.ini, so source/observation/structuredefinition-Observation.xml is the current authoritative source to check. Later history first carried a corrected/canonicalized focusCode link in the StructureDefinition and then removed the old focusCode guidance from the current Observation.focus comment during related Observation.focus reconciliation. The observation-focusCode extension itself now lives in the FHIR Extension Pack and has since been deprecated/retired through FHIR-44333, so core should not restore the old link merely to mirror STU3 wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The broken link reported by FHIR-17795 is therefore not present in the current build source.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-17795; any future work on observation-focusCode belongs to the FHIR Extension Pack or to a new OO decision about the deprecated extension, not to this historical broken-link correction.
