FHIR-16051: Audit Provenance W3C model wording

Issue request:
FHIR-16051 was Published/Persuasive for FHIR-core Provenance, raised against STU3. It reported that the Background and Context list explaining the W3C Provenance model incorrectly included "Target" even though Target is a FHIR Provenance concept rather than a W3C PROV model concept. The requested correction was to remove the Target bullet from the W3C list and describe target separately as FHIR Provenance usage.

Initial application:
The issue was applied by git commit 9071f6d0d16cb86417520b9023adce221aaff3cf, which explicitly mentions GF#16051 and removed the Target bullet from source/provenance/provenance-introduction.xml. The separate FHIR Provenance paragraph below the W3C list already described the set of resources generated by the activity as target, so the one-line deletion addressed the misleading W3C list placement.

Additional context:
Provenance is an active resource in source/fhir.ini and source/provenance/provenance-introduction.xml feeds the current build. Later Provenance decisions, including FHIR-23065, FHIR-55409, and FHIR-55410, refined the same W3C/FHIR explanatory text by clarifying .target/.entity notation and adjusting Entity/Activity wording. Those later changes preserve FHIR-16051's key distinction: the W3C model list contains Entity, Agent, and Activity, while FHIR .target is explained separately afterward. Exact Zulip and Confluence searches for FHIR-16051 found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/provenance/provenance-introduction.xml no longer has a Target bullet in the W3C list and already has the separate FHIR .target paragraph immediately after that list, so further editing would only restate correct current guidance.
