Issue request:
FHIR-2853 was Published with a Persuasive resolution for the Initial Draft/DSTU1 DiagnosticReport context. It asked to add narrative where extension or contained-resource serialization is described, and to ensure the schema no longer allowed extensions on the contained element.

Initial application:
The Jira comments report SVN revision 3027 as the application, noting that narrative was added and the schema already did not allow extensions. In git history this is commit b943ef0d57fd306f7de05120bcae928dc9841f86, which added the contained-element extension prohibition to source/references.html.

Additional context:

Quoted Jira/Zulip/Confluence searches found only the seed Jira and no later community record that changes this conclusion.

Recommendation:
Keep this audit commit as-is. No follow-up source change is needed for FHIR-2853 unless the work group later wants to revisit contained-resource serialization rules more broadly.
