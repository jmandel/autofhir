FHIR-23003: Audit revenue center example codes

Issue request:
FHIR-23003 is Applied/Persuasive with Modification for Financial Management. It originally raised IP concerns about ex-revenue-center and ex-diagnosis-on-admission example CodeSystems, but the final 2022 resolution narrowed the requested current-build action to changing only ex-revenue-center codes to made-up values.

Initial application:
The issue was initially applied in core by f7b4d814e2, which replaced the historical revenue center concepts with three example concepts and also changed diagnosis-on-admission concepts under the broader earlier resolution. A later core commit, 5c0494aacf, removed both CodeSystem source files from the FHIR core build as part of the UTG/THO migration, leaving only the active Claim/EOB ValueSet source files in core.

Additional context:
FHIR-22116 is the earlier NUBC attribution issue for the same revenue example codes; its resolution comment says the codes in question were removed. Current source/fhir.ini keeps Claim and ExplanationOfBenefit in build scope, and the current source ValueSets point to terminology.hl7.org CodeSystems rather than carrying local concept lists. The current THO ex-revenue-center CodeSystem has three sample concepts: 0010 Vision Clinic, 0011 Dental Clinic, and 1001 Emergency. The current THO ex-diagnosis-on-admission CodeSystem is outside this core source checkout and is not part of the final FHIR-23003 core source change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR core source no longer contains the infringing revenue-center CodeSystem concepts or any local revenue-center concept list to update, and the external current terminology surface already reflects made-up revenue-center examples.

Recommendation:
Keep this audit commit as-is for FHIR core. No core source follow-up is needed for FHIR-23003; any future desire to revisit ex-diagnosis-on-admission terminology should be handled as a separate THO/UTG work item, not as a core source edit under this narrowed applied issue.
