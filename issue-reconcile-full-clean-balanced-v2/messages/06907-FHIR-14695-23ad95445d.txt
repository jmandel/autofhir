FHIR-14695: Audit jurisdiction ValueSet expansion link

Issue request:
FHIR-14695 was a Published/Persuasive STU3 Vocab issue for the 2018-Jan Core ballot. The reported problem was that http://hl7.org/fhir/2018Jan/valueset-jurisdiction.html#expansion showed a publication-tooling failure instead of an expansion because urn:iso:std:iso:3166 was not supported. The Jira resolution says this was addressed during the May 2018 ballot QA phase and the value set now expands with content shown properly.

Initial application:
No commit explicitly mentioning FHIR-14695 or 14695 was found in the FHIR source history, so this appears to have been applied through ballot QA/tooling rather than a Jira-tagged source commit. Historical source did define source/terminologies/valueset-jurisdiction.xml, and the R5 published page for the core Jurisdiction ValueSet rendered an expansion rather than the original error.

Additional context:
Later same-family issues FHIR-18280 and FHIR-20375 reported the same jurisdiction expansion failure for urn:iso:std:iso:3166:-2 and were also resolved as fixed/known tooling work; FHIR-31537 was later Resolved - No Change because the current build expanded successfully. UP-521 and TI minutes then moved the deprecated core jurisdiction ValueSet to THO. Current core source no longer has source/terminologies/valueset-jurisdiction.xml, active non-SVG source references use http://terminology.hl7.org/ValueSet/jurisdiction, and the current THO rendered page shows a jurisdiction expansion. Some checked-in generated-looking SVG diagrams still contain valueset-jurisdiction.html links, but the authoritative XML/spreadsheet bindings point to THO and diagram-only edits are outside this reconciliation threshold.

AutoFHIR reconciliation:
Made no source changes. The current core source is already aligned with the resolved issue: the old core jurisdiction expansion page is no longer an active core source artifact, active bindings use the THO jurisdiction ValueSet, and the published THO page renders expansion content for the same CLD.

Recommendation:
Keep this empty audit commit. No core source follow-up is recommended for FHIR-14695. If a future jurisdiction expansion or rendering problem recurs, handle it through THO/UTG or the terminology tooling rather than reintroducing a core ValueSet or manually editing generated SVG links.
