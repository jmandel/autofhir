FHIR-3821: Audit external ValueSet expansion case sensitivity extension

Issue request:
FHIR-3821 was Published/Persuasive with Modification for DSTU1 ValueSet expansion metadata. It asked for a way to report whether a code system is case sensitive in an expansion, suggesting a code-system manifest and moving version there; the final resolution was to add an extension in the ValueSet extensions, applied as svn revision 3596.

Initial application:
The issue was applied in the historical source by git-svn commit d075dc8341a89d03d90cc8ac6b787cee543c174e, which added a caseSensitive boolean extension scoped to ValueSet.expansion.contains in source/valueset/valueset-extensions-spreadsheet.xml. That old core spreadsheet was later deleted during the R4B/new-build source rework, so the absence of the spreadsheet in the current core checkout is not itself a missed application.

Additional context:
ValueSet is an active core resource in source/fhir.ini. The current core ValueSet source now records expansion inputs through ValueSet.expansion.parameter and says that persisted expansions SHALL include the CodeSystems, CodeSystem Supplements, and ValueSets used, including versions. The case-sensitivity extension requested by FHIR-3821 is now maintained in the FHIR Extension Pack as input/definitions/ValueSet/StructureDefinition-valueset-caseSensitive.xml, with context ValueSet.expansion.contains and a boolean value. Later FHIR-40719 clarified that extension in the extension-pack source, confirming that this artifact is still the intended representation for the case-sensitive assertion.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the core FHIR checkout. The remaining issue artifact is external to this repository and is already present in the FHIR Extension Pack; adding duplicate core prose or recreating the old core extension spreadsheet would be misleading.

Recommendation:
Keep this external-repo audit commit as-is. Future changes to the valueset-caseSensitive extension should be made in the FHIR Extension Pack, not in the core ValueSet source, unless the work group separately decides that the core ValueSet narrative needs an explicit cross-reference.
