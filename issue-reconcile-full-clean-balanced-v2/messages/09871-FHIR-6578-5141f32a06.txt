FHIR-6578: Audit NamingSystem terminology bundle history

Issue request:
FHIR-6578 was a Published/Persuasive DSTU1 FHIR-core change request asking to publish a bundle of all NamingSystems used in the specification, analogous to the then-available ValueSet distribution. The resolution was "do this," and the Jira comments identify SVN revision 6408 as the application.

Initial application:
Git-svn commit 3a825375d3c60a8b71bce5ae52893d251b04c409 corresponds to SVN revision 6408 and explicitly says "#6578 - add naming system registry for code systems." It added source/namingsystem/namingsystem-terminologies.xml as a Bundle of NamingSystem resources for code systems and registered it in the old NamingSystem spreadsheet source.

Additional context:
Later Published/Persuasive issue FHIR-37889 intentionally reversed the ongoing presence of the NamingSystem terminology and identity-system example bundles for R5 because the content duplicated material authoritatively maintained in HL7 Terminology and could become misleading. Commit 76c99d3aaec99d971f19b9a464838c0c62dbf199 removed the terminology bundle content and most registry content. FHIR-40117 then confirmed the remaining empty namingsystem-registry.xml file should not exist because naming systems are managed by THO, and commit ededc6fc845f772bb45c2d3b1e4e7b105c2e3d19 deleted it. The combined branch already contains separate reconciliations for FHIR-37889, FHIR-40117, and the closely related FHIR-6783.

AutoFHIR reconciliation:
This is an empty audit commit. Current source has NamingSystem active in source/fhir.ini, but source/namingsystem no longer contains namingsystem-terminologies.xml or namingsystem-registry.xml and the examples list no longer references those bundle examples. Restoring the FHIR-6578 bundle would conflict with later final Vocabulary and FHIR-I decisions that moved authority for these identifiers to THO.

Recommendation:
Keep this no-change audit as-is. No current core FHIR source change is needed for FHIR-6578; any future machine-loadable NamingSystem distribution for external terminology identifiers should be governed through THO/TSMG rather than restoring the removed core bundle examples.
