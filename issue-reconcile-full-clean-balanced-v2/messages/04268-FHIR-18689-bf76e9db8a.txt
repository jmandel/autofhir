FHIR-18689: Audit ValueSet activity status date disposition

Issue request:
FHIR-18689 was a Published Vocab change request, resolved Persuasive for STU3, asking to support the VSD Activity Status Date by changing the prior ValueSet expiration-date extension to activityStatusDate and updating the definition to match VSD semantics.

Initial application:
Commit 4907f9bcb0b710cb2837a93a20c4b23210a37249 explicitly listed GF#18689 and updated source/valueset/valueset-extensions-spreadsheet.xml by adding an activityStatusDate row with the VSD-oriented definition and explanatory comment. During the later source refactor, commit 33b409a4b6d544598262f2f074ebb4b6dc466157 carried that extension forward as source/valueset/structuredefinition-extension-valueset-activityStatusDate.xml and referenced StructureDefinition/valueset-activityStatusDate from the ValueSet core IG.

Additional context:
The related Published issue FHIR-28450 later renamed the artifact to valueset-status-activityStatusDate, and FHIR-34258 later removed that extension from core after ValueSet.effectivePeriod and related metadata-resource work made the VSD activity-status-date extension obsolete. The combined branch already contains no-change audit commits for FHIR-28450 and FHIR-34258. Current core still builds ValueSet, but the ValueSet core IG has no activityStatusDate extension resources and the active ValueSet StructureDefinition includes ValueSet.effectivePeriod. The only activityStatusDate-family StructureDefinition found now is a retired/deprecated FHIR Extension Pack artifact, with the extension-pack disposition still under unresolved FHIR-49169.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing a core activityStatusDate extension for FHIR-18689 would conflict with the later final removal decision in FHIR-34258, and the current core source already lacks active activityStatusDate extension definitions while retaining the replacement first-class timing element.

Recommendation:
Keep this no-change audit for core FHIR. Do not restore the historical core extension for FHIR-18689; any future clarification of the retired extension-pack artifact should proceed through FHIR-49169 or another final FHIR-extensions decision.
