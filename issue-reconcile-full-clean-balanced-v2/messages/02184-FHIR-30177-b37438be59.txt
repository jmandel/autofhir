FHIR-30177: Audit Statistic count datatypes

Issue request:
FHIR-30177 was Published/Persuasive for R5 and asked to change Statistic.numberOfEvents, Statistic.sampleSize.numberOfStudies, Statistic.sampleSize.numberOfParticipants, and Statistic.sampleSize.knownDataCount from integer to unsignedInt so sample and event counts cannot be negative.

Initial application:
The request was initially applied by commit 9040dbb48bc7 ("Changes to the Evidence Resource and Statistic DataType and EvidenceReport Resource", J#30094 #J30177), which changed the four rows in the then-current source/datatypes/statistic.xml spreadsheet from integer to unsignedInt. No prior Issue-Reconcile-Key commit for FHIR-30177 was present on the combined branch.

Additional context:
Statistic no longer exists as a standalone current datatype source. FHIR-31866 moved the Statistic content into Evidence.statistic, and FHIR-31564 removed source/datatypes/statistic.xml and OrderedDistribution. The current build has Evidence active in source/fhir.ini and no current Statistic spreadsheet or StructureDefinition source. The active Evidence source carries the four requested elements forward as Evidence.statistic.numberOfEvents, Evidence.statistic.sampleSize.numberOfStudies, Evidence.statistic.sampleSize.numberOfParticipants, and Evidence.statistic.sampleSize.knownDataCount, all typed unsignedInt. FHIR-31493 is an adjacent count-guidance issue already represented on the combined branch and does not alter these four type requirements.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source already preserves the approved FHIR-30177 datatype change after the Statistic-to-Evidence refactor, and editing the removed spreadsheet would be out of current build scope.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-30177 unless the work group reintroduces a standalone Statistic datatype or changes the Evidence statistic count model.
