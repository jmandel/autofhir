FHIR-29264: Audit variable extension scope

Issue request:
FHIR-29264 was Published/Persuasive for R5 and asked to clarify that a variable declared with the variable extension is in scope on the node where it is defined, not only while processing descendant nodes. The Jira description pointed to the R4 variable extension page and noted that the existing ordering guidance only made sense if later variable extension repetitions on the same node could use earlier ones.

Initial application:
The issue was applied in core by commit 3e19d7d0b3f6c4984d28b8741c1a7246924dc60f, which updated source/profiles/general-extensions-spreadsheet.xml so the variable extension definition added "as well as extensions within the same element" to the prior descendants-only wording. Commit c37de616d7 later normalized the spreadsheet while preserving that text.

Additional context:
The variable extension definition was later removed from the core FHIR source as part of the R5 extension source move in commit dd468d4f1799dd79819315b211588ef1cf4586e0. The authoritative current definition now lives in the FHIR Extension Pack, whose README says it defines standard extensions referenced by FHIR core and is maintained as a separate specification. The current Extension Pack source still contains the same-element wording and the ordering-significant comment. Same-change-family issue FHIR-29329 has already been audited on the combined branch and confirms the same interpretation.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Current core source has no active variable extension StructureDefinition to edit, while the authoritative external extension source already carries the requested same-node/same-element scope clarification. Editing core would either touch only residual registry data or duplicate externally owned extension text.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-29264; any future change to the variable extension's computable definition should be made in the FHIR Extension Pack.
