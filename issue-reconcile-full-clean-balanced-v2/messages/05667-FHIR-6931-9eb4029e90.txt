FHIR-6931: Audit Organization preferred contact state

Issue request:
FHIR-6931 was a Published FHIR-core Organization change request from DSTU1, resolved Persuasive with Modification. It asked for a boolean standard extension on Organization.contact to mark the preferred contact for a purpose, and for the Organization Contact Purpose value set binding to be relaxed from required to a recommended extensible value set.

Initial application:
Commit 608a3b87d0ba3f1e6b99d05d0be7def789cd49c0, "Tracker# 6931, organization standard extensions", added the organization preferredContact standard extension to the Organization extension spreadsheet with context Organization.contact and boolean value semantics. The same historical Organization spreadsheet carried the ContactPartyType binding to valueset-contactentity-type as extensible.

Additional context:
Organization remains an active resource in source/fhir.ini and current source/organization/structuredefinition-Organization.xml makes Organization.contact an ExtendedContactDetail. FHIR-29034 moved Organization.contact from an inline backbone to ExtendedContactDetail, and FHIR-29035 later defined ExtendedContactDetail.purpose with the contactentity-type value set at preferred strength, superseding the older Organization-specific binding location and strength. The original organization-preferredContact extension no longer lives in core source after the R5 extension migration; it is in the FHIR Extension Pack, where FHIR-50768/FHIR-49912 context records its deprecation in favor of contact priority/rank-style preference handling.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core build already preserves the useful Organization contact-purpose semantics through ExtendedContactDetail.purpose, and the historical standard extension is now maintained outside this checkout and has later deprecation/replacement guidance. Reintroducing or editing the old Organization-specific extension in core would be out of build scope and would conflict with later applied decisions.

Recommendation:
Keep this empty audit commit as-is for FHIR-6931. Any remaining work to finish the later FHIR-50768/FHIR-49912 deprecation/replacement path belongs to those issue records and the FHIR Extension Pack, not to a FHIR-6931 core source change.
