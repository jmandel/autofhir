FHIR-41181: Audit detailed-definition element links

Issue request:
FHIR-41181 is an Applied/Persuasive FHIR-core change request from FHIR-I. It asked for the detailed definitions tab to expose links for individual elements, because anchors such as imagingstudy-definitions.html#ImagingStudy.started existed in the DOM but users had no visible link affordance on the detailed definitions page.

Initial application:
No HL7/fhir source commit explicitly mentioning FHIR-41181 was found. The apparent application is in the external Kindling generator: HL7/kindling commit 78d6ba5652a8943ba0ba8dc8f1fc386b70227a1d, dated 2025-02-28 and titled "FHIR-41181 Show links to elements in detailed definitions page", changed DictHTMLGenerator.java so detailed dictionary rows emit a self-link href and SVG icon beside each element name.

Additional context:
FHIR-I minutes for 2023-11-06 record the work group discussion as "Anchor was missing from the element details tab, oversight" and the Persuasive vote. The current HL7/fhir checkout builds through the Gradle kindling dependency and already includes CSS for .self-link-parent/.self-link. ImagingStudy is an active resource in source/fhir.ini, and the current build.fhir.org ImagingStudy detailed definitions page renders the ImagingStudy.started row with a self-link anchor icon. The R5 published page lacked that row-level link, matching the original problem statement.
