FHIR-15647: Audit ICD period-format guidance

Issue request:
FHIR-15647 was a Published/Persuasive with Modification STU3 Vocabulary change request asking whether ICD code formatting should be normalized or constrained. The final resolution was to say explicitly on the ICD-10 page that the form with the period, such as 123.4, is required for conformance.

Initial application:
The request was applied in the historical FHIR-core source by git-svn commit 36036280db3b94ad603d4d97ca2a019286de349c, which added the exact sentence "ICD codes SHALL be represented with the period included, e.g. 123.4" to source/icd.html. The Jira comments also record svn revision 14644, matching that commit.

Additional context:
The detailed "Using ICD-[X] Codes with FHIR" page that received the original edit is no longer maintained in this FHIR-core checkout. FHIR-35933 later removed the old external-code-system usage pages from core and redirected authoritative external terminology guidance to HL7 Terminology (THO). Current core source keeps the build-scoped Code Systems page and ICD SID pages, marks Defined Externally content as non-authoritative, and links the ICD row to the THO ICD guidance page. The current THO ICD page still carries the exact period-required conformance wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Duplicating the conformance sentence into source/sid-icd-10.html would put detailed external-terminology usage guidance back into core after the approved THO migration, while the current core table already directs implementers to the authoritative THO page that contains the rule.

Recommendation:
Keep this audit commit as-is. If the ICD period-format guidance needs future maintenance, handle it through the THO/UTG source for the "Using ICD with HL7 Standards" page rather than by reintroducing detailed ICD usage prose into FHIR core.
