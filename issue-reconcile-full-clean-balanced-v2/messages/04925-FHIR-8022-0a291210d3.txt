FHIR-8022: Audit Medication.code terminology binding

Issue request:
FHIR-8022 was a Published/Persuasive FHIR-core Pharmacy issue from the 2015 May DSTU1 ballot. It reported that the value set linked from Medication.code appeared to contain route-of-administration codes and asked that it be updated to medication codes; the approved resolution was to fix the terminology binding to SNOMED CT medication concepts, stated at the time as concept is-a 410942007.

Initial application:
The issue was applied in historical source. Commit 6ce87fde09500c2d61c86a07ac98f49037e7d747, titled "#8064 - fixed Medication.code exemplar valueset", changed source/medication/valueset-medication-codes.xml from SNOMED CT route-of-administration concept 284009009 to 410942007. The same ballot-change family also references FHIR-8022 directly in commit 534313123abc479f1c95a22956d9992582f9743c, and FHIR-8064 records itself as a duplicate of FHIR-8022 for Medication.code.

Additional context:
Medication is an active current-build resource in source/fhir.ini. Current source/medication/structuredefinition-Medication.xml binds Medication.code to http://hl7.org/fhir/ValueSet/medication-codes. The current ValueSet is no longer the exact 2015 root code: later Pharmacy terminology work, including commit 055e6c67af51c6ea21726fe2c7ed0539dc1fdd4d for FHIR-8435 and commit 51ce8a822f639be478cea8655beab71f95afb6ab for GF 19294, refined the exemplar from 410942007 to a medication/product-oriented definition now expressed as SNOMED CT concept is-a 763158003. That later refinement does not reintroduce route codes and supersedes the exact 2015 wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative Medication source already uses the medication-codes value set for Medication.code, and that value set contains a medicinal-product SNOMED CT hierarchy rather than the route-of-administration hierarchy that FHIR-8022 identified.

Recommendation:
Keep this audit commit as-is. Do not revert the current 763158003 root to the older 410942007 wording solely for FHIR-8022; the seed issue's required correction was the removal of the route-code value set, and later applied terminology history refined the medication-code exemplar.
