FHIR-39005: Audit external Patient merge response example

Issue request:
FHIR-39005 was a Published FHIR-core Patient issue resolved Persuasive with Modification for R5. It asked for the Patient $merge response example to be a Parameters resource containing at least the input parameters and merged Patient, and for the OperationOutcome out-parameter description to state that OperationOutcomes are optional except when preview = true.

Initial application:
The request was applied in core before R5. Commit f81504c568640ecff36ef240d3f3812f13c4bff3 changed source/patient/$merge-response.txt from a bare Patient to a Parameters response with input, outcome, and result parts. Commit bc0518825da9aee1f84d428e12b00f40103608c2 then replaced the single out parameter with named input, outcome, result, and tracking out parameters, including the preview-specific OperationOutcome requirement.

Additional context:
The current core build no longer owns OperationDefinition/Patient-merge. source/patient/list-Patient-operations.xml lists Patient-match and Patient-purge but not Patient-merge, source/patient/operationdefinition-Patient-merge.xml has been deleted, and commit b487fdda4bb4a5382a93dbb5a811efd02425b9bc relinked Patient merge narrative to the external HL7/admin-incubator continuous build. The external HL7/admin-incubator source currently has the corrected $merge-response.txt example, but its OperationDefinition-Patient-merge.xml still has the old single return out parameter and old OperationOutcome bullet, so any remaining live correction belongs in that external IG repository rather than this core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Editing the orphaned core response/example files would not affect the current core build, and reintroducing the removed OperationDefinition would conflict with the later move to the Administrative Incubator IG.

Recommendation:
Keep this external-repo audit in core. If PA wants the current linked operation page to retain the full FHIR-39005 application, follow up in HL7/admin-incubator by porting the bc0518825 out-parameter restructuring or an equivalent OperationOutcome clarification there.
