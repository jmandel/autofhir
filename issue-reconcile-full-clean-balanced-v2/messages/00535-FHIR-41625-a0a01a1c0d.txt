The Jira comment points to HL7/fhir-extensions pull request #29. In the extension-pack repository, commit f34e5e1e11b7d14fe955c9b7d1f5c4bb15d6e7af added the CRMI extension definitions and merge commit 5c841d473e2219cb7d6848f89ccc1ea4350c2692 merged that pull request. Additional context:
The current FHIR core source states that extensions moved to the separate hl7.fhir.uv.extensions package and that the extensions pack is the source of truth for clinical-reasoning extension descriptions. The fhir-extensions checkout defines the FHIR Extensions Pack IG as hl7.fhir.uv.extensions and currently contains StructureDefinition sources for every extension named by FHIR-41625. Core source retains supporting links and OID registrations for many of these canonicals, but the authoritative extension definitions are outside this core checkout.
