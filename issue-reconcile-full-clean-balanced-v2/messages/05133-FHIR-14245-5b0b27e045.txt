FHIR-14245: Audit ConceptMap URI search parameters

Issue request:
FHIR-14245 was Published/Persuasive with Modification for R5. It asked whether ConceptMap `source-uri` and `target-uri` reference search parameters were erroneous because they searched URI choice elements, and the final Vocab decision approved the attached ConceptMap search-parameter changes.

Initial application:
The original Zulip discussion concluded the STU3 reference-typed URI search parameters looked like a mistake. The applied source commit 1b5b44719301018908cbec59de2ac76177570c54 changed the active ConceptMap search-parameter bundle by renaming the source/target scope parameters and adding URI-typed `source-scope-uri` and `target-scope-uri` parameters for `ConceptMap.sourceScope as uri` and `ConceptMap.targetScope as uri`.

Additional context:
FHIR-12902 introduced the canonical datatype and explains why canonical references may be searched as reference parameters, while the older same-family FHIR-13739 was marked applied by that superseding canonical/reference work. ConceptMap is active in the current build, and the current StructureDefinition defines `ConceptMap.sourceScope[x]` and `ConceptMap.targetScope[x]` as `uri | canonical(ValueSet)`. The current CI-rendered search page exposes `source-scope-uri` and `target-scope-uri` as URI parameters and no longer exposes the old `source-uri`/`target-uri` reference parameters.

AutoFHIR reconciliation:
This audit commit makes no source change. The current source id/code/type/expression entries and the generated search page already satisfy the issue's semantic request, so adding or changing normative source text would be redundant. Residual source-side `build/SearchParameter/...` placeholder URL asymmetries for the source-side entries do not change the built search surface and are not a necessary FHIR-14245 correction.

Recommendation:
Keep this no-change audit. If the work group wants internal search-parameter placeholder URL cleanup, handle that as a separate consistency issue rather than as part of FHIR-14245.
