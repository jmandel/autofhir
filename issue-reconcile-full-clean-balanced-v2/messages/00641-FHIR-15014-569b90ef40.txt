FHIR-15014: Audit current-job indicator outside core

Issue request:
FHIR-15014 is Published/Persuasive with Modification for FHIR-core OccupationalData. It asked for a way to distinguish current from past entries in OccupationalData.pastOrPresentJob because dates were optional; the recorded resolution was to add a status of active for current jobs and completed for historical jobs.

Initial application:
No FHIR-core commit mentioning FHIR-15014 or adding ODHIsCurrentJobExtension was found in the current checkout history. PHWG meeting notes still listed FHIR-15014 as previously resolved but not applied in February 2022, and the later Jira comment says application was completed in ODH version 1.1 and retained in 1.2 by adding ODHIsCurrentJobExtension to the US ODH Past or Present Job profile.

Additional context:
Current FHIR core does not build OccupationalData. source/fhir.ini has no active OccupationalData resource/profile entry and records only the deleted-resource note `; OccupationalDataforHealth=pending -> Dropped`; the leftover source/occupationaldata files are therefore historical/out-of-build. The FHIR Extension Pack checkout also has no ODHIsCurrentJob or PastOrPresentJob content. The published US ODH package-list identifies hl7.fhir.us.odh as the active external IG, and the current PastOrPresentJob profile contains Observation.extension:ODHIsCurrentJobExtension, a 0..1 boolean extension at http://hl7.org/fhir/us/odh/StructureDefinition/odh-isCurrentJob-extension.

This commit intentionally makes no source change in FHIR core and records FHIR-15014 as external-repo. Editing the stale core OccupationalData source would not affect the current build, and adding equivalent core text would duplicate content now owned by the US ODH IG.
