FHIR-7253: Audit ConsentDirective profile replacement by Consent

Issue request:
FHIR-7253 was a Published FHIR-core Contract change request from the 2015May ballot, resolved Persuasive with Modification, saying the old ConsentDirective profile on Contract violated DSTU2 profile rules, lacked scope and examples, used generic Contract bindings, and was not implementable as-is. The final resolution was that the specification had moved on to Consent as a Resource.

Initial application:
No source commit explicitly citing FHIR-7253 was found. The repository history shows the pre-resolution Contract-profile path in commits fce5366537, a2e2c1b6c1, and 0db745f2d6, followed by the Consent-resource replacement path in acc3f3137b, ba3db96597, and 1264e32b13. In the current build configuration, Consent is active, the deleted-resource note says ConsentDirective became Consent, and there is no active fhir.ini profile entry for source/contract/consentdirective.profile.xml.

Additional context:
FHIR-7871 is the same change family and asks why Contract was being used for consent directives; it was resolved by the same Consent-resource replacement. Later FHIR-19529 intentionally says Consent should be used where it applies and, if a Contract also exists for a consent directive, the Consent shall reference the Contract. FHIR-23719 later removed Advance Directives from Consent scope, so old advance-directive expectations should not be revived through this Contract profile issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active specification has moved to Consent as a resource, and the old ConsentDirective profile source is not referenced by the active fhir.ini profiles list. Editing that out-of-build profile or removing later Contract examples would not be a current-spec correction for FHIR-7253.

Recommendation:
Keep this no-change audit. If the work group wants to delete dormant source files or change active Contract examples and Contract/Consent guidance, that should be handled under a specific current issue such as Contract cleanup/removal work, not under this historical ConsentDirective-profile audit.
