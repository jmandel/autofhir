FHIR-50382: Add protein supplement frequency

Issue request:
FHIR-50382 is Applied/Persuasive for R6 and asks for NutritionOrder examples to include more implementer- and clinician-facing details, specifically noting that the protein supplement example needs frequency added. The OO Nutrition group voted 7-0-0 to apply the attached example revisions.

Initial application:
Commit 7d20f33c77f467f4a6b0a596d195b5e0f744dd74 explicitly applied FHIR-50382 by updating NutritionOrder examples. That commit touched the protein supplement example, but it removed the only frequency from an invalid additive.schedule representation and left the current example as NutritionOrder.additive, which has no schedule or instruction element.

Additional context:
source/fhir.ini actively includes NutritionOrder in the current build. The current NutritionOrder structure defines supplement as the oral nutritional product component and provides supplement.schedule.timing plus supplement.instruction for frequency and administration instructions; additive is for modular components and has no schedule. Confluence OO Nutrition minutes confirm the WG reviewed and voted on corrected example revisions, and no relevant Zulip discussion was found that changes that conclusion.

AutoFHIR reconciliation:
Changed the protein supplement example to use NutritionOrder.supplement, preserving the protein product coding, product name, and scoop quantity while adding a three-times-per-day supplement schedule and instruction to take one scoop with meals. This fixes the visible unresolved portion of the applied request using the current build-scoped model instead of reintroducing invalid additive scheduling.

Recommendation:
Keep this source fix. If the WG wants modular additive-specific scheduling in addition to oral supplement scheduling, that would require a separate model decision because the current additive backbone has no schedule or instruction element.
