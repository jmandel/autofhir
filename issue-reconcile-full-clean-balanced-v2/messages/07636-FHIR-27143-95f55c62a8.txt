FHIR-27143: Audit SubscriptionTopic search parameter status

Issue request:
FHIR-27143 was Applied/Persuasive with Modification for R5 after SubscriptionTopic search parameters appeared normative even though SubscriptionTopic was not then a normative resource. The approved fix was to distinguish the standards status of a shared SearchParameter definition from the standards status of each non-normative base resource where that parameter appears, and to have the search table reflect the resource-specific status.

Initial application:
No commit explicitly mentioning FHIR-27143 was found. The same policy was implemented through the closely related FHIR-25744 trail: commit fede0a935133 changed SubscriptionTopic search parameter standards-status extensions from normative to trial-use, matching the non-normative SubscriptionTopic status then present in the source. Later SubscriptionTopic search-parameter commits, including FHIR-39633, preserved trial-use status while restoring and adjusting the SubscriptionTopic search parameters.

Additional context:
The current R6 source no longer has the condition that triggered the issue. Commit 270e0ceb7b changed SubscriptionTopic's StructureDefinition standards status from trial-use to normative as part of R6 normative changes, and commit 9987f9c0c3 subsequently changed the SubscriptionTopic search parameter bundle from trial-use back to normative. The current CI rendering also presents SubscriptionTopic with Standards Status = Normative, so the current normative search parameter display is consistent with the current resource status rather than a stale non-normative-resource mismatch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source has SubscriptionTopic in build scope through source/fhir.ini, marks the resource normative, and marks the resource's search parameters normative. Reverting the search parameters to trial-use would conflict with the later R6 normative-status source change.

Recommendation:
Keep this audit commit as-is for FHIR-27143. If the R6 normative promotion of SubscriptionTopic itself is later reconsidered by FHIR-I, revisit the resource standards status and its search parameter statuses together; do not change only the search parameter bundle in isolation.
