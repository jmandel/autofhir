FHIR-22494: Audit Provenance agent type vocabulary

Issue request:
FHIR-22494 was Published/Persuasive with Modification for FHIR-core Provenance. It asked that Provenance.agent.type use a sufficient vocabulary aligned with AuditEvent.agent.type, specifically changing to http://hl7.org/fhir/ValueSet/participation-role-type while retaining the existing useful Provenance-specific codes.

Initial application:
No explicit source commit mentioning FHIR-22494 was found. In current R5/R6 source history, 33b409a4b6d introduced source/provenance/structuredefinition-Provenance.xml with Provenance.agent.type already bound to participation-role-type. The R4B draft line in c69d71aa213d still used provenance-agent-type, and aa9defa3c842 later added the THO provenance-agent-type value set into participation-role-type alongside the AuditEvent DICOM source.

Additional context:
Provenance and AuditEvent are active build resources in source/fhir.ini. Later Published issues FHIR-32519 and FHIR-32451 refined the same agent.type binding family by narrowing participation-role-type and using Preferred binding strength; FHIR-32519 is already represented on the combined branch and has updated Provenance.agent.type to preferred. FHIR-53882 later clarified AuditEvent.agent.type wording only, without changing the shared value set. The linked Zulip thread and Security WG minutes confirm that FHIR-22494's purpose was to use the AuditEvent value set for Provenance.agent.type.

AutoFHIR reconciliation:
Made no source change. Current source/provenance/structuredefinition-Provenance.xml binds Provenance.agent.type to participation-role-type, source/auditevent/structuredefinition-AuditEvent.xml binds AuditEvent.agent.type to the same value set, and source/terminologies/valueset-participation-role-type.xml includes the old provenance-agent-type value set plus DICOM CID 402. Adding more prose would be redundant and might conflict with later, narrower wording decisions.

Recommendation:
Keep this empty audit commit as-is. No core source follow-up is needed for FHIR-22494; any future attempt to further align Provenance.agent.type wording with the 2026 AuditEvent clarification should be handled under a separate Security WG decision, not this 2019 vocabulary issue.
