FHIR-15773: Correct Bundle.identifier comment wording

Issue request:
FHIR-15773 was a Published/Persuasive FHIR-core change request for STU3. It reported that Bundle.identifier used "batch" where it meant "bundle" in both the definition and comments, with the approved resolution to correct the wording to Bundle.

Initial application:
The definition was corrected before this reconciliation: commit ec03877d31 (GF#16918, svn 14391) changed "A persistent identifier for the batch" to "A persistent identifier for the bundle" in the old Bundle spreadsheet, and later source conversions preserved that definition wording. The adjacent comment was not corrected and still said persistent identity matters for "batches of type Document, Message, and Collection" in the active XML source.

Additional context:
FHIR-16918 is a same-family Published/Persuasive tracker for the definition wording only and confirms the same source location and implementation commit. Bundle is an active resource in source/fhir.ini, so source/bundle/structuredefinition-Bundle.xml feeds the current build. Community searches found only tracker-bot Zulip mentions for FHIR-15773/FHIR-16918 and no Confluence decision that changes the Jira/source conclusion.

AutoFHIR reconciliation:
Updated the active Bundle StructureDefinition comment to say "bundles of type Document, Message, and Collection". The later phrase "processing batches and transactions" was left unchanged because it refers to actual Bundle.type values.

Recommendation:
Keep this source fix. It completes the approved correction without changing Bundle.identifier semantics beyond replacing the erroneous generic "batches" wording in the comment.
