FHIR-20591: Audit item-control display code ownership

Issue request:
FHIR-20591 was a Published/Persuasive FHIR-core Questionnaire change request. It asked to change the questionnaire-item-control code system's abstract code from 'text' to 'display' and to update the descriptions of that code and its descendants so they aligned with the earlier Questionnaire.item.type rename.

Initial application:
The Jira comment identifies commit 1532bb00b6, which changed source/questionnaire/codesystem-questionnaire-item-control.xml by replacing the abstract item-control code 'text' with 'display' and updating the descendant definitions from text-item wording to display-item wording. Later same-artifact history continued to alter the item-control code system, including FHIR-21023 removing the prompt code.

Additional context:
The current core build has Questionnaire active, but it no longer has an active questionnaire-item-control CodeSystem, ValueSet, or StructureDefinition source. The tracked core source only retains OID and conversion/history references for questionnaire-item-control; commit dd468d4f17 removed source/questionnaire/codesystem-questionnaire-item-control.xml and source/questionnaire/valueset-questionnaire-item-control.xml as part of moving extension material out of the R5 source. The current authoritative item-control artifacts are in the separate FHIR Extension Pack checkout. There, the parent code is already 'display'; one deprecated descendant prompt definition still begins "Text is displayed", so any further wording cleanup would be an extension-pack change, not a core source change.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Reintroducing or editing the questionnaire-item-control artifacts in this repository would be outside the current core build ownership; the seed is recorded as external-repo for the current FHIR core checkout.

Recommendation:
Keep this audit commit as-is for core. If the work group wants exact descendant wording parity with the original resolution, file or apply a follow-up in the FHIR Extension Pack for CodeSystem-questionnaire-item-control.xml; do not restore the retired core item-control source files.
