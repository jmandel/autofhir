FHIR-11301: Audit vital signs qualifier guidance

Issue request:
FHIR-11301 was a Published/Persuasive with Modification OO change request raised against the DSTU2 vital signs profile page. It asked whether several LOINC vital-sign variation variables should be added; the final resolution narrowed that to including LOINC names in the vital signs table and adding the spreadsheet-identified measurement qualifiers as notes/comments rather than as additional table rows.

Initial application:
The explicit historical application is git fad3d2f2fa, labeled "[11301],[11300](partial)". That commit updated the active Observation vital signs introduction table, added the "LOINC Name and Comments" column, changed the vital signs panel code, and added qualifier guidance in row comments instead of creating independent rows for the requested variation variables.

Additional context:
The current vital signs introduction is in build scope through the active vitalsigns IG and Observation source. FHIR-11300 is the same 2017 panel/table change family and provides the companion panel-code and all-LOINC-name context. Later Applied OO issues FHIR-32787 and FHIR-32788 revisited the same supplemental-code guidance: body weight was clarified as an Observation.component or linked Observation, while FHIR-32788 directed removing the blood-pressure supplement sentence rather than adding more modeling guidance. The combined branch already contains the FHIR-32788 reconciliation commit d696144c46. Current source retains the non-blood-pressure qualifier guidance and LOINC names, and no longer tells readers to use the blood-pressure variation codes from the original FHIR-11301 request.

AutoFHIR reconciliation:
Made no source change. The current active vital signs table already reflects the durable part of FHIR-11301, and re-adding the original blood-pressure qualifier list would conflict with the later FHIR-32788 OO decision.

Recommendation:
Keep this no-change audit commit as-is. Do not use FHIR-11301 to reintroduce the removed blood-pressure qualifier sentence; any future guidance for blood-pressure method/site/cuff/device modeling or instrument inventory identifiers should be handled as new OO work rather than by reopening this DSTU2 table-note request.
