FHIR-11310: Audit Sequence quantity clarification

Issue request:
FHIR-11310 was a Published/Persuasive Clinical Genomics change request from the DSTU2 Sequence ballot asking what Sequence.quantity meant. The accepted clarification was that Quantity meant the number of copies of the sequence of interest for RNASeq.

Initial application:
The change was applied in historical commit 5ab7990995, which revised source/sequence/sequence-spreadsheet.xml for both FHIR-11309 and FHIR-11310. That commit replaced the vague Sequence.quantity wording with "The number of copies of the seqeunce of interest. (RNASeq)" in the Sequence spreadsheet.

Additional context:
Sequence later became MolecularSequence, and the clarified quantity text was carried into source/molecularsequence/structuredefinition-MolecularSequence.xml. Published later issue FHIR-36085 then removed MolecularSequence.quantity, and commit d4613dfa1 removed the element with a commit message explicitly naming quantity removal. In the current source, Sequence appears only in [removed-resources], molecularsequence is commented out in fhir.ini, and core narrative points implementers to external MolecularDefinition material rather than an active core Sequence/MolecularSequence resource.

AutoFHIR reconciliation:
This commit intentionally makes no source change. There is no active current-core Sequence.quantity or MolecularSequence.quantity definition to update, and reintroducing the retired clarification would conflict with later published cleanup that removed the element.

Recommendation:
Keep this audit commit as-is. No current FHIR core source change is needed for FHIR-11310; any future copy-count semantics should be handled through the active MolecularDefinition/Clinical Genomics work rather than by reviving the retired Sequence.quantity element.
