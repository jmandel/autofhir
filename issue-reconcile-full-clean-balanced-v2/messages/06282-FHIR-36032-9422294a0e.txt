FHIR-36032: Audit transaction link replacement clarification

Issue request:
FHIR-36032 was a Published FHIR-core HTTP change request with resolution Not Persuasive with Modification. The submitter asked whether transaction processing should continue requiring servers to update non-Reference fields such as uri, url, oid, uuid, and narrative href/img links; the final decision retained required replacement for matching links in specified locations, clarified exact-match/# URL behavior, added Composition.section.text, and made markdown replacement a SHOULD.

Earlier FHIR-13823/FHIR-13990 history explains why url/uri/reference/canonical behavior was in scope; FHIR-34343 touched neighboring version-specific reference behavior but not this replacement rule; later FHIR-53999 is Triaged and unresolved, so it is background only and does not supersede the Published FHIR-36032 disposition.
