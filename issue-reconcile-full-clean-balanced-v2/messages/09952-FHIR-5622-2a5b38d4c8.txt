FHIR-5622: Audit OperationOutcome issue coding history

Issue request:
FHIR-5622 was a Published/Persuasive FHIR-core OperationOutcome change request from DSTU1. It asked to replace the then-current OperationOutcome issue type Coding with a CodeableConcept so senders could include a required base IssueType code plus more specific local codes.

Initial application:
The issue was applied by git-svn commit 62514b59c1089b4bde7edf6e204c9c1957484a9c, svn revision 4488, which changed OperationOutcome.issue.type to OperationOutcome.issue.code, made it 1..1, changed its type to CodeableConcept, and updated the example accordingly.

Additional context:
The same artifact was later reconsidered by Published/Persuasive with Modification issue FHIR-8449. Its approved resolution changed OperationOutcome.issue.code from CodeableConcept back to primitive code with a required IssueType binding, added OperationOutcome.issue.details as the CodeableConcept extension point for local codes, and renamed the old details text to diagnostics. Commit 8f9d370156502bee2cc1371a3c97f28a1588ed2a applied that later decision. The active current source/fhir.ini includes operationoutcome as a built resource.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current OperationOutcome source reflects the later governing decision: issue.code is a required primitive code bound to IssueType, issue.details is CodeableConcept for additional/local detail codes, and current examples use primitive issue.code with optional details CodeableConcept content.

Recommendation:
Keep this audit commit as-is. Do not restore FHIR-5622's original CodeableConcept issue.code shape unless the work group explicitly reverses FHIR-8449 or adopts a new OperationOutcome coding model.
