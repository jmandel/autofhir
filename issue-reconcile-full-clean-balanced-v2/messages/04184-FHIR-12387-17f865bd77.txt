FHIR-12387: Audit MedicationAdministration workflow harmonization

Issue request:
FHIR-12387 was a Published Pharmacy change request, resolved Persuasive with Modification for DSTU2, asking to harmonize MedicationAdministration with the Workflow Event logical model. The approved resolution called for a definition/protocol link to ActivityDefinition and PlanDefinition, partOf references to MedicationAdministration and Procedure, the unknown status code, Group as a subject target, a context element for Encounter or EpisodeOfCare, and a performer backbone with role/function and actor details.

Initial application:
The Jira comments say the spreadsheet changes were applied on 2017-01-14. Git commit 7003eba639b96a6cb1198300f293effe3f4bda1d is the matching source application: it updated the MedicationAdministration spreadsheet and examples, adding MedicationAdministration.definition, partOf, unknown status, subject Reference(Patient|Group), context Reference(Encounter|EpisodeOfCare), and a repeating performer backbone with role, actor, and an initial onBehalfOf placement. Follow-up commit 6aceb453fc5da56a92144d6de12c118e3b891ef0 corrected that onBehalfOf placement under performer for FHIR-12631.

Additional context:
Later final Pharmacy/workflow decisions reshaped the same area rather than leaving FHIR-12387 partly unapplied. FHIR-14022, applied in commit b22fbdaff11417e468a75c0657ffec6170e99c1f and already audited on the combined branch, realigned MedicationAdministration to the updated Workflow Event pattern by replacing definition with instantiates, adding not-done/statusReason/performer.function, and removing performer.onBehalfOf. Current FHIR also moved the old generic instantiatesCanonical/instantiatesUri mechanism to more specific workflow relationship extensions, now maintained in the FHIR Extension Pack, and records prior-version guidance in the workflow extension notes. MedicationAdministration remains active in source/fhir.ini, so the current StructureDefinition is the authoritative build-scope source.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active MedicationAdministration source already includes the surviving FHIR-12387 semantics: partOf references MedicationAdministration and Procedure, status includes unknown, subject allows Group, performer is a backbone with function and actor, and the resource is mapped to Workflow Event with documented Event mapping exceptions. Reintroducing the old definition/context/onBeHalfOf shape would conflict with later applied workflow alignment and current extension guidance.

Recommendation:
Keep this no-change audit as-is. Do not reopen FHIR-12387 unless Pharmacy or Workflow decides to supersede the later FHIR-14022 alignment or to add a new current MedicationAdministration-specific workflow definition relationship.
