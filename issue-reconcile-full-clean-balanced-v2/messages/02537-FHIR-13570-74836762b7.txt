FHIR-13570: Audit Provenance entity identifier guidance

Issue request:
FHIR-13570 was a Published/Persuasive with Modification Security change request for STU3 asking to clarify when Provenance.entity.whatUri and whatIdentifier should be used, to change Provenance.agent URI choices to Identifier choices, to remove Provenance.entity.whatUri as redundant with whatIdentifier, and to state that Reference should be used when a FHIR resource is known or when an identifier is for something that could be a FHIR resource, otherwise Identifier should be used.

Initial application:
FHIR-13694 first clarified Reference.identifier in commit ae45563ea5abedd261338cf4ff404a07a722d4ed. FHIR-13570 was then applied in commit f72fd6237875c6ba9d2a21e235881c7fed559700, which changed Provenance.agent.who/onBehalfOf from uri|Reference choices to Identifier|Reference choices and removed Provenance.entity.whatUri by changing Provenance.entity.what[x] from uri|Reference(Any)|Identifier to Identifier|Reference(Any). The current source no longer has those STU3 choice elements.

Additional context:
Later FHIR-15659 was Published/Persuasive and implemented in commit 6c0a0563b3ac6a188b713f2f1a04ff26229100cf, simplifying Provenance.agent.who, Provenance.agent.onBehalfOf, and Provenance.entity.what from Identifier|Reference choices to plain Reference elements now that Reference.identifier covers logical references. The combined branch already contains an AutoFHIR FHIR-15659 reconciliation commit. FHIR-49893 later corrected the current Provenance.entity.what comment from whatIdentity to what.identifier without reintroducing a separate Identifier or URI choice. FHIR-13571, the parallel AuditEvent request, was resolved no-change based on FHIR-13694.

AutoFHIR reconciliation:
Made no source change. In the active current build, source/fhir.ini lists Provenance as an active resource, source/provenance/structuredefinition-Provenance.xml defines Provenance.agent.who, Provenance.agent.onBehalfOf, and Provenance.entity.what as Reference elements, and source/datatypes/reference.xml contains the logical-reference guidance from FHIR-13694. Reintroducing whatUri/whatIdentifier or separate agent Identifier choices would reverse the later FHIR-15659 decision rather than complete FHIR-13570.

Recommendation:
Keep this empty audit commit. The current specification should remain Reference-based; any future clarification should be handled as a new targeted Provenance/Reference wording issue rather than as a delayed application of the retired STU3 choice-element model.
