FHIR-25283: Audit evaluatedResource Resource reference wording

Issue request:
FHIR-25283 was a Published/Persuasive CQI change request for R5 MeasureReport.evaluatedResource. It asked to replace the old definition, "A reference to a Bundle containing the Resources that were used in the calculation of this measure," with wording reflecting the repeating structure: references to the Resources used in the calculation.

Initial application:
The issue was applied in d14f95267ae327335084154ede0ae1374aab146d, part of PR #2301 merged as fb1432b6921ab1318d4cfb5fc91e93ab0d5ddbff, changing the active MeasureReport StructureDefinition definition from a Bundle reference to "A reference to a Resource that was used in the calculation of this measure." A closely related earlier commit for FHIR-27026 had briefly allowed either a Resource or Bundle, but the FHIR-25283 application removed the Bundle wording.

Additional context:
MeasureReport is active in source/fhir.ini, and source/measurereport/structuredefinition-MeasureReport.xml is the authoritative in-build source for the element. The current combined branch defines MeasureReport.evaluatedResource as 0..* Reference(Resource) and its definition now says individual reports reference subject-specific resources, while data-exchange reports reference data-of-interest submitted or collected for the measure. Later Published CQI issue FHIR-34033 refined the same element's bounded report-scope wording without restoring the obsolete Bundle description. Zulip and Confluence searches found no directly relevant or conflicting community record for FHIR-25283.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies FHIR-25283's semantic request: evaluatedResource is no longer described as a reference to a Bundle, and the repeating Resource references are conveyed by the element's 0..* Reference(Resource) type plus the current definition text.

Recommendation:
Keep this audit commit as-is. No additional core source work is needed for FHIR-25283 unless CQI later changes the approved MeasureReport.evaluatedResource report-scope model.
