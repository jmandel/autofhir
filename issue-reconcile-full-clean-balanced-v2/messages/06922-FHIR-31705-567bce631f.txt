FHIR-31705: Audit terminology binding examples tab

Issue request:
FHIR-31705 was a Published FHIR-core change request for the R4B ballot. It reported that the Terminology/Operations navigation skipped the 4.2 tab between "Using Codes" and "Code Systems" and asked for the default tab to become 4.1. The final Persuasive with Modification resolution required making the "Binding examples" page a distinct tab between 4.1 and 4.3, while intentionally leaving the Terminologies link default pointed at the terminology list/code systems area.

The terminology hierarchy already had the binding examples page, and later cleanup in d78907197b3fbbbafead95cc5d551aded6e3435c normalized its position between Using Codes and Code Systems.
