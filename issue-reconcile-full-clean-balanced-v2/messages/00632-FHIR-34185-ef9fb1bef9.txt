FHIR-34185: Align Invoice issuer definition

Issue request:
FHIR-34185 was an Applied/Persuasive FM change request for FHIR-core Invoice asking to add Practitioner and PractitionerRole as targets for Invoice.issuer and to change the description to "Issuing entity".

Initial application:
The issue was partially applied by commit 70ed0d12c18dcf477ba9bd45271276d7365c7b09, merged by 542aeed5cc68390bd842f9bce2b74c40a18fe797, which added Practitioner and PractitionerRole targetProfile entries and changed the short text to "Issuing entity". The authoritative element definition still said "The organizationissuing the Invoice." and the checked-in Invoice SVG diagram still showed only Organization, so the current source remained semantically inconsistent with the applied decision.

Additional context:
Invoice is in current build scope through active source/fhir.ini [resources] and [draft-resources] entries, and Practitioner and PractitionerRole are active resources. The originating Zulip thread records the same real-world need for invoices issued by a practitioner or organization. No Confluence reference or conflicting community evidence was found.

AutoFHIR reconciliation:
Updated source/invoice/structuredefinition-Invoice.xml so Invoice.issuer is defined as the entity issuing the Invoice, matching its Organization, Practitioner, and PractitionerRole targets. Aligned source/invoice/invoice.svg with the same wording and target list as part of the independently necessary authoritative XML fix, so the resource diagram no longer contradicts the StructureDefinition.

Recommendation:
Keep this commit as-is. The change completes the already-applied target expansion and removes the remaining implementer-facing contradiction without requiring further work-group review.
