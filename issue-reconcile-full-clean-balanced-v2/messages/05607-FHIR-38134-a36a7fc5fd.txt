FHIR-38134: Audit mustSupport inheritance guidance

Issue request:
FHIR-38134 is a Published FHIR-core R5 change request resolved Persuasive. It asked for the Must Support / Implementation Obligations section of the profiling page to state whether the meaning of mustSupport is inherited when one implementation guide or profile depends on another: base-artifact mustSupport meanings apply to elements marked mustSupport in the base artifact, while elements newly marked mustSupport in the derived artifact use the derived IG/profile meaning unless the derived artifact references ancestor mustSupport artifacts.
