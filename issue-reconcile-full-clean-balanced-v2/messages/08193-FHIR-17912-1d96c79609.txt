FHIR-17912: Audit moved styleSensitive extension scope

Issue request:
FHIR-17912 was Published/Persuasive with Modification for the core rendering-styleSensitive extension. The approved change was to limit the extension context to Resource, update the definition/comment so unsupported style/markdown/xhtml rendering prevents appropriate resource rendering, add SDC-specific guidance, ensure SDC ValueSet/CodeSystem profile usage, and document ValueSet expansion implications for related rendering extensions.

Initial application:
The core source was changed in the historical GF#17912 application path. Commit f7bcd0a0a8 (merged by 0cdfeece69) updated source/profiles/rendering-extensions-spreadsheet.xml with context Resource and the revised definition/comment text, alongside related Questionnaire/SDC work.

Additional context:
The current core build no longer owns the extension definition. The R5 history page records that extensions moved to the hl7.fhir.uv.extensions package, and current core source only retains the rendering-styleSensitive OID. The active Extension Pack definition now lives at input/definitions/Element/StructureDefinition-rendering-styleSensitive.xml, carries the updated definition/comment and SDC link, but still declares context element/Element rather than Resource. R4/R4B generated history shows the same broad Element context, and a 2019 Questionnaire Zulip thread explicitly called that broad context wrong, with Lloyd McKenzie saying it should likely apply to Resource while SDC expects root Questionnaire use. Later SDC decisions deprecated rendering-styleSensitive in favor of rendering-criticalExtension, but they do not put the core extension source back into this repository.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. A source fix for the remaining context mismatch would have to be made in the FHIR Extension Pack, not in the current core checkout. Editing core source/oids.ini or the now-empty rendering extension profile would not alter the authoritative extension definition.

Recommendation:
Keep this commit as an external-repo audit for core. If the remaining FHIR-17912 context requirement is still desired despite later SDC deprecation work, update the Extension Pack definition by moving rendering-styleSensitive to the Resource context (or otherwise changing its StructureDefinition.context expression to Resource) and consider reviewing the malformed closing parenthesis in its linked comment text at the same time.
