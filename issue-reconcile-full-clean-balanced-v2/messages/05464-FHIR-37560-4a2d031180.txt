FHIR-37560: Audit symptom observation category external terminology

Issue request:
FHIR-37560 is Applied/Persuasive with Modification for R6 and asks to add `symptom` to the Observation Category ValueSet with display "Symptom" and the definition "A symptom is a manifestation of a disease apparent to and communicated by the patient."

Initial application:
No core source commit mentioning FHIR-37560 was found. Current core source already delegates Observation Category code content to external terminology: `source/observation/valueset-observation-category.xml` includes all codes from `http://terminology.hl7.org/CodeSystem/observation-category`, and the active `Observation.category` definition binds with preferred strength to `http://hl7.org/fhir/ValueSet/observation-category`.

Additional context:
FHIR-34408 is the same Applied change family and also requested an updated `exam` definition. FHIR-50889 and FHIR-52872 are later Applied R6 issues for the same symptom category request and are already represented on the combined branch by external-repo audit commits. UP-717 was an earlier unresolved UTG request, but UP-738 superseded it in practice and is Proposal Implemented for the THO/UTG Observation Category CodeSystem. UP-738 lists FHIR-37560 in comments, adds `symptom`, and applies an editorially refined symptom definition that preserves the Jira intent. Current THO and the current FHIR build expansion include `symptom` from CodeSystem observation-category version 2.0.0.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the FHIR core checkout. The requested concept belongs to the external THO/UTG Observation Category CodeSystem, while core already imports that CodeSystem wholesale in the Observation Category ValueSet and uses that ValueSet for the active Observation.category binding.

Recommendation:
Keep this audit commit as-is for FHIR core. Do not duplicate the THO CodeSystem concept in core source; any remaining follow-up belongs to THO/UTG release or package-version coordination if the external terminology publication changes.
