FHIR-41228: Audit TestPlan scope outside core

Issue request:
FHIR-41228 was Applied/Persuasive with Modification for R6. It reported that TestPlan elements using Reference or CodeableReference had empty target lists, and the accepted resolution changed TestPlan.scope and TestPlan.testCase.scope away from unconstrained Reference() to canonical targets for conformance artifacts plus markdown and uri, with a comment that including an artifact in scope means some portion of testing pertains to that artifact.

Initial application:
The issue was applied while TestPlan was still part of the core source. Commit d36f990aaa55ee14dab54d78516551729927422f changed source/testplan/structuredefinition-TestPlan.xml so TestPlan.scope and TestPlan.testCase.scope became backbone scopes with artifact[x] choices for canonical(ActivityDefinition, ActorDefinition, CapabilityStatement, ImplementationGuide, Library, Measure, MessageDefinition, OperationDefinition, PlanDefinition, Questionnaire, Requirements, StructureDefinition, SearchParameter, StructureMap, SubscriptionTopic), markdown, and uri, and added the requested scope comment. The same change updated TestPlan scope search parameters, and PR #3322 was merged by 7e3300d58765ec86b043a759cf66bf31dab94419.

Additional context:
Later TestPlan work changed the shape again: commit 80ac210e33dd10b2582e5bbcea1000bf4d4fabb4 reworked TestPlan per a committee decision in Madrid, and commit ffc1360661664da6c65749c6bd070ec67a6fac4b revised it on review. Before TestPlan left core, the scope model no longer matched the exact FHIR-41228 backbone artifact[x] shape; it used TestPlan.scope with a canonical TestPlan.scope.reference child and no longer had TestPlan.testCase.scope. Commit f9a44787c45071394532c7c2ee94d76f30f47387 then removed the testing resources from the core build and added the FHIR Testing IG to source/fhir.ini as an additional IG. Current source/fhir.ini has no active testplan=TestPlan resource entry, and current core pages link TestPlan to https://build.fhir.org/ig/HL7/fhir-testing-ig/en/StructureDefinition-TestPlan.html.

AutoFHIR reconciliation:
This empty commit records that there is no safe or necessary core source edit for FHIR-41228. The core change was applied historically, but TestPlan is no longer an in-scope core resource, and the current external TestPlan artifact is maintained outside this checkout.

Recommendation:
Keep this audit commit as-is for the core reconciliation. If the FHIR Testing IG should still carry the exact FHIR-41228 canonical/markdown/uri scope design or comment, handle that in the external testing IG source with work-group review; do not reintroduce TestPlan source to core for this issue.
