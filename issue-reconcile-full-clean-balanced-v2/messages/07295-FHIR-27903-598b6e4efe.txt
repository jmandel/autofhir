FHIR-27903: Audit List/Group distinction

Issue request:
FHIR-27903 is a Published/Persuasive with Modification FHIR-core FHIR-I change request raised against R4 List and Group. It asked to reduce ambiguity between List and Group after noting overlap in loosely coupled collections; the final resolution directed replacing the List description with examples such as problem, allergy, facility, and organization lists and adding that a List cannot be the subject of an intervention or direct action.

Initial application:
The issue was explicitly applied in commits f79aa963d84 and 33ba1604c0 on 2022-08-10. f79aa963d84 added the intervention/direct-action sentence to source/list/list-introduction.xml and expanded the StructureDefinition description; 33ba1604c0 expanded the root List definition. Current blame still points to those commits for the relevant lines.

Additional context:
FHIR-27083 is the closely related Group/List family decision: it declined merging the resources and added guidance preferring Group when a collection can be a subject of measures, observations, communications, or similar actions. The 2020 FHIR-I minutes confirm the FHIR-27903 vote. A later combined-branch audit for FHIR-14875 treats FHIR-27903 as a later clarification in the collection-resource guidance family. source/fhir.ini lists both Group and List as active and approved, so the inspected List source is in current build scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/list/structuredefinition-List.xml contains the requested expanded List description in both the resource description and root definition, and source/list/list-introduction.xml contains the requested direct-action/intervention distinction. Adding more prose would restate already-applied guidance.

Recommendation:
Keep this empty no-change audit commit as-is. Revisit only if a future work group decision asks for a new semantic constraint or for additional Group/List boundary text beyond the wording already applied for FHIR-27903 and the supporting FHIR-27083 guidance.
