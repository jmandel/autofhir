FHIR-13731: Audit Medication UCUM example fixes

Issue request:
FHIR-13731 was a Published/Persuasive STU3 Pharmacy change request asking that MedicationDispense examples stop emitting UCUM warnings for codes such as TAB, RECSUPP, gm, and patch. The Jira resolution agreed that the examples would be fixed, and the application comment says the UCUM errors were fixed in Medication, MedicationAdministration, and MedicationDispense by either using the drug-form code system or correcting the UCUM unit.

Initial application:
The issue was explicitly applied in commit 17795bbfaf5fb47e4c1961e386c5fea10e7b4926, whose subject includes "TR#13731 - UCUM units correction". That commit changed affected MedicationDispense quantities from http://unitsofmeasure.org to the v3 orderable drug-form system for TAB, RECSUPP, and patch/PATCH cases, and corrected gm to the valid UCUM code g; it also corrected related Medication and MedicationAdministration UCUM codes.

Additional context:
Medication, MedicationAdministration, and MedicationDispense are active resources in source/fhir.ini, so their source examples remain in current build scope. Later terminology maintenance updated the v3 orderable drug-form canonical to http://terminology.hl7.org/CodeSystem/v3-orderableDrugForm, but preserved the same separation between drug-form codes and UCUM units. Searches for FHIR-13731 and related UCUM/MedicationDispense terms found no Zulip or Confluence discussion that changes the Jira/source conclusion.
