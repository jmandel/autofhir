FHIR-39150: Audit Questionnaire derivedFrom guidance

Issue request:
FHIR-39150 was a Published, Persuasive with Modification FHIR-core change request for Questionnaire.derivedFrom, raised against R4 and applied for R5. It said the inherited/brief description did not match the intended constraints and asked to distinguish tight derivation, where a derived Questionnaire remains compatible with the parent, from looser inspiration-style derivation.

Initial application:
The issue was applied to core in commit f8d89d749d6a7c46299e85b47bae4269a6a3129e, which added a Questionnaire.derivedFrom comment explaining that the element covers a broad range of relationships from somewhat inspired by to fully compliant with and pointing to the questionnaire-derivationType extension. The companion extension was created in the FHIR Extension Pack in commit 60e73b11631f519530273413ff2d8bfe73836d2d.

Additional context:
Questionnaire is an active resource in source/fhir.ini, so source/questionnaire/structuredefinition-Questionnaire.xml is build-scope source. A related same-element correction, FHIR-39606, changed the short description to "Based on Questionnaire" and is already represented on the combined branch. Later FHIR-41451 revised the extension-pack derivationType extension by changing its context/type and clarifying the extends code; that issue belongs to the extension pack and does not require another core source change for FHIR-39150.
