FHIR-9793: Audit Encounter.class Daytime replacement

Issue request:
FHIR-9793 was a Published PA change request, resolved Persuasive with Modification for DSTU2. It asked to address the unclear Daytime code in the then-required FHIR Encounter Class value set by changing Encounter.class from a code to a coding, binding it extensibly to v3 ActEncounterCode, and making the old FHIR-defined value set redundant.

Initial application:
The issue was applied before this reconciliation. Commit 4a6a3e7a00257340bec67fe3186073ce734f8f1a updated the Encounter spreadsheet binding from a required local code list to an extensible v3 ActEncounterCode value set and changed Encounter examples from local class codes such as inpatient/outpatient to v3 ActCode codings such as IMP, AMB, and HH.

Additional context:
Encounter is active in source/fhir.ini, so source/encounter/structuredefinition-Encounter.xml is in current build scope. The current source defines Encounter.class as 0..* CodeableConcept with a preferred binding to http://terminology.hl7.org/ValueSet/encounter-class. Those differences from the 2016 resolution are intentional later decisions: FHIR-32342 changed Encounter.class from Coding to CodeableConcept, FHIR-32341 changed the binding from extensible to preferred and introduced a smaller EncounterClass value set, UP-344 implemented the THO terminology value set, FHIR-39147 fixed the current canonical URL, and FHIR-39014 declined reverting to required/extensible ActEncounterCode.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative Encounter source no longer contains the old Daytime/local FHIR Encounter Class binding, uses v3 ActCode-based Encounter class examples, and reflects the later published PA/UTG decisions that supersede the exact DSTU2 binding details.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-9793 unless PA separately reopens Encounter.class terminology or the THO EncounterClass value set.
