FHIR-23965: Audit ImplementationGuide example profile split

Issue request:
FHIR-23965 is a Published FHIR-core Change Request for ImplementationGuide. It asked for ImplementationGuide.definition.resource.exampleCanonical to allow multiple profile targets for an example; the final Persuasive with Modification resolution instead split example[x] into isExample 0..1 boolean and profile 0..* canonical(StructureDefinition), because conformance to a profile does not by itself make a resource an example.

Initial application:
The Jira comment initially named commit 1fbaee7964c114b5586a1cf28405bbb77642ba8e, but that nearby ImplementationGuide commit did not apply this change. The actual Jira-tagged application was a650f00b253aa468831e14177fe7ecd3a797c807, which replaced ImplementationGuide.definition.resource.example[x] with ImplementationGuide.definition.resource.isExample and ImplementationGuide.definition.resource.profile in the active StructureDefinition source. A later cleanup commit, 83a633c206c56eee8492fda361afbf6418fee8e8, updated the ImplementationGuide example instance to use profile instead of exampleCanonical.

Additional context:
source/fhir.ini lists ImplementationGuide as an active resource, so source/implementationguide/structuredefinition-ImplementationGuide.xml is in the current build scope. FHIR-I minutes from January 2020 record the approved 21-0-13 motion for isExample plus profile 0..*, and Zulip discussion in 2020 and 2021 confirms that FHIR-23965 was the intended way to support examples that validate against multiple profiles without relying on meta.profile. The only remaining current references to the old example[x] name are fhir.ini migration aliases to isExample, not active element definitions. FHIR-44784 later refined the profile wording for non-example resources and is already represented on the combined branch, so it is related context rather than a new decision here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active ImplementationGuide source already has ImplementationGuide.definition.resource.isExample as 0..1 boolean and ImplementationGuide.definition.resource.profile as 0..* canonical(StructureDefinition); the parallel manifest resource elements are also aligned. Adding another edit would be redundant and risk drifting from the already-applied R5/R6 source.

Recommendation:
Keep this empty audit commit as-is. No further core FHIR source work is needed for FHIR-23965 unless a future work group decision changes the semantics of ImplementationGuide resource profile assertions.
