FHIR-36027: Request review for perioperative category codes

Issue request:
FHIR-36027 is Applied/Persuasive for Pharmacy and asked for medication usage/statement category support to declare medications as pre-op, intra-op, and post-op for surgery-related use cases. The recorded resolution said the MedicationUsage.category value set would be updated to include the three requested values.

Initial application:
No source commit or git history entry that mentions FHIR-36027 was found in the FHIR core checkout. Pharmacy minutes from 2022-02-28 recorded FHIR-36001 and FHIR-36027 as related, with partOf and category discussed as possible ways to represent the surgical context; Pharmacy then voted FHIR-36027 Persuasive on 2022-03-07. Later UP-555 attempted the terminology update in UTG, and FHIR-51726/PR #3896 moved the MedicationRequest category CodeSystem and ValueSet back into FHIR Core and rebound MedicationStatement.category to that core ValueSet, but those later applied changes did not add pre-op, intra-op, or post-op concepts.

Additional context:
MedicationRequest and MedicationStatement are active current-build resources, and MedicationStatement.category is example-bound to http://hl7.org/fhir/ValueSet/medicationrequest-category. The current core CodeSystem at http://hl7.org/fhir/CodeSystem/medicationrequest-category contains inpatient, outpatient, community, and discharge only. UP-555 remains Proposal Draft/Unresolved and records unresolved comments about overlap with existing concepts, whether an example-bound code system should publish shared codes, and the proposed "intra" display not making its surgical meaning clear. Terminology Infrastructure minutes also said that if this is example content, it likely should not live in THO, while later Pharmacy minutes said the work group still intended to use .category for pre-op, intra-op, and post-op after getting the CodeSystem from THO to core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source is not a cleanly completed application of FHIR-36027 because the requested perioperative concepts are absent, but adding them here would require choosing code values, displays, hierarchy/overlap treatment, and definitions that the unresolved UP-555 trail explicitly left open. The safest reconciliation is a human-review audit for the applied core issue rather than inventing terminology content.

Recommendation:
Revisit FHIR-36027 with Pharmacy and Terminology Infrastructure. If Pharmacy still wants the core example CodeSystem to demonstrate these categories, resolve UP-555 or a core follow-up with explicit code values, displays, and definitions (for example, whether the middle concept is "intra" or "intra-op" and how the concepts relate to inpatient/outpatient/community), then add those concepts to source/medicationrequest/codesystem-medicationrequest-category.xml. Keep this audit commit as the current AutoFHIR disposition until that human decision is available.
