FHIR-5283: Audit retired order/request naming motion

Issue request:
FHIR-5283 was a Published/Persuasive with Modification DSTU1 OO ballot comment about inconsistent use of "order" and "request" around the retired Order resource. Its final recorded motion asked OO/PC/CDS to harmonize names by changing referral request to referral order, procedure request to procedure order, device use request to device use order, and communication request to communication order.

Initial application:
No source commit explicitly mentioning FHIR-5283 was found. The original Order page wording that caused the contradiction was later removed when commit 16997a29ca removed Order and OrderResponse for FHIR-10059 and simultaneously applied FHIR-10295's request-resource rename work. A direct follow-up, FHIR-7389, repeated that the FHIR-5283 naming motion had not been made and was ultimately resolved no-change because the Order resource had been retired.

Additional context:
Later final Jira decisions supersede the 2015 motion as current-build guidance. FHIR-10059 removed Order and OrderResponse, FHIR-10295 intentionally renamed request resources to [xxx]Request instead of [xxx]Order because they cover proposals, plans, and recommendations as well as orders, and FHIR-11092 restored NutritionOrder as a domain-specific exception. Current source/fhir.ini has active Request, CommunicationRequest, DeviceRequest, MedicationRequest, NutritionOrder, ServiceRequest, and VisionPrescription entries, lists DeviceUseRequest, DiagnosticOrder, and DiagnosticRequest under removed resources, and records DiagnosticOrder as subsumed into ServiceRequest. Current Request and resource introductions explain that requests encompass orders as well as proposals/plans and link active request resources to the Workflow Request pattern.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reapplying FHIR-5283's DSTU1 order-name motion to the current build would contradict later Published workflow decisions and active source. The current source has no remaining "orders are often called requests" wording from the retired Order page and already represents the intended current semantics through the Request pattern and active request-resource names.

Recommendation:
Keep this no-change audit as-is. No FHIR core source follow-up is needed for FHIR-5283; any future renaming of active request resources should be raised as a new current workflow/resource-specific issue rather than by reviving this retired Order-resource ballot motion.
