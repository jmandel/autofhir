FHIR-12625: Audit patient search parameter validation

Issue request:
FHIR-12625 was a Published/Persuasive DSTU2 FHIR-core issue reporting that the build no longer caught resources whose patient-capable subject reference lacked a patient search parameter. The concrete examples were MedicationStatement and MedicationRequest, and the intended fix was to restore the build warning/check for patient search parameter coverage.

Initial application:
Jira records svn revision 11446. In git history this maps to 5362a6a50040a3da339ccf786dea36204185034b, titled "#12625 - Check for patient search parameter", which added a ResourceValidator warning when a resource has subject as a Reference including Patient but lacks a patient search parameter. The current in-repository tools/java source has since moved out to Kindling, but the current build depends on org.hl7.fhir:kindling and the installed Kindling source still contains the same FHIR-12625 validation rule.

Additional context:
MedicationRequest and MedicationStatement are active resources in source/fhir.ini. Their current StructureDefinition sources both define subject as Reference(Patient, Group), and their current search-parameter bundles define patient search parameters over subject with target Patient. A bounded audit across active resource StructureDefinitions found 50 resources with either subject or patient references to Patient and no missing patient search parameter. FHIR-32876 is a later SearchParameter target-only issue in the same broad patient-search area, but it is separate from this build-coverage check and was not decided here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already contains the patient search parameters that motivated the issue, and the current build toolchain still carries the validation rule that catches the missing-parameter condition.

Recommendation:
Keep this no-change audit commit as-is. Revisit only if the Kindling dependency is replaced or if a future active resource adds a Patient-capable subject/patient reference without a patient search parameter; otherwise no core source follow-up is needed for FHIR-12625.
