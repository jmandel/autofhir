FHIR-7904: Audit Claim prescription clarification

Issue request:
FHIR-7904 was a Published FHIR-core Claim issue asking whether Claim.prescription should link to MedicationDispense rather than the prescription resource so pharmacy claims could convey actual refill/dispense details. The final Not Persuasive with Modification disposition says Claim.prescription is for the authorization for what was billed, and the claim line item should carry the required dispense details; additional examples would be added as time permits.

Initial application:
No commit explicitly tagged FHIR-7904 was found in the Claim source history. The historical source nevertheless shows the relevant application path: pharmacy Claim examples were added after the 2016 vote window, later updated to include MedicationRequest-based prescription and originalPrescription references, and the Claim.prescription definition was later enhanced in the R5 source to describe it as the document/authorization for reimbursable products and services.

Additional context:
Claim is active in source/fhir.ini, so source/claim feeds the current build. The current Claim.prescription target list remains request/authorization resources, not MedicationDispense, and the current pharmacy medication example shows dispense/refill-relevant details in supportingInfo and item/detail content. Related Published issues FHIR-7890 and FHIR-24871 clarify the prescription/originalPrescription distinction and Claim.prescription definition. Later FHIR-43308 raises a broader R6 design question about clearer line-item links to MedicationDispense, but it remains Triaged and explicitly calls for broader community review, so it does not override FHIR-7904 for this reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already preserves the FHIR-7904 resolution: Claim.prescription is an authorization reference, while pharmacy claim examples and line item fields carry the billed dispense details.

Recommendation:
Keep this no-change audit. Do not add MedicationDispense to Claim.prescription or add redundant example prose for FHIR-7904. Revisit only if a future final FM decision, such as the broader FHIR-43308 design work, is applied to the current build.
