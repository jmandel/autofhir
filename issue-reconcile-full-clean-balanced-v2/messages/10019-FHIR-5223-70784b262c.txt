FHIR-5223: Audit contained-resource inheritance clarification

Issue request:
FHIR-5223 was Published / Persuasive for a DSTU1 ballot comment on the References page's contained-resource text. The issue asked to soften the sentence "Resources that are contained inline also inherit context" to "may also inherit context" because the original wording conflicted with the later caution that subject-like elements might not mean the same thing across container and contained resource.

Initial application:
The issue was applied in git-svn revision 4512, now commit 2d61ba93352c, which changed source/references.html from "also inherit" to "may also inherit", quoted the contained resource's "subject" element consistently, and replaced the generic contradiction note with examples of related but non-identical element names.

Additional context:
FHIR-3691 then revisited the same contained-resource context-conduction concern and was applied in git-svn revision 4615, warning that FHIR had no mechanism to define or constrain inferred property conduction. FHIR-7385 later made a stronger final decision: contained resources do not inherit values from their context. Its historical application in git-svn revision 5814 changed the contained-resource section to explicit no-inheritance wording, and the current combined branch already includes a FHIR-7385 reconciliation that aligned the page introduction with that rule. source/fhir.ini actively maps the Reference type page to references.html, so this is current build-scope source.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current source no longer contains the ambiguous FHIR-5223-era "may inherit" rule; instead it states that relationships do not conduct context, contained resources follow the same no-inheritance rule, and inline contained resources do not inherit context from their parent resource.

Recommendation:
Keep this audit commit as-is. Reintroducing the older optional inheritance language would conflict with later Published guidance, so no source edit is appropriate for FHIR-5223.
