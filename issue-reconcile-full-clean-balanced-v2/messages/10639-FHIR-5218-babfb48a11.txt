FHIR-5218: Audit footer ToC link

Issue request:
FHIR-5218 was a Published/Persuasive with Modification FHIR-core DSTU1 ballot issue asking for easier linear navigation through the web specification. The accepted proposal was to add a toc.html link from the bottom of every page, labeled "Specification Map" at the time.

Initial application:
The issue was applied in historical commit 9c8cefdd39ab0146a6f0567ed4f7b0ff96085b6e, whose subject was "#5218 - how to navigate spec?" and whose patch added a footer link from the page-bottom template to <%level%>toc.html with the label "Specification Map". The footer template has since moved from source/newfooter.html to tools/templates/newfooter.html, but the bottom-page link survived as a link to toc.html in the current template.

Additional context:
Current build source lists toc.html in publish.ini, titles it "Table of Contents" in source/hierarchy.xml and source/toc.html, and includes the newfooter template on 198 source HTML pages. FHIR-7378 later asked to rename the bottom link away from "Specification Map" toward "Table of Contents"; that issue is already represented on the combined branch by e9a17c17aafc3efd540eeb612c4d512048c2d1c1 and supports not restoring the obsolete label. No relevant Zulip or Confluence records were found that would change the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current spec already has a bottom footer link to the active Table of Contents page, so the navigation improvement requested by FHIR-5218 is present, and changing the label back to "Specification Map" would conflict with the later FHIR-7378 direction.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-5218 unless future page chrome removes the footer link to toc.html.
