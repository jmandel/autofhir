FHIR-13519: Audit Practitioner qualification definitions

Issue request:
FHIR-13519 was a Published/Persuasive Patient Administration change request for STU3 Practitioner definitions. It asked for better Practitioner property definitions because short and long definitions were often the same or circular, specifically noting that Practitioner.qualification did not make clear what a qualification is and should include examples of appropriate content. The accepted resolution was to update descriptions as requested.

Initial application:
The issue was applied in source history by 85a500a375a412882d3967105ce8ada6d8ce728b, "GF#13519 - Need better definitions (for practitioner properties)", which changed source/practitioner/practitioner-spreadsheet.xml from a terse Practitioner.qualification short description to an expanded short description and added a long definition with a medical-license example. That spreadsheet source was later refactored into the current StructureDefinition XML representation.

Additional context:
Practitioner is in the current build scope: source/fhir.ini lists practitioner as an active resource owned by PA. Later PA decisions continued to refine the same qualification block: FHIR-19961 added qualification/licensure wording, FHIR-25033 added the PractitionerRole.specialty distinction comment, FHIR-36681 narrowed qualification.identifier wording, and FHIR-34375 added qualification.status and period guidance. The current source includes the expanded Practitioner.qualification short and long definitions, an explicit medical licensure example, and the specialty-vs-qualification comment. A local scan still finds some self-evident Practitioner short/definition pairs that differ only by punctuation, but they are not the specific qualification ambiguity FHIR-13519 identified and do not create a semantic defect warranting a source change in this issue. Broader duplicate-definition cleanup is also represented separately by FHIR-31798 on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current in-build Practitioner source already preserves the FHIR-13519 application and later clarifications, so adding more local prose or rewriting unrelated self-evident definitions would be broader editorial work rather than a necessary correction for this issue.

Recommendation:
Keep this audit commit as-is. No follow-up core source work is recommended for FHIR-13519 unless PA opens a new, specific editorial issue to revise additional Practitioner element definitions beyond the already-correct qualification definition.
