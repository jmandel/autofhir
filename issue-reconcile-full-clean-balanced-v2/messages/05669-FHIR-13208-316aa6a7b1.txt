Initial application:

The explicit application was git commit 9ab4222960fdd822fee328183740919341432c3a (svn revision 14640), titled "GF#13208 - fix up inactive codes", which added the HL7 usage note to the CodeSystem status section.

Additional context:
The concept-properties CodeSystem is in current build scope through the active source/fhir.ini [codesystems] entry. Later vocabulary work kept the inactive property while refining the surrounding guidance: FHIR-37849 harmonized the CodeSystem page table with the concept-properties CodeSystem, FHIR-41678 added reserved-code guidance for the defined concept properties, and FHIR-51249 added the current rules for how status and inactive relate. FHIR-42956 is related background but remains Resolved - change required rather than Applied/Published source-edit scope for this seed.
