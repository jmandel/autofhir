FHIR-33092: Audit ContributorSummaryType outside core

Issue request:
FHIR-33092 was a Published FHIR-core R5 CDS change request resolved Persuasive. It asked to update the ContributorSummaryType code system/value set for Citation.citedArtifact.contributorship.summary.type to contain author-string, contributorship-list, contributorship-statement, acknowledgement-list, acknowledgment-statement, funding-statement, and competing-interests-statement, separating the previous acknowledgement concept into list and statement forms.

Initial application:
The issue was applied in core before this reconciliation by commit e7d479cbe3978099d0b9c16201c07a2f3019dd0c, merged as 2f5ad9c52d4b80c10733cde002650b3250c080da. That commit explicitly mentioned J#33092 and updated source/citation/codesystem-contributor-summary-type.xml from the older author-string/contributorship-statement/acknowledgment set to the requested seven concepts. The R5 release history in tools/history/release5/valuesets.xml and the published R5 CodeSystem both contain the seven requested codes.

Additional context:
The current core build no longer contains the Citation resource or source/citation terminology files. Current source/fhir.ini has no active Citation resource entry, source/citation is absent, and current core narrative links Citation to the Evidence Based Medicine IG. Later core commit caa1fb75adbcca96f92873c7d958e31f547124bb moved Citation-related code system definitions out of base FHIR and changed Citation bindings to terminology.hl7.org URLs before the Citation resource was removed from the current core build. The current THO CodeSystem/ValueSet surfaces for contributor-summary-type contain the seven requested codes.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The R5 request was already applied and published, and the current core repository no longer owns the Citation artifact or contributor-summary-type terminology source. Reintroducing source/citation terminology in core would duplicate terminology maintained outside this checkout and outside the current core build scope.

Recommendation:
Keep this audit commit as-is for core reconciliation. No core follow-up is needed for FHIR-33092 unless the work group decides to bring Citation or this terminology back into the core build. Future changes to ContributorSummaryType should be made in the external terminology source used by terminology.hl7.org and coordinated with the EBM IG Citation artifact.
