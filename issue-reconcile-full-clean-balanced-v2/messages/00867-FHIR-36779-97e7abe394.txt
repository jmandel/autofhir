FHIR-36779: Audit EvidenceVariable combination codes

Issue request:
FHIR-36779 was Published/Persuasive for R5 and asked to add 'statistical' and 'dataset' to the CharacteristicCombination value set used by EvidenceVariable, and to change the 'net-effect' definition from a generic statistical-combination meaning to addition of benefits and subtraction of harms.

Initial application:
The issue was applied in April 2022 by Jira-tagged commits 878eb1abe3c41c689adf4a936c8e9d1d3e6068ae and 09556cea5c81778c7023ffc771f9b1e86f9754bd, merged by PR #1902. Those commits added the requested CodeSystem concepts, updated the net-effect definition, and updated the old EvidenceVariable.characteristic.defByCombination.code short description.

Additional context:
Later R6 work changed the model. FHIR-41583 added Group.combinationMethod for conceptual cohort/group definitions, and FHIR-42886 removed EvidenceVariable.characteristic and the EvidenceVariable-specific CharacteristicCombination value set in favor of EvidenceVariable.definition as a CodeableReference to Group. The surviving group-characteristic-combination CodeSystem still contains statistical, net-effect, and dataset with the FHIR-36779 definitions, while the current Group value set is intentionally scoped to Group.combinationMethod codes and excludes the EvidenceVariable-specific statistical/dataset/net-effect semantics.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding statistical or dataset to the current required Group.combinationMethod value set would be a new R6 Group semantics change, not completion of the R5 EvidenceVariable value-set request, because the EvidenceVariable element and binding that FHIR-36779 targeted no longer exist in current source.

Recommendation:
Keep this no-change audit commit. If CDS/FHIR-I want statistical, dataset, or net-effect to be valid Group.combinationMethod codes in the current model, open or apply a current Group/EvidenceVariable tracker for that semantics decision; do not treat that as missing application of FHIR-36779.
