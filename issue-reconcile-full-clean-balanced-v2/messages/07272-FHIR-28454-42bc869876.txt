FHIR-28454: Audit experimental meaning-if-missing

Issue request:
FHIR-28454 was a Published/Persuasive R5 FHIR-I change request asking that Questionnaire.experimental, the base CanonicalResource pattern, and all resources inheriting experimental specify meaning-if-missing guidance. The approved resolution was: "If absent, this resource is treated as though it is not experimental."

Initial application:
The issue was applied by git commit 68793b9e97, which explicitly mentions FHIR-28454 and added/corrected meaningWhenMissing for CanonicalResource.experimental and the inheriting canonical resource experimental elements. That source application is still present in the current checkout.

Additional context:
source/fhir.ini keeps CanonicalResource in the active resource infrastructure section and maps MetadataResource.experimental to CanonicalResource.experimental. The active [resources] section includes Questionnaire and the canonical-resource descendants checked by this reconciliation. A later related clarification, FHIR-48306, changed the short/definition/comment for experimental but did not change or supersede the meaning-if-missing rule.

This commit intentionally makes no source change.
