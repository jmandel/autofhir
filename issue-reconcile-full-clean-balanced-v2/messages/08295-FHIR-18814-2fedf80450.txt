FHIR-18814: Normalize FHIRPath Patch parameter labels

Issue request:
FHIR-18814 is a Published/Persuasive FHIR-core technical correction, raised and applied for STU3, asking why FHIRPath Patch parameter names mixed uppercase Type/Path/Name/Value with lowercase index/source/destination. The approved resolution was to make all parameter names lower-case to match the examples and make the page heading labels bold.

Initial application:
The original FHIRPath Patch page was introduced by git commit 9f852260fef9f4cdd37913228c5a24cf9c1c72b2 with mixed-case parameter names in both tables. No explicit FHIR-18814-tagged application commit was found. The nearby 2018-10-10 commit 3711daf34c0bfd80da9afe8a6c468dcb2cc37d6e lowercased Type/Path/Name/Value in the Parameters Format table, shortly after the FHIR-18814 vote date, but it left the Operations table parameter-name headings mixed-case and left the Parameters Format heading row unbolded.

Additional context:
The current fhirpath-patch Parameters profile already fixes the constrained part names as lowercase strings, and all examples on source/fhirpatch.html use lowercase names. source/fhirpatch.html is a current build input through publish.ini and the source hierarchy, with links from the HTTP Patch and documentation pages; the fhirpath-patch profile is included in the Parameters implementation guide source. Later FHIRPath Patch work, including FHIR-18815, FHIR-34214, FHIR-26324, FHIR-33256, and FHIR-43079, changed nearby guidance but did not reverse the lowercase-name decision. Zulip and Confluence searches found no FHIR-18814-specific or conflicting community decision.

AutoFHIR reconciliation:
This commit completes the published correction in the active FHIRPath Patch page by lowercasing the Operations table parameter-name headings type, path, name, value, and index while preserving source and destination, and by bolding the Parameters Format table heading labels. The fhirpath-patch profile needed no source edit because its fixedString names are already lowercase.

Recommendation:
Keep this source correction as-is. It aligns the active narrative, profile, and examples with the published FHIR-18814 resolution without changing FHIRPath Patch semantics; further FHIRPath Patch behavior changes should be handled under separate tracker decisions.
