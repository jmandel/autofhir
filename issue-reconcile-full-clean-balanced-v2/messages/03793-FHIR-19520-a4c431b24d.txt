FHIR-19520: Audit RxNorm display clarification

Issue request:
FHIR-19520 was Published/Persuasive for FHIR-core-CodeSystem after STU3. It asked to clarify the correct RxNorm CUI display by adding a separate display section, verifying the RxNorm SQL guidance, and moving or copying that guidance from the RxNorm MySQL Database section.

Initial application:

No source/rxnorm.html file remains in the current core build.

Additional context:
The same issue family includes FHIR-18661, the earlier no-change ballot comment that spawned this task, and FHIR-19524, a duplicate of FHIR-19520. Later FHIR-33127 refined the same display paragraph so the SCD/SBD SQL is explicitly only an example for two available term types; that related issue is already represented on the combined branch. FHIR-35933 then removed the external code-system pages from FHIR core and redirected the RxNorm guidance to HL7 Terminology, also already represented on the combined branch. Current core source links RxNorm users to the THO page, and the current THO page contains the corrected display section.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative RxNorm display prose no longer belongs in this FHIR core checkout, and the current core source correctly points to HL7 Terminology for RxNorm usage guidance.

Recommendation:
Keep this audit commit as-is. Do not restore source/rxnorm.html or duplicate the RxNorm display SQL in FHIR core; future wording changes for the RxNorm guidance should be made in HL7 Terminology/THO unless core's outgoing link or surrounding delegation text becomes stale.
