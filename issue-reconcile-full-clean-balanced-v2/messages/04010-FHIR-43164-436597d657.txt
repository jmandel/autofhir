FHIR-43164: Audit DeviceDefinition name type binding

Issue request:
FHIR-43164 was an Applied, Persuasive with Modification OO change request for R6. It asked to change DeviceDefinition.deviceName.type from a required code binding to an extensible binding that permits additional name types, add jurisdictional guidance for choosing the registered-name, and apply the same change to Device.name.type.

Initial application:
The change was applied in two Jira-tagged commits. fe02a2c70b changed DeviceDefinition.deviceName.type to CodeableConcept, set the DeviceNameType binding strength to extensible, and added the registered-name jurisdiction comment. After Jira QA noted that Device.name.type had been missed, 744c0f6283 made the same CodeableConcept/extensible/comment change for Device.name.type.

Additional context:
Device and DeviceDefinition are active current-build resources in source/fhir.ini. Current source still carries the requested binding strength, datatype, and comment on both elements. The OO 2023-11-30 and 2023-12-07 Confluence minutes show FHIR-43164 in the OO block-vote trail with the same 7-0-5 vote recorded in Jira.
