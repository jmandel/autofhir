FHIR-14828: Audit MedicationAdministration dosage note

Issue request:
FHIR-14828 was a Published FHIR-core Pharmacy change request raised against STU3 MedicationAdministration. It asked whether MedicationAdministration.dosage could use the shared Dosage datatype; the final Not Persuasive with Modification resolution rejected that type change because MedicationAdministration is an event and not all Dosage attributes are appropriate, and instead required the explanatory note: "This is a constrained list of attributes from the Dosage type.  These are the only attributes needed to describe the dose administered."

Initial application:
The Jira-linked SVN/Git commit 73c779d3aeb5a6120955eb499d67727c2fdfdf47 applied FHIR-14828 by adding that exact text to the MedicationAdministration.dosage Committee Notes column in the then-authoritative spreadsheet source. Later source refactors converted the spreadsheet source to StructureDefinition XML and preserved the note as the build committee-notes extension.

Additional context:
MedicationAdministration is active in the current build through source/fhir.ini. The current source/medicationadministration/structuredefinition-MedicationAdministration.xml defines MedicationAdministration.dosage as a BackboneElement, not Dosage, and carries the exact committee note on that element. Jira search found no separate closely related issue for this same request, and quoted Zulip/Confluence searches found no FHIR-14828-specific community evidence that would change the Jira/source conclusion.
