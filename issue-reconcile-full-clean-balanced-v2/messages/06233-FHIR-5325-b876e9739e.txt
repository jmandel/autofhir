FHIR-5325: Audit ClinicalImpression trigger migration

Issue request:
FHIR-5325 was a Published / Persuasive with Modification DSTU1 Patient Care ballot comment for ClinicalImpression, asking to remove the specific carePlan and referral elements that prompted an assessment and add a polymorphic trigger element for the request or event that necessitated the assessment.

Initial application:
The Jira comment records svn revision 4782, and the imported git history shows the change in March 2015: source/clinicalimpression/clinicalimpression-spreadsheet.xml replaced ClinicalImpression.careplan and ClinicalImpression.referral search paths with ClinicalImpression.triggerReference and ClinicalImpression.triggerCodeableConcept, with the trigger definition matching the Jira resolution.

Additional context:
Later Patient Care issue FHIR-8463, also Published / Persuasive with Modification, explicitly decided to remove ClinicalImpression.trigger because its purpose was unclear. Commit ca8df34006 applied that ClinicalImpression update and removed both the trigger element and trigger search parameters. Current core source still has an inactive ClinicalImpression source directory, but source/fhir.ini has no active ClinicalImpression or ClinicalAssessment resource entry, build.fhir.org/clinicalimpression.html returns 404, and source/history.html points ClinicalImpression readers to the Patient Care incubator ClinicalAssessment artifact. The external PC incubator ClinicalAssessment continuous build is based on github.com/HL7/pc-incubator and has no trigger, carePlan, or referral elements.

AutoFHIR reconciliation:
This commit makes no source change in the core checkout. The FHIR-5325 change was historically applied, later superseded by FHIR-8463, and the remaining ClinicalAssessment/ClinicalImpression work is now outside the active core build.

Recommendation:
Keep this audit commit as-is for core reconciliation. If Patient Care wants to revisit the migrated ClinicalAssessment narrative or resurrect a request/event field, that should be handled in the PC incubator repository with FHIR-8463 in view, not as a core source edit.
