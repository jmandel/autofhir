FHIR-7430: Align Composition section root wording

Issue request:
FHIR-7430 was a Published/Persuasive Structured Documents change request from the 2015May core ballot for FHIR-core Composition. It asked to harmonize with ISO EN 13606 by changing the Composition section definition from "The root of the sections that make up the composition." to "The root of the contents that make up the composition." The resolution was to make the change as recommended.

Initial application:
The Jira comments record acceptance and svn revision #6190, but the current git source still contained the original "sections" wording. Git pickaxe searches found no prior occurrence of the accepted "contents" wording in the active Composition StructureDefinition, and the current phrase was carried into the XML source by the 2021 source rework.

Additional context:
source/fhir.ini lists composition=Composition in the active [resources] section, so source/composition/structuredefinition-Composition.xml is current build input. The same old wording also appears in a commented-out CDA profile and a generated-looking SVG, but the CDA profile is not active in [profiles] and the SVG is not the authoritative source. Jira/community searches did not find a later decision reversing this old ballot resolution.

AutoFHIR reconciliation:
Changed the active Composition.section definition in source/composition/structuredefinition-Composition.xml to use "contents" as requested. No out-of-build profile or generated diagram artifacts were edited.

Recommendation:
Keep this source fix. It applies the accepted 2015May wording in the active Composition definition while avoiding inactive/generated artifacts; no follow-up is indicated unless the Structured Documents work group wants a broader modern terminology review of Composition.section.
