FHIR-7124: Audit Procedure approach and target sites

Issue request:
FHIR-7124 was a Published Patient Care change request with resolution Persuasive with Modification. It asked to address confusion between Procedure.bodySite target sites and approach sites; the recorded decision said both approach and target sites may need capture, and the Jira comment records that approachBodySite and targetBodySite were added as extensions while root bodySite remained consistent with Condition and ProcedureRequest.

Initial application:
The issue was historically applied in git commit 27f73740e4afc943ade51df795872e6e5c3865ee, whose subject explicitly cites #7124 and #7630. That commit changed Procedure.bodySite's short label to "Target body sites", kept the RIM mapping as .targetSiteCode, and added approachBodySite/targetBodySite extension rows in the then-current Procedure and ProcedureRequest spreadsheet sources rather than adding a nested role element.

Additional context:
The current build has Procedure active in source/fhir.ini and defines Procedure.bodySite as "Target body sites" with a target-site full definition and targetSiteCode RIM mapping. The closely related Published FHIR-7630 decision required keeping the bodySite name while clarifying target/focal semantics; it is already represented on the combined branch by commit 1d2eb9021b6f5d80b61af204e9919cf0ba3fcad9, which completed the current Procedure.bodySite full-definition wording. The historical BodySite-reference extensions were later renamed to BodyStructure and now live in the FHIR Extension Pack as procedure-approachBodyStructure and procedure-targetBodyStructure.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing a Procedure.bodySite.role element would conflict with the way the Published issue was actually applied and with later FHIR-7630 clarification; the current core Procedure source already conveys that bodySite/bodyStructure are target locations, and approach-site capture is handled by standard Extension Pack definitions.

Recommendation:
Keep this audit commit as-is. No current core source change is needed for FHIR-7124; future changes to the approach/target BodyStructure extensions, if any, should be considered in the FHIR Extension Pack rather than in this core checkout.
