FHIR-38639: Audit gender identity code system removal

Issue request:
FHIR-38639 was a Published/Persuasive PA change request for R5 asking to remove the Gender Identity example CodeSystem because the related value set had moved to THO and now references non-FHIR CodeSystems, including SNOMED CT. The resolution also noted that the individual gender identity extension should reference the THO value set.

Initial application:
The issue was applied by git commit 3d3c55b02b42f14f2b2fe23716469b13db06ca2c, which removed source/patient/codesystem-gender-identity.xml, removed the http://hl7.org/fhir/gender-identity OID registration from source/oids.ini, and removed the example CodeSystem from the terminology server TerminologyCapabilities example. A later R5 cleanup commit moved the remaining Gender Harmony terminology value sets out of core.

Additional context:
Current core source has no active source/fhir.ini entry for gender identity terminology and no remaining reference to the removed http://hl7.org/fhir/gender-identity CodeSystem or deleted codesystem-gender-identity source. The only current core OID entry found for this family is the THO value set canonical http://terminology.hl7.org/ValueSet/gender-identity, and the FHIR Extension Pack's individual-genderIdentity extension binds to that THO value set. PA minutes record the 6-0-0 persuasive vote, and later Vocab minutes note the topic as resolved by FHIR-38639.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR core checkout already reflects the requested removal, and the extension/value set evidence is outside the current core build or correctly points to THO.

Recommendation:
Keep this audit commit as-is. No additional core source work is needed for FHIR-38639 unless a future THO or Extension Pack reconciliation finds a separate issue in those repositories.
