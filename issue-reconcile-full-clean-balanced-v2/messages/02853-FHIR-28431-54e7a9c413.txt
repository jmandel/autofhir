FHIR-28431: Remove stale batch identifier ModelInfo

Issue request:
FHIR-28431 was a Published/Persuasive BRR R5 change request to remove PackagedProductDefinition.batchIdentifier because PackagedProductDefinition describes package definitions rather than package instances; the Jira comment corrected the description typo but kept the requested removal, noting batch numbers belong in Medication.batch when needed.

Initial application:
Commit ac2bb27d613a8dad5854f82da2130183f0695d14, "removed batch FHIR#28431", removed the batchIdentifier example content and the PackagedProductDefinition.batchIdentifier spreadsheet rows from the resource source. The current authoritative PackagedProductDefinition StructureDefinition has no batchIdentifier element, but the active Library/FHIR-ModelInfo example still exposed the old MedicinalProductPackaged.batchIdentifier and its BatchIdentifier class.

Additional context:
source/fhir.ini lists PackagedProductDefinition and Library as active resources, and source/library/list-Library-examples.xml includes Library/FHIR-ModelInfo as a Library example whose XML payload is embedded from source/library/library-fhir-model-definition-content.xml. FHIR-28431's Jira related artifact used the older MedicinalProductPackaged label; later R4B medication-definition work deleted the old MedicinalProductPackaged source folder and retained PackagedProductDefinition, leaving the old ModelInfo entry as the remaining stale current-model surface. Jira, Zulip, and Confluence searches found no later decision or community discussion conflicting with the removal.

AutoFHIR reconciliation:
Removed the stale MedicinalProductPackaged.batchIdentifier element and the now-unreferenced MedicinalProductPackaged.BatchIdentifier class from source/library/library-fhir-model-definition-content.xml, then regenerated the embedded base64 payload in source/library/library-fhir-model-definition.xml. The authoritative PackagedProductDefinition StructureDefinition and examples were already correct and were left unchanged.

Recommendation:
Keep this source fix. It aligns the active FHIR 6.0.0 ModelInfo Library example with the already-correct PackagedProductDefinition source without attempting broader cleanup of old MedicinalProductPackaged ModelInfo entries that are outside this issue's requested batchIdentifier removal.
