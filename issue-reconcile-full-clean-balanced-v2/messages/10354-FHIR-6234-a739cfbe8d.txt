FHIR-6234: Audit _fields-to-_elements resolution

Issue request:
FHIR-6234 was Published as Persuasive with Modification for DSTU1. It requested a lightweight `_fields` query parameter for selecting or excluding response payload fields, and the final resolution was to make the `_element`/`_elements` change agreed in the related FHIR-7540 task instead of adding a separate `_fields` mechanism.

Initial application:
The Jira comments cite SVN revision 6176, and the local HL7/fhir history has commit ca544e1cfb16d5154cc1cfa746620817c015c096, `#7540 - _elements parameter`, at that revision. That commit added `_elements` to `source/search.html` as a comma-separated list of base element names and added SUBSETTED tagging guidance. No separate `_fields` source implementation was expected because the resolution explicitly chose the FHIR-7540 `_elements` mechanism.

Additional context:
FHIR-7540 is the controlling same-change-family issue and asked for fetch-by-profile functionality that was narrowed to `_elements`. Later applied decisions refined the same parameter family, especially FHIR-23729 for dotted paths and FHIR-27054 for included-resource restrictions. The current active `source/search.html` and `source/http.html` pages retain the `_elements` behavior, and `source/hierarchy.xml` places those pages under the RESTful API build hierarchy. Focused community searches found no direct FHIR-6234 or FHIR-7540 community record that conflicts with this Jira/source history.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current specification correctly exposes `_elements` rather than `_fields`, describes element-name and dotted-path selection, preserves server discretion and mandatory/modifier return guidance, and instructs servers to tag incomplete resources with SUBSETTED.

Recommendation:
Keep this no-change audit. FHIR-6234 was satisfied by the same active `_elements` source created for FHIR-7540, and adding a separate `_fields` parameter or resurrecting exclusion syntax would contradict the published resolution.
