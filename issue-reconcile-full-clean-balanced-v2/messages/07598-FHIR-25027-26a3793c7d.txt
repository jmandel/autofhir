FHIR-25027: Audit choice-type extension differential migration

Issue request:
FHIR-25027 was Published/Persuasive for R5 as a FHIR-I technical correction. It reported that many profile differentials used typed choice paths incorrectly, with the iso21090 ADXP postBox extension shown as using Extension.valueString where the differential should constrain Extension.value[x] with type string.

Initial application:
The issue appears to have been applied by core commit 9346c8cc45, which changed the legacy SpreadsheetParser extension-generation logic to always name the generated Extension value element value[x] instead of deriving valueString, valueReference, or another type-specific value element name. A contemporaneous FHIR-I Zulip technical-correction thread records GF#25027 as approved.

Additional context:
The affected legacy parser is no longer present in this checkout after the later Gradle/kindling migration, and the active core iso-21090 profile page now links to extension definitions via the Extension Pack location rather than carrying the definitions directly in core. The current Extension Pack postBox definition already has Extension.value[x] with type string. A bounded residual search found no current core source definitions with top-level Extension.value<Type> paths, but did find a separate active Extension Pack extension, address-official from FHIR-43838, with the same style of typed value paths.

AutoFHIR reconciliation:
This empty audit commit makes no core source change. The original FHIR-core correction is already represented in history and the seed example is correct in the current external Extension Pack; any remaining same-pattern cleanup is outside this FHIR-core checkout.

Recommendation:
Keep this audit commit as the core reconciliation for FHIR-25027. If the Extension Pack is in scope for a separate worker or human follow-up, review and likely correct StructureDefinition-address-official.xml so its value[x] type slices use path Extension.value[x] rather than Extension.valueBoolean/Extension.valueCodeableConcept.
