FHIR-32451: Audit AuditEvent agent type binding

Issue request:
FHIR-32451 was Published/Persuasive for R5 in the Security work group. It asked that AuditEvent.agent.type not use an extensible binding to the large, overlapping participation-role-type value set and requested that the issue be handled through a smaller example or cleaned value set. The final Jira resolution says the request is covered by FHIR-32453, FHIR-32520, and FHIR-32519.

Initial application:
Commit a4a8e4475 mentioned FHIR-32451 while applying adjacent AuditEvent event-type changes, but the actual agent.type binding/value-set work came through the companion issues. Commit f577d68ceb applied FHIR-32453/FHIR-32520 by changing AuditEvent.agent.type and Provenance.agent.type from extensible to example and separating agent.role structural-role examples. Commit 760011453b then applied FHIR-32519 by narrowing participation-role-type to DICOM audit and W3C provenance participation concepts and changing AuditEvent.agent.type to preferred. The combined branch already contains a FHIR-32519 source fix for the missed Provenance.agent.type preferred binding and a FHIR-32453 no-change audit; this worker also published the companion FHIR-32520 no-change audit.

Additional context:
AuditEvent is an active current-build resource in source/fhir.ini. Current AuditEvent.agent.type binds to http://hl7.org/fhir/ValueSet/participation-role-type with strength preferred, not extensible, and the value set is narrowed to the THO provenance agent type value set plus DICOM CID 402. Later Applied issue FHIR-53882 deliberately changed AuditEvent role/type wording to be less tied to ISO 21298 while preserving the preferred AuditEvent.agent.type binding. Other resources may still use participation-role-type with their own binding strengths, so changing the global terminology spreadsheet row or value-set metadata would be broader than this AuditEvent-specific issue.

AutoFHIR reconciliation:
This audit commit makes no source change. The current AuditEvent source already satisfies FHIR-32451 when the companion Jira decisions and later AuditEvent clarification are considered together: agent.type is not extensible, and the value set has been cleaned enough to support the final preferred binding decision.

Recommendation:
Keep this audit commit as-is. No additional core source change is needed for FHIR-32451; future changes to participation-role-type uses outside AuditEvent should be handled by their own Jira decisions.
