FHIR-3230: Audit Questionnaire split

Issue request:
FHIR-3230 was a Published/Persuasive Patient Care change request from the Initial Draft/DSTU1 era asking to split the then-combined Questionnaire concept into two resources: one for the form/design and one for completed questionnaire data. The accepted resolution agreed to split the resources and named them Questionnaire and QuestionnaireAnswers.

Initial application:
No git commit explicitly mentions FHIR-3230, but git/SVN history shows the split was applied in commit 54ddc30bbb4ff904ff5e5c0f7cce9088b15b19c6 on 2014-05-13. That commit message says it "Split Questionnaire into two" and added the QuestionnaireAnswers resource files while updating Questionnaire, matching the Jira request and its May 2014 comments.

Additional context:
The completed-answer resource was later renamed by FHIR-8480 from QuestionnaireAnswers to QuestionnaireResponse in commit c51b8682420300c0f51dd0ad260d0be7f5ae20ab/SVN #6162. Current source/fhir.ini has active [resources] entries for questionnaire=Questionnaire and questionnaireresponse=QuestionnaireResponse, with no active QuestionnaireAnswers resource, and the current narrative and StructureDefinitions describe Questionnaire as the form definition and QuestionnaireResponse as the answer instance. A newer FHIR-12172 reconciliation commit already corrected remaining current-build stale response wording; the remaining QuestionnaireAnswers strings are a QuestionnaireResponse alias, release history, or QUICK model example content rather than evidence that the FHIR-3230 split is missing.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current specification already reflects the split requested by FHIR-3230. Adding or renaming source now would either duplicate already-correct Questionnaire/QuestionnaireResponse semantics or reopen later naming decisions that superseded the original QuestionnaireAnswers name.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-3230; any future review of historical QUICK model example names should be handled under a separate issue, not as part of the original Questionnaire split.
