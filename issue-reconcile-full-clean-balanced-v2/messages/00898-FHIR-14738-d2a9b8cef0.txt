FHIR-14738: Audit dropped OccupationalData author split

Issue request:
FHIR-14738 was a Published/Persuasive with Modification STU3 PHER issue for FHIR-core-OccupationalData. It asked whether OccupationalData.author meant the person providing the data or the person recording it, and the resolution required clearer wording, a reference-list update, and a separate entering-user/recorder concept.

Initial application:
The Jira comment says the issue was applied in svn 13307. The corresponding Git commit, 1834d69412f3ba4890c5930897e1a58b6c98aad0, explicitly references GF#14738/#163 and changed source/occupationaldata by replacing OccupationalData.author with OccupationalData.recorder, adding OccupationalData.informant, updating the example from Author to Recorder/Informant, and preserving the broad recorder reference list. The remaining inactive spreadsheet currently defines recorder as the person who created or last updated the record and informant as the person who provided the subject's health-related occupational data.

Additional context:
PHWG 2018 WGM minutes for Comment 163 record the same ambiguity: the resource needed both the person providing the data and the person who entered it. Later final issues FHIR-16930 and FHIR-14868 withdrew OccupationalData as a FHIR core resource. Commit efef182022eba3d6868acbe3fda5360783848135 removed active OccupationalData build mappings, the current source/fhir.ini retains only a commented "OccupationalDataforHealth=pending -> Dropped" note, current source has no occupationaldata.html page, and combined-branch commit 9ee22091b6346c46d4c6d948113f496a86ad1a52 already removed the stale Resource Guide row. The FHIR Extension Pack checkout has no OccupationalData definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change and records FHIR-14738 as external to the current FHIR core build. Editing source/occupationaldata would alter an inactive, out-of-build artifact, and the retained inactive source already reflects the historical recorder/informant split requested by the issue family.

Recommendation:
Keep this audit commit as-is for FHIR core. Do not edit or resurrect retired core OccupationalData remnants for this issue; if the recorder/informant distinction needs current maintenance, review the active ODH implementation guide or other external owner rather than the dropped core resource.
