FHIR-10762: Audit Practitioner example coding system correction

Issue request:
FHIR-10762 is a Published/Persuasive PA change request asking to fix Practitioner examples such as f001 and f005 that used urn:oid:2.16.840.1.113883.2.4.15.111 for role/specialty codings. The PA resolution was to update examples, with the comment that the issue should be considered when those roles migrated to PractitionerRole and that role and specialty should be different except where a source system such as NUCC defines them.

Initial application:
The issue was applied before this reconciliation by git commit 552e17520a123a9c027792aab6cf875b40f76e07, which changed the active PractitionerRole general example bundle from the old AssignedRoleType OID to SNOMED CT role/specialty codings and fixed the PractitionerRole examples list entry to reference the bundle. There is no remaining role/specialty coding in the current f001/f005 Practitioner examples.

Additional context:
source/fhir.ini actively includes both Practitioner and PractitionerRole. The current f001 and f005 Practitioner examples contain only practitioner demographics/identifiers, while the migrated PractitionerRole entries f005-0 and f001-0 use SNOMED CT systems and codes. Later terminology QA commit 6a8c26405c4a1430c7817e211d2f84acc57f9105 corrected the SNOMED display strings without reintroducing the old system. Jira/community searches found no later decision changing the FHIR-10762 scope; current occurrences of the old OID are outside the Practitioner/PractitionerRole source paths implicated by this issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already reflects the requested correction for the Practitioner examples and their PractitionerRole migration.

Recommendation:
Keep this no-change audit commit as-is for FHIR-10762. Any broader cleanup of the same old Dutch role-code OID in non-Practitioner examples should be handled under a separate PA issue because it was not part of this Jira request or implementation trail.
