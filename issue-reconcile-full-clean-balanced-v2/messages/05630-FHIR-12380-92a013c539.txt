FHIR-12380: Audit ConceptMap example mappings

Issue request:
FHIR-12380 was a Published Vocabulary change request, resolved Persuasive with Modification for DSTU2. It reported that the example ConceptMap repeated the map from FHIR address-use code "home" to v3 AddressUse code "H" and also asked why equivalence relationships had disappeared; the approved resolution said the duplicate was addressed and the equivalence relationships would be restored as they were in DSTU3.

Initial application:
No git commit explicitly mentions FHIR-12380. The duplicate mapping was removed by git-svn commit 7ad0c6364e2c36a9bc3d92cb70f7aa22231970c3, titled "#12590 & #12617 - add default mappings and display to ConceptMap", which deleted the second home-to-H target from source/conceptmap/conceptmap-example.xml. The relationship/equivalence values were then restored in git-svn commit 72143f2fd3d86e1d1de43b7aab6821463d9611ab, and later migrated from the old ConceptMap.equivalence element to the current ConceptMap.relationship element by 049b740c24b9a670f52f04286093e41bc6f2d74d.

Additional context:
ConceptMap is an active current-build resource in source/fhir.ini and the example list includes ConceptMap/101 from source/conceptmap/conceptmap-example.xml. Later ConceptMap model changes renamed target.equivalence to target.relationship and replaced the old disjoint code with not-related-to, so current relationship wording should be judged against the current model rather than the DSTU2 element names. FHIR-12590 and FHIR-12617 share the 2017 source-history commit but are already represented on the combined branch and are only background for this audit.

AutoFHIR reconciliation:
No source change was made. The current active ConceptMap example contains exactly one source code "home" mapping to target code "H" with relationship="equivalent"; the work and temp mappings also carry relationship="equivalent"; the old mapping carries relationship="not-related-to"; and the unmapped fixed mapping carries relationship="related-to". That satisfies the published FHIR-12380 resolution in current R6 ConceptMap terms.

Recommendation:
Keep this no-change audit commit. Future changes to this example should be driven by later ConceptMap trackers, not by FHIR-12380, because the duplicate and omitted relationship values have already been corrected in build-scoped source.
