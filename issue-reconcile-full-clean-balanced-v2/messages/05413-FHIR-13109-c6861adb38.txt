FHIR-13109: Audit ValueSet history Provenance replacement

Issue request:
FHIR-13109 was Published/Persuasive for DSTU2. It asked to drop the ValueSet history extension and replace that need with Provenance, consistent with the Workflow project recommendation; the Jira resolution agreed that Provenance should adequately support the need.

Initial application:
The Jira comment says the issue was applied in svn 13319. Git history maps that to commit 495b9b8da5781c2da58944e1a7f8f94c16952259, whose message is "GF#13109 - Removed the valueset-history extension" and whose patch removed the ValueSet extension rows history, history.name, history.revision, history.revision.date, history.revision.id, history.revision.author, and history.revision.notes from source/valueset/valueset-extensions-spreadsheet.xml. Later source refactors removed the old ValueSet extension spreadsheet entirely.

Additional context:
The current build scope still actively includes ValueSet and Provenance as resources in source/fhir.ini. Current ValueSet source no longer contains a ValueSet history extension and ValueSet.date now points readers to extensions or Provenances associated with past versions for additional dates. Current Provenance source includes the ProvenanceRelevantHistory profile and Provenance notes for relevant history; later Published/Applied issues FHIR-27794, FHIR-46637, FHIR-48829, and FHIR-48828 clarified ownership, soft guidance, profile-specific Request/Event references, and retention of that profile in core. Existing combined-branch audit commits already represent the later FHIR-46637, FHIR-48829, and FHIR-48828 decisions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The obsolete ValueSet-specific history extension has already been removed from current build-scope source, and the current specification already uses Provenance-based guidance for historical/relevant-history needs. Adding new ValueSet-local prose would be redundant with the existing ValueSet.date comment and Provenance guidance and would risk maintenance drift.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-13109 unless a future work group decides to add new, ValueSet-specific Provenance guidance beyond the existing general Provenance and relevant-history material.
