FHIR-7084: Audit no-bullet narrative CSS support

Issue request:
FHIR-7084 was a Published/Persuasive with Modification FHIR-core narrative request to approve use of CSS list-style-type:none for FHIR narrative, with implementation details left to the implementation team.

Initial application:
The Jira comment records svn revision 5864. Git commit 9cdb0a817b722407dfa561b2e0060ab0e4ec9873, imported from that revision, added a no-bullet list class to the narrative CSS/style examples: source/narrative.html documented class unlist with list-style-type:none, source/basic/basic-example-narrative.xml added an unlist example, and implementations/fhir-runtime.css added a no-bullet class under the name nolist.

Additional context:
That initial application left a naming mismatch between unlist in the narrative page/example and nolist in the runtime stylesheet. Later Applied issue FHIR-49732 resolved the discrepancy by requiring the backwards-compatible fix of defining both nolist and unlist in both places. Current source/narrative.html now lists both classes and explains they are duplicates, and implementations/fhir-runtime.css defines both selectors with list-style-type:none. source/fhir.ini keeps Narrative active, maps narrative/xhtml to the narrative page, marks Narrative normative, and assigns Narrative=txt, so these files are in current build scope.

AutoFHIR reconciliation:
No source change was made. The current build source already carries the requested no-bullet narrative styling support and the later compatibility clarification that preserves both class names.

Recommendation:
Keep this empty audit commit as-is. No FHIR-core source follow-up is needed for FHIR-7084 unless a future work-group decision changes the accepted narrative CSS class set.
