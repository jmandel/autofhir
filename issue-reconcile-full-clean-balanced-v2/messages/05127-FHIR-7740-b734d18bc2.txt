FHIR-7740: Audit coded dosage instruction examples

Issue request:
FHIR-7740 is a Published/Persuasive Pharmacy change request from the DSTU1 ballot asking whether MedicationPrescription.dosageInstruction.additionalInstructions, a CodeableConcept described with free-text examples such as "Swallow with plenty of water", needed an example showing coded use. The final resolution was to add an example.

Initial application:
No source commit explicitly tagged FHIR-7740 or the ballot item number was found. Historical source shows MedicationPrescription examples had already been added by af1b3adefa, including a coded additionalInstructions example using SNOMED CT "With or after food". The MedicationPrescription resource was later renamed/reworked through MedicationOrder into MedicationRequest, and later MedicationRequest dosage-example commits such as 8175cd2686 preserved and expanded coded additionalInstruction examples.

Additional context:
MedicationPrescription is no longer an active current-build resource; source/fhir.ini lists MedicationRequest as the active medication request resource and records "MedicationPrescription became MedicationRequest" in the removed-resource notes. Current MedicationRequest examples include multiple coded additionalInstruction CodeableConcepts, and the shared Dosage.additionalInstruction definition remains CodeableConcept with guidance that coded use is intended and an example binding to the SNOMED CT Additional Dosage Instructions value set. Related FHIR-8603 later supports the same direction by adding an exemplar value set for additional instructions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already satisfies FHIR-7740 through build-scoped MedicationRequest examples and the shared Dosage datatype definition, so adding another example would be redundant and editing retired MedicationPrescription source would be out of current build scope.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-7740 unless Pharmacy opens a new issue requesting a different current MedicationRequest or Dosage example.
