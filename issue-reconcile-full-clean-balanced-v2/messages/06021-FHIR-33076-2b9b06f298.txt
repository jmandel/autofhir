FHIR-33076: Audit ServiceRequest bodyStructure reconciliation

Issue request:
FHIR-33076 was Published with resolution Persuasive with Modification for R5. It asked to allow more specific body-site references by changing ServiceRequest.bodySite from CodeableConcept to CodeableReference(BodyStructure); the voted resolution instead added ServiceRequest.bodyStructure as a 0..1 BodyStructure reference, changed bodySite to 0..*, required only one of bodySite/bodyStructure, and revised search parameters for both.

Initial application:
The Jira application comment points to f9fe7b872369abed6580eb173c609f6babf5baf1. That commit added ServiceRequest.bodyStructure as Reference(BodyStructure), adjusted the bodySite short label, and added a ServiceRequest body-structure reference search parameter. The ServiceRequest resource is active in source/fhir.ini, so source/servicerequest/structuredefinition-ServiceRequest.xml and source/servicerequest/bundle-ServiceRequest-search-params.xml are build-scope inputs.

Additional context:
OO Confluence minutes record the bodyStructure/bodySite discussion and the later FHIR-33076 vote. FHIR-50355 later clarified that ServiceRequest.bodyStructure was preferred over bodySite. FHIR-53203 is an Applied R6 decision for OO resources that superseded the split ServiceRequest bodySite/bodyStructure model by replacing non-Observation bodySite elements and search parameters with bodyStructure as CodeableReference(BodyStructure). ServiceRequest commits 696ac9113f1d1061e7fd4e4032043c744800f7a2 and 6be8ab5bc1bcae562ad5e2d663f46c7b23a9f72d made that later change by converting bodyStructure to CodeableReference, adding code/reference bodyStructure search parameters, and removing the deprecated bodySite element and body-site search parameter. FHIR-54843 is a later Resolved - change required BodyStructure issue that would make ServiceRequest.bodyStructure 0..*, but it is not Applied or Published and is not decided by this seed audit.

AutoFHIR reconciliation:
No source change is needed. Current ServiceRequest source has ServiceRequest.bodyStructure 0..1 CodeableReference(BodyStructure) with a body-site value set binding, no ServiceRequest.bodySite element, and no obsolete body-site search parameter. The search parameter bundle now has separate bodyStructure reference and code search parameters. Because bodySite is no longer present, the FHIR-33076 mutual-exclusion invariant is intentionally obsolete.

Recommendation:
Keep this empty audit commit as-is for FHIR-33076. Future changes to make bodyStructure repeatable or to adjust BodyStructure guidance should be handled under the later BodyStructure issues, especially FHIR-54843, rather than reopening this R5 ServiceRequest audit.
