FHIR-13459: Audit AllergyIntolerance certainty extension binding

Issue request:
FHIR-13459 was Published/Persuasive for STU3 by Patient Care. It asked to change the core AllergyIntolerance reaction certainty extension to use CodeableConcept and an extensible binding because the required coded binding could not carry jurisdiction-specific SNOMED CT certainty concepts.

Initial application:
The change was applied in historical core commit 50cb53f9114776e8bdefa48a848c0fd4bf49b7a5, which changed the AllergyIntolerance extensions spreadsheet from code/required to CodeableConcept/extensible for allergyintolerance-certainty. Earlier FHIR-11020 moved AllergyIntolerance.reaction.certainty out of the base resource into an extension, and FHIR-10369 supplied the preceding request to add or otherwise allow additional certainty concepts.

Additional context:
Starting with R5-era source cleanup, core extensions were removed from the FHIR core checkout and are now maintained in the FHIR Extension Pack. The Extension Pack introduction says the globally defined extensions moved out of core starting from R5. Its current StructureDefinition/allergyintolerance-certainty definition still applies at AllergyIntolerance.reaction and has Extension.value[x] constrained to CodeableConcept with strength extensible and value set http://hl7.org/fhir/ValueSet/reaction-event-certainty. Later FHIR-37637 confirms the binding was already extensible and removed the stale AllergyIntolerance Trial Use note that still called it required.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. The current core source no longer contains the allergyintolerance-certainty extension definition, and the authoritative Extension Pack source already preserves the requested CodeableConcept/extensible semantics.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-13459; if the extension definition changes in the future, review the FHIR Extension Pack rather than reintroducing the extension source into core.
