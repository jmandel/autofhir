FHIR-48399: Clarify Patient multipleBirth short display

Issue request:
FHIR-48399 was Applied/Persuasive for R6 by Patient Administration to clarify that Patient.multipleBirth[x] and the patient-multipleBirthTotal extension can be used for pre-birth scenarios. The approved Patient.multipleBirth[x] text included a definition mentioning known multiple fetuses before birth, a short display of "Whether patient is part or potentially part of a multiple birth", and comments limiting valueInteger to after live birth.

Initial application:
Core commit a2bbe78839 applied the requested Patient.multipleBirth[x] definition and comment text in source/patient/structuredefinition-Patient.xml, but left the short display as "Whether patient is part of a multiple birth". The FHIR Extension Pack commit 05aee317d9 applied the requested patient-multipleBirthTotal description in input/definitions/Patient/StructureDefinition-patient-multipleBirthTotal.xml.

Additional context:
source/fhir.ini lists patient=Patient in the active [resources] section, so source/patient/structuredefinition-Patient.xml is in current core build scope. The patient-multipleBirthTotal extension is maintained in the FHIR Extension Pack, and its current source already contains the approved pre-birth description. PA September 2024 WGM minutes show FHIR-48399 was created from the Patient/PC discussion and later approved.

AutoFHIR reconciliation:
Updated the Patient.multipleBirth[x] short display in the active core StructureDefinition source to match the approved Applied resolution and the already-applied definition/comment semantics. No extension-pack source was edited from this core reconciliation worktree.
