FHIR-47249 was an Applied, Persuasive with Modification OO change request for R6 asking ServiceRequest.code to explain when a reference to PlanDefinition should be used, because the reporter understood ActivityDefinition use but not how PlanDefinition relates to a service.

This commit intentionally makes no source change. The current authoritative ServiceRequest source already contains the approved clarification: PlanDefinition may be used to group multiple activities together, such as an order set that is part of a plan.
