FHIR-33043: Audit not-asked Observation status clarification

Issue request:
FHIR-33043 was an OO FHIR-core Observation change request, currently Applied with Jira resolution Persuasive with Modification. It asked whether HL7 v2 OBX-11 "not asked" should be clarified as part of Observation.status="final" or represented by a separate status. The adopted resolution was to clarify that "not asked" is a form of final status when represented with a data absent reason of not-asked.

Initial application:
The issue was applied before this reconciliation by commit 3eb925d9fb58c5c201d2477f024d90ebe8029bca, later included in merge commit 55f6bd5d2f78d1b06573faad4ad1474595a2db60 referenced from Jira. That commit updated source/observation/codesystem-observation-status.xml so the definition of the final status says it also applies when dataAbsentReason has a not-asked code. No prior Issue-Reconcile-Key audit commit for FHIR-33043 was present on the combined branch.

Additional context:
Observation is active in source/fhir.ini, so the Observation code system and StructureDefinition sources are in current build scope. The current combined branch still contains the final/not-asked clarification in the Observation status code system. A later Applied mapping-review issue, FHIR-50536, further updated Observation's v2 mappings so Observation.dataAbsentReason maps to OBX-32 and, when dataAbsentReason.code is not-asked, also to OBX-11=N. Later not-performed/cancelled Observation guidance in FHIR-51640 and the FHIR-46579 cleanup of a different superseded status code do not reverse or narrow the FHIR-33043 rule.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the active Observation source already conveys the work-group decision: not-asked is handled with Observation.status final plus Observation.dataAbsentReason not-asked, and the current v2 mapping text aligns that representation with OBX-11=N.

Recommendation:
Keep this audit commit as-is. Do not add a separate Observation.status code for not-asked unless OO makes a new decision; the current source and later mapping guidance are consistent with the applied FHIR-33043 resolution.
