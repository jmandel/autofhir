Issue request:
FHIR-16708 was a Published/Persuasive CDS change request from the STU3 ballot asking how to represent quotes in a CQL expression reference. The approved resolution was to add a note explaining use of the &quot; XML entity and to add a JSON example.

Initial application:
The issue was initially applied by git-svn commit 9069a302587993bb7e53ac85531a96db7329c904, which added the XML quote-escaping note and a JSON example to source/clinicalreasoning-topics-using-expressions.html. That application survived later clinical reasoning maintenance and media-type updates, but the JSON example's dynamicValue array was missing the required object wrapper.

Additional context:
The Using Expressions topic is current build source: source/hierarchy.xml lists it under the Clinical Reasoning page, and source/clinicalreasoning-module.html links to it from the Clinical Reasoning module. Later source updates changed the CQL language examples from text/cql to text/cql-identifier, but no discovered Jira, Zulip, or Confluence evidence reverses the FHIR-16708 guidance.

AutoFHIR reconciliation:
This commit keeps the existing XML &quot; explanation and escaped CQL expression, and corrects the JSON example so it is a valid JSON object containing a dynamicValue array whose element is an object with path and expression properties.

Recommendation:
Keep this source fix. It completes the original Published issue in the current build by preserving the quote-escaping guidance while avoiding an invalid JSON example that could confuse implementers.
