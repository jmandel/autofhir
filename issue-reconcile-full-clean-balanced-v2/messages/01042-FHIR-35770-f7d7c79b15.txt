FHIR-35770: Audit EvidenceVariable characteristic combination naming

Issue request:
FHIR-35770 was a Published/Persuasive R5 CDS change request asking to rename the EvidenceVariable CharacteristicCombination code system and value set to CharacteristicCombinationCode because the then-current EvidenceVariable.characteristicCombination element and CharacteristicCombination binding/type name created duplicate code-generation names.

Initial application:
No commit explicitly mentioning FHIR-35770 was found. The relevant source history instead shows the same R5 area being changed by FHIR-36131 in commit 257b27a14fbae5c1bd725d3c46dfbbfcf5ed36df, which removed EvidenceVariable.characteristicCombination and replaced it with EvidenceVariable.characteristic.definitionByCombination. Later, FHIR-42886 in commit b6ffbe50c67dfcc7f9ceac3463e582537ad2d85c removed the EvidenceVariable.characteristic backbone and the EvidenceVariable-owned characteristic-combination terminology files entirely.

Additional context:
FHIR-36131 is Published/Persuasive with Modification and explicitly says to proceed with Option 2 and remove EvidenceVariable.characteristicCombination. FHIR-42886 is Applied/Persuasive with Modification and makes Group the preferred resource for defining combinations of characteristics, replacing EvidenceVariable.characteristic with EvidenceVariable.definition. The current build has EvidenceVariable active in source/fhir.ini, but current source/evidencevariable/structuredefinition-EvidenceVariable.xml contains EvidenceVariable.definition as a CodeableReference to Group and no characteristicCombination or definitionByCombination element. The remaining combination terminology is Group-scoped as GroupCharacteristicCombination in source/group, so changing it to the old requested CharacteristicCombinationCode name would be inaccurate for the current specification.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original duplicate EvidenceVariable naming condition no longer exists in current build source, and the current Group-scoped code system and value set names already distinguish the terminology from EvidenceVariable-specific element names.

Recommendation:
Keep this audit commit as-is. Do not apply the original R5 rename literally to the current R6 source unless a new work-group decision asks to rename the Group-scoped combination terminology or the Group.combinationMethod binding name.
