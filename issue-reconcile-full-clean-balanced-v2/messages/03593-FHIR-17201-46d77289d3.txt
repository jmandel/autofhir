FHIR-17201: Audit PlanDefinition device participant support

Issue request:
FHIR-17201 was a Published/Persuasive CDS change request raised against STU3 PlanDefinition. It asked that PlanDefinition.action.participant.type support a system/device participant, and the accepted resolution was to add device to the action participant type value set.

Initial application:
The issue was applied in the historical SVN-to-git history. Commit 3dc81b908557be64248363dc4e5bbf5ed5213965, git-svn build r14073, explicitly cites GF#17201 and added participantType changes to PlanDefinition and ActivityDefinition, including the device code in the action-participant-type sheet. Commit 218ca52323d4eeaca9d06b840cf6b24edd19891b, git-svn build r14074, followed up by fixing participant type short descriptions for the same issue.

Additional context:
The current source no longer uses the old spreadsheet as the primary representation, but PlanDefinition remains active in source/fhir.ini. The current action-participant-type CodeSystem includes code device with the definition "The participant is a system or device used in the care of the patient", and the ValueSet includes all codes from that system. PlanDefinition.action.participant.type and the parallel actor option type both have required bindings to that ValueSet and list device in their short code lists. ActivityDefinition and RequestOrchestration use the same participant type terminology consistently. Later DeviceDefinition/typeReference issues are separate reference-target refinements and do not change the FHIR-17201 code-system/value-set decision.

AutoFHIR reconciliation:
No source change was made. The current build-scope source and the live CI build already express the accepted FHIR-17201 decision: PlanDefinition participant type can be device, and the device code definition covers a system or device.

Recommendation:
Keep this empty audit commit as-is. No follow-up is needed for FHIR-17201 unless a future work group decision reopens whether the participant type code should distinguish systems from devices.
