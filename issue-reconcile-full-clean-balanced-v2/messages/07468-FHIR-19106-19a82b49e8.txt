FHIR-19106: Audit vital signs profile status

Issue request:
FHIR-19106 was a Published/Persuasive with Modification OO change request for the STU3 Observation vital signs profiles. The issue raised that Observation normativity could be undermined if required, non-normative vital-signs profile codes changed without the normative ballot process, and the accepted resolution was to add an STU tag to the Observation section referencing the vital signs profiles.

Initial application:
The issue was applied by git commit 4e1a75b0c290c0845cf0b007aed69d6fa1d7eec9, which added a Trial Use badge to the "Core Profiles for Observation" heading in source/observation/observation-introduction.xml. Commit deeb34d853b02952ec4016b1628737a2a9824653 later adjusted that badge from "Ballot Status" to "Standards Status" wording when FHIR moved to normative footing.

Additional context:
The current build no longer has the same Trial Use premise. Observation is an active resource in source/fhir.ini, the current Observation introduction still links to the Vital Signs profile set, and source/observation/implementationguide-Observation-vitalsigns.xml plus the Vital Signs Base and specific Vital Signs StructureDefinitions now carry structuredefinition-standards-status = normative. Commit 9a5f0357ef4d1c2e0eb8587ad85dae851ebfac0d changed those vital-signs profile statuses from trial-use to normative and removed the old Trial Use badge from the Observation core-profiles heading. Later applied issues such as FHIR-46418, FHIR-45617, FHIR-50689, and FHIR-50705 revisited vital-signs profile code stability and category-vs-code concerns for R6, but they do not make the old STU label appropriate again.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical FHIR-19106 request was already applied for the STU3-era source, and the current source is now clearer and stronger than the requested label because the vital-signs IG and profiles themselves are marked normative. Reintroducing a Trial Use/STU badge on the current Observation section would contradict those authoritative standards-status extensions.

Recommendation:
Keep this audit commit as-is. Do not restore the old Trial Use heading label for FHIR-19106 unless the OO Work Group explicitly changes the current standards status of the Vital Signs profiles. Continue handling any remaining R6 vital-signs modeling or code/category cleanup under their own Jira issues rather than under this STU3 status-label issue.
