Initial application:

The current text has since received routine conformance-language cleanup, changing may/should wording to current style without changing the clarification.

AutoFHIR reconciliation:

Recommendation:
Keep this audit commit as-is. The related Observation/VitalSigns profile request should remain separate because OO resolved that as no-change while Security supplied the intended clarification in the module narrative.
