FHIR-5233: Audit datatype summary diagrams

Issue request:
FHIR-5233 was a Published/Persuasive Jan 2015 MnM ballot clarification for the core datatypes page. It asked that the unexplained datatype diagram either be removed or expanded, and the accepted resolution was to add a primitive datatype summary diagram above the complex datatype diagram plus a legend explaining the then-used pink profile color.

Initial application:
The issue was applied in svn 4533, now git commit d8c3b09240e38503a709e6540aea5782e76cc4f7, which replaced the single datatype diagram with primitive and complex datatype summary diagrams and added the old white/light-blue/light-pink legend.

Additional context:
Later datatype-page refactors kept the navigation aid but broadened it: the current build-scope source shows primitive, general-purpose, metadata, and special-purpose datatype summary diagrams. The old profile-color legend was superseded during datatype/normative-status refactoring by the current standards-status color legend; no Zulip or Confluence evidence found a later instruction to restore the old pink-profile legend.

AutoFHIR reconciliation:
No source change was made. The current datatypes page already satisfies the accepted clarification by presenting primitive and complex/general-purpose datatype diagrams in the summary, and adding the old legend text would now be misleading because the current diagrams use the standards-status color model.

Recommendation:
Keep this audit commit as-is. Revisit only if the diagram renderer or current rendered page stops showing the primitive and general-purpose datatype summaries, or if MnM decides that diagram colors need a new local legend beyond the shared standards-status legend.
