FHIR-40717: Audit valueset-toocostly follow-up review

Issue request:
FHIR-40717 was an Applied/Persuasive with Modification FHIR-core ValueSet tracker asking for better documentation of the http://hl7.org/fhir/StructureDefinition/valueset-toocostly extension. The approved January 2024 resolution said to deprecate valueset-too-costly, add the structuredefinition-standards-status deprecated extension, and add text to the extension definition and description saying it was used in STU3 and earlier terminology services and that newer terminology servers should communicate the information with OperationOutcome issue code too-costly.

Initial application:
No current FHIR-core StructureDefinition source for valueset-toocostly exists: the extension definition was removed from core during the R5 extension move and now lives in the FHIR Extension Pack. Extension Pack commit 2d8d6741385fe7229cd5fbeb5ee276ec0abe31a5 explicitly implemented FHIR-40717 by adding the deprecated standards-status extension and the approved STU3/OperationOutcome too-costly wording to both the description and definition; follow-up commit 5d9a90e4e3a86095519075d326a1109b9a3f2e30 removed the duplicate trial-use status, and commit ea2d7b0ee5b77e9fe38e889cfc778d87e4edf776 later changed the artifact status to retired.

Additional context:
The current core checkout still has the active ValueSet resource and ValueSet/$expand operation. The $expand operation already says an overly large expansion may return an OperationOutcome with code too-costly, and OperationOutcome.issue.code includes too-costly. However, July 2025 TI minutes for FHIR-40717 record that Grahame thought the prior response missed the point: an OperationOutcome covers an operation that is too costly, but there should also be a way to mark a response as incomplete and provide too-costly as the reason; the issue was to be reviewed and brought back. Later related FHIR-core issues FHIR-49701 and FHIR-42811 continue the incomplete/unclosed/too-costly expansion discussion but are only Resolved - change required in this default Applied/Published run.
