FHIR-29573: Audit Medication batch container extension

Issue request:
FHIR-29573 was a Published Pharmacy change request, resolved Persuasive with Modification for R5, asking to add container type information to Medication.batch. The approved resolution was to create a core extension for this attribute rather than add a base Medication element.

Initial application:
No source commit was found whose message explicitly names FHIR-29573. Git history shows the request was nevertheless applied in the Medication batch extension family: December 2020 commits added the container-type definition to source/medication/medication-extensions-spreadsheet.xml, the January 2021 source rework generated source/medication/structuredefinition-extension-medication-manufacturingBatch.xml with the same container.type slice, and a February 2023 R5 cleanup removed that core extension source from this repository.

Additional context:
Current core Medication is active, but the historical Medication.batch path is mapped to Medication.instance in source/fhir.ini and the medication-manufacturingBatch StructureDefinition itself is no longer in the core source tree. The same extension now lives in the FHIR Extension Pack, whose IG includes input/definitions/* and whose medication-manufacturingBatch definition has context Medication.batch plus Extension.extension:container.extension:type with the requested container-type definition. Pharmacy minutes for 2020-11-09 confirm the work group block vote to add core extensions for this PQ/CMC batch issue family. Zulip and Confluence keyword searches found no later conflicting discussion for this seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change in HL7/fhir. The current core checkout does not own the extension definition, and the external Extension Pack source already carries the requested container type slice on the Medication batch manufacturing extension.

Recommendation:
Keep this audit commit as an external-repo decision. No core FHIR source change is recommended; any future content correction to medication-manufacturingBatch should be made in HL7/fhir-extensions rather than reintroducing the extension source into core.
