Issue request:
FHIR-15721 was a Published/Persuasive STU3 Vocabulary change request to update the "Using SNOMED CT with FHIR" core page based on SNOMED on FHIR group review. The approved resolution was to make the requested updates.

Initial application:
The issue was applied before this reconciliation in four 2018-03-14 git-svn commits: 86feee2310 (svn 13463) updated source/snomedct.html with the SNOMED on FHIR review material, 508caf7768 (svn 13464) fixed HTML, f509fd773c (svn 13466) made minor follow-up updates, and f9af1dd8 (svn 13471) fixed table headers.

Additional context:
FHIR-35933 later removed the external "Using X with FHIR" pages from core for R5 because their content migrated to HL7 Terminology (THO), with supporting Vocab minutes and UP-289. Current core no longer contains source/snomedct.html; source/hierarchy.xml and publish.ini actively include only source/snomedct-usage.html, and source/terminologies-systems.html links SNOMED CT guidance to https://terminology.hl7.org/SNOMEDCT.html plus the local usage report.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested STU3 page update was historically applied, and the current core build should not reintroduce or patch the removed source/snomedct.html page.

Recommendation:
Keep this audit commit as-is. Future substantive changes to general SNOMED CT guidance should be handled in THO/UTG; core should continue to maintain only the generated/local usage report and links unless Vocabulary reverses FHIR-35933.
