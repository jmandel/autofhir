FHIR-39256: Audit ValueSet profile descriptions

Issue request:
FHIR-39256 is Published/Persuasive for R5. It reported that the ValueSet profiles page showed the same package description for ComputableValueSet, ExecutableValueSet, PublishableValueSet, and ShareableValueSet instead of each profile's own description, and the final resolution says GG adjusted the build so the profile description displays.

Initial application:
No HL7/fhir source commit explicitly references FHIR-39256. The underlying profile source already had distinct descriptions from the ValueSet profile work in commit 93fadfaa2a89cdc46a2a2633431ebbc34f06fe74, so the defect was the generated profile-list display pulling the ValueSet Core package description. Jira comments and TI minutes record this as a build issue, and the R5 published ValueSet profiles page now shows the distinct profile descriptions.

Additional context:
FHIR-37959 later decided to remove the Shareable/Publishable/Computable/Executable profiles from core for R6 and maintain them outside the core FHIR specification. Commit 3958dd1e7c2fd73ad1e94c66f8d0884df55695d5 removed the ValueSet profile StructureDefinition source files and the ValueSet Core implementation guide references from current core; the current CI ValueSet profiles page reports that no profiles are defined for the resource.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The R5 publication surface already reflects the requested per-profile descriptions, and the current core build no longer includes the affected ValueSet profiles, so editing source/valueset/implementationguide-ValueSet-core.xml or adding duplicate prose would not fix a current core-spec defect.

Recommendation:
Keep this no-change audit commit as-is. If future work is needed for the migrated profile definitions, handle it in the repository/specification that now owns those profiles rather than reopening this R5 core build-display issue.
