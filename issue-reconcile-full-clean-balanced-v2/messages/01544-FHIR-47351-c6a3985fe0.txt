Issue request:
FHIR-47351 was an Applied/Persuasive FHIR-core Subscription change request for R6. It reported that the Subscription channel flow charts showed notification Bundles as Bundle.type = history and asked that the diagram values be changed to Bundle.type = subscription-notification.

Initial application:
The issue was applied before this reconciliation by commit 93da371da75483bd04af8e13c3ac0bd47fd390ea, "FHIR-47351 - fix bundle type in workflow diagrams", later merged through PR #3967 in 2ec3e732369b18cd589904205b73b4237f850e82. That commit updated the build-scoped PlantUML and SVG files for the email, REST hook, and websocket channel diagrams from Bundle.type: history to Bundle.type: subscription-notification.

Additional context:
Subscription is an active resource in source/fhir.ini, source/subscription/subscription-notes.xml references the channel workflow SVGs, and publish.ini includes the subscriptions SVG assets. The messaging diagram already distinguished the outer message Bundle from the inner subscription-notification Bundle. A later FHIR-50621 Triaged issue reports the same stale-label symptom, but it is not final and current source searches found no remaining Bundle.type: history labels in the Subscription source or subscription diagram assets. Confluence minutes and the Zulip block-vote announcement both list FHIR-47351 in the March 2025 Subscription block vote.
