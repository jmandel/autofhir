FHIR-28308: Audit Device status bindings

Issue request:
FHIR-28308 was a Published/Persuasive R5 OO change request asking for bindings on the then-current Device.operationalStatus.value and Device.associationStatus.value elements, using example value sets for already-agreed values such as on/off/standby and implanted/explanted/attached.

Initial application:
The issue was applied before this reconciliation by commit b1671782cb820cad536d9bcfb7747f99544cd085, which explicitly listed 28308 and added example bindings plus Device operational and association status code system/value set files to source/device/structuredefinition-Device.xml.

Additional context:
Later final Device work changed the shape of this area. FHIR-36195 revised Device.operationalStatus into an operation/operationalState structure, and FHIR-38904 then removed Device association and operation status content from Device while adding DeviceAssociation for patient/device association tracking. In the current build, source/fhir.ini has active Device and DeviceAssociation resources; parsed active Device elements no longer include operationalStatus, associationStatus, or operation, while DeviceAssociation.associationStatus is active and bound to http://hl7.org/fhir/ValueSet/deviceassociation-association-status. FHIR-48532 further updated DeviceAssociation.status and added the current preferred DeviceAssociation.associationStatus binding with association and operational codes.

AutoFHIR reconciliation:
No source change was made. The original missing Device bindings were applied, the original Device elements are no longer active build content after later published decisions, and the current active successor concept already has a binding to the DeviceAssociation Association Status value set.

Recommendation:
Keep this audit commit as-is. Do not edit the commented-out legacy Device element block or add redundant Device bindings; future work should only revisit this area through the active DeviceAssociation source if OO changes the current association/operational status model.
