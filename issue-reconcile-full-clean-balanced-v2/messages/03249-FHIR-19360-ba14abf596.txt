FHIR-19360: Audit PlanDefinition action context variable

Issue request:
FHIR-19360 was a Published/Persuasive with Modification CDS issue for STU3 PlanDefinition. It requested a way for PlanDefinition dynamicValue processing to refer to the current realized RequestGroup action, with the accepted mechanism being a FHIRPath-style %action environment variable, including an example such as %action.description.

Initial application:
The issue was applied by commit 66deb017f7378f60837b767ce3833f21336abfe2, which added the %action dynamicValue.path comment to the PlanDefinition spreadsheet source. Shortly afterward, related commit 760504d5b6cf37cf71430074257a1d92922ed371 added the PlanDefinition module note that $apply parameters are available as context variables and that %action may be used in dynamicValue.path.

Additional context:
The current build no longer uses the historical spreadsheet source for this resource, but source/fhir.ini actively includes PlanDefinition and RequestOrchestration. The current PlanDefinition StructureDefinition preserves the %action comment on PlanDefinition.action.dynamicValue.path, and the PlanDefinition notes preserve the example. FHIR-34265 later added the same dynamicValue/path semantics to RequestOrchestration.action.dynamicValue.path as RequestGroup evolved into RequestOrchestration. Corrected Zulip and Confluence searches found no conflicting community discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active source already conveys the accepted rule: %action is available in the dynamicValue path to refer to the current action target, with %action.description as the concrete example, and the surrounding $apply text documents dynamicValue CQL/FHIRPath operation parameters separately.

Recommendation:
Keep this no-change audit commit. No follow-up core source work is needed for FHIR-19360 unless the CDS work group separately decides that %action should also become a general dynamicValue expression variable beyond the path-specific rule that was actually applied.
