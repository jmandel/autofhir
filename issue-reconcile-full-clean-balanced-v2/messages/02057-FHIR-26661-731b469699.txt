FHIR-26661: Audit MedicationKnowledge cost category application

Issue request:
FHIR-26661 was Published / Persuasive with Modification for R5. It asked to add a coded price category to MedicationKnowledge.cost, and the approved resolution was to represent MedicationKnowledge cost as either an actual Money price or a CodeableConcept tier/band, with an example medication cost category value set using Band A, Band B, or symbolic tiers such as $ and $$.

Initial application:
The issue appears to have been applied by commit 603de50396, which listed FHIR-26661 among bundled Pharmacy changes. That commit changed the then-authoritative MedicationKnowledge spreadsheet from MedicationKnowledge.cost.cost Money to MedicationKnowledge.cost.cost[x], added CodeableConcept alongside Money, added a MedicationCostCategory example binding, added medication-cost-category CodeSystem/ValueSet files, and used the approved Band A/B and $/$$ definition text. The later source rework commit 33b409a4b6 converted the spreadsheet into the current StructureDefinition XML and preserved those cost[x] semantics.

Additional context:
The retained current source still has MedicationKnowledge.cost.cost[x] with Money and CodeableConcept types, the medication-cost-category example value set binding, and Band A/B concepts. However, MedicationKnowledge is no longer in the active current resource build list: source/fhir.ini has no MedicationKnowledge entry in [draft-resources] or [resources], and git commit 5a4307d78b removed the active MedicationKnowledge entries from source/fhir.ini and module/resource list pages. The same implementation commit also handled FHIR-26825 for the adjacent cost effective date; that issue already has a reconcile audit commit on the combined branch and is not duplicated here. Community searching found only a Zulip announcement of the new Jira and no Confluence references or conflicting rationale.
