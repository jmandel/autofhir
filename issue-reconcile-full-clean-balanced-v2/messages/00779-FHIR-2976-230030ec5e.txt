FHIR-2976: Audit retired TagList example request

Issue request:
FHIR-2976 is a Published/Persuasive FHIR-core ITS change request from the Initial Draft/DSTU1 era. It asked for XML and JSON examples of the old taglist response payload because taglist was then one of the few content types returned by servers.

Initial application:
The Jira comments record agreement and svn revisions 3083 and 3084. Git history contains the corresponding converted commits 2f90dba297ecb405b31de9bc7a6cd673872dd448 and 08db2f4f096142be620f434ef423284ef7f22aa5, both titled "{#2976} and {#2974}: add examples for tag list, bundles, binary resources". Revision 3083 wired the examples page into the old extras page machinery, and revision 3084 added source/extras-examples.html with XML and JSON taglist examples.

Additional context:
The old TagList/taglist wire structure was later retired when FHIR-3728, with related FHIR-3558 and FHIR-2889, replaced Atom/taglist wrappers with native Bundle and resource metadata. The current active REST source defines only application/fhir+xml, application/fhir+json, and application/fhir+turtle FHIR content types, and current resource/search pages describe tags through Resource.meta.tag and the _tag search parameter. Current source has no active taglist/TagList conformance text; the only current source hit is source/history.html release-history text saying atom and taglist were replaced by Bundle. Existing combined-branch audits for FHIR-3148 and FHIR-5476 independently confirm the same retired TagList/Atom cleanup family.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing examples for a retired TagList response format would make the current specification less correct, and editing the historical release note would not improve current implementer-facing behavior.

Recommendation:
Keep this audit commit as-is. No current FHIR core source follow-up is needed for FHIR-2976; any desire to repair archived DSTU1 TagList examples or old unit tests would be outside the current build.
