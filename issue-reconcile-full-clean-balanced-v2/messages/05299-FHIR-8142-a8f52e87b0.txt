FHIR-8142: Audit Condition patient search parameter rename

Issue request:
FHIR-8142 is a Published/Persuasive Patient Care change request from the 2015 May DAF ballot asking that Condition's valid search parameters remove subject because it had been replaced with patient; the recorded resolution says to rename the subject search parameter to patient.

Initial application:
No current git commit was found that mentions FHIR-8142 directly. The same 2015 Condition search-parameter change appears to have been applied through FHIR-6094, which has the same Patient Care vote date and svn revision 5891; git commit 584064415b304f98fd1074e03db8e78fba0dba2b removed the subject search parameter from the old Condition.patient model.

Additional context:
The current active Condition resource is no longer the old Patient-only model. Current source/fhir.ini includes Condition in the build, source/condition/structuredefinition-Condition.xml defines Condition.subject as Reference(Patient|Group) with alias patient, and source/condition/bundle-Condition-search-params.xml contains both Condition-patient, constrained to Condition.subject where the resolved target is Patient, and Condition-subject for the broader subject reference. Git commit e35d3b3f92f11757466373e8b8f9f829d96d5cc9 reintroduced Condition.subject and a subject search parameter when the resource model broadened to Patient|Group. Later FHIR-31714 work kept target-constrained patient search parameters Patient-only, and a 2019 implementer Zulip thread describes the current patient-vs-subject distinction.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reapplying the 2015 DAF removal now would delete the broader subject search parameter needed for non-Patient Condition subjects and would contradict the current Condition.subject model.

Recommendation:
Keep this audit commit as-is. Do not remove Condition-subject for FHIR-8142; any future desire to retire or rename the broader subject search parameter should be raised as a new current-version Patient Care/FHIR-I decision.
