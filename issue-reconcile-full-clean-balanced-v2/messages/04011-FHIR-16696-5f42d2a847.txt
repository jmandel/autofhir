FHIR-16696: Audit CDS Hooks clinical reasoning update

Issue request:
FHIR-16696 was a Published/Persuasive STU3 CDS change request for the Clinical Reasoning module audience text. The Jira noted a TBD/comment around whether the Knowledge Evaluation Service Provider guidance should continue to describe a service for guidance request and response consistent with the Decision Support Service specification; the approved resolution was to update the text to reflect the shift to using CDS Hooks for evaluation.

Initial application:
The issue was applied by git-svn commit 0a99dc43984b5ede4e1e2778815865245071bf93, which changed source/clinicalreasoning-module.html from referencing the current Decision Support Service specification to referencing the CDS Hooks specification in the Knowledge Evaluation Service Provider paragraph. Later Clinical Reasoning history continued the same direction by adding CDS Hooks guidance and by replacing stale $evaluate-focused wording with CDS Hooks-oriented service-integration wording.

Additional context:
The current Clinical Reasoning module and CDS-on-FHIR topic are active build inputs through source/hierarchy.xml. Later applied CDS issues refined the same area: FHIR-41440 changed the common use case description to reference CDS Hooks rather than $evaluate, and FHIR-53085 moved detailed CDS Hooks mapping/profile guidance to the Using FHIR Clinical Reasoning with CDS Hooks implementation guide while keeping the core page as an informative overview. The current source therefore no longer preserves the original DSS-specific guidance-request wording; it links the Knowledge Evaluation Service Provider paragraph to the local Decision Support Services topic and points detailed CDS Hooks guidance to the IG.

AutoFHIR reconciliation:
This commit intentionally makes no source change. source/clinicalreasoning-module.html already avoids the obsolete DSS-specification wording, source/clinicalreasoning-module.html:288 explicitly describes obtaining guidance through services such as CDS Hooks, and source/clinicalreasoning-cds-on-fhir.html describes surfacing clinical decision support through CDS Hooks with a maintained IG link. Reintroducing a direct CDS Hooks link in the audience paragraph would duplicate nearby guidance and partially undo the later FHIR-53085 decision to make core an overview that points to the IG for detailed CDS Hooks content.

Recommendation:
Keep this audit commit as-is. No current core source fix is needed for FHIR-16696; revisit only if the CDS work group wants the module audience paragraph itself to explicitly name CDS Hooks despite the later applied migration of detailed CDS Hooks guidance to the IG.
