It asked to change the Scope and Usage PICO wording from "population, exposure, comparator, and outcome" to "population, intervention/exposure, comparator, and outcome" so the EvidenceReport page aligned with other Evidence-related PICO descriptions.

Initial application:

Current active core narrative states that the EvidenceReport Resource in prior FHIR versions has been replaced with an EvidenceReport Profile of Composition in the Evidence Based Medicine on FHIR IG. Current active PICO-related core text no longer contains the rejected "population, exposure, comparator, and outcome" sentence.
