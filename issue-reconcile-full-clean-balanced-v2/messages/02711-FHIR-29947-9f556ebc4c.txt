FHIR-29947: Audit ConceptMap rendering outside core source

Issue request:
FHIR-29947 is a Published/Persuasive Vocab change request raised for R4 and applied for R5. It asked that ConceptMap examples render relationship codes without reversing source/target meaning, specifically by changing the column heading "Destination" to "Target" and adding hover text over Relationship column values that shows the concept definition.

Initial application:
No core source commit explicitly tagged FHIR-29947 was found. Jira and Vocab minutes show the issue was partially fixed in the build before July 2022, then reopened because the ConceptMap renderer still hard-coded a shortened relationship display/description. Current build output for cm-administrative-gender-v2 shows the heading has been changed to Target Concept Details, but the Relationship links still use title="source-is-broader-than-target" rather than the concept definition.

Additional context:
The authoritative core sources are in build scope: source/fhir.ini lists ConceptMap as an active resource, source/terminologies/bindings.xml supplies the administrative-gender ConceptMap data, and source/conceptmap/codesystem-concept-map-relationship.xml contains the correct definitions such as "The source concept is broader in meaning than the target concept." The remaining rendering behavior is not controlled by tracked source in this checkout: build.gradle.kts runs org.hl7.fhir.tools.publisher.Publisher from the external org.hl7.fhir:kindling dependency, and this repository currently tracks no Java publisher source. The example-comment follow-up from FHIR-29947 became FHIR-37815 and is already represented on the combined branch by commit 8ca85d225d.

AutoFHIR reconciliation:
This commit intentionally makes no source change and records an external-repo decision. The core FHIR source data needed by the renderer is already present and correct, while the still-missing hover-definition behavior belongs in the external Kindling/publisher renderer rather than in generated HTML or local source files in this checkout.

Recommendation:
Keep this audit commit as-is for core. Follow up in the Kindling/FHIR publisher renderer so ConceptMap relationship links use the relationship concept definition as their hover/title text while retaining the current Target heading. Do not edit generated ConceptMap HTML in this repository as a substitute for the renderer fix.
