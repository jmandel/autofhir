Initial application:

The current XML source preserves the Condition Category Codes naming and generic category definition.

FHIR-54157 separately records a Resolved - change required request to drop "Preferred" from the Condition category and clinical-status value set descriptions, but that issue is not Applied/Published in this default run and should not be implemented under FHIR-6132.
