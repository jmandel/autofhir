FHIR-28134: Audit Evidence certainty rating binding

Issue request:
FHIR-28134 was a Published/Persuasive CDS technical correction for R5 asking Evidence.certainty.rating's EvidenceCertaintyRating binding to use the existing http://hl7.org/fhir/ValueSet/evidence-quality value set, with Preferred binding strength, rather than a separate four-code certainty-rating list.

Initial application:
The request was directly applied in commit 34ac676510, which changed the then-authoritative Evidence spreadsheet binding row from a code list/extensible #certainty-rating entry to a value set/preferred http://hl7.org/fhir/ValueSet/evidence-quality entry. Follow-up commits 35167980e3 and cefed7e614 adjusted related Evidence examples, with cefed7e614 correcting the instance coding system to http://terminology.hl7.org/CodeSystem/evidence-quality.

Additional context:
Later Published CDS issue FHIR-28920 reworked Evidence.certainty for R5 and explicitly required EvidenceCertaintyRating to link to a combined certainty-rating value set with the high/moderate/low/very-low quality codes plus additional risk-of-bias and rating-change codes. That later change superseded the narrower FHIR-28134 evidence-quality binding. R5 final source already had Evidence.certainty.rating bound to http://hl7.org/fhir/ValueSet/certainty-rating with extensible strength, and current source points to the THO version, http://terminology.hl7.org/ValueSet/certainty-rating. FHIR-39632 and UP-396 then moved/filled the certainty-rating terminology in THO, and FHIR-53156 later changed this family of Evidence bindings to Example strength while adding a comment directing implementers to the EBMonFHIR IG for extensible and preferred value sets.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reverting Evidence.certainty.rating to evidence-quality/preferred would undo later final CDS decisions and would omit current certainty-rating codes needed by Evidence certainty use cases. The active Evidence resource source in source/fhir.ini and source/evidence/structuredefinition-Evidence.xml is internally consistent with current Evidence examples and ArtifactAssessment's parallel EvidenceCertaintyRating binding.

Recommendation:
Keep this no-change audit as-is. Do not reapply the original FHIR-28134 binding unless CDS explicitly reverses FHIR-28920/FHIR-39632/FHIR-53156 or the EBMonFHIR IG migration changes how these terminology bindings should be represented in core.
