FHIR-40471: Audit profile representation default

Issue request:
FHIR-40471 was Applied/Persuasive for FHIR-core profiles. It asked that profile presentations in Implementation Guides and the core specification default to the Key Elements view rather than the Differential table because modifier elements can change resource behavior and may be missed in a differential-only default. The Jira resolution was "Already done" with a 2026-04-13 FHIR-I vote of 13-0-0.

Initial application:
No FHIR-core source commit tagged FHIR-40471 was found. The Jira comment and 2024 FHIR IG Authoring minutes show the request was raised as HL7/fhir-ig-publisher#879. That IG Publisher issue records the community discussion, notes agreement to move to Key Elements once Key Elements defects were fixed, and was closed as Done on 2025-07-22. Current core profile pages generated from tools/templates/template-profile.html already put Text Summary before Differential View, so they do not default to the Differential table.

Additional context:
The 2024 Zulip discussion confirmed the policy question and the rationale: Key Elements is intended to show must-support, mandatory, constrained, modifier, and other implementation-significant elements, while Differential only shows changes from the immediate parent. Later Zulip discussion in July 2025 states that the current base template should already make Key Elements the default for IG profile pages. Current core build output for a profile page (vitalsigns.html) uses template-profile.html and shows Text Summary as the first tab and Differential View second. The core template does not expose a tab literally named Key Elements; introducing a new core-specific Key Elements tab would be broader renderer/template work and is not supported by a Jira issue resolved as already done.

AutoFHIR reconciliation:
Published this empty audit commit with no source change. The current FHIR-core source is not defaulting profiles to the Differential table, and the IG-specific implementation belongs to and has already been closed in the IG Publisher/base-template path.

Recommendation:
Keep this audit commit as-is. If a future work group explicitly wants FHIR-core profile pages to add or rename a first tab to Key Elements, that should be handled as a new renderer/template change rather than as a missing application of FHIR-40471.
