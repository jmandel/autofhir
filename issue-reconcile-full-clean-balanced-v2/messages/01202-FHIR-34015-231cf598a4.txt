FHIR-34015: Audit recommendation profile handling

Issue request:
FHIR-34015 was Applied with resolution Not Persuasive with Modification. It asked to add 33 recommendation-specific elements to PlanDefinition to support an evidence-based recommendation resource/profile, but the accepted resolution was not to add those elements to the base resource and instead to use a PlanDefinition-related profile/extensions and an EBM on FHIR IG.

Initial application:
The Jira comment says the issue was applied in 536780002c920af0f9be0bc243314cbc4bb5dcbf, but that SHA is not resolvable in the local HL7/fhir object graph or through the GitHub commit API. Local history shows the intended application path: cfe8c5e5c12e7cf7ce7f34da2dbc310e6c03d338 added a draft EBMRecommendation profile for ArtifactAssessment in source/artifactassessment/structuredefinition-profile-ebmrecommendation.xml, followed by ebd503dc549449cfb9e78fce422dc7c914b69327 refining the draft profile. That profile changed ArtifactAssessment/citation/artifact constraints rather than adding the requested elements to base PlanDefinition.

Additional context:
FHIR-48393 was later Applied/Persuasive for R6 and explicitly listed EBMRecommendation as already moved to EBM while removing profiles from the base specification. Its implementation commit 571498e2b2959573e07980c9117923b42624e3a1 deleted source/artifactassessment/structuredefinition-profile-ebmrecommendation.xml and other core profile files. Current source/fhir.ini keeps PlanDefinition as an active core resource and lists active core extension spreadsheets, but there is no active EBMRecommendation profile entry. Confluence records show CDS extensively discussed FHIR-34015 on 2021-09-29 and that the follow-on EBM Decision Map work remapped the recommendation modeling toward ArtifactAssessment/Citation/profile/IG work rather than base PlanDefinition element additions.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The current core source should not add the 33 requested PlanDefinition elements: that would contradict the applied FHIR-34015 disposition and the later FHIR-48393 removal of the EBMRecommendation profile from the base specification.

Recommendation:
Keep this audit commit as-is for core. Any future work on an EBM recommendation/decision-map profile should happen in the appropriate EBM IG or external source, not by adding recommendation-specific elements to base PlanDefinition in this repository.
