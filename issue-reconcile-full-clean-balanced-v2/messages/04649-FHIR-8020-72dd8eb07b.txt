FHIR-8020: Audit medication dispense request distinction

Issue request:
FHIR-8020 was Published as Persuasive with Modification for the DSTU1 Pharmacy MedicationDispense area. It asked for clarification about when to use the order-side MedicationPrescription.dispense information versus a full MedicationDispense resource; the approved resolution renamed the order element to dispenseRequest, expanded its definition, and clarified the MedicationDispense resource description and scope.

Initial application:
The Jira comment identifies SVN r6690. In git history this is 970685d6e91deb8f5a9ead1e97eb7abe674398c5, which renamed MedicationOrder.dispense to MedicationOrder.dispenseRequest in the then-current source and examples, updated the order-side definition, and updated MedicationDispense description/scope text.

Additional context:
The current build uses MedicationRequest rather than MedicationPrescription/MedicationOrder, and source/fhir.ini lists both MedicationRequest and MedicationDispense as active approved resources. The current MedicationRequest.dispenseRequest definition preserves the approved distinction in modern terminology. A later Published issue, FHIR-31016, correctly changed MedicationDispense from always being the result of an order to saying it can result from a pharmacy system responding to a medication request; that later wording is already represented on the combined branch and explains the difference from the original 2015 "is the result" sentence.

AutoFHIR reconciliation:
No source change was made. Current active source already distinguishes order-side dispense-request details from the MedicationDispense event/resource and incorporates the later approved FHIR-31016 wording. Reverting or restating the older exact Medication Order sentence would conflict with that later decision.

Recommendation:
Keep this empty audit commit as-is. The seed issue is already satisfied in current core source; no follow-up is needed for FHIR-8020 unless the Pharmacy work group wants a new, separate clarification about modern MedicationRequest/MedicationDispense workflow boundaries.
