FHIR-22492: Audit QuestionnaireResponse author role targets

Issue request:
FHIR-22492 was a Published/Persuasive with Modification FHIR-core QuestionnaireAnswers change request. It reported that the question-level author extension at http://hl7.org/fhir/StructureDefinition/questionnaireresponse-author did not allow PractitionerRole, preventing capture of a care provider's capacity or organization affiliation. The accepted resolution was to make the extension value Reference targets match the then-current QuestionnaireResponse.author list: Device, Practitioner, PractitionerRole, Patient, RelatedPerson, and Organization.

Initial application:
The issue was applied before this reconciliation. Jira records PR #1283, and git commit 63d9e813b4eb3934889324c15bd075801a86085d added PractitionerRole and Organization to source/questionnaireresponse/structuredefinition-extension-questionnaireresponse-author.xml while preserving Device, Practitioner, Patient, and RelatedPerson. Merge commit 6e63552ba58c6e4fdd4477a479d107d3df246bba brought that work into the main history. The core extension source was later removed from the R5 core checkout by dd468d4f1799dd79819315b211588ef1cf4586e0 when extensions moved out of core source.

Additional context:
QuestionnaireResponse is active in source/fhir.ini, and the current core QuestionnaireResponse.author target list includes PractitionerRole. The questionnaireresponse-author extension now lives in the FHIR Extension Pack, where input/definitions/multiple/StructureDefinition-questionnaireresponse-author.xml also includes PractitionerRole in the value Reference targets. FHIR-15882 is the earlier same-family decision that added PractitionerRole and Organization to QuestionnaireResponse.author itself. FHIR-41407 later added Group to QuestionnaireResponse.author/source in core and is already represented on the combined branch; any future extension-pack alignment for Group would belong to that later issue family or a new extension-pack task, not to this FHIR-22492 PractitionerRole reconciliation.
