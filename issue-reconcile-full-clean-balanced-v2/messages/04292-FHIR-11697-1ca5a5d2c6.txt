FHIR-11697: Audit PlanDefinition action code rename

Issue request:
FHIR-11697 was a Published/Persuasive CDS change request raised against DSTU2 PlanDefinition. It asked to rename PlanDefinition.actionDefinition.concept to PlanDefinition.actionDefinition.code because other resources use code-named CodeableConcept elements, and Jira recorded the approved resolution to change the element name to code.

Initial application:
The issue was applied in SVN revision 10081, imported as git commit b1b06618efbf85fca01daa3a495ef7a410905abb, which changed the PlanDefinition element from concept to code and also made the parallel action element rename in the then-current ActivityGroup/RequestGroup family for consistency.

Additional context:
Current source no longer has actionDefinition or RequestGroup as the active names. PlanDefinition is an active resource in source/fhir.ini, and the RequestGroup resource was later renamed to RequestOrchestration by J#24619. The active RequestOrchestration source preserves the action.code element. Searches of current source found no remaining PlanDefinition.action.concept, RequestGroup.action.concept, RequestOrchestration.action.concept, or actionDefinition.concept paths. Jira search found the adjacent FHIR-11698 tracker, but that is a separate wording/definition issue and was not needed to decide this element-name reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already contains PlanDefinition.action.code and RequestOrchestration.action.code, with the old concept path absent, so the requested rename is already represented in the current specification.

Recommendation:
