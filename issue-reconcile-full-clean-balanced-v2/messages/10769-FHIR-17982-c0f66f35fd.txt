FHIR-17982: Audit EOB obtainment guidance

Issue request:
FHIR-17982 is a Published/Persuasive FHIR-core ExplanationOfBenefit change request asking to add documentation on how to obtain EOBs from a payor. The issue was raised for STU3, applied for STU3, and marked non-substantive by Financial Management.

Initial application:
The application appears in Git commit 96ee4c7ff55abe91e3c9e496f4eda7609be542ba, whose subject lists GF #17982 with related financial trackers. That commit added the ExplanationOfBenefit introduction bullet "RealTime Exchange and Obtaining EOBs: EOBs may be obtained using Polling or FHIR REST (SEARCH)" linking to financial-module.html#real-time, and it added the real-time anchor to source/financial-module.html. The financial module also contains the "Request an Explanation of Benefits" polling use case.

Additional context:
source/fhir.ini lists ExplanationOfBenefit as an active FM resource with the eob abbreviation, so the EOB introduction is current build input. source/financial-module.html is the current Financial Module source page and includes the ExplanationOfBenefit resource item. Later source changes normalized payor to payer and changed patient health record wording to Personal Health Record, but they did not remove or contradict the EOB-obtainment guidance. Zulip and Confluence searches found no directly relevant or conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source already tells implementers that EOBs can be obtained using Polling or FHIR REST (SEARCH), and the linked financial module explains deferred responses via GET/SEARCH or Poll and includes a Task-based "Request an Explanation of Benefits" use case.

Recommendation:
Keep this empty audit commit as-is for FHIR-17982. No follow-up is needed unless Financial Management later decides to replace the legacy polling/REST guidance with a different workflow in a separate issue.
