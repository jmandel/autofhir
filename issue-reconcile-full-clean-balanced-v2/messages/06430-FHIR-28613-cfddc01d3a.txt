FHIR-28613: Audit ObservationDefinition boundaries text

Issue request:
FHIR-28613 was Published/Persuasive for R5 and requested replacing ObservationDefinition section 8.26.2, "Boundaries and Relationships", with narrative explaining that an Observation may instantiate an ObservationDefinition and should inherit the corresponding definitional characteristics, including category/code/value type, reference ranges, valid coded values, subject, device, specimen, and unit handling.

Initial application:
The issue was applied before this reconciliation. Jira records the requested text and an "Added to the build" PR commit, while local history shows FHIR-28613 commits 48d31af3b7/2757b927a8 adding the replacement narrative, 6e8533f366 updating qualifiedValues wording to qualifiedValue, and 51a7c5808c aligning the section more closely to the final Jira proposal.

Additional context:
ObservationDefinition is active in source/fhir.ini, so source/observationdefinition/observationdefinition-introduction.xml is in current build scope. Later source and Jira changes changed the resource model and the matching narrative: the current resource uses bodyStructure instead of bodySite, qualifiedValue instead of qualifiedInterval, subject instead of subjectCodeableConcept, and permittedUnit instead of the older unit/customaryUnit text. FHIR-40678 specifically replaced the old customaryUnit paragraph with permittedUnit wording, so the current wording is an intentional later correction rather than missed FHIR-28613 text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Boundaries and Relationships section already conveys the approved FHIR-28613 relationship and inheritance guidance, with the element names updated for the current ObservationDefinition structure and later applied decisions.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the original R5-era qualifiedInterval, bodySite, subjectCodeableConcept, or customaryUnit wording; those names are stale for the current resource model.
