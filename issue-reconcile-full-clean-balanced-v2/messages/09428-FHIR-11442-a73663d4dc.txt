FHIR-11442: Audit homepage credits link

Issue request:
FHIR-11442 was a Published/Persuasive with Modification FHIR-core change request from the DSTU2 ballot asking for a credits link at the bottom of the home page. The accepted resolution was to add it to the footer.

Initial application:
The issue was explicitly applied in git-svn commit 8b58c09a58 (#11442 / svn revision 11398), which added an active Credits link to source/newfooter.html. A later untagged commit, 057ed2a475, added a Community Credits link directly to source/index.html.

Additional context:
The current build-scope home page is source/index.html, listed in publish.ini, and it still includes a visible Community Credits link to credits.html. The credits page itself is also listed in publish.ini and source/documentation.html links to it. The old global footer link was commented out in the generic 2019 footer rebuild commit b953d9bd97 and that commented state was carried forward when templates moved to tools/templates/newfooter.html in 2020. No Jira, Zulip, or Confluence evidence was found requiring the global footer link to be restored now.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current specification already provides the requested homepage navigation to Community Credits, and re-enabling the commented footer link would be a broader global navigation change rather than a necessary correction for this non-substantive historical issue.

Recommendation:
Keep this no-change audit. Revisit only if the work group explicitly wants the Credits link restored to every generated page footer, because that would be a current navigation/design decision rather than a missing application of FHIR-11442.
