FHIR-7805: Add Medication RXC text mapping

Issue request:
FHIR-7805 is a Published/Persuasive FHIR-core Medication tracker from the DSTU1 QA process. It asked to add RXC-2.2 Component Text to the existing HL7 v2 text mapping for medication names, alongside RXO-1.2, RXE-2.2, RXD-2.2, RXG-4.2, and RXA-5.2 code text components.

Initial application:
The Jira comments say the issue was applied during DSTU QA, and git-svn commit 651364cb09 lists tracker #7805 in a 2015 Medication v2 mapping batch. That patch added RXC-2.1 Component Code to Medication.code, satisfying companion issue FHIR-7806, but exact-source history did not show RXC-2.2 Component Text being carried into Medication source.

Additional context:
The original request targeted the old Medication.name/text mapping. Later FHIR-8553 removed Medication.name and updated Medication.code to carry textual descriptions, and later FHIR-45876 reaffirmed that the medication name can be conveyed in Medication.code.text. Medication is active in source/fhir.ini, and the current authoritative source is source/medication/structuredefinition-Medication.xml. The combined branch already has a FHIR-7806 no-change audit for the preserved RXC-2.1 code mapping, so this commit is limited to the missing text mapping.

AutoFHIR reconciliation:
This commit updates the active Medication.code v2 mapping to retain the current RXO/RXE/RXD/RXG/RXA/RXC code-component mapping and add the corresponding text-component mapping, including the requested RXC-2.2 Component Text, as the current-model equivalent of the old Medication.name mapping.

Recommendation:
Keep this source fix as-is. It is a narrow build-scoped completion of the Published DSTU1 v2 mapping request after later Medication.name removal, and it does not reopen the broader Medication.code/name design settled by FHIR-8553 and FHIR-45876.
