FHIR-50224: Audit corrected ServiceRequest orderDetail typo

Issue request:
FHIR-50224 is an Applied/Persuasive OO technical correction for FHIR-core-ServiceRequest. It asked to fix the ServiceRequest.orderDetail definition typo from "For example, and order for a urinary catheter" to "For example, an order for a urinary catheter" on the ServiceRequest definitions page, applied for R6.

Initial application:
No prior reconciliation commit with Issue-Reconcile-Key: FHIR-50224 was present on the combined branch. The active ServiceRequest.orderDetail source had already been corrected by the FHIR-31589 ServiceRequest clarification work in 2024, whose approved resolution text includes the same corrected sentence now present in source. A later git commit and merge mentioning FHIR-50224 exist in the current branch history, but they changed only publish.ini to add transport-resource-event.png and did not alter ServiceRequest wording.

Additional context:
ServiceRequest is active in the current build through source/fhir.ini. The only remaining literal typo matches are in a commented-out legacy ServiceRequest.orderDetail XML block and in source/servicerequest/servicerequest.svg, a generated-looking diagram artifact. The authoritative active StructureDefinition element already uses the corrected definition, and the workflow guardrail says not to make a source-changing commit whose only remaining edit would be a generated-looking SVG or out-of-build commented source.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The build-relevant ServiceRequest.orderDetail definition already says "For example, an order for a urinary catheter...", so editing the inactive commented block or stale SVG would not improve the current specification semantics.

Recommendation:
Keep this audit commit as-is for FHIR-50224. If maintainers regenerate ServiceRequest diagrams, the stale SVG tooltip should be refreshed from authoritative source, but no manual core source correction is needed for the definitions page typo.
