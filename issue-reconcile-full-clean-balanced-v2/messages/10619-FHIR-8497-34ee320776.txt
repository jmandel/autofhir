Initial application:

Additional context:
The old c80-doc-classcodes source file is no longer in the current FHIR build. Later document-class terminology work, especially FHIR-11907 and the 68a11fd7f788b9d67f05aca68d9ecd08236580ca source commit, removed that old C80 value set. Current DocumentReference.category instead binds the active referenced-item-category value set, and the current document category/type value sets are defined by a filter over all LOINC DOC scale codes plus media-category codes. FHIR-24671 later accepted the current DocumentReference.category value set as already applied.
