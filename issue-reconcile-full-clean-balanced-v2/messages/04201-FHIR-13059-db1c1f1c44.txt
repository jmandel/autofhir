FHIR-13059: Audit UsageContext value set examples

Issue request:
FHIR-13059 was a Published/Persuasive CDS change request for DSTU2 asking that Usage Context type codes stop describing possible value sets only by OID and instead define or locate FHIR value sets for those context types. The accepted resolution was that example value sets would be defined for each usage context type.

Initial application:
The issue was applied in SVN 11663, imported as git commit 08d280b8e8593f627923e0cade06a02eea8d7d2b (#13059: Example value sets for use contexts). That commit changed the active UsageContext datatype spreadsheet and valueset-use-context terminology source to add a UsageContextValue example binding plus FHIR value set URLs and compose inclusions for the relevant usage context examples.

Additional context:
The active build still includes UsageContext in source/fhir.ini [types], with usagecontext mapped to the metadatatypes page. Current source/datatypes/usagecontext.xml binds UsageContext.code to the THO usage-context-type value set and UsageContext.value[x] to the FHIR use-context example value set, and its usage-context-type definitions now cite FHIR/THO value set URLs rather than bare OIDs. Later FHIR-14233, already represented on the combined branch, relaxed the wording to make the value sets clearly examples and changed venue to ServiceDeliveryLocationRoleType; FHIR-13091 was closed Resolved - No Change because that venue change had already been made elsewhere.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current UsageContext spreadsheet, valueset-use-context terminology source, and additional bindings already preserve the accepted FHIR-13059 outcome after later clarifications.

Recommendation:
Keep this audit commit as-is. No follow-up core source edit is needed for FHIR-13059; any review of the related venue clarification should use the existing FHIR-14233 reconcile record rather than duplicating it here.
