Issue request:
FHIR-12345 was a Published Pharmacy technical correction with resolution Persuasive/auto-approved. It asked to fix the MedicationStatement.category terminology binding description by adding the missing word "statement" so the description referred to medication included in the MedicationStatement.

Initial application:
Jira records the issue as applied on November 14, 2016 in build@10195. Git history confirms the corresponding git-svn commit a14bb96e03, whose subject says TR#12345 fixed the MedicationStatement.category binding description; the patch changed the spreadsheet binding text from "where the medication included in the is expected" to "where the medication included in the medicationstatement is expected".

Additional context:
MedicationStatement is an active current-build resource in source/fhir.ini, and the authoritative current StructureDefinition now renders the binding description as "A coded concept identifying where the medication included in the MedicationStatement is expected to be consumed or administered."
