FHIR-13739: Audit ConceptMap URI search parameter types

Issue request:
FHIR-13739 was Published/Persuasive for STU3. It reported that the ConceptMap `source-uri` and `target-uri` search parameters were token-typed and asked to change them to `uri`. Jira later records that the request was superseded by GF/FHIR-12902 canonical datatype work and was marked applied because the original intention had been met.

Initial application:
No git commit found in the current source history explicitly mentions FHIR-13739. The application trail is through the superseding FHIR-12902 work in git 2319e45e4115705f873661fe217ae2971eebc13f, which introduced canonical/reference search semantics, and the later same-family FHIR-14245 application in git 1b5b44719301018908cbec59de2ac76177570c54, which updated the active ConceptMap search-parameter bundle after the R5 ConceptMap refactor. That later commit made the URI-specific ConceptMap scope parameters `source-scope-uri` and `target-scope-uri` type `uri`.

Additional context:
FHIR-14245 is already represented on the combined branch by commit 5b0b27e045f0bbe8afa296d64f867b043755bb92, so this reconciliation must not duplicate that issue. Current ConceptMap source is active in the build, and the current StructureDefinition models `ConceptMap.sourceScope[x]` and `ConceptMap.targetScope[x]` as `uri | canonical(ValueSet)`. The matching current search parameters use `reference` for the canonical-valued scope entries and `uri` for the URI-valued scope entries. A later Zulip thread about the R4 `source-uri` type confirms the current R5/R6 shape: the old R4 parameters were renamed/replaced, and the current URI-specific parameters are URI typed.

AutoFHIR reconciliation:
This audit commit makes no source change. The current source already satisfies FHIR-13739's semantic request in the current build: the URI-valued ConceptMap source/target scope search parameters are `uri`, while the canonical-valued counterparts intentionally remain `reference` because versioned canonical search behavior is desired. Adding further prose or changing the already-audited FHIR-14245 search parameter entries would be redundant.

Recommendation:
Keep this no-change audit. If the work group wants to revisit R4 publication behavior, search-page wording, or internal placeholder URL consistency, handle those as separate issues rather than changing the current ConceptMap source for FHIR-13739.
