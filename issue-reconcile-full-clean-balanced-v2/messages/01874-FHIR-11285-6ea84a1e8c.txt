FHIR-11285: Audit removed ImagingStudy radiology guidance

Issue request:
FHIR-11285 was Published with a Persuasive with Modification resolution for the DSTU2 ImagingStudy ballot comment. It asked to remove the ImagingStudy.procedure comment recommending LOINC radiology orderables because ImagingStudy can be used outside radiology and implementers should choose the right value set for their environment.

Initial application:
The prior application is visible in git history. Commit b838ed23f3, "Updates to ImagingStudy for CP GF#10740, GF#11282, and GF#11285", removed the old "For the Procedure.code, LOINC radiology orderables would be a good value set to use" comment from the ImagingStudy spreadsheet source. The old comment had been introduced by FHIR-6243 in commit d2e4d8176d.

Additional context:
ImagingStudy is an active current-build resource in source/fhir.ini. The current authoritative StructureDefinition has ImagingStudy.procedure as Reference(Procedure) with only a local comment about using ImagingStudy.encounter to link to an Encounter; it no longer contains radiology, LOINC orderables, RadLex, or RSNA guidance. Later radiology-playbook discussion found in Zulip concerned value set URI availability and does not conflict with this removal decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope ImagingStudy source already reflects the Jira resolution by omitting the radiology-specific Procedure.code recommendation, so adding or removing text now would not improve the current specification.

Recommendation:
Keep this audit commit as-is. No follow-up in FHIR core is needed for FHIR-11285 unless a future work group decision reintroduces explicit ImagingStudy procedure coding guidance.
