FHIR-17391: Audit Observation test comments

Issue request:
FHIR-17391 was a Published OO change request with resolution Not Persuasive with Modification. It asked to extend Observation for laboratory test-level comments because STU3 Observation.comment was defined as comments about the result; the accepted modification declined a new element and said to clarify the definition to "comments about the test result value", with event-note as the then-existing general event-comment extension.

Initial application:
The issue was applied in historical commit 99532b4c0a ("GF#17391..."). That commit changed the Observation.comment spreadsheet source so the short/definition became "Comments about the test result value" and added explanatory text about significant, unexpected, or unreliable result values and source information relevant to interpretation.

Additional context:
Later same-element work superseded the exact STU3 shape. FHIR-17576 changed Observation.comment 0..1 string to Observation.note 0..* Annotation and intentionally broadened the wording to comments about the observation or results. FHIR-18157 corrected a typo in that explanatory text. FHIR-17522 expanded Annotation.author[x] to include Organization, PractitionerRole, and Device, directly addressing the Jira comment concern that lab- or instrument-generated comments need not be tied to an individual. Observation is active in the current build, and the current source now represents this capability through Observation.note rather than the old Observation.comment/event-note split.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build-scope Observation.note definition and comment already cover comments about the observation/test and its results, and Annotation authoring already supports organizations and devices; changing the wording back to the narrower STU3 "test result value" phrasing would undo later OO decisions.

Recommendation:
Keep this no-change audit as-is. No core FHIR follow-up is needed for FHIR-17391 unless OO reopens the later Observation.note wording policy.
