FHIR-38028 was a Published/Persuasive FHIR-core technical correction from OO asking to replace the ValueSet definition for BDP.productCodes from "Biologically Derived Product Codes." with an ISBT 128 Product Description Codes description that explains ICCBBA publication and use for characterization and classification of medical products of human origin.

Initial application:

Additional context:
BiologicallyDerivedProduct is active in source/fhir.ini, so the ValueSet source under source/biologicallyderivedproduct is in current build scope. Later source harmonization and metadata commits changed formatting, version/status metadata, and copyright representation, but the current ValueSet description still conveys the FHIR-38028 requested definition; the current text includes an added copyright symbol after "Product Description Codes" without changing the rule. OO minutes from 2022-08-29 independently record that the BDP ValueSet description was missing and that FHIR-38028 was added to update it. A later UTG proposal, UP-796, concerns adding a terminology code-system fragment and remains Proposal Draft/on hold, so it does not supersede this core ValueSet-definition audit.
