FHIR-19967: Rename remaining profile snapshot heading

Issue request:
FHIR-19967 is Published with resolution Persuasive with Modification. It asked to replace the confusing profile publishing tab label "Snapshot" with "Full Structure" and to add explanatory text for the differential and consolidated profile views in the core publication process for profiles and extensions.

Initial application:
The issue was applied by Jira-tagged commit aae540952c, which changed the profile template's main tab from "Snapshot Table" to "Full Structure" and added the requested differential and consolidated-view descriptions. Current extension template source already uses "Full Structure". The profile template's combined "All" tab still retained the old user-facing heading "Snapshot View" for the same consolidated structure section.

Additional context:
FHIR-I minutes show the group first discussed names such as "Full Snapshot" or "Full View (Snapshot)" and then decided at WGM to rename the tab to "Full Structure" while keeping explanatory text that mentions the technical snapshot name. The Jira comment also created external follow-up issues for Kindling and the IG template. The current core checkout still has a hidden ad-hoc IG StructureDefinition template with a "Snapshot" heading, but that is not the active core profile/extension page template fixed by this reconciliation.

AutoFHIR reconciliation:
Changed tools/templates/template-profile.html so the combined "All" tab labels the consolidated profile section "Full Structure", matching the main tab and the approved terminology while preserving the explanatory "aka snapshot" text.

Recommendation:
Keep this core template fix. If the open Kindling or IG-template GitHub issues still matter for non-core publishing surfaces, handle them in those external tooling repositories or by a focused tooling review rather than broadening this core source reconciliation.
