FHIR-31811: Audit Ingredient manufacturer backbone

Issue request:
FHIR-31811 was a Published FHIR-core/BR&R change request for R5. Although the summary said manufacturer did not belong directly on Ingredient, the final Persuasive with Modification resolution was to keep manufacturer on Ingredient as a 0..* backbone element, add an optional 0..1 role code with a required binding, and keep a 1..1 Organization reference for the manufacturer.

Initial application:
The issue was applied before this reconciliation. Commit 90626a2640 changed Ingredient.manufacturer from a direct Organization reference into a BackboneElement containing Ingredient.manufacturer.role and Ingredient.manufacturer.manufacturer. Later FHIR#31811 commits refined the application: 72c7bcfe69 and 464b98e6e7 inserted the approved multi-case definition text, and ec0ce86256 changed role from Coding to code and corrected the value set description.

Additional context:
Ingredient is active in the current build through source/fhir.ini, with MedicinalProductIngredient mapped forward to Ingredient. The latest combined branch already contains the requested structure, required role binding to ingredient-manufacturer-role, Organization target reference, and the corresponding manufacturer search parameter expression over Ingredient.manufacturer.manufacturer. BR&R Confluence minutes show FHIR-31811 was continued on 2021-09-28 and considered/resolved on 2021-09-30; Jira and community searches found no later conflicting issue or Zulip discussion for this manufacturer backbone decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already implements the published resolution, so any edit would be redundant formatting or restatement rather than a necessary specification correction.

Recommendation:
Keep this no-change audit commit as-is. No FHIR-core follow-up is needed for FHIR-31811 unless BR&R later chooses to revisit the policy question of whether manufacturer information should move fully to SubstanceDefinition.
