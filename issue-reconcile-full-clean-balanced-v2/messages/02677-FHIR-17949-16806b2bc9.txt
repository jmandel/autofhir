FHIR-17949: Audit Coverage class search parameters

Issue request:
FHIR-17949 is a Published/Persuasive FHIR-core Coverage change request from the Financial Management work group. It asked to add Coverage class.type and class.value search parameters so implementers can search for all members of a coverage class, for example a payer group value such as ABC123.

Initial application:
The request was applied in commit 7fbe7046270ff6857644a6af63207642576dc7ef, whose subject explicitly included #17949 and whose Coverage spreadsheet changes added search parameter rows for class-type on Coverage.class.type and class-value on Coverage.class.value. The later core source refactor in 33b409a4b6d544598262f2f074ebb4b6dc466157 moved those search parameters into source/coverage/bundle-Coverage-search-params.xml without dropping them.

Additional context:
Coverage is active in source/fhir.ini, so source/coverage is current build scope. Later Coverage work changed Coverage.class.value from a primitive string to an Identifier and the class-value SearchParameter now has type token, which is the correct search type for Identifier while preserving the original searchable Coverage.class.value intent. Related Jira issues about Coverage.class.value mappings and datatype refinements support that the class structure remains current rather than superseding this search-parameter request.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Coverage search parameter bundle already defines code class-type with expression Coverage.class.type and code class-value with expression Coverage.class.value, so the Published Jira request is satisfied in current source.
