FHIR-12615: Audit Goal value set display casing

Issue request:
FHIR-12615 was a Published/Persuasive Patient Care QA change request for DSTU2 asking that the Goal value set display names be TitleCase, specifically calling out goal-category dietary, goal-priority high, and goal-status-reason surgery.

Initial application:
The request was applied in January 2017 by df58ee3f55, which changed Goal category displays to values such as Dietary and changed the priority codes/displays to high-priority/High Priority, medium-priority/Medium Priority, and low-priority/Low Priority. A follow-up commit fd96fa1d81 completed the status-reason display casing, including surgery/Surgery, life-event/Life Event, and Goal Not Attainable Temporarily.

Additional context:
Goal remains an active and approved current build resource. The category and priority code systems were later removed from the core checkout as UTG/THO terminology content, and current Goal bindings now reference the core Goal Category value set and the THO Goal Priority value set. The current THO category and priority code systems expose TitleCase displays, and the remaining core Goal status-reason code system source also uses TitleCase displays. Later Goal priority binding commits FHIR-53104 and FHIR-56542 changed the binding targets to THO but did not reverse the display-casing decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source and referenced THO terminology already preserve the TitleCase display names required by FHIR-12615, and editing core would either be redundant or belong to external terminology content rather than this FHIR source checkout.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-12615 unless a future terminology publication regresses the THO Goal category or priority displays.
