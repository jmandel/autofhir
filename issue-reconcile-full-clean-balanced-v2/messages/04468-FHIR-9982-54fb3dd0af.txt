FHIR-9982: Audit MedicationStatement summary flags

Issue request:
FHIR-9982 is a Published/Persuasive Pharmacy change request from the DSTU2 era asking that MedicationStatement retain summary flags for status, medication, patient, effective[x], wasNotTaken, and dateAsserted.

Initial application:
The issue was applied in historical commit 2df711bee7ad56d7df9aef20f8c483a9bcc56ce8, which explicitly mentioned 9982 and added summary markers in the old MedicationStatement spreadsheet source for status, medication, patient, effective[x], wasNotTaken, and dateAsserted. That spreadsheet source is no longer present in the current build; MedicationStatement now uses the active StructureDefinition XML source.

Additional context:
The current build includes MedicationStatement as an active resource in source/fhir.ini. Later source evolution renamed MedicationStatement.patient to MedicationStatement.subject, and Pharmacy R5 decisions replaced the older not-taken/taken representation with MedicationStatement.adherence. FHIR-19468 records the decision to remove not-taken from status and convey taken/not-taken using adherence; FHIR-19470 records the decision to rename takenAsOrdered to adherence; FHIR-38682 later renamed MedicationUsage back to MedicationStatement while keeping those changes. Current MedicationStatement marks status, medication, subject, effective[x], dateAsserted, adherence, and adherence.code as summary, so the FHIR-9982 semantics are still represented after the later redesign.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding obsolete patient, wasNotTaken, or notTaken elements would be wrong for the current resource, and removing later summary flags such as category, encounter, author, or adherence would exceed the DSTU2 issue and conflict with later active source state.

Recommendation:
Keep this audit commit as-is. No follow-up is needed in FHIR core for FHIR-9982 unless the Pharmacy work group later reopens the broader question of which current MedicationStatement elements should be summary.
