FHIR-27832: Clarify package example folder path

Issue request:
FHIR-27832 was a Published/Persuasive FHIR-core technical correction raised against R4 and applied for R5. It asked the NPM package specification to say that examples, when present, are JSON and that additional package folders are below the package folder rather than siblings of it.

Initial application:
The issue was initially applied by b270ad0998373820b9f6c195ce3fa39e3dc318a6, which changed source/packages.html to mention JSON example resources below the package folder and additional folders below package. That application left the main structure bullet saying an examples folder while a neighboring package type bullet and current package artifacts use /package/example.

Additional context:
source/hierarchy.xml includes packages.html in the current build navigation, so source/packages.html is an active source page. FHIR-I minutes for 2020-06-22 recorded the issue as a technical correction to improve the JSON package documentation while noting XML package documentation could be parallel future work. Current HL7 IG packages and a 2024 implementer discussion use package/example for IG examples, which makes the prior plural folder name misleading.

AutoFHIR reconciliation:
This commit keeps the Jira-requested JSON and under-package-folder guidance, changes the example folder name to the explicit current path /package/example, and clarifies that additional folders and files are below the package folder.

Recommendation:
Keep this source fix. It preserves the published resolution while removing an implementer-visible inconsistency in the current package specification; separate XML package documentation, if still desired, should be handled by a new work-group decision.
