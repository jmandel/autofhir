FHIR-17659: Audit JHN display wording

Issue request:
FHIR-17659 was a Published/Persuasive FHIR-core M&M change request raised for STU3 asking to remove "(Canada)" from the JHN identifier type display because JHN is not Canada-specific. Jira records approval through a November 2018 harmonization proposal.

Initial application:
No git commit explicitly mentioning FHIR-17659 was found in the FHIR source history. The neighboring FHIR-13972 application added JHN to source/terminologies/valueset-identifier-type.xml in commit c3b2e501fb466020064156d469506929efd94fa5, and the old R4 core package still shows the pre-correction display "Jurisdictional health number (Canada)" for v2-0203/JHN.

Additional context:
The current core source does not define the v2-0203 code display directly. It only includes code JHN in the active Identifier Type Codes ValueSet, sourced from http://terminology.hl7.org/CodeSystem/v2-0203. Current local THO packages for both hl7.terminology.r5#5.3.0 and hl7.terminology#4.0.0 define JHN with display and definition "Jurisdictional health number", while retaining comments that explain both UK and Canadian uses. The already-published combined-branch audit for FHIR-13972 confirms the JHN ValueSet inclusion and should not be duplicated here.

AutoFHIR reconciliation:
This audit commit makes no source change because the current core source contains no stale "Jurisdictional health number (Canada)" wording to remove, and the terminology source of truth used by current builds already has the corrected non-Canada-specific JHN display.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-17659; future changes to v2-0203/JHN wording should be handled through THO terminology governance rather than by editing the core ValueSet membership.
