FHIR-11121: Audit Immunization reporting source elements

Issue request:
FHIR-11121 was a Published/Persuasive with Modification PHER FHIR-core Immunization issue. It said the GForge 9205 change had not made STU3 and requested removing the top-level Immunization.reported element, adding Immunization.primarySource as a boolean, and adding Immunization.reportOrigin for the source of non-primary immunization reports while avoiding a split into separate administration and statement resources.

Initial application:
The issue was explicitly applied in git commit baf0c978b8, whose subject says "[#9205] and [#11121]" and which replaced reported with primarySource in examples, added primarySource and reportOrigin to the Immunization spreadsheet, and added the immunization-origin value set. The old spreadsheet source was later refactored into the current StructureDefinition XML; the active current source still carries the replacement primarySource concept and the report-origin concept as Immunization.informationSource.

Additional context:
Immunization is active in the current build via source/fhir.ini. Later final decisions intentionally changed literal details from the 2016 resolution: FHIR-15694 changed primarySource from 1..1 to 0..1; FHIR-15696 and FHIR-20327 approved Option B, which renamed and expanded reportOrigin to informationSource[x]; FHIR-32394 converted informationSource to CodeableReference; and FHIR-37722 clarified that informationSource captures the source of a reported immunization event while primarySource captures the relationship of the record source to the administration event. The combined branch already has separate no-change audit commits for FHIR-11187 and FHIR-15694, and no commit for FHIR-11121 existed before this reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped Immunization StructureDefinition has no top-level Immunization.reported element, defines Immunization.primarySource with the later-approved optional cardinality and clarified definition, and defines Immunization.informationSource with the ImmunizationReportOrigin binding to the immunization-origin value set. Reverting to reportOrigin or restoring primarySource to 1..1 would conflict with later Published decisions.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source edit is needed for FHIR-11121; future changes to these elements should be handled under the later primarySource/informationSource issue family rather than by replaying the original 2016 wording.
