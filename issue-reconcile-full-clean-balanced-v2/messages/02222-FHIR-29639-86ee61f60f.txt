FHIR-29639: Audit Statistic modelCharacteristic cleanup

Issue request:
FHIR-29639 was Published/Persuasive with Modification for R5 and asked to simplify Statistic.modelCharacteristic by removing valueCodeableConcept from Statistic.modelCharacteristic.value[x], making Statistic.modelCharacteristic.code 1..1, adding StatisticModelCode codes, and then further simplifying value[x] so the remaining value element was only SimpleQuantity after removing valueBoolean and valueRange.

Initial application:
The issue was applied in commit 7d9ae39d22525c89071c3ab92d5bf08eaf152ed4 against the then-current source/datatypes/statistic.xml spreadsheet. That commit changed Statistic.modelCharacteristic.code from 0..1 to 1..1, replaced the value[x] choice CodeableConcept | boolean | SimpleQuantity | Range with a non-choice SimpleQuantity value, and expanded the statistic-model-code sheet. Later R5/R6 refactors removed the standalone Statistic datatype and inlined the statistic backbone under Evidence.

Additional context:
Evidence is an active CDS resource in source/fhir.ini, while the old Statistic datatype source no longer exists in the current build. The current authoritative source is source/evidence/structuredefinition-Evidence.xml. In R5-import state commit 49b86f8a697 the inlined Evidence.statistic.modelCharacteristic.value was still SimpleQuantity-only, preserving FHIR-29639. Later Applied R6 issue FHIR-41379 deliberately changed the current Evidence.statistic.modelCharacteristic.value element back to value[x] with Quantity | Range | CodeableConcept to support endpoint analysis plans. Later FHIR-42885 removed only the conditional core element in favor of an EBM extension, and FHIR-43328 simplified recursive modelCharacteristic structure; neither reversed FHIR-41379's value[x] decision. FHIR-39632 and commit caa1fb75adbcca96f92873c7d958e31f547124bb moved Evidence terminology definitions out of base FHIR to THO, and the current THO Statistic Model CodeSystem contains the relevant Paule-Mandel/tau and related model codes.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Removing Range and CodeableConcept from the current Evidence.statistic.modelCharacteristic.value[x] would incorrectly reverse the later Applied R6 FHIR-41379 decision. Adding or editing Statistic datatype source is also out of scope because that datatype is no longer in the current build.

Recommendation:
Keep this audit commit as-is. The current core source is correct after considering the R5 application plus later R6 Evidence decisions; any future desire to narrow Evidence.statistic.modelCharacteristic.value[x] again should be raised as a new CDS tracker that explicitly supersedes FHIR-41379.
