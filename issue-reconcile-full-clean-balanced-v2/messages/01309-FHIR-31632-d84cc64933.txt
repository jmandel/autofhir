FHIR-31632: Restore medication category examples to core

Issue request:
FHIR-31632 was an Applied/Persuasive Pharmacy change request, raised for R4 and applied for R6, asking to update the specification to bring example medication value set/code system bindings back into FHIR Core from terminology.hl7.org. The related artifacts covered the Medication, MedicationAdministration, MedicationDispense, MedicationKnowledge, MedicationRequest/MedicationPrescription, and MedicationStatement family.

Initial application:
Pharmacy approved FHIR-31632 and companion FHIR-31633 on 2021-04-05. The current source application appears in the later R6 Pharmacy terminology work: PR HL7/fhir#3896 (commits 4a73291f0c and c23f0477b6) created the in-core MedicationRequest category CodeSystem/ValueSet and changed MedicationRequest and MedicationStatement category bindings, while PR HL7/fhir#3911 (commit 2571d5b4b2, merged as a90a43e3f4) explicitly said it applied FHIR-31632 and FHIR-50142 while completing FHIR-51726. That history left three built examples still using obsolete terminology.hl7.org medication category systems and left an unbound MedicationStatement category ValueSet source that still composed from a terminology.hl7.org system.

Additional context:
MedicationRequest and MedicationStatement are active resources in source/fhir.ini, and their authoritative StructureDefinition bindings now point to http://hl7.org/fhir/ValueSet/medicationrequest-category with the ValueSet including http://hl7.org/fhir/CodeSystem/medicationrequest-category. FHIR-32825 is a later Published same-family decision that eliminated separate MedicationStatement category vocabulary by sharing the MedicationRequest category ValueSet. FHIR-53306, the 2025 PR-review Zulip discussion, and Pharmacy 2025-11-03 minutes record a possible future move/consolidation in THO, but FHIR-53306 is only Triaged and the later FHIR-55335/FHIR-55337 THO-candidate issues are unresolved, so they do not supersede the applied FHIR-core state for this reconciliation.

AutoFHIR reconciliation:
This commit changes the built MedicationRequest examples medicationrequest0301 and medicationrequest0333 and the built MedicationStatement example medicationstatementexample1 so their category codings use http://hl7.org/fhir/CodeSystem/medicationrequest-category, matching the current core CodeSystem/ValueSet and the active bindings. It also removes the obsolete unbound source/medicationstatement/valueset-medication-statement-category.xml file because current MedicationStatement.category deliberately uses the shared MedicationRequest category ValueSet and no separate MedicationStatement category CodeSystem remains. Generated-looking SVG diagram links, historical release files, OID registry remnants, and future-THO ballot notes were left untouched.

Recommendation:
Keep this source fix as the FHIR-31632 reconciliation. If Pharmacy and Terminology later finalize moving/consolidating these category codes in THO, handle that under FHIR-53306/FHIR-55335/FHIR-55337 or a successor final tracker; do not leave current built examples pointing at obsolete/nonexistent terminology.hl7.org systems in the meantime.
