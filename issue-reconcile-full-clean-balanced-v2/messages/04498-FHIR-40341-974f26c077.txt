FHIR-40341: Complete Group Range search reconciliation

Issue request:
FHIR-40341 was Applied/Persuasive with Modification for R6 by FHIR-I. The issue asked for Group searches to cover characteristic valueQuantity/valueRange and exclude semantics; the final approved resolution narrowed the core source work to search-page Range/quantity behavior, search-type link correction, explicit-range prefix examples, and a canonical-units caveat, while the applied source also added Group quantity/exclude search parameters.

Initial application:
Source commit 56d9a2058dcb78d38d8d3e29b28ab83f2f6bb4ba, "FHIR-40341 Allow Group to be searched by characteristic valueQuantity and valueRange, and by exclude", was already on the combined branch and added Group quantity/exclude search parameters plus some search-page text, but it did not carry an Issue-Reconcile-Key trailer. Current source showed the application was incomplete: the type-mapping table still omitted Range from the quantity row and its left-column search-type links still pointed to datatype anchors. The adjacent Group search-parameter source also still had two directly coupled defects: an invalid characteristic-reference component expression and a Group-quantity canonical URL that duplicated Group-value.

Additional context:
FHIR-I minutes for 2025-04-14 record the formal motion for FHIR-40341, including adding Range as an allowed quantity search-type target, correcting type-mapping links, adding decimal explicit-range examples, and noting canonical-unit limitations. Earlier and later Zulip discussion shows the Group.characteristic.valueRange use case and the related FHIR-41688 path for more detailed composite Range support; FHIR-41688 is already represented separately on the combined branch and should remain a related, not duplicate, decision here. The edited Group bundle is part of the active Group resource source, and source/search.html is the current search-page source for the build.

AutoFHIR reconciliation:
Updated source/search.html so the Search Types and FHIR Types table links the search-type names to the search sections and lists Range as a FHIR type usable with quantity search. Corrected the explicit Range decimal example from an upper bound of 2.50000000000000000000 to 2.30000000000000000000. Updated source/group/bundle-Group-search-params.xml so Group-characteristic-reference has a valid FHIRPath component expression and Group-quantity has its own canonical URL.

Recommendation:
Keep this commit as-is. It completes the missing current-build source changes for FHIR-40341 without duplicating the already landed generic FHIR-41688 reconciliation. Future requests for additional resource-specific Range composites or exclude-in-composite behavior should be handled under separate Jira issues with explicit work-group approval.
