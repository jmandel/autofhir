FHIR-3846: Audit existing Encounter location status

Issue request:
FHIR-3846 was Published with resolution Persuasive with Modification for the PA work group. It reported that Encounter supported multiple locations but had no way to indicate each location's status, especially for planned locations or reserved locations while a patient is temporarily away. The recorded resolution says that the encounter location status field was added.

Initial application:
No git commit explicitly mentioning FHIR-3846 was found on the current history, but commit 1b5840ba7773850b22a1699919f9ec5704866e76 on 2014-12-07 added Encounter.location.status and the initial EncounterLocationStatus codes to the historical Encounter spreadsheet/status-code sources. Later source reshaping, including commit 33b409a4b6d544598262f2f074ebb4b6dc466157, carried the element into the current StructureDefinition source.

Additional context:
The Encounter resource is active in source/fhir.ini, so source/encounter feeds the current build. FHIR-8120 later refined the same Encounter.location.status code set from planned/present/reserved to planned/active/reserved/completed, and commit bf320e3425c2ad24825390bfd7c87d565b89b39b applied that follow-up. FHIR-12321 later handled stray carriage-return formatting in the encounter-location-status definitions and is already represented on the combined branch. Searches of Zulip and Confluence found no FHIR-3846-specific discussion or later work-group decision reversing the field.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/encounter/structuredefinition-Encounter.xml defines Encounter.location.status as 0..1 code with a required binding to http://hl7.org/fhir/ValueSet/encounter-location-status, and source/encounter/codesystem-encounter-location-status.xml contains planned, active, reserved, and completed definitions. That satisfies the seed request after the later FHIR-8120 refinement.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-3846 unless PA chooses to introduce a new, separate notion such as temporary versus long-term Encounter locations.
