FHIR-14705: Audit CodeSystem supplement wording

Issue request:
FHIR-14705 was a Published/Persuasive with Modification STU3 vocab issue asking to fix the CodeSystem.supplements definition and comment: use reference-style wording instead of "Defines", use singular "supplement", and correct "too" to "to". The Jira resolution says the language was fixed in the CodeSystem.supplements Definition and Comments.

Initial application:
The issue was applied before publication in git-svn commit 080e47c1a0 (svn r13341), a Rob Hausam CodeSystem documentation batch explicitly listing GF#14705. That commit changed the then-authoritative CodeSystem spreadsheet definition from "Defines the code system that this code system supplement is adding designations and properties too" to "References the code system that this code system supplement is adding designations and properties to" and changed the comment to singular "a code system supplement" language.

Additional context:
The current build uses CodeSystem as an active resource in source/fhir.ini, and the present authoritative StructureDefinition source has the refactored CodeSystem.supplements wording: "The canonical URL of the code system that this code system supplement is adding designations and properties to" plus the singular supplement comment. Later source refactors and canonical/metadata updates changed file shape and blame, but not the issue's intended meaning. Jira search found other CodeSystem supplement issues, but they concern distinct supplement behavior or guidance and do not require changing this wording. Zulip and Confluence searches found no FHIR-14705-specific conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already removes the old "Defines" wording, uses singular supplement language in the comment, and fixes "too" to "to". The only matching non-authoritative diagram title also says "References ... to", so there is no remaining current-build correction for FHIR-14705.

Recommendation:
Keep this empty audit commit as-is. No follow-up is needed for FHIR-14705 unless a future work group decision reopens broader CodeSystem supplement guidance, which should be handled under that later issue rather than this wording cleanup.
