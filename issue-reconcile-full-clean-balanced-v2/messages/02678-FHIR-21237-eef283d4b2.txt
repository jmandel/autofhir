FHIR-21237: Audit MedicationRequest category short

Issue request:
FHIR-21237 was Published/Persuasive for R5 by Pharmacy. It asked to clarify the MedicationRequest.category short by replacing the R4 wording "Type of medication usage" with "Classification of medication request" so the element would not be limited to medication use and could also classify the medication request itself.

Initial application:
The Jira records a 2019-06-18 committed-and-merged implementation at b60fb4b7d3fe218dfc65fc253645e4c6c79d4708. The underlying source commit 634360b51d40494b5427df25cc2ecce831d928e4 changed source/medicationrequest/medicationrequest-spreadsheet.xml from "Type of medication usage" to "Grouping or category of medication request" and updated the definition to describe grouping or category of a medication request.

Additional context:
The current build uses source/medicationrequest/structuredefinition-MedicationRequest.xml for the active MedicationRequest resource listed in source/fhir.ini. The current short is "Grouping or category of medication request" and the definition/comment explicitly allow arbitrary categorization of the request, including administration setting, other request types, and legal category. The older "Type of medication usage" wording remains only in checked-in historical release files for STU3/R4/R4B, not in the active current resource source. Focused Jira, Zulip, and Confluence searches found no later conflicting decision for this short.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active source no longer has the limiting R4 short and already conveys the request-classification meaning approved by FHIR-21237, with later wording that is at least as broad as the requested "Classification of medication request" phrase.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed in the current FHIR source for FHIR-21237; changing the current short to the exact 2019 requested phrase would be unnecessary churn and would narrow the already-correct "grouping or category" wording.
