FHIR-9239: Audit datatype value set migration

Issue request:
FHIR-9239 was a Published/Persuasive MnM DSTU2 change request asking that the Timing Abbreviation and Identifier Type value-set codes be migrated out of FHIR-owned code systems. The recorded resolution was to request/use the corresponding v3 and v2 code systems, and the comments narrowed the remaining action to removing FHIR-specific Identifier.type codes once the v2 table 0203 codes were available.

Initial application:
The timing side appears to have been applied before the explicitly tagged identifier commit: git commit dbd836d2e3ef43f83a940d8ea0b101bc4bf3b8cb, "fix Timing value set post harmonization," moved the Timing abbreviation rows such as QD, QOD, Q4H, and Q6H from inline/internal identifiers to the v3 GTSAbbreviation system. Commit d1f387ce5e71114e7369ac9dd345022ded36edd0 later updated v2/v3 terminology URLs to the terminology.hl7.org CodeSystem form. Commit 935f74cd0eea1f34d310215a5d78ce192122e241, "GF#9239: Change Identifier.type codes to use v2 codes now that they are defined," removed the FHIR-specific identifier-type include and added the requested v2 table 0203 codes to the existing v2 include.

Additional context:
source/fhir.ini actively lists Identifier and Timing in the [types] section, so the checked source files are in current build scope. Current source/terminologies/valueset-identifier-type.xml includes only http://terminology.hl7.org/CodeSystem/v2-0203 for the Identifier Type value set. Current source/datatypes/timing.xml binds Timing.code to TimingAbbreviation and has the timing-abbreviation worksheet rows using http://terminology.hl7.org/CodeSystem/v3-GTSAbbreviation for the historical abbreviations. The remaining C/Continuous timing abbreviation is a later Published issue, FHIR-20609, and FHIR-20609 is already represented on the combined branch; FHIR-13520 similarly added later timing abbreviations and is already represented. Zulip discussion in #terminology > Table 0203 confirms the v2 table 0203 code availability question that delayed the identifier migration, and no Confluence reference or conflicting later decision was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped source already reflects the FHIR-9239 migration: Identifier Type uses v2-0203, Timing Abbreviation uses v3 GTSAbbreviation for the seed-era abbreviations, and no active FHIR-owned identifier-type or timing-abbreviation code system source remains to correct for this issue.

Keep this no-change audit commit. No core FHIR source follow-up is needed for FHIR-9239; future work on the later Timing C code or generated Timing Abbreviation CodeSystem should remain attached to its own issue family, not to this DSTU2 migration audit.
