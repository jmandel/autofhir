FHIR-8496: Audit Observation bodySite usage note

Issue request:
FHIR-8496 is a Published/Persuasive OO change request for DSTU1 asking Observation.bodySite usage notes to say that in many systems body site information may be better represented as a related Observation instead of inline.

Initial application:
The request was applied in git commit 348686f20075ff53db8f62afc2a7a25ce7b99e57, whose message explicitly includes [#8496] and whose patch changed Observation.bodySite comments in the then-authoritative observation spreadsheet to add the related-observation/inline-component guidance.

Additional context:
Observation is an active current-build resource in source/fhir.ini. The source was later refactored from the observation spreadsheet into source/observation/structuredefinition-Observation.xml, Observation.bodyStructure was added as a replacement, and FHIR-53203 later deprecated Observation.bodySite. Those later source changes preserved the same related-observation guidance on the deprecated bodySite element and copied it to the replacement bodyStructure element. FHIR-11293 reused the same bodySite comment as background but only requested a parallel specimen note, and a 2017 Zulip thread quoted the bodySite guidance without identifying a need to remove it.

AutoFHIR reconciliation:
This audit commit makes no source change because the active Observation StructureDefinition already contains the requested note on Observation.bodySite and carries equivalent guidance on Observation.bodyStructure for current implementers.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-8496 unless a future applied issue reopens the broader bodySite/bodyStructure modeling guidance.
