Issue request:
FHIR-7957 was Published/Persuasive with Modification for the DSTU1 search page. It asked to avoid the old symbolic date comparison prefixes and the final resolution was to use two-character operator combinations, with eq assumed when no operator is present.

Initial application:
The Jira records application as svn revision 5816. No current Git commit message on this checkout directly mentions FHIR-7957, but the current search source and later refactors preserve the two-letter prefix-code approach rather than the old >, >=, <=, and < wording.
