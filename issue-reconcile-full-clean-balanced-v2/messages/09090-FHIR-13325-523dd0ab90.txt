FHIR-13325: Audit V3 terminology OID rendering

Issue request:
FHIR-13325 was a Published/Persuasive STU3 correction asking the FHIR-core terminology systems page V3 tab to render complete V3 code-system OIDs. The reported example was ActCode, which should show 2.16.840.1.113883.5.4 rather than the truncated .1.113883.5.4.

Initial application:
The issue was applied in svn revision 12612, represented in git by 278f5d78391ee233bee1d8d50b2a9305e3244def, which removed the publisher-side substring operation that stripped leading characters from V3 OID values when rendering the V3 code-system index. No current source file still contains the reported truncated ActCode OID.

Additional context:
The current source/terminologies-systems.html page is active in publish.ini, but the V3 and V2 tabs that used the affected generated index were removed from core by 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 as part of moving UTG/THO terminology content out of the core build. The current page directs readers first to published THO and the THO CI build for code systems not listed in core. THO's current v3-ActCode CodeSystem carries the complete identifier urn:oid:2.16.840.1.113883.5.4.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original rendering bug was fixed historically, the affected V3 registry table is no longer built from FHIR-core source, and the current authoritative THO artifact has the complete ActCode OID.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed unless a future THO review finds a current terminology.hl7.org OID error, which would belong in the THO/UTG source rather than this core page.
