FHIR-6818 was a Published/Persuasive DSTU1 Patient Care technical correction for Questionnaire. It reported duplicated questionnaire-instruction, questionnaire-security, questionnaire-help, questionnaire-tooltip, and questionnaire-trailing extension paths under Questionnaire.group and was auto-approved.

Initial application:
The Jira comments say the path had been entered incorrectly and cite SVN #5956. Git history contains the migrated commit 26892bfc929619da970a52ee4ab6cb7d9c0a8380, "Corrected path for extensions {#6818}", which changed guides/sdc/questionnaire-sdc-profile-spreadsheet.xml so the question-level copies of those extensions used Questionnaire.group.question.extension instead of duplicating Questionnaire.group.extension.

Additional context:
That old SDC spreadsheet is no longer present in the current checkout, and source/fhir.ini lists the current Questionnaire resource from source/questionnaire. The current Questionnaire structure uses Questionnaire.item rather than the old DSTU1 Questionnaire.group / Questionnaire.group.question split. Current active source contains no definitions for questionnaire-help, questionnaire-tooltip, or the duplicated old extension rows; the remaining old questionnaire-instruction, questionnaire-security, and questionnaire-trailing references are in the R2-to-R3 conversion stylesheet, with release2 history artifacts preserving old release content. FHIR-8391 confirms the questionnaire-instruction extension existed at the time but was a separate no-change request for a new attribute.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The recorded application fixed the historical SDC mapping path, and the current build-scope Questionnaire source no longer contains the duplicate extension definitions or obsolete paths that FHIR-6818 targeted.

Recommendation:
Keep this no-change audit commit as-is. No core source follow-up is needed unless a future task explicitly reconciles retained historical release artifacts rather than the current build.
