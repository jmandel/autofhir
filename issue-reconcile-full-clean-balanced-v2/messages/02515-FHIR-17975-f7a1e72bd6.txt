FHIR-17975: Audit EOB precedence description

Issue request:
FHIR-17975 was Published/Persuasive with Modification for STU3 by the Financial Management work group. It asked for ExplanationOfBenefit long-description changes, specifically changing .precedence to describe the position of the adjudication instance relative to others, with primary/secondary ordering represented by an ordinal value.

Initial application:
The issue was applied before this reconciliation by commit 89bb47c31d84 ("GF#15786,GF#17772,GF#17971,GF#17972,GF#17973,GF#17974,GF#17975,GF#17976,GF#17983"). That commit updated the active EOB spreadsheet source so ExplanationOfBenefit.precedence had the long definition "This indicates the relative order of a series of EOBs related to different coverages for the same suite of services" and requirements text for coordinating multiple EOBs. Later source refactoring carried that wording into the current StructureDefinition XML.

Additional context:
ExplanationOfBenefit is an active resource in source/fhir.ini, and the current source/explanationofbenefit/structuredefinition-ExplanationOfBenefit.xml still defines ExplanationOfBenefit.precedence as a positiveInt with short text "Precedence (primary, secondary, etc.)" and the applied long definition. The exact Jira description phrase is not present, but the current wording preserves the intended ordering semantics and is more specific to EOBs over different coverages for the same services. Targeted Zulip and Confluence searches found no conflicting later community decision.

AutoFHIR reconciliation:
Made no source change. The current active source already contains the substantive long-description improvement from FHIR-17975, and rewriting it to the Jira description's older phrasing would not change implementer understanding.

Recommendation:
Keep this no-change audit commit. Future work should only revisit the wording if Financial Management wants a new clarification beyond the already-applied EOB precedence description.
