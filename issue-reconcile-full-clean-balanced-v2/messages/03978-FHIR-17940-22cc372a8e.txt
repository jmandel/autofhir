FHIR-17940: Audit GTIN terminology registry move

Issue request:
FHIR-17940 was a Published/Persuasive Vocabulary change request from STU3 asking to add GTIN to terminologies-systems.html, based on Zulip discussion and the GS1 GTIN URL https://www.gs1.org/gtin. The Jira resolution approved the change as pre-applied.

Initial application:
The issue was applied by bc2fbf0da2bedef715d54d01c4bdf33e613bac59, which added a GTIN row to source/terminologies-systems.html with https://www.gs1.org/gtin, OID 1.3.160, and a note that GTINs may be used in Coding and Identifier. That row reflected the earlier FHIR-13499 decision to use the GS1 URL for GTIN.

Additional context:
The current terminologies-systems.html page is in the active build via source/hierarchy.xml and publish.ini, but it no longer tries to be the authoritative registry for external terminology identifiers. Later Published/Persuasive issue FHIR-37853 established HL7 Terminology (THO) as the source of truth for external code and identifier system information and required deleting Defined Externally rows that did not have a Using X with FHIR page; commit 736ccce2005fd2c8c2d20dfe8df948e8c9d586d8 applied that policy and removed the GTIN row. Current source now directs readers to THO for external terminology identifiers, and the current hl7.terminology 7.1.0 package contains NamingSystem/gtin with title GTIN Global Trade Item Number, OID 1.3.160, and preferred URI https://www.gs1.org/gtin.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the GTIN row to core terminologies-systems.html would reverse the later FHIR-37853 source-of-truth policy; the current core page plus THO NamingSystem preserve the implementer-facing GTIN URI information without duplicating external registry content in core.

Recommendation:
Keep this audit commit as-is. Do not re-add GTIN to the core Code Systems page unless Vocabulary/TSMG reopens the THO source-of-truth policy; future GTIN registry corrections should be made in THO/NamingSystem-gtin rather than this core page.
