FHIR-20386: Audit v2 code-system encoding outside core

Issue request:
FHIR-20386 was a Published/Persuasive FHIR-core CodeSystem issue raised against STU3 and applied for R5. It reported apparent bad character conversion in HL7 v2 CodeSystem JSON, including table 0550 codes such as whitespace/garbled External Jugular and KIDN variants, and table 0291 ellipsis-like codes.

Initial application:
No explicit FHIR-20386-tagged source commit was found. Before R5, commit 5c0494a removed the old source/v2 terminology content and v2/v3 importers from the core build as part of moving UTG content out of core. The old v2 source later reappeared under tools/tx/v2, but no active build reference from source/fhir.ini or the current terminology pages was found.

Additional context:
The current core terminology systems page directs missing or external code-system authority to HL7 Terminology (THO), its UTG CI build, and TSMG rather than embedding HL7 v2 CodeSystem content in core. Current THO table 0550 has been fixed through UP-681, while the table 0291 ellipsis question is tracked externally in unresolved UTG proposal UP-403. FHIR-19733 is the closely related FHIR-core report for the table 0550 External Jugular whitespace code.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing tools/tx/v2 would not correct the current FHIR core build, and the authoritative remaining work for v2 CodeSystem source is in the external UTG/THO terminology pipeline.

Recommendation:
Keep this external-repo audit commit for FHIR-20386. Do not patch unused core tooling copies for this issue; any remaining v2 table cleanup should proceed through UTG/THO, especially UP-403 for table 0291 if the ellipsis codes are to change.
