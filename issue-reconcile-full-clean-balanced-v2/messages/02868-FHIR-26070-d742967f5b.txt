Later Appointment-specific corrections updated the element spelling from cancelationReason to cancellationReason and the status code from no-show to noshow, without reintroducing the resource prefix.

PA Confluence minutes record the 2020-04-29 6-0-0 persuasive vote for FHIR-26070, and the later Zulip/Jira trail confirms only the noshow code was subsequently corrected.
