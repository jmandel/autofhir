FHIR-12805: Audit Quantity diagram anchors

Issue request:
FHIR-12805 was a Published/Persuasive FHIR-core DSTU2 change request, auto-approved, reporting that links to Duration, Age, and other Quantity specializations from the generated allTypes diagram were not working because the diagram links used lower-case fragments instead of upper-case type anchors.

Initial application:
Jira records that the issue was auto-approved and that Grahame Grieve commented on 2017-02-27 that it had been fixed. No explicit current git commit message with FHIR-12805 was found, which is consistent with older tracker/SVN-era fixes not always carrying the later Jira key.

Additional context:
FHIR-13241 later raised the same anchor/link family for Quantity variations on datatypes.html and was applied by fixing lower-case Duration links to the canonical upper-case Duration anchor. The current source/fhir.ini actively includes alltypes=datatypes/alltypes.diagram and the Quantity specialization types.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/datatypes/alltypes.diagram and source/datatypes/types.diagram list Age, Distance, Duration, Count, Money, MoneyQuantity, and SimpleQuantity with canonical upper-case type names, and source/datatypes.html exposes matching upper-case anchors for those Quantity specializations and constraints.

Recommendation:
Keep this audit commit as-is. Do not edit checked-in or generated diagram artifacts for this issue; current authoritative diagram source and datatype page anchors already reflect the intended upper-case link targets.
