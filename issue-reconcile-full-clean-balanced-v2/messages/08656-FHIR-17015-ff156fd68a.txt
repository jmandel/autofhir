FHIR-17015: Audit BackboneElement specialization list move

Issue request:
FHIR-17015 was a Published/Persuasive with Modification FHIR-core issue asking why the BackboneElement page listed every BackboneElement specialization in a public table. The approved resolution was to move that list to a JSON file for the few people interested.

Initial application:
The issue appears to have been applied in git-svn commit 80af10ced20a8c7a2ead7470a7d0adc81212d56c, matching the Jira comment for svn revision 13949. That commit removed the Specializations section and <%backboneelementlist%> macro from source/backboneelement.html, changed the publisher helper from an HTML table generator into a backbone-elements.json generator, wrote the JSON file during publication, and added a downloads-page link to the JSON.

Additional context:
Later datatype-page refactors removed the obsolete source/backboneelement.html page and moved BackboneElement into the active Type Framework page. The current build scope still includes BackboneElement as an abstract infrastructure type and maps backboneelement to source/types.html. The current source/types.html BackboneElement section explains the implicit descendant model without a specialization table, and source/downloads.html still points code generators to backbone-elements.json. The current build surface confirms that types.html has no public specialization list and that backbone-elements.json exists. A later already-published FHIR-26878 reconciliation updated BackboneType datatype lists, but that concerns a different current list and does not reopen the FHIR-17015 table-to-JSON decision.

AutoFHIR reconciliation:
No source change was made. The old public BackboneElement specialization table and macro are absent from current source, the active source page keeps only the explanatory BackboneElement text, and the downloadable JSON list remains advertised and present in the current build.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-17015 unless the build tooling stops producing backbone-elements.json or the downloads link becomes stale.
