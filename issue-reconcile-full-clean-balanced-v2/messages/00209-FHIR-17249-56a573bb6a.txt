FHIR-17249: Audit FHIRPath keyword list publication

Issue request:
FHIR-17249 was a Published/Persuasive FHIR-core change request from STU3 asking FHIRPath to publish a quick-reference list of language keywords because the keywords were only visible through the grammar. Jira records the resolution as "Already applied."

Initial application:
No FHIR-core commit mentioning FHIR-17249 was found. The application appears to have been in the FHIRPath publication itself: the FHIRPath 2018May source and the current published FHIRPath specification both include a Lexical Elements / Keywords section listing the language keywords.

Additional context:
Current FHIR core no longer owns the full FHIRPath language definition. source/fhirpath.html is an active core page that links readers to the standalone FHIRPath release 2 specification, and later FHIR-core work such as FHIR-53208 deliberately removed duplicated language content from core when it belonged in the FHIRPath specification. Zulip discussion from the day the issue was raised confirms the original concern was the absence/visibility of a keyword list, and later reserved-word discussion confirms the FHIRPath keyword section became the normative reference.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding a keyword list to the FHIR core FHIRPath page would duplicate the authoritative FHIRPath specification and risk drift; the current core page correctly delegates to the external FHIRPath spec, where the requested list is already published.

Recommendation:
Keep this audit commit as-is. No FHIR-core source change is needed unless the standalone FHIRPath specification stops publishing its keyword list or the core page stops linking to the authoritative FHIRPath specification.
