FHIR-39148: Audit Encounter admission definition

Issue request:
FHIR-39148 was a Published R5 PA change request resolved Persuasive with Modification. It asked whether Encounter.admission should be split because the renamed admission backbone still contains discharge information. The approved resolution clarified that Encounter.admission represents details relevant from admittance through discharge, not only the intake event.

Initial application:
The issue appears to have been applied by git commit 9075007296, which changed source/encounter/structuredefinition-Encounter.xml so Encounter.admission.definition matches the approved clarification. The current source still contains that definition.

Additional context:

Bounded Jira searches for Encounter.admission and the exact approved phrase found no later final core decision that reverses this clarification. PA minutes from 2022-11-09 reference FHIR-39148, and corrected Zulip key search found no directly relevant discussion.

AutoFHIR reconciliation:
No source change was made. Recommendation:
Keep this audit commit as-is. No follow-up core source work is needed for FHIR-39148 unless PA later decides to rename or restructure the admission backbone more broadly.
