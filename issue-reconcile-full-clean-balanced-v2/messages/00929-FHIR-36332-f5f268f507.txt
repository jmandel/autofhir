FHIR-36332: Audit Citation relatesTo move out of core

Issue request:
FHIR-36332 was a Published/Persuasive R5 CDS change request to convert Citation.citedArtifact.relatesTo from the RelatedArtifact datatype to an inline BackboneElement that reproduced the usable RelatedArtifact structure without RelatedArtifact's FHIR-resource restrictions, bind Citation.citedArtifact.relatesTo.type to a RelatedArtifactTypeExpanded value set, and add the reprint/reprint-of relationship codes.

Initial application:
The request was applied for R5. Commit 85447dc81219e2260d6dc9076f55b2f86ccf94bd changed source/citation/structuredefinition-Citation.xml so Citation.citedArtifact.relatesTo was modeled with child elements and type binding metadata for RelatedArtifactTypeExpanded, and added the expanded terminology. Commit c306590de4d7deb3747fadab95e2b19b4d9c4636 then addressed Bryn Rhodes' Jira comment by composing the expanded value set from the base related-artifact-type system plus a separate expanded code system containing only reprint and reprint-of.

Additional context:
FHIR-36039 is the supporting RelatedArtifact decision that created the FHIR-resource restrictions that Citation needed to avoid. The current core build no longer owns an active Citation resource: source/fhir.ini has no active Citation resource entry and leaves the related-artifact-type-expanded value set commented out, while current clinical reasoning text links Citation to the Evidence Based Medicine on FHIR IG and says the Citation Resource was moved there. Commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/citation and related active build entries from core after R5.

AutoFHIR reconciliation:
No source files were changed. The historical R5 core application matches the Jira request, and the current core checkout no longer has the authoritative Citation definition or active expanded value set to edit. Treating this as external to the current core build avoids resurrecting retired source or changing stale commented entries.

Recommendation:
Keep this audit commit as-is for FHIR core. If FHIR-36332 needs to be revalidated for the current Citation artifact, do that in the Evidence Based Medicine on FHIR IG source that now owns Citation rather than in this core checkout.
