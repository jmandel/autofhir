FHIR-28295: Refer LOINC license notice to THO

Issue request:
FHIR-28295 was a Published/Persuasive with Modification Vocabulary WG change request for R5 asking to update the "Using LOINC with FHIR" page by removing the dated text "LOINC is copyright © 1995-2020, Regenstrief Institute, Inc." and replacing it with a reference to terminology.hl7.org for current copyright information.

Initial application:
Rob Hausam pre-applied the issue in git commit 8cd675bf1d, updating both source/loinc.html and source/license.html from older static LOINC copyright text to a 1995-2020 statement. Jessica Bota later applied a grouped text update in commit 0bcb947d84 that changed source/loinc.html to refer to terminology.hl7.org, but source/license.html was not updated and retained the exact dated 1995-2020 statement.

Additional context:
FHIR-35933 later removed the local "Using LOINC with FHIR" page from FHIR core and moved the authoritative external-code-system usage guidance to HL7 Terminology (THO); this is already audited on the combined branch. The current source/terminologies-systems.html points LOINC users to THO, while source/license.html remains an active build-scoped core page through publish.ini, source/hierarchy.xml, documentation.html, and the shared footer. The unversioned THO CodeSystem-v3-loinc page named in the original Jira resolution is no longer a live current URL, while the current THO LOINC NamingSystem page exposes current LOINC copyright/license text.

AutoFHIR reconciliation:
This commit updates only the build-scoped core license page. It removes the stale 1995-2020 LOINC copyright/license sentence and replaces it with a pointer to the HL7 Terminology LOINC NamingSystem for current copyright and license information, preserving the basic LOINC content notice and trademark statement. No removed local LOINC usage page was restored or edited.

Recommendation:
Keep this source fix. Future detailed LOINC usage-page content belongs in THO/UTG, but the FHIR-core license page should not continue to publish a dated LOINC copyright statement after FHIR-28295 and the FHIR-35933 migration.
