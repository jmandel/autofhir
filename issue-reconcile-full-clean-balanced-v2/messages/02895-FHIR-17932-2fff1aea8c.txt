FHIR-17932: Audit ClaimResponse short descriptions

Issue request:
FHIR-17932 was a Published/Persuasive with Modification FM change request for ClaimResponse short descriptions. The request asked to replace the ClaimResponse.insurer short text "Target" with insurer/adjudication wording and to replace "point" wording in ClaimResponse.addItem.unitPrice, ClaimResponse.addItem.detail.unitPrice, and ClaimResponse.addItem.detail.subDetail.unitPrice with unit-oriented wording from the descriptions.

Initial application:
The issue was applied in the 2018 FM batch commit afb5ec66f68641293bb7950b6e0eeb118fa1444a, whose subject explicitly lists "17932: ClaimResponse short descriptions". That commit replaced the older ClaimResponse.insurer wording with "Party responsible for reimbursement" plus an authorization/adjudication/reimbursement definition, and replaced the affected unitPrice shorts with "Fee, charge or cost per item" plus requirements saying the amount is for a single unit.

Additional context:
ClaimResponse is an active current-build resource in source/fhir.ini. The old spreadsheet source was later imported into the current StructureDefinition source by the 2021 new-build-core rework, and the current source retains the 2018 application semantics. Published R4 and R5 surfaces match the current source for the checked elements. Target/point wording is not present in the current authoritative ClaimResponse source. No relevant Zulip or Confluence evidence was found that conflicts with the Jira, source, and git-history conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build already removes the misleading target/point short descriptions and conveys the approved adjudicating insurer and single-unit price semantics through the current short, definition, and requirements text. Replacing the later approved/refactored wording with the Jira's abbreviated request text would not improve current conformance meaning.

Recommendation:
Keep this audit commit as-is. Revisit only if FM raises a new issue saying the current "Party responsible for reimbursement" or "Fee, charge or cost per item" wording is now semantically wrong, rather than merely different from the 2018 request wording.
