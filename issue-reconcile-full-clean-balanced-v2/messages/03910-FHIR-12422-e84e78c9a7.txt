Issue request:
FHIR-12422 is a Published/Persuasive Financial Management change request raised against DSTU2 asking to add procedureLinkId to Claim.item and ExplanationOfBenefit.item.

Initial application:
The available git history does not show a commit that explicitly names FHIR-12422, but the old financial-resource spreadsheet sources already received the requested Claim.item.procedureLinkId and ExplanationOfBenefit.item.procedureLinkId rows in commit 37303c8e87f0. Later R3-to-R4 mapping commits recorded the current-name transition from Claim.item.procedureLinkId to Claim.item.procedureSequence and from ExplanationOfBenefit.item.procedureLinkId to ExplanationOfBenefit.item.procedureSequence.

Additional context:
Claim and ExplanationOfBenefit are active current-build resources in source/fhir.ini. Their authoritative current StructureDefinition sources define Claim.item.procedureSequence and ExplanationOfBenefit.item.procedureSequence as 0..* positiveInt links to applicable procedures, and source/fhir.ini retains explicit cross-version aliases from the old procedureLinkId names. FHIR-37513 later asked to replace Claim-related sequence properties with Element.id and was resolved Not Persuasive, supporting continued use of the sequence pattern rather than removing or renaming these elements.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already preserves the requested semantic link under the R4+ procedureSequence name, and adding procedureLinkId back to the current resources would be an obsolete duplicate rather than a current-spec correction.

Recommendation:
Keep this no-change audit commit. No follow-up source work is recommended for FHIR-12422 unless FM separately decides to change the Claim/EOB sequence-link pattern in a future issue.
