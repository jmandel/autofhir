FHIR-5213: Clarify historical IG ballot status

Issue request:
FHIR-5213 was a Published/Persuasive FHIR-I change request from the January 2015 ballot asking the version 0.4 history entry to clarify the ballot status of the listed implementation guides, because Argonaut was new and DAF had a separate ballot even though the guides were part of the publication.

Initial application:
The issue was initially applied in git commit 84095b0c9051, imported from svn revision 4515, by changing the 0.4 history entry from "New Implementation Guides" to "New Implementation Guides (see discussion of status)" with a link to source/iglist.html.

Additional context:
The linked iglist.html page later carried the relevant status table, including that Argonaut had no balloted content, DAF and SDC had their own ballots, and the US Laboratory guides were part of the FHIR DSTU ballot. In 2016, broken-link cleanup replaced the history entry's iglist link with code-form placeholder text; in 2017, iglist.html was removed. The current source/hierarchy.xml still includes history.html as the built Version History page, so the remaining placeholder in source/history.html no longer satisfied the original clarification.

AutoFHIR reconciliation:
This commit makes the version 0.4 implementation-guide note self-contained by stating that the guides were published with the release while their ballot status varied, and by summarizing the status for the listed guide families. This preserves the historical decision without restoring the retired IG list page.

Recommendation:
Keep this source change. It fixes a lost clarification on a current built history page and does not reopen the broader retired implementation-guide page structure.
