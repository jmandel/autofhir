FHIR-24432: Audit EBM resource revisions

Issue request:
FHIR-24432 was a Published/Persuasive CDS change request for R5. It asked to revise the Clinical Reasoning module for the EBMonFHIR work by removing older draft evidence resources, updating Evidence and EvidenceVariable, adding Statistic and OrderedDistribution data types, and modifying the Clinical Reasoning module pages. The final resolution approved Evidence, EvidenceVariable, Statistic, and OrderedDistribution as draft for inclusion; a Jira comment also noted the missing link to the overall evidence pages.

The issue was applied in the 2019 GF#24432 source history, especially commit 3aa4e3d51c31eb45bc1745ae751bf15165c6fd01 and merge c3c0a7e48a11671e57393418e2ea01d61eed7f7c for PR #692. No later current-build source location was found where the seed's original R5 inclusion request remains unapplied.

Additional context:
Later final CDS decisions changed part of the original seed outcome. FHIR-31564 and FHIR-31866 removed OrderedDistribution and Statistic from current FHIR, with implementation in commit 9545244b7167d105bd862aa06a62fea63101dec7. FHIR-29320, FHIR-49687, and FHIR-53004 later revised the same Clinical Reasoning Evidence and Statistics page and are context for the current wording; FHIR-29320 and FHIR-53004 already have reconciliation commits on the combined branch. Current source/fhir.ini keeps Evidence and EvidenceVariable active, records EffectEvidenceSynthesis and RiskEvidenceSynthesis as removed resources, does not list Statistic or OrderedDistribution as current types, and does not actively build ResearchDefinition or ResearchElementDefinition. The remaining old ResearchDefinition/ResearchElementDefinition source directories are not active current-build resources.
