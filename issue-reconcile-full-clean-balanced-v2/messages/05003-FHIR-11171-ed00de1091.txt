FHIR-11171: Audit CarePlan context and period clarification

Issue request:
FHIR-11171 was a Published/Not Persuasive with Modification Patient Care change request against DSTU2 CarePlan.context and CarePlan.duration. The accepted resolution said FHIR-11333 would clarify CarePlan.context as the original creation context and that there was no CarePlan.duration element, so CarePlan.period should clarify longitudinal care plan activities across encounters or episodes.

Initial application:
The context portion was handled by FHIR-11333's historical application in commit f39dde8e171836d3345715f788c746e0a1624492. The period portion appears to have been applied in commit bd9f60dbffee762fd2b3e49ee2e07e232b9685a9, which changed the CarePlan.period comment to mention activities planned within a single encounter/episode or across multiple encounters/episodes, including longitudinal chronic-condition management.

Additional context:
CarePlan is active in source/fhir.ini. Later workflow alignment renamed CarePlan.context to CarePlan.encounter and preserved the creation-context semantics in the current CarePlan.encounter definition and comment. The current CarePlan.period comment still contains the longitudinal-care wording requested by FHIR-11171. No Zulip or Confluence evidence was found that conflicts with the Jira/source history.
