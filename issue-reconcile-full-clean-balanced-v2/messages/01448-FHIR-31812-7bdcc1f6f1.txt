FHIR-31812: Audit Ingredient substance reference targets

Issue request:
FHIR-31812 was a Published/Persuasive BRR change request for R5 asking why the definitional medicinal product ingredient model allowed both SubstanceDefinition and Substance; the final Jira resolution was to drop Substance.

Initial application:
The issue was applied by commit e51759e1f5aa20553bc8b9f3ab3f933f4efe3581, which removed the Substance targetProfile from Ingredient.substance.code and Ingredient.substance.strength.referenceStrength.substance. The current active Ingredient source still has only SubstanceDefinition as the target for both CodeableReference elements.

Additional context:
The current build maps the former MedicinalProductIngredient artifact to the active Ingredient resource and includes Ingredient and SubstanceDefinition in source/fhir.ini. Current SubstanceDefinition and Substance narrative also distinguishes definitional SubstanceDefinition from instance-level Substance. BRR Confluence minutes mention the tracker and documentation request, while precise Zulip search found no issue-specific discussion changing the Jira/source conclusion.

AutoFHIR reconciliation:

Recommendation:
