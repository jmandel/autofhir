FHIR-12796: Audit BodySite W5 reorder

Issue request:
FHIR-12796 was a Published/Persuasive Orders and Observations change request for the DSTU2 BodySite resource. It asked to reorder BodySite elements from patient, identifier, code, qualifier, description, image, active to identifier, active, code, qualifier, description, image, patient based on W5.

Initial application:
The request was pre-applied before final publication. Commit c6a89473d1b27de21e9562196573520bb710a269, dated 2017-02-08 and titled "QA updates reorder - #12796, RIM, W5 Mappings", moved BodySite.identifier and BodySite.active ahead of BodySite.code/qualifier and moved BodySite.patient to the end in source/bodysite/bodysite-spreadsheet.* and updated examples.

Additional context:
Later BodySite was renamed/reworked as BodyStructure by FHIR-13396. The current build scope in source/fhir.ini lists bodystructure=BodyStructure as an active resource, lists BodySite under [removed-resources], and records that BodySite became BodyStructure. There are no tracked current source/bodysite files; current BodyStructure source has evolved beyond the old BodySite element list while retaining identifier and active near the start and patient at the end of the current resource definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing a retired BodySite source would be outside the current build, and forcing the old DSTU2 BodySite order onto the current BodyStructure model would ignore later accepted resource redesign work.

Recommendation:
Keep this audit commit as-is. No current FHIR core source edit is needed for FHIR-12796; future BodyStructure ordering or modeling concerns should be handled through a new BodyStructure-specific tracker rather than by replaying the old BodySite reorder.
