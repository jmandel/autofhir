FHIR-31567: Audit lastSourceSync extension ownership

Issue request:
FHIR-31567 was a Published/Persuasive with Modification FHIR-core change request asking for a new 0..1 dateTime extension named lastSourceSync on Resource.meta/Meta to indicate when propagated data was last accessed from its original source, with a comment limiting relevance to data propagated from another system.

Initial application:
The issue was applied in core by commit 2e023b1de7, which added source/datatypes/meta-extensions-spreadsheet.xml and registered it from source/fhir.ini as meta-extensions. That spreadsheet entry had code lastSourceSync, context Meta, cardinality 0..1, type dateTime, the requested definition, requirements, and comment. Core later retained only the canonical OID registration for http://hl7.org/fhir/StructureDefinition/lastSourceSync.

Additional context:
The current core checkout no longer contains an active lastSourceSync definition; searching current source outside generated/history material finds only source/oids.ini. The FHIR Extension Pack is now the authoritative home for this extension: input/extensions-ig.xml includes input/definitions/*, and input/definitions/datatypes/StructureDefinition-lastSourceSync.xml defines the active extension with URL http://hl7.org/fhir/StructureDefinition/lastSourceSync, context Meta, value dateTime, the same definition/comment, and the OID 2.16.840.1.113883.4.642.5.1570. The continuous build for the Extension Pack publishes the same extension.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Re-adding lastSourceSync to the core meta-extensions spreadsheet would duplicate an extension definition now maintained in the FHIR Extension Pack; the current core source is correct to retain only the OID registry entry.

Recommendation:
Keep this empty external-repo audit commit as-is. Future changes to the lastSourceSync extension definition should be made in HL7/fhir-extensions, not in this FHIR core checkout, unless the build architecture changes to return this extension to core ownership.
