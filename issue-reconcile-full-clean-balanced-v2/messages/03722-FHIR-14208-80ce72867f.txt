FHIR-14208: Audit datatype date/time examples

Issue request:
FHIR-14208 was a Published FHIR-core MnM change request for STU3, resolved Persuasive with Modification, asking for human-friendly syntax/examples for date, dateTime, and timestamp. The accepted resolution was to add usage-note examples for date, dateTime, instant, and time.

Initial application:
The Jira comment says the work was applied in svn revision 12706. Git history shows the explicit implementation as 97b8292e52d8616ee9d0386b5c68b80d7982475a, "#14208 - improve doco on data types", which changed source/datatypes.html on 2017-12-13 and added date/dateTime/instant examples plus a human-readable time format.

Additional context:
source/fhir.ini maps primitive type pages through the datatypes page, so source/datatypes.html is in current build scope for this material. Later datatype wording edits preserved the human-readable date/dateTime/instant examples and the time hh:mm:ss format, while modernizing timezone language to UTC offset wording. Community searches found only bot/generated references for this issue and unrelated numeric hits, with no discovered work-group discussion reversing or narrowing the published Jira decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current combined source already states date as YYYY, YYYY-MM, or YYYY-MM-DD with examples; dateTime as YYYY, YYYY-MM, YYYY-MM-DD, or YYYY-MM-DDThh:mm:ss+zz:zz with examples; instant as YYYY-MM-DDThh:mm:ss.sss+zz:zz with examples; and time as hh:mm:ss. The absence of the literal time example "15:24:00" is not a semantic gap because the format is already explicit and adding that example would be redundant editorial polish.

Keep this audit commit as-is. No follow-up source change is needed for FHIR-14208 unless a future work group wants a broader editorial pass over primitive datatype examples.
