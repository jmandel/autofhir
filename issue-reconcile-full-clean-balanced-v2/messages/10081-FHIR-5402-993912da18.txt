FHIR-5402: Audit Claim resource collapse

Issue request:
FHIR-5402 is a Published/Persuasive DSTU1 ballot issue asking why the specification had separate InstitutionalClaim, OralHealthClaim, PharmacyClaim, ProfessionalClaim, and VisionClaim resources, proposing a single healthcare claim resource with profiles or specializations for discipline-specific claim types. The Jira comments record that FM had independently voted on March 13, 2015 to collapse the individual Claim resources into a single resource.

Initial application:
The current git history shows the collapse was applied in the 2015 source work: commit ad79f6119f added the unified Claim resource, and commit 80474beb51 completed the switch from separate claim resources to Claim across financial/source metadata. Later source metadata commit 94445ca431 preserved the fact that Claim was collapsed from ProfessionalClaim, PharmacyClaim, and similar resources while marking the old specialized claim resources as dropped.

Additional context:
Current build configuration has active resource entries for claim=Claim, claimresponse=ClaimResponse, and explanationofbenefit=ExplanationOfBenefit, while InstitutionalClaim, OralHealthClaim, PharmacyClaim, ProfessionalClaim, and VisionClaim appear only in removed-resource/history contexts. The current Claim introduction describes one Claim resource and claim types/codes for oral, pharmacy, vision, professional, and institutional use rather than separate resources. Related issue FHIR-7861 later requested cleanup of old claim-resource references and is already represented on the combined branch by its own audit commit, so this reconciliation does not decide it again.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. The current build already implements the FHIR-5402 disposition: there is a single active Claim resource, the old separate claim resources are not active build resources, and the remaining historical references document the collapse rather than creating current conformance expectations.

Recommendation:
Keep this no-change audit commit as-is. No current core source correction is needed for FHIR-5402; any future work should be limited to separate editorial cleanup if the Financial Management work group wants to revise historical notes or terminology, not to reintroduce or further collapse current resources.
