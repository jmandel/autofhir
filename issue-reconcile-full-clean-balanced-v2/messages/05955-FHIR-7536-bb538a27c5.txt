FHIR-7536: Audit BCP47 language system documentation

Issue request:
FHIR-7536 was a Published/Persuasive vocab issue from the DSTU1 cycle requesting that the terminology systems page document `urn:ietf:bcp:47` as the system URI for language.

Initial application:
The issue was initially applied in svn revision 5681, represented in git by 4e71ae0b99, which added an external code system row for `urn:ietf:bcp:47` to `source/terminologies-systems.html`.

Additional context:
FHIR-37853 was a later Published/Persuasive vocab decision for R5 that made HL7 Terminology the source of truth for external code and identifier system information and required unqualified external rows on the Terminologies - Code Systems page to be removed. Its application in 736ccce200 removed the old BCP47 row along with other external systems. The current core source still exposes the language system through the language binding and value set sources, and THO now carries the BCP47 NamingSystem with `urn:ietf:bcp:47` as the preferred URI.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the old row to `source/terminologies-systems.html` would conflict with the later THO source-of-truth decision, while the current language value set and binding sources already preserve the implementer-facing system URI.

Recommendation:
Keep this audit commit as-is. Future changes to external BCP47 identifiers or OIDs should be handled through THO/UTG, not by restoring the removed core terminology-systems row.
