FHIR-5521: Audit MedicationAdministration scope wording

Issue request:
FHIR-5521 was a Published/Persuasive Pharmacy change request for FHIR-core MedicationAdministration raised in DSTU1. It asked to clarify the resource scope by changing the description to "Describes the event of a patient consuming or otherwise being administered a medication."

Initial application:
No commit explicitly tagged FHIR-5521 was found in the repository history. The historical source evidence shows the change was nevertheless applied immediately after the Jira was created: git-svn mirror commit abce09d8c1 changed the old MedicationAdministration spreadsheet definition from "a patient being given a dose of a medication" to the requested "a patient consuming or otherwise being administered a medication" wording. Later source refactors carried that wording into the current StructureDefinition XML.

Additional context:
MedicationAdministration is active in the current build through source/fhir.ini. The current StructureDefinition description and root element definition both retain the requested scope sentence, and the Scope and Usage / Boundaries narrative continues to explain medication administration, self-administration, device administration, outpatient use, and the Immunization boundary. A later Published Pharmacy issue, FHIR-37337, intentionally added waste-recording guidance to MedicationAdministration; that additional sentence is compatible with, not a reversal of, FHIR-5521. Jira, Zulip, and Confluence searches found no contrary core decision for FHIR-5521.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already conveys the requested scope clarification, and removing later compatible scope detail would undo a subsequent published decision rather than improve FHIR-5521 application.

Recommendation:
Keep this no-change audit commit as-is. Future MedicationAdministration scope changes should be handled through a new Pharmacy work-group decision rather than by narrowing the already-applied FHIR-5521 wording.
