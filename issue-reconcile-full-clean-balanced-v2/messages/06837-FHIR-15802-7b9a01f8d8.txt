Issue request:
FHIR-15802 was a Published/Persuasive technical correction for the STU3 FHIR-core Observation vital signs profiles. It reported that the Blood Pressure row used LOINC 85354-9, while the nearby search guidance still said a blood pressure Observation would be returned when searching on 55284-4.

Initial application:
The issue was applied by git commit c3aea2a3e283dd9a40883ec92ab0df20531fa72e, whose subject explicitly references #15802 and changes the vital-signs profile introduction from 55284-4 to 85354-9 in the affected search implementation note.

Additional context:
Observation is an active resource in source/fhir.ini, and the Observation vital-signs implementation guide includes the introduction page and Blood Pressure profile. The current source table, examples, and Blood Pressure profile use 85354-9 for the interoperability-standard Blood Pressure panel code. Later R6 vital-signs work in FHIR-45617 broadened guidance about detailed additional codings but did not restore the old 55284-4 conflict.

Keep this audit commit as-is. No FHIR-core follow-up is needed for FHIR-15802 unless the work group separately revisits the broader vital-signs code policy.
