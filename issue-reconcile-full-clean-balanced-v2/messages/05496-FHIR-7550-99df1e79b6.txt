FHIR-7550: Audit AllergyIntolerance negation guidance

Issue request:
FHIR-7550 was Published with Persuasive with Modification for the Patient Care AllergyIntolerance resource. It requested explicit AllergyIntolerance negation support by expanding the AllergyIntolerance code value set with concepts such as no known allergies/no known food allergies and by adding guidance for negated allergy/intolerance statements, including how refuted negation statements should be handled when a new allergy is discovered.

Initial application:
The request appears to have been applied in the old SVN/Git history rather than in a commit mentioning the Jira key. Commit 0eea1114d50dfb349fa07d20c74b64aba76bb94c explicitly mentions #7055/7550 and added the Negated Allergies and Intolerances usage notes plus the allergy/intolerance substance-code value set changes. Commit aead4b335ae5ba2e58976fab61fa02950003d793 explicitly mentions #7550 and added the refuted-negation note. Later AllergyIntolerance work renamed substance to code and reshaped the source, but the same guidance remains in the current active source.

Additional context:
FHIR-7055 was the paired Published issue asking where List fits for No Known Allergies. FHIR-10358 renamed AllergyIntolerance.substance to AllergyIntolerance.code, added the substanceExposureRisk alternative, and updated the value set/documentation. FHIR-10380 cleaned up the AllergyIntolerance documentation and value set name. FHIR-10442 moved the no-known-allergy hierarchy to active SNOMED CT concept 716186003. FHIR-13087 added NKA/NKDA/No Latex Allergy examples. FHIR-26410 later clarified that the preferred no-known-allergies wording refers to AllergyIntolerance.code and added the inline NKA example. FHIR-35848 later confirmed that AllergyIntolerance.code intentionally supports conditions/statements, including negated statements. Community searches found no direct FHIR-7550 contradiction; the Confluence negation page lists FHIR-7550 in the same AllergyIntolerance negation lineage.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scope AllergyIntolerance resource is active in source/fhir.ini, the current value set title/description and SNOMED CT includes cover negation/exclusion codes including the 716186003 no-known-allergy hierarchy, the Negated Allergies and Intolerances notes explain AllergyIntolerance.code versus List.emptyReason, refuted negation handling, and reconciliation when new allergies are added, and the examples list includes NKA, NKDA, and No Known Latex Allergy instances. Additional source edits would mostly duplicate current guidance and risk drift.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-7550 unless the Patient Care work group later decides to change the broader negation model; such a change would need a new issue because current source reflects the applied FHIR-7550 family and later clarifications.
