FHIR-7321: Audit financial attachment guidance

Issue request:
FHIR-7321 was Published with resolution Persuasive with Modification. It asked for information about attachments sent with a claim and separately from a claim; the accepted resolution was to add Financial module guidance explaining claim attachments, including solicited and unsolicited flows.

Initial application:
No source commit explicitly tagged FHIR-7321 was found. The relevant Financial module attachment section was added by git-svn commit a5160b5bbdc shortly after the recorded 2016-12-02 vote, then later source history refined the prose, changed the embedded-content reference from the old information section to supportingInfo, and added a Claim introduction link to the Financial module attachment guidance.

Additional context:
The current build includes Claim, ClaimResponse, Communication, and CommunicationRequest as active resources. Claim.supportingInfo currently accepts data, documents, images, resources, references, or actual included data, while Communication carries separate payloads and can be associated with other resources. No directly relevant Zulip or Confluence record was found that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current Financial module already has an Attachments - Supporting Information section that explains included, unsolicited, solicited, and task/operation input options, and the Claim page links implementers to that guidance.

Recommendation:
Keep this audit as-is. Further core source changes would duplicate or risk drifting from existing module guidance; any more detailed attachment workflows, such as jurisdiction-specific claims attachment transactions, belong in implementation guides rather than this core reconciliation.
