Initial application:

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding a hard-coded patient-extensions.html link to the current core profile list would reintroduce a stale manual link to an artifact that is no longer a current core build page and would conflict with the generated-list design.

Recommendation:
Keep this audit commit as-is. No current core source edit is needed for FHIR-7560; future work on the patient extension definitions should occur in the Extension Pack if any of those external artifacts need changes.
