FHIR-16423: Audit modifierExtension clarifications

Issue request:
FHIR-16423 was a Published, Not Persuasive with Modification FHIR-I change request raised against STU3 DomainResource. It asked to forbid modifier extensions, but the approved resolution kept modifier extensions and instead required clarifications about Narrative.status = extensions, limits on changing Resource/DomainResource meaning, processing consequences and options, and implementation-guide limits on modifier extensions.

Initial application:
The issue was applied by fe5743607404d3b80d049da7a8fde4dc85be2d5d (svn revision 14333), which added the modifier-extension narrative status rule, the Resource/DomainResource meaning limit, processing options for unrecognized modifier extensions, and implementation-guide limitation language. The later source rework in 33b409a4b6d544598262f2f074ebb4b6dc466157 preserved the DomainResource modifierExtension definition in the current StructureDefinition source.

Additional context:
FHIR-18356 later narrowed the narrative rule so modifier extensions only have to be reflected when they extend elements described by the narrative; that connected issue is reconciled separately in this branch. FHIR-17688 also treated the FHIR-16423 narrative clarification as already partly addressed while resolving a separate narrative conformance-language concern. Community searches found only the tracker and commit bot notifications and no Confluence evidence that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change for FHIR-16423. After the related FHIR-18356 harmonization, the current active source still preserves the FHIR-16423 decision to allow modifier extensions while warning implementers about their downstream processing impact, constraining what they may modify, listing processing responses, and allowing implementation guides to limit their use.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source change is needed for FHIR-16423; future changes to the narrowed narrative-scope rule should be handled under FHIR-18356 or a new work-group decision, not by reopening the original request to forbid modifier extensions.
