FHIR-13941: Audit Timing text guidance

Issue request:
FHIR-13941 was a Published FHIR-core datatypes change request, resolved Not Persuasive with Modification, asking to add Timing.text so systems could exchange complex timing instructions as text alongside encoded timing. The approved resolution was not to add a new Timing element, but to use Timing.code.text and add examples/documentation for that capability.

Initial application:
The Jira comment points to SVN revision 12468, represented in git as 08d6b08d14dacdd6187f73f62986a6d9ec0ac346. That commit added Timing narrative explaining that text timing instructions map to Timing.code.text and included a JSON example; the current Timing spreadsheet also defines Timing.code as CodeableConcept and says it can be "just text in code.text". There was no separate Timing.text element added.

Additional context:
FHIR-5950 had already added Timing.code as a CodeableConcept for text/coded timing representation. Later FHIR-20671 followed the same no-new-element approach and moved the Timing.code.text guidance before the common examples table; that related issue already has a combined-branch audit commit. Later FHIR-53411 removed an inaccurate sentence from the same Timing prose but preserved the Timing.code.text solution. source/fhir.ini lists Timing as an active datatype and routes datatype pages to datatypes.html, so the checked source is in current build scope. Zulip and Confluence searches found only tracker/commit notifications and no conflicting community rationale.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scope source already conveys the approved resolution: free-text timing instructions are represented with Timing.code.text, the narrative shows an inline JSON example, and the authoritative Timing element definition allows text in code.text.

Recommendation:
Keep this no-change audit as-is. Do not add a Timing.text element for FHIR-13941 unless a future work-group decision changes the established Timing.code.text approach.
