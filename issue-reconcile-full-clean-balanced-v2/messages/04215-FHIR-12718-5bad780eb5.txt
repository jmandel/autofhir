FHIR-12718: Audit Goal outcome code rename

Issue request:
FHIR-12718 was a Published/Persuasive Patient Care change request for DSTU2 asking to rename Goal.outcomeCodeableConcept to Goal.outcomeCode.

Initial application:
The request was applied in Jira-tagged commit 4576ba4d2c, which changed the Goal spreadsheet source and the stop-smoking example from Goal.outcomeCodeableConcept to Goal.outcomeCode. A current source grep found no active Goal.outcomeCodeableConcept references; the only current Goal.outcomeCode references are migration/model-info leftovers, not an active Goal element.

Additional context:
FHIR-12661 created the flattened Goal outcome code/reference shape immediately before FHIR-12718, and later Applied issue FHIR-37262 removed Goal.outcome altogether in commit 0d8e3756353. The current active Goal StructureDefinition keeps Goal.outcome commented out, and source/fhir.ini records that Goal.outcomeCode and Goal.outcomeReference have no R4-to-R6 mapping because Goal.outcome was deleted.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or remapping Goal.outcomeCode would conflict with the later applied removal of Goal.outcome, and the obsolete Goal.outcomeCodeableConcept name is absent from current active Goal source.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-12718 unless the Patient Care work group separately revisits the later Goal.outcome removal or its migration guidance.
