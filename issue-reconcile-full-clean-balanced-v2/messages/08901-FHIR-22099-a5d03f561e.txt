FHIR-22099: Audit _since search parameter decision

Issue request:
FHIR-22099 was a Published FHIR-core search change request asking whether _since should be documented as a common search parameter. The final resolution was Not Persuasive with Modification: _since is not a search parameter, remains a specialized history/operation parameter, and Subscription guidance should use _lastUpdated instead.

Initial application:
The issue was explicitly applied by git commit 6123ca87d90300306078f8dd2cd121fb93a4c54e, which replaced the Subscription empty-payload example's _since query parameter with _lastUpdated before R5. No current source commit was needed to add _since to the common search parameter page because the Jira decision rejected that part of the request.

Additional context:
Current source/search.html documents _lastUpdated as the standard search parameter and has no _since entry or SearchParameter definition. Current source/http.html still defines _since only in the history interaction parameter table, which matches the Jira resolution. Current Subscription source is build-scoped through source/fhir.ini and its empty-payload guidance uses _lastUpdated. The only Subscription-folder _since occurrence found is in source/subscription/josh proposal.txt, an unreferenced draft/proposal text file rather than authoritative build content. Zulip discussion confirms the rationale: Subscription uses FHIR search and therefore must use a defined search parameter, while operation-style uses such as Bulk Data/$everything may define their own _since parameter.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current built core source already reflects the published FHIR-22099 decision and editing the stale unreferenced proposal text would not change implementer-facing specification behavior.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed unless a future build-scope review decides to purge obsolete draft/proposal files from resource folders as a separate cleanup.
