FHIR-25396: Audit AdverseEvent category binding

Issue request:
FHIR-25396 was a Published/Persuasive with Modification Patient Care change request for FHIR-core AdverseEvent. It asked to update the binding of AdverseEvent.category to Example and replace the value set with a broader set containing wrong patient, procedure mishap, medication mishap, device, unsafe physical environment, hospital acquired infection, and wrong body site.

Initial application:
The issue was directly applied in commit faf138c4d6, which changed the then-authoritative AdverseEvent spreadsheet from an extensible binding to an example binding, replaced the old product-focused category list with the requested broader examples, added the FHIR-25396 committee note, and updated the AdverseEvent example category to medication-mishap. The current refactored source preserves that application: AdverseEvent.category carries the FHIR-25396 committee note, has strength="example", and binds to http://hl7.org/fhir/ValueSet/adverse-event-category.

Additional context:
AdverseEvent is active in the current build via source/fhir.ini. The current core value set source includes all codes from the external THO CodeSystem http://terminology.hl7.org/CodeSystem/adverse-event-category, whose current artifact contains the FHIR-25396 category codes. A later applied issue, FHIR-38908, and UTG proposal UP-597 added clinical-research to the same external code system; that later core text alignment is already represented on the combined branch by commit ad68f5c5d8 and should not be duplicated here. Confluence has Patient Care minutes for the FHIR-25396 vote, and no directly relevant Zulip conflict was found.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build inputs already satisfy FHIR-25396: the binding strength is example, the binding points to the Adverse Event Category value set, the value set delegates to the THO adverse-event-category code system, and the local AdverseEvent summary/search text includes the seed category examples plus the later clinical-research addition.

Recommendation:
Keep this audit commit as-is. No further FHIR-core source work is needed for FHIR-25396; any future correction to external terminology code spelling or additional category codes should be handled through the terminology/UTG process rather than this core-source reconciliation.
