FHIR-12477: Audit ImagingStudy modality decision

Issue request:
FHIR-12477 was a Published FHIR-core ImagingStudy change request raised in DSTU2. It asked to make ImagingStudy.series.modality optional so ImagingStudy could replace ImagingManifest. The final Not Persuasive with Modification resolution rejected changing series.modality cardinality because the group could not identify a case where series.modality was unavailable while other series-level information was present, but it did approve renaming the top-level modalityList element to modality.

Initial application:
Historical commit 7b2b64512052c9a800a59b0ac3cd2cd013659b1b explicitly included GF#12477 in a bundled ImagingStudy update and changed the ImagingStudy spreadsheet from ImagingStudy.modalityList to ImagingStudy.modality. Current source no longer contains modalityList in the active ImagingStudy resource source, and fhir.ini preserves the old-to-new map ImagingStudy.modalityList=ImagingStudy.modality.

Additional context:
ImagingStudy is an active build resource in source/fhir.ini. The current StructureDefinition has top-level ImagingStudy.modality as 0..* and ImagingStudy.series.modality as 1..1, matching the accepted modification and rejected cardinality request. The ImagingStudy search parameter still targets ImagingStudy.series.modality. Searches of Zulip and Confluence for FHIR-12477/ImagingStudy modality terms found no directly relevant or conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source already retains required series.modality and uses the renamed top-level modality element, so making series.modality optional would contradict the published issue decision.

Recommendation:
Keep this no-change audit commit. Revisit only if a later work-group decision explicitly changes ImagingStudy.series.modality cardinality or supersedes the modality naming decision.
