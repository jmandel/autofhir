FHIR-7836: Audit MedicationStatement RXA-25 removal

Issue request:
FHIR-7836 was a Published/Persuasive Pharmacy change request from the DSTU1 QA cycle asking to blank the HL7 v2 mapping for MedicationStatement.identifier by removing "RXA-25-Administered Barcode Identifier?" because MedicationStatement is not MedicationAdministration and RXA administration fields do not apply to MedicationStatement.

Initial application:
The issue appears to have been applied by commit 5bb461af1063efe577bac2b8b17b6992be7560bf, which explicitly listed tracker item 7836 and removed the RXA-25-Administered Barcode Identifier? mapping from the old MedicationStatement spreadsheet source as part of the 2015 MedicationStatement v2 mapping cleanup.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini and its current authoritative source is source/medicationstatement/structuredefinition-MedicationStatement.xml. That StructureDefinition still declares the HL7 v2 mapping namespace at the resource level, but MedicationStatement.identifier has only workflow, FiveWs, and RIM mappings, and source/medicationstatement contains no RXA/RAS/RXE/RXR/ORC mapping text. Related MedicationStatement v2 mapping cleanups have been separately audited or fixed on the combined branch, including FHIR-7837, FHIR-7843, FHIR-7848, and FHIR-7849; those sibling decisions support that the 2015 RXA removal family was preserved except where separately corrected.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current MedicationStatement source already implements the requested removal of the RXA-25 identifier mapping. Editing the top-level v2 mapping identity would be broader than the Jira request and unnecessary because the semantic element-level RXA-25 mapping is absent.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-7836 unless Pharmacy makes a future decision to reintroduce MedicationStatement-specific HL7 v2 mappings.
