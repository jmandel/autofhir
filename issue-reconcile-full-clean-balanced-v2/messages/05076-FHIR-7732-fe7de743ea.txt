FHIR-7732: Audit vaccination Immunization guidance

Issue request:
FHIR-7732 was a Published/Persuasive Pharmacy DSTU1 clarification request asking what it meant when MedicationAdministration guidance said that systems using MedicationAdministration to capture vaccinations SHOULD also expose an equivalent Immunization instance. The accepted resolution retained the Immunization-resource guidance because Immunization was not going away and said the wording should include Grahame's clarification that such systems should create the Immunization instance as well.

Initial application:
The issue was applied in git commit 5555750a4cce94cd357c3178441d043caa13f1ca, whose message explicitly listed #7732 and changed the active MedicationAdministration introduction from "SHOULD also expose an equivalent Immunization instance" to "SHOULD also create and expose an equivalent Immunization instance." The same commit also applied the closely related FHIR-7731 scope wording.

Additional context:
MedicationAdministration and Immunization are both active current-build resources in source/fhir.ini. Later Published issue FHIR-32960 revisited the same vaccine-administration boundary and is already represented on the combined branch by commit b7214bc5256739e402b4118bf12c9492f9291cbd, which normalized the MedicationAdministration text and aligned the paired Immunization Boundaries paragraph. A 2017 Zulip thread quoted the older guidance without recording a conflicting decision, and Confluence reference search found no FHIR-7732 minutes that alter the Jira/git conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active MedicationAdministration and Immunization introduction pages both say that vaccine administration is intended to be handled using Immunization and that, if a MedicationAdministration resource is needed for vaccination workflow or other reasons, systems SHOULD also create and expose an equivalent Immunization instance. That preserves the FHIR-7732 clarification after the later FHIR-32960 wording cleanup.

Recommendation:
Keep this empty audit commit as-is. No additional core source change is needed for FHIR-7732; the related FHIR-32960 source-changing commit should remain as the current wording reconciliation for the shared vaccine-boundary paragraph.
