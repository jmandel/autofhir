FHIR-8078: Audit retired genomic coordinate extensions

Issue request:
FHIR-8078 was a Published/Persuasive Clinical Genomics change request for FHIR-core Observation from the DSTU1 cycle. It asked that the old Standard Profile for Genetics clarify the coordinate semantics for genomic start and stop positions because implementers could not know whether positions were 0- or 1-based and whether endpoints were open or closed. The resolution clarified that positions are 0-based, start is inclusive, and end is exclusive; for example, 5-start and 6-stop is a single base at location 5.

Initial application:
No explicit current git commit mentioning FHIR-8078 was found. Historical R2 generated artifacts in tools/history/release2 contain the requested clarified semantics for the old geneticsGenomicStart and geneticsGenomicStop extensions: GenomicStart is an inclusive 0-based nucleotide position and GenomicStop is an exclusive 0-based nucleotide position. Git pickaxe searches for the extension names find pre-current-source history/import commits rather than a FHIR-8078-tagged application commit.

Additional context:
The old Observation-genetics profile family was later retired from active core source. FHIR-28620 records the later Published/Persuasive-with-Modification decision that Observation-genetics guidance, extensions, and examples were deprecated and removed as of R5, with implementers directed to Genomics Reporting guidance. Current core source and source/fhir.ini have active Observation resource ownership but no active geneticsGenomicStart/geneticsGenomicStop extension source, and the FHIR Extension Pack checkout also has no current copy of those two old extension definitions. Current genomics source points readers toward the Genomics Reporting IG and newer molecular definition work instead of the retired Observation-genetics extension pair.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical clarification requested by FHIR-8078 was applied to the old generated definitions, and the relevant Observation-genetics artifacts are no longer part of the current core build. Reintroducing or editing those retired extensions in core would be out of scope and could conflict with later deprecation/removal decisions.

Recommendation:
Keep this no-change audit commit for core reconciliation. If a future work group wants additional coordinate-system guidance, it should be considered in the current genomics artifacts or implementation guides rather than by reviving the retired Observation-genetics genomic start/stop extensions in core.
