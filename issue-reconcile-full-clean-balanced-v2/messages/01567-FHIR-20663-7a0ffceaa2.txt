FHIR-20663: Audit Provenance transform agent type text

Issue request:
FHIR-20663 was a Published/Persuasive Security WG change request for the Provenance import/transform narrative. It reported that section 6.3.4.5 told implementers to use Provenance.agent.role of assembler even though assembler belongs to the Provenance.agent.type value set.

Initial application:
The import/transform section was originally introduced by FHIR-9996 in commit d6bec271 with the stale Provenance.agent.role wording. FHIR-20663 was applied through PR #708 in commit b569c440, merged as e5f777ad, which changed the narrative to Provenance.agent.type and added an import anchor and related example links.

Additional context:
The current build has Provenance as an active resource in source/fhir.ini, and the current Provenance notes still say the middleware agent uses Provenance.agent.type of assembler. The current import example also encodes assembler under agent.type, and the StructureDefinition distinguishes agent.type from agent.role. Later related vocabulary requests FHIR-26313 and FHIR-27000 were resolved no-change in core with THO/UP-524 handling terminology wording; they do not require a core narrative reversal.

AutoFHIR reconciliation:
This empty audit commit records that no source edit is needed for FHIR-20663. The current source already carries the approved correction and no remaining Provenance transform text points implementers to agent.role for assembler.

Recommendation:
Keep this audit commit as-is. Any future changes about the exact assembler/transformer vocabulary should follow the THO/UTG terminology path rather than reopen the already-correct core Provenance narrative.
