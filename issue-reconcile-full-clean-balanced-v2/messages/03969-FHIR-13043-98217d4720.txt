FHIR-13043: Audit MedicationDispense performer role

Issue request:
FHIR-13043 was a Published/Persuasive with Modification Pharmacy change request from DSTU2 asking to fix MedicationDispense performer by making clear that the performer is the dispenser and adding a role back with an appropriate example value set.

Initial application:
The initial STU3 QA application first updated MedicationDispense performer text to say the performer/actor is the dispenser and to note R4 review. The later workflow-alignment application cited from Jira (5115fa6) and its immediate build-fix companion b22fbda added MedicationDispense.performer.function, bound it to MedicationDispensePerformerFunction, and updated dispense examples. The current StructureDefinition form was introduced later from the spreadsheet source while preserving those semantics.

Additional context:
FHIR-12831 explains why the older generic MedicationDispense.performer.role was removed before FHIR-13043. The 2017 Zulip thread linked from FHIR-13043 says that, without a type, performer should be read as the dispenser; the later 2020 dispenser profession/role Zulip discussion separates dispense function from professional capacity, using MedicationDispense.performer.function for what was done and Practitioner, PractitionerRole, or qualifications for pharmacist/physician-type capacity. Later Pharmacy decisions such as FHIR-22148 and FHIR-50110 retained the function/actor model and clarified actor use rather than reintroducing the old role element.

AutoFHIR reconciliation:
No source change was made. The active MedicationDispense resource is in the current build, and its current source already contains MedicationDispense.performer.function with an example binding to http://hl7.org/fhir/ValueSet/medicationdispense-performer-function plus MedicationDispense.performer.actor wording that the actor is the dispenser of the medication. Adding another role element or changing the binding to professional-role codes would conflict with the later current interpretation of where professional capacity is represented.

Recommendation:
Keep this audit commit as-is. Revisit only if Pharmacy opens a new issue to change the current model for professional capacity on MedicationDispense; FHIR-13043 itself is already reflected in the current build.
