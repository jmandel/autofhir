Additional context:
Endpoint is active in the current build through source/fhir.ini. Current Endpoint narrative and examples explicitly cover DICOM WADO-RS, WADO-URI, QIDO-RS, and STOW-RS. Later FHIR-36589 intentionally moved IHE connection type vocabulary out of core and added Endpoint notes pointing to IHE mCSD, so the inactive legacy IID example is not a missing core-source application of this issue.
