FHIR-20594: Rename missed Medication example dose form

Issue request:
FHIR-20594 was a Published/Persuasive Pharmacy change request asking to resolve an element-name inconsistency: MedicationKnowledge used doseForm for dosage form while Medication still used form. The accepted resolution was to update the Medication attribute name to doseForm.

Initial application:
Jira records the change as committed to CI in merge commit a6310682f5c644b348e380c5c295e4af8ca49574. That merge includes implementation commit 8c0d5b260da748e6818ba978ed1c699bd7eeb039, which changed the Medication spreadsheet and the then-current numbered Medication examples from form to doseForm, but did not update the top-level source/medication/medication-example.xml example.

Additional context:
Medication and MedicationKnowledge are active resources in source/fhir.ini. Current source definitions now use Medication.doseForm and MedicationKnowledge.definitional.doseForm, and current MedicationKnowledge examples/search parameters also use doseForm. The only non-archive Medication/MedicationKnowledge source XML still using form was source/medication/medication-example.xml; archived Medication examples still contain old form tags but are under source/medication/Archive and were not edited as current build inputs.

AutoFHIR reconciliation:
This commit updates source/medication/medication-example.xml so the example uses doseForm rather than the obsolete form element, matching the active Medication StructureDefinition and the FHIR-20594 resolution.

Recommendation:
Keep this commit as-is. It is a narrow source correction for a missed current example in an active resource folder; no further core source change is recommended for FHIR-20594.
