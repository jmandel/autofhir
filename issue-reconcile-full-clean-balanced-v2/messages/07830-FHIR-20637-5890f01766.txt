FHIR-20637: Audit extension view highlighting

Issue request:
FHIR-20637 was Published/Persuasive for R5 and asked FHIR core to make standard extensions more visible by changing many resource views to use Zulip option 2: add a link to extensions below the resource content view rather than leaving the page as-is or adding a full extension table.

Initial application:
The issue was applied by git commit 118fa79d000735ef4e115260ea6de72ebac5d728, "FHIR-20637 highlight extensions in views", which changed the active resource templates under tools/templates. That commit removed the old leading res-ext-link placement and retitled the post-content resource links as Additional definitions while retaining the extension-link placeholder in the concrete resource template.

Additional context:
The referenced Zulip thread records option 2 as "add link to extension below content view" and the only substantive feedback cautions that option 3 could make extension lists too long and too prominent. Later template work adjusted resource tabs, R5 diff links, and search-parameter registry links without removing the concrete resource extension link. Current CI rendering for Patient and Observation shows the Extensions navigation link and an Additional definitions line containing "see the extensions" immediately after the resource content views; search pages also point to the Extension registry when extension search parameters exist. No Confluence reference or conflicting community record was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source templates and rendered CI output already preserve the requested option-2 visibility for normal resource pages, so adding more prose or duplicating extension tables would go beyond the accepted request and risk making extensions more prominent than the work-group discussion supported.

Recommendation:
Keep this no-change audit commit. Revisit only if the publisher/template contract changes and concrete resource pages no longer render the post-content "see the extensions" link or equivalent Extensions navigation.
