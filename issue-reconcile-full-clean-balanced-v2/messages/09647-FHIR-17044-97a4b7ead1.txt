FHIR-17044: Audit OperationOutcome batch error clarification

Issue request:
FHIR-17044 was a Published FHIR-core/FHIR-I change request, resolved Not Persuasive with Modification for STU3. The issue asked whether Bundle.entry.response.outcome, described as an OperationOutcome with hints and warnings for batch/transaction, should also carry batch errors or per-entry transaction errors. The accepted clarification was that batch errors are not carried in entry.response.outcome, and failed transactions return one OperationOutcome instead of an entry-by-entry error Bundle.

Initial application:
The issue was applied by Grahame Grieve in SVN revision 14364, mirrored in git commit 815bf9f45c ("GF#17044 - clarification about error handling"), which edited the Bundle spreadsheet source for Bundle.entry.response.outcome. Later source rework carried that text into source/bundle/structuredefinition-Bundle.xml, and Bundle is an active resource in source/fhir.ini.

Additional context:
Current HTTP transaction/batch guidance still says a failed transaction returns a single OperationOutcome instead of a Bundle. Later FHIR-32011 added Bundle.issues for whole-Bundle information and warnings, with severity constrained to information or warning, and does not reopen the FHIR-17044 error-response rule. FHIR-53053 is a later Triaged, unresolved request about the same element description and is not a final decision to apply here. Zulip and Confluence searches found no direct FHIR-17044 discussion or conflicting minutes.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The active Bundle source already states that Bundle.entry.response.outcome is not used for error responses in batch/transaction, is only for hints and warnings, and that failed transactions return a single OperationOutcome instead of a Bundle.

Recommendation:
Keep this audit as-is. No source fix is needed for FHIR-17044; revisit only if the unresolved FHIR-53053 or another future final decision changes the intended semantics of Bundle.entry.response.outcome.
