FHIR-17773: Audit externalized targetDisease cardinality

Issue request:
FHIR-17773 was Published/Persuasive with Modification for PHER and asked to change ImmunizationRecommendation.recommendation.targetDisease from 0..1 to 0..* because one recommended vaccine administration, such as MMR, can target multiple diseases. The accepted resolution also asked for a comment explaining that a recommendation backbone instance corresponds to a single recommended administration and may encompass multiple target diseases.

Initial application:
The requested change was applied in git commit 8386871f82a95342647f6f39d9e145d17dd4f980, which updated source/immunizationrecommendation/immunizationrecommendation-spreadsheet.xml by changing targetDisease to 0..*, adding the MMR/repeating-targetDisease comment, and adding committee note #17773 on both the recommendation backbone and targetDisease rows. The generated R5 StructureDefinition in tag v5.0.0 contains ImmunizationRecommendation.recommendation.targetDisease with max="*" and the accepted comment.

Additional context:
The current core build no longer contains the ImmunizationRecommendation resource. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed source/immunizationrecommendation and deleted the active source/fhir.ini entries for ImmunizationRecommendation and ImmunizationEvaluation. Current core module/resource-guide pages link ImmunizationRecommendation to the HL7 Immunization Incubator IG as an Additional Resource, and that external continuous build still shows targetDisease as 0..* with the FHIR-17773 MMR comment. Later ImmunizationRecommendation wording issues such as FHIR-44950, FHIR-47040, and FHIR-48726 have already been audited on the combined branch with the same resource-removal context.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The FHIR-17773 cardinality and comment were already applied to the target resource before R5 publication, and the current core checkout has no active ImmunizationRecommendation StructureDefinition or source directory to edit. Reintroducing the deleted resource or changing residual references would exceed this issue's scope and could conflict with the later externalization of the resource.

Recommendation:
Keep this external-repo audit commit for the current core build. No core follow-up is needed for FHIR-17773 unless ImmunizationRecommendation returns to the core build; if it does, carry forward targetDisease max="*" and the MMR/repeating-targetDisease comment from the R5/external resource definition. Any future corrections to the current ImmunizationRecommendation definition should be made in the Immunization Incubator IG.
