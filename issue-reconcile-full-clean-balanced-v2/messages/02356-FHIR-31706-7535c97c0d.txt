FHIR-31706: Audit NamingSystem identifier system type binding

Issue request:
FHIR-31706 was Published with a Not Persuasive with Modification resolution. The request began as a NamingSystem extension for identifier system sub-type, but the final disposition was to remove the extensible NamingSystem.type binding to IdentifierType, create an IdentifierSystemType value set made from all codes in the THO v2-0203 code system, and bind NamingSystem.type to that value set with preferred strength.

NamingSystem is an active resource in source/fhir.ini. Later source commits changed NamingSystem metadata, canonical titles, and status bookkeeping, but did not reverse the FHIR-31706 binding.
