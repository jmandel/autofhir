FHIR-34883: Audit Person reference removal from CDS resources

Issue request:
FHIR-34883 was a Published/Persuasive FHIR-core CDS change request for R5 asking that Person not be allowed as an actor target. The accepted disposition was to change EvidenceReport.section.author from Person to Practitioner, while taking no separate Citation action because the offending Citation element was already being removed by another change.

Initial application:
No git commit explicitly mentioning FHIR-34883 was found. The Citation side was handled by FHIR-35866 in commit 307428a99b18208750cf6862eb52e95b39838ec0, which removed Citation.citedArtifact.classification.whoClassified.person and its Person target. EvidenceReport.section.author still had Person until commit 5aaea4cd29083bcdc02bbcc54b710015b18d5137 for FHIR-40278 replaced Person with Patient, Practitioner, PractitionerRole, and RelatedPerson.

Additional context:
FHIR-40278 later made the same EvidenceReport author rule explicit and broadened the permitted role-specific human targets. FHIR-31867 then deprecated and ultimately removed EvidenceReport from core in R6, and current core narrative says Citation moved to the Evidence Based Medicine on FHIR IG and EvidenceReport was replaced by an EvidenceReport Profile of Composition.

AutoFHIR reconciliation:
This audit commit makes no source change. The current FHIR core build has no active EvidenceReport or Citation resource entries in source/fhir.ini, no source/evidencereport or source/citation StructureDefinition to repair, and current narrative already points implementers to the EBM IG for those artifacts.

Recommendation:
Keep this audit commit as-is. No core source edit is needed for FHIR-34883; any future questions about the replacement Composition profile or external Citation resource should be handled in the EBM IG rather than by reviving removed core resource definitions.
