FHIR-33266: Remove stale EvidenceVariable timeFromStart references

Issue request:
FHIR-33266 was a Published/Persuasive CDS change request for R5 asking to remove EvidenceVariable.characteristic.timeFromStart because EvidenceVariable.characteristic.timeFromEvent could express study start, and to add the EvidenceVariableEvent example value set with study-start, hospital-admission, hospital-discharge, and operative-procedure.

Initial application:
The historical implementation commit 9a5e8d697f ("J# 33266") removed timeFromStart from source/evidencevariable/structuredefinition-EvidenceVariable.xml, updated EvidenceVariable examples from timeFromStart to timeFromEvent, and added the EvidenceVariableEvent CodeSystem/ValueSet. Current source still has no timeFromStart in the EvidenceVariable StructureDefinition and retains the EvidenceVariableEvent terminology, but two active build inputs still exposed the removed element: the Clinical Reasoning definitional-resources page and the FHIR model-info Library content.

Additional context:
FHIR-42886 later removed EvidenceVariable.characteristic in favor of EvidenceVariable.definition with a CodeableReference to Group, and FHIR-41582 introduced RelativeTime for event-relative timing. Those later Applied issues mean the current narrative should not point implementers back to either timeFromStart or the older EvidenceVariable.characteristic shape. The remaining source/fhir.ini timeFromStart entry is in the [r4-r6-changes] compatibility section and documents the old R4 path as removed, so it is intentionally unchanged.

AutoFHIR reconciliation:
Updated source/clinicalreasoning-topics-definitional-resources.html so the EvidenceVariable guidance and example use EvidenceVariable.definition with a referenced Group and Group.characteristic.relativeTime instead of EvidenceVariable.characteristic.timeFromStart. Removed the stale timeFromStart element from source/library/library-fhir-model-definition-content.xml so the active FHIR model-info example no longer advertises the deleted element.

Recommendation:
Keep this source fix. It completes the FHIR-33266 removal across active current-spec inputs while respecting later R6 EvidenceVariable and RelativeTime decisions; broader cleanup of other EvidenceVariable model-info drift should be handled separately if desired.
