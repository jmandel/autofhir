FHIR-5739: Audit Questionnaire terminology examples

Issue request:
FHIR-5739 was a Published/Persuasive Patient Care change request for the DSTU1 Questionnaire resource. It asked that wording describing the code element for questionnaire groups/questions stop saying "such as LOINC or SNOMED" because SNOMED CT should not be implied as a good or best-practice terminology for identifying questions or groups of questions.

Initial application:
The Jira says the change was pre-applied. Git history confirms commit 70b9e0bca53603a79cd40acbd12322cbd92695b3 removed "or SNOMED" from source/questionnaire/questionnaire-notes.xml on 2015-02-22, leaving "such as LOINC" in the relevant Questionnaire guidance.

Additional context:
The current build includes Questionnaire as an active resource in source/fhir.ini. The DSTU1 Group/Question wording has since been refactored into the current Questionnaire.code and Questionnaire.item.code definitions and mapping exceptions, all of which use LOINC-only example language for identifying questionnaires, groups, or questions. Exact issue-key searches found no Zulip or Confluence record that changes the Jira/source conclusion. Other current Questionnaire SNOMED references concern answer value sets or example answer coding, not the question-identity guidance targeted by this issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Questionnaire source already avoids recommending SNOMED CT as the example terminology for identifying questions or question groups and preserves the requested LOINC-only guidance.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed for FHIR core unless a future Patient Care decision changes the broader policy for Questionnaire.item.code examples.
