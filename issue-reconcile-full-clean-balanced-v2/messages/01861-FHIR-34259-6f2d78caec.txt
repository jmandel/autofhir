FHIR-34259: Audit ValueSet multiplicity extension removal

Issue request:
FHIR-34259 was a Published/Persuasive Vocab change request for R5 asking to remove the core ValueSet extensions valueset-compose-include-maximumMultiplicity and valueset-compose-include-minimumMultiplicity. The final tracker resolution says the extensions can be removed.

Initial application:
The extensions were originally added for the VSDP work tracked by FHIR-26551. The FHIR-34259 implementation was applied through the FHIR-34259 branch and PR #1947: commit 6cd93edefb deleted both extension StructureDefinition XML files and removed their ImplementationGuide resource entries, and commit 61b4f0d4a3 removed the corresponding slices from the VSD-aligned ValueSet profile.

Additional context:
Current source/fhir.ini keeps ValueSet in the active resource build scope, but current core source no longer contains either removed extension name or canonical URL. The current ValueSet core ImplementationGuide source has no resource entries for these extensions, the old VSD-aligned profile source file that held the removed slices is no longer present, and a parallel search of the FHIR Extension Pack found no migrated copy of either extension. Related VSDP/profile work such as FHIR-31395 and the original addition in FHIR-26551 explains why these extensions existed, but does not require a further current-core edit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current specification already satisfies FHIR-34259 because the two requested extensions and their known source references have been removed from the current core build inputs, with no discovered conflicting community or extension-pack evidence.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR core unless a human wants to revisit broader historical VSDP documentation outside the scope of removing these two extension definitions.
