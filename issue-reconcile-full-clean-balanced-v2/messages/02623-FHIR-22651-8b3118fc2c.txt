FHIR-22651: Audit MedicationStatement effectivePeriod end guidance

Issue request:
FHIR-22651 was a Published, Persuasive with Modification Pharmacy change request for R5. It asked that MedicationUsage/MedicationStatement.effective[x] stop implying that an active medication statement must omit effectivePeriod.end whenever the medication is still being taken, and the approved wording allowed a known future end date while omitting the end only when ongoing use is expected to continue indefinitely.

Initial application:
The Jira snapshot records a 2019-06-18 committed-and-merged implementation link for the tracker. In the local source ancestry, commit 634360b51d40494b5427df25cc2ecce831d928e4 is the GF 22651 application visible on this branch family; it changed the then-current source/medicationusage/medicationusage-spreadsheet.xml effective[x] comment from the misleading unconditional omission rule to the approved indefinite-use/known-end-date distinction. Later source refactors and the MedicationUsage-to-MedicationStatement naming path carried that rule into the current structure definition source.

Additional context:
MedicationStatement is an active current-build resource in source/fhir.ini. The current authoritative source/medicationstatement/structuredefinition-MedicationStatement.xml comment for MedicationStatement.effective[x] says effectivePeriod.end is omitted only when the medication is still being taken and is expected to continue indefinitely, and says a known effectivePeriod.end is included as the end date. The Event mapping exception source repeats the same resource-specific wording because it intentionally diverges from the generic Event occurrence text. The originating Zulip thread confirms the problem report and Pharmacy-editor agreement that the old comment was misleading; Confluence reference search found no separate conflicting minutes.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The active source already preserves the approved semantic rule for future known end dates, and changing it further would only restate or editorially adjust already-correct guidance.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR follow-up is needed for FHIR-22651 unless a future Pharmacy decision wants to revise the broader MedicationStatement effective[x] wording.
