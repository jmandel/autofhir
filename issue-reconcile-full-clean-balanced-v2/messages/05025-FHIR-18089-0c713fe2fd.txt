FHIR-18089: Audit ValueSet composition clarification

Issue request:
Published/Persuasive Vocab change request from STU3 asking to clarify VSD-3 for ValueSet.compose.include.valueSet when valueSet is combined with system plus concept or filter. The accepted resolution was to add a note to the Composition Rules explaining that multiple includes are cumulative and that criteria within one include intersect, specifically for valueSet+system+filter or valueSet+system+concept combinations.

Initial application:
The Jira comment identifies git 66ae1e40f1bc02283363c872db14035fc795f8f7. That commit changed source/valueset/valueset-notes.xml to split the Composition Rules into explicit valueSet-only, system-only, and valueSet+system bullets, including the statement that system selection is applied after checking concept/filter and then intersected with all referenced value sets. No later source history removed that rule.

Additional context:
source/fhir.ini actively lists valueset=ValueSet and maps ValueSet to work group code vsd, so source/valueset/valueset-notes.xml and source/valueset/structuredefinition-ValueSet.xml are in current build scope. The originating Zulip thread records the same question and confirms the intended model: filter applies to the system and criteria within the include are intersections; empty intersections are not errors. A later nearby issue, FHIR-51117, clarified filter.value syntax only and does not alter the valueSet+system composition semantics.

AutoFHIR reconciliation:
No source change was made. The current active ValueSet notes already contain the requested Composition Rules clarification, and the StructureDefinition comment independently states that all include conditions must be true and all listed value sets must contain the selected codes.

Recommendation:
Keep this audit commit as-is. Further edits would duplicate existing normative guidance rather than change implementer understanding; only revisit if a future work-group decision changes the intersection semantics for ValueSet.compose.include.valueSet combined with system criteria.
