FHIR-17253: Audit Endpoint DICOM scope wording

Issue request:
FHIR-17253 was a Published/Persuasive PA change request for R5 asking the Endpoint Scope and Usage DICOM/imaging bullet to say "Location of where to query, retrieve or store imaging content and metadata (QIDO-RS, WADO-RS, WADO-URI, STOW-RS)" so it aligned with the Endpoint connection type value set expansion.

Initial application:
The original DICOM/imaging bullet came from FHIR-14100 in git commit fe0b0b0dae752745d989a9b6c408341e7572cf16. FHIR-17253 was then explicitly applied by git commit d1732ddecc196dd7db2c0a5748a5aa2bcb6c7444, which replaced the old "query for imaging content and metadata (QIDO-RS, WADO-RS, or WADO-URI)" sentence with the approved query/retrieve/store wording including STOW-RS.

Additional context:
Endpoint is an active current-build resource in source/fhir.ini. Later Endpoint DICOM terminology-link issues, including FHIR-50770 and FHIR-53728, concern THO/UTG code-system URL maintenance rather than the Endpoint Scope and Usage narrative fixed by this issue.
