FHIR-38941: Audit Bundle.link navigation guidance

Issue request:
FHIR-38941 was a Published FHIR-core Change Request, resolved Persuasive with Modification for R5, asking what happens when non-search/history Bundles that require a particular first entry use navigation links such as next. The approved resolution was to add a Bundle.link note that next/prev/first/last behavior is defined for searchset and history Bundles but not currently defined for other Bundle types, where partners must negotiate behavior.

Initial application:
The issue was applied before this reconciliation. Commit df898291c7 added the approved sentence to Bundle.link.definition, and follow-up commit 078e61d079, matching the Jira comment "Git master 078e61d079", moved the sentence into the Bundle.link comment/notes area while restoring the concise definition.

Additional context:
source/fhir.ini actively lists bundle=Bundle under [resources], so source/bundle/structuredefinition-Bundle.xml is in current build scope. The current Bundle.link comment contains the approved navigation-link wording. Nearby Bundle notes continue to describe next links only for searchset and history use, and searches found no related Jira issue requiring a different current rule. FHIR-I minutes for 2022-10-17 record the Persuasive with Mod vote.
