FHIR-39634: Audit DeviceDefinition guideline resolution

Issue request:
FHIR-39634 was a Published FHIR-core Change Request for OO asking whether intendedUse or instructionsForUse elements should be added to Device and/or DeviceDefinition. The persuasive-with-modification resolution was to leave Device unchanged, change DeviceDefinition.guideline.indication, DeviceDefinition.guideline.contraindication, and DeviceDefinition.guideline.warning from CodeableReference to CodeableConcept, and add comments pointing implementers to ClinicalUseDefinition when more structured data is needed.

Initial application:
DeviceDefinition.guideline.usageInstruction and DeviceDefinition.guideline.intendedUse were already present from the earlier FHIR-29728 DeviceDefinition work. Commit 4f84a83b0dead210ca9182a4090de7273ecae847 applied the FHIR-39634 datatype change to the three guideline clinical-use elements and added ClinicalUseDefinition comments. Follow-up QA cleanup commits 2c438fd7442fa30ca1a54b4b693f5ab44cb702da and d16f598c76ae8d431c38634fc430f26c3f686f0f added and fixed the broader DeviceDefinition.guideline comment.

Additional context:
OO WGM minutes record the same disposition: ClinicalUseDefinition.subject points back to Device and DeviceDefinition, the DeviceDefinition guideline clinical-use elements should become CodeableConcept, comments should point to ClinicalUseDefinition for structured data, and there should be no Device resource change. Device, DeviceDefinition, and ClinicalUseDefinition are active resources in source/fhir.ini. Current ClinicalUseDefinition.subject includes target profiles for both Device and DeviceDefinition. Searches found no Zulip discussion or later Jira/community evidence that changes this interpretation; FHIR-31394 was only a related BR&R ClinicalUseDefinition follow-up noted by OO minutes, not part of this core Device/DeviceDefinition reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current DeviceDefinition source has CodeableConcept for guideline.indication, guideline.contraindication, and guideline.warning, each with the ClinicalUseDefinition comment and no ClinicalUseDefinition targetProfile. Device has no Device.intendedUse or Device.instructionsForUse element. The remaining Device.property text allowing static intended-use or instruction-like characteristics is consistent with the resolution's explicit no-change treatment of Device and does not require a new core edit.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core follow-up is needed for FHIR-39634 unless a future work-group decision reopens whether Device should gain dedicated intended-use or instruction elements.
