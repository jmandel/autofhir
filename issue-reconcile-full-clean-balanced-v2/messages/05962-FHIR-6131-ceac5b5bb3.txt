FHIR-6131: Audit CarePlan EpisodeOfCare context

Issue request:
FHIR-6131 was a Published/Persuasive with Modification DSTU1 Patient Care change request asking for CarePlan to reference EpisodeOfCare. The accepted resolution was to add a 0..1 CarePlan context element of type Reference(Encounter|EpisodeOfCare) with a usage note that activities may occur in other encounters or episodes.

Initial application:
The Jira comments cite SVN #6766. Git history maps that to d6c4981fa8fe7d58cc3e1cc393aa8cc0b6a83c54, which added the old CarePlan context row with Reference(Encounter|EpisodeOfCare) in source/careplan/careplan-spreadsheet.xml. A later CarePlan clarification commit, f39dde8e171836d3345715f788c746e0a1624492, still operated on the same historical context element.

Additional context:
FHIR-19511 is the later Published Patient Care workflow decision for CarePlan and related resources. It explicitly says to rename context to encounter, make it 0..1 Reference(Encounter), and handle EpisodeOfCare linkage with the workflow extension. Commit 9e6a11d5a0bdd5e6489c0e130b394313dc9acb75 pre-applied that context-to-encounter change. Current CarePlan source is in build scope via source/fhir.ini and now has CarePlan.encounter Reference(Encounter) only; the FHIR Extension Pack defines workflow-episodeOfCare with CarePlan context and Reference(EpisodeOfCare). FHIR-54402, resolved No Change in 2026, reaffirmed for the current ballot that CarePlan-to-EpisodeOfCare linkage should use that extension instead of a direct core element.

AutoFHIR reconciliation:
No source change was made. The current core CarePlan source correctly reflects the later published workflow decision and the current extension-based mechanism for EpisodeOfCare linkage, so re-adding EpisodeOfCare to CarePlan.encounter or adding a parallel core element would contradict later decisions.

Recommendation:
Keep this audit commit as-is. Future requests for direct CarePlan/EpisodeOfCare linkage should be evaluated against FHIR-19511 and FHIR-54402; if the work group changes direction, the likely change would be a new Patient Care decision rather than completing FHIR-6131 again.
