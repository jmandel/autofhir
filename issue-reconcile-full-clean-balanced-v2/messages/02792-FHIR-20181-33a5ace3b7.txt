Issue request:
FHIR-20181 is a Published/Persuasive FHIR-core Pharmacy change request raised against MedicationRequest/MedicationPrescription. It asked to correct the non-substantive typo "patte3rn" to "pattern" in the MedicationRequest.courseOfTherapyType definition, and Jira records it as auto-approved for R5.

Initial application:
Jira records the issue as applied by merge commit aa42e5dcc1e780bf1fa001dc784d2801f6d3b1d4 on 18Feb2019. Inspecting that merge's source-changing child, 9d4a0fe09370e2b75ede4debcff124f36c3d3d7e, shows the historical MedicationRequest spreadsheet definition changed from "overall patte3rn" to "overall pattern".

Additional context:
MedicationRequest is an active current-build resource in source/fhir.ini. The current active StructureDefinition source now contains the corrected courseOfTherapyType definition and the typo is absent from source/. FHIR-17255 introduced the element and FHIR-32489 later tightened its value set binding to extensible, but those same-element decisions do not alter the typo resolution; FHIR-32489 is also already represented on the combined reconciliation branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source already says "The description of the overall pattern of the administration of the medication to the patient." for MedicationRequest.courseOfTherapyType, so reapplying the 2019 typo fix would be redundant.

Recommendation:
Keep this empty audit commit as-is for FHIR-20181. No FHIR-core follow-up is needed unless a future generated artifact unexpectedly reintroduces the misspelling.
