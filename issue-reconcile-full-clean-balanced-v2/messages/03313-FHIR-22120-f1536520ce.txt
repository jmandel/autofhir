FHIR-22120: Audit ChargeItemDefinition external ownership

Issue request:
FHIR-22120 was a Published/Persuasive with Modification PA change request for R5 asking that ChargeItemDefinition.instance allow DeviceDefinition as an additional choice without removing Device. The accepted modification also added ActivityDefinition and PlanDefinition, matching similar definitional targets used by Procedure.

Initial application:
The request was historically applied in HL7/fhir by commit b8b51c33e1319e14185cb4eeb1b80540b2fde501, which added DeviceDefinition, ActivityDefinition, and PlanDefinition targetProfile entries to source/chargeitemdefinition/structuredefinition-ChargeItemDefinition.xml when ChargeItemDefinition was still a core source resource. Later same-element work, including FHIR-34621, built on that applied state rather than reversing it.

Additional context:
ChargeItemDefinition is no longer an active FHIR core resource in this checkout: source/fhir.ini's current [resources] list omits ChargeItemDefinition, source/metadataresource/metadataresource-introduction.xml and source/resource/resource-notes.xml link ChargeItemDefinition to the HL7 admin-incubator IG, and git commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/chargeitemdefinition from core. The current admin-incubator published StructureDefinition still lists Device, DeviceDefinition, ActivityDefinition, and PlanDefinition among ChargeItemDefinition.instance targetProfile values. FHIR-53234 is a later same-element Triaged issue proposing a future split between instance-like and definition-like targets, but it is not an Applied or Published reversal for this reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change in HL7/fhir. The seed issue's requested core edit was applied historically, and any current authoritative source maintenance for ChargeItemDefinition belongs to the external admin-incubator artifact rather than the current core build.

Recommendation:
Keep this external-repo audit as-is for FHIR core. If PA later advances FHIR-53234 or other ChargeItemDefinition.instance restructuring, apply it in the admin-incubator source or whichever repository then owns ChargeItemDefinition, not by restoring or editing retired core source.
