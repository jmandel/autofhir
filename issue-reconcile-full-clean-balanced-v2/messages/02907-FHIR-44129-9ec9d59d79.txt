FHIR-44129: Audit ImplementationGuide scope sentence

Issue request:
FHIR-44129 was an Applied/Persuasive FHIR-I change request for the R6 ImplementationGuide Scope and Usage text. It identified the sentence "so that the logical package that the IG represents, so that the contents are computable" as misconstructed and proposed removing the bad phrase; the final resolution pointed to FHIR-43527.

Initial application:
There is no separate FHIR-44129 source commit. The same text was applied through FHIR-43527, and current history contains commit 5ac21ed0d23493bde9815dba537d9cb0048132df, "FHIR-43527 Sentence not clear," which replaced the malformed sentence in source/implementationguide/implementationguide-introduction.xml.

Additional context:
FHIR-43527 is an Applied/Persuasive issue for the same ImplementationGuide Scope and Usage sentence and gives the approved replacement wording. FHIR-I minutes from 2024-03-04 record a 9-0-0 persuasive vote for FHIR-43527 and explicitly say the same resolution applies to FHIR-44129. The implementationguide resource is active in source/fhir.ini, and the combined branch already contains the corrected source wording.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current built source already says that ImplementationGuide defines the content of the IG, with entry pages into the publication as a single logical package, so the IG contents are computable for publication, validation, registry lookup, and other uses.

Recommendation:
Keep this no-change audit commit. No further core source work is needed for FHIR-44129 unless the work group later reopens the broader ImplementationGuide scope text.
