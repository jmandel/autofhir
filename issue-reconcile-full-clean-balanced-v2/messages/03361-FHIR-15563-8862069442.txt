FHIR-15563: Audit Coverage copay details

Issue request:
FHIR-15563 was a Published/Persuasive STU3 Financial Management Coverage change request. It asked to add the Copay structure to Coverage as shown in the December 2017 ballot, and its resolution agreed to add that Copay structure and add Televisit to the current copay list.

Initial application:
The December 2017 ballot preparation commit 4251af7d60629fdcd0051f1c47a1edac71416304 added Coverage.copay, Coverage.copay.type, Coverage.copay.value, and the coverage-copay-type terminology source. The later Jira-tagged commit 8f5e8739dc6dfa0edfae82f9d09b26f6f0e7b02a, "Tracker #15563 and #15564", preserved the Coverage copay rows while applying the Coverage ballot material. A closely following terminology commit 49ee52b963abadc71e75fff3c1f5e31e86d25d30 added the televisit concept to the same copay CodeSystem, completing the Televisit part of the FHIR-15563 resolution even though that commit was not labeled with this issue key.

Additional context:
Coverage is an active current-build resource in source/fhir.ini. Later Coverage work renamed and broadened the original Coverage.copay backbone into Coverage.costToBeneficiary, preserving the patient copay/payment meaning while adding category, network, unit, term, value[x], and exception detail. Later issue-reconcile commits already on the combined branch for FHIR-18122 and FHIR-27024 further completed and constrained Coverage.costToBeneficiary.exception without reversing the seed request. The copay CodeSystem itself was moved out of core during UTG/THO cleanup, while the active core Coverage value set continues to include http://terminology.hl7.org/CodeSystem/coverage-copay-type; a current THO check confirms the televisit concept is present.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The active Coverage StructureDefinition already contains the copay/card detail requested by the issue as Coverage.costToBeneficiary, an active Coverage example demonstrates a gpvisit costToBeneficiary with an exception, and the Televisit copay code is already present in the external terminology source referenced by the core value set.

Recommendation:
Keep this no-change audit commit. No core source edit is needed for FHIR-15563; any future changes to the sample copay terminology should be handled through THO/UTG rather than by reintroducing a core CodeSystem source file.
