FHIR-22497: Confirm Encounter serviceProvider example

Issue request:
FHIR-22497 was a Published/Persuasive PA change request for Encounter.serviceProvider. The issue reported that the definition referred to an unlinked and hard-to-find "example bundle" showing abbreviated Encounters for a colonoscopy, while the Encounter examples were individual Encounter instances. The accepted resolution was to include or identify the colonoscopy Encounter example.

Initial application:
The issue was applied by git commit 18fbe3d31c9e5dc7a71197f051ca047a38eac20c on 2023-02-03. That commit added source/encounter/encounter-example-colonoscopy.xml, added it to source/encounter/list-Encounter-examples.xml as "Colonoscopy with an external service provider", and changed Encounter.serviceProvider from the old "example bundle" sentence to "Refer to the colonoscopy example on the Encounter examples tab." Current source still contains that applied state.

Additional context:
Encounter is an active resource in source/fhir.ini, so the Encounter StructureDefinition and examples under source/encounter are in current build scope. The old wording originated from the earlier FHIR-13155 serviceProvider clarification, but FHIR-22497 specifically corrected the missing/unclear example identification. Bounded Jira, Zulip, Confluence, and source searches found no later conflicting decision or remaining current-source occurrence of the old unknown-bundle wording.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because the current authoritative Encounter source identifies the colonoscopy example and includes the example on the Encounter examples list.

Recommendation:
Keep this audit as-is. Follow-up is only needed if PA wants a stronger direct rendered link than the examples-tab reference, which would be a new editorial request rather than incomplete application of FHIR-22497.
