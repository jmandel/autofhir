FHIR-11012: Request review of BioCompute provenance example

Issue request:
FHIR-11012 was a Published/Persuasive Clinical Genomics DSTU2 issue for the old Sequence resource. The accepted resolution was to add a Provenance example with explanation showing how a BioCompute scenario can be recorded, and to reference the Provenance resource.

Initial application:
The issue was historically applied before this reconciliation. Commit 7adda962ef added an initial BioCompute Provenance example source, and commit 8c08a289ec explicitly referenced #11012 while adding provenance-example-biocompute-object.xml and provenance-example-cwl.xml to the Provenance examples list. Later maintenance renamed/updated the target from Sequence/MolecularSequence to MolecularDefinition before the examples were removed during MolecularSequence cleanup.

Additional context:
The original target artifact has moved out of current core build scope: source/fhir.ini lists Sequence under removed resources and comments MolecularSequence out of current build metadata, while later FHIR-51227 records the Clinical Genomics decision to replace MolecularSequence with MolecularDefinition. Current core source also has no BioCompute/CWL Provenance example. A later Security issue, FHIR-50994, and Security WG minutes identified that the old example was semantically unclear: the BioCompute object was modeled as Provenance.entity while the title could imply a software/device agent. FHIR-50994 was later retracted/no-change, but no final replacement wording or modeling decision was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing the removed example would require choosing a new current target artifact and deciding whether BioCompute belongs as an input entity, an agent/device, or both. That would be a new Clinical Genomics/Security modeling decision rather than a safe mechanical restoration of the 2016 Sequence-era application.

Recommendation:
Keep this human-review audit as-is. If CG and Security still want a core BioCompute Provenance example, open or apply a current-build issue that identifies the target artifact and the intended Provenance.agent/Provenance.entity semantics; otherwise leave the removed Sequence/MolecularSequence-era examples out of the current core build.
