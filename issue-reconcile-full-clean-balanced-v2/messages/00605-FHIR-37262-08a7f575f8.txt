FHIR-37262: Remove stale Goal outcome examples

Issue request:
FHIR-37262 was Applied with resolution Not Persuasive with Modification. The original request asked to add more target resource types to Goal.outcome; Patient Care instead resolved to remove Goal.outcome and use the resource-pertainsToGoal extension for resources that need to point back to a Goal.

Initial application:
The Jira comment cites HL7/fhir commit 0d8e375635, which commented Goal.outcome out of source/goal/structuredefinition-Goal.xml. That application did not update the active Goal examples listed in source/goal/list-Goal-examples.xml, so Goal/example and Goal/stop-smoking still contained active <outcome> elements even though Goal.outcome no longer participates in the built resource definition.

Additional context:
Goal is an active build resource in source/fhir.ini. Later applied/no-change decisions FHIR-53828 and FHIR-48360 continue to support using resource-pertainsToGoal rather than restoring a core Goal.outcome element. The extension definition currently lives in the FHIR Extension Pack and has Resource context with a Reference(Goal) value, so adding a replacement element on Goal would contradict the issue family. FHIR-57447 is an unresolved OO follow-up about adding Observation-side documentation and is not decided here.

AutoFHIR reconciliation:
This commit removes the stale Goal.outcome content from the two active Goal examples. It does not add Observation examples or edit the extension pack because the only current core-source inconsistency for this issue was that active Goal examples still used a removed element.

Recommendation:
Keep this commit as-is. Any additional Observation guidance should proceed through FHIR-57447 or another OO-approved change; do not reintroduce Goal.outcome without a new Patient Care decision reversing FHIR-37262/FHIR-48360.
