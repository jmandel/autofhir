FHIR-26654: Audit Practitioner language preference model

Issue request:
FHIR-26654 was Published/Persuasive with Modification for the PA work group. It asked to add a Practitioner language preference indicator by changing Practitioner.communication from a direct CodeableConcept list into a Patient/RelatedPerson/Person-like BackboneElement with language and preferred children, adding PractitionerRole.communication to carry the prior patient-facing language use, and clarifying PractitionerRole and HealthcareService communication documentation.

Initial application:
Commit f0398618a026c4fc3381d09fe7690c7b73fa9d6b explicitly applied FHIR-26654 for R5. It changed the active Practitioner and PractitionerRole StructureDefinitions, their communication search parameters, practitioner examples, and the HealthcareService communication search-parameter bundle. Current source contains the requested Practitioner.communication BackboneElement, Practitioner.communication.language CodeableConcept, Practitioner.communication.preferred boolean, PractitionerRole.communication CodeableConcept, and HealthcareService.communication clarification.

Additional context:
FHIR-22114 was reopened and resolved in the same PA September 2022 work because FHIR-26654 addressed the consistency request. FHIR-54008 was later Resolved - No Change after PA confirmed the PractitionerRole.communication datatype discrepancy is intentional: person-type resources can carry preferences, while role/service-oriented resources list languages available for patient interaction. FHIR-41524 later corrected language-tag wording on these elements without reversing the FHIR-26654 structural split, and its reconciliation commit is already on the combined branch.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the active current source already implements the final FHIR-26654 decision and later related decisions support leaving PractitionerRole.communication as a direct CodeableConcept without a preferred child.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-26654 unless PA later changes the PractitionerRole/service-language policy recorded in FHIR-54008.
