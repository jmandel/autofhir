FHIR-16135: Audit Observation category definitions

Issue request:
FHIR-16135 was Published with a Persuasive with Modification resolution for the STU3 Observation category value set/code system. The resolution treated the categories as high-level grouping guidance, confirmed procedure versus therapy and questionnaire/survey interpretation, changed the social-history definition to remove administrative demographics and add familial/environmental health-risk language, changed imaging wording to say observations regarding imaging modalities, and added digital pathology to laboratory.

Initial application:
The issue was applied in commit efab7476097644c09577492e10eaa99988210c61 ("GF#16135"), which changed the then-core source/observation/codesystem-observation-category.xml definitions for social-history, imaging, and laboratory exactly along the approved lines. Procedure, therapy, and survey already carried category definitions consistent with the resolution's implementation choice at that time.

Additional context:
The Observation category CodeSystem is no longer authored in this FHIR core checkout. Commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 deleted the core CodeSystem copy as part of moving UTG-maintained terminology out of the core build, while preserving the FHIR-16135 text in the deleted source. The current build-scoped core source keeps Observation active and binds Observation.category to source/observation/valueset-observation-category.xml, whose compose imports http://terminology.hl7.org/CodeSystem/observation-category. Current THO version 2.0.0 carries the FHIR-16135 social-history, imaging, and laboratory definitions, the procedure/therapy distinction, and, via later FHIR-36305/UP-738 work already reconciled separately on the combined branch, explicit questionnaire/form wording for survey.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing core would duplicate or diverge from the authoritative external THO CodeSystem, and the build-scoped core ValueSet already points at the terminology source that contains the required wording.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-16135; future changes to Observation category code definitions should proceed through UTG/THO, with separate FHIR issue reconciliation only for distinct applied decisions.
