FHIR-15909: Audit security input-validation recommendation

Issue request:
FHIR-15909 was a Published/Persuasive Security work group change request from the STU3 cycle asking to add an Input Validation item to the top summary list on the FHIR Security page. The requested wording said to validate all input received from other actors so the data is well formed and does not contain content that would cause unwanted system behavior, and included examples of testing with fuzzing, invalid input attacks, and injection attacks; Jira comments record WG concern that the testing sentence not be read as exhaustive or prescriptive.
