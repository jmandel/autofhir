FHIR-16862: Audit optional ElementDefinition constraint expressions

Issue request:
FHIR-16862 was a Published/Persuasive with Modification FHIR-I STU3 change request asking to relax ElementDefinition.constraint.expression from 1..1 to 0..1 because FHIRPath should not be mandatory for every invariant, warn that constraints without FHIRPath may not be machine-enforceable or may be missed, and make ElementDefinition.constraint.xpath trial-use with documentation that XPath was generally not useful and might later be removed.

Initial application:
Jira records svn revision 14313, which maps to git commit 6c966da0773fee83a59bb664bc42d5f91f9cc661. That commit explicitly mentioned GF#16862 and changed the ElementDefinition spreadsheet so constraint.expression moved from 1..1 to 0..1, added the warning invariant that constraints should have an expression, and added XPath caution text.

Additional context:
ElementDefinition is active in the current build and marked normative in source/fhir.ini. The current source still has ElementDefinition.constraint.expression as 0..1, carries invariant 21 as a warning on ElementDefinition.constraint when expression is absent, and now marks ElementDefinition.constraint.xpath as a deleted row with an R5 conversion note saying XPath was removed due to lack of use and maintenance. That later removal is governed by FHIR-37871, which is already represented on the combined branch by commit 95bee07998f5421bf581d674e630d1a31aedcfb6, so this seed should not re-decide it.

AutoFHIR reconciliation:
Made no source change. The current build-scope ElementDefinition source already preserves the FHIR-16862 semantic change for optional FHIRPath expressions and the requested warning, while the XPath portion has been safely superseded by the later published removal decision.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-16862 unless a future work group decision reintroduces an XPath constraint surface or changes the policy for constraints without FHIRPath expressions.
