FHIR-37529: Audit useSupplement operation parameters

Issue request:
FHIR-37529 was a Published Vocab change request with a Persuasive with Modification resolution. It asked for a 0..* canonical input parameter named useSupplement on ValueSet $expand and $validate-code, with documentation saying that the supplement must be used as if it were included through the http://hl7.org/fhir/StructureDefinition/valueset-supplement extension.

Initial application:
The issue was applied before this reconciliation by git commit 1e011219c1eb2738181c75f2f4add7fc85e3e4c8, which added useSupplement to source/valueset/operationdefinition-ValueSet-expand.xml and source/valueset/operationdefinition-ValueSet-validate-code.xml. A later link-maintenance commit, c3432543e2b93c3befc06f628938d37e6c1f1f02, changed the documentation links to the current canonical triple-bracket form without changing the parameter semantics.

Additional context:
ValueSet is an active resource in source/fhir.ini and source/valueset/list-ValueSet-operations.xml includes both ValueSet-expand and ValueSet-validate-code, so the checked operation definitions are in current build scope. FHIR-36232 was the earlier duplicate/retracted $expand-only supplement request. Later Applied issue FHIR-44898 clarified that required CodeSystem supplements must be declared through the valueset-supplement extension or the useSupplement $expand input parameter, which supports rather than supersedes the FHIR-37529 application. The valueset-supplement extension definition now lives in the FHIR Extension Pack while the core operation definitions correctly reference its canonical URL.
