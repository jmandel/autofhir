FHIR-5824: Audit Device availability status support

Issue request:
FHIR-5824 was Published/Persuasive for DSTU1 and asked OO to add a Device.status element because Device had no way to indicate that a device was no longer available, including cases such as lost, expired, destroyed, contaminated, or entered in error.

Initial application:
No commit explicitly mentioning FHIR-5824 was found in the current git history. The Jira issue is marked Applied for DSTU1, and Device.status is present in the current Device resource; current git history imported the Device status source during the 2021 build-source/R4B work. Later explicit Device-status work is visible in 0cd35c3c18, which applied FHIR-32557 and FHIR-34542 by changing Device.status from device availability to record status and adding Device.availabilityStatus.

Additional context:
FHIR-32557 superseded the older availability semantics for Device.status: status is now about the Device record, while Device.availabilityStatus is about the physical device availability. FHIR-46962 later corrected the Device narrative to name availabilityStatus, and FHIR-53243 re-added unknown to the record-status code system. FHIR-54324 is a later Resolved - change required issue that may further broaden availabilityStatus and move terminology, but it is not yet Applied/Published and does not make the current seed issue incomplete.

AutoFHIR reconciliation:
This audit makes no source change. Device is active in source/fhir.ini, Device.status is defined and required-bound to ValueSet/device-status, Device.availabilityStatus is defined with an extensible binding to ValueSet/device-availability-status, and the current notes explicitly distinguish record status from device availability. The current source therefore preserves the seed's required capability, adjusted by later OO decisions.

Recommendation:
Keep this no-change audit. Future work should handle FHIR-54324 or related terminology migration separately when those decisions are Applied/Published; do not re-purpose Device.status back to physical availability for FHIR-5824.
