FHIR-6247: Audit ClinicalImpression imaging reference scope

Issue request:
FHIR-6247 was a Published/Persuasive DSTU1 Patient Care request to add ImagingObjectSelection to the choice for ClinicalImpression.investigations.item so clinical assessments could directly reference imaging evidence.

Initial application:
The Jira comment records SVN #9058. The corresponding git-svn commit 127b8fa2717d9a7b08169daaf955d8a9c3ec9aa5 includes #6247 and changed ClinicalImpression.investigations.item from a closed reference list ending at RiskAssessment to a list that also included ImagingStudy. That was the applied source change for the seed issue, even though the Jira request named the older ImagingObjectSelection resource.

Additional context:
Later Patient Care decisions changed the relevant surface. FHIR-7185 introduced broad ClinicalImpression.supportingInfo as Reference(Any), FHIR-18860 then removed ClinicalImpression.investigation and clarified supportingInfo as the place that can contain investigation results, and FHIR-46596 renamed ClinicalImpression to ClinicalAssessment. Current source/fhir.ini no longer has an active ClinicalImpression or ClinicalAssessment resource entry after fad1b9cf84ef652e88947e1a13b026c62f95334e removed ClinicalAssessment from active build configuration, and source/ballot-intro.html points ClinicalAssessment to the PC incubator IG. The remaining core checkout ClinicalAssessment source is therefore out of current core build scope; if inspected, its supportingInfo is Reference(Resource), which does not exclude ImagingStudy or ImagingSelection.

AutoFHIR reconciliation:
This audit commit makes no source change. The seed's old choice-list request was historically applied, the specific ClinicalImpression.investigations.item element was superseded by supportingInfo, and the renamed ClinicalAssessment artifact is now outside the active core build.

Recommendation:
Keep this external-repo audit as-is for FHIR core. If Patient Care wants to revisit imaging references for ClinicalAssessment, do that in the PC incubator ClinicalAssessment source rather than reactivating or editing the stale core ClinicalImpression/ClinicalAssessment files.
