FHIR-48408: Clarify additional binding usage conjunction

Issue request:
FHIR-48408 is Applied/Persuasive for R6 and asks the specification to clarify the meaning of multiple ElementDefinition.binding.additional.usage repetitions. The accepted resolution says that when multiple usages are present, they all have to be true.

Initial application:
No prior local source application was found on the current branch or combined branch. The active ElementDefinition spreadsheet source still described how a usage context is determined but did not say whether multiple usage contexts are ANDed or ORed.

Additional context:
The linked Zulip discussion in #conformance agreed that multiple ElementDefinition.binding.additional.usage entries mean AND, and that OR semantics can be represented by multiple additional bindings with different usages. Terminology Infrastructure WGM minutes and agenda reference FHIR-48408 and defer to the ticket. Later additional-binding tickets found in search are either broader, unresolved, or not in this default applied/published source-edit scope.

AutoFHIR reconciliation:
Updated the active ElementDefinition spreadsheet source, source/datatypes/elementdefinition.xml, to state that when multiple usage contexts are specified, all of them apply and the contexts are combined with AND rather than OR.

Recommendation:
Keep this source fix as-is. It directly applies the approved clarification in the authoritative ElementDefinition source and does not attempt to resolve separate broader additional-binding modeling questions.
