FHIR-8874: Audit transaction request wording

Issue request:
FHIR-8874 was a Published/Persuasive DSTU1 correction against the Bundle transaction narrative. It reported that the transaction bundle description referred to a non-existent "transaction element" and said it should instead be the request element.

Initial application:
The issue was directly applied in git commit 078364522c266f4333e1fe044d95127faff99bec, matching Jira's svn revision 7179 comment. That commit replaced "transaction element" with "request element" in the Bundle history and transaction narrative and also renamed transactionResponse to response in the response narrative. A later same-family commit for FHIR-8881 corrected another nearby "transaction" element reference to "request".

Additional context:
Bundle is an active current-build resource in source/fhir.ini. The current Bundle transaction/batch narrative in source/bundle/bundle-notes.xml refers to a request element, not a transaction element, and Bundle invariant bdl-3c in source/bundle/structuredefinition-Bundle.xml requires transaction and batch entries to carry request details. The related FHIR-8881 audit is already represented on the combined branch and confirms that later decisions made entry.request mandatory for transaction/batch entries.
