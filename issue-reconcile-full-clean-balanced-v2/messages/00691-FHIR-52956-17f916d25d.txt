FHIR-52956: Audit removed Trial Use markers

Issue request:
FHIR-52956 was Applied/Persuasive for R6 and asked Patient Care to remove the Trial Use designation from AllergyIntolerance.type, AllergyIntolerance.reaction, Condition.stage, and Condition.evidence.

Initial application:
The issue was applied in b0795b968d8cfa56f4b734c40b63f80898a03542, which removed the per-element structuredefinition-standards-status=trial-use extensions from source/allergyintolerance/structuredefinition-AllergyIntolerance.xml and source/condition/structuredefinition-Condition.xml. The Jira comment links the same GitHub commit.

Additional context:
FHIR-36063 and FHIR-32478 explain the earlier 2022 decision to keep Condition.stage and Condition.evidence Trial Use when Condition was expected to become normative. The 2025 Patient Care WGM minutes document the later decision to remove Trial Use from all four elements because they had been available since DSTU releases and implemented by large EHRs. Both Condition and AllergyIntolerance are active resources in source/fhir.ini.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped source already has no per-element Trial Use standards-status extension on Condition.stage, Condition.evidence, AllergyIntolerance.type, or AllergyIntolerance.reaction.

Recommendation:
Keep this audit commit as-is. No follow-up source change is needed in FHIR core unless Patient Care later decides to reintroduce per-element standards-status exceptions.
