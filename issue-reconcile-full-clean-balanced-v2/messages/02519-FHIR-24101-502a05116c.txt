FHIR-24101: Audit MedicationKnowledge scope documentation

Issue request:
FHIR-24101 was Published/Not Persuasive with Modification for R5 after an STU3 comment said MedicationKnowledge was unclear about whether it served medication catalog/formulary use cases or a broader medication knowledge base, and asked for clearer resource intent and scope. The approved resolution did not require a wholesale redesign; it said the Medication module would be updated with additional content, including relationship information from the Medication, MedicationKnowledge, and IDMP boundary work, while noting that MedicationKnowledge already included many requested attributes and that some areas such as clinical trials were out of scope.

Initial application:
The only source-history commit explicitly mentioning FHIR-24101 is 2caba87573ebfebd34602aa26b0f072bd3b2b316, which changed a MedicationDispense status-reason value set description and does not apply the MedicationKnowledge scope resolution. The current correctness appears to come from later MedicationKnowledge and medication-definition work: 6422f2f98a0fcf03140c15fe93bfd6c765fc6377 removed the preliminary-review warning, clarified the MedicationKnowledge Scope and Usage text, and reorganized definitional elements; later medication-definition commits and the already-published FHIR-31736 reconciliation added and linked the Medication Definition relationship guidance and diagram.

Additional context:
MedicationKnowledge remains in current build scope through active fhir.ini entries. The current MedicationKnowledge introduction states that the resource supports creation and querying of medication information for formularies/catalogues, is more detailed than Medication for prescribing/dispensing/administering, and is not a complete MedicinalProductDefinition. The current structure includes formulary/catalogue information such as costs, monitoring programs, classification and packaging references, plus clinical/supporting content such as indications, dosing guidance, preparation, clinical issues, and storage guidance. The Medication Definition module contains the relationship-to-prescribing diagram and explains the boundaries between Medication and detailed product-definition resources; the Medications module now directs readers to that section. Related Jira FHIR-31736 and broader product-definition discussions refined the same boundary without creating a new FHIR-24101 source defect.
