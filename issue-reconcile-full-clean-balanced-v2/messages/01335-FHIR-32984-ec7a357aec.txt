FHIR-32984: Audit EvidenceVariable timeFromEvent supersession

Issue request:
FHIR-32984 was a Published CDS change request for R5, resolved Persuasive with Modification, asking to add EvidenceVariable.characteristic.timeFromEvent 0..* with description, event, quantity, range, and note children, and to bind the event element by example to Procedure Codes.

Initial application:
The Jira comment points to bac01125124ef5d906e86c9f6d75340772380ce2, which added EvidenceVariable.characteristic.timeFromEvent and its children to source/evidencevariable/structuredefinition-EvidenceVariable.xml, including the initial example binding to http://hl7.org/fhir/ValueSet/procedure-code. Later R5 history refined the timeFromEvent shape and descriptions, including changing event to event[x] and FHIR-38845's description cleanup.

Additional context:
The current R6 build still includes EvidenceVariable, but the characteristic backbone is no longer current. FHIR-42886 is Applied and explicitly removed EvidenceVariable.characteristic rather than deprecating it, replacing it with EvidenceVariable.definition and relying on Group as the preferred resource for characteristic combinations. The active source also includes RelativeTime as a core datatype and EvidenceVariable.timing as RelativeTime for event-relative observation timing; source/fhir.ini records the removed EvidenceVariable.characteristic.timeFromEvent paths under [r5-r6-changes], confirming they are prior-release paths rather than missing current-build elements.

AutoFHIR reconciliation:
This commit makes no source change. Re-adding EvidenceVariable.characteristic.timeFromEvent would restore an R5 element that a later final R6 decision intentionally removed, and the current source already carries event-relative timing through RelativeTime where appropriate.

Recommendation:
Keep this audit commit as-is for FHIR-32984. No core source follow-up is needed unless CDS or FHIR-I reopens the R6 EvidenceVariable/Group/RelativeTime modeling decision.
