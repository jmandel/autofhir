FHIR-27131: Audit inclusive subscription event count wording

Issue request:
FHIR-27131 was a Published/Persuasive R5 Subscription change request asking the Subscription Status text to say SubscriptionStatus.eventsSinceSubscriptionStart counts unique notification-triggering events inclusive of the current notification, rather than only prior to it.

Initial application:
The issue was initially applied by commit 798d44a3d77a03b78f80e45aff6b6187e236de71, which changed source/subscription/subscription-notes.xml from "PRIOR to the current notification" to "inclusive of the current notification." Later Subscription/SubscriptionStatus refactors moved the relevant explanatory text out of the old Subscription note and into the active SubscriptionStatus resource and notes.

Additional context:
source/fhir.ini lists subscription, subscriptionstatus, and subscriptiontopic as active resources, so the current SubscriptionStatus source is in build scope. The current SubscriptionStatus definition says eventsSinceSubscriptionStart is generated since the Subscription was created "inclusive of this notification," and the SubscriptionStatus Event Numbering notes say the value is inclusive of the current notification with the first event notification carrying one. The Subscriptions framework now links to the SubscriptionStatus Event Numbering section for tracking details rather than repeating the old local sentence. FHIR-I minutes for 2020-05-18 record the 12-0-0 persuasive vote, and later Zulip subscription discussion confirmed the same interpretation while discussing event counter accuracy.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active source already conveys the requested inclusive semantics and no remaining active source text was found that says the count is only prior to the current notification.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-27131 unless the work group wants a broader redesign of SubscriptionStatus event-numbering guidance beyond this resolved inclusive-count wording.
