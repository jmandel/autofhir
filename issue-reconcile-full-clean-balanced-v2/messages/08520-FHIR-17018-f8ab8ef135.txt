FHIR-17018: Audit BackboneElement definitions tab

Issue request:
FHIR-17018 is a Published/Persuasive FHIR-core STU3 technical correction asking that the BackboneElement "Definitions" tab lead to BackboneElement definitions rather than Element definitions. The issue was auto-approved, and the only Jira comment says to see task FHIR-16877.

Initial application:
No current git commit explicitly mentions FHIR-17018. The practical application path is the same BackboneElement definitions-page defect tracked by FHIR-16877: historical commit 22d5233b31f33ae541736868584dea6fc8790a50, GF#16877, changed the old source/backboneelement-definitions.html page from the Element header and <%dictionary Element%> to the BackboneElement header and <%dictionary BackboneElement%>. That commit also matches the svn revision recorded on FHIR-16877, the issue FHIR-17018 points to.

Additional context:
The old standalone source/backboneelement-definitions.html input no longer exists in the current source after later type-framework refactors. BackboneElement remains in current build scope because source/fhir.ini lists it as an active abstract infrastructure type, maps backboneelement to the shared types page, marks BackboneElement normative, and gives it a TLA entry. Current source/types.html links the BackboneElement Detailed Descriptions tab to types-definitions.html#BackboneElement, and source/types-definitions.html renders <%dictionary BackboneElement%> at the BackboneElement anchor. Related FHIR-16877, FHIR-17020, and FHIR-17204 are already represented on the combined branch, so they should not receive duplicate commits here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build source already routes BackboneElement detailed descriptions to the BackboneElement dictionary rather than the Element dictionary, so the wrong Definitions-tab target reported by FHIR-17018 is no longer present.

Recommendation:
Keep this audit commit as-is. No follow-up is needed unless a generated build reintroduces BackboneElement page links to Element definitions or otherwise stops rendering the BackboneElement dictionary at the BackboneElement detailed-description anchor.
