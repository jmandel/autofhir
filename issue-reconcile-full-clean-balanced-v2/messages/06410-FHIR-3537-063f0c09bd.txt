FHIR-3537: Audit CarePlan component rename

Issue request:
FHIR-3537 was Published/Persuasive for DSTU1. It asked Patient Care to rename old CarePlan activity components: activity.detail to activity.reference, the inline class simple to detail, and simple.details to details.note.

Initial application:
The historical application is the 2015 git-svn commit db4ace37c6615c9732f958d34d6286fe739fc657, which explicitly lists {#3537} among PC-approved CarePlan change requests. In source/careplan/careplan-spreadsheet.xml that commit introduced CarePlan.activity.reference, CarePlan.activity.detail, and CarePlan.activity.detail.note, replacing the old simple/detail naming family requested by the issue. No later Jira-keyed FHIR-3537 commit exists in the current XML-source era because CarePlan source was subsequently refactored and remodeled.

Additional context:
CarePlan remains active in source/fhir.ini. Later published Patient Care decisions changed the same activity model: FHIR-26064 renamed activity.reference to plannedActivityReference and activity.detail to plannedActivityDetail, and FHIR-39101 then removed the active plannedActivityDetail inline backbone in favor of plannedActivityReference. Current CarePlan source has active activity children performedActivity, progress, and plannedActivityReference, with no active activity.reference, activity.detail, activity.simple, or activity.detail.note element after XML comments are excluded. The current fhir.ini version maps still preserve legacy activity.detail and activity.reference mappings to plannedActivityReference.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original rename was applied historically, and the current build is already correct after later approved CarePlan remodels. Reintroducing the DSTU1 target names or editing the commented-out historical plannedActivityDetail block would make the current specification less accurate.

Recommendation:
Keep this audit commit as-is. If Patient Care wants to change the current performedActivity/progress/plannedActivityReference model, that should be handled as a new current-version CarePlan decision, not as pending work for FHIR-3537.
