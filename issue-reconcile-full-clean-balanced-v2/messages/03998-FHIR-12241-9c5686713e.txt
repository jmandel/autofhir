FHIR-12241: Audit Coverage subscriberId separation

Issue request:
FHIR-12241 was a Published/Persuasive Financial Management change request raised against DSTU2/STU3 Coverage asking that the insurance subscriber/member number remain a distinct Coverage.subscriberId instead of being folded only into Coverage.identifier, where multiple identifiers make the card number hard to recover.

Initial application:
No git commit explicitly mentioning FHIR-12241 was found. Commit 43806174288e821cb06173a72cde96317186412b on 2016-11-17 reintroduced Coverage.subscriberId as a separate 0..1 string element in the Coverage spreadsheet source and removed "Subscriber Id" from the Coverage.identifier definition, matching the requested separation even though the commit message listed neighboring tracker numbers rather than this key.

Additional context:
FHIR-24638 later changed Coverage.subscriberId from string to Identifier, and FHIR-24688 later changed its cardinality from 0..1 to 0..*. Both later Published Coverage subscriberId issues are already represented on the combined branch with source-fixing AutoFHIR commits for stale model-definition metadata. Coverage is an active resource in source/fhir.ini, and the remaining differences from the DSTU2-era element shape are therefore intentional later decisions rather than missed application of FHIR-12241.

AutoFHIR reconciliation:
Made no source change. The current active Coverage source already keeps Coverage.subscriberId separate from Coverage.identifier: the StructureDefinition defines Coverage.subscriberId as Identifier [0..*], the Coverage search parameter bundle exposes token search code subscriberid on Coverage.subscriberId, Coverage examples populate subscriberId, and the model-definition Library exposes subscriberId as a repeating FHIR.Identifier.

Recommendation:
Keep this audit commit as-is. Reverting subscriberId to a scalar string or 0..1 would conflict with later Published decisions; any future concern should be tracked as a new wording issue rather than as incomplete application of FHIR-12241.
