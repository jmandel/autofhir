FHIR-7738: Audit MedicationRequest reason examples

Issue request:
FHIR-7738 was a Published/Persuasive DSTU1 Pharmacy change request for MedicationPrescription asking whether an example should be provided for the reason CodeableConcept. The accepted resolution was to add a coded reason to MedicationOrder examples.

Initial application:
No source-history commit explicitly tagged FHIR-7738 was found. The closest application trail is the June 2016 MedicationOrder example refresh, which added and documented many MedicationOrder examples containing reasonCode/coded reason content, followed by the October 2016 MedicationOrder-to-MedicationRequest rename and later resource/example refactors.

Additional context:
MedicationPrescription/MedicationOrder are no longer active current-build resources; source/fhir.ini lists MedicationRequest as the active resource and records that MedicationPrescription became MedicationRequest. Later MedicationRequest modeling changed reasonCode/reasonReference into MedicationRequest.reason CodeableReference, but the current examples still include coded reasons through reason.concept and the example list labels multiple coded-reason examples.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build-scoped MedicationRequest source already satisfies the historical request by including coded reason examples, such as a SNOMED CT reason.concept in medicationrequest0315.xml and other MedicationRequest examples, so adding another example would be redundant rather than corrective.

Recommendation:
Keep this no-change audit as-is. No core source follow-up is needed for FHIR-7738 unless the Pharmacy WG wants a new, separate R6-era example policy change beyond the original DSTU1 request.
