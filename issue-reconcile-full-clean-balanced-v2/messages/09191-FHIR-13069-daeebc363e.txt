FHIR-13069: Audit TestReport.result modifier status

Issue request:
FHIR-13069 was a Published/Persuasive FHIR-core change request from the FHIR-I work group asking that TestReport.result not be marked as a modifier.

Initial application:
The issue was applied in SVN revision 11657, represented in git by ab71ec01b1390c074d264329c817d8b4341b6ebb, which removed the Is Modifier value from TestReport.result in the TestReport spreadsheet source. The Jira comment records the same SVN revision. The last core TestReport StructureDefinition before testing resources were removed shows TestReport.result without isModifier or isModifierReason.

Additional context:
A March 2017 FMG Zulip approval thread records +1 votes for GF#13069, and the broader isModifier review thread explicitly listed TestReport.result among elements that should not be modifiers. Current core no longer has active source/testreport resource definitions: source/fhir.ini no longer lists testreport in [resources] and instead points to the external HL7 FHIR testing IG. The current testing IG JSON for StructureDefinition/TestReport also has TestReport.result with no isModifier or isModifierReason.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested modifier removal is already represented in the historical core source, and the current authoritative TestReport definition is outside this core checkout and remains consistent with the issue.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-13069 unless TestReport is brought back into the core build or the external testing IG later reintroduces an isModifier flag on TestReport.result.
