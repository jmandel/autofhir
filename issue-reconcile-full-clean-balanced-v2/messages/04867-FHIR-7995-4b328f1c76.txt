FHIR-7995: Audit medication code support

Issue request:
FHIR-7995 was a Published Pharmacy change request with resolution Persuasive with Modification. It asked to allow a CodeableConcept in addition to a Medication reference for MedicationStatement because recording only a medication code is common; its resolution says to make medicationPrescription, medicationStatement, medicationAdministration, and medicationDispense support either a code or the full Medication resource, and notes it was approved as a duplicate of FHIR-7473.

Initial application:
No current git commit was found whose message explicitly mentions FHIR-7995 or FHIR-7473. The Jira comments say the work was already done, and history shows 2015-era medication spreadsheet changes adding medicationCodeableConcept/code search support near medicationReference handling.

Additional context:
MedicationPrescription is now MedicationRequest. The active current build includes MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement in source/fhir.ini. Current StructureDefinition XML represents each requested medication element as CodeableReference targeting Medication, with definitions/comments explaining the code-only and referenced-Medication alternatives. Later R5 work temporarily renamed MedicationStatement to MedicationUsage, but FHIR-38682 restored the MedicationStatement name while recording that the resource scope had not changed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies FHIR-7995 by using CodeableReference(Medication) for all four medication resources named in the resolution.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-7995 unless Pharmacy later decides to change the modern CodeableReference medication pattern.
