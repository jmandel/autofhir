FHIR-12393: Audit Medication manufacturer clarification

Issue request:
FHIR-12393 is a Published/Not Persuasive with Modification FHIR-core Medication issue from DSTU2. It asked Pharmacy to clarify Medication.manufacturer because the old definition, "Describes the details of the manufacturer," did not distinguish the medication manufacturer from distributors, sponsors, or jurisdictional registration holders. The accepted resolution said the element meant the manufacturer of the medication and not the distributor, and that both description and definition needed clearer wording.

Initial application:
The Jira comments record that Melva Peters added clarification that manufacturer was not intended to represent the distributor, and link SVN/git commit b0500f8b520d72851aba346483f21d1ded9a86b3. That commit's subject appears to typo the tracker number as TR 12392, but the patch changed the Medication manufacturer definition to "Describes the details of the manufacturer of the medication product. This is not intended to represent the distributor of a medication product," matching FHIR-12393's request.

Additional context:
Medication is active in the current build through source/fhir.ini, but the current active Medication source no longer has Medication.manufacturer. Later Pharmacy issue FHIR-27030 renamed the element to Medication.sponsor, FHIR-32759 then renamed it to Medication.marketingAuthorizationHolder, and FHIR-35858 corrected the MAH definition because it still described manufacturer. Current fhir.ini maps old Medication.manufacturer to Medication.marketingAuthorizationHolder for version conversion, and current Medication source plus search parameters use marketingAuthorizationHolder. A direct FHIR-12393 community search found only the tracker bot announcement and no conflicting Confluence references; the later FHIR-27030 Zulip thread documents the same manufacturer/sponsor/MAH ambiguity and supports treating the current MAH model as intentional.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical clarification was applied to the old manufacturer element, and the current build-scope source has moved beyond that element to the later approved MAH wording. Adding the old "not distributor" manufacturer clarification to the current MAH element would reintroduce manufacturer-centered semantics that FHIR-35858 explicitly corrected.

Recommendation:
Keep this no-change audit commit. No FHIR core source edit is recommended for FHIR-12393; future physical-manufacturer representation concerns should follow the later manufacturer-extension work rather than changing Medication.marketingAuthorizationHolder for this DSTU2 clarification.
