FHIR-51608: Audit compartment search URL clarification

Issue request:
FHIR-51608 was Applied as Persuasive with Modification for R6. It asked the core HTTP, Search, and CompartmentDefinition guidance to clarify that compartment-qualified URLs are a search view, not an alternate resource identity: search bundles should use native, non-compartment-specific full URLs, returned references should not be rewritten through the compartment path, and only search is defined as a compartment interaction while operations through compartment-qualified links are not defined.

Initial application:
The current source already contains the requested changes. Source commit 7737bfeea16cc151563f253dfa404f58eacc9a5f, later merged through PR #3967 by merge commit 2ec3e732369b18cd589904205b73b4237f850e82, updated source/compartmentdefinition/compartmentdefinition-notes.xml, source/http.html, and source/search.html for FHIR-51608. That application commit did not include an Issue-Reconcile-Key trailer, so this reconciliation publishes a parseable audit record instead of duplicating the source changes.

Additional context:
FHIR-I minutes from 2025-08-18 record the work group continuing FHIR-51608 from the prior week, adding search-page guidance, HTTP examples and links, a Compartment Interactions row in the HTTP introduction, and a note that operations via a compartment are not defined; the motion passed Persuasive with Modification 13-0-0. The 2025-08-11 minutes show the issue was deferred to the following week. The edited files are in current build scope: source/fhir.ini has an active CompartmentDefinition resource entry, and http.html and search.html are the core REST and Search pages referenced by the issue.

AutoFHIR reconciliation:
This empty audit commit makes no source changes because the combined branch already has the necessary source text: CompartmentDefinition says compartment search outcomes match equivalent system/type searches with non-compartment-specific full URLs and only search is defined at compartment endpoints; HTTP lists compartment search as the only compartment interaction and links to Search and Compartments; Search Contexts says fullUrls and returned references are not rewritten into compartment paths.

Recommendation:
Keep this audit commit as-is. No additional core source change is recommended for FHIR-51608 unless FHIR-I later decides to further constrain optional server-specific behavior for compartment-qualified operation URLs.
