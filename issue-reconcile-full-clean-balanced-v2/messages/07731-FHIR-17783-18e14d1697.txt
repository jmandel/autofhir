FHIR-17783: Audit oxygen saturation profile summary

Issue request:
FHIR-17783 was a Published/Persuasive OO change request for FHIR-core Observation raised in STU3. It reported that the oxygenSat Observation profile page looked confused with head circumference and the accepted resolution was to fix the summary file, identifying the problem as a cut-and-paste error.

Initial application:
The Jira comment points to commit 98752dd6c14e0ad544430fd0d7457f25282173d0. That commit changed the historical oxygen saturation vitals profile spreadsheet summary from the head-circumference LOINC code 9843-4 and UCUM length units cm/[in_i] to the oxygen saturation LOINC code 2708-6 and UCUM percent unit. The old spreadsheet source no longer exists in the current branch after later vital-sign profile refactors.

Additional context:
The current build-scoped source keeps the oxygen saturation profile in source/observation/structuredefinition-profile-oxygensat.xml, with source/observation/implementationguide-Observation-vitalsigns.xml referencing StructureDefinition/oxygensat and source/fhir.ini listing Observation as an active resource. Later vital-sign profile refactors preserved the correct oxygen saturation code, value sets, and summary wording. Jira neighborhood search only surfaced the seed and a broader older vital-sign alignment issue, and no directly relevant Zulip or Confluence evidence was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current oxygen saturation profile summary, code constraint, and unit binding already use oxygen saturation values, and targeted searches found no head-circumference/body-length remnants in the oxygen saturation profile or its value sets.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed unless a future rendered build diverges from the checked source profile.
