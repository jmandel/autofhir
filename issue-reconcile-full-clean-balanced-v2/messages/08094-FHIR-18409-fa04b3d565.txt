FHIR-18409: Audit modifierExtension descendant wording

Issue request:
FHIR-18409 was a Published/Persuasive FHIR-I change request for FHIR-core DomainResource, raised against STU3, asking that the DomainResource.modifierExtension definition append "and/or the understanding of the containing element's descendants" after the existing wording about modifying the understanding of the containing element.

Initial application:
The issue was initially applied by git commit 9507ff17d7 ("GF#18409 - clarification about modification"), which changed the then-authoritative DomainResource spreadsheet and BackboneElement spreadsheet modifierExtension definitions to include the descendant-impact wording. The current source no longer uses source/domainresource/domainresource-spreadsheet.xml, but commit 33b409a4b6 converted DomainResource to source/domainresource/structuredefinition-DomainResource.xml while preserving the requested wording.

Additional context:
source/fhir.ini lists domainresource as an active abstract infrastructure resource, and the current StructureDefinition contains the requested descendant-impact wording on DomainResource.modifierExtension. The active BackboneElement and BackboneType type definitions also contain the descendant wording. A later DomainResource issue, FHIR-27916, touched the same line only as part of fixing dom-3/apostrophe escaping and did not reverse or narrow FHIR-18409. The only remaining old "element that contains it" wording found was in source/profiles/cda.profile.xml, whose fhir.ini entry is commented out, so it is not an in-build core correction for this seed.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit was made because the current build-scope source already implements the Published FHIR-18409 decision, and adding redundant prose or editing an out-of-build CDA profile would not improve the current specification.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-18409 unless the work group decides to revisit modifierExtension semantics more broadly; the current active source already conveys that modifier extensions can affect the containing element's descendants.
