FHIR-12950: Audit MeasureReport calculation wording

Issue request:
FHIR-12950 was a Published/Persuasive CQI change request for the MeasureReport resource, raised against DSTU2. It asked to clarify wording that described MeasureReport as evaluating a measure or only referencing the measure, with the final resolution replacing that phrasing with calculation-oriented text for the resource and MeasureReport.measure.

Initial application:
The issue was applied in SVN 13336, represented in git as 09671045938ee85e38a331e9fac9927ca8c01cae, with the commit message "GF#12950: Clarified language defining MeasureReport." That commit changed the MeasureReport introduction from evaluating to calculating a measure, changed the resource definition to describe calculation results and resources involved in the calculation, and changed MeasureReport.measure from the measure evaluated to the measure calculated.

Additional context:
MeasureReport is active in the current build through source/fhir.ini, and the authoritative current StructureDefinition and introduction preserve the requested calculation wording. Later MeasureReport issues, including FHIR-17273 and FHIR-34033, refined evaluatedResource semantics and did not reverse the FHIR-12950 clarification; FHIR-34033 is already represented on the combined branch. Community searches found only tracker/commit bot notifications for this key and no substantive Zulip or Confluence discussion changing the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit makes no source change. The current MeasureReport StructureDefinition says the resource contains results of calculation of a measure and optional references to resources involved in that calculation, MeasureReport.measure is the measure calculated, and the MeasureReport introduction and Measure $evaluate operation text use calculation-oriented wording for subjects.

Recommendation:
Keep this no-change audit. The historical application remains present in active current source, and adding further wording would be redundant rather than a necessary correction.
