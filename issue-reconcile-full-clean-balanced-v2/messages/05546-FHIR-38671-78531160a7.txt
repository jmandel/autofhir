FHIR-38671: Audit TestScript manual assertion migration

Issue request:
FHIR-38671 was a Published FHIR-core change request for TestScript, resolved Persuasive with Modification for R5. It asked for support for manual operations or assertions outside test-engine control, with the final resolution adding manualEval support and defaultManualCompletion behavior.

Initial application:
The request was applied in core by commit ef97bb4874ab7f0db48f039a7fb04e1de5fca230 on 2023-01-12. That commit added the assert-manual-completion code system and value set, added manualEval to assert-operator-codes, and added TestScript.setup.action.assert.defaultManualCompletion with a required binding and meaningWhenMissing text. The commit is included in the v5.0.0 tag.

Additional context:
FHIR-I minutes first assigned Richard Ettema to write the detailed proposal on 2022-12-12, then recorded the 2023-01-09 vote to add manualEval and defaultManualCompletion. Current core no longer owns TestScript source: commit f9a44787c45071394532c7c2ee94d76f30f47387 removed the testing resources from source/fhir.ini and deleted source/testscript while adding the Testing FHIR IG as an additional IG. Current core pages link to the Testing IG, and the current Testing IG package contains manualEval, defaultManualCompletion, and the fail/pass/skip/stop completion codes.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source change is appropriate because TestScript is outside the current core build, and the requested manual assertion semantics are present in the current external Testing IG artifact.

Recommendation:
Keep this audit commit as-is. Future changes to TestScript manual assertion behavior should be made in the source for the Testing FHIR IG, not by restoring or editing retired core TestScript source; revisit core only if its links to the Testing IG become stale or misleading.
