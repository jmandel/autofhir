FHIR-14337: Audit retired OccupationalData addition

Issue request:
FHIR-14337 was Published/Persuasive for FHIR core and asked to add the OccupationalData resource per the Occupational Data for Health proposal. Jira records the resource as pre-applied in December 2017, raised in STU3, and applied for R5.

Initial application:
The request was applied before this reconciliation: fa656ae1d9 added the draft OccupationalData resource stub, 43bb1f0626 completed the initial build, and later GF#14337 commits updated the structure, examples, and documentation. The current source still retains inactive source/occupationaldata draft files from that work.

Additional context:
Later final decisions reversed the resource-addition direction. FHIR-16930 was Published/Persuasive and says the work group agreed to withdraw OccupationalData because the content should be met through questionnaires, logical models, and principally Observations; FHIR-14868 reached the same conclusion and points to FHIR-16930. Git commit efef182022 removed OccupationalData from active fhir.ini resource/workgroup/status mappings under GF#16930, and the combined branch already contains 9ee22091, which removed the remaining current Resource Guide link for FHIR-16930. Zulip discussion after withdrawal likewise says the resource was retired and replaced by Observation profiles and an ODH IG.

AutoFHIR reconciliation:
This commit intentionally makes no source change for FHIR-14337. On the target combined branch, OccupationalData is not an active resource in source/fhir.ini, the only fhir.ini mention is the dropped-resource note, and there are no current non-history/non-dormant source references presenting OccupationalData as an available core resource. Restoring the resource would contradict the later published withdrawal decision.

Recommendation:
Keep this audit commit as-is. Do not re-add OccupationalData to core for FHIR-14337; any future occupational data work should proceed through the ODH profiles/IG or a new work-group decision, not by reviving this superseded draft resource request.
