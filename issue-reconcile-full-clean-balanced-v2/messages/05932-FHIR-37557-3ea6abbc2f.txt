FHIR-37557: Audit display extension name

Issue request:
FHIR-37557 was a Published FHIR-core change request for the R4 display extension. It asked to repair the invalid StructureDefinition display name, suggesting a new id/url as well, but the final Persuasive with Modification resolution was narrower: change name to "DisplayName", add title "Display Name", and leave the id and canonical URL unchanged for inter-version compatibility.

Initial application:
The issue was applied in core by commit 06b1575fe5ad2babe3fee7bb9b856428dd51bdb2, which changed the display extension row in source/profiles/general-extensions-spreadsheet.xml from name "Display Name" with no title to name "DisplayName" and title "Display Name" while keeping the row id as display. No separate source application is needed now.

Additional context:
The core source later removed extension definitions from the R5 source tree in commit dd468d4f1799dd79819315b211588ef1cf4586e0. The active core fhir.ini still references the general extensions spreadsheet for current core-owned extensions, but the display extension row is no longer present there. The current authoritative extension definition is in the FHIR Extension Pack checkout, where id="display", url="http://hl7.org/fhir/StructureDefinition/display", name="DisplayName", and title="Display Name" all match the Jira resolution. Zulip discussion and FHIR-I minutes both support preserving the existing canonical URL while fixing name/title.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the core checkout. The current core build no longer owns the display extension definition, and the extension-pack source already carries the corrected name/title with the unchanged id/url required by the final resolution.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed unless the display extension is reintroduced into core or the extension-pack definition regresses from the resolved name/title and canonical URL values.
