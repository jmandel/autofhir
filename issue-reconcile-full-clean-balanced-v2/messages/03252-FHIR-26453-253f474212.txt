FHIR-26453: Add Ingredient strength text to ModelInfo

Issue request:
FHIR-26453 was Published/Persuasive for the BR&R MedicinalProductIngredient/Ingredient model. It requested text expressions of strength for both the presentation and concentration forms, in addition to the structured strength representation, because some real-world strengths are too complex or too legacy-textual for a simple ratio.

Initial application:
The Jira-tagged application commit 35630a55b9 added Ingredient.specifiedSubstance.strength.presentationText and concentrationText to the old Ingredient spreadsheet. Later source refactors moved Ingredient into source/ingredient/structuredefinition-Ingredient.xml, where the current active StructureDefinition already contains the requested text strength elements as Ingredient.substance.strength.textPresentation and textConcentration. The remaining omission found during reconciliation was the active FHIR ModelInfo Library example, which still listed MedicinalProductIngredient.Strength without corresponding text strength properties.

Additional context:
FHIR-36687 later determined that presentationText and concentrationText were invalid peer names beside presentation[x] and concentration[x], and renamed them to textPresentation and textConcentration without changing the meaning. source/fhir.ini keeps Ingredient and Library active in the current build, maps MedicinalProductIngredient to Ingredient, and source/library/list-Library-examples.xml includes Library/FHIR-ModelInfo as the FHIR ModelInfo example. The embedded Library data in source/library/library-fhir-model-definition.xml matched source/library/library-fhir-model-definition-content.xml before this edit, so both files needed to be synchronized. Direct Zulip and Confluence searches for FHIR-26453 and the strength-text terms found no conflicting community guidance.

AutoFHIR reconciliation:
Added textPresentation and textConcentration as FHIR.string elements to MedicinalProductIngredient.Strength in source/library/library-fhir-model-definition-content.xml, and regenerated the embedded base64 data in source/library/library-fhir-model-definition.xml so the Library resource and linked XML content stay aligned. No Ingredient StructureDefinition edit was needed because the authoritative resource definition already carries the current renamed text elements.

Recommendation:
Keep this commit as-is. It completes FHIR-26453 on the current build's parallel ModelInfo surface while preserving the FHIR-36687 element names; do not restore the original presentationText/concentrationText names.
