FHIR-11194: Audit BodySite qualifier rename

Issue request:
FHIR-11194 is a Published/Persuasive OO change request for DSTU2 BodySite asking to rename BodySite.modifier to BodySite.qualifier because laterality and relative-location details qualify/refine the anatomical location rather than acting as FHIR modifier elements.

Initial application:
The rename appears to have been applied before this reconciliation in git commit 29f4601440af8375fc9f1e19f0d38727cd29aec4, which changed the BodySite spreadsheet source from BodySite.modifier/BodySiteModifier/"Modifier" wording to BodySite.qualifier/BodySiteQualifier/"Qualifier" wording. No explicit FHIR-11194 grep hit exists in current commit subjects because the historical commit used the older issue-number style [#11194].

Additional context:
BodySite is no longer an active current-build resource: source/fhir.ini lists bodystructure=BodyStructure under [resources] and BodySite under [removed-resources], with a note that BodySite became BodyStructure. Jira FHIR-13396 and commit 386071a8e535114ff8df5ae7611b966cf354b3cb later renamed BodySite to BodyStructure. The current active BodyStructure definition uses BodyStructure.includedStructure.qualifier, and the only current non-history BodySite.modifier occurrence is the intentional old-to-new conversion map BodySite.modifier=BodySite.qualifier in source/fhir.ini.

AutoFHIR reconciliation:
This audit commit makes no source change because the requested element rename is already represented in the historical BodySite source application, preserved in the version-conversion map, and carried forward into the current active BodyStructure qualifier element.

Recommendation:
Keep this audit commit as-is. Do not reintroduce a BodySite source edit in the current build; if future work revisits anatomical-location modeling, handle it under the current BodyStructure resource rather than this already-applied DSTU2 rename.
