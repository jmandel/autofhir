FHIR-38908: Include clinical research in AdverseEvent category text

Issue request:
FHIR-38908 was an Applied/Persuasive Patient Care change request for FHIR-core AdverseEvent. The final resolution was to add code "clinical-research" to the adverse-event category value set with definition "The adverse event pertains to clinical research."

Initial application:
No FHIR-core commit tagged FHIR-38908 or UP-597 was found in the AdverseEvent source history. The terminology change was applied through UTG as UP-597, and THO 6.5.0 now contains the clinical-research code in CodeSystem-adverse-event-category. The remaining core source still carried the old category example list in AdverseEvent.category and the generated AdverseEvent category SearchParameter description.

Additional context:
AdverseEvent is active in the current build via source/fhir.ini, and the category value set in source/adverseevent/valueset-adverse-event-category.xml includes all codes from http://terminology.hl7.org/CodeSystem/adverse-event-category. Because the authoritative code system is external THO content, this reconciliation does not duplicate the code definition in core; it only aligns the core element/search-parameter summary text with the now-implemented terminology.

AutoFHIR reconciliation:
Updated source/adverseevent/structuredefinition-AdverseEvent.xml and source/adverseevent/bundle-AdverseEvent-search-params.xml so the category example list includes clinical-research ahead of the existing THO category codes.

Recommendation:
Keep this source fix. The external terminology source already contains the new code, and these two core source fields were the only current AdverseEvent build inputs found with the stale category example list.
