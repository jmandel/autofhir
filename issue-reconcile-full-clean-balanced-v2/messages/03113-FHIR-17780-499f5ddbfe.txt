FHIR-17780: Audit FamilyMemberHistory sex rename

Issue request:
FHIR-17780 was a Published Patient Care change request from the STU3 cycle asking to resolve the mismatch between the FamilyMemberHistory element name "gender" and a definition that described sex. The final persuasive-with-modification resolution renamed FamilyMemberHistory.gender to FamilyMemberHistory.sex, kept the existing binding/code system/value set approach, and updated the comment and requirements wording to use sex/genetic sex language.

Initial application:
The Jira comment records GitHub commit 04c4d675c5f4. That commit renamed the spreadsheet element and example XML from gender to sex and added the requested definition, comment, and requirements wording. A later cleanup commit, 984e2972b7e7, fixed the FamilyMemberHistory search parameter from gender to sex. The 2021 source rework converted the resource source into structuredefinition-FamilyMemberHistory.xml while preserving the sex element and wording.

Additional context:
FamilyMemberHistory is active in source/fhir.ini, so source/familymemberhistory/structuredefinition-FamilyMemberHistory.xml and the FamilyMemberHistory search-parameter bundle are current build inputs. Current source contains FamilyMemberHistory.sex, the requested comment and requirements text, a sex search parameter, and no remaining FamilyMemberHistory.gender source references in the active FamilyMemberHistory directory. Related FHIR-18850 is already represented on the combined branch and supports the administrative-gender binding context. Later FHIR-43360 resolved no-change and confirmed Patient Care still wanted the element named sex. Later FHIR-55021 is a separate R6 Resolved-change-required follow-up to revise the sex element definition/binding and add explanatory text; it is not yet Applied/Published and should be handled under its own issue, not by altering the already-applied FHIR-17780 reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already reflects the FHIR-17780 rename and wording, and changing it now would either be redundant or would improperly apply the later FHIR-55021 work outside this applied/published seed scope.

Recommendation:
Keep this audit commit as-is for FHIR-17780. Treat FHIR-55021 as the appropriate follow-up if the R6 sex/gender wording and binding update is to be applied; do not reopen FHIR-17780 for that newer scope.
