FHIR-7556: Audit ValueSet filter table cleanup

Issue request:
FHIR-7556 was a Published/Persuasive Vocab change request against the DSTU1 ValueSet page, reporting that the table in 2015May section 6.21.7.1 was missing data or not formatted properly. The accepted resolution was to tidy the table up.

Initial application:
The issue was applied in SVN revision 5678, represented in git as c138c5bb380395b868c5a7337421d5225f2175a1. That commit edited source/valueset/valueset-notes.xml by removing the broken separator row, adding the missing external code system links, and adding the HL7 v2 table row showing that no filters were defined.

Additional context:
The current build no longer uses the 2015May table as the authoritative representation. ValueSet and CodeSystem are active resources in source/fhir.ini. Later Published Vocab decisions changed the surrounding model: FHIR-10221 moved generic filter definitions into the active CodeSystem notes; FHIR-31938 removed NCI Metathesaurus because it is not a code system; and FHIR-35933 migrated external "Using X with FHIR" pages to HL7 Terminology, leaving current ValueSet notes to point to CodeSystem filters and THO pages. Current source/terminologies-systems.html still links UNII, NDC, CVX, and other external systems to THO guidance, and current source/codesystem/codesystem-notes.xml contains the base and is-a filter tables.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original malformed/missing table entries were applied historically, and re-adding the old DSTU1 table or its removed links would conflict with later final decisions that centralized filters in CodeSystem and external terminology guidance in THO.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-7556 unless the Vocabulary work group opens a new issue to change the current THO-linked external terminology guidance.
