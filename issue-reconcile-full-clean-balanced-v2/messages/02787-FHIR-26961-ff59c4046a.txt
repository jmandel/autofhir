FHIR-26961: Audit Appointment insurance guidance

Issue request:
FHIR-26961 was an Applied PA change request asking whether the request-insurance standard extension should apply to Appointment. The final Not Persuasive with Modification resolution rejected adding Appointment as an extension context because the extension was not well-defined enough for Appointment coverage details, and instead directed the spec to remove request-insurance from core use and add Appointment narrative guidance for expected coverages and prior authorization.

Initial application:

Current core source retains the historical request-insurance OID but no active core StructureDefinition or extension page reference was found outside generated history, while the active Appointment resource remains build-scoped in source/fhir.ini.

Additional context:
FHIR-26526 started the broader review of request-related extensions and specifically spawned the Appointment insurance follow-up. FHIR-I minutes first sent the context question back to PA, PA minutes record the later decision to describe insurance/prior-auth handling in Appointment notes, and the FHIR Extension Pack now carries request-insurance for NutritionOrder and CarePlan without Appointment as a context.
