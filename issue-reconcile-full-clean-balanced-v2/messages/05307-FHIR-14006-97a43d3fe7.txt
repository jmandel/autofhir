FHIR-14006: Audit SNOMED ECL implicit value set URI

Issue request:
FHIR-14006 was Published/Persuasive with Modification for STU3. It asked to add SNOMED CT implicit ValueSet URIs for Expression Constraint Language expressions, specifically ?fhir_vs=ecl/[expression], and to document the corresponding ValueSet template using the SNOMED CT constraint filter.

Initial application:
The feature was first pre-applied in SVN r12747, now git commit 5557727253b532ee80752365259b8a112524f386, but that initial application used the variant ?fhir_vs=ecl:[ecl] and had template wording copied from the reference-set form. The FHIR-14006/FHIR-14359 correction was pre-applied in SVN r13310, now git commit 9fe99d788004f20048165682a9ff7d64bc23c01d, which updated source/snomedct.html to ?fhir_vs=ecl/[ecl] and fixed the ECL template URL, name, description, and text.

Additional context:
FHIR-14010 is the same change family and requested adding an ECL query value to the SNOMED CT implicit value set list. FHIR-14359 corrected the separator to align with existing implicit URI formats and is already represented on the combined branch by commit ad4f9523d27a3c8343fda97ff57ee40e38418095. Vocab minutes from 2018-02-22 list FHIR-14006 and related FHIR-14359 in a block vote that carried 7-0-0, and the related Zulip thread supports the slash separator. FHIR-35933 later removed the old external terminology detail pages from FHIR core and changed source/terminologies-systems.html to link to THO's SNOMED CT guidance. The current THO page linked from core, https://terminology.hl7.org/en/SNOMEDCT.html, still documents ?fhir_vs=ecl/[ecl] and the ECL template.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested URI and template were applied and corrected in the historical core source, then moved out of current core build scope by the later THO migration. Current FHIR core correctly links to the maintained THO guidance, and that guidance already contains the FHIR-14006 ECL implicit ValueSet syntax.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core source follow-up is needed for FHIR-14006. Future changes to SNOMED CT implicit ValueSet guidance should be made in THO/UTG rather than reintroducing source/snomedct.html to core.
