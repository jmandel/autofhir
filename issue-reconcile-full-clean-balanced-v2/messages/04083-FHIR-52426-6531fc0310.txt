Additional context:
The related committers Zulip thread records the policy reason: a core code element with a required binding should not depend on extension-pack terminology. FHIR-I minutes for 2025-09-22 record the same decision: the code system and value set need to move to core and the URL remains the same, so this is not breaking. The Extension Pack still carries copies for extension use, marked as R6-sourced terminology, but the core checkout has the authoritative R6 source files.

This audit commit makes no source change. The current FHIR core source already includes the synchronicity CodeSystem and ValueSet beside the active OperationDefinition resource, satisfying the source-side requirement of FHIR-52426.
