FHIR-12696: Audit historical DSTU2 IG publisher fix

Issue request:
FHIR-12696 was a Published/Persuasive DSTU2 FHIR-core tooling issue reporting spurious IG Publisher QA validation errors for Argonaut DSTU IG fragments, where generated DSTU2 ImplementationGuide.package.resource entries appeared to be missing the required purpose element even though the source IG XML contained the data.

Initial application:
The Jira comment says the issue was applied in SVN revision 11498. The migrated Git commit 5a70a27559cb678511f3d7e1f3c6d27db0021fb9 is exactly that revision and fixed the DSTU2 publishing converter by setting converted non-example guide resources to GuideResourcePurpose.PROFILE when src.getExample() was false.

Additional context:
That converter file, implementations/java/org.hl7.fhir.convertors/src/org/hl7/fhir/convertors/VersionConvertor_10_20.java, is no longer present in the current FHIR specification checkout; it was deleted during the later 3.0.0 upgrade. The active current build still includes the ImplementationGuide resource, but the current source uses ImplementationGuide.definition.resource with isExample/profile/groupingId rather than the DSTU2 package.resource.purpose element. The r3-renames table maps ImplementationGuide.package.resource to ImplementationGuide.definition.resource, confirming this is historical migration context rather than a current missing element. Corrected Zulip and Confluence searches found no community evidence contradicting the Jira/source-history conclusion.
