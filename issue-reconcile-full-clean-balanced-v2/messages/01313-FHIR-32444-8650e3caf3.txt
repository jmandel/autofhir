FHIR-32444: Confirm AuditEvent occurred choice

Issue request:
FHIR-32444 was a Published/Persuasive Security WG change request for R5 asking to replace AuditEvent.period with the Provenance-style AuditEvent.occurred[x] element and allow either Period or dateTime because many audited events are instantaneous.

Initial application:
The request was applied by git commit 25018f7336cfa1cb370d0b8c1c8800df515cf1f9, which changed source/auditevent/structuredefinition-AuditEvent.xml from AuditEvent.period of type Period to AuditEvent.occurred[x] with Period and dateTime types. Later commit 94c0e69169bfaae21f14ba9d6612fb251921cb6d updated the R4-R6 change map in source/fhir.ini to record AuditEvent.period=@AuditEvent.occurred[x].

Additional context:
AuditEvent is an active resource in source/fhir.ini and assigned to the Security work group. Security WG minutes for 2021-09-13 record the block vote that included FHIR-32444 as Persuasive with an 8-0-1 motion, matching the Jira vote. No Zulip discussion found in the local index changed the Jira/source conclusion.
