FHIR-27885: Audit MedicationRequest grouping guidance

Issue request:
FHIR-27885 was Published/Persuasive for R5 by Pharmacy and requested MedicationRequest guidance on grouping medication orders, including when to use MedicationRequest.groupIdentifier for independently managed requests, when to use a parent RequestGroup for complex/optional/timing relationships, and that List or Composition should not be used for those grouping requirements.

Initial application:
The Jira comment trail recorded the approved text in July 2020 and a December 2020 note that it had not yet been applied. It was later applied by commit 1683ac6414, which added the "Grouping Medication Requests" section to source/medicationrequest/medicationrequest-notes.xml under Dosage Instructions.

Additional context:
MedicationRequest is an active resource in source/fhir.ini, so source/medicationrequest/medicationrequest-notes.xml is in current build scope. Later accepted work on FHIR-24619 renamed RequestGroup to RequestOrchestration and commit 46bea37a00 updated the same MedicationRequest guidance accordingly. A 2025 dosage refactor also copied the grouping guidance into source/medicationrequest/medicationrequest-introduction.xml, but it does not contradict the notes guidance.
