FHIR-22996: Audit ICD-11 release wording removal

Issue request:
FHIR-22996 was a Published, Persuasive with Modification Vocabulary change request for the FHIR-core "Using ICD-[X] Codes with FHIR" page. It asked to correct the obsolete sentence saying, "The next revision, ICD-11, is scheduled for release in 2017." The final resolution was to remove that text rather than replace it with another date-specific forecast.

Initial application:
The issue appears to have been applied in 9500b398d1, a Vocabulary R5 batch commit whose message lists FHIR-22996. That commit removed the exact obsolete ICD-11 sentence from source/icd.html. The same commit also adjusted the ICD row on source/terminologies-systems.html, which was the build-scoped terminology code systems page that linked to the ICD usage page.

Additional context:
FHIR-31601 raised the same stale ICD-11 sentence and later added an updated ICD-11 release/history sentence before the whole ICD usage page moved out of core. FHIR-35933 then removed the external-code-system usage pages, including source/icd.html, from FHIR core and redirected implementers to HL7 Terminology/THO. Current core source keeps source/terminologies-systems.html in the page hierarchy and links ICD usage to https://terminology.hl7.org/ICD.html, while stating that THO is authoritative for external terminology guidance. FHIR-31601 is already represented on the combined branch by 62250a8dd4cd10a4d85da6e5eba17edccd8329a7, so this commit does not duplicate that related audit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current FHIR core source no longer contains source/icd.html or the obsolete 2017 ICD-11 sentence, and the current core build-scoped terminology page already points readers to THO for ICD guidance. The current THO English ICD page also does not contain the obsolete 2017 sentence, so the specific FHIR-22996 request is already satisfied.

Recommendation:
Keep this no-change audit. No FHIR-core source edit is needed for FHIR-22996. If future work wants to modernize remaining ICD-11 history prose, it should be handled as a THO/UTG content update, not by recreating an ICD usage page in core.
