FHIR-32347: Audit Encounter participant actor optionality

Issue request:
FHIR-32347 was a Published/Persuasive PA change request asking why Encounter.participant.individual was optional and requesting either a required cardinality or explanatory rationale. The adopted resolution required an Encounter.participant invariant like Appointment's type-or-actor rule and a note explaining that participant type can describe the actor's role and that an unspecified individual during planning is expected to be filled before the encounter starts.

Initial application:
The issue was applied by git commit 9b42c8865f716de39b17a1343b6900fece6e4e1b, which added Encounter participant invariant enc-1 with expression actor.exists() or type.exists(), and appended the requested planning/role note to Encounter.participant.actor. No prior duplicate reconciliation commit for FHIR-32347 was present on the combined branch before this audit.

Additional context:
FHIR-22696 renamed the R4 Encounter.participant.individual element to Encounter.participant.actor before FHIR-32347 was applied; source/fhir.ini still records Encounter.participant.individual=@Encounter.participant.actor for cross-version mapping. Encounter is an active current-build resource in source/fhir.ini, so source/encounter/structuredefinition-Encounter.xml is the authoritative place to check this issue. PA WGM minutes for 2021-05 record the same vote and note text, and no Zulip search hit was found that conflicts with the Jira/source conclusion.

AutoFHIR reconciliation:
This audit made no source change because the current active Encounter StructureDefinition already contains the required type-or-actor invariant and the explanatory note on the renamed actor element. The current source therefore preserves the approved meaning even though the original Jira prose used the R4 element name individual.

Recommendation:
Keep this audit commit as-is. No follow-up source change is needed in core FHIR for FHIR-32347 unless the PA work group later decides to change Encounter participant planning semantics.
