FHIR-37701: Audit CodeSystem redirect reconciliation

Issue request:
FHIR-37701 was a Published/Persuasive FHIR-core technical correction raised in R4B. It reported that versionless internal CodeSystem URLs such as http://hl7.org/fhir/account-status and http://hl7.org/fhir/abstract-types still redirected to R4, and that http://hl7.org/fhir/clinical-use-definition-category did not redirect at all; the requested outcome was to make those redirects point to R4B or the current versionless specification.

Initial application:
No Jira-tagged source commit for FHIR-37701 was found in the FHIR source history. The surrounding R4B Zulip thread shows the issue was part of the manual R4B website publication cleanup: Grahame described uploading R4B redirect files, Lee confirmed ValueSet redirects had been corrected while CodeSystem redirects still pointed to R4, and then opened FHIR-37701. FHIR-I minutes on 2022-08-09 record FHIR-37701 as marked closed.

Additional context:
The current redirect templates in source/redirect.asp and the parallel source/template files send JSON, XML, and HTML requests to versionless http://hl7.org/fhir/<artifact> targets rather than to /R4. Account and ClinicalUseDefinition are active current-build resources in source/fhir.ini, and their CodeSystem source files carry the expected canonical URLs. The formerly cited abstract-types code system is no longer present in current source, so its current 404 is not evidence of a missed current-build redirect.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current active CodeSystem redirects checked on hl7.org route to /fhir/codesystem-account-status.* and /fhir/codesystem-clinical-use-definition-category.* rather than /fhir/R4/..., and the source templates already encode the versionless redirect behavior needed for current publications.

Recommendation:
Keep this no-change audit commit. No core source edit is needed for FHIR-37701; if similar failures recur, they should be handled as website publication/deployment redirect regeneration rather than by changing current FHIR definitions.
