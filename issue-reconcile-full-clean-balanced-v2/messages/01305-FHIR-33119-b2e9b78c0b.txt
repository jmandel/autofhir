FHIR-33119: Audit Citation relationship reconciliation

Issue request:
FHIR-33119 was a Published CDS change request for R5 Citation. The original description asked to correct the short description on Citation.citedArtifact.relatesTo.relationshipType from "How the cited artifact resource relates to the target artifact" to "How the cited artifact relates to the target artifact". The final Persuasive with Modification resolution instead recorded the broader approved change to rename Citation.relatesTo to Citation.relatedArtifact to reduce confusion with Citation.citedArtifact.relatesTo, with comments noting that the relatesTo elements should use the RelatedArtifact datatype.

Initial application:
The short-description correction was applied before final resolution in git commit e4a5ff940068, which removed "resource" from Citation.citedArtifact.relatesTo.relationshipType. The datatype simplification to RelatedArtifact was applied implicitly in git commit a519c04228cf for both Citation.relatesTo and Citation.citedArtifact.relatesTo. The Jira-tagged application was git commit fa06f9231615, which renamed Citation.relatesTo to Citation.relatedArtifact.

Additional context:
CDS Confluence agendas for 2021-09-29 and 2021-10-06 list FHIR-33119 as the tracker to change Citation relatesTo elements to RelatedArtifact and note the overlap with FHIR-32795 and FHIR-31742. Later R6 decisions superseded the R5 shape: FHIR-49758 removed Citation.relatedArtifact and reintroduced Citation.relatesTo as a BackboneElement relationship structure, and FHIR-53002 changed relatesTo.type to CodeableConcept. The current source no longer has an active Citation resource at all: source/fhir.ini has no active citation entry, source/citation has no tracked files, and git commit 71567db3ee03 deleted the Citation source files as part of removing Citation from the current build.

AutoFHIR reconciliation:
This is an empty audit commit. No current-build source edit is needed because the R5 issue was historically applied, later final R6 work intentionally changed the Citation relationship model while Citation still existed, and Citation is now absent from the active build.

Recommendation:
Keep this audit commit as-is. Do not reintroduce Citation.relatedArtifact or edit generated/history artifacts for FHIR-33119; any future work should be based on a new work-group decision about the current resources that still reference Citation canonicals, not this R5 Citation tracker.
