FHIR-50702: Audit MeasureReport countQuantity option

Issue request:
FHIR-50702 was Applied/Persuasive for R6 MeasureReport. It accepted option 2 for decimal-valued counts: retain the existing integer count element and use the added countQuantity element for backwards compatibility. The resolution also noted that the countQuantity option ballot comment should be removed from MeasureReport before November 1.

Initial application:
The countQuantity model change was already present before this issue through the FHIR-43088 implementation commits: 3446e427f6 added the two countQuantity elements and f07af5959c added the mutually-exclusive count/countQuantity constraints and the temporary ballot note seeking option feedback. FHIR-50702 itself was applied by 2c06751379, whose subject contains a typo as FHIR-507002 but links to FHIR-50702 and removes the countQuantity option ballot note from source/measurereport/measurereport-introduction.xml.

Additional context:
Related R6 ballot comments FHIR-50273 and FHIR-50563 were resolved with no source change while confirming that CQI would continue with option 2. The current source/fhir.ini actively includes MeasureReport and tracks both countQuantity elements as R5-to-R6 additions. The current MeasureReport introduction still has a later generic ballot note listing changes since FHIR 6.0.0-ballot4, but git blame shows that note was added in April 2026 and it is not the removed countQuantity options note.

AutoFHIR reconciliation:
No source change was made. The authoritative MeasureReport StructureDefinition source already contains MeasureReport.group.population.countQuantity and MeasureReport.group.stratifier.stratum.population.countQuantity, and the specific countQuantity option ballot note requested by FHIR-50702 is no longer present.

Recommendation:
Keep this empty audit commit as-is for FHIR-50702. Any separate reconciliation of the original FHIR-43088 tracker should be evaluated independently, especially its broader example/test-history details, and is not decided by this FHIR-50702 audit.
