FHIR-34421: Audit biological source search parameters

Issue request:
FHIR-34421 was a Published/Persuasive OO change request for R5 asking to make the new biologicalSource element a search parameter on BiologicallyDerivedProduct, Device, and NutritionProduct, and to remove the old distinctIdentifier-to-RIM-lotNumber mapping concern that had existed around the same biological-source concept.

Initial application:
The source history shows the issue was initially applied by adding biologicalSource search parameters to all three resources in commit 4b23eaac39. Follow-up commits 5bcd0301a3 and f231fc0832 corrected the NutritionProduct expression/code, and FHIR-35968 commit 2eea560fe4 removed BiologicallyDerivedProduct.distinctIdentifier and its RIM lotNumberText mapping. The later FHIR-37199 rename changed the resource element names from biologicalSource to biologicalSourceEvent.

Additional context:
The three resources are active in source/fhir.ini. Current source already has active biological-source-event search parameters for BiologicallyDerivedProduct.biologicalSourceEvent and Device.biologicalSourceEvent. NutritionProduct still has NutritionProduct.instance.biologicalSourceEvent as an element, but Applied R6 issue FHIR-47242 specifically reconsidered proposed NutritionProduct search parameters including instance.biologicalSourceEvent and decided not to make that element a standard search parameter because projects can add it locally when needed. Later NutritionProduct traceability issues continue to rely on the element itself, not on a required standard search parameter.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring a NutritionProduct biological-source-event search parameter would conflict with the later FHIR-47242 work-group decision, while BiologicallyDerivedProduct and Device already carry the renamed search parameter and the obsolete distinctIdentifier/RIM mapping is not present on the current biologicalSourceEvent elements.

Recommendation:
Keep this audit commit as-is. Do not re-add a standard NutritionProduct biological-source-event search parameter unless the work group explicitly supersedes FHIR-47242; projects that need that search can define their own parameter as FHIR-47242 notes.
