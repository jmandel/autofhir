FHIR-11169: Audit DetectedIssue category cleanup

Issue request:
FHIR-11169 was an Applied/Persuasive with Modification CDS change request asking that the DetectedIssue.category value set be carefully examined and cleaned up. The reported problem was that the preferred V3-derived category value set included confusing or semantically misplaced detailed detected-issue codes such as ALRTSTRTLAT, ALRTENDLATE, ENDLATE, STRTLATE, and PREVINEF. The final resolution directed CDS to work with vocabulary facilitation to clean up the value set and move it through harmonization.

Initial application:
No git commit explicitly mentioning FHIR-11169 was found. The Jira later comment links HL7/fhir pull request #3305. That PR merged as 065b66f62534babf9063f00a4ad89f7a865b9906 and included commit 34181b9f2184a72b527d9f5b26c234c0c07669ed, which restricted source/detectedissue/valueset-detectedissue-category.xml to category-level concepts and created source/detectedissue/valueset-detectedissue-code.xml for the more detailed detected issue codes.

Additional context:
DetectedIssue is active in source/fhir.ini, so files under source/detectedissue feed the current build. Current DetectedIssue.category is still preferred and bound to http://hl7.org/fhir/ValueSet/detectedissue-category, but that value set now includes only FOOD, DRUG, ALGY, and DUPTHPY from v3-ActCode. The broader V3 detailed-code hierarchies are no longer used as the category value set; they are represented in the separate DetectedIssue.code value set introduced by the related Applied issue FHIR-39458. The original V3 source still contains the old detailed codes, but the current FHIR category value set excludes the reported problematic concepts.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped FHIR source already implements the needed cleanup for FHIR-11169 by limiting DetectedIssue.category to a small category-level value set and separating detailed issue codes from category codes.

Recommendation:
Keep this no-change audit commit as-is for FHIR-11169. A separate review of FHIR-39458 may audit the category/code split, and any broader V3/THO cleanup should be handled through the terminology governance path rather than by changing core DetectedIssue.category source here.
