FHIR-28183: Audit CapabilityStatement.url wording

Issue request:
FHIR-28183 is a Published/Persuasive FHIR-I technical correction for R5 asking that the CapabilityStatement.url definition use the grammatical phrase "literal address at which an authoritative instance of this capability statement is (or will be) published" rather than the duplicated wording that appeared in the R4-era text.

Initial application:
The issue was applied before this reconciliation by commit dcbefa70991b587365f8962291244c1a137d9f6f, "FHIR-28183 Duplicate wording in CapabilityStatement.url", which removed the duplicate "at which" from both source/capabilitystatement/structuredefinition-CapabilityStatement.xml and the reusable canonical URL wording in source/shareable/shareable-spreadsheet.xml.

Additional context:
CapabilityStatement is an active current-build resource in source/fhir.ini, and the current CapabilityStatement StructureDefinition and shareable spreadsheet both contain the corrected single "at which" wording. The originating Zulip thread surfaced the duplicate text while discussing CapabilityStatement.url resolution, and the 2020-11-09 FHIR-I minutes record FHIR-28183 as a technical correction to fix. No later source, Zulip, or Confluence evidence found in this reconciliation indicates a different wording decision.
