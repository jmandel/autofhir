FHIR-49290: Audit HealthcareService actor clarification

Issue request:
FHIR-49290 is an Applied/Persuasive with Modification PA change request asking the HealthcareService documentation to clarify whether HealthcareService can represent the portion of an Organization delivering a service and can be used as an actor, such as performer/requester/recipient.

Initial application:
Commit 088f214be3cbdf3f39fcbe68419ff0f19e543edd added the approved clarification to source/healthcareservice/healthcareservice-introduction.xml. No prior Issue-Reconcile-Key audit commit for FHIR-49290 was present on the combined branch.

Additional context:
FHIR-49290 was created from the Zulip discussion that followed OO review of FHIR-22145. Its Jira description says the FHIR-22145 resolution assumes this actor definition, while its resolution records that HealthcareService can be used as a performer in the Event pattern and that the Scope & Usage section should explain the actor interpretation. source/fhir.ini lists HealthcareService as an active PA resource, so the introduction file is current build-scope narrative source.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current HealthcareService Scope & Usage text already states that HealthcareService is the intersection of Organization, Location, and Service; can be used as an actor such as performer/requester/recipient; and means the collection of people who work with or for that HealthcareService in such cases.

Recommendation:
Keep this empty audit commit as-is. The HealthcareService clarification requested by FHIR-49290 is present; separate linked issues about individual participant references or workflow pattern propagation should remain separate reconciliation work.
