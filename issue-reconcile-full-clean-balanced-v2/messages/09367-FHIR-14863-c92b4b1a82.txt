FHIR-14863: Audit Observation focus application

Issue request:
FHIR-14863 was a Published/Persuasive with Modification FHIR-core Observation request to add an Observation focal point for cases where an observation is about something associated with the patient that is more specific than the patient or a body site. The accepted resolution was to promote the focal-subject extension to a DSTU core element, initially named focalSubject, with Reference(Any), and to add boundary guidance discouraging use of Observation when a more specific resource already fits.

Initial application:
The issue appears to have been applied in the STU3/R4 development source. Commit d06b52856c89401a981241a811faa7b455037c08 added focal-subject-related Observation changes and Observation boundary text under GF#14863. Commit 5c093b94a97c0320ee01c1ec9914fd824433ba4e then updated the same change family under GF#14863/GF#14443 by renaming Observation.focalSubject to Observation.focus. The current build uses source/observation/structuredefinition-Observation.xml for the active Observation resource listed in source/fhir.ini.

Additional context:
The linked Zulip discussion shows the work group moving away from broadening Observation.subject to Reference(Any), choosing an inline focus element with boundary text instead, and then renaming the proposed focal-subject element to focus at Mark Kramer's request. Later published issue FHIR-15825 deliberately changed Observation.focus from 0..1 to 0..*, so the current cardinality should not be reverted to the original FHIR-14863 resolution text. Later clarification work also refined subject/focus guidance while preserving the same modeling approach.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active Observation source defines Observation.focus as a 0..* Reference to Resource, which is the current source representation of Reference(Any), describes it as the actual focus when it is not the subject of record, marks it as modifier, and includes examples. The Observation narrative also contains the requested boundary guidance that Observation should not replace more appropriate specific resources.

Recommendation:
Keep this audit commit as-is. Do not reintroduce a separate Observation.focalPoint/focalSubject element or restore 0..1 cardinality for this issue; any future changes to subject target profiles or focus examples should be reconciled under their own Jira keys.
