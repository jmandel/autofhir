FHIR-12154: Audit translation extension cleanup

Issue request:
FHIR-12154 was a Published/Persuasive FHIR-core datatypes change request from DSTU2. It asked to remove the old iso21090-ST-translation and iso21090-ST-language extensions, or at least steer users to the newer http://hl7.org/fhir/StructureDefinition/translation extension, and to add a RIM mapping on the newer extension showing the ST.translation relationship.

Initial application:
The Jira comment says the issue was applied in svn revision 10254. The git-svn import of that change is commit 891791d1df (#12154 - clean up translations), which removed the ISO 21090 String/ST translation section from profiles/iso-21090-introduction.xml, disabled ST-translation and ST-language in profiles/iso-21090-spreadsheet.xml by prefixing their codes with '!', and added the ST.translation RIM mapping to profiles/general-extensions-spreadsheet.xml.

Additional context:
Current core source no longer contains iso21090-ST-translation or iso21090-ST-language, and the active Multi-Language Support page is in the build hierarchy and links to the translation extension as the multi-translation mechanism. The translation extension definition itself now lives in the FHIR Extension Pack, where its canonical URL remains http://hl7.org/fhir/StructureDefinition/translation and its differential contains the requested RIM mapping to ST.translation. A 2020 Zulip implementer thread also distinguishes the retired iso21090-ST-translation pattern as the old way and points users to the current translation extension.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The retired ST translation extensions are already absent from current core and the current translation extension already carries the requested RIM mapping in the extension-pack source of truth.

Recommendation:
Keep this no-change audit commit. No core follow-up is needed for FHIR-12154; if future work changes the translation extension definition, maintain the Extension Pack mapping and the core Multi-Language Support link together.
