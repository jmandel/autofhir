FHIR-7829: Audit MedicationDispense ORC-3 removal

Issue request:
FHIR-7829 is a Published/Persuasive pharmacy change request from the 2015May DSTU1 ballot asking to remove ORC-3 Filler Order Number from the HL7 v2 mapping for MedicationDispense.authorizingPrescription, leaving ORC-2 Placer Order Number because the filler order number is scoped by the dispenser rather than by the original/authorizing prescription.

Initial application:
The issue appears to have been applied in historical commit 5bb461af1063efe577bac2b8b17b6992be7560bf, which explicitly names tracker item 7829 and changes the old MedicationDispense spreadsheet v2 mapping from "ORC-3-Filler Order Number / ORC-2-Placer Order Number" to "ORC-2 Placer Order Number". The source was later refactored into the current generated StructureDefinition form, preserving the corrected mapping.

Additional context:
MedicationDispense is an active resource in source/fhir.ini, so source/medicationdispense/structuredefinition-MedicationDispense.xml is in current build scope. Current source has MedicationDispense.authorizingPrescription mapped to "ORC-2 Placer Order Number" only, and a targeted search found no ORC-3 or Filler Order Number text in source/medicationdispense. Jira search only surfaced FHIR-7829 for the MedicationDispense authorizingPrescription ORC query, while Zulip and Confluence searches found no directly relevant discussion or conflicting work-group evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already reflects the requested correction, and editing unrelated ORC-3 mappings in other resources would exceed the issue scope.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-7829 unless a future pharmacy work-group decision changes the MedicationDispense.authorizingPrescription v2 mapping.
