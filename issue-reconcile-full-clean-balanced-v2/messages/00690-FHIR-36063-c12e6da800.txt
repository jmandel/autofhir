FHIR-36063: Audit superseded Condition Trial Use markers

Issue request:
FHIR-36063 was Published/Persuasive for R5 and asked Patient Care to designate Condition.stage and Condition.evidence as Trial Use (non-normative).

Initial application:
The request was applied in e32f44011c31b4ff54efacb50819ce146af411c4, which added structuredefinition-standards-status=trial-use extensions to Condition.stage and Condition.evidence in source/condition/structuredefinition-Condition.xml. The Jira comment points to the same GitHub commit, and the 2022 Patient Care minutes/FHIR-32478 show the underlying 6-0-0 motion to hold those two elements back from the rest of Condition.

Additional context:
A later final Patient Care decision, FHIR-52956 (Applied/Persuasive for R6), explicitly removed the Trial Use designation from Condition.stage and Condition.evidence, along with AllergyIntolerance.type and AllergyIntolerance.reaction, after PC concluded those elements had long-standing large-EHR implementation. Commit b0795b968d8cfa56f4b734c40b63f80898a03542 removed the per-element trial-use extensions. The current build scope includes Condition via source/fhir.ini, and the current Condition source no longer contains per-element standards-status extensions on Condition.stage or Condition.evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reinstating the FHIR-36063 Trial Use markers would conflict with the later Applied FHIR-52956 decision and with the current authoritative Condition StructureDefinition source.

Recommendation:
Keep this audit commit as-is. Treat FHIR-36063 as historically applied for R5 but superseded in the current R6 source by FHIR-52956; only revisit if Patient Care reverses the 2025 removal decision.
