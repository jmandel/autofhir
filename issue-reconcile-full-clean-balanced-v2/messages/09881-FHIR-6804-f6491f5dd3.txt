FHIR-6804: Audit IG-specific schema support

Issue request:
FHIR-6804 was a Published/Persuasive with Modification FHIR-core change request from the 2015 May SDC ballot asking whether HL7 could publish implementation-guide-specific schemas that include only the data elements and resources used by an IG. The final resolution was that this could be done in the IG Publisher, with most of the work already done.

Initial application:
No commit in the current core source history explicitly mentions FHIR-6804. The surrounding history shows the in-repository IG Publisher already generated profile-specific Schematron and validation packs by the 2016-2017 application window, including a December 2016 commit that packaged IG output and publisher code paths that generated schematron.zip, json.schema.zip, shex.zip, and IG-specific validator packs.

Additional context:
The IG Publisher source was removed from this core FHIR checkout in 2019 with the commit message "Remove IG publisher (it's gone to Maven)". Current core source still documents the base specification's all-resource XML schemas and the limits of profile-generated Schematron/JSON Schema, while current HL7/fhir-ig-publisher source continues to generate profile Schematrons and IG/package validation artifacts outside this repository. Community searches found no Zulip or Confluence discussion that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. The requested implementation is a publisher/tooling capability rather than a current core specification source correction, and the relevant publisher code is now maintained outside this checkout.

Recommendation:
