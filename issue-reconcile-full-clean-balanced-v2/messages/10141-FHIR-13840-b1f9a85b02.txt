FHIR-13840: Remove stale MessageHeader timestamp example comments

Issue request:
FHIR-13840 was Published/Persuasive with Modification. It asked for a persistent Bundle date for document creation because Bundle.meta.lastUpdated is server-specific and Composition.date is the composition authoring/editing time. The approved resolution was to add Bundle.timestamp, document/message/query-response guidance about its use and its distinction from meta.lastUpdated, and to remove MessageHeader.timestamp in favor of Bundle.timestamp.

Initial application:
The historical application is git commit c3463df3ff5896ae7f6771267a31325bc6a3302f, the git-svn import of svn revision 12717, titled "#13840 - add Bundle.timestamp". That commit added Bundle.timestamp, a Bundle timestamp search parameter, message/document/searchset usage text, Bundle timestamps on message request/response examples, MessageHeader guidance pointing to Bundle.timestamp, and marked MessageHeader.timestamp as removed in the then-current spreadsheet source. It also changed the standalone MessageHeader example's old timestamp element into an XML comment rather than deleting it.

Additional context:
Bundle and MessageHeader are active current-build resources in source/fhir.ini. Current Bundle source already defines Bundle.timestamp, requires it for document Bundles, explains document/message/history/searchset usage and the relationship to meta.lastUpdated, and MessageHeader narrative/definitions point message time to Bundle.timestamp. A 2019 Zulip thread on MessageHeader.timestamp explicitly identified GF#13840 as the reason Bundle.timestamp was added in R4 and MessageHeader.timestamp was removed. Later MessageHeader endpoint work in FHIR-20522 copied the stale commented-out timestamp into source/messageheader/message-header-example.xml, but that issue is about endpoint cardinalities rather than timestamp semantics.

AutoFHIR reconciliation:
This commit removes only the stale commented-out MessageHeader timestamp example lines from source/messageheader/messageheader-example.xml and the copied source/messageheader/message-header-example.xml. It leaves the already-correct Bundle.timestamp definition, document constraint, message examples with Bundle-level timestamps, and MessageHeader guidance unchanged.

Recommendation:
Keep this source fix. It completes the original removal of MessageHeader.timestamp from example source without changing Bundle.timestamp semantics; no additional core source action is indicated for FHIR-13840.
