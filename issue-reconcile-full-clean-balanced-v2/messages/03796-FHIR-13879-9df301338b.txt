FHIR-13879: Audit Medication resource reconciliation

Issue request:
FHIR-13879 was a Published/Persuasive STU3 Pharmacy change request for the Medication resource. The final decision required clearer descriptions for Medication.amount and Medication.ingredient.amount, examples, removal of medication.preparedInstructions, and after a later Pharmacy vote, retaining Medication.status while updating its definitions/descriptions and examples of use.

Initial application:
The issue was applied in historical source. Commit 2559032b9b1cd17a3f528abbe59749fff309ed69, "GF #13879 - Updates to Medication resource," updated the Medication spreadsheet, added Medication.amount wording, removed the old prepared-dose/prepared-instructions source text, removed/reshaped the package content model, and updated many Medication examples. Commit eddae4c6adc0a38d7c292dfa6f82cc15e75e194e, "GF #13943, GF #13879, GF #13871, GF #13780, GF #13999 - Pharmacy Resource changes," then applied the November 2017 decision to keep Medication.status and expanded its comment to explain active local drug-database/inventory use and formulary/catalogue separation.

Additional context:
Medication is an active current-build resource in source/fhir.ini. The current XML StructureDefinition is no longer the 2017 spreadsheet form, and later final Pharmacy decisions intentionally changed the STU3 amount model: FHIR-17375 renamed Medication.ingredient.amount to Medication.ingredient.strength and fixed definitions; FHIR-46416 later replaced the package amount concept with Medication.packageSize.numberOfItems and amountPerItem. Those later decisions explain why current source has packageSize and ingredient.strength[x] instead of the exact STU3 Medication.amount and ingredient.amount names.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scope Medication source retains the FHIR-13879 status explanation, has no active medication.preparedInstructions or Medication.ingredient.amount source, carries clear packageSize and ingredient.strength definitions, and includes active examples using ingredient strength and Medication.status. Editing current source back toward the 2017 element names or adding redundant prose would conflict with later applied Pharmacy issue history.

Recommendation:
Keep this no-change audit as-is. Future Medication packaging or ingredient-strength changes should be handled under the later Medication issue family, not by reopening FHIR-13879's already-applied STU3 resource-model cleanup.
