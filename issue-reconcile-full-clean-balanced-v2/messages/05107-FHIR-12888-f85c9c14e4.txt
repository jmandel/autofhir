FHIR-12888: Audit alternate-home discharge disposition

Issue request:
FHIR-12888 was Published/Persuasive for PA and requested adding an alternate-home discharge disposition concept for patients discharged home but not to the patient's own home. The accepted resolution specified code alt-home with display Alternative home and a definition covering family-member or caregiver homes.

Initial application:
The request was applied in git commit f4b6c9c7d8c20db1a1b04162e1f13143723c8935, whose message lists GF#12888 among Encounter changes and whose patch added code alt-home to the then-core codesystem-encounter-discharge-disposition.xml. Later terminology refactoring moved the discharge-disposition code system out of core and left the core Encounter value set as an include of the THO code system.

Additional context:
Encounter is an active current-build resource in source/fhir.ini, and Encounter.admission.dischargeDisposition still binds to ValueSet/encounter-discharge-disposition. The current core ValueSet source includes http://terminology.hl7.org/CodeSystem/discharge-disposition, and the local hl7.terminology.r5 package's CodeSystem-discharge-disposition.json contains alt-home with the requested family-member-home definition. Checked release-history artifacts also show alt-home in R4 and R5 expansions. Jira search found no FHIR-core later issue overturning this concept, and Zulip/Confluence searches found no substantive conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding inline concepts to the core ValueSet would duplicate terminology now supplied by THO and would not change the current built specification's discharge disposition expansion.

Recommendation:
Keep this audit commit as-is. No FHIR-core follow-up is needed unless a future terminology governance decision changes or removes alt-home from the THO discharge-disposition CodeSystem.
