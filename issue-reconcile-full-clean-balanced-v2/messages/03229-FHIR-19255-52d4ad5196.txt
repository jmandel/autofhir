Issue request:
FHIR-19255 was Published/Persuasive for FHIR-core Library. It asked that clients be able to retrieve Library resources by the content type of attached library content, with the resolution to define a token search parameter over content.contentType.

Initial application:

That commit added a `content-type` token search parameter with expression `Library.content.contentType` to the former Library spreadsheet source. The later source refactor in 33b409a4b6 migrated the search parameter into `source/library/bundle-Library-search-params.xml`, where it remains.
