FHIR-7973: Audit Provenance entity type binding

Issue request:
FHIR-7973 is a Published/Persuasive FHIR-core Provenance issue from the 2015 May ballot asking that the value set binding for Provenance.entity.type, then composed of FHIR resource types, be changed from Required to extensible.

Initial application:
The same 2015 ballot change family appears in FHIR-7460, where Grahame Grieve commented that the required binding was a tooling error and had been pre-applied. The DSTU2 source import already shows the ProvenanceEntityType binding to http://hl7.org/fhir/ValueSet/resource-types with Conformance = extensible, so the requested binding change was applied before this reconciliation.

Additional context:
Provenance remains an active current-build resource in source/fhir.ini. Later Provenance work for GF#9996 changed Provenance.entity.reference to Reference(Any) and disabled Provenance.entity.type and Provenance.entity.display, replacing the old resource-type discriminator with a direct reference model that still supports non-FHIR content. Current source has Provenance.entity, Provenance.entity.role, Provenance.entity.what, and Provenance.entity.agent, but no active Provenance.entity.type or ProvenanceEntityType/resource-types binding to correct.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current specification is already correct for FHIR-7973: the obsolete binding was first made extensible, and the obsolete element has since been removed from the active Provenance definition.

Recommendation:
Keep this audit commit as-is. Do not reintroduce or edit Provenance.entity.type for FHIR-7973; future work should treat FHIR-9996 and later Provenance.entity.what modeling as the current design.
