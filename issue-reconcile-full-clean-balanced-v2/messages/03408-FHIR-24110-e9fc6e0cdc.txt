FHIR-24110: Audit genomics code system URI slashes

Issue request:
FHIR-24110 was Published with a Persuasive with Modification resolution asking to remove accidental trailing slashes from the Code Systems for Genetics URIs, subject to Clinical Genomics confirming that the R4 technical correction would not impact existing implementers.

Initial application:
The change was applied before this reconciliation. Git commit 2c2e2d5931 updated source/terminologies-systems.html to change http://www.ncbi.nlm.nih.gov/refseq/, http://www.ncbi.nlm.nih.gov/clinvar/, and http://varnomen.hgvs.org/ to the slashless forms, and git commit e0c3d06011 was explicitly tagged GF#24110 while doing follow-up definition fixes. Jira's final comment also records that the change was fixed in both the R4 technical correction and current build.

Additional context:
The current build still includes the terminologies module through source/fhir.ini, but source/terminologies-systems.html no longer lists the old genomics external systems directly and instead points readers to THO for authoritative external code system information. A current source search found no occurrences of the three affected trailing-slash system URIs, while current MolecularDefinition examples that use RefSeq or HGVS use the slashless URIs. Zulip announcements and the genomics thread confirm the exact three URI corrections and Clinical Genomics outreach; no Confluence record was found that changes that conclusion.

AutoFHIR reconciliation:
This audit commit makes no source change because the current FHIR source is already consistent with the FHIR-24110 decision and there is no in-scope core source location still carrying the accidental trailing slashes.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-24110; any future concern about authoritative external terminology registry content should be handled in THO rather than by reintroducing a core terminologies-systems table entry.
