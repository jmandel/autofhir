Issue request:
FHIR-18562 was a Published/Persuasive STU3 vocabulary change request for the ValueSet page. The ballot comment asked whether the short lists in Boundaries and Relationships and the Intensional vs Extensional area were complete or only samples; the recorded resolution was to make sure the list is complete.

Initial application:
The Jira comment points to git 4907f9bcb0b710cb2837a93a20c4b23210a37249. Additional context:
ValueSet is an active resource in source/fhir.ini, so source/valueset/valueset-introduction.xml and source/valueset/valueset-notes.xml feed the current build. The current ValueSet page includes a generated "References to this Resource" section listing the full Resource References and Extension References, and the current Intensional vs Extensional wording defines the two styles without presenting a misleading resource list. No later Jira, Zulip, or Confluence evidence found in bounded searches changes this conclusion.
