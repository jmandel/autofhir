FHIR-5570: Audit DICOM code system URI correction

Issue request:
FHIR-5570 was a Published/Persuasive DSTU1 FHIR-core terminology-valuesets correction asking that DICOM code system uses of http://nema.org/dicom/dcid be replaced with http://nema.org/dicom/dicm, because DCID identified DICOM context groups while dicm was then the intended DICOM code system URI.

Initial application:
The issue was applied in historical SVN r3985, now git commit ce4fa67b0458b398c8a66215012d0b7f3d6f84ea, which replaced the dcid URI with dicm across the then-current DICOM code system, value sets, examples, and spreadsheets.

Additional context:
Later DICOM terminology work changed the correct modern URI from the historical FHIR dicm spelling to the DICOM-published http://dicom.nema.org/resources/ontology/DCM URI. FHIR-12944 confirmed that the DICOM code-system page/link mismatch was acceptable and only required code-system wording cleanup, FHIR-12947 recorded the broader DICOM-derived value-set consistency work, and FHIR-24908 moved core source toward DICOM-authored code systems/value sets. Those related issues are already represented on the combined reconciliation branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current active source has no http://nema.org/dicom/dcid or http://nema.org/dicom/dicm uses, while active DICOM-coded examples and value sets use http://dicom.nema.org/resources/ontology/DCM. The remaining source/fhir.ini valueset-dicom-dcim entry is an artifact identifier in the valueset-fixup section, not the obsolete dcid URI that FHIR-5570 corrected.

Recommendation:
Keep this empty audit commit as-is. Reverting current source to the old dicm URI would conflict with later DICOM/FHIR terminology decisions; no further core source work is indicated for FHIR-5570.
