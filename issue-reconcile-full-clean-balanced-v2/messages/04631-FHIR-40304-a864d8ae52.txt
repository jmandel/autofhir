FHIR-40304: Audit date search period bounds

Issue request:
FHIR-40304 was Applied with a Persuasive with Modification resolution for R6 to clarify that date searches are compared as periods, including the earliest instant through the latest instant of the searched value, and to explain Period and Timing handling in the date search section.

Initial application:
The current source already contains the accepted clarification. Commit 567404363cd3f8b75c115a0e1a9df8cae7476622, "FHIR-40304 - Search period comparison clarifications", rewrote source/search.html so date/dateTime/instant values are converted to period start/end values, Period needs no conversion, Timing uses outer limits, unspecified precision is expanded to lowest/highest instants, and missing boundaries compare before/after actual dates.

Additional context:
The same search wording family was discussed with FHIR-51068, FHIR-40319, and FHIR-51077.
