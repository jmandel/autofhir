FHIR-13449: Audit MedicationRequest intended performer search

Issue request:
FHIR-13449 was a Published/Persuasive Pharmacy change request raised for STU3. It asked to add MedicationRequest.intendedPerformer to the search parameters after FHIR-12439 added the intended performer element so servers could retrieve requests by the intended medication administration performer, including privacy-sensitive access-control use cases.

Initial application:
The issue appears to have been applied by git-svn commit 333047669dbe6165ff81da07eabda57b3f9880e6, whose subject explicitly says "TR# 13449 - add intended-performer search parameter to MedicationRequest" and whose patch added an intended-performer reference search parameter on MedicationRequest.performer to the MedicationRequest spreadsheet source. The companion element had already been added by FHIR-12439 in git-svn commit 4b21106775caa782aa07057cdc51cb67b83f467f.

Additional context:
Current core source no longer uses the old spreadsheet as the authoritative checked-in search-parameter surface; the active MedicationRequest resource in source/fhir.ini now has source/medicationrequest/bundle-MedicationRequest-search-params.xml. The current structure definition names the underlying element MedicationRequest.performer, with short text "Intended performer of administration", so the older Jira wording "intendedPerformer" is represented by the current performer element and the intended-performer search code. No Zulip or Confluence search result was found that changes this interpretation.

AutoFHIR reconciliation:
No source change was made. The active MedicationRequest search-parameter bundle already contains MedicationRequest-intended-performer with code intended-performer, type reference, expression MedicationRequest.performer, and a description matching the Jira request. The active resource entry in source/fhir.ini confirms the MedicationRequest source folder is part of the current build.

Recommendation:
Keep this no-change audit commit as-is. The current specification already satisfies FHIR-13449; future work should only revisit this if Pharmacy intentionally renames or removes MedicationRequest.performer or changes the canonical search parameter code.
