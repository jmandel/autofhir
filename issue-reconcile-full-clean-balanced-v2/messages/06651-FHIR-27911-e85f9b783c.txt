FHIR-27911: Audit vital signs UCUM binding evolution

Issue request:
FHIR-27911 was a Published/Persuasive OO technical correction for R5 asking to relax the Vital Signs UCUM common-unit binding from required to extensible for both Observation.value[x] and Observation.component.value[x], with resolution text adding that extensions to the enumerated UCUM-code list SHOULD come from UCUM.

Initial application:
The issue was applied before this reconciliation. Git b1bdb5bcbcff042d0e26bf061ffd5086872881fc added extensible ucum-vitals-common bindings and the UCUM SHOULD description to Observation.value[x] and Observation.component.value[x]; git 64a395a67cbd3e61bdce02c2522d32b37d8c46ff applied the same family for R4B.

Additional context:
Observation is active in source/fhir.ini and the Observation Vital Signs IG includes StructureDefinition/vitalsigns, so the inspected profile source is in build scope. Later Applied R6 decisions intentionally moved beyond the FHIR-27911 outcome: FHIR-43353 relaxed valueQuantity/component.valueQuantity to preferred UCUM bindings, FHIR-44721 approved http://unitsofmeasure.org/vs for component.valueQuantity, and FHIR-47136 source work implemented that all-UCUM component quantity binding. Those related issues are already represented on the combined branch. FHIR-54503 later identifies remaining narrative binding-strength wording but is still Triaged rather than Applied/Published, so it is not safe to apply under this seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Vital Signs Base Profile no longer contains the old required ucum-vitals-common restriction: Observation.value[x] has a preferred binding to ucum-vitals-common, and Observation.component.value[x]:valueQuantity has a preferred binding to http://unitsofmeasure.org/vs. Reintroducing FHIR-27911's exact extensible common-UCUM wording would undo later applied decisions.

Recommendation:
Keep this audit commit as-is. Do not change the formal Vital Signs UCUM bindings for FHIR-27911 unless OO reopens the later preferred/all-UCUM R6 decisions; handle the Triaged FHIR-54503 narrative consistency question separately if it reaches Applied or Published.
