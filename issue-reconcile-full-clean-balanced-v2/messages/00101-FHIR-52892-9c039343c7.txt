FHIR-52892: Audit MedicationDispense doseAdministrationAid application

Issue request:
FHIR-52892 was an Applied FHIR-core Pharmacy change request for R6 asking how to record that a MedicationDispense was supplied in a distribution or adherence packaging form such as a Baxter roll. The Persuasive with Modification resolution voted 9-0-0 on 2025-09-17 required adding MedicationDispense.doseAdministrationAid with definition "Provides information about the type of adherence packaging supplied for the medication dispense.", short display "Type of adherence packaging to use for the dispense", cardinality 0..1, and an example binding to Medication Dose Aids.

Initial application:
The source application exists before this reconciliation. Commit a94da33de370f06f3ea261e97bbc29f412dfc194, later included in merged PR HL7/fhir#3896, added MedicationDispense.doseAdministrationAid to source/medicationdispense/structuredefinition-MedicationDispense.xml. The current combined branch already contains that commit and the active source includes the element, but no prior combined-branch commit carried Issue-Reconcile-Key: FHIR-52892.

Additional context:
MedicationDispense is active in source/fhir.ini, and source/fhir.ini also includes the new MedicationDispense.doseAdministrationAid marker, so the StructureDefinition source is in current build scope. Pharmacy WGM minutes for September 2025 confirm the same 9-0-0 decision and explain that the existing MedicationRequest doseAdministrationAid pattern and Medication Dose Aids example binding were reused for MedicationDispense. Those minutes also note interest in adding a code representing "Baxter roll" to the dose-aid code system, but the final Jira resolution and PR applied only the new MedicationDispense element; because the binding is example and no exact new code/display/definition was resolved in the applied Jira text, this reconciliation does not invent terminology content.
