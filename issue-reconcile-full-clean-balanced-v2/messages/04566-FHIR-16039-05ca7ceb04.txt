FHIR-16039: Audit Patient $everything US Core wording

Issue request:
FHIR-16039 was a Published/Persuasive with Modification STU3 Patient Administration change request for FHIR-core Patient. It asked to replace the US Realm Patient $everything sentence's DAF reference with US Core; the final resolution said "DAF" should become "US Core Implementation Guide" and the hyperlink should be removed because a stable US Core versions directory did not exist.

Initial application:
The request was applied historically in two source-history steps. Commit ef22a35e358a065db276f56ac53597bc8a608755, "fixed typos GF#16608,16610,16611", first changed the Patient $everything spreadsheet description from the DAF link to a linked US-CORE reference. Commit 9e75eb3795fde681b5809e83f51f02ebbebd2131 explicitly named GF#16039 and changed the same sentence to "US Core Implementation Guide" without a hyperlink while correcting "mimimum" to "minimum", matching FHIR-16039's final no-link resolution.

Additional context:
Patient remains an active current core resource, but the current Patient operations list includes only Patient-match and Patient-purge. Later FHIR-43373 application in commit 8085536f12e251d00b80ac47323658eb94e9b1ac removed the entire US Realm/meaningful-use minimum sentence from Patient $everything and kept only generic implementation-guide guidance. Later commit b487fdda4bb4a5382a93dbb5a811efd02425b9bc moved PA operations out of core, deleted source/patient/operationdefinition-Patient-everything.xml, and changed current core references to the Administrative Incubator operation page. The current externally linked Patient $everything XML has no DAF, US Core, or US Realm minimum sentence. Related FHIR-16610 and FHIR-16421 audits already on the combined branch support the same history and current-source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The DAF-to-US Core/no-link wording was applied in historical core source, and the current core build no longer contains an authoritative Patient $everything OperationDefinition needing this edit. Existing core references point externally, where the stale DAF/link wording is absent.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-16039; future Patient $everything wording changes should be made in the Administrative Incubator source if that external definition changes.
