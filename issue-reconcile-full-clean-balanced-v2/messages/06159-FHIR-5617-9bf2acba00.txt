FHIR-5617: Audit CarePlan activity title extension ownership

Issue request:
FHIR-5617 is a Published/Persuasive with Modification FHIR-core CarePlan issue from DSTU1. It asked for a name on CarePlan.activity for display of activities such as running, swimming, or appointments; the final PC resolution was to define a common extension to capture activity "title" and watch implementer uptake.

Initial application:
The issue appears to have been applied in core history by db4ace37c6615c9732f958d34d6286fe739fc657, whose message lists #5617 among PC-approved CarePlan changes and added a CarePlan extensions spreadsheet row for `activity-title` with short "Label for activity" and definition "Human-friendly name for the activity." The same artifact later existed as `source/careplan/structuredefinition-extension-careplan-activity-title.xml` with URL `http://hl7.org/fhir/StructureDefinition/careplan-activity-title`, context `CarePlan.activity`, and string value.

Additional context:
The current core CarePlan resource is active in `source/fhir.ini`, but core no longer owns this extension definition. Commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed `structuredefinition-extension-careplan-activity-title.xml` and the CarePlan-core IG reference as part of the R5 extension-source removal, and current `source/history.html` says all extensions moved to package `hl7.fhir.uv.extensions` while still being published as part of the specification. The current FHIR Extension Pack source at `/home/jmandel/work/fhir-extensions/input/definitions/CarePlan/StructureDefinition-careplan-activity-title.xml` defines the requested active extension with PC work group, context `CarePlan.activity`, description "Human-friendly name for the activity," and `value[x]` type `string`. FHIR-12646 later added top-level `CarePlan.title` to core and does not replace this per-activity extension. FHIR-53008 is a 2025 Submitted, unresolved Extension Pack issue about the extension's short text versus definition, so it is not a final source-edit decision for this core reconciliation.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. Reintroducing the CarePlan activity-title extension into core would duplicate the post-R5 Extension Pack ownership model, and the current authoritative extension already represents the seed decision.

Recommendation:
Keep this external-repo audit commit as the core reconciliation record. No FHIR core follow-up is needed for FHIR-5617; any future wording change to the CarePlan activity-title extension should be handled in the FHIR Extension Pack after a final Extension Pack Jira decision such as FHIR-53008.
