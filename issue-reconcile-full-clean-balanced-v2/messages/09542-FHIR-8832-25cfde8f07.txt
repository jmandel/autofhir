FHIR-8832: Audit Subscription criteria examples

Issue request:
FHIR-8832 is a Published/Persuasive FHIR-core Subscription technical correction that asked for the example Subscription criteria to use `Observation?code=http://loinc.org|1975-2` instead of `Observation?name=http://loinc.org|1975-2`.

Initial application:
The issue was applied in svn revision 7155, imported as git commit 987e5fc8279a762452d4d545d722001d2b6aa6c0, which changed both `source/subscription/subscription-example.xml` and `source/subscription/subscription-example-error.xml` from `Observation?name` to `Observation?code`.

Additional context:
Subscription remains an active current-build resource in `source/fhir.ini`, but the current resource model no longer has the DSTU-era `Subscription.criteria` element. The current example list points to `Subscription/example` and `Subscription/admission`, which use `Subscription.filterBy` and do not contain the old LOINC Observation criteria. Later Subscription changes, including FHIR-12723 and FHIR-27129, reordered/refactored the examples and removed the old error example. The only remaining `Observation?name=http://loinc.org|1975-2` occurrence is in `source/subscription/josh proposal.txt`, an unreferenced proposal note rather than a built Subscription example resource.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current built Subscription examples are no longer affected by the DSTU-era criteria typo, and editing the unreferenced proposal note would not correct the current specification.

Recommendation:
Keep this audit commit as-is. No follow-up core source work is needed for FHIR-8832 unless the build starts publishing the historical proposal note or a future Subscription example reintroduces an Observation criteria search.
