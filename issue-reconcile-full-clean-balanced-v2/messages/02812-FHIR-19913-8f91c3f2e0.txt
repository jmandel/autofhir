FHIR-19913: Correct Dosage method examples

Issue request:
FHIR-19913 was Published/Persuasive with Modification for the Pharmacy WG. It asked to review the Dosage.method exemplar value set so examples such as continuous infusion and IV bolus could be represented, and the accepted resolution changed the binding basis from SNOMED CT 422096002 Dosing instruction fragment to 736665006 Dose form administration method while fixing the long-description examples.

Initial application:
The historical application commit 1dcdc4c567 changed the active source/datatypes/valueset-administration-method-codes.xml filter from 422096002 to 736665006 for R5. Current Dosage source is active through source/fhir.ini and binds Dosage.method to valueset-administration-method-codes, but the Dosage.method requirements text still used the older examples "Slow Push; Deep IV." MedicationAdministration.dosage.method is an active parallel resource element with the same canonical value set and retained the same stale route/method examples. An old source/medicationrequest copy of the value set still contains 422096002, but current source references and release-history output point to the datatypes value set as the active binding source.

Additional context:
Pharmacy Confluence minutes record the accepted FHIR-19913 disposition as "change binding to administration method" and "fix examples in the description" with an 8-0-0 Persuasive with Modification vote. The referenced Zulip "Mapping infusion" thread shows why the WG wanted better separation of intravenous route, bolus/push method, and infusion workflow concepts rather than retaining examples that combine route and method.

AutoFHIR reconciliation:
Updated the active Dosage.method requirements text and the matching active MedicationAdministration.dosage.method definition to use the Jira-requested method-style examples "inject, swallow, or chew." The already-correct active value set filter remains 736665006, and the unreferenced MedicationRequest copy was not changed because it is not the source that feeds the current binding.

Recommendation:
Keep this source fix. If a future terminology cleanup audits unused duplicate value set files under resource folders, source/medicationrequest/valueset-administration-method-codes.xml should be considered separately, but it should not block this FHIR-19913 correction to active built content.
