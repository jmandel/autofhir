Initial application:

Additional context:
Measure remains an active resource in `source/fhir.ini`, but the old spreadsheet source is no longer the current authoritative source surface. The current `source/measure/bundle-Measure-search-params.xml` contains no `Measure-topic` search parameter. That absence is explained by later Applied/Persuasive issue FHIR-55436 and commit 06ab81280ad55b6232b7acf245ed9fbc014b41d4, which removed deprecated `Measure.topic` and removed the matching `Measure-topic` search parameter after it already contained the corrected "measure" wording. FHIR-55436 has a later Jira comment proposing to reopen and undo that removal because topic is not useContext, but there is no final workflow reversal in the inspected evidence.
