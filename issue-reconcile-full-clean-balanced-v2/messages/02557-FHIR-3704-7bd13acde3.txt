FHIR-3704: Audit ImagingStudy subject naming

Issue request:
FHIR-3704 was a Published/Persuasive DSTU1 change request to rename ImagingStudy.subject to ImagingStudy.patient because the then-current element only allowed Patient, following the naming guideline that patient is used when Patient is the only reasonable subject.

Initial application:
The request was applied in git commit 9567767b1d930e2b478f74866cb5039e3acef23d on 2014-11-29, which renamed the then-current ImagingStudy element, example, and search-path rows from ImagingStudy.subject to ImagingStudy.patient. The current source also retains release-mapping metadata for the later name transition as ImagingStudy.patient=ImagingStudy.subject.

Additional context:
FHIR-14147 later reached Published/Persuasive with Modification for the same ImagingStudy element family. It changed the element name back to subject, added Device and Group as allowed subject targets, and modeled whole-slide specimen imaging with a new series-level specimen reference. Commit d21acd48143d1cbe35a35616864c97839b13a361 applied that later update. The current R6 build includes ImagingStudy as an active resource, defines ImagingStudy.subject as Reference(Patient, Device, Group), and provides both the Patient-only patient search parameter and the broader subject search parameter. Exact-key Zulip and Confluence searches found no conflicting community evidence.

AutoFHIR reconciliation:
No source change was made. Renaming current ImagingStudy.subject to patient would contradict the later FHIR-14147 decision and the current source semantics because the element is no longer Patient-only. The current source already satisfies the naming guideline cited by FHIR-3704 by using subject when non-Patient targets are possible.

Recommendation:
Keep this no-change audit commit as-is. Do not reapply FHIR-3704 to the current build; revisit only if a future work-group decision narrows ImagingStudy.subject back to Patient-only.
