FHIR-12764: Audit Medication product backbone removal

Issue request:
FHIR-12764 was a Published/Persuasive Pharmacy change request for DSTU2 asking to remove the Medication.product backbone element and move its child elements directly under Medication, with TR/FHIR-12399 reviewed as part of that cleanup.

Initial application:
The Jira comments cite SVN/Git commit b0500f8b520d72851aba346483f21d1ded9a86b3 (@11055), which removed the Medication.product row from the then-authoritative Medication spreadsheet, renamed Medication.product.form/ingredient/batch paths to direct Medication children, and fixed examples by deleting product wrappers. The same commit also carried related Medication introduction and clarification work.

Additional context:
Current source/fhir.ini actively includes Medication in the build. The current Medication StructureDefinition has top-level Medication.doseForm and Medication.ingredient elements, later medication modeling changed package/batch details to current Medication.packageSize and Medication.instance/definition structures, and no Medication.product element or path remains in the active Medication definition. Active Medication examples listed by list-Medication-examples.xml no longer use product wrappers. Some source/medication/Archive files still contain historical <product> elements, but those archive files are not referenced by active source lists/configuration and are not current build inputs. FHIR-12412 separately asked for a better name for Medication.product and was retracted because the product backbone removal made it moot.

AutoFHIR reconciliation:
No source change was made. The current built Medication source already reflects the FHIR-12764 decision by omitting the product backbone and keeping the relevant medication characterization elements outside any product wrapper.

Recommendation:
Keep this empty audit commit as-is. Do not edit the archived Medication examples for this issue unless a separate build-scope decision makes those Archive files active again; the current active Medication source and examples already satisfy the published Jira decision.
