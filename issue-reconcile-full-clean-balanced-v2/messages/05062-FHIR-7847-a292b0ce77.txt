FHIR-7847: Audit MedicationStatement RXR-4 removal

Issue request:
FHIR-7847 was a Published/Persuasive Pharmacy change request from the 2015May ballot asking that the HL7 v2 mapping for MedicationStatement method be changed from RXR-4 Administration Method to blank. The rationale was that MedicationStatement is a reported medication-use record rather than a v2 prescribe-dispense-administer transaction concept, so RXR-4 is not a likely mapping source for MedicationStatement.

Initial application:
The issue appears to have been applied in historical commit 5bb461af1063efe577bac2b8b17b6992be7560bf, which grouped tracker items 7827, 7829-7838, and 7840-7848 for MedicationDispense and MedicationStatement v2 mapping updates. That commit removed the RXR-4-Administration Method cell from the old MedicationStatement.dosage.method spreadsheet row and left the v2 mapping blank.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. The current source no longer has the old MedicationStatement.dosage.method element; MedicationStatement.dosage now uses DosageDetails, and current MedicationStatement/DosageDetails source contains no RXR-4 or Administration Method mapping. RXR-4 remains in the reusable Dosage datatype and in MedicationAdministration.dosage.method, where this MedicationStatement-specific issue does not require removal. Jira search returned neighboring MedicationStatement RXR removal issues, but they concern separate mapping rows and were not decided here. Zulip and Confluence searches found no direct conflicting discussion for FHIR-7847.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Removing RXR-4 from the reusable Dosage datatype or MedicationAdministration would over-apply a MedicationStatement-specific request, while the authoritative MedicationStatement source already reflects the requested blank mapping.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-7847 unless Pharmacy decides in a separate tracker to revisit reusable Dosage v2 mappings across all resources.
