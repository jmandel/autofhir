FHIR-19469: Audit superseded MedicationUsage rename

Issue request:
FHIR-19469 was a Published/Persuasive Pharmacy change request for R5 asking to rename MedicationStatement to MedicationUsage because the resource documents medication use and "statement" could be confused with a medication profile.

Initial application:
The rename was applied in commit 040377bccb10e55b6158e9ab260883ded1e13b13, which changed active build entries such as source/fhir.ini and source/hierarchy.xml from MedicationStatement/medicationstatement to MedicationUsage/medicationusage and renamed the MedicationStatement source folder and examples. The Jira application comment points to build commit 014d1416, but the source-history commit that actually performs the rename is 040377bccb.

Additional context:
Later Published/Persuasive with Modification issue FHIR-38682 reversed the R5 resource name back to MedicationStatement while retaining the other R5 content changes. Pharmacy meeting minutes for 2022-10-31 record the 11-0-0 motion that MedicationUsage would revert to MedicationStatement. Commit b2032629f28b8d31b9a67b46170dde873398fb0d applied that reversal across fhir.ini, hierarchy.xml, the medication resource source, examples, and cross-references. Current source/fhir.ini and source/hierarchy.xml actively build MedicationStatement, no tracked source/medicationusage files remain, and the only current MedicationUsage source occurrence is the intentional old-type code in source/terminologies/codesystem-fhir-old-types.xml. Existing combined-branch audits for FHIR-24568, FHIR-30582, and FHIR-38873 also treat FHIR-38682 as the governing later rename-back decision.

AutoFHIR reconciliation:
No source change was made. Reintroducing MedicationUsage for FHIR-19469 would now contradict the later final Pharmacy decision in FHIR-38682 and would make the current build less correct. The current MedicationStatement source is the intended post-reversal state, so this commit records the seed issue as audited and superseded by later source history.

Recommendation:
Keep this no-change audit commit. Do not rename the current resource to MedicationUsage unless Pharmacy makes a new decision that supersedes FHIR-38682; any future cleanup should preserve the old-type MedicationUsage entry as a historical/compatibility code unless that terminology policy changes separately.
