Issue request:
FHIR-17274 was Published/Persuasive for CQI and requested a Measure-level $collect-data operation with the same parameters and options as $evaluate-measure. The requested response was a Bundle with the MeasureReport as the first entry and evaluated resources included, using the then-new data-collection report type.

Initial application:

The later source rework commit 33b409a4b6 materialized the current OperationDefinition/Measure-collect-data XML and added it to the Measure operations list.

Additional context:
FHIR-17272 supplied the paired MeasureReport data-collection type used by the original request. Later Published/Applied work intentionally changed and refined the surface: FHIR-20509 renamed the report type from data-collection to data-exchange, and FHIR-34112 plus later DEQM-alignment commits reshaped the $collect-data parameters and return documentation. Current source differences from the 2018 wording reflect those later decisions rather than a missed application.
