FHIR-17615: Audit List definition wording

Issue request:
FHIR-17615 was a Published/Persuasive FHIR-core List issue. It objected that the List definition "A set of information summarized from a list of other resources" was misleading because summarizing is not the point of List, and the approved resolution was to change the definition to "A list is a curated collection of resources."

Initial application:
The Jira comment cites GH#ae0434b086. Local history contains commit ae0434b086b9157d78915146bec2205e1325f35c, "GF#17615 - fix definition of list", which changed the then-authoritative source/list/list-spreadsheet.xml short and definition from the summarizing wording to "A list is a curated collection of resources".

Additional context:
The current build scope includes List as an active resource in source/fhir.ini. The current source/list/structuredefinition-List.xml short still says "A list is a curated collection of resources", while the description/definition now use the later FHIR-27903 clarification adding examples of problem/allergy/facility/organization lists. FHIR-27903 also added the List/Group distinction in source/list/list-introduction.xml. Historical release2/release3 snapshots still contain the old wording, but release4/release4b snapshots and current source contain the corrected wording; those old snapshots are historical evidence, not current authoritative source needing edits.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active List definition no longer says that List summarizes other resources, and the later example-rich wording is semantically consistent with the FHIR-17615 resolution rather than a regression.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-17615 unless a future work group decision wants to revisit the broader List/Group wording introduced by FHIR-27903.
