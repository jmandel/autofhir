FHIR-17960: Audit CoverageEligibilityRequest boundary section

Issue request:
FHIR-17960 was a Published/Persuasive Financial Management change request for the STU3 EligibilityRequest/CERq artifact. It asked to add a missing Boundaries and Relationships section and distinguish the resource from preauthorization and predetermination.

Initial application:
The historical application is commit 4bc111798571c5d90b18cf42db9b70a05d603c60, whose subject explicitly includes GF#17960. That commit added the CoverageEligibilityRequest Boundaries and Relationships section, including text distinguishing CoverageEligibilityRequest eligibility/benefit/preauthorization-requirements inquiries from Claim adjudication, authorization, and what-if adjudication use.

Additional context:
The old EligibilityRequest source directory still exists, but source/fhir.ini marks EligibilityRequest as a removed resource and records that EligibilityRequest/Response became CoverageEligibilityRequest/Response. CoverageEligibilityRequest is the active, approved build resource. The Claim page and the Financial module separately define Claim.use=preauthorization and Claim.use=predetermination and point eligibility checks to CoverageEligibilityRequest, so the current spec family preserves the requested distinction even though not every term is repeated in the CoverageEligibilityRequest boundary paragraph.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active CoverageEligibilityRequest source already has the requested boundary section, and nearby active Claim/Financial module guidance provides the explicit preauthorization and predetermination details without needing duplicative prose in the CoverageEligibilityRequest page.

Recommendation:
Keep this audit commit as-is. Revisit only if the Financial Management work group wants a new editorial change to repeat the words "preauthorization" and "predetermination" directly on the CoverageEligibilityRequest page; that would be a new clarification, not a missing application of FHIR-17960.
