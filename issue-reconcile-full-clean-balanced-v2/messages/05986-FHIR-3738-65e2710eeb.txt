FHIR-3738: Audit Person resource reinstatement

Issue request:
FHIR-3738 was a Published/Persuasive Patient Administration change request to reinstate Person as an independent resource for patient identity management and qualified record linking across identity domains. The accepted resolution says Person is a linker joining person-type resources such as Patient, RelatedPerson, and Practitioner, not a generic base class for those resources.

Initial application:
The issue was applied in commit e7291feeeed431c97f14f54a83d348baf36c163d, "Tracker #3738 - reinstated the Person resource." That commit added person=Person to source/fhir.ini, removed Person from the removed-resources list, and added Person examples, narrative, and spreadsheet source. The source was later migrated into the current StructureDefinition-based layout, but the active Person resource and its PA ownership remain present.

Additional context:
Current source/fhir.ini includes Person as an active resource, assigns it to the PA work group, gives it the psn abbreviation, and marks it approved. The current Person StructureDefinition and narrative describe a linkage resource for common demographics across roles, with Person.link.target referencing Patient, Practitioner, RelatedPerson, and Person, and the surrounding narrative preserves the optional/advanced-feature and non-actor boundaries discussed in the Jira comments. Jira exposes no normalized linked issues for FHIR-3738, and no directly relevant Zulip or Confluence records were found that would reverse the historical application.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source already contains Person in the active build and conveys the issue's approved semantics: an independent, optional linkage resource rather than a superclass for patient/practitioner/related-person data.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-3738 unless PA later decides to change the current Person model through a new tracker.
