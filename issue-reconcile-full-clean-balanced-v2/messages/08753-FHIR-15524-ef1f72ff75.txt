FHIR-15524: Audit QuestionnaireResponse language guidance

Issue request:
FHIR-15524 was a Published FHIR-core QuestionnaireAnswers change request with resolution Not Persuasive with Modification. It asked for an attribute on QuestionnaireResponse to indicate the language in which the patient completed the survey; the approved resolution was to use inherited QuestionnaireResponse.language and add guidance to the QuestionnaireResponse notes section.

Initial application:
The issue appears to have been applied by git commit e4ad0ecfef, which added a QuestionnaireResponse notes bullet saying the language element can be used for the patient-completed survey/questionnaire language. That initial line contained a spelling typo, later corrected by the FHIR-25940 typo commit, and the current notes source retains the intended guidance.

Additional context:
QuestionnaireResponse is active in source/fhir.ini, and the notes file is authoritative source for the current QuestionnaireResponse page. Resource.language remains inherited from Resource with a required IETF language-tag binding and a definition for the base language of the resource content. Jira, Zulip, and Confluence searches found no directly relevant later core decision that supersedes the FHIR-15524 guidance.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current active source already implements the approved resolution in source/questionnaireresponse/questionnaireresponse-notes.xml and the inherited Resource.language element supports the described use.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-15524 unless a future work group decision changes how QuestionnaireResponse language capture should be represented.
