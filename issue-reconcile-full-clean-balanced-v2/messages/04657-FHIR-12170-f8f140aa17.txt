FHIR-12170: Audit Questionnaire repeats clarification

Issue request:
FHIR-12170 is a Published/Persuasive with Modification FHIR-core Questionnaire clarification. It asked whether repeats=true on a question means repeated QuestionnaireResponse items or multiple answers in one response item, and the approved guidance said question repeats allow multiple answers while rendering software may either repeat the question text or show multiple answers beneath one question.

Initial application:
The issue was initially applied in historical commit 76675fcc, whose subject explicitly lists 12170 among Questionnaire clarifications and whose patch added the approved repeats=true comment to the old questionnaire spreadsheet source. The exact guidance was carried forward through later source refactors into the current StructureDefinition XML.

Additional context:
source/fhir.ini lists Questionnaire and QuestionnaireResponse as active resources, so their StructureDefinition XML files are current build inputs. Later Published FHIR-33335 refined the same model by adding qrs-2 and making explicit that repeated question answers are represented as multiple answers in one item while repeated groups use repeated items. Later Applied FHIR-55973, already represented on the combined branch, added the distinct-answer qualifier and qrs-4; it does not reverse the FHIR-12170 rule.

AutoFHIR reconciliation:
Made no source change. The current Questionnaire.item.repeats definition and comment already convey the requested rule, including that a repeats=true question produces one QuestionnaireResponse question item with multiple answers and that rendering may repeat question text or allow multiple answer entry/selection.

Recommendation:
Keep this empty audit commit as-is. No core source follow-up is needed for FHIR-12170; any future work should be scoped to newer repeats-related trackers rather than reapplying the 2016 clarification.
