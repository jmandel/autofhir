FHIR-7405: Clarify MedicationStatement common usage

Issue request:
FHIR-7405 was a Published Pharmacy change request, resolved Persuasive for DSTU1. It said the MedicationStatement common-usage examples incorrectly implied that one MedicationStatement represents an intake medication list or active-medication summary, and the resolution asked to describe medication use plus each medication within a list or summary.

Initial application:
No git commit explicitly mentioning FHIR-7405 was found. The Jira comment said "already done", and commit 7d50996061 (#7167) added the clarifying paragraph that MedicationStatement does not produce a medication list and instead produces individual MedicationStatement instances for use in List, but the two common-usage bullets identified by FHIR-7405 remained in their old list/summary wording through later resource renames and Pharmacy cleanups.

Additional context:
FHIR-5916 raised the same second and third common-usage bullets and its resolution points to the same 2015 #7167/#5941 application trail. FHIR-5941 separately covered the MedicationAdministration/MedicationStatement boundary and is already represented on the combined branch. FHIR-38682 renamed MedicationUsage back to MedicationStatement while stating the scope section had not changed. FHIR-39165 later removed non-prescribed substance-abuse/alcohol/tobacco use from MedicationStatement scope, so the first common-usage bullet must not reintroduce the older "recreational drugs" example from the 2015 resolution.

AutoFHIR reconciliation:
This commit updates the active MedicationStatement introduction common-usage bullets. It changes the list and summary examples to say "each medication" and "representation of a medication" and adapts the first resolved bullet to the current medication-only scope by mentioning prescription or non-prescription medications rather than recreational drugs.

Recommendation:
Keep this source fix. It completes the published Pharmacy decision without undoing later scope clarifications; no further core source change is recommended for FHIR-7405.
