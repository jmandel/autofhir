FHIR-36301: Audit Device normative markers

Issue request:
FHIR-36301 was a Published/Persuasive R5 OO change request asking that normative markers in the Device resource definition be removed. The relevant decision was non-substantive and intended to prevent Device attributes/search parameters from carrying normative status while Device was not proceeding as normative in R5.

Initial application:
The Jira comment says the issue was added to the build via PR commit 959edb68. In the current git history, the substantive Device application is the adjacent pre-merge commit 746a6a0e8c, which changed selected entries in source/device/bundle-Device-search-params.xml from normative to trial-use; the FHIR-keyed follow-up commit 4fddf63f45 only added trailing whitespace to the same file. No broader Device source edit from FHIR-36301 is missing in the current R5-era trail.

Additional context:
OO minutes from March and June 2022 confirm the R5 plan: remove Device normative markers and treat Device normative comments as not applicable until R6. Later R6 work changed the premise. FHIR-53389 is Applied/Persuasive for R6 and explicitly directs every Device search parameter in source/device/bundle-Device-search-params.xml to be normative; d022c23cff applied that to the search-parameter bundle. The current Device StructureDefinition has standards-status normative from later status-code cleanup at 5c20769cc7, and FHIR-53625 adds the current ballot note that Device is being prepared for Normative status. source/fhir.ini lists Device as an active resource and approved, so these files are in current build scope.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Removing the current normative markers would revert later R6 Applied normative-ballot work rather than complete FHIR-36301.

Recommendation:
Keep this no-change audit as-is. Do not use FHIR-36301 to remove current Device normative markers; any concern about Device's R6 normative readiness should be handled as a new human/work-group review item against the R6 normative-ballot decisions.
