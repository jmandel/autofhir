FHIR-15109: Audit superseded ImagingStudy procedureCode binding

Issue request:
FHIR-15109 was a Published/Persuasive STU3 Imaging Integration change request asking that the old ImagingStudy.procedureCode binding not use SNOMED CT/generic procedure-code content and instead point implementers toward the radiology procedure code set reflected by RadLex/LOINC-RSNA Playbook guidance.

Initial application:
The issue was applied before this reconciliation. Git commit 7b2b64512052c9a800a59b0ac3cd2cd013659b1b, whose subject explicitly includes GF#15109, changed the then-active ImagingStudy spreadsheet's ImagingProcedureCode value set from http://hl7.org/fhir/ValueSet/procedure-code to http://www.rsna.org/RadLex_Playbook.aspx and added the description "Use of RadLex is preferred." Later source history kept carrying that coded procedure binding until subsequent ImagingStudy remodels.

Additional context:
Closely related later decisions changed the same source surface. FHIR-20166 corrected the obsolete RadLex URL to the LOINC/RSNA Radiology Playbook URL and later canonical LOINC value set URI. FHIR-19637 merged procedureCode and procedureReference into a repeated procedure element, FHIR-32719 converted that R5 shape to CodeableReference, FHIR-32793 weakened the coded binding from extensible to preferred, and later R6 work represented the current performed-procedure relationship as ImagingStudy.procedure with Reference(Procedure). The combined branch already contains no-change/fix reconciliation commits for those later ImagingStudy procedure issues. Current source/fhir.ini actively includes imagingstudy=ImagingStudy and records ImagingStudy.procedureCode as renamed to ImagingStudy.procedure.

AutoFHIR reconciliation:
Made no source change. The active current StructureDefinition defines ImagingStudy.procedure as a 0..* Reference(Procedure) with no terminology binding, so the old SNOMED/generic procedure-code binding requested by FHIR-15109 is not present in the current built resource. Targeted searches found the obsolete RadLex URL only in source/genomicstudy/imagingstudy.svg, a generated-looking copied diagram under a GenomicStudy directory that is not active in source/fhir.ini, so editing it would not be a current-spec fix.

Recommendation:
Keep this no-change audit. Do not reintroduce a coded ImagingStudy procedure binding for FHIR-15109; if a future work-group decision adds coded performed procedures back to ImagingStudy, use the later FHIR-20166 and FHIR-32793 history as guidance for a canonical LOINC/RSNA Playbook value set with preferred, not extensible, binding strength.
