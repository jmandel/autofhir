FHIR-11294: Audit absent data example guidance

Issue request:
FHIR-11294 was a Published/Persuasive OO change request for FHIR-core Observation, raised against DSTU2 section 10.1.7. The request asked to clarify absent-data examples, especially that laboratory observations such as urinalyses or differential cell counts may omit records when no reportable value exists, so implementers should not assume every absence must be represented by one of the then-present examples.

Initial application:
The issue was applied before this reconciliation by commit 29f4601440af8375fc9f1e19f0d38727cd29aec4, whose subject listed [#11294] along with adjacent Observation issues. That commit added the sentence that an observation may only be reported if there are values to report, with the differential-cell-count values-when-greater-than-zero example, to the Observation.dataAbsentReason comment in the then-authoritative Observation spreadsheet source.

Additional context:
Observation is an active current-build resource in source/fhir.ini, and current Observation source now lives in source/observation/structuredefinition-Observation.xml plus narrative/example files under source/observation. Later Applied issue FHIR-41321 directly reconsidered the FHIR-11294 narrative text and resolved Persuasive with Modification to remove the whole passage about observations only being reported when values exist, differential cell counts, and use-case agreements because it did not fit the rest of the dataAbsentReason guidance. Commit c5544079b363fdd536766fd5fbc3fe3bc26550ac made that removal, and FHIR-41321 already has a no-change reconciliation commit on the combined branch. Current Observation notes still include cancelled/not-performed guidance and a specimen reject example without reintroducing the superseded differential-count comment.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. Re-adding the original FHIR-11294 differential-count narrative would undo the later FHIR-41321 work-group decision; the authoritative current source no longer contains that text, and the remaining Observation.dataAbsentReason and not-performed guidance is internally consistent.

Recommendation:
Keep this no-change audit as-is. No current core source follow-up is needed for FHIR-11294 unless OO explicitly reopens the later FHIR-41321 decision and approves new guidance for omitted laboratory result records.
