Issue request:
FHIR-17699 was a Published/Persuasive with Modification FHIR-core clarification for the extensibility page. It asked to clarify that the Exchanging Extensions section describes non-modifier extensions except where modifier extensions are explicitly mentioned, and to qualify the Summary: Handling extensions guidance so unknown modifier extensions are not treated like ordinary ignored extensions.

Initial application:
The Jira comment points to GH#f536a40888, and commit f536a40888561aa716bad59f9e1a1686d6aa3c16 applied both requested source changes to source/extensibility.html: it inserted the non-modifier note at the start of Exchanging Extensions and appended "except for modifier extensions" to the handling summary bullet.

Additional context:
source/fhir.ini contains the active extension=extensibility page entry, so source/extensibility.html is in current build scope. Later FHIR-18362 refined the same summary bullet so unrecognized non-modifier extensions should be preserved when possible and ignored only when preservation is impossible; its already-published combined-branch commit preserved FHIR-17699's distinction by saying unrecognized modifier extensions require special handling as described above. Bounded Zulip and Confluence searches found no FHIR-17699-specific community record contradicting the Jira/source conclusion.
