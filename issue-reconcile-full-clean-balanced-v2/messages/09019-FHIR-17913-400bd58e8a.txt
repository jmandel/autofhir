FHIR-17913: Audit Device identifier alternate-name cleanup

Issue request:
FHIR-17913 was Published/Persuasive with Modification for STU3 Device.identifier. It asked to remove "Serial Number" from Device.identifier Alternate Names and to remove the UDI serial-number explanation from the Device.identifier Comments text.

Initial application:
The Jira comments cite commit dafaea89c60abbe36b277673dc7bc37d15fbd607, which changed the then-authoritative source/device/device-spreadsheet.xml by blanking the Device.identifier alternate-name cell that contained "Serial Number" and deleting the requested UDI sentence from the comments cell.

Additional context:
Device remains an active current-build resource through source/fhir.ini. The current source/device/structuredefinition-Device.xml no longer has the retired alternate-name or the removed comment sentence. The remaining serial-number wording is current guidance from later published Device work: FHIR-22835 replaced the Device.identifier comment to explain that serial number and UDI carrier are not consistently device instance identifiers, FHIR-32559 clarified why Device.serialNumber remains a dedicated attribute, and FHIR-35861 updated Device search parameters so serial-number searches cover both Device.serialNumber and Device.identifier.where(type='SNO'). The UDI mapping row that still mentions serial number is not the alternate-name cell or the retired Comments prose from FHIR-17913.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical request is already reflected in the current active Device StructureDefinition, and removing the later serial-number guidance or the UDI mapping would conflict with subsequent published decisions rather than complete FHIR-17913.

Recommendation:
Keep this audit commit as-is. No FHIR-core source follow-up is needed for FHIR-17913 unless the work group separately reopens the later Device.identifier/serialNumber guidance.
