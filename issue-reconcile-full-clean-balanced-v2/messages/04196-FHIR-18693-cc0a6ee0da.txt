FHIR-18693: Audit ValueSet steward extension status

Issue request:
FHIR-18693 was Published/Persuasive for STU3 and asked Vocab to add a ValueSet extension for the VSD Steward role, including contact information when it differed from publisher contact details.

Initial application:
The Jira comment cites git 4907f9bcb0b710cb2837a93a20c4b23210a37249. That commit added a steward row to the ValueSet extension spreadsheet with ValueSet context, 0..* cardinality, ContactDetail value type, and comments that contact information should be included.

Additional context:
Later R5 decisions changed the correct current representation. FHIR-35987 clarified publisher/steward wording for CanonicalResource-style publisher elements after explicitly reviewing valueset-steward. FHIR-35985 made ValueSet a MetadataResource and deprecated related redundant extensions. FHIR-39257 then directed removal of valueset-author, valueset-effectiveDate, valueset-expirationDate, and valueset-steward because they had first-class replacements. Current active core ValueSet source says ValueSet.publisher is the publisher/steward, and the ValueSet notes state that ValueSet.publisher satisfies both publisher and steward. The old valueset-steward StructureDefinition is no longer active core source; it is retained in the FHIR Extension Pack as a retired/deprecated artifact with reason "Use ValueSet.publisher instead" and the same ContactDetail value shape.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding valueset-steward to active core source would contradict later published tracker decisions, while removing all trace of it would be wrong because the Extension Pack preserves the retired canonical extension and core still retains the OID registry entry.

Recommendation:
Keep this no-change audit commit as-is for core FHIR. Any future change to separate steward from publisher again should be handled as a new tracker that explicitly revisits FHIR-35987, FHIR-35985, and FHIR-39257; the current core checkout needs no FHIR-18693 source edit.
