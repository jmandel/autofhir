FHIR-11017: Audit genomics examples links

Issue request:
FHIR-11017 was a Published/Persuasive Clinical Genomics issue from the DSTU2 ballot asking to add links to examples from the Genomics Implementer Guidance document, with resolution text saying links to examples in the IG would be added, especially for newly implemented ones.

Initial application:
The issue was explicitly applied in git commit b2b49e7e2bb0572d2de4ba7516e2c44df48751b2, which resolved #11017 together with related genomics ballot issues by adding PGx and TPMT examples, wiring those examples into resource spreadsheets, and updating source/genomics.html with links to the examples.

Additional context:
Later core history intentionally changed the same area. Commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435 removed outdated Clinical Genomics profiles, extensions, and examples under Observation, DiagnosticReport, and ServiceRequest and streamlined source/genomics.html. Commit 033e2c9e617375abaef8b8b6b13ef2520fbdac33 then added the current Clinical Genomics use-case link from source/genomics.html. The current build still includes source/genomics.html through source/hierarchy.xml, and the page now points readers to the Genomics Reporting Implementation Guide and the Clinical Genomics on FHIR use-case page instead of the retired STU3 example set. Later FHIR-28403 tracks examples/guidance work in the Genomics Reporting IG, confirming that new example curation belongs primarily outside this core-source issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing the 2016 example links would point to artifacts that were later removed as outdated, and adding another core-page example link would duplicate current IG/use-case navigation without changing implementer understanding of the current specification.

Recommendation:
Keep this audit commit as-is. Do not restore the retired PGx/TPMT links in core; future genomics example improvements should be handled in the active Genomics Reporting IG or another current Clinical Genomics tracker with concrete current artifacts.
