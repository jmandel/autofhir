FHIR-12656: Audit Observation and Media boundary relationship

Issue request:
FHIR-12656 was a Published/Persuasive DSTU2 OO change request asking to describe Media's relationship to Observation in the Boundaries section because Media existed as a parallel to Observation.

Initial application:
No git commit explicitly mentions FHIR-12656. The same issue family was applied through the Media update in git commit 1f8156067a07341db5f660a2ac4a0f55c4bcb1a6, whose FHIR-12657 change added Media Boundaries text saying Media captures a specific type of Observation whose value is audio, video, or image data and is preferred when its metadata is needed. Earlier Observation boundary prose also linked to Media before later removal.

Additional context:
Media is no longer an active current-build resource: source/fhir.ini has Observation in the active [resources] list, but no media=Media entry and only a commented Media standards-status line. The later GF#19250/FHIR-19250 Media-to-DocumentReference work removed Media from [resources] and removed Observation's Media-specific narrative. FHIR-38950 then carried the useful Media boundary guidance forward into DocumentReference, and current Observation source points image/binary result guidance to valueAttachment, DocumentReference via derivedFrom, and DiagnosticReport.media/presentedForm.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing Media into current Observation boundaries would reference a retired/out-of-build resource and conflict with later source history; the current build already conveys the successor relationship through DocumentReference and Observation's Attachment/derivedFrom guidance.

Recommendation:
Keep this no-change audit commit. Do not re-add Media-specific Observation text unless the work group reintroduces Media or explicitly asks for release-history wording; any current wording improvements should be evaluated against the active DocumentReference, DiagnosticReport, ImagingStudy/ImagingSelection, and Observation guidance rather than the retired Media page.
