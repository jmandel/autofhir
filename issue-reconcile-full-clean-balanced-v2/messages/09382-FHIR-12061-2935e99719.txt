FHIR-12061: Audit extension slicing by url

Issue request:
FHIR-12061 was a Published/Persuasive FHIR-core DSTU2 change request asking that DomainResource.extension and Element.extension expose the standard rule that extensions are sliced by url rather than relying only on prose. The resolution was to document clearly that extensions are always sliced by URL and may be re-sliced, and to expose that explicitly on DomainResource and Element.

Initial application:
The Jira comment cites SVN revision 11243. In the git-svn history, b48380f01b10a6a18fa88cbc6f13d7fc8b409b16 is revision 11243 and added the defining-extensions note plus generator logic for extension slicing by url, even though its subject uses the misleading number "#12131". A later explicit FHIR-12061 commit, aed32a0db4637f14a5c7da6cd11c2f18d5625460, fixed generation of extension slicing in the profile utilities.

Additional context:
FHIR-12131 is a separate QI-Core navigation issue whose Jira snapshot and SVN revision 11242 show that the #12131 subject on revision 11243 is not the governing issue. Current source/fhir.ini still lists Base, Element, BackboneElement, and DomainResource as active normative or abstract build artifacts. Current DomainResource source includes open slicing by value:url on both extension and modifierExtension, and the current CI-generated Element profile includes the same open value:url slicing on Element.extension. Current extension-authoring prose also says Extension.extension is automatically sliced by url and that extensions are always sliced by their url property with re-slicing allowed.

AutoFHIR reconciliation:
This is an empty audit commit. No source hunk is needed because the current built specification already conveys the FHIR-12061 rule in the technical artifacts and supporting prose.

Recommendation:
Keep this audit commit as-is. Do not add duplicate source wording or spreadsheet edits unless a future build regression removes the generated Element.extension or DomainResource.extension slicing from the published StructureDefinitions.
