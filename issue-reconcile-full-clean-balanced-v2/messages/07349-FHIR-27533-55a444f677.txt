FHIR-27533: Audit TestScript scope outside core

Issue request:
FHIR-27533 was Published/Not Persuasive with Modification for R5 by FHIR-I. It asked whether TestScript.profile should be renamed and clarified to identify the artifacts a TestScript is meant to cover; the accepted disposition kept TestScript.profile for validation profile use and added a new TestScript.scope element to identify conformance or definitional artifacts under test.

Initial application:
No source commit explicitly mentioning FHIR-27533 was found. The same TestScript scope request was carried forward in FHIR-27007, whose Published/Persuasive with Modification disposition defined a concrete TestScript.scope BackboneElement with scope.artifact canonical(Any), conformance, and phase children. Commit bd6381b4ffae4b45c6397dbfc952ec02418c418b added that structure and the related search parameters to source/testscript while TestScript was still active in core.

Additional context:
The FHIR-I minutes for 2020-06-08 record FHIR-27533 as adding TestScript.scope as canonical, Not Persuasive with Modification, 11-0-0. The linked Zulip discussion explains why TestScript.profile was not renamed: it was used as a validation profile alias, while the broader artifact-under-test need belonged in a new scope element. Later FHIR-38814 kept TestScript.profile as canonical(StructureDefinition), and FHIR-36211/FHIR-46100 audits on the combined branch document later TestScript work and the current move of TestScript out of core. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testscript and active TestScript fhir.ini entries and added the FHIR Testing IG link; current core source has no tracked source/testscript files and points TestScript to HL7/fhir-testing-ig.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. The requested semantics were historically applied through the concrete FHIR-27007 TestScript.scope implementation, and the current FHIR core build no longer owns the TestScript StructureDefinition. A read-only check of the current HL7/fhir-testing-ig source found TestScript.scope and TestScript.scope.artifact canonical still present, with TestScript.profile remaining a validation profile reference.

Recommendation:
Keep this core audit as an external-repo decision. Do not reintroduce TestScript source in core for FHIR-27533; if future refinement is needed, handle it in HL7/fhir-testing-ig alongside the current TestScript resource source.
