FHIR-14790: Audit ValueSet compose definition

Issue request:
FHIR-14790 was a Published/Persuasive with Modification STU3 ValueSet issue asking for more detail about the differences and uses of ValueSet.compose and ValueSet.expansion. The approved resolution rejected the proposed extra local prose as not clearer, and instead called for linking the .compose introductory mention to its element definition and updating the ValueSet.compose definition to describe the Content Logical Definition (CLD).

Initial application:
The issue was pre-applied in SVN revision 13351, represented in git as d90f55e1cb. That commit updated source/valueset/valueset-introduction.xml so .compose links to valueset-definitions.html#ValueSet.compose, and updated the then-authoritative source/valueset/valueset-spreadsheet.xml ValueSet.compose row to the approved CLD definition. The old spreadsheet source was later migrated into the current StructureDefinition source layout.

Additional context:
The ValueSet resource is active in the current build through source/fhir.ini. The current source/valueset/valueset-introduction.xml still contains the .compose element-definition link, and source/valueset/structuredefinition-ValueSet.xml contains the approved CLD wording for ValueSet.compose. Current ValueSet notes also explain compose-only, expansion-only, both, and neither cases, so adding the originally proposed sentence would be redundant and contrary to the accepted modification. Confluence minutes record the Vocab WG's 5-0-0 approval of the documented FHIR-14790/FHIR-14791 changes, and community searches found no conflicting decision.

AutoFHIR reconciliation:
This is an empty audit commit because the current authoritative source already implements the approved FHIR-14790 clarification. No source edit is needed.

Recommendation:
Keep this audit commit as-is. Future changes to ValueSet.compose or ValueSet.expansion explanatory guidance should be made under a later issue with a current work-group decision, not by reapplying the rejected FHIR-14790 proposed wording.
