FHIR-10463: Audit ImagingStudy count cardinalities

Issue request:
FHIR-10463 was Published/Persuasive with Modification for DSTU2 by Imaging Integration. It requested lowering ImagingStudy.numberOfSeries, ImagingStudy.numberOfInstances, and ImagingStudy.series.numberOfInstances to 0..1 and updating their descriptions so an ImagingStudy can exist when only the Study Instance UID or incomplete series/instance detail is known.

Initial application:
The historical GForge-imported commit d6c6d61a7220660624430008cee9d5aaee9727d1 explicitly referenced GF#10463 and updated the old ImagingStudy spreadsheet source, including changing the numberOfSeries description to the Jira-requested wording. The source has since been refactored to source/imagingstudy/structuredefinition-ImagingStudy.xml, where the affected elements are active build input.

Additional context:
ImagingStudy is active in source/fhir.ini. The current StructureDefinition keeps all three affected elements at min 0 and max 1. Later R6 decisions intentionally changed the top-level numberOfSeries and numberOfInstances definitions to "known" counts that may be present with empty or partially populated series/instance detail, while FHIR-50775 retained and corrected the series.numberOfInstances wording. FHIR-50771 later added count-consistency invariants, and FHIR-52028 was Resolved - No Change after challenging those invariants, so this audit should not rewrite those later accepted rules.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The cardinality part of FHIR-10463 is already present in the authoritative current source, and the remaining description differences are explained by later applied or no-change ImagingStudy decisions rather than an unapplied seed gap.

Recommendation:
Keep this audit commit as-is. Do not reopen FHIR-10463 for source work unless the work group separately decides to revisit the newer ImagingStudy count invariants and related description wording.
