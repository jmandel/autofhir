FHIR-27800: Audit vital signs component quantity binding

Issue request:
FHIR-27800 is an Applied FHIR-core OO change request, resolved Persuasive for R6. It asked that the ucum-vitals-common binding that had been on Observation.component.value[x] in the Vital Signs profile apply only to the Quantity/valueQuantity slice, not to other component value types such as CodeableConcept, and also suggested checking whether unused vital-sign value datatypes should be constrained out.

Initial application:
No source commit found during this reconciliation explicitly names FHIR-27800. The issue was marked Persuasive and preapplied by OO on 2025-09-15. Source history shows the binding family was changed by related Observation/Vital Signs work: FHIR-27911 retained the binding on unsliced component.value[x] as extensible, FHIR-43353 moved the relevant unit bindings to quantity-specific elements and relaxed component quantity binding strength, and FHIR-47136/related component profiling work left the current source with a distinct Observation.component.value[x]:valueQuantity slice.

Additional context:
Observation is active in source/fhir.ini, and the Observation Vital Signs implementation guide includes StructureDefinition/vitalsigns, so source/observation/structuredefinition-profile-vitalsigns.xml is current build-scope source. Later applied FHIR-44721 and FHIR-47136 context intentionally changed the component valueQuantity binding from the narrow ucum-vitals-common value set to the all-UCUM value set http://unitsofmeasure.org/vs to avoid blocking downstream component units such as flow rate. Existing combined-branch reconcile commits already represent FHIR-43353, FHIR-44721, and FHIR-47136; this commit does not duplicate those decisions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source has no binding on unsliced Observation.component.value[x]; the only component unit binding is on Observation.component.value[x]:valueQuantity, whose type is Quantity. The fact that this slice now binds to http://unitsofmeasure.org/vs rather than ucum-vitals-common is a later approved correction, not a remaining FHIR-27800 defect.

Recommendation:
Keep this no-change audit. Further edits for FHIR-27800 would either re-narrow the component quantity binding contrary to later applied decisions or duplicate already-published related reconciliations.
