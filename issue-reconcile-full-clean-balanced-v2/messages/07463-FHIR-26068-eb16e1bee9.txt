FHIR-26068: Audit GraphDefinition FHIRPath wording

Issue request:
FHIR-26068 was a Published/Persuasive FHIR-I correction for R5 asking that GraphDefinition.link.path say "FHIRPath expression" instead of the ambiguous "FHIR expression".

Initial application:
The issue was applied in core by commit 2ff4cda4a3af626ee2a45d7c353410ea0eec85da, which changed source/graphdefinition/structuredefinition-GraphDefinition.xml so GraphDefinition.link.path used "A FHIRPath expression that identifies one of FHIR References to other resources." No prior reconcile commit for FHIR-26068 was present on the combined branch before this audit.

Additional context:
FHIR-I minutes for 2020-06-29 record the motion passing for FHIR-26068. Current R6 core no longer contains an active GraphDefinition resource: source/fhir.ini has no graphdefinition resource entry, source/conformance-module.html directs GraphDefinition to the API Incubator, and commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd removed source/graphdefinition from core. The current HL7/api-incubator-ig source for StructureDefinition-GraphDefinition carries the already-correct FHIRPath wording for GraphDefinition.link.path.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current core checkout is not the authoritative build source for GraphDefinition, and the external API Incubator source already preserves the FHIR-26068 wording.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-26068; any future GraphDefinition wording maintenance belongs in HL7/api-incubator-ig, but this specific definition is already correct there.
