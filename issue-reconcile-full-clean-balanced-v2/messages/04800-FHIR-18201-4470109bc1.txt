FHIR-18201: Audit CodeSystem filter clarification

Issue request:
FHIR-18201 was Published/Persuasive for FHIR-core ValueSet and asked that ValueSet.compose.include.filter explicitly allow criteria based on CodeSystem filters as well as CodeSystem properties, that filter.property and filter.op explain the filter case, that filter.value describe how filter values are interpreted, and that an example show a ValueSet compose include using a CodeSystem-defined filter.

Initial application:
The Jira comment identifies git 66ae1e40f1bc02283363c872db14035fc795f8f7 as the application commit. That commit added source/valueset/valueset-example-filter.xml, edited the ValueSet spreadsheet and notes to mention filters defined by CodeSystem.filter, and also included terminology cleanups. Current source has since migrated the ValueSet element definitions into source/valueset/structuredefinition-ValueSet.xml while preserving the accepted wording.

Additional context:
FHIR-13288 separately clarified the CodeSystem.filter.code side of the same relationship before FHIR-18201. Later Applied issues FHIR-38104 and FHIR-44866 rewrote the details for ValueSet.compose.include.filter.value into the current valueset.html#filter-values notes section, so the current filter.value definition intentionally delegates there rather than repeating the older R4 wording. Targeted Zulip and Confluence searches found no FHIR-18201-specific discussion or conflicting later decision.

AutoFHIR reconciliation:
No source change was made. The active ValueSet resource is in build scope, and current source already states that ValueSet.compose.include.filter criteria may be based on properties or filters defined by the system, filter.property may identify a property or filter, filter.op must match CodeSystem.filter.operator when filter.property is a filter, and filter.value is governed by the filter-values section. The requested CodeSystem-filter example is still present and listed among ValueSet examples.

Recommendation:
Keep this empty audit commit as-is. No FHIR core follow-up is needed for FHIR-18201 unless future terminology work deliberately changes the broader filter-value model.
