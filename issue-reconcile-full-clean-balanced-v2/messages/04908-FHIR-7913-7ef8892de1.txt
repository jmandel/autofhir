FHIR-7913: Audit MedicationStatement status clarification

Issue request:
FHIR-7913 was Published/Persuasive with Modification for the DSTU1 MedicationStatement.status wording. The reporter asked whether status described the medication order/prescription or the compliance/taking statement because the old definition said it was the state of the statement while the code definition for in-progress described the medication still being taken.

Initial application:
The Jira resolution said all Pharmacy statuses would be reviewed and updated with the attached spreadsheet. The Jira comment records that the work was fixed as part of tracker 6310 in svn 6552. In git history, d3c2a3a0552f97b710394710badf5ee4e69c0d56 is git-svn build@6552 and updated MedicationStatement.status codes as part of FHIR-6310, while follow-up commit 31e9678a6e9f698b2828df5d58dc739aad32c602 changed the MedicationStatement.status definition from the old state-of-statement wording to the state of the medication used that the statement is about.

Additional context:
MedicationStatement is active in the current build. Later Pharmacy decisions changed the model again: FHIR-12011 recognized the mixed record-status/use-status problem; FHIR-28593 made status the status of the record rather than medication use; FHIR-32060 and FHIR-39271 refined that into the current recorded/entered-in-error/draft status values and the separate MedicationStatement.adherence element for medication-taking semantics. Related audit/fix commits for several of those later issues are already on the combined branch.

AutoFHIR reconciliation:
No source change was made. The current authoritative MedicationStatement source says status is "the status of recording the medication statement," includes a comment directing medication-taking/adherence semantics to MedicationStatement.adherence, and the current status CodeSystem contains only recorded, entered-in-error, and draft. That is no longer the exact 2015 active/completed design, but it correctly resolves the ambiguity raised by FHIR-7913 after the later published redesigns.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the old active/completed MedicationStatement.status clarification into current source; future work on medication-taking semantics should use MedicationStatement.adherence and its terminology rather than MedicationStatement.status.
