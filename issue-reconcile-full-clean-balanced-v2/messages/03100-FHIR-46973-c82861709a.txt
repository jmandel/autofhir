FHIR-46973: Audit DeviceAssociation search parameters

Issue request:
FHIR-46973 was an Applied/Persuasive OO R6 change request about DeviceAssociation search parameters. It asked to restore/add a patient reference search parameter constrained to Patient, correct subject so it describes the broader individual or entity and uses DeviceAssociation.subject, and update DeviceAssociation patient compartment membership to include patient alongside subject/operator.

Initial application:
Jira records application in 11a4adc200. That commit updated source/deviceassociation/bundle-DeviceAssociation-search-params.xml by changing subject from the patient-only expression/description to DeviceAssociation.subject with the broader description, adding DeviceAssociation-patient with DeviceAssociation.subject.where(resolve() is Patient) and target Patient, and updating source/compartments.xml from subject | operator to patient | subject | operator for the patient compartment. Follow-up commit 2d0736366a changed the patient search parameter description to the approved "The patient associated with the device" wording.

Additional context:
DeviceAssociation is active in source/fhir.ini, and the current source keeps the FHIR-46973 search-parameter fixes. The subject reference target list is supplied by DeviceAssociation.subject in the StructureDefinition and appears on the generated search page; the patient search parameter renders as the common clinical-patient parameter with Target Resources Patient. Later applied FHIR-47604 removed DeviceAssociation.operator, added DeviceAssociation.focus, and replaced operator-based compartment participation with focus, so the current patient compartment row correctly reads patient | subject | focus rather than the older operator text. FHIR-47604 and FHIR-51498 are already represented on the combined branch, and no direct Zulip discussion for FHIR-46973 was found.
