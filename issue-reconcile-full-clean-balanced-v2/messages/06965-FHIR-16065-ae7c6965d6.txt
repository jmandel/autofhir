FHIR-16065: Audit BDP procedure application

Issue request:
FHIR-16065 was a Published OO change request for BiologicallyDerivedProduct. It asked to add procedure to manipulation in parallel with processing; the final resolution changed BDP.processing.procedure from CodeableConcept to CodeableReference(Procedure) and added BDP.manipulation.procedure as a 0..* CodeableReference(Procedure).

Initial application:
The change first appeared in the core resource review history in dae319f775, which changed processing.procedure to CodeableReference(Procedure) and added manipulation.procedure. After the broader BDP restructure, ed33c9b5aaa applied the issue to the core BDP processing/manipulation extension definitions instead, preserving processing.procedure as 0..1 CodeableReference(Procedure) and manipulation.procedure as 0..* CodeableReference(Procedure).

Additional context:
FHIR-33068 later replaced the BiologicallyDerivedProduct attribute set and its discussion explicitly treated processing and manipulation as extension-style content rather than resource backbone elements. OO and FMG minutes in December 2021 record that FHIR-16065 needed review to determine whether the restructure had lost anything. Core commit dd468d4f17 subsequently removed the BDP extension definitions from the R5 source, and the current Extension Pack contains active BDPProcessing and BDPManipulation definitions with the requested procedure CodeableReference(Procedure) slices. The current core resource remains active in fhir.ini but no longer defines processing or manipulation backbones.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current core checkout is not missing the procedure elements because the authoritative processing/manipulation extension definitions now live in the Extension Pack, and those definitions preserve the applied FHIR-16065 semantics.

Recommendation:
Keep this audit commit as-is for core FHIR. If future cleanup targets the BDP processing or manipulation extensions themselves, reconcile that work in HL7/fhir-extensions rather than reintroducing the removed core extension files.
