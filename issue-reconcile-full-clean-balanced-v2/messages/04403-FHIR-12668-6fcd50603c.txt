FHIR-12668: Audit condition partOf target support

Issue request:
FHIR-12668 was a Published/Persuasive Patient Care change request for DSTU2 asking that the condition-partOf extension support Reference(Condition) in addition to the existing Observation and Procedure targets, with the stated use case of one condition being part of another.

Initial application:
The request was applied before this reconciliation in git commit 913017fdf7d3b9fad5bb3c88c1cfa7395923b097, which changed source/condition/condition-extensions-spreadsheet.xml from Reference(Observation|Procedure) to Reference(Observation|Procedure|Condition) and updated the extension wording.

Additional context:
FHIR-13783 later clarified the condition-partOf wording, kept Reference(Observation|Condition|Procedure), and added condition-related for unspecified condition-to-condition relationships. FHIR-14446 later switched workflow resource-specific extensions to common workflow extensions; commit f235b25c5ef0e84d57ea366f811fa801f1db9a25 removed the Condition-specific partOf extension row. The current core checkout no longer has an active condition-partOf source definition, and the current FHIR Extension Pack has the common event-partOf extension with Condition as a context and Reference(Resource) as the value target, which includes Condition.

AutoFHIR reconciliation:
This audit commit makes no source change. The original requested target expansion was historically applied, and the current specification no longer needs a core Condition-specific extension edit because the current event-partOf extension lives in the Extension Pack and already allows a Condition reference.

Recommendation:
Keep this no-change audit commit. Do not restore condition-partOf in core. If future work wants to clean up the Extension Pack condition-related comment that still mentions a condition-partOf-style extension name, handle that in the Extension Pack under a separate tracker because it is outside this core reconciliation and does not change the FHIR-12668 target-support outcome.
