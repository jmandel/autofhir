FHIR-19344: Audit Immediate event-timing code

Issue request:
FHIR-19344 was a Published/Persuasive MnM change request raised against STU3 MedicationPrescription/MedicationRequest priority. The final resolution did not move MedicationRequest.priority; it required adding an Immediate timing code to http://hl7.org/fhir/event-timing with the definition "Occurs a single time (with no repetitions) as soon as possible after the scheduled or actual start of the overall event."

Initial application:
The issue appears to have been applied in c4807a5165ee632872ef9f6289fee8e9e1abbb5f ("MnM changes for R5"), whose message explicitly lists FHIR-19344 and whose patch adds the IMD/Immediate row with the requested definition to source/datatypes/timing.xml. A short-lived timing-abbreviation CodeSystem file from the same work was removed in 6314862f6c410bf17b0136e5e54e1d20b7c2d5c3 while keeping codes directly in the datatype spreadsheet.

Additional context:
The current build source keeps Timing.repeat.when bound to EventTiming, defines the EventTiming value set from #event-timing in source/datatypes/timing.xml, and contains code IMD with display Immediate and the requested single-time/as-soon-as-possible definition. R5 and current CI CodeSystem event-timing pages also show IMD/Immediate, confirming the R5-applied source is present on the publication surface. Community searches found no Zulip or Confluence evidence changing this interpretation.

AutoFHIR reconciliation:
No source change was made. The current source already implements the Jira resolution; retaining MedicationRequest.priority is consistent with the final decision because the approved fix was to add Timing.repeat.when support for immediate administration rather than to move the request-level priority element.

Recommendation:
Keep this no-change audit commit as-is. Revisit only if MnM later decides that the code mnemonic must literally be IMMEDIATE rather than the existing FHIR code IMD, but current source and published R5/current build behavior consistently use IMD with display Immediate.
