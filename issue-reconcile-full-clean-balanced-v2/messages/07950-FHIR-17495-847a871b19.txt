FHIR-17495: Audit Observation reagent extension ownership

Issue request:
FHIR-17495 was Published/Persuasive for STU3 and asked to add a standard Observation reagent extension, cardinality 0..*, whose value is Reference(Substance), to carry reagents/substances used to generate a laboratory observation.

Initial application:
The issue was applied in core by git commit 93900ade91 ("fixed Overvation-reagent extension - GF#17495"), which updated the Observation extension spreadsheet entry for Reagent to use Reference(Substance) and the approved wording. That later produced a core StructureDefinition for observation-reagent before the extension-source split.

Additional context:
Core no longer owns this extension definition. Git commit dd468d4f17 removed observation-reagent and the other resource extension definitions from the R5 core source/Observation implementation guide, while the current FHIR Extension Pack repository describes itself as the separate specification for standard extensions referenced by core. The extension pack contains an active StructureDefinition/observation-reagent with context Observation, max 0..*, value Reference(Substance), the approved in-lab LIS wording, and the original OID still appears in core source/oids.ini. Zulip and Confluence evidence show the laboratory reagent use case and later discussion, but no discovered final decision requires reintroducing the extension into core.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the FHIR core checkout. The requested artifact belongs to, and is already represented in, the FHIR Extension Pack rather than current core source.

Recommendation:
Keep this audit as-is for core. Future changes to observation-reagent should be made in HL7/fhir-extensions unless a work group explicitly decides to move the extension definition back into core.
