FHIR-12430: Audit QuestionnaireResponse alignment note

Issue request:
FHIR-12430 was Published/Persuasive for DSTU2 and asked that QuestionnaireResponse make clear that, when it points to a Questionnaire, its groups and nested questions must be structured consistently with that Questionnaire.

Initial application:
The issue was applied historically in commit 6048380f2c7ce7028763d9790403cc48c6839438, which added the requested usage note to source/questionnaireresponse/questionnaireresponse-notes.xml. Later source rework commits, including 33b409a4b6 and c69d71aa21, carried the same alignment sentence into the generated StructureDefinition source for QuestionnaireResponse.questionnaire.

Additional context:
QuestionnaireResponse is active in source/fhir.ini, and the current active source has the alignment rule in both source/questionnaireresponse/structuredefinition-QuestionnaireResponse.xml and source/questionnaireresponse/questionnaireresponse-notes.xml. Later FHIR-37550 made QuestionnaireResponse.questionnaire required and added legacy/non-resolving Questionnaire caveats, so the current wording correctly scopes the FHIR-12430 rule to references that can be resolved rather than requiring impossible alignment when no Questionnaire definition exists. Zulip discussions in 2018 and 2019 challenged the rule and recorded the rationale for retaining it; no Confluence reference for FHIR-12430 was found.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current spec already conveys the required consistency rule on the authoritative element definition and the QuestionnaireResponse narrative page, and changing it back to the original unqualified sentence would conflict with later published FHIR-37550 guidance.

Recommendation:
Keep this no-change audit. No follow-up is needed for FHIR-12430 unless a future work group decision changes the handling of QuestionnaireResponse instances whose questionnaire canonical cannot be resolved.
