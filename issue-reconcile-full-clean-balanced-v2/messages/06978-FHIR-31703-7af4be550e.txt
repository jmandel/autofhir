FHIR-31703: Audit Resource Types navbar emphasis

Issue request:
FHIR-31703 was a Published FHIR-core/R4B ballot issue asking why the Resource Types item in the generated site navbar appeared highlighted no matter which page/tab was selected. The final Not Persuasive with Modification resolution said the item was intentionally emphasized as important, but should be highlighted in a way that looked less like a selected tab.

Initial application:
The Jira comment cites git caafe82c5220821d282ae8b295e4b7a472875296. That commit changed tools/templates/newnavbar.html, replacing the old yellow Resource Types span with bold/italic text while also applying same-navbar menu changes for FHIR-16526 and FHIR-12773. A follow-up commit, 94db6fa8858589cf796c599e9fc1919fa8f6137c, restored the <%level%> path prefix on the changed navbar links without reverting the Resource Types emphasis.

Additional context:
tools/templates/newnavbar.html is in build scope because source pages and template wrappers include it with [%file newnavbar%]. Confluence FHIR-I WGM minutes for May 2021 reference FHIR-31703 and record the 21-0-0 Not Persuasive with Modification motion. Later navbar history did not restore the yellow styling or introduce selected-tab behavior for Resource Types, and an exact Zulip issue-key search found no contradictory discussion.
