FHIR-40531: Audit DeviceDispense QA fixes outside core build

Issue request:
FHIR-40531 was Published with a Persuasive with Modification resolution for R5 DeviceDispense QA findings. The accepted scope was to create the missing DeviceDispense `status` and `identifier` search parameters and address the root short description warning; the CodeableConcept/Coding binding warnings for `category`, `performer.function`, and `type`, plus the patient search-parameter example warning, were explicitly left for future consideration.

Initial application:
The search-parameter part was applied by git commit b3d9958540b54b91cabc69fbe7e4dd36aa8ba7ce, which added `DeviceDispense-identifier` and `DeviceDispense-status` to `source/devicedispense/bundle-DeviceDispense-search-params.xml`; PR #2813 merged that work. The short-description part was applied during the same QA period by commit 902ba6f12616081ae5bda98e46bae0150ef0ea28, with commit 002d86145a88b695a063f0dafe13531a30644eb9 removing the trailing period. The R5 tag and the current retained core source both contain the requested search parameters and the non-redundant root short `A record of dispensation of a device`.

Additional context:
DeviceDispense is no longer an active FHIR core build artifact. Current `source/fhir.ini` has no active `devicedispense=DeviceDispense` entry under `[resources]`, and git commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed DeviceDispense and other OO resources from core while pointing core narrative links to the OO Incubator IG. The current core CI pages for DeviceDispense and its search parameters return 404, while the OO Incubator IG exposes `DeviceDispense-status` and `DeviceDispense-identifier` with the expected expressions.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. Editing `source/devicedispense` would modify retained but out-of-build core source, and the accepted FHIR-40531 changes are already present in the historical R5 source and in the current external OO Incubator publication surface.

Recommendation:
Keep this audit commit as-is for core. No FHIR core source follow-up is needed for FHIR-40531; any future DeviceDispense maintenance should be reconciled in the OO Incubator source, or in whichever repository owns DeviceDispense if it returns to core.
