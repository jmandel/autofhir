FHIR-44603: Audit Patient contact priority extension outside core

Issue request:
FHIR-44603 was an Applied/Persuasive Patient Administration change request asking for a standard Patient.contact contact-priority extension: 0..1 positiveInt, titled Patient Contact Priority, scoped to Patient.contact, with guidance for equal priorities and contacts without a priority.

Initial application:
No core source-changing commit was found for FHIR-44603. The issue was applied in the FHIR Extension Pack by commit a24c7b912c073437ca818dcc6766a07642ee92a8, which created input/definitions/Patient/StructureDefinition-patient-contactPriority.xml with Patient.contact context, positiveInt value, max 1, the requested title/description, and an OID that is also registered in core source/oids.ini.

Additional context:
Core source/fhir.ini actively includes the Patient resource, but the current core checkout does not contain the Patient contact-priority StructureDefinition; the Extension Pack includes input/definitions/* in its IG source. Later applied extension-family decisions changed the extension-pack surface: FHIR-50768 broadened patient-contactPriority beyond Patient.contact and deprecated organization-preferredContact, while FHIR-49912 introduced a general rank extension and asked for patient-contactPriority to point there. Current extension-pack source therefore retains patient-contactPriority as a retired extension pointing at rank rather than as an active core-defined extension.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The remaining authoritative extension definitions and any cleanup of same-priority/missing-priority guidance or the later rank replacement belong in the FHIR Extension Pack, not this FHIR core checkout.

Recommendation:
Keep this core audit commit as-is. If further work is desired, review the FHIR Extension Pack definitions for patient-contactPriority and rank: FHIR-44603's post-vote guidance about contacts with equal or absent priority is not explicitly preserved in the current retired contact-priority text, and the FHIR-49912 rank replacement should be checked in that repository rather than patched in core.
