FHIR-19728: Audit Observation search expression fix

Issue request:
FHIR-19728 was a Published/Persuasive OO change request for STU3/R4 publication asking to fix the FHIRPath expressions for Observation combo-value-quantity, component-value-quantity, value-quantity, and value-string search parameters. The cited Zulip thread identified invalid operator precedence where `|` bound ahead of `as`, requiring parenthesized casts before R4 publication.

Initial application:
The issue was pre-applied as a technical correction before publishing R4. The relevant source application is git commit 005eb62bce088bddc5a6fad83a7978027490a419, which changed source/observation/observation-spreadsheet.xml to wrap each affected `as` expression operand in parentheses. The Zulip discussion records Grahame confirming that this was the right fix and Eric/Brian applying it during build freeze.

Additional context:
The current build no longer uses the old spreadsheet row as the active source; Observation is active in source/fhir.ini and its search parameters are tracked in source/observation/bundle-Observation-search-params.xml. Later source rework and FHIR-29653 converted the parenthesized `as` expressions to `ofType(...)`, and later Observation search-parameter changes adjusted the value coverage independently. The current cited expressions contain no old unparenthesized `as` operators and are valid FHIRPath for the current model.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The active Observation search-parameter source already carries corrected FHIRPath expressions for combo-value-quantity, component-value-quantity, value-quantity, and value-string, so reintroducing the historical parenthesized `as` spelling would be stale rather than corrective.

Recommendation:
Keep this no-change audit commit as-is. Any future changes to these search parameters should be handled through newer Observation/search-parameter trackers, not by replaying the pre-R4 spreadsheet correction.
