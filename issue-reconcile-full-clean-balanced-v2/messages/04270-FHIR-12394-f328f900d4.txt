FHIR-12394: Audit Medication ingredient guidance

Issue request:
FHIR-12394 was a Published/Persuasive FHIR-core Medication change request asking why DSTU2 Medication.product.ingredient could reference either Substance or Medication. The final Pharmacy resolution was to add documentation explaining that compounded medications can have multiple ingredients, some base chemicals such as hydrocortisone powder and some manufactured products such as Glaxal Base.

Initial application:
The Jira comments cite git-svn/Git commit b0500f8b520d72851aba346483f21d1ded9a86b3 (@11055), whose subject explicitly includes TR 12394. That commit updated source/medication/medication-introduction.xml with the compounded-product paragraph using the hydrocortisone powder and Glaxal Base examples while also applying FHIR-12764's removal of the Medication.product backbone.

Additional context:
Medication is an active current-build resource in source/fhir.ini. Because FHIR-12764 removed Medication.product, the current comparable path is Medication.ingredient. The current Medication introduction still contains the FHIR-12394 compounded-product explanation, and the current Medication.ingredient.item definition is a CodeableReference that can target Substance, SubstanceDefinition, or Medication, with a Glaxal Base example for another-medication ingredients. Later tightly related decisions FHIR-16024 and FHIR-36499 preserved and expanded this guidance and are already represented on the combined branch, so they are cited as context rather than republished here. Zulip and Confluence searches found no conflicting community record; one Zulip thread quoted the same Medication scope text while discussing Medication identifiers.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The build-scoped Medication source already explains when a Medication ingredient may be another manufactured medication product and no current source location contradicts that rule.

Recommendation:
Keep this no-change audit as-is. No FHIR-core follow-up is needed for FHIR-12394 unless Pharmacy opens a new current-version request to change how compounded-product ingredient hierarchies are represented or resolved.
