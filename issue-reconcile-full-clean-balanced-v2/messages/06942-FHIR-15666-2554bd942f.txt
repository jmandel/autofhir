FHIR-15666: Audit Specimen.subject Location support

Issue request:
FHIR-15666 was a Published OO change request, resolved Persuasive with Modification, asking to add Location as an allowed reference target for Specimen.subject and to describe environmental specimens as coming from a location.

Initial application:
The issue was applied in two 2018 source commits: 6a1430471a added Location to the Specimen.subject reference list, and 68d00fb715 updated the subject definition with the location/environmental-sample wording. The current XML StructureDefinition was later regenerated into source/specimen/structuredefinition-Specimen.xml by 33b409a4b6 with Location still present.

Additional context:
Specimen is an active resource in source/fhir.ini, so source/specimen/structuredefinition-Specimen.xml is in the current build scope. Later R6 work in FHIR-53384 and FHIR-56301 added/refined Specimen.focus and changed Specimen.subject to mean subject of record; that later decision explicitly retained location as a possible Specimen.subject target while directing non-record sources to Specimen.focus. Both related issues already have reconcile commits on the combined branch, so this seed should not duplicate them.

AutoFHIR reconciliation:
No source change was made. The current Specimen.subject definition says the subject may be a patient, group, location, device, or another entity, and its Reference target list includes http://hl7.org/fhir/StructureDefinition/Location. A related SpecimenDefinition $apply parameter also still lists Location as an allowed subject. The remaining checked-in SVG still has older generated-looking title text that includes Location; it is not the authoritative source for this decision and does not justify a source-only fix.

Recommendation:
Keep this audit commit as-is. The current build-scope source satisfies FHIR-15666 after accounting for the later Specimen.focus refactor; no follow-up in core is needed for this issue.
