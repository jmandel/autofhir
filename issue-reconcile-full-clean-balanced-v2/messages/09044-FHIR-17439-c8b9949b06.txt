FHIR-17439: Record existing group/display guidance

Issue request:
FHIR-17439 was a Published FHIR-core Questionnaire change request, resolved Persuasive with Modification, asking to clarify the difference between Questionnaire item types group and display. The approved resolution rejected moving the usage table into Scope and Usage, but required Notes guidance about when group versus display should be used and why.

Initial application:
The issue appears to have been applied in SVN revision 14772, imported as git commit b8c5990ac5ad735ba1e8e836fd8a4c6fd3534a3e, whose commit subject lists 17439 and whose patch added Questionnaire notes explaining that group text is a short label/heading for nested items and that detailed instructions should be represented with display items. No separate Jira-keyed git commit was found, but the SVN-tagged commit and Jira comment "SVN #14772" align.

Additional context:
The current Questionnaire notes are in build scope because source/fhir.ini has an active Questionnaire resource entry. The current notes distinguish display items, group items, and question items, then state that group text is intended as a label/heading and that detailed instructions should be conveyed by nested display items or intermingled display items. The linked Zulip discussion confirms the intended distinction: groups organize content and are reflected as headings/response structure, while display items carry instructions or help text. Related published issue FHIR-17910 later reinforced the same point in Questionnaire.item.text guidance.

Recommendation:
