FHIR-52870: Audit CDS Hooks indicator map move

Issue request:
FHIR-52870 was Applied/Persuasive for R6 by Vocabulary. It requested that the CDS Hooks Indicator to Request Priority ConceptMap stop being treated as an example, move to CDS ownership, and carry normative/FMM 5 metadata, with application dependent on FHIR-48308 adding explicit source and target CodeSystems.

Initial application:
The core source first received the FHIR-48308 dependency in commit c06394415c05a44bfdb6b7d150d0730634862e7e, which added group.source and group.target to source/conceptmap/conceptmap-cdshooks-indicator.xml while the map was still in core. The FHIR-53085 core cleanup then removed the CDS Hooks indicator map from the ConceptMap examples list and removed the core copy of the ConceptMap in commit 1268605a53fabdafc86a868ba2a51656aa9907c7. Jira comments for FHIR-52870 and FHIR-48308 point to HL7/cds-hooks-clinical-reasoning commit 61bbc5e8933a1eed0012f8efe7b6627172a687d8 as the application location.

Additional context:
FHIR-53085 moved CDS-on-FHIR page content, related profiles, and CDS Hooks mapping ConceptMaps from FHIR core to the Using FHIR Clinical Reasoning with CDS Hooks IG. Current core source no longer has conceptmap-cdshooks-indicator or an example-list entry for it; the clinical reasoning CDS Hooks page points readers to that IG. The external IG ConceptMap has CDS work-group ownership, is active/non-example content, and includes the FHIR-48308 CodeSystem source and target values, but its current metadata still shows trial-use/FMM 4 rather than the normative/FMM 5 wording in the FHIR-52870 resolution.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The artifact FHIR-52870 governs has been removed from the current FHIR core build and is maintained in HL7/cds-hooks-clinical-reasoning, so any remaining standards-status/FMM metadata adjustment belongs in that external repository rather than in this checkout.

Recommendation:
Keep this audit commit for core. Follow up in HL7/cds-hooks-clinical-reasoning if the CDS/Vocabulary decision still requires changing the moved ConceptMap from trial-use/FMM 4 to normative/FMM 5 before publication; no FHIR core source edit is indicated unless the map is returned to core build scope.
