FHIR-36030: Audit search result parameter singleton guidance

Issue request:
FHIR-36030 was Published as Persuasive for R5. It asked what should happen when search result parameters such as _sort, _count, _summary, _elements, and _total appear more than once, and the accepted resolution clarified that all search result parameters except _include and _revInclude SHOULD only appear once; if such a parameter appears more than once, behavior is undefined and a server MAY treat it as an error.

Initial application:
The issue was initially applied in a3a5c74c15013f3d02db070631edd347f7f8cf61, which added the singleton guidance to source/search.html under Modifying Search Results. A later search-page refactor in ebb31030e5595881bd9f0511dafcbdf6e26dac365 for FHIR-22785 reorganized the same section, added the summary table, and preserved the FHIR-36030 guidance with code formatting and normalized _revinclude casing.

Additional context:
FHIR-I minutes from 2022-04-25 record the same decision and 10-0-0 vote. source/hierarchy.xml and source/documentation.html actively include search.html in the RESTful API/Search navigation, so the checked source page is in current build scope. Current source/search.html also explains that search result parameters are not SearchParameter resources and do not appear in the registry, which keeps this clarification scoped to result-control parameters rather than ordinary search filters. Targeted Jira, Zulip, and Confluence searches found no later FHIR-core decision that reverses or narrows the duplicate-result-parameter rule.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active Search page already contains the accepted conformance statement, including both exceptions and the undefined/error behavior for repeated non-include result parameters.

Recommendation:
Keep this no-change audit commit as-is. No FHIR-core source follow-up is needed for FHIR-36030 unless a future work group decision chooses to define repeated search result parameter behavior more precisely.
