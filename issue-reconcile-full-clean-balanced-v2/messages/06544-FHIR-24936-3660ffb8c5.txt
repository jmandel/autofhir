FHIR-24936: Audit healthcare product scope updates

Issue request:
FHIR-24936 was Published/Persuasive for R5 by OO. It asked to update the Scope and Usage and Boundaries and Relationships descriptions for healthcare-product resources, including BiologicallyDerivedProduct, Device, DeviceDefinition, DeviceUseRequest/DeviceUseStatement successors, Substance, and SupplyRequest, according to the attached clean/markup documents and Jira comment corrections.

Initial application:
The issue was applied in multiple historical source commits. The February 2020 Device and DeviceUseStatement updates explicitly listed FHIR-24936 and changed the Device kind/instance and DeviceUseStatement reporting text. Commit 578361a9000ef12bb67e86de2e5fb27ea52bd79a, titled FHIR-24936, then changed BiologicallyDerivedProduct, DeviceDefinition, DeviceRequest, Substance, SupplyDelivery, and SupplyRequest narrative and StructureDefinition descriptions. Current source retains the material parts of those changes, though later R6 work has refactored names, wording, and ownership.

Additional context:
FHIR-27941 and OO HCP minutes recorded that the original FHIR-24936 application was not fully applied, particularly for SupplyRequest. That follow-up was later resolved and is already represented on the combined branch. Other related audits and fixes on the combined branch address neighboring consequences, including DeviceRequest/SupplyRequest boundary history, SupplyRequest definition migration, and the DeviceDefinition packaging sentence that a broad scope rewrite had overwritten. Current source/fhir.ini lists BiologicallyDerivedProduct, Device, DeviceDefinition, DeviceRequest, DeviceUsage, and Substance as active resources, while SupplyRequest and SupplyDelivery were removed from the active core build by commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 and redirected to the OO Incubator.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active core resources already convey the requested healthcare-product scope and boundary distinctions: biologically derived product versus nutrition/medication/substance, Device versus DeviceDefinition kind/instance usage, patient-focused DeviceRequest, report-focused DeviceUsage, and Substance as an instance material distinct from SubstanceDefinition and NutritionProduct. The retained SupplyRequest files still show the FHIR-24936 inventory-management/non-patient-specific wording, but SupplyRequest is no longer an active core resource, so editing it here would not be a current-spec fix.

Recommendation:
Keep this no-change audit commit as-is. Do not edit dormant core SupplyRequest/SupplyDelivery files for FHIR-24936; if OO wants additional SupplyRequest wording changes, make them in the current OO Incubator source or open a new core issue for active cross-resource guidance.
