FHIR-47040: Audit removed ImmunizationRecommendation series wording

Issue request:
FHIR-47040 was Applied/Persuasive with Modification for R6 by PHER. It asked for ImmunizationRecommendation.recommendation.series to keep the short display "Name of vaccination series", replace the unclear definition with "The name of the vaccination series within the context of the authority which defines the series. A series is one possible path to achieve presumed immunity against a disease.", and add Scope and Usage text explaining series within immunization schedules.

Initial application:
The requested source change was applied in commit 84178e5179049f1620aeb7d7b565c278b5c268a1, later merged by PR #3402 in 778a9f472b522e53cbaf6f0ecbd91b9e5b98c05d. That commit updated source/immunizationrecommendation/structuredefinition-ImmunizationRecommendation.xml and source/immunizationrecommendation/immunizationrecommendation-introduction.xml with the Jira-approved definition and narrative text.

Additional context:
The current build no longer contains the ImmunizationRecommendation resource. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed ImmunizationRecommendation and ImmunizationEvaluation source directories and deleted their active source/fhir.ini resource, work group, compartment, FMM, abbreviation, and status entries. The current source/fhir.ini active resources list contains immunization=Immunization but no immunizationrecommendation entry, and source/immunizationrecommendation is absent in the current checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The Jira-requested wording was already applied to the target resource before that resource was removed from the current build. Reintroducing source/immunizationrecommendation or applying this wording to the separate Immunization.protocolApplied.series element would exceed the seed issue scope and change a current artifact without a supporting decision for that artifact.

Recommendation:
Keep this audit commit as-is for the current build. If ImmunizationRecommendation is reintroduced in core, restore the FHIR-47040 wording from commit 84178e5179049f1620aeb7d7b565c278b5c268a1. Any remaining stale references to the deleted ImmunizationRecommendation resource should be handled as a separate removal-cleanup issue, not as part of this series-description reconciliation.
