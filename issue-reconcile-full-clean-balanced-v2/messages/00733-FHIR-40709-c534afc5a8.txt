FHIR-40709: Audit select-by-map Extension Pack move

Issue request:
FHIR-40709 is an Applied/Persuasive FHIR-core ValueSet change request from the vocab work group. It asked the committee to consider the select-by-map use case, where a ValueSet selection should also select source codes mapped to selected target codes, and the final resolution was to move the temporary fhir-tools extension and associated value set to the Extensions Pack at maturity level 1.

Initial application:
No prior FHIR core source application was found. The Jira comments point to HL7/fhir-extensions#120, and the Extension Pack history shows commit 9e454aa adding the select-by-map StructureDefinition and its select-by-map-filter ValueSet under input/definitions/ValueSet. Later Extension Pack commits corrected the canonical id/URL, the r4-equivalence system URL, and the responsible work-group code.

Additional context:
VOC WGM minutes record the approved motion to move the extension as defined, and its associated value set, from the temporary fhir-tools location to the Extensions Pack. FHIR-46218 is a later Published FHIR-extensions tracker for the same migration and tooling-IG deprecation; it confirms that the extension and terminology artifacts belong in the Extension Pack rather than the FHIR core source checkout. Current published Extension Pack pages expose the Select By Map extension and the select-by-map-filter value set.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. The current core source has no select-by-map artifacts to correct, while the Extension Pack source and publication contain the extension and value set requested by FHIR-40709, so the remaining ownership is outside this checkout.

Recommendation:
Keep this as an external-repo audit. No FHIR core follow-up is needed for FHIR-40709; any future corrections to the extension text, value set contents, or tooling-IG deprecation should be handled in the FHIR Extension Pack or fhir-tools IG repositories.
