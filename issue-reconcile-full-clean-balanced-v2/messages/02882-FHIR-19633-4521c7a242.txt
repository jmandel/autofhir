FHIR-19633: Audit status comment rationale

Issue request:
FHIR-19633 was a Published/Persuasive Patient Care change request asking to add comments to AllergyIntolerance and Condition clinicalStatus and verificationStatus explaining why the elements are CodeableConcept despite required bindings: the status judgments may need more specificity than the required FHIR value sets allow, such as additional SNOMED or local coding specificity.

Initial application:
The issue was applied by commit cccb69d8142e7ec5234dde242ca3da5d556591f5, which added the requested rationale to the then-authoritative AllergyIntolerance and Condition spreadsheets. Later source-rework commits carried those comments into the active StructureDefinition XML source used by the current build.

Additional context:
AllergyIntolerance and Condition are active resources in source/fhir.ini. The current AllergyIntolerance clinicalStatus and verificationStatus comments still contain the requested rationale, and Condition clinicalStatus does as well. Condition.verificationStatus now uses later FHIR-54914 wording, applied by commit 921fc1585a203f472f9650a5896e155734300777, that keeps the same implementer meaning by explaining that the required binding code may be accompanied by additional, more specific codings from other terminologies. The linked Zulip discussion and Patient Care minutes support that this was documentation rationale for retaining CodeableConcept with required bindings, not a request for a further conformance change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already gives implementers the requested rationale for all four affected status elements, with the one later-refined Condition.verificationStatus comment preserving and clarifying the same rule.

Recommendation:
Keep this no-change audit commit as-is. Do not reinsert the older Condition.verificationStatus wording because FHIR-54914 deliberately replaced it with clearer required-binding guidance while preserving the additional-specificity rationale relevant to FHIR-19633.
