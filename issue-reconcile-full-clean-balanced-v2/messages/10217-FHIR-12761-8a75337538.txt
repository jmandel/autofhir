Initial application:
The Jira comment records svn @11106, and git commit 69a658a0b7af9cf0af86f4c9f0eb23e1eb790785 matches that application by changing the old Questionnaire spreadsheet invariant text and XPath from answered to hasAnswer. That historical source is no longer the current authoritative Questionnaire definition.

Additional context:
Questionnaire is in the current build scope through source/fhir.ini. Later Questionnaire enableWhen work, especially FHIR-15665 and commit 651aa532afe40d621b6a593df3fabc0b86b0af62, dropped hasAnswer and introduced the current operator plus answer[x] model. The current source/questionnaire/structuredefinition-Questionnaire.xml defines Questionnaire.item.enableWhen.question, operator, and answer[x], and a source-wide search found no remaining copy of the obsolete human wording.
