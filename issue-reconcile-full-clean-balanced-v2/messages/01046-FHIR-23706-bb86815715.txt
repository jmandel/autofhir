FHIR-23706: Audit Consent ResearchStudy extension ownership

Issue request:
FHIR-23706 was Published/Persuasive for FHIR-core Consent. It requested a ResearchStudyContext extension on Consent.provision as a Reference(ResearchStudy), with an invariant limiting use to research-scoped Consents.

Initial application:
The issue appears to have been initially applied in commit f42fe3d5760779e6b4967c9e2f66fcc36564eba1, which added the Consent.provision ResearchStudyContext extension row and a Consent-level ppc invariant to the old Consent spreadsheets. Commit 33b409a4b6d544598262f2f074ebb4b6dc466157 later converted Consent to generated StructureDefinition XML, including structuredefinition-extension-consent-ResearchStudyContext.xml.

Additional context:
FHIR-31903 later made a Published/Persuasive with Modification decision to eliminate Consent.scope, make Consent.category 0..*, and leave scope-specific guard rails to profiles or implementation guides. Current core source has Consent active in source/fhir.ini, but no Consent.scope element and no core-owned consent-ResearchStudyContext StructureDefinition. Commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed the core extension source, and the current tracked extension definition is in the FHIR Extension Pack at input/definitions/Consent/StructureDefinition-consent-ResearchStudyContext.xml. That definition keeps the requested Consent.provision context and Reference(ResearchStudy) value, while the original Consent.scope invariant is no longer applicable.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. Reintroducing a Consent.scope-based invariant would reference a removed element and would conflict with the later FHIR-31903 direction that scope-specific rules belong in profiles or implementation guides. The authoritative extension source is now outside this core checkout.

Recommendation:
Keep this audit commit as-is for FHIR core. If CBCC wants a new category-based constraint for this extension, that should be a new work-group decision and Extension Pack/profile change rather than a core source fix for FHIR-23706.
