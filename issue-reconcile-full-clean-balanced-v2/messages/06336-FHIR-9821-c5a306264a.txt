FHIR-9821: Audit Procedure used CodeableReference

Issue request:
FHIR-9821 was a Published Patient Care change request with a Persuasive resolution asking Procedure.used to support a CodeableConcept or a reference, specifically by replacing Procedure.used with usedCode 0..* CodeableConcept and usedReference 0..* Reference(Medication|Substance|Device).

Initial application:
The issue was applied in SVN r9015, imported as git commit c725899b327ab6d1589f58c19d65d3fc96c7ca87, which replaced Procedure.used with Procedure.usedCode and Procedure.usedReference and updated Procedure examples. Later source refactoring moved the same meaning into CodeableReference.

Additional context:
FHIR-3715 originally introduced the Procedure supplies-used element. FHIR-31539 later records that in R5 the requested code-or-reference capability had already been pre-applied through the CodeableReference datatype. The current R5/R6 diff mapping in source/fhir.ini maps both Procedure.usedCode and Procedure.usedReference to Procedure.used.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Procedure is in active build scope, and the current Procedure.used element is a repeating CodeableReference with concept support and references to Device, Medication, Substance, and BiologicallyDerivedProduct, preserving and modernizing the split usedCode/usedReference design.

Recommendation:
Keep this audit as-is. The current CodeableReference representation is the intended modern source form of FHIR-9821, so reintroducing separate usedCode/usedReference elements or adding redundant prose would be incorrect for the current build.
