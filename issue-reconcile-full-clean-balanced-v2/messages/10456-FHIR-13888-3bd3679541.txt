FHIR-13888: Audit $convert operation already present

Issue request:
FHIR-13888 was a Published FHIR-core change request, raised for STU3 and resolved Persuasive with Modification, asking for a draft system-level operation to convert a FHIR instance from one format to another. The original proposal name was $convert-format, but the accepted resolution was to add the draft operation per the linked implementers discussion.

Initial application:
The Jira records svn revision 14068 as the application. In git-svn history, b2cfcb7d23 added the Resource spreadsheet operation row for code convert as a system operation with draft/FMM 1 metadata, single Resource input/output parameters, and format-conversion prose; 9af457e51d then added the request/response examples. The current source has since been migrated from the spreadsheet into source/resource/operationdefinition-Resource-convert.xml and the Resource operations list.

Additional context:
The linked Zulip discussion shows Grahame Grieve described GF#13888 as creating $convert to convert resources between JSON and XML, while also labeling broader conversion uses as draft experimentation. Later Published issues refined the same operation without reversing it: FHIR-37983 renamed input/output parameters to resource/return, and FHIR-20912 clarified the HTTP version-parameter rule for operations such as $convert that perform version conversion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Resource source already defines OperationDefinition/Resource-convert with code convert, system=true, type=false, instance=false, draft status, FMM 1, one required Resource input named resource, one required Resource output named return, examples for XML-to-JSON and version conversion, and an HTTP-page cross-reference to $convert.

Recommendation:
Keep this audit commit as-is. No follow-up core source change is needed for FHIR-13888 unless FHIR-I later decides to split $convert into more specific operations or define additional conversion parameters.
