FHIR-6044: Audit Questionnaire subjectType

Issue request:
FHIR-6044 was a Published/Persuasive FHIR-core Questionnaire change request from DSTU1 asking to add Questionnaire.subjectType 0..* bound to the list of resource types, because QuestionnaireAnswers/QuestionnaireResponse.subject could reference any resource and Questionnaire needed a way to declare allowed subject types.

Initial application:
The issue appears to have been applied in SVN r5941, now git commit 26e8b597d5034f4372a848e5660a88268f4b664c, whose message lists {#6044} and whose patch added subjectType values to Questionnaire examples and updated the then-authoritative Questionnaire spreadsheet. Later source refactors converted the spreadsheet-backed definition into source/questionnaire/structuredefinition-Questionnaire.xml without losing the element.

Additional context:
Questionnaire is in the active [resources] list in source/fhir.ini, so source/questionnaire/structuredefinition-Questionnaire.xml is current build input. A later FHIR-core clarification, FHIR-11004, explains the relationship to QuestionnaireResponse.subject and is already represented on the combined branch. A later FHIR-sdc issue, FHIR-27844, relaxed an SDC profile cardinality restriction and confirmed that an absent subjectType means no subject-type restriction; that is consistent with the current core comment and does not require a core source edit.

AutoFHIR reconciliation:
No source change was made. The current Questionnaire source defines Questionnaire.subjectType with min 0, max *, type code, a required binding to http://hl7.org/fhir/ValueSet/resource-types, and the comment that if none are specified the subject is unlimited. QuestionnaireResponse.subject also carries the related clarification that when a Questionnaire declares subjectType, the response subject must be one of the listed types.

Recommendation:
Keep this audit commit as-is. The current core build source already satisfies FHIR-6044 and later related clarifications; no additional FHIR-core change is recommended.
