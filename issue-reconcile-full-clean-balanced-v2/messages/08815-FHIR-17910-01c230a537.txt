FHIR-17910: Audit Questionnaire group text guidance

Issue request:
FHIR-17910 was a Published/Persuasive FHIR-core Questionnaire change request asking for guidance that Questionnaire group item text be limited to a short section heading and that longer group instructions be represented as display-type child items.

Initial application:
Jira records Git #ecdd7d61. That hash is the 2018-10-31 HL7/fhir merge commit for PR #189, and the included 9b1695bfd416c4f23560a3e60b999b6c5600db58 Questionnaire changes commit added the requested item.text comment to the then-authoritative Questionnaire spreadsheet. The 2021 source rework preserved the wording in the current StructureDefinition XML source.

Additional context:
Questionnaire is active in the current build through source/fhir.ini. The current Questionnaire.item.text definition already says section text should use a group-type item, be a short string suitable for a section heading, and place group instructions in a display-type child item. The current Questionnaire notes also explain that group text is a label/heading and detailed instructions should be nested display items. Corrected Zulip and Confluence searches found no community record that conflicts with this source/history conclusion. FHIR-17911 is a separate SDC shortText extension issue already represented on the combined branch and does not require a FHIR-17910 source change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current Questionnaire source already contains the guidance requested by FHIR-17910 in both the item.text element comment and the resource notes, so adding more prose would be redundant and could create maintenance drift.

Recommendation:
Keep this empty no-change audit commit as-is. No FHIR-core follow-up is indicated for FHIR-17910 unless the work group later changes how group headings and display-item instructions should be modeled.
