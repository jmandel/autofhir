FHIR-13102 was Published/Persuasive for FHIR-core and asked that IGPublisher produce non-empty narrative XHTML for Bundle examples instead of a blank root page, ideally showing the Bundle type, entry links, and the narratives of contained entry resources.

Initial application:

That commit changed the then-in-repository Java NarrativeGenerator, XhtmlNode, and IGPublisher Publisher code to add Bundle narrative rendering and route Bundle example HTML through the narrative generator.

Additional context:
The Java files changed by the original application are no longer active source in this FHIR checkout. The IGPublisher class was removed in 2019 with the commit message "Remove IG publisher (it's gone to Maven)", and the old Java support files were later removed during Java cleanup/R4B work. The current build uses the external Maven Kindling publisher dependency and runs org.hl7.fhir.tools.publisher.Publisher from that dependency.
