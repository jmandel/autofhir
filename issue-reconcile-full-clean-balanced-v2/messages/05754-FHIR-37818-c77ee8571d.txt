FHIR-37818: Audit TestScript minimumId outside core

Issue request:
FHIR-37818 was a Published FHIR-core TestScript change request, resolved Persuasive with Modification for R5. It asked that TestScript.setup.action.assert.minimumId be specified more clearly for element ordering, value-less element presence checks, and fixture serialization format; the final resolution accepted clarification but rejected support for a <novalueelement/> sentinel, instead directing authors to use separate assertions for value-independent presence checks.

Initial application:
The request was applied in core by commit 8784f97f340498d087383b2430744c21e4652502 on 2023-01-12. That commit added a Testing FHIR "Use minimumId" section to source/testing.html, explained source-fixture superset comparison, clarified that attribute/element and array ordering mismatches do not fail when paths match, and stated that value-less element presence is not supported by minimumId and should be handled with separate asserts.

Additional context:
FHIR-I minutes on 2022-08-29 assigned Richard Ettema to draft the FHIR-37818 proposal, and minutes on 2023-01-09 record the work group vote accepting the proposal with the <novalueelement/> removal. Current core no longer owns TestScript source: commit f9a44787c45071394532c7c2ee94d76f30f47387 removed testscript, testreport, and testplan from active source/fhir.ini resource metadata and deleted source/testing.html while adding the FHIR Testing IG as an additional IG. Current core still points implementers to that external Testing IG, and the current Testing IG continuous build contains the TestScript resource and the migrated Use minimumId guidance.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source change is appropriate because the authoritative TestScript and minimumId documentation are outside the current core build, and the current external Testing IG already contains the applied minimumId clarification.

Recommendation:
Keep this audit commit as-is. Future changes to TestScript.minimumId behavior or wording should be made in the HL7 FHIR Testing IG source, not by restoring or editing retired core TestScript/testing page source; revisit core only if its links to the Testing IG become stale or misleading.
