FHIR-20566: Audit CareTeam participant role binding

Issue request:
FHIR-20566 was Published with resolution Persuasive with Modification for R5. It asked to replace the CareTeam.participant.role example value set content that described broad relationships rather than roles: remove the broad SNOMED CT Person hierarchy 125676002, keep Healthcare professional 223366009, replace Healthcare related organisation 394730007 with Services 224930009, and keep the binding strength as Example rather than Preferred.

Initial application:
The issue was applied by git commit 4639ce74485a86649aaa2ea3b45075cca3a3810e, merged by PR #530, which changed source/careteam/valueset-participant-role.xml from Person/Healthcare professional/Healthcare related organization to Healthcare professional/Services. The CareTeam element binding already uses strength="example" and points CareTeam.participant.role to http://hl7.org/fhir/ValueSet/participant-role.

Additional context:
FHIR-33956 later amended the same CareTeam value set because the FHIR-20566 cleanup intentionally removed broad Person descendants and also removed unpaid care-team-member role concepts. FHIR-33956 is already represented on the combined branch by commit 177091d79ec62511573ce064462715f784806ff6, which completed the targeted restoration of Patient advocate, Patient, and Caregiver descendants while preserving the FHIR-20566 removal of all Person descendants and Healthcare related organization. A stale source/careplan/valueset-participant-role.xml with the old compose still exists, but CarePlan no longer binds to ValueSet/participant-role and the current build surface resolves this canonical value set from the CareTeam source, so editing the orphan would not be a current CareTeam spec fix.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The active current source for CareTeam.participant.role has Example binding strength, uses the participant-role value set, includes Healthcare professional 223366009 and Services 224930009, and no longer includes the FHIR-20566-deprecated 125676002 or 394730007 roots. The additional FHIR-33956 person-role entries are a later published refinement, not a reversal of FHIR-20566.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-20566 unless Patient Care later decides that the orphaned CarePlan copy should be removed or reconciled as a separate cleanup issue.
