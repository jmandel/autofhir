FHIR-11122: Audit STU3 Immunization status application

Issue request:
FHIR-11122 was a Published FHIR-core Immunization change request, resolved Persuasive, reporting that GForge item 9070 had been voted on but had not made it into the STU3 version. The Jira comment says the change was applied on 2016-11-04.

Initial application:
The historical application is explicit. Commit 1212b3f471b75003758b78b258e740eed23a98dd says it addressed tracker items 9070 and 11122, changed Immunization.status from the broader in-progress/on-hold/completed/entered-in-error/stopped list to completed/entered-in-error, changed the binding away from the MedicationAdministration status value set, and introduced an Immunization-specific status value set. That matches the FHIR-11122 request to make the already-approved GForge 9070 change appear in the STU3 source stream.

Additional context:
FHIR-9070 is the underlying same-change-family issue and is audited by the immediately preceding reconciliation commit. Current source no longer exactly has only the two 2016 status codes because later R4/R5/R6 work intentionally aligned Immunization with the Event workflow pattern: notGiven was removed, status=not-done was added for not-administered/refused events, and statusReason/reason guidance was subsequently refined. PHWG minutes, FHIR-14377, FHIR-54325, and FHIR-55330 all support the current three-code status model.

AutoFHIR reconciliation:
No source change was made. The active Immunization source in the current build remains consistent with the substance of FHIR-11122: the old GForge 9070 status trim was applied, and the current Immunization.status value set does not include the irrelevant MedicationAdministration statuses that prompted the original issue. The only extra code, not-done, comes from later approved Immunization/Event-pattern work.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-11122; future work should treat the current completed/entered-in-error/not-done set as intentional unless a new PHWG decision changes Immunization.status.
