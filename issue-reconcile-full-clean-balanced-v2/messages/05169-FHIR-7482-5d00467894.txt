FHIR-7482: Audit dosage rate comment cleanup

Issue request:
FHIR-7482 was Published/Persuasive for the Pharmacy work group and asked to remove the MedicationAdministration.dosage.rate comment that still said changing rates should be represented as distinct dosage repetitions, because MedicationAdministration.dosage had become 0..1.

Initial application:
The issue was applied in git-svn commit 5555750a4cce94cd357c3178441d043caa13f1ca, whose message says "#7482 - dosage comment removed" and whose patch removed the obsolete "distinct dosage repetition" comment from the MedicationAdministration spreadsheet source. The Jira comment records the same application as build revision @6685.

Additional context:
MedicationAdministration is an active, approved resource in source/fhir.ini. A later Published/Persuasive-with-Modification issue, FHIR-8502, revisited the same apparent contradiction and approved replacement wording that says rate changes captured in MedicationAdministration should be represented as distinct MedicationAdministration events with their own MedicationAdministration.dosage.rate and timestamp. Git commit 0c6541df609f5323c35e204e971168e5a89a4846 applied that later wording. The current StructureDefinition carries that corrected guidance, not the stale dosage-repetition wording.

AutoFHIR reconciliation:
No source change was made. The current active MedicationAdministration StructureDefinition has MedicationAdministration.dosage max 1 and the rate comment now directs implementers to separate MedicationAdministration events rather than repeated dosage elements, so removing it would discard later approved FHIR-8502 guidance rather than finish FHIR-7482.

Recommendation:
Keep this audit commit as-is. FHIR-7482 is satisfied in the current build; if FHIR-8502 is reconciled separately, it should use this same source/history trail and likely conclude the current wording is already applied.
