FHIR-47872: Audit Home Use device clarification

Issue request:
FHIR-47872 was an Applied, Persuasive with Modification R6 OO change request for the Device Home Use device wording. The ballot comment said the first two sentences contradicted each other and asked what a home use device is. The approved resolution clarified that a home use medical device is intended for users outside a professional healthcare facility while allowing use in professional healthcare facilities, added definitions for user and qualified healthcare professional, and removed the old standalone FDA-citation wording from that Home Use definition.

Initial application:
The change appears to have been applied in commit 3cf635fa2b606d038462a683a53338e39b3f30e3, "Text updates for Devices - R6 Info3", which lists FHIR-47872. That commit moved the detailed device category descriptions from source/device/device-introduction.xml into source/devicedefinition/devicedefinition-introduction.xml and replaced the Home Use device paragraph with the clarified sentence plus the two approved definition bullets. Jira comments later recorded that the change was already applied on the DeviceDefinition page and confirmed it had been added and moved to DeviceDefinition.

Additional context:
DeviceDefinition is an active resource in source/fhir.ini, and the Device page now sends readers to DeviceDefinition for detailed device category descriptions. A separate Patient-use device paragraph still contains older FHIR-26636/FHIR-47876 text and the FDA source link, but that paragraph is a different section with its own Published/Applied issue history; FHIR-47876 subsequently touched it only to expand the PHD abbreviation. Confluence minutes show FHIR-47872 was discussed as a Scope/Usage text change whose final wording would be worked out by HCP/editors and then moved with the Device content refactoring. No Zulip hit or conflicting community record was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current combined-branch source already gives the Home Use device definition approved for FHIR-47872 in the active DeviceDefinition introduction, and the active Device page points to DeviceDefinition rather than carrying the obsolete contradictory Home Use wording itself.

Recommendation:
Keep this audit commit as-is for FHIR-47872. If the work group wants to modernize or de-duplicate the separate Patient-use device paragraph, handle that as a separate DeviceDefinition wording issue because it descends from FHIR-26636/FHIR-47876 rather than from the approved Home Use subsection edit audited here.
