FHIR-5956: Audit Questionnaire layout extensions ownership

Issue request:
FHIR-5956 was a Published/Persuasive FHIR-core Questionnaire change request asking for additional Questionnaire layout hints for autocomplete, select/drop-down, and horizontal rendering. The final PC WG resolution replaced the three proposed extension URLs with two more generic extensions: one for direction/orientation and one for control type.

Initial application:
The Jira application note points to SVN #6652. In the imported git history, commit 52dbc1c478 shows the corresponding Questionnaire extension family in core source: questionnaire item-control terminology with autocomplete, drop-down, lookup, radio-button, slider, spinner, and text-box controls, and choice-list orientation terminology with horizontal and vertical values. Later core commits continued maintaining the same extension family before the core-source ownership changed.

Additional context:
The current core build still includes Questionnaire as an active resource, but the relevant authoritative extension definitions are no longer active core source files. Commit dd468d4f17 removed questionnaire-choiceOrientation, questionnaire-itemControl, and their code system/value set files from R5 core source as part of the global extension-source removal. The FHIR Extension Pack now contains active questionnaire-itemControl and questionnaire-choiceOrientation definitions plus their bound value sets/code systems. Later FHIR-extension work such as FHIR-43033 confirms the current maintenance path for Questionnaire extension details is the Extension Pack, not this core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The requested seed behavior is represented by current Extension Pack artifacts, and adding or recreating these extension definitions in core would conflict with the current source ownership model.

Recommendation:
Keep this audit commit as-is for the core reconciliation. Any future semantic change to these Questionnaire layout hints should be made in the FHIR Extension Pack and coordinated with the relevant extension-pack Jira, not by editing core FHIR source.
