FHIR-32876: Audit clinical-patient target scope

Issue request:
FHIR-32876 is a Published/Persuasive FHIR-I technical correction raised against R4 and applied for R5. It reported that the generated/downloaded SearchParameter/clinical-patient target list had expanded to all resource types, despite the related patient-search decisions requiring the common clinical-patient search parameter to target only Patient. The Jira disposition records it as a duplicate of FHIR-31714.

Initial application:
FHIR-32876 itself does not appear to have a direct source commit. Its duplicate target, FHIR-31714, was applied by commits a96b79e23a892164f261dcf4c7868ec1ef8023e2 and b9ee4c1747a9d505eec4b76c41e26d95c5dd6a30, which added explicit target declarations to target-constrained reference SearchParameters across the resource search-parameter bundles. The FHIR-32876 Jira comments later record that R4B and R5 showed SearchParameter/clinical-patient target ["Patient"].

Additional context:
Earlier related decisions FHIR-15903 and FHIR-28219 establish the intended split: patient search parameters should resolve only Patient, while broader Patient-or-Group references are represented by subject or group parameters where needed. FHIR-I minutes on 2021-12-20 explicitly treated FHIR-32876 as a duplicate of FHIR-31714 with no separate vote needed. A 2022-2023 Zulip thread and 2023 FHIR-I minutes noted possible build regressions, but the current source and current published generated artifacts no longer show the all-resource target list.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. SearchParameter is an active current-build resource in source/fhir.ini; source/searchparameter/common-search-parameters.xml contains the common clinical-patient base list without asserting a Group or all-resource target; all inspected patient-code SearchParameter source blocks declare only Patient targets; and the current build, R5, and R4B search-parameters.json artifacts all report SearchParameter/clinical-patient target ["Patient"].

Recommendation:
Keep this no-change audit. The current core source and generated publication surfaces already satisfy FHIR-32876 through the FHIR-31714/FHIR-28219 change family. No follow-up is needed unless a future build regression again expands clinical-patient.target beyond Patient.
