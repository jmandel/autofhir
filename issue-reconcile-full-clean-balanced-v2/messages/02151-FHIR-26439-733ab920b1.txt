FHIR-26439: Audit inactive MedicationKnowledge definitions

Issue request:
FHIR-26439 was a Published/Persuasive R5 Pharmacy change request for FHIR-core MedicationKnowledge. It asked to review relatedMedicationKnowledge and associatedMedicationKnowledge/associatedMedication wording, setting relatedMedicationKnowledge to describe associated or related medications such as branded products and therapeutic moieties, and setting associatedMedication to "Links to associated medications that could be prescribed, dispensed or administered."

Initial application:
The issue was represented in source history by commit 603de50396973db754fec17786a66ce29799296c, a grouped Pharmacy commit explicitly mentioning FHIR-26439. That commit carried the requested associatedMedication definition in source/medicationknowledge/medicationknowledge-spreadsheet.xml, and the later source rework commit 33b409a4b6d544598262f2f074ebb4b6dc466157 migrated the MedicationKnowledge definitions into source/medicationknowledge/structuredefinition-MedicationKnowledge.xml. The residual current StructureDefinition still contains the requested associatedMedication wording and relatedMedicationKnowledge concept, although the inactive relatedMedicationKnowledge definition also preserves an old spelling/punctuation defect.

Additional context:
MedicationKnowledge is no longer an active current-build core resource. source/fhir.ini's active [resources] list omits MedicationKnowledge; only residual workgroup, security categorization, and FMM entries remain. Commit 5a4307d78b0209f61bbc68d582c1e190b3aaee5c explicitly removed MedicationKnowledge from active resource registration. Later Pharmacy direction in FHIR-50845 agreed to remove MedicationKnowledge and move applicable elements to FormularyItem or other resources, and FHIR-51149 audited the FormularyItem migration separately on the combined branch. The current CI build URLs for medicationknowledge.html and medicationknowledge.profile.json return 404.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing the residual MedicationKnowledge StructureDefinition to repair relatedMedicationKnowledge spelling or punctuation would not correct a current built artifact because the resource is outside the current core build. The associatedMedication wording requested by FHIR-26439 was historically present before the resource was removed from current build scope.

Recommendation:
Keep this external-repo audit commit as-is for the current core build. If Pharmacy restores MedicationKnowledge to core or maintains it in another active specification, review the inactive source/medicationknowledge/structuredefinition-MedicationKnowledge.xml wording at that time and correct the residual "Therapeutic Moeity"/unclosed-parenthetical text in the maintained artifact.
