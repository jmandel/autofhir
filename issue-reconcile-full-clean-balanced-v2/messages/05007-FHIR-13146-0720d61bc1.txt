FHIR-13146: Audit RelatedPerson relationship split

Issue request:
FHIR-13146 is a Published/Persuasive with Modification PA change request raised against DSTU2 and applied for STU3. It asked to separate RelatedPerson.relationship from functional roles because the then-bound relationship value set mixed family relationships and role/function concepts. The approved modified resolution was narrower than the original request: open RelatedPerson.relationship cardinality from 0..1 to 0..* and do not add roles to RelatedPerson under that issue.

Initial application:
No standalone source commit was found for only FHIR-13146. The substantive cardinality part was applied in the same 2017 issue family by git commit 2e012e76a18a08930e5396bbee8addc60c952edb ("Tracker #14225"), which changed the RelatedPerson spreadsheet cardinality from 0..1 to 0..*. The explicit commit mentioning this seed, 987c2abb05d766abc9b78c0d02cea42fe3e9a468 ("Tracker #13146, 13452, 13621"), changed adjacent RelatedPerson wording and typo/period text but did not add a RelatedPerson.role element.

Additional context:
source/fhir.ini actively includes relatedperson=RelatedPerson, so source/relatedperson/structuredefinition-RelatedPerson.xml is current build-scope source. Current source preserves RelatedPerson.relationship at 0..* and now also contains RelatedPerson.role. That role element is not an incomplete or mistaken application of FHIR-13146; it is a later PA model decision from FHIR-15841, with FHIR-29929 explicitly saying that FHIR-15841 addressed the role/relationship request. FHIR-14225, FHIR-15841, and FHIR-29929 are already represented on the combined branch and should not be duplicated here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies the seed's approved cardinality change, and removing or weakening RelatedPerson.role would incorrectly reverse later applied/published PA decisions.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-13146 unless PA opens a new decision to revisit the later FHIR-15841 personal-vs-functional relationship model.
