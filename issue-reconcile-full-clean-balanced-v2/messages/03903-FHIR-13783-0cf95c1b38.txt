FHIR-13783: Audit Condition extension clarification

Issue request:
FHIR-13783 was a Published Patient Care change request with a Persuasive with Modification resolution for STU3. It asked to add a condition-related extension for unspecified relationships, keep the existing Condition-specific dueTo/occurredFollowing/partOf extensions, and clarify condition-partOf so it used hypertension being part of metabolic syndrome rather than the misleading elevated-blood-pressure/diabetes example.

Initial application:
The request was applied in core by git commit 32b35437cc8daef171fb42950801c6a39d6f918b, which updated source/condition/condition-extensions-spreadsheet.xml to change the condition-partOf definition to the approved documented-as-part-of/metabolic-syndrome wording and added the condition-related extension with Reference(Condition) and the GF#13783 marker.

Additional context:
FHIR-14446 later approved switching Patient Care workflow resource-specific extensions to common workflow extensions. Git commit f235b25c5ef0e84d57ea366f811fa801f1db9a25 removed the Condition-specific condition-partOf row from the core Condition extension spreadsheet as part of replacing Condition-specific workflow extensions with common event extensions. In the current core checkout, active source no longer contains the obsolete condition-partOf definition or the rejected diabetes example; the current event pattern source defines Event.partOf as a larger event of which the current event is a component or step. The Extension Pack now carries the remaining Condition relationship extension definitions, and event-partOf is available for Condition there.

AutoFHIR reconciliation:
This audit made no source change. The original clarification was applied, and the current FHIR core build no longer has the Condition-specific condition-partOf source location that FHIR-13783 corrected. Reintroducing or editing that obsolete extension in core would conflict with the later workflow-extension refactor.

Recommendation:
Keep this no-change audit commit for core. No current FHIR core source edit is needed for FHIR-13783; any future cleanup of Extension Pack wording, such as the condition-related comment's stale reference to condition-part of instead of event-partOf, should be handled in the Extension Pack repository rather than this core reconcile.
