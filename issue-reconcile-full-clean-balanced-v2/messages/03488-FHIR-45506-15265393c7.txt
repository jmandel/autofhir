FHIR-45506: Audit SupplyDelivery workflow guidance ownership

Issue request:
FHIR-45506 was an Applied OO change request for R5, resolved Not Persuasive with Modification, asking not to add core SupplyDelivery dispatch/reception profiles and instead to add a Workflow Considerations section explaining dispatch and reception use, extensible stages, connected-system visibility, and return handling through separate SupplyDelivery instances.

Initial application:
The request was applied before this reconciliation by Jira-tagged commit 49b77e9ffa and PR HL7/fhir#3559, which added the requested Workflow Considerations prose and blood-stock-replenishment example to source/supplydelivery/supplydelivery-notes.xml. Later FHIR-46405 commits augmented the same notes section, but the core SupplyDelivery source file is now legacy inactive source.

Additional context:
FHIR-38818 created the stage-based SupplyDelivery approach and separated the question of core dispatch/reception profiles into FHIR-45506. FHIR-45046 moved the proposed return-dispatch/return-reception profile constraints into FHIR-45506, and FHIR-45506's final disposition instead clarified that returns are still documented as dispatch and reception stages. Subsequent source history changed build ownership: commit 3b38b80cf2 removed SupplyDelivery and SupplyRequest from active source/fhir.ini metadata and changed current core narrative links to the OO Incubator IG. The current HL7/oo-incubator source contains SupplyDelivery as an active IG resource, but its notes page still has the placeholder text, so any remaining implementer-facing workflow-note transfer belongs there rather than in this core checkout.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source was changed because editing source/supplydelivery/supplydelivery-notes.xml would only adjust inactive legacy source, while the current core build points implementers to HL7/oo-incubator for SupplyDelivery.

Recommendation:
Keep this audit commit for FHIR core. If OO wants the detailed FHIR-45506 Workflow Considerations section to appear in the current implementer-facing SupplyDelivery material, apply or reconcile that text in HL7/oo-incubator, not in inactive core SupplyDelivery source.
