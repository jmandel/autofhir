FHIR-17054: Audit Bundle history timestamp wording

Issue request:
FHIR-17054 was a Published/Persuasive STU3 FHIR-core Feed clarification. It asked to change the Bundle.timestamp history usage sentence from "This time would be used to ask for subsequent updates" to "This time would be used as the _since time to ask for subsequent updates", because the old sentence was not clear.

Initial application:
The issue was applied in git commit 246c4a92c7af1cd8ac8f8c36e24c4db04db718af (svn revision 14367), which changed the then-authoritative source/bundle/bundle-spreadsheet.xml Bundle.timestamp comment to the requested _since wording. The later source migration preserved that wording in the current StructureDefinition source.

Additional context:
source/fhir.ini has an active bundle=Bundle resource entry, so source/bundle/structuredefinition-Bundle.xml is in current build scope. Current Bundle.timestamp still says that for history bundles, the date the history was assembled is used as the _since time to ask for subsequent updates. Related history Bundle reconciliations FHIR-17069 and FHIR-17077 are already represented on the combined branch and do not alter this timestamp clarification. Zulip and Confluence searches found no contrary community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested clarification is already present in the authoritative current Bundle StructureDefinition, and adding duplicate narrative would not change implementer understanding.

Recommendation:
Keep this no-change audit commit as-is. No core source follow-up is needed for FHIR-17054 unless a future FHIR-I decision changes the semantics of Bundle.timestamp for history bundles.
