FHIR-11383: Audit Coverage display reconciliation

Issue request:
FHIR-11383 was a Published/Persuasive with Modification Financial Management change request raised against DSTU2 Coverage to add groupDesc, subGroupDesc, planDesc, subPlanDesc, classDesc, and networkDesc, with the final resolution stating that elements were added as elementDisplay rather than elementDesc.

Initial application:
The historical application appears in commit 4380617428, which updated the Coverage spreadsheet and examples. That commit added groupDisplay, subGroupDisplay, planDisplay, subPlanDisplay, classDisplay, and subClassDisplay example/source rows and revised Coverage.network wording, but it did not introduce a separate networkDisplay element. The issue later reached Published status with that application history.

Additional context:
Coverage is active in the current build through source/fhir.ini. Later Coverage work, especially FHIR-15564, replaced the older Coverage.grouping structure with the repeating Coverage.class structure for group, plan, and related card classifications. The current source preserves the display/description function through Coverage.class.name, and fhir.ini records Coverage.grouping as mapped to Coverage.class. Current examples use Coverage.class.name for group, subgroup, plan, subplan, class, and subclass labels.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding a new Coverage.network display/name element now would be a new R6 model change not justified by the later Coverage redesign evidence, while the current Coverage.class.name source already carries the applied display intent for the group/plan/class classification fields that survived the redesign.

Recommendation:
Keep this audit commit as-is. If Financial Management still wants a separate human-readable network label distinct from Coverage.network, handle that as a fresh current-version change request because FHIR-11383's applied source history and later Coverage.class redesign do not provide a safe basis for adding that new element during reconciliation.
