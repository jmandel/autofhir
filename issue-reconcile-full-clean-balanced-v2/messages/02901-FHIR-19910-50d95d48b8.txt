FHIR-19910: Audit MedicationDispense not-done mappings

Issue request:
FHIR-19910 was a Published/Not Persuasive with Modification Pharmacy change request raised against STU3 for MedicationDispense.status. It asked to review and update the definition of "declined"; the approved resolution narrowed the required work to fixing mappings so both "declined" and "cancelled" point to the workflow "Not Done" status, applied for R5.

Initial application:
Jira records the issue as applied by merge commit aa42e5dcc1 on 18Feb2019. The relevant parent commit 9d4a0fe093 changed source/status-codes.xml so the MedicationDispense.status row mapped both "cancelled" and "declined" in the column whose workflow status code is not-done, and also updated the then-current MedicationDispense spreadsheet short status list to include declined.

Additional context:
MedicationDispense remains an active current resource in source/fhir.ini. The old resource spreadsheet has since been refactored into source/medicationdispense XML inputs, and later Applied Pharmacy issues changed nearby MedicationDispense status details: FHIR-40692 replaced stopped with unfulfilled and was already audited on the combined branch, while FHIR-49940 added declined/cancelled examples and clarified intended-supply wording. Neither later decision reverses the FHIR-19910 mapping direction. Community searches found discussion using declined for a patient refusal and cancelled for prepared-but-not-picked-up medication, but no conflicting decision for the not-done mapping.
