FHIR-41183: Audit ElementDefinition id metadata fix

Issue request:
FHIR-41183 was an Applied/Persuasive FHIR-I change request for the R5 ElementDefinition metadata. The R5 generated StructureDefinition for ElementDefinition.id carried structuredefinition-fhir-type valueUrl "id" even though ElementDefinition.id is inherited from Element.id and should use the FHIR string flavor; Jira records the requested correction as "It should be string, not id" and notes that it was actually fixed in R6.

Initial application:
The historical R5 profile cache still shows the defect in tools/history/release5/profiles-types.xml, and no commit in this FHIR source checkout directly references FHIR-41183. The implementation appears to have happened in the external Kindling generator: HL7/kindling commit 62a8c188e5ff9dcee8bbfe6ac10a7670d934abed is titled "FHIR-41183 R5 ElementDefinition.id metadata specifies id data type instead of string" and modified ProfileGenerator.java.

Additional context:
The active FHIR source still defines Element.@id as type string and fhir.ini keeps ElementDefinition in the current datatype/build scope. Current R6 ballot4/build artifacts now emit ElementDefinition.id with structuredefinition-fhir-type valueUrl "string", while the published R5 artifact emits "id". FHIR-25262 separately establishes that Resource.id should remain fhir-type "id"; FHIR-57383 is a later Submitted report that the Kindling change may have regressed inherited resource ids such as Patient.id, but that issue is unresolved and is not decided here.

AutoFHIR reconciliation:
This audit commit intentionally makes no FHIR source change. The seed issue's current target output is already corrected, and the remaining nearby Resource.id/Patient.id concern is a separate unresolved generator issue rather than an approved source edit for FHIR-41183.

Recommendation:
Keep this no-change audit as the FHIR-41183 reconciliation. Do not broaden this issue into Resource.id or inherited resource id edits; follow FHIR-57383/Kindling if the work group approves a separate generator correction.
