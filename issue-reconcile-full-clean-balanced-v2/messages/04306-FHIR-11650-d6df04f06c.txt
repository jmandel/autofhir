FHIR-11650: Audit dynamicValue examples

Issue request:
FHIR-11650 was a Published/Persuasive CDS issue raised against the DSTU2 Clinical Reasoning module and ActivityDefinition.dynamicValue, requesting more guidance and examples for dynamicValue usage. Jira records a 2016-10-19 CDS vote of 6-0-0 and the resolution, "Agreed, more examples will be provided."

Initial application:
No historical source commit was found that explicitly mentions FHIR-11650, #11650, or cqf #161. The Jira application comment says it was "Addressed by other commits" and specifically names two application routes: the Using Expressions topic was expanded with more dynamicValue discussion, and an additional example was added to the ActivityDefinition example list. The source history supports that trail: commit 5e5d104c55 added ActivityDefinition examples and Clinical Reasoning/CQIF expression content, commit 854daa09f7 expanded Using Expressions and adjacent expression guidance, and commit 89d8c9f91d later patched Bryn's examples and added more ActivityDefinition/PlanDefinition example support.

Additional context:
ActivityDefinition is an active current-build resource in source/fhir.ini, and the Clinical Reasoning module links the Using Expressions topic and its dynamic-value-for-a-resource-element section. Later final CDS issues, including FHIR-13587, FHIR-13588, FHIR-16705, FHIR-18237, and FHIR-18239, refined the same dynamicValue/example family; those later reconciliations are already represented on the combined branch and do not reverse the seed request. FHIR-11600 was applied in the same historical Using Expressions work but is a separate FHIR-cqif evaluation-context issue, so it is context only here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/clinicalreasoning-topics-using-expressions.html already contains dynamicValue guidance and multiple ActivityDefinition/PlanDefinition dynamicValue fragments, including description-only, inline CQL, named-expression, qualified-expression, and JSON examples. Current source/activitydefinition/list-ActivityDefinition-examples.xml includes the citalopram ActivityDefinition example, and source/activitydefinition/activitydefinition-medicationorder-example.xml contains concrete dynamicValue entries for dispenseRequest.numberOfRepeatsAllowed and dispenseRequest.quantity. Adding more local prose or examples for this old non-substantive request would be redundant with the current build surface.

Recommendation:
Keep this no-change audit commit. No FHIR core source follow-up is needed for FHIR-11650 unless the CDS work group wants new example content beyond the examples and guidance already added and subsequently refined by later issues.
