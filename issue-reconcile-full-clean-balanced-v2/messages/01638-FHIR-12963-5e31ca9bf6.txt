FHIR-12963: Audit Composition document principles

Issue request:
FHIR-12963 was a Published FHIR-core / Structured Documents change request with resolution Persuasive with Modification. It asked for Composition Scope and Usage to link to clinicaldocument.html and for the clinical document page to state fundamental document characteristics such as persistence, wholeness, stewardship, context, and potential for authentication.

Initial application:
The issue was historically applied. Jira records a Grahame Grieve comment citing SVN revision 13014, and git-svn history has commit 04fb3079bd44513f51cffc189ec0828259a77715, "GF#12963 - improve CDA related doco", which added a Composition Scope and Usage paragraph linking to the then-current CDA/ClinicalDocument profile and CDA comparison, and changed the Composition spreadsheet source that later fed clinical-document profile introduction content.

Additional context:
Later Composition decisions changed how this old request should be interpreted. FHIR-13426 generalized Composition so it is not solely a document-paradigm resource, and FHIR-25438 removed clinical-only attestation/status wording. FHIR-13528 reversed the temporary "CDA on FHIR" profile naming, while FHIR-34407 later removed the ClinicalDocument Composition profile entirely because Composition.version replaced its meaningful versionNumber contribution. On the current combined branch, FHIR-13528 has already removed the stale active ClinicalDocument profile link from Composition. Current source/fhir.ini still builds Composition and documents.html, but the legacy cda profile hook is commented out and the ClinicalDocument StructureDefinition source has been deleted. The active cda-intro.html page is listed in source/hierarchy.xml and already states the clinical document characteristics.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring a clinicaldocument.html link in Composition would point readers toward a removed core profile and would conflict with later applied decisions. The current active Composition introduction correctly sends readers to FHIR Documents and CDA comparison guidance, while active CDA-on-FHIR/documentation source carries the clinical document principles.

Recommendation:
Keep this audit commit as-is. No core source change is needed for FHIR-12963 unless SDWG reintroduces a core ClinicalDocument profile or asks for new document-principles prose beyond the current FHIR Documents and CDA-on-FHIR pages.
