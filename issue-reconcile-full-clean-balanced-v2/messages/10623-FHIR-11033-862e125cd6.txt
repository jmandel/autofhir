FHIR-11033: Audit resource instance terminology

Issue request:
FHIR-11033 was a Published/Persuasive FHIR-core clarification from the DSTU2 cycle. It asked the developer introduction to distinguish resource instances from resource types, note that the specification sometimes uses "Resource" without repeating that distinction when context makes it clear, rename the example section to "Example resource instance", use "instance" in the later resource-content example text, and clarify that the base resource section describes the Resource and DomainResource types whose elements appear on resource instances.

Initial application:

No unapplied source gap was found.

Additional context:
overview-dev.html is still in the current build through publish.ini and the source hierarchy. The current page has evolved since the 2016 SVN commit, including corrections to transient typos in the original patch, but it preserves the intended resource instance/type distinctions. FHIR-5225 is a related earlier overview-dev heading clarification already represented on the combined branch; it does not require a duplicate FHIR-11033 decision. Zulip and Confluence searches found no substantive community discussion or later work-group record that conflicts with the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change.
