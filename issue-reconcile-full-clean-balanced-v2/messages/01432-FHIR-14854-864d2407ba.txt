FHIR-14854: Fix resource identity guidance links

Issue request:
FHIR-14854 was Published with a Persuasive with Modification resolution for STU3. It asked for guidance explaining how content represented in multiple ways can be identified as coming from the same source data, with discussion in Managing Resource Identity covering shared identifiers, Provenance, and when each is appropriate.

Initial application:
The issue was initially applied by svn revision 13383, preserved in git commit 040f93b4100be211e372779937ea23efe4c73b23, which added the Consistent Resource Identification discussion to source/managing.html and added cross-references from resource identity and logical references. That application included the MedicationRequest/MedicationStatement example, identifier guidance, Provenance.entity.what[x], and Resource.meta.source.

Additional context:
A later Published issue, FHIR-16466, moved the identity terminology and Consistent Resource Identification material from managing.html into the normative Resource page, as shown by git commit 6952564a0194f2d05079049d21b581cf35342188. The current source keeps the requested substantive guidance in source/resource/resource-notes.xml, which feeds the active Resource page, but several cross-references still described that section as part of managing.html or pointed directly to managing.html#consistency, an anchor that no longer exists.

AutoFHIR reconciliation:
This commit keeps the existing guidance unchanged and updates the stale current-spec links in source/lifecycle.html, source/references.html, and source/resource/resource-notes.xml so that Consistent Resource Identification points to resource.html#consistency while Managing Resource Identity remains linked separately.

Recommendation:
Keep this commit as-is. It is a narrow source fix for link/navigation drift after the later FHIR-16466 move; no broader prose change is needed because the central Resource page already contains the identifier, Provenance, and Meta.source guidance requested by FHIR-14854.
