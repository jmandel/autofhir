FHIR-40733: Audit retired CodeSystem history extension

Issue request:
FHIR-40733 was an Applied/Persuasive Vocab change request for FHIR-core CodeSystem asking that the http://hl7.org/fhir/StructureDefinition/codesystem-history extension be revisited because it referenced a value set in its definition and should instead be based on Provenance as used in THO. The approved resolution was to retire the extension.

Initial application:
The current core FHIR checkout no longer contains an active codesystem-history StructureDefinition. Core history shows the CodeSystem extension definitions, including structuredefinition-extension-codesystem-history.xml, were removed from the R5 source in dd468d4f17 when extensions moved out of core; current core grep finds only the historical OID assignment in source/oids.ini.

Additional context:
The active source for this extension is in the FHIR Extension Pack, not this core checkout. Extension Pack commit 2d8d6741385fe7229cd5fbeb5ee276ec0abe31a5 explicitly included FHIR-40733 in a batch of TI extension retire/deprecate/remove changes and changed StructureDefinition-codesystem-history.xml from active to retired. The current Extension Pack file also carries a deprecated standards-status reason and description saying the extension is retired and that history should be recorded using Provenance instead. Confluence Vocab minutes for 2024-04-08 record the same decision: THO uses Provenance bundles to track history, so the extension was retired.

AutoFHIR reconciliation:
This commit makes no core source change. The requested source edit belongs to the FHIR Extension Pack and has already been applied there; changing core would either edit no active definition or remove the retained OID assignment rather than the extension itself.

Recommendation:
Keep this audit commit as-is for the core combined branch. No core follow-up is needed for FHIR-40733 unless a future process requires mirroring Extension Pack retirement metadata into a core-generated registry; any future change to the extension definition itself should be made in the FHIR Extension Pack.
