FHIR-33090: Audit CitedMedium outside core

Issue request:
FHIR-33090 was Published/Persuasive for R5 and asked to change the JournalIssueMedium value set to CitedMedium, lower-case the existing terms, and add offline-digital-storage, print-without-issue, and offline-digital-storage-without-issue so Citation.citedArtifact publication forms could represent internet, print, and offline-digital-storage media with or without a periodic issue.

Initial application:
The issue was applied in commit e7d479cbe3978099d0b9c16201c07a2f3019dd0c, which explicitly cites J#33090. That patch deleted the old journal-issue-medium CodeSystem, added source/citation/codesystem-cited-medium.xml with the six requested concepts, renamed the ValueSet source to valueset-cited-medium.xml, and changed the Citation binding name/valueSet to CitedMedium. The checked-in R5 history contains CitedMedium with all six requested concepts and Citation.citedArtifact.publicationForm.citedMedium bound to ValueSet/cited-medium.

Additional context:
FHIR-32322 was the broader Citation value set request that spawned this focused tracker. FHIR-37913 later simplified Citation.citedArtifact.publicationForm by moving citedMedium out from periodicRelease while retaining the CitedMedium binding. FHIR-39632 and commit caa1fb75adbcca96f92873c7d958e31f547124bb then moved duplicated Citation terminology definitions out of the base FHIR source and updated Citation bindings to terminology.hl7.org. Later commit 71567db3ee2d9fe45368e165a2bd55ff069b4d44 removed the Citation resource itself from current core; current fhir.ini has no active Citation resource or cited-medium terminology source, and current Clinical Reasoning text points Citation to the Evidence Based Medicine on FHIR IG.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. The requested R5 terminology edit was applied historically, and the relevant Citation resource and CitedMedium terminology source are no longer active current-core build inputs. Editing the absent source/citation artifacts or leftover OID registry lines would not improve the current FHIR build and would risk reintroducing out-of-scope terminology into core.

Recommendation:
Keep this audit commit as-is for core. If the active EBM IG or THO-owned CitedMedium terminology does not preserve the six FHIR-33090 concepts, handle that as follow-up in the owning external repository rather than in the base FHIR checkout.
