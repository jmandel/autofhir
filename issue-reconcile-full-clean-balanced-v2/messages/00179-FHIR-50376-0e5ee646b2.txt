FHIR-50376: Audit external PersonalRelationship period wording

Issue request:
FHIR-50376 was an Applied FHIR-core R6 ballot issue with resolution Persuasive with Modification. It asked to clarify the apparent contradiction in PersonalRelationship.period where the definition said no dates means the interval is unknown, while the comment said permanent relationships should omit .period. The approved clarification was to say that for permanent relationships the period end date should be omitted.

Initial application:
The Jira application comment points to core commit a0df14f47ec1225319b7120d4da206fc16a4ca1c, which changed source/personalrelationship/structuredefinition-PersonalRelationship.xml from "the .period should be omitted" to "the period end date should be omitted." That applied the requested wording while PersonalRelationship was still a core draft resource.

Additional context:
PersonalRelationship is no longer in the current core build. Core commit 71567db3ee039ac6977be5f96a7e013896569a36 removed the source/personalrelationship files and changed core narrative/ballot references to the Admin Incubator URL. The current HL7/admin-incubator source still has the corrected PersonalRelationship.period comment.
