FHIR-39110: Audit retired MolecularSequence focus

Issue request:
FHIR-39110 was Published as Persuasive for R5. It requested a new MolecularSequence.focus element, 0..* Reference(Any), summary=true, so a sequence could record the actual focus when that focus was not the patient of record, such as trio testing where the subject is the proband and the focus is a parent.

Initial application:
The issue was applied before this reconciliation. Commit 47b93eae3d/PR #2678 added MolecularSequence.focus to source/molecularsequence/structuredefinition-MolecularSequence.xml, added a MolecularSequence-focus search parameter, and added a focus example; merge commit 5eaf750128 brought that implementation into the main history.

Additional context:
Later R6 work changed the artifact family. FHIR-51227 was Applied as Persuasive with Modification to replace the legacy MolecularSequence resource with MolecularDefinition and explicitly decouple molecular definitional data from patient/encounter context, leaving patient-specific context to Observation references. Current source/fhir.ini does not list MolecularSequence in the active [resources] build list, the source/molecularsequence folder is absent, and the diagnostics module states that MolecularSequence has been replaced by MolecularDefinition. MolecularDefinition's current representation.focus is a CodeableConcept for disambiguating molecular representations, not the patient-context Reference focus requested for R5 MolecularSequence.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Re-adding MolecularSequence.focus would edit an out-of-build retired resource, and transplanting the R5 patient-context focus onto MolecularDefinition would conflict with the later approved design that keeps patient/encounter context on Observation.

Recommendation:
Keep this audit as-is for the current core build. If a future work group decision reintroduces an active patient-context molecular sequence resource, evaluate that new artifact directly rather than carrying forward the retired MolecularSequence focus element.
