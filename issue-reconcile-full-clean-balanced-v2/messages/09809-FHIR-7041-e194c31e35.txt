FHIR-7041: Audit List snapshot status guidance

Issue request:
FHIR-7041 was a Published FHIR-core List change request, resolved Not Persuasive with Modification, asking for a list-status value to indicate that a List is accurate within its usage context but not necessarily current over time. The accepted resolution was that this meaning is represented by List.mode = snapshot, with documentation added about the relationship between mode and status.
