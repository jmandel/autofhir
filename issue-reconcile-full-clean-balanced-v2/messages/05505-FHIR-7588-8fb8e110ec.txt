FHIR-7588: Audit Procedure bodySite simplification

Issue request:
FHIR-7588 was Published/Persuasive with Modification for the DSTU1 Procedure bodySite model. It objected to Procedure.bodySite being a choice between CodeableConcept and a BodySite resource reference, proposed a simpler inline site plus optional laterality, and was resolved to move the BodySite reference to a standard extension while leaving laterality out of core.

Initial application:
The issue appears to have been applied by historical commit 27f73740e4, whose message explicitly includes #7588. That commit flattened Procedure.bodySite to CodeableConcept, disabled the nested Procedure.bodySite.site[x] choice that had allowed Reference(BodySite), updated examples to remove siteCodeableConcept wrappers, and added a Procedure targetBodySite extension for the BodySite reference use case.

Additional context:
Procedure is active in the current build via source/fhir.ini. Current source no longer has the old bodySite choice: Procedure.bodySite is 0..* CodeableConcept. The current Procedure.bodyStructure 0..1 Reference(BodyStructure) is not an unapplied remnant of FHIR-7588; it was intentionally added by Applied issue FHIR-39288, with an invariant preventing simultaneous bodySite/bodyStructure use, and FHIR-51792 later reverted FHIR-41690 to keep Procedure.bodyStructure at 0..1. The old procedure-targetBodyStructure extension now lives in the FHIR Extension Pack for pre-R6/extension-pack use. Current harmonization questions around Procedure.bodySite/bodyStructure are represented by unresolved or Triaged later issues, not final decisions that should be applied under FHIR-7588.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-removing Procedure.bodyStructure or moving it back to an extension would contradict later final Procedure decisions. Adding a laterality element would also exceed the FHIR-7588 resolution, which explicitly did not put laterality into core.

Recommendation:
Keep this no-change audit as-is for FHIR-7588. Future changes to deprecate Procedure.bodySite, alter Procedure.bodyStructure, or clarify the extension/core boundary should be handled under the later active bodySite/bodyStructure Jira items, not by reopening the 2015 simplification issue.
