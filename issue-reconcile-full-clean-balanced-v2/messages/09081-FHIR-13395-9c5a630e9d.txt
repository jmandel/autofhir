FHIR-13395: Audit IG spreadsheet profile-on-profile fix

Issue request:
FHIR-13395 was a Published/Persuasive STU3 FHIR-core change request in the FHIR-Tools-IG grouping. It reported that the spreadsheet-based IG Publisher generated a profile intended to derive from US Core Patient as a profile on base Patient instead, because IgSpreadsheetParser used targetProfile rather than profile when selecting the StructureDefinition.baseDefinition for a profile-on-profile.

Initial application:
The Jira comments record that Eric Haas locally changed IgSpreadsheetParser.java lines 294-295 from get/hasTargetProfile to get/hasProfile and that the fix was preapplied in fhir-svn commit 5064546deb0865ee7d36a88a36e116f69441c863. Git history confirms that commit changed the parser to set baseDefinition from the first differential root type profile when present.
