FHIR-12705: Audit body weight summary LOINC code

Issue request:
FHIR-12705 was a Published/Persuasive Orders and Observations change request for DSTU2. It reported that FHIR-10420 had changed the Body Weight profile LOINC code from 59574-4 to 29463-7, but the human-readable text summary on bodyweight.html still showed the old 59574-4 value. The requested resolution was to fix the code in that text summary.

Initial application:
The issue appears to have been applied by git commit 20e489d0d4577bb13967a5310d208b1857c98687, whose subject was "preapply [#12705],[#12670]". That commit changed source/observation/observation-vitalsigns-profile-spreadsheet.xml so the summary-BodyWeight text replaced `Observation.code.coding.code` 59574-4 with 29463-7. The older supporting issue FHIR-10420 established the intended 29463-7 Body Weight code, although the tagged FHIR-10420 commit left the summary text still stale.

Additional context:
The current build no longer uses that old spreadsheet as the visible source for this profile. Observation is an active resource in source/fhir.ini, and source/observation/implementationguide-Observation-vitalsigns.xml includes StructureDefinition/bodyweight plus the vital signs introduction. Current source/observation/structuredefinition-profile-bodyweight.xml has 29463-7 in both profile-summary extensions and in the Observation.code pattern, and source/observation/observation-vitalsigns-profile-introduction.xml lists Body weight with 29463-7. Source-wide searches found no remaining 59574-4 reference in the current source checkout. Direct Zulip and Confluence searches for FHIR-12705/FHIR-10420 plus the affected LOINC/body weight terms found no conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested summary correction is already present in the current built Observation/Vital Signs source, and adding another edit would only restate already-correct content.

Recommendation:
Keep this audit commit as-is for FHIR-12705. No core FHIR follow-up is needed for the body weight summary LOINC code unless a future change intentionally revises the Vital Signs Body Weight profile code.
