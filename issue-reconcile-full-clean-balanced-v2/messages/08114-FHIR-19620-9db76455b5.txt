FHIR-19620: Audit PATCH history conflict

Issue request:
FHIR-19620 is Published/Persuasive for R5 and asked the HTTP history documentation to clarify that PATCH creates a history entry, that the resulting history Bundle represents the PATCH as an update with entry.request.method PUT, and that PATCH cannot be used when Bundle.type is history.

Initial application:
The request was explicitly applied in git commit 3dff2e6f876c7cdbdbed773ad35b754a74fa729e, which updated source/http.html and added Bundle invariant bdl-14. Current source/http.html still says PATCH interactions create history entries but are represented as PUT, and current source/bundle/structuredefinition-Bundle.xml still contains bdl-14 prohibiting PATCH in history Bundles.

Additional context:
The active Bundle source is in build scope through source/fhir.ini, and it still contains a conflicting FHIR-34388 application: source/bundle/bundle-notes.xml and bdl-3b mention PATCH as a history request method that requires a resource. FHIR-34388 is also Published/Persuasive and has already been represented on the combined branch by commit 394b6c23afc8deb6a0a1ce487d84da87b09e5a95 as a human-review audit because accepting or removing that PATCH wording requires choosing between two final Jira decisions. FHIR-50118 later reports a bdl-3b text/expression mismatch, but it is Triaged and unresolved.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. FHIR-19620's specific HTTP wording and bdl-14 invariant are already present, but removing the remaining PATCH mentions from Bundle history narrative and bdl-3b would effectively reverse the still-final FHIR-34388 wording decision. That conflict needs FHIR-I review rather than an automated source edit.

Recommendation:
Keep this human-review audit record. FHIR-I should decide whether history Bundle entries may ever use entry.request.method PATCH. If yes, revise FHIR-19620's bdl-14/HTTP representation rule. If no, remove PATCH from the Bundle history resource-inclusion sentence and bdl-3b history expression while leaving PATCH allowed for transaction and batch Bundles.
