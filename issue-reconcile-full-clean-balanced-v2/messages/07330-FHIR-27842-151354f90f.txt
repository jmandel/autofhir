FHIR-27842: Audit MedicationAdministration schema rate choice name

Issue request:
FHIR-27842 was a Published/Persuasive technical correction for FHIR-core MedicationAdministration, raised against STU3 and applied for R5. It reported that human-readable pages used MedicationAdministration.rateQuantity while JSON Schema outputs, including MedicationAdministration.schema.json, Dosage.schema.json, NutritionOrder.schema.json, and fhir.schema.json, exposed rateSimpleQuantity.

Initial application:
No source commit tagged with FHIR-27842 was found in this checkout. The FHIR-I minutes for 2020-06-22 record the work group conclusion that rateSimpleQuantity was a tooling bug and moved it as an R4 technical correction. The current core source keeps the affected build-scoped elements as rate[x] choices with Quantity/SimpleQuantity typing where appropriate and does not contain rateSimpleQuantity.

Additional context:
MedicationAdministration is active in source/fhir.ini, Dosage is an active datatype, and NutritionOrder is an active resource. Current build.fhir.org schema output in fhir.schema.json.zip now exposes MedicationAdministration_Dosage.rateQuantity/rateRatio, Dosage_DoseAndRate.rateQuantity/rateRatio, and NutritionOrder_Administration.rateQuantity/rateRatio, with no rateSimpleQuantity hits. The historical generator code that likely produced schema artifacts is no longer present in the current source checkout, so there is no current core source hunk to apply.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current source and generated current-build schema surface already satisfy the Jira request by using rateQuantity rather than rateSimpleQuantity.

Recommendation:
Keep this no-change audit commit. No FHIR core source follow-up is needed unless a future build reintroduces rateSimpleQuantity in generated JSON Schema output, in which case the fix should be made in the active schema-generation tooling rather than by changing the MedicationAdministration, Dosage, or NutritionOrder definitions.
