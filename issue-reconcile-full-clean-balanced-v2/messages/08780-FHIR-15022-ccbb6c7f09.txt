FHIR-15022: Audit Media resource list classification

Issue request:
FHIR-15022 was a Published/Persuasive STU3 change request asking to move Media out of Foundation/Other on the Resource Type Index after Media moved from FHIR-I/infrastructure ownership to O&O/clinical ownership.

Initial application:
Jira comments said the request was already pre-applied. Git history confirms that commit e5b3d89 moved Media from Foundation/Other to Clinical Diagnostics in source/resourcelist.html and changed the fhir.ini work group from fhir to oo before the issue was created.

Additional context:
Current source no longer lists Media as an active resource in source/fhir.ini, and source/resourcelist.html has no Media entry to classify. Later Media-to-DocumentReference work, including commit 5c62f91 for GF#19250/FHIR-19250, removed Media from the active resource list and replaced the Clinical Diagnostics Resource Type Index entry with DocumentReference; FHIR-19250 is already represented on the combined reconciliation branch.

AutoFHIR reconciliation:
No source change was made. The requested move was applied before Jira resolution, and the current build cannot still show Media under Foundation/Other because Media is not an active current-build resource and no Media link appears in the Resource Type Index.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-15022 unless a future work group decision reintroduces Media as an active resource, in which case it should be classified by that new decision rather than by this STU3 tracker.
