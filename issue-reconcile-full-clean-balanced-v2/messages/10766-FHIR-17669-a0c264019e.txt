FHIR-17669: Audit sa and eb number prefix clarification

Issue request:
FHIR-17669 was a Published FHIR-core Search page change request, resolved Not Persuasive with Modification, asking whether the sa (starts-after) and eb (ends-before) search prefixes apply to decimals. The approved resolution was to clarify that sa and eb are not used with integer values but are used for decimals, because decimals are covered by the number search parameter rules.

Initial application:
The Jira comments point to GH#7fc760dc06 and say the change was already applied under a different task. Commit 7fc760dc068ce480e3a0572501f7124876d4d9f3 changed source/search.html from saying sa/eb were not used with integer values to saying they were not used with integer values but are used for decimals.

Additional context:
The Search page has since been substantially refactored by later search-prefix clarification work. The old sentence no longer exists, but the current source/search.html prefix section says prefixes are available for the ordered parameter types number, date, and quantity, the sa and eb rows define starts-after and ends-before boundary behavior, and the current number section explicitly lists sa and eb among comparison prefixes that ignore implicit number precision. FHIR-17668 and FHIR-26311 provide adjacent/later decimal implicit-range context, and FHIR-40319 later simplified the prefix definitions without reversing decimal applicability.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already communicates the core FHIR-17669 outcome that sa and eb apply to number/decimal searches, while the newer wording integrates that rule with the current boundary-comparison model. Re-adding the historical sentence would be redundant and could conflict with later clarifications.

Recommendation:
Keep this audit commit as-is. If the work group wants to revisit whether integer-valued number searches should be excluded from sa/eb under the current boundary model, handle that as a new search-prefix clarification rather than as unfinished FHIR-17669 application work.
