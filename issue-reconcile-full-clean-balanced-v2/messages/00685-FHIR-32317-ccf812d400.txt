FHIR-32317: Audit ResearchStudySite profile outside core

Issue request:
FHIR-32317 asked FHIR core to create a ResearchLocation profile of Location for research study sites, including site recruitment status and contact details. The issue is Applied for R6 with resolution Not Persuasive with Modification; the decisive resolution was to instead create a site profile of ResearchStudy.

Initial application:
No core source commit mentioning FHIR-32317 was found, and the current core checkout has no ResearchLocation or ResearchStudySite profile source. Location and ResearchStudy are both active core resources, but the active source does not add a study-site recruitment profile to Location. ResearchStudy already supports study-site modeling through ResearchStudy.site and hierarchical ResearchStudy.partOf, while the older SiteRecruitment extension is maintained in the FHIR Extension Pack rather than as a core profile.

Additional context:
Related issue FHIR-33000 was Resolved - No Change by Patient Administration, rejecting recruitment/enrollment status on Location or Organization as inappropriate and pointing the work back to ResearchStudy. BRR minutes later recorded that no R6 core action was required and that the site profile should be created in an IG. December 2025 and January 2026 BRR minutes show the ResearchStudySite profile being handled in the Evidence Based Medicine on FHIR IG, and the current EBM IG continuous build exposes a ResearchStudySite profile of ResearchStudy at http://hl7.org/fhir/uv/ebm/StructureDefinition/research-study-site.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR core source change. Creating a core Location profile now would contradict the final issue resolution, the FHIR-33000 no-change decision, and the later BRR direction to house the ResearchStudySite profile in an implementation guide outside this checkout.

Recommendation:
Keep this external-repo audit commit as-is for core. Any future changes for the profile should be made in the EBM-on-FHIR IG, or in the FHIR Extension Pack for the related SiteRecruitment extension, unless BRR opens a new final tracker to move this content into core.
