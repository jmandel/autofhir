FHIR-35939: Audit Transport incubator move

Issue request:
FHIR-35939 was a Published/Persuasive R5 OO change request to create the initial Transport resource. The resolution said to add the resource to the build as described by the Transport Resource Proposal.

Initial application:
The issue was applied in the R5 development line. The initial Transport commit added the active fhir.ini resource registration, source/transport StructureDefinition, examples, terminology, and search parameters; PR #1686 then merged the branch, with the Jira comment pointing to the final typo-fix commit in that PR.

Additional context:
The proposal and OO minutes confirm the intended initial resource scope for movement of people and items, with Task used for workflow operationalization. Later Transport decisions refined the resource, especially FHIR-39512, which aligned Transport with Event semantics instead of letting it bridge Event and Request. The current core branch later removed Transport and several other OO resources from active fhir.ini registration in commit 3b38b80, "Remove OO resources and point to new incubator", and current core pages link Transport to the OO Incubator IG. FHIR-53282 tracks Jira artifact configuration for OO-Incubator additional resources, but it is not a final Applied/Published issue for this worker to decide.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding Transport to the core [resources] list would reverse the later incubator move, and editing source/transport would modify legacy source that is no longer an active current-core build resource.

Recommendation:
Keep this audit commit as-is for core reconciliation. Follow-up Transport resource work should happen in the OO Incubator/source responsible for https://build.fhir.org/ig/HL7/oo-incubator/StructureDefinition-Transport.html unless a new final work-group decision explicitly returns Transport to core.
