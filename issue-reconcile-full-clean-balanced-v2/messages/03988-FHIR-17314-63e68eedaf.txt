FHIR-17314: Clarify OrganizationAffiliation affiliation text

Issue request:
FHIR-17314 was a Published/Persuasive PA change request raised against STU3 OrganizationRole and applied for R5. It reported that much of the OrganizationRole narrative and element description content had been copied from PractitionerRole and still referred to practitioners or roles where the organization affiliation itself was meant. The resolution said most content had already been corrected for R4, but some role text should be further clarified as affiliation text, with "Business identifiers that are specific to this role" called out as an example to change.

Initial application:
Commit 28a52e3312 pre-applied GF#17314 to the old OrganizationRole spreadsheet by replacing many PractitionerRole-derived descriptions, but it still left the identifier short/definition as "Business identifiers that are specific to this role" and left the active comment saying the period showed when the role was active. Commit 0b2790895e later renamed OrganizationRole to OrganizationAffiliation and significantly cleaned up the resource, but the stale affiliation-level role wording survived through the current StructureDefinition source. No prior combined-branch commit for Issue-Reconcile-Key: FHIR-17314 was found.

Additional context:
OrganizationAffiliation is active in the current build through source/fhir.ini, and source/organizationaffiliation/structuredefinition-OrganizationAffiliation.xml is the authoritative source for these element definitions. Later OrganizationAffiliation work, including FHIR-25406, intentionally kept role terminology where the element is about the role/code a participating organization plays; this reconciliation therefore leaves role-specific code, service, location, specialty, and endpoint text unchanged. Negative Zulip and Confluence searches found no community evidence that narrows or reverses the Jira resolution.

AutoFHIR reconciliation:
This commit changes OrganizationAffiliation.identifier's short and definition from "this role" to "this affiliation" and changes the OrganizationAffiliation.active comment from "when the role was in active use" to "when the affiliation was in active use." These are the remaining current-build affiliation-level descriptions that match the Jira-requested clarification.

Recommendation:
Keep this commit as-is. It completes the published non-substantive clarification in the active OrganizationAffiliation source while avoiding broader rewrites of valid role-specific terminology.
