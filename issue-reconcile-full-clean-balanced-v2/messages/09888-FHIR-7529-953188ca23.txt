FHIR-7529: Audit ElementDefinition min/max Quantity support

Issue request:
FHIR-7529 was a Published/Persuasive with Modification FHIR-I change request from DSTU1 asking ElementDefinition to support constraints for non-coded values, especially quantities, by adding min/max support. The approved motion added inclusive min/max values, and the implementation comment says svn revision 5865 named the elements minValue[x] and maxValue[x], allowed Quantity with canonical interpretation, and allowed relative Duration for date/dateTime/instant values.

Initial application:
The historical application is explicit: git commit 3315304d9e315169825e8348d1bd828b1b156b28 (#7529, git-svn build@5865) added ElementDefinition.minValue[x] and ElementDefinition.maxValue[x] to source/datatypes/elementdefinition.xml. Later FHIR-10152 changed the type column from a wildcard to a discrete type list, but the FHIR-7529 quantity semantics remained in the ElementDefinition source.

Additional context:
Current source/fhir.ini includes ElementDefinition in the active datatype list, type-page mapping, normative list, and work-group mapping, so source/datatypes/elementdefinition.xml is in current build scope. Later min/max issues do not reverse this conclusion: FHIR-12063 and FHIR-12166 were resolved with no source change, while FHIR-27914 and FHIR-14017 dealt with minValue/maxValue extension type consistency and treated ElementDefinition Quantity support as the baseline.

AutoFHIR reconciliation:
No source change was made. The current ElementDefinition source already has 0..1 minValue[x] and maxValue[x], includes Quantity in the permitted type list for both, states that the bounds are inclusive, and defines canonical Quantity interpretation for minimum and maximum values.

Recommendation:
Keep this empty audit commit as-is. Future cleanup of min/max wording or extension-type consistency should be handled under its own tracker rather than by reopening FHIR-7529, because the seed request is already satisfied in the current build-scope ElementDefinition source.
