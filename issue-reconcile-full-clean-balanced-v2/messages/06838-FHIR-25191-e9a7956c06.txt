FHIR-25191: Audit arterial BP vital-sign narrative

Issue request:
FHIR-25191 was an Applied/Persuasive OO change request for FHIR-core Observation, raised in STU3 and applied for R6. It asked to clarify the Vital Signs narrative that the blood pressure vital-sign panel and systolic/diastolic component codes mean arterial blood pressure, not venous pressure; the final Jira disposition added "arterial" to the blood pressure entries on observation-vitalsigns.html.

Initial application:
The request was applied by c6455a91d66110ba0f8ecc239d16447908cd4ffa, "Added 'arterial' to requested areas," which references FHIR-25191 and changed source/observation/observation-vitalsigns-profile-introduction.xml table labels and emphasis text for the blood pressure panel, systolic blood pressure, and diastolic blood pressure. Jira records PR #3669 for this application. No prior combined-branch reconciliation commit for FHIR-25191 was present before this audit.

Additional context:
Observation is active in source/fhir.ini, source/observation/list-Observation-packs.xml includes ImplementationGuide/Observation-vitalsigns, and that implementation guide references observation-vitalsigns-profile-introduction.xml and StructureDefinition/bp, so the checked files are current build inputs. The current source keeps "arterial" in the vital-sign table labels and emphasis text, and the BP profile and value set descriptions also use arterial. A later FHIR-32788 reconciliation commit changed the same blood pressure row by removing disputed supplemental-code guidance, but it left the arterial clarification intact and explains why the current paragraph no longer literally matches every older resolution word. The originating Zulip thread confirms the ambiguity was arterial versus venous BP, and no searched Zulip or Confluence evidence showed a contrary later decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the active source already conveys the approved clarification. Adding another "arterial" in the panel row's parenthetical component phrase would be redundant beside the arterial panel label and the arterial systolic/diastolic component entries, and it would re-expand a paragraph that FHIR-32788 intentionally simplified.

Recommendation:
Keep this audit commit as-is. Revisit only if OO explicitly decides the panel paragraph must separately repeat "arterial" after the FHIR-32788 simplification; no current source correction is needed for FHIR-25191.
