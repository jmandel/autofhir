FHIR-31596: Audit simple package model supersession

Issue request:
FHIR-31596 was a Published FHIR-core BR&R change request resolved as Persuasive for R5. It asked to replace MedicinalProductDefinition.packagedMedicinalProduct with a repeatable MedicinalProductDefinition.package backbone containing type, size[x] Quantity|integer, and a package Reference to PackagedProductDefinition so simple packaging could be represented without always using the full package resource.

Initial application:
The issue was explicitly applied before this reconciliation by commit 568677234571883603b9e0001acb394e271a40aa, which removed MedicinalProductDefinition.packagedMedicinalProduct and added the requested MedicinalProductDefinition.package backbone. Later same-area history narrowed and then removed that backbone: commit aa2f228c821b96e4c0fc79e1c815d97ce6997050 removed MedicinalProductDefinition.package.package and the integer size option while applying FHIR-31859, and commit 5d196f882b51cf9548321a5819882de30fdfe2c4 removed the remaining MedicinalProductDefinition.package backbone and restored packagedMedicinalProduct as a CodeableConcept while applying FHIR-31782.

Additional context:
source/fhir.ini lists MedicinalProductDefinition and PackagedProductDefinition as active current-build resources. Current source has MedicinalProductDefinition.packagedMedicinalProduct as a CodeableConcept package-type list, no MedicinalProductDefinition.package backbone, and no MedicinalProductDefinition reference target to PackagedProductDefinition. Full package details are represented on PackagedProductDefinition, whose packageFor element references MedicinalProductDefinition. FHIR-31859 and FHIR-31782 are Published/Persuasive BR&R decisions in the same MedDef family and are already represented on the combined branch, so they should not be duplicated here.

AutoFHIR reconciliation:
Published an empty no-change audit commit for FHIR-31596. No source edit is needed because reintroducing the requested package backbone would contradict the later published no-bidirectional-link and backbone-removal decisions that now define the current model.

Recommendation:
Keep this audit commit as-is. The original FHIR-31596 change was applied, but the current source correctly reflects later approved MedDef decisions; future work should revisit FHIR-31859/FHIR-31782 or open a new tracker rather than restoring MedicinalProductDefinition.package under FHIR-31596.
