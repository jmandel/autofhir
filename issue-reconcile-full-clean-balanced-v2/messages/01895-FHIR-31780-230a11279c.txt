FHIR-31780: Audit medication definition status fields

Issue request:
FHIR-31780 was Published/Persuasive with Modification for R5. It asked to add a distinct status to the medication-definition resources that lacked one: the current-build successors of MedicinalProductManufactured and MedicinalProductPharmaceutical, plus Ingredient per the final Jira resolution. The approved representation was a 1..1 modifier status using the draft/active/retired/unknown publication-status values.

Initial application:
The issue was applied before this reconciliation by f67c15e888 and b838576d2f, both titled "Ingredient.status and ManufacturedItemDefinition and AdministrableProductDefinition FHIR-31780". Those commits added the required code status elements to AdministrableProductDefinition, ManufacturedItemDefinition, and Ingredient and added active status values to their examples; the Jira comment also says the change was applied in the R4B branch and main build.

Additional context:
source/fhir.ini lists AdministrableProductDefinition, ManufacturedItemDefinition, and Ingredient as active current-build resources. BRR minutes from 2021-10-05 record the FHIR-31780 vote and clarify that status was to be added to three medication resources using the value set already used by other knowledge resources. The related FHIR-31790 and FHIR-31830 status-family issues are already represented on the combined branch and apply the same required code/publication-status pattern to other BRR resources. Zulip searches found no conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current StructureDefinition sources already define AdministrableProductDefinition.status, ManufacturedItemDefinition.status, and Ingredient.status as 1..1 code elements, modifier=true, with required bindings to http://hl7.org/fhir/ValueSet/publication-status, and the checked-in examples include active status values.

Recommendation:
Keep this audit commit as-is. No FHIR core source change is needed for FHIR-31780 unless BRR later reopens the broader medication-definition status/canonical-resource policy.
