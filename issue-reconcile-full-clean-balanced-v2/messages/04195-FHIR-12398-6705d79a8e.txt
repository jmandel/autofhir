FHIR-12398: Audit Medication ingredient active flag

Issue request:
FHIR-12398 was Published with a Persuasive with Modification resolution for the DSTU2 Medication resource. It requested a way to distinguish active from inactive Medication.product.ingredient entries; the accepted change was to add product.ingredient.isActive as a 0..1 boolean where true means the ingredient affects the drug's therapeutic action and false means it does not.

Initial application:
The issue was applied in git commit 6ef7a79e5d50d39ae6d127dc66cada986d958001, which added Medication.product.ingredient.isActive to the Medication spreadsheet and recorded the active/inactive true/false requirements. A later Medication refactor in b0500f8b520d72851aba346483f21d1ded9a86b3 removed the product backbone and moved the applied element to Medication.ingredient.isActive, and the 2021 source rework in 33b409a4b6d544598262f2f074ebb4b6dc466157 carried that element into source/medication/structuredefinition-Medication.xml.

Additional context:
Medication is an active resource in source/fhir.ini, so source/medication/structuredefinition-Medication.xml is in current build scope. Current source retains Medication.ingredient.isActive as a 0..1 boolean with the requested therapeutic-action definition and true/false requirements, while Medication.ingredient comments also allow both inactive and active ingredients. Later discussions and Jira decisions did not reverse the flag: FHIR-36048 was Resolved - No Change when replacing isActive with a role code was requested; FHIR-46607 later added Medication.ingredient.role as a complementary CodeableConcept; and FHIR-54375 is a separate Resolved - change required cleanup for the role definition, not for the existence or semantics of isActive.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current source already represents the FHIR-12398 decision after the Medication.product-to-Medication.ingredient refactor.

Recommendation:
Keep this audit commit as-is for FHIR-12398. Handle FHIR-54375 separately when Resolved - change required issues are in scope, because that later cleanup should adjust Medication.ingredient.role wording without removing or weakening the FHIR-12398 isActive flag.
