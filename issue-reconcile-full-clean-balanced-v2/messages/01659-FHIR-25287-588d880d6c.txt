FHIR-25287: Align AuditEvent outcome ModelInfo

Issue request:
FHIR-25287 was a Published FHIR-core Security change request, resolved Persuasive with Modification for R5, asking to remove AuditEvent.outcomeDesc and change AuditEvent.outcome from the R4 outcome code plus text description pair into a 0..1 CodeableConcept. The resolution allowed text-only outcome text, an extensible binding to the AuditEvent outcome value set, and additional codings such as HTTP response classes.

Initial application:
The issue was initially applied in git history by d97f7c47d, which changed AuditEvent examples from separate outcome/outcomeDesc elements to a CodeableConcept outcome, and Security WG minutes later recorded FHIR-25287 as applied to the FHIR core build. The early R4B StructureDefinition source also carried the requested CodeableConcept outcome shape and removed outcomeDesc before later AuditEvent outcome remodeling.

Additional context:
FHIR-32447 later superseded the FHIR-25287 CodeableConcept shape with the current outcome backbone containing code 1..1 code and detail 0..* CodeableConcept. That later issue is already represented on the combined branch, so this commit does not duplicate its primary AuditEvent source changes. Current source/auditevent/structuredefinition-AuditEvent.xml is in build scope through source/fhir.ini and already has no outcomeDesc; it now uses outcome.detail.text for text details and a required outcome.code. Library is also active, and the Library examples page exposes source/library/library-fhir-model-definition-content.xml as the FHIR ModelInfo file used by CQL tooling. That active FHIR 6.0.0 ModelInfo surface still exposed the old scalar AuditEvent.outcome and stale outcomeDesc, while the separate QUICK model-definition example is legacy QUICK content and was not changed.

AutoFHIR reconciliation:
Updated source/library/library-fhir-model-definition-content.xml so current FHIR ModelInfo defines AuditEvent.Outcome as a backbone with code and repeatable detail entries, points AuditEvent.outcome at FHIR.AuditEvent.Outcome, and removes the stale AuditEvent.outcomeDesc element. Refreshed the embedded base64 data in source/library/library-fhir-model-definition.xml so the Library resource and readable ModelInfo content remain identical.

Recommendation:
Keep this commit as-is. It completes FHIR-25287 across the current build-scoped FHIR ModelInfo surface while respecting the later FHIR-32447 outcome model; any further AuditEvent outcome terminology or required-binding changes should continue to be handled under their specific later Jira decisions.
