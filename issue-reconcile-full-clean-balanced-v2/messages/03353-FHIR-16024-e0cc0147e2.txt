FHIR-16024: Audit Medication ingredient references

Issue request:
FHIR-16024 was a Published/Persuasive with Modification STU3 Pharmacy change request asking whether Medication.ingredient should reference only Substance and not Medication. The work group rejected the Substance-only interpretation because Medication ingredients also need to reference Medication when an ingredient in a compound or combination package is itself a packaged product, and requested adding an example to the reference definition.

Initial application:
The issue was applied in git-svn commit e880d7aefcd50da109830288c2be9b4f5746d923, which explicitly listed tracker 16024 and changed the Medication spreadsheet so the ingredient item could be a substance or another medication, adding the Glaxal Base compound-product example to the comment text. The source was later refactored from spreadsheet input to source/medication/structuredefinition-Medication.xml.

Additional context:
Medication is an active resource in source/fhir.ini, and the current Medication.ingredient.item source still targets Medication as well as Substance. Later Substance/SubstanceDefinition work added SubstanceDefinition as an additional target and updated the prose, but it preserved the Medication target and the Glaxal Base example. The Medication introduction also says compounded products may include manufactured-product ingredients and combination packaged products may reference Medication instances. No contradictory current-source or community evidence was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already conveys the FHIR-16024 decision: it does not restrict Medication.ingredient.item to Substance, it explicitly includes Medication as a target, and it provides the requested medication-as-ingredient example.

Recommendation:
Keep this audit commit as-is. Do not narrow Medication.ingredient.item to Substance; later SubstanceDefinition additions are compatible with, not a reversal of, the FHIR-16024 decision.
