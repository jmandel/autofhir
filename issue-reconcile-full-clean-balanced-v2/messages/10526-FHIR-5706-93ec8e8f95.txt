FHIR-5706 is a Published/Persuasive FHIR-core technical correction for the search page's Advanced filtering section. It asked to replace the ungrammatical sentence beginning "While the search mechanism described above is flexible ... but is limited in it's ability" with a syntactically corrected sentence.

Initial application:
The issue was applied in svn revision 4115, preserved as git commit 5a1385a72dcc2a0c40c9ea0f69c795743ddfa9e2 (#5706: fix typo), which changed the sentence in source/search.html from the "While ... but" form to a normal main clause and inserted "but it is limited". That commit still left the possessive typo "it's", but FHIR-5235's later typo sweep in b96ed091e1a76a841b2ad40c8f31486489d18881 changed occurrences of "it's" to "its" in search.html.

The current search.html Advanced filtering paragraph is still in the core search narrative source and now reads "The search mechanism described above is flexible, and easy to implement for simple cases, but is limited in its ability to express combination queries." Later wording and QA work changed nearby prose and the exact phrasing, but retained the corrected syntax and meaning.
