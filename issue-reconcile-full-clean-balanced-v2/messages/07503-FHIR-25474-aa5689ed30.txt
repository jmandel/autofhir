FHIR-25474: Audit GraphDefinition graph redesign externally

Issue request:
FHIR-25474 was a Published/Persuasive with Modification FHIR-I change request for R5 asking GraphDefinition to describe an actual graph rather than a tree. The accepted resolution was to revamp the resource around node definitions, edge relationships between node definitions, an optional root/start node, and structures for constraining references to specific node instances.

Initial application:
The issue was applied in core by commit 93e0bc90e3a80969bae01ab57e37a0cb9221ee68. That commit rewrote source/graphdefinition/structuredefinition-GraphDefinition.xml and examples/notes from the old start/profile/link.target recursive shape to GraphDefinition.start as a node id, GraphDefinition.node with nodeId/type/profile, GraphDefinition.link with sourceId/targetId, and link-level compartment rules. No prior reconcile commit for FHIR-25474 was present on the combined branch before this audit.

Additional context:
The 2019-2020 Zulip discussion and the 2020-06-08 FHIR-I minutes support the same direction: the old resource was tree-like, the request was to make it a true graph using identified nodes and edges, and the WG accepted that with modification. A 2022-09 WGM carry-over assigned Lloyd McKenzie to define the specific data structure details, which aligns with the later 2022 implementation commit. Current R6 core no longer contains an active GraphDefinition resource: source/fhir.ini has no graphdefinition resource entry, source/conformance-module.html directs GraphDefinition to the API Incubator, and commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd removed source/graphdefinition from core. The current HL7/api-incubator-ig source for StructureDefinition-GraphDefinition still contains the FHIR-25474 node/link graph structure. A later FHIR-41494 decision asks for invariants tying start/sourceId/targetId to declared nodeIds, but it is only Resolved - change required and belongs to the external GraphDefinition artifact rather than this current core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The FHIR-25474 redesign was applied before reconciliation, and the current core checkout is not the authoritative build source for GraphDefinition.

Recommendation:
Keep this external-repo audit commit as-is for core. No core follow-up is needed for FHIR-25474; future GraphDefinition maintenance, including the later FHIR-41494 invariant request, should be handled in HL7/api-incubator-ig or the repository that owns the API Incubator artifact.
