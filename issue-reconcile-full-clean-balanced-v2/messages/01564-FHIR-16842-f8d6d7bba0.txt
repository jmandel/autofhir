FHIR-16842: Audit Measure.description wording

Issue request:
FHIR-16842 was a Published/Persuasive CQI change request for STU3 Measure.description. It objected that the existing example referred to "the language of the profile" and appeared to assume measures were always profiles; the accepted resolution was to clarify the wording so the example applied to description.

Initial application:
The Jira comment records SVN 14852. The mirrored git history contains d6775d2e5c070e7cf9a2ee0a6fcb41b52fde6420, "GF#16842: Clarified description documentation in MetadataResource," which changed the Measure and MetadataResource spreadsheet wording from "language of the profile ... place the profile was created" to the templated "language of the {{title}} ... place the {{title}} was created." Later source refactors moved the generated/current Measure definition into source/measure/structuredefinition-Measure.xml.

Additional context:
Measure is an active resource in source/fhir.ini, so source/measure/structuredefinition-Measure.xml is in the current build scope. Later Published issue FHIR-35986 removed the separate "why the measure was built" overlap from CanonicalResource.description comments but preserved this FHIR-16842 wording. Searches found no relevant Zulip or Confluence discussion and no current source occurrence of the old "language of the profile" wording.
