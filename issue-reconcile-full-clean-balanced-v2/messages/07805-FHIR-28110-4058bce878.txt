FHIR-28110: Audit _query standard-parameter guidance

Issue request:
FHIR-28110 was a Published/Persuasive FHIR-I clarification for R5 asking whether _query can be used with _include, _revinclude, and other standard search parameters; whether non-general search parameters must be declared in the OperationDefinition; what name is used in _query=name; and whether a query OperationDefinition may also be invoked with $code.

Initial application:
The issue was applied in source history by c1ec74312bef4ae87d0c629f87020507d27ca68d and revised by 0d3162cfbb9fbd27bc071508bdde6ed46a182f92. Those commits added OperationDefinition.code-based _query naming, named-query standard/inherited parameter guidance, and the non-$code invocation rule to the Search page, with additional OperationDefinition query constraints added alongside related FHIR-19645 work.

Additional context:
FHIR-I minutes from 2020-10-26 record the same three-part FHIR-28110 decision. The current combined branch has later related named-query reconciliations for FHIR-34406, FHIR-31491, FHIR-39316, and FHIR-39318; those later changes preserve and refine the FHIR-28110 semantics rather than reversing them. source/search.html is active build-scope narrative through publish.ini and source/hierarchy.xml, and OperationDefinition is an active resource in source/fhir.ini.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Search page says _query is matched to OperationDefinition.code, says named-query operations should be invoked through search with _query rather than $operation-code URLs, and explains that standard all-resource, result-modifying, and resource-scoped search parameters are potentially available while authors should include relevant parameters in the OperationDefinition. The OperationDefinition notes page carries the parallel named-query search guidance.

Recommendation:
Keep this audit commit as-is. The current source already conveys the FHIR-28110 decision, and further wording changes would duplicate or destabilize guidance that later related reconciliations have already aligned.
