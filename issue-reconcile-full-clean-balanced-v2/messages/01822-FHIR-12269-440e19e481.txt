Issue request:
FHIR-12269 was Published/Persuasive for DSTU2 by Imaging Integration. It asked to update the ImagingStudy DICOM mappings, including StudyInstanceUID/Study ID and accession identifiers, procedureCode, location, reasonCode, note, description, series.description, series.performer, and series.instance.title tag mappings while leaving other rows unchanged.

Initial application:
The Jira comments identify SVN 14699, and git history contains commit 44a2cad3446e7fc39c551517a3ec01f9fd175eea with subject "updates to ImagingStudy dicom mapping GF#12269". That commit changed the then-authoritative source/imagingstudy/imagingstudy-spreadsheet.xml; the resource source was later converted to source/imagingstudy/structuredefinition-ImagingStudy.xml.

Additional context:
ImagingStudy is active in source/fhir.ini, so the StructureDefinition is build-scoped. Current R6 source has also been shaped by later final Imaging Integration decisions: FHIR-22118, FHIR-49675, and FHIR-56033 keep accession-number guidance under ImagingStudy.basedOn rather than ImagingStudy.identifier; FHIR-47520 replaced the old DICOM mapping table with named attributes and removed the invalid title tag; FHIR-47666 and FHIR-53025 changed the procedure representation; FHIR-47670 removed DICOM mapping language from ImagingStudy.note; and later R6-DICOMTagMapping issues refined several mapping rows.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current combined-branch source already carries the build-scoped ImagingStudy DICOM mapping table after the seed application and later accepted revisions. Reintroducing the exact DSTU2 rows would now be incorrect for accession number, note, procedure, and title because those rows were superseded by later final Jira decisions.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-12269; future ImagingStudy mapping work should be handled through the later R6 mapping issue family rather than restoring the historical DSTU2 wording.
