FHIR-10303: Audit value set CLD descriptions

Issue request:
FHIR-10303 was a Published/Persuasive with Modification Vocabulary change request from DSTU2 asking that rendered Content Logical Definitions for intensionally defined value sets include descriptions for filter code values, especially SNOMED CT is-a filters such as the historical substance-code examples. The recorded resolution says the problem was already fixed.

Initial application:
No commit on the current FHIR source history explicitly mentions FHIR-10303. The relevant substance-code source was already changed before the January 2017 FHIR-10303 vote by git commit 8f5579319910f584e8044f2fa17414395ab9f346, which added SNOMED descriptions for the 105590001 and 373873005 is-a filters in source/substance/valueset-substance-code.xml as part of FHIR-12239-related SNOMED CT recommendations. That explains why the Jira disposition could be "already fixed" rather than requiring a new FHIR-10303-specific source change.

Additional context:
The current Substance resource is active in source/fhir.ini and the current source/substance/valueset-substance-code.xml still names the remaining SNOMED is-a filter as 105590001 (Substance (substance)). A later Published issue, FHIR-19295, intentionally removed the 373873005 pharmaceutical/biologic product filter from the Substance value set in 2019 while preserving the code description pattern for the remaining filter. Current and published rendered pages show CLD rows with code descriptions, including the current build and R5 rendering of 105590001 (Substance) and the R4 rendering of both original filters as 105590001 (Substance) and 373873005 (Pharmaceutical / biologic product).

Recommendation:
Keep this audit commit as-is. No FHIR core source change is needed unless a future publisher regression causes CLD filter rows to omit terminology display text again.
