FHIR-6242: Audit ImagingStudy clinical information removal

Issue request:
FHIR-6242 was Published/Persuasive with Modification for DSTU1. It asked whether ImagingStudy.clinicalInformation should become a choice of string, Condition, and possibly code; the accepted resolution instead said to remove ImagingStudy.clinicalInformation and request equivalent Reason for Requested Procedure content in DiagnosticOrder.

Initial application:
No explicit git commit mentioning FHIR-6242 was found. Historical source shows the field was already disabled as !ImagingStudy.clinicalInformation in the checked-in 2015 ImagingStudy spreadsheet, and git commit af0194455209a0b1f8e57e5ab25f8db53645da0b later removed that disabled row from the ImagingStudy source. DiagnosticOrder source from the same era already had reason and supportingInformation elements for order justification and clinical context.

Additional context:
The current build scope lists ImagingStudy and ServiceRequest as active resources, while DiagnosticOrder is retired/subsumed into ServiceRequest. Current ImagingStudy has no clinicalInformation element. Its current ImagingStudy.reason CodeableReference is a later event-reason lineage from Published ImagingStudy workflow issues and subsequent CodeableReference refactoring, not the removed clinicalInformation element from FHIR-6242. Current ServiceRequest.reason and ServiceRequest.supportingInfo cover request justification and additional clinical information.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already reflects the FHIR-6242 decision by omitting ImagingStudy.clinicalInformation, and the later current-source reason/supportingInfo elements are governed by later decisions rather than by this DSTU1 removal request.

Recommendation:
Keep this audit commit as-is. Revisit only if II and O&O decide in a new tracker that the later ImagingStudy.reason/ServiceRequest.reason/supportingInfo modeling needs to change; that would be separate follow-up work, not a missing application of FHIR-6242.
