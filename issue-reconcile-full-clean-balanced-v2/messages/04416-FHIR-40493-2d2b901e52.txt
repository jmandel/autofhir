FHIR-40493: Audit R5 trial-use element markers

Issue request:
FHIR-40493 was a Published/Persuasive FHIR-I technical correction raised against R4 and applied for R5. It asked that all elements newly added to already normative FHIR-core artifacts since R4 be marked Trial Use, based on an attached R4-to-R5 comparison.

Initial application:
The issue was applied in git commit cc475f0dcf, which added element-level structuredefinition-standards-status=trial-use markers to new elements in active normative artifacts including CapabilityStatement, CodeSystem, ElementDefinition, Observation, OperationDefinition, StructureDefinition, and ValueSet. The Jira comment explicitly identifies that commit as the applied source change.

Additional context:
The affected files are active current-build sources: the resources are listed in source/fhir.ini [resources], ElementDefinition is listed as normative in [standards-status], and the affected StructureDefinition sources now identify version 6.0.0 with root standards-status=normative and normative-version=4.0.0. Later R6 normative-ballot work intentionally removed element-level trial-use flags from these normative resources: 148c3eb080 did so for Terminology Infrastructure artifacts, 5c20769cc7 did so broadly for FHIR-I/OO and other current artifacts, and 7466cfc63c removed mixed trial-use notes. FMG minutes from 2025-05-11 say trial-use elements in normative resources in R6 need a policy and should not be trial-use content in normative resources unless FMG approves; FHIR-54783 later deferred the broader mechanism for future STU elements in normative resources outside R6 core.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the R5 trial-use markers would undo later R6 normative-ballot cleanup and conflict with the current source's normative status treatment. The seed's R5 request was applied, and the current absence of those labels reflects later policy/history rather than an unapplied FHIR-40493 defect.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the R5 element-level trial-use markers in current core unless FMG/FHIR-I makes a new, explicit R6+ decision for STU elements inside normative resources; use FHIR-54783 or its successor work for that broader future mechanism.
