FHIR-13291: Audit CodeSystem scope use cases

Issue request:
FHIR-13291 was a Published/Persuasive STU3 vocabulary change request for the CodeSystem Scope and Usage section. It objected to wording that CodeSystem was intended for smaller ad-hoc code systems and asked the specification to mention larger code system metadata use cases, including systems such as SNOMED where CodeSystem.content and CodeSystem metadata can describe filters and properties without distributing all concepts.
