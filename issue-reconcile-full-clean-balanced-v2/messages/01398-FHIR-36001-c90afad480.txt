FHIR-36001: Audit MedicationStatement partOf restoration

Issue request:
FHIR-36001 was a Published/Persuasive Pharmacy change request raised against R4 MedicationStatement/MedicationUsage. It explicitly revisited FHIR-31508, stated that the removal overlooked a use case where a MedicationUsage was part of a procedure, and resolved to add support for partOf constrained to Procedure.

Initial application:
Git commit 0e463239a18c2754e691aecf97c70119c5891b41, under the subject "FHIR-37372, FHIR-35899, FHIR-36001", restored MedicationUsage.partOf in source/medicationusage/structuredefinition-MedicationUsage.xml with a Procedure target.

Additional context:
FHIR-38690 later added the MedicationUsage target for parent/child usage statements, and FHIR-38682 renamed MedicationUsage back to MedicationStatement. The current active source therefore correctly carries the FHIR-36001 Procedure target along with the later MedicationStatement target. FHIR-57403 is an unresolved R6 request questioning whether the element should be explained or removed, so it is background only.

AutoFHIR reconciliation:
This commit makes no source change. The current build-scope MedicationStatement definition already includes partOf with Procedure as one of its targets, and the later MedicationStatement target is separately justified by FHIR-38690.

Recommendation:
Keep this audit commit as-is. Do not narrow or remove the Procedure target unless a later final Pharmacy decision resolves the open R6 concern differently.
