FHIR-41415: Audit external InventoryItem Group support

Issue request:
FHIR-41415 is Applied/Persuasive with Modification for R6. It asked for InventoryItem.instance.subject to allow Reference(Patient | Organization | Group), for the Group use to be limited to family/household groups rather than practitioner groups, and for the InventoryItem subject search parameter to place InventoryItem in the Group compartment.

Initial application:
The issue was applied in core git commit bcbe0d48a4cf331a9354935711e88c7ea1e8c4ed, which added the Group targetProfile and family/household comment to source/inventoryitem/structuredefinition-InventoryItem.xml and added an InventoryItem subject entry under the Group column in source/compartments.xml. No additional source change was needed for the search parameter itself because InventoryItem-subject already existed.

Additional context:
Later commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed InventoryItem and related OO incubator resources from the active core resource list and compartments matrix, then updated core module pages to point InventoryItem readers to the OO Incubator IG. In the current core build, source/fhir.ini has no active inventoryitem resource entry, and the remaining core module references link to https://build.fhir.org/ig/HL7/oo-incubator/StructureDefinition-InventoryItem.html. The OO Incubator package hl7.fhir.uv.oo-incubator 0.1.0 currently carries InventoryItem.instance.subject with Patient, Organization, and Group target profiles plus the requested family/household comment.

AutoFHIR reconciliation:
This commit intentionally makes no source changes in the FHIR core checkout. Re-adding InventoryItem to core compartments.xml would be wrong because InventoryItem is no longer an active core resource, and editing the inactive source/inventoryitem files would not affect the current core build. The active external InventoryItem artifact already reflects the applied Jira resolution.

Recommendation:
Keep this empty audit commit as-is for FHIR core. If future InventoryItem subject or compartment behavior changes are needed, handle them in HL7/oo-incubator; no current core-source follow-up is required for FHIR-41415.
