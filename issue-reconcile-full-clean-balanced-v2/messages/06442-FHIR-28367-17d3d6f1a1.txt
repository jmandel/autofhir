FHIR-28367: Audit Diagnostics module examples

Issue request:
FHIR-28367 was an Applied/Persuasive OO technical correction for the FHIR-core index page. It reported that the Diagnostics module examples in modules-fragment.html used the wrong DiagnosticReport label, duplicated Specimen/ImagingStudy historically, and listed Genomics as though it were a resource.

Initial application:
The requested correction was applied by HL7/fhir merge commit 78b54a9cd063a75a56f36b6da7a560dccc9b0708 for PR #3025, which changed source/modules-fragment.html from the stale Observation/Report/Specimen/ImagingStudy/Genomics examples to corrected DiagnosticReport-oriented examples.

Additional context:
source/index.html includes modules-fragment.html in the built index page, so the fragment is in current build scope. Later OO module rework in commit 203dad3ce447b7094c867ef9b1e0cd5955a6bd39 moved and shortened the Diagnostics box, but preserved the substantive correction: the current examples use DiagnosticReport, no longer duplicate the old entries, and do not list Genomics as a resource. The full Diagnostics module page remains the authoritative module index for the broader and evolving set of resources.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies FHIR-28367's applied correction, and adding a longer exhaustive list to the home-page module fragment would be redundant with diagnostics-module.html and more likely to drift.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed unless OO chooses a new policy for how exhaustive the index-page module example lists should be.
