Issue request:
FHIR-3674 was a Published/Persuasive DSTU1 FHIR-core tooling issue reporting that the SDC profile table view rendered extension rows as "extension", showed question marks in a profile name, and exposed standard extension slicing rows for complex extensions.

Initial application:
The Jira comment says the issue was applied in SVN revision 3261. In the git-svn history this is commit a7d1aef4b7921db67adf4f508cfa51be96c232a4, "{#3674}: Fix rendering of complex extensions", which changed the old Java ProfileUtilities and PageProcessor table-rendering code to resolve nested extension elements, display their actual element names, and suppress standard extension slicing rows. Those Java source paths are no longer present in the current FHIR source checkout.

Zulip and Confluence searches found no directly relevant later discussion or reversal.
