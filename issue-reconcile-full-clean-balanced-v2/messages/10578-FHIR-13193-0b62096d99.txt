FHIR-13193: Audit generic extension discoverability

Issue request:
FHIR-13193 was a Published/Persuasive STU3 FHIR-core change request following GForge tracker #10460. It said the prior visibility work did not make extensions whose contexts apply to all resources or elements discoverable from resource extension views, using the resource-pertainsToGoal extension and MedicationRequest as the motivating example. The Jira resolution text says Auto-deferred, but the done workflow state, Applied for Version STU3, and Grahame's comment identifying SVN revision 12703 are the operative application evidence.

Initial application:
The issue appears to have been applied by SVN revision 12703, represented in git as 01e6e8a758a8914622fcab563fbe03b4d4dbd236, whose subject is "#10460 - generic extensions cross-linked". That publisher change added generic all-resource/all-element extension rows and reference-any extension rows to resource extension pages, matching the FHIR-13193 request even though the commit used the older GForge tracker number rather than the Jira key.

Additional context:
FHIR-12667 is the concrete MedicationRequest/Goal question that exposed the discoverability problem and confirmed that resource-pertainsToGoal was the intended extension. The extension definition now lives in the FHIR Extension Pack, not core source, with context type element and expression Resource. Current core source still links resource pages to extension lists through the generated extension-link hook, and the Extension Pack uses page-factory source to generate per-resource extension pages. Later visibility decisions in FHIR-13656, FHIR-16525, and FHIR-20637 favor prominent resource-page links over inline extension tables, and the current defining-extensions page documents Resource and Element context behavior.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current build output for MedicationRequest links to the Extension Pack's MedicationRequest extensions page, and that page lists resource-pertainsToGoal with Resource as its context. The current source therefore preserves the required discoverability without duplicating extension lists in core or moving Extension Pack-owned definitions back into core.

Recommendation:
Keep this audit commit as-is. No core FHIR source change is recommended for FHIR-13193; future changes to extension discoverability should be handled in the Extension Pack or IG Publisher/resource-page linking design, taking the later FHIR-16525/FHIR-20637 direction into account.
