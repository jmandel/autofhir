FHIR-9197 was Applied with resolution Persuasive with Modification for the FHIR-core TestScript artifact. It asked for reusable TestScript action collections with named parameters and references from setup/test actions, later refined to TestScript.common, action.common.keyRef, action.common.parameter, and teardown action.common behavior.

Initial application:
The issue was applied to core in PR HL7/fhir#3084, merged 2024-05-30. Commit d9855015e35a557a252ca9a1f3bb62ab6c50a3f6 added TestScript.common, setup/test/teardown action.common references, parameters, a readcommon example, and an OID entry under source/testscript while TestScript was still an active core resource.

Additional context:
Core commit f9a44787c45071394532c7c2ee94d76f30f47387 later removed TestScript, TestReport, and TestPlan from the active core build, deleted source/testscript, and added the Testing FHIR IG as the current location for testing resources. The current core source/fhir.ini has no active testscript resource entry, while the Testing IG source and continuous-build StructureDefinition-TestScript profile contain the FHIR-9197 TestScript.common and action.common elements.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. FHIR-9197 now belongs to HL7/fhir-testing-ig rather than the core FHIR checkout, and the relevant external TestScript definition already carries the applied action-reuse structure.

Recommendation:
Keep this external-repo audit commit. Any further corrections to TestScript.common or action.common should be made in HL7/fhir-testing-ig, not by restoring or editing removed core TestScript source.
