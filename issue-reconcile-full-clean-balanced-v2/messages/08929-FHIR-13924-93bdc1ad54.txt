FHIR-13924: Audit ImplementationGuide page documentation

Issue request:
FHIR-13924 was a Published/Persuasive STU3 non-substantive change request asking for fuller explanation of the purpose and use of ImplementationGuide.page and its children. The Jira resolution says to clarify, while the only Jira comment from Grahame Grieve says the request was overtaken by events.

Initial application:
No git commit explicitly mentioning FHIR-13924 was found. History shows the old STU3 top-level ImplementationGuide.page model was subsequently reworked by b319b6a0da, "Rework ImplementationGuide after extensive discussion," splitting page metadata under ImplementationGuide.definition.page and ImplementationGuide.manifest.page; 75410cdf57 then added ImplementationGuide.definition.page.generation and the GuidePageGeneration terminology. Those later structural changes are the apparent events that overtook the original documentation request.

Additional context:
The linked Zulip topic records the original ambiguity: Stephen Royce said the ImplementationGuide.page element descriptions were thin; Grahame first said the publisher passed page content through mostly untouched; Lloyd McKenzie clarified that the IG Publisher uses listed pages for table-of-contents and section-number generation. In the current build, source/fhir.ini actively includes implementationguide=ImplementationGuide and maps the old R3 name ImplementationGuide.page to ImplementationGuide.definition.page. The current StructureDefinition source now describes the root page, source inference, local output naming, navigation titles, generation mode, nested pages, and breadcrumb generation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding new prose would mostly duplicate current element definitions and terminology, while the original STU3 element no longer exists as a current top-level element except through the R3 rename map.

Recommendation:
Keep this no-change audit. Revisit only if the work group wants new publisher-user guide prose outside the ImplementationGuide StructureDefinition; the current normative resource source does not need a FHIR-13924 fix.
