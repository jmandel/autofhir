FHIR-5741: Audit root group clarification

Issue request:
FHIR-5741 was a Published/Persuasive Patient Care clarification for DSTU1 Questionnaire. It asked that the first/root Questionnaire group be described more explicitly as the container for questionnaire-wide title, concept, top display text, and typical required/repeats expectations.

Initial application:
The issue was pre-applied in SVN #4160 by git commit 699e812e2b7e1bb5520c1e9568e95f5fb5260a2b, which updated source/questionnaire/questionnaire-notes.xml to replace the old "main" group language with the requested "root" Group clarification and aligned code/concept terminology.

Additional context:
The current build includes Questionnaire as an active resource in source/fhir.ini. A later Published/Persuasive Questionnaire change, FHIR-8986, was applied by git commit 52dbc1c47868e26651369ea4109008738f17ce5e and intentionally merged the old Group and Question backbone structures into recursive Questionnaire.item. The current notes now say Questionnaire has zero or more items rather than one root Group, the StructureDefinition defines Questionnaire.item as the question/grouping/display container, and fhir.ini maps the retired Questionnaire.group path to Questionnaire.item for version conversion. No Zulip or Confluence evidence was found that reopens the old root-group clarification.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing root-group prose would be incorrect for the current model because questionnaire-wide metadata now lives directly on Questionnaire and form content is represented by zero or more Questionnaire.item entries, including group items where needed.

Recommendation:
Keep this no-change audit commit. No core source follow-up is needed unless the work group separately decides to add new guidance about top-level Questionnaire.item grouping in the current item-based model.
