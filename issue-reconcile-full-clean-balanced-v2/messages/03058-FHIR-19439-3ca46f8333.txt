FHIR-19439: Audit Medication ingredient sufficient quantity

Issue request:
FHIR-19439 is a Published/Persuasive Pharmacy change request raised against STU3 and applied for R5. It asked how to represent a Medication ingredient whose amount is "sufficient quantity"; the final resolution was to add a choice of Ratio or CodeableConcept to Medication.ingredient.strength, with a value set containing codes such as qs and trace.

Initial application:
No current git commit explicitly tagged FHIR-19439 was found. The April 2019 Medication commit cdb9b154325715da80c5913ec7939955b7d52105 appears to have applied the issue implicitly by changing Medication.ingredient.strength to Medication.ingredient.strength[x] with type Ratio | CodeableConcept and by adding the medication-ingredientstrength CodeSystem and ValueSet with qs and trace. The current generated StructureDefinition source preserves that change.

Additional context:
Medication is an active resource in source/fhir.ini, so source/medication/structuredefinition-Medication.xml and the Medication terminology files are in current build scope. Later FHIR-25122 added Quantity as a third strength[x] choice for cases where the denominator is assumed to be one dosage form. Later FHIR-30879 and FHIR-31625 address the distinct "sufficient quantity to reach a stated total" case through Quantity.comparator code ad and Medication examples. These later decisions supplement, but do not supersede, the plain qs/trace CodeableConcept path established for FHIR-19439.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current Medication.ingredient.strength[x] already supports Ratio and CodeableConcept, binds the element to http://hl7.org/fhir/ValueSet/medication-ingredientstrength, and defines the requested qs and trace codes. Further local prose or type edits would be redundant and could confuse the distinction from the later Quantity/ad decision family.

Recommendation:
Keep this no-change audit commit. No core source fix is needed for FHIR-19439 unless Pharmacy later decides to change the ingredient-strength value set or move this terminology elsewhere through a separate final tracker.
