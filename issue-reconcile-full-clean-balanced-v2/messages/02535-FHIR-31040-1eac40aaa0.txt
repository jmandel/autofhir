FHIR-31040: Audit ResearchStudy result references

Issue request:
FHIR-31040 was a Published/Persuasive with Modification R5 BR&R change request for ResearchStudy. It asked for ResearchStudy results from stability studies to be able to reference DiagnosticReport, and the final resolution also said to add Citation.

Initial application:
ResearchStudy is active in the current build through source/fhir.ini. The result element was introduced for FHIR-30091, commit d5448ea900e832422a9dfa5dcaea0cd8cb30bb16 added Citation as a ResearchStudy.result target before the seed was applied, and the FHIR-31040-tagged commit 9175459a6ea354d82e8b09ca90574344bbe333d6 added DiagnosticReport. The seed's requested DiagnosticReport target therefore was applied, and Citation was already present in the same target list at that point.

Additional context:
Later R6 work changed the ResearchStudy.result target family. FHIR-46095 and commit bd6875188a7dcc57c2a07da5a7b8593021bf7a03 replaced EvidenceReport with Composition, and the current source also allows Evidence and DocumentReference. More importantly for the Citation part of FHIR-31040, FMG and CDS later moved Citation to the Additional/Incubating Resources track: the CDS 2025-09-10 minutes record a 22-0-0 motion to move Citation to Additional Resources/EBM-on-FHIR while keeping ArtifactAssessment, Evidence, and EvidenceVariable in the base specification, and the FMG resource-removal discussion states that resources moved to Additional Resources can no longer be referred to directly from core resources. Commit 71567db3ee039ac6977be5f96a7e013896569a36 then removed Citation from source/fhir.ini and from ResearchStudy.result.

AutoFHIR reconciliation:
This audit commit makes no source change. The active ResearchStudy StructureDefinition still allows DiagnosticReport in ResearchStudy.result, satisfying the seed's current-core effect. Re-adding Citation to ResearchStudy.result as a direct core target would conflict with the later Citation Additional/Incubating Resources move and the source commit that removed it.

Recommendation:
Keep this audit as-is for FHIR-31040. If FHIR-I/CDS later define direct targetProfile or canonical handling for Incubating/Additional Resources, BR&R and CDS should revisit Citation as a new R6/R7 design item rather than reopening this R5 issue.
