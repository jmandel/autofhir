Issue request:
FHIR-8447 was a Published FHIR-core ValueSet change request, resolved Persuasive with Modification and applied for DSTU1. It asked whether http://hl7.org/fhir/ValueSet/@all included all versions of all value sets or only a latest/arbitrary version.

Initial application:

FHIR-19442 was Published for R5 and resolved that the section should be removed because the feature was very limited, server-specific, and did not support interoperability.
