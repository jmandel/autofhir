FHIR-39528: Audit subject evaluation context guidance

Issue request:
FHIR-39528 is Applied/Persuasive for R6 and asked to clarify that knowledge artifacts with a subject/subjectType element evaluate expressions in the context of that subject, with guidance in the Using Expressions topic and the overview discussions for Measure, PlanDefinition, ActivityDefinition, and Library.

Initial application:
The implementation was applied by HL7/fhir#3411 in commit 67989bee777b5e31b8065968748cc29aa4f5fb34, which added the general Using Expressions rule and ActivityDefinition/PlanDefinition notes. There was no prior AutoFHIR reconcile commit for this key on the combined branch.

Additional context:
The active build includes the Clinical Reasoning Using Expressions topic through source/hierarchy.xml and includes ActivityDefinition, Library, Measure, and PlanDefinition as active resources in source/fhir.ini. Current Measure guidance already states that subject determines the perspective for criteria expression evaluation, and later FHIR-51574 refined Measure-specific behavior by deprecating root Measure.subject and clarifying unfiltered group.subject semantics. Library has subject metadata but no core Library evaluation operation-specific page; the general Using Expressions topic covers knowledge artifacts broadly, so adding a Library-only restatement would duplicate guidance and risk implying operation semantics not defined locally. Zulip and Confluence searches found no conflicting community evidence.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current source already preserves the approved clarification through active general guidance plus resource-specific ActivityDefinition, PlanDefinition, and Measure discussion; no necessary, non-redundant Library source edit was identified.

Recommendation:
Keep this audit commit as-is. Revisit only if the CDS work group wants explicit Library-specific operational semantics beyond the current general Using Expressions guidance and Library.subject metadata.
