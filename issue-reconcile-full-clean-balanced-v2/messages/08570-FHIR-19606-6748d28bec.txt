FHIR-19606: Audit Questionnaire SDC guidance

Issue request:
FHIR-19606 was a Published/Persuasive FHIR-core Questionnaire issue. It asked for a clearer Questionnaire reference to Structured Data Capture (SDC), including a Notes section summarizing SDC operations and rendering/form-control capabilities, a link from the boundaries/relationships discussion to the SDC notes guidance, and movement of populate-related operations to SDC while keeping their canonical URLs.

Initial application:
The Jira comment points to commit cd80b481c37dbfdafa7b73995a63020c7ca94753. That commit changed source/questionnaire/questionnaire-introduction.xml to point readers to the SDC notes section, added the Structured Data Capture and Adaptive Questionnaires notes in source/questionnaire/questionnaire-notes.xml, and removed the Questionnaire-populate operation example from the core OperationDefinition example list. The closely related FHIR-19273 work, implemented by bbee029cd111c0e576e5181737f81a736d92a0d0 and merged as 596ab9615a, added SDC-derived framing to the Questionnaire boundaries/relationships text.

Additional context:
Questionnaire is active in the current build through source/fhir.ini. The current notes page has an SDC section that links to http://hl7.org/fhir/uv/sdc/ and summarizes rendering, dynamic-questionnaire, population, extraction, and adaptive-completion capabilities. source/questionnaire/list-Questionnaire-operations.xml is an empty current list, and source/fhir.ini has no active Questionnaire populate operation entries. Later OperationDefinition guidance from FHIR-38034 uses the preserved Questionnaire-populate canonical URL only as a derived-operation example, not as a reintroduced core Questionnaire operation.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already gives implementers the SDC pointer and capability summary requested by the issue, and the active core build no longer publishes the Questionnaire populate operation as a Questionnaire operation. Adding another boundaries/relationships sentence or duplicating exact operation names would not change the current specification semantics.

Recommendation:
Keep this audit commit as-is. Future changes to the concrete SDC operations should be made in the SDC implementation guide; revisit core only if the Questionnaire source loses the SDC link/capability summary or active core Questionnaire operation definitions reappear.
