FHIR-3543: Audit ImagingStudy accession rename

Issue request:
FHIR-3543 was a Published/Persuasive with Modification FHIR-core ImagingStudy change request from the initial draft asking to rename the unfriendly ImagingStudy.accessionNo element to ImagingStudy.accession for DSTU1.

Initial application:
The rename was applied in historical commit e621d20623aabcc8c4ceddf6fc115cc185c914c0, whose message explicitly cites [#3543] and whose patch changed ImagingStudy.accessionNo to ImagingStudy.accession in the then-current imagingstudy spreadsheet and search parameter mapping.

Additional context:
ImagingStudy is active in the current build through source/fhir.ini. The old spreadsheet source no longer exists in the current resource folder, and current ImagingStudy source has no ImagingStudy.accessionNo element or search parameter. Later ImagingStudy revisions removed the standalone accession element and now document accession number encoding through ImagingStudy.basedOn Reference.identifier with ACSN; FHIR-56033 later clarified this same accession-number guidance by removing inconsistent mention under ImagingStudy.identifier.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current active ImagingStudy source does not contain the obsolete accessionNo name and the current accession-number guidance is internally consistent with later applied work.

Recommendation:
Keep this audit as-is. No core FHIR source follow-up is needed for FHIR-3543; any future change to accession-number modeling should be handled under a new ImagingStudy tracker rather than reviving the DSTU1 rename.
