The issue reported that removing Goal.outcome made it ambiguous how Observations should be linked to Goals for evaluation or progress, and Patient Care selected the resolution to document the resource-pertainsToGoal extension on the Goal resource while asking OO to consider parallel Observation guidance.

Initial application:
The issue was applied in HL7/fhir PR #4060. Commit 7c5f0e1 added the Goal note that points to resource-pertainsToGoal and identifies Observation as an example resource related to the measurement, achievement, or progress toward a referenced goal; the same commit also added a ballot-note entry for FHIR-53828. The other Jira-cited PR commit, f17eb11, only updated source/status-codes.xml and did not affect the Goal/Observation guidance.

Additional context:

The resource-pertainsToGoal extension itself now lives in the FHIR Extension Pack and is active there. FHIR-48360 records the related PC/OO decision not to add first-class Goal/Observation references because the existing extension handles this use case. FHIR-54318 duplicates this seed. The requested Observation-side note is now tracked separately as FHIR-57447, but that OO issue is still Submitted and is not final source-edit scope for this reconciliation. Confluence pages reference the PC discussion, and no Zulip search hit was found that conflicts with the Jira/source conclusion.
