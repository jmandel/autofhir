Issue request:
FHIR-45470 was an Applied OO change request with a Persuasive with Modification resolution to add direct Organization support to Specimen.collection.collector with Reference(Organization) and cardinality 0..1, avoiding an unnecessary PractitionerRole.organization intermediary for collection facilities.

Initial application:
The Jira comment said the change was added to the build in PR 3107 at c06f3f2, and git history shows the actual Specimen source hunk in 7326eeac41 added the Organization targetProfile to source/specimen/structuredefinition-Specimen.xml. The current branch already has Reference(Organization) on Specimen.collection.collector and retains the 0..1 cardinality, so the structural part of the request was applied.

Additional context:
OO Confluence minutes first recorded an indirect-location/practitioner-role discussion and then the May 2024 WGM motion to add Organization directly to Specimen.collection.collector by a 7-0-1 vote. The active source/fhir.ini resource and work group entries show Specimen is in the current build. A related older Published issue, FHIR-32907, broadened the same collector element for patient-collected specimens, so the current definition should describe the permitted collector actor generically rather than as only a person.

It does not change cardinality or targetProfile because the Organization reference was already present.
