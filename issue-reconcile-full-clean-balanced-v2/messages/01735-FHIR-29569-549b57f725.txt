FHIR-29569: Audit expiration classification extension

Issue request:
FHIR-29569 was a Published Pharmacy change request, resolved Persuasive with Modification for R5, asking to add Expiration Date Classification to Medication.Batch. The Jira description used date-type wording, but the final summary and the implemented issue family identify this as a classification/rationale attribute, and the approved resolution was to create a core extension rather than add a base Medication element.

Initial application:
No implementation commit was found whose message explicitly names FHIR-29569. Git history shows the request was nevertheless applied in the Medication manufacturing-batch extension family: commit 52f3ef3d50 added manufacturingBatch.expirationDateClassification to source/medication/medication-extensions-spreadsheet.xml as a CodeableConcept, commit 33b409a4b6 generated source/medication/structuredefinition-extension-medication-manufacturingBatch.xml with expirationDateClassification as a CodeableConcept slice, and commit dd468d4f17 later removed that core extension source when R5 extensions were moved out of this repository. The Extension Pack imported and retained the same extension family.

Additional context:
Medication remains an active core resource, but the current core source maps the historical Medication.batch path to Medication.instance and no longer owns the medication-manufacturingBatch StructureDefinition except for its OID registry entry. The same extension now lives in the FHIR Extension Pack, whose input/definitions/multiple/StructureDefinition-medication-manufacturingBatch.xml applies to Medication.batch and defines Extension.extension:expirationDateClassification with the requested classification definition and CodeableConcept value. Pharmacy minutes for 2020-11-09 record the PQ/CMC manufacturing discussion and the 9-0-0 carried block vote, including FHIR-29569, to add a core extension. A 2022 Zulip thread shows implementation use of the medication-manufacturingBatch extension family and includes expirationDateClassification in a PQ/CMC profile; no later conflicting decision was found.

Recommendation:
