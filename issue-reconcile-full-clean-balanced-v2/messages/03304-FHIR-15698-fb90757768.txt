FHIR-15698: Audit Coverage beneficiary cost codes

Issue request:
FHIR-15698 was a Published FHIR-core Coverage change request resolved Persuasive with Modification for STU3. It asked to add deductible and maximum annual out-of-pocket concepts, with the final resolution directing that deductible and maxannualoutofpocket be added to the Coverage.costToBeneficiary.type example code set.

Initial application:
The issue was applied by git commit 7fbe7046270ff6857644a6af63207642576dc7ef, whose message included GF #15698 and whose Coverage terminology patch added the codes deductible and maxoutofpocket to source/coverage/codesystem-coverage-copay-type.xml. The current worker branch contains that historical commit.

Additional context:
Core Coverage remains in the current build, and Coverage.costToBeneficiary.type still binds extensibly to http://hl7.org/fhir/ValueSet/coverage-copay-type. The value set source now composes all codes from http://terminology.hl7.org/CodeSystem/coverage-copay-type because commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed UTG/THO CodeSystem content from the core build. The current THO CodeSystem version 1.0.1 contains both deductible and maxoutofpocket. FHIR-32966 later refined the Coverage model with category, network, unit, and term elements so annual/family/out-of-network cost-sharing details can be conveyed without changing the seed issue's code-system conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current code system is outside core and already includes the requested concepts, while the active core Coverage source points costToBeneficiary.type to the value set that includes that THO system.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-15698; any future edits to the coverage-copay-type code definitions or displays belong in HL7 terminology governance rather than this core source checkout.
