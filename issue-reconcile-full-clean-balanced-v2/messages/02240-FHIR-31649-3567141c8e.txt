FHIR-31649: Audit ResearchStudy arm exposure changes

Issue request:
FHIR-31649 was a Published FHIR-core BRR change request for R5, resolved Persuasive, asking to add ResearchStudy.arm.intendedExposure 0..* Reference(EvidenceVariable) for interventions or exposures in an arm/cohort and ResearchStudy.arm.observedGroup 0..1 Reference(Group) for the actual enrolled group.

Initial application:
The substantive R5 application appears in git commit d7dbd7689b50ed517e3900c4512399c2cf62d466, which renamed ResearchStudy.arm to ResearchStudy.comparisonGroup while adding comparisonGroup.intendedExposure and comparisonGroup.observedGroup. A later commit, 9175459a6ea354d82e8b09ca90574344bbe333d6, mentioned #31649 but changed unrelated ResearchStudy target profiles, so it was not the meaningful application of this issue.

Additional context:
FHIR-31681, already represented on the combined branch, explains why arm became comparisonGroup. FHIR-39094, also already represented on the combined branch, later audited the comparison-group linkage model. The later Applied R6 decision FHIR-48736 intentionally reshaped ResearchStudy.recruitment and ResearchStudy.comparisonGroup around targetNumber, actualNumber, eligibility, and observedGroup Group references; that change removed comparisonGroup.intendedExposure and retained observedGroup. FHIR-49963 further clarified that outcome-measure intervention/comparator linkage should re-use Groups represented in comparisonGroup.eligibility. Current source/fhir.ini records ResearchStudy as an active resource and records comparisonGroup.intendedExposure as removed in the R5-to-R6 change map.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative ResearchStudy source defines comparisonGroup.observedGroup 0..1 Reference(Group), has no intendedExposure element, and the build-scoped ModelInfo surface matches that child shape. Re-adding intendedExposure for this R5 issue would contradict the later final R6 ResearchStudy model approved in FHIR-48736.

Recommendation:
Keep this audit commit as-is. Do not restore ResearchStudy.comparisonGroup.intendedExposure under FHIR-31649. If BRR wants a new current-version exposure/intervention link on comparisonGroup, that should be raised as a new R6 issue because the old R5 element was superseded by a later applied model change.
