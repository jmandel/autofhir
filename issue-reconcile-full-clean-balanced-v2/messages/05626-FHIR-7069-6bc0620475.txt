FHIR-7069: Audit CarePlan author wording

Issue request:
FHIR-7069 was a Published, Persuasive with Modification DSTU1 CarePlan issue asking whether CarePlan.Author really meant the party responsible for the plan and resolving to amend the wording to "Who is responsible for contents of plan."

Initial application:
The issue appears to have been applied in SVN r6766, imported as git commit d6c4981fa8fe7d58cc3e1cc393aa8cc0b6a83c54, which changed the CarePlan.author short label from "Who is responsible for plan" to "Who is responsible for contents of the plan" in the then-current CarePlan spreadsheet source.

Additional context:
CarePlan is still an active resource in the current build, but the old author element is no longer present as a same-name element. Later published work in FHIR-28544 renamed CarePlan.author to CarePlan.custodian and deliberately separated the designated responsible party from content authorship: CarePlan.custodian is responsible for the care plan, while CarePlan.contributor identifies who provided the contents of the care plan. FHIR-33954 later rejected changing the renamed author/custodian back toward a plan-author wording because that concept is already CarePlan.contributor.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Current source already preserves the implementer-facing distinction that FHIR-7069 was concerned about, as refined by later published Patient Care decisions; changing CarePlan.custodian to be responsible for contents would contradict FHIR-28544 and FHIR-33954, and adding duplicate prose to CarePlan.contributor is unnecessary.

Recommendation:
Keep this no-change audit as-is. Any further adjustment to the custodian/contributor/author distinction should be treated as new Patient Care work rather than a remaining application step for FHIR-7069.
