FHIR-6298: Audit retired QICore profile rendering

Issue request:
FHIR-6298 was a Published/Persuasive FHIR-core DSTU1 change request about the old 2015May QICore AdverseEvent profile rendering at hl7.org/fhir/2015May/adverseevent-qicore-qicore-adverseevent.html. It said the descriptions and bindings for the Basic/QICore AdverseEvent profile were not accessible; the Jira comment gave examples where permitted reference types for AdverseEvent.cause.item were not visible, the allergyintolerance-resolutionAge extension link did not jump to the correct detailed element, and the page could not trace mappings for that extension. Jira records the resolution as the publication problem being resolved by many rendering fixes.

The combined branch already contains audits for related FHIR-8194, FHIR-8196, and FHIR-8705 historical QICore rendering/link issues, so those issues are cited but not republished here.
