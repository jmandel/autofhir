FHIR-3544: Audit ImagingStudy modality naming

Issue request:
FHIR-3544 was a Published / Persuasive FHIR-core ImagingStudy change request raised against the Initial Draft and applied for DSTU1. It asked to rename the top-level ImagingStudy.modality element to ImagingStudy.modalityList to disambiguate it from ImagingStudy.series.modality.

Initial application:
Historical commit e621d20623aabcc8c4ceddf6fc115cc185c914c0 applied the original GForge issue as [#3544], changing the ImagingStudy spreadsheet from ImagingStudy.modality to ImagingStudy.modalityList and updating the example XML element name. No current source-changing commit is needed for that original DSTU1 application because later history changed the approved element name again.

Additional context:
Later Published issue FHIR-12477 explicitly superseded the naming portion of FHIR-3544: while rejecting a request to make ImagingStudy.series.modality optional, its final resolution recognized that modalityList did not follow FHIR element naming guidelines and approved renaming modalityList back to modality. Historical commit 7b2b64512052c9a800a59b0ac3cd2cd013659b1b applied that bundled ImagingStudy update, including the modalityList-to-modality rename. The combined reconciliation branch already contains c116df3a4a22f3a16c1a4d6f594ad7c2f41478ef for FHIR-12477. ImagingStudy is an active build resource in source/fhir.ini; current source has ImagingStudy.modality and ImagingStudy.series.modality, and fhir.ini preserves the old-to-new migration map ImagingStudy.modalityList=ImagingStudy.modality. Later ImagingStudy decisions such as FHIR-17279 and FHIR-36120 also refer to the current ImagingStudy.modality element, reinforcing that the current name is intentional.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring modalityList would undo a later published work-group decision and contradict the current active StructureDefinition. The only remaining modalityList occurrences are the intentional version-mapping entry in fhir.ini and an old QUICK model-definition example outside the authoritative ImagingStudy resource source, so neither is a FHIR-3544 correction.

Recommendation:
Keep this no-change audit commit. Do not rename the current ImagingStudy.modality element for FHIR-3544; any future work on the old QUICK example should be handled as a separate Library/clinical-reasoning example review, not as this ImagingStudy tracker.
