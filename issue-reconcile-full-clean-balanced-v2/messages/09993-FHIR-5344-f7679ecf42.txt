FHIR-5344: Audit superseded contained narrative rule

Issue request:
FHIR-5344 was a Published/Persuasive FHIR-core FHIR-I DSTU1 technical correction from the January 2015 ballot. It asked to resolve a contradiction where the References page said contained resources SHOULD not contain narrative while the Narrative page said contained resources SHALL NOT have narrative of their own; the accepted resolution was svn 4194, making the References constraint consistent with the Narrative page.

Initial application:
The issue was applied in the git-svn mirror commit b96ed091e13d3289a60376e042a6974a574aa807, whose message included #5344 and whose patch changed source/references.html from "Contained resources SHOULD not contain any narrative" to "Contained resources SHALL NOT contain any narrative". No current correction is needed to restore that historical DSTU1 application because the rule it enforced was later replaced.

Additional context:
FHIR-13870 was a later Published/Persuasive with Modification FHIR-I decision that dropped the invariant preventing contained resources from having narrative and added the current rule that contained resources can contain narrative, but that contained-resource narrative is ignored when rendering the containing resource and relevant information SHALL appear in the containing resource's narrative. FHIR-17802 and FHIR-18483 were later Published/Persuasive corrections in the same change family that removed the remaining stale no-contained-narrative text. Those related issues are already represented on the combined branch, so this commit audits only FHIR-5344.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Reintroducing FHIR-5344's older SHALL NOT wording would contradict the later FHIR-13870/FHIR-17802/FHIR-18483 decisions and the current build-scoped source: source/references.html says contained resources can contain narrative, source/narrative.html no longer contains the old prohibition, and active DomainResource comments now only say resources that are not contained SHOULD have narrative.

Recommendation:
Keep this no-change audit. FHIR-5344 is correctly represented as historically applied and now superseded by later Published decisions; no further core source work is needed for this issue.
