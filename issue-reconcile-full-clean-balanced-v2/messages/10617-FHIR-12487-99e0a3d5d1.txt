FHIR-12487: Audit fixed IG business version handling

Issue request:
FHIR-12487 was a Published/Persuasive DSTU2 change request asking for IG Publisher support to set the version element on generated metadata resources to one fixed implementation-guide business version, and for ImplementationGuide specification guidance to make clear that this could be a useful version-management approach.

Initial application:
The issue was applied in svn revision 10630, preserved as git commit 0323c0de1b30d652ff540a205eb5cde0eaad789c, which added a fixed-business-version configuration value and enforcement to the then-in-tree IG Publisher. No separate Jira-tagged source change to ImplementationGuide narrative or StructureDefinition source was found in that application commit.

Additional context:
The referenced Zulip thread shows the decision path: Lloyd proposed avoiding cascading canonical URL/profile version updates by versioning profiles together with the IG, Grahame recommended incrementing all profile versions with the IG, and Lloyd requested an IG Publisher JSON setting that would set version on all metadata artifacts. That implementation surface later left this checkout in commit 56ceb0df08dd72381a4f98f1ea4ac5ea6d139a8b, "Remove IG publisher (it's gone to Maven)". The current core build still includes ImplementationGuide and canonical-resource source; those sources already define ImplementationGuide.version/CanonicalResource.version as business/canonical version identifiers and point readers to the Resource technical-vs-business version guidance.

AutoFHIR reconciliation:
This commit intentionally makes no source change. In the current HL7/fhir checkout, the old IG Publisher configuration is not an in-build source surface, and the active core specification text already permits and explains the business-version model needed for IG-scoped metadata resources. Adding publisher-specific configuration prose to the core resource definition would duplicate external IG Publisher documentation rather than fix a current spec defect.

Recommendation:
Keep this audit commit as-is for the core specification. If someone needs to verify or change the concrete fixed-version publisher option today, do that in the current IG Publisher/Maven source and documentation rather than in this checkout.
