FHIR-13862: Audit activity observation category external terminology

Issue request:
FHIR-13862 is a Published/Persuasive with Modification FHIR-core OO issue from STU3. It asked to add a patient-reported physical activity category to the Observation.category value set, with a definition about observations that measure bodily activity for physical fitness, health, and wellness, and examples such as laps swum, steps, and sleep data. The resolution text contains spelling variants such as "physical-activty", but the applied code in source history was `activity`.

Initial application:
The applying source history appears to be git commit 9b52190635e745d4a09b61888e3a47a9ed9aa05b from 2017-10-14. Its subject appears to swap the nearby GForge issue numbers, but the patch added `activity` to `source/observation/codesystem-observation-category.xml` with display `Activity` and the FHIR-13862 definition. Commit b63ba456ef969b5e173fc94623f34884301e68cc later moved the Observation Category code system URL to the UTG/THO form, and commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed the inline core CodeSystem as part of removing UTG content from the core build.

Additional context:
The current FHIR core source still owns the `http://hl7.org/fhir/ValueSet/observation-category` ValueSet, but that ValueSet includes all concepts from `http://terminology.hl7.org/CodeSystem/observation-category`. The active Observation resource binds Observation.category to this ValueSet with preferred strength. Later Jira and UTG decisions, especially FHIR-42844, UP-724, and implemented UP-738, revised the external THO definition of `activity` by removing the "Not under direct supervision..." sentence. Current THO still contains the `activity` concept, so the seed issue's requested category is present even though the authoritative code definition now lives outside the FHIR core checkout.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change in FHIR core. Editing core would either duplicate an external THO CodeSystem concept or revert later work-group/UTG terminology decisions. The current core ValueSet imports the external CodeSystem, and current THO publishes `activity` in that CodeSystem.

Recommendation:
Keep this audit commit as-is for FHIR core. Do not reintroduce `source/observation/codesystem-observation-category.xml` or hard-code the `activity` definition in core; any future edits to the code display or definition should be handled through the THO/UTG Observation Category CodeSystem process.
