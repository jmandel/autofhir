FHIR-27128: Audit SearchParameter target usage notes

Issue request:
FHIR-27128 was a Published FHIR-I change request, resolved Not Persuasive with Modification for R5. The submitter asked to split the core clinical-encounter search parameter or remove EpisodeOfCare/DocumentReference because not every base resource can resolve EpisodeOfCare from the shared FHIRPath. The approved resolution instead required usage notes on SearchParameter.target explaining that targets may be present even when not valid for every base resource, but that targets SHOULD cover all permitted targets.
