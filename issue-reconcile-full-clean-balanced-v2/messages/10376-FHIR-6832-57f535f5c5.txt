FHIR-6832: Audit extension All-view JSON template

Issue request:
FHIR-6832 was a Published/Persuasive DSTU1 FHIR-core change request from the 2015May SDC ballot. It reported that the JSON template was available on an extension definition's JSON tab but was missing from the All tab for extension definition pages, using the SDC optionalDisplay extension as the observed example. The recorded resolution was to fix the rendering.

Initial application:
The issue was explicitly applied in git commit f044b3876185c42b18caab9186d3a1152f3662c1, whose subject was "#6832 - fix missing json template". That commit changed source/template-extension.html so the All tab's JSON Template block used the JSON inner div and the <%json%> renderer instead of an XML inner div containing a "to do" placeholder.

Additional context:
The extension page template was later moved without content changes from source/template-extension.html to tools/templates/template-extension.html in commit 24e6675dcd8f9f6dbd68745fbcfcafc9b32443b2. Current source/fhir.ini still includes extensiondefinition in the active work-group/build metadata, and the current template retains both the dedicated JSON tab and the All tab JSON Template block. The specific old SDC optionalDisplay extension is historical and no longer a core extension source artifact, but the rendering issue was template-wide rather than specific to that extension definition.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current extension definition template already includes the JSON template in the All tab at tools/templates/template-extension.html lines 131-135, so the requested correction remains present in the current source.

Recommendation:
Keep this no-change audit commit. No follow-up source work is needed for FHIR-6832 unless a future publisher/template migration drops the All-tab JSON block again.
