FHIR-16425: Audit bulk data format status

Issue request:
FHIR-16425 was a Published/Persuasive FHIR-core FHIR-I change request for the STU3-era formats page. It asked that the Bulk Data Formats subsection on the Normative Formats page be flagged Informative because the subsection text itself said the bulk formats were not intended to be normative.

Initial application:
The Jira comments record svn revision 14248. The corresponding git-svn commit c186eb68d4e1ad666db113ba8611651919b0ce38 explicitly mentioned GF#16425 and GF#16997 and wrapped the Bulk Data Formats subsection in draft-content with a warning that the bulk use formats were draft until further experience was gained. The later FHIR-18448 formats-page split moved the applied material into source/resource-formats.html while preserving that draft warning at the time.

Additional context:
FHIR-16997 is the same 2018 change family and has already been represented on the combined branch by no-change audit commit 6f08e4cb1b25fbfc740224cb8a36f369e8eb3cce. The 2018 FHIR-16500 MIME-type issue also confirms that NDJSON should not have been normative then. Those decisions established the historical STU/draft posture, not a permanent prohibition on later normative advancement. Current source/hierarchy.xml links source/resource-formats.html and source/nd-json.html into the Resource Definitions section. Later R6 work deliberately changed the current source: commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd removed the draft-content warning from source/resource-formats.html and changed source/nd-json.html from Draft to Normative, and 2025-09 FHIR-I WGM minutes record the R6 review noting "JSON, NDJSON (already normative)".

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing an Informative or draft marker for the current Bulk Data Formats/NDJSON material would undo a later R6 normative-status decision rather than complete FHIR-16425. The current source is therefore correct for this seed after considering the original application and later status history.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the 2018 Informative/draft warning for FHIR-16425 unless FHIR-I or FMG makes a new decision to reverse NDJSON or bulk-format normative status.
