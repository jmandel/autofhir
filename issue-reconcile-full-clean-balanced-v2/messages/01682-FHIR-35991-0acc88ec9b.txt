FHIR-35991: Audit CodeSystem metadata resource application

Issue request:
FHIR-35991 was Published/Persuasive for FHIR-core-CodeSystem. It requested making CodeSystem a MetadataResource, adding the MetadataResource elements approvalDate, lastReviewDate, effectivePeriod, topic, author, editor, reviewer, endorser, and relatedArtifact, and deprecating/removing the older CodeSystem metadata extensions that were replaced by those first-class elements.

Initial application:
The first application was merge b6dd02933aa689169890719c75396529e3408925 / commit dcc502e4dc654e5ee1c7c86f011209f79936c98b, which changed CodeSystem from CanonicalResource to MetadataResource but did not add the explicit interface elements. The Jira comments then reopened the issue for the missing element and extension work, and PR #2062, merged as c39cdc989629bdbde2038bfa2f21cda0bb2ce97e, added the CodeSystem MetadataResource elements, metadata examples, search parameters, and deprecated the old core extension files that existed at the time.

Additional context:
CodeSystem is active in source/fhir.ini and the current StructureDefinition uses the MetadataResource template and baseDefinition. The requested explicit elements are present in source/codesystem/structuredefinition-CodeSystem.xml and the old core extension definition files are no longer present in the current FHIR source tree. The Extension Pack now owns the migrated extension definitions; later FHIR-extensions decisions FHIR-43630/FHIR-43631 and FHIR-52827 adjusted the CodeSystem/ValueSet keyWord extension handling there, including un-deprecating codesystem-keyWord for pre-R5 use while telling implementers to use CodeSystem.topic from R5 onward.

AutoFHIR reconciliation:
This audit commit intentionally makes no source changes. The current core source already conveys the FHIR-35991 decision: CodeSystem is a MetadataResource, the requested elements are first-class CodeSystem elements, and the superseded core extension definitions are not in the core build.

Recommendation:
Keep this no-change audit commit. Any further changes to the migrated CodeSystem extension definitions, especially codesystem-keyWord status in light of FHIR-52827, belong in the FHIR Extension Pack and its Jira stream rather than in this core FHIR checkout.
