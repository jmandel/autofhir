FHIR-3701: Audit Condition subject naming

Issue request:
FHIR-3701 is a Published/Persuasive with Modification Patient Care change request from DSTU1 asking to rename Condition.subject to Condition.patient because, at that time, the only reasonable Condition subject was a Patient. The recorded resolution approved the change from subject to patient.

Initial application:
The request was applied historically in git commit 925a359a770f79cf932102b21172cd2b36fc1f00, '#3701 - rename Condition.subject to patient', corresponding to svn revision 4796 cited in Jira. That commit renamed Condition examples and the then-current spreadsheet definition from subject to patient.

Additional context:
The current build is no longer the Patient-only model that FHIR-3701 addressed. Condition is active in source/fhir.ini, and source/condition/structuredefinition-Condition.xml now defines Condition.subject as Reference(Patient|Group) with an alias of patient. Later Published issue FHIR-11089 directly addressed the AllergyIntolerance.patient versus Condition.subject inconsistency and resolved that AllergyIntolerance is only Patient, but Condition can be Patient or Group, so subject is correct. Git commit e35d3b3f92f11757466373e8b8f9f829d96d5cc9, 'Substantive Workflow for Condition', is the source-history point that reworked Condition back to a Patient|Group subject model. Related search-parameter audits FHIR-6094 and FHIR-8142 are already represented on the combined branch and reached the same current-state conclusion for Condition patient/subject searches.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-renaming the current Condition.subject element to Condition.patient would contradict the active Patient|Group target model and the later Patient Care decision that subject is correct for Condition.

Recommendation:
Keep this audit commit as-is. Treat FHIR-3701 as historically applied for DSTU1 and superseded by later Condition Patient|Group modeling; require a new current-version Patient Care decision before changing the element name again.
