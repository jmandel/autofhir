FHIR-51024: Add conditional assert model metadata

Issue request:
FHIR-51024 was Applied with a Persuasive with Modification resolution for R6. It asked to enhance TestScript setup action asserts so label remains a string, a new optional id-valued assert.key identifies an assert, and repeating id-valued assert.evaluateBasedOn references earlier assert.key values to conditionally decide whether the current assert is evaluated or skipped.

Initial application:
The request was initially applied in core by ba91e922ce318538784226167ba47b70cf786729, merged through HL7/fhir#3508 alongside FHIR-51025 and FHIR-51111. That commit added TestScript.setup.action.assert.key and TestScript.setup.action.assert.evaluateBasedOn to source/testscript/structuredefinition-TestScript.xml while leaving assert.label as string.

Additional context:
Later commit f9a44787c45071394532c7c2ee94d76f30f47387 removed TestScript, TestReport, and TestPlan from the active core resource list and added the FHIR Testing IG reference. Current source/fhir.ini and source/ballot-intro.html therefore point the authoritative TestScript StructureDefinition to the external HL7/fhir-testing-ig source, where the conditional-assert elements are present. However, the current core Library resource remains active, publish.ini copies source/library/library-fhir-model-definition-content.xml into the build, and that model-definition metadata still exposed TestScript.Assert without key or evaluateBasedOn.

AutoFHIR reconciliation:
This commit updates the current build-scope FHIR model-definition Library by adding key as FHIR.id and evaluateBasedOn as List<FHIR.id> to TestScript.Assert, then regenerates the Library.data attachment so source/library/library-fhir-model-definition.xml stays synchronized with source/library/library-fhir-model-definition-content.xml. It intentionally does not restore source/testscript because the resource definition now belongs to the FHIR Testing IG.

Recommendation:
Keep this core source fix as-is. Future changes to TestScript resource definitions should be made in HL7/fhir-testing-ig, while this commit preserves the conditional-assert metadata on the active core model-definition surface that still includes TestScript classes.
