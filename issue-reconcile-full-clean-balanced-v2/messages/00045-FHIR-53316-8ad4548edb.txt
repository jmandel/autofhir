FHIR-53316: Audit EventDefinition undeprecation

Issue request:
FHIR-53316 was Applied/Persuasive for R6 by the CDS work group. It asked to undeprecate the EventDefinition resource because there are EventDefinition use cases not covered by SubscriptionTopic, and to explain the relationships among MessageDefinition, EventDefinition, SubscriptionTopic, and TriggerDefinition in the EventDefinition Scope and Boundaries content.

Initial application:
The issue was already applied upstream by PR HL7/fhir#3943 in commit c3c3940220063db7380a7920e77039224546f52f. That commit removed the EventDefinition implementation note saying it was deprecated in favor of SubscriptionTopic, changed the EventDefinition standards-status extension from deprecated to normative and FMM from 0 to 6, and added the current Boundaries and Relationships explanation.

Additional context:
FHIR-41372 had previously applied the now-reversed deprecation of EventDefinition in favor of SubscriptionTopic. The linked Zulip thread records the concern that EventDefinition still supports messaging and architecture event-definition uses outside SubscriptionTopic. Current source also includes later EventDefinition follow-up work, including FHIR-53409 and FHIR-53414, without reintroducing resource-level deprecation text. The active fhir.ini resource and standards-status entries confirm EventDefinition remains in current build scope.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already has EventDefinition as an active normative resource and the EventDefinition introduction already explains the requested relationships, so adding another hunk would be redundant and could create maintenance drift. The only remaining deprecated marker found in the EventDefinition source is for the EventDefinition.topic element, not for the resource.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-53316 unless the work group later decides to further refine EventDefinition/SubscriptionTopic boundaries beyond the already-applied R6 wording.
