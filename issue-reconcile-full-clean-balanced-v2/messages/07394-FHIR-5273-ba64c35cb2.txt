FHIR-5273: Audit Observation imaging guidance

Issue request:
FHIR-5273 was a Published OO change request from the Jan 2015 ballot, resolved Persuasive with Modification. It asked the Observation scope examples to call out laboratory data, imaging results such as bone density or fetal measurements, and device measurements such as EKG/pulse oximetry data, and it asked the Observation boundaries section to clarify that laboratory, pathology, and imaging reports belong in DiagnosticReport while Observation carries the atomic results.

Initial application:
The issue was applied in source by commit e6fbaaa95201041fcc6a3680731e9defca16311e (#5273, #5274), which changed source/observation/observation-introduction.xml to add the imaging-results bullet, revise the device-measurements bullet, and add the DiagnosticReport boundary paragraph. Commit 1a1a9868d5186613a0e3aa02a2676638d36968f8 later added parallel DiagnosticReport boundary wording.

Additional context:
Observation and DiagnosticReport are active current-build resources in source/fhir.ini; DeviceObservationReport is now listed under removed resources, so no current source edit is expected there. Later Jira FHIR-11188 added the current sentence that DiagnosticReport provides clinical/workflow context and references Observation for laboratory, imaging, and other diagnostic data, and FHIR-29032 later broadened Observation scope while retaining that relationship. The old pulse-oximetry example link was removed in 2025 when the specific example file was removed, but current source still lists device measurements with EKG and covers oxygen saturation in the vital-signs profile, so this example-level drift does not undermine FHIR-5273's accepted semantic guidance.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/observation/observation-introduction.xml already includes the imaging-results example and the Observation-vs-DiagnosticReport boundary text, and source/diagnosticreport/diagnosticreport-introduction.xml contains matching boundaries. Adding another edit would either duplicate existing guidance or restore only a nonessential example whose linked artifact no longer exists.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-5273 unless the work group wants a broader editorial refresh of Observation examples independent of this 2015 ballot disposition.
