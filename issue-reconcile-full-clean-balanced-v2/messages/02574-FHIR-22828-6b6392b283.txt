FHIR-22828: Audit medication image characteristic support

Issue request:
FHIR-22828 was Published with resolution Persuasive with Modification for R5. It requested a way to represent reference images of dispensed medication pills; the final resolution was to add Attachment as a type for drugCharacteristic.value, clarify the definitions, and add an image code to the drugCharacteristic.type value set.

Initial application:
The issue was applied by commit f5adcd0ed5 (GF #22828), which added the image concept to medicationknowledge-characteristic and changed the MedicationKnowledge drugCharacteristic spreadsheet so value[x] allowed Attachment. Later source refactoring preserved that application in source/medicationknowledge/structuredefinition-MedicationKnowledge.xml, where MedicationKnowledge.definitional.drugCharacteristic.value[x] includes Attachment and describes image use.

Additional context:
Current core build scope no longer includes MedicationKnowledge as an active resource: source/fhir.ini has Medication in [resources] but no medicationknowledge entry, and commit 5a4307d78b removed MedicationKnowledge from active build configuration. The current Medication resource is active but has no drugCharacteristic element, and the active medicationknowledge characteristic value set points at the THO CodeSystem that still includes the image code.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing the retained MedicationKnowledge source would not affect the current build, and adding a new image characteristic to active Medication would exceed the R5 issue resolution and conflict with the later R6 build-scope change.

Recommendation:
Keep this no-change audit for FHIR-22828. If Pharmacy wants medication image support in an active R6 core or external formulary/knowledge artifact, that should be handled as a new R6 work-group decision in the appropriate active resource or IG rather than as a replay of this R5 MedicationKnowledge change.
