Issue request:
FHIR-19335 was a Published/Persuasive Patient Care change request asking to add support for Goal.addresses to Reference(MedicationRequest), because a medication request can be an intervention that addresses a goal more directly than a medication statement.

Initial application:
The issue was applied by commit 2c912ff9559a2b6d52b0fbb709228154ae5908aa, which added MedicationRequest to the Goal.addresses reference target list in the then-authoritative Goal spreadsheet and marked the row with GF#19335. The current StructureDefinition source still carries GF#19335 in the committee notes and includes MedicationRequest in Goal.addresses.

Additional context:
Goal is an active current-build resource in source/fhir.ini. Later same-element decisions added Procedure and NutritionIntake, and FHIR-40777 specifically considered removing MedicationRequest and other intervention/request resources from Goal.addresses but resolved not to remove them, instead clarifying the definition to resources that provide context for why the goal exists.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative source already supports Reference(MedicationRequest) on Goal.addresses, and the later clarification confirms that retaining MedicationRequest remains the current work-group decision.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-19335 unless a future Patient Care decision reopens the broader Goal.addresses scope question.
