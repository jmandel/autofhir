FHIR-50645: Audit Transport beneficiary restriction outside core

Issue request:
FHIR-50645 was Applied/Persuasive for R6. It asked OO to restrict Transport.for from Reference(Any) to Practitioner, Group, PractitionerRole, Organization, CareTeam, HealthcareService, Patient, Device, and RelatedPerson, and to update the short display and definition to describe the transport beneficiary.

Initial application:
The issue was applied in 6b067f6d8d, which changed source/transport/structuredefinition-Transport.xml for Transport.for to the requested short display, definition, and restricted target profile list. The Jira snapshot and OO WGM minutes both record the same persuasive decision and 11-0-3 vote.

Additional context:
Later applied issue FHIR-50911 aligned Transport with the Event pattern by renaming Transport.for to Transport.subject and explicitly changing both Transport.focus and Transport.subject to Reference(Any). That later source application preserved FHIR-50645's beneficiary short display and definition on Transport.subject while replacing the restricted target list with Reference(Resource). FHIR-51849 and FHIR-53052 then removed the remaining Request workflow mappings. Commit 3b38b80cf2 subsequently removed Transport from the active core resource list and pointed current core pages to the OO incubator Transport artifact.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core build no longer includes Transport as an active resource, and the residual core source plus the OO incubator artifact already reflect the later Event-aligned Transport.subject shape with FHIR-50645's beneficiary wording. Reinstating the older Transport.for restricted reference list in inactive core source would conflict with the later applied Transport decisions and would not affect the current core build.

Recommendation:
Keep this external-scope audit commit for core. If the active OO incubator Transport artifact should revisit whether Transport.subject ought to be narrower than Reference(Any), raise or reconcile that in the OO incubator source stream rather than changing inactive core source.
