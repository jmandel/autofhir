FHIR-8571 was a Published/Persuasive FHIR-core Financial Management change request raised against DSTU1 because the Payee Type value set page showed an empty Definition column for the Payee type codes. The recorded resolution says the issue was addressed in STU3.

Initial application:

Git history shows commit 0d16fa6b9d38300d230738eb5a55c99646b78a5e added displays and definitions for subscriber, provider, and other to source/terminologies/valueset-payeetype.xml before STU3. Later commit fdf6e754e002a4b713061c5c23949fa61209a3db moved inline ValueSet.codeSystem content into a compose include, and commit b63ba456ef969b5e173fc94623f34884301e68cc updated that include to the UTG/THO canonical http://terminology.hl7.org/CodeSystem/payeetype.

Additional context:
The current core source keeps source/terminologies/valueset-payeetype.xml as an active terminology value set and includes the THO PayeeType code system. The THO code system and current build value set expansion define subscriber, provider, beneficiary, and other, so the missing-definition problem is not present in the current specification. Later PayeeType work such as FHIR-30929 and UTG proposals UP-246 and UP-315 concerns changed/additional THO content; FHIR-30929 remains Resolved - change required and is outside this default applied/published reconciliation scope.

Recommendation:
