Additional context:
Later TestPlan decisions changed the relevant artifact. Commit 80ac210e33dd10b2582e5bbcea1000bf4d4fabb4 reworked TestPlan per the Madrid committee decision, replacing the prior testCase-centric shape with suite/test structure. Commit f9a44787c45071394532c7c2ee94d76f30f47387 then removed TestPlan, TestReport, and TestScript from active core source; current source/fhir.ini has no active TestPlan resource entry and instead points to the FHIR Testing IG in [additional-ig-list]. Current core narrative links TestPlan to that external IG, and the current Testing IG StructureDefinition no longer contains TestPlan.testCase.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. There is no current source/testplan build input to edit in this checkout, and reintroducing TestPlan.testCase.key or TestPlan.testCase.description in core would conflict with both the later TestPlan redesign and the move of TestPlan maintenance to the external FHIR Testing IG.

Recommendation:
Keep this audit commit as-is for core. If FHIR-I wants additional identifier or description semantics in the current TestPlan model, handle that follow-up in HL7/fhir-testing-ig, considering the current TestPlan.suite.test.name and TestPlan.suite.test.description elements rather than restoring the obsolete core TestPlan.testCase shape.
