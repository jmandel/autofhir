FHIR-28556: Audit DataRequirement example links

Issue request:
FHIR-28556 was Published with a Persuasive with Modification resolution. The Jira reported that the Metadata Types Examples page listed Measure as an example source for DataRequirement even though the R4 Measure resource did not have DataRequirement elements, and the approved change was to point to specific examples illustrating each metadata type rather than broad resource example pages.

Initial application:
The Jira comment links HL7/fhir#2372. That PR was merged by 4461dbd3 and includes commit 7a7282f, "J#28556: Improved data requirement example links", which replaced the broad DataRequirement Library/Measure/PlanDefinition examples sentence in source/metadatatypes-examples.html with a concrete table of Library examples that contain DataRequirements. The same implementation also converted nearby ParameterDefinition and RelatedArtifact example links to specific tables, matching the FHIR-I minutes.

Additional context:
The 2020-12-14 FHIR-I minutes record the motion and the intended scope: update the hard-to-navigate link to CQL dedicated DataRequirement examples, with the same approach for related metadata types. Current source/fhir.ini maps DataRequirement to the metadatatypes page, and source/metadatatypes-examples.html is the active examples page for those metadata types. No Zulip or additional Confluence search result was found that conflicts with the Jira, minutes, source, and git history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source and the current combined branch already show "The following resource examples contain DataRequirements" followed by specific Library example rows, and the DataRequirement section no longer points to measure-examples.html as a general Measure resource example page.

Recommendation:
Keep this audit commit as-is. The previously applied PR already satisfies FHIR-28556 in the current build, and adding or changing source text now would be redundant unless a future work group decision asks for a broader refresh of metadata type example curation.
