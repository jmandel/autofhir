FHIR-11072: Audit dosage instruction harmonization

Issue request:
FHIR-11072 was a Published/Persuasive Pharmacy change request for DSTU2 asking to harmonize MedicationPrescription/MedicationOrder dosageInstruction with MedicationDispense.dosageInstruction. The accepted resolution said to create a new DosageInstruction type and use it on MedicationOrder, MedicationDispense, and MedicationStatement.

Initial application:
The change was applied in historical commit 1d00edee4413c641918bdf96071c2407902bc4c3, whose message explicitly cited #11072 and added a DosageInstruction datatype while updating MedicationOrder, MedicationDispense, and MedicationStatement sources. Later commit 6a4b0d916ec0983d3c0e8a2d28366e99dc12fc76 implemented FHIR-12840 by renaming DosageInstruction to Dosage, so the original type name is no longer the current source name.

Additional context:
The current build scope lists Dosage, DosageDetails, DosageSafety, and DosageCondition as active types, and MedicationDispense, MedicationRequest, and MedicationStatement as active resources; MedicationOrder/MedicationPrescription and the old DosageInstruction name are only retained in removed-resource/change-map history. Later R6 dosage work represented in current source introduces DosageDetails for the full rendered and structured dosage course, but the active medication resources still share the same dosage-instruction datatype surface.

AutoFHIR reconciliation:
This audit commit makes no source change. Current MedicationRequest.dosageInstruction, MedicationDispense.dosageInstruction, and MedicationStatement.dosage are all 0..1 and all use DosageDetails, whose source contains renderedInstruction plus simple/structured Dosage content. That satisfies the harmonization requested by FHIR-11072 after later approved renaming and rework are considered.

Recommendation:
Keep this no-change audit. Revisit only if the work group decides to undo the later DosageDetails model; FHIR-11072 itself does not require restoring the obsolete DosageInstruction name or changing active medication resource definitions.
