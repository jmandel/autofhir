FHIR-17332: Audit history response constraint

Issue request:
FHIR-17332 was Published with a Persuasive resolution for FHIR-core HTTP/history guidance. It reported that the RESTful history section recommended populating Bundle.entry.response.lastModified in history Bundles, while historical bdl-4 allowed Bundle.entry.response only for batch-response or transaction-response, and asked to fix this by loosening the constraint.

Initial application:
The Jira comment says the change was already made under a different task. Git history shows that c613b68f9b (GF#14550) changed the historical Bundle spreadsheet invariant from response-only-for batch/transaction responses to requiring response for batch-response, transaction-response, and history. Later source refactors preserved that rule: 1b2d9f9e24 corrected the then-current bdl-4 FHIRPath context while still including history, and 55512f8e09 split the old bdl-3/bdl-4 constraints into the current bdl-3a through bdl-3d family.

Additional context:
The current build includes Bundle as an active resource in source/fhir.ini. The current authoritative Bundle StructureDefinition no longer has bdl-4; bdl-3b requires history entries to have request and response elements, and Bundle.entry.response.lastModified remains available as an optional response child. The current HTTP history section includes response.lastModified in history examples and repeats the guidance that servers SHOULD populate it. Related issues FHIR-17420, FHIR-19619, and FHIR-23013 have already been audited on the combined branch and support the current response metadata/status wording rather than requiring another source edit here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies FHIR-17332 because history Bundles may contain Bundle.entry.response, and the history guidance can validly recommend response.lastModified.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-17332 unless a future work group decision changes the current history Bundle response model.
