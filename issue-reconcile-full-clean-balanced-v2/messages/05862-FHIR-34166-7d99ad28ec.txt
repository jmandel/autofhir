FHIR-34166: Audit DeviceDefinition part number alignment

Issue request:

Initial application:
The Jira comments point to PR commits a9721a4 and 77cdf00. In the reachable source history, 7ae3253 added the element for FHIR-34166 and f49c535 fixed the initial typo so both the element id and path are DeviceDefinition.partNumber. OO Catalog minutes later recorded the item as re-applied and OK.

Additional context:
DeviceDefinition is active in source/fhir.ini, so source/devicedefinition/structuredefinition-DeviceDefinition.xml is in current build scope. The current source has DeviceDefinition.partNumber as 0..1 string with the same short, definition, comment, W5 mapping, and RIM mapping as Device.partNumber. A current DeviceDefinition example includes partNumber, and the later FHIR-40434 search-parameter issue added part-number separately. A later FHIR-43119 request to remodel part/model numbers as repeating backbones was resolved no-change, so it does not supersede this single string element.
