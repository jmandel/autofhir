Issue request:
FHIR-7900 was a Published FHIR-core Claim change request, resolved Persuasive with Modification, asking that Claim.coverage.focal stop describing an instance number because the element is boolean. The approved resolution changed the definition to describe a flag indicating the Coverage focus for adjudication.

Initial application:

No commit message explicitly mentions FHIR-7900, so the application was identified by pickaxe history on the old and replacement wording.

Additional context:

Later source refactoring reworded the definition to 'A flag to indicate that this Coverage is to be used for adjudication of this claim when set to true,' which preserves the approved clarification and avoids the original instance-number ambiguity.
