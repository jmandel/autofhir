FHIR-32874 was a Published/Persuasive PA change request for R5 Patient asking that Patient.link.short and Patient.link.definition be corrected from awkward/incorrect Patient-or-RelatedPerson wording to "Link to a Patient or RelatedPerson resource that concerns the same actual person."

Initial application:

Patient is active in source/fhir.ini, so this StructureDefinition source is in build scope.

Additional context:
FHIR-23009 introduced the RelatedPerson-inclusive Patient.link wording that FHIR-32874 corrected. FHIR-34329 later replaced "person" with "individual" for the same Patient.link text, and that later issue already has a reconciliation commit on the combined branch. FHIR-34156 aligned Patient.link.other.definition with the same final Patient-or-RelatedPerson wording. FHIR-41559 later clarified RelatedPerson's relationship to Patient.link without changing Patient.link itself.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/patient/structuredefinition-Patient.xml has Patient.link.short and Patient.link.definition aligned to the later-approved "Patient or RelatedPerson" / "same actual individual" wording.

Recommendation:
Keep this audit commit as-is. The current wording intentionally differs from FHIR-32874's original "same actual person" only because FHIR-34329 made the later approved refinement to "same actual individual."
