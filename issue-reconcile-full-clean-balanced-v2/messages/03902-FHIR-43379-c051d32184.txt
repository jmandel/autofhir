FHIR-43379: Audit SupplyDelivery condition text

Issue request:
FHIR-43379 was Applied with a Persuasive resolution to correct the short description and long definition for the SupplyDelivery condition element. The Jira text and OO minutes identify the intended element as SupplyDelivery.suppliedItem.condition, not a root-level SupplyDelivery.condition.

Initial application:
The issue was applied by commit c710afe97d, which replaced the copied "Amount supplied" short text with "A description of the supplied item's condition (e.g., box is damaged)" and expanded the definition to explain damaged or out-of-temperature supplied items. Later same-element work under FHIR-44996 converted the element from string to CodeableConcept and added an example condition value set; a separate AutoFHIR commit already reconciled the remaining CodeSystem-description mismatch for FHIR-44996.

Additional context:
SupplyDelivery is no longer an active core resource in the current build. Commit 3b38b80cf2 removed supplydelivery and supplyrequest from active source/fhir.ini build sections and updated current core narrative/module pages to link SupplyDelivery to the OO Incubator IG instead. The inactive core StructureDefinition still contains the FHIR-43379 short and definition, and the current OO Incubator published StructureDefinition-SupplyDelivery JSON also contains the same short and definition for SupplyDelivery.suppliedItem.condition. Confluence minutes from the OO HCP 2023-12-18 call confirm the group treated this as a typo/wording correction for SupplyDelivery.suppliedItem.condition and voted Persuasive 6-0-1.

AutoFHIR reconciliation:
This audit commit makes no source change. Editing source/supplydelivery now would not affect the active core build, and the current external SupplyDelivery profile already preserves the applied FHIR-43379 wording.

Recommendation:
Keep this commit as-is for core reconciliation. No FHIR core source follow-up is needed for FHIR-43379; if future condition wording changes are desired, they should be made in the OO Incubator source that now owns SupplyDelivery.
