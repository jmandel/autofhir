Issue request:
FHIR-5695 was a Published Pharmacy change request, resolved Persuasive with Modification, asking that MedicationStatement.medication be changed from optional to required because a MedicationStatement without an identified medication was unclear. The accepted resolution broadened the fix to make medication 1..1 in all four medication resources.

Initial application:
No explicit source commit tagged FHIR-5695 was found in current git history. Historical spreadsheet source available before the current StructureDefinition conversion already showed MedicationStatement.medication[x] as 1..1, and the current StructureDefinition lineage preserves medication min/max 1..1 on MedicationStatement and the parallel active medication resources.

Additional context:
The current build-scope resources are MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement; historical MedicationOrder has been replaced by MedicationRequest in current core source. Later FHIR-53425 intentionally clarified how MedicationStatement can still represent "no known medications" while keeping MedicationStatement.medication required by allowing a situation code in the required medication element. FHIR-54566 is a later unresolved clarification request about how that no-known-medications code interacts with other elements, but it does not reverse FHIR-5695's cardinality decision.
