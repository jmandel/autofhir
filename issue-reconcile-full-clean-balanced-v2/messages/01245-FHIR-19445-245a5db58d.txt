FHIR-19445: Audit improvement notation code wording

Issue request:
FHIR-19445 was Published/Persuasive with Modification for CQI. It asked to improve the MeasureImprovementNotation code system wording so increase means "Increased score indicates improvement" with a definition that improvement is indicated by an increase in the score or measurement, and decrease means "Decreased score indicates improvement" with a definition that improvement is indicated by a decrease in the score or measurement.

Initial application:
The Jira comment cites GH#780fae5356. That commit explicitly mentioned GF#19445 and updated the historical Measure spreadsheet's MeasureImprovementNotation code rows from the older "Increase"/"Decrease" displays and "Improvement in the measure is noted..." definitions to the accepted increase/decrease wording. The same commit also carried the tightly related FHIR-19446 datatype/terminology work.

Additional context:
Measure, MeasureReport, and CodeSystem are active resource types in the current build, but the old core source file for source/measure/codesystem-measure-improvement-notation.xml was removed by the later THO-duplicate cleanup. FHIR-39623 later confirmed the measure-improvement-notation CodeSystem should be removed from base FHIR and referenced through THO, and FHIR-19446 has already been reconciled on the combined branch as an audit of that same terminology migration. Current Measure and MeasureReport XML bind improvementNotation to http://terminology.hl7.org/ValueSet/measure-improvement-notation, and the current THO CodeSystem at http://terminology.hl7.org/CodeSystem/measure-improvement-notation contains the corrected increase/decrease displays and definitions. An inactive legacy ResearchDefinition spreadsheet still contains old wording, but ResearchDefinition is not in the active source/fhir.ini resource list and was previously removed from the current build.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing a core CodeSystem definition would conflict with the later THO migration, and editing the inactive ResearchDefinition spreadsheet would not affect the current specification. The active core source points to the THO terminology surface that already reflects FHIR-19445.

Recommendation:
Keep this audit commit as-is. If future wording changes are needed for the MeasureImprovementNotation concepts, they should be handled through THO/UTG rather than by restoring a core code system copy.
