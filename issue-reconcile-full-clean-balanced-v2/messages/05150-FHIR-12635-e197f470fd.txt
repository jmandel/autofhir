FHIR-12635: Audit Encounter unknown status application

Issue request:
FHIR-12635 was a Published/Persuasive PA change request asking whether Encounter.status, which is 1..1 with a required binding, should support an unknown value when systems cannot map to one of the known status codes. The approved resolution added an Encounter status code "unknown" with the stated last-resort definition and explicitly rejected adding "other" or changing the cardinality to 0..1.

Initial application:
The change appears to have been applied by git commit d562f07e0ff1abf6b607baacde81c2a276e3214e, whose message included tracker 12635 and whose Encounter spreadsheet diff added "unknown" to the Encounter.status/statusHistory status lists and added the exact unknown code definition to the encounter-status terminology sheet. Later source refactors moved the authoritative terminology into source/encounter/codesystem-encounter-status.xml and source/encounter/valueset-encounter-status.xml.

Additional context:
Encounter is an active current-build resource in source/fhir.ini. Current source preserves Encounter.status as 1..1, binds it required to ValueSet/encounter-status, includes code "unknown" in the Encounter Status code system with the Jira-approved last-resort definition, and does not include an "other" code. Later PA decisions such as FHIR-13702, FHIR-22726, and FHIR-47297 changed adjacent Encounter status modeling by moving patient/waiting state to subjectStatus, adding discharged, and adding businessStatus for granular workflow states; none supersede or remove the FHIR-12635 unknown-status decision. Separate reconcile commits for those later issues already exist on the combined branch, so this commit does not duplicate them.

AutoFHIR reconciliation:
No source change was made. The current active source already implements the requested unknown code while preserving the rejected alternatives: no Encounter.status "other" code and no 0..1 cardinality change.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-12635 unless PA later chooses to revisit the broader status/businessStatus model; that would be a new decision rather than a missed application of this issue.
