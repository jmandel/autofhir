FHIR-8026: Audit document Composition reference inclusion

Issue request:
FHIR-8026 was a Published/Persuasive DSTU1 clarification for the FHIR documents page. It asked whether the rule that resources directly referenced by the Composition SHALL be included in a document Bundle should be updated after Composition section content references changed to a list; the final resolution was to update the wording per that comment.

Initial application:
The issue was applied in git-svn commit f5bac309ca9e1addc0aaf5c31f99bdaa8d65c6af on 2015-06-20, matching the Jira comment's svn revision 5533. That commit changed source/documents.html from a single broad sentence to an explicit generated list of Composition reference elements using <%res-ref-list Composition%>.

Additional context:
The current active documents page still uses that generated Composition reference list, and later commit 84b04d276f340dfea2c181d0d211d7b5e0234654 only refactored the lead-in sentence to "Resources referenced by the Composition as listed below". The current Composition model no longer uses the DSTU1 Composition.section.content.reference name; relevant current references include Composition.section.focus and Composition.section.entry, so the generator-based wording is the safer current-spec expression. source/hierarchy.xml and publish.ini show documents.html is an active page, and later document-reference clarifications such as FHIR-43295/FHIR-45507 affect supporting graph references without reversing the required Composition reference list. Zulip and Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already conveys the approved clarification by requiring resources referenced by the Composition as listed in the generated reference list to be included in the document Bundle.

Recommendation:
Keep this audit commit as-is. No follow-up is needed in core unless a future publisher/build check shows the <%res-ref-list Composition%> expansion is incomplete for current Composition reference elements.
