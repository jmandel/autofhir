FHIR-23786 was a Published/Persuasive FHIR-core Vocabulary change request for R5 to remove the valueset-system extension because it duplicated ValueSet.compose.include.system and added no semantics.

Initial application:
No core commit explicitly mentioning FHIR-23786 was found. Additional context:
The 2020 Vocab block vote and minutes record FHIR-23786 as persuasive and accepted. Current exact source searches find no active core or extension-pack valueset-system StructureDefinition; the remaining core hit is the historical OID assignment in source/oids.ini, while valueset-systemName is a separate extension handled by other Jira work.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Removing the historical OID mapping would not be a necessary source correction for this Jira request.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-23786; any future work on neighboring ValueSet extensions should stay tied to their separate FHIR-core or FHIR-extensions trackers.
