FHIR-39205: Audit RSG terminology correction

Issue request:
FHIR-39205 is Published with resolution Persuasive with Modification. It asked to correct the recorded sex or gender type terminology by removing the invalid DICOM Patient Sex code 0010,0040, removing LOINC 76691-5 Gender identity, adding LOINC 74698-2 Sex [AHRQ], and changing the individual-recordedSexOrGender.type binding from preferred to example.

Initial application:
Core commit bfbc0c2594 removed the DICOM include from source/patient/valueset-recorded-sex-or-gender-type.xml. The other resolution parts were applied in the FHIR Extension Pack after the GHP material moved there: commit 789f571 changed the individual-recordedSexOrGender.type binding to example, and commit d93382e replaced LOINC 76691-5 with LOINC 74698-2 in the recorded-sex-or-gender-type value set.

Additional context:
The RSG terminology source is no longer active FHIR-core source. Core commit f3c0d3659c deleted the GHP terminology resources from source/patient after moving them to the extension IG, and the Extension Pack later removed the value set after moving terminology resources to THO. The current core fhir.ini has Patient as an active resource but no active recorded-sex-or-gender-type value set or individual-recordedSexOrGender profile entry. Current Extension Pack source binds individual-recordedSexOrGender.type with example strength, and current THO publication includes 46098-0, 76689-9, and 74698-2 only. The 2023-02-20 Gender Harmony meeting notes confirm the final motion to remove the DICOM and 76691-5 codes, add 74698-2, and make the binding example.
