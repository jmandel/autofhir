FHIR-9201: Audit isSummary type-profile guidance

Issue request:
FHIR-9201 was Published/Persuasive for DSTU2 and asked to remove or disallow isSummary on the first/root element of type StructureDefinitions, clarify ElementDefinition.isSummary as the source for _summary=true serialization, note datatype summary behavior, link the _summary search parameter to that definition, and state that profiles cannot override isSummary.

Initial application:
Jira records svn revision 8685. The imported git commit 081c8ea90309b8ce3b8cfbc8d3163aa32a995add, titled "#9201 - note about summary searches", added the serializer/datatype note to source/datatypes/elementdefinition.xml and linked source/search.html's _summary=true text to ElementDefinition.isSummary.

Additional context:
Current source already contains the rest of the requested rule set. The ElementDefinition interpretation table marks isSummary as "Not expected" for type-definition and constraint-definition root elements, and requires constraint-definition non-root values to match the base definition. ElementDefinition.isSummary now explains _summary=true serialization, datatype summary exceptions, and links back to the interpretation table. The search page links _summary=true to ElementDefinition.isSummary, and the profiling page says profiles cannot change isSummary. Later FHIR-14272, FHIR-33148, and FHIR-35855 refined this exact guidance; FHIR-14272 is already represented on the combined branch and added the current cross-reference from isSummary back to the interpretation table.

AutoFHIR reconciliation:
Made no source change. A source check found all inspected datatype root rows have empty Summary cells, and the active narrative/source pages already convey the root, serializer, search-link, datatype-exception, and no-profile-override rules requested by FHIR-9201.

Recommendation:
Keep this audit commit as-is. Reopening source would risk restating or tightening settled later wording; any future change should be handled through a new work-group decision if the WG wants "Not expected" to become a strict invalid/prohibited rule.
