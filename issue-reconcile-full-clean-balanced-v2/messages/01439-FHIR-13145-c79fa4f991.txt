FHIR-13145: Audit ImagingManifest frame reference

Issue request:
FHIR-13145 is a Published/Persuasive FHIR-core Imaging Integration issue, raised against DSTU2 and applied for STU3, asking to add instance-level frameNumbers to ImagingManifest as unsignedInt with cardinality 0..n so a selected multi-frame DICOM object could identify specific frames.

Initial application:
The issue was applied by 9fa95b1d5035610e18cc3c571d60d84fd32c8f46, whose message says "ImagingManifest add back Frame numbers #GF13145" and whose patch added ImagingManifest.study.series.instance.frameNumbers to the spreadsheet source. Current retained ImagingManifest source still contains the corresponding 0..* unsignedInt element as ImagingManifest.study.series.instance.frameNumber, with DICOM mapping (0008,1160) Referenced Frame Numbers.

Additional context:
FHIR-14080 later removed ImagingManifest from active FHIR-core resources; that related issue is already represented on the combined branch by 915412ef84817e407d3aaf194fbdc9fbc12d9447. Current source/fhir.ini lists ImagingSelection and ImagingStudy in active [resources], lists imagingmanifest under [removed-resources], and source/history.html records ImagingManifest as deleted/removed. FHIR-17183 later introduced ImagingSelection for R5; that related issue is already represented on the combined branch by 004bef4da38b52b7bbc2650204a6cca61f58bc29. Current ImagingSelection source includes active instance.frameNumber support and notes/examples for selecting frames from multiframe SOP Instances.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original ImagingManifest defect was applied in historical source, the resource is no longer in current build scope, and the active replacement-style ImagingSelection resource already supports frame-level image selection. Editing the retired ImagingManifest spreadsheet or duplicating guidance in current pages would not change implementer understanding of the current specification.

Recommendation:
Keep this audit commit as-is. Do not restore ImagingManifest or edit its out-of-build spreadsheet for FHIR-13145. Future frame-selection changes should be handled against active ImagingSelection issues unless the work group explicitly reopens the removed ImagingManifest design.
