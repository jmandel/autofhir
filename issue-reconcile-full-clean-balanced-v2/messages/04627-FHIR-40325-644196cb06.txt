FHIR-40325: Audit Observation date search wording

Issue request:
FHIR-40325 was a Published FHIR-core Observation change request, resolved Persuasive with Modification for R5, asking to replace the Observation date search-parameter description "Obtained date/time. If the obtained element is a period, a date that falls in the period" with "Clinically relevant time/time-period for observation" because the old wording contradicted the general date-search rules for Period comparisons.

Initial application:
The issue was applied by Rob Hausam in git commit c5710c3d40, which changed source/observation/bundle-Observation-search-params.xml so SearchParameter/Observation-date uses the approved description. Current source still contains that wording, and source/fhir.ini lists Observation as an active resource owned by OO.

Additional context:
OO minutes from 2023-02-28 record the motion to find FHIR-40325 Persuasive with Modification and to keep the search description consistent with the Observation.effective[x] description. A Zulip implementers thread, "Date search on periods", shows the reporter raising the contradiction before filing the issue. Later source history touching the Observation search-parameter bundle did not restore the obsolete Observation-date wording. The obsolete phrase still appears only in historical release snapshots and a dropped OccupationalData spreadsheet source; source/fhir.ini marks OccupationalDataforHealth as dropped, so that is not a current Observation search-parameter fix.

AutoFHIR reconciliation:
This audit commit makes no source change because the current active Observation search parameter and the Observation.effective[x] short description already carry the approved text, and the remaining stale occurrences are outside the current Observation build scope.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed in FHIR core for FHIR-40325 unless a future work group decision changes the general date-search semantics or reactivates the dropped OccupationalData source.
