FHIR-31564: Audit datatype removal

Issue request:
FHIR-31564 was a Published/Persuasive with Modification R4B ballot issue for CDS. It questioned why OrderedDistribution and Statistic were special data types, asked that they appear in the special-purpose datatype diagram, and asked for an Evidence example using Evidence.distribution. The final resolution instead removed OrderedDistribution because it lacked community engagement and could be modeled with EvidenceReport/List patterns, with a follow-up R5 tracker for the same change.

Initial application:
The explicit application is git commit 9545244b7167d105bd862aa06a62fea63101dec7, "J# 31564 Removed Statistic and OrderedDistribution data types", which removed the standalone datatype source/pages for Statistic and OrderedDistribution and updated build configuration and surrounding narrative. Earlier related commits for FHIR-31866 moved Statistic content into Evidence and removed OrderedDistribution from datatype lists.

Additional context:
FHIR-31866 is the tightly related R5 tracker and is already represented on the combined branch by commit 7a842d2892ab4c77a26c10c1cb13f4ae93152cd9, so this reconciliation does not publish a duplicate FHIR-31866 decision. FHIR-31866's Published/Persuasive resolution explicitly said to reincorporate Statistic elements into Evidence, remove the Statistic and OrderedDistribution data types, remove Evidence.distribution, and apply the change to R4B and R5. CDS Confluence references show the group remembered FHIR-31564 when discussing the same R5 work, while a Zulip search found no contrary OrderedDistribution discussion.

AutoFHIR reconciliation:
This is an empty no-change audit commit. Current build-scoped source already reflects the combined FHIR-31564/FHIR-31866 outcome: source/fhir.ini has Evidence as an active resource, source/evidence/structuredefinition-Evidence.xml defines Evidence.statistic as a BackboneElement, source/evidence and source/datatypes have no Evidence.distribution or OrderedDistribution source, and source/datatypes/specialtypes.diagram no longer lists Statistic or OrderedDistribution as special-purpose datatypes.

Recommendation:
Keep this audit commit as-is. No core source change is needed for FHIR-31564; future work, if any, should happen only if a new work-group decision reintroduces a shared statistics datatype or a separate modeling pattern.
