FHIR-7366: Audit contained-resource no-inheritance guidance

Issue request:
FHIR-7366 was Published / Persuasive with Modification for a DSTU1 ballot comment asking why contained resources could omit an explicit subject and rely on contextual inference from their container. The approved resolution was to disallow that inheritance/conduction model and rewrite the contained-resource guidance to say contained resources do not inherit any values from their context.

Initial application:
The Jira comment records svn revision 5814. In the git history, that is commit 6bb9d508d3, which implemented the linked FHIR-7385/FHIR-7366 decision by changing source/references.html so contained resources do not "inherit" context from their parent resource. A later FHIR-7385 reconciliation commit, ee09fbb1af, removed the remaining introductory contradiction that had still called contained resources an exception to the no-inheritance rule.

Additional context:
FHIR-7385 is the linked Published companion issue with the same approved resolution and has already been represented on the combined branch. FHIR-50639 is an unresolved later tracker that reported the same introduction-vs-contained-section contradiction; it is useful background but not final work-group scope for this seed. The relevant Reference narrative page is in current build scope because source/fhir.ini maps reference=references.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/references.html introduction says contained resources follow the same no-inheritance rule, and the contained-resource section says resources contained inline do not inherit context from the parent resource and do not implicitly share the parent's subject. That satisfies the FHIR-7366 resolution without adding redundant prose or reopening the unresolved FHIR-50639 tracker.

Recommendation:
Keep this no-change audit commit. No further core source work is needed for FHIR-7366 unless the work group separately decides FHIR-50639 or another future issue to revise contained-resource context guidance.
