FHIR-39183: Audit ElementDefinition diff tab label

Issue request:
FHIR-39183 is a Published/Persuasive R5 technical correction for the ElementDefinition page. The reporter observed that the September 2022 R5 ballot ElementDefinition content tab was labeled "R3 Diff" even though the tab contents were the R4 comparison, and asked that the typo be corrected to "R4 Diff".

Initial application:
No Jira-tagged source commit for FHIR-39183 was found. Nearby history shows commit 2c85eeddd6 changed the active resource template and global difference page from R3 wording to R4 wording before the issue was filed, but the September 2022 ballot ElementDefinition page still rendered the stale "R3 Diff" label. The final published R5 ElementDefinition page now renders "R4 Diff", so the published issue was applied by later generation/source state even though there is no explicit issue-key commit.

Additional context:
ElementDefinition is an active datatype in source/fhir.ini, and source/elementdefinition.html uses the generated ElementDefinition datatype header/content block rather than hard-coding the diff tab text. In the current R6 build inputs, tools/templates/template.html and tools/templates/template-intf.html use the version-neutral "Version Diff" label and link to R5, R4, and R4B diff artifacts, which supersedes the R5-specific "R4 Diff" wording without reintroducing the original typo. Community searches found no Zulip or Confluence record that changes the Jira/source conclusion.

AutoFHIR reconciliation:
Made no source change. The current build source no longer contains the erroneous "R3 Diff" tab label for the active templates, the current CI ElementDefinition page renders "Version Diff", and the R5 publication surface renders the requested "R4 Diff" label.

Recommendation:
Keep this audit commit as-is. No follow-up is needed in core FHIR unless a future rendered ElementDefinition page again shows a release-specific stale diff label; in that case the generator/template that emits datatype tabs should be investigated rather than editing generated output.
