FHIR-11300: Audit vital signs panel LOINC code

Issue request:
FHIR-11300 was a Published/Persuasive with Modification OO change request raised against the DSTU2 vital signs profile page. It asked to replace the erroneous top-level Vital Signs Panel LOINC code with a new Regenstrief-supplied LOINC panel code, include LOINC names for all table codes, and keep the spreadsheet-identified measurement qualifiers as notes/comments rather than as additional table rows.

Initial application:
The source history shows explicit FHIR-11300 application in 2017. Commit fad3d2f2fa, labeled "[11301],[11300](partial)", changed the vital signs table from 8716-3 to 85353-1, added the LOINC Name and Comments column, and added qualifier guidance as comments. Commit cb9bb1ba62 updated the old vital sign result value set from 8716-3 to 85353-1; commit 3535e5b333 temporarily reverted that value set because 85353-1 was not yet in the code system; commits 1e5bec1a6e, 8b2144d9f1, and c932546572 then restored the new LOINC code in the table, example, and value set once pre-release LOINC codes were available.

Additional context:
The current vital signs IG is active in source/igs.xml and includes the vitalspanel StructureDefinition and the vital signs introduction table. Later vital-signs rewrites changed the representation around "interoperability standard" codes and hasMember wording, but the durable FHIR-11300 result remains: the active vitalspanel profile fixes Observation.code to LOINC 85353-1, the panel example uses 85353-1, and the table presents 85353-1 with the LOINC name and panel comments. The companion qualifier issue FHIR-11301 has already been audited on the combined branch as no-change, and later qualifier-specific decisions explain why not every original qualifier sentence remains verbatim. Remaining 8716-3 occurrences are either a commented deprecated code in the panel example or Composition section-code examples, not the Observation Vital Signs Panel profile code targeted by this issue.

AutoFHIR reconciliation:
Made no source change. The current build-scope source already reflects the approved panel LOINC replacement and table-name/comment application, and changing the unrelated document-section examples or re-adding later-removed qualifier wording would be overbroad.

Recommendation:
Keep this no-change audit commit as-is. Future changes to vital-signs qualifier modeling or the panel value-set expansion should be handled by newer OO issues, not by reopening this completed DSTU2 panel-code correction.
