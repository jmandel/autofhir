Issue request:
FHIR-17822 was a Published/Persuasive CDS change request for FHIR-core Questionnaire asking to remove the cqf-optioncode extension because it was incomprehensible and appeared to duplicate Questionnaire.code. The approved resolution was "Agreed, remove as suggested."

Initial application:
The issue was applied by git commit 54dcccf677457b19171bbca3c632e084905c39e9, matching the Jira comment "GH#54dcccf677". That commit removed the optionCode row from source/clinicalreasoning-module.html and changed the clinical reasoning extension spreadsheet so the cqf-optioncode extension was no longer emitted. The original extension traces back to commit 98c5119546d6e84950825099fdb0814fb8d7508c for FHIR-12485/GF#12485.

Additional context:
source/fhir.ini currently lists questionnaire as an active resource and clinicalreasoning-extensions as an active profile spreadsheet. Current source keeps Questionnaire.code as a 0..* Coding element for the overall questionnaire, while searches of current core source and the FHIR Extension Pack found no cqf-optioncode, optionCode, or StructureDefinition-cqf-optioncode definition/reference outside historical generated data. The related Zulip discussion records Grahame's concern that cqf-optionCode duplicated Questionnaire.code and Bryn's response that newer extensions were a better approach to the FHIR-12485 use case; Confluence searches found no conflicting work-group record.
