FHIR-45046: Audit SupplyDelivery relevant-history ownership

Issue request:
FHIR-45046 was an Applied OO R6 change request, resolved Persuasive with Modification, asking for SupplyDelivery "relevant history" support. The final motion added a previousDelivery extension with data type Reference(SupplyDelivery), added return dispatch and return reception to the SupplyDeliveryStage value set, and explicitly moved the dispatch/reception profile-binding changes into FHIR-45506.

Initial application:
The extension portion was applied in the FHIR Extension Pack by commit 1df85443 and PR HL7/fhir-extensions#178 as input/definitions/SupplyDelivery/StructureDefinition-supplydelivery-previousDelivery.xml. The core stage-code portion appears in an unmerged HL7/fhir branch commit babe1ac0e5, which added return-dispatch and return-reception to the legacy source/supplydelivery/codesystem-supplydelivery-stage.xml; the current core checkout still has only dispatch and reception in that legacy file.

Additional context:
FHIR-45506 later handled the profile-binding work that FHIR-45046 removed from its own scope and concluded that returns are still modeled as dispatch and reception stages rather than through mandatory core profiles. After the FHIR-45046 branch work, commit 3b38b80cf2 removed SupplyDelivery and SupplyRequest from active source/fhir.ini metadata and changed current core narrative links to the HL7/oo-incubator IG. The active OO Incubator SupplyDelivery CodeSystem currently contains only dispatch and reception and a search found no previousDelivery or return-dispatch/return-reception content there.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No FHIR core source was changed because source/supplydelivery is inactive legacy source in the current core build, the previousDelivery extension is already present in the Extension Pack, and the remaining stage-code correction belongs in HL7/oo-incubator rather than this FHIR core checkout.

Recommendation:
Keep this core audit commit. If OO still wants the FHIR-45046 stage codes on the current implementer-facing SupplyDelivery artifact, add return-dispatch and return-reception to HL7/oo-incubator input/resources/supplydelivery/codesystem-supplydelivery-stage.xml and rebuild that IG; no additional FHIR core source change is indicated.
