FHIR-5840: Audit List folder code as THO work

Issue request:
FHIR-5840 is a Published/Persuasive with Modification FHIR-core List issue requesting a new List.code value for "folder" so XDS-style folders can be represented as Lists.

Initial application:
The historical application appears in db4ace37c6, which lists {#5840} and added a folder concept with the approved broad resource-collection definition to source/list/valueset-list-listpurposecodes.xml. That file is not the current List.code binding; current List.code binds to ValueSet/list-example-codes, so the approved concept is absent from the current conformance surface.

Additional context:
List is an active resource in source/fhir.ini, and source/list/structuredefinition-List.xml binds List.code to http://hl7.org/fhir/ValueSet/list-example-codes. That value set now composes all codes from the external THO CodeSystem http://terminology.hl7.org/CodeSystem/list-example-use-codes. Current build/THO expansion has nine codes and no folder concept. Related List/XDS issues FHIR-5650, FHIR-19821, and FHIR-19822 explain the same use-case family but do not reverse the FHIR-5840 request.

AutoFHIR reconciliation:
No HL7/fhir source file was changed. Re-adding folder to the obsolete source/list/valueset-list-listpurposecodes.xml would not fix List.code, and adding a core value-set include for a code that the external THO CodeSystem does not define would make the core source depend on terminology that is not present in this checkout. The needed correction is a THO/UTG update to list-example-use-codes.

Recommendation:
Keep this external-repo audit commit as-is, then file or complete a THO/UTG change adding code folder to http://terminology.hl7.org/CodeSystem/list-example-use-codes with the FHIR-5840 definition. After THO publishes, verify that the FHIR core ValueSet/list-example-codes expansion includes folder.
