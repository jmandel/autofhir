FHIR-32111: Audit Citation explicit type name outside current build

Issue request:
FHIR-32111 was a Published/Persuasive FHIR-core technical correction raised for R4B and applied for R5. It asked to add the structuredefinition-explicit-type-name extension with value ContributorshipSummary to Citation.contributorship.summary, because the recursive contributorship backbone created problems for some code generators. The applied element in source was Citation.citedArtifact.contributorship.summary.

Initial application:
The Jira comment records two implementation commits: 350cc71f03 for R5 and 72eda94964 for R4B. Both commits added the requested structuredefinition-explicit-type-name extension with value ContributorshipSummary to source/citation/structuredefinition-Citation.xml at Citation.citedArtifact.contributorship.summary. The published R5 Citation profile still exposes that extension on the same element.

Additional context:
Citation is no longer an active resource in the current core build. Commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/citation/structuredefinition-Citation.xml and the active Citation entries from source/fhir.ini as part of removing Citation and several other resources from the current build. Current source searches find no active Citation StructureDefinition in core or the FHIR Extension Pack, and source/fhir.ini only retains a commented citation-related value set entry.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. Reintroducing or editing Citation source would be wrong for the current build, while the historical R4B/R5 application that the Jira requested is already present in the implementation commits and R5 published profile.

Recommendation:
Keep this audit commit as-is for core. No current core source follow-up is needed. If Citation is maintained or reintroduced in a future core or external artifact, carry forward the ContributorshipSummary explicit type name on Citation.citedArtifact.contributorship.summary so code generators retain the intended non-recursive name.
