FHIR-26421: Audit CareTeam participant invariant

Issue request:
FHIR-26421 was a Published/Persuasive Patient Care change request for R5 asking CareTeam.participant to have an invariant that at least one of role or member is present, while keeping both elements 0..1. Jira comments clarified that the invariant should be a warning or best practice with FHIRPath role.exists() or member.exists().

Initial application:
The issue appears to have been applied by commit 1b49161451944185626348ae983487055a76652b, titled "J#20012 CareTeam name search parameter; J#26421 CareTeam invariant". That commit added ctm-2 as a warning on source/careteam/structuredefinition-CareTeam.xml with expression role.exists() or member.exists(); the same commit also made an unrelated CareTeam name search-parameter change for J#20012.

Additional context:
CareTeam is an active current-build resource in source/fhir.ini, with abbreviation ctm and approved status. Current source/careteam/structuredefinition-CareTeam.xml still contains ctm-2 on CareTeam.participant and condition references from CareTeam.participant.role and CareTeam.participant.member. Later CareTeam work for FHIR-42928 removed the separate onBehalfOf/member-is-Practitioner invariant and briefly renumbered the role/member invariant before restoring it to ctm-2; it did not reverse the FHIR-26421 rule. Community searches found Patient Care meeting context but no Zulip or Confluence evidence contradicting the Jira/source conclusion.

AutoFHIR reconciliation:
This is an empty audit commit. No source change is needed because the current authoritative CareTeam StructureDefinition already implements the requested warning invariant in the active build scope, and the current invariant-test fixture for ctm-2 still exercises a participant without either role or member.

Recommendation:
Keep this audit commit as-is. Do not add duplicate prose or a second invariant; future work should only revisit this if Patient Care intentionally changes whether role/member absence should remain a warning/best-practice condition.
