FHIR-37195: Align ExampleScenario ModelInfo cleanup

Issue request:
FHIR-37195 was Published/Persuasive with Modification for R5. It asked to clean up ExampleScenario by renaming R4-era identifiers such as actor.actorId, actor.name, instance.resourceId, instance.resourceType, instance.name, version.versionId, containedInstance.resourceId, containedInstance.versionId, and operation.name, tightening actor/instance title cardinalities, clarifying actor type semantics, and adding reference/key invariants.

Initial application:
The main ExampleScenario StructureDefinition already reflects the applied request: actor.key/type/title, instance.key/structureType/title, instance.version.key, containedInstance.instanceReference/versionReference, operation.title, and key-reference invariants are present. The Jira-tagged implementation commit de7f583 applied the main source changes, but it did not touch the checked-in FHIR ModelInfo XML content, which remained a published Library example surface with stale ExampleScenario element names.

Additional context:
The Library resource is active in the current build, and the Library examples page links library-fhir-model-definition-content.xml as the FHIR XML information model for Library/FHIR-ModelInfo. FHIR-I minutes on 2022-05-02 confirm the persuasive-with-modification vote for FHIR-37195. The historical implementation commit also mentions FHIR-22855, FHIR-25260, and FHIR-37895, but those are not decided here; this commit is limited to the FHIR-37195 cleanup names still present in the active ModelInfo example.

AutoFHIR reconciliation:
Updated source/library/library-fhir-model-definition-content.xml so the ExampleScenario ModelInfo classes use the current cleanup names and actor type family: actor key/title/definition with ActorDefinitionActorType, instance key/structureType/title, version key, containedInstance instanceReference/versionReference, and operation title. This does not attempt a broader regeneration or unrelated ModelInfo overhaul.

Recommendation:
Keep this source fix. If future work revisits the FHIR ModelInfo generation process, separately review other ExampleScenario ModelInfo drift under the Jira issues that introduced those changes rather than expanding this FHIR-37195 reconciliation.
