FHIR-19650: Audit Device hierarchy wording

Issue request:
FHIR-19650 was Published/Persuasive for R5 by OO. It reported that the Device narrative was out of date because it contrasted Device with DeviceComponent and DeviceMetric even though DeviceComponent no longer existed, and requested updating the text to reference the Device parent element for hierarchies.

Initial application:
No source commit explicitly tagged FHIR-19650 was found. The stale narrative text was removed by commit a7f2575daae7bbacd9a22ea439c7ec35a4784f96, which listed FHIR-24936 and rewrote the Device Scope and Usage and Boundaries text to describe Device instances/components and parent relationships instead of the old DeviceComponent split. The matching StructureDefinition summary was later updated by commit 334268c12b164fb910884605255cf3da17132c17 for FHIR-23768.

Additional context:
FHIR-23768 raised the same obsolete DeviceComponent wording and was considered applied through the broader FHIR-24936 healthcare-product scope/boundary work. Both related issues are already represented on robo-spec-combined-issue-reconcile-full-clean-balanced-v2, so this seed audit does not publish duplicate related decisions. Current source/fhir.ini lists Device as active and approved, while DeviceComponent appears only in commented or dropped entries.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Device introduction says a Device can represent a whole device or a component of an encapsulating device and points to the parent device, and the current Device StructureDefinition description says physical units can consist of modules represented by multiple Device resources bound through the parent element. The obsolete DeviceComponent contrast is absent from active Device source.

Recommendation:
Keep this no-change audit commit as-is. No current core source edit is needed for FHIR-19650; future changes to Device hierarchy guidance should be handled through new OO tracker decisions rather than reopening this already-applied R5 clarification.
