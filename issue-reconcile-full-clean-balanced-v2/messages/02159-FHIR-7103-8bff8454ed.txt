FHIR-7103: Audit narrative-only section guidance

Issue request:
FHIR-7103 was Published with resolution Persuasive. It asked to simplify DSTU1 Composition guidance that said narrative-only sections could be made by putting narrative in a suitable resource or, when no suitable resource existed, in a List resource. The proposed wording would have made List.text the simple rule for narrative-only section content, but the Jira comment records that the issue was made irrelevant by the change to FHIR-7404.

Initial application:
No explicit FHIR-7103 or #7103 source commit was found in the Composition/List/document history. The relevant application appears to be the related FHIR-7404 implementation: git-svn commits 686889f8a3b83c74a4e58ddddfac7616dd0da4ca and 749c4dd88234688f57191d3d0b4d62bdc525b87d refactored Composition away from section.content/List, introduced Composition.section.text and Composition.section.entry, updated document presentation text to use section.text narratives instead of List resources, and removed the exact obsolete narrative-only section note.

Additional context:
FHIR-7404 is already represented on the combined branch by commit 40f10d0835dfa1b2886ceb5e5d2cdf0456ca504e, so this worker must not publish another FHIR-7404 decision. Current build scope includes Composition and List as active resources in source/fhir.ini. Current source says Composition.section.text contains the attested section narrative, Composition.section.entry references supporting data, narrative-only sections are represented with Composition.section.text and no Composition.section.entry, and List narrative is not part of the attested document presentation unless incorporated into Composition narrative or Composition.section.text. Direct Zulip and Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
Published an empty no-change audit commit for FHIR-7103. No source edit is needed because applying the original List.text simplification now would reintroduce an obsolete model that FHIR-7404 superseded, while the current active source already gives implementers the correct Composition.section.text rule for narrative-only document sections.

Recommendation:
Keep this audit commit as-is. Do not add new List.text guidance for FHIR-7103 unless the work group reopens the document narrative model; any future adjustment should start from the current Composition.section.text and document presentation rules, not from the retired section.content/List model.
