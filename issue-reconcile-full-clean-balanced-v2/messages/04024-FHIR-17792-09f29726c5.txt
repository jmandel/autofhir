It asked to resolve the confusing CodeSearchSupport value set codes by retiring the existing explicit/all codes and replacing them with in-compose, in-expansion, and in-compose-or-expansion definitions for ValueSet code search support.

Initial application:
The issue was applied by git commit 301156f887 (merged by 968d352ccc), which replaced the CodeSearchSupport code system concepts explicit/all with the three approved codes, updated TerminologyCapabilities.codeSearch short text, and updated the TerminologyCapabilities example to use in-compose-or-expansion. The value set source already includes the whole code-search-support code system, so with the current code system it expands to the approved three-code set.
