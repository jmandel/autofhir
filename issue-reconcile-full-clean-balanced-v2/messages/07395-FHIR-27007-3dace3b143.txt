FHIR-27007: Audit TestScript scope outside core

Issue request:
FHIR-27007 was Published/Persuasive with Modification for R5 by FHIR-I. It asked for a way to declare which conformance or implementation artifacts a TestScript tests, because TestScript.metadata.capability described prerequisites rather than the artifact under test. The accepted resolution added TestScript.scope after metadata with artifact canonical(Any), conformance CodeableConcept, and phase CodeableConcept children.

Initial application:
The issue was applied while TestScript was still a core resource. Commit bd6381b4ffae4b45c6397dbfc952ec02418c418b added TestScript.scope, scope.artifact, scope.conformance, scope.phase, scope CodeSystems/ValueSets, and initial scope search parameters under source/testscript. Commit c723b0637f2c5455d61d0e18f9593afbb59ffdd2b assigned OIDs and reworked those search parameters as scope-artifact-conformance and scope-artifact-phase composites, and commit b8bb7165976d1a1485320b9641e238733fdbbbba added a scope-artifact search parameter.

Additional context:
Later FHIR-32689 refined the scope.conformance codes to required, optional, and strict. Later FHIR-41254 fixed missing simple scope search-parameter subparts. Current core source no longer has an active TestScript resource: commit f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testscript, source/testplan, source/testreport, and active core build entries, while adding the FHIR Testing IG pointer. Current source/fhir.ini lists https://build.fhir.org/ig/HL7/fhir-testing-ig and source/ballot-intro.html points TestScript to that IG. Existing combined-branch audits for FHIR-27533, FHIR-32689, FHIR-36211, FHIR-41254, and FHIR-46100 also document that TestScript work now belongs outside core.

AutoFHIR reconciliation:
This audit commit intentionally makes no core source change. FHIR-27007 was historically applied in core, and the current authoritative TestScript source is now maintained in HL7/fhir-testing-ig. A read-only check of that source shows TestScript.scope, scope.artifact canonical, scope.conformance CodeableConcept, scope.phase CodeableConcept, and the scope search-parameter family are present.

Recommendation:
Keep this core audit as an external-repo decision. Do not reintroduce source/testscript to core for FHIR-27007; future TestScript.scope changes should be handled in HL7/fhir-testing-ig alongside the current TestScript resource source.
