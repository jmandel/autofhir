FHIR-6239: Audit ImagingStudy DICOM tag legend

Issue request:
FHIR-6239 was Published with a Persuasive with Modification resolution for the ImagingStudy resource. The issue asked for an introductory legend explaining parenthetical identifiers in ImagingStudy descriptions, and the resolution called for the Scope and Usage text to describe DICOM Attribute tags and link to the relevant current DICOM publication material.

Initial application:
A 2015 omnibus source commit, 2a416c3e03, explicitly mentioned 6239 while updating ImagingStudy and related imaging material. The current full legend text was then added to the ImagingStudy Scope and Usage section by commit 420e76081f, whose related Jira FHIR-7679 resolution carried the same DICOM tag explanation and DICOM Part 3/4/6 links.

Additional context:
ImagingStudy is an active current-build resource in source/fhir.ini. The current StructureDefinition still contains many DICOM mapping rows with parenthetical tags, so the introductory legend remains relevant. Later R6 work such as FHIR-54781 adjusted individual DICOM mapping wording but did not conflict with the tag legend. Searches of Zulip and Confluence found no directly relevant community record changing the Jira/source conclusion.

AutoFHIR reconciliation:
No source change was made. source/imagingstudy/imagingstudy-introduction.xml already explains that DICOM attributes are identified by 32-bit tags shown as two four-digit hexadecimal values in parentheses, gives an example, and links to DICOM Part 6, Part 3, and Part 4 Annex C.

Recommendation:
Keep this no-change audit commit as-is. The current core source satisfies FHIR-6239; future link modernization can be handled separately if the project adopts a broader DICOM URL policy.
