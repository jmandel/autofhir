FHIR-25257: Align message Bundle graph rule

Issue request:
FHIR-25257 was a Published/Persuasive FHIR-core change request for the messaging page and MessageHeader, asking that FHIR messages have the same rule as documents: every resource in a message Bundle must be connected, directly or indirectly, to the MessageHeader so unconnected content cannot appear without computable meaning.

Initial application:
The issue was first applied by git commit 0b7a4055d444b1f400b9d3ddcca79a027c85909e, which added a Basic Messaging Assumptions sentence saying the message bundle includes only the MessageHeader and resources directly or indirectly referenced from it. That established the requested rule, but its directional "referenced from it" wording became stale next to later source and work-group decisions that define the requirement as a connected graph including the MessageHeader.

Additional context:
FHIR-23722, resolved before the seed but applied later, added the main message Bundle rule and explicitly allowed traversal paths following Reference or canonical links either to or from the MessageHeader. FHIR-43295 later clarified the document and message "must link" requirements as connected graphs of RESTful references, and current Bundle guidance says FHIR messages and documents require a single interconnected graph and notes that some references may be reverse references. The messaging page is in current build scope through the core documentation page and active MessageHeader resource configuration.

AutoFHIR reconciliation:
This commit updates the active source/messaging.html Basic Messaging Assumptions sentence to require a connected graph of RESTful references that includes the MessageHeader, rather than requiring resources to be referenced only from the MessageHeader. No generated artifacts or out-of-scope files were edited.

Recommendation:
Keep this commit as-is. It preserves the FHIR-25257 rule against unconnected message Bundle content while aligning the older application text with later FHIR-I decisions and current graph-connected Bundle guidance; no separate related-issue reconciliation is needed from this bounded check.
