FHIR-32759: Audit Medication MAH rename

Issue request:
FHIR-32759 is Published/Persuasive for FHIR-core Medication. It asked Pharmacy to change Medication.sponsor to Medication.marketingAuthorizationHolder after the May 2021 BR&R/Pharmacy WGM discussion, with the original resolution also saying to include older names such as sponsor in comments.

Initial application:
An earlier commit, 934e7819020c72ee6e3ba509ecb5445a1850f109, mentioned FHIR-32759 but did not apply this rename. The effective application was 6cdd7b792e2241b7191584bd35915d4b0f9841f8, which changed the Medication element id/path from Medication.sponsor to Medication.marketingAuthorizationHolder and renamed the Medication search parameter from sponsor to marketingauthorizationholder.

Additional context:
Medication is active in source/fhir.ini. Current source no longer contains a Medication.sponsor element, path, XPath, or search parameter. The apparent difference from the original FHIR-32759 comment text is intentional later history: FHIR-35858 is Published/Persuasive and specifically corrected marketingAuthorizationHolder because its description still described manufacturer, and b9257918056a31ebdc080627432cc94db78637e0 updated the current definition. FHIR-48400 later confirms manufacturer is distinct from marketingAuthorizationHolder and has already been represented on the combined branch as an external-repo audit for the standard Medication manufacturer extension.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope Medication source already uses Medication.marketingAuthorizationHolder and the current definition reflects the later FHIR-35858 correction, so restoring the original sponsor/manufacturer comment language would conflict with later Pharmacy decisions rather than complete FHIR-32759.

Recommendation:
Keep this no-change audit commit. No core source edit is recommended for FHIR-32759; any future work about manufacturer should follow the separate FHIR-48400 extension-pack path rather than modifying the base marketingAuthorizationHolder element.
