FHIR-5811: Audit ImagingStudy order search parameter

Issue request:
FHIR-5811 was a Published/Persuasive FHIR-core ImagingStudy change request from DSTU1 asking to add an ImagingStudy search parameter for the DiagnosticOrder/order relationship so clients could find ImagingStudy resources associated with a given order.

Initial application:
The request was applied in git commit 217b178aefaf287e7db78ea1a2015d2c23dd9d71, whose message explicitly includes "ImagingStudy #5811 - search on order" and whose patch added an `order` reference search row on `ImagingStudy.order` to the then-authoritative ImagingStudy spreadsheet.

Additional context:
Later Published issue FHIR-10349 broadened the ImagingStudy workflow relationship by renaming `ImagingStudy.order` to `ImagingStudy.basedOn` and allowing it to reference plans, proposals, and requests. The current build has ImagingStudy active in `source/fhir.ini`, defines `ImagingStudy.basedOn` as the plan or order fulfilled by the study, and includes an active `based-on` reference SearchParameter over `ImagingStudy.basedOn` with the description "The order for the image such as Accession Number". Direct Zulip and Confluence searches for FHIR-5811 found no conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already preserves the implemented FHIR-5811 capability under the later workflow-aligned `based-on` search parameter, so re-adding an obsolete `order` search code would conflict with the later Published rename rather than repair the current specification.

Recommendation:
Keep this no-change audit commit as-is. If future reviewers evaluate legacy-version migration artifacts, inspect them separately, but the current ImagingStudy resource and search-parameter source do not need a FHIR-5811 fix.
