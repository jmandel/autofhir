FHIR-24675: Audit DetectedIssue mitigated status

Issue request:
FHIR-24675 was a Published/Persuasive CDS change request raised in STU3 and applied for R5. It noted that DetectedIssue.status reused ObservationStatus, making it difficult to search for DetectedIssues that had not been mitigated, and requested a mitigated status value; the accepted resolution was to create DetectedIssueStatus from the applicable ObservationStatus codes and add mitigated.

Initial application:
The issue was directly applied by PR 2288 in commit 5af0772e4846b965dd7d88afb05b442a8fcdd321, "J#24675: Added mitigated status for DetectedIssue", which created source/detectedissue/codesystem-detectedissue-status.xml with mitigated, added the detectedissue-status include to source/detectedissue/valueset-detectedissue-status.xml, updated the DetectedIssue.status short text, and added mitigated to source/status-codes.xml. DetectedIssue is active in source/fhir.ini, so these files are current build inputs.

Additional context:
FHIR-34294 had already narrowed DetectedIssue.status away from all ObservationStatus codes to a DetectedIssue-specific required binding; its AutoFHIR audit is already on the combined branch at fcc7a518547dd47d1ec70cfeefcd2f0b4a180e38. Later Applied R6 work FHIR-30808 and FHIR-50606 explain the current unknown and processing-error codes. The checked-in source/detectedissue/detectedissue.svg still names ObservationStatus, but it is a generated-looking diagram; the authoritative StructureDefinition and terminology files are correct, so this audit does not edit the diagram-only artifact. Community searches found no relevant Zulip or Confluence evidence changing the Jira/source conclusion.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current source binds DetectedIssue.status to ValueSet/detectedissue-status, includes mitigated in both the DetectedIssueStatus CodeSystem and ValueSet, keeps status as a token search parameter, and includes mitigated in the status code matrix.

Recommendation:
Keep this commit as-is. Do not remove mitigated or revert DetectedIssue.status to ObservationStatus; any future cleanup should come from regenerating generated diagrams or a separate work-group decision, not from this seed.
