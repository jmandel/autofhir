FHIR-7814: Audit removed MedicationPrescription mapping question mark

Issue request:
FHIR-7814 was a Published/Persuasive 2015 May pharmacy correction for FHIR-core MedicationPrescription. It asked to remove the trailing question mark from the v2 mapping for dosageInstruction/additionalInstructions because TQ1-10 Condition Text and TQ1-11 Text Instruction are valid mappings to dosage instructions.

Initial application:
The issue appears to have been applied in git commit 651364cb098a623c36afc1d6b9d56578507d897c, whose message lists tracker item 7814 among v2 mapping updates to Medication, MedicationOrder, and MedicationAdministration. That commit removed the question mark from MedicationOrder.dosageInstruction.additionalInstructions in both the sheet text and spreadsheet XML.

Additional context:
MedicationPrescription/MedicationOrder was later renamed to MedicationRequest, and the dosage instruction backbone was refactored into the shared Dosage datatype. The active current build lists MedicationRequest and Dosage, notes the MedicationPrescription to MedicationRequest transition, and marks Dosage as normative. The current Dosage.additionalInstruction v2 mapping still has the RXE-7.2/RXO-7.2/TQ1-10/TQ1-11 text without the question mark. Searches found no relevant Zulip or Confluence record that changes this conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested correction is already present in the active current source, and an exact search found no remaining current source occurrence of "TQ1-11-Text Instruction ?".

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-7814 unless a future work group wants to revisit the v2 mapping substance rather than the obsolete question mark.
