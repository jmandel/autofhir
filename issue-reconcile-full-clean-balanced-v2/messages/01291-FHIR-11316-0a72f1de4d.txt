FHIR-11316: Audit genetics observation example status

Issue request:
FHIR-11316 was a Published/Persuasive DSTU2 Clinical Genomics request asking for an example because the then-current Observation Genetics material did not show how genetic Observations related to the Sequence resource. The recorded resolution was to add an example using Observation.relate and/or the observation-geneticssequence extension to refer to the relative sequence.

Initial application:
The issue appears to have been applied by commit b2b49e7e2bb0572d2de4ba7516e2c44df48751b2, which explicitly resolved #11316 along with related Clinical Genomics example trackers and added PGx DiagnosticReport, DiagnosticRequest, Observation haplotype/diplotype/phenotype, Sequence examples, and genomics page links. A later fix-build commit also mentioned #11316, but did not change the conclusion that the requested example family was initially present.

Additional context:
The original DSTU2/R3-era Observation Genetics and Sequence example files are no longer current core build artifacts. Commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435 intentionally removed outdated clinical genomics artifacts, including the old Observation Genetics profiles and examples. In current source/fhir.ini, Observation and MolecularDefinition are active while MolecularSequence is commented out. Current core genomics guidance points readers to the Genomics Reporting IG, GenomicStudy, and MolecularDefinition/molecular data-type work; current MolecularDefinition source includes active genotype/haplotype examples with memberState and sequenceContext relationships. The Extension Pack retains old observation-genetics extensions only as deprecated artifacts replaced by the Genomics Reporting Guide.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing the old Observation-to-Sequence example into core would revive removed, deprecated Clinical Genomics material and conflict with the current build scope. The current core source already directs implementers to the maintained genomics artifacts and active MolecularDefinition examples.

Recommendation:
Keep this no-change audit as-is. If future Clinical Genomics work wants more Observation-specific examples, it should be raised against the Genomics Reporting IG or current MolecularDefinition/GenomicStudy work rather than restoring the retired DSTU2 Observation Genetics example family in core.
