Issue request:
FHIR-46924 is an Applied/Persuasive OO change request for R6. It asked to add NutritionOrder.additive.routeOfAdministration as a CodeableConcept with cardinality 0..* and an Enteral Route Codes binding, originally described as Extensible.

Initial application:
The request was applied in source history by de8f14ac79f7ecf959a2c097ae8823ad8b8ab7a7, which added NutritionOrder.additive.routeOfAdministration with CodeableConcept 0..*, bindingName AdditiveRouteOfAdministration, valueSet http://hl7.org/fhir/ValueSet/enteral-route, and an extensible binding. The current source/fhir.ini keeps NutritionOrder active and records NutritionOrder.additive.routeOfAdministration as an R6 addition.

Additional context:
A later Applied/Persuasive OO decision, FHIR-55651, specifically reviewed NutritionOrder.additive.routeOfAdministration and NutritionOrder.enteralFormula.routeOfAdministration and changed their Enteral Route Codes bindings from extensible to preferred because the code system may not be used by all jurisdiction or implementation communities. The current source reflects that later decision. The broader related FHIR-54613 remains Triaged/unresolved and is background only.
