FHIR-36062: Audit superseded AllergyIntolerance trial-use status

Issue request:
FHIR-36062 was Published/Persuasive for R5 and requested that AllergyIntolerance.type and AllergyIntolerance.reaction be designated Trial Use (non-normative). The request said the type designation also applied to the corresponding value set and code system, and the reaction designation applied to the BackboneElement and children.

Initial application:
The Jira comment points to GH#3d03f64. Commit 3d03f6438ccf44f583282583d89d8b8a86068eb0 added structuredefinition-standards-status trial-use extensions to the active AllergyIntolerance.type and AllergyIntolerance.reaction element definitions in source/allergyintolerance/structuredefinition-AllergyIntolerance.xml. No separate value set or code system source change was part of that commit.

Additional context:
FHIR-52956 is a later Applied/Persuasive R6 Patient Care decision that explicitly removed the Trial Use designation from AllergyIntolerance.type and AllergyIntolerance.reaction, along with Condition.stage and Condition.evidence, because all had been implemented by large EHRs and available since DSTU2. Commit b0795b968d8cfa56f4b734c40b63f80898a03542 removed the AllergyIntolerance element trial-use extensions, and commit 5c20769cc74459a8c1057d2747418dc4340f4244 restored the AllergyIntolerance resource standards status to normative after related status-code cleanup. The current build-scope source lists AllergyIntolerance as an active resource in source/fhir.ini and now has no trial-use extension on AllergyIntolerance.type or AllergyIntolerance.reaction; the type ValueSet and CodeSystem source also carry normative standards status.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Re-adding the FHIR-36062 Trial Use designation would reverse the later FHIR-52956 R6 work-group decision and make the current specification stale.

Recommendation:
Keep this no-change audit. Revisit only if Patient Care reopens the later FHIR-52956 maturation/removal decision or requests an R5 historical erratum outside the current R6 source line.
