FHIR-6126: Audit service-animal guidance

Issue request:
FHIR-6126 was a Published/Persuasive Patient Administration change request from DSTU1 asking the Practitioner and RelatedPerson usage notes to make clear that service animals can fill those roles, to distinguish Practitioner versus RelatedPerson based on organizational responsibility, and to provide a standard species extension.

Initial application:
The issue was applied in the historical source by Tracker# 6126 commits 198d23b84ea1cef8dfec5e8e87d117ef4dfd32ab and e3b3e7b337f5f2d17d27230a47b9ad2f52214884, with daf977bef83c0aef7bafe4019207b7c75d4fc3e6 adding the extension hyperlink. Those changes introduced the RelatedPerson Guide Dog example, the Practitioner service animal example, the shared Practitioner/RelatedPerson boundary language, and the animalSpecies extension reference.

Additional context:
Practitioner and RelatedPerson remain active resources in source/fhir.ini. Later Practitioner scope work in FHIR-21242 kept the service animal example while adding broader Practitioner examples, and later RelatedPerson boundary work in FHIR-48870 retained the service-animal boundary and extension text. The animalSpecies extension definition was removed from core source when extensions moved out of R5 core, but the current FHIR Extension Pack defines practitioner-animalSpecies for both Practitioner and RelatedPerson with an animal-species value set.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already satisfies the final Jira request: RelatedPerson Scope and Usage lists a Guide Dog, Practitioner Scope and Usage lists a service animal, both Boundaries and Relationships sections distinguish person/animal roles based on organizational responsibility, and both link to the standard animalSpecies extension in the extension package.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-6126 unless a future PA decision changes service-animal modeling or moves the extension again.
