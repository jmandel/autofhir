FHIR-5699: Audit Encounter v2 mapping updates

Issue request:
FHIR-5699 is a Published/Persuasive Patient Administration DSTU1 issue asking to update Encounter HL7 v2 mappings. It requested episodeOfCare -> PV1-54/PV1-53; indication -> Condition/Procedure resources aligned to DG1/PRB and PR1; participant -> ROL with type ROL-3, period ROL-5/ROL-6, and individual ROL-4; period -> PV1-44/PV1-45; and destination -> PV1-37. The resolution was "Updated mappings as provided."

Initial application:
The explicit Jira-tagged source commit 454f90ad94, "Tracker# 5699 Updated Encounter v2 mappings," updated the historical Encounter spreadsheet with the PV1, ROL, and destination mappings requested by the issue. The Encounter.indication v2 mapping phrase was already present immediately before that commit from earlier Encounter ballot reconciliation commit 27302910ae, so the issue's indication mapping was represented in source even though 454f90ad94 did not touch that row.

Additional context:
Encounter is an active current resource in source/fhir.ini, and the current authoritative source is source/encounter/structuredefinition-Encounter.xml. Later published Encounter decisions changed the model and terminology: Encounter.period became Encounter.actualPeriod, participant.individual became participant.actor, hospitalization.destination became admission.destination, and indication/reason/diagnosis were redesigned. FHIR-16148 and FHIR-38807 split Encounter.reason from Encounter.diagnosis, FHIR-19285 moved ranked billing diagnosis/procedure data to Account, and the already-published FHIR-23764 reconciliation on the combined branch replaced the stale inherited Encounter.indication/DG1-PRB/PR1 wording on Encounter.diagnosis.condition with the current DG1-3 mapping.

AutoFHIR reconciliation:
