FHIR-51149: Audit FormularyItem expansion migration

Issue request:
FHIR-51149 was an Applied/Persuasive R6 FHIR-core Pharmacy change request asking to expand the FormularyItem resource with the formulary-based elements from MedicationKnowledge, as a consequence of FHIR-50845.

Initial application:
The expansion appears to have been applied before Jira was formally moved to Applied. Commit c07ddd6f87f8e5aa096b645f2a7d976dd8d60df7, titled "Update formulary item with additional elements from MedicationKnowledge," replaced the original code-centric FormularyItem definition with identifier/status/category/context/subject/author, cost, precautions, monitoring program, indication/dosing guideline, documents, characteristics, availability, coverage, substitution, schedule, maximum dispense, and associated item elements. Pharmacy's 2025-09-29 meeting notes record FHIR-51149 as already agreed and applied with an 8-0-0 vote.

Additional context:
FHIR-50845 was the parent Pharmacy decision to remove MedicationKnowledge and move its applicable content to FormularyItem or other resources, but it remains in Resolved - change required rather than Applied/Published and is broader than this seed. Later source history and FHIR-53486 changed current core scope: commit 9987f9c0c3ce5ec4f277c22ed71cbb2d210efeb6 removed FormularyItem from active core fhir.ini registration, and the Medications module now lists FormularyItem as an external Additional Resource linked to the PHX incubator IG. The PHX incubator package currently contains a FormularyItem StructureDefinition with the same 46 differential element ids as the inactive core source.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current core build no longer owns an active FormularyItem resource definition, and the external PHX incubator artifact already carries the expanded FormularyItem element set that FHIR-51149 requested. Restoring or editing the inactive core source would conflict with the later migration out of active core build scope.

Recommendation:
Keep this external-repo audit commit as-is. Future FormularyItem content changes should be made in the PHX incubator IG, while core should continue to reference that external Additional Resource unless Pharmacy and FMG make a new decision to restore FormularyItem to active core.
