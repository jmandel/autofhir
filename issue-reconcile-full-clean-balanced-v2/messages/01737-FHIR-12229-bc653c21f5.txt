FHIR-12229: Audit document Provenance wording

Issue request:
FHIR-12229 was a Published, Persuasive with Modification Structured Documents clarification for DSTU2. It asked that the document-content rule allow Provenance resources whose target is the Composition itself or another resource included in the document, instead of saying the target had to be a resource included in the Composition.

Initial application:
The issue was applied in git commit e88780ca7bed60fb83ef49bfddd9b40217d5690f, matching the Jira comment that referenced svn revision 13013. That commit changed source/documents.html from "Provenance Resources that have a target which is a resource included in item #1" to "Provenance Resources that have a target of Composition or another resource included in the document."

Additional context:
FHIR-39502 later rewrote the document-content bullets into the current graph-based rule: the composition set, supporting information that references or is referenced from that set, and supporting collateral. FHIR-14033 later resolved no-change because the current list no longer names Provenance but is generic enough to include Provenance along with other resources that reference or are referenced by document contents. The current Bundle graph-connected guidance also calls out reverse references, including Provenances that point to resources within the Bundle. FHIR-54514 is a later R6 Resolved - change required item asking for explicit Bundle-target Provenance guidance; it is not Applied/Published and addresses a distinct whole-Bundle target case, so it is context rather than a source-edit basis for this seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/documents.html still permits Provenance that targets the Composition or another document resource because such a Provenance is supporting information in the graph of resources that reference the composition set. The current nearby narrative also says the bundle may include Provenance statements including signatures, and source/bundle/bundle-notes.xml explains that reverse references such as Provenances pointing to Bundle resources count for graph-connected Bundles.

Recommendation:
Keep this no-change audit as-is for FHIR-12229. Do not restore the old explicit Provenance-only bullet for this seed, because later Published and Resolved - No Change decisions deliberately generalized the rule. Handle FHIR-54514 separately if and when its R6 change-required decision is applied to address Provenance targeting the Bundle itself.
