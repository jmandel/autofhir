FHIR-35931: Audit mandatory referenceStrength substance

Issue request:
FHIR-35931 was a Published/Persuasive FHIR-core BR&R change request for MedicinalProductIngredient proposing that Ingredient.substance.strength.referenceStrength.substance be 1..1, while leaving referenceStrength itself optional.

Initial application:
Commit 0be7405ba746f8bbd28cca9884aea332a6de8707 applied the issue by changing referenceStrength.substance from min 0 to min 1 in source/ingredient/structuredefinition-Ingredient.xml.

Additional context:
The change follows the FHIR-31819/FHIR-31820 documentation family: referenceStrength only has meaning when it is tied to a reference substance. The current source still keeps Ingredient.substance.strength.referenceStrength optional at 0..*, so the later mandatory-substance rule applies only when a referenceStrength backbone is present.

AutoFHIR reconciliation:
No source change was made. The active StructureDefinition has referenceStrength.substance min=1/max=1, and Ingredient is the active build-scope replacement for the historical MedicinalProductIngredient artifact.

Recommendation:
Keep this no-change audit commit. The current conformance source exactly reflects the issue's accepted proposal.
