FHIR-35810: Audit machine practitioner guidance

Issue request:
FHIR-35810 was an Applied FHIR-core Practitioner change request, resolved Persuasive with Modification, asking whether AI/ML agents or other machine practitioners should be represented using Practitioner or PractitionerRole. The accepted resolution was to clarify the Practitioner Boundaries and Relationships section that autonomous systems and machines, including AI/ML systems, should be represented with Device.

Initial application:
The requested clarification was already applied by git commit 85f02ebfed30126b59a6f0a2bd7f5fb4f07db19d, "FHIR-35810 Machine Practitioner - Provide guidance to use Device not Practitioner," which added the current paragraph to source/practitioner/practitioner-introduction.xml. The active source/fhir.ini resources list includes practitioner=Practitioner, so the edited Practitioner narrative is in current build scope.

Additional context:
The current source preserves the accepted resolution: the Practitioner Boundaries and Relationships section says that when an autonomous system or machine is an actor or participant, Device should be used, including AI/ML and other automated systems. PA, PC, and O&O discussion in May 2023 and the Implementers Zulip thread converged on Device; FHIR-40568 was later rejected as no-change because its request to negate this Device direction was withdrawn/rejected, and FHIR-20511 is the older related Encounter-specific change that added Device as an allowed actor.

AutoFHIR reconciliation:
No source change was made. The authoritative current Practitioner source already contains the required guidance, PractitionerRole did not require a separate change under the final resolution, and related current source does not contradict the Device guidance.

Recommendation:
Keep this empty audit commit as-is. Further work, if any, should be handled by separate issue-specific review of individual resources that still need Device added as an allowed participant type, not by changing the Practitioner guidance for FHIR-35810.
