FHIR-42978: Audit Condition.onset event wording

Issue request:
FHIR-42978 was an Applied FHIR-core Condition change request, resolved Persuasive with Modification by Patient Care, asking to revise Condition.onset[x] so clinical events, situations, and concerns are covered. The approved text changed the definition to "Estimated or actual date or date-time the condition, situation, or concern began, in the opinion of the clinician." and added a comment that the event occurrence date is the onset date when an event rises to a level of concern.

Initial application:
The Jira comments point to HL7/fhir PR #2992 commits c71dae0 and 5475f14. Commit c71dae0 added the J#42978 committee note, updated the Condition.onset[x] definition, and added the event-onset comment in source/condition/structuredefinition-Condition.xml. Commit 5475f14 then added the missing terminal period. The current active source still contains those changes.

Additional context:
source/fhir.ini actively lists condition=Condition, so source/condition/structuredefinition-Condition.xml is in build scope. The Patient Care WG Zulip "Clinical Event" thread shows the issue arose because event-like Conditions made the old onset wording awkward and records that J#42978 was resolved.
