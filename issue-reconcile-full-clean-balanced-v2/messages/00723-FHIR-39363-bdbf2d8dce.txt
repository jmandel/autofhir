FHIR-39363: Audit moved encounter cancellation extension

Issue request:
FHIR-39363 was a Published FHIR-core Patient Administration change request for the Encounter reasonCancelled extension. The final Persuasive with Modification resolution asked to add an example binding to http://hl7.org/fhir/ValueSet/appointment-cancellation-reason and, instead of adding an invariant, change the documentation sentence from "Applies only if the status is cancelled." to "Usually applies when the status is cancelled.".

Initial application:
Core commit c4d724de25bab25db907de4320824cd216c67935 added an example binding to the appointment-cancellation-reason value set in source/encounter/structuredefinition-extension-encounter-reasonCancelled.xml. That commit did not change the description/definition sentence, which still said "Applies only if the status is cancelled.".

Additional context:
Core commit dd468d4f1799dd79819315b211588ef1cf4586e0 then removed the Encounter extension definitions, including encounter-reasonCancelled, from the R5 core source and removed the Encounter-core IG resource references. In the current core checkout, searches for encounter-reasonCancelled find only source/oids.ini; source/encounter/implementationguide-Encounter-core.xml has no resource entries. The current extension definition is in the FHIR Extension Pack. A later Published FHIR-extensions issue, FHIR-52945, created a dedicated example value set for encounter-reasonCancelled and the Extension Pack source now binds to that value set, while its description/definition still carries the older "Applies only" wording.

AutoFHIR reconciliation:
This is an empty audit commit. No core source file was changed because the affected StructureDefinition is no longer part of the current core build/source checkout. The remaining wording reconciliation, if desired, belongs in /home/jmandel/work/fhir-extensions/input/definitions/Encounter/StructureDefinition-encounter-reasonCancelled.xml rather than in HL7/fhir core.

Recommendation:
Keep this core audit commit as an external-repo decision. Follow up in the FHIR Extension Pack to decide whether the encounter-reasonCancelled description and differential definition should be changed from "Applies only if the status is cancelled." to "Usually applies when the status is cancelled." in light of FHIR-39363 and the later FHIR-52945 dedicated value set.
