FHIR-39094: Audit comparison group reconciliation

Issue request:
FHIR-39094 was Published with a Persuasive with Modification resolution for R5 ResearchStudy. It asked to reduce confusion between ResearchStudy.comparisonGroup.observedGroup and ResearchSubject.assignedArm/actualArm by renaming the ResearchSubject elements to assignedComparisonGroup and actualComparisonGroup, making those and the ResearchStudy comparison-group linkage id-typed, replacing the ResearchStudy comparisonGroup identifier with an id, and adding explanatory examples through FHIR-39370.

Initial application:
The R5 source was changed in git commit f41665322e16e96793c7267bc630cb679b614ddc, which replaced ResearchStudy.comparisonGroup.identifier with an id-typed linkage element and renamed ResearchSubject.assignedArm/actualArm to assignedComparisonGroup/actualComparisonGroup. Follow-up commits 1e9c3f475cfd7f51d896c95659a2fe46f95f8005 and e0bbd68448764e0d54463d56c17fdcf5e7f48abb renamed that ResearchStudy child to linkId for validator compatibility. FHIR-39370 was then implemented by commit 92569721347e01f38e70e6dc7cef31f23c7c0915 with a ResearchSubject example.

Additional context:
Later final R6 decisions intentionally changed the model again. FHIR-48736 refactored ResearchStudy.comparisonGroup to targetNumber, actualNumber, eligibility, and observedGroup, removing the old linkId. FHIR-49963 then explicitly replaced the stale "comparisonGroup.id" reference guidance with guidance to re-use a Group represented in ResearchStudy.comparisonGroup.eligibility by containing that Group and referencing it by Group.id. FHIR-53229, already represented on the combined branch, replaced ResearchSubject.assignedComparisonGroup and actualComparisonGroup with ResearchSubject.comparisonGroup 0..* CodeableReference as part of keeping ResearchSubject on the normative track. FHIR-53693 later added ResearchStudy.comparisonGroup.name for a simple label. The current source/fhir.ini actively includes ResearchStudy and ResearchSubject and records the R5-to-R6 removal of ResearchStudy.comparisonGroup.linkId and ResearchSubject assigned/actualComparisonGroup plus the addition of ResearchSubject.comparisonGroup.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative source is internally consistent with the later applied R6 model: ResearchStudy.comparisonGroup.eligibility and observedGroup reference Group, ResearchStudy.objective.outcomeMeasure intervention/comparator comments explain the Group-reference linkage, and ResearchSubject.comparisonGroup is a CodeableReference to Group or an example-coded concept. Restoring the exact R5 id/linkId and assigned/actualComparisonGroup elements would contradict later applied BRR decisions.

Recommendation:
Keep this audit commit as-is. Do not restore the R5 linkage elements for FHIR-39094. If BRR wants a new direct linkage between a ResearchSubject comparisonGroup and a ResearchStudy comparisonGroup backbone row, that should be raised as a new R6 issue because the current model intentionally moved away from FHIR-39094's id/linkId approach.
