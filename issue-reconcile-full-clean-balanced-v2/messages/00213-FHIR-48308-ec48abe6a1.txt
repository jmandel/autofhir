FHIR-48308: Audit CDS Hooks ConceptMap external move

Issue request:
FHIR-48308 was an Applied/Persuasive vocab change request for R6 asking the CDS Hooks indicator-to-request-priority ConceptMap to state its CodeSystem URIs explicitly: group.source as http://cds-hooks.hl7.org/CodeSystem/indicator and group.target as http://hl7.org/fhir/request-priority.

Initial application:
FHIR core history includes c06394415c05a44bfdb6b7d150d0730634862e7e, which added exactly those group.source and group.target values to source/conceptmap/conceptmap-cdshooks-indicator.xml. The Jira applied comment now points to HL7/cds-hooks-clinical-reasoning commit 61bbc5e8933a1eed0012f8efe7b6627172a687d8, which added the current external IG ConceptMap source with the same CodeSystem URIs.

Additional context:
FHIR-52870 decided that the CDS Hooks indicator ConceptMap should not remain a core ConceptMap example, and FHIR-53085 moved CDS-on-FHIR content and supporting ConceptMaps to the Using FHIR Clinical Reasoning with CDS Hooks IG. Current core source no longer contains or lists conceptmap-cdshooks-indicator as an active ConceptMap example; source/clinicalreasoning-cds-on-fhir.html points readers to the external IG. Confluence and Zulip evidence confirm the FHIR-48308 resolution was acceptable but the artifact ownership moved to the CDS IG, where Bryn Rhodes applied both FHIR-48308 and FHIR-52870. The combined branch already has reconciliation commits for FHIR-52870 and FHIR-53085, so this commit does not duplicate them.

AutoFHIR reconciliation:
Made no core source change. This is an external-repo audit because the artifact that FHIR-48308 changed is no longer owned by the current FHIR core build, and the external IG source already carries the requested group.source and group.target CodeSystem URIs.

Recommendation:
Keep this audit commit as-is for FHIR core. Future changes to the CDS Hooks indicator ConceptMap, including any ownership, standards-status, or possible THO migration work, should be handled in the CDS Hooks Clinical Reasoning IG or terminology governance process rather than by restoring the old core example.
