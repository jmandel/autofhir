FHIR-4004: Confirm NutritionOrder nutrient amount is Quantity

Issue request:
FHIR-4004 is a Published FHIR-core OO change request from the DSTU1 ballot. It asked to simplify NutritionOrder.item.oralDiet.nutrients.amount[x] by removing the Range choice and leaving Quantity, because Quantity can still express restrictions such as a comparator of less than 2 gm sodium.

Initial application:
No explicit git commit message mentions FHIR-4004, but the historical SVN-imported commit 7d67ca802e5a4a4a472dcba2a975d3e1b6b9a230 changed the NutritionOrder spreadsheet shortly after the 2015-01-19 vote. That change removed the old NutritionOrder.item.oralDiet.nutrients.amount[x] Quantity|Range row and replaced it with a non-choice NutritionOrder.oralDiet.nutrients.amount Quantity row. The current StructureDefinition also carries a committee note, "2/4/2015 EH: [#4004] remove choice from .nutient.amount." The source was later migrated from spreadsheets into source/nutritionorder/structuredefinition-NutritionOrder.xml.

Additional context:
NutritionOrder is active in the current build through source/fhir.ini, and the current canonical source path is source/nutritionorder/structuredefinition-NutritionOrder.xml. Later element naming changed from nutrients to nutrient, but the relevant element still resolves to NutritionOrder.oralDiet.nutrient.amount. Broader Quantity-comparator discussion in FHIR-5165 mentioned NutritionOrder.oralDiet.nutrient.amount but did not create a later requirement to restore Range; its resolution left other Quantity references as Quantity. Searches found no Zulip or Confluence discussion that conflicts with the Jira/source conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active NutritionOrder StructureDefinition already defines NutritionOrder.oralDiet.nutrient.amount as a single Quantity type with cardinality 0..1, and searches found no current amountRange, Quantity|Range, or amount[x] Range choice remaining in the NutritionOrder source.

Recommendation:
Keep this audit commit as-is. No follow-up source edit is needed for FHIR-4004 unless a future work group decision independently reopens the question of allowing Range on NutritionOrder.oralDiet.nutrient.amount.
