FHIR-32861: Audit MedicationRequest ended status

Issue request:
FHIR-32861 was Published/Persuasive with Modification for R5. It asked to add MedicationRequest.status code "ended" for historical or plan records where therapy is known to be no longer active but the reason is not known, and the approved resolution made "ended" an ancestor of completed, cancelled, and stopped.

Initial application:
The change appears to have been applied in historical commit 7acfd680713d0152367c6841b366974c594b4ec0, which added the ended concept to source/medicationrequest/codesystem-medicationrequest-status.xml and added ended to the MedicationRequest.status short display in source/medicationrequest/structuredefinition-MedicationRequest.xml. That commit grouped several Pharmacy issues, including FHIR-32861.

Additional context:
source/fhir.ini actively lists medicationrequest as a resource and assigns MedicationRequest the mps page code, so source/medicationrequest is in current build scope. Later related status work did not reverse this decision: FHIR-43569 added the matching canonical resource-status ended code, and FHIR-48861 separately added a generic Request pattern ended status, already represented on the combined branch by 2943f297a6fb4bcd452517fc3e12055a637c7936. Pharmacy Confluence minutes reference the FHIR-32861 tracker around the vote period, and targeted Zulip searches found only later implementer questions, not conflicting WG guidance.

AutoFHIR reconciliation:
No source change was made. The current MedicationRequest status CodeSystem has hierarchyMeaning="is-a", defines ended as "The request is no longer active and the subject should no longer be taking the medication.", and nests stopped, completed, and cancelled under it. MedicationRequest.status is bound to the MedicationRequest status value set and its short display includes ended.

Recommendation:
Keep this audit commit as-is. The seed issue is already correctly represented in current source; additional prose would be redundant and could drift from the authoritative CodeSystem hierarchy.
