Issue request:
FHIR-38856 was Published/Persuasive for R5 and asked that EncounterHistory be included in R5. Its resolution was to apply the Encounter reorganization described by FHIR-14157 to R5.

Initial application:
The issue was applied before R5 publication. Commit 53538c40d6 added the first draft EncounterHistory resource under source/encounterhistory, and commit 935d04e828 completed the EncounterHistory narrative/structure while explicitly citing FHIR-38856. The v5.0.0 tag contains that implementation, and the published R5 StructureDefinition is present as EncounterHistory version 5.0.0.

Additional context:
The current branch is no longer the R5 publication source. The active current source has no EncounterHistory entry in source/fhir.ini's [resources] list and no source/encounterhistory/structuredefinition-EncounterHistory.xml file. Later R6 cleanup commit 71567db3ee removed EncounterHistory and redirected current core narrative/module links to the PA admin-incubator IG. FHIR-47415 later rejected replacing EncounterHistory with Event.relevantHistory, but it does not require re-adding EncounterHistory to current core for this R5 ballot issue.

AutoFHIR reconciliation:

Recommendation:
