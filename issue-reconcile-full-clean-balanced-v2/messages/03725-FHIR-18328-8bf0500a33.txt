FHIR-18328: Audit patient animal extension wording

Issue request:
FHIR-18328 was a Published/Persuasive PA technical correction for FHIR-core Patient, raised against STU3 and applied for STU3. It asked to change the patient-animal wording from "The absence of the animal element does not imply that the patient is a human" to "The absence of the animal extension does not imply that the patient is a human" because animal had been moved from Patient.animal to a standard extension.

Initial application:
The exact correction appears to have been applied before this reconciliation by commit 7bf7397f4a, which changed the Patient extension spreadsheet text from "animal element" to "animal extension." Earlier commit e3d290e779 moved Patient.animal into the standard patient-animal extension and updated the animal Patient example to use the extension URL.

Additional context:
Current core build scope still includes the Patient resource, but the patient-animal extension definition itself was removed from core by dd468d4f17 as part of moving extensions out of R5 source. The current core Patient narrative links to the standard patient-animal extension and the current animal Patient example uses http://hl7.org/fhir/StructureDefinition/patient-animal. The current FHIR Extension Pack definition for patient-animal contains the corrected comment, "The absence of the animal extension does not imply that the patient is a human." Remaining core references to legacy Patient.animal are in out-of-build or historical artifacts for this issue's purpose, such as the commented-out CDA profile entry and QUICK model content, and are not the applied wording.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current extension definition is outside the core checkout and is already correct, while active core Patient source no longer contains the incorrect "animal element" wording and already points implementers to the extension.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-18328; only revisit if the Extension Pack definition regresses from "animal extension" or if HL7 decides to bring patient-animal extension source back into core.
