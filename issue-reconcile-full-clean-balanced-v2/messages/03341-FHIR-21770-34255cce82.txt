FHIR-21770: Audit Encounter patient search parameter description

Issue request:
FHIR-21770 was a Published/Persuasive PA change request asking that the Encounter:patient search parameter documentation stop saying "The patient or group present at the encounter" because its FHIRPath expression is Encounter.subject.where(resolve() is Patient). The approved resolution said the patient search property description would be updated by removing "or group".

Initial application:
No commit explicitly tagged FHIR-21770 was found in the Encounter source history. The same wording correction was applied in commit f3156be190 (#FHIR-13601), which changed source/encounter/bundle-Encounter-search-params.xml from "The patient or group present at the encounter" to "The patient present at the encounter" for SearchParameter/Encounter-patient.

Additional context:
Encounter is active in source/fhir.ini, so source/encounter/bundle-Encounter-search-params.xml is in current build scope. The current Encounter-patient search parameter has description "The patient present at the encounter", expression Encounter.subject.where(resolve() is Patient), and target Patient. The separate Encounter-subject search parameter still says "The patient or group present at the encounter" and uses expression Encounter.subject, which is consistent with subject covering both Patient and Group and is not part of the requested patient-only correction. FHIR-13601 is the same-change-family issue and its Jira resolution explicitly names Encounter and ClinicalImpression patient search parameter descriptions.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change because the current authoritative Encounter-patient search parameter already matches the FHIR-21770 request, and the remaining "patient or group" wording belongs to the broader subject search parameter/Encounter.subject definition rather than Encounter:patient.

Recommendation:
Keep this no-change audit commit as-is. No further core FHIR source change is needed for FHIR-21770 unless a future work group decision changes the semantics of Encounter.subject or the subject search parameter.
