FHIR-14151: Audit AdverseEvent media history

Issue request:
FHIR-14151 was Published/Persuasive with Modification for STU3 and asked to add support for Reference(Media | DocumentReference) to AdverseEvent.subjectMedicalHistory because many places that allow Observation should also allow Media.

Initial application:
No git commit explicitly mentioning FHIR-14151 was found. The change family was applied through later AdverseEvent source work: commit 0a593f76aea6a1c4e1e181668f260708adcf1fd0 for FHIR-20593 merged subjectMedicalHistory and referenceDocument into AdverseEvent.supportingInfo.item and retained GF#14151 on the element while listing Reference(Condition | Observation | AllergyIntolerance | FamilyMemberHistory | Immunization | Procedure | Media | DocumentReference). FHIR-20593 is already represented on the combined branch, so this commit does not duplicate it.

Additional context:
Current source has since moved AdverseEvent.supportingInfo to a repeating CodeableReference under FHIR-46599/J#46599. The active resources list in source/fhir.ini includes AdverseEvent, DocumentReference, and Observation, but not Media; Media appears only in the historical approved/dropped notes and inactive legacy source. The current AdverseEvent.supportingInfo target profiles include DocumentReference and Observation but intentionally do not include a non-active Media StructureDefinition target.

AutoFHIR reconciliation:
No source change was made. Adding Media back to AdverseEvent.supportingInfo would introduce a target to a resource that is not active in the current build, while the surviving current semantics still allow subject medical history observations and relevant documents through Observation and DocumentReference.

Recommendation:
Keep this no-change audit. Revisit only if the Patient Care work group reactivates Media as a current resource or makes a new R6+ decision to allow references to retired/past resources from current AdverseEvent.
