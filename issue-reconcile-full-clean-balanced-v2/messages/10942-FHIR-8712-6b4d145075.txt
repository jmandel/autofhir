FHIR-8712: Correct ValueSet URLs used as coding systems

Issue request:
FHIR-8712 was a Published/Persuasive FHIR-core change request from DSTU1 reporting examples whose Coding.system values used ValueSet URLs rather than the CodeSystem URLs that supplied the codes, with the validator failing to catch those invalid systems.

Initial application:
The Jira record says the original DSTU1 problem was applied in svn revision 7074. The originally cited ImmunizationRecommendation example is no longer in current core source, but current active source had the same semantic error in later examples and example terminology: Group family/household examples used http://hl7.org/fhir/ValueSet/group-code as Coding.system; Consent notSecLabel used http://terminology.hl7.org/ValueSet/v3-InformationSensitivityPolicy as Coding.system; and the Measure stratifier age-range example and companion CQL used the old OHIE ValueSet URI as a code system.

Additional context:
Consent, Group, Library, and Measure are active in source/fhir.ini, and the Group examples are explicitly listed in list-Group-examples.xml. The correct Group Code CodeSystem URL is http://hl7.org/fhir/group-code in current source; FHIR-55163 may later move Group terminology to THO but says to keep the existing URL and is not Applied/Published. UP-709 implemented the production THO Time Period Ranges CodeSystem at http://terminology.hl7.org/CodeSystem/time-period-ranges, superseding the stale OHIE ValueSet URI for the Measure age-range codes. A remaining ValueSet-as-system pattern in source/us/valueset-omb-ethnicity.xml was left untouched because the US Core profile entry is commented out in fhir.ini and is not current-build source.

AutoFHIR reconciliation:
This commit replaces the invalid ValueSet systems with the applicable CodeSystem systems in the current active source: Group examples now use http://hl7.org/fhir/group-code, the Consent securityLabel example now uses http://terminology.hl7.org/CodeSystem/v3-ActCode for HIV, and the Measure age-range ValueSet plus HIV Indicators CQL now use http://terminology.hl7.org/CodeSystem/time-period-ranges consistently.

Recommendation:
Keep this source fix. If the disabled legacy US profile source is ever reactivated, separately review source/us/valueset-omb-ethnicity.xml; do not fold that out-of-build cleanup into this current FHIR-8712 reconciliation.
