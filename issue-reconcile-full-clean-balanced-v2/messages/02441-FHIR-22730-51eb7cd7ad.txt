FHIR-22730: Audit ClinicalImpression statusReason binding

Issue request:
FHIR-22730 was a Published Patient Care change request, resolved Persuasive with Modification for R5, asking to bind ClinicalImpression.status to the existing event-status value set, add an example ClinicalImpression.statusReason binding with specified SNOMED CT exception/status-reason codes, and update the statusReason comment to say it is generally used for exception statuses such as not-done, on-hold, or stopped.

Initial application:
The Jira comments link the implementation commits in HL7/fhir PR #689/#691. Commit 405b65fcc96ad1fea82940854a15052ffa02408e updated the spreadsheet-era ClinicalImpression source to use event-status for ClinicalImpression.status, add the ClinicalImpressionStatusReason example binding, and apply the requested comment. Commit 95a699fbd0cefa88137c0c84874d7018dd95b62b added valueset-clinicalimpression-status-reason.xml with the requested SNOMED CT concepts, commit 8f4534b182ee69b8f60832a9b25716a09b88e0ee adjusted the status code text, and commit 8d0a045fcb76650a923df9da29f26d9045f42ff9 fixed the new value set description.

Additional context:
Later source refactoring preserved the same bindings in source/clinicalimpression/structuredefinition-ClinicalImpression.xml. FHIR-46596 then renamed ClinicalImpression to ClinicalAssessment for R6, and commit 670d3a407a962cdde0ef1136fbcdea045b124f19 copied the GF#22730 status/statusReason bindings into source/clinicalassessment/structuredefinition-ClinicalAssessment.xml and valueset-clinicalassessment-status-reason.xml. After that, commit fad1b9cf84ef652e88947e1a13b026c62f95334e removed ClinicalAssessment from active source/fhir.ini build tables and changed the core resource guide to link ClinicalAssessment to the external HL7 Patient Care incubator IG. Current source/fhir.ini has no active ClinicalImpression or ClinicalAssessment resource entry, and the external pc-incubator continuous-build artifact still carries the event-status and clinicalassessment-status-reason bindings.
