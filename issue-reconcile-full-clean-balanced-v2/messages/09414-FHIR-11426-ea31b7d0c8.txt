Initial application:

That commit changed the Definition logical model source under source/definition/ and added the Definition state-machine material, alongside a group of workflow tracker applications. There is no separate per-issue source commit for only FHIR-11426.

Additional context:

The current source supplies h2 headings for the Definition page sections in source/definition/definition-spreadsheet-introduction.xml and source/definition/definition-spreadsheet-notes.xml, while the FHIR build machinery injects numeric section labels. The current CI rendering of definition.html shows section counts for Scope and Usage, Boundaries and Relationships, Background and Context, Pattern Content, Definition extensions, State Machine, and Mappings. Recommendation:
Keep this no-change audit commit. No follow-up is needed for FHIR-core unless future publisher output again omits generated section numbers on definition.html.
