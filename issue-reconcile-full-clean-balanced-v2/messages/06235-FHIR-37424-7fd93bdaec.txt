FHIR-37424: Audit identifier query distinction

Issue request:
FHIR-37424 was a Published/Persuasive with Modification FHIR-I clarification request for the FHIR-core Search page. It reported that Observation?subject:identifier and Observation?subject.identifier can appear similar but are not equal: :identifier matches Reference.identifier, while .identifier is chained search through the resolved referenced resource's identifier. The final resolution said to update the specification through FHIR-29410 and not to mark the section as a dragon section.

Initial application:
The relevant prior source application is git commit 90c02ba9a4d70c6b0281011bfcf3b5f2066fe515, explicitly titled for both FHIR-29410 and FHIR-37424. That commit replaced a Search-page TODO about :identifier versus chained searches with detailed identifier-search guidance, including separate chained and :identifier examples. No prior Issue-Reconcile-Key commit for FHIR-37424 was found on the combined branch before this audit.

Additional context:
The linked Zulip discussion contains the exact implementer question and the answer that .identifier and :identifier are not equivalent. FHIR-I minutes from 2022-05-23 record FHIR-37424 as similar to FHIR-29410 and approved a Persuasive with Modification disposition pointing to the earlier issue's resolution. The current combined branch already contains a separate FHIR-45252 reconciliation that refined adjacent chaining language for non-Reference references, but it does not change this issue's core distinction.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/search.html already explains that chaining resolves the reference and tests Patient.identifier, while the identifier modifier tests Reference.identifier in the referencing resource; it also calls out that the difference between the examples is the period versus colon. That is the implementer-facing clarification FHIR-37424 requested.

Recommendation:
Keep this empty audit commit as-is. The current Search page is correct for FHIR-37424; follow-up should only occur if a later WG decision changes the policy for equivalence or support discovery between chained identifier searches and :identifier searches.
