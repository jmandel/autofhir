FHIR-5916: Audit MedicationStatement usage clarification

Issue request:
FHIR-5916 was a Published Pharmacy change request, resolved Persuasive with Modification for DSTU1. It asked to clarify the second and third MedicationStatement common-usage bullets so readers understand that a MedicationStatement represents each medication within an intake list or active-medication summary, and also asked for List-related context.

Initial application:
The Jira resolution says the issue was addressed by 2015 Tracker #7167 and #5941. Git commit 7d50996061 (#7167) added the active paragraph explaining that MedicationStatement does not produce a medication list but does produce individual medication statements usable by the List resource, and commit 0462d54886 already audits the related FHIR-5941 boundary decision on the combined branch. The exact common-usage bullets, however, stayed in old list/summary wording until the immediately preceding FHIR-7405 reconciliation commit updated them.

Additional context:
FHIR-7405 is the same MedicationStatement common-usage wording family and is the source-changing commit in this run. FHIR-38682 later renamed MedicationUsage back to MedicationStatement while stating that the scope section had not changed. FHIR-39165 later removed non-prescribed alcohol/tobacco/substance-abuse use from MedicationStatement scope, which is why the current first bullet is medication-only. FHIR-7910 raised a broader active-medication-list decoupling concern but was resolved Retracted/No Change, so it does not require additional source change here.
