FHIR-7614: Audit Condition encounter usage note

Issue request:
FHIR-7614 was Published with resolution Not Persuasive with Modification for a DSTU1 Patient Care request to rename Condition.encounter to firstEncounter because the original wording sounded like the first encounter where the condition was known. The approved change was not a rename; it was to add a usage note explaining that the element identifies the encounter associated with this Condition record and may differ from the first encounter where the underlying condition was known.

Initial application:
The issue was applied by git commit 80c713db6273e0fea9b46a4890014f59a01856de on 2015-08-24, whose subject explicitly says "#7614 - usage notes added to encounter field" and whose patch added the approved note to source/condition/condition-spreadsheet.xml. Later source-generation/refactor commits moved Condition to source/condition/structuredefinition-Condition.xml while preserving the same note.

Additional context:
Condition is an active current-build resource in source/fhir.ini, and source/condition/structuredefinition-Condition.xml is the authoritative current resource definition. A duplicate Jira issue, FHIR-7905, raised the same concern that source systems more commonly track the encounter where a condition is treated rather than the first assessment; it was closed as Duplicate and does not require a separate reconciliation commit. Jira, Zulip, and Confluence searches found no later core FHIR decision reversing or conflicting with the current Condition.encounter usage note.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Condition.encounter comment already includes the approved FHIR-7614 usage note, including the distinction between the encounter associated with this record and the first encounter where the underlying condition was known.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-7614 unless Patient Care later reopens the broader modeling question for Condition.encounter.
