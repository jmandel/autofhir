FHIR-17558: Remove stale ValueSet expansion profile reference

Issue request:
FHIR-17558 was Published/Persuasive for FHIR-core ValueSet and asked that ValueSet resource text remove references to ExpansionProfile overrides after ExpansionProfile was removed for R4.

Initial application:
The Jira comment points to svn revision 17558, which is git commit 56da3031e76fa8066c9ad10c82d3e81c48807cf0. That commit removed the cited ExpansionProfile wording from source/valueset/valueset-notes.xml and the ValueSet operation spreadsheet-derived parameter text, and the current ValueSet notes plus ValueSet/$expand operation definition already reflect that cleanup. A build-scoped prepared expansion example still had an XML comment saying a hierarchy may be controlled by "the expansion profile".

Additional context:
ValueSet remains an active current-build resource in source/fhir.ini, and source/valueset/list-ValueSet-examples.xml includes valueset-example-expansion as a ValueSet example. Related Vocab decisions FHIR-16337 and FHIR-16490 record the broader R4 removal of ExpansionProfile and replacement of its expansion-control behavior with explicit operation parameters. Remaining non-ValueSet matches for ExpansionProfile are historical release notes, old-type terminology, or IG build metadata rather than current ValueSet guidance.

AutoFHIR reconciliation:
Updated source/valueset/valueset-example-expansion.xml so the example comment says hierarchy control may come from extensions, operation parameters, or the expansion service, removing the stale ExpansionProfile reference without changing example data.

Recommendation:
Keep this source fix. It completes the requested ValueSet cleanup in a build-scoped example while preserving intentional historical references elsewhere.
