FHIR-41426: Audit vital signs applicability guidance

Issue request:
FHIR-41426 was an Applied OO R6 change request, resolved Persuasive with Modification. It asked for clearer guidance on when the Observation Vital Signs profile family applies, including renaming the main page from "Observation Vital Signs Panel Profile" to "Observation Vital Signs Profiles" and clarifying that conformance applies when the patient is known and the data is recognized and processed/displayed as a vital sign.

Initial application:
The page/profile naming portion was preapplied through the FHIR-46418 vital signs rework, which set the active vital signs ImplementationGuide title to "Observation Vital Signs Profiles" and renamed the base profile to "Vital Signs Base Profile." The substantive applicability wording was then applied by commit 6cb9883195, "FHIR-41426 - Updates to clarify the Vital Signs profile introduction text (includes the updates from dbarwin-50194)," which split and expanded the vital signs introduction paragraphs.

Additional context:
Observation is an active current-build resource and the vital signs ImplementationGuide is a core IG whose introduction source is source/observation/observation-vitalsigns-profile-introduction.xml. Current source now states that support for observations listed in the Vital Signs table requires conformance to the Vital Signs Base and specific profiles, explains that the relevant Observation.code value sets define the expected code scope including semantically equivalent non-value-set code systems, and states that de-identified data or device measurements not yet associated with a patient are not required to conform. Jira comments in April 2025 record that adding the same detailed explanation to the Observation resource core-profile row was considered unnecessary, and the requester accepted that adding the detailed text on the Vital Signs page was enough. The tightly related FHIR-50194 de-identified-data clarification is already represented on the combined branch by commit 6d3f42300e.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already contains the approved FHIR-41426 guidance in the authoritative Vital Signs page, keeps the Observation core-profile table as a concise link to that page, and avoids duplicating detailed conformance rules in a second location where they could drift.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-41426 unless the work group later decides that the Observation core-profile table should duplicate the full Vital Signs applicability rule despite the current linked guidance.
