Issue request:
FHIR-17961 was a Published/Persuasive FM change request for the STU3 EligibilityRequest/CoverageEligibilityRequest page asking to add the Request-or-Event workflow statement and link, specifically identifying the resource as a Request style resource.

Initial application:

Additional context:

Recommendation:
Keep this source fix as-is. It aligns the built resource narrative with the Jira request, the workflow index, and the Request pattern mapping without changing unrelated FM resource classifications.
