FHIR-35778: Audit IG Publisher tool definitions outside core

Issue request:
FHIR-35778 was Published/Persuasive for R5 after reporting that IG Publisher-generated R4 ImplementationGuide resources referenced non-existing tool extensions, including http://hl7.org/fhir/tools/StructureDefinition/ig-parameter and http://hl7.org/fhir/tools/StructureDefinition/resource-information, and used tool-specific parameter codes such as copyrightyear and releaselabel that were not in the R4 guide-parameter-code value set. The accepted resolution was that IGs are authored using R5 and that the IG Publisher package conversion process must ensure packaged IG instances are valid for the target FHIR version.

Initial application:
No commit explicitly mentioning FHIR-35778 was found in core history. The related core model change was applied by FHIR-20018 in commit 493ea99d47628ab5c056aed42faff4b36ecdb638, which changed ImplementationGuide.definition.parameter.code from string to Coding and added an extensible binding to guide-parameter-code; follow-up commits fixed the guide-parameter-code terminology metadata. That makes the current core resource model a generic hook for tool-specific parameter systems rather than a closed list of IG Publisher parameters.

Additional context:
FHIR-I minutes for the January 2022 WGM recorded the issue as a tools-folder / FHIR-Tool-IG task, and the current published hl7.fhir.uv.tools package provides the R4 compatibility extension http://hl7.org/fhir/tools/StructureDefinition/ig-parameter plus the complete CodeSystem http://hl7.org/fhir/tools/CodeSystem/ig-parameters containing the requested parameter codes. Current core source still quotes external IG examples that use the older resource-information URL, and current external packages can still contain that URL, but that artifact belongs to the Tools IG / IG Publisher package output rather than the core build source.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The active core ImplementationGuide definition already supports external tool-specific parameter codings, while the formal IG Publisher parameter definitions and any remaining resource-information cleanup are maintained outside this FHIR core checkout.

Recommendation:
Keep this audit commit as an external-repo decision for core. If validators still report missing http://hl7.org/fhir/tools/StructureDefinition/resource-information in current IG packages, follow up in the HL7 Tools Extension IG or HL7/fhir-ig-publisher so that the external package either defines that extension or stops emitting it; do not add IG Publisher-specific tool internals to core merely to satisfy generated package output.
