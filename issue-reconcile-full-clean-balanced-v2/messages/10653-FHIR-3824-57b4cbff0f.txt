FHIR-3824: Audit tab label rename

Issue request:
FHIR-3824 was a Published/Persuasive DSTU1 FHIR-core change request asking for clearer page/tab labels: the old "Packages" label was considered insufficiently descriptive, and "Formal Definitions" was proposed to become "Detailed Descriptions" because those pages contained more than formal definitions.

Initial application:
Jira records SVN revision 3602 for the initial application. Git-svn commit d8c1759c3428878e3bbfda9b178d948d99053f96, "{#3824}: change tab names", is that revision and changed datatype/resource definition page titles and cross-links from "Formal Definitions" to "Detailed Descriptions". The Jira comments also say the package label was later changed to "profiles" as part of another task; FHIR-5585 and git-svn commit ebc8bdfc17f551e9f1e5285b65d51146128991b2 record the related DSTU1 decision to use "profile" for the former "Conformance Package" concept.

Additional context:
Current source has since been refactored, but the relevant current build-scoped surfaces still carry the clarified labels. Datatype and resource definition pages use "Detailed Descriptions" for the tab/page label, resource profile pages use "Profiles", and the remaining current "packages.html" page is specifically titled "FHIR NPM Packages"/"NPM Packages" for the modern machine-consumable package specification rather than the old conformance-package tab. A few "Formal Definitions" strings remain as column labels for XML/JSON formal artifact links, not as the misleading tab/page label targeted by this issue. Zulip and Confluence searches found no later discussion contradicting the Jira/source outcome.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. The historical requested label changes were applied, later terminology changes explain the package/profile wording, and the current build output already renders the clarified labels without needing another source edit.

Recommendation:
Keep this no-change audit commit as-is. No follow-up is needed for FHIR-3824 unless a new work-group issue asks to redesign current navigation labels beyond the historical DSTU1 tab-label request.
