FHIR-11550: Audit relatedAction anchor collapse

Issue request:
FHIR-11550 was a Published CDS change request resolved Persuasive with Modification. It asked to combine relatedAction.relationship and the optional relatedAction.anchor, including the parallel GuidanceResponse action surface, so implementers could say before-start, before, before-end, concurrent-with-start, concurrent, concurrent-with-end, after-start, after, and after-end directly in the relationship code.

Initial application:
The issue was applied by SVN #10082, imported as git commit 6035db0d17e6050e99907530dc154276673675f6, which removed ActionRelationshipAnchor/action-relationship-anchor and the relatedAction.anchor element from the PlanDefinition and GuidanceResponse spreadsheets while expanding ActionRelationshipType to the nine combined codes requested by the resolution. GuidanceResponse action content was then removed by FHIR-12301 in SVN #10096, so there is no current GuidanceResponse relatedAction anchor surface to reconcile.

Additional context:
source/fhir.ini keeps PlanDefinition, GuidanceResponse, and RequestOrchestration in the current build. Current PlanDefinition.action.relatedAction.relationship uses the combined ActionRelationshipType codes, the action-relationship-type CodeSystem contains those codes, and no build-scope source retains relatedAction.anchor, relationshipAnchor, or ActionRelationshipAnchor. Later Published issue FHIR-26696 clarified the same timing code family by adding hierarchy, v3 concept maps, and optional endRelationship elements to PlanDefinition and RequestOrchestration; that later change refines start/end timing semantics without reversing the FHIR-11550 collapse.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current sources already express the combined relationship codes and omit the old anchor element; adding extra prose or reworking the later FHIR-26696 endRelationship model would not be a needed FHIR-11550 correction.

Recommendation:
Keep this no-change audit commit as-is. Future work on the timing relationship model should be evaluated under later issues such as FHIR-26696 rather than reopening the already-applied FHIR-11550 anchor collapse.
