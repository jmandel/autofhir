Initial application:
No current git commit explicitly mentions FHIR-7741. The issue appears to have been applied through the historical MedicationOrder example refresh in git commit 65be5a01c7, which added medicationorder0329.xml with a coded siteCodeableConcept using SNOMED CT 72098002 "Entire left upper arm (body structure)". Commit 7387b2894c then performed the MedicationOrder-to-MedicationRequest rename and preserved that example as medicationrequest0329.xml.

Additional context:
MedicationPrescription is no longer a current resource name; the active current build resource is MedicationRequest. The current source includes medicationrequest0329.xml and medicationrequest0323.xml as MedicationRequest examples with coded Dosage.site values, and list-MedicationRequest-examples.xml plus medicationrequest-examples-header.xml publish those examples. Later FHIR-54848 changed Dosage.site from CodeableConcept to CodeableReference(BodyStructure) while keeping coded concept use valid, so the current <site><coding> representation remains the correct successor to the original CodeableConcept request. Related FHIR-10066 discussed route/site placement and examples but does not require a separate reconciliation here.
