The original request asked to improve the valueset-expand-group extension description/comment by referencing ValueSet/$expand excludeNotForUI, but the final Vocab decision was to remove the valueset-expand-group extension and the hierarchical ValueSet example because the extension was underspecified.

Initial application:

Current active core source no longer contains valueset-expand-group references.

Additional context:
FHIR-30703 was resolved and applied in the same change family for valueset-expand-rules. FHIR-30700 provided the related ValueSet/$expand parameter clarification path, and the 2022-03-21 Vocab minutes summarize the combined decision as resolving all three tickets by removing the two extensions, improving the existing parameter descriptions, and not adding the proposed mode parameter. A later 2025 FMG/Zulip discussion and FHIR Extension Pack commit restored the removed extension canonicals only as retired/deprecated external artifacts because they were underspecified and not usable; that does not put the extension back into core build scope.
