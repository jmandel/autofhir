FHIR-14711: Audit CodeSystem validate-code title

Issue request:
FHIR-14711 was a Published/Persuasive Vocabulary technical correction for STU3 asking that the CodeSystem $validate-code operation list entry and operation heading say "Code System based Validation" rather than "Value Set based Validation".

Initial application:
The wrong title was introduced when CodeSystem $validate-code was added, and git history shows the CodeSystem spreadsheet title had already changed from "Value Set based Validation" to "Code System based Validation" by 83679db2a7. The Jira comment records the work as pre-applied in svn 13341, represented in git by 080e47c1a0, a CodeSystem documentation batch mentioning GF#14711. The 2021 source refactor then preserved the corrected operation title in source/codesystem/operationdefinition-CodeSystem-validate-code.xml.

Additional context:
The original Zulip discussion identified the CodeSystem title as a copy/paste error from the ValueSet operation, and the Vocabulary block vote page listed tracker 14711 as Persuasive and pre-applied. No later source or community evidence found during this reconciliation indicates that the CodeSystem operation should use the ValueSet title.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped CodeSystem resource folder contains list-CodeSystem-operations.xml pointing at OperationDefinition/CodeSystem-validate-code, and that operation definition has title "Code System based Validation" and resource "CodeSystem". A current source search found no stale "Value Set based Validation" title under source/codesystem; the ValueSet operation still correctly retains the ValueSet title.

Recommendation:
Keep this audit commit as-is. The requested correction is already represented in the current source, so editing would only duplicate the historical fix or risk changing the distinct ValueSet operation title.
