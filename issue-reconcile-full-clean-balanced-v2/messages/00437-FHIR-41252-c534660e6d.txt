FHIR-41252: Audit Ingredient strength composite parameters

Issue request:
FHIR-41252 was an Applied/Persuasive technical correction for the BR&R Ingredient resource. It reported that Ingredient.strength-concentration-ratio and Ingredient.strength-presentation-ratio used numerator/denominator composite parts that did not resolve to defined search parameters, and asked for matching numerator and denominator search parameters to be added for the Ratio-valued presentation and concentration strengths.

Initial application:
The issue was applied before this reconciliation by commit c5f2f84b50a596467558d343fd81c43e85e8b761, "added extra search params as used by existing composite ones FHIR-41252". That commit added Ingredient strength-concentration-numerator, strength-concentration-denominator, strength-presentation-numerator, and strength-presentation-denominator quantity search parameters and changed both composite search parameter component expressions away from the missing generic numerator/denominator references.

Additional context:
Ingredient is an active resource in source/fhir.ini, and source/ingredient/bundle-Ingredient-search-params.xml is the authoritative search parameter bundle for the current build. The original ratio composites came from FHIR-40313, and Zulip discussions in 2023 show the broader class of unresolved composite search parameter components that led Alexander Zautke to file FHIR-41252 and related resource-specific tickets. No Confluence minutes or Zulip messages were found that conflict with the applied Ingredient fix.

AutoFHIR reconciliation:
This commit makes no source change. The current Ingredient search parameter XML already contains the four needed quantity component search parameters with the expected Ratio numerator/denominator expressions, and the two affected composite search parameters now reference those resource-specific component codes.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-41252 unless a later work-group decision changes how ratio-valued Ingredient strengths should be searched.
