FHIR-19774: Audit Vital Signs profile name

Issue request:
FHIR-19774 is an Applied/Persuasive OO clarification from the STU3/R4 cycle requesting that the Vital Signs profile StructureDefinition.name be fixed. The Jira and linked Zulip thread identify the problem as the R4 VitalSigns profile using name="Vital Signs Profile" with whitespace even though StructureDefinition.name is required to be computer-friendly; the Jira resolution says to fix the name and notes that it was pre-applied for R4.

Initial application:
No current-source commit was found that explicitly names FHIR-19774. The issue appears to have been applied before the final R4 publication: official R4 vitalsigns.profile.xml has <name value="observation-vitalsigns"/> and <title value="Vital Signs Profile"/>, preserving the human title while making the computable name whitespace-free. Current git history also shows later profile-name maintenance, including FHIR-37449 changing the current source name from observation-vitalsigns to Observationvitalsigns before subsequent vital-signs refactoring renamed the base profile to Observationvitalsignsbase.

Additional context:
The current Observation source is in build scope because source/fhir.ini has Observation=observation as an active resource entry, and implementationguide-Observation-vitalsigns.xml includes StructureDefinition/vitalsigns in the core vital-signs IG. Current source/observation/structuredefinition-profile-vitalsigns.xml uses <name value="Observationvitalsignsbase"/> with <title value="Vital Signs Base Profile"/>, and the current vital-signs profile source set has no primary StructureDefinition.name values containing whitespace. The linked Zulip thread only confirms the original error and intent to fix it; Confluence references found FHIR-19774 in later OO tracker/project lists but no conflicting decision to change the current source.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The invalid whitespace-bearing StructureDefinition.name is absent from the current active core source and from the official R4/R5 publication surface checked during reconciliation, so changing the current spec would be redundant and could disturb later profile-name refactors.

Recommendation:
Keep this empty audit commit as-is. No core follow-up is needed for FHIR-19774 unless a future generated artifact or validator report identifies a remaining whitespace-bearing Vital Signs StructureDefinition.name in an active build artifact.
