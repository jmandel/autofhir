FHIR-12048: Audit Location operational status

Issue request:
FHIR-12048 was a Published/Persuasive Patient Administration change request from DSTU2 asking how to represent HL7 v2 table 0116 bed statuses that could not fit in the required Location.status code set. The accepted resolution was to add Location.operationalStatus 0..1 Coding, preferred-bound to the v2-0116 bed-status value set, with descriptive text covering beds, rooms, units, chairs, contamination, housekeeping, and maintenance.

Initial application:
The issue was applied by git commit 3e4dd26ef51c6ba90a3bcad1e3fb51e317ac05bb, whose subject explicitly listed tracker 12048 and whose Location diff added operationalStatus to the old spreadsheet source, added a room example with v2-0116 Housekeeping, and added an operational-status search parameter. Later source refactoring carried that content into source/location/structuredefinition-Location.xml, and the v2 terminology URLs were migrated to terminology.hl7.org.

Additional context:
Location is an active resource in source/fhir.ini. The current Location source keeps Location.status restricted to active/suspended/inactive but explains that current operational values may be represented by operationalStatus. Location.operationalStatus is present as 0..1 Coding with a preferred binding to http://terminology.hl7.org/ValueSet/v2-0116 and the requested bed/room operational-status definition. The current example and search parameter source also exercise the element. Later FHIR-55300 context confirms Location.operationalStatus is already in THO; FHIR-41741 was a retracted typo report against the same binding description and does not create a source-edit obligation for this seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already implements the FHIR-12048 resolution, and the current terminology URL reflects the later THO home for v2-0116 rather than a missed application.
