FHIR-11168: Audit ClinicalImpression action scope

Issue request:
FHIR-11168 was a Published Patient Care change request for DSTU2 ClinicalImpression.action. It asked to clarify that action represented action taken as part of the assessment procedure, to remove NutritionRequest and SupplyRequest-style planning resources from the action reference list, and to add a usage note distinguishing actions recommended after the impression.

Initial application:
The change was applied in git commit 6225693f5e9ed809b62ef6ac5e5fe203e3d4f2b6, which removed NutritionRequest and DeviceUseRequest from ClinicalImpression.action, changed the short/definition to "Action taken as part of assessment procedure", and added the action usage comment. The closely related FHIR-11167 plan-removal commit had already removed ClinicalImpression.plan and the scope phrase about actions planned as a result of assessment.

Additional context:
FHIR-46596 later renamed ClinicalImpression to ClinicalAssessment in commit 670d3a407a962cdde0ef1136fbcdea045b124f19. Commit fad1b9cf84ef652e88947e1a13b026c62f95334e then removed ClinicalAssessment from source/fhir.ini's active resource configuration. Current source/fhir.ini has no active ClinicalImpression or ClinicalAssessment entries, and the remaining inactive ClinicalImpression/ClinicalAssessment source has no action or plan element to correct.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the affected artifact is outside the current build scope. Editing the remaining inactive ClinicalImpression or ClinicalAssessment files would not correct the current built specification.

Recommendation:
Keep this audit commit as-is for the current build. If Patient Care reintroduces ClinicalAssessment/ClinicalImpression, revisit the inactive narrative and definitions together with FHIR-11167 because the old care-plan/action wording may need a fresh in-scope review.
