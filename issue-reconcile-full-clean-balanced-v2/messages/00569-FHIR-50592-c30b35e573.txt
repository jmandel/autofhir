FHIR-50592: Audit Group filter support declaration

Issue request:
FHIR-50592 was an Applied/Persuasive FHIR-core Group issue asking how a server should declare support for only enumerated or characteristic Group membership filters. The final resolution says support can be described non-computably through CapabilityStatement.rest.resource.documentation markdown, and that the use case should also be covered by the FHIR Application Feature Framework with a core-defined feature.

Initial application:
The source has been partially applied. Commit 73d80b15379961e418e9cae1cd24a5b9649f5757 added the non-computable declaration sentence to source/group/group-notes.xml, which is in build scope because source/fhir.ini lists group=Group as an active resource. I found no FHIR-core source artifact that defines a computable Group-filter feature.

Additional context:
FHIR-I May 2025 WGM minutes record the same two-part direction: CapabilityStatement documentation can be used non-computably, and computable support should come through the Application Feature Framework. The minutes also record the final warning that the issue would likely be partially applied until a place was identified to define core features. The current Application Feature Framework IG is maintained outside this core checkout and says it only defines FeatureSupport; code search in HL7/capstmt found no FHIR-50592 or Group FeatureDefinition.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. Adding speculative prose to Group would not provide the promised computable feature, and inventing a FeatureDefinition in FHIR core would be unsafe because the current core build has no identified FeatureDefinition artifact home or integration pattern for core feature definitions.

Recommendation:
Keep this audit as human-review. The existing Group documentation should remain as-is for the non-computable declaration path. FHIR-I or the responsible editor should define where core-owned Application Feature Framework features live, then add a canonical feature for Group membership-filter support and an example/assertion in the appropriate core or HL7/capstmt source.
