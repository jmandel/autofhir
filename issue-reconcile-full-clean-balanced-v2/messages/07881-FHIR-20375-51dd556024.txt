It reported that the Jurisdiction ValueSet expansion page showed a publication-tooling error, "Unable to provide support for code system urn:iso:std:iso:3166:-2", and the final resolution recorded this as a known issue on Grahame's list to fix.

Initial application:
No FHIR source commit explicitly mentioning FHIR-20375 was found. The issue appears to have been applied through terminology-server/publication tooling and subsequent terminology source evolution rather than by a Jira-tagged source hunk. Historical source/terminologies/valueset-jurisdiction.xml did include urn:iso:std:iso:3166:-2 in the Jurisdiction ValueSet CLD, and the checked R5 publication page renders expansion content instead of the reported error.

Additional context:
Same-family issues FHIR-14695 and FHIR-18280 reported earlier Jurisdiction ValueSet expansion failures, and FHIR-31537 later resolved no-change because the current build expanded successfully. UP-521 then moved the needed Jurisdiction ValueSet CLD to THO at http://terminology.hl7.org/ValueSet/jurisdiction. Current core source no longer contains source/terminologies/valueset-jurisdiction.xml; active non-SVG source references bind Jurisdiction to the THO URL. The ISO 3166 2-letter helper value set remains active in source/fhir.ini and already uses the later FHIR-37971 regex CLD.
