FHIR-25478: Audit migrated grid itemControl definition

Issue request:
FHIR-25478 was Published/Persuasive for FHIR-core Questionnaire and asked to clarify the vague gtable guidance. The approved resolution added a new group control code, grid, with semantics for rendering questionnaire child items as a grid.

Initial application:
The issue was applied in core by 7d821de56b996e383fa3a2af58c9f2d872568531, which added the grid concept to source/questionnaire/codesystem-questionnaire-item-control.xml. That same commit also implemented the tightly related FHIR-25599 refinement, replacing the original vertical-bar parsing proposal with child group rows and nested questions as columns.

Additional context:
FHIR-25599 is a Published/Persuasive SDC issue and is relevant because FHIR-25478's Jira comments explicitly point to it as the revised approach. The item-control CodeSystem and ValueSet were later removed from the current core source by dd468d4f1799dd79819315b211588ef1cf4586e0 as part of removing extensions from R5 source. Current core no longer tracks questionnaire item-control source files or active fhir.ini entries for them, while the FHIR Extension Pack contains the questionnaire-item-control CodeSystem with the grid definition.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The FHIR-core checkout no longer owns the item-control terminology artifact, and the authoritative extension-pack source already includes the grid code with the revised FHIR-25599 wording that superseded FHIR-25478's original vertical-bar text.

Recommendation:
Keep this audit commit as-is for the core reconciliation. Any future wording change to questionnaire-item-control should be handled in the FHIR Extension Pack rather than by recreating retired core source files.
