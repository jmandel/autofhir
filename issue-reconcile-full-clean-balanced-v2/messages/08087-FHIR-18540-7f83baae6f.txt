FHIR-18540: Audit Parameters definition update

Issue request:
FHIR-18540 was a Published/Persuasive with Modification FHIR-core Parameters clarification from STU3. It asked to replace the old Parameters description that called it a special resource type for operation request and response with "This resource is used to pass information into and back from an operation".

Initial application:
The Jira comment identifies git commit 37ed2fa09f7fc559a764a535192d05a2705b9737 as the application. That commit changed source/parameters/parameters-introduction.xml and the then-authoritative source/parameters/parameters-spreadsheet.xml from the old "special resource type" wording to the requested operation input/output wording. Later source refactoring removed the spreadsheet source and moved the active conformance definition into source/parameters/structuredefinition-Parameters.xml.

Additional context:
Later Published Parameters issues FHIR-26368 and FHIR-26390 refined the same introductory definition to handle messaging and limited non-operation uses. FHIR-26390's application and the existing combined-branch reconciliation commit 4f2edddd4a388a76f071bb8b4f1f6f3ba7d1a743 preserve FHIR-18540's core wording while adding the current "whether invoked directly from REST or within a messaging environment" and "except as described" qualifiers. The current build configuration actively lists Parameters as a concrete infrastructure resource.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Current source/parameters/parameters-introduction.xml already begins with the requested "This resource is used to pass information into and back from an operation" wording, and source/parameters/structuredefinition-Parameters.xml carries the same current definition in both the StructureDefinition description and root element definition.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core source edit is needed for FHIR-18540; future changes to broader Parameters-use semantics should be handled under their later issue keys rather than reopening this STU3 definition clarification.
