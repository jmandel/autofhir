FHIR-52930: Audit DeviceMetric status application

Issue request:
FHIR-52930 was an Applied FHIR-core DeviceMetric change request resolved as Persuasive with Modification for R6. It asked the Devices WG to add a way to indicate the DeviceMetric record state, including invalid or no-longer-current records, with a required status binding, FiveWs.status mapping, modifier semantics for entered-in-error, and a token status search parameter. The later issue comments and Devices WG minutes narrowed the implementation to adding DeviceMetric.status while also aligning the existing operationalStatus codes.

Initial application:
The issue was applied before this reconciliation through HL7/fhir#3873, merged as baf35c25463da2a4616c8e226b5aeef7fb865491. The implementation commit f04b9c191ea637727687d8d5306cf076d04e12d9 added DeviceMetric.status, the DeviceMetric-status search parameter, metric-status CodeSystem/ValueSet, and an example status; follow-up commits in the same PR fixed the status short/comment and operationalStatus alignment. Current git blame still traces the status element and search parameter to that implementation.

Additional context:
source/fhir.ini lists DeviceMetric as an active resource with approved status, so source/devicemetric is in current build scope. The current authoritative StructureDefinition has DeviceMetric.status as a required code, summary and modifier element bound to ValueSet/metric-status and mapped to FiveWs.status; the search parameter bundle contains DeviceMetric-status. The metric-status CodeSystem/ValueSet define active, inactive, entered-in-error, and unknown, while operationalStatus now covers on, off, standby, and unknown. FHIR-53367 later clarified the modifier handling: DeviceMetric.status carries the modifier reason and operationalStatus is no longer a modifier, which current source reflects. Confluence Devices WG minutes on 2025-10-22 and 2025-10-29 record approval of the status change and agreement that Elliot would align operationalStatus; Zulip search found no conflicting discussion.
