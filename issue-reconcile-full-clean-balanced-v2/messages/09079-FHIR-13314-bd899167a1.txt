FHIR-13314: Audit NamingSystem replacedBy removal

Issue request:
FHIR-13314 was Published/Persuasive with Modification for STU3. It asked whether NamingSystem.replacedBy should be changed from a REST resource reference to a fixed URL because copied NamingSystem records in registries would otherwise need registry-local references. The final resolution instead removed NamingSystem.replacedBy entirely and also removed the associated nsd-3 constraint.

Initial application:
The issue was explicitly applied by git-svn commit 06130884835bbf984b96075033d9cca5cca713de (#13314 - Remove NamingSystem.replacedBy, svn revision 12723). That commit deleted the replaced example, removed NamingSystem.replacedBy, removed the replaced-by search parameter, and removed the old nsd-3 invariant whose expression was replacedBy.empty() or status = 'retired'.

Additional context:
The current build-scope source still has an nsd-3 key, but it is not the removed FHIR-13314 invariant. It is a later authoritative-identifier constraint introduced for FHIR-27056 and now attached to NamingSystem.uniqueId.authoritative. FHIR-29704 later asked to add NamingSystem.replacedBy back and was resolved No Change, confirming that the original removal was not reversed.

AutoFHIR reconciliation:
No source change was made. Current NamingSystem source has no NamingSystem.replacedBy element, no replaced-by search parameter, and no old replacedBy/status invariant. The active resource source instead contains the later authoritative-identifier nsd-3 rule, so removing it for FHIR-13314 would undo later published work.

Recommendation:
Keep this empty audit commit as-is. No FHIR core follow-up is needed for FHIR-13314; future work should treat any change to the current nsd-3 invariant as part of the later authoritative-identifier issue family, not this replacedBy removal.
