FHIR-20306: Audit medication statement category value set

Issue request:
FHIR-20306 was a Published/Persuasive Pharmacy change request, raised in STU3 and applied for R5, reporting that the MedicationStatement.category binding pointed to http://hl7.org/fhir/ValueSet/medication-statement-category while that ValueSet was incorrectly named and described as "Medication Status Codes". The approved resolution was to fix the typo/value-set metadata.

Initial application:
The Jira snapshot records the application as merge commit 16680e7ffc2f0f3b8cf031ce23e828ec14c2457e from PR #490. The relevant merged commit 92cc8632039c231c346b3ab90697c9c0537a1a5f changed source/medicationstatement/valueset-medication-statement-category.xml from name/description "Medication Status Codes" to "MedicationStatement Category Codes".

Additional context:
MedicationStatement is still an active resource in source/fhir.ini, but the current authoritative MedicationStatement.category binding no longer uses the old medication-statement-category ValueSet. It now binds to the shared http://hl7.org/fhir/ValueSet/medicationrequest-category ValueSet, whose source is under MedicationRequest and is not named or described as Medication Status Codes. Later same-family combined-branch decisions for FHIR-31632 and FHIR-32825 document the shift to the shared MedicationRequest category vocabulary and the removal of the obsolete MedicationStatement category ValueSet source. FHIR-22826 and FHIR-23979 are same-defect audit issues already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical bad ValueSet name/description was corrected by the original application, and current source has no active medication-statement-category ValueSet definition left to fix; the only remaining old URL reference found in current source is the OID registry row, not a built ValueSet definition.

Recommendation:
Keep this no-change audit commit. Do not recreate or edit the obsolete medication-statement-category ValueSet in core for this historical typo; any future medication category terminology consolidation should follow later Pharmacy/Terminology issue decisions rather than FHIR-20306.
