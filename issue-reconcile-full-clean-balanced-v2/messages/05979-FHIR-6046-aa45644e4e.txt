FHIR-6046: Audit Questionnaire populate content type

Issue request:
FHIR-6046 is a Published/Persuasive FHIR-core Questionnaire change request from DSTU1. It asked that the Questionnaire.$populate content input parameter use type Any instead of string, noting that subject and content appeared to have their types reversed; the recorded resolution was to make content "ANY".

Initial application:
The Jira comments cite SVN #5941. In the git-svn history this is commit 26e8b597d5034f4372a848e5660a88268f4b664c, which changed source/questionnaire/questionnaire-spreadsheet.xml so the historical populate.content row moved from string to Any in the then-active Questionnaire operation spreadsheet.

Additional context:
The current core build still includes Questionnaire, but source/questionnaire/list-Questionnaire-operations.xml is empty and source/fhir.ini has no populate operation entry. Later Published issue FHIR-19606 explicitly moved the Questionnaire populate operations to the SDC implementation guide, implemented by commit cd80b481c37dbfdafa7b73995a63020c7ca94753, while current Questionnaire narrative points readers to SDC for advanced operations. A bounded check of the SDC 4.0.0 package found Questionnaire-populate there, not in core, and did not find a stale top-level content parameter typed string.

AutoFHIR reconciliation:
No source change was made. The requested core correction was applied historically, and the relevant operation definition is no longer an active core artifact to edit in the current build.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-6046; any future changes to the current Questionnaire populate operation should be handled in the SDC implementation guide rather than by reintroducing the old core operation source.
