FHIR-16319: Audit removed marital-status CodeSystem

Issue request:
FHIR-16319 was a Published/Persuasive PA issue raised against STU3 Patient. It reported that the FHIR marital-status CodeSystem page was confusing because it contained only one concept and said it was not currently used; the approved resolution was to remove the redundant unused CodeSystem rather than populate it.

Initial application:
The issue appears to have been applied by git commit 6fc4d35729, "Tracker 16319 remove codesystem-marital-status as it is not used," which deleted source/terminologies/codesystem-marital-status.xml. The Jira comments also record that codesystem-marital-status was removed.

Additional context:
FHIR-16516 asked the same substantive question and was resolved with the same removal text; FHIR-16616 was closed as a duplicate request to add missing marital-status codes. Current source keeps the active Patient.maritalStatus binding to http://hl7.org/fhir/ValueSet/marital-status, and that ValueSet composes terminology.hl7.org v3-MaritalStatus plus v3-NullFlavor UNK rather than the old FHIR-owned CodeSystem. source/fhir.ini still actively builds Patient, and its active [codesystems] section has no marital-status entry.

This commit intentionally makes no source change. The obsolete CodeSystem source file and canonical http://hl7.org/fhir/marital-status references are absent from current source, while the Patient marital-status ValueSet binding remains present and points at the intended external code systems.
