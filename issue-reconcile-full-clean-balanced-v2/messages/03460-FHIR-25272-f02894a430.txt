FHIR-25272: Audit ValueSet scope removal

Issue request:
FHIR-25272 was a Published R4 Vocabulary change request, resolved Persuasive, asking to add a core ValueSet.scope backbone element with focus, inclusionCriteria, exclusionCriteria, and modelContext string subelements using Value Set Definition (VSD) scope text. The request was approved for R5 by a 2020-06-25 Vocab block vote.

Initial application:
No source commit found in this checkout explicitly names FHIR-25272. The requested structure appears to have been applied implicitly by the R5 VSD profile work in git commit 054eabf3116825c0f65107fedff6668447bf43a1, after an earlier reverted attempt, which added ValueSet.scope and the requested subelements to source/valueset/structuredefinition-ValueSet.xml. Later R5 cleanup under FHIR-34171, FHIR-35988, and FHIR-35989 narrowed that design by tying scope to ValueSet.description and removing scope.focus.

Additional context:
FHIR-34171 is a Published later-change issue whose description explicitly calls itself a reversal of FHIR-25272 because implementers were using ValueSet.description for the VSD scope concept; that issue and the FHIR-35988/FHIR-35989 compromise are already represented by no-change audit commits on the combined branch. In 2025 Terminology Infrastructure minutes, the work group approved moving trial-use ValueSet.scope out of core for R6 and creating an extension-pack replacement; FHIR-53122 records that FHIR-extensions request, while FHIR-54123 is still Triaged and not a final core decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. source/fhir.ini lists ValueSet as an active resource, and the current authoritative ValueSet source no longer contains ValueSet.scope or any requested subelement because git commit 40306e5cd9c1b1e3eb6f115de16a8da3aa13a351 removed the trial-use scope structure and related notes for the R6 terminology cleanup. Re-adding the core element would contradict the later applied source state and the existing related audit decisions.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-25272; any future replacement should proceed through the FHIR-extensions work in FHIR-53122 or a later final core decision such as FHIR-54123 if it reaches an applied state.
