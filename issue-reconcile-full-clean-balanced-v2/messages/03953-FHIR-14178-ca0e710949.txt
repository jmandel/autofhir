FHIR-14178: Audit BR&R naming in research resources

Issue request:
FHIR-14178 was a Published/Persuasive STU3 change request asking to replace stale RCRIM wording with BR&R wording in the Scope and Usage sections for ResearchStudy and ResearchSubject after the work group name changed.

Initial application:
The source history shows the requested wording was applied in the 2017 STU3 cycle. Commit 271b586593 explicitly mentions GF#14178 and changed ResearchStudy Scope and Usage from "RCRIM standards" to "Biomedical Research and Regulation standards". The adjacent same-author commit 6859bc52a5 made the same wording replacement in ResearchSubject while applying a ResearchSubject search-parameter issue.

Additional context:
Later commit cf0ceda05d rewrote both introduction pages and removed the old work-group mission sentence entirely rather than restoring any RCRIM wording. The current build includes both resources through active source/fhir.ini resource entries and assigns both to work group code brr. Current StructureDefinition metadata for ResearchStudy and ResearchSubject uses publisher "HL7 International / Biomedical Research and Regulation" and wg code brr. Case-insensitive source search finds only legacy rcrim URL paths for the BR&R work group, not RCRIM as current resource prose or publisher text. Jira and community searches did not identify a conflicting later decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The stale RCRIM Scope and Usage wording targeted by FHIR-14178 is absent from current build-scope source, and adding a new BR&R sentence to the current resource introductions would be redundant rather than a necessary correction.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-14178 unless the work group later wants a broader editorial pass over BR&R contact URLs or introductory prose, which would be outside this issue's specific request.
