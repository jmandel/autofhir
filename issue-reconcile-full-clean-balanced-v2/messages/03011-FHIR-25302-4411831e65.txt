FHIR-25302: Audit Location language extension application

Issue request:
FHIR-25302 was Published with a Persuasive with Modification resolution for R5. It asked to represent languages spoken or services available in languages at a Location, and the final disposition called for Location-facing standard extension support for communication modes plus characteristic support analogous to HealthcareService.communication and HealthcareService.characteristic.

Initial application:
The issue was initially applied in core by commit 6e9a2824646e131f72e8f6bc1cfdde9d8e3b6e0e, which added StructureDefinition/location-communication and referenced it from implementationguide-Location-core.xml. The companion characteristic work was applied under FHIR-20965 by commits 0694e9259a7023c4dcaf42820689fe1bcaed0276 and d51b909f2215297921821a275758651be3d5d9fd, adding Location.characteristic, a characteristic search parameter, and the location-characteristic CodeSystem/ValueSet.

Additional context:
Current source/fhir.ini keeps Location active in the core build, and current source/location/structuredefinition-Location.xml still contains Location.characteristic with the location-characteristic binding. Core no longer contains the location-communication extension because commit dd468d4f1799dd79819315b211588ef1cf4586e0 intentionally removed R5 extension definitions from core source. The FHIR Extension Pack now contains input/definitions/Location/StructureDefinition-location-communication.xml as an active PA extension with Location context and CodeableConcept language binding, preserving and broadening the original standard extension semantics.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source already contains the build-scope characteristic portion, and the requested language extension is present in the Extension Pack rather than in this core checkout. Re-adding a core extension definition or Location IG entry would duplicate the current source-of-truth ownership.

Recommendation:
Keep this audit commit as-is. Future edits to the language extension itself should be made in the FHIR Extension Pack; no current core FHIR source follow-up is indicated for FHIR-25302.
