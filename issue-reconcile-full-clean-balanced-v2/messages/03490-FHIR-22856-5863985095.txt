FHIR-22856: Audit Designation Use note removal

Issue request:
FHIR-22856 was a Published vocab change request, resolved Persuasive with Modification for R5. It asked to update the Designation Use value set implementer note because the SNOMED CT concepts were available in the Global Patient Set and the note implied a confusing variation on extensible binding behavior. The approved resolution was to remove the pink implementer-note box.

Initial application:
The issue was applied in git commit 9500b398d1 ("vocab r5 tickets batch 2"), which explicitly listed FHIR-22856 and deleted the valueset-warning extension containing the implementer-note markdown from source/valueset/valueset-designation-use.xml. Current history does not show that warning being reintroduced.

Additional context:
source/fhir.ini actively includes the ValueSet resource folder in the build, and the current source/valueset/valueset-designation-use.xml has no valueset-warning extension or implementer-note markdown. The file still has the ordinary SNOMED CT copyright statement, but that is separate from the removed pink warning box. The related HTA-98 and UP-107 items concern broader SNOMED/UTG terminology policy and remain unresolved or out of scope, so they do not justify changing the current core source for this seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current source already reflects the Jira resolution by omitting the Designation Use implementer-note warning.

Recommendation:
Keep this audit commit as-is. If HL7 wants to revisit generic SNOMED CT copyright or UTG Designation Usage policy, that should proceed through the unresolved HTA/UTG work rather than by reopening this already-applied FHIR-22856 note-removal change.
