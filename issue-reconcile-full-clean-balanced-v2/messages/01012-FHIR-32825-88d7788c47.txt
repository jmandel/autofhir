FHIR-32825: Audit shared medication category vocabulary

Issue request:
FHIR-32825 was a Published/Persuasive Pharmacy change request for R5 asking why MedicationUsage.category and MedicationRequest.category used duplicate administration-location value sets/code systems. The accepted resolution was to have MedicationUsage reference the MedicationRequest administration-location value set, because multiple code systems and value sets were unnecessary for this example binding.

Initial application:
The Jira-tagged source commit 7acfd68071 changed MedicationUsage.category from http://hl7.org/fhir/ValueSet/medication-usage-admin-location to http://hl7.org/fhir/ValueSet/medicationrequest-admin-location. Later, FHIR-38682 renamed MedicationUsage back to MedicationStatement and preserved that shared binding.

Additional context:
MedicationRequest and MedicationStatement are active resources in source/fhir.ini. A later Applied Pharmacy issue, FHIR-51726, moved the example category terminology back into core and renamed the shared canonical to http://hl7.org/fhir/ValueSet/medicationrequest-category and http://hl7.org/fhir/CodeSystem/medicationrequest-category; current MedicationRequest.category and MedicationStatement.category both use that shared value set. FHIR-53306 and related terminology work discuss broader future consolidation of medication category code systems, but FHIR-53306 is not in a final Applied/Published state and is outside this seed decision. The remaining admin-location references found in current source are historical OID registry entries and generated-looking SVG diagram links, not authoritative binding source.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current authoritative StructureDefinition bindings already satisfy FHIR-32825 after the later canonical rename, and changing stale diagram/OID remnants or broader pending medication category terminology would exceed the applied seed decision.

Recommendation:
Keep this no-change audit commit as-is for FHIR-32825. If Pharmacy finalizes the broader category-code-system consolidation described around FHIR-53306, handle that as a separate issue with its own source-changing commit.
