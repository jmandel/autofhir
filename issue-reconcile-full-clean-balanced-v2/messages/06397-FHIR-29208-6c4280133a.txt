FHIR-29208: Audit InventoryReport externalization

Issue request:
FHIR-29208 was a Published FHIR-core change request from Orders and Observations, resolved Persuasive for R5. It asked to start a draft Inventory Status Report resource in the FHIR R5 build so the work group could discuss and evolve the resource proposal.

Initial application:
The issue was applied before R5. HL7/fhir commit d859feaadf9f9a93eb140df22024b99294ef3cd9 started adding InventoryReport source, and merge commit 84488dd4c5694d8e2a1a491b7dcbe8a3496598bc for PR #1022 explicitly says "Applied FHIR-29208". Those changes added source/inventoryreport content, active source/fhir.ini resource metadata, resource-list entries, and workflow-module links. The v5.0.0 tag still contains active InventoryReport fhir.ini entries and R5 resource-list/workflow links, confirming the requested R5 draft resource was published.

Additional context:
Current core no longer treats InventoryReport as an active build-scope resource. Current source/fhir.ini has no InventoryReport or inventoryreport entry, while current narrative pages link InventoryReport to the OO incubator/additional-resources IG. Later history explains that this is intentional: the #fmg "Assessment of Resources for removal from R6" thread recommended InventoryItem and InventoryReport for the Additional Resources track, the OO Additional Resource IG naming thread listed InventoryReport among the resources planned for that IG, Jira FHIR-53282 tracks OO Additional Resources configuration including InventoryReport, and commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed InventoryReport and related OO resources from active core metadata while pointing narrative links to the incubator.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source change is appropriate because the seed's requested R5 addition was already applied and published, and the current core build deliberately excludes InventoryReport in favor of the external OO incubator/additional-resources path. The orphan source/inventoryreport files are not sufficient build-scope evidence without an active source/fhir.ini entry.

Recommendation:
Keep this audit commit as-is for core. Do not restore InventoryReport to source/fhir.ini or the core resource list for FHIR-29208. Future InventoryReport corrections should be made in the OO additional-resources/incubator repository unless OO/FMG makes a new explicit decision to migrate the resource back into core.
