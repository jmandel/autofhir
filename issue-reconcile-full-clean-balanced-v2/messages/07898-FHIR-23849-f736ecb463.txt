FHIR-23849: Audit Questionnaire item text label mapping

Issue request:
FHIR-23849 was Published with a Persuasive resolution for R5. It asked to add guidance that Questionnaire.item.text can be derived from ElementDefinition.label when Questionnaire.item.definition points to an ElementDefinition.

Initial application:
No seed-keyed source commit was found for FHIR-23849. The request was instead applied through the later Published FHIR-28305 change family: commit 3f2444c74d added the active Questionnaire notes list entry "text (from ElementDefinition.label)", and FHIR-23849's Jira comment records that the issue was handled by a prior change request. Commit f7d53f8a45 for FHIR-23128 then removed the older derived-field list from Questionnaire.item.definition itself and linked that element definition to the detailed notes section.

Additional context:
The originating Zulip thread shows Paul Lynch asking why item.definition did not list label/text mapping, with Lloyd McKenzie confirming that the question text would be ElementDefinition.label. FHIR-28305's Jira resolution and the 2020-10-01 SDC minutes explicitly include adding item.text to the ElementDefinition mapping list. Questionnaire is an active core resource in source/fhir.ini, and the current source/questionnaire/questionnaire-notes.xml guidance already contains the requested mapping. The current combined branch already has a separate FHIR-28305 reconciliation, so this commit intentionally does not duplicate that related issue.

AutoFHIR reconciliation:
This commit makes no source change. The active Questionnaire narrative already tells implementers that item.text is derived from ElementDefinition.label when using Questionnaire.item.definition, and the item.definition element definition points readers to that detailed notes section.

Recommendation:
Keep this no-change audit commit. No core FHIR source follow-up is needed for FHIR-23849 unless the work group later decides that the mapping must be duplicated directly in the item.definition element definition instead of maintained in the linked Questionnaire notes.
