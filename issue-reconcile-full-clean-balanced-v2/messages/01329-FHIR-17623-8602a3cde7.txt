FHIR-17623: Audit component stratifier support

Issue request:
FHIR-17623 was a Published FHIR-core/CQI change request resolved Persuasive with Modification for STU3. It asked to support stratification by multiple components so implementers would not have to combine age group, sex, or similar criteria with artificial separators; the requested model added repeatable Measure stratifier components and matching MeasureReport stratum component values.

Initial application:
The Jira comment points to GH#422102297f. Git commit 422102297fc7daa54eb3a94c39d56f71e1e9fa63, followed by ac358312458b32e583a3f83588386715d749674f, added component-based stratifiers to the then-authoritative Measure and MeasureReport spreadsheet sources. Those spreadsheet sources were later refactored into the current StructureDefinition XML files, and the component structures remain present.

Additional context:
Measure and MeasureReport are active resources in source/fhir.ini. The current Measure StructureDefinition has repeatable Measure.group.stratifier.component with component code, description, and criteria descendants; the current MeasureReport StructureDefinition has repeatable MeasureReport.group.stratifier.stratum.component with required code and value[x] descendants. The quality reporting narrative now explains component stratifiers with the age-range/gender example from the Jira request. A later Published core issue, FHIR-34896, intentionally corrected MeasureReport.group.stratifier.code from 0..* to 0..1, so that difference from the original FHIR-17623 resolution is not a remaining defect.

AutoFHIR reconciliation:
This audit commit makes no source change because the current build-scope source already supports multiple stratifier components and matching report component values. Re-adding or reverting historical cardinalities would conflict with later accepted Measure/MeasureReport decisions.

Recommendation:
Keep this no-change audit as-is. If future work revisits Measure stratifier modeling, use FHIR-17623 as historical support for component stratifiers and FHIR-34896 as the controlling later decision for MeasureReport.group.stratifier.code cardinality.
