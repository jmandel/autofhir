Issue request:
FHIR-7545 was Published with a Persuasive with Modification resolution for the DSTU1 FHIR-core Feed issue "transaction and base interaction". The accepted motion was to drop the Bundle base fields, add fullUrl on Transaction/Bundle entries, document reference resolution, and update the affected transaction documentation.

Initial application:
The issue was applied in the historical source through three explicit #7545 commits: 3c8bef2fb3e86a56a8efb32857f71baebc766a76 removed Bundle.base/Bundle.entry.base and introduced Bundle.entry.fullUrl, 98b424be4b871513ba695dd26e8ead4a2c73c382 added bundle reference resolution rules, and 93db83230f06ea04d51ee0b09a610f39047d1f4f added the bundle resolution example and further notes. The current source has since been refactored into resource-specific Bundle XML files, but the applied semantics remain present.

Additional context:
Bundle is an active resource in source/fhir.ini, so source/bundle/* is in current build scope. Later fullUrl/reference-resolution Jira issues such as FHIR-9180, FHIR-14056, FHIR-29271, FHIR-27813, FHIR-31354, and FHIR-28364 refined or reaffirmed the fullUrl/transaction rules, but none restore the removed base elements or contradict the current fullUrl-centered reference resolution model.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The active Bundle StructureDefinition defines Bundle.entry.fullUrl and contains no Bundle.base or Bundle.entry.base element; the Bundle notes document fullUrl identity, uniqueness, and reference resolution; and the HTTP batch/transaction section directs entries to use Bundle.entry.request details rather than a per-bundle base field.

Recommendation:
Keep this no-change audit. Future edits should be limited to later fullUrl or reference-resolution trackers if those issue-specific decisions require wording changes; FHIR-7545 itself is already represented in current build-scope source.
