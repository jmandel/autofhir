FHIR-12523: Audit broken-link build control capability

Issue request:
FHIR-12523 was a Published/Persuasive with Modification FHIR Infrastructure change request from the DSTU2 cycle asking for broken links in generated FHIR documentation to produce at least build warnings, and preferably be prevented once known problems were cleaned up. The approved resolution was to add capability for editors to manage this better.

Initial application:
The issue was applied in SVN r11983, now git commit 64e060603fc58a5b7794f2d4e696796817b3faaf, which changed the then-in-tree IG publisher so that a control-file broken-links value of error halted the build when broken links were found. Later source refactors moved the resource definitions into the current ImplementationGuide XML sources while retaining the broken-link rule as a guide parameter code.

Additional context:
ImplementationGuide is an active resource in source/fhir.ini, and ImplementationGuide.definition.parameter.code is bound to the guide-parameter-code value set. The current source/implementationguide/codesystem-guide-parameter-code.xml includes rule-broken-links with warning/error behavior and default error semantics. The old Java publisher implementation is no longer part of this FHIR source checkout, and community searches found no later decision reversing or narrowing this applied tracker.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build-scoped core source already carries the relevant editor-facing control through the ImplementationGuide guide-parameter-code CodeSystem and binding. Adding duplicate prose or editing generated history artifacts would not change implementer understanding of the current specification.

Recommendation:
Keep this no-change audit commit as-is. If future work is needed, it should be handled in the IG Publisher/tooling repository or implementation documentation rather than as a new FHIR core source edit, unless the core guide-parameter-code definition itself is changed by a later work-group decision.
