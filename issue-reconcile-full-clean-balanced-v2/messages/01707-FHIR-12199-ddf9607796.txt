FHIR-12199: Audit NameUse maiden terminology update

Issue request:
FHIR-12199 was Published with a Persuasive with Modification resolution for the Patient-related NameUse terminology. It asked to avoid presenting "maiden name" as the display/definition while preserving the stable code `maiden`, changing the display to a marriage-name-change description, defining the use as names used before a marriage-related name change, and making `maiden` subsumed by `old`.

Initial application:
The issue appears to have been applied by git-svn commit 9f1a975027d8c35d5bc51d909f5f6407ac67fbe7, whose message cites #12199 and svn revision 10483. That commit changed source/datatypes/humanname.xml from display `Maiden` and a definition about collecting "maiden" names to display `Name changed for Marriage`, a gender-neutral marriage-name-change definition, and parent code `old`.

Additional context:
source/fhir.ini lists HumanName as an active datatype, so source/datatypes/humanname.xml is in current build scope and is the authoritative source for the HumanName.use/name-use terminology row. A later ballot issue, FHIR-16962, again requested changing the biased `maiden` term and was Resolved - No Change because birth name is not equivalent and no better replacement term had been found. Searches for FHIR-12199 and the maiden-name terms found no relevant Zulip or Confluence record that changes the Jira/source conclusion. Separate mother’s-maiden-name extension/search-parameter issues were not part of this value-set display/definition decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active NameUse source already retains the code `maiden`, sets its parent to `old`, and uses the gender-neutral marriage-name-change display and definition required by the published resolution. Remaining core references to `maiden` are either the stable code, examples using the code, OID/link references, or separate extension-pack/search-parameter material and do not make the current core NameUse terminology misleading.

Recommendation:
Keep this audit commit as-is. Do not rename the `maiden` code or add redundant wording in core for FHIR-12199; any future change to the terminology label/code or to the separate mother’s-maiden-name extension should be handled through a new work-group decision.
