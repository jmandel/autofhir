FHIR-12945: Audit removed KOS title value set

Issue request:
FHIR-12945 was a Published/Persuasive change request from the Imaging Integration work group asking to remove the unused KOS title value set from the FHIR-core terminology value set page for DSTU2.

Initial application:
The applied source history is the December 2017 commit d21acd4814, whose subject explicitly includes "GF#12945 remove KOS title valueset". That commit did not delete legacy value set files directly; it removed ImagingManifest from the active [resources] list in source/fhir.ini and moved imagingmanifest to [removed-resources], which also removed the only active resource source that used the KOS title binding.

Additional context:
The same historical commit also applied FHIR-14080, the Published/Persuasive-with-Modification decision to remove ImagingManifest from FHIR because its primary IHE use case no longer used the resource. Current source/fhir.ini still lists imagingmanifest only as a removed resource and does not register kos-title in the active [codesystems] or [valuesets] sections. Remaining kos-title files are under the legacy source/imagingmanifest directory or historical release snapshots, and source/oids.ini retains historical OID assignments that are not surfaced on the current build's OID page.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current built specification no longer publishes valueset-kos-title or CodeSystem-kos-title, and the remaining source references are legacy/out-of-build artifacts rather than active terminology inputs.

Recommendation:
Keep this no-change audit commit as-is. Do not delete the legacy ImagingManifest directory or historical OID mappings for this tracker without a broader cleanup decision for removed-resource source retention and historical identifier preservation.
