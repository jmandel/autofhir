FHIR-25456: Audit Evidence description updates

Issue request:
FHIR-25456 was a Published/Persuasive CDS change request for R5 asking to correct Description & Constraints text in the Evidence resource: Evidence.referentGroup.evidenceSource to "Group from which the evidence is derived", Evidence.referentGroup.intendedGroup to "Group for which the evidence applies", the certainty note text to "Footnotes and/or explanatory notes", and the certainty type text to "Type of certainty being rated".

Initial application:
No source commit explicitly mentioned FHIR-25456, but commit dae9b81d9363589921aa157bdba11bd1905839a9, made by the reporter shortly after the vote, changed source/evidence/evidence-spreadsheet.xml exactly from the old descriptions to the requested descriptions. Later generated StructureDefinition source preserved the note wording and carried forward the certainty type concept with refined wording.

Additional context:
Evidence is active in the current build through source/fhir.ini. Later Published Evidence decisions changed the relevant structure: FHIR-26455 deleted Evidence.referentGroup and renamed the group-related concepts into Evidence.variableDefinition.observed and Evidence.variableDefinition.intended, and FHIR-28920 streamlined Evidence.certainty into the current recursive structure with Evidence.certainty.note and Evidence.certainty.type. The current combined branch already contains audit commits for FHIR-25774, FHIR-26455, and FHIR-28920, so this seed should not republish those related issues.

AutoFHIR reconciliation:
