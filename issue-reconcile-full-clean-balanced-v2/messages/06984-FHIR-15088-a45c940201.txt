FHIR-15088: Audit Media imaging boundary guidance

Issue request:
Applied/Persuasive OO issue FHIR-15088 requested supporting use cases and examples to clarify the boundary between Media and ImagingStudy, including Media-as-Observation cases such as a cell-phone photo of a bump, blob-server images, and pathology-report images.

Initial application:
No git commit explicitly mentions FHIR-15088. The old Media source already contained examples and boundary prose before the Jira was created: Media use cases for diagnostic/care photos and diagnostic-report images, plus DICOM/WADO-RS guidance explaining when ImagingStudy is preferred and when portable media representation is useful. The January 2018 OO WGM minutes record the same boundary task and specifically call out non-formal media, diagnostic-grade imaging, pathology/gross images, and ImagingStudy as the DICOM-server entry point.

Additional context:
Later final issues changed how this issue should be read in the current build. FHIR-23567 merged Media into DocumentReference for R5 and moved Media examples into DocumentReference. FHIR-38950 then explicitly copied the useful Media boundaries-and-relationships material into DocumentReference. In source/fhir.ini, DocumentReference and ImagingStudy are active resources while Media is not listed under [resources], and source/history.html says Media was removed after R4B with DocumentReference or Observation as replacements. Current DocumentReference and ImagingStudy source now contains the successor boundary guidance and examples.

AutoFHIR reconciliation:
Made no source change. Editing source/media would touch a removed/out-of-build resource, and the active DocumentReference/ImagingStudy pages already convey the necessary current guidance: audio/video/image data can be represented through DocumentReference, DiagnosticReport overlap is explained, DICOM images are related to ImagingStudy or ImagingSelection with WADO-RS preferred for full imaging context, DocumentReference can carry rendered/portable images when full context is not important or WADO-RS is unavailable, and DICOM ultrasound plus left-hand x-ray examples are listed.

Recommendation:
Keep this no-change audit. Do not add new Media-specific examples to the current build; if the work group wants more current implementer guidance, it should be framed as a DocumentReference/ImagingStudy clarification rather than a Media edit.
