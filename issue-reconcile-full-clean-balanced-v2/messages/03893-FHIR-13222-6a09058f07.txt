FHIR-13222: Audit Dosage text/additionalInstruction guidance

Issue request:
FHIR-13222 was Published/Persuasive with Modification for STU3 by Pharmacy. It asked when complex administration, timing, tapering, and relationship instructions should be represented in Dosage.text versus Dosage.additionalInstruction, and whether additionalInstruction content should also appear in the free-text dosage instruction. The accepted resolution said all examples except the prescribed drug name belong in dosage.text, while Dosage.additionalInstruction is intended to be coded and may include text only when no code exists, with examples and guidance added.

Initial application:
The issue was applied in commit 36e1ed2f5f126b7641b3e1961589013cff52ea12, "TR# 13222 - clarify dosage.text and dosage.additionalInstruction". That commit changed the Dosage spreadsheet source to add the administration/preparation guidance to Dosage.text, expand Dosage.additionalInstruction examples to patient instructions and warnings, state that additionalInstruction is primarily coded but can carry text when no code exists, and add a comment that administration/preparation details such as intraperitoneal infusion or following another drug should be populated in dosage.text.

Additional context:
The current build keeps Dosage as an active normative datatype in source/fhir.ini, and source/datatypes/dosage.xml still carries the FHIR-13222 distinction. Later source refactors and the combined-branch FHIR-39319 reconciliation changed Dosage.text to be a complete free-text dosage/SIG representation, but they preserved the same additionalInstruction guidance. The reporter's Zulip thread confirms Pharmacy resolved that dosage.text was appropriate for the submitted examples, and no Confluence reference or conflicting community evidence was found.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active source already tells implementers that Dosage.text is the complete free-text/SIG representation and that administration/preparation details should be in dosage.text, while Dosage.additionalInstruction is a CodeableConcept for supplemental patient instructions or warnings, preferably coded but allowed to carry text when no code exists.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-13222 unless Pharmacy chooses to add new R6-era dosage examples as a separate editorial improvement.
