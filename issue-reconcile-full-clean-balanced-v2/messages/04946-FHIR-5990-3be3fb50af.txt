FHIR-5990: Audit administration method expansion correction

Issue request:
FHIR-5990 was a Published/Persuasive Pharmacy change request for DSTU1 medication resources. It reported that the administration-method value-set expansion looked like procedure types rather than medication administration methods/routes, and the accepted resolution was to fix the link to the correct value set and add SNOMED CT 422096002 Dosing instruction fragment as an exemplar value set.

Initial application:
The historical application is the same commit as FHIR-7742: adf4e89f89fd, whose subject explicitly includes GF#7742 and GF#5990 and says it added the administration method exemplar value set binding. That commit added example bindings for MedicationAdministrationMethod across the medication spreadsheets and rewrote the then medication order administration-method value set around SNOMED CT 422096002.

Additional context:
FHIR-7742 is the parallel MedicationAdministration issue from the same value-set correction family. The current model has since been refactored: source/fhir.ini lists MedicationAdministration, MedicationRequest, MedicationDispense, MedicationStatement, Dosage, and DosageDetails as active, while the current administration-method value set is used by MedicationAdministration.dosage.method and Dosage.method. A later Published/Persuasive with Modification Pharmacy decision, FHIR-19913, intentionally changed the active Dosage.method value set basis from 422096002 to SNOMED CT 736665006; commit 1dcdc4c567 applied that in source/datatypes/valueset-administration-method-codes.xml, and the combined branch already contains FHIR-19913 reconciliation commit 8f91c3f2e034.

AutoFHIR reconciliation:
This commit intentionally makes no source change. FHIR-5990 was applied historically, the current active administration-method value set is correct after FHIR-19913, and the remaining source/medicationrequest copy with 422096002 is an unreferenced historical duplicate rather than the active current binding source.

Recommendation:
Keep this empty audit commit as-is. Do not change the active value set back to 422096002 for FHIR-5990; any future cleanup of unused duplicate value-set files should be handled separately from this applied/published issue reconciliation.
