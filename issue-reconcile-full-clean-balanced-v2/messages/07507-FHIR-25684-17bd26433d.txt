FHIR-25684: Audit XHTML narrative root div requirement

Issue request:
FHIR-25684 was a Published/Persuasive FHIR-I clarification asking the narrative XHTML datatype page to state clearly that the root XHTML element for Narrative.div must be a div, not another legal XHTML element such as pre.

Initial application:
The request was applied in source history by commit 450fc3172fe21051b0546ee6a5bbc8afe773d04b, which changed source/narrative.html so the xhtml table says the id property becomes xml:id on the root element "which is an xhtml div" and that JSON encodes the XHTML div.

Additional context:
The source/fhir.ini type-page mapping actively routes both narrative and xhtml to source/narrative.html, so this page is in current build scope. The linked Zulip thread records Grahame confirming that the standard intended the root to be a div and inviting a clarification task, and the FHIR-I minutes record the 2020-04-20 Persuasive vote for FHIR-25684. Later current-source checks show the root-div clarification remains present.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build-scoped narrative source already conveys the requested root-div requirement in the XHTML datatype table. Adding redundant prose would not materially improve the current specification and could create avoidable maintenance drift.
