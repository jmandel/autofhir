FHIR-11566: Audit definitional resources clarification

Issue request:
FHIR-11566 was a Published/Persuasive CDS clarification from the 2016-09 CQIF ballot. It asked whether the definitional resources discussion implied resources beyond ActivityDefinition and resolved to expand the discussion to state that ActivityDefinition was then the only instantiation, while the broader definitional-resource concept could support future resources.

Initial application:
The issue was applied in SVN r10935, represented in git by 21fb883470b18d1dd855f6e5d61e73259b77f73e. That commit explicitly listed #11566 and added a note to guides/cqif/cqif-topics-definitional-resources.html saying there was then only one definitional resource, ActivityDefinition, but that the concept was general and could later split into additional resources.

Additional context:
The old CQIF page has since become source/clinicalreasoning-topics-definitional-resources.html and is part of the current build through source/hierarchy.xml under the Clinical Reasoning module. Later FHIR-53082 updated the same page for R6, adding the Definition pattern reference and revising the note to say there are now only a few definitional resources, naming ActivityDefinition, ObservationDefinition, and SpecimenDefinition. Current source also links to the page from the Clinical Reasoning module, Workflow, and Definition pattern material. Targeted Zulip and Confluence searches found no FHIR-11566 discussion or conflicting community record.

AutoFHIR reconciliation:
No source change was made. The current active page already preserves the FHIR-11566 clarification at the appropriate abstraction level: it no longer implies an unexplained plural, it says the concept is general, and it has been updated for later definitional-resource additions rather than retaining the original 2016 "only one" wording.

Recommendation:
Keep this audit commit as-is. Do not reintroduce the 2016 wording; the current wording is the correct post-FHIR-53082 expression of the same clarification. Any future update to the exact list of definitional resources should be handled under a current Clinical Reasoning issue rather than FHIR-11566.
