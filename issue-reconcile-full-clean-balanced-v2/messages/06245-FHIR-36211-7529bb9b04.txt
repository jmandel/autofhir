FHIR-36211: Audit TestScript scope outside core

Issue request:
FHIR-36211 was Published/Persuasive with Modification for R5 by FHIR-I. It asked to update the TestScript Scope and Usage section to describe TestScript use for both FHIR client and server implementations, and to explain possible use against other HL7 FHIR-based and non-FHIR-based specifications. The approved resolution also changed TestScript.setup.action.operation.resource from code to uri, made its binding extensible, and added a usage note that non-HL7 artifacts need full URI identifiers.

Initial application:
The issue was applied in core by commit 3ddff5b380956809cfa28febd612e3d45bcd1899, merged by 3a55e135e03cc38c90043b3d40a8dc9c9c80ac33. That commit updated source/testscript/testscript-introduction.xml to cover clients and servers and updated source/testscript/structuredefinition-TestScript.xml so operation.resource used uri with an extensible binding and the non-HL7 URI note. The related FMM work was also reflected by commit 1491ca500926439e943cacbeced5c0eaa2f4f3b4.

Additional context:
The current core branch no longer has an active TestScript resource. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testscript, source/testplan, and source/testreport, removed their active fhir.ini resource/workgroup/status entries, and added the FHIR Testing IG under [additional-ig-list]. Current source/fhir.ini points testing to https://build.fhir.org/ig/HL7/fhir-testing-ig, source/ballot-intro.html points TestScript to the external Testing IG, and git ls-files source/testscript returns no tracked core build inputs. The current HL7/fhir-testing-ig TestScript source retains the client/server description and the operation.resource uri/extensible/non-HL7-artifact changes.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The approved FHIR-36211 changes were historically applied while TestScript was in core, and the current authoritative TestScript artifact is now maintained outside this core checkout in the FHIR Testing IG.

Recommendation:
Keep this audit commit as-is for core. If FHIR-I wants the external Testing IG to say more explicitly that TestScript may apply to other HL7 FHIR-based or non-FHIR-based specifications, handle that as follow-up work in HL7/fhir-testing-ig rather than reintroducing removed core TestScript files.
