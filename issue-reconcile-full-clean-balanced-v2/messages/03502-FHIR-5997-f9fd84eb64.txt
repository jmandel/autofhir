FHIR-5997: Audit Provenance agent identity rename

Issue request:
FHIR-5997 was Published/Persuasive with Modification for DSTU1 by the Security WG. It asked to rename Provenance.agent.reference[x], remove uri as a datatype choice, remove Provenance.agent.display, update the agent identity wording, and add a userId Identifier for authorization-system identity.

Initial application:
The issue was applied in git-svn commit 0e6040334215da7696e0e29af0db1ff2c868acd8 / SVN r5606, which explicitly cited "5997 - rename Provenance.agent.reference[x]". That commit changed the Provenance spreadsheet from Provenance.agent.reference[x] to Provenance.agent.actor, removed the uri choice, replaced display with userId, and updated the example to use actor plus userId; this matches the Jira comment that the final implementation used actor for W5 alignment rather than the proposed reference name.

Additional context:
Provenance is an active current resource in source/fhir.ini. Later Security work evolved the same agent identity area: FHIR-11141 changed actor/userId into who[x]/onBehalfOf[x] and disabled the old actor and userId rows, later source rework materialized Provenance as StructureDefinition XML, and FHIR-32454 expanded agent.who to align with Event performer actor types. A separate already-published AutoFHIR commit for FHIR-14370 removed stale Provenance userId wording, confirming that the old userId subelement should not be restored now.

AutoFHIR reconciliation:
This audit commit makes no source change. Current source/provenance/structuredefinition-Provenance.xml defines Provenance.agent.who as the agent identity Reference, the current search parameter targets Provenance.agent.who, and source/provenance contains no remaining Provenance.agent.reference[x], Provenance.agent.actor element, Provenance.agent.display element, or Provenance.agent.userId element to correct.

Recommendation:
Keep this no-change audit commit. The seed issue was historically applied, and the current source is correct after later approved Provenance agent model changes; do not reintroduce the DSTU1-era actor/userId intermediate model.
