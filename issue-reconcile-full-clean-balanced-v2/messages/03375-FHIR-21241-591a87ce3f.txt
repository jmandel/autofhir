FHIR-21241: Audit Person actor prohibition wording

Issue request:
FHIR-21241 was a Published PA change request with resolution Persuasive with Modification. It asked to make the Person resource prohibition more obvious by emphasizing that Person instances are never directly referenced as actors, adding that Person SHALL NOT be referenced by other clinical or administrative resources, giving examples of allowed infrastructure use versus prohibited List/Group/Observation use, and clarifying that Practitioner can include people who are not licensed healthcare practitioners.

Initial application:
The issue appears to have been applied by git commit 44ec49c38110e0301543132b063dc498bf6fc859, "#FHIR-21241 Make prohibited use of Person more obvious", which changed source/person/person-introduction.xml. Person is active in source/fhir.ini under [resources], so the introduction file is current build source for the Person resource.

Additional context:
The 2021-06-09 PA minutes record the same modified wording and a 5-0-0 vote. Later no-change Jira decisions FHIR-31723 and FHIR-36832 rejected attempts to reference Person from Observation or Consent contexts and cited the same Person boundary rule. Relevant Zulip threads show implementer confusion about Person as a user/subject, but no discovered work-group or community evidence reverses the published rule.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source/person/person-introduction.xml already contains the approved prohibition text, including NEVER, SHALL NOT, allowed operation/message/Bundle examples, prohibited List/Group/Observation examples, and the Practitioner clarification. A targeted source search found no direct Reference(Person) in current source outside Person.link.target, which is part of Person's own linkage model rather than a clinical or administrative actor reference.

Recommendation:
Keep this no-change audit commit as-is. Future requests to allow Person as a subject, performer, grantor, or other actor should be handled as separate work-group policy decisions rather than as completion work for FHIR-21241.
