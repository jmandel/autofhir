FHIR-21005: Audit CQIF Questionnaire withdrawal

Issue request:
FHIR-21005 was a Published/Persuasive CDS change request for R5 asking to withdraw CQIF Questionnaire because the R4 profile only pointed to a CQL library, gave no real population guidance, and had a technically incorrect example. The resolution agreed to remove the CQIF-Questionnaire profile in favor of referencing the SDC questionnaire profile.

Initial application:
The issue was applied before this reconciliation by git commit bc30255627a58b5e899f1afd7a087806ab48ac23, explicitly tagged J#30204 and J#21005. That commit removed the CQF/CQIF Questionnaire StructureDefinition, ImplementationGuide, notes, PHQ-9 example, Questionnaire example entry, and Questionnaire pack entry, and changed the Clinical Reasoning documentation to point documentation-template users to Structured Data Capture.

Additional context:
FHIR-30204 is the later same-change-family issue that also requested eliminating CQF Questionnaire and was resolved Published/Persuasive. FHIR-20411 records the broader SDC/CQF harmonization decision, including migration of the CQF example to SDC. A 2018 Zulip thread shows the CQIF Questionnaire approach was already expected to converge with SDC work for external data retrieval and questionnaire behavior.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current core source has no active CQF/CQIF Questionnaire profile or example remnants, and the active Clinical Reasoning documentation points users to SDC rather than maintaining obsolete CQIF Questionnaire guidance.

Recommendation:
Keep this no-change audit commit. No core FHIR source follow-up is needed for FHIR-21005; any future refinement of detailed questionnaire/library guidance should happen in SDC or the Extension Pack unless the work groups request a specific core cross-reference.
