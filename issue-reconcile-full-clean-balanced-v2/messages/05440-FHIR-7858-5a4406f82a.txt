FHIR-7858: Audit Condition outcome extension placement

Issue request:
FHIR-7858 was a Published/Persuasive with Modification Patient Care issue asking how to represent patient cause of death. The accepted resolution was to add a Condition.outcome extension with an example value set and to note that patient cause of death is typically captured as an Observation, that outcome does not imply causality, and that some outcomes may not be assessable until Condition.clinicalStatus is no longer active.

Initial application:
The issue was applied in core by git commit e5933ab3cb970792db0fa1415abff23b2e0ea799, which added source/condition/valueset-condition-outcome.xml and changed the then-current Condition extension spreadsheet. The extension later existed as source/condition/structuredefinition-extension-condition-outcome.xml before the R5 source cleanup.

Additional context:
The active current core build includes Condition, Patient, and FamilyMemberHistory resources and an active condition-outcome value set entry in source/fhir.ini. Current core no longer carries the Condition outcome extension StructureDefinition because dd468d4f1799dd79819315b211588ef1cf4586e0 removed resource-specific extension definitions from the R5 core source, while keeping the condition-outcome value set active. The current FHIR Extension Pack contains input/definitions/Condition/StructureDefinition-condition-outcome.xml with the expected extension URL, Condition context, binding to http://hl7.org/fhir/ValueSet/condition-outcome, and the exact usage note about cause of death as Observation and outcome not implying causality. Later FamilyMemberHistory work added contributedToDeath and clarified that outcome does not itself imply cause of death.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core checkout is not missing a Condition.outcome element or extension definition: the active core source supplies the shared value set, and the Extension Pack supplies the extension and usage note that now belong outside the core checkout.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-7858; any future edits to the Condition outcome extension definition should be made in the FHIR Extension Pack rather than reintroducing the extension StructureDefinition to core.
