FHIR-12140: Audit TestScript FHIRPath support outside core

Issue request:
FHIR-12140 is a Published/Persuasive with Modification FHIR-core TestScript change request from the DSTU2 cycle. It asked for FHIRPath support in TestScript.variable.path, TestScript.setup.action.assert.path, and TestScript.setup.action.assert.compareToSourcePath by adding parallel expression elements while preserving the existing path elements for backwards compatibility.

Initial application:
The issue was applied in svn revision 10002, mirrored in git as 8c7627b26e26e23cb06ce3f4c1fbcc6892ab23d7. That commit updated source/testscript/testscript-spreadsheet.xml to add TestScript.variable.expression, TestScript.setup.action.assert.compareToSourceExpression, and TestScript.setup.action.assert.expression, and updated related invariants to account for expression/path alternatives.

Additional context:
Current core no longer owns the TestScript resource. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testscript and removed testscript=TestScript from the active resource build configuration while adding the HL7 FHIR Testing IG to source/fhir.ini's additional IG list. The current core FHIRPath page links TestScript assertion-expression guidance to that Testing IG, and the current Testing IG package still contains the requested expression peers alongside the legacy path elements.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The requested support was historically applied, the authoritative current TestScript artifact is outside this FHIR-core checkout, and the external Testing IG currently preserves the expression/path model needed by FHIR-12140.

Recommendation:
Keep this audit commit as-is for FHIR core. If future review finds a mismatch in TestScript FHIRPath expression support, make the fix in the HL7 FHIR Testing IG rather than reintroducing inactive core TestScript source.
