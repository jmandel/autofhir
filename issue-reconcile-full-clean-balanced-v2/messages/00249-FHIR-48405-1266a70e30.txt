FHIR-48405: Remove stale Substance.instance remnants

Issue request:
FHIR-48405 is an Applied/Persuasive BR&R change request for R6. It asked that Substance be used only for substance instances, with SubstanceDefinition used for definitions, and specifically requested removing Substance.instance and Substance.ingredient, updating resource descriptions, and assessing definitional Substance references.

Initial application:
The current branch already included the main application commits: c7b1723155a5f4c24466742a1fd1b8beedad5ac2 removed Substance.instance and Substance.ingredient from the authoritative Substance StructureDefinition, search parameters, and Substance narrative; bb552f054ba4dd01e148d70b16726d28c2fa8253, 12badf2d1c4d595438fb032caa92223d7c27d403, 1f1daea7ee29d599ba705f8d14d0e19c8f0ec4c0, 9a87ab0381fdb8f89012b0a55914bd85d3e35ac5, and 0dd810799c152f460b098735875dc51374554220 adjusted several definitional references; c55361c8bc001973e6b03f28bc75c376760d9222 updated SubstanceDefinition narrative. The remaining gap was that active examples and checked-in diagrams still exposed the removed instance/ingredient model, and Medication.ingredient.item prose had not caught up with its SubstanceDefinition target.

Additional context:
Active fhir.ini entries include Substance, Medication, ActivityDefinition, PlanDefinition, and SubstanceDefinition, so the affected examples and narrative are in the current build scope. FHIR-43166 was later marked Duplicate of FHIR-48405 and informed the Medication.ingredient.item SubstanceDefinition target, but it is not independently decided here. Confluence minutes corroborate the BR&R vote and later cross-WG understanding that Substance.instance is removed because Substance is always an instance; no conflicting Zulip discussion was found.

AutoFHIR reconciliation:
This commit removes stale <instance> elements from active Substance examples and contained Substance examples in Medication, ActivityDefinition, and PlanDefinition examples. It updates Medication.ingredient.item prose and the medication-definition module to include SubstanceDefinition and to say Substance represents actual instances. It also removes the obsolete Substance.instance and Substance.ingredient entries from the checked-in Substance diagram and updates the Medication diagram tooltip so generated-looking artifacts no longer contradict the authoritative source. The fhir.ini Substance.instance/Substance.ingredient entries are left unchanged because they are cross-version migration notes describing old elements.

Recommendation:
Keep this fixed commit. If the publisher regenerates diagrams, the generated output should be compared with these source changes, but no further work group decision is needed for the stale example and wording cleanup.
