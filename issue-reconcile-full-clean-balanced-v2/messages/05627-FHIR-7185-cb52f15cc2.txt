FHIR-7185: Audit ClinicalImpression current scope

Issue request:
FHIR-7185 was a Published/Persuasive with Modification Patient Care change request for DSTU1 ClinicalImpression. It asked not to remove the resource, but to clarify the ClinicalImpression boundaries with Condition by describing it as the outcome of the clinical assessment process and the "A" in SOAP, and to rename ClinicalImpression.action to supportingInfo 0..* Reference(Any) with the definition "Information supporting the clinical impression." The Jira discussion also noted that ClinicalImpression.plan had already been removed by another change because plans should point back to the earlier clinical impression.

Initial application:
The change was historically applied in git commit 5596f16348577cb6da1e332d48404a9bf6c17305, which added the SOAP/Condition boundary paragraph to the ClinicalImpression introduction and renamed the authored ClinicalImpression.action spreadsheet row to ClinicalImpression.supportingInfo with Reference(Any), the requested short/definition, and GF#7185 committee notes. Current inactive ClinicalImpression source still has the boundary text and supportingInfo element, and the later inactive ClinicalAssessment copy preserves the same semantics under the renamed resource.

Additional context:
FHIR-11167 had already removed ClinicalImpression.plan, and FHIR-11168 separately clarified the old action element before FHIR-7185 renamed it to supportingInfo; both have already been audited on the combined branch. FHIR-46596 later renamed ClinicalImpression to ClinicalAssessment, and an existing reconciliation commit for FHIR-46596 fixed remaining active narrative rename references. Commit fad1b9cf84ef652e88947e1a13b026c62f95334e then removed ClinicalAssessment from source/fhir.ini's active core resource configuration and changed current core narrative to link to the PC incubator ClinicalAssessment artifact. Patient Care Zulip discussion records that ClinicalAssessment was voted out of R6 core to the Additional Resources track, and the current PC incubator page carries the FHIR-7185 boundary/supportingInfo content.

AutoFHIR reconciliation:
This empty audit commit makes no source change because neither ClinicalImpression nor ClinicalAssessment is an active core resource in the current build. Editing the remaining inactive source/clinicalimpression or source/clinicalassessment files would not correct the current built core specification, and any future authoritative ClinicalAssessment wording work belongs with the PC incubator/Additional Resources artifact or a deliberate core reintroduction.

Recommendation:
Keep this audit commit as-is for the current core build. If Patient Care reintroduces ClinicalAssessment into core or updates the PC incubator artifact, review FHIR-7185 together with FHIR-11167 and FHIR-11168 so the assessment-versus-condition and assessment-versus-plan boundaries remain explicit.
