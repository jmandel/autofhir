FHIR-27807: Audit Patient multiple-birth-total extension

Issue request:
FHIR-27807 was a Published/Persuasive Patient Administration change request raised for R4 and applied for R5. It asked FHIR core to introduce a standard integer extension for Patient.multipleBirth[x] that records the total number of births from one pregnancy, so implementations can express values such as the 4 in "3 of 4".

Initial application:
The request was initially applied in core by commit 0bcf5a6283, which added StructureDefinition/patient-multipleBirthTotal under source/patient and added it to the Patient implementation guide. That definition used a positiveInt value and context Patient.multipleBirth[x]. Commit dd468d4f17 later removed the Patient extension definitions from core as part of the migration of global extensions out of the R5 source tree.

Additional context:
The current Patient resource remains in build scope through source/fhir.ini, and Patient.multipleBirth[x] now explicitly points implementers to the patient-multipleBirthTotal extension. The authoritative extension is present in the FHIR Extension Pack at input/definitions/Patient/StructureDefinition-patient-multipleBirthTotal.xml with the same canonical URL, Patient.multipleBirth[x] context, positiveInt value, and later clarifications from FHIR-41244 and FHIR-48399 about fetal losses and pre-birth use. The original 2017 Zulip discussion and 2020 PA WGM minutes align with the Jira request and do not reveal a conflicting current requirement.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the extension definition to core would duplicate the Extension Pack source of truth, and the current core Patient definition plus OID entry already preserve the cross-reference needed in the active core build.

Recommendation:
Keep this audit commit as-is. If future work changes the extension definition itself, make that change in the FHIR Extension Pack rather than in the core checkout, while keeping the core Patient.multipleBirth[x] reference aligned.
