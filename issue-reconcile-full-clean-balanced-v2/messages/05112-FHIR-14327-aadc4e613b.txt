FHIR-14327: Audit HLA code-system registry update

Issue request:
FHIR-14327 was a Published/Persuasive vocab change request for the STU3 terminology code-systems page. It asked that the external IMGT/HLA code system row use OID 2.16.840.1.113883.6.341 and remove the trailing slash from the URI, changing it to http://www.ebi.ac.uk/ipd/imgt/hla.

Initial application:
The requested source change was applied in git-svn commit 0a95e00e03c30ab8aa2a1adea453b74bd5cc0968, which is the commit for SVN revision 12790 cited in the Jira comment. That commit changed source/terminologies-systems.html from http://www.ebi.ac.uk/ipd/imgt/hla/ and OID 2.16.840.1.113883.13.252 to http://www.ebi.ac.uk/ipd/imgt/hla and OID 2.16.840.1.113883.6.341.

Additional context:
The current source no longer contains the IMGT/HLA row. FHIR-37853, also Published/Persuasive, later changed the Code Systems page so HL7 Terminology is the source of truth for external terminology information and deleted external rows without FHIR-specific usage documentation. The current source/hierarchy.xml includes terminologies-systems.html in the build, and source/terminologies-systems.html now points readers to terminology.hl7.org/external_code_systems.html for authoritative external code-system URI and OID information. The combined branch already contains an audit commit for FHIR-37853, so this commit does not re-decide that later issue.

AutoFHIR reconciliation:
This commit intentionally makes no source change. There is no stale IMGT/HLA URI or OID row left in the current core source, and re-adding one would contradict the later THO source-of-truth decision.

Recommendation:
Keep this audit commit as-is for FHIR core. If authoritative IMGT/HLA registration information needs to be updated today, pursue that in the HL7 Terminology/TSMG source of truth rather than adding the old external row back to the FHIR core Code Systems page.
