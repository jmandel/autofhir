FHIR-17922: Clarify Claim insurer short description

Issue request:
FHIR-17922 is a Published/Persuasive with Modification FM change request raised against STU3 for FHIR-core Claim. It asked to change the Claim.insurer short description from "Target" to the approved wording "Party to adjudicate the request".

Initial application:
The historical batch commit afb5ec66f68641293bb7950b6e0eeb118fa1444a mentioned FHIR-17922 in its message, but inspection of the resulting Claim spreadsheet showed Claim.insurer still had short text "Target" and definition "The Insurer who is target of the request." The current generated StructureDefinition source therefore retained the stale short description.

Additional context:
Claim is an active current build resource through source/fhir.ini. A later reconciled FHIR-19457 commit made Claim.insurer mandatory but intentionally left the short and definition wording unchanged, so it does not supersede or complete the FHIR-17922 wording request. Exact Zulip and Confluence searches found no discussion or conflicting work-group record.

AutoFHIR reconciliation:
This commit updates source/claim/structuredefinition-Claim.xml so Claim.insurer.short is "Party to adjudicate the request". It leaves the longer definition unchanged because FHIR-17922 specifically approved a short-description change and no evidence supports a broader definition rewrite.

Recommendation:
Keep this source fix as-is. If FM wants the Claim.insurer definition modernized as well, that should be handled as a separate editorial or work-group decision rather than bundled into this STU3 short-description reconciliation.
