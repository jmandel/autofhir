Issue request:
FHIR-28432 is a Published/Persuasive with Modification FHIR-core CDS change request for R5. It asked to add subject[x] support for MedicinalProductDefinition and SubstanceDefinition for PQ/CMC quality specifications, and the final resolution expanded the allowed product-definition targets to MedicinalProductDefinition, SubstanceDefinition, AdministrableProductDefinition, ManufacturedItemDefinition, and PackagedProductDefinition while adding a canonical subject choice for definitional subjects.

Initial application:
Jira comments link HL7/fhir#1043, #1054, and the R4B application in #1134. Local history shows ae9498546d initially added product-definition subject support in the spreadsheets, 86008a3206 constrained PlanDefinition.subject canonical targets to the five product-definition resources, and 55174ee020 re-applied those targets to the R4B StructureDefinition after a temporary tooling-related backout.

Additional context:
PlanDefinition is an active approved resource in source/fhir.ini. Later FHIR-37485 identified that the product-definition resources are not all canonical resources, so commit 3cef25612a moved them from PlanDefinition.subjectCanonical to subjectReference and left canonical limited to EvidenceVariable; a separate reconciliation commit for FHIR-37485 aligned the remaining prose and mirrored source metadata. The current source therefore no longer matches the older canonical-target implementation literally, but it preserves the approved FHIR-28432 capability using the correct Reference choice.
