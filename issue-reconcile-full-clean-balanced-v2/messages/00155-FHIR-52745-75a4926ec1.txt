FHIR-52745: Audit external choiceOrientation scope

Issue request:
FHIR-52745 was an Applied FHIR-core / FHIR-I change request, resolved Persuasive with Modification, asking that the questionnaire-choiceOrientation extension allow R5-and-later choice questions using all Questionnaire.item.answerOption data types rather than only Coding. The accepted resolution said to broaden the context constraint to exclude only group and display items and to add a note that the extension is meaningful only when the item has a constrained list of permitted answers.

Initial application:
No active core source definition for questionnaire-choiceOrientation exists in this checkout. Core source/fhir.ini has active Questionnaire resources and active profile spreadsheets, but searches found this extension only in source/oids.ini and historical release bundles. The active StructureDefinition is in the FHIR Extension Pack. There, commit 424aae2 added a broader contextInvariant for FHIR-52745, and commit a7598a2 adjusted the FHIRPath from type.exists() to type.hasValue().

Additional context:
FHIR-51643 first identified that the old contextInvariant was version-specific and inappropriate for R5. The linked Zulip post asked the questionnaire community whether removing the invariant entirely made sense. FHIR-56057 is a later Published FHIR-extensions decision for the same StructureDefinition; it says to remove the context expression entirely and keep the explanatory constrained-list note, so that later decision should govern any future Extension Pack source reconciliation. Current Extension Pack master retains the note but also retains a contextInvariant after the FHIR-52745 application.
