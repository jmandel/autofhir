FHIR-28086: Correct packaged product R5 change target

Issue request:
FHIR-28086 was a Published FHIR-core BR&R change request resolved as Persuasive for R5. It asked to broaden the former MedicinalProductPackaged/PackagedProductDefinition scope beyond medicinal products by adding a type CodeableConcept, expanding PackagedProductDefinition.package.containedItem.item references to BiologicallyDerivedProduct and NutritionProduct, and updating resource text that was limited to medicinal products.

Initial application:
The issue was explicitly applied in git commit d72f0cd65b, which updated the PackagedProductDefinition introduction, added PackagedProductDefinition.type, expanded contained-item targets to BiologicallyDerivedProduct and NutritionProduct, and added biological/nutrition search parameters. Subsequent source refactors moved the spreadsheet-era changes into the current StructureDefinition XML and search-parameter bundle, and later commits renamed package to packaging and converted the contained-item element to CodeableReference while preserving the added target profiles.

Additional context:
The current fhir.ini lists PackagedProductDefinition as an active BR&R current-build resource with normative standards status, and the current resource source already contains the requested type, package-type value set/code system, broadened contained-item target profiles, biological and nutrition search parameters, and scope narrative. BR&R minutes from 2020-07-28 record approval of FHIR-28086 by 17-0-0. During the build-scope check, the active [r5-changes] map still pointed the old R4 resource name MedicinalProductPackaged to ProductPackagedDefinition, a non-existent current resource name; the correct current resource is PackagedProductDefinition.

AutoFHIR reconciliation:
This commit corrects the remaining active R5 change-map reference in source/fhir.ini from ProductPackagedDefinition to PackagedProductDefinition. No model, terminology, search-parameter, or narrative edits were needed because those parts already reflect the published issue and later source refactors.

Recommendation:
Keep this commit as-is. It preserves the already-applied model and narrative changes while fixing the only current-build reference problem found for the old MedicinalProductPackaged artifact. A separate audit can address any other unrelated r5-changes medication-definition mapping typos.
