FHIR-13367: Audit dragon warning mechanism

Issue request:
FHIR-13367 was a Published FHIR-core STU3 change request resolved Persuasive with Modification. It asked for a dragon-style graphic to highlight implementation challenges, especially safety, security, and privacy notes, with category indexing if practical.

Initial application:
The issue appears to have been applied by git commit e0fb4dcd4e8de6a68f5c9e68dfd37b64ab9b1007, the git-svn import of SVN revision 14473 cited in Jira. That commit created tools/macros/dragons-start.html and tools/macros/dragons-end.html, taught the old PageProcessor to load macro HTML from tools/macros, and added a first dragon warning around break-the-glass guidance.

Additional context:
The current source still contains the dragon macro and active dragon warning blocks across core narrative/resource pages such as HTTP, security, search, JSON, FHIRPath, versions, Resource notes, ValueSet notes, ImplementationGuide notes, and DeviceAlert. The current Clinical Safety page and active safety-entries CodeSystem provide the central implementer checklist that covers safety, privacy, and security concerns. Later Jira and Zulip evidence shows the dragon mechanism continues to be curated at the individual-warning level; a 2026 core request, FHIR-55557, asks for clearer dragon meaning but remains Submitted and is not a final decision for this run.

AutoFHIR reconciliation:
This audit makes no source change. Reconstructing the original category/index proposal now would be a new tooling and editorial design change, not a necessary correction to the current FHIR source, and would overlap an unresolved later request about documenting dragon usage. The current build-scope source already has the practical warning mechanism created for this issue.

Recommendation:
Keep this no-change audit. If the work group wants reader-facing documentation, tooltip text, or a formal index of dragon warnings, handle that through the later open dragon-documentation issue or a new tooling decision rather than through this already-published STU3 tracker.
