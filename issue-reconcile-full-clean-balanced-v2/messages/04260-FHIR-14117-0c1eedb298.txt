FHIR-14117: Audit ResearchStudy location rename

Issue request:
FHIR-14117 was a Published/Persuasive BRR change request for STU3 ResearchStudy. It said the old "jurisdiction" element name should better reflect participating location; the final resolution recorded that the element was changed to "location" after FMG discussion and was published in the December 2017 FHIR ballot.

Initial application:
The historical ResearchStudy spreadsheet was first changed from ResearchStudy.jurisdiction to ResearchStudy.participatingLocation in git-svn commits d8f6af6f29 and 09e837eab3, with 09e837eab3 explicitly carrying GF#14117. The December 2017 ResearchStudy batch commit f09300abf4 then changed ResearchStudy.participatingLocation and its search parameter path/name to ResearchStudy.location, matching the Jira resolution.

Additional context:
A later Published/Persuasive with Modification BRR issue, FHIR-37641, revisited ResearchStudy.location for R5 and resolved to clarify that it is a broad geographic area rather than a precise address, rename the element to ResearchStudy.region, and update the short definition. Commit a7c2740146 implemented that rename in the active StructureDefinition, and commit 136aeb7fbf updated the ResearchStudy search parameter metadata to point at ResearchStudy.region.

AutoFHIR reconciliation:
No source change is made. In the current active ResearchStudy source, there is no ResearchStudy.jurisdiction or ResearchStudy.participatingLocation element to fix; the relevant element is ResearchStudy.region with the later approved definition, and only the BRIDG mapping still uses the external model name participatingLocationCode. Reverting or adding a location element now would conflict with FHIR-37641.

Recommendation:
Keep this audit commit as-is. The seed issue was applied historically and the current source is correct after the later FHIR-37641 rename; no core follow-up is recommended for FHIR-14117.
