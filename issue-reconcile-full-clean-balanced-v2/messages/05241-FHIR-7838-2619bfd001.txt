FHIR-7838: Audit MedicationStatement RXA-20 removal

Issue request:
FHIR-7838 was a Published/Persuasive Pharmacy change request from the DSTU1 ballot asking to remove the MedicationStatement.wasNotGiven HL7 v2 mapping to RXA-20 Completion Status='NA' because MedicationStatement is not MedicationAdministration and RXA mappings were not applicable.

Initial application:
The request was applied in historical commit 5bb461af1063efe577bac2b8b17b6992be7560bf, which removed the RXA-20 mapping for wasNotGiven and the adjacent RXA/RXR/RAS v2 mappings from the then-authoritative MedicationStatement spreadsheet sources.

Additional context:
MedicationStatement remains an active resource in source/fhir.ini. The current StructureDefinition source no longer has MedicationStatement.wasNotGiven, and its only retained HL7 v2 element mapping under MedicationStatement is the subject mapping to PID-3. Current non-use/adherence semantics are represented through MedicationStatement.adherence rather than the removed DSTU1 wasNotGiven element. Jira search found no separate RXA-20 MedicationStatement issue beyond FHIR-7838, and quoted Zulip/Confluence searches found no conflicting community record.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current source already satisfies the applied issue: the RXA-20 mapping is absent from MedicationStatement, and the remaining MedicationStatement v2 mapping does not reintroduce the RXA administration semantics the issue rejected.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-7838 unless a future Pharmacy review decides to revisit MedicationStatement's broader HL7 v2 mapping policy.
