FHIR-40704: Audit valueset-expression extension ownership

Issue request:
FHIR-40704 is an Applied/Persuasive Vocab change request asking to tidy the valueset-expression extension definition. The accepted resolution replaces the broken final clause about a server processing the value set with wording that the ValueSet definition (compose) can only be evaluated by a system that understands the expression syntax.

Initial application:
The core FHIR source had already moved this extension out of the core build before the Jira was applied: commit dd468d4f17 removed source/valueset/structuredefinition-extension-valueset-expression.xml as part of moving extension definitions out of R5 source. The Jira application happened in HL7/fhir-extensions PR #120; commit d97f79ca changed input/definitions/ValueSet/StructureDefinition-valueset-expression.xml only at StructureDefinition.description.

Additional context:
Current core build scope does not include a valueset-expression StructureDefinition source; source/fhir.ini lists active extension spreadsheets but not this ValueSet extension, and source/valueset/valueset-notes.xml only links to the Extension Pack and already uses the approved "evaluated by a system" concept. The current Extension Pack source and CI page show that the top StructureDefinition.description is corrected, while the differential root ElementDefinition.definition still carries the old "server... expression is computable" text and leaks into the formal extension table.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The authoritative source needing any further cleanup is in the HL7/fhir-extensions repository, which is outside this core FHIR worktree for this reconciliation run.

Recommendation:
Keep this audit commit as the core decision. If follow-up is desired, update HL7/fhir-extensions input/definitions/ValueSet/StructureDefinition-valueset-expression.xml so differential.element[id="Extension"].definition matches the corrected StructureDefinition.description/resolution text; no core FHIR source edit is indicated.
