FHIR-36014: Audit Encounter participant type value set

Issue request:
FHIR-36014 was a Published/Persuasive PA change request for R5 asking to remove the explicitly included v3 ParticipationType codes SPRF, PPRF, and PART from the Encounter participant type value set because PART was so broad that the extensible binding effectively became required.

Initial application:
The issue was applied by commit c212a82696a805aa56193730c5523eda878e9562, which removed the separate v3-ParticipationType include containing SPRF, PPRF, and PART from source/encounter/valueset-encounter-participant-type.xml. No prior reconcile commit for FHIR-36014 was present on the combined branch.

Additional context:
Encounter is an active current-build resource in source/fhir.ini, and Encounter.participant.type binds extensibly to http://hl7.org/fhir/ValueSet/encounter-participant-type. The current value set compose keeps the remaining includes and excludes only abstract/broad hierarchy anchors; it no longer explicitly includes SPRF, PPRF, or PART. FHIR-8376 is the historical issue that added those broad codes, but FHIR-36014 superseded that part of the earlier change. PA WGM minutes recorded the 8-0-0 persuasive vote and noted that existing systems using the removed codes would not be broken because the binding remains extensible.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current value set source already reflects the FHIR-36014 resolution, and the remaining Encounter examples that mention PPRF or PART do not re-add those codes to the value set or make the extensible binding required.

Recommendation:
Keep this audit commit as-is. If PA wants examples to avoid broad historical v3 ParticipationType codes as an editorial improvement, that should be handled by a new targeted tracker because FHIR-36014's value-set composition change is already applied.
