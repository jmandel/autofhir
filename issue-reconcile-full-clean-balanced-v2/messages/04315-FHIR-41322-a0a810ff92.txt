FHIR-41322: Audit Observation rejection guidance

Issue request:
FHIR-41322 was an Applied/Persuasive OO change request for FHIR-core Observation. It asked to rename section 10.1.5.9 from "Canceled or Aborted Observations" to "Cancelled or Not Performed Observations", clarify use of Observation.dataAbsentReason for tests not performed, and change dataAbsentReason/component.referenceRange wording from "result" to "result value" where the value is specifically Observation.value[x] or Observation.component.value[x].

Initial application:
The issue was applied before this reconciliation by commit 67b1a3d10a1a57d1013e4d8dcc612173e9b2f135 and merged by HL7/fhir#3045. That commit changed the Observation notes heading and the short definitions for Observation.dataAbsentReason, Observation.component.dataAbsentReason, and Observation.component.referenceRange. Current blame shows those FHIR-41322 lines still present.

Additional context:
Observation is an active resource in source/fhir.ini, so source/observation/observation-notes.xml and source/observation/structuredefinition-Observation.xml are in the current build scope. OO minutes on 2024-02-27 recorded that only the section header needed to change because the existing paragraph already contained the dataAbsentReason/specimen reject example guidance. Later Applied issue FHIR-51640 added explicit bullets for observations that will not or were not performed, reinforcing the same guidance without reversing FHIR-41322.

AutoFHIR reconciliation:

Recommendation:
Keep this no-change audit as-is. No FHIR-41322 follow-up is needed in core Observation; any broader DiagnosticReport or diagnostics-module coverage belongs to the later FHIR-51640 family rather than this seed issue.
