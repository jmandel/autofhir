FHIR-13910: Audit ChargeItem costCenter migration

Issue request:
FHIR-13910 was Published/Persuasive for STU3 and requested a new ChargeItem.costCenter 0..1 Reference(Organization|OrganizationRole) element to identify the organization owning the potential future revenue, with guidance that the reference could be either a concrete organization resource or an identifier carrying cost-center assignment details.

Initial application:
The request was applied in core by git commit 9dfd8e2352, which added ChargeItem.costCenter to source/chargeitem/chargeitem-spreadsheet.xml with cardinality 0..1, the requested short/definition/comment text, and an initial Reference(Organization|OrganizationRole) type. Later history refined the type: commit 4d4ee2b7bd removed OrganizationRole from the ChargeItem reference list, and commit 0b2790895e renamed/cleaned up OrganizationRole as OrganizationAffiliation.

Additional context:
ChargeItem is no longer an active core resource in the current FHIR build: source/fhir.ini has no active ChargeItem resource entry, and current module/workflow pages link ChargeItem to the HL7 admin-incubator IG. Commit 71567db3ee removed source/chargeitem and source/chargeitemdefinition from core while replacing local links with admin-incubator links. The current admin-incubator StructureDefinition-ChargeItem JSON still contains ChargeItem.costCenter 0..1 with the same short, definition, and identifier guidance, using Reference(Organization) after the later OrganizationRole cleanup.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the core checkout. The historical core request was applied, and the current authoritative ChargeItem artifact belongs to the admin-incubator IG rather than this core build.

Recommendation:
Keep this audit as an external-repo decision for core. Future changes to ChargeItem.costCenter should be made against the admin-incubator source/ownership process; broadening the target to OrganizationAffiliation would need a new PA work-group decision rather than resurrecting the original STU3 OrganizationRole text in core.
