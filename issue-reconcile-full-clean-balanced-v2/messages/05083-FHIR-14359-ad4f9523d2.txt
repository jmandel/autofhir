FHIR-14359: Audit SNOMED ECL implicit value set syntax

Issue request:
FHIR-14359 was Published/Persuasive for STU3. It asked to align the SNOMED CT ECL implicit ValueSet URI with the existing implicit URI formats by changing the separator from ?fhir_vs=ecl:[ecl] to ?fhir_vs=ecl/[ecl], matching the slash style already used by ?fhir_vs=isa/[sctid] and ?fhir_vs=refset/[sctid].

Initial application:
The issue was pre-applied in SVN r13310, now git commit 9fe99d788004f20048165682a9ff7d64bc23c01d. That commit explicitly references GF#14006 and GF#14359 and changed source/snomedct.html from ?fhir_vs=ecl:[ecl] to ?fhir_vs=ecl/[ecl] in both the list of SNOMED CT implicit value set URL forms and the ECL template URL.

Additional context:
FHIR-14006 introduced the ECL implicit ValueSet URI and is the same change family; its Jira comments explain that the first pre-application used ?fhir_vs=ecl:[ecl] and that r13310 corrected it. Zulip discussion supported using ecl/ for consistency. Vocab minutes for 2018-02-22 record GF#14006 and related GF#14359 in a block vote that carried 7-0-0. Later, FHIR-35933 commit 81e5862f203fdb8a03e9c943a7cf455aba8973f4 removed source/snomedct.html and other external terminology detail pages from the core build, changing source/terminologies-systems.html to link to THO's SNOMED CT guidance while retaining only the local SNOMED CT Usage Report in source/hierarchy.xml. Current core source no longer contains ?fhir_vs=ecl: or ?fhir_vs=ecl/ text; the linked THO page at https://terminology.hl7.org/en/SNOMEDCT.html documents ?fhir_vs=ecl/[ecl].

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical core source applied the requested syntax correction, the current core build no longer owns the detailed SNOMED CT implicit ValueSet page, and the external THO guidance currently linked from core already uses the aligned ecl/ syntax.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core source follow-up is needed for FHIR-14359. If the SNOMED CT implicit ValueSet wording needs future maintenance, do it in the THO source that produces terminology.hl7.org/SNOMEDCT.html rather than recreating the removed core page.
