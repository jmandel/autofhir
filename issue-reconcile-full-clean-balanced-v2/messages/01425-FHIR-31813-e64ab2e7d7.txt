FHIR-31813: Audit specifiedSubstance removal

Issue request:
FHIR-31813 was a Published/Persuasive with Modification BR&R change request for the R4 MedicinalProductIngredient/Ingredient model. The issue said the definition of specifiedSubstance was not sufficient to explain how a specified substance differed from a substance. The final resolution said current IDMP need was unclear, PQ/CMC was not using it, and the specifiedSubstance backbone element should be dropped from Ingredient, with a possible extension later if needed.

Initial application:
The change was explicitly applied before this reconciliation. Jira records that it was applied in the R4B branch and main build. Git history contains 6b369be0a3586b4327b7be45bb93e65c344f66e0 and the parallel branch commit 5730009f8bc3d8edcbaba2bbf979741b55017c7b, both titled "removed ingredient.specifiedSubstance FHIR#31813, FHIR#31815, FHIR#31816, FHIR#31876". Those commits removed Ingredient.specifiedSubstance, its specified-substance search parameters, and the specified-substance example, while making Ingredient.substance mandatory.

Additional context:
Ingredient is an active current-build resource in source/fhir.ini, and the old MedicinalProductIngredient name redirects to Ingredient. FHIR-31815, FHIR-31816, and FHIR-31876 are the same modeling family: FHIR-31815 became no-change because the remodeling made mutual exclusivity unnecessary, FHIR-31816 asked to address multiple specified substances, and FHIR-31876 asked to collapse duplicate substance/specifiedSubstance modeling. The combined branch already contains separate reconciliation commits for FHIR-31816 and FHIR-31876, so this commit does not duplicate those decisions. Zulip background shows the old specifiedSubstance explanation was confusing and edge-case oriented; BR&R minutes record the FHIR-31813 vote and later minutes confirm that the Substance/SpecifiedSubstance model had been simplified.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Ingredient StructureDefinition has a single Ingredient.substance backbone element with cardinality 1..1 and no Ingredient.specifiedSubstance or Ingredient.specificSubstance element. Ingredient search parameters and examples no longer expose specified-substance surfaces, and the current FHIR ModelInfo content no longer exposes a MedicinalProductIngredient.specifiedSubstance element after the already-published FHIR-31816 cleanup. The remaining "Specified Substance.Strength" text in Ingredient is an IDMP mapping label on Ingredient.substance.strength, not a FHIR backbone element or definition that preserves the removed model.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source follow-up is needed for FHIR-31813 unless BR&R later decides to introduce a new extension or other explicit model for specified-substance details.
