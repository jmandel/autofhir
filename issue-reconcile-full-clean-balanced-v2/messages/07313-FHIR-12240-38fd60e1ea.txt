FHIR-12240: Audit applied microbiology examples

Issue request:
FHIR-12240 is Published / Persuasive with Modification. It asked OO to update the Culture and susceptibility examples to reflect the OO-on-FHIR microbiology pattern, add the referenced LRI example, keep/update the existing C&S example, and seek community input because examples are guidance rather than normative content.

Initial application:
The issue was applied before this reconciliation. Commit 3f524db8d8 added the LRI culture-and-susceptibility example and expanded the DiagnosticReport examples header/spreadsheet, and commit 5cea064fde fixed the new example link. Later FHIR-13567 work converted contained DiagnosticReport examples, including the micro example family, into Bundle-shaped examples, so the current LRI source is now bundle-lri-example.xml.

Additional context:
DiagnosticReport and Observation are active current-build resources. The current DiagnosticReport example list publishes both DiagnosticReport/micro and Bundle/lri-example, and the current examples header points readers to the Diagnostics Module for the parent/child microbiology guidance. Later FHIR-39168/FHIR-40540 replaced the older examples-page prose and diagrams with module-level DiagnosticReport/Observation organization guidance; those issues are already represented on the combined branch. Zulip micro/culture discussions show ongoing debate and possible future AMR refinements, but no final later decision requiring a FHIR-12240 source change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested example addition/update is present in build-scoped source, and the current page structure avoids stale local prose by delegating evolving parent/child guidance to the Diagnostics Module.

Recommendation:
Keep this audit commit as-is. Future changes to microbiology/AMR example semantics should be handled under specific later OO decisions rather than reopening FHIR-12240.
