FHIR-8264: Audit List query guidance

Issue request:
FHIR-8264 was a Published / Not Persuasive with Modification DAF ballot issue asking to represent DAF data as queries rather than Lists. The accepted modification was to add List resource guidance explaining how querying base resources differs from querying Lists and List contents, including when each approach may be appropriate.

Initial application:
The issue appears to have been applied before reconciliation. Git history first shows 4c165166306200a13e982396e0d2e9c4962a0ea7 adding a concise List-vs-resource-endpoint paragraph to source/list/list-introduction.xml for comment 8264, then f9e07521d60b40df99e9e760f7aee858daaa66c1 adding the dedicated "Querying Lists vs. the underlying resources" section to source/list/list-notes.xml with the tradeoffs requested by the Jira resolution.

Additional context:
The current build scope includes List as an active resource in source/fhir.ini. Current source/list/list-notes.xml still contains the dedicated guidance describing three retrieval options, un-curated resource endpoint results, curated Lists, Current resource lists, and the need for clients to adapt by environment. Current source/list/list-introduction.xml also summarizes the curated point-in-time List behavior versus current non-curated endpoint searches. Corrected Zulip and Confluence searches for FHIR-8264, DAF List queries, and the exact guidance heading found no conflicting community evidence.
