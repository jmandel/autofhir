FHIR-5761: Audit MedicationStatement precondition guidance

Issue request:
FHIR-5761 was Published/Persuasive with Modification for DSTU1 Pharmacy. It asked whether C-CDA medication preconditions should be represented on relevant FHIR pharmacy resources, and the final disposition was to clarify the existing as-needed CodeableConcept comments and binding text for MedicationOrder/MedicationPrescription, MedicationDispense, and MedicationStatement rather than add a new element.

Initial application:
The issue was explicitly applied by git commit b5078c273e9d98521d581ade1ccba94c469cadae, which changed the dosageInstruction.asNeeded wording for MedicationOrder, MedicationDispense, and MedicationStatement and updated the MedicationAsNeededReason binding text to describe a precondition that should be met or evaluated before a dose.

Additional context:
MedicationOrder became MedicationRequest, and later refactors moved the shared medication dosage semantics into the active Dosage/DosageDetails datatypes used by MedicationRequest, MedicationDispense, and MedicationStatement. Later Pharmacy decisions FHIR-34325 and FHIR-41267 split the old asNeeded[x] choice into Dosage.asNeeded plus 0..* Dosage.asNeededFor and clarified the false/PRN comments; those later issue-reconcile commits are already present on the combined branch.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. In current build-scope source, MedicationStatement.dosage is active and typed as DosageDetails; DosageDetails contains Dosage components; Dosage.asNeededFor is a CodeableConcept bound to MedicationAsNeededReason and says it represents one or more preconditions for taking the medication. The binding text still describes the precondition that should be met or evaluated before consuming or administering a medication dose.

Recommendation:
Keep this no-change audit commit. The current source preserves the FHIR-5761 semantics after later datatype refactors, and adding resource-local duplicate text would risk drift from the shared Dosage definition.
