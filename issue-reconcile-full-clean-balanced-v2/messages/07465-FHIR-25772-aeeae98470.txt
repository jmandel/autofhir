FHIR-25772: Audit local package dependency support

Issue request:
FHIR-25772 was a Published/Persuasive FHIR-I change request asking FHIR package.json dependencies to support npm-style local path dependencies such as file:/local/path, with the resolved scope to support absolute or relative local paths and update the NPM Package specification while not requiring HL7 package stack or package-server support.

Initial application:
The issue was applied by commit 843626fb5d (FHIR-25772: Local Package dependencies), which updated source/packages.html in the package.json dependencies row to say that development packages may use a local path for the package version and linked to npm Local Paths documentation.

Additional context:
The package page is in current build scope through source/hierarchy.xml and source/documentation.html. FHIR-I WGM minutes and the contemporaneous Zulip tooling thread match the Jira resolution: local paths were allowed for development/private use, but public HL7 package infrastructure was not expected to support them.

AutoFHIR reconciliation:
No source change was made. Current source already tells package authors that development packages may use local paths for dependency versions and points to the npm local-path syntax that covers file: relative and absolute paths; adding package-server caveats would be operational guidance beyond the current source correction needed for this issue.

Recommendation:
Keep this audit commit as-is. Revisit only if the work group wants a separate policy statement about packages.fhir.org or CI-build behavior for packages containing local-path dependencies.
