FHIR-38814 was Published/Persuasive for R5 and asked to change TestScript.profile from Reference(Resource) to canonical(StructureDefinition), because the element was intended to identify a FHIR profile by canonical URL.

Initial application:

The R5 published TestScript profile JSON exposes that same canonical(StructureDefinition) type.

Additional context:
Current core source no longer contains source/testscript, source/testreport, or source/testplan resource definitions. Recommendation:
Keep this audit commit as-is. No current FHIR core source follow-up is needed for FHIR-38814 unless the testing resources are reintroduced into the core build; if that happens, the reintroduced TestScript.profile definition should retain canonical(StructureDefinition).
