FHIR-20583: Add Provenance entity.what element example

Issue request:
FHIR-20583 was a Published/Persuasive FHIR-core Provenance change request asking for guidance and examples for two element-level Provenance scenarios: Provenance.target pointing at a target element, and Provenance.entity.what pointing at a specific source element such as a Claim or ExplanationOfBenefit line item. The final resolution said to add examples to the Provenance page using the core extensions defined by GF#21284.

Initial application:
FHIR-21284 appears to have been initially applied by commit 38993a71ef, which added targetElement and targetPath extension definitions for Reference. Commit b84bf92092 then added Provenance examples 1-3 using those extensions on Provenance.target, and commit 6e01cea5c6f later added Provenance narrative for target-level element Provenance. Later commits refined that target narrative and added another target-level example, but the current active Provenance source still had no example using targetElement or targetPath on Provenance.entity.what.

Additional context:
FHIR-23076 is the same change family for Provenance target narrative and is already reflected by the target-level note and examples. The targetElement and targetPath definitions now live in the FHIR Extension Pack and declare context Reference, so using targetPath on Provenance.entity.what is within the approved extension scope. The source/fhir.ini configuration lists Provenance as an active resource, and the Provenance example list is the active source for built Provenance examples. Zulip discussion in 2021 explicitly observed that the then-new examples addressed the first FHIR-20583 use case and that the second was the same extension pattern in .entity.

AutoFHIR reconciliation:
This commit adds provenance-example7, which shows a Procedure target derived from a specific Claim line item by placing the targetPath extension on Provenance.entity.what. It registers that example in list-Provenance-examples.xml and extends the Element Level Provenance note to point readers from Provenance.entity.what to the new example.

Recommendation:
Keep this source change. It completes the missing source-side example for FHIR-20583 without changing the extension definitions, which are already valid for any Reference. Future work can refine the clinical scenario if a work group wants a richer Claim or ExplanationOfBenefit example, but the current build now covers both requested Provenance patterns.
