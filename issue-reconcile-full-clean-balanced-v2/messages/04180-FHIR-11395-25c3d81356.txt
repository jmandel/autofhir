FHIR-11395: Audit EOB missing-teeth removal

Issue request:
FHIR-11395 is a Published/Persuasive with Modification FM issue from the DSTU2 ballot asking whether ExplanationOfBenefit MissingTeeth should instead be represented as an Observation placed in the proposed information/clinical area. The accepted resolution was that missing teeth can be represented in Claim.information and that the missing-teeth elements should be removed.

Initial application:
The historical application appears in commit aaa1e5693e365bca976f7aa2115c85a0f2293a38, which handled Tracker #7901, #11373, #11395, and #12356 together. For ExplanationOfBenefit it disabled the old ExplanationOfBenefit.missingTeeth, .tooth, .reason, and .extractionDate rows and added ExplanationOfBenefit.information.reason using the MissingReason binding; later resource refactoring renamed information to supportingInfo.

Additional context:
The same application batch included the parallel Claim missing-teeth issues FHIR-7901 and FHIR-11373, and FHIR-12356 supplied the supporting information payload/reason pattern for Claim and ExplanationOfBenefit. FHIR-12356 is already represented on the combined branch. Current active source still has a stale QUICK Claim-only MissingTeeth model surface, but no ExplanationOfBenefit MissingTeeth surface was found; the Claim cleanup belongs with the parallel Claim issues rather than this EOB seed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active ExplanationOfBenefit resource is in the current build, exposes supportingInfo.value[x] and supportingInfo.reason for additional supporting information and missing-tooth rationale, and no longer defines ExplanationOfBenefit.missingTeeth or related child elements in the EOB source or QUICK model content.

Recommendation:
Keep this audit commit as-is for FHIR-11395. If maintainers want to remove the stale QUICK Claim.missingTeeth metadata, reconcile FHIR-7901 and/or FHIR-11373 separately so the Claim-specific source change has the correct issue key and audit trail.
