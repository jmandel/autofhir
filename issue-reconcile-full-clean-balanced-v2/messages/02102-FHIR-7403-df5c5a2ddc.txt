FHIR-7403: Clarify CDA comparison section narrative

Issue request:
FHIR-7403 was Published with resolution Persuasive with Modification. It reported that the FHIR/CDA comparison's human-readable text discussion was inaccurate because it described FHIR narrative as being on a resource pointed to by a section and asked that the language be updated per the companion FHIR-7404 task.

Initial application:
The issue was initially applied in git-svn commit 3e3d711ca1ec6ff4ed21ee014d3c4c6a2b82071c / svn revision 6204, which removed the original paragraph saying FHIR text lived on the resource the section points to. That removed the exact challenged wording, but the active comparison page still had a separate Human readable granularity paragraph saying FHIR narrative only exists on resources at the root of each section and that FHIR container sections cannot have narrative.

Additional context:
FHIR-7404 changed the document model to carry attested section narrative in Composition.section.text with Composition.section.entry references for supporting data. Current source confirms comparison-cda.html is active in publish.ini and hierarchy.xml, and Composition.section.text / Composition.section.entry are the current build artifacts. Later Documents guide wording, including FHIR-15723, also treats the document presentation as subject, Composition, and section.text narratives rather than List or section.content resource narratives.

AutoFHIR reconciliation:
Updated source/comparison-cda.html to describe CDA section narrative versus FHIR Composition.section.text narrative, including nested sections, and to state that Composition.section.entry references supporting resources. This removes the stale statement that FHIR container sections cannot have narrative.

Recommendation:
Keep this commit as-is. It is a focused correction to an active informative comparison page and aligns the page with the applied FHIR-7404 document narrative model.
