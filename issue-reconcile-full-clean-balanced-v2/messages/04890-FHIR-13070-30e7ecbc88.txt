FHIR-13070: Audit ValueSet filter modifier removal

Issue request:
FHIR-13070 was Published with a Persuasive resolution agreeing that ValueSet.compose.include.filter should not be a modifier because a filter does not modify the meaning of include/exclude beyond specifying the selected concepts.

Initial application:
The request was applied by git commit 00093bc6b3 (svn r13318), which removed the modifier flag from ValueSet.compose.include.filter in source/valueset/valueset-spreadsheet.xml.

Additional context:
FHIR-8726 had previously made ValueSet.compose.include.filter a modifier, but FHIR-13070 superseded that older decision. FHIR-15586 later repeated the same ValueSet outcome while adding a separate ConceptMap isModifierReason. The current ValueSet StructureDefinition is active in source/fhir.ini and still omits isModifier from ValueSet.compose.include.filter.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already implements the FHIR-13070 removal and remains aligned with the later FHIR-15586 confirmation.

Recommendation:
Keep this audit as-is. No follow-up source work is needed for ValueSet.compose.include.filter unless a new work-group decision changes its modifier status again.
