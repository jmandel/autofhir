FHIR-12899: Audit MedicationAdministration request rename

Issue request:
FHIR-12899 was a Published Pharmacy change request with resolution Persuasive with Modification. It asked how MedicationAdministration could link an administration to a prescription/order, an instance-order MedicationRequest, and related care plan context; the approved action was to rename MedicationAdministration.prescription to MedicationAdministration.request and update documentation so the element could reference a MedicationRequest with intent order or instance-order.

Initial application:
The issue was applied in git commit fb85e74cbc7631131c5e76eb713022eae4cd0de5, which renamed the spreadsheet element and search parameter from prescription to request, added the order/instance-order comment, and updated MedicationAdministration examples from <prescription> to <request>. Current source has no remaining MedicationAdministration.prescription element or search parameter.

Additional context:
MedicationAdministration is active in source/fhir.ini, so source/medicationadministration/structuredefinition-MedicationAdministration.xml and the colocated search parameter/example sources are in current build scope. Later Published issue FHIR-27019 revisited request versus basedOn and confirmed request points to the authorizing request/order while basedOn points to a care plan; that related issue is already represented on the combined branch and does not call for another FHIR-12899 source edit.

AutoFHIR reconciliation:
Made no source change. The current active StructureDefinition uses MedicationAdministration.request, its comment explicitly allows MedicationRequest intents order and instance-order, the request search parameter is named and expressed against MedicationAdministration.request, and examples use <request> rather than the retired <prescription> element.

Recommendation:
Keep this empty audit commit as-is. The seed issue is already correctly reflected in current core source, and FHIR-27019 should remain the separate later-change record for basedOn wording rather than being duplicated here.
