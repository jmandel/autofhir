FHIR-6171: Audit Flag subject scope

Issue request:
FHIR-6171 was a Published FHIR-core Flag change request with a Not Persuasive with Modification resolution. It asked to relax Flag.patient from 1..1 to 0..1 for non-patient flag use cases; the final decision instead kept a mandatory subject, renamed patient to subject, allowed Location, Group, Organization and Practitioner (per the application comment), broadened the narrative, and retained patient search while adding subject search.

Initial application:
The issue appears to have been applied in git-svn commit b56250f4bf (#6171), which changed the example from patient to subject and changed the Flag source spreadsheet/introduction to open up flag.subject. Follow-up commit 4f011f662a rewrote Flag scope and usage to describe Patient, Location, Practitioner, and Group subjects, matching Jira's note that introduction and notes still needed work; later QA commits cleaned wording.

Additional context:
Flag is an active core resource in source/fhir.ini. Later applied Flag issues expanded the same subject target set (FHIR-10083 added PlanDefinition/Medication/Procedure examples, FHIR-20380 added PractitionerRole, and FHIR-37950 added RelatedPerson), which explains why the current target list is broader than FHIR-6171 without contradicting it. Zulip and Confluence searches for FHIR-6171 plus Flag patient/subject terms did not find conflicting community guidance.
