FHIR-24680: Audit DeviceUsage body structure move externally

Issue request:
FHIR-24680 is a Published/Persuasive with Modification OO change request for R5. It asked to change DeviceUseStatement.bodySite from CodeableConcept to a BodyStructure-capable representation so implementers could provide more detail than a single body-site code; the approved resolution proposed bodySite[x] with CodeableConcept and Reference(BodyStructure), and the Jira comment noted the emerging CodeableReference datatype.

Initial application:
The issue was applied before this reconciliation in the DeviceUseStatement spreadsheet history. Commit ce5720447c explicitly names FHIR-24680 and changes DeviceUseStatement.bodySite from CodeableConcept to CodeableReference(BodyStructure); commit 8e3a45ff18 keeps that shape while completing the DeviceUseStatement updates. Later retained source/deviceusage/structuredefinition-DeviceUsage.xml represents the element as DeviceUsage.bodyStructure with type CodeableReference targeting BodyStructure.

Additional context:
FHIR-26308 later accepted the implicit/pre-applied DeviceUsage changes made while addressing FHIR-24680 and neighboring DeviceUseStatement issues. FHIR-53203 subsequently moved OO body-site style elements toward bodyStructure CodeableReference and renamed DeviceUsage.bodySite to DeviceUsage.bodyStructure. Most importantly for this core reconciliation, commit 3b38b80cf2 removed DeviceUsage from active source/fhir.ini resource/build lists and changed the core device module to point DeviceUsage readers to the OO Incubator IG. The current core fhir.ini has no active DeviceUsage resource entry; DeviceUseStatement appears only as a historical rename to DeviceUsage. The OO Incubator continuous-build package currently exposes DeviceUsage.bodyStructure as CodeableReference(BodyStructure), though its requirements prose still carries an older bodySite-extension sentence that should be handled in the external source if the work group wants that cleaned up.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source files were changed because DeviceUsage/DeviceUseStatement is outside the active FHIR core build scope; editing retained source/deviceusage files would not correct the current core specification, and the active core module already links DeviceUsage to the OO Incubator artifact.

Recommendation:
Keep this audit commit as-is for the core reconciliation. If further cleanup is desired, update the OO Incubator DeviceUsage source to align the bodyStructure requirements prose with the CodeableReference(BodyStructure) type rather than editing inactive core source/deviceusage files.
