FHIR-17228: Audit Observation supporting context handling

Issue request:
FHIR-17228 was a Published STU3 FHIR-core Observation change request resolved Persuasive with Modification. It asked for support for contextual information needed to interpret an Observation, and the final disposition chose an Observation-scoped 0..* precondition extension referencing Observation, with notes guidance to be handled in a follow-up tracker.

Initial application:
The issue was applied in historical commit 4b3545da2a5d, which added the observation-precondition extension to the then-core Observation extension spreadsheet with the requested Observation context, Reference(Observation) value, short description, and definition. The related notes-guidance tracker FHIR-17578 was applied in commit 1c6e2d841cd2 by adding the Observation notes refinement section that described using codes, components, and the new precondition extension.

Additional context:
Core no longer carries that extension source: the R5 extension-removal work moved general extensions out of this checkout, and the current observation-precondition definition is in the FHIR Extension Pack. Later applied decisions changed how current core should represent this use case. FHIR-38971 clarified that observation-precondition should not be a modifier extension and changed its wording from "correctly interpret" to "understand the context and significance". FHIR-42899 then made the extension version-specific through R5 and directed post-R5 users to Observation.interpretationContext, while FHIR-51529 added Observation.interpretationContext as a current R6 core element. The active Observation source and notes now point users to that element for critical preceding or concurrent context not represented by Observation grouping.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original FHIR-17228 extension request was historically applied, the extension now belongs to the FHIR Extension Pack rather than this core checkout, and current core source already contains the superseding Observation.interpretationContext element plus Observation notes guidance.

Recommendation:
Keep this audit commit as-is for core. Do not re-add observation-precondition to the core source; current core should continue using Observation.interpretationContext, with the Extension Pack retaining the pre-R6 extension definition.
