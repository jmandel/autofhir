FHIR-28282: Audit adjusted analysis support

Issue request:
FHIR-28282 was a Published/Persuasive CDS change request for R5. It asked to adjust EvidenceVariable and Statistic for adjusted analysis: rename EvidenceVariable.type to handling, add EvidenceVariable.category, revise the variable-handling value set, add Statistic model code terms, rename StatisticStatisticType to StatisticType, and add Statistic.modelCharacteristic.variable so adjusted analyses can list variables instead of using modelCharacteristic.value[x].

Initial application:
The request was pre-applied by the August 2020 merge commit c7c7e23e42bc614e9429471e7ec54e701fe38423 / PR #971, which changed the EvidenceVariable resource and Statistic datatype sources. The historical diff shows the StatisticType binding name, Statistic.modelCharacteristic.variable subtree, variable-handling terminology, adjusted model-code terms, and EvidenceVariable.handling/category additions.

Additional context:
Later final decisions changed the shape without reversing the seed. FHIR-31866 reincorporated Statistic into the Evidence resource and removed the standalone Statistic datatype. FHIR-51456 and FHIR-52949 changed EvidenceVariable.handling and Evidence.statistic.modelCharacteristic.variable.handling from required code bindings to CodeableConcept bindings. FHIR-53156 then changed these EBMonFHIR-owned bindings to example strength and renamed the local terminology to variable-handling-example, while FHIR-39632 moved reusable statistic terminology toward THO. Confluence evidence records FHIR-28282 as already applied for R5 and found no contrary community direction.

AutoFHIR reconciliation:
No source change was made. The active build includes EvidenceVariable and Evidence, not a standalone Statistic datatype, and the current source preserves the seed semantics in the current R6 model: EvidenceVariable.handling, EvidenceVariable.category, Evidence.statistic.modelCharacteristic.variable, variableDefinition/handling/valueCategory/valueQuantity/valueRange, and StatisticModelCode/StatisticType bindings are present in active resource StructureDefinitions.

Recommendation:
Keep this no-change audit commit. Reopen only if the work group wants to revisit the later EBMonFHIR terminology binding decisions or THO migration work; FHIR-28282 itself is already represented correctly in the current core build.
