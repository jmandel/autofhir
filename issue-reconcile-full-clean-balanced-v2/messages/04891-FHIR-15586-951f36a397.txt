FHIR-15586: Audit modifier reason reconciliation

Issue request:
FHIR-15586 was Published with a Persuasive with Modification resolution for STU3 vocabulary resources. It asked to document why ConceptMap.group.element.target.equivalence was a modifier, specifically because of no-mapping relationship values such as disjoint/unmapped, and to remove the isModifier flag from ValueSet.compose.include.filter.

Initial application:
The Jira-tagged application was git commit eb861d334d (svn r14643), which updated source/conceptmap/conceptmap-spreadsheet.xml with a ConceptMap modifier reason explaining that some values, particularly disjoint, mean there is no mapping and the mapping cannot be interpreted without the value. The ValueSet removal portion had already been applied by FHIR-13070 in git commit 00093bc6b3, which removed the ValueSet.compose.include.filter modifier flag.

Additional context:
ConceptMap was redesigned after STU3. FHIR-22632 renamed ConceptMap.group.element.target.equivalence to ConceptMap.group.element.target.relationship and introduced the current relationship code system. Later current-source text records the rename, and the active ConceptMap relationship codes now use not-related-to for the no-mapping case. The current ConceptMap StructureDefinition carries an isModifierReason on ConceptMap.group.element.target.relationship that explains not-related-to means no mapping. The current ValueSet StructureDefinition has no isModifier on ValueSet.compose.include.filter. Both ConceptMap and ValueSet are active resources in source/fhir.ini. Exact FHIR-15586 Zulip and Confluence searches found no conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already carries the needed ConceptMap modifier reason on the successor relationship element and already omits the ValueSet filter modifier flag.

Recommendation:
Keep this audit as-is. No source follow-up is needed unless the work group later changes the ConceptMap relationship code semantics or ValueSet filter modifier status.
