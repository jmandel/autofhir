FHIR-37758: Audit GenomicStudy changeType binding

Issue request:
FHIR-37758 is a Published Clinical Genomics R5 change request resolved Persuasive with Modification. It asked to add terminology support for GenomicStudy.analysis.changeType; the final resolution requested a new example CodeSystem and ValueSet with DNA, RNA, AA, CHR, and CNV change-type codes.

Initial application:
The issue was first applied in commit e9225d72a12b by adding DNA/RNA/amino-acid examples to the GenomicStudy.analysis.changeType definition. The full terminology application followed on the genomicStudy_terminologyBinding branch: f74554c0ff63 added the genomicstudy-changetype CodeSystem, 40b99a801c28 wired the matching ValueSet, ff3c60841406 added the example binding on GenomicStudy.analysis.changeType, and PR #2116 merged that work in ff7c5cbbec68.

Additional context:
The retained GenomicStudy source still has the requested example binding to http://hl7.org/fhir/ValueSet/genomicstudy-changetype, with corresponding CodeSystem and ValueSet files containing the requested codes. The R5 published StructureDefinition and release5 history artifacts expose the same binding and terminology. Current source/fhir.ini no longer includes GenomicStudy in the active resource/build-scope entries after the 2025 remove-additional-resources change, so editing retained GenomicStudy source would not be a current-build correction. FHIR-37759, the same terminology-binding family for input/output data format, is already represented on the combined branch.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested R5 change is already present in retained source and the published R5 artifact, and the artifact is outside current core build scope.

Recommendation:
Keep this audit commit as-is. Do not edit the inactive core GenomicStudy source for this issue unless GenomicStudy is reintroduced to the current build; if that happens, preserve the existing changeType CodeSystem, ValueSet, and example binding unless the Clinical Genomics work group makes a newer terminology decision.
