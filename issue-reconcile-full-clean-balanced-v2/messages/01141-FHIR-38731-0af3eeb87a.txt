FHIR-38731: Audit Appointment cancellationDate

Issue request:
FHIR-38731 was a Published/Persuasive PA change request for R5 asking to add Appointment.cancellationDate immediately after Appointment.created as a 0..1 dateTime with the short "When the appointment was cancelled" and definition "The date/time describing when the appointment was cancelled." It also requested an invariant like app-4 requiring cancellationDate only when status is noshow or cancelled, and an update to the rejection/cancellation flow indicating cancellationDate should be set when an appointment is cancelled.

Initial application:
The request was applied before this reconciliation by 4c9aaa5a7e73955b2c066974523dd1300f24c75a, which added Appointment.cancellationDate and updated the rejection/cancellation narrative.
