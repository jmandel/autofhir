FHIR-19495: Audit PaymentNotice attribute cleanup

Issue request:
FHIR-19495 was a Published/Persuasive Financial Management change request for STU3 PaymentNotice. It asked to remove redundant PaymentNotice.statusDate and PaymentNotice.provider attributes after ballot-added fields made them redundant, and to rename PaymentNotice.target to PaymentNotice.recipient.

Initial application:
The Jira-tagged commit f369c813fb40cd39c0db46336b2b3186f496fb47 was the initial application path for a batch of Financial Management issues including GF#19495. It replaced the PaymentNotice example's statusDate and target usage with paymentDate and recipient and added the newer payment-related fields, but provider remained in that historical R4-era source. Later PaymentNotice source refactors and FHIR-40448 completed the remaining provider-to-current reporter evolution.

Additional context:
PaymentNotice is an active current-build resource in source/fhir.ini. The current source/paymentnotice StructureDefinition and example contain reporter, paymentDate, and recipient, and contain no live PaymentNotice.statusDate, PaymentNotice.target, or PaymentNotice.provider elements. The old names that still appear in source/fhir.ini are version-difference mappings, including PaymentNotice.provider to PaymentNotice.reporter and PaymentNotice.statusDate/target to PaymentNotice.paymentDate/recipient, not current resource definitions. The later related FHIR-40448 provider-to-reporter correction is already represented on the combined branch, so this seed should not publish a duplicate related commit.

AutoFHIR reconciliation:

Recommendation:
Keep this audit commit as-is. No additional core FHIR source work is needed for FHIR-19495; future generated artifacts should continue to derive from the existing PaymentNotice StructureDefinition and example sources.
