FHIR-7270: Audit terminology conformance statement

Issue request:
FHIR-7270 was a Published/Persuasive DSTU1 vocab issue for the terminology-service conformance section. The issue reported that the wording "SHALL conform to this conformance statement: [link to be provided]" lacked the critical link needed to know the requirement, and the accepted resolution was to create a Conformance statement based on the existing definitions.

Initial application:
The issue was applied in SVN revision 5738, imported as git commit 746c4c28f6437d977184d1ae67a7ea137bef350c, which added source/conformance/conformance-terminology-server.xml and changed source/terminology-service.html from the placeholder "[link to be provided]" text to a link to conformance-terminology-server.html. The same source event also applied FHIR-7015, a duplicate/same-change-family missing-link report.

Additional context:
The Conformance resource and terminology-server file were later migrated to CapabilityStatement by 6106a1be5b1703ee84bdbe31a1b6202faa8a567c. A later Published/Persuasive issue, FHIR-24698, deliberately replaced the old single SHALL-conform sentence with the current explicit minimum terminology-service requirement list and linked CapabilityStatement/TerminologyCapabilities examples. Current source/terminology-service.html no longer contains the placeholder wording, and the active terminology section links to capabilitystatement-terminology-server.html as an example of the required capabilities.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original missing-link defect is already resolved in the current source, and reintroducing a direct old-style "SHALL conform to this statement" sentence would conflict with the later FHIR-24698 structure that defines requirements in the page text and supplies linked examples.

Recommendation:
Keep this audit commit as-is. Future terminology-service conformance changes should be handled under the later terminology capability-statement issue family rather than reopening the DSTU1 placeholder-link fix.
