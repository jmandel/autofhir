FHIR-8613: Audit withdrawn FHIR Book EPUB link

Issue request:
FHIR-8613 was a Published FHIR-core documentation issue with Persuasive with Modification resolution. It asked for the downloads page FHIR Book EPUB link to be changed from the unreadable DSTU1 fhir-v0.0.82.epub to a readable GitHub-hosted fhir-v0.5.0.epub, but the final resolution instead withdrew the EPUB version because making it conformant across readers was not practical.

Initial application:
The issue was applied in Subversion revision 6712, imported as git commit ac5f9b4d98e50aa779bfc1454fdb8cdd0db0bf91, whose message explicitly says "#8613 - abandon attempts to make the epub work" and comments out the FHIR Book EPUB row in source/downloads.html. Later downloads-page refactors removed that commented row entirely.

Additional context:
The current downloads page is still an active build page through source/hierarchy.xml. The current source/downloads.html contains current specification/package download entries and no FHIR Book, EPUB, fhir-v0.0.82.epub, or fhir-v0.5.0 EPUB link. Earlier related EPUB Jira issues FHIR-3140 and FHIR-3792 show the EPUB row had prior reader/link problems, but FHIR-8613 is the later issue that records the withdrawal decision. Zulip and Confluence searches found no conflicting community evidence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already implements the final FHIR-8613 outcome by not publishing the EPUB/FHIR Book link, so restoring or changing an EPUB link would contradict the Published resolution.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed unless the work group makes a new decision to reintroduce an EPUB/FHIR Book artifact with a maintained, conformant generation process.
