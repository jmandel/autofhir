FHIR-14315: Audit Genotype profile as external IG content

Issue request:
FHIR-14315 is a Published/Persuasive with Modification FHIR-core Observation change request from STU3. It asked to create a "Genotype" profile under Observation-genetics with derivedFrom pointing to Haplotype, Observation.code genotype-name 84413-4, valueString for the genotype value, gene-studied component 48018-6, and GenomicLocation component grouping. The accepted resolution says the work was already applied as the Genotype profile in the Genomics Reporting IG.

Initial application:
No current FHIR-core commit explicitly applies FHIR-14315 as a core profile. Clinical Genomics WGM minutes accepted FHIR-14315 together with FHIR-14316, FHIR-14317, and FHIR-14318, explicitly noting that the changes had already been applied to the Genomics Reporting IG but not to Observation-genetics in FHIR core. Historical core source did carry Observation-genetics artifacts, but commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435 removed the outdated clinical genomics artifacts, including Observation genetics profile sources and examples.

Additional context:
Current FHIR core still has active Observation and profile build configuration, but searches found no active Observation-genetics/Genotype profile source and no current core source for the requested LOINC 84413-4 or gene-studied 48018-6 constraints. Instead, current Observation, DiagnosticReport, and genomics narrative points implementers to the Genomics Reporting IG. The published Genomics Reporting IG package hl7.fhir.uv.genomics-reporting 3.0.0 contains an active Observation Genotype profile with canonical http://hl7.org/fhir/uv/genomics-reporting/StructureDefinition/genotype and the requested code, value, derivedFrom, and gene-studied constraints. The Extension Pack's legacy observation-genetics extensions are retired/deprecated and direct implementers to the Genomics Reporting Guide. Companion profile issues FHIR-14316, FHIR-14317, and FHIR-14318 are already represented on the combined branch as external-IG audit commits.

AutoFHIR reconciliation:
This empty audit commit makes no FHIR-core source change. Recreating an Observation-genetics Genotype profile in core would be outside current build scope and would conflict with the accepted resolution and the current ownership split, where Genomics Reporting IG carries these profiles and core links to that IG.

Recommendation:
Keep this external-repo audit as-is. Future corrections to Genotype profile constraints, including any location-coordinate refinements raised later in Zulip, should be made in HL7/genomics-reporting or the published Genomics Reporting IG unless the Clinical Genomics work group explicitly decides to move this content back into FHIR core.
