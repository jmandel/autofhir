FHIR-50034: Audit TestReport approval outside core

Issue request:
FHIR-50034 was an Applied/Persuasive R6 FHIR-I change request to approve the TestReport changes made after implementer discussion immediately before ballot. The approved change set clarified that score is a 0..100 percentage, made participant.uri optional, added participant.version, added runner parameters, clarified that TestReport.test.name links back to TestScript tests by name, added an overall test result, added a period for test run timing, added log attachments at the test and report levels, and added presentedForm for rendered report output.

Initial application:
The issue was applied by PR #3389, merged on 2025-03-18. The PR included commits c100f9cc53, 5c9bdf7e0b, c91d0b3963, and 2013d602b5, which updated source/testreport/structuredefinition-TestReport.xml with the approved score bounds, participant, parameter, test result, period, log, and presentedForm changes.

Additional context:
Later commit f9a44787c4 removed TestPlan, TestReport, and TestScript from the active core resource list and deleted source/testreport, source/testscript, and source/testplan while adding source/fhir.ini's FHIR Testing IG pointer. Current core has no source/testreport directory and no active [resources] testreport entry; source/ballot-intro.html points TestReport to the FHIR Testing IG. The current HL7/fhir-testing-ig source contains input/resources/testreport/StructureDefinition-TestReport.xml with the FHIR-50034 semantics preserved.
