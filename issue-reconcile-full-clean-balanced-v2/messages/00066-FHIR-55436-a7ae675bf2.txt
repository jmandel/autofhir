FHIR-55436: Flag Measure.topic removal for review

Issue request:
FHIR-55436 is Applied/Persuasive and asked CQI to remove the deprecated Measure.topic element in R6 because the element was deprecated in R5 under the broader deprecated-element cleanup from FHIR-53722.

Initial application:
The issue was applied by git commit 06ab81280a, which removed Measure.topic from source/measure/structuredefinition-Measure.xml, removed the Measure-topic search parameter from source/measure/bundle-Measure-search-params.xml, and noted the change in source/measure/measure-introduction.xml. That application did not remove the still-active Measure examples that contain <topic> elements.

Additional context:
Measure is active in source/fhir.ini, and list-Measure-examples.xml includes the example instances that still contain <topic>. However, the latest Jira comment on FHIR-55436, added after the application, says the topic removals were identified as incorrect because topic is about artifact subject matter while useContext is about contexts of appropriate use, and proposes reopening this issue as not persuasive and undoing the change. FHIR-55564 carries the same later concern for the related CDS topic-removal family after Rotterdam WGM discussion. The original R5 deprecation issue FHIR-38841 was Published, but its own linked discussion included the same conceptual distinction between topic as keyword and useContext as name-value context.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Completing the currently partial removal by deleting <topic> from active examples would further cement a change that a responsible editor has just proposed to reverse. Restoring Measure.topic, the search parameter, and generated-looking diagram content would also be unsafe before the Jira status and work-group decision are actually updated.

Recommendation:
Keep this human-review audit commit until CQI/FHIR-I decide whether FHIR-55436 remains Applied/Persuasive or is reopened/not persuasive. If the removal stands, remove topic from active Measure examples and regenerated narrative consistently. If the reversal is approved, restore Measure.topic and the related search/rendering artifacts through the normal source-generation path.
