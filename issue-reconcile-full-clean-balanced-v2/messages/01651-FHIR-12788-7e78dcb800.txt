FHIR-12788: Audit C-CDA 2.1 FormatCode codes

Issue request:
FHIR-12788 was a Published/Persuasive with Modification SDWG change request for DSTU2 asking to add urn:hl7-org:sdwg:ccda-structuredBody:2.1 to the DocumentReference FormatCode value set; the approved resolution also added urn:hl7-org:sdwg:ccda-nonXMLBody:2.1.

Initial application:
Git b07ae74b6f applied the request directly to source/documentreference/valueset-formatcodes.xml by adding both C-CDA 2.1 structuredBody and nonXMLBody concepts and clarifying the C-CDA 1.1 displays. FHIR-12757 was applied soon after in the same value set family.

Additional context:
The hand-maintained core FormatCodes value set was later superseded. FHIR-13950/FHIR-14003 moved the terminology toward IHE/HL7 code-system ownership, FHIR-14104 and UP-241 established the THO HL7FormatCodes value set, and git 6f1b3314e9 deleted the in-core value set while rebinding DocumentReference.content.profile.value[x] to http://terminology.hl7.org/ValueSet/v3-HL7FormatCodes. Current cached THO packages include both C-CDA 2.1 codes.

AutoFHIR reconciliation:
This empty audit commit intentionally makes no source change. The active core source already delegates FormatCode content to THO, and the authoritative THO code system contains both codes named in the FHIR-12788 resolution.

Recommendation:
Keep this no-change audit. Do not restore the obsolete core value set; future C-CDA FormatCode maintenance should happen through THO/IHE terminology proposals.
