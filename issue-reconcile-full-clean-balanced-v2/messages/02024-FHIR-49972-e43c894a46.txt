Initial application:
The Jira application comment says to add UCUM code '[oz_av]' to ucum-vitals-common and ucum-bodyweight and records applied git 90f6f81f6c. That commit added the concept to both source/observation value-set XML files. A follow-up FHIR-49972 commit, 8515a4fcf4, added the missing '[oz_av]' references in the bodyweight profile binding summaries and binding description.

Additional context:
FHIR-27004 is the parent vital-signs unit discussion and was ultimately resolved by adding oz_av rather than relaxing the body-weight profile's required unit binding. The 2025-03-07 OO minutes record an 8-0-0 motion that FHIR-49972 needed to be in the R6 ballot and should add oz_av as an allowable body-weight unit. Current source/fhir.ini keeps Observation active in the build, so source/observation value sets and profiles are in current build scope. Related no-change issue FHIR-39153 confirms ucum-bodyweight and ucum-vitals-common were not moved out of core, and FHIR-31919's later no-change request for displays/stone does not conflict with adding '[oz_av]'.
