FHIR-12425: Audit communicationRequest application

Issue request:
FHIR-12425 was a Published/Persuasive Financial Management change request from DSTU2 asking to add CommunicationRequest 0..* Reference(CommunicationRequest) to ClaimResponse and ProcessResponse so payers could request supporting information.

Initial application:
The requested change appears to have been applied in historical source by commit ec7e3be959d19baec21dc0782462a3dc33808f46, whose subject says it added CommunicationRequest to ClaimResponse and ProcessResponse. Current source still contains the ClaimResponse element, and the retained historical ProcessResponse spreadsheet also contains ProcessResponse.communicationRequest with cardinality 0..* and type Reference(CommunicationRequest).

Additional context:
ClaimResponse remains an active resource in source/fhir.ini. ProcessResponse is no longer active in the current build: its [resources] entry is commented out, it appears under [removed-resources], and the FMG approval note says "ProcessResponse=approved use Task". A later build-scope commit, 642e610a19880384fa234022f0166a3111678708, made the ProcessResponse resource/workgroup/FMM entries inactive and recorded the Task replacement note. Jira search found FHIR-12425 as the only directly relevant issue for the combined ClaimResponse/ProcessResponse/CommunicationRequest request; Zulip only showed a tracker bot notification, and Confluence had no relevant references.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current-spec ClaimResponse definition already has ClaimResponse.communicationRequest as 0..* Reference(CommunicationRequest), and reactivating or editing ProcessResponse would be outside current build scope because ProcessResponse has been removed in favor of Task.

Recommendation:
Keep this audit commit as-is. No current FHIR source edit is needed for FHIR-12425 unless a future work group decision reintroduces ProcessResponse or asks for a different active-resource representation of the supporting-information request flow.
