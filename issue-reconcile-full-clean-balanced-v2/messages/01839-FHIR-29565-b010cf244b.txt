FHIR-29565: Audit manufacturing date classification extension location

Issue request:
FHIR-29565 was a Published Pharmacy change request, resolved Persuasive with Modification for R5, asking to add a textual description/rationale associated with the Manufacturing Date on Medication.batch. The Jira description said the description should include the specific operation or step in the manufacturing process associated with the assigned manufacturing date, and the final resolution said to create a core extension for the attribute.

Initial application:
No source commit was found whose message explicitly names FHIR-29565. Git history shows the request was nevertheless applied in the Medication manufacturing-batch extension family: commit 52f3ef3d50 added the manufacturingBatch extension family to source/medication/medication-extensions-spreadsheet.xml, commit 5faa63a834 added the manufacturingDate description that points to manufacturingDateClassification for the operation/step, commit 33b409a4b6 generated source/medication/structuredefinition-extension-medication-manufacturingBatch.xml with manufacturingDateClassification as a 0..1 CodeableConcept slice, and commit dd468d4f17 later removed that core extension source when R5 extensions were moved out of this repository. The Extension Pack imported and retained the same extension family.

Additional context:
Medication remains an active core resource, but the current core source maps the historical Medication.batch path to Medication.instance and no longer owns the medication-manufacturingBatch StructureDefinition except for its OID registry entry. The same extension now lives in the FHIR Extension Pack, whose input/definitions/multiple/StructureDefinition-medication-manufacturingBatch.xml applies to Medication.batch, defines manufacturingDate as a dateTime slice, and defines manufacturingDateClassification as a CodeableConcept slice whose definition provides the rationale for the selected manufacturing date. Pharmacy minutes for 2020-11-09 record the PQ/CMC manufacturing discussion and the 9-0-0 carried block vote, including FHIR-29565, to add a core extension. A direct Zulip search for FHIR-29565 found no hits; a broader extension search found implementation discussion of profiling medication-manufacturingBatch, with no later conflicting decision found.
