FHIR-33166: Audit Observation episode-of-care guidance

Issue request:
FHIR-33166 is an Applied OO change request with a Not Persuasive with Modification resolution. It asked O&O to revisit the Observation.context-to-Observation.encounter change and EpisodeOfCare support; the final accepted action was to update the short display text of Observation.encounter so implementers are directed to use the workflow-episodeOfCare extension when an Observation needs to be placed within one or more episodes of care.

Initial application:
The issue was applied in commit b7d6acf83a, which changed source/observation/structuredefinition-Observation.xml so Observation.encounter's short text includes the approved workflow-episodeOfCare guidance. A later cleanup commit, b8984e5cbe, made the same wording consistent in source/observation/observation-event-mapping-exceptions.xml.

Additional context:
Observation is an active core resource in source/fhir.ini, so source/observation/structuredefinition-Observation.xml is in current build scope. The historical background is FHIR-17661/FHIR-17901, which split the old context pattern into 0..1 Encounter plus a 0..* EpisodeOfCare extension. FHIR-42761 later reaffirmed that the Event pattern should not be changed back to an EpisodeOfCare-bearing context element, and FHIR-42762 provided the fallback by defining a workflow-EpisodeOfCare search parameter in the Extension Pack rather than on each core resource page. The Extension Pack source currently includes both the workflow-episodeOfCare extension and its search parameter with Observation listed as a base.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Observation source already contains the approved short-text guidance, the Event mapping exception source is consistent, and the related EpisodeOfCare extension/search parameter maintenance is represented outside core in the Extension Pack.

Recommendation:
Keep this audit commit as-is. Do not rename Observation.encounter or add EpisodeOfCare directly to the core element unless a future work-group decision reverses FHIR-42761; any follow-up about rendering extension search parameters on core resource pages should continue through the Extension Pack/tooling path captured by FHIR-42762.
