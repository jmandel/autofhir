FHIR-5439: Audit ProcessRequest status application

Issue request:
FHIR-5439 is a Published FHIR-core/FM ProcessRequest change request from the January 2015 ballot. It asked that status be a property of the underlying resource and a status search parameter, with the related comment that StatusRequest and StatusResponse should not exist as separate resources. The final Persuasive with Modification resolution says status had already been added to all FM resources for STU3.

Initial application:
No Jira-keyed source commit for FHIR-5439 was found. History shows StatusRequest was first replaced by ProcessRequest in 2015, and a 2016 cleanup commit explicitly added status to EligibilityResponse, EnrollmentResponse, ProcessRequest, and ProcessResponse. The retained ProcessRequest spreadsheet source includes ProcessRequest.status and a status search parameter.

Additional context:
The latest combined branch does not build ProcessRequest: source/fhir.ini comments ProcessRequest and ProcessResponse out of the active resource and workgroup lists, lists ProcessRequest with removed resources, and records that ProcessRequest should use Task instead. FHIR-5440 is the matching ProcessResponse ballot comment with the same request and resolution, and it is already represented on the combined branch by a no-change audit commit. Zulip and Confluence searches found no directly relevant or conflicting community records.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active FM resources on the combined branch all have status elements and status search parameters, and the retired ProcessRequest source already contains the historical status artifacts. Editing out-of-build ProcessRequest files or adding redundant prose would not change the current specification.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed unless the FM work group reintroduces ProcessRequest or identifies an active FM resource that lacks the expected status element or status search parameter.
