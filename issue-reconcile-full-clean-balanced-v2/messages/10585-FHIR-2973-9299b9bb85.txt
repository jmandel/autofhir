FHIR-2973: Fix Observation BMD UCUM unit code

Issue request:
FHIR-2973 was a Published/Persuasive with Modification OO issue asking that coding errors in examples be fixed. The described errors included the old Observation BMI example's incorrect SNOMED coding for weight, an invented UCUM code "tbl" in the discharge summary example, a "g/cm-2" value represented as a UCUM code, and LOINC concentration mismatches.

Initial application:
The issue was explicitly applied in commit 7a2e91fe31, which corrected the old observation-example-f201-bmi.xml SNOMED codes. Current source no longer carries that old active f201 BMI example, and the current BMI Observation uses LOINC 39156-5 with kg/m2. The discharge summary tablet code was later corrected in commit 2be4de7258 from UCUM tbl to v3-orderableDrugForm TAB.

Additional context:
Observation is an active current-build resource in source/fhir.ini, and source/observation/list-Observation-examples.xml lists observation-example-bmd. The BMD example was introduced later in commit 0fb9cb5f9c with the same "g/cm-2" UCUM code pattern named in FHIR-2973 and also quoted in FHIR-5273's Observation/imaging discussion. No Zulip or Confluence search result was found that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This commit changes the active Observation BMD example's Quantity.code from "g/cm-2" to the UCUM expression "g/cm2", preserving the display unit "g/cm²" and correcting the coded unit without touching generated artifacts or unrelated examples.

Recommendation:
Keep this source fix. It is a narrow correction to an active example source file and completes the remaining discovered FHIR-2973 unit-code issue; broader example-code cleanup outside the Observation/discharge-summary trail should be handled by separate trackers.
