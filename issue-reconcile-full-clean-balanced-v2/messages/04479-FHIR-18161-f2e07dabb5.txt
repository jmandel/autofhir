FHIR-18161: Audit CodeSystem supplement example

Issue request:
FHIR-18161 was a Published/Persuasive vocab change request for STU3 asking for an example that clarifies how a CodeSystem supplement would provide supplemental information such as drug form, ingredient, and strength for an existing code. The accepted resolution was to add an example, explicitly without committing to make it an RxNorm-specific example.

Initial application:
The Jira comment records git 66ae1e40f1bc02283363c872db14035fc795f8f7. That commit added source/codesystem/codesystem-example-supplement.xml as a CodeSystem with content="supplement", supplements="http://hl7.org/fhir/CodeSystem/example", a supplemental boolean property, and supplemental property values for existing concepts.

Additional context:
CodeSystem remains an active current-build resource in source/fhir.ini, and source/codesystem/list-CodeSystem-examples.xml includes CodeSystem/example-supplement on the CodeSystem examples page. Later related vocab work added a second language-translation CodeSystem supplement example for FHIR-27745 and a ValueSet example using the supplement property for FHIR-38675, but those later examples extend rather than invalidate the FHIR-18161 application. Zulip and Confluence searches found no FHIR-18161-specific discussion or conflicting later decision.

AutoFHIR reconciliation:

Recommendation:
