FHIR-18323: Audit Patient FiveWs self-link CSS

Issue request:
FHIR-18323 was a Published/Persuasive STU3 technical correction for the Patient mappings page. It reported that section 8.1.15.1, the FiveWs Pattern mapping heading, initially displayed empty brackets because the link inside the brackets was hidden until hover, and it suspected the `.self-link-parent a { visibility: hidden; }` CSS rule as the root cause.

Initial application:
No commit explicitly mentioning FHIR-18323 was found. The relevant source history does contain commit 0504da21410640232eafa1e9aeebcac151dce0cd, titled "Fix problem with CSS causing anchor references inside a self-link-parent to disappear when they weren't the self-link", which changed the selector from hiding every anchor under `.self-link-parent` to hiding only anchors with class `self-link`. That directly matches the Jira-reported root cause and is present in the current source.

Additional context:
Patient is an active current resource and FiveWs is an active logical pattern in source/fhir.ini, so the Patient mappings page and its FiveWs section remain in current build scope. The current rendered Patient mappings heading contains the FiveWs mapping link as a normal anchor inside an h3.self-link-parent and contains a separate anchor with class `self-link` for the section permalink. Current source and current build CSS hide only `a.self-link`, so the bracketed FiveWs mapping link is not hidden by the self-link hover behavior. Adjacent Patient mapping-link issues FHIR-18324 and FHIR-18326 are already represented on the combined branch and do not require another decision here.

AutoFHIR reconciliation:
No source change was made. The active CSS source already preserves the intended self-link hover behavior while leaving ordinary links inside self-link headings visible, which is the correction FHIR-18323 requested.

Recommendation:
Keep this audit commit as-is. Further work is only needed if future publication tooling reintroduces a broad `.self-link-parent a` visibility rule or otherwise hides non-self-link anchors in headings.
