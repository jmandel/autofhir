FHIR-26366: Audit messaging example element names

Issue request:
FHIR-26366 was a Published/Persuasive FHIR-core correction against the messaging page search example. The issue reported that the inline MessageHeader example at messaging.html#search still used the old XML <event> choice and MessageHeader.data, and asked for eventCoding and focus instead, preferably through a validated inline example mechanism.

Initial application:
No source commit that explicitly mentioned FHIR-26366 was found. The relevant source history nevertheless removed or superseded the stale forms: git commit 472644928c6d9df6d0cbc44736a1697fa8ef6ac2 removed the <data> fragments from the messaging operation and search examples, FHIR-36098 rewrote the active search-in-messaging section and commented out the older typed-parameter XML example, and FHIR-37416 later changed the remaining active MessageHeader examples from <event>/MessageHeader.data wording to eventCoding/MessageHeader.focus. A prior AutoFHIR FHIR-37416 commit on the combined branch completed adjacent active prose cleanup.

Additional context:
FHIR-I minutes for 2020-02-24 record the FHIR-26366 decision as fixing the inline example by using the publisher's validating <pre class="xml" fragment="Bundle"> mechanism rather than extracting a full standalone example. The current active operation example on source/messaging.html uses that fragment marker, and the current active search section no longer renders the stale XML snippet. The only remaining search XML block that resembles the original report is inside an HTML comment and already uses eventCoding with no MessageHeader.data reference. MessageHeader's current definition uses event[x] and focus.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current built messaging page no longer presents the obsolete element names that FHIR-26366 reported, and editing the commented-out historical block or adding redundant search prose would not improve current implementer-facing guidance.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-26366; if a future edit re-enables the commented search XML example, convert it to a validated fragment and ensure it includes a MessageHeader.focus reference consistent with the current MessageHeader definition.
