FHIR-7473: Audit medication code support

Issue request:
FHIR-7473 was a Published Pharmacy change request with resolution Persuasive with Modification. It asked that MedicationStatement allow a medication code as an alternative to a full Medication resource, and the accepted resolution expanded that same code-or-resource support to medicationPrescription, medicationStatement, medicationAdministration, and medicationDispense.

Initial application:
No current git commit was found whose message explicitly mentions FHIR-7473 or its duplicate FHIR-7995. Jira comments say the change was already done in 2015, and history shows the 2015-era medication spreadsheets gaining medicationCodeableConcept/code search support alongside medicationReference handling.

Additional context:
MedicationPrescription is now MedicationRequest. The active current build includes MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement in source/fhir.ini. Current StructureDefinition XML represents each requested medication element as CodeableReference targeting Medication, with definitions/comments explaining the code-only and referenced-Medication alternatives. Later R5 work temporarily renamed MedicationStatement to MedicationUsage, but FHIR-38682 restored the MedicationStatement name while recording that the resource scope had not changed.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source already conveys the requested semantics through CodeableReference(Medication) on all four resources named in the accepted resolution, so adding duplicate or legacy medication[x] wording would not improve implementer understanding.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-7473 unless Pharmacy later decides to change the modern CodeableReference medication pattern.
