FHIR-9121: Audit ValueSet title localization

Issue request:
FHIR-9121 was a Published/Persuasive vocab issue raised against DSTU2 asking to add a repeatable top-level ValueSet.designation, modeled after concept designations, so a value-set designer could provide localized or purpose-specific labels for the value set itself. The recorded resolution was "already done," with the issue comment noting that strings are localizable by extension.

Initial application:
No Jira-tagged FHIR-9121 source commit was found in the current git history or on the combined branch. The nearby historical designation work predates the issue and added concept-level designations, not a top-level ValueSet.designation. The current active ValueSet source instead exposes ValueSet.title as the human-friendly label, marks it translatable, and keeps concept designations at ValueSet.compose.include.concept.designation.

Additional context:
ValueSet is active in the current build and owned by vocab. Later VSD alignment work documents that the VSD Name maps to ValueSet.title and directs authors to the ValueSet.valueset-otherTitle extension when language or preference is needed. That extension now lives in the FHIR Extension Pack and provides repeated alternative titles with preferred and language slices. Tightly related later issues FHIR-25395 and FHIR-44727 are already represented on the combined branch, so this reconciliation does not publish duplicate commits for them.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Adding a new top-level ValueSet.designation would contradict the current ValueSet/title/extension model and is not required to satisfy the published "already done" decision; the current build already has the implementer-visible path for localized or preferred value-set titles.

Recommendation:
Keep this no-change audit. Do not add ValueSet.designation to core unless vocab makes a new explicit resource-model decision; future refinements to alternative title language/preference behavior belong with the FHIR Extension Pack extension artifacts rather than this closed DSTU2 tracker.
