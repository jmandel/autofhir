FHIR-6207: Audit Composition.event.detail wording

Issue request:
FHIR-6207 was a Published, Persuasive with Modification Structured Documents clarification for DSTU1 Composition. It asked to replace the confusing Composition.event.detail wording, "Full details for the event(s) the composition consents", with wording that describes the documented event by description and/or reference, with colonoscopy and appendectomy examples.

Initial application:
The Jira comment records svn revision 6207, and git-svn commit 4f7384c613 applied #6207 to source/composition/composition-spreadsheet.xml by changing the short to "The event(s) being documented" and the definition to "The description and/or reference of the event(s) being documented" with the requested examples. The current StructureDefinition source descends from later source conversion work, and commit 67e426c9eb subsequently merged Composition.event.code into Composition.event.detail while preserving and expanding the documented-clinical-act semantics.

Additional context:
source/fhir.ini lists composition as an active resource, so source/composition/structuredefinition-Composition.xml is the current build-scope authority. That file now defines Composition.event.detail as "The event(s) being documented, as code(s), reference(s), or both" and explains that it represents main clinical acts such as colonoscopy or appendectomy. The only remaining old "Full details" text found under source/ is in source/profiles/cda.profile.xml, whose fhir.ini profile entry is commented out, so editing that legacy profile would not be a current-spec fix. Zulip and Confluence searches found no later or conflicting community record.
