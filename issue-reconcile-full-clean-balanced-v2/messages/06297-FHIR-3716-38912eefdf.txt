Issue request:
FHIR-3716 was a Published Patient Care change request for DSTU1 asking to specify a value set for the type of Procedure. The final Persuasive with Modification resolution concluded that Procedure is broad, so an example binding was appropriate, using SNOMED CT or other code systems as examples and ensuring examples show the resource breadth.

Initial application:
The Jira comments say the issue was applied in svn revision 4812. No later FHIR-3716-specific commit was found.

Additional context:

The old Procedure.type element was later renamed to Procedure.code in 77c0aa01f08d8517bcba177c89b296095491221d (#6129 and #7123), and the current source retains the binding on Procedure.code. The value set now lives as http://hl7.org/fhir/ValueSet/procedure-code with title Procedure Codes (SNOMED CT), an example binding strength, and a compose filter for SNOMED CT descendants of 71388002 Procedure. Current Procedure examples include clinical, therapy, education, HCBS, narrative-only, obstetric, device, and ventilator-setting examples, so the breadth concern is not an unaddressed current-source gap.
