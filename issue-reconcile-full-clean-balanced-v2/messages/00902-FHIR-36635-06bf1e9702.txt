FHIR-36635: Audit superseded EvidenceVariable characteristic model

Issue request:
FHIR-36635 was Published as Persuasive with Modification for R5. It asked to simplify the EvidenceVariable.characteristic definition model by replacing the earlier mutually exclusive definition[x] versus type/value/combination rule with explicit alternatives: definition[x], defByTypeAndValue, and defByCombination, with the final comment adjusting names to avoid starting an element name with the same characters as a choice element.

Initial application:
The issue was applied in git commit 8019b7c9a69cae8d916756f78130981b23493354, whose message says EvidenceVariable.characteristic now uses definition[x], defByTypeAndValue, or defByCombination, and whose changed files included the EvidenceVariable StructureDefinition, search-parameter bundle, examples, and list files. Later R5 issues in the same model family refined that application: FHIR-37356 renamed the three-way model into seven definitionXXX elements with an at-most-one constraint, and FHIR-39607 relaxed the constraint to allow definitionExpression alongside another definition element.

Additional context:
EvidenceVariable is an active resource in source/fhir.ini, but the current R6 source no longer has the R5 EvidenceVariable.characteristic model. FHIR-42886 was later Applied as Persuasive with Modification for R6 and replaced EvidenceVariable.characteristic with EvidenceVariable.definition, a CodeableReference constrained to Group for references; b6ffbe50c67dfcc7f9ceac3463e582537ad2d85c removed characteristic from the StructureDefinition and updated the introduction. The old characteristic paths that remain in source/fhir.ini are in the [r4-r6-changes] and [r5-r6-changes] migration/change-map sections, where removed historical paths are expected. The combined branch already contains c5e250deed70b0c0709be800747b868001493146 for FHIR-42886, which converted the last direct EvidenceVariable.characteristic example.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The FHIR-36635 request was historically applied for R5 and has since been superseded in the current build by the final FHIR-42886 decision to remove EvidenceVariable.characteristic altogether. Re-adding or editing defByTypeAndValue/defByCombination in current source would reintroduce an obsolete R5 model rather than correct the current specification.

Recommendation:
Keep this audit commit as-is. No FHIR-core source follow-up is needed for FHIR-36635; any future review of the current EvidenceVariable.definition model should be handled under FHIR-42886 or a new R6+ tracker rather than under the superseded R5 characteristic simplification.
