FHIR-39386: Audit Patient compartment additions

Issue request:
FHIR-39386 was a Published FHIR-core CompartmentDefinition change request, resolved Persuasive with Modification for R5. It asked to add resources that had patient or subject-equivalent search parameters to the Patient compartment; the final resolution specifically called for Task.patient, Task.focus, Contract.patient, and GuidanceResponse.patient.

Initial application:
The issue was applied by commit 49328521fc, which updated the build-scoped source/compartments.xml spreadsheet. Before that commit, Contract, GuidanceResponse, and Task rows existed without Patient-compartment search parameters; after it, Contract.patient, GuidanceResponse.patient, and Task.patient | focus were present.

Additional context:
source/fhir.ini actively lists CompartmentDefinition, Contract, GuidanceResponse, and Task in the current build, so source/compartments.xml and the corresponding search-parameter bundles are in scope for the current branch. Later Task work split the original Task.focus search parameter into Task-focus-reference and Task-focus-canonical, and commit b6998e4d30 updated the compartment row from focus to focus-reference, which is the current reference-valued equivalent needed for Patient compartment membership. A later unresolved Contract-removal issue, FHIR-55563, is only Resolved - change required and its Branch_55563 commit is not on the combined branch, so it does not change this default Applied/Published reconciliation.

AutoFHIR reconciliation:
No source change was made. The current source already has Contract with patient in the Patient column, GuidanceResponse with patient in the Patient column, and Task with patient | focus-reference in the Patient column. The referenced search parameters also exist as Contract-patient, GuidanceResponse-patient, Task-patient, and Task-focus-reference.

Recommendation:
Keep this audit commit as-is. No current FHIR-core source follow-up is needed for FHIR-39386; any future Contract removal should be handled under FHIR-55563 or its own applied/published reconciliation, not by changing this already-applied R5 compartment fix.
