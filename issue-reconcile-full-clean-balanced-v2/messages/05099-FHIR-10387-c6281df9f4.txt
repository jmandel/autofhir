FHIR-10387: Audit CommunicationRequest initiatingLocation migration

Issue request:
FHIR-10387 was a Published/Persuasive Patient Care change request for DSTU2 asking for CommunicationRequest to support describing the Location where the requested communication happened. The approved resolution was to add a CommunicationRequest extension named initiatingLocation, Reference(Location), 0..1, for cases where initiation location matters for interpretation and not for general Provenance purposes.

Initial application:
No current core commit explicitly mentions FHIR-10387, but core history shows the extension source existed before the R5 extension migration. The removed core StructureDefinition used canonical http://hl7.org/fhir/StructureDefinition/communicationrequest-initiatingLocation, context CommunicationRequest, value Reference(Location), max 1, and the comment limiting use to interpretation rather than general Provenance. Historical R4/R4B extension bundles and source/oids.ini also retain the same canonical and OID.

Additional context:
The current CommunicationRequest resource is active in source/fhir.ini, but the extension definition is no longer active core source. Core commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed extension definitions from R5 source, including the CommunicationRequest initiatingLocation file and its CommunicationRequest IG reference. The current FHIR Extension Pack checkout contains input/definitions/CommunicationRequest/StructureDefinition-communicationrequest-initiatingLocation.xml with the requested context, description/comment, cardinality, and Reference(Location) target. No relevant Zulip or Confluence evidence was found that changes this source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change in the core FHIR checkout. The extension-pack source already satisfies the Jira request.

Recommendation:
Keep this audit commit as-is for core reconciliation. Future substantive edits to the initiatingLocation extension should be made in the FHIR Extension Pack, not by restoring the removed core StructureDefinition, unless HL7 changes the extension-pack ownership policy.
