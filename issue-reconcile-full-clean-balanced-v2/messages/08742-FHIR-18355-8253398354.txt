FHIR-18355: Audit modifier-extension processing options

Issue request:
FHIR-18355 was a Published/Persuasive FHIR-I correction against the FHIR-core extensibility page. It asked to clarify #2 in modifier-extension processing so "do not process" is not understood only as rejecting the whole resource: when an unrecognized modifier is on a child element, a system may process the resource while excluding that element, treating it as missing, if incomplete data is safe and any meaning-if-missing is considered. It also asked to move the "An application only needs to concern itself" paragraph up to appear right after #3.
