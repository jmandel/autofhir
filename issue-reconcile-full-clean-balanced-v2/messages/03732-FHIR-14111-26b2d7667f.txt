FHIR-14111: Audit MedicationRequest weight-based dosing examples

Issue request:
FHIR-14111 was a Published/Persuasive with Modification pharmacy change request for STU3 MedicationRequest. It asked to fix medicationrequest0316 so the chemotherapy example used a rateRatio of 1.8 mg/kg over 20 minutes instead of a rateQuantity of 20 minutes, make the free-text dosage say 20 minutes, and add weight-based dopamine dosing examples showing 4 mcg/kg/min, 200 mcg/min, and 7.5 mL/hour plus a 400 mg dose.

Initial application:
The medicationrequest0316 correction appears to have been applied before the final Jira publication in git commit 5115fa663f, which changed the example text from 30 to 20 minutes and replaced the 20-minute rateQuantity with a rateRatio. Commit e60c66de12 later moved the same rateRatio into doseAndRate during Dosage model changes. The Jira-cited SVN revision build@13233 maps to git commit 0899ef42e9, which added medicationrequest0336, medicationrequest0337, and medicationrequest0338 plus the examples header entries for the dopamine weight-based dosing cases.
