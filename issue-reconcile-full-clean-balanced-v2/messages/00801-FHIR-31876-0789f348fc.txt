FHIR-31876: Audit Ingredient specifiedSubstance removal

Issue request:
FHIR-31876 was a Published/Persuasive BR&R change request for the R4B MedicinalProductIngredient/Ingredient model. It said Ingredient.substance and Ingredient.specificSubstance were duplicates and asked to simplify the model to one substance representation, possibly by referencing Substance.

Initial application:
The change was explicitly applied before this reconciliation. Git history contains the source commit 6b369be0a3586b4327b7be45bb93e65c344f66e0, "removed ingredient.specifiedSubstance FHIR#31813, FHIR#31815, FHIR#31816, FHIR#31876", which removed Ingredient.specifiedSubstance, its search parameters, and the specified-substance example while making Ingredient.substance mandatory. The same patch also appears as 5730009f8bc3d8edcbaba2bbf979741b55017c7b on another branch, matching Jira's comment that the change was applied in both the R4B branch and main build.

Additional context:
Ingredient is an active current-build resource in source/fhir.ini, and the old MedicinalProductIngredient name redirects to Ingredient. Related Jira issues FHIR-31813, FHIR-31815, and FHIR-31816 record the same specifiedSubstance simplification family. A 2020 BR&R Zulip thread shows the original confusion and modeling tension around specifiedSubstance versus substance, and BR&R minutes on 2021-10-05 confirm the related work-group vote that the Substance/SpecifiedSubstance model had been simplified. No direct Zulip or Confluence evidence was found that conflicts with the Jira/source conclusion for FHIR-31876.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current Ingredient StructureDefinition has exactly one Ingredient.substance backbone element with cardinality 1..1 and no Ingredient.specifiedSubstance or Ingredient.specificSubstance element. The Ingredient search-parameter bundle now contains only the substance search parameters, and repository-wide searches under source/ingredient find no remaining specifiedSubstance/specificSubstance source surface to correct.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR follow-up is needed for FHIR-31876 unless BR&R later reopens the modeling question or requests a new extension for specified-substance details.
