FHIR-32869: Audit $translate ConceptMap scope wording

Issue request:
FHIR-32869 was a Published vocab change request for R5 that initially asked to add an optional onlyUseConceptMap input parameter to ConceptMap/$translate so clients could require use of only the specified ConceptMap. The final Not Persuasive with Modification resolution instead replaced the introductory text to say translation is based on the specified ConceptMap resource and that other server knowledge may be used only when no ConceptMap resource is specified.

Initial application:
The approved wording appears to have been applied in git commit 9500b398d1d850a06cd180c82ce330e4809a2b49, the "vocab r5 tickets batch 2" commit that explicitly listed FHIR-32869 and changed the then-current ConceptMap2 $translate OperationDefinition description to the Jira-approved text. Commit 8623473ddfcef0cb88b9abf5241abfe6e28ea542 later renamed ConceptMap2 back to ConceptMap and carried the same approved wording into the current ConceptMap $translate operation source.
