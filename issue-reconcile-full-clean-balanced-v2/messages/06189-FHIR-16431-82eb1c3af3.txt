Issue request:
FHIR-16431 was a Published/Not Persuasive with Modification STU3 Vocabulary change request asking whether ValueSet.status should align with the VSD activity status and requesting workflow status support or at least a reference from the ValueSet.status documentation.

Initial application:
The issue was applied in commit c7f83f6f3efb65e6c8622a0c7ff190a2e7790add, whose message says "GF#16431 - link status definition to extension" and whose SVN id matches Jira comment svn 14667. That commit added a ValueSet.status spreadsheet comment linking to the valueset-workflowStatus extension for additional editorial-process status information.

Additional context:
The current ValueSet source is active in source/fhir.ini and the ValueSet.status comment now links to valueset-workflowStatusDescription, the successor extension. Commit b89a83b4b7fa2bec4cbaf92672d13c943c7772d5 renamed the link to workflowStatusDescription, commit c3432543e2b93c3befc06f628938d37e6c1f1f02 converted it to a canonical triple-bracket extension link, and the Extension Pack shows the older valueset-workflowStatus extension as retired and replaced by valueset-workflowStatusDescription. The 2018 Zulip GF#16431 thread records that the work group compared VSD activity states to FHIR ValueSet.status and did not find a solid candidate for changing the common FHIR status definitions.

This empty audit commit intentionally makes no source change. Recommendation:
