FHIR-47340: Audit Subscription managingEntity clarification

Issue request:
FHIR-47340 was an Applied/Persuasive R6 FHIR-core Subscription change request. It asked to replace the Subscription.managingEntity definition with wording about authorization to communicate with the server about the Subscription, such as requesting endpoint URL changes, and to add a note that the managing entity need not be the client for server-managed Subscriptions.

Initial application:
The change was applied before this reconciliation in commit f64b39db58da25085d64e9f9cd771f63d616b000, "FHIR-47340 - Subscription.managingEntity definition clarification," which changed source/subscription/structuredefinition-Subscription.xml by replacing the old authorization/disclosure definition and adding the requested comment. PR HL7/fhir#3967, linked from the Jira comment, was merged on 2025-11-09 and includes that commit.

Additional context:
Subscription is an active current-build resource in source/fhir.ini. The current authoritative StructureDefinition source has the requested definition and comment for Subscription.managingEntity. A checked-in source/subscription/subscription.svg tooltip still contains the old definition, but it is a generated-looking diagram artifact; the reconciliation workflow says not to make a source-changing commit whose only edit is such an SVG when the authoritative XML already conveys the correct semantics. FHIR-37555 is background because it originally introduced managingEntity with the older wording, and FHIR-47337 is a same-element block-vote issue about target profiles rather than this definition wording.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current StructureDefinition source already satisfies FHIR-47340, and changing only the stale SVG tooltip would be an out-of-threshold generated-artifact edit rather than a necessary current-spec correction.
