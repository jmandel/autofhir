FHIR-22495: Audit clinical-date ge comparator

Issue request:
FHIR-22495 was Published with a Persuasive resolution for FHIR-core AllergyIntolerance/common clinical date search parameters. The request said the clinical-date SearchParameter was missing the `ge` modifier; the final resolution clarified this as a technical correction to add `ge` to each generated date comparator list.

Initial application:
The issue was applied in git by GF#22495 commits b6e3db69721c07eb9e8029dd3bd9d0a9cc4ab961 and 4024936438654eb729bcc2ec9174efb40e69fd93, which inserted SearchComparator.GE into ProfileGenerator's generated search parameter comparator list. The later 9f549566d1346cad7db6d2afca6080d7cebdfbbe build migration removed that checked-in generator source from core in favor of the Gradle/Kindling build dependency, so there is no current in-repository ProfileGenerator line to edit.

Additional context:
Current active source still defines `clinical-date` as a common search parameter in source/searchparameter/common-search-parameters.xml and keeps AllergyIntolerance and SearchParameter in the active fhir.ini resource list. That checked-in common source intentionally does not enumerate generated comparator arrays. The current search comparator terminology includes `ge`, and both the current CI build and R5 publication surface list `eq,ne,gt,ge,lt,le,sa,eb,ap` for SearchParameter/clinical-date. Community searches found no Confluence or Zulip record contradicting the Jira/source/git evidence; a 2021 implementers thread quoted the clinical-date JSON with `ge` already present.

AutoFHIR reconciliation:
This commit makes no source change because the current generated specification already contains the requested `ge` comparator for clinical-date, including the AllergyIntolerance/common clinical date search parameter family. Adding comparator elements to the checked-in common source would duplicate generated behavior rather than fix a current spec defect.

Recommendation:
Keep this no-change audit commit. No FHIR core follow-up is needed for FHIR-22495 unless a future build regression drops `ge` from generated date search parameter comparator arrays.
