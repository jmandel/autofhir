FHIR-12299: Audit Patient animal breed mapping

Issue request:
FHIR-12299 was a Published/Persuasive Patient Administration change request from DSTU2. It reported that Patient.animal.breed was mapped to v2 PID-37, asked why FHIR carried breed when v2 Breed was deprecated, and noted that PID-35 had been renamed Taxonomic Classification Code. The accepted resolution was to update both Patient.animal.species and Patient.animal.breed to map to v2 PID-35, with breed using PID-35 when a more detailed value is present.

Initial application:
The issue appears to have been applied in git commit 276058c0c9a1ea9d2144a0c2f95d5ba8c2f1d1e2, whose subject was "Tracker #13194, 12594, 12299". That commit changed the Patient spreadsheet source so Patient.animal.breed moved from "PID-37" to "PID-35 (where more detailed value is present)" while Patient.animal.species already mapped to PID-35.

Additional context:
Patient remains an active core resource in source/fhir.ini, but current source/patient/structuredefinition-Patient.xml no longer contains Patient.animal or PID-35/PID-37 mappings. Current veterinary guidance in source/patient/patient-notes.xml points to the standard patient-animal extension. The old CDA profile reference to Patient.animal is in source/profiles/cda.profile.xml, but fhir.ini keeps that profile commented out, so it is not an active build-scope target. The patient-animal extension definition was removed from core in 2023 and now lives in the FHIR Extension Pack, where its current source maps species to PID-35 and breed to "PID-35 (where more detailed value is present)".

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested correction was historically applied, the affected core element is no longer in the current Patient resource, and the current extension-pack replacement already preserves the corrected v2 mapping.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-12299; if future work revisits veterinary mappings, it should inspect the Extension Pack patient-animal extension rather than reintroducing Patient.animal in core.
