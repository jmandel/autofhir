FHIR-6019: Audit Goal reference extension

Issue request:
FHIR-6019 was Published with a Persuasive with Modification disposition for the DSTU1 core Goal issue asking for a common extension that lets other resources reference Goals. The approved resolution was to add the extension, limit it by usage notes to subject-specific activity-related resources such as events and intents, and point to it from the Goal introduction; the association was for observations, prescriptions, or other activities pertinent to Goal achievement rather than for Goal management.

Initial application:
The Jira comments record SVN #6806. In git history that maps to commit 8bd3bd917d537625fad908b5f0f6277d113b941e, whose git-svn-id is build@6806 and whose subject is "Goal tracker items". That commit added the original Goal extension spreadsheet row for pertainsToGoal with type Reference(Goal), requirements saying it would typically link Observations capturing measurements to evaluate a Goal, and the usage note limiting the association to subject-specific activity-related resources.

Additional context:
FHIR-8254 is a direct specialization of this same request for Observation-to-Goal links. FHIR-13895 later moved/renamed the extension to resource-pertainsToGoal, and current core history states that extensions moved to the hl7.fhir.uv.extensions package. The FHIR Extension Pack now contains the authoritative active StructureDefinition-resource-pertainsToGoal definition. FHIR-53828 later raised R6 discoverability after Goal.outcome was removed and is already represented on the combined branch by a no-change audit commit; its application added the current Goal note pointing to resource-pertainsToGoal. FHIR-48360 later rejected adding first-class Goal/Observation references because the existing extension can be used.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Goal is an active current-build resource, the current Goal notes already point implementers to resource-pertainsToGoal and explicitly name Observation as an example, and the extension-pack definition still carries the requested Reference(Goal), measurement/achievement/progress semantics, and subject-specific usage note.

Recommendation:
Keep this audit commit as-is. No FHIR-core edit is needed for FHIR-6019; future changes to the extension definition itself belong in the FHIR Extension Pack, and the unresolved Observation-side awareness request should be reconciled only if OO finalizes it.
