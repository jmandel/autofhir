FHIR-11344: Audit CareTeam performer support

Issue request:
FHIR-11344 was a Published/Persuasive with Modification DSTU2 Patient Care request to allow CarePlan.activity.detail.performer to reference CareTeam and to revise CareTeam boundary text so CareTeam was not described as unable to act when used for care-plan responsibility.

Initial application:
The request was applied in historical commit df58ee3f55, which explicitly cited #11344, added CareTeam to the old CarePlan.activity.detail.performer target list, and replaced the CareTeam boundary sentence that said "CareTeam isn't an actor" with wording about individual members or organized groups of individuals.

Additional context:
CarePlan and CareTeam are active resources in the current build. The old CarePlan.activity.detail element is now mapped forward to CarePlan.activity.plannedActivityReference, and FHIR-39101 later removed the active inline plannedActivityDetail model by commenting out that block. The commented legacy performer block still includes CareTeam, while the active CarePlan activity model uses plannedActivityReference to specific request resources. Current CareTeam boundaries no longer contain the rejected "isn't an actor" statement and retain the "individual members or organized group of individuals" concept, with later FHIR-46553 wording clarifying "Group resource" rather than changing the FHIR-11344 decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. There is no active CarePlan.activity.detail.performer or plannedActivityDetail.performer target list in the current build to modify, and the current CareTeam narrative already avoids the stale actor prohibition while preserving the approved organized-group concept.

Recommendation:
Keep this audit commit as-is. No current FHIR core source fix is needed for FHIR-11344; future work should only revisit this area if Patient Care decides to remove the commented legacy plannedActivityDetail block or reintroduce inline CarePlan activity details.
