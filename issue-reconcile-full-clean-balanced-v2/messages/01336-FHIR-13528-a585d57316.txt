FHIR-13528: Remove stale ClinicalDocument profile link

Issue request:
FHIR-13528 was a Published FHIR-core / Structured Documents change request with resolution Persuasive with Modification. The issue first asked to rename the Clinical Document profile to "CDA on FHIR Profile", but SDWG later reopened the item and voted to undo that direction: the profile should remain ClinicalDocument / Clinical Document, and profile pages should not use "CDA on FHIR" or "CDA in FHIR" as the profile name.

Initial application:
The issue was applied before this reconciliation. Commit 8610555c84de813fe4eb56b23123645881940256 initially renamed the Composition ClinicalDocument profile source to CDA on FHIR. Commit 9918d179fbe866e2bebc244da795cba15eb538ba then reversed that change, deleting the CDA-on-FHIR profile spreadsheet/introduction source, restoring composition-clinicaldocument source, and changing the Composition introduction link text from "CDA on FHIR profile" to "Clinical Document profile".

Additional context:
Later issue FHIR-34407 superseded the profile-naming target by removing the ClinicalDocument Composition profile entirely. Commit 938bdf21940e09a728baa17dc0060c413a0054c7 deleted the current-source ClinicalDocument StructureDefinition and ImplementationGuide, and the combined reconciliation branch already contains a FHIR-34407 audit commit. Current source/fhir.ini still builds Composition as an active resource, but the old cda profile entry is commented out and the ClinicalDocument profile source files are absent. The active Composition introduction nevertheless still pointed "Clinical Document profile" at composition-core.html, which now renders as the unrelated Composition HL7 Extensions page.

AutoFHIR reconciliation:
This commit updates the active Composition introduction so it no longer claims that a ClinicalDocument profile constrains Composition or links readers to composition-core.html for that retired profile. It now points readers to the CDA-aware note and CDA comparison page for the current Composition/CDA relationship. Retired out-of-build profile artifacts, including the commented source/profiles/cda.profile.xml hook and orphaned composition-clinicaldocument-introduction.xml, were left untouched.

Recommendation:
Keep this source fix. It preserves the FHIR-13528 decision not to call the profile "CDA on FHIR" while also reflecting the later FHIR-34407 decision that there is no current core ClinicalDocument profile. No additional core profile-naming work is needed unless SDWG creates a new ClinicalDocument profile in a future project.
