FHIR-11293: Audit Observation.specimen guidance

Issue request:
FHIR-11293 was a Published/Persuasive with Modification DSTU2 Observation change request from OO. It asked to add a comment to Observation.specimen saying it should be used if not implicit in Observation.code, based on similar BodySite and method guidance.

Initial application:
The request was applied in git commit 29f4601440af8375fc9f1e19f0d38727cd29aec4, which changed the Observation spreadsheet source for Observation.specimen to say it should only be used if not implicit in `Observation.code` and retained surrounding specimen guidance. The current build no longer uses that spreadsheet as the authoritative source, but the change flowed into the later structuredefinition source history.

Additional context:
Observation is an active resource in source/fhir.ini, and the current authoritative source is source/observation/structuredefinition-Observation.xml. A later Applied/Persuasive with Modification OO issue, FHIR-50127, specifically reconsidered the same Observation.specimen comment for R6 and resolved to replace the older "implicit in code" guidance with a stronger SHOULD-use statement when the observation is performed on a specimen. Commits 21683fadd8f2c1b2336bfe1507f944af7f016494 and 1b060a6f4f9faceab7db263ea23d3efc9a69cd2f made that source change and conformance-word capitalization. The combined branch already contains a reconcile audit for FHIR-50127 as fab383b33b0a6d145bb15e6b283983159dfb8604, so this seed should not duplicate that related issue.

AutoFHIR reconciliation:
No source change was made. The current Observation.specimen comment reflects the later FHIR-50127 decision: "SHOULD be used when the observation is performed on a specimen. The type of specimen SHOULD be consistent with anything implied in the `Observation.code` value." Reverting or re-adding the FHIR-11293 wording would conflict with the newer applied issue.

Recommendation:
Keep this audit commit as-is. The current source is correct for the seed when later WG intent is considered; any future change to the specimen guidance should be handled as a new OO decision rather than by restoring the DSTU2 wording.
