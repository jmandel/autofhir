FHIR-40732: Audit concept-order extension relocation

Issue request:
FHIR-40732 was an Applied FHIR-core vocab change request asking to deprecate the codesystem-conceptOrder extension because presentation order is context/value-set specific rather than inherent to a CodeSystem. The accepted 2024-03-25 TI decision was to deprecate the extension.

Initial application:
The core checkout no longer owns the extension definition: commit dd468d4f17 removed core extension definitions, including source/codesystem/structuredefinition-extension-codesystem-conceptOrder.xml, before this Jira was applied. The issue appears to have been applied in the FHIR Extension Pack by commit 2d8d674, which added deprecated standards-status to input/definitions/CodeSystem/StructureDefinition-codesystem-conceptOrder.xml. There is no current core source file for this StructureDefinition; the core checkout only retains the canonical OID mapping in source/oids.ini.

Additional context:
FHIR-43385 later added the standard CodeSystem concept property `order` to current core source. FHIR-43396, a Published FHIR-extensions issue for the same extension, refined the outcome from deprecating the extension to restricting it to versions prior to R6. The current Extension Pack source reflects that later decision with version-specific-use endFhirVersion 5.0 and description text saying that in R6+ the order property is used in place of this extension; it is active/trial-use rather than deprecated.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR-core source change. The live extension definition and any remaining maintenance belong to the FHIR Extension Pack, not this core checkout, and the current core source already contains the replacement `order` concept property.

Recommendation:
Keep this empty external-repo audit commit as the core reconciliation record. Do not add a core copy of the extension or remove the OID mapping; any future adjustment to the extension definition should be made in HL7/fhir-extensions and should account for FHIR-43396's pre-R6-only resolution.
