FHIR-40739 was an Applied/Persuasive with Modification Vocabulary change request for the CodeSystem sourceReference extension. It originally asked that http://hl7.org/fhir/StructureDefinition/codesystem-sourceReference and codesystem-authoritativeSource reference each other and clarify their difference, but the final 2024-03-25 resolution was to deprecate the sourceReference extension.

Initial application:
No prior FHIR core commit was found for FHIR-40739, and the current core source has no active fhir.ini entry or StructureDefinition source for codesystem-sourceReference or codesystem-authoritativeSource. The implementation trail points to HL7/fhir-extensions, where commit 2d8d674 added deprecated standards-status markers for both CodeSystem extensions, and later commits d0ac764 and ea2d7b0 added deprecation rationale and retired the sourceReference extension.

Additional context:
The 2024-03-25 Vocabulary minutes record that the group reviewed FHIR-40739, found the sourceReference description nonsensical in the CodeSystem context, and resolved to deprecate the extension. The neighboring codesystem-authoritativeSource issue, FHIR-40730, was discussed in the same minutes and was also resolved for deprecation, so the original request to make the two extensions explain their differences is superseded by retiring/deprecating the maintained extension definitions. Core still only carries OID registrations for these URLs; the active extension definitions live in the Extension Pack checkout.
