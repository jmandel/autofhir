FHIR-28205: Audit CQF Questionnaire SDC guidance

Issue request:
FHIR-28205 was Published with a Persuasive with Modification resolution. The issue asked for clarification of CQF-Questionnaire use of cqf-expression on Questionnaire.item, including whether calculated values, editability, answer options, and related behavior were defined by the profile or by downstream use cases. The final resolution was not to extend the CQIF-Questionnaire profile, but to deprecate it in favor of SDC questionnaire profiles and update the documentation to reference the SDC IG.

Initial application:
No git commit in the current history directly mentions FHIR-28205. The same change family appears to have been applied by bc30255627a58b5e899f1afd7a087806ab48ac23, which cites J#30204 and J#21005, removes the CQF Questionnaire profile/example/IG entries, and replaces the Documentation Template CQF-Questionnaire narrative with a Structured Data Capture IG reference.

Additional context:
FHIR-21005 requested withdrawing CQIF Questionnaire in favor of SDC, and FHIR-30204 requested eliminating CQF Questionnaire and pointing CQF documentation to SDC. FHIR-I WGM 202101 minutes also record that CQF would point to SDC for using CQL with Questionnaires. The current Extension Pack cqf-expression definition likewise tells questionnaire readers to use SDC guidance. A direct search found no Zulip or Confluence references to FHIR-28205 that conflict with this source/history trail.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active Clinical Reasoning source already says the Questionnaire resource can use expression extensions for dynamic behavior and that the Structured Data Capture IG provides profiles and guidance for this and other data capture use cases. The page is in the build through publish.ini/hierarchy.xml, and current source no longer contains stale CQF-Questionnaire, CQIF-Questionnaire, or questionnaire-cqf-example references.

Recommendation:
Keep this no-change audit. Further normative or implementer-detail changes about cqf-expression behavior in questionnaires should be handled in SDC or the Extension Pack unless a new core issue explicitly asks for core Clinical Reasoning text.
