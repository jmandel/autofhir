FHIR-13150: Audit detected issue guidance supersession

Issue request:
FHIR-13150 was Published/Persuasive for STU3. It asked Pharmacy to review the DetectedIssue attribute in MedicationRequest and MedicationDispense and add description or definition text so implementers understood what information the attribute conveyed and how it could be used.

Initial application:
The Jira comment says the issue was applied on 2017-08-18 in SVN/Git commit ccfc10c2b0d8324e7805bdad3489470709201430. That commit added the same explanatory comment to the then-current MedicationRequest.detectedIssue and MedicationDispense.detectedIssue spreadsheet rows: the element could include a detected issue identified by a decision support system or clinician and could include information on steps taken to address the issue.

Additional context:
The current build no longer has MedicationRequest.detectedIssue or MedicationDispense.detectedIssue elements. Later Published issue FHIR-34293 required removal of those direct links from both resources because DetectedIssue points to implicated therapies and FHIR references are not bidirectional. Historical commit 26e2a82259 removed the direct elements, and combined-branch reconciliation commit e25b1231a9ed3c4fec8abcdec9281d95a66dd10c completed the remaining Medication Module guidance by explaining DetectedIssue.implicated, direct searches, _revinclude, and containment. Later FHIR-39018 was resolved Not Persuasive and reaffirmed that the search parameter on DetectedIssue is the intended retrieval path.

AutoFHIR reconciliation:
Made no source change. The original FHIR-13150 guidance was applied to elements that have since been intentionally removed, and the latest combined branch already has the replacement module guidance required by the later Pharmacy decision. Reintroducing local comments or direct medication-to-DetectedIssue references would conflict with the later current-spec design.

Recommendation:
Keep this audit commit as-is. No FHIR-13150 source edit is needed unless Pharmacy reopens the later DetectedIssue design; any future clarification should be made in the Medication Module or DetectedIssue retrieval guidance rather than on removed MedicationRequest.detectedIssue or MedicationDispense.detectedIssue elements.
