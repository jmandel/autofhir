Initial application:

Additional context:
MedicationAdministration is an active current-build resource in source/fhir.ini. The source was later refactored from spreadsheets into StructureDefinition XML, and the current authoritative XML still contains MedicationAdministration.performer.function as a CodeableConcept with example binding to http://hl7.org/fhir/ValueSet/med-admin-perform-function. FHIR-19618 later corrected spelling in the MedicationAdministration value set names, and FHIR-46960 later rejected changing the performer.function short description because it is inherited from the Event pattern. The referenced Zulip thread confirms the original problem: MedAdmin had a performer without a type after workflow alignment.
