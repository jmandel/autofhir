FHIR-41872: Audit BDP dispense release clarification

Issue request:
FHIR-41872 was an Applied/Persuasive with Modification FHIR-core request for R6 asking that BiologicallyDerivedProductDispense clarify that a dispense should only be completed after necessary product approvals and medical release conditions for the patient have occurred. The original proposal also suggested removing preparation and in-progress statuses, but the final approved resolution adopted the scope wording that a dispense is typically considered completed, i.e. status=allocated or issued, after necessary medical release conditions have been met.

Initial application:
The request was applied in core by commit ef2a727c1576e6c14864af62f868570203a3397c on 2024-04-15, which added the approved scope sentence to source/biologicallyderivedproductdispense/biologicallyderivedproductdispense-introduction.xml. The local core source copy still contains that sentence. The related status value set retained preparation and in-progress, consistent with the earlier Published FHIR-40329 status-code decision and with FHIR-41872's final scope-only modification.

Additional context:
BiologicallyDerivedProductDispense is no longer an active FHIR-core build resource. source/fhir.ini has no active biologicallyderivedproductdispense resource entry, and commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed the OO additional-resource entries while pointing the BDP module to the OO Incubator IG; commit 01706a920f4e88452c409c2cc0b7c74f09ac51c6 corrected those links to https://build.fhir.org/ig/HL7/oo-incubator/. The current HL7/oo-incubator source file input/pagecontent/StructureDefinition-BiologicallyDerivedProductDispense-intro.xml contains the same FHIR-41872 scope sentence. FHIR-53609 tracks exposing incubator intro content but is an external, Resolved - change required issue and not a core-source edit in this run.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Editing source/biologicallyderivedproductdispense in this checkout would alter an out-of-build core copy, not the current core specification. The current active core pages link to the OO Incubator artifact, and the corresponding OO Incubator source already carries the approved FHIR-41872 clarification.
