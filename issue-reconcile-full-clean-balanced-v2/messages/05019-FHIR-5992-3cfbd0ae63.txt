FHIR-5992: Audit medication form value set

Issue request:
FHIR-5992 was a Published/Persuasive DSTU1 Pharmacy correction reporting that the expansion for http://hl7.org/fhir/vs/medication-form-codes showed administration routes rather than medication forms. The accepted resolution was to fix the Medication.product.form binding to use the medication-form-codes value set defined from SNOMED CT descendants of 421967003.

Initial application:
The Jira comments say this was fixed in svn 6615. In git history, commit c74b8e3ebb (#6219, #7262, several other duplicates) is that svn 6615 source change and updates source/medication/valueset-medication-form-codes.xml from the SNOMED route-of-administration parent 284009009 to the medication-form parent 421967003. The current build source has since been refactored from Medication.product.form to Medication.doseForm, but the active Medication source still binds that element to http://hl7.org/fhir/ValueSet/medication-form-codes.

Additional context:
Later Published Pharmacy issue FHIR-19296 deliberately changed the medication form binding from 421967003 to the newer SNOMED CT parent 736542009 (Pharmaceutical dose form). FHIR-22272 was marked duplicate of FHIR-19296 for the same 421967003 versus 736542009 correction, and FHIR-24700/FHIR-25441 document the later tooling-expansion problem for 736542009 rather than reverting the terminology scope. The combined branch already has an audit commit for FHIR-19296, so this seed should be interpreted as the original route-code error being fixed and then superseded by the later dose-form parent change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source/medication/valueset-medication-form-codes.xml includes SNOMED CT descendants of 736542009, which is a medication dose-form hierarchy, not the route-code hierarchy that FHIR-5992 reported. source/medication/structuredefinition-Medication.xml and source/medicationknowledge/structuredefinition-MedicationKnowledge.xml bind their doseForm elements to that ValueSet, and source/fhir.ini includes Medication and MedicationKnowledge as active current-build resources.

Recommendation:
Keep this audit commit as-is. Do not restore the older 421967003 parent from the DSTU1 resolution, because later Published issue FHIR-19296 intentionally replaced it with 736542009. No follow-up in core is needed for FHIR-5992 unless a future terminology decision changes the medication dose-form hierarchy again.
