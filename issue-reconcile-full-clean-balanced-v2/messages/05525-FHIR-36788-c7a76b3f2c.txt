FHIR-36788: Audit Transport status reconciliation

Issue request:
FHIR-36788 was Published/Persuasive with Modification for FHIR-core Transport in R5. It asked to update Transport.status to a required value set containing in-progress, completed, abandoned, cancelled, planned, and entered-in-error, and to add an example statusReason value set/code system with declined/refused/not-available/wrong-data/accident/not-acknowledged reasons.

Initial application:
The issue was applied in 2022 through the Jira-linked Transport source updates, including commit 88a67482e7, which updated Transport.status, added transport-status-reason source, and bound Transport.statusReason to the new example value set. Follow-up QA commits normalized the checked-in CodeSystem/ValueSet source but preserved the statusReason concepts.

Additional context:
Transport is active build scope as an OO resource in source/fhir.ini. Later final R6 decisions intentionally changed the status interpretation: FHIR-39512 aligned Transport with Event semantics, FHIR-40491 was Applied/Persuasive and replaced the old mixed request/event Transport.status list with preparation | in-progress | not-done | suspended | stopped | on-hold | completed | entered-in-error | unknown, and FHIR-50642 was Resolved - No Change for adding a pending/planned request status because Transport is an Event resource and request state belongs on the related Request. FHIR-40749 separately corrected the statusReason CodeSystem name.

AutoFHIR reconciliation:
This audit commit makes no source change. The current source already carries the FHIR-36788 statusReason binding and concepts, and the mismatch between the current Transport.status codes and the original FHIR-36788 status list is explained by later final Transport/Event decisions that should not be reverted.

Recommendation:
Keep this no-change audit. Do not reinstate the R5 planned/cancelled/abandoned status list without new OO work-group direction; current Transport.status should remain governed by the later Event-oriented Transport decisions.
