FHIR-24885: Audit agreement-scope usage context

Issue request:
FHIR-24885 was a Published, Persuasive with Modification FHIR-I change request originally asking for ImplementationGuide.kind to identify the nature of implementation guides. The accepted resolution did not add a direct ImplementationGuide.kind element; it instead required a new usage-context-type code agreement-scope, a new usage-context-agreement-scope code system and whole-system value set, and inclusion of that value set in the broad Context of Use ValueSet.
