FHIR-13013: Audit Provenance activity value set outcome

Issue request:
FHIR-13013 was Published with resolution Persuasive with Modification. It reported that the Provenance.activity value set was unusable because it mixed change activities with statuses, reads/executes, obligation policies, and v3-oriented labels, and the accepted resolution asked to use a limited extensible subset focused on provenance-causing activities such as create, delete, update, append, nullify, anonymize/de-identify/mask, privacy marking, and legal authentication/signature cases.

Initial application:
The issue appears to have been applied by git commit df8241d8ed19f08b12c18f34bf71c7bdbf611ef9, which updated Provenance narrative and reduced the then-current source/provenance/valueset-provenance-activity-type.xml to selected DocumentCompletion, ActCode, and DataOperation concepts while commenting out ActStatus, ObligationPolicy, W3C, and extra activity includes. That implementation was close to the requested subset but not the final current policy for the same value set.

Additional context:
Later final same-artifact decisions changed how the old DSTU2 request should be interpreted now. FHIR-19410 removed v3 ParticipationType role/function codes and is already represented on the combined branch. FHIR-22104 and FHIR-23712 added and then broadened activity vocabulary, but FHIR-32517 later superseded that broad model by making Provenance.activity an example binding and simplifying ProvenanceActivityType to representative ISO 21089 lifecycle examples. FHIR-55798 and FHIR-55797 then clarified that example value set description and added destroy. The current source should therefore not be changed back to the FHIR-13013-era v3 subset or extensible binding.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Provenance is an active resource in source/fhir.ini; current source/provenance/structuredefinition-Provenance.xml binds Provenance.activity with strength example to http://hl7.org/fhir/ValueSet/provenance-activity-type; and source/terminologies/valueset-provenance-activity-type.xml now contains only a small representative ISO 21089 lifecycle activity set, including destroy. The original problem of using an incoherent extensible grab-bag for the base Provenance.activity binding is no longer present.

Recommendation:
Keep this audit commit as-is. No core FHIR source change is recommended for FHIR-13013; any future Provenance.activity vocabulary expansion should be raised as a new Security WG issue rather than by reopening the obsolete DSTU2 subset request.
