FHIR-23722: Audit message Bundle content rule

Issue request:
FHIR-23722 was a Published/Persuasive with Modification FHIR-core messaging change request, raised against STU3 and applied for R5, asking the messaging page to state what may appear in a message Bundle. The approved wording required the MessageHeader, any resources referenced by MessageHeader.focus and MessageHeader.response.details, allowed additional resources only when traversal by Reference or canonical links connects them to or from the MessageHeader, and said the Bundle SHOULD include resources needed to process the MessageHeader.event.

Initial application:
The issue was directly applied by git commit 5f469dee282a284b707d08a47f140a2467150b23, which expanded source/messaging.html from a short prose paragraph into the current message Bundle rules. The original application had some rough wording, but it introduced the substantive focus/response-details inclusion rule, the additional-resource permission, and the graph/traversal constraint that implements the Jira resolution.

Additional context:
Later same-family decisions refined the exact expression of the rule without reversing it. FHIR-25257 added and has now reconciled the general rule that every message Bundle resource must be connected directly or indirectly to the MessageHeader. FHIR-43295 clarified that the document and message must-link rules are met through RESTful references, and source/messaging.html now uses connected-graph wording with Reference.reference, canonical, or URI links and points to the shared Graph-connected Bundles section. Those later decisions make the current connected-graph formulation the correct current wording rather than the older literal FHIR-23722 sentence.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active messaging page already requires MessageHeader as the first message Bundle entry, requires any MessageHeader.focus and MessageHeader.response.details resources to be included, permits needed additional resources, prohibits resources outside a connected graph that includes MessageHeader, and repeats the connected-graph rule in Basic Messaging Assumptions. The page is part of the current core documentation surface and is linked from source/documentation.html; MessageHeader remains an active resource in source/fhir.ini.

Recommendation:
Keep this empty audit commit as-is. No further FHIR core edit is needed for FHIR-23722 unless a future work-group decision intentionally changes the graph-connected message Bundle model; any such change should be handled through the later graph/reference issue family rather than by restating the 2019 resolution verbatim.
