FHIR-3545: Audit ImagingStudy description

Issue request:
FHIR-3545 was Published/Persuasive with Modification for DSTU1 by Imaging Integration. It asked to update the ImagingStudy resource description so ImagingStudy represents the content produced in one DICOM imaging study, comprising series and SOP Instances acquired or produced in a common context, and to disambiguate that from a manifest of an arbitrary set of SOP Instances that might come from multiple studies.

Initial application:
The Jira-tagged implementation commit e621d20623aabcc8c4ceddf6fc115cc185c914c0 changed the then-authoritative ImagingStudy spreadsheet, replacing the old manifest wording with the FHIR-3545 DICOM-study description. Later source refactors moved the resource definition into source/imagingstudy/structuredefinition-ImagingStudy.xml.

Additional context:
ImagingStudy is an active resource in source/fhir.ini, so source/imagingstudy/structuredefinition-ImagingStudy.xml and source/imagingstudy/imagingstudy-introduction.xml are in current build scope. Current source still carries the important DICOM-study distinction: the resource description and root definition say ImagingStudy is a representation of content produced in a DICOM imaging study with series and SOP Instances in a common context, the introduction says an ImagingStudy provides information on a single DICOM imaging study, and the scope text states one ImagingStudy resource SHALL reference one DICOM Study. Later Applied R6 issues refined this wording: FHIR-50769 retained the single-DICOM-study scope, FHIR-50771 aligned the root detailed definition to the current resource description and intentionally removed the older local modality sentence, and FHIR-50775 completed adjacent ImagingStudy description updates.

AutoFHIR reconciliation:
This empty audit commit makes no source change. The current build-scoped source already preserves the semantic correction FHIR-3545 requested, and re-adding the older modality sentence from the DSTU1 resolution would be redundant with current modality elements and inconsistent with the later FHIR-50771 reconciliation already present on the combined branch.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-3545 unless the work group reopens ImagingStudy scope wording more broadly.
