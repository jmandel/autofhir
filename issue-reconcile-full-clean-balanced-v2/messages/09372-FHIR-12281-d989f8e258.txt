FHIR-12281: Audit XHTML active-content schema restrictions

Issue request:
FHIR-12281 was a Published/Persuasive FHIR-core change request for the Narrative/XHTML page. It reported that fhir-xhtml.xsd allowed content the narrative rules already prohibited, including active XHTML/event attributes such as onClick, scripts, forms, head/body content, and other banned elements.

Initial application:
The issue appears to have been applied by git commit f5e1ff77b89f4d5b48cf7e5d3aa6296f71235683 on 2016-10-17, whose message explicitly says it fixes 12281 and replaces source/fhir-xhtml.xsd with a pared-down XHTML schema. The current source schema still omits the event attributes from the common attribute group and leaves script, forms, object, and document-structure elements outside the allowed content model. A later build refactor added the same restricted schema under tools/schema/fhir-xhtml.xsd.

Additional context:
source/fhir.ini maps both Narrative and xhtml to the narrative page, and source/narrative.html still states the normative rule that XHTML content SHALL NOT contain active content or event related attributes. Later source/fhir-xhtml.xsd edits only adjusted punctuation/QA text and did not reopen active XHTML. Jira search found only FHIR-12281 for the active-XHTML/onmouse question, Zulip search found only tracker/commit bot notifications, and Confluence search found no referenced or conflicting work-group record.

AutoFHIR reconciliation:
No source change was made. The current schema and narrative source already reflect the requested restriction, and xmllint validation against source/fhir-xhtml.xsd accepts a simple styled div while rejecting onclick, script, form, and body examples.

Recommendation:
Keep this audit commit as-is. No current core source follow-up is needed unless a future work-group decision intentionally changes which XHTML elements or attributes are allowed in Narrative.div.
