Issue request:
FHIR-40622 was a Published/Persuasive R5 technical correction for DiagnosticReport dgr-1. It asked to replace the overly broad Composition-descendants rule with text and FHIRPath requiring Observation resources referenced from Composition entries to also be referenced by DiagnosticReport.result or by Observation.hasMember from those results.

Initial application:
The issue was initially applied in git commit 2333cec1ec, which changed source/diagnosticreport/structuredefinition-DiagnosticReport.xml from the descendants/id expression to the proposed Composition.entry Observation/reference expression and added dgr-1 invariant examples.

Later FHIR-45964 corrected the human-readable dgr-1 text in commit 892cd5451d, and a later validator-compatibility change in commit dd240588aa1 fixed the expression form to use all() and %resource while preserving the FHIR-40622 semantics.
