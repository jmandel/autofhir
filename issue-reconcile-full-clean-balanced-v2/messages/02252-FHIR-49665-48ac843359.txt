FHIR-49665: Audit moved MPHO examples

Issue request:
FHIR-49665 was Applied/Persuasive for R6 and asked to add two BiologicallyDerivedProduct examples that comply with the Medical Product of Human Origin (MPHO) profile: an apheresis platelet product using ISBT 128 product code E3046 and a red blood cell product with a red cell antigen profile using product code E0398.

Initial application:
The request was initially applied in core by commits 8b315006f80ec885fd8093ef732a70889ab99e89 and 16d36096dbf0c4d53dbaf1c18e34a82ff66438ce. Those commits added source/biologicallyderivedproduct/biologicallyderivedproduct-example-red-cell-antigen.xml and source/biologicallyderivedproduct/biologicallyderivedproduct-example-apheresis-platelet.xml and registered both examples in source/biologicallyderivedproduct/list-BiologicallyDerivedProduct-examples.xml.

Additional context:
Later OO decisions FHIR-52021 and FHIR-54998 concluded that the MPHO profile was not ready to remain in FHIR core and should move to the OO Incubator IG. Commit 6bf92471f8ac024d9dcfc067a2aab9f70a9416d9 removed the MPHO profile and the two FHIR-49665 examples from core, and the active BiologicallyDerivedProduct introduction now says the MPHO profile has moved to the OO Incubator IG. The HL7/oo-incubator source currently contains the MedicalProductOfHumanOrigin profile plus the apheresis platelet and red cell antigen examples as FSH artifacts.

AutoFHIR reconciliation:
This is an empty audit commit. It intentionally makes no core source change because re-adding MPHO-profile examples to FHIR core would reverse the later profile migration. The seed issue has been reconciled as external-repo for current core: the examples belong with the MPHO profile in the OO Incubator IG, not in the active core BiologicallyDerivedProduct example list.

Recommendation:
Keep this audit commit as-is for FHIR core. Any further work on these examples should happen in HL7/oo-incubator alongside the MedicalProductOfHumanOrigin profile, especially if the work group wants to correct or refine ISBT 128 URI casing, profile slicing, or example details there.
