FHIR-17510: Audit TestScript rule/ruleset move

Issue request:
FHIR-17510 was Published/Persuasive for STU3/R4 and asked to remove the TestScript rule and ruleset elements because support for external rules engines caused compatibility problems between FHIR test engines. The resolution also said to use extensions for cases where those details were still needed.

Initial application:
The request was applied in core source by commit 2adf2bc16064ef00751f144ee1437455bba61b42, whose message says "GF 17510 - rule and ruleset elements removed". That commit deleted the rule-based TestScript example and removed TestScript.rule, TestScript.ruleset, TestScript.setup.action.assert.rule, and TestScript.setup.action.assert.ruleset from the TestScript spreadsheet while leaving TestScript.setup.action.assert.expression available for FHIRPath-based assertions.

Additional context:
Current core build scope no longer owns TestScript. source/fhir.ini now lists the FHIR Testing IG as an additional IG and does not list testscript in the active [resources] section; commit f9a44787c45071394532c7c2ee94d76f30f47387 removed TestScript, TestReport, and TestPlan from core source and pointed core narrative to the external Testing IG. The live FHIR Testing IG TestScript StructureDefinition also lacks rule/ruleset elements and still includes assert.expression. FHIR-19284, which shared the same 2018 application commit, is already represented on the combined branch as an external-repo audit.

AutoFHIR reconciliation:
This is an empty external-repo audit commit. No core source was changed because the FHIR-17510 removal is already reflected in the current authoritative TestScript artifact, and TestScript changes now belong to the external FHIR Testing IG rather than this core source checkout.

Recommendation:
Keep this audit as-is for the core combined branch. If the work group still wants standard extensions for external rule/ruleset metadata, that should be evaluated in the FHIR Testing IG or extension-maintenance workflow rather than by restoring or editing removed core TestScript files.
