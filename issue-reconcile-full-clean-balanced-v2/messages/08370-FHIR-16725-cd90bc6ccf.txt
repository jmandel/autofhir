FHIR-16725: Audit Observation category wording

Issue request:
FHIR-16725 was a Published/Persuasive OO technical correction for the STU3 Observation category code system text. It asked that the procedure category definition replace the ambiguous "such as where" clause with two clearer sentences ending in the gastroenterologist/polyp/colonoscopy example.

Initial application:
The change was applied before this reconciliation in git commit e6081d74315d0c3701a49890e164e184283df549, whose message lists GF#16725 and changes source/observation/codesystem-observation-category.xml from "such as where" to "An example would be when". No separate prior Issue-Reconcile-Key commit existed on the combined branch.

Additional context:
The Observation resource is active in source/fhir.ini, but the Observation category CodeSystem source that carried this wording was removed from core in 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 as part of moving UTG content out of the core build. Current core source keeps source/observation/valueset-observation-category.xml, which includes http://terminology.hl7.org/CodeSystem/observation-category, and Observation.category binds to that ValueSet. The current published THO CodeSystem definition for the procedure code already contains the corrected wording.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current core source no longer owns the moved CodeSystem definition, and the external terminology definition consumed by the current core ValueSet is already correct.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-16725; if this wording is revisited in the future, it should be handled in the terminology source of truth rather than by reintroducing a core CodeSystem source file.
