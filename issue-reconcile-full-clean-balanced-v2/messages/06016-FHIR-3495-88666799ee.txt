The accepted resolution kept Location.name singular and added a standard Alias extension with search support for local contexts.

Additional context:
Location is active in source/fhir.ini. Current source/location/bundle-Location-search-params.xml defines Location-name over Location.name and Location.alias. FHIR-13345 later removed the redundant standard alias extension after alias existed in core. Zulip, Confluence, and Extension Pack searches found no conflicting current evidence for reintroducing the old extension in core.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-3495; FHIR-9624 and FHIR-13345 explain why the current source uses a core element instead of preserving the old Location alias extension.
