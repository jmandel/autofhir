FHIR-51111: Audit TestScript expression update location

Issue request:
FHIR-51111 was Applied with a Persuasive with Modification resolution. It asked to move TestScript away from path-only usage by updating expression elements to the Expression data type, documenting support for multiple expression languages, and deprecating rather than removing the existing path elements.

Initial application:
The request was applied in core by ba91e922ce318538784226167ba47b70cf786729, merged through HL7/fhir#3508, alongside FHIR-51024 and FHIR-51025. That commit added TestScript.fixture.expression, changed TestScript.variable.expression, TestScript.setup.action.assert.compareToSourceExpression, and TestScript.setup.action.assert.expression from string to Expression, converted several TestScript examples to nested Expression values, and marked TestScript.variable.path, compareToSourcePath, and assert.path as deprecated.

Additional context:
FHIR-I minutes for 2025-06-23 record the 12-0-0 vote for the Persuasive with Modification resolution. A later core commit, f9a44787c45071394532c7c2ee94d76f30f47387, removed TestScript, TestReport, and TestPlan from core and added a Testing IG reference. Current source/fhir.ini no longer has TestScript in the active [resources] list, source/ballot-intro.html links TestScript to the FHIR Testing IG, and the current HL7/fhir-testing-ig source/build includes TestScript as an R6 additional resource with the FHIR-51111 Expression-typed elements and deprecated path elements.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current FHIR core checkout is correct not to re-add or edit TestScript because the authoritative TestScript resource definition now lives in the external FHIR Testing IG, and the external source checked during this reconciliation preserves the requested FHIR-51111 semantics.

Recommendation:
Keep this audit commit as-is for the core reconciliation. Future TestScript expression/path work should be made in HL7/fhir-testing-ig rather than by restoring source/testscript to the core FHIR repository.
