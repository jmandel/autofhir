FHIR-27919: Audit Statistic event count move

Issue request:
FHIR-27919 was Published/Persuasive for R5 and asked to remove Statistic.sampleSize.numeratorCount, add a separate event-count element, and update Evidence examples that used numeratorCount. The tracker summary/intro names numberOfParticipants, but the detailed proposed solution, accepted resolution, and implementation trail identify the replacement event-count element as Statistic.numberOfEvents, with integer rather than decimal type.

Initial application:
Commit 4cc2c6dbbb ("J# 27919 Made the change to the Statistic DataType and updated the Evidence examples to reflect that change") applied the request by adding Statistic.numberOfEvents in source/datatypes/statistic.xml and replacing numeratorCount with numberOfEvents in the affected Evidence examples. There was no prior Issue-Reconcile-Key commit for FHIR-27919 on the combined branch.

Additional context:
Later Statistic/Evidence refactors changed the source shape. FHIR-31866 moved the Statistic content into the active Evidence resource, and FHIR-31564 removed the standalone source/datatypes/statistic.xml spreadsheet. FHIR-30177 later changed the count datatypes, including numberOfEvents and sampleSize.numberOfParticipants, to unsignedInt and is already represented on the combined branch. FHIR-31493 later adjusted adjacent event/affected count guidance and is also already represented.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build has Evidence active in source/fhir.ini, the authoritative current source defines Evidence.statistic.numberOfEvents and Evidence.statistic.sampleSize.numberOfParticipants as unsignedInt, and Evidence.statistic.sampleSize.numeratorCount is absent. The Evidence examples that formerly used numeratorCount now use numberOfEvents for the event counts, so the approved change has already been preserved through the current Evidence source model.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-27919 unless the work group reopens the event-count model; do not edit the removed Statistic spreadsheet, and do not reinterpret the summary typo as a request to collapse event counts into sampleSize.numberOfParticipants.
