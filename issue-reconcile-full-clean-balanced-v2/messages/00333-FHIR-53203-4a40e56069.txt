FHIR-53203: Audit OO bodyStructure adoption

Issue request:
FHIR-53203 is an Applied/Persuasive OO R6 change request asking resources that include bodySite to adopt bodyStructure as CodeableReference(BodyStructure), to deprecate Observation.bodySite and related search parameters, and to use the SNOMED CT Body Structures example binding where a codeable value is supported.

Initial application:
The Jira comments identify HL7/fhir PR #3793 and follow-up PR #3859 as the application path. Local history shows PR #3793 merged e5edada2d0 after commits 696ac9113f and 27683446f3 updated Observation, ObservationDefinition, ServiceRequest, DeviceUsage, and DocumentReference bodyStructure definitions/search parameters; PR #3859 merged ff72f09dd4 and removed the deprecated ServiceRequest.bodySite element and search parameter. Those commits did not change Specimen.

Additional context:
Observation, ObservationDefinition, ServiceRequest, and Specimen are active resources in source/fhir.ini. The current source has Observation.bodySite deprecated, Observation.bodyStructure / ObservationDefinition.bodyStructure / ServiceRequest.bodyStructure as CodeableReference(BodyStructure) with the body-site example binding, and paired reference/code search parameters for those bodyStructure elements. Specimen.collection.bodySite remains named bodySite but is already CodeableReference(BodyStructure) with the body-site binding from the earlier Published FHIR-33072 decision. Later issue FHIR-53457 removed the deprecated Observation.bodySite binding. Later bodySite/bodyStructure harmonization is not settled through this applied seed: FHIR-55603 was Resolved - No Change because the proposed two-element pattern needed more discussion, and FHIR-54843 is currently Resolved - change required with open PR #4107 to rename Specimen.collection.bodySite, change cardinalities, and make broader BodyStructure guidance updates.

AutoFHIR reconciliation:
This commit is intentionally empty. The current active source already contains the Jira-linked FHIR-53203 application for Observation, ObservationDefinition, and ServiceRequest, while Specimen already satisfies the CodeableReference(BodyStructure) datatype/binding part through FHIR-33072. The remaining Specimen rename/cardinality harmonization is now governed by FHIR-54843 and open PR #4107, so making a partial source edit under FHIR-53203 would duplicate or pre-apply a later not-yet-applied decision.

Recommendation:
Keep this no-change audit commit as-is for FHIR-53203. Let FHIR-54843 / PR #4107, or its successor if revised, handle the remaining Specimen naming/cardinality and broader bodyStructure guidance work as a separate applied change.
