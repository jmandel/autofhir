FHIR-14166: Audit retired ResearchStudy sponsor definition

Issue request:
FHIR-14166 was a Published/Persuasive BRR change request raised for STU3. The Jira snapshot says the BR&R subgroup agreed to change the definition of the ResearchStudy.sponsor element and records that the change was made and published in the Dec 2017 FHIR ballot.

Initial application:
The issue was applied in the old ResearchStudy spreadsheet by commit 61b5fa5576, which explicitly lists GF#14166. That commit changed the ResearchStudy.sponsor definition from a generic responsible organization to an organization that initiates the investigation and is legally responsible for the study. The Jira snapshot's researcher-overseeing-study wording also appears in the same commit, but on ResearchStudy.principalInvestigator under the neighboring GF#14168 change, so the historical application trail is real even though the Jira prose overlaps the sibling issue.

Additional context:
The current build no longer has a ResearchStudy.sponsor element. Later Published/Persuasive issue FHIR-37814 deliberately deleted ResearchStudy.sponsor, ResearchStudy.principalInvestigator, and ResearchStudy.contact, with sponsor and primary-investigator represented through ResearchStudy.associatedParty.role instead. Current source/fhir.ini keeps a conversion mapping from ResearchStudy.sponsor to ResearchStudy.associatedParty.party with role='sponsor', and the active StructureDefinition defines associatedParty and its ResearchStudyPartyRole binding. BRR minutes from 2022-07-26 record the 11-0-0 motion to delete sponsor from ResearchStudy and use AssociatedParty.role. The combined branch already contains an audit/source reconciliation commit for FHIR-37814, so this commit does not re-decide that later issue.

AutoFHIR reconciliation:
This commit makes no source change. Reintroducing or changing ResearchStudy.sponsor would conflict with the later R5-era model; changing the current sponsor role terminology to the old Jira wording would also be unsupported because FHIR-37814 moved the representation to associatedParty roles rather than preserving the old element definition.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-14166 unless BRR opens a new issue to redefine the current ResearchStudyPartyRole sponsor code or associatedParty guidance.
