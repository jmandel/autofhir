FHIR-27834: Audit MedicationAdministration dosage constraint

Issue request:
FHIR-27834 was a Published Pharmacy change request raised against R4 MedicationAdministration. It asked that a MedicationAdministration with status not-done be valid without dosage information; the final Not Persuasive with Modification resolution noted that MedicationAdministration.dosage is already 0..1 and directed the invariant to require dosage.text, dosage.dose, or dosage.rate[x] only when dosage is present.

Initial application:
The Jira-tagged source application appears in commit aa9bb900cb46fbcac2b5689dcf3a735a3524f12c, which updated the old MedicationAdministration spreadsheet mad-1 row from dose/rate-only wording to the current text/dose/rate requirement for the dosage backbone. Commit 33b409a4b6d544598262f2f074ebb4b6dc466157 then reworked the source into structuredefinition-MedicationAdministration.xml while carrying that invariant forward.

Additional context:
MedicationAdministration is in current build scope through source/fhir.ini, and the current StructureDefinition keeps MedicationAdministration.dosage at 0..1. The mad-1 invariant is attached to MedicationAdministration.dosage itself, so its FHIRPath expression is evaluated only when the dosage backbone exists. Pharmacy minutes from 2020-06-29 record FHIR-27834 as a constraint clarification updated in Jira, and a later Zulip implementer thread confirms not-done is the proper status for administrations not performed without creating a conflicting source requirement.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current active source already implements the published resolution: omitted dosage is allowed, and present dosage must include text, dose, or rate[x]. Adding extra narrative would be redundant and could drift from the authoritative invariant.

Recommendation:
Keep this commit as-is. No FHIR core follow-up is needed for FHIR-27834 unless Pharmacy later wants separate best-practice guidance about whether planned dosage should be populated for not-done administrations.
