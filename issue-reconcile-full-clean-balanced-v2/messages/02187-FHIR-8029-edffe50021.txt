FHIR-8029: Audit genomics information model disposition

Issue request:
FHIR-8029 was a Published/Persuasive DSTU1 Clinical Genomics ballot comment on the FHIR core overview's "Approach to information modeling" section asking that the missing information model be supplied or linked. The recorded resolution pointed to the Clinical Genomics DAM and the SMART on FHIR Genomics JAMIA article as the relevant model/background.

Initial application:
No commit was found that explicitly mentioned FHIR-8029. The requested DAM and SMART context did appear in source/genomics.html when the genomics guidance page was added in 2016, including links to the Clinical Genomics DAM use cases and SMART on FHIR Genomics article.

Additional context:
The generic overview section is active in the build and now says FHIR's model is expressed through resources and StructureDefinitions rather than a single external reference model. A later same-section ballot issue, FHIR-11140, was resolved Not Persuasive/No Change with the explicit rationale that FHIR has no single reference information model and that each resource is described by StructureDefinition with XSD/Schematron artifacts. The active genomics page was later simplified from the old MolecularSequence/DAM-era material to current Clinical Genomics work products: the Genomics Reporting IG, GenomicStudy, MolecularDefinition, molecular-definition data types, and CG Confluence use cases.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-adding the 2014 DAM or 2015 SMART article to the current core overview or current genomics guidance would resurrect obsolete background rather than fix current implementer guidance; the current build already points readers to the maintained FHIR modeling surfaces and Clinical Genomics work products.

Recommendation:
Keep this audit commit as-is. If Clinical Genomics wants a new canonical information-model landing page, that should be a fresh work-group decision in the maintained CG IG/incubator ecosystem rather than a core-spec restoration of the historical DAM/JAMIA links.
