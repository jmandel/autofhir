FHIR-17911: Audit SDC shortText extension scope

Issue request:
FHIR-17911 was a Published/Persuasive FHIR-core Questionnaire change request asking either to add a Questionnaire.item title element or to define a standard questionnaire-title extension for short question text usable on Questionnaire.item or nested Questionnaire.item.item. The final resolution was not to add a core element; it directed that SDC add an extension for "short question text" to the advanced rendering profile and include QuestionnaireResponse usage notes.

Initial application:
No FHIR-core commit applying FHIR-17911 was found in the current core checkout. Jira records Git#89b578f, and the matching HL7/sdc commit 89b578f65802d7c954883b2c4f58d0d1ae9b50b3 is titled "#17911 Added shortText extenstion" and changed SDC page content, examples, rendering guidance, and the SDC spreadsheet rather than core source.

Additional context:
The current FHIR core Questionnaire resource remains active in source/fhir.ini and still models Questionnaire.item.text as the single primary text for an item. The related FHIR-17910 group-heading clarification is already present in core as Questionnaire.item.text comments and is a separate applied issue. The current SDC published package hl7.fhir.uv.sdc#4.0.0 contains StructureDefinition/sdc-questionnaire-shortText with context Questionnaire.item and ElementDefinition, valueString, advanced rendering listing, and intro text recommending that when only the short text is displayed, the QuestionnaireResponse should express that displayed text.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The seed's approved work belongs to the SDC implementation guide repository/package, where the requested extension and usage guidance are already present, and adding a parallel core element or core extension would contradict the recorded resolution.

Recommendation:
Keep this empty external-repo audit commit as-is for core reconciliation. No FHIR-core follow-up is indicated for FHIR-17911 unless the work group later decides to move the SDC shortText extension into core or the FHIR Extension Pack.
