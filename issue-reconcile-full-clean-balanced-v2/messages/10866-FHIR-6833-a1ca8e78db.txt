FHIR-6833: Audit retired questionnaire operation links

Issue request:
FHIR-6833 was a Published/Persuasive FHIR-core correction from the 2015 May SDC tracker asking to fix unresolved links to StructureDefinition profiles on the Operation-structuredefinition-questionnaire page. The approved resolution was "fix", and the Jira comments record that the links were already fixed in previous work.

Initial application:
No Jira-tagged FHIR-6833 implementation commit was found in the current git history. The Jira audit trail itself says the issue had already been fixed before the tracker was closed, and the R5 source for OperationDefinition/StructureDefinition-questionnaire used ordinary markdown links to questionnaire.html, structuredefinition.html, and questionnaireresponse.html rather than unresolved StructureDefinition-profile placeholders.

Additional context:
The current build keeps StructureDefinition active, but source/structuredefinition/list-StructureDefinition-operations.xml now lists only OperationDefinition/StructureDefinition-snapshot. The StructureDefinition $questionnaire operation definition and its example files were removed from current R6 source by git commit 270e0ceb7b029dad4ca0fc5ccf5296ff370888cd. A later, separate Published issue, FHIR-27884, corrected parameter types on the same operation while it still existed for R5, but that does not require restoring the retired operation. Jira, Zulip, and Confluence searches found no later community decision requiring a current-source link fix for FHIR-6833.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The page identified by FHIR-6833 is no longer in the current build, and the relevant current source does not contain the old StructureDefinition-questionnaire operation or unresolved links that could be corrected.

Recommendation:
Keep this no-change audit commit as-is. Do not reintroduce the retired $questionnaire operation for this old link-resolution tracker; any future desire to add a questionnaire-generation operation should be handled as a new work-group decision.
