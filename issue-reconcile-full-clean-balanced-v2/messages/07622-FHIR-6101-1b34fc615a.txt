FHIR-6101: Audit enteral formula schedule placement

Issue request:
FHIR-6101 is a Published FHIR-core NutritionRequest/NutritionOrder change request resolved Persuasive with Modification. It asked to move enteralFormula.scheduled next to enteralFormula.quantity because those elements together express bolus or continuous enteral feeding schedules, and its resolution says to use FHIR-6100 for disposition.

Initial application:
The issue was pre-applied in historical NutritionOrder source. Commit 9a331d0ab4, "preapplied 6100,6101, 6102, 6111, 8177, 8179, 8181," removed the old NutritionOrder.enteralFormula.scheduled element and created NutritionOrder.enteralFormula.administration.schedule beside administration.quantity within a repeating administration backbone. The current StructureDefinition source preserves that applied shape.

Additional context:
FHIR-6100 supplied the controlling disposition by creating the enteralFormula.administration complex element with quantity, rate, and schedule components, and FHIR-6111 belongs to the same rate/administration change family. Both FHIR-6100 and FHIR-6111 are already represented on the combined branch, so this commit does not duplicate those audits. The resource was later renamed to NutritionRequest and then back to NutritionOrder; source/fhir.ini currently lists nutritionorder=NutritionOrder as active and lists NutritionRequest under removed resources.

AutoFHIR reconciliation:
No source change was made. The active source already places the enteral formula schedule in the same administration backbone as quantity, and the current notes and examples explain/use enteralFormula.administration.quantity with enteralFormula.administration.schedule for intermittent feedings.

Recommendation:
Keep this audit commit as-is. The current specification matches the final FHIR-6101/FHIR-6100 disposition, and changing the long-standing element order or adding redundant prose would not improve implementer understanding.
