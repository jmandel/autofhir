FHIR-32312 was Published with a Persuasive with Modification resolution for R5. It asked to support ClinicalTrials.gov title kinds for ResearchStudy, with the final decision to use Citation's TitleType value set and add official, scientific, and plain-language to TitleType.

Initial application:
The issue appears to have been applied in commit 0f18a0191c450d2a3bdef6286d38f786cdefed61, which changed ResearchStudy.label.type from the ResearchStudyLabelType binding to TitleType and updated the element short list to include official, scientific, plain-language, acronym, and the rest of the TitleType codes. The companion Published issue FHIR-32975 was then applied in commit 962e0153096274c9ebbb137280dfe78a3bb9a07b, replacing the TitleType code system terms and definitions.

ResearchStudy is active in source/fhir.ini, so source/researchstudy/structuredefinition-ResearchStudy.xml is in current build scope. The current source now binds ResearchStudy.label.type to http://terminology.hl7.org/ValueSet/title-type after the terminology was moved to THO, and the current/R5 title-type code system includes official, scientific, plain-language, and acronym. Confluence references show the seed was on the BRR agenda and later cited in CDS title-type notes; no relevant Zulip discussion or conflicting community evidence was found.
