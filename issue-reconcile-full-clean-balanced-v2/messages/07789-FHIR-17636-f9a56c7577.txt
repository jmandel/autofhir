FHIR-17636: Audit BodyHeight body length guidance

Issue request:
FHIR-17636 is a Published/Persuasive with Modification FHIR-core Observation change request asking the BodyHeight profile to clarify that body height subsumes body length, that LOINC 8306-3 Body height - lying may be included as an additional Observation.code for body length, and that a body length example be added without creating a separate slice.

Initial application:
The issue was pre-applied in August 2018. Commit a3fc640972dc1f34e2ff97bc5a013dbaf6ed1ec8 updated the vital signs profile spreadsheet so the BodyHeight summary mentioned 8306-3 as a body length additional observation code. Commit 7778f9c2c3920b39aa5caa5aff4b7034b4a84ec6 added the Body Length example and listed it in the Observation examples. Later source refactors moved the applied content from spreadsheets into the current XML profile, introduction, example, and example-list sources.

Additional context:
source/fhir.ini actively includes Observation and the Observation vital signs ImplementationGuide references StructureDefinition/bodyheight, so the checked source/observation files are current build inputs. The current BodyHeight StructureDefinition says the Body Height code value set covers body height including body length, its generated/profile summary repeats the 8306-3 body length guidance, and source/observation/observation-example-body-length.xml demonstrates 8306-3 with 8302-2 as the vital-sign/body-height coding. OO minutes on 2018-10-30 record the block-vote approval for GF#17636. Related FHIR-17540 supplied the earlier methodless Body Height/additional-code framing, FHIR-11303 is earlier infant body length background, and FHIR-25378 is a later body length unit audit already represented on the combined branch.
