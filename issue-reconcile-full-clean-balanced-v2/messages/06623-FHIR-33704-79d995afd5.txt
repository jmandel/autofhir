FHIR-33704: Audit item-control drop-down guidance in extension pack

Issue request:
FHIR-33704 was Published with resolution Persuasive with Modification for the FHIR-core Questionnaire artifact. It asked to clarify the questionnaire item-control code "drop-down" so implementers understand it is appropriate for small-to-medium answer lists, including answerValueSet-backed lists whose codes are fully available and appropriately sized, while larger lists should use autocomplete.

Initial application:
The issue was applied in core by d165de74ed, "FHIR-33704 - added guidance on 'drop-down' itemControl code", which appended the approved guidance to source/questionnaire/codesystem-questionnaire-item-control.xml. That core source file later disappeared from the current build when dd468d4f17 removed extension artifacts, including the questionnaire item-control CodeSystem and ValueSet, from the R5 core source.

Additional context:
The questionnaire resource remains in the current core build, but the questionnaire-itemControl extension, questionnaire-item-control ValueSet, and questionnaire-item-control CodeSystem are no longer active core source artifacts. The current authoritative source for those artifacts is in the FHIR Extension Pack at input/definitions/multiple/CodeSystem-questionnaire-item-control.xml, where the drop-down definition already contains the FHIR-33704 wording. Confluence minutes from 2021-10-14 record the SDC tracker disposition as persuasive with modification; escaped Jira and community searches found no conflicting later decision.

AutoFHIR reconciliation:

Recommendation:
