Initial application:
The Jira comment says this was applied in svn revision 5557. The corresponding git-svn commit 5abf6f76ce4b9086bad1edd348c102852e94acf7 is titled "#8328 - remove duplicate profile tags" and changed ValueSetUtilities.makeShareable to return without adding the shareable profile when that profile URI already exists.

Current source/documentreference/valueset-c80-facilitycodes.xml no longer has a meta.profile assertion at all, and a repository-wide XML source scan found zero duplicate meta.profile values. Later cleanup commits also removed shareable profile metadata from the cited C80 ValueSet, so reintroducing or editing that metadata would not be a current-spec correction.

Recommendation:
