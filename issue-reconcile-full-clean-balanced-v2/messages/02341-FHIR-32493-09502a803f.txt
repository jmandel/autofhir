FHIR-32493: Audit Practitioner identifier guidance

Issue request:
FHIR-32493 was a Published/Persuasive R5 clarification for Practitioner asking for usage notes about whether license or qualification identifiers should appear in Practitioner.identifier, Practitioner.qualification.identifier, or both. The approved resolution said that systems may use either or both locations, and that a license number in Practitioner.identifier does not convey license status while Practitioner.qualification should carry qualification details when known.

Initial application:
Commit a12d5b2e66f77d1cd8f85e2a7ba47491619a129f first applied the identifier-expectations note to PractitionerRole, matching the issue's misleading related-artifact metadata but not the resolution text. Commit 7571a34d8b034e2cc5f9d1b546787dbe129aaa5d then moved that note into the Practitioner notes and removed it from PractitionerRole.

Additional context:
Practitioner is an active core resource in source/fhir.ini, so source/practitioner/practitioner-notes.xml is in current build scope. The current Practitioner notes already say that business identifiers may be sent in Practitioner.identifier and/or Practitioner.qualification.identifier, explain that Practitioner.identifier alone does not convey qualification status, issuer, or type, and direct known qualification details to Practitioner.qualification. The related FHIR-32494 search-parameter change is already represented on the combined branch and the current Practitioner identifier search expression includes both paths. The later related FHIR-36681 reconciliation is also already represented on the combined branch and refined the note to address unknown qualification status and repeatable qualification identifiers.

AutoFHIR reconciliation:
Made no source change. The current active Practitioner source already satisfies the FHIR-32493 resolution, and adding another wording change would duplicate or destabilize the clearer FHIR-36681 text.

Recommendation:
Keep this no-change audit commit. No further core source work is needed for FHIR-32493 unless PA chooses to reopen the broader Practitioner qualification guidance, because the current notes and search parameter together convey the intended rule.
