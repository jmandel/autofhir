FHIR-13060: Add missing knowledge-resource summary flags

Issue request:
FHIR-13060 was Published with a Persuasive with Modification resolution for CDS knowledge resources. It requested summary flags on selected description, textEquivalent, and MeasureReport measureScore elements, while the final decision and FMG discussion rejected applying the requested modifier flags as part of this issue.

Initial application:
The original application was SVN 11646, represented in git by 3677417ce0, which added summary flags to several spreadsheet sources and removed/rejected some modifier flags. After the source migrated from spreadsheets to current StructureDefinition XML and RequestGroup was renamed to RequestOrchestration, most approved summary flags were still present, but PlanDefinition.action.textEquivalent and MeasureReport.group.stratifier.stratum.measureScore[x] were missing isSummary in the current active source.

Additional context:
source/fhir.ini lists PlanDefinition, MeasureReport, RequestOrchestration, ActivityDefinition, Library, Measure, and GuidanceResponse as current resources. RequestGroup is a historical name now mapped to RequestOrchestration, where the originally applied action.description and action.textEquivalent summary flags are already present. Later MeasureReport modifier cleanup in FHIR-55366 removed unrelated modifier flags and left status-specific modifier semantics separate from this reconciliation, so this commit only restores the approved summary semantics.

AutoFHIR reconciliation:
Added isSummary=true to PlanDefinition.action.textEquivalent and MeasureReport.group.stratifier.stratum.measureScore[x]. No rejected modifier flags were added or removed.

Recommendation:
Keep this source-changing commit. It finishes the applied FHIR-13060 summary-flag decision in the current build without reopening the rejected modifier requests or broader MeasureReport status/modifier policy.
