FHIR-32667: Audit CQL library version guidance

Issue request:
FHIR-32667 was a Published/Persuasive FHIR-core Library change request asking CDS to add guidance and conformance expectations for using the media type version parameter on Library.content.contentType so CQL and ELM library content can state the CQL/ELM version they contain.

Initial application:
The seed Jira comment points to HL7/fhir pull request #2635. The core commit in that PR trail, 2e2ccec2adf474bbdbb66019700fc8f71ecc3b99, did not duplicate the detailed rules in the Library resource; it added a Clinical Reasoning/Using Expressions pointer to external CQL usage guidance, consistent with the related FHIR-30570 note that CQL guidance had been consolidated outside the base specification.

Additional context:
The current source keeps that build-scoped Clinical Reasoning pointer, now targeting the published Using CQL with FHIR implementation guide. That IG contains the direct CQL Version conformance language: Library CQL/ELM content SHOULD specify the version parameter of text/cql, application/elm+xml, and application/elm+json; if present, the parameter SHALL match a published CQL major/minor version; and resource narratives SHALL include the version when specified. Later CQL IG issues FHIR-43877 and FHIR-49605 refine that same external guidance, confirming this rule family is maintained in FHIR-uv-cql rather than FHIR core.

AutoFHIR reconciliation:
No FHIR core source change was made. The current build-scoped core source already directs implementers to the active CQL IG, and the active CQL IG contains the requested version-parameter guidance and conformance expectations. Adding a duplicate sentence to core would create avoidable maintenance drift without changing implementer requirements.

Recommendation:
Keep this no-change audit. If reviewers want core to point to a more specific anchor, that should be treated as a separate editorial link-target decision, not as an unapplied FHIR-32667 conformance fix; substantive maintenance of the version-parameter rule should remain in FHIR-uv-cql.
