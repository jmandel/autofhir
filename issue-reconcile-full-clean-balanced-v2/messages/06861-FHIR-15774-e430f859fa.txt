FHIR-15774: Audit Device UDI hyperlink correction

Issue request:
FHIR-15774 was a Published/Persuasive FHIR-core Device correction for STU3. It reported that Device.udi and the Scope and Usage narrative linked Unique device identifier (UDI) to device.html#5.11.3.2.2, an anchor that did not exist, and suggested the UDI section anchor instead.

Initial application:
The issue was applied in SVN revision 13524, mirrored as git commit 7aafad4fc4aeda26ba35ffec7ae56ad413b4ea6e, which changed both old Device spreadsheet UDI links from device.html#5.11.3.2.2 to device.html#udi. Related scope-link corrections were also applied in FHIR-13398 and FHIR-15566 before the current source layout.

Additional context:
Device is active in the current build through source/fhir.ini. The old device-spreadsheet.xml source no longer exists in the current Device directory; the build-relevant source is now the Device StructureDefinition and narrative XML. Current source/device/structuredefinition-Device.xml defines Device.udiCarrier without the bad self-link, source/device/device-introduction.xml links the UDI narrative to device.html#udi, and source/device/device-notes.xml defines the udi anchor. Repository-wide source search finds no remaining device.html#5.11.3.2.2 link.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build source no longer contains the broken FHIR-15774 anchor, and adding new prose would be redundant rather than corrective.

Recommendation:
Keep this audit commit as-is. No FHIR-core follow-up is needed for FHIR-15774 unless a future generated-link check finds a new broken UDI anchor on the Device page.
