FHIR-12562: Audit TestScript capabilities wording

Issue request:
FHIR-12562 was a Published/Persuasive FHIR-core TestScript change request for the DSTU2 Testing FHIR "How to specify metadata capabilities" section. It asked to replace wording that said unsupported capabilities could cause either the whole TestScript or a specific test to be skipped depending on where the capabilities section was defined, because the then-current TestScript definition no longer had test.metadata. The approved replacement said that a test engine provides a comparison of the system under test's conformance capabilities and allows the TestScript as a whole to be skipped based on that comparison.

Initial application:
The request was applied before this reconciliation by git-svn commit 758b8ebf8d8973c81cb6fbd6bae9e4b9462b5ba6, whose subject is "#12562 - testing.html \"How to specify capabilities\" section updated" and whose git-svn trailer records SVN build@10808. That commit changed source/testing.html in both the preprocessing workflow paragraph and the "How to specify metadata capabilities" subsection.

Additional context:
Later TestScript work changed the same area. FHIR-37818, applied by 8784f97f340498d087383b2430744c21e4652502, rewrote the preprocessing text to compare TestScript setup/test action.operation interactions against the system under test CapabilityStatement and to say the test engine should provide a comparison. In 2025, f9a44787c45071394532c7c2ee94d76f30f47387 removed source/testing.html and the core TestScript/TestPlan/TestReport source files, removed their active core resource entries, and added the Testing IG to source/fhir.ini. Current core source links testing implementation content and TestScript references to the Testing IG instead of carrying the old Testing FHIR page locally. FHIR-I 2025 WGM minutes also record the decision direction to move testing-related resources into the Testing IG.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The stale sentence identified by FHIR-12562 is not present in the current core source; the historical change was applied, later refined, and then moved out of the core build. Current core source is in the right state for this issue because it points to the Testing IG as the owner of TestScript/testing content. A check of the current Testing IG page found capability preprocessing wording that evaluates TestScript setup/test operations against the system under test CapabilityStatement, not the original obsolete placement-based skip wording.

Recommendation:
Keep this no-change audit commit. Future edits to detailed TestScript/testing narrative should be made in the Testing IG rather than in core unless core's references to that IG become stale.
