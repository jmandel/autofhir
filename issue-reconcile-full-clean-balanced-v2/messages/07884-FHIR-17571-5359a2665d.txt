FHIR-17571: Audit vital signs profile names

Issue request:
FHIR-17571 was a Published/Persuasive with Modification OO change request from STU3 reporting that derived Vital Signs profiles such as BodyWeight exposed the base VitalSigns name/title instead of names and titles specific to each derived profile. The accepted resolution said the title issue was a build tooling limitation and that the vital signs profile spreadsheet tabs should be broken into several spreadsheets; Jira notes this was pre-applied.

Initial application:
The issue appears to have been applied by historical commit be750bb59d92575730445cf25f9a2941fd04dd26, "preapply GF#17571 fix titles in vitals panel", which split the Observation vital signs profile tabs into separate profile spreadsheet files and registered specific profile entries such as the Body Weight, Body Height, Heart Rate, Respiratory Rate, Oxygen Saturation, BMI, Blood Pressure, Head Circumference, Body Temperature, and Vital Signs Panel profiles. The current generated XML source no longer carries the old BodyWeight metadata values that triggered the issue.

Additional context:
Observation is an active current-build resource in source/fhir.ini, and source/observation/implementationguide-Observation-vitalsigns.xml actively references StructureDefinition/bodyweight and the other specific vital signs profiles. Later source conversion and metadata cleanup commits, including f87870f372, transformed the older spreadsheet source into current StructureDefinition XML while preserving distinct profile-specific name/title metadata. Zulip discussion at the time confirms the reporter's concern and the community expectation that derived profiles have specific names and titles; no Confluence reference or conflicting community record was found.

AutoFHIR reconciliation:
No source change was made. The current authoritative source gives each specific Vital Signs profile its own name and title, for example StructureDefinition/bodyweight has name Observationbodyweight and title Observation Body Weight Profile, while the base profile remains Observationvitalsignsbase / Vital Signs Base Profile. Exact searches found no remaining current source instance of the old offending metadata <name value="Vital Signs Profile"> or <title value="VitalSigns">.

Recommendation:
Keep this audit commit as-is. The Published Jira request is already satisfied in active current-build source, and changing the current canonical names/titles would be unnecessary churn unless a new issue asks for a different naming convention.
