FHIR-5759: Audit ImmunizationRecommendation forecast wording

Issue request:
FHIR-5759 was a Published/Persuasive DSTU1 Public Health ballot comment asking that the ImmunizationRecommendation resource definition include the term forecast because that was the intent of the content.

Initial application:
The issue was applied in git commit e490b9db1e4bfe85e7ece4ccde849ec813120a8f, which changed the then-active ImmunizationRecommendation spreadsheet definition from a point-of-time immunization status/recommendation description to wording that explicitly said the resource was for forecasting a patient's immunization eligibility according to a published schedule.

Additional context:
The current FHIR core build no longer has ImmunizationRecommendation as an active resource in source/fhir.ini. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed ImmunizationRecommendation and ImmunizationEvaluation from the core resource list and redirected current core module/resource-guide links to the Immunization Incubator IG. The current Medications module still describes ImmunizationRecommendation as personalized point-in-time immunization recommendations and explicitly includes forecasting a patient's immunization eligibility. The linked Immunization Incubator continuous build also has a top-level definition that says "A patient's point-in-time set of recommendations (i.e. forecasting) according to a published schedule with optional supporting justification." Later Jira issues such as FHIR-44950 and FHIR-47040 refined ImmunizationRecommendation status, series, and narrative details, but they do not reverse the forecast wording requested by FHIR-5759.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested forecast concept was historically applied, the active core resource definition no longer exists in the current build, and the remaining current core reference plus the external target already preserve the forecast meaning.

Recommendation:
Keep this no-change audit commit. No core source follow-up is needed for FHIR-5759 unless a future work group decision brings ImmunizationRecommendation back into core or changes the linked incubator resource definition.
