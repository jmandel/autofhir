FHIR-47674: Audit ImagingStudy.series description

Issue request:
FHIR-47674 was Applied as Persuasive with Modification for R6. It asked to correct ImagingStudy.series because the 0..* cardinality permits ordered or scheduled studies with no started series, so the short and definition should no longer say "one or more" series.

Initial application:

The Jira comment points to HL7/fhir#3319, merged by 34c21d3320791eccd74e38ecdf9079268382a2e1.

Additional context:
source/fhir.ini lists ImagingStudy as an active resource, so source/imagingstudy/structuredefinition-ImagingStudy.xml is in current build scope. The current XML source has the approved short, definition, and 0..* cardinality. A checked-in imagingstudy.svg tooltip still contains the old sentence, but it is a generated-looking diagram artifact; the operating guardrail says not to make a source-changing commit when the only remaining mismatch is such an SVG and the authoritative source is correct.
