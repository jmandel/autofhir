FHIR-35874: Audit Product pattern advancement

Issue request:
FHIR-35874 was Applied/Not Persuasive with Modification for R5. It asked to advance the Product pattern for product delivery, tracking, and catalogs, including common search parameters, GS1 alignment, and consideration of a generic Product resource or common characteristic/relationship model across Medication, Device, DeviceDefinition, NutritionProduct, and BiologicallyDerivedProduct. OO resolved not to add a standalone Product resource because InventoryItem addressed the inventory/catalog capabilities while specialized product resources remained appropriate, and agreed to clarify InventoryItem usage and rely on harmonized search parameters on the specialized resources.

Initial application:
OO WGM minutes on 2023-05-09 record the 12-0-0 motion for FHIR-35874, stating that InventoryItem had been created, search parameters across the related specialized resources had been harmonized, and InventoryItem would be clarified for when it can stand alone versus when it should reference another product resource. The explicit source application found for this Jira is f73c212746740cc7e8a5dac6d8334c7f1a5d934f, merged through HL7/fhir#3122, which updated source/inventoryitem/inventoryitem-introduction.xml with the requested scope language. No separate FHIR-35874-tagged source commit was found for search-parameter harmonization; the current source contains the Product pattern and active product-resource search parameter bundles.

Additional context:
The Product pattern page remains in the current core page hierarchy, and active fhir.ini entries still include the specialized product resources relevant to this issue, such as Medication, MedicationKnowledge, Device, DeviceDefinition, NutritionProduct, and BiologicallyDerivedProduct. InventoryItem is different: later governance moved InventoryItem and sibling low-maturity OO resources out of the active core build. Commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed InventoryItem from fhir.ini and changed the Administration module link to an OO Incubator page; current source/administration-module.html links InventoryItem to the OO Incubator continuous build, which is based on HL7/oo-incubator. The combined branch already contains a FHIR-39161 external-repo audit documenting that InventoryItem ownership moved out of current FHIR-core.

AutoFHIR reconciliation:
This audit commit makes no source change. The current core source already has the Product pattern, the specialized product resources are active, and their search parameter bundles expose the relevant product search surfaces such as identifier, code/type/status, serial-number, lot-number, and expiration-date where applicable. The InventoryItem clarification requested by FHIR-35874 was applied historically, but InventoryItem is now out of the active FHIR-core build; editing the leftover core InventoryItem files would not affect the current specification, and restoring InventoryItem to core would reverse a later governance decision.

Recommendation:
Keep this audit as-is for FHIR-core. If further InventoryItem wording is needed, make it in the HL7/oo-incubator source. If additional product search-parameter harmonization is needed for active core resources, raise or apply resource-specific Jira issues rather than reopening this broad R5 Product pattern tracker.
