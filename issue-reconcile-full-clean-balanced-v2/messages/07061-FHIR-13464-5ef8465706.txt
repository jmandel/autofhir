FHIR-13464: Audit NutritionOrder liquid exclusions

Issue request:
FHIR-13464 was Published with a Persuasive with Modification resolution for STU3. It asked how NutritionRequest/NutritionOrder can represent no oral liquids and directed implementers to use excludeFoodModifier with a code such as SNOMED CT Dietary fluid, while changing the element description from only food exclusions to oral food or oral fluids.

Initial application:
The request was applied in historical commit 4fb140007ce4d98260abb203f8af627c8951210e, which changed the NutritionOrder spreadsheet definition for excludeFoodModifier to mention oral food or oral fluids. Later source refactors migrated the resource from spreadsheets to the active StructureDefinition source and changed the resource name back to NutritionOrder, but kept the element and its preferred edible-substance binding.

Additional context:
source/fhir.ini lists nutritionorder=NutritionOrder as an active resource, so source/nutritionorder/structuredefinition-NutritionOrder.xml is in current build scope. The current authoritative element text says excludeFoodModifier is for specific oral food solid/liquid exclusions and binds to the Types of Edible Substances value set, whose source includes edible substances and water-related SNOMED CT content. A later Applied R6 decision, FHIR-46700, deliberately refined the same element's long and short descriptions and is already represented on the combined branch. The checked-in nutritionorder.svg tooltip still looks like generated stale output, but the authoritative StructureDefinition source is current and should drive generated artifacts.

AutoFHIR reconciliation:
Made no source change. The current active source already supports representing no oral liquids through NutritionOrder.excludeFoodModifier, and adding another local restatement would duplicate or potentially drift from the later FHIR-46700 wording.

Recommendation:
Keep this no-change audit commit. Do not hand-edit only the generated-looking SVG; if reviewers care about the diagram tooltip, refresh generated artifacts from the authoritative StructureDefinition during the normal build.
