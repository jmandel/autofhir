FHIR-29211: Audit expression parameter context guidance

Issue request:
FHIR-29211 was a Published/Persuasive with Modification FHIR-core change request asking that expression evaluation be able to access operation parameters. The accepted resolution was to add discussion of how PlanDefinition/$apply and ActivityDefinition/$apply expose operation parameters, and to suggest the same approach as a general pattern for operations that evaluate logic rather than impose a blanket FHIRPath rule.

Initial application:
The issue was applied by 96ae6fe19d929585aa3b10e1257887adf15b9557, which added a paragraph to source/clinicalreasoning-topics-using-expressions.html recommending that operations make their parameters available as context variables when evaluating expressions. The pre-existing PlanDefinition and ActivityDefinition documentation already described $apply parameters as dynamicValue CQL/FHIRPath context variables, accessible by the parameter name prefixed with percent (%).

Additional context:
FHIR-I minutes before the CDS handoff recorded the collision concern around generic percent variables, and the Jira discussion narrowed the request from a blanket requirement to a recommendation each operation can apply as appropriate. The current build scope includes the relevant resources in source/fhir.ini, and source/hierarchy.xml includes clinicalreasoning-topics-using-expressions.html as the active Clinical Reasoning "Using Expressions" page. Questionnaire-related current source already points to launchContext/name-based variables for QuestionnaireResponse expression evaluation, consistent with the Jira comments explaining that Questionnaire had a separate solution.

AutoFHIR reconciliation:
No source change was made. The current source already satisfies the final resolution: the active Clinical Reasoning topic contains the general SHOULD recommendation, ActivityDefinition/$apply and PlanDefinition/$apply operation definitions and notes expose operation parameters as context variables, and no conflicting later source or community evidence was found.
