FHIR-48923: Audit Device communication extensions in Extension Pack

Issue request:
FHIR-48923 is Applied/Persuasive and asked FMG to approve creation of one or more extensions on Device for communication-related elements moved out of Device as part of FHIR-32565. The Jira comments direct implementation to FHIR-47326 and record that the applied work was HL7/fhir-extensions PR #166, commit 1827387.

Initial application:
Core commit 2286646d6c79a907f5e539b73445661331094313, titled FHIR-48923, commented Device.endpoint and Device.gateway out of the active Device StructureDefinition source. The corresponding extension-pack issue FHIR-47326 was applied in HL7/fhir-extensions commit 18273876b410b74a1f4f65f8002bdeae707ad052, which added StructureDefinition-device-endpoint.xml and StructureDefinition-device-gateway.xml.

Additional context:
FHIR-32565 is the broader Applied/Persuasive with Modification core decision to move Device.mode, Device.cycle, Device.duration, Device.gateway, and Device.endpoint into extensions. FHIR-47326 is Published/Persuasive with Modification in FHIR-extensions and narrowed the communication work to device-endpoint and device-gateway because Device.url was not approved for removal. FMG minutes from 2024-12-18 approved FHIR-48923 for moving Device communication elements into the extensions pack by vote 6-0-1.

AutoFHIR reconciliation:
No core source change was made. The active core Device source already omits Device.endpoint and Device.gateway, and the Device introduction notes the removed elements and their replacement extension names. The requested extension definitions are current in the Extension Pack checkout rather than this FHIR core checkout.

Recommendation:
Keep this audit commit as an external-repo decision for core reconciliation. Any future edits to the device-endpoint or device-gateway definitions should be made in HL7/fhir-extensions, not in the core FHIR source tree, unless a later Jira asks for corresponding core narrative changes.
