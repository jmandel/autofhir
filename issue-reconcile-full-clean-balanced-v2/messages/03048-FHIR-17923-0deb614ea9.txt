FHIR-17923: Audit Claim unitPrice unit wording

Issue request:
FHIR-17923 was a Published/Persuasive with Modification FHIR-core Claim change request from STU3 asking that Claim.item.unitPrice, Claim.item.detail.unitPrice, and Claim.item.detail.subDetail.unitPrice replace "point" with "unit" or "element" in the description.

Initial application:
The change appears to have been applied in historical commit afb5ec66f6, which explicitly lists 17923 in a batch of Claim updates. In that commit, the old Claim spreadsheet rows for the three unitPrice elements were changed from "Fee, charge or cost per point" to "Fee, charge or cost per item", with requirements text using "a single unit".

Additional context:
Claim is an active current-build resource in source/fhir.ini. The current authoritative Claim StructureDefinition source no longer contains the old "per point" unitPrice wording; each requested unitPrice element says "Fee, charge or cost per item" and "The amount charged to the patient by the provider for a single unit." No relevant Zulip or Confluence discussion was found. A Jira neighborhood search found only FHIR-17923 plus an older broad datatype issue, FHIR-5165, whose Claim mentions concern whether Money/Quantity comparators apply and do not reopen this wording change.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build-scope Claim source already reflects the requested replacement and no stale "point" wording remains in Claim XML source for these unitPrice descriptions.

Recommendation:
Keep this audit commit as-is. No follow-up source work is needed for FHIR-17923 unless a future financial-management decision changes the Claim unitPrice semantics beyond this wording correction.
