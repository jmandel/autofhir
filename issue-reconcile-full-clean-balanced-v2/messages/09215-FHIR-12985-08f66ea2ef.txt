FHIR-12985: Audit Resource _type search parameter

Issue request:
FHIR-12985 was a Published/Persuasive FHIR-I change request raised against DSTU2 BaseResource search documentation. It asked why the search.html "Parameters for all resources" list included parameters that were not present on resource.html#search, most notably _type. The accepted resolution was to add _type to the Resource search parameters on resource.html#search.

Initial application:
The Jira comment records SVN revision 12796. Later source refactors replaced that injected Resource-page table mechanism with explicit Resource search parameter bundle and search-page summary sources.

Current source/fhir.ini keeps Resource as an active infrastructure resource, and source/hierarchy.xml keeps search.html in the active RESTful API page hierarchy. The current Resource search parameter bundle defines Resource-_type with code _type and type special, and source/search.html now lists _type in both the all-resources narrative and the common-parameters summary table. A later same-change-family issue, FHIR-20640, was already reconciled on the combined branch and restored the _type row in the current search.html summary table, so another source edit for FHIR-12985 would duplicate already-correct current source.
