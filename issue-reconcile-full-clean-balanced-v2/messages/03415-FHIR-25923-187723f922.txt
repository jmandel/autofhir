FHIR-25923: Audit ConceptMap relationship codes

Issue request:
FHIR-25923 is Published/Persuasive with Modification for the FHIR-core ConceptMap artifact. It asked that the ambiguous ConceptMapRelationship broader/narrower codes be replaced with codes that explicitly state source-to-target direction; the final resolution selected source_is_narrower_than_target and source_is_broader_than_target descriptions, while preserving related-to, equivalent, and not-related-to from the earlier FHIR-25373 discussion.

Initial application:
The Jira comments report the changes as applied on 2020-04-30 in fhir commit 70168c7d32. That commit updated the ConceptMap spreadsheet, ConceptMap notes, and terminology binding worksheet from broader/narrower to source-is-narrower-than-target and source-is-broader-than-target, and changed the target.relationship definition to read from source to target. Later source refactors generated or retained the current CodeSystem XML and StructureDefinition entries with the same directional semantics.

Additional context:
FHIR-25373 was closed as replaced by FHIR-25923. The 2019 Vocab minutes and 2020 discussion record the source-to-target direction concern that led to explicit directional code strings. FHIR-26315 later objected that the R5 ConceptMap relationship changes were unnecessary, but it was resolved Not Persuasive with the decision that the vetted R5 changes would remain. FHIR-25924, a separate maturity issue for the same code system, is already represented on the combined branch and does not change the relationship-code semantics.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope ConceptMap source already uses source-is-narrower-than-target and source-is-broader-than-target in the ConceptMapRelationship CodeSystem, the terminology binding worksheet, ConceptMap.group.element.target.relationship, examples, notes, and invariant tests; old bare broader/narrower relationship codes are not present in current source.

Recommendation:
Keep this audit commit as-is. No further core source work is needed for FHIR-25923 unless a future work-group decision reopens the broader R5 ConceptMap relationship direction question.
