FHIR-40330: Audit BDPDispense origin relationship terminology ownership

Issue request:
FHIR-40330 was Published/Persuasive for R5 by OO and asked FHIR core to create a CodeSystem and ValueSet for the BiologicallyDerivedProductDispense origin relationship, used by the BDPDispense originRelationship/originRelationshipType element as an example binding. The requested concepts were autologous, related, directed, allogeneic, and xenogenic.

Initial application:
The R5 work was applied before this reconciliation in the BDPDispense terminology series. Commit 751e8d6a97 added the original BiologicalProductDispense value-set/code-system family for FHIR-40329 through FHIR-40332; commit 668c22759f moved the origin relationship CodeSystem, ValueSet, and binding to the longer BiologicallyDerivedProductDispense naming; commit 36e58f5401 corrected the allogeneic code; and merge commit c478c055e0 brought the BDPDispense work into the main branch. FHIR-49688 later set the origin relationship CodeSystem content back to complete for expansion behavior.

Additional context:
FHIR-40329, FHIR-40331, and FHIR-40332 were the neighboring BDPDispense terminology requests from the same OO value-set discussion. FHIR-40331 and FHIR-40332 are already represented on the combined branch as external-repo audits. In current core, BiologicallyDerivedProductDispense is no longer an active resource in source/fhir.ini: commit 3b38b80cf2 removed the OO resource entries and changed workflow links to the OO Incubator IG. Current source/biologicallyderivedproduct/biologicallyderivedproduct-introduction.xml also says BiologicallyDerivedProductDispense moved to OO Incubator. The OO Incubator continuous build contains the BDPDispense.originRelationshipType binding and the origin-relationship CodeSystem/ValueSet with the five requested concepts.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the core FHIR checkout. The remaining source/biologicallyderivedproductdispense files are stale core copies outside active build scope, and the authoritative current BDPDispense artifact is external to core. Editing those orphaned core files would not correct the current core specification.

Recommendation:
Keep this audit commit as-is for core. If future corrections are needed for BiologicallyDerivedProductDispense.originRelationshipType terminology, make them in HL7/oo-incubator rather than reactivating or editing the stale core BDPDispense source copies.
