FHIR-16095: Audit MedicationKnowledge development changes

Issue request:
FHIR-16095 was a Published/Persuasive with Modification Pharmacy change request for R5 MedicationKnowledge. It asked to rename the old cost.formulary attribute to source and make it 0..1, change the medicine classification value from string to CodeableConcept, rename the old medication name element to synonym with clearer description, and remove the old description data element.

Initial application:
The issue was initially applied during MedicationKnowledge resource development. Git commit 3fb9137568b7dc812a358c405f25cedc82ba3024, matching the Jira April 30, 2018 application comment, changed the old spreadsheet so MedicationKnowledge.cost.formulary became MedicationKnowledge.cost.source with cardinality 0..1, MedicationKnowledge.medicineClassification.classification became CodeableConcept, MedicationKnowledge.name became MedicationKnowledge.synonym with the requested explanatory text, and MedicationKnowledge.description was removed. Later GF-16095-tagged commits c78bc226e5ca077b65f8c7a49d31272801ec620d and ff9266d082ef6dd553a653a50eb5d4a6426b73ba further reworked MedicationKnowledge while preserving the cost.source and CodeableConcept classification changes.

Additional context:
MedicationKnowledge is an active current-build resource in source/fhir.ini. Current source no longer contains the old cost.formulary, synonym, or description data elements, and it retains MedicationKnowledge.cost.source as 0..1 plus MedicationKnowledge.medicineClassification.classification as CodeableConcept. The current MedicationKnowledge.name element is not the old medication-name/synonym element: later Published/Applied decisions FHIR-32801 and FHIR-45285 made MedicationKnowledge a MetadataResource/CanonicalResource-compatible artifact, with a 0..1 computer-friendly canonical name. A checked-in SVG still contains old medication-name tooltip text, but it is a generated-looking diagram artifact and should not drive a source-only correction for FHIR-16095.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The requested substantive FHIR-16095 changes are already reflected or have been superseded by later final MedicationKnowledge metadata decisions; reintroducing synonym or editing only the stale SVG would make the current specification less consistent.

Recommendation:
Keep this audit commit as-is. No FHIR-core follow-up is needed for FHIR-16095. If diagram artifacts are regenerated for other MedicationKnowledge metadata cleanups, the stale SVG tooltip can be refreshed there rather than hand-edited here.
