FHIR-32491: Audit MedicationRequest substitution binding

Issue request:
FHIR-32491 was a Published/Persuasive Pharmacy WG change request raised against MedicationPrescription/MedicationRequest.substitution.allowed[x]. It asked for the substitution allowed code binding to be tighter than example, possibly preferred or extensible; the final resolution was to change the binding to Preferred and not to make it extensible because many systems use their own value sets.

Initial application:
The issue appears to have been applied in git commit 7acfd680713d0152367c6841b366974c594b4ec0, whose commit message includes FHIR-32491 and whose patch changed MedicationRequest.substitution.allowed[x] from example to preferred in source/medicationrequest/structuredefinition-MedicationRequest.xml. Current blame still attributes the preferred strength line to that application commit.

Additional context:

Pharmacy WGM minutes for May 2021 record the same decision, including the rationale that common eRx/claims systems use other code systems such as NCPDP and the motion to accept Preferred 5-0-0. Bounded later searches found no Jira issue for the same element, binding name, or value set that reverses this decision; later git changes in the same StructureDefinition touched other MedicationRequest bindings, not the substitution allowed binding.
