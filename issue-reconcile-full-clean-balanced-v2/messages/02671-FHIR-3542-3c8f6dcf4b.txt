FHIR-3542: Audit ImagingStudy series number definition

Issue request:
FHIR-3542 was Published/Persuasive and asked to replace the ImagingStudy.series.number short definition that described an overall sequence number with "Numeric identifier of this series (0020,0011)" and to replace the long definition with "The Numeric identifier of this series in the study." to align with DICOM.

Initial application:
The change was applied in historical commit 0e3beda01a8fa15f5af7fbf5f5c35d4e27a0a1af, which changed source/imagingstudy/imagingstudy-spreadsheet.xml from "Number of this series in overall sequence (0020,0011)" to "Numeric identifier of this series (0020,0011)" and changed the long definition to the requested in-study wording.

Additional context:
ImagingStudy is an active current-build resource in source/fhir.ini. The 2021 source refactor moved the spreadsheet content into source/imagingstudy/structuredefinition-ImagingStudy.xml while preserving the requested short and long definition semantics. Later DICOM mapping work for FHIR-47520 updated the same element's DICOM map to "Series Number (0020,0011)", and that issue is already represented on the combined branch. FHIR-47676 later decided not to add uniqueness or consecutiveness requirements for this element because it reflects DICOM source data.

AutoFHIR reconciliation:
This is an empty no-change audit commit. The current authoritative source already says ImagingStudy.series.number is the numeric identifier of the series in the study, and the DICOM mapping carries the Series Number (0020,0011) tag; adding the tag redundantly to the short display would not change implementer understanding.

Recommendation:
Keep this audit commit as-is. No current FHIR core source change is needed for FHIR-3542; future changes to constraints or DICOM mapping policy should be handled under their own Jira issues rather than as a reopen of this DSTU1 technical correction.
