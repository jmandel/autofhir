FHIR-13770: Audit CodeSystem lookup example typo fix

Issue request:
FHIR-13770 was a Published/Persuasive vocab change request for STU3 asking that the CodeSystem $lookup JSON response example use "display" for the simple display parameter instead of a second differently structured "designation" parameter, and that the trailing space be removed from the designation value.

Initial application:
The request was applied in SVN revision 14620, represented in Git as 966c7a6d28eb13a313c4aac7a1cf7fb75c3854e8 ("GF#13770 - fix typos"), which changed source/codesystem/$lookup-response.txt from the simple "designation" parameter to "display" and removed the trailing space from the designation part value.

Additional context:
The linked Zulip thread records the same correction from Grahame Grieve: the simple designation-shaped value was a typo and should be the display parameter, while repeated designations should be represented as repeated designation parameters with parts. CodeSystem is an active resource in source/fhir.ini, and operationdefinition-CodeSystem-lookup.xml actively includes $lookup-response.txt as the response example for the built CodeSystem $lookup operation. No Confluence reference was found that changes this conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/codesystem/$lookup-response.txt already has "name" : "display" for the simple display value and the designation part value has no trailing whitespace; the later wording change from "Serum" to "Serum or Plasma" does not reintroduce the typo described by FHIR-13770.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-13770 unless a future terminology decision asks to change the example content for reasons unrelated to the original typo.
