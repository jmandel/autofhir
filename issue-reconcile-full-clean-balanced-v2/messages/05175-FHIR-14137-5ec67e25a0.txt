FHIR-14137: Audit superseded UMLS URL guidance

Issue request:
FHIR-14137 was a Published/Persuasive Vocabulary change request from STU3 asking FHIR core to document that UMLS source-abbreviation URLs, using http://www.nlm.nih.gov/research/umls/[SAB], could be used temporarily for UMLS-contained code systems that lacked registered identifiers, while warning that such URLs might not be supported in the future.

Initial application:
The issue appears to have been applied by git-svn commit 40536d152413e94ee690d99bdb1cecad8634bc64, "#14137 - UMLS note", which added the UMLS Note paragraph to source/terminologies-systems.html and included the requested temporary [SAB] pattern, Multum MediSource Lexicon example, and warning that registered systems might later use different identifiers.

Additional context:
Later final Vocabulary decisions FHIR-27805 and FHIR-25030 asked to remove that same UMLS Note because HTA/NLM considered the guidance technically incorrect and improper. Their implementation commit 2e0905373f66c2bab9a4ad5e396b3b72f804aec7 removed the paragraph from source/terminologies-systems.html. Both later issues already have Issue-Reconcile-Key audit commits on the combined branch. Current source keeps terminologies-systems.html in build/navigation scope and directs unlisted external code-system URI questions to THO/TSMG rather than reviving the UMLS [SAB] pattern.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Restoring the FHIR-14137 UMLS note would contradict later Published/Persuasive removal decisions, while the current page already provides the modern external-code-system authority path through THO and TSMG.

Recommendation:
Keep this no-change audit commit as-is. No FHIR core source follow-up is needed for FHIR-14137; future UMLS or external code-system identifier questions should proceed through THO/TSMG rather than through the superseded FHIR core UMLS [SAB] note.
