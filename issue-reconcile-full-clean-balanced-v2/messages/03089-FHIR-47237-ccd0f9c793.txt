FHIR-47237: Remove human-only NutritionProduct wording

Issue request:
FHIR-47237 was an Applied/Persuasive R6 OO change request asking whether NutritionProduct was limited to products for human consumption. The approved resolution says it can also be used for animal consumption and that the Scope and Usage sentence should refer to food products for consumption, not human consumption.

Initial application:
The Jira-tagged commit d0f9f0cb92 updated source/nutritionproduct/nutritionproduct-introduction.xml so the resource Scope and Usage sentence now says products for consumption. That commit also included separate NutritionProduct changes for other issues. A later module-page commit, 1405277d53 for FHIR-46343, added source/nutrition-module.html with a NutritionProduct summary that still said products were intended for human consumption.

Additional context:
NutritionProduct is an active resource in source/fhir.ini, and source/hierarchy.xml links nutrition-module.html into the built Nutrition page. The current resource Scope and Usage page already reflects FHIR-47237, but the built Nutrition module page contradicted it by preserving human-only wording. OO Nutrition minutes on 2024-10-23 record the 8-0-0 vote for FHIR-47237, and no Zulip search hits were found that would narrow or reverse the Jira resolution.

AutoFHIR reconciliation:
This commit removes "human" from the Nutrition module's NutritionProduct summary so it now says consumable food products are intended for consumption. This keeps the module page consistent with the already-correct resource Scope and Usage sentence without adding broader veterinary-specific guidance or changing unrelated NutritionProduct text.

Recommendation:
Keep this source fix. It resolves the remaining built-page inconsistency for FHIR-47237; no follow-up is needed unless the work group later wants explicit veterinary examples or broader nutrition-domain guidance.
