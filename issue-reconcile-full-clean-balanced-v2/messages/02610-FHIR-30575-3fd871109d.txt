FHIR-30575: Audit ValueSet extension cardinalities

Issue request:
FHIR-30575 was a Published/Persuasive Vocab change request asking that the lone element in a set of ValueSet-related extensions be made required. The later Jira comments record the decisive clarification: the request came from misunderstanding extension summary cardinalities, because the extension occurrence may be optional while the payload value or required sub-extension is already mandatory when the extension is present.

Initial application:
No core or extension-pack commit explicitly mentioning FHIR-30575 was found. The Jira record shows Marc Duteau first observed in February 2022 that the listed extensions already had required values, and the August 2022 Vocab tracker follow-up recorded that no source application was needed before the issue was marked Applied/Published.

Additional context:
The current core source no longer contains ValueSet extension StructureDefinition source files; commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed those extension definitions from the R5 core source. Current definitions live in the FHIR Extension Pack. Spot checks and a scripted scan of the listed current extension definitions show the payload element is required, e.g. valueset-author has Extension 0..* and Extension.value[x] min 1, valueset-authoritativeSource has Extension 0..1 and Extension.value[x] min 1, and complex extensions such as valueset-otherName and valueset-usage have required named sub-extensions with required values while Extension.value[x] is correctly prohibited. Confluence minutes corroborate both the January 2021 Persuasive vote and the August 2022 decision to update the ticket as applied without further implementation.

AutoFHIR reconciliation:
This is an empty audit commit. No core source edit is appropriate because making the extension occurrence 1..1 would change the meaning of every profile that uses the extension, while the value/sub-extension cardinalities that FHIR-30575 intended to require are already required in the current maintained definitions.

Recommendation:
Keep this no-change audit as-is. Do not change the listed extension root cardinalities to required unless a future Vocab decision explicitly chooses a breaking conformance change for specific extension usages.
