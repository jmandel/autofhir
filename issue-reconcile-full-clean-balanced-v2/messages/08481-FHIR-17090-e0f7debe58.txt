FHIR-17090: Audit Bundle search parameter wording

Issue request:
FHIR-17090 was a Published/Persuasive FHIR-core Feed technical correction for STU3 asking that the Bundle document search parameter description say "this parameter provides access to search its contents" rather than "searches its contents".

Initial application:
The Jira comment records svn 14377, and git history maps that to 7926b460db2a76ff2676138f5a9e31ca2dde7d80, "GF#17090 - fix typo", which changed the then-authoritative source/bundle/bundle-spreadsheet.xml wording from "searches" to "search" on 2018-08-02. Later source refactoring replaced the spreadsheet input with source/bundle/bundle-Bundle-search-params.xml.

Additional context:
The current build has Bundle active in source/fhir.ini, and the current Bundle search parameter source already uses the singular wording for both composition and message search parameters. A tracked-source grep finds no remaining "provides access to searches its contents" occurrence under source/.
