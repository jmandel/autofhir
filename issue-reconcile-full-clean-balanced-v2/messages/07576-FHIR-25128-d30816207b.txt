FHIR-25128: Audit display-category terminology move

Issue request:
FHIR-25128 is a Published/Persuasive FHIR-core technical correction asking that the questionnaire-display-category CodeSystem and ValueSet documentation use "display"/"Display" rather than "text"/"Text", because text is a distinct Questionnaire item type.

Initial application:
The issue was applied in core by commit 12b5e16b4a, which changed source/questionnaire/codesystem-questionnaire-display-category.xml and source/questionnaire/valueset-questionnaire-display-category.xml from QuestionnaireTextCategories/Questionnaire Text Categories and "type 'text'" wording to QuestionnaireDisplayCategories/Questionnaire Display Categories and "type 'display'" wording. No prior Issue-Reconcile-Key commit exists on the combined branch for this issue.

Additional context:
Commit dd468d4f17 later removed the R5 extension/terminology artifacts from this core checkout, including the two questionnaire-display-category source files. Current source/fhir.ini still lists Questionnaire as an active resource, but it has no active CodeSystem or ValueSet entry for questionnaire-display-category; current core source only retains OID/example references and historical generated release bundles. The current FHIR Extension Pack contains the authoritative CodeSystem-questionnaire-display-category.xml and ValueSet-questionnaire-display-category.xml artifacts with the corrected "Questionnaire Display Categories" names and "type 'display'" descriptions. The cited Zulip thread confirms the original typo report, and Confluence searches found no conflicting work-group record.
