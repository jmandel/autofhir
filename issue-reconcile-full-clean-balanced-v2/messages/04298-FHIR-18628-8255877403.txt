FHIR-18628: Audit CodeSystem.supplements canonical wording

Issue request:
FHIR-18628 was a Published/Persuasive STU3 vocabulary clarification for FHIR-core-CodeSystem. It asked that the CodeSystem.supplements element definition be made consistent with CodeSystem.valueSet by saying it is the canonical URL for the code system the supplement adds designations and properties to.

Initial application:
The Jira comment identifies git 4907f9bcb0b710cb2837a93a20c4b23210a37249. That commit updated the then-authoritative source/codesystem/codesystem-spreadsheet.xml row for CodeSystem.supplements from "Code System this adds designations and properties to" / "References the code system..." to "Canonical URL of Code System this adds designations and properties to" / "The canonical URL of the code system that this code system supplement is adding designations and properties to." The later build-source rework in 33b409a4b6d544598262f2f074ebb4b6dc466157 carried the same wording into source/codesystem/structuredefinition-CodeSystem.xml.

Additional context:
CodeSystem is active in source/fhir.ini as a vocabulary resource and its current authoritative StructureDefinition source defines CodeSystem.supplements as canonical(CodeSystem). Later canonical-resource cleanup, including 49b86f8a6978650d8f8a6d36d27dee0433e455bc, touched CodeSystem.valueSet and the CodeSystem StructureDefinition but did not reverse the FHIR-18628 wording for CodeSystem.supplements. Searches for direct Zulip or Confluence discussion of FHIR-18628 found no conflicting community record.
