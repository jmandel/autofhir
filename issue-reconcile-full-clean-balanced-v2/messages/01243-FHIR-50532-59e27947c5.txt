FHIR-50532: Audit normalValue example binding

Issue request:
FHIR-50532 was an Applied R6 OO change request with Persuasive resolution. It asked that Observation.referenceRange.normalValue not use a strict extensible binding to the two-code Observation Reference Range Normal Value value set, and the final resolution was to change the binding strength to Example.

Initial application:
The issue was already applied by git commit 32f80fd081b48e91ba113a631f350c6184c7207c, which changed source/observation/structuredefinition-Observation.xml from <strength value="extensible"/> to <strength value="example"/> for Observation.referenceRange.normalValue. Observation is an active resource in source/fhir.ini, so that StructureDefinition is the authoritative current source for the built element definition.

Additional context:
OO WGM minutes for the May 2025 ballot reconciliation record the rationale: the group did not want an extensible binding because the concepts exist in standard code systems and preferred not to maintain HL7-only codes where other SDO codes can be used; the motion was to back the binding off to example. A later related issue, FHIR-55269, is Resolved - change required and would keep the value set while moving the CodeSystem to THO, but it is not Applied/Published and does not change the binding-strength decision audited here.
