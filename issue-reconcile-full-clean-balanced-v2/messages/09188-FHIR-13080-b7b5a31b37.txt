FHIR-13080: Audit ICPC-1-NL terminology ownership

Issue request:
FHIR-13080 was a Published/Persuasive DSTU2 change request asking FHIR core to add the NHG reference URL for http://hl7.org/fhir/sid/icpc-1-nl to the Code Systems table on terminologies-systems.html.

Initial application:
The requested change was applied in source history before this reconciliation. Commit eb3bd4125bcf57772b4be4698d5f7f6fa0feb8f8, "Added link to the governing body of ICPC-1 NL", added an NHG Table 24 ICPC-1 (NL) link to the ICPC row in source/terminologies-systems.html.

Additional context:
A later Published/Persuasive terminology tracker, FHIR-37853, made HL7 Terminology (THO) the source of truth for external code-system metadata and directed core to delete external Code Systems rows that did not have a "Using X with FHIR" page. Its applied commit 736ccce2005fd2c8c2d20dfe8df948e8c9d586d8 removed the ICPC row, including the FHIR-13080 NHG link. The current core page is in build scope and now points readers to THO external code-system metadata as authoritative. A current THO page check found ICPC entries but no ICPC-1-NL/NHG reference, so any remaining metadata correction belongs to THO/TSMG/UTG rather than this FHIR-core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change in FHIR core. Restoring the old ICPC-1-NL row would conflict with FHIR-37853's later source-of-truth decision and reintroduce non-authoritative external terminology metadata into core.

Recommendation:
Keep this external-repo audit commit as-is. If the ICPC-1-NL NHG Table 24 reference is still needed for current implementers, file or apply that change in the HL7 Terminology/THO source of truth, not in FHIR core.
