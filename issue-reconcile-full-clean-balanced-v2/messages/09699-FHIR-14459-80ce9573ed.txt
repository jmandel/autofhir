FHIR-14459: Audit Vital Signs UCUM system typo

Issue request:
FHIR-14459 was a Published/Persuasive STU3 technical correction from OO asking to fix two Vital Signs Profile references to the UCUM coding system, specifically the malformed `http://unitsofmeasure` URI that should be `http://unitsofmeasure.org`.

Initial application:
The issue appears to have been applied by git commit d2ba28f2081aa24ada764e47671f577bbe3f0fa4 (`[#14459] fix typo`) on 2018-02-05, which changed the old `source/observation/observation-vitalsigns-profile-spreadsheet.xml` summary from `Observation.valueQuantity.system` = `http://unitsofmeasure` to `http://unitsofmeasure.org` and also normalized the component system display to `http://unitsofmeasure.org`.

Additional context:
The old spreadsheet source was later refactored away. The current `source/fhir.ini` actively includes `observation=Observation`, and the current Observation/Vital Signs source under `source/observation` has no malformed `http://unitsofmeasure` URI. The active Vital Signs value set source composes from `http://unitsofmeasure.org`; later Vital Signs binding work such as FHIR-27911 concerns separate value set/content questions, not this URI typo.

AutoFHIR reconciliation:
This commit intentionally makes no source change because the current build-scoped source already uses the correct UCUM system URI and a repository-wide Observation scan found no remaining `http://unitsofmeasure` reference lacking `.org`.

Recommendation:
Keep this empty audit commit as-is. No follow-up is needed for FHIR-14459 in the core FHIR source unless a future generated artifact reintroduces a malformed UCUM system URI.
