FHIR-16603: Audit Patient link type typo removal

Issue request:
FHIR-16603 was a Published PA technical correction against the STU3 Patient resource content table. The reporter asked to correct the displayed LinkType row from "seealso - type of link" to avoid the apparent typo, and the final Not Persuasive with Modification resolution clarified that `seealso` is the code and the extra "- type of link" text should be removed instead.

Initial application:
The historical application appears in commit c3db39b3a857cf5a34988fbc05a935d8ed67a278, "fixed typos GF#16603,16605,16606". The parent Patient spreadsheet contained `replaced-by | replaces | refer | seealso - type of link`; that commit changed the row to `replaced-by | replaces | refer | seealso`. The current source was later refactored into `source/patient/structuredefinition-Patient.xml`, which preserves the corrected short display.

Additional context:
`source/fhir.ini` actively lists `patient=Patient` under `[resources]`, so `source/patient/structuredefinition-Patient.xml` is in the current build scope. The current Patient link code system still defines the code as `seealso` with display "See also", matching the Jira rationale that the code spelling should not be changed. Searches for FHIR-16603 in Zulip and Confluence found no relevant discussion or conflicting work-group record.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already says `replaced-by | replaces | refer | seealso` for `Patient.link.type` and does not include the misleading `- type of link` suffix that FHIR-16603 resolved to remove.
