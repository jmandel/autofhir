FHIR-50647: Audit Transport.focus reference scope

Issue request:
FHIR-50647 was an Applied/Persuasive OO change request for R6 asking to clarify Transport.focus as "The resource representing the physical entity being transported" and to restrict its type from Reference(Any) to a named physical-entity reference list.

Initial application:
The change was initially applied in commit 0eeb5718b2, which updated the Transport.focus definition and replaced Reference(Resource) with a targetProfile list. Commit e9a73dbed7 immediately removed Product from that list because Product is a pattern. The active build scope is the Transport resource entry in source/fhir.ini, with source/transport/structuredefinition-Transport.xml providing the current StructureDefinition source.

Additional context:
OO WGM minutes record the FHIR-50647 motion and 8-0-0 vote to restrict Transport.focus and update the definition. A later Applied/Persuasive with Modification Transport issue, FHIR-50911, explicitly decided to change the references for Transport.focus and Transport.subject to Reference(Any). Commit 00dca87607 applied FHIR-50911 by preserving the FHIR-50647 definition but replacing the restricted Transport.focus targetProfile list with Resource, which is how this source represents Reference(Any).

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source retains the FHIR-50647 definition, and the only apparent mismatch with the original target list is explained by the later FHIR-50911 applied decision. Reintroducing the FHIR-50647 restriction would contradict the current later Transport decision.

Recommendation:
Keep this audit commit as-is. No core source follow-up is recommended for FHIR-50647 unless the work group reopens the later FHIR-50911 Reference(Any) decision.
