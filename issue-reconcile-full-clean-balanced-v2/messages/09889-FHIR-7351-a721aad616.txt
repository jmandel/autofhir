FHIR-7351: Audit ambulatory care context wording

Issue request:
FHIR-7351 was a Published/Persuasive FHIR-core overview change request from the 2015May cycle asking section 1.7.2 to add "ambulatory care" to the list of contexts where FHIR is intended to be usable. The approved resolution was "add it".

Initial application:
The Jira comment says "svn review 6511". Git history contains commit 5e324fa4ca06ecbd4ad29e342be1dda60a0d8b1c, imported from SVN build@6511, with subject "#7351, #7352, #7445, #7353 - editorial updates to clinical overview". That commit changed source/overview-clinical.html from listing "long-term care, community care, allied health" to listing "ambulatory care, long-term care, community care, allied health".

Additional context:
The current build-source page source/overview-clinical.html is still an active clinical overview page: source/hierarchy.xml lists overview-clinical.html as "Clinical Introduction", publish.ini has an output entry for overview-clinical.html, and multiple current overview/module pages link to it. The present wording has evolved editorially to say "usable" and also includes "acute care", but it still includes the requested "ambulatory care" in the same context list. Searches of Zulip and Confluence for FHIR-7351 plus ambulatory-care terms found no conflicting community evidence. Same-family issues FHIR-7352, FHIR-7353, and FHIR-7445 were implemented in the same historical commit and already have separate audit commits on the combined branch, so they are not decided here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative source already contains the requested ambulatory-care context in an active overview page, so adding or rewriting prose would be redundant and could create unnecessary editorial churn.

Recommendation:
Keep this no-change audit commit as-is. No follow-up source work is needed for FHIR-7351 unless the work group separately decides to revise the broader clinical overview context list.
