FHIR-34033: Clarify evaluatedResource report scopes

Issue request:
FHIR-34033 was a Published/Persuasive with Modification CQI change request for R5 MeasureReport.evaluatedResource. It asked to avoid wording that implied evaluatedResource should contain every resource considered during evaluation, and the final resolution clarified that evaluated resources are bounded, primarily individual-report evidence, while R5 would separate supplemental data and include a subject-list example.

Initial application:
The issue was applied in f19cf89c19ca2169c4df72ed0e24161259840ba0, which changed MeasureReport.evaluatedResource from a generic reference to resources used in calculation to language saying evaluated resources were only allowed for individual reports, and added a subject-list MeasureReport example. That application addressed the original concern at the time but left the current source too narrow after later data-exchange work.

Additional context:
MeasureReport is active in source/fhir.ini, and the authoritative source is source/measurereport/structuredefinition-MeasureReport.xml. Later applied CQI work, including FHIR-51066 for $collect-data and FHIR-39174/FHIR-50487 for $submit-data/data-exchange reporting, makes data-exchange MeasureReports a current build use case for evaluatedResource. Current operation examples and guidance use MeasureReport.type=data-exchange with evaluatedResource references to data-of-interest, so the old individual-only wording had become inconsistent with the rest of the current specification.

AutoFHIR reconciliation:
This commit updates the MeasureReport.evaluatedResource short text, definition, comment, and committee note to preserve FHIR-34033's bounded-data intent while explicitly allowing the later data-exchange report use. The new wording distinguishes subject-specific resources for individual reports from data-of-interest submitted or collected for data-exchange reports, and points subject-list/summary reports to their population and subject reporting elements instead of evaluatedResource.

Recommendation:
Keep this source change. It is a targeted correction to the active MeasureReport StructureDefinition that reconciles FHIR-34033 with later applied data-exchange decisions without adding a new invariant or changing examples outside the evidence-supported scope.
