FHIR-39003: Audit SEVCO removal from ResearchStudy classifiers

Issue request:
FHIR-39003 is Applied/Persuasive for R6 and requested removal of copied external SEVCO study-design codes from the core research-study-classifiers CodeSystem once SEVCO was listed for use through THO.

Initial application:
Commit d69a19f9aef94ce2ea85ea794f0a3c23ae051982 originally added the temporary SEVCO codes to source/researchstudy/codesystem-research-study-classifiers.xml. Commit d85c4f83a0934485bbec58088923ddb7c4ebe1cd then removed 1107 lines from that CodeSystem with the message that codes were moved to their own system. The later PR #4035 binding changes completed the current-source migration by pointing Study Design bindings to the THO ValueSet.

Additional context:
BRR minutes on 2025-03-13 record a 6-0-0 vote on FHIR-39003 under "SEVCO used for studyDesign." Current core source still defines the local research-study-classifiers CodeSystem, but it now contains only local classifier concepts such as fda-regulated-drug, fda-regulated-device, mpg-paragraph-23b, and irb-exempt. The THO 7.1.0 package contains CodeSystem-SEVCO with URL https://fevir.net/sevco and the THO Study Design ValueSet uses SEVCO codes.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the copied SEVCO codes are already absent from the core ResearchStudy classifiers CodeSystem and the external SEVCO CodeSystem is represented through THO.

Recommendation:
Keep this no-change audit commit as-is. Future changes to SEVCO content or the Study Design value set should be handled in THO/UTG rather than by reintroducing copied SEVCO content into FHIR core.
