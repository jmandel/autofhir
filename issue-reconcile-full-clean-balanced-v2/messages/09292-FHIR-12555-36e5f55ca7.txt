FHIR-12555: Audit Downloads package guidance

Issue request:
FHIR-12555 was a Published/Persuasive FHIR-I change request for DSTU2 asking the Downloads page to include the validation/IG pack artifact and clarify how downloadable artifacts are used for validation, publishing, implementations, definitions, examples, and full IG output.

Initial application:
The issue was applied in git-svn commit 344f6b42c141e8e03cd7ac7211e5cef07432b0ac, matching Jira's svn revision 11395 comment, by adding an IG Pack row to source/downloads.html. Later Downloads history changed that row from igpack.zip to the FHIR NPM package system, including commit 641002468f296d9085044e7704733e224a609f82 and follow-up package link fixes.

Additional context:
The current build-scoped Downloads page is listed in publish.ini and no longer references validator.pack, igpack.zip, or package.tgz directly. Instead it lists the current hl7.fhir.r6.* NPM packages and says they contain resources for conformance testing/code generation and are used by the IG publisher and validator through the NPM-based distribution framework. Later community guidance treats validator.pack as deprecated and points IG authors to .tgz packages instead, so restoring the old artifact name would be stale.

AutoFHIR reconciliation:
This is an empty audit commit. The current source and CI-rendered Downloads page already communicate the modern replacement for the validation pack guidance and the issue's historical implementation has been carried forward through the package-system refactor.

Recommendation:
Keep this audit commit as-is. No source change is recommended unless a future work group decision asks for new current-package wording; reintroducing validator.pack/igpack.zip would conflict with current package-system guidance.
