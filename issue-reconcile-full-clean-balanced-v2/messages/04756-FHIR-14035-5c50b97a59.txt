FHIR-14035: Audit Practitioner cab-driver note removal

Issue request:
FHIR-14035 was a Published/Persuasive Patient Administration change request for the STU3 Practitioner page asking to remove the unusual comment, "Note that a cab driver no longer fits the bill. You probably would be interested in the organization rather than the individual?" Lloyd McKenzie's Jira comment confirmed the note should be removed while preserving the rule that Practitioner covers anyone acting in a professional capacity.

Initial application:
The issue was applied in git commit a77b1c2819418c7e6eebaad47f57213c62769019, "GF#14035: remove cab driver comment," which removed that exact comment from the then-authoritative source/practitioner/practitioner-spreadsheet.xml source. The current resource source has since been refactored to source/practitioner/structuredefinition-Practitioner.xml and source/practitioner/practitioner-introduction.xml; neither current Practitioner source file contains the removed cab-driver note.

Additional context:
source/fhir.ini actively includes practitioner=Practitioner, so the source/practitioner inputs are in current build scope. The only remaining exact old wording is in tools/history/release2 and tools/history/release3 release snapshots, plus the external published STU3 profile, which are historical surfaces rather than current Practitioner source to correct in this reconciliation. Later Published Practitioner issues FHIR-21242 and FHIR-27900 deliberately clarified that Practitioner has a wide scope, including bus/truck-driver-style examples when the person is acting for a care-related organization, so the current bus-driver example is not a regression of FHIR-14035.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build-scope Practitioner definition and introduction no longer contain the removed note, and editing historical release snapshots would rewrite old release evidence rather than fix the current specification.

Recommendation:
Keep this audit commit as-is. No current FHIR core source edit is needed for FHIR-14035; if HL7 ever chooses to republish or annotate old STU3 artifacts, that should be handled as a separate historical-publication decision rather than a current R6 source fix.
