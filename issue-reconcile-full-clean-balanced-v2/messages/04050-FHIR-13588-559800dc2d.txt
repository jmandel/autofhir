FHIR-13588: Audit dynamicValue whole-resource path

Issue request:
FHIR-13588 was a Published/Persuasive CDS issue for STU3 ActivityDefinition and PlanDefinition. It reported that a dynamicValue.path example used "~" to mean the whole result object, and the accepted resolution was to use "$this" instead so the path is valid FHIRPath and to document that usage for expressions.

Initial application:
The Jira comment records SVN 13322. The corresponding git-svn commit fe9a278da48fa5f1e5fac3ca1bc517fafd96b8e2 corrected Using Expressions examples but did not itself replace the PlanDefinition chlamydia example's "~" path. The surrounding application trail shows the substantive fix: commit 2efa733958ddc13c6c625fb4907c881ef081037c changed the PlanDefinition action definition comment from a root "~" path to a root "$this" path, and commit 3dc81b908557be64248363dc4e5bbf5ed5213965 later replaced the chlamydia example's <path value="~"/> with <path value="$this"/> while reworking ActivityDefinition and PlanDefinition dynamicValue content to use the Expression datatype.

Additional context:
ActivityDefinition and PlanDefinition are active current-build resources in source/fhir.ini, and the Using Expressions page is in the active Clinical Reasoning hierarchy. Later source refactors to StructureDefinition XML preserved the PlanDefinition root "$this" comment, and FHIR-19545 separately clarified that the restricted Simple FHIRPath subset allows "$this" to refer to the focused element. The related dynamicValue path issues FHIR-18237 and FHIR-18239 are already represented on the combined branch and do not require another decision here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source no longer contains the old dynamicValue "~" path in the relevant PlanDefinition, ActivityDefinition, or Using Expressions sources; it uses <path value="$this"/> in the chlamydia PlanDefinition example, explains root ($this) dynamicValue usage in PlanDefinition.action.definition[x], and the linked Simple FHIRPath page defines "$this" as the focused element.

Recommendation:
Keep this no-change audit commit. No follow-up core source work is needed for FHIR-13588 unless the CDS work group wants additional non-normative examples beyond the existing PlanDefinition example, PlanDefinition comment, and Simple FHIRPath definition.
