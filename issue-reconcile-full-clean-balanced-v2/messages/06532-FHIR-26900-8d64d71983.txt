FHIR-26900: Audit DeviceUsage patient search scope

Issue request:
FHIR-26900 is a Published/Persuasive OO technical correction for the R4 DeviceUseStatement clinical-patient search parameter. It asked that the patient search parameter restrict DeviceUseStatement.subject to Patient only so Group references remain available only through the subject search parameter.

Initial application:
The linked R4B application commit b717783b86bab2bb3aa9ca289f2cd11a7ba18107 changed source/deviceusestatement/bundle-DeviceUseStatement-search-params.xml from DeviceUseStatement.subject to DeviceUseStatement.subject.where(resolve() is Patient). That commit is on the R4B lineage rather than the current core branch. The current branch later renamed DeviceUseStatement to DeviceUsage and, through the FHIR-41413 family-care work, restored the same Patient-only expression plus target Patient on DeviceUsage-patient.

Additional context:
Current source/fhir.ini no longer lists DeviceUsage as an active core resource; commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed DeviceUsage and other OO resources from core build metadata and changed core narrative links to the OO Incubator IG. The remaining source/deviceusage files in this checkout are therefore not authoritative current-build inputs. The current HL7/oo-incubator source and CI build define SearchParameter/DeviceUsage-patient with expression DeviceUsage.subject.where(resolve() is Patient) and target Patient. Related FHIR-28219/FHIR-32876 confirm the broader clinical-patient target intent, and later FHIR-41413 intentionally allows Group on DeviceUsage.subject while preserving the Patient-only patient search parameter.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current FHIR core build no longer owns DeviceUsage, and the external OO Incubator artifact that now owns DeviceUsage already carries the Patient-only search parameter semantics requested by FHIR-26900.

Recommendation:
Keep this audit commit as-is for core reconciliation. No follow-up is needed in FHIR core for FHIR-26900; if DeviceUsage is reviewed in the OO Incubator IG, preserve the current split between patient = DeviceUsage.subject.where(resolve() is Patient) with target Patient and subject = DeviceUsage.subject for Patient or Group.
