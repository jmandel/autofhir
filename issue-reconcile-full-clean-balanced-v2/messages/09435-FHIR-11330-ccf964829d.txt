FHIR-11330: Point exchange guidance to Exchange Module

Issue request:
Published/Persuasive FHIR-core issue FHIR-11330 asked to correct the Foundation Module exchange-paradigm text because it said FHIR supported 3 paradigms while the surrounding section also described Services; the accepted decision was that there are 4.

Initial application:
The issue was initially applied in svn @10162, represented in git by 83f1205cc1, which changed source/foundation-module.html from 3 to 4 exchange paradigms and added Services to the list. Later git history, especially c397bd0b1f, moved the exchange-use content out of the Foundation Module into the current Exchange Module.

Additional context:
The current active Exchange Module already lists the recognized exchange methods, including Services, and has since expanded the set to include Database / Persistent Storage and the Subscriptions Framework. source/hierarchy.xml includes exchange-module.html as the active Exchange module page. A current-source search found no remaining stale "3 different paradigms" or "4 different paradigms" wording, but source/modules.html still sent implementers asking how information is exchanged to the removed foundation-module.html#uses anchor instead of the current Exchange Module.

AutoFHIR reconciliation:
Updated source/modules.html so the Getting Started question "How will information be exchanged?" links to exchange-module.html and labels it the Exchange Module. The already-correct exchange-method list was not rewritten.

Recommendation:
Keep this source fix. It preserves the original Jira decision, respects the later module refactor, and removes the only discovered current navigation defect tied to the retired Foundation Module exchange-use section.
