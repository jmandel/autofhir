FHIR-8908: Audit ShareableValueSet profile update

Issue request:
FHIR-8908 was a Published/Persuasive Vocabulary change request for the FHIR-core ValueSet artifact asking that the ShareableValueSet profile explicitly state the extensions in use.

Initial application:
The issue was applied for R5 in Bryn Rhodes' PR 2068 implementation commit 93fadfaa2a, whose subject explicitly cites J#8908 and whose diff added explicit ValueSet.extension slices for cqf-knowledgeRepresentationLevel and valueset-authoritativeSource to source/valueset/structuredefinition-profile-shareablevalueset.xml. The same commit also registered the Shareable/Publishable/Computable/Executable ValueSet profiles in source/valueset/implementationguide-ValueSet-core.xml.

Additional context:
FHIR-31395 was implemented in the same PR 2068 change family and broadened the R5 ValueSet profile work. A later final R6 decision, FHIR-37959, resolved that the Shareable/Publishable/Computable/Executable profiles should be removed from FHIR core and maintained going forward in the Canonical Resource Management IG, with the profile URIs unchanged. The current source reflects that migration: the ValueSet core implementation guide no longer lists those profile resources, the ShareableValueSet StructureDefinition source file is absent, and fhir.ini has no active profile entry for it.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Reintroducing or editing the old ShareableValueSet profile in current core would conflict with the later applied R6 migration decision and would touch an out-of-build artifact rather than fixing the current FHIR specification.

Recommendation:
Keep this audit commit as-is. If future work discovers a problem in the migrated ShareableValueSet profile, handle it in the repository that owns the CRMI/terminology profile content rather than in FHIR core.
