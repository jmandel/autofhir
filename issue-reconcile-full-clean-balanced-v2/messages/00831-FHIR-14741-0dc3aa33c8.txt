FHIR-14741 was a Published/Persuasive STU3 FHIR-core OccupationalData change request from PHER asking to rename the `combatZoneWork` element to `combatZonePeriod` because the element is a Period rather than a flag-like work concept.

Initial application:
The Jira comment says the change was applied as svn 13307. Git commit 1834d69412f3ba4890c5930897e1a58b6c98aad0 is that svn revision and explicitly references FHIR-14741/#192 while changing the OccupationalData XML example from `<combatZoneWork>` to `<combatZonePeriod>` and the spreadsheet row from `OccupationalData.combatZoneWork` to `OccupationalData.combatZonePeriod`.

Additional context:
The current core build no longer includes OccupationalData: source/fhir.ini keeps only a commented retired entry, `; OccupationalDataforHealth=pending -> Dropped`. The remaining inactive source/occupationaldata files still use the requested `combatZonePeriod` name, and the FHIR Extension Pack checkout has no OccupationalData definition to reconcile here. PHWG WGM minutes record Comment 192 as persuasive and say CombatZoneWork would be updated to CombatZonePeriod; no Zulip or Confluence Jira-reference search found a conflicting later decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change. FHIR-14741 concerns a dropped, out-of-current-build core artifact, and the remaining inactive source already reflects the historical rename, so editing it would not change the current built specification.

Recommendation:
