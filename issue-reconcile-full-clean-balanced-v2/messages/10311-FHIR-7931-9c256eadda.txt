FHIR-7931: Audit compartment search clarification

Issue request:
FHIR-7931 was a Published FHIR-core/FHIR-I clarification request from the 2015May ballot asking for clearer rules and examples for variant searches within compartments. The final Persuasive with Modification resolution was to add more explanation about criteria for compartment selection on the compartments page and to add a few more example searches.

Initial application:
The issue was applied in git-svn commit 37bfea665763e845403dcef6d28a2903f3c501bc, whose message is "#7931 - more doco about compartments" and whose git-svn id records SVN revision 6529, matching the Jira application comment. That commit added compartment usage examples and explanatory text to the historical source/compartments.html page.

Additional context:
The current R6 source has since been refactored into the active CompartmentDefinition resource pages. source/fhir.ini lists compartmentdefinition as an active resource, and source/compartmentdefinition/compartmentdefinition-introduction.xml now explains that membership is determined by the listed search parameters with the compartment resource as the value. source/compartmentdefinition/compartmentdefinition-notes.xml retains the concrete Patient/Condition and Patient/Communication examples, explains direct-search equivalents and union semantics, and links back to HTTP variant search behavior. The HTTP page still contains the Encounter/Observation compartment search example and now points readers to both Search Contexts and the Compartments page. Later applied/published compartment issues such as FHIR-19651, FHIR-22269, FHIR-51604, and FHIR-51725 clarify boundaries and computability but do not reverse the FHIR-7931 guidance.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already conveys the approved additional explanation and examples, and adding duplicate prose to source/http.html would not change implementer understanding.

Recommendation:
Keep this audit commit as-is. No follow-up source work is recommended for FHIR-7931 unless the work group wants a broader reorganization of compartment documentation beyond the original 2015 clarification.
