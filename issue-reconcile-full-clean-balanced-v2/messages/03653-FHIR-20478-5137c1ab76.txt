FHIR-20478: Audit NamingSystem clarification

Issue request:
FHIR-20478 was a Published Vocab change request for R5 asking to clarify the specific use of NamingSystem. The persuasive-with-modification resolution replaced the NamingSystem Boundaries and Relationships prose so it explains that NamingSystem manages identifiers of code or identifier systems, identifier metadata, and limited system metadata, while CodeSystem can represent code-system content and other metadata.

Initial application:
The issue was applied by git commit 9500b398d1d850a06cd180c82ce330e4809a2b49, "vocab r5 tickets batch 2", which replaced the NamingSystem introduction's old CodeSystem/NamingSystem comparison with the approved replacement text. The current build-scope configuration has namingsystem as an active resource, and the current NamingSystem introduction still contains the approved replacement.

Additional context:
The 2020 Zulip discussion and the May/October 2021 Vocab minutes show the work group was clarifying when NamingSystem should be used for identifier metadata versus CodeSystem. The CodeSystem introduction still contains older relationship prose, but that later CodeSystem-page problem is now directly addressed by FHIR-54129, an R6 technical-correction issue in Resolved - change required / indeterminate status that was reopened because Grahame Grieve had concerns. That related issue is context, not a safe source-change target for this default Applied/Published reconciliation.
