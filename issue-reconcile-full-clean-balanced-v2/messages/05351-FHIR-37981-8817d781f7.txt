FHIR-37981: Audit SupplyDelivery receiver organization target

Issue request:
FHIR-37981 was a Published/Persuasive R5 OO change request asking that SupplyDelivery.receiver add Organization to the allowed reference targets and that the receiver description/constraint match "The individual or organization that received the delivery."

Initial application:
The Jira comment says the change was added to the build in fbd31739bfe479a3c2172cdb1ea21e805f2691b1. That commit updated source/supplydelivery/structuredefinition-SupplyDelivery.xml by adding the Organization target profile to SupplyDelivery.receiver and changing the definition from "person or organization" to "individual or organization."

Additional context:
A later Applied OO issue, FHIR-41414, intentionally broadened the same receiver element for R6 by adding Group, changing the definition to "individual(s) or organization," and adding the Group-usage comment. Current core build scope has since changed: commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed supplydelivery=SupplyDelivery from active source/fhir.ini resource/workgroup/fmm/classification entries and redirected core pages to the OO Incubator IG. The current external OO Incubator StructureDefinition for SupplyDelivery.receiver contains Practitioner, PractitionerRole, Organization, and Group target profiles, preserving the FHIR-37981 Organization addition together with the later FHIR-41414 Group addition.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. SupplyDelivery is no longer an active core resource in this checkout, and the current external artifact already includes the requested Organization receiver target. Editing the disabled core source or generated-looking diagrams would not correct the current core build.

Recommendation:
Keep this audit commit as-is for FHIR core. If SupplyDelivery.receiver needs further change, perform it in the HL7/oo-incubator source rather than in the inactive core SupplyDelivery files.
