FHIR-14356: Audit CodeSystem supplements status

Issue request:
FHIR-14356 was a Published/Persuasive Vocab change request for R5 asking that CodeSystem.supplements and the Code System Supplements section heading be marked Trial Use because supplements were still immature and insufficiently documented.

Initial application:
The request was applied in commit 9500b398d1, which added a trial-use standards-status extension to CodeSystem.supplements and a Trial Use badge on the Code System Supplements heading. Commit 6a5c1b1ac6 then fixed the malformed heading markup from that application.

Additional context:
The same CodeSystem resource is active in the current build through source/fhir.ini, but later issue FHIR-39260 was Applied/Persuasive for R6 and explicitly resolved to remove references to code system supplements as trial use from the core specification. Commit 39f96b21ce implemented that later decision by removing the heading badge, the supplements element trial-use extension, and the experimentation warning.

AutoFHIR reconciliation:
This audit commit makes no source change. Reintroducing the FHIR-14356 Trial Use notation would contradict the later FHIR-39260 work-group decision and the current authoritative CodeSystem source.

Recommendation:
Keep this audit commit as-is. The R5 application of FHIR-14356 is historically correct, and the current build should stay with the later R6 FHIR-39260 state unless the work group reopens supplements status.
