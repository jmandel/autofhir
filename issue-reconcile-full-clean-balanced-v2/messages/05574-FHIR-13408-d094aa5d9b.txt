FHIR-13408: Audit SNOMED CT version guidance

Issue request:
FHIR-13408 was a Published/Persuasive with Modification STU3 vocabulary issue asking to clarify the old FHIR-core SNOMED CT "Version Issues" section. The approved clarification was that terminology services may default to the latest available SNOMED CT International Edition when no version URI is supplied, may default to the latest version of a named distribution when a distribution URI omits a release date, and should treat date-only version strings as errors per the additional comment.

Initial application:
The issue was applied in SVN/git history by 716c57421852089f5d4b87df378fc2ca0ccaccb0, whose message is "GF#13408 - clarifications about SCT Uri" and whose patch updated source/snomedct.html with the date-only error guidance, the minimum http://snomed.info/sct/[sctid] URI form, and the no-version/no-date defaulting language.

Additional context:
The old source/snomedct.html page is no longer in the current FHIR-core build. Later Published issue FHIR-35933 moved the "Using external code system with FHIR" pages out of FHIR core and into HL7 Terminology (THO), deleting source/snomedct.html and leaving source/terminologies-systems.html to link to https://terminology.hl7.org/SNOMEDCT.html. The current THO SNOMED CT page contains the relevant Versions guidance, including the date-only error rule and the defaulting text requested by FHIR-13408. Current source/hierarchy.xml still includes only the SNOMED CT usage report as a local child page, confirming the old narrative page is not in build scope.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No FHIR-core source edit is needed because the FHIR-core source now delegates authoritative SNOMED CT usage guidance to THO, and the linked current THO page already preserves the FHIR-13408 clarification.

Recommendation:
Keep this audit commit as-is. Do not re-create the removed FHIR-core snomedct.html page or duplicate the THO guidance in current core source; future wording changes for the SNOMED CT guidance should be handled in THO/UTG unless the FHIR-core link itself becomes incorrect.
