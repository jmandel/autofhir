FHIR-41288: Audit hosted comparison links

Issue request:
FHIR-41288 was an Applied/Persuasive FHIR-core BaseResource issue reporting that the Base page footer comparison link could fail for prior versions such as R4B/R4 types.html because Base was added after those releases. The final Jira resolution says this is not a specification issue and was already fixed by hosting the W3C comparison service directly in HL7.

Initial application:
No Jira-keyed FHIR-41288 source commit was found. Source history shows the footer comparison service was changed implicitly: commit 79c1d3ae328738b78f62d3644395f0dafe6ed7b1 removed the W3C htmldiff URL for the then-current R5 comparison link, and commit 71567db3ee039ac6977be5f96a7e013896569a36 later put the current Compare to R4, Compare to R5, and Compare to Last Ballot links on https://www.fhir.org/perl/htmldiff.pl.

Additional context:

FHIR-I minutes on 2026-04-13 record the final 13-0-0 Persuasive vote and the note that it was already fixed. The current footer template is in build scope for generated pages and now uses the HL7-hosted comparison endpoint rather than services.w3.org.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current FHIR source already reflects the applied decision by using the HL7-hosted comparison endpoint, and the Jira resolution explicitly treats the remaining concern as service/hosting behavior rather than a Base page specification defect.

Recommendation:
