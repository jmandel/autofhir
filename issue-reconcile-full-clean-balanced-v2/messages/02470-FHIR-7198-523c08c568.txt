FHIR-7198: Audit superseded genetics profile

Issue request:
FHIR-7198 was a Published/Persuasive DSTU1 Clinical Genomics request against FHIR-core Observation saying the 2015May genetics material seemed unfinished. The accepted resolution was to make the Observation genetics profile support current genetic reports without sequence information by using Observation.component, adding a Result extension for lists of mutations or variants, and adding AllelicFrequency, CopyNumberEvent, and ReadCoverage.

Initial application:
No current commit message explicitly mentions FHIR-7198, but the nearby Git/SVN history shows the requested change was applied to the old Observation genetics profile. Commit 45025abf6c99388591b956ef20357479b9a0e7ab, dated 2015-08-21 and titled "updated genetics", updated source/observation/observation-genetics-introduction.xml and source/observation/observation-genetics-profile-spreadsheet.xml to add Observation.component guidance, a Result extension, and the AllelicFrequency, CopyNumberEvent, and ReadCoverage attributes named in the Jira resolution.

Additional context:
The old core Observation genetics material did not remain part of the current build. Later Clinical Genomics work first deprecated the core genomics reporting profiles and pointed implementers to the Genomics Reporting Implementation Guide, then removed the outdated Observation, DiagnosticReport, and ServiceRequest genomics profiles and examples from core in commit 3cfe12f1b4037e4fe922af288ba96fa49faf1435. FHIR-19440 and FHIR-28620 record the later published decisions to refactor, deprecate, or remove Observation-genetics guidance and direct implementers to the Genomics Reporting IG. Current source/genomics.html points to the Genomics Reporting IG and current genomics resources; source/fhir.ini has no active old Observation genetics profile entry, and the old source/observation/observation-genetics-* profile files are absent.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing or editing the obsolete Observation genetics profile would be contrary to later published Clinical Genomics/O&O decisions and outside the current core build. The current core source already reflects the appropriate state: a genomics overview plus current GenomicStudy and MolecularDefinition material, with clinical genomic result profiles handled by the Genomics Reporting IG.

Recommendation:
Keep this audit commit as-is. If implementers need changes to clinical genomic reporting profiles, handle them in the Genomics Reporting IG or current Clinical Genomics resource work rather than reviving the removed DSTU1/R4 Observation-genetics profile in core.
