FHIR-6917: Audit narrative-only section guidance

Issue request:
FHIR-6917 was Published with resolution Persuasive with Modification. It asked to simplify DSTU1 Composition wording that said narrative-only sections could be made by setting section content to a suitable resource with only narrative, or by using List when no suitable resource existed. The proposed wording would have made List.text the narrative holder for sections, but the Jira comments record that the language was removed altogether per #7404.

Initial application:
No explicit FHIR-6917 or #6917 source commit was found in Composition/List/document history. The relevant application appears to be the related FHIR-7404 implementation: git-svn commits 686889f8a3b83c74a4e58ddddfac7616dd0da4ca and 749c4dd88234688f57191d3d0b4d62bdc525b87d refactored Composition from section.content/List toward Composition.section.text and Composition.section.entry, updated document presentation prose, and removed the exact obsolete narrative-only section paragraph.

Additional context:
FHIR-7103 raised the same Composition narrative-only wording request and is already represented on the combined branch by commit 8bff8454ed916dfb06b41eb0f670233d02044c42. FHIR-7404 is already represented on the combined branch by commit 40f10d0835dfa1b2886ceb5e5d2cdf0456ca504e. Current build scope includes Composition and List as active resources in source/fhir.ini. Current combined source says Composition.section.text contains the attested section narrative, Composition.section.entry references supporting data, narrative-only sections are represented with Composition.section.text and no Composition.section.entry, and List narrative is not part of the attested document presentation unless incorporated into Composition narrative or Composition.section.text.

AutoFHIR reconciliation:
Published an empty no-change audit commit for FHIR-6917. No source edit is needed because applying the original List.text simplification now would reintroduce an obsolete model that FHIR-7404 superseded, while current active source already gives implementers the correct Composition.section.text rule for narrative-only document sections.

Recommendation:
Keep this audit commit as-is. Do not add new List.text guidance for FHIR-6917 unless the work group reopens the document narrative model; any future adjustment should start from current Composition.section.text and document presentation rules, not from the retired section.content/List model.
