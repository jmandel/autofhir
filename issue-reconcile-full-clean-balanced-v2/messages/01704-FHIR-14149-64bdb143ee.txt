FHIR-14149: Audit comments guidance for Media and ImagingStudy

Issue request:
FHIR-14149 was Published/Persuasive for STU3. It asked to clarify that Media.note and ImagingStudy.description are not for observations, conclusions, or findings, and that those should instead be recorded using another resource such as Observation based on the Media or ImagingStudy resource.

Initial application:
The Media part appears to have been applied before this reconciliation: commit 17a86882a2828780d4c4f2bd3155b8434c7af17f added the requested Media.note comment text to source/media/media-spreadsheet.xml. The ImagingStudy part was explicitly applied in commit 7b2b64512052c9a800a59b0ac3cd2cd013659b1b, whose subject includes GF#14149 and whose ImagingStudy spreadsheet hunk added the DICOM Study Description and observation/finding guidance to ImagingStudy.description.

Additional context:
In the current build, ImagingStudy remains active in source/fhir.ini and source/imagingstudy/structuredefinition-ImagingStudy.xml is the authoritative source for the resource. Media is not listed as an active resource in source/fhir.ini's [resources] section, and the current resource guide classifies Media as a past resource, so editing source/media for this STU3-era request would not be a current-spec fix. Later Applied R6 issues FHIR-47670 and FHIR-47672 deliberately revisited the same ImagingStudy note/description confusion: FHIR-47670 removed the old DICOM Study Description and Observation warning from ImagingStudy.note, and FHIR-47672 clarified ImagingStudy.description as "Description or classification of the imaging study." Those later decisions supersede restoring the literal FHIR-14149 ImagingStudy warning text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The only still-current artifact from the seed's scope, ImagingStudy, now has later work-group-approved note and description definitions that avoid the old confusion without restating the STU3 warning. Media's historical source already contains the requested note text, but Media is outside the current active build scope.

Recommendation:
Keep this audit commit as-is. Do not re-add the FHIR-14149 observation/finding warning to current ImagingStudy.description unless the work group reopens the 2025 FHIR-47670/FHIR-47672 clarification family; do not edit source/media unless Media is reintroduced into the active build.
