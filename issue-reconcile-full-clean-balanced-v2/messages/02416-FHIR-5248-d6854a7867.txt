FHIR-5248: Audit document presentation clarification

Issue request:
FHIR-5248 was a Published FHIR-core DSTU1 clarification request for the Documents page. It asked whether the page's statements that a document has a fixed presentation and that its presentation cannot change contradicted the stylesheet guidance, because document-specified stylesheets were only a SHOULD and alternative stylesheets might change presentation. The disposition agreed further clarification was needed and left the DSTU2 edit to the editors, especially for authenticated content.

Initial application:
The issue was applied by git-svn commit 4d09a65d3047151c00ef5391e3f7cf61d360da05, which matches the Jira comment's SVN revision 4657 and added the rule that any referenced or used stylesheet SHALL NOT alter presentation in a way that changes the clinical meaning of the content. No current source gap remains from that application.

Additional context:
Later document-page decisions refined the same area. FHIR-7388 softened the old "presentation of the document cannot change" sentence to allow non-substantial presentation differences that do not change clinical meaning. FHIR-8027 adjusted the internal stylesheet rationale. FHIR-36636 later removed the old immutability/cannot-change paragraph entirely and reframed document updates around frozen resource versions and attestation validity. The current source/documents.html page is active in the build through the source hierarchy and now defines document presentation as attested content while retaining the stylesheet SHALL NOT clinical-meaning guardrail.

AutoFHIR reconciliation:
This is an empty audit commit. The current source already resolves the FHIR-5248 ambiguity: it no longer contains the original absolute "presentation cannot change" wording, it explains attested content in the Document Presentation section, and it permits stylesheet use only with the existing clinical-meaning constraint plus a SHOULD for document-specified stylesheets unless trading partners agree otherwise.

Recommendation:
Keep this audit commit as-is. No source change is needed for FHIR-5248; adding more local prose would restate existing guidance and risk drifting from the later FHIR-36636 document-control wording.
