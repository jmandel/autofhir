FHIR-39067 was a Published/Persuasive Patient Administration technical correction for the R5 Encounter artifact. It asked to change the Encounter status code from `onhold` to `on-hold`, noting that other status codes use hyphens to represent spaces.

Initial application:
The request was already applied by git commit b799f4f33ac8d1a4353b75fdf631bdd1a61ce3ba, `FHIR-39067 onhold Change of Code`, which changed Encounter status source, the Encounter search-parameter description, an Encounter example, and the shared status-code spreadsheet row from `onhold` to `on-hold`.

Additional context:
Patient Administration minutes from 2022-11-02 confirm the work group voted on FHIR-39067 because the nominal technical correction was not backward compatible. Encounter is an active current-build resource in source/fhir.ini, and the current authoritative Encounter CodeSystem, StructureDefinition short text, shared status-code row, event mapping exception, and narrative all use `on-hold`. The only remaining `onhold` source hits are EpisodeOfCare-specific rows and files, which are outside this Encounter-scoped issue and were not decided here.
