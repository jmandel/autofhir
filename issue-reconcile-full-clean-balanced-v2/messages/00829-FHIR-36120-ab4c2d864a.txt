FHIR-36120: Audit ImagingStudy Coding datatype update

Issue request:
FHIR-36120 was a Published/Persuasive R5 Imaging Integration change request asking to replace ImagingStudy Coding elements with richer datatypes: ImagingStudy.modality, ImagingStudy.series.modality, and ImagingStudy.series.laterality should become CodeableConcept, and ImagingStudy.series.bodySite should become CodeableReference targeting BodyStructure.

Initial application:
The issue was applied before this reconciliation by commit 1891df8e49d773c1958178726f7399e5f5bd7e7e ("imaging CR FHIR-36165, FHIR-36164, FHIR-36120"). That commit changed the authoritative ImagingStudy StructureDefinition datatypes, added the BodyStructure target for series.bodySite, adjusted examples to wrap Coding content inside CodeableConcept/CodeableReference branches, and moved the body-site token search path to ImagingStudy.series.bodySite.concept.

Additional context:
Later R6 work changed how laterality is represented. FHIR-46301 first clarified that ImagingStudy.series.laterality, when present, had to be consistent with laterality inside bodySite. FHIR-50859 then applied the final laterality/bodySite approach: keep series.bodySite as CodeableReference, remove ImagingStudy.series.laterality, and add Body Site and Laterality guidance. FHIR-50859 and the same-change-family FHIR-36164 already have audit commits on the combined branch, so this commit does not duplicate them. The remaining stale ImagingStudy.series.laterality mentions found during this seed check are in the generated-looking SVG diagram, not in the authoritative XML source.

AutoFHIR reconciliation:
This commit intentionally makes no source changes. ImagingStudy is an active current-build resource in source/fhir.ini. The current source defines ImagingStudy.modality and ImagingStudy.series.modality as CodeableConcept and ImagingStudy.series.bodySite as CodeableReference with targetProfile BodyStructure; ImagingStudy.series.laterality is absent because of the later FHIR-50859 decision, with current narrative guidance explaining that laterality can be carried through series.bodySite codes or BodyStructure references. Search parameters and examples are aligned with the CodeableConcept/CodeableReference representation.

Recommendation:
Keep this no-change audit commit as-is. The current specification satisfies FHIR-36120 after later accepted R6 refinements; do not reintroduce ImagingStudy.series.laterality or manually edit generated diagrams under this issue. If the stale SVG is still used by the build, regenerate diagrams through the normal pipeline under the later bodySite/laterality work rather than treating it as missing FHIR-36120 source work.
