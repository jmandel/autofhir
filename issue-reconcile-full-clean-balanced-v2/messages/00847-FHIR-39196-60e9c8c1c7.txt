FHIR-39196: Audit SFCU guidance referral

Issue request:
FHIR-39196 was a Published FHIR-core Patient Administration change request asking whether resource-level Sex for Clinical Use was precise enough, especially for Observation where SFCU might apply to subject or focus. The final Not Persuasive with Modification disposition chose not to add detailed core rules; it said core should remain fairly vague and defer usage guidance to the Gender Harmony Implementation Guide.

Initial application:
No core commit explicitly names FHIR-39196. The same February 2023 Gender Harmony application stream updated the Patient gender/sex narrative in core, while the SFCU/SPCU extension definition was renamed and simplified under FHIR-39219 in the extension source. That extension update replaced the long core-style SFCU usage discussion with concise Sex Parameter for Clinical Use wording that explicitly refers implementers to the Gender Harmony Implementation Guide.

Additional context:
The current FHIR core checkout no longer contains the SFCU StructureDefinition source; the active core Patient page links to the extension through the extensions location, and the current Extension Pack source for patient-sexParameterForClinicalUse contains the Gender Harmony referral. Confluence meeting notes for the Gender Harmony/FHIR R5 reconciliation record that Observation focus/subject behavior was considered an Observation concern and that the FHIR section should avoid the same level of detail as the Gender Harmony IG while linking out to that IG. Related Gender Harmony issues such as FHIR-39219 have already been represented on the combined branch.

AutoFHIR reconciliation:
This is an empty audit commit. I made no source change because the current built core source gives only high-level SPCU text and links to the extension, while the authoritative extension definition already performs the requested deferral to the Gender Harmony Implementation Guide. Adding another local restatement to the Patient narrative would duplicate guidance and risk future drift rather than correct a current semantic defect.

Recommendation:
Keep this audit commit as-is. If implementers still need Observation-specific guidance about contextual extensions applying to subject versus focus, that should be handled by the Observation/O&O owners or the Gender Harmony IG rather than by adding SFCU-specific rules to FHIR core.
