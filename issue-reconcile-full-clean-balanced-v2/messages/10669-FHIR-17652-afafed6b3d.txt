FHIR-17652: Audit adaptive Questionnaire guidance

Issue request:
FHIR-17652 was a Published FHIR-core Questionnaire change request, raised for STU3 and resolved Persuasive with Modification. It asked to support a Questionnaire.content-style signal so Questionnaires could be returned without items even when they do have items; the accepted resolution instead called for SDC adaptive-questionnaire guidance, an SDC extension for the adaptive/next-question endpoint, and a trial-use note seeking feedback about identifying adaptive questionnaires and fill-out services.

Initial application:
The issue was applied in SVN revision 14772, mirrored as git commit b8c5990ac5ad735ba1e8e836fd8a4c6fd3534a3e, which added an Adaptive Questionnaires section to source/questionnaire/questionnaire-notes.xml and noted that adaptive questionnaires can be active with no questions or an insufficient question set. A later Questionnaire cleanup commit, cd80b481c37dbfdafa7b73995a63020c7ca94753, moved that guidance near the SDC section and replaced the trial-use feedback block with a pointer to the SDC implementation guide.

Additional context:
Questionnaire is an active current-build resource in source/fhir.ini, and the current source/questionnaire/questionnaire-notes.xml still contains the SDC and Adaptive Questionnaires sections. The authoritative Questionnaire.item definition remains 0..* and says the item list constructs questionnaire content, so a Questionnaire with no items is structurally allowed. The SDC capability requested by the resolution now lives in the SDC IG rather than core: FHIR-24891 added the questionnaireAdaptive extension, and FHIR-41742 later clarified the adaptive search profile, endpoint discovery, and $next-question flow. Current SDC source defines the questionnaireAdaptive extension and adaptive questionnaire/search profiles, including item 0..0 for the adaptive search profile.

AutoFHIR reconciliation:
This is an empty audit commit. No core source change is needed because the current FHIR source already preserves the applied adaptive-questionnaire note in an active Questionnaire page, and the endpoint/profile mechanics are maintained in the external SDC IG where the issue resolution expected them.

Recommendation:
Keep this audit commit as-is. Do not add a Questionnaire.content element or duplicate SDC adaptive mechanics in core; future changes to adaptive Questionnaire endpoint discovery should be handled in the SDC IG unless a new FHIR-core issue explicitly changes base Questionnaire semantics.
