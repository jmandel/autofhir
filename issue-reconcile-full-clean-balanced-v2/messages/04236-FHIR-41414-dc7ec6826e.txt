FHIR-41414: Audit SupplyDelivery move to OO incubator

Issue request:
FHIR-41414 was Applied/Persuasive with Modification for R6. It asked to rename SupplyDelivery.patient to SupplyDelivery.subject with Patient, Group, and Organization targets; retain a patient search parameter that only returns Patient; add a subject search parameter; add Group to SupplyDelivery.receiver; update Patient and Group compartment membership; and add the family/household-only Group comment to subject and receiver.

Initial application:
The issue was applied in core before this reconciliation by 30a4512bff, which changed source/supplydelivery/structuredefinition-SupplyDelivery.xml, source/supplydelivery/bundle-SupplyDelivery-search-params.xml, and source/compartments.xml. The follow-up 53854dc11c added target Patient to SupplyDelivery-patient so the patient search parameter no longer advertised Group or Organization.

Additional context:
A later core commit, 3b38b80cf2, removed SupplyDelivery and neighboring OO resources from active core build configuration and compartment generation, then repointed core narrative pages to the OO incubator IG. In the current checkout, source/fhir.ini has no active supplydelivery resource entry and source/compartments.xml has no SupplyDelivery row; current module pages link to https://build.fhir.org/ig/HL7/oo-incubator/StructureDefinition-SupplyDelivery.html. The external OO incubator artifact has the subject/receiver targets and search parameters, but its subject definition still uses the older person-only wording, so any remaining exact-definition cleanup belongs in HL7/oo-incubator rather than this core checkout.

AutoFHIR reconciliation:
This empty commit records an external-repo decision. No source files were changed because the authoritative current SupplyDelivery artifact is outside the active FHIR core build, and editing inactive source/supplydelivery files in core would not correct the built specification.

Recommendation:
Keep this audit commit as-is for FHIR core. If OO wants the FHIR-41414 resolution reflected exactly in the active SupplyDelivery artifact, update HL7/oo-incubator input/resources/supplydelivery/StructureDefinition-SupplyDelivery.xml so SupplyDelivery.subject says person, group, or organization.
