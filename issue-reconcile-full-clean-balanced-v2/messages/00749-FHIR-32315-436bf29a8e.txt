FHIR-32315: Audit retired ResearchStudy relatesTo extension

Issue request:
FHIR-32315 was a Published/Persuasive with Modification BR&R change request for the R5 ResearchStudy relatesTo extension. The original request asked to bind relatesTo.relationshipType to Artifact Relationship Type, bind targetClassifier to Citation Artifact Classifier, and remove the extension description slice. The final resolution changed direction after FHIR-32973: remove the ResearchStudy relatesTo extension, retain a temporary note for known adopters, and point to the prior version where the extension existed.

Initial application:
Commit 0ee60e33062c6b01a988523af8a6d38f3e7a4d67 removed source/researchstudy/structuredefinition-extension-researchStudy-relatesTo.xml and removed the extension from source/researchstudy/implementationguide-ResearchStudy-core.xml. Commit dcb559de39164b7bc3aace21fe57cbaf57e13cc8 then added the requested temporary ResearchStudy introduction note linking to the May 2021 extension definition. Those commits applied the final Jira direction for R5 rather than preserving the earlier extension-slice value set edits.

Additional context:
The current build includes ResearchStudy as an active resource, but there is no active core or extension-pack definition for StructureDefinition/researchStudy-relatesTo. FHIR-38076 later published a ResearchStudy content-page rewrite that removed the temporary deprecated-extension note. FHIR-49760 later removed ResearchStudy.relatedArtifact for R6 and added the current ResearchStudy.relatesTo backbone; FHIR-50710 subsequently moved ResearchStudy.relatesTo.type to the THO Artifact Relationship Type value set. The FHIR Extension Pack has a generic relatesto-classifier extension for classifiers on relatesTo-like elements, not the retired ResearchStudy-specific extension.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current source no longer contains the retired extension or its description slice, and the active ResearchStudy.relatesTo element carries the current relationship-type binding. Re-adding the old R5-ballot deprecation note would resurrect stale transitional text that was removed by a later published ResearchStudy page update.

Recommendation:
Keep this audit commit as-is. No current core FHIR source change is needed for FHIR-32315; any future desire to host legacy guidance for the retired extension should be handled as a separate human/editorial decision, likely outside the current ResearchStudy core page.
