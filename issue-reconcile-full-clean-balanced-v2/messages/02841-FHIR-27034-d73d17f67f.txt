FHIR-27034 was a Published/Persuasive R5 CDS change request asking to modify the PlanDefinition resource scope/description for the FDA PQ/CMC project so it explicitly supports clinical and non-clinical artifacts, including drug quality specifications.

Initial application:

Git commit 910a2256446d1b85ebcbbe618cbe3a4255ad05c0 applied FHIR-27034 together with the FHIR-27037 through FHIR-27042 PlanDefinition PQ/CMC family by updating the legacy source/plandefinition/plandefinition-spreadsheet.xml root definition from clinical-only examples to clinical and non-clinical artifacts including drug quality specifications. Later source refactors moved the authoritative text into source/plandefinition/structuredefinition-PlanDefinition.xml.

Additional context:
PlanDefinition is active in the current build via source/fhir.ini, assigned to CDS, and marked approved. The current StructureDefinition metadata description and root PlanDefinition element definition both include the FHIR-27034 non-clinical/drug-quality wording. A later Applied/Persuasive issue, FHIR-49838, intentionally expanded the same description to add drug manufacturing process; the combined branch already contains the FHIR-49838 reconciliation that aligned the parallel root definition with that later wording. The same 2020 application commit also covered FHIR-27037 through FHIR-27042, each of which is already represented on the combined branch by its own Issue-Reconcile-Key commit.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active PlanDefinition source already preserves the requested FHIR-27034 scope in both relevant description surfaces, and further editing would be redundant and risk disturbing the later FHIR-49838 wording.

Recommendation:
Keep this audit commit as-is. No FHIR-27034 follow-up is needed in core unless the CDS work group opens a separate editorial request to repeat the non-clinical examples in narrative introduction text beyond the resource scope/description changed by this issue.
