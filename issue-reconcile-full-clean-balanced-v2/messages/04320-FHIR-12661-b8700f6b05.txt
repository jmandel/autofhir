FHIR-12661: Audit Goal target measure binding

Issue request:
FHIR-12661 was a Published/Persuasive Patient Care DSTU2 change request asking to add an example binding for Goal.target.measure to valueset-observation-codes and to flatten Goal.outcome from a BackboneElement into Goal.outcomeCodeableConcept 0..* and Goal.outcomeReference 0..* for consistency with CarePlan.activity.outcome.

Initial application:
The current git history has no literal FHIR-12661 commit, but Jira-era commit 24b4a33a4c explicitly listed #12661 and changed the Goal spreadsheet source. That commit added the GoalTargetMeasure reference to http://hl7.org/fhir/ValueSet/observation-codes and flattened Goal.outcome into separate codeable concept and reference elements. Later source refactors moved the active Goal definition into source/goal/structuredefinition-Goal.xml while preserving the target-measure binding.

Additional context:
Goal is an active current resource in source/fhir.ini. The active Goal StructureDefinition binds Goal.target.measure with example strength to http://hl7.org/fhir/ValueSet/observation-codes, matching the seed request. The old flattened outcome shape should not be reintroduced: related Published issue FHIR-12718 immediately renamed Goal.outcomeCodeableConcept to Goal.outcomeCode, and later Applied issue FHIR-37262 removed Goal.outcome altogether in commit 0d8e3756353. Current source/fhir.ini records that Goal.outcome was deleted and has no R4-to-R6 mapping for Goal.outcomeCode or Goal.outcomeReference. A 2024 Patient Care Zulip discussion also confirms that Goal.target.measure is intended to align with Observation.code and use the same broad value set.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already satisfies the Goal.target.measure binding request, and applying the original outcome flattening now would conflict with later approved Goal.outcome removal.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-12661 unless the Patient Care work group separately revisits the later Goal.outcome removal or decides to change the broad Observation-code example binding for Goal.target.measure.
