FHIR-5211: Audit EpisodeOfCare date search parameter wording

Issue request:
FHIR-5211 was a Published/Persuasive DSTU1 PA ballot issue asking to clarify the EpisodeOfCare date search parameter. The requested change was from the misleading inherited period text, "The interval during which the managing organization assumes the defined responsibility," to wording that says the provided date search value falls within the episode of care's period.

Initial application:
No git commit explicitly tagged FHIR-5211 was found. The 2015 EpisodeOfCare ballot reconciliation commit f659c3fbc1 added the requested date search parameter text to the spreadsheet-era source while leaving the EpisodeOfCare.period element definition intact. The later core source rewrite 33b409a4b6 carried that wording into source/episodeofcare/bundle-EpisodeOfCare-search-params.xml, and fede0a9351 only normalized the apostrophe escaping while preserving the same search parameter description.

Additional context:
EpisodeOfCare is an active build resource in source/fhir.ini, and the current search parameter bundle is the authoritative active source for EpisodeOfCare search parameters. The older "managing organization" wording still appears on EpisodeOfCare.period itself and generated-looking diagram/mapping artifacts, but FHIR-5211 targeted Search Parameters -> Date; related ballot issues FHIR-5201 and FHIR-5208 separately explain the intended organization/period semantics. Confluence and Zulip searches found no directly relevant contradictory community decision.

AutoFHIR reconciliation:
This commit intentionally makes no source change because source/episodeofcare/bundle-EpisodeOfCare-search-params.xml already states, "The provided date search value falls within the episode of care's period" for SearchParameter/EpisodeOfCare-date. Editing EpisodeOfCare.period or SVG/mapping artifacts would exceed the issue scope and could weaken the separate period definition.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-5211 unless a future PA decision changes the EpisodeOfCare.period element definition or the generated search parameter pipeline.
