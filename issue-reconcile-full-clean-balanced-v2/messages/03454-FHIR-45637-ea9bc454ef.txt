FHIR-45637: Audit BDP collection procedure extension scope

Issue request:
FHIR-45637 is an Applied/Persuasive FHIR-core technical correction for the OO work group asking to remove the BiologicallyDerivedProduct collection procedure extension because FHIR-44575 integrated that concept into the main BiologicallyDerivedProduct resource for R6. Later Jira comments narrowed the practical application to updating the Extension Pack artifact for http://hl7.org/fhir/StructureDefinition/biologicallyderivedproduct-collection-procedure with deprecation/version-specific-use metadata and replacement text.

Initial application:
No core source commit directly applied FHIR-45637 because the extension definition is not in the current core source tree. The prerequisite core change was applied by FHIR-44575 in aa978a866b and a458b8db6d, which added BiologicallyDerivedProduct.collection.procedure Reference(Procedure) 0..1. The FHIR-45637 extension work was applied outside this checkout in HL7/fhir-extensions commit 6d703ef73d2883ce5c260a091556d6f045b757ea, followed by Extension Pack QA commits that adjusted the current external file state.

Additional context:
source/fhir.ini actively includes biologicallyderivedproduct as a current resource, and the current core StructureDefinition contains BiologicallyDerivedProduct.collection.procedure. Searching the current core source finds no StructureDefinition for biologicallyderivedproduct-collection-procedure; the only current core source reference is the historical OID registry mapping in source/oids.ini. The Extension Pack checkout is read-only for this worker and currently retains the extension with replacement text and version-specific-use ending at FHIR 5.0, while a later external commit restored standards-status to trial-use rather than the deprecated value requested in the Jira comment. OO HCP minutes for 2024-06-24 confirm the intended disposition: collection procedure is now in the core resource and the extension needed removal/update.

AutoFHIR reconciliation:
This commit intentionally makes no core source change and records an external-repo decision. The current core build already contains the R6 element that replaces the extension, and the only remaining source-of-truth changes for the extension belong to HL7/fhir-extensions, not this FHIR core checkout.

Recommendation:
Keep this audit commit as-is for core reconciliation. If further action is desired, review the Extension Pack current file and the post-6d703ef QA commits to decide whether the restored trial-use status and missing standards-status-reason intentionally supersede the FHIR-45637 Jira comment; any such change should be made in HL7/fhir-extensions, not core.
