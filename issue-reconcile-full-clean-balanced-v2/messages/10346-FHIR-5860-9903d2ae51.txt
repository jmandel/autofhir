FHIR-5860: Audit Bundle entry request rename

Issue request:
FHIR-5860 was a Published FHIR-core Feed change request with a Persuasive with Modification resolution. It asked for Bundle entry components named Transaction and TransactionResponse to be renamed to Interaction and InteractionResponse because each entry represents an individual REST interaction within a transaction. The recorded resolution says the issue was resolved under FHIR-6122.

Initial application:
No git commit was found that explicitly mentions FHIR-5860. The linked FHIR-6122 resolution was applied by git commit 5a81d5df0f, which added batch/batch-response support and renamed Bundle.entry.transaction and Bundle.entry.transactionResponse to Bundle.entry.request and Bundle.entry.response in the Bundle source inputs, examples, and REST narrative. Commit 078364522c then fixed remaining Bundle narrative references to the renamed request/response elements.

Additional context:
FHIR-6122 was also Published/Persuasive with Modification and its approved modification chose the final names request and response, not the Interaction/InteractionResponse names proposed by FHIR-5860. Bundle is active in source/fhir.ini, and the current authoritative Bundle StructureDefinition, Bundle notes, examples, and REST transaction/batch narrative use Bundle.entry.request and Bundle.entry.response. A current source search found no remaining core Bundle element named Bundle.entry.transaction or Bundle.entry.transactionResponse; the only remaining transactionResponse hit is inside a QUICK model-definition Library example, not the authoritative Bundle resource definition being reconciled here. Zulip and Confluence searches found no directly relevant discussion or conflicting later work-group record.

AutoFHIR reconciliation:
This empty audit commit makes no source change because the current built Bundle source already reflects the modified FHIR-6122 resolution that disposed of FHIR-5860. Adding Interaction/InteractionResponse now would contradict the applied broader decision and the current request/response names used throughout transaction and batch processing.

Recommendation:
Keep this audit commit as-is. If the obsolete-looking QUICK model-definition example should be modernized, handle that as a separate Clinical Reasoning/Library review rather than as part of the FHIR-5860 Bundle resource rename.
