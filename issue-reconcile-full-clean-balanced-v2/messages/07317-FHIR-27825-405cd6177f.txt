FHIR-I minutes recorded the item as a technical correction, and the Jira assignee later marked it applied after confirming current build terminology pages showed the logos.

Initial application:
No source commit explicitly mentions FHIR-27825. Git history shows the current CodeSystem and ValueSet page templates were created during the 2020 UTG-content restructuring and include the shared navbar/header path rather than a separate logo-less terminology template.

Current terminology registry and CodeSystem pages use tools/templates/newnavbar.html through the CodeSystem and ValueSet templates, and that navbar references both the FHIR logo and HL7 logo assets. External verification of the current CI build found terminologies-systems.html, terminologies-valuesets.html, and a CodeSystem page all returning HTML with those logo image references; the referenced logo assets return 200, while the original v3/orderableDrugForm/cs.html URL returns 404. Confluence has one relevant FHIR-I minutes page approving FHIR-27825 as a technical correction; Zulip searches found no directly relevant conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring or editing the obsolete v3/orderableDrugForm page would not be a current FHIR build correction.

Recommendation:
Keep this no-change audit commit. Revisit only if a future current terminology page renders without the shared navbar logos or if a separate THO/UTG publication issue is filed for terminology.hl7.org content outside this core checkout.
