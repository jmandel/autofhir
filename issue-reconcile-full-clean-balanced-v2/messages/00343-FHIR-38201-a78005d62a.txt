FHIR-38201: Audit Composition versionNumber removal

Issue request:
FHIR-38201 was an Applied FHIR-core / Structured Documents change request with resolution Persuasive. It asked to remove the Composition versionNumber extension because Composition already has a version element; its resolution explicitly said to fix it along with FHIR-34407.

Initial application:
The core source work had already happened. Commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed source/composition/structuredefinition-extension-composition-clinicaldocument-versionNumber.xml and its core ImplementationGuide reference. Commit 3a5b06b66d70b43948f87f2cd0d141e83f17268c removed the remaining versionNumber slice/reference from the ClinicalDocument profile before commit 938bdf21940e09a728baa17dc0060c413a0054c7 deleted the profile itself.

Additional context:
FHIR-34407 is the same change family and provided the approved profile-removal decision. SDWG minutes from September 2022 record the 6-0-0 motion to delete the versionNumber extension and ClinicalDocument profile. The extension was later handled in the FHIR Extension Pack: a removal was attempted, reverted after use concerns, and then the artifact was limited/deprecated for pre-R5 use because Composition.version exists in R5 and later. Current core source has no active versionNumber extension definition or profile reference; only historical/OID registry references remain.

AutoFHIR reconciliation:
This commit intentionally makes no source change. For FHIR core, the extension is already absent from the active current build and Composition.version is the replacement. The separate extension-pack artifact is outside this core checkout and is already marked for pre-R5 use, so deleting core OID registry entries or CDA mapping prose would be broader than the Jira decision.

Recommendation:
Keep this audit commit as-is. No core follow-up is needed for FHIR-38201; any future decision to remove or further revise the legacy extension-pack artifact should be made in the FHIR Extension Pack repository with SDWG review.
