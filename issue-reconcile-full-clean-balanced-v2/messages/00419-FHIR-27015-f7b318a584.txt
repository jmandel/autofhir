FHIR-27015: Audit Immunization basedOn

Issue request:
FHIR-27015 was a Published/Persuasive with Modification FHIR-core Immunization change request for R5. It asked to add Immunization.basedOn as a 0..* Reference element to link an immunization event to the plan, order, or recommendation it fulfilled, with the approved 2020 target set CarePlan, MedicationRequest, and ImmunizationRecommendation, and with ServiceRequest intentionally out of scope at that time.

Initial application:
The issue was initially applied by git commit 9d03b8ce9189242d136e22cf5fc4f777742b4a52, which added Immunization.basedOn to the Immunization spreadsheet with the approved definition and original targets. The later source refactor commit 33b409a4b6d1e678255ec1b23963da363d7f8ed8 carried the Jira note, cardinality, definition, workflow mapping, and original target profiles into source/immunization/structuredefinition-Immunization.xml.

Additional context:
The current build lists immunization as an active resource in source/fhir.ini, and the active StructureDefinition still defines Immunization.basedOn as 0..* with the same short, definition, comment, and Event.basedOn mapping. The target list now differs from the original ballot resolution because FHIR-36061 later published a same-element change adding ServiceRequest, supported by a Zulip discussion about referrals or wellness-visit ServiceRequests authorizing vaccinations, and commit 49ef07f437aabd36aa48b6ac67530f14bcdaa885 implemented that addition. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 later removed ImmunizationRecommendation from this element while removing ImmunizationRecommendation and ImmunizationEvaluation from the current core build; the remaining authoritative source is CarePlan, MedicationRequest, and ServiceRequest. A checked-in SVG still mentions ImmunizationRecommendation, but it is a generated-looking diagram artifact and is not an authoritative source hunk to edit for this FHIR-27015 audit.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current active Immunization source contains the FHIR-27015 element and preserves its purpose, while later same-element and build-scope changes explain why the target list is no longer the exact 2020 list.

Recommendation:
Keep this no-change audit as-is for FHIR-27015. Do not revert ServiceRequest or re-add ImmunizationRecommendation as part of this seed; any cleanup of stale generated diagrams or broader post-removal references to ImmunizationRecommendation should be handled under the later removal work, not this original basedOn-addition issue.
