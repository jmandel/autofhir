FHIR-25774: Audit EvidenceVariable R5 revisions

Issue request:
FHIR-25774 was a Published/Persuasive CDS change request for R5 to simplify EvidenceVariable after Connectathon 23. It asked to update the resource description, definition, comments, Scope and Usage, and Boundaries and Relationships; add characteristicCombination and timeFromStart child elements; remove definitionDataRequirement, definitionTriggerDefinition, booleanSet, and participantEffective from the characteristic model; and replace the EvidenceVariable, Evidence, and ActivityDefinition examples.

Initial application:
The issue was applied by git commit 5595d874e8f73f92aec2bdb2739daddfae534a56, whose subject is "Changes described in FHIR-25774". That commit changed the EvidenceVariable spreadsheet and introduction, removed the old EvidenceVariable profile spreadsheet, added the requested EvidenceVariable examples, updated Evidence examples, and added the Alteplase ActivityDefinition example. The current source still carries the seed's top-level EvidenceVariable short, definition, and comment wording.

Additional context:
The current build is no longer the original R5 model. Later final EvidenceVariable decisions changed the R5 additions: FHIR-32647 revised characteristicCombination, FHIR-32984 added timeFromEvent, and FHIR-42886 explicitly replaced EvidenceVariable.characteristic with EvidenceVariable.definition for R6 because Group became the preferred resource for characteristic combinations. Current source/fhir.ini records the old R4-R6 and R5-R6 EvidenceVariable characteristic elements as version changes rather than active elements, and the active resource now uses EvidenceVariable.definition plus timing/period/dataStorage/constraint structures. The current example lists contain the EvidenceVariable, Evidence, and ActivityDefinition examples that satisfy and exceed the seed's example intent.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Re-introducing characteristicCombination, timeFromStart, participantEffective, or the old characteristic.definition[x] choices would contradict the later applied R6 EvidenceVariable model. The current source is build-scoped, already preserves the still-relevant wording from FHIR-25774, and reflects later final decisions for the portions that were superseded.

Recommendation:
Keep this audit commit as-is. No FHIR core source fix is needed for FHIR-25774; future EvidenceVariable work should be evaluated against the current definition-based R6 model, not by restoring the older R5 characteristic structure.
