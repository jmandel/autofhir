FHIR-35933: Audit external terminology page migration

Issue request:
FHIR-35933 was a Published/Persuasive R5 Vocabulary WG change request to remove the old FHIR-core "Using X with FHIR" external code-system pages from the FHIR CI build, add a Defined Externally note that authoritative external terminology guidance lives in HL7 Terminology (THO), and update external code-system usage links to THO permalinks.

Initial application:
The issue was directly applied by the FHIR-35933 branch merged as HL7/fhir#2091 in commit 4a3611b38f. That merge removed the old external-code-system pages from publish.ini and source, and commit 81e5862f20 updated source/terminologies-systems.html so the Defined Externally table links to terminology.hl7.org "Using ... with HL7 Standards" pages rather than local "Using ... with FHIR" pages. Commit 41ece7b8bd fixed two remaining LOINC references in Questionnaire source.

Additional context:
UP-289 implemented the matching THO-side migration and is not a FHIR-core source decision. FHIR-37853, already represented on the combined branch by commit cc0fb19298, later refined the same build-scoped source/terminologies-systems.html page by making THO authoritative for external terminology information and pruning rows without THO usage pages. Commit 6bbb8cc01d later corrected the THO page URL from external_terminologies.html to external_code_systems.html. The current source keeps snomedct-usage.html as a FHIR-specific SNOMED CT usage summary, not as one of the removed external code-system authority pages.

AutoFHIR reconciliation:
No source change was made. The current build-scoped source/terminologies-systems.html page is listed in publish.ini and linked from the terminology documentation page; it contains the THO authority notice, uses THO permalinks for the external usage pages, and the old local external-code-system pages are absent from both source and publish.ini.

Recommendation:
Keep this empty audit commit as-is. No FHIR-core follow-up is needed for FHIR-35933; future content changes for the migrated external terminology pages should be handled in THO/UTG or by later FHIR-core trackers such as the already-audited FHIR-37853.
