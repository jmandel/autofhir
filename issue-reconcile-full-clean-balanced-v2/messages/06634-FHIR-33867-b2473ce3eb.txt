FHIR-33867: Audit TestScript operation codes relocation

Issue request:
FHIR-33867 was a Published/Persuasive FHIR-I change request for R5 asking to replace the single generic TestScript operation code 'history' with scope-specific history-instance, history-type, and history-system codes. The final Jira discussion narrowed that to having the TestScript operation value set include the existing FHIR base REST interaction code system rather than maintaining a parallel TestScript operation code system.

Initial application:
The issue was applied in commit 4672c1704c576182f143374939db33cbbcf73e74 and merged by PR #1505. That commit updated source/testscript/valueset-testscript-operation-codes.xml and TestScript examples so the value set included http://hl7.org/fhir/restful-interaction, whose history concept carries the scoped child concepts.

Additional context:
UP-250, the UTG follow-up created from FHIR-33867, was withdrawn because the group concluded the TestScript-specific operation code system should not be maintained in UTG and that the FHIR issue's resolution no longer used it. UP-266 records an unresolved UTG cleanup proposal to deprecate/delete the old THO code system. Current core source has since removed TestScript, TestReport, and TestPlan from source/fhir.ini and source/testscript/ in commit f9a44787c45071394532c7c2ee94d76f30f47387, while adding the FHIR Testing IG to the additional IG list.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The current core checkout no longer owns the TestScript resource or the testscript-operation-codes value set; the active FHIR Testing IG publishes ValueSet/testscript-operation-codes as a composition that includes http://hl7.org/fhir/restful-interaction, and the current core restful-interaction CodeSystem contains history-instance, history-type, and history-system under the abstract history concept. The only remaining core hit for the old TestScript value set is a generated-looking ExampleScenario SVG link, while the authoritative ExampleScenario XML binds to ValueSet/examplescenario-operation-codes, so it is not an appropriate source fix for this TestScript issue.

Recommendation:
Keep this audit commit as-is for core FHIR. Any future work on the TestScript value set should be done in HL7/fhir-testing-ig, and any THO cleanup for the abandoned TestScript-specific operation code system should follow the unresolved UP-266 process rather than this core reconciliation.
