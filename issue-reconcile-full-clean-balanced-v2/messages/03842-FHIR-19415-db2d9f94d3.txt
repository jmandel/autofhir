FHIR-19415: Audit MDC terminology documentation

Issue request:
FHIR-19415 was a Published/Persuasive FHIR-core vocabulary change request for the terminologies systems page. It asked to update the MDC documentation according to a Dev WG-prepared document, and the final Jira resolution was to agree with the changes as pre-applied.

Initial application:
The pre-application is visible in commits 528e0c6b742b6d6c78b2e61505a59c1ed45fc312 and bd59d15fa3a50e42d30cc0aa8b6066d2dc5ec6c1. Those commits changed the MDC row on source/terminologies-systems.html from a short RTMMS/code-display note to a Medical Device Codes row linked to source/mdc.html, and then refined the MDC display guidance on source/mdc.html.

Additional context:
Later published FHIR-core terminology decisions changed where this information belongs. FHIR-35933 removed the external "Using X with FHIR" pages from core and moved their authoritative content to HL7 Terminology (THO), while FHIR-37853 established THO as the source of truth for external terminology information on the code-systems page. The current core source has no source/mdc.html, keeps the active terminologies-systems.html MDC row, and links to https://terminology.hl7.org/MDC.html for the detailed "Using MDC with HL7 Standards" guidance. FHIR-46008 is already represented on the combined branch and updated the same row's ISO/IEEE 11073-10101 link to the ISO standards page. HTA-101 and HTA-105 discuss further MDC/THO questions but are not final FHIR-core decisions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The original FHIR-19415 content was applied, and the current build-scope core page correctly delegates detailed MDC usage documentation to THO rather than reintroducing an obsolete core source page.

Recommendation:
Keep this audit commit as-is. Future detailed MDC content updates should be handled through THO/UTG/HTA unless a final FHIR-core tracker specifically changes the core terminology systems row.
