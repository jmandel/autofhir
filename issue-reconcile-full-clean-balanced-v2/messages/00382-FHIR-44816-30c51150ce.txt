FHIR-44816: Audit moved Encounter $everything updates

Issue request:
FHIR-44816 was Applied/Persuasive by Patient Administration to review the Encounter and EpisodeOfCare $everything operations after the Patient $everything changes from FHIR-43373 and FHIR-44604, specifically removing US Core requirements, single-bundle/paging assumptions, and stale ordering guidance while keeping the correct compartment references.

Initial application:
FHIR-43373 and FHIR-44604 were first applied to Patient/$everything in commit 8085536f12e251d00b80ac47323658eb94e9b1ac. FHIR-44816 was then applied in commit e8524f5b6b54904776987148319de565a582b52d, which updated Encounter/$everything and EpisodeOfCare/$everything to the same paging and ordering semantics and removed the US Realm minimum-data requirement from Encounter. There was no existing Issue-Reconcile-Key commit for FHIR-44816 on the combined branch.

Additional context:
The current core source no longer owns these PA $everything OperationDefinition resources. In November 2025 the PA operation definitions for Patient/$everything, Encounter/$everything, EpisodeOfCare/$everything, and Patient/$merge were moved to the HL7 Administrative Incubator IG; core commit b487fdda4bb4a5382a93dbb5a811efd02425b9bc removed the three $everything OperationDefinition XML files and removed them from the Patient, Encounter, and EpisodeOfCare operation lists. Current core narrative links to the Admin Incubator build, and the Admin Incubator package/source contains the FHIR-44816 wording for Encounter and EpisodeOfCare. FHIR-52121 is a later Triaged discussion about future $everything paging behavior, not an Applied/Published reversal of FHIR-44816.

AutoFHIR reconciliation:
This commit intentionally makes no source change in core. The relevant authoritative operation definitions are outside this checkout/current core build scope, and the remaining current core references point to the external Admin Incubator pages rather than to local OperationDefinition sources.

Recommendation:
Keep this audit commit as-is for core. If additional $everything wording changes are needed, make them in HL7/admin-incubator unless Patient Administration and FHIR-I move these operations back into the core specification.
