FHIR-6094: Audit Condition subject search parameter rename

Issue request:
FHIR-6094 is a Published/Persuasive Patient Care change request asking to rename Condition's subject search parameter to patient because the Condition resource still had a subject search parameter; Jira records vote Russell/Laura 6-0-0 and svn revision 5891.

Initial application:
The request was applied directly in git commit 584064415b304f98fd1074e03db8e78fba0dba2b, '#6094 - remove subject search parameter on Condition', which left only the patient search parameter while the resource element was then Condition.patient.

Additional context:
A later 2016 Condition workflow/source change, e35d3b3f92f11757466373e8b8f9f829d96d5cc9, changed the resource model back from Condition.patient to Condition.subject, broadened the subject element to Reference(Patient|Group), and restored a subject search parameter while keeping the patient search parameter. The current active source preserves that split: Condition-patient is constrained to Patient and Condition-subject covers the full subject reference. FHIR-31714 later supports Patient-only targets for target-constrained patient search parameters, and an implementer Zulip thread explains the same patient-vs-subject distinction.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The exact 2015 change was historically applied, but the current specification has a later, broader subject model; deleting Condition-subject now would remove valid Group-subject search behavior.

Recommendation:
Keep this audit commit as-is. Treat FHIR-6094 as historically applied and superseded by later Condition.subject/Patient|Group modeling; require a new current tracker before changing the present subject search parameter.
