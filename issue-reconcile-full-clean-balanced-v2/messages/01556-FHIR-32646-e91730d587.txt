FHIR-32646: Audit EvidenceVariable characteristic type

Issue request:
FHIR-32646 was a Published, Persuasive with Modification R5 request to add EvidenceVariable.characteristic.type as a 0..1 CodeableConcept with an example binding to usage-context-type so a specific characteristic such as dexamethasone could also be classified as a type of intervention.

Initial application:
The Jira comment identifies commit bac01125124ef5d906e86c9f6d75340772380ce2 as the initial application. That commit added EvidenceVariable.characteristic.type with CodeableConcept type and a usage-context-type example binding in source/evidencevariable/structuredefinition-EvidenceVariable.xml. Later R5 issue FHIR-36635, implemented by commit 8019b7c9a69cae8d916756f78130981b23493354, refactored the same type/value capability into EvidenceVariable.characteristic.definitionByTypeAndValue.type[x] while preserving the purpose of expressing the type of characteristic.

Additional context:
EvidenceVariable is active in the current build through source/fhir.ini. The current source no longer contains EvidenceVariable.characteristic because FHIR-42886 was an Applied R6 decision to replace EvidenceVariable.characteristic with EvidenceVariable.definition and use Group as the preferred resource for characteristic definitions. Commit b6ffbe50c67dfcc7f9ceac3463e582537ad2d85c applied that replacement by removing the characteristic backbone, including the later definitionByTypeAndValue.type element.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Reintroducing EvidenceVariable.characteristic.type would conflict with the later Applied R6 model; the current source is already correct when FHIR-32646 is read together with the subsequent EvidenceVariable refactors.

Recommendation:
Keep this audit commit as-is. Future changes for classifying current EvidenceVariable definitions should be raised against the current EvidenceVariable.definition, EvidenceVariable.definitionModifier, or referenced Group model rather than reopening the removed R5 characteristic.type element.
