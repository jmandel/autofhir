FHIR-13518: Audit Organization active search parameter

Issue request:
FHIR-13518 was a Published/Persuasive STU3 Patient Administration change request reporting that the Organization active search parameter incorrectly used the generic Address search description. The approved correction was to give Organization.active an active-flag description and put the generic Address string-field description on Organization.address.

Initial application:
No current git commit explicitly mentions FHIR-13518. The archived STU3 search-parameters bundle still shows the reported wrong active description, but the current build-scoped Organization search-parameter source introduced by the 2021 source refactor already has Organization-active described as "Is the Organization record active" and Organization-address described with the generic Address string-field text.

Additional context:
Organization is an active resource in source/fhir.ini, so source/organization/bundle-Organization-search-params.xml is in current build scope. A later Organization model change (FHIR-29034) moved the address search expressions from Organization.address to Organization.contact.address while preserving the correct Address search description. The current active wording differs from the exact STU3 proposal but preserves the intended boolean/token search meaning and is consistent with neighboring active search parameter descriptions.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scoped source no longer contains the swapped Address description on Organization.active, and replacing the current clear active wording with the exact historical proposal would not change implementer understanding.

Recommendation:
Keep this audit commit as-is. No core source follow-up is needed for FHIR-13518 unless PA wants a separate global editorial standardization of active search-parameter descriptions.
