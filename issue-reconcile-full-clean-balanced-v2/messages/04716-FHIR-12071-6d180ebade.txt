FHIR-12071: Audit QuestionnaireResponse nesting guidance

Issue request:
FHIR-12071 was Published with a Persuasive resolution for DSTU2 QuestionnaireAnswers. It asked the specification to explain when QuestionnaireResponse nesting should use item.item versus item.answer[x].item, using the rationale that groups cannot have answers and question children must nest beneath each answer when a question can have multiple answers.

Initial application:
The issue was applied in git 014f454e13, which added the requested comment and GF#12071 committee note to the QuestionnaireResponse spreadsheet source. The active source was later migrated to source/questionnaireresponse/structuredefinition-QuestionnaireResponse.xml, where the GF#12071 note and nesting guidance remain on QuestionnaireResponse.item.

Additional context:
QuestionnaireResponse is an active current-build resource in source/fhir.ini. Related final issues confirm the model rather than superseding it: FHIR-10481 rejected removing item.answer.item, FHIR-20768 added element-level comments for item.item and item.answer.item, FHIR-31357 added a narrative Nested Items section, and FHIR-38853 later refined the same group-nesting sentence and diagram link in a separate AutoFHIR source commit in this run.

AutoFHIR reconciliation:
No seed source change is needed. The active StructureDefinition and narrative already convey the requested distinction: group children use item.item, child items beneath questions use item.answer.item under each answer, and repeated group versus repeated question behavior is described.

Recommendation:
Keep this audit commit as-is. Future work should address only separate later tracker issues or editorial cleanup, not FHIR-12071 itself.
