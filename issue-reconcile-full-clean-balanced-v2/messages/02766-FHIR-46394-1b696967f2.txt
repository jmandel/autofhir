FHIR-46394: Audit GenomicStudy supportingInfo reference

Issue request:
FHIR-46394 was an Applied O&O change request, resolved Persuasive with Modification for R6, asking to expand DiagnosticReport.supportingInfo.reference. Its final resolution added GenomicStudy as a valid supportingInfo target because DiagnosticReport.study then also pointed to GenomicStudy.

Initial application:
The issue was applied before this reconciliation. OO minutes on 2024-07-16 record the persuasive-with-modification decision to add GenomicStudy, and commit fcbce86c2ab97e6388a24d1da0d7018dc5764de8 added the GenomicStudy targetProfile to source/diagnosticreport/structuredefinition-DiagnosticReport.xml.

Additional context:
Later R6 work moved GenomicStudy out of the active core resource set. Current source/fhir.ini has an active DiagnosticReport entry but no active genomicstudy entry; FHIR-48645 says the resources were moved out of core; and OO WGM minutes for FHIR-54164 say to remove references and text to GenomicStudy because it is now in the incubator Additional Resources IG. Commit fad1b9cf84ef652e88947e1a13b026c62f95334e removed GenomicStudy from source/fhir.ini and from DiagnosticReport.study and DiagnosticReport.supportingInfo.reference. The current supportingInfo.reference target list therefore intentionally excludes GenomicStudy.

AutoFHIR reconciliation:
This is an empty no-change audit commit. Re-adding GenomicStudy to the core DiagnosticReport reference list would reintroduce a targetProfile for a resource that is no longer active in the current core build.

Recommendation:
Keep this audit as-is. Do not re-add GenomicStudy to core DiagnosticReport unless the work group reopens the R6 additional-resources policy or establishes an explicit core-to-incubator reference mechanism.
