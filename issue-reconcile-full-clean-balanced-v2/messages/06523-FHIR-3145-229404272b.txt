FHIR-3145: Audit Questionnaire cardinality extensions

Issue request:
FHIR-3145 was a Published/Persuasive FHIR-core Questionnaire change request asking that, when a question allows multiple answers, standard extensions make it possible to constrain the number of allowed answers. The PC approval comment records the intended application as standard extensions.

Initial application:
No current git commit explicitly naming FHIR-3145 or {#3145} was found. Historical core source did contain source/questionnaire/structuredefinition-extension-questionnaire-minOccurs.xml and source/questionnaire/structuredefinition-extension-questionnaire-maxOccurs.xml, whose definitions expressed the requested minimum and maximum answer/repetition counts. Those core extension definition files were later removed from active R5 source by the broad extension move commit dd468d4f17.

Additional context:
The current core build keeps Questionnaire active, but source/fhir.ini has no active profile entry for questionnaire-minOccurs or questionnaire-maxOccurs. The active extension definitions now live in the FHIR Extension Pack at input/definitions/multiple/StructureDefinition-questionnaire-minOccurs.xml and input/definitions/multiple/StructureDefinition-questionnaire-maxOccurs.xml. Later Extension Pack issues, including FHIR-48948 and FHIR-43033, continue to maintain those same definitions, confirming that the current source of truth is outside this core checkout. FHIR-15916 is a related historical typo correction for maxOccurs, and the current Extension Pack text already uses the corrected maximum-answer wording.

AutoFHIR reconciliation:
This commit intentionally makes no core source change. The requested standard extensions already exist in the Extension Pack, and editing core to reintroduce duplicate extension definitions would be outside the current build scope and would conflict with the extension-pack split.

Recommendation:
Keep this audit commit as-is for core reconciliation. Future substantive changes to questionnaire-minOccurs or questionnaire-maxOccurs should be made in the FHIR Extension Pack rather than by re-adding core source definitions.
