FHIR-25124: Point boolean special-values links to CodeSystem

Issue request:
FHIR-25124 was a Published FHIR-I change request, resolved Persuasive with Modification for R5, asking that the boolean token-search special-values URL/link be corrected from the obsolete http://hl7.org/fhir/special-values reference.

Initial application:
Commit 7b2d96b1ef0a applied FHIR-25124 by changing the boolean token row, explanatory note, and summary-table text in source/search.html to use http://terminology.hl7.org/CodeSystem/special-values. A later link-fix commit d382fc3af52 changed the local Special Values hrefs to the external THO ValueSet page, leaving the CodeSystem URI and code-system prose pointing at a ValueSet page.

Additional context:
The search page source is in current build scope: source/fhir.ini maps boolean to token in [search-rules] and explicitly notes that search.html carries the summary table. Current THO publishes both a CodeSystem-special-values page with canonical http://terminology.hl7.org/CodeSystem/special-values and a ValueSet-special-values page whose canonical is http://terminology.hl7.org/ValueSet/special-values. Since a token search system is a code system identifier, the existing CodeSystem URI text is the correct semantic target. FHIR-I minutes from 2020-04-06 record the vote to fix FHIR-25124, and no conflicting Jira, Zulip, or Confluence evidence was found.

AutoFHIR reconciliation:
Updated the two boolean-token Special Values hyperlinks in source/search.html from https://terminology.hl7.org/ValueSet-special-values.html to https://terminology.hl7.org/CodeSystem-special-values.html, aligning the link targets with the displayed CodeSystem URI and the surrounding code-system prose. The code system URI text and token summary behavior were left unchanged.

Recommendation:
Keep this source fix. It completes the applied Jira correction for the current source without changing token-search semantics; no broader search or terminology follow-up is indicated.
