FHIR-33989: Fix Apgar heart-rate text values

Issue request:
FHIR-33989 is an Applied/Persuasive OO change request for R6 asking that the heart-rate components in the 1, 2, 5, 10, and 20 minute Apgar Observation examples use <text value="Apgar heart rate"/> instead of the copied respiratory-effort text. A later Jira comment explicitly noted that the applied spec still said <text value="Apgar heart rate score"/> while the ticket asked for <text value="Apgar heart rate"/>.

Initial application:
The issue was initially applied in commit 9ea52dcd42, which changed both the heart-rate component text and the respiratory-effort component text in the five examples to "Apgar heart rate". PR review then identified that only the SNOMED 249223000 heart-rate component should change; commit 1a7badc6f4 restored the respiratory-effort component text, and commit f58d84a112 changed the remaining heart-rate text to "Apgar heart rate score" before PR 3548 merged. A later branch-only commit d3e24e5d14 removed the extra word "score", but it was not merged into the current branch.

Additional context:
Observation is an active resource in source/fhir.ini, and source/observation/list-Observation-examples.xml plus observation-examples-header.xml list the five named Apgar examples, so the edited XML examples are in build scope. The SNOMED coding display remains "Apgar heart rate score" for code 249223000; this reconciliation only changes CodeableConcept.text to the Jira-requested display text and leaves the respiratory-effort components unchanged. OO minutes record the 5-0-0 vote to make changes per the description, and no directly relevant Zulip or conflicting Confluence hits were found.

AutoFHIR reconciliation:
Changed the heart-rate component <text> value in the 1, 2, 5, 10, and 20 minute Apgar Observation example XML files from "Apgar heart rate score" to "Apgar heart rate". No other coded displays, values, or respiratory-effort component text values were changed.

Recommendation:
Keep this source fix as-is. It completes the applied Jira wording and matches the unmerged follow-up correction while avoiding the earlier overbroad respiratory-effort change.
