FHIR-7802: Audit binding-strength tooling warning

Issue request:
FHIR-7802 is a Published/Persuasive FHIR-core issue from DSTU1 asking the tooling to catch profiles that weaken a base required terminology binding to extensible, preferred, or example; the Jira example was invalid DAF profile snapshots overriding required bindings.

Initial application:
The Jira application comment says "svn revision 5953 - start generating warnings." Git history contains that SVN import as commit 89942b0b07df756077361ad35a65da4870e169d7, "#7802- detect illegal binding in profiles," which wired validation messages through the old Java publisher/ProfileUtilities path and warned on illegal required-binding changes.

Additional context:
The current profiling source still includes the binding-strength derivation table: required bindings can only remain required in a derived profile, and constraining profiles cannot make codes valid that are invalid in the base profile. The current Gradle build depends on the external kindling publisher artifact and the historical tools/java sources changed by r5953 are no longer present in this checkout, so there is no current in-repository tooling source hunk to restore. Later community discussion and Vocabulary/FHIR-I minutes continue to describe the same rule: derived bindings must be the same strength or narrower and cannot relax required bindings.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The normative profiling guidance is present in current source, the historical tooling change is already in repository history, and editing current core source would either duplicate existing prose or target obsolete/absent tooling files rather than the current publisher implementation.

Recommendation:
Keep this empty audit commit as-is for FHIR-7802. If future validation shows the current external kindling/validator publisher no longer enforces this rule, track that as a tooling issue in the publisher/validator codebase; no core spec source change is indicated by this reconciliation.
