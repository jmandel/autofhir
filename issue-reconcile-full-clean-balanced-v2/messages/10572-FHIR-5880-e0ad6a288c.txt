FHIR-5880: Audit external profile registry discovery

Issue request:
FHIR-5880 was a Published/Persuasive DSTU1 FHIR-core change request asking that the wiki page for profiles developed by organizations outside HL7 be discoverable from the FHIR specification homepage. The Jira resolution records the 2015-03-26 MnM block vote and a later application note for SVN revision 5053.

Initial application:
The request was applied by git-svn commit 5e96122d85e43d56da1bed66eb82f4e71411f03, which changed source/index.html to add an "Implementation guide registry" link to http://wiki.hl7.org/index.php?title=FHIR_Profiles_from_other_Organizations. Later source history replaced the wiki link with the Confluence successor in dbd08df53eb122db3a7accbc4ac47e87ad999c36 and then replaced that homepage entry with current registry links in bc0c3d8207aaec46b99155b3946a776e4d3c545c and 4118eb9ddb6eabe52c56c903b3932f27c2c42e38.

Additional context:
The current active homepage source still has an Implementation Guides section with a curated IG list, registry.fhir.org for publicly available FHIR specification artifacts, and the packages2.fhir.org XIG index. The current profiles list page also points additional profiles and extensions to registry.fhir.org. The Confluence successor page "IGs from other Organizations" now only points readers to the Implementation Guide Registry, and Zulip discussion records that IHE content had moved into fhir.org/guides/registry and that the old wiki/spec-homepage link could be removed or replaced. FHIR-16526 later handled the broader homepage/navigation and IG-registry cleanup, including moving IGs from the Confluence page to the registry.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Restoring the obsolete wiki or Confluence page link would make the current specification less accurate; the current homepage already makes externally published profiles and implementation guides discoverable through the maintained registry surfaces.

Recommendation:
Keep this no-change audit commit. Future changes to the external IG list should be made in the IG registry/package registry infrastructure rather than by reintroducing a core-spec homepage link to the retired wiki or Confluence list.
