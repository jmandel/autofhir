FHIR-17753: Audit Goal target detail datatypes

Issue request:
FHIR-17753 was a Published, Persuasive with Modification Patient Care change request to align Goal.target.detail data types with Observation.value data types by additionally supporting string, boolean, integer, and Ratio. The Jira discussion explicitly scoped out Observation.value types such as SampledData, time, dateTime, and Period until concrete Goal use cases were confirmed.

Initial application:
The Jira comment cites GitHub commit ef05a01a0bea. That commit, merged by PR #85, changed the then-authoritative source/goal/goal-spreadsheet.xml row for Goal.target.detail[x] from Quantity | Range | CodeableConcept to Quantity | Range | CodeableConcept | string | boolean | integer | Ratio. Later source refactoring preserved those datatypes in source/goal/structuredefinition-Goal.xml.

Additional context:
Goal is in the current build scope through the active source/fhir.ini [resources] entry goal=Goal. The current Goal StructureDefinition lists Quantity, Range, CodeableConcept, string, boolean, integer, and Ratio for Goal.target.detail[x]. Observation.value[x] still has the broader Observation list, but FHIR-17753's recorded resolution and meeting comment only approved the four added types. Later related decisions FHIR-22732 and FHIR-46293 intentionally keep Goal.target.detail unbound like Observation.value and remove an orphaned binding; they do not change the datatype list. Direct Zulip and Confluence searches for FHIR-17753 found no conflicting community record.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current source already implements the requested datatype alignment at the approved scope, and adding further Observation.value datatypes or metadata-only source churn would go beyond the Jira resolution.

Recommendation:
Keep this no-change audit commit. No follow-up is needed for FHIR-17753 unless Patient Care opens a new issue to expand Goal.target.detail[x] beyond the four approved datatypes or to address separate binding/methodology questions.
