FHIR-17413: Audit AuditEvent source observer Reference

Issue request:
FHIR-17413 was Published/Persuasive for STU3. It requested changing AuditEvent.source.identifier to AuditEvent.source.observer as a Reference, rather than leaving the AuditEvent source as only an Identifier.

Initial application:
The issue was applied in git commit 6c0a0563b3ac6a188b713f2f1a04ff26229100cf, whose message explicitly listed GF#17413 and changed the AuditEvent spreadsheet from AuditEvent.source.identifier with type Identifier to AuditEvent.source.observer with type Reference(...). The same commit updated the AuditEvent source search parameter from a token expression on AuditEvent.source.identifier to a reference expression on AuditEvent.source.observer and renamed the examples to use observer.

Additional context:
AuditEvent is an active resource in source/fhir.ini, and the current generated-source form is source/auditevent/structuredefinition-AuditEvent.xml. Later AuditEvent decisions refined the surrounding source wording: FHIR-32464 changed source.site to Reference(Location), and FHIR-32465 changed source/observer prose from system/identifier language to actor language. A 2023 Security and Privacy Zulip thread confirmed that source.observer remains a Reference and can use Reference.identifier for logical references, so examples that carry an identifier-like value are not a reversal of FHIR-17413.

AutoFHIR reconciliation:
No source change was made. The current build source has AuditEvent.source.observer as a required Reference with participant-style target profiles, the AuditEvent source search parameter is type reference over AuditEvent.source.observer, and no active AuditEvent source definition still exposes AuditEvent.source.identifier.

Recommendation:
Keep this empty audit commit as-is. The current core FHIR source already implements FHIR-17413; no follow-up is needed for this issue unless the work group later chooses to change the target-profile set or Reference.identifier examples under a separate tracker.
