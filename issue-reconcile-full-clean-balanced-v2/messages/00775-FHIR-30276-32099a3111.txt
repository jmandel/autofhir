FHIR-30276: Audit patientPaid core application

Issue request:
FHIR-30276 is a Published/Persuasive with Modification FM change request for R5. It requested patientPaid 0..1 Money in Claim and ExplanationOfBenefit at the header, item, detail, and subDetail levels, also at ExplanationOfBenefit addItem levels, plus patient-paid and patient-responsibility adjudication category codes for adjudications used in ClaimResponse and ExplanationOfBenefit.

Initial application:
No current-history commit explicitly mentions FHIR-30276. The 2022-08-07 commit 75e9d09e288b16ae6531e19fbaffff9380ebf942 added patientPaid to the active Claim and ExplanationOfBenefit StructureDefinition sources and added related Financial Management narrative. The current source has Claim.patientPaid, Claim.item.patientPaid, Claim.item.detail.patientPaid, Claim.item.detail.subDetail.patientPaid, and the matching ExplanationOfBenefit patientPaid elements including addItem, addItem.detail, and addItem.detail.subDetail.

Additional context:
Claim and ExplanationOfBenefit are active resources in source/fhir.ini, and ClaimResponse is active too. The closely related Published issue FHIR-37869, already represented on the combined branch by a6dba58a1004fac33b30131e8626b4766ca26844, added patientPaid to ClaimResponse addItem levels. The remaining adjudication-code request is not defined in an editable core CodeSystem source: source/claimresponse/valueset-adjudication.xml imports all codes from http://terminology.hl7.org/CodeSystem/adjudication. Current local THO/FHIR package evidence and terminology.hl7.org show that CodeSystem/adjudication still contains only submitted, copay, eligible, deductible, unallocdeduct, eligpercent, tax, and benefit. Later related terminology work, including FHIR-30502 and UP-172, addresses broader harmonization of adjudication/category codes such as paid-by-patient/member-liability, but that work is not an Applied/Published core source decision in this run.

AutoFHIR reconciliation:
Published an empty external-repo audit commit. No core source was changed because the in-scope core patientPaid elements are already present in active source, while the only remaining unsatisfied portion requires THO/UTG terminology maintenance rather than adding codes to a core ValueSet that imports an external CodeSystem.

Recommendation:
Keep this audit commit as-is for core. Follow up with FM/THO or the relevant UTG proposal path to add or harmonize patient-paid and patient-responsibility/member-liability adjudication concepts in the external adjudication CodeSystem; once that terminology source is updated, the core ValueSet can include the codes through its existing THO import.
