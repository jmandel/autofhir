FHIR-5658: Audit ASTM signature definitions

Issue request:
FHIR-5658 is a Published/Persuasive Security change request raised for DSTU1 Contract. It asked to add the ASTM E1762 section 8.2.2 definitions to the ASTM signature purpose vocabulary because the short names alone did not make it clear which value to use for which purpose; the recorded motion approved the definitions 5-0-0.

Initial application:
The issue appears to have been initially applied in git commit ee90e45c798d2fb961e7e28d3ff9a052c19e26b2, which added ASTM definition text and copyright wording to the then-current Contract signer/signature-purpose value set. A follow-up commit, c455598a280e9b8e7988a17473bcc30bbfd0013d, moved the signature-purpose work toward the Signature datatype/value set. Later source refactoring created the standalone ASTM signature CodeSystem in commit 591b6b1e2af11332f5abed7455a91d11b91513b1 while retaining the approved definition text.

Additional context:
Current Contract.signer.type is no longer the ASTM signature purpose vocabulary; it is a Contract signer-role binding, and its value set explicitly says it is related but different to the signature type. The current build-scope authority, source/fhir.ini, actively includes the ASTM signature CodeSystem, and the Signature Type value set composes in the ASTM system. Related published issues FHIR-8918 and FHIR-9082 addressed the ASTM display names and the missed timestamp/display completion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active current source already contains all 18 ASTM E1762 signature purpose concepts with substantive definitions copied from the approved issue text, and the active Signature Type value set includes that CodeSystem. Editing the current Contract signer-role value set would be incorrect because it now represents signer roles, not signature purposes.

Recommendation:
Keep this empty audit commit as-is. No current FHIR core source edit is needed for FHIR-5658 unless a future Security or FM decision changes the relationship between Contract signer roles and Signature.type purposes.
