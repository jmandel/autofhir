FHIR-7974: Audit Provenance agent Organization target

Issue request:
FHIR-7974 was a Published/Persuasive FHIR-core Provenance change request from the 2015 May ballot. It asked to add Organization to the allowed reference types for the Provenance agent reference because the agent type/definition already allowed an organization and omitting Organization from the reference target list was a substantive oversight.

Initial application:
The issue was initially applied in git-svn commit e858186b98, matching the Jira comment for SVN revision 5868. That commit changed source/provenance/provenance-spreadsheet.xml from Reference(Practitioner|RelatedPerson|Patient|Device) to Reference(Practitioner|RelatedPerson|Patient|Device|Organization) for the then-current Provenance.agent.actor/reference element.

Additional context:
The current resource source is build-scoped through the active source/fhir.ini provenance=Provenance entry. The current element name is Provenance.agent.who after later Provenance refactors, and source/provenance/structuredefinition-Provenance.xml includes Organization among the Reference targetProfile values. Later commits added and reordered other allowed target types for the same element but preserved Organization. Jira, Zulip, and Confluence searches found no later decision or community discussion contradicting the original applied change.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The authoritative current Provenance StructureDefinition already includes Organization as an allowed target for Provenance.agent.who, so adding redundant prose or changing generated-looking artifacts would not improve implementer understanding.

Recommendation:
