FHIR-8198: Audit CommunicationRequest request timestamp rename

Issue request:
FHIR-8198 was a Published/Persuasive Patient Care change request from the DSTU1/QICore ballot asking FHIR Core to rename CommunicationRequest.orderedOn to CommunicationRequest.requestedOn because the resource is a request and the change could not be made only in a profile.

Initial application:
The request was applied in git commit a452682b2a (#8044, #8198, #8466, #6251), which changed the CommunicationRequest spreadsheet element from orderedOn to requestedOn and changed the matching search parameter from ordered to requested.

Additional context:
Later Published/Persuasive Patient Care issue FHIR-10293 applied workflow standardization to CommunicationRequest. Its implementation commit 999f9323ad removed requestedOn from the resource model, added CommunicationRequest.authoredOn mapped to Request.authoredOn, updated examples and the search parameter to authored, and left the R4 conversion mapping CommunicationRequest.requestedOn=CommunicationRequest.authoredOn in active source/fhir.ini. The current CommunicationRequest resource is active in source/fhir.ini.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active CommunicationRequest definition no longer contains orderedOn, and its current authoredOn element is the later workflow-aligned successor to the already-applied requestedOn change, with conversion support from requestedOn preserved.

Recommendation:
Keep this no-change audit commit. Reintroducing requestedOn would undo the later workflow-alignment decision; no follow-up is needed in FHIR core for FHIR-8198 unless Patient Care reopens the broader CommunicationRequest workflow naming decision.
