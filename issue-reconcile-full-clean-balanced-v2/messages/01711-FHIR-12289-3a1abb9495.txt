FHIR-12289: Audit Composition attester RelatedPerson support

Issue request:
FHIR-12289 is a Published/Persuasive FHIR-core Composition change request for DSTU2. It asked to include RelatedPerson as an allowed reference target for Composition.attester.party, matching representative/guardian use cases where an authorized related person attests a Composition.

Initial application:
The Jira comments state "svn revisoin 13104" as the application note. That Subversion revision maps to git commit 04fb3079bd44513f51cffc189ec0828259a77715, which changed the historical source/composition/composition-spreadsheet.xml row for Composition.attester.party from Reference(Patient|Practitioner|PractitionerRole|Organization) to Reference(Patient|RelatedPerson|Practitioner|PractitionerRole|Organization). Later source refactoring moved the resource definition into source/composition/structuredefinition-Composition.xml while preserving the RelatedPerson target.

Additional context:
The current build has composition=Composition active under source/fhir.ini [resources]. The current Composition StructureDefinition source already lists http://hl7.org/fhir/StructureDefinition/RelatedPerson as a targetProfile for Composition.attester.party. The same-change-family STU3 issue FHIR-15154 has already been audited on the combined branch in commit 4f105e56beacd41737de058149fdf1edeb85b65b and confirms that FHIR-12289 was the earlier application evidence for the same target addition. Community searches found only the FHIR-12289 tracker bot notification and the FHIR-15154 implementers thread, with no Confluence references or conflicting later decision to remove RelatedPerson from Composition.attester.party.
