Issue request:
FHIR-5675 was a Published FHIR-core NutritionRequest/NutritionOrder change request from the OO work group, resolved Persuasive with Modification for DSTU1. The recorded resolution asked to add text instructions for the supplement element.

Initial application:
The issue appears to have been applied before publication by git commit 5f4b59ef5387cfe691e41b262ffedae6e37f8b76, whose message says it pre-applied #5675 to NutritionOrder. That commit added NutritionOrder.supplement.instruction to the historical NutritionOrder spreadsheet as a 0..1 string with short/definition text and a committee note. The 2021 source rework carried the element forward into source/nutritionorder/structuredefinition-NutritionOrder.xml.

Additional context:
NutritionOrder is an active resource in source/fhir.ini, so the current StructureDefinition source is in build scope. A later Published issue, FHIR-39584, considered whether NutritionOrder instruction elements should be markdown and resolved that NutritionOrder.supplement.instruction should remain short text/string, while only NutritionOrder.enteralFormula.administrationInstruction should be markdown; that related issue is already represented on the combined branch. No direct Zulip or Confluence record for FHIR-5675 was found, and the relevant OO minutes for FHIR-39584 support leaving supplement instructions as text.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current active source already contains NutritionOrder.supplement.instruction with the requested instruction text, cardinality 0..1, type string, summary flag, and the historical #5675 committee note.

Recommendation:
Keep this audit commit as-is. No additional FHIR core source work is needed for FHIR-5675 unless the OO work group later reopens the separate question of instruction datatype or cardinality.
