FHIR-11004: Audit QuestionnaireResponse subjectType clarification

Issue request:
FHIR-11004 was a Published FHIR-core Questionnaire change request resolved as Persuasive with Modification. It asked whether Questionnaire.subjectType and QuestionnaireResponse.subject were the same and resolved to clarify QuestionnaireResponse.subject with wording that, if the Questionnaire declared a subjectType, the resource pointed to by QuestionnaireResponse.subject must be an instance of that type.

Initial application:
The issue appears to have been applied in the historical SVN-era commit 76675fcc91, whose subject explicitly lists QuestionnaireResponse #11004 among several clarifications. That commit added the requested subjectType comment to the then-authoritative QuestionnaireResponse spreadsheet source. Later source migrations carried the clarification into the current StructureDefinition XML.

Additional context:
Questionnaire and QuestionnaireResponse are active resources in source/fhir.ini. The current Questionnaire.subjectType definition is 0..* and says omitted subjectType means the subject is unlimited, while QuestionnaireResponse.subject says the response subject must be an instance of one of the listed types when a Questionnaire declares subjectType. Later SDC issue FHIR-27844 and associated minutes confirm the distinction: Questionnaire says what subjects are allowed, QuestionnaireResponse says what subject is used. No FHIR-11004-specific Zulip or Confluence evidence was found that changes this conclusion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current QuestionnaireResponse.subject comment already implements the Jira resolution, and its "one of the listed types" wording is more precise for the current 0..* Questionnaire.subjectType cardinality than the original singular resolution text.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-11004; related SDC profile cardinality decisions belong to the SDC specification, not this core reconciliation.
