FHIR-28583: Audit Ingredient CodeableReference migration

Issue request:
FHIR-28583 was a Published/Persuasive BR&R R5 change request for FHIR-core-MedicinalProductIngredient. It asked to change Ingredient.Substance.code[x] and Ingredient.SpecifiedSubstance.code[x] to CodeableReference because those elements already combined coded and referenced substance representations.

Initial application:
The request was explicitly applied before this reconciliation by commit 0ee3e67a82c0c38d9b72a24283a41aefd527d296, which changed the Ingredient spreadsheet and examples from CodeableConcept|Reference choices to CodeableReference for Ingredient.substance.code and Ingredient.specifiedSubstance.code. Later source refactors moved the built definition to source/ingredient/structuredefinition-Ingredient.xml, where Ingredient.substance.code remains a CodeableReference.

Additional context:
The current build uses Ingredient as the active successor to the old MedicinalProductIngredient artifact. Later Published BR&R issue FHIR-31813 removed Ingredient.specifiedSubstance entirely, with related modeling issues already represented on the combined branch, so the second element named by FHIR-28583 is no longer a current-build surface to edit. Later Published issue FHIR-31812 further narrowed the Ingredient substance CodeableReference target to SubstanceDefinition only; that related decision is also already represented on the combined branch.

AutoFHIR reconciliation:
This is an empty no-change audit commit. No source edit is needed because current build-scoped source already represents Ingredient.substance.code as CodeableReference, with concept and reference search parameters/examples, and there is no remaining Ingredient.specifiedSubstance or stale code[x] surface under the active Ingredient source.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-28583 unless BR&R reopens the later substance/specifiedSubstance modeling decisions in a new tracker.
