FHIR-12883: Audit modifierExtension differential rendering scope

Issue request:
FHIR-12883 was Published/Persuasive and reported that the FHIR 1.8 IG Publisher showed regular extensions in a profile differential table but showed modifierExtensions only in the snapshot table, even though the generated StructureDefinition XML and JSON contained the modifierExtension elements in both differential and snapshot.

Initial application:
The issue was applied in git-svn commit 73125f8da33e250f5f3ea10b43b4667b342923f0, matching Jira's svn revision 11859 comment. That commit changed the old DSTU3 ProfileUtilities and NarrativeGenerator Java code, added modifierExtension snapshot-generation fixtures and assertions, and wired the old IG Publisher narrative generation so modifierExtension slices could render in differentials.

Additional context:
The current HL7/fhir core checkout no longer contains the old IG Publisher Java implementation or the DSTU3 ProfileUtilities source that FHIR-12883 changed. Commit 56ceb0df08dd72381a4f98f1ea4ac5ea6d139a8b removed the IG Publisher from this repository because it had gone to Maven, and commit 7a2c3cd52484193783dcf3edf9b0c815e88d7aac later removed the old DSTU3 ProfileUtilities file. Jira, Zulip, and Confluence searches found the original Zulip report and no later core-spec decision requiring a source change.
