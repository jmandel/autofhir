FHIR-35981: Correct qualified CQL expression media types

Issue request:
FHIR-35981 is a Published/Persuasive CDS correction for R5 asking that the Clinical Reasoning Using Expressions topic stop using the generic text/cql media type where examples should use text/cql-expression or text/cql-identifier.

Initial application:
The issue was applied by PR 1801, merged as 1053365100b489e63db045d70bcbf378cdc3c30f from implementation commit c3a6925d119e8f0c2360c819b1e3ddcd7b772b04. That change fixed the first inline CQL examples and the first named-expression identifier example, but the same build-scope page still had XML and JSON examples of a qualified named expression using text/cql.

Additional context:
publish.ini actively includes clinicalreasoning-topics-using-expressions.html, so this page is in the current build. The ExpressionLanguage value set defines text/cql-identifier as the media type for a CQL identifier, and later Using Expressions updates for FHIR-49976 and FHIR-53080 added identifier/expression guidance and backwards-compatibility text without changing these stale examples. A 2024 Zulip discussion with Bryn Rhodes clarified that text/cql-identifier covers a valid identifier or qualified identifier, while text/cql-expression covers inline CQL expressions.

AutoFHIR reconciliation:
Changed the remaining qualified named-expression examples in source/clinicalreasoning-topics-using-expressions.html from text/cql to text/cql-identifier. The generic text/cql list entry and backwards-compatibility note were left unchanged because they describe the still-supported media type rather than an example that should use a more specific CQL subtype.

Recommendation:
Keep this source fix. It completes the original Published correction without broadening the issue into unrelated CQL media type policy or later Using Expressions cleanup.
