FHIR-7177: Audit NutritionOrder nutrient examples

Issue request:
FHIR-7177 was a Published FHIR-core OO change request with Persuasive with Modification resolution for NutritionOrder.oralDiet.nutrient. The reporter asked how the nutrient backbone would be used, and the accepted resolution was to add example nutrients in the definition, specifically a parenthetical like "for example carbohydrate, fiber or sodium".

Initial application:
The issue appears to have been applied in historical commit 534862556cd06a263b3e746ace9c828669fd04da, which changed the old NutritionOrder spreadsheet definition for oralDiet.nutrient to include "(for example carbohydrate, fiber or sodium)". Later source migration moved the resource from spreadsheet input into structuredefinition-NutritionOrder.xml, and the 2024 NutritionOrder revision preserved the same parenthetical examples while rephrasing the surrounding sentence.

Additional context:
The current build scope uses NutritionOrder, not NutritionRequest: source/fhir.ini has an active nutritionorder=NutritionOrder resource entry, while NutritionRequest appears only in the removed-resources list. FHIR-11092 and commit bc0b5b5ebe7774e25d724e29b882f1f43e7c341f explain that the temporary NutritionRequest rename was reversed back to NutritionOrder. Bounded Zulip and Confluence searches found no later community evidence contradicting the Jira/source conclusion.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change.
