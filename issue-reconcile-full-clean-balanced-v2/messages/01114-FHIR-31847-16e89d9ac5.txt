FHIR-31847: Finish ClinicalUseDefinition list ids

Issue request:
FHIR-31847 was Published with resolution Persuasive with Modification for the BRR ClinicalUseIssue resource. The approved decision was to change the resource name to ClinicalUseDefinition because indication is not itself a use issue.

Initial application:
The current source already carries the active resource as ClinicalUseDefinition in fhir.ini and in the StructureDefinition. Git history shows the 2021 rename work in this branch added the ClinicalUseDefinition source and renamed most internals, but the empty ClinicalUseDefinition List source files were introduced with lingering ClinicalUseIssue ids. A later R4B-side commit corrected those ids, but that commit is not in the current HEAD lineage.

Additional context:
BRR minutes on 2021-07-06 record the 16-1-2 motion to change the name to ClinicalUseDefinition, and 2022-02-10 minutes record the change as applied. Zulip discussion in August and December 2021 confirms the old and new names represented the same resource and that remaining ClinicalUseIssue references were expected to disappear once build dependencies allowed. Remaining current-source matches are either historical release text for the 4.6.0 ballot or a commented inactive fhir.ini line, not active resource identifiers.

AutoFHIR reconciliation:
Updated the active ClinicalUseDefinition pack and operations List ids from ClinicalUseIssue-packs and ClinicalUseIssue-operations to ClinicalUseDefinition-packs and ClinicalUseDefinition-operations. No other source was changed because the resource, canonical URL, type, active build configuration, and current narrative already use ClinicalUseDefinition.

Recommendation:
Keep this commit as the final FHIR-31847 reconciliation. No further core source change is recommended unless a future full build surfaces generated output that still derives an active ClinicalUseIssue resource identifier from another source.
