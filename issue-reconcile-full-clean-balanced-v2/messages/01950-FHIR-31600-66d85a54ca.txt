FHIR-31600: Audit Citation boundary clarification scope

Issue request:
FHIR-31600 was a Published/Persuasive with Modification CDS issue for R5 asking for a Boundaries and Relationships discussion of when to use Citation versus DocumentReference. The approved resolution distinguished DocumentReference as a healthcare-exchange-oriented reference to a document of any kind from Citation as a scholarly/scientific knowledge-artifact reference modeled for identification, attribution, classification, status tracking, and citation summaries.

Initial application:
The issue was applied in the former core Citation source by b3308a803cdb2a3f27639f659bb67ff044db5cc1, which added the approved DocumentReference/Citation boundary paragraph to source/citation/citation-introduction.xml. No separate DocumentReference source change appears to have been part of the application.

Additional context:
Citation is no longer an active FHIR-core resource in this checkout. The active resources list includes DocumentReference but has no Citation resource entry, source/citation was removed by 71567db3ee039ac6977be5f96a7e013896569a36, and current Clinical Reasoning narrative links Citation to the Evidence Based Medicine on FHIR IG and states that Citation moved there. A separate current-core reconciliation for FHIR-31643 already corrected the in-scope Citation links to the external EBM IG page. The current DocumentReference Boundaries and Relationships section remains accurate for DocumentReference itself and is not the historical target where FHIR-31600 was applied.
