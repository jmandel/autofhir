FHIR-36305: Audit survey category terminology in THO

Issue request:
FHIR-36305 was an Applied FHIR-core Observation change request resolved Persuasive with Modification. It asked to clarify the Observation.category code survey by changing the Observation Category Codes definition to: "Observations from survey instruments (e.g. patient experience surveys), questionnaires, forms (e.g. patient admission forms) and assessment tools (e.g. Apgar Scores, Montreal Cognitive Assessment (MoCA))."

Initial application:
No core source commit explicitly mentioning FHIR-36305 was found. The current core source keeps Observation in the active build and binds Observation.category to http://hl7.org/fhir/ValueSet/observation-category, but source/observation/valueset-observation-category.xml only composes the external THO CodeSystem http://terminology.hl7.org/CodeSystem/observation-category. The old core source file source/observation/codesystem-observation-category.xml, which contained the pre-clarification survey definition, was removed by 5c0494aacf as part of removing UTG content from the core build.

Additional context:
The originating Zulip thread proposed the same clarification text. OO minutes on 2022-10-04 added FHIR-36305 to block vote, and the Jira vote later recorded the Persuasive with Modification decision. Later Jira comments correctly redirected implementation through the UTG process and identified the THO Observation Category Code CodeSystem/ValueSet plus the generated build.fhir.org ValueSet as the only relevant surfaces. UTG proposal UP-738 is Proposal Implemented and modified input/sourceOfTruth/fhir/codeSystems/CodeSystem-observation-category.xml for the R6 ballot; THO 7.1.0 and the current build.fhir.org ValueSet expansion now show the clarified survey definition.

AutoFHIR reconciliation:
This commit intentionally makes no source change in the FHIR core checkout. The editable source of truth for the survey concept definition is THO/UTG, not core, and the current core ValueSet source is already the correct build-scoped include of that external CodeSystem.

Recommendation:
Keep this empty external-repo audit commit as-is for FHIR core. If the survey wording is revisited, make the follow-up in UTG/THO and verify that the FHIR build continues to expand http://hl7.org/fhir/ValueSet/observation-category from the updated THO CodeSystem.
