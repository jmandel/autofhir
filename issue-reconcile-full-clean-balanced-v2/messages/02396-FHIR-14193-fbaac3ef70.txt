FHIR-14193: Audit Signature datatype definition wording

Issue request:
FHIR-14193 was a Published/Persuasive Security WG change request for STU3 asking that the Signature datatype definition change from "A digital Signature - XML DigSig, JWS, Graphical image of signature, etc." to "A Signature - XML DigSig, JWS, Graphical image of signature, etc." so the datatype is inclusive of electronic and non-digital signature forms.

Initial application:
No git commit explicitly mentioning FHIR-14193 was found.
