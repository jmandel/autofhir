Issue request:
FHIR-29032 was Published with a Persuasive with Modification resolution for R5. It asked to broaden the Observation Scope and Usage text so Observation clearly covers non-clinical product/substance testing, specifically by adding results of tests performed on products and substances and a product quality tests bullet.

Initial application:
Jira records the issue as applied in git 4fd5511530. That commit updated source/observation/observation-introduction.xml to add the requested products/substances sentence and product quality tests bullet. The current source still retains that meaning.

Additional context:

A later applied issue, FHIR-31081, deliberately broadened the same Observation introduction text from products/substances to products, substances, and environments; that later issue is already represented on the combined branch and should not be duplicated here. DiagnosticReport still includes product quality tests for products and substances, so the Observation wording remains aligned with the original non-clinical product/substance scope while also preserving the later environment clarification. OO and BR&R minutes confirm the original FHIR-29032 discussion, planned application, and completed application; no relevant Zulip conflict was found.
