FHIR-41566: Audit RelatedPerson responsibility wording

Issue request:
FHIR-41566 was an Applied/Persuasive PA change request asking to remove or clarify the RelatedPerson summary phrase "nor has a formal responsibility in the care process" because RelatedPerson can be referenced in roles that carry responsibility, such as CarePlan.custodian. The final resolution said the extra text would be removed because RelatedPerson Scope and Usage and Boundaries and Relationships already explain when to use Practitioner or RelatedPerson.

Initial application:
Git commit 35f8bd751cf8c2ccfdf05add3ae46a3b5973c60f applied the issue by removing the formal-responsibility clause from both the RelatedPerson StructureDefinition description and root element definition.

Additional context:
RelatedPerson is active current-build source. Current source/relatedperson/structuredefinition-RelatedPerson.xml no longer contains "formal responsibility", while source/relatedperson/relatedperson-introduction.xml keeps the Practitioner vs RelatedPerson boundary text. The September 2023 PA WGM minutes record the decision to remove the sentence because Scope and Usage and Boundaries already provide explanation. FHIR-41559 then changed the same definition to "primary target of healthcare" without reintroducing the removed clause.
