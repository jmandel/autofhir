FHIR-8203: Audit MedicationRequest TPN scope

Issue request:
FHIR-8203 was a Published/Persuasive with Modification Pharmacy change request asking MedicationPrescription to explicitly include the ability to order total parenteral nutrition and distinguish it from NutritionOrder/diet orders.

Initial application:
The issue was applied in git commit 1035927e2bb56676468ca554f2325536de2c059d, which changed the then-current MedicationOrder introduction to include total parenteral nutrition and diet/vitamin supplements and to exclude particular diets. The resource later became MedicationRequest, and the active MedicationRequest source still preserves the same semantic boundary.

Additional context:
FHIR-7172 is the paired OO issue that excludes parenteral (IV) nutrition from NutritionOrder and says it is typically filled by pharmacy. Current NutritionOrder boundaries direct parenteral (IV) nutrition to MedicationRequest. Later FHIR-15943 was Resolved - No Change after noting the NutritionOrder introduction already limits NutritionOrder and keeps parenteral nutrition out of scope. A 2019 Zulip implementer thread likewise treats TPN as outside NutritionOrder.

AutoFHIR reconciliation:
No source change was made. The active MedicationRequest introduction already includes total parenteral nutrition and diet/vitamin supplements in medication-order scope and separately excludes prescribing particular diets.

Recommendation:
Keep this no-change audit commit as-is. No core FHIR source follow-up is needed for FHIR-8203 unless Pharmacy later revisits whether total parenteral nutrition should be represented by a different request resource.
