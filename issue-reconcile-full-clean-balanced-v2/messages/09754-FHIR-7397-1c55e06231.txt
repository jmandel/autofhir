FHIR-7397: Audit Basic Resource Types SLOT removal

Issue request:
FHIR-7397 was Published/Persuasive for DSTU1 and asked to remove or deprecate SLOT / Resource Slot from the Basic Resource Types value set because Slot had become a normal FHIR resource. The accepted resolution was to revisit the list and remove duplicates.

Initial application:
The issue was applied in git-svn revision 6444, now commit cddf8c5cdfaa6b3a73584d76f57e7f11aff877ba, whose message was "#7397 - trim basic.resourceType". That commit removed the inline slot concept from source/basic/valueset-basic-resource-type.xml, along with another duplicate concept.

Additional context:
The current Basic resource remains in the active source/fhir.ini [resources] list, and source/basic/valueset-basic-resource-type.xml is still present in that build-scoped resource folder. The value set has since been refactored to include the THO CodeSystem http://terminology.hl7.org/CodeSystem/basic-resource-type rather than inline concepts. A current THO check shows that code system contains consent, referral, advevent, aptmtreq, transfer, diet, adminact, exposure, investigation, account, invoice, adjudicat, predetreq, predetermine, study, and protocol, but no slot/SLOT or Resource Slot concept. Later issue FHIR-48798 changed Basic.code away from this value set to version-independent-resource-types, so the present Basic.code binding is governed by that later decision rather than by the old Basic Resource Types list.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The historical duplicate SLOT concept is absent from the current core source and absent from the terminology code system that the current value set imports, so editing the current source would not improve implementer understanding or conformance.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-7397 unless THO later reintroduces slot/SLOT into CodeSystem/basic-resource-type, which would be a terminology-source issue outside this core checkout.
