Initial application:
The Jira comment identifies git 74a9269071f19ec5a6b7c3fa2bb21e67fb3aa753. Additional context:
The current build still actively consumes source/profiles/iso-21090-spreadsheet.xml via source/fhir.ini, so that spreadsheet is the authoritative core source to check. Current core source has no iso21090-verification definition or link. The exact extension remains only in tools/history/release2 and tools/history/release3 archived release bundles, which preserve already-published historical packages rather than define the current build. The FHIR Extension Pack contains other ISO 21090 extensions but no iso21090-verification definition.

Keep this audit commit as-is. No core source follow-up is needed unless a human explicitly decides to rewrite historical release archives, which is outside normal current-build reconciliation scope.
