FHIR-7167: Audit MedicationStatement purpose wording

Issue request:
FHIR-7167 was a Published/Persuasive with Modification Pharmacy change request from DSTU1 asking to clarify the purpose of MedicationStatement, explain that it records active, past, or future medication use from sources beyond the patient, explain how MedicationStatement relates to medication lists, and distinguish MedicationStatement from MedicationAdministration.

Initial application:
The issue was explicitly applied in git commit 7d50996061 (#7167, svn 6686), which updated the MedicationStatement definition and scope/usage narrative. Commit e7200c208f immediately adjusted the definition text to fix the build. The current source no longer has the old spreadsheet inputs, but the active StructureDefinition and introduction preserve the relevant #7167 clarification.

Additional context:
MedicationStatement is active, Pharmacy-owned, and approved in source/fhir.ini, so source/medicationstatement/structuredefinition-MedicationStatement.xml and source/medicationstatement/medicationstatement-introduction.xml are current build inputs. Related same-change-family issues FHIR-5916 and FHIR-5941 are already represented on the combined branch. Later reconciliations FHIR-7405, FHIR-7168, FHIR-39165, and FHIR-41500 refined adjacent common-usage, reporter/source, social-history, and informationSource wording without reversing the FHIR-7167 purpose clarification.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Current active source already states that MedicationStatement records medication being taken, not taken, past use, or planned future use; explains that MedicationStatement produces individual statements that can be used in List rather than producing a medication list itself; distinguishes MedicationStatement from request, dispense, and administration events; and provides informationSource/derivedFrom elements for the source context requested by the issue.

Recommendation:
Keep this audit commit as-is. Do not add redundant purpose prose for FHIR-7167; any future edit should be limited to a later final Pharmacy decision or a targeted typo/editorial tracker, not this already-applied 2015 clarification.
