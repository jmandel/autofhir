FHIR-8014: Audit MedicationStatement free-text dosage guidance

Issue request:
FHIR-8014 was a Published/Persuasive with Modification DSTU1 Pharmacy request asking where a free-text SIG belongs on MedicationStatement and specifically asking for guidance near MedicationStatement.note. The accepted resolution said Dosage.text is the appropriate field, with the short description changed to "Reported dosage information" and the definition changed to "Free text dosage information as reported about a patient's medication use. When coded dosage information is present, the free text may still be present for display to humans."

Initial application:
The issue was applied in legacy source by git commit 8926d3f854ca89a48d4ddec52559c160f94ec710, which changed MedicationStatement.dosage.text in the MedicationStatement spreadsheet to the requested short label and definition. A later same-family commit for FHIR-5925 adjusted the MedicationStatement dosage.text label to explicitly mention free-text SIG, and the dosage instruction model was subsequently consolidated into reusable dosage datatypes.

Additional context:
MedicationStatement is active in source/fhir.ini, and the current MedicationStatement.dosage element is active source using the DosageDetails datatype rather than an in-resource MedicationStatement.dosage.text child. DosageDetails is also active in source/fhir.ini. Current DosageDetails.renderedInstruction is 1..1 markdown with a definition requiring the full dosage intent to be communicated in every case; this later R6 wording was required by Applied issue FHIR-54014. The current note element remains general extra information, so adding MedicationStatement.note-specific SIG guidance would now duplicate or conflict with the authoritative dosage datatype guidance.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current build already gives implementers a required free-text dosage representation for MedicationStatement.dosage through DosageDetails.renderedInstruction, which preserves the substance of the FHIR-8014 decision in the current model.

Recommendation:
Keep this no-change audit. If Pharmacy later reopens the R6 DosageDetails model, review the free-text SIG guidance there rather than adding MedicationStatement.note-specific prose.
