FHIR-11308: Audit retired Sequence identifier clarification

Issue request:
FHIR-11308 was a Published/Persuasive DSTU2 Clinical Genomics change request for the old FHIR-core Sequence resource. It asked to clarify Sequence.identifier because "a unique identifier for this particular sequence instance" did not make clear whether the identifier was for the variation or sequence resource and whether it was local or universal. The accepted resolution said the identifier was a business identifier for the whole Sequence resource that would not change when copied to another server.

Initial application:
The historical source shows an explicit application commit, 6072b705b61538f2fe3fe5d5cc3779298ae2e79c, whose subject is "#11238 #11308 Revise definition for strand and identifier". That commit changed source/sequence/sequence-spreadsheet.xml so Sequence.identifier's short and definition appended "This is a FHIR-defined id"; the wording was later carried into MolecularSequence.identifier after the Sequence-to-MolecularSequence rename.

Additional context:
The original Sequence resource is no longer active in the current build. FHIR-19453 renamed Sequence to MolecularSequence, and later FHIR-51227 decided that the new MolecularDefinition resource supersedes legacy MolecularSequence. Current source/fhir.ini lists Sequence under [removed-resources], comments out MolecularSequence in current resource metadata, and classifies MolecularDefinition as the active Clinical Genomics resource. Current source contains no Sequence.identifier or MolecularSequence.identifier definition. MolecularDefinition.identifier is a different current-model element, typed as Identifier, and the Identifier datatype already establishes that identifiers are typically business identifiers; translating the old DSTU2 Sequence wording into MolecularDefinition would be a new Clinical Genomics model decision rather than completing FHIR-11308.

AutoFHIR reconciliation:
This is an empty audit commit. No source file was changed because FHIR-11308's historical target was applied in the retired Sequence source and no current-build Sequence/MolecularSequence identifier remains to correct.

Recommendation:
Keep this audit commit as-is. No FHIR core follow-up is needed for FHIR-11308; if Clinical Genomics wants stronger or different identifier semantics for the active MolecularDefinition model, that should be handled as a new MolecularDefinition issue rather than by reopening this retired DSTU2 Sequence tracker.
