FHIR-29575: Audit Medication batch container fill extension

Issue request:
FHIR-29575 was Published with resolution Persuasive with Modification. It asked to add Container Fill/Container Fill Unit to Medication.Batch, with examples such as 100 tablets, 10 mL, 1 patch, or 1 sachet, and the approved resolution was to create a core extension for this attribute.

Initial application:
No FHIR-29575-tagged source commit was found in the core or Extension Pack history. Historical core source did contain source/medication/structuredefinition-extension-medication-manufacturingBatch.xml with a container.quantity sub-extension whose definition covers the requested amount or volume of drug product in the container, and Pharmacy minutes record that the PQ/CMC manufacturing extension was created and added to the build. The core extension file was later removed by dd468d4f17 when extensions were moved out of the R5 core source.

Additional context:
The current HL7/fhir checkout is the R6 ballot source and Medication is active, but extension definitions have been moved to the FHIR Extension Pack. Current core Medication now uses Medication.instance after FHIR-47622 and also has Medication.packageSize for package-level amount information, while the Extension Pack contains input/definitions/multiple/StructureDefinition-medication-manufacturingBatch.xml with canonical http://hl7.org/fhir/StructureDefinition/medication-manufacturingBatch, context Medication.batch/Substance, and the requested container.quantity Ratio sub-extension. A 2022 Zulip thread shows the reporter profiling this standard extension and using container.quantity as "Container Fill per Container Size".

AutoFHIR reconciliation:
This commit intentionally makes no HL7/fhir source change. The requested extension content exists in the Extension Pack, and the absence of the old core extension definition from HL7/fhir is consistent with the deliberate extension move rather than an unapplied core issue.

Recommendation:
Keep this audit commit as-is for core reconciliation. If Pharmacy wants the manufacturing batch extension adjusted for R6 Medication.instance context, packageSize interaction, or later wording refinements, that follow-up should be handled in the FHIR Extension Pack with Pharmacy work-group review.
