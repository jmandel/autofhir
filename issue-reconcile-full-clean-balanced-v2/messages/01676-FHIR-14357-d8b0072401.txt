FHIR-14357: Audit ImagingStudy availability application

Issue request:
FHIR-14357 was a Published FHIR-core ImagingStudy change request, resolved Persuasive with Modification for STU3. It asked how to represent study availability when different endpoints may have different online/offline status; the accepted resolution removed ImagingStudy.availability from both study and series and added implementation-note text that availability can be determined by interacting with the endpoint.

Initial application:
The historical source application is commit 7b2b645120, whose message references GF#14357 in the ImagingStudy change set. That commit marked ImagingStudy.availability and ImagingStudy.series.availability as removed in the then-authoritative spreadsheet source, removed availability values from examples, and added the endpoint/offline note to ImagingStudy implementation notes. Later source refactoring moved the resource definition into source/imagingstudy/structuredefinition-ImagingStudy.xml.

Additional context:
ImagingStudy is active in the current build via source/fhir.ini. The current StructureDefinition contains ImagingStudy.endpoint and ImagingStudy.series.endpoint but no ImagingStudy.availability or ImagingStudy.series.availability elements, and source/imagingstudy/imagingstudy-notes.xml still includes the endpoint/offline note requested by the Jira resolution. Related FHIR-14358 considered a broader per-endpoint ImagingStudy model and resolved no-change, supporting the current multi-endpoint model rather than one ImagingStudy per endpoint. Later FHIR-50775 updated ImagingStudy descriptions without reintroducing availability elements.
