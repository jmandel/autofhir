FHIR-5365: Audit Base Resource link section numbering

Issue request:
FHIR-5365 was a Published/Persuasive DSTU1 FHIR-core documentation ballot issue. It reported that following the Base Resource link from the Documentation Index/Resources area produced Resource page subsection headings prefixed with "null", and asked to remove the "null" prefix throughout that page. The recorded resolution was that the content was not registered in the hierarchy and the broken index should be fixed; Jira comments say it was already fixed.

Initial application:

The active Documentation Index links Resource through the Type Framework section, Resource is registered in the current hierarchy and resource-infrastructure configuration, and build.fhir.org renders Resource headings with numeric section counts rather than null prefixes.
