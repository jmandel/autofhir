AutoFHIR reconciliation:

Editing the inactive/absent core Citation source would reintroduce out-of-scope terminology rather than improve the current specification.

Recommendation:
Keep this audit commit as-is for core. If the active EBM IG, Extension Pack, or terminology source for the Citation artifacts lacks the coverage concept, handle that as follow-up in the owning external repository rather than in the base FHIR checkout.
