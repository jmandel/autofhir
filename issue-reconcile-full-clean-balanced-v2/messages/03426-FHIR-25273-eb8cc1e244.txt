FHIR-25273: Audit ValueSet.description clarification

Issue request:
FHIR-25273 was a Published Vocab change request, resolved Persuasive with Modification for R5, asking that ValueSet.description, ValueSet.purpose, and useContext be reviewed after the proposed ValueSet.scope work. The final decision accepted the 2021-02-18 Vocab wording for ValueSet.description and explicitly noted removal of the confusing Description alternate names Scope and Purpose.

Initial application:
The change was applied before this reconciliation. Commit 9fca6ca36f added the accepted ValueSet.description definition/comment, removed the Scope and Purpose aliases from ValueSet.description, and added the FHIR-25272 ValueSet.scope trial-use structure. Commit b0172dd266 then made a small spacing/editorial cleanup to the same ValueSet.description comment. The active source/fhir.ini resource entry confirms source/valueset/structuredefinition-ValueSet.xml is in the current build scope for ValueSet.

Additional context:
FHIR-24085 separately supports removing Scope and Purpose aliases from ValueSet.description. FHIR-35988 and duplicate/supporting FHIR-35989 later made a Published R5 decision to replace the ValueSet.description comment while making no change to the ValueSet.description definition; commit f564419fa5 implemented that later comment. FHIR-34171 and the later R6 preparation commit 40306e5cd9 removed the ValueSet.scope elements from core, so the absence of current core scope elements is a later ValueSet/VSD change rather than a missed FHIR-25273 application.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current ValueSet source preserves the FHIR-25273 description definition, retains the canonical useContext and purpose text, has no Scope or Purpose aliases on ValueSet.description, and reflects the later FHIR-35988/FHIR-35989 replacement of the description comment.

Recommendation:
Keep this audit commit as-is. No core FHIR source follow-up is needed for FHIR-25273; any future ValueSet scope work should be handled under the later scope-removal/extension issue family rather than by restoring the older R5 trial-use scope text.
