FHIR-25927: Audit FMM0 experimental metadata

Issue request:
FHIR-25927 was a Published/Persuasive R5 FHIR-I change request asking that experimental StructureDefinitions be marked as such, with build.fhir.org/capabilitystatement2.html as the example. The approved resolution said to change code so the experimental flag would be set for all artifacts with FMM=0.

Initial application:
No explicit Jira-tagged HL7/fhir source commit for FHIR-25927 was found. The 2020 FHIR-I minutes record the intended rule as treating FMM level 0 resources as experimental by default so outside specifications that lack FMM can still identify immature FHIR artifacts. The named CapabilityStatement2 example was later removed from current build scope, so there is no surviving CapabilityStatement2 source to edit.

Additional context:
Later FHIR-I decisions changed the current interpretation of experimental. FHIR-28454 added meaningWhenMissing text saying absent experimental is treated as not experimental, and FHIR-48306 clarified that experimental is a testing-only classification rather than draft/FMM/lifecycle status. The supporting Zulip discussion explicitly distinguishes experimental from draft and FMM. Current source/fhir.ini still identifies active FMM=0 resources, but their StructureDefinition sources omit experimental and the current CI build publishes those FMM=0 artifacts with experimental=false.

AutoFHIR reconciliation:
This commit intentionally makes no source change. Automatically marking all FMM=0 artifacts experimental would now contradict the later StructureDefinition.experimental semantics: low maturity/draft FHIR artifacts can still be intended for real use, while experimental=true means authored for testing-only use. Current source is therefore correct to leave FMM=0 artifacts non-experimental unless a specific artifact is actually testing-only.

Recommendation:
Keep this no-change audit commit. If FHIR-I still wants external specifications to identify low-FMM artifacts without understanding FMM, that should be handled by a new decision or mechanism that preserves the FHIR-48306 distinction between draft/FMM and experimental.
