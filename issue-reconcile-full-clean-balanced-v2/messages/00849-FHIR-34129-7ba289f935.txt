FHIR-34129: Correct doseAndRate example units

Issue request:
FHIR-34129 was Published with a Persuasive with Modification resolution for R5 Pharmacy work. It asked for guidance on repeated Dosage.doseAndRate, specifically an example showing "1800 mg (1000 mg/m2) orally twice daily from days 1-14 of cycle", and it asked whether the dose-rate-type binding should become required. The resolution was to add the example but not change the binding because Pharmacy did not know all needed codes and implementers may need their own codes.

Initial application:
Commit 7482aeda78 added source/medicationrequest/medicationrequestexample3.xml and linked it from the active MedicationRequest examples. Commit c0a117e508 then tried to correct the ordered/calculated values after a Jira comment said the 1800 value should be calculated and the 1000 value should be ordered, but it swapped only the numeric values and left the units attached to the wrong quantities.

Additional context:
MedicationRequest is active in source/fhir.ini, and the example is listed by source/medicationrequest/medicationrequest-examples-header.xml and source/medicationrequest/list-MedicationRequest-examples.xml, so the XML example is in current build scope. Dosage.doseAndRate.type remains bound to DoseAndRateType with example strength, matching the Jira resolution not to require the value set. The originating Zulip thread led to FHIR-34129, and a later Zulip follow-up explicitly confirmed that the published example still had the units backwards: ordered should be 1000 mg/m2 and calculated should be 1800 mg.

AutoFHIR reconciliation:
This commit corrects source/medicationrequest/medicationrequestexample3.xml so the calculated doseAndRate is 1800 mg and the ordered doseAndRate is 1000 mg/m2. It intentionally leaves the dose-rate-type binding as example strength.

Recommendation:
Keep this source fix. It completes the already-published Jira disposition by making the active example match the approved text and later WG/editor clarification without broadening the value set binding beyond the resolution.
