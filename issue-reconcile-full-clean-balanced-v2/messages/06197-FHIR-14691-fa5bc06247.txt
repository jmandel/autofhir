FHIR-14691 was a Published FHIR-core CodeSystem clarification with resolution Persuasive with Modification. It asked that CodeSystem.url documentation stop switching confusingly between "canonical URI" and "canonical URL" in the CodeSystem Identification text.

Initial application:

Those commits rewrote the CodeSystem Identification section and follow-up wording/case details, initially using "canonical URI" with "canonical URL" as an explanatory alternate in some places.

Additional context:
The current build includes CodeSystem as an active resource in source/fhir.ini. Later final issues changed the relevant wording family: FHIR-18673/commit 6f7c3716 clarified canonical URL language and replaced the earlier CodeSystem "canonical URI" wording with "canonical URL" while retaining a precise note that the element type/identifier is still a URI; FHIR-34146 and FHIR-39111 later clarified the same CodeSystem identification and Coding relationship text. Community searches found no non-bot Zulip or Confluence record that conflicts with the Jira/source history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The active CodeSystem source now consistently describes CodeSystem.url as the canonical URL in the places FHIR-14691 targeted, and the remaining word "URI" is used to explain identifier syntax and resolvability rather than to reintroduce the original ambiguity.

Recommendation:
Keep this audit commit as-is. No follow-up core source change is needed for FHIR-14691 unless the work group wants a broader terminology-wide policy change for canonical URL/URI phrasing, which would be outside this published CodeSystem clarification.
