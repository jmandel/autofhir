FHIR-29260: Align Observation subject notes

Issue request:
FHIR-29260 was Published with a Persuasive with Modification OO resolution for R5. It requested adding Organization, Procedure, and Practitioner to Observation.subject, clarifying how Procedure is used as a subject in the regulatory inspection process, and keeping those additions STU rather than immediately normative.

Initial application:
The Jira application comment points to git f88c6800c3, which updated the then-authoritative Observation spreadsheet by adding Organization, Procedure, and Practitioner to Observation.subject and adding the procedure/regulatory-inspection clarification. Current source has since moved to StructureDefinition XML, and source/observation/structuredefinition-Observation.xml preserves those targetProfiles and the Procedure clarification.

Additional context:
Later subject-expansion work added Medication, Substance, BiologicallyDerivedProduct, and NutritionProduct to Observation.subject; FHIR-29031 already reconciled the element definition and mapping text for those later targets. FHIR-29930 and FHIR-32575 are already represented on the combined branch and explain the related DiagnosticReport subject/focus path, including that the DiagnosticReport Procedure cleanup does not reverse Procedure as an Observation.subject. FHIR-40335 later added subject/focus/device guidance to Observation notes, but the lead-in sentence still listed only the pre-FHIR-29260 subject examples.

AutoFHIR reconciliation:
This commit updates source/observation/observation-notes.xml in the active Observation resource folder so the built “Subject of an Observation” narrative lists the current Observation.subject target set instead of the old Patient/Group/Location/Device-only wording. This is a source-changing fix because the stale narrative could lead readers away from the subject references already allowed and described by the authoritative Observation.subject definition. Generated-looking diagram text in source/observation/observation.svg was not edited.

Recommendation:
Keep this source fix. It completes the FHIR-29260 narrative alignment without changing the conformance model, and future subject-target changes should update the element definition, mapping exceptions, and Observation notes together to avoid repeating this drift.
