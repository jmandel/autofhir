FHIR-31425: Complete NDJSON page corrections

Issue request:
FHIR-31425 was a Published/Persuasive FHIR-I clarification request for the NDJSON representation page. It asked to link the NDJSON specification, consistently use the name "NDJSON" instead of "ND-JSON", "nd-json", or "ns-json", make the single-resource-type rule an RFC 2119 requirement using SHALL, and label the sample as "NDJSON example".

Initial application:
The historical Jira-tagged source commit 5ff951a848f4c4e937ebbcd51442e9262f65ab7a applied the main page change in source/nd-json.html by adding the external NDJSON spec link, adding SHALL to the single-resource-type sentence, and changing the example shape. That application did not touch current navigation and format-summary pages, left the example caption as only "Example", left a double space in "SHALL  only", and accidentally changed the opening sentence to say NDJSON was a variant of the NDJSON format.

Additional context:
Confluence FHIR-I minutes for 2021-05-31 record FHIR-31425 as persuasive, matching the Jira disposition. Community searches found no Zulip discussion or later Jira decision that narrowed or reversed the requested wording cleanup.

AutoFHIR reconciliation:
This commit completes the current-build source application. It fixes source/nd-json.html to describe NDJSON as a variant of JSON, labels the sample "NDJSON example", and normalizes the SHALL sentence. It also updates current user-visible source labels in source/documentation.html, source/downloads.html, source/hierarchy.xml, source/resource-formats.html, and source/history.html so the built specification consistently presents the format as NDJSON while preserving the nd-json.html filename and links.
