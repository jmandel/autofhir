FHIR-33072: Audit Specimen bodySite CodeableReference

Issue request:
FHIR-33072 was Published/Persuasive with Modification for R5. It asked that Specimen.collection.bodySite stop being only a CodeableConcept and instead become a CodeableReference(BodyStructure), supporting both a simple coded body site and a reference to a BodyStructure instance.

Initial application:
The issue was applied before this reconciliation. The Jira comments first pointed to 7ca1165, then corrected that to merge commit a87c891 for PR #1393. The underlying change 24781f0 changed source/specimen/structuredefinition-Specimen.xml from CodeableConcept to CodeableReference with targetProfile BodyStructure, updated specimen-example.xml to wrap the code in CodeableReference.concept, and PR #1393 also changed the bodysite search parameter from token on Specimen.collection.bodySite to reference on Specimen.collection.bodySite.reference.

Additional context:
Specimen is an active core resource in source/fhir.ini, so source/specimen/structuredefinition-Specimen.xml and source/specimen/bundle-Specimen-search-params.xml are current build inputs. The current combined branch still has Specimen.collection.bodySite typed as CodeableReference with targetProfile http://hl7.org/fhir/StructureDefinition/BodyStructure and the bodysite search parameter is reference-based. The 2021-08-23 OO Specimen minutes confirm the FHIR-33072 vote and rationale that CodeableReference allows either a code or BodyStructure reference. Later bodySite/bodyStructure work was checked: FHIR-53203 is already represented separately on the combined branch and did not require changing this Specimen element for this issue; FHIR-54843 would rename Specimen.collection.bodySite to bodyStructure and make it repeating, but it is still Resolved - change required/Ready_to_Apply rather than Applied or Published, and its branch commit is not an ancestor of the current combined branch.

AutoFHIR reconciliation:
No source change was made. The current source already satisfies the FHIR-33072 request, and applying the later FHIR-54843 rename/cardinality change under this R5 issue would overreach the seed scope and duplicate a separate pending decision.

Recommendation:
Keep this no-change audit commit as-is for FHIR-33072. Any future Specimen.collection.bodySite rename, binding-name change, search-parameter rename, or cardinality update should be handled under FHIR-54843 or its applied successor once that work is fully in scope.
