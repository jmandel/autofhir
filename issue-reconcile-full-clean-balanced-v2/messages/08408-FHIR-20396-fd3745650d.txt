FHIR-20396: Fix Questionnaire answerConstraint code reference

Issue request:
FHIR-20396 was Published with a Persuasive with Modification resolution for FHIR-core Questionnaire. It requested removing choice and open-choice from Questionnaire.item.type, adding Coding in their place, adding an answer/choice constraint element with optionsOnly/optionsOrType/optionsOrString-style behavior, and constraining that element to items with answer choices.

Initial application:
Commit ae142a024a99c23b140a4d007595a8e3f1f06d52 applied the R5 change by removing choice/open-choice from the item type code system, adding coding, adding Questionnaire.item.answerConstraint, and creating the QuestionnaireAnswerConstraint code system/value set. The current combined branch had no prior Issue-Reconcile-Key for FHIR-20396.

Additional context:
Questionnaire is an active current-build resource in source/fhir.ini. Current source already uses the final answerConstraint name rather than choiceConstraint, and the active QuestionnaireAnswerConstraint code system defines optionsOnly, optionsOrType, and optionsOrString. However, the active que-10 invariant still compared answerConstraint to the non-existent singular code optionOrString. FHIR-49161 and FHIR-54716 later identified the same typo as a technical correction, and git history shows FHIR-49161 briefly fixed it before FHIR-49226's maxLength date-support edit reintroduced the stale singular spelling while changing the same expression.

AutoFHIR reconciliation:
Updated source/questionnaire/structuredefinition-Questionnaire.xml so que-10 compares answerConstraint to optionsOrString, matching the active required binding and preserving the later FHIR-49226 date/dateTime/time maxLength scope.

Recommendation:
Keep this source fix. It completes the current FHIR-20396 answerConstraint semantics without restoring obsolete choice/open-choice terminology. Do not publish separate reconciliation commits for FHIR-49161 or FHIR-54716 in this default Applied/Published run; they are supporting unresolved technical-correction records for the same typo.
