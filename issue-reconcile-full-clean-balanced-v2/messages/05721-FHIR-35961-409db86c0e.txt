FHIR-35961: Audit DeviceDefinition R4B shelf life compatibility

Issue request:
FHIR-35961 was Published/Persuasive for OO and asked that R4B avoid breaking R4 DeviceDefinition.shelfLifeStorage clients after ProductShelfLife was changed for R4B/R5 work. The accepted resolution was to add a backbone and revert the ProductShelfLife datatype so DeviceDefinition was not affected in R4B.

Initial application:
The issue was applied on the R4B branch, not by changing the current mainline DeviceDefinition model. Git commit 5867a2793cabf3f64156b91eb5761ab57937d3d6 changed R4B PackagedProductDefinition.package.shelfLifeStorage to a local BackboneElement carrying the updated Duration|string shape, and git commit e1ba7be3cb5ea88c283bcc09ed3335260abe3b93 reverted ProductShelfLife itself to the R4 Quantity-based shape so R4B DeviceDefinition remained compatible with R4.

Additional context:
The seed Jira description explicitly expected R5 to stay with the updated ProductShelfLife model. Current HEAD is the active R6/mainline build: source/fhir.ini includes ProductShelfLife, DeviceDefinition, and PackagedProductDefinition; current DeviceDefinition.shelfLifeStorage and PackagedProductDefinition.packaging.shelfLifeStorage both use ProductShelfLife; and current ProductShelfLife.period[x] is Duration|string. Existing combined-branch reconciliations for FHIR-31802 and FHIR-26543 already fixed current ProductShelfLife ModelInfo surfaces while treating FHIR-35961 as R4B-only background.

AutoFHIR reconciliation:
This commit makes no source change. Reapplying the R4B compatibility revert to the current build would incorrectly undo the intended R5/R6 ProductShelfLife model and conflict with later ProductShelfLife decisions. The R4B branch history and meeting record show the requested compatibility work was already applied where it belonged.

Recommendation:
Keep this empty audit commit as-is. No current core source change is needed for FHIR-35961; only revisit if the work group opens a new issue asking current R5/R6 DeviceDefinition to diverge from ProductShelfLife.
