FHIR-32758: Audit external insurance plan type code

Issue request:
FHIR-32758 was a Published/Persuasive Patient Administration correction against FHIR-core ProductPlan/InsurancePlan terminology. It reported that the InsurancePlanType value set had one uppercase code, "Drug", while the other insurance plan type codes were lowercase, and the accepted resolution was to update the value set so the code is "drug".

Initial application:
No FHIR-core commit was found that mentions FHIR-32758. The historical core CodeSystem source did contain code="Drug", but commit 5c0494aacf deleted source/insuranceplan/codesystem-insuranceplan-type.xml during the Phase 1 UTG content removal before this Jira was created. The Jira comment says a UTG submission was created, and UP-344 is the implemented UTG proposal that includes FHIR-32758.

Additional context:
ProductPlan has since been renamed to InsurancePlan, and the current build includes active InsurancePlan and InsuranceProduct resources. Current core value set sources do not enumerate the affected concepts; source/insuranceplan/valueset-insuranceplan-type.xml and source/insuranceproduct/valueset-insuranceproduct-type.xml both compose from http://terminology.hl7.org/CodeSystem/insurance-plan-type. UP-344 comments state that the old 'Drug' code was retired and a new 'drug' code was created in that THO CodeSystem. Current THO/package evidence shows active code "drug" and legacy code "Drug" marked retired/inactive, so the remaining uppercase string is compatibility metadata/display text rather than the active code requested by FHIR-32758.

AutoFHIR reconciliation:
This commit intentionally makes no FHIR-core source change and records an external-repo decision. The source of truth for the affected code is UTG/THO, not the current FHIR-core checkout, and the current core sources already reference the corrected external terminology artifact.

Recommendation:
Keep this audit commit as-is for FHIR core. If future work needs to alter insurance-plan-type concepts, make the change through UTG/THO; if stale rendered expansions show the retired uppercase code unexpectedly, refresh or configure the terminology expansion rather than editing core value set source.
