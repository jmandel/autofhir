FHIR-8003: Audit operation examples application

Issue request:
FHIR-8003 was a Published/Persuasive FHIR-core change request from the DSTU1 cycle asking that each FHIR-defined operation include an example on its page, specifically calling out the Validate a Resource operation needing a full URL with parameters and an example response.

Initial application:
The issue was applied in the 2015 source history by commits cfcf4590696ecabe6964951fc1eb96205920ee77 ("8003 - operation examples") and a6347c9d19ccb2d51d47563102aaf84a2ae08c49 ("8003 - complete operation examples"), matching the Jira comment that the work was done in SVN revisions 5839 through 5841. Those commits added operation request/response example files, operation page/template support, and operation metadata for the operation set that existed at the time.

Additional context:
The current build still has OperationDefinition as an active resource in source/fhir.ini, and operation examples are now carried as build example extensions on operationdefinition-*.xml source files. The Validate a Resource operation still references request and response examples, and those example files still exist. A current inventory of listed operations found 41 operation-list references, with 39 carrying build example extensions; the two without extensions are later/special-case operations (Resource $graphql, introduced after FHIR-8003, and RequestOrchestration $apply, added by later FHIR-34265 work), so they should not be authored under this DSTU1 issue without a separate current work-group decision.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The 2015 request was already applied, and using FHIR-8003 to create new examples for unrelated later operations would exceed the issue's applied scope.

Recommendation:
Keep this no-change audit. If the work group wants every later operation to have request/response examples, track Resource $graphql and RequestOrchestration $apply separately rather than reopening the completed DSTU1 FHIR-8003 application.
