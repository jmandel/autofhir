FHIR-34348: Audit DeviceDefinition UDI label production identifiers

Issue request:
FHIR-34348 was a Published/Persuasive with Modification OO change request for R5 asking DeviceDefinition to capture whether production identifiers are included in UDI labeling for traceability. The approved resolution requested productionIdentifierInUDI 0..* code, indicating the production identifier(s) expected to appear in the UDI carrier on the device label, with an extensible binding containing lot-number, serial-number, manufactured-date, expiration-date, biological-source, and software-version.

Initial application:
The issue was applied in source history. Commit a6b6ef24d89242c1bd430f7c73a963856a2b8e79, titled #34348, added the element; commit 5bcd0301a3b10ea179804e72e69f1cafa3975bbb corrected the path from DeviceDefinition.material.productionIdentifierInUDI to DeviceDefinition.productionIdentifierInUDI; commits 3877ba2aec57052097910f011950241d6e752dff and f8399864d57188dd3a13a2802952ea383d6c6c77 added/renamed the supporting code system and value set files and aligned the short name. Later canonical cleanup kept the source artifacts under the current device-productidentifierinudi names.

Additional context:
DeviceDefinition is an active core resource in source/fhir.ini, so source/devicedefinition/structuredefinition-DeviceDefinition.xml and its companion value set/code system files are in current build scope. Current source contains DeviceDefinition.productionIdentifierInUDI as 0..* CodeableConcept with the requested definition and an extensible binding to http://hl7.org/fhir/ValueSet/device-productidentifierinudi; the companion code system contains all six requested concepts and the value set includes that system. The original request's code datatype was superseded by later Applied FHIR-43167 work, which changed the element to CodeableConcept, made the binding extensible, and added jurisdictional guidance; that related issue is already represented on the combined branch by commit 02ba4bbddd7a897a1469fc94de25f82388e214e5. FHIR-55255 is related later terminology background but is only Resolved - change required and is not an Applied/Published current-build decision for this seed.
