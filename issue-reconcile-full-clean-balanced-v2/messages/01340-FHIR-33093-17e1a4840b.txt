FHIR-33093: Audit ContributorRole author display

Issue request:
FHIR-33093 was a Published CDS R5 change request resolved Persuasive with Modification. It asked to change the ContributorRole author code display to "Author/Creator" and its definition to "An entity primarily responsible for making the resource, often called author or creator", with similar definitional detail added to the other codes in the code system/value set used by Citation.citedArtifact.contributorship.entry.role.

Initial application:
The request was applied by git commit e7d479cbe3978099d0b9c16201c07a2f3019dd0c, which changed source/citation/codesystem-contributor-role.xml so author had display "Author/Creator" and the requested definition, and also replaced the placeholder definitions for publisher, reviewer, endorser, editor, informant, and funder with descriptive definitions.

Additional context:
The request originated from the ContributorRole portion of FHIR-32322, whose comments state that all non-CitationArtifactClassifier concepts were handled in other trackers. Current R5 release-history artifacts still contain the requested ContributorRole content. Later, commit caa1fb75adbcca96f92873c7d958e31f547124bb removed the Citation terminology code system/value set source files from core as part of moving code system definitions out of the base FHIR specification, and commit 71567db3ee039ac6977be5f96a7e013896569a36 removed the Citation resource source from the current build. The current source/fhir.ini active resource and terminology sections do not include Citation or contributor-role, and current narrative says the Citation Resource moved from the FHIR specification to the Evidence Based Medicine on FHIR Implementation Guide. The current terminology.hl7.org CodeSystem/contributor-role JSON still has author display "Author/Creator" with the requested definition.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The requested R5 terminology change is already preserved in the FHIR release-history surface and the current THO terminology surface, while there is no active core ContributorRole or Citation source in the current build to edit.

Recommendation:
Keep this no-change audit commit as-is for FHIR core. If future work changes ContributorRole, it should be handled in the external terminology source of truth or the EBM IG/Citation maintenance stream rather than by reintroducing inactive core Citation terminology files.
