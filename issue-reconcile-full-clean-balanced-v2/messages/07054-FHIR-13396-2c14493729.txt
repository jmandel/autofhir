FHIR-13396: Audit BodyStructure rename application

Issue request:
FHIR-13396 was a Published/Persuasive OO change request from STU3 to rename the BodySite resource to BodyStructure, because the resource needed to represent things such as tumors rather than only anatomical locations, and to align affected body-site extensions.

Initial application:
The issue was applied in the historical source before this reconciliation. Commit 386071a8e535114ff8df5ae7611b966cf354b3cb renamed the active resource entry, resource folder, examples, resource pages, extension references, and related narrative from BodySite/bodysite/body-site-instance to BodyStructure/bodystructure/body-structure. Commit ca3c7d832757cc1f958071ec5788462aea3c0cb0 then added BodySite to the removed-resource list. Commit cc0dad0855c57bc2eee75736c3e72867c6635930 preapplied the tightly related BodyStructure morphology/location work from FHIR-13394.

Additional context:
Current source/fhir.ini lists bodystructure=BodyStructure as an active resource and keeps BodySite only in the removed-resource/R2-rename compatibility areas. The current BodyStructure source uses the BodyStructure canonical URL, name, title, examples, and narrative. Remaining bodySite/body-site strings checked during this reconciliation are anatomical-site element/search-parameter/value-set names, legacy compatibility metadata, or extension-pack definitions whose current value targets BodyStructure rather than a BodySite resource. The referenced Zulip thread supports the rename rationale, while no direct Confluence references to FHIR-13396 were found.

AutoFHIR reconciliation:
No source files were changed. The current built core source already implements the requested BodySite-to-BodyStructure rename and the relevant current extension/package evidence does not show a remaining core source defect.

Recommendation:
Keep this audit commit as-is. If future work wants to revisit bodySite extension canonical naming, do it as an extension-pack or compatibility policy question rather than as a core BodySite resource rename fix.
