FHIR-12631: Audit MedicationAdministration onBehalfOf history

Issue request:
FHIR-12631 was a Published/Persuasive Pharmacy change request for DSTU2 asking that MedicationAdministration.onbehalfof be part of the MedicationAdministration.performer backbone element rather than a top-level element. Jira records the issue as auto-approved and applied to correct an initial addition that was not added correctly.

Initial application:
The problem was introduced by the MedicationAdministration workflow harmonization work in FHIR-12387, where commit 7003eba added a top-level MedicationAdministration.onBehalfOf while also introducing MedicationAdministration.performer as a backbone. Commit 6aceb453 then applied FHIR-12631 by changing MedicationAdministration.onBehalfOf to MedicationAdministration.performer.onBehalfOf in the spreadsheet source.

Additional context:
A later Published/Persuasive with Modification workflow-alignment issue, FHIR-14022, was applied by commit b22fbda and removed MedicationAdministration.performer.onBehalfOf while reshaping performer around function and actor. The current active MedicationAdministration StructureDefinition therefore has performer.function and performer.actor but no onBehalfOf child. The resource is active in source/fhir.ini, and a current-source search found no MedicationAdministration onBehalfOf element remaining to correct. Zulip/Confluence searches found only bot/commit references and no substantive community record conflicting with the Jira/source history.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The seed issue was already applied historically, and the absence of MedicationAdministration.performer.onBehalfOf in the current build reflects a later applied workflow-alignment decision rather than an unapplied FHIR-12631 defect.

Recommendation:
Keep this no-change audit as-is. Do not reintroduce MedicationAdministration.performer.onBehalfOf for FHIR-12631 without a new Pharmacy/workflow decision that supersedes the later FHIR-14022 alignment.
