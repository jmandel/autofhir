FHIR-13210: Audit ICD modifier syntax handoff to THO

Issue request:
FHIR-13210 was Published/Persuasive for STU3 and asked the ICD guidance to stop implying that dagger, asterisk, and ICD-10-GM exclamation modifiers should be omitted from Coding.code. The accepted motion was to document allowable ICD syntax, including dagger-asterisk, *, !, and other identified syntaxes, on the Using ICD-[x] guidance page.

Initial application:
The issue was applied in core by SVN-derived commits baa02c5372, 4a70358229, and 5bd3a27120 on 2018-04-02, which added multiple-coding guidance to source/icd.html including the J21.8+ B95.6* and S62.32 Z33! examples. There was no missing FHIR-13210 source hunk in the current checkout because source/icd.html was later removed from the core build.

Additional context:
FHIR-35933 later moved the Using X external code-system pages out of FHIR core and into HL7 Terminology. Current FHIR core keeps an active terminology table row for ICD that links implementers to https://terminology.hl7.org/ICD.html, while the language-specific THO page at https://terminology.hl7.org/en/ICD.html contains the FHIR-13210 modifier guidance. Community searches found no later Zulip or Confluence evidence contradicting that handoff.

AutoFHIR reconciliation:
This audit commit intentionally makes no FHIR core source change. The current core source correctly delegates ICD usage details to THO, and the authoritative THO ICD page already preserves the dagger/asterisk and ICD-10-GM ! syntax requested by FHIR-13210.

Recommendation:
Keep this empty external-repo audit commit. Future editorial or terminology changes to the detailed ICD modifier guidance should be made in the THO/UTG source, not by restoring source/icd.html or duplicating the same rules in FHIR core.
