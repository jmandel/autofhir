FHIR-17255: Audit MedicationRequest therapy course element

Issue request:
FHIR-17255 was a Published/Persuasive with Modification Pharmacy change request raised against STU3 MedicationPrescription/MedicationRequest. It requested a long-term medication indicator by adding a 0..1 MedicationRequest course-of-therapy attribute with values for continuous long-term therapy, short-course acute therapy, and seasonal therapy, plus a note not to confuse the attribute with medication protocol.

Initial application:
The Jira comment says the issue was applied on 2018-07-25. Git commit ce698b9ee5288dac0d1f13735b92bb16a46c008d explicitly included GF 17255 and added MedicationRequest.courseOfTherapyType, the requested definition/comment, cardinality, CodeableConcept type, and a course-of-therapy codelist in the then-authoritative MedicationRequest spreadsheet. Git commit 7373e742ee4ae5907dc0d8b0779cadb0cb0892f0 then materialized the course-of-therapy CodeSystem and ValueSet files with continuous, acute, and seasonal concepts; later source refactors carried the element into source/medicationrequest/structuredefinition-MedicationRequest.xml.

Additional context:
MedicationRequest is active in source/fhir.ini, and MedicationPrescription is recorded there as having become MedicationRequest. The current StructureDefinition source still has MedicationRequest.courseOfTherapyType as a 0..1 CodeableConcept with the requested definition and protocol warning, and the current ValueSet source points at the medicationrequest-course-of-therapy terminology system. The original example binding should not be restored because later Published Pharmacy issue FHIR-32489 resolved to make this same binding extensible; FHIR-32489 and the typo cleanup FHIR-20181 are already represented by audit commits on the combined branch.
