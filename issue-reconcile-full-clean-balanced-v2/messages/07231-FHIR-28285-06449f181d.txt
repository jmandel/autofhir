Issue request:
FHIR-28285 was Published/Persuasive for FHIR-core after an R4 report that example bindings should not be allowed on code elements. The accepted FHIR-I resolution was to update tooling so every code element must have a required binding unless it has a maximum binding, where extensible is allowed.

Initial application:
