FHIR-5508: Audit MedicationStatement information source

Issue request:
FHIR-5508 was a Published/Persuasive with Modification Pharmacy ballot issue for DSTU1 MedicationStatement. It asked that the practitioner responsible for an original medication reconciliation entry be clearly identifiable, and the final resolution rejected adding MedicationStatement.author for that purpose while agreeing to add MedicationStatement.informationSource to capture where the statement information came from.

Initial application:
No current git commit explicitly mentions FHIR-5508. The closest historical application is abce09d8c1edffa07e8bd6fbdf60eaa097da3d91, committed one day after the Jira comments, whose "Pharmacy updates based on recent ballot" spreadsheet change added MedicationStatement.informationSource as 0..1 Reference(Patient | Practitioner | RelatedPerson) with the definition "The person who provided the information about the taking of this medication." The current resource source is now the StructureDefinition XML rather than the old spreadsheet.

Additional context:
MedicationStatement is active in the current build through source/fhir.ini. The current StructureDefinition contains MedicationStatement.informationSource with source-oriented wording and target profiles for Device, Patient, Practitioner, PractitionerRole, RelatedPerson, Organization, and Group. It also now contains MedicationStatement.author, but that is not a stale reversion of FHIR-5508: later Applied issue FHIR-41760 explicitly decided that informationSource remains the information source while author should be a separate MedicationStatement element. FHIR-41500, already represented on the combined branch by an AutoFHIR reconcile commit, further clarified the informationSource wording after adding Device.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current authoritative source preserves the FHIR-5508 informationSource concept, and the later author element is supported by a separate final Pharmacy decision rather than contradicting the 2015 resolution.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-5508 in core FHIR unless a future Pharmacy decision changes the distinction between informationSource and author.
