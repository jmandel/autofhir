FHIR-11303: Audit infant body length handling

Issue request:
FHIR-11303 was a Published/Persuasive FHIR-core OO change request from the DSTU2 vital-signs page asking that infant height be represented using the clinically appropriate body length / Body height lying down terminology, with the resolution to add this in alignment with US Core Vital Signs.

Initial application:
No current git commit explicitly mentions FHIR-11303. The closest application trail is the vital-signs work around the 2016-11-03 vote: 0ae70da2 aligned Observation vital signs with US Core the next day and included the separate Body length / 8306-3 profile/table material. Earlier draft vital-signs source already had 8306-3, so the issue appears to have confirmed and retained body length handling rather than introducing it from nothing.

Additional context:
Later issue FHIR-13801 questioned the separate Body length profile but was resolved No Change because body length remained clinically relevant for pediatric measurements. FHIR-17540 then made the more precise current decision: remove the separate Body length line/profile treatment and fold 8306-3 Body height - lying into Body height as an additional Observation.code coding. OO minutes from 2018-07-26 record the same "Remove body-length, and add to body height" decision. FHIR-32787 later clarified the vital-signs table wording and preserved the 8306-3/body length guidance as an Observation.code specialization.

AutoFHIR reconciliation:
This is an empty audit commit. The current build-scoped Observation vital-signs source already says 8306-3 Body height - lying, i.e. body length typically used for infants, may be used in Observation.code; the body-height profile binding description includes body length; the body-height value set is named and described for body height including body length; and a body-length example carries both 8306-3 and the general 8302-2 Body height coding. Reintroducing a separate body-length profile or row would conflict with the later FHIR-17540 reconciliation.

Recommendation:
Keep this audit commit as-is. No core source change is needed for FHIR-11303; future work should only revisit this if OO changes the post-FHIR-17540 policy that infant body length is represented as a more specific coding under the Body height vital-sign profile.
