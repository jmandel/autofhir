FHIR-16097: Audit BDP processing clarification

Issue request:
FHIR-16097 was Published/Persuasive for the Orders and Observations BiologicallyDerivedProduct resource. It asked for an example use case because the distinction between processing and manipulation was unclear; the decisive Jira comment distinguishes processing that does not change the product's fundamental nature, such as adding anti-coagulants during PBSC collection, from manipulation intended to alter the product, such as buffy-coat enrichment or CD8 reduction.

Initial application:
The Jira comment identifies commit b4bd0b1, and that commit updated the then-active BiologicallyDerivedProduct spreadsheet definitions for `.processing` and `.manipulation` with those exact explanatory examples. No current source change is needed to complete that initial application.

Additional context:
Later Published/Persuasive-with-Modification issue FHIR-33068 replaced the BDP attribute set for R5 and commit a261b7c666 removed the old core `.processing` and `.manipulation` backbone elements while adding generic `property` support. The current core resource is active in `source/fhir.ini`, and its StructureDefinition contains `processingFacility`, `collection`, and `property` but no separate `.processing` or `.manipulation` elements. The old processing/manipulation concepts now exist as Extension Pack definitions, where the clarifying FHIR-16097 examples are still present.
