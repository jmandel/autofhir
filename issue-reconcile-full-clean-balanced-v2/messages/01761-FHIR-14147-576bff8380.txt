FHIR-14147: Audit ImagingStudy subject reconciliation

Issue request:
FHIR-14147 was Published with a Persuasive with Modification resolution for STU3 ImagingStudy. It requested renaming ImagingStudy.patient to subject, allowing Device and Group as subject targets alongside Patient, and representing whole-slide imaging specimens with a new series-level 0..* Reference(Specimen) element rather than by adding Specimen to the study subject.

Initial application:
The change appears to have been applied in git commit d21acd48143d1cbe35a35616864c97839b13a361, which explicitly mentions GF#14147 and changed the ImagingStudy source spreadsheet from ImagingStudy.patient to ImagingStudy.subject with Reference(Patient|Device|Group), added ImagingStudy.series.specimen, and updated examples from patient to subject. Later source refactors moved the authoritative resource definition into source/imagingstudy/structuredefinition-ImagingStudy.xml.

Additional context:
ImagingStudy is an active current-build resource in source/fhir.ini. The current StructureDefinition has ImagingStudy.subject as 1..1 Reference(Patient, Device, Group) with the expected patient/phantom/group semantics, and has ImagingStudy.series.specimen as 0..* Reference(Specimen). The legacy ImagingStudy-patient search parameter intentionally searches only Patient-valued subjects, which is consistent with later search-parameter work such as FHIR-32876; the separate ImagingStudy-subject search parameter covers the broader subject reference.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current build-scope source already implements the published FHIR-14147 resolution, and changing the legacy patient search parameter or adding Specimen to ImagingStudy.subject would conflict with the modified resolution and later search-parameter context.

Recommendation:
Keep this audit commit as-is. No follow-up is needed for FHIR-14147 in the core FHIR source unless a future work group decision changes the subject or specimen model.
