FHIR-33389: Audit Observation device settings guidance

Issue request:
FHIR-33389 was a Published/Persuasive with Modification R5 change request asking how to store device-related parameters when executing a procedure. The final OO decision moved the change from Procedure to Observation: add device settings, such as mechanical ventilator parameters, to Observation Scope and Usage and update Observation.device so it covers the device generating measurements or device settings.

Initial application:
The issue was applied in git commit 63183dbbcb ("FHIR-33389"), which changed source/observation/observation-introduction.xml and source/observation/structuredefinition-Observation.xml. The current Observation source still contains the device settings bullet and the requested Observation.device short/definition text.

Additional context:
Observation is an active resource in source/fhir.ini, so these source files are build-scope inputs. OO minutes on 2023-01-26 record the accepted disposition and clarify that the ticket moved from Procedure to Observation with text-only instructions for device settings. Related FHIR-37972 was later resolved No Change, saying device settings are supported as described in FHIR-33389 while broader quantity, route, and supply placement questions should be handled as targeted tickets. Direct Zulip search for FHIR-33389 found no conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source changes because the current build-scope Observation source already reflects the published resolution. Adding more Procedure or Device prose would exceed the accepted FHIR-33389 scope and duplicate or reopen topics reserved for later targeted issues.

Recommendation:
Keep this audit commit as-is. Future work, if any, should be filed as targeted tickets for the unresolved Procedure quantity/route/supply use cases rather than altering the already-applied FHIR-33389 Observation guidance.
