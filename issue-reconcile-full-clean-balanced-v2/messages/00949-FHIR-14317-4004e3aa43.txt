FHIR-14317: Audit DiscreteVariant profile as external IG work

Issue request:
FHIR-14317 was a Published FHIR-core Observation change request, resolved Persuasive with Modification, asking to create a "DiscreteVariant" profile under the STU3 Observation-genetics profile. The requested content included Sequence derivedFrom linkage, LOINC-coded discrete-variant, variant-assessment, and variant-analysis method elements, plus VariantChange, GenomicLocation, AllelicState, and AminoAcidChange component groups. The accepted resolution said the request was already applied using the DescribedVariant profile in the Genomics Reporting IG.

Initial application:
No FHIR-core git commit in this checkout mentions FHIR-14317, DiscreteVariant, DescribedVariant, or obs-described-variant. Core history shows the older Observation-genetics material was updated separately in 2018 and then removed from core as outdated clinical genomics artifacts in 2020. Current source/fhir.ini has active Observation and DiagnosticReport resources and profile configuration, but no active Observation-genetics, DiscreteVariant, or DescribedVariant profile entry. The substantive application was therefore outside core, as the Jira resolution and Clinical Genomics WGM minutes state.

Additional context:
Current FHIR core narrative for genomics, Observation, and DiagnosticReport directs implementers to the Genomics Reporting IG for structured genomic data instead of defining local Observation-genetics profiles. The FHIR Extension Pack copy of the old observation-geneticsVariant extension is retired/deprecated and states it has been replaced by profiles and extensions in the Genomics Reporting Guide. The current Genomics Reporting IG build exposes an active Variant Observation profile as the successor locus for this family of variant content. Related component-group issues FHIR-14319, FHIR-14320, FHIR-14322, and FHIR-14323 are FHIR-genomics-reporting issues; the neighboring core StructuralVariant request FHIR-14318 has already been audited on the combined branch as external IG work.

AutoFHIR reconciliation:
This empty audit commit makes no FHIR-core source change. Recreating a DiscreteVariant/Observation-genetics profile in core would be out of current build scope and would conflict with the accepted resolution that placed the requested content in the Genomics Reporting IG.

Recommendation:
Keep this audit commit as-is. Future corrections to discrete-variant modeling should be made in HL7/genomics-reporting or the published Genomics Reporting IG, not in the FHIR core checkout, unless the Clinical Genomics work group explicitly moves this content back into core.
