FHIR-43527: Audit ImplementationGuide scope wording

Issue request:
FHIR-43527 was an Applied/Persuasive FHIR-I R6 change request for the ImplementationGuide Scope and Usage page. It said the sentence ending "so that the logical package that the IG represents, so that the contents are computable" was unclear, and its resolution approved replacement wording explaining that ImplementationGuide defines IG content and entry pages as a single logical package so the contents are computable for publication, validation, registry look-up, and other uses.

Initial application:
The malformed text was originally introduced by older ImplementationGuide explanatory prose. Commit b32b2939b34eb543e75cad02bf187663b33a061b partially applied FHIR-43527 by replacing the unclear tail of the sentence, and commit 5ac21ed0d23493bde9815dba537d9cb0048132df, "FHIR-43527 Sentence not clear," then replaced the paragraph with the current wording that matches the Jira resolution while preserving readable line wrapping.

Additional context:
The implementationguide resource is active in source/fhir.ini, so source/implementationguide/implementationguide-introduction.xml is in current build scope for the ImplementationGuide page. FHIR-I minutes from 2024-03-04 record the 9-0-0 persuasive vote for FHIR-43527 and state that the same resolution also applies to FHIR-44129. The combined branch already contains an audit commit for FHIR-44129, but it lists FHIR-43527 only as related evidence and does not carry an Issue-Reconcile-Key for this seed.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. Keep this no-change audit commit. No further core source work is needed for FHIR-43527 unless the work group later reopens the surrounding ImplementationGuide Scope and Usage text.
