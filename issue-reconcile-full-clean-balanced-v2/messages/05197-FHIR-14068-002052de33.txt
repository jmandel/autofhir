FHIR-14068: Audit ConceptMap translate example correction

Issue request:
FHIR-14068 was a Published/Persuasive STU3 Vocabulary change request for FHIR-core ConceptMap. It reported that the ConceptMap $translate example incorrectly used the `valueSet` input parameter for the source context and should use `source` instead.

Initial application:
No Jira-keyed FHIR-14068 implementation commit was found in git history. The relevant source history shows that source/conceptmap/$translate-request.txt originally used `valueSet` in the 2015 operation example, commit 86db0921cc changed that parameter to `source` in December 2017, and commit 1c78b00bec removed the stray space after `source=` in March 2018, matching the Jira comment that the issue was already fixed.

Additional context:
ConceptMap is an active current-build resource in source/fhir.ini, and the $translate OperationDefinition includes source/conceptmap/$translate-request.txt as the request example. Later ConceptMap revisions renamed the STU3 `source` and `target` value-set context parameters to `sourceScope` and `targetScope`, and FHIR-41175 later harmonized source-side code/system example names to `sourceCode` and `sourceSystem`. The active Terminology Service narrative now uses the same source-prefixed and scope-prefixed request names. Zulip and Confluence searches found no FHIR-14068-specific community record that changes this conclusion; the relevant Zulip hit uses the corrected R4 `source` parameter and treats that request shape as valid.

AutoFHIR reconciliation:
Made no source change. The current authoritative ConceptMap operation example and the active Terminology Service narrative no longer contain the erroneous `valueSet` request parameter and now use the current `sourceScope` / `targetScope` names defined by the OperationDefinition.

Recommendation:
Keep this no-change audit commit as-is. No core follow-up is needed for FHIR-14068 unless a future ConceptMap $translate change intentionally revisits the current `sourceScope` / `targetScope` parameter names.
