FHIR-18324: Audit Patient FiveWs mapping link

Issue request:
FHIR-18324 was a Published/Persuasive STU3 technical correction for the Patient mappings page. It reported that the FiveWs mapping link in section 8.1.15.1 pointed to http://hl7.org/fhir/fivews and produced an HL7 404, and requested a corrected working link.

Initial application:
Jira records Grahame Grieve's 2018-11-08 comment that the issue was fixed. No commit explicitly mentioning FHIR-18324 was found, but the adjacent historical commit fc4ada05433e0fb0f903d430fef9cc70ad1a4119, titled "GF#18326 - fix mapping spaces links", added source/mappingSpaces.xml link entries for mapping spaces, including mapping http://hl7.org/fhir/fivews to http://hl7.org/fhir/fivews.html. That shared mapping-space source feeds the Patient mappings tab because Patient declares the FiveWs mapping identity.

Additional context:
Patient is an active current resource, FiveWs is an active current logical pattern, and the current source intentionally separates the canonical mapping-space URL from the human-facing rendered link. The canonical Patient mapping URI remains http://hl7.org/fhir/fivews, while source/mappingSpaces.xml supplies the reader-facing http://hl7.org/fhir/fivews.html link. The related sibling mapping-link issue FHIR-18326 is already represented on the combined branch; FHIR-18323 concerns a separate same-section CSS/link-visibility report and was not decided here.

AutoFHIR reconciliation:
No source change was made. The active source already contains the necessary mapping-space link, and changing the StructureDefinition mapping URI itself would conflate the stable mapping identifier with the rendered documentation target. The current build.fhir.org Patient mappings page renders the FiveWs heading link to http://hl7.org/fhir/fivews.html, and that target resolves.

Recommendation:
Keep this audit commit as-is. Further work is only needed if the FHIR publication tooling changes how mapping-space links are rendered globally; there is no Patient-specific source correction needed for FHIR-18324.
