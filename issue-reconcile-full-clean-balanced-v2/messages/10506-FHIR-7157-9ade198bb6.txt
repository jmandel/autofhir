FHIR-7157: Audit Observation code focus guidance

Issue request:
FHIR-7157 was a Published/Persuasive OO clarification from the 2015 May DSTU1 ballot. It asked to add text to the Observation.subject comment saying that the distinction between the patient's own value for an observation and that of a fetus, donor, blood product unit, etc. is often specified in Observation.code.

Initial application:
The issue was historically applied in git commit 89739dcf150cb051d4f4a26d48e1a827649c9af5, which edited source/observation/observation-spreadsheet.xml for #7152, #7155, and #7157 and appended the requested "patient's own value ... fetus ... donor or blood product unit" sentence to the old Observation.subject comment. Later source history, especially 8da41eb1e5b69c9ac8d6b759ba1c88e9d892b881, removed that exact DSTU1 comment wording while replacing it with the current subject/focus model: when the actual focus differs from the subject, Observation.focus or Observation.code itself specifies the focus.

Additional context:
Observation's subject/focus semantics changed after DSTU1. FHIR-14443 promoted the old focal-subject extension concept into the Observation.focus element, and later decisions such as FHIR-43357 approved the current focus wording and examples. On the latest combined branch, Observation is active in source/fhir.ini, Observation.subject says that `focus` or `code` itself specifies the actual focus when it differs from the subject, and the Observation notes say the distinction between the subject and what is directly measured is specified in Observation.code itself and need not be represented separately. FHIR-7156, the sibling donor/fetus wording issue from the same old comment family, is already represented on the combined branch by a no-change audit commit.

AutoFHIR reconciliation:
This audit commit makes no source change. The current build-scope source already conveys the implementer-relevant rule requested by FHIR-7157 in generalized, current-model terms. Re-adding the exact DSTU1 fetus/donor/blood-product-unit sentence to Observation.subject would duplicate the current notes and risk reviving obsolete indirect-target wording instead of improving conformance guidance.

Recommendation:
Keep this no-change audit as-is. No core source follow-up is needed for FHIR-7157 unless OO decides a new, specific blood-product or fetus/donor example is needed in the modern Observation.focus/code guidance.
