FHIR-14282: Audit moved Questionnaire StructureMap extensions

Issue request:
FHIR-14282 was Published/Persuasive for STU3. It asked to clarify the Questionnaire sourceStructureMap and targetStructureMap extension descriptions so the maps are described as using QuestionnaireResponses for/of the Questionnaire, not the Questionnaire resource itself, as the transform source or target.

Initial application:
No core commit was found that mentions FHIR-14282 directly. The relevant text was nevertheless applied during the Questionnaire extension move work: core commit 9b1695bfd4, merged by ecdd7d61, removed the sourceStructureMap and targetStructureMap rows from the core Questionnaire extension spreadsheet with the clarified FHIR-14282 wording already present, and SDC commit 91958f6 added the moved SDC definitions with that clarified wording.

Additional context:
FHIR-19527 was Published/Persuasive with Modification and explicitly moved questionnaire-sourceStructureMap and questionnaire-targetStructureMap, among other complex Questionnaire extensions, from core to the SDC IG. That related issue is already represented on the combined branch by commit 5babcfe4755f2e5c5b3d03460d570ed25778052c, so this reconciliation does not publish another FHIR-19527 commit. In the current core checkout, Questionnaire and QuestionnaireResponse are active resources, but the exact old extension ids appear only in tools/history/release3/extension-definitions.xml, a frozen historical artifact, and not in active core source or fhir.ini extension/profile references. The current active SDC source defines sdc-questionnaire-sourceStructureMap and sdc-questionnaire-targetStructureMap with the clarified QuestionnaireResponse-focused wording.

AutoFHIR reconciliation:
Published this empty audit commit because the current FHIR core build no longer owns the active extension definitions. Editing tools/history/release3/extension-definitions.xml would change historical generated STU3 material rather than a current build input, while the active SDC definitions outside this checkout already carry the clarified semantics.

Recommendation:
Keep this commit as an external-repo audit. No core source change is needed for FHIR-14282; any future editorial cleanup of the active wording, such as improving the grammar of the SDC sourceStructureMap sentence, belongs in the HL7/sdc IG rather than in this FHIR core repository.
