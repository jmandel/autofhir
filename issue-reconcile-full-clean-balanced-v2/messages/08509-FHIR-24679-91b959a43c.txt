FHIR-24679: Audit FHIR homepage IG registry link

Issue request:
FHIR-24679 was a Published FHIR-core change request, resolved Persuasive and auto-approved for R5, reporting that the build.fhir.org home page bottom-left link labeled "Published by HL7, Affiliates & FHIR Foundation" to http://www.fhir.org/guides/registry was broken because it redirected to http://fhir-org.fhir-ehws.net.au/guides/registry/.

Initial application:
No source commit that explicitly mentions FHIR-24679 was found. The historical homepage link family was changed in stages: c5859b35be6074438d35c3d28b104350d4054c73 introduced the guides/registry destination for the old visible label, and bc0c3d8207aaec46b99155b3946a776e4d3c545c later replaced the old "Published by HL7, Affiliates & FHIR Foundation" homepage label with "Curated list of Implementation Guides" and added registry.fhir.org to the same homepage link cluster. The same-change-family audit for FHIR-20734 is already on the combined branch and documents the broader homepage registry-link correction.

Additional context:
The current active homepage source no longer contains the obsolete visible label or the obsolete fhir-org.fhir-ehws.net.au host. A directly relevant 2019 Zulip thread with the same "Published by HL7, Affiliates & FHIR Foundation" text indicates the problem was with the external fhir.org registry page behavior in some browsers, not with a current FHIR source target. Current link checks show the fhir.org/guides/registry URLs now redirect to HTTPS and return 200. FHIR-23809 mentioned a similar fhir-org.fhir-ehws redirect from modules.html among many typo issues and is also already represented on the combined branch, so it was not re-decided here.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current source/index.html homepage Implementation Guides section uses current labels and links to http://www.fhir.org/guides/registry, https://registry.fhir.org/, and https://packages2.fhir.org/xig, and no current source refers to the obsolete fhir-org.fhir-ehws.net.au target reported by the issue.

Recommendation:
Keep this audit commit as-is. No current FHIR core source edit is needed for FHIR-24679; if the external fhir.org registry page or redirects break again, that should be handled as website/infrastructure work outside this source tree rather than by changing the current specification source.
