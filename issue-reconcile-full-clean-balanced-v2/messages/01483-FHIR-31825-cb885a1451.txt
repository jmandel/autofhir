FHIR-31825: Audit SubstanceDefinition source rename

Issue request:
FHIR-31825 was Published/Persuasive with Modification for the BR&R SubstanceSpecification/SubstanceDefinition resource. It asked why the top-level literature reference was named source, and the accepted resolution was to rename the attribute to informationSource and change its target from DocumentReference to Citation.

Initial application:
The issue was applied by commits 0843635693167b180dacb358114b3257715f78c3 and 08d35148dd0fa3866502882e1805fe34cb107da4, which changed SubstanceDefinition.source to SubstanceDefinition.informationSource and changed the reference target from DocumentReference to Citation. BR&R WGM minutes also record FHIR-31825 as changing Source to InformationSource with a 13-0-0 vote.

Additional context:
SubstanceDefinition is still an active current-build resource in source/fhir.ini, but the current authoritative SubstanceDefinition XML comments out the top-level SubstanceDefinition.informationSource element. Citation is no longer an active core resource, and commit 71567db3ee039ac6977be5f96a7e013896569a36 commented out the Citation-targeted informationSource element while removing Citation from core. A later Zulip committers thread confirms that this element became extension/additional-resource follow-up territory after Citation moved out, not a current core element to rename again.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The original odd top-level SubstanceDefinition.source element is absent from the active current source; the previously applied replacement is retained only in a commented block because its Citation target is outside current core build scope.

Recommendation:
Keep this audit commit as-is for FHIR-core reconciliation. Any future decision to restore the concept as an extension, and whether it should target Citation or DocumentReference, should be handled by the relevant additional-resource or extension-pack work rather than by re-editing the inactive core element for FHIR-31825.
