FHIR-17991: Clarify PaymentNotice search descriptions

Issue request:
FHIR-17991 was Published/Persuasive for the Financial Management PaymentNotice resource and asked to correct the PaymentNotice search descriptions: fix the created search parameter typo from "fro" to "for", and replace the request/response descriptions that only named Claim and ClaimResponse with descriptions of the payment request and response resources.

Initial application:
No commit explicitly mentioning FHIR-17991 was found in the relevant PaymentNotice source history. The 2021 source rework added bundle-PaymentNotice-search-params.xml with the original "Creation date fro the notice", "The Claim", and "The ClaimResponse" descriptions. Commit f4af0bcf79 later corrected only the created typo to "for", leaving the request and response descriptions unchanged.

Additional context:
PaymentNotice is active in source/fhir.ini and the checked search parameter bundle feeds the current PaymentNotice search parameter definitions. Later Jira FHIR-53920, currently Resolved - change required for R6, confirms that "The Claim" and "The ClaimResponse" are ambiguous because PaymentNotice.request and PaymentNotice.response are Reference(Any), and resolves to clarify them as "The request resource" and "The response to the request resource" rather than narrowing the element types. No Zulip or Confluence evidence was found that conflicts with the Jira/source conclusion.

AutoFHIR reconciliation:
Updated source/paymentnotice/bundle-PaymentNotice-search-params.xml so PaymentNotice.request describes "The request resource" and PaymentNotice.response describes "The response to the request resource". The existing created description already says "Creation date for the notice", so no created hunk was needed.

Recommendation:
Keep this source change. It finishes the unapplied portion of FHIR-17991 while aligning the current R6 wording with the later FM work-group clarification in FHIR-53920; do not publish a separate FHIR-53920 decision from this default Applied/Published seed run.
