FHIR-17465: Audit Signature Reference-only signer elements

Issue request:
FHIR-17465 was a Published/Persuasive FHIR-core datatypes change request from the Security work group. It asked to simplify Signature.who[x] and Signature.onBehalfOf[x] to Reference-only elements because Reference can carry Identifier, making the former uri choice unnecessary.

Initial application:
The change was applied before this reconciliation by git commit 9071f6d0d16cb86417520b9023adce221aaff3cf, which changed source/datatypes/signature.xml from Signature.who[x] and Signature.onBehalfOf[x] with uri|Reference choices to Signature.who and Signature.onBehalfOf with Reference-only types. Later source evolution kept the elements Reference-only while adding PractitionerRole to the allowed reference targets and making Signature.who optional.

Additional context:
source/fhir.ini lists Signature as an active datatype and normative, so source/datatypes/signature.xml is the authoritative current build source. The current CQL FHIR model definition also represents FHIR.Signature.who and FHIR.Signature.onBehalfOf as FHIR.Reference. Broad scans found legacy whoUri/onBehalfOfUri only in historical release snapshots and in the separate QUICK example model definition, not in the current FHIR Signature datatype. Jira search found only this final datatype issue plus later Triaged signature narrative rewrite issues, and Zulip/Confluence searches found no directly relevant or conflicting discussion.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current authoritative Signature datatype source already satisfies FHIR-17465 by using non-choice Reference elements for both signer identity and represented party, and nearby current model-definition surfaces are consistent with that result.

Recommendation:
Keep this audit commit as-is. No FHIR core source follow-up is needed for FHIR-17465 unless a future work-group decision reopens the separate, older QUICK model example or one of the later Triaged signature narrative rewrite issues.
