FHIR-13004: Audit removed Condition criticality extension

Issue request:
FHIR-13004 was a Published Patient Care change request, resolved Persuasive with Modification, that started from a request to bind extension-condition-criticality to a value set but was decided by the WG as removal of the extension because it represented an Observation of the patient's current medical state rather than a Condition attribute.

Initial application:
The historical application is commit 25735dcc63a312d77a995ab0d2d8d0ab2ed7f835, whose subject includes "#13004 extension-condition-criticality removed" and whose patch changed the Condition extensions spreadsheet criticality row to "!criticality" with the note "Removed per GF#13004". Later source refactors removed that spreadsheet from the current Condition source set.

Additional context:
The current build scope still includes Condition in source/fhir.ini, but current source/condition contains Condition.severity and related Condition terminology only; it has no condition-criticality extension definition or active fhir.ini profile reference. The FHIR Extension Pack checkout also has no condition-criticality extension, so this is not a core-to-extension-pack move. A Zulip implementers thread records Michelle Miller explaining that the Condition criticality extension was removed per GF#13004 because PC determined it was not an attribute of a specific condition and should instead be represented as an Observation of patient medical state/status.

AutoFHIR reconciliation:
This audit commit intentionally makes no source change. The current core source already reflects the approved removal, and remaining condition-criticality hits are limited to historical release artifacts under tools/history, not current build inputs.

Recommendation:
Keep this no-change audit commit as-is. Do not restore or move the Condition criticality extension in core unless Patient Care makes a new post-R6 decision; any future need for patient status or medical state should be modeled through Observation or a newly approved artifact.
