Initial application:

The source application was PR HL7/fhir#2415 on branch FHIR-14307, merged 2022-09-21, with commits ced07cd59b and 1f9b10954f changing the Encounter.class and Encounter.type short descriptions. The same application path created UTG issue UP-350 for the new Encounter.type value-set proposal.

Additional context:

UP-350 is still unresolved in UTG, so there is no safe core-source terminology edit to make here. Later Encounter decisions, including FHIR-31399 and FHIR-32341, are already represented on the combined branch and do not reverse this clarification.
