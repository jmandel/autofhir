FHIR-45094: Audit Evidence quoted-source guidance

Issue request:
FHIR-45094 was Applied with a Persuasive resolution for R6. It requested a comment on Evidence.relatedArtifact explaining that type derived-from identifies the source of Evidence content and that exact phrasing in the source material can be carried as a classifier coded quotation with the quoted text, plus an extracted-evidence example showing the pattern.

Initial application:
The request was applied by git commit 5482fd364f504c27b57eaebfee0a9ae43af04f9f and merged through HL7/fhir pull request #3077. That commit added the requested Evidence.relatedArtifact comment in source/evidence/structuredefinition-Evidence.xml, added source/evidence/evidence-example-quoted-source.xml with relatedArtifact.type derived-from, classifier quotation text, and a Citation reference, and listed the example in source/evidence/list-Evidence-examples.xml.

Additional context:
FHIR-49758 was later Applied for R6 and replaced RelatedArtifact usage in the EBM resources. Its implementation commit 16e8cfe739612663eb51cf987d198926a137b635 removed Evidence.relatedArtifact from the active Evidence StructureDefinition and added Evidence.citeAs plus Evidence.relatesTo. A follow-up source commit 2f0d2399fdaddbaf742e17ef543cecdcacc81adf removed the active relatedArtifact content from the quoted-source example and left only a commented placeholder for a possible quotation extension. The combined branch already contains the FHIR-49758 reconciliation commit fc05bb85d289e78fed85a04fe2588b260f888bbc, which removed the stale wording that still said the example used relatedArtifact. FHIR-51513 later added a published Extension Pack relatesto-classifier extension because classifier was removed from RelatedArtifact and not replaced in resources using relatesTo, but that extension is outside this core checkout and its current extension source only declares active contexts for RelatedArtifact and Composition.relatesTo while its description discusses R6 Evidence.relatesTo use.

AutoFHIR reconciliation:
This empty audit commit makes no source change. Reintroducing an Evidence.relatedArtifact comment would contradict the current active Evidence model, while automatically changing the example to use an extension-pack classifier or another relatesTo encoding would require work-group confirmation of the intended R6 replacement pattern for exact source quotations.

Recommendation:
Keep this audit commit as a human-review marker. The CDS/EBM work group should decide whether the current quoted-source example should be retired, changed to an active Evidence.relatesTo example using an approved extension-pack pattern, or accompanied by new current-model guidance; do not restore the obsolete Evidence.relatedArtifact text in core.
