FHIR-28151: Audit externalized ImmunizationEvaluation cleanup

Issue request:
FHIR-28151 was Published/Persuasive with Modification for R5. It asked to clean publisher warnings on ImmunizationEvaluation by taking no action on the informational RIM-mapping warning, changing ImmunizationEvaluation.doseStatusReason.short to "Reason why the dose is considered valid, invalid, or some other status", and changing ImmunizationEvaluation.targetDisease.short to "The vaccine preventable disease schedule being evaluated".

Initial application:
The issue was applied in core by git commit f39499ca0d3db1420b7dbe4c688151d38b8744ac, which changed source/immunizationevaluation/structuredefinition-ImmunizationEvaluation.xml. That commit set targetDisease.short to the requested wording and changed doseStatusReason.short to the same intended wording, though with the typo "doese" and without the comma from the Jira text. PHWG meeting notes from 2022-02-18 also record FHIR-28151 as "Persuasive with Mod - applied".

Additional context:
The current core branch no longer builds ImmunizationEvaluation. Commit e073fb45ec6f5a738a9f674baf63406bfe90fb78 removed source/immunizationevaluation and deleted the active fhir.ini resource/workgroup/security/FMM/type/status entries for ImmunizationEvaluation. Current core pages link ImmunizationEvaluation to the HL7 immunization-incubator IG instead of a local resource definition. The current incubator continuous build still has the requested targetDisease short text and the migrated doseStatusReason typo, so any remaining typo-level correction belongs in HL7/immunization-incubator rather than this core checkout.

AutoFHIR reconciliation:
This commit intentionally makes no source change. FHIR-28151 was historically applied while ImmunizationEvaluation was in core, and the current core source has no in-build ImmunizationEvaluation StructureDefinition to edit.

Recommendation:
Keep this external-repo audit commit for core. If the Immunization Incubator IG continues to publish ImmunizationEvaluation, consider a separate external-repository follow-up to correct "doese" to "dose" and, if desired, align punctuation with the original FHIR-28151 resolution.
