FHIR-6909: Audit retired SDC translation link

Issue request:
FHIR-6909 was a Published/Persuasive with Modification FHIR-core technical correction from the 2015 May SDC ballot. It reported that the related URL http://hl7.org/fhir/StructureDefinition/iso21090-ST-translation generated a 404 from the FHIR-core profiles/SDC context. The accepted resolution said the link would no longer be broken once DSTU2 was published.

Initial application:
No git commit explicitly mentioning FHIR-6909 was found. The nearby source history shows the old SDC DataElement profile note had already been converted from ExtensionDefinition links to StructureDefinition links by git-svn commit 2b54214b7e, and the SDC profile files were then moved out of the core source tree by 7fc9007c49 before the July 2015 vote. The checked-in DSTU2 release-history bundle contains a StructureDefinition entry for http://hl7.org/fhir/StructureDefinition/iso21090-ST-translation, matching the Jira resolution's publication-based fix.

Additional context:
Current core build inputs no longer link to or define iso21090-ST-translation. The active ISO 21090 profile source is still listed in source/fhir.ini, but the current ISO 21090 profile narrative and spreadsheet contain no ST-translation entry. The old DataElement resource is commented out of the current resource list, and current multi-language guidance links to the newer translation extension. The newer translation extension now lives in the FHIR Extension Pack. Later Jira FHIR-12154, already represented on the combined branch, explicitly retired the old iso21090-ST-translation and iso21090-ST-language pattern, so recreating the obsolete URL in current core would conflict with later applied specification history.

AutoFHIR reconciliation:
This commit intentionally makes no source change. The current core source has no remaining broken current-build link for FHIR-6909 to fix, the old DSTU2 artifact exists only in release-history inputs, and later cleanup intentionally removed the obsolete ST translation extension from current core guidance.

Recommendation:
Keep this no-change audit commit. No current FHIR-core source follow-up is needed for FHIR-6909; if the project wants legacy canonical URLs such as iso21090-ST-translation to redirect rather than 404, that should be treated as publication infrastructure or historical-archive policy work, not as a current core spec source fix.
