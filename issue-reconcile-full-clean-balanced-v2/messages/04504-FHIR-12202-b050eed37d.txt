FHIR-12202: Audit MedicationRequest intended dispenser

Issue request:
FHIR-12202 was a Published/Persuasive with Modification Pharmacy change request, raised against DSTU2 MedicationOrder/MedicationPrescription, asking to add an intended dispenser to MedicationOrder.dispenseRequest. The final resolution narrowed the reference to Organization after the reporter confirmed Practitioner was not a use case.

Initial application:
The issue appears to have been applied by git-svn commit 3880b34a88fdb78ad02767cb665c33375ecbdc52, whose subject explicitly says "TR#12202 - added intendedDispenser to MedicationRequest." That commit added MedicationRequest.dispenseRequest.performer as a 0..1 Reference(Organization) with intended dispenser wording and an intendeddispenser search parameter in the historical spreadsheet source.

Additional context:
MedicationOrder is now represented by MedicationRequest in current source, and source/fhir.ini records both the active MedicationRequest resource and legacy MedicationOrder mapping. The current build has since renamed the dispense-request performer element to MedicationRequest.dispenseRequest.dispenser through later Pharmacy work (FHIR-24701), with a compatibility alias from the old performer path. Current examples and the intended-dispenser search parameter use the dispenser path. FHIR-12439 is related background because it added the separate top-level MedicationRequest.performer for administration, not the dispenseRequest intended dispenser. Zulip and Confluence checks found no FHIR-12202-specific or conflicting community decision; later implementer discussion uses MedicationRequest.dispenseRequest.dispenser for the intended dispense performer.

AutoFHIR reconciliation:
No source change was made. The active MedicationRequest StructureDefinition already contains MedicationRequest.dispenseRequest.dispenser as a 0..1 Reference(Organization) with intended dispense-performer wording, and the active search-parameter bundle exposes intended-dispenser over that path.

Recommendation:
Keep this empty audit commit as-is. The current source satisfies FHIR-12202 after accounting for the MedicationOrder-to-MedicationRequest evolution and the later performer-to-dispenser rename; future changes should use newer Pharmacy issues rather than reintroducing the old dispenseRequest.performer name.
