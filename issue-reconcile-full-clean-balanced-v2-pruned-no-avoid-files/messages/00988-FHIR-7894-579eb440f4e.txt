FHIR-7894 was Published with a Persuasive with Modification resolution for the DSTU1 AllergyIntolerance ballot item asking to rename AllergyIntolerance.event to AllergyIntolerance.reaction, move event.duration to an extension, and keep onset semantics where clinically relevant.

Initial application:
The historical implementation commit 0f045d224d13b80774a8ec78841b808cde4abba8 renamed AllergyIntolerance event content to reaction and also applied related onset work from FHIR-8407. Current source already defines AllergyIntolerance.reaction, reaction.description, reaction.onset, reaction.severity, reaction.exposureRoute, and reaction.note, and the duration extension now lives in the FHIR Extension Pack, but the root AllergyIntolerance.note comment still referenced the old AllergyIntolerance.event.description and AllergyIntolerance.event.notes paths.

Additional context:
source/fhir.ini actively includes allergyintolerance=AllergyIntolerance, so source/allergyintolerance/structuredefinition-AllergyIntolerance.xml is in current build scope. The FHIR Extension Pack has StructureDefinition-allergyintolerance-duration with context AllergyIntolerance.reaction, matching the Jira instruction to move duration out of the core backbone. Searches for Zulip and Confluence discussion on FHIR-7894 found no conflicting community record.

AutoFHIR reconciliation:
This commit updates the active AllergyIntolerance StructureDefinition comment so episode-specific notes and descriptions point to AllergyIntolerance.reaction.description and AllergyIntolerance.reaction.note, the current element paths. No other event/reaction wording was changed because the remaining uses of "event" are descriptive prose about reaction events rather than stale element names.

Recommendation:
Keep this commit as-is. It completes the historical rename in the current authoritative source without reopening the separate FHIR-8407 onset issue or moving extension-pack content back into core.
