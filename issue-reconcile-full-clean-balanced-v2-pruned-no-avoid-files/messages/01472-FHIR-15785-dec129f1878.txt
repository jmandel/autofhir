FHIR-15785: Align Observation example catalog text

Issue request:
FHIR-15785 was a Published/Persuasive FHIR-core Observation change request from STU3 asking to add the QI-Core example as an illustration of the observation-bodyPosition extension. The recorded resolution was to add the example.

Initial application:
The request appears to have been applied in git commit 6843a329c79cf453e5d8b856b47f8321cf87f3dc, which added source/observation/observation-example-map-sitting.xml with observation-bodyPosition and observation-delta extensions. Later current-branch commits removed those extension instances from the example: 69dcaa85e95f0d1782dfdfbd6d8ee60a2d65f43a commented out bodyPosition and db2e218cd7c96e5acf17edbe542e06e1e21b3aa4 removed the commented bodyPosition and delta blocks, but the example catalog text still said the example demonstrated those extensions.

Additional context:
Observation is an active current-build resource in source/fhir.ini, so the Observation examples and example list are in build scope. The observation-bodyPosition extension definition is no longer owned by core source; it lives in the FHIR Extension Pack. FHIR-31355 later decided to mark that extension as not for use past R5 on Observation and to address the business need using core elements, and extension-pack commit e4bb9937474bd1cbd1703620aab4773993fb5ded applied an endFhirVersion marker. FHIR-51528 is the unresolved core follow-up for deciding the appropriate current modeling of body position. That later context makes restoring the extension or adding new body-position modeling guidance unsafe in this core reconciliation.

AutoFHIR reconciliation:
This commit updates the active Observation example catalog/header text to describe the current map-sitting example as mean arterial blood pressure with a low interpretation, and removes stale claims that it demonstrates bodyPosition or delta extensions. It also changes the example list display from "MAP Sitting" to a label that matches the current resource content.

Recommendation:
Keep this source correction as-is. Do not restore the observation-bodyPosition extension in core for the current build unless a later final OO decision, such as FHIR-51528, explicitly reintroduces current core guidance or examples for body-position modeling.
