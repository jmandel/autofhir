FHIR-17917: Correct Contract example type system

Issue request:
FHIR-17917 was a Published/Persuasive Financial Management change request for STU3 asking that the Contract code system URL be changed from http://terminology.hl7.org/CodeSystem/coverage-copay-type to http://terminology.hl7.org/CodeSystem/contract-type, because the duplicated URL caused Contract type codes to appear in place of Coverage copay type codes.

Initial application:
The issue was initially applied by git commit 182ce2688b7257156c2a879e4f64f362546cff84, which changed source/contract/codesystem-contract-type.xml, source/contract/valueset-contract-type.xml, and source/contract/contract-example-ins-policy.xml from the Coverage copay type system to the Contract type system. Later UTG migration commit 5c0494aacfd0b8bd52bc72c587aa89d0a64246f8 removed the core Contract CodeSystem source after it already carried the corrected Contract URL.

Additional context:
Contract remains active in the current build through source/fhir.ini, and source/contract/list-Contract-examples.xml includes the general Contract example. Current source already has source/contract/valueset-contract-type.xml composing http://terminology.hl7.org/CodeSystem/contract-type and the insurance policy example uses that same system, while Coverage continues to use http://terminology.hl7.org/CodeSystem/coverage-copay-type. The only remaining Contract-source occurrence of the Coverage copay system was in a commented Contract.type snippet in source/contract/contract-example.xml, and the raw XML example published for R5/current build surfaces that comment.

AutoFHIR reconciliation:
This commit updates the commented Contract.type snippet in source/contract/contract-example.xml to use http://terminology.hl7.org/CodeSystem/contract-type, eliminating the last visible Contract example reference to the Coverage copay type system without changing unrelated Coverage terminology.

Recommendation:
Keep this fix as-is. It completes the original URL separation in the active Contract example source; no further core source change is indicated for FHIR-17917 unless a later, separate Contract-removal decision is merged into this branch.
