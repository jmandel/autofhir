FHIR-53486: Complete medications module updates

Issue request:
FHIR-53486 was an Applied/Persuasive R6 FHIR-core change request from PHER for the Medications Module page. It requested typo fixes, new Normative Resources and Additional Resources subsections in section 11.0.2, moving FormularyItem, ImmunizationEvaluation, and ImmunizationRecommendation to Additional Resources, updated descriptions for the immunization additional resources, and reordered common use cases so medication use cases precede immunization use cases.

Initial application:
The issue had been partially applied before this reconciliation. Commit 4339778eb3f56eda5d28a552377b5185197b69ed fixed two of the listed typos, created an Additional Resources table for ImmunizationRecommendation and ImmunizationEvaluation, updated their descriptions, and moved the medication use cases before the immunization use cases. Commit 2b1fe4c966ab0534ff1397cb94e46f4a70e4c086 then added ballot-note text linking the page changes to FHIR-53486. The current source still left FormularyItem outside the Additional Resources table, kept separate Medications/Immunizations resource subsections instead of the requested Normative/Additional split, and retained the typo "as while reviewing a patients' medication list."

Additional context:
The current Medications module page is in build scope through source/hierarchy.xml, which lists medications-module.html and the active core resources under the Medications page. FormularyItem was removed from active core build registration by 9987f9c0c3ce5ec4f277c22ed71cbb2d210efeb6 and the current module page already links it to the PHX incubator, so this reconciliation treats FormularyItem as an external Additional Resource rather than restoring the retired core resource. PHWG Confluence minutes for 2025-12-11 record the FHIR-53486 motion as persuasive with changes as suggested and a 28-0-1 vote. A Zulip search for the issue and module found no conflicting discussion.
