FHIR-38105: Clarify CodeSystem property code values

Issue request:
FHIR-38105 was Applied/Persuasive for the vocab work group. It asked that the Concept Properties table clarify which code system supplies values for properties of type "code", replacing the ambiguous statement that such properties contain a code defined by "the code system" with wording that CodeSystem.concept.property.valueCode values are drawn from codes defined in the CodeSystem instance.

Initial application:
The Jira wording was partially applied by git commit 09caaf636406cf39544c443f4b55bbf33e78cfdf, which changed source/codesystem/codesystem-notes.xml to the requested sentence. That commit did not update the active CodeSystem StructureDefinition source or its checked-in diagram tooltip, so codesystem-definitions.html and the diagram still carried the old ambiguous sentence.

Additional context:
source/fhir.ini lists codesystem=CodeSystem as an active resource, so source/codesystem/structuredefinition-CodeSystem.xml feeds the current build. Confluence minutes for the 2023-07-17 Terminology Infrastructure tracker call list FHIR-38105 as resolved change required, matching the Jira disposition. A later unresolved FHIR-53549 issue discusses whether the clarified sentence should instead recommend Coding, but it is Triaged and not a final decision that supersedes FHIR-38105.

AutoFHIR reconciliation:
This commit updates CodeSystem.property.type in source/codesystem/structuredefinition-CodeSystem.xml to the same approved sentence already present in codesystem-notes.xml, and updates the corresponding checked-in codesystem.svg title so no current source location retains the ambiguous tooltip text.

Recommendation:
Keep this source-changing reconciliation. It completes the applied clarification across the active CodeSystem definition surfaces without addressing the separate unresolved FHIR-53549 policy question.
