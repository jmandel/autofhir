FHIR-34134: Restore DeviceAssociation bodyStructure codeable reference

Issue request:
FHIR-34134 was Published with resolution Persuasive with Modification for R5. It asked to support patient-associated devices with anatomical location, and the accepted resolution changed the Device association model so the association included humanSubject and bodyStructure, with bodyStructure typed as CodeableReference(BodyStructure).

Initial application:
The issue was first applied in Device by b446711a78, which renamed Device.associationState to Device.association and added Device.association.bodyStructure as CodeableReference(BodyStructure). The Jira comment points to follow-up commit 6a6ee72b71, which corrected Device.association metadata and the bodyStructure definition. Later source history moved patient-identifying association information out of Device into DeviceAssociation, leaving the original Device.association block commented out.

Additional context:
FHIR-38904 was a later Published OO decision that superseded the Device-hosted location by removing Device.association and creating DeviceAssociation to avoid patient-identifying information in reusable Device instances. Its proposed DeviceAssociation structure still listed bodyStructure as 0..1 CodeableReference(BodyStructure). The current build includes DeviceAssociation in source/fhir.ini and Device's boundaries text points implementers there. Later FHIR-54206 and FHIR-54843 identify broader BodyStructure-pattern and cardinality/binding work for DeviceAssociation.bodyStructure, but those R6 issues are not decided by this commit.

AutoFHIR reconciliation:
Changed the active DeviceAssociation.bodyStructure type from Reference(BodyStructure) to CodeableReference(BodyStructure), restoring the approved ability to provide either a coded anatomical location or a BodyStructure reference while preserving the current 0..1 cardinality and existing examples.

Recommendation:
Keep this commit as the bounded FHIR-34134 reconciliation. Follow-up work for FHIR-54843 should decide and apply the broader R6 changes such as 0..* cardinality and an example body-site binding.
