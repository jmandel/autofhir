FHIR-43501: Constrain Group instance ranges

Issue request:
FHIR-43501 was Applied/Persuasive with Modification for R6 Group. It asked that Group.characteristic.instances[x] represent only non-negative whole instance counts; the final resolution changed the choice to unsignedInt|Range and required an invariant that Range minimum and maximum values are >= 0 with unit, code, and system omitted.

Initial application:
Git commit 191fa02f04 changed Group.characteristic.instances[x] from Quantity|Range to unsignedInt|Range and added grp-1, but the invariant copied Count-style Quantity rules: a Range boundary value required code, allowed system = %ucum and code = '1', and did not check unit. Later Group invariant fixture commits added passing examples with code "1", so the current source still diverged from the Jira resolution.

Additional context:
Group is active in the current build through source/fhir.ini, and Group.characteristic.instances[x] is an active element. FHIR-I minutes from 2024-05-06 record the approved decision as positive integers, allowing 0, and changing to unsignedInt|Range. A March 2025 Zulip thread briefly reconsidered Count|Range, but no request to reopen was made and the discussion did not reverse the final Jira requirement to omit unit, code, and system.

AutoFHIR reconciliation:
This commit updates source/group/structuredefinition-Group.xml so grp-1 requires Range.low and Range.high values to be whole numbers greater than or equal to 0 and requires unit, system, and code to be absent. It updates affected Group invariant fixtures to omit code "1" where they are intended to pass this constraint, keeps unrelated fail fixtures from failing grp-1 accidentally, adds a grp-1 fail fixture for unit/system/code, and repairs missing commas in the touched cnl-1 fixtures so the edited JSON remains parseable.

Recommendation:
Keep this source fix. If FHIR-I wants Count-like UCUM "1" semantics for Range boundaries instead, that should be handled as a new explicit tracker because it relaxes the Applied FHIR-43501 resolution.
