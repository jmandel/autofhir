FHIR-17412: Update Provenance AuditEvent entity mappings

Issue request:
FHIR-17412 was Published/Persuasive for STU3 and asked Security to simplify AuditEvent by changing agent.reference to agent.who, removing agent.userId as redundant to agent.who, changing entity.reference to entity.what, and removing entity.identifier.

Initial application:
The AuditEvent element changes were initially applied in git commit 6c0a0563b3, which explicitly cited GF#17412 along with GF#17413 and GF#15659 and updated the AuditEvent spreadsheet, examples, constraints, and search parameters from the old identifier/reference split to the current Reference-based elements. In the current source, active AuditEvent already has AuditEvent.agent.who and AuditEvent.entity.what and no active AuditEvent.agent.reference, AuditEvent.agent.userId, AuditEvent.entity.reference, or AuditEvent.entity.identifier elements.

Additional context:
AuditEvent and Provenance are both active resources in source/fhir.ini. A remaining current build-scope inconsistency was in Provenance's fhirauditevent mappings, where Provenance.target and Provenance.entity.what still pointed to the retired AuditEvent.entity.reference path even though AuditEvent now maps entity.what back to Provenance.target and Provenance.entity.what. FHIR-17413 was applied by the same historical commit family and is already represented on the combined branch; FHIR-15659 was the related Provenance identifier/reference issue but is broader than this stale AuditEvent-path mapping correction. FHIR-32449 later made AuditEvent.agent.who 1..1 and does not reverse this issue.

AutoFHIR reconciliation:
Updated the two active Provenance fhirauditevent mappings from AuditEvent.entity.reference to AuditEvent.entity.what. No AuditEvent source hunk was needed because the authoritative AuditEvent structure definition and search parameters already use agent.who and entity.what and no longer define the removed elements.

Recommendation:
Keep this source fix as-is. It removes the last discovered current-source reference to the retired AuditEvent.entity.reference path in the active AuditEvent/Provenance build scope; no additional core change is needed for FHIR-17412 unless a future work group decision revisits the AuditEvent-Provenance mapping model.
