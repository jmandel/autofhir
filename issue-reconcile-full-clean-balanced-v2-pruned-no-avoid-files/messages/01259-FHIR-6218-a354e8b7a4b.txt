FHIR-6218: Correct NutritionOrder CHF example display

Issue request:
FHIR-6218 is a Published/Persuasive OO technical correction for the DSTU1 NutritionRequest/NutritionOrder example. It asked to change the example name from "Nutrition Order Low Sodium and Fiber Restricted Diet Example" to "Nutrition Order Low Sodium and Fluid Restricted Diet Example".

Initial application:
The Jira resolution says the change was preapplied. Current source already had the corrected full description string, but the authoritative examples-list display for the same CHF diet example still said "Low Sodium and Fiber Restricted Diet". No explicit FHIR-6218-tagged commit was found in the local history; the current examples-list source was introduced in the 2021 build-source rework with the corrected description and stale display side by side.

Additional context:
source/fhir.ini actively includes nutritionorder=NutritionOrder, so source/nutritionorder/list-NutritionOrder-examples.xml is in current build scope. The referenced example source is now NutritionOrder/chfdiet and its oralDiet content is low sodium plus fluid restricted, including a fluid-restricted type and fluid nutrient limit. The later FHIR-50382 NutritionOrder examples update changed the example reference from cardiacdiet to chfdiet but preserved the stale display, so that later work does not supersede the FHIR-6218 correction. Zulip and Confluence searches found no conflicting community evidence.

AutoFHIR reconciliation:
Updated the NutritionOrder examples list display for NutritionOrder/chfdiet from "Low Sodium and Fiber Restricted Diet" to "Low Sodium and Fluid Restricted Diet". This aligns the rendered list label with the already-correct description and the example content without changing unrelated NutritionOrder examples.

Recommendation:
Keep this source fix. No follow-up is needed for FHIR-6218 unless a future NutritionOrder examples pass intentionally renames the CHF diet example again.
