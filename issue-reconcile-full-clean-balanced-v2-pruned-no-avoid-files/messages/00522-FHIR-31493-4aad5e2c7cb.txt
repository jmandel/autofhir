FHIR-31493: Correct Evidence statistic type references

Issue request:
FHIR-31493 was Published/Persuasive for R5 and asked to add Statistic.numberAffected as a 0..1 unsignedInt, with guidance distinguishing numberAffected from numberOfEvents and telling authors to use the statistic type Count code when the count itself is the statistic.

Initial application:
The Jira comment says the issue was applied to R5 by HL7/fhir#1164. Git history shows commit 2bc640fae8 ("J#31369 and J#31493") added numberAffected and updated numberOfEvents on the then-current Statistic datatype source. No prior Issue-Reconcile-Key commit for FHIR-31493 was present on the combined branch.

Additional context:
FHIR-31866 later removed Statistic as a standalone datatype and reincorporated its elements into the active Evidence resource. The current build has Evidence enabled in source/fhir.ini, has no current Statistic StructureDefinition source, and names the statistic type element Evidence.statistic.statisticType. The FHIR-31866 refactor copied the FHIR-31493 comments forward as Evidence.statistic.type.coding.*, which now points to a non-existent element.

AutoFHIR reconciliation:
This commit updates the two FHIR-31493 comment locations in source/evidence/structuredefinition-Evidence.xml so the Count guidance points to Evidence.statistic.statisticType.coding.code and Evidence.statistic.statisticType.coding.display. The numberAffected element, numberOfEvents definition, cardinalities, and types were already present and were left unchanged.

Recommendation:
Keep this source fix. It preserves the approved FHIR-31493 semantics while aligning the guidance with the current Evidence resource shape after the FHIR-31866 refactor.
