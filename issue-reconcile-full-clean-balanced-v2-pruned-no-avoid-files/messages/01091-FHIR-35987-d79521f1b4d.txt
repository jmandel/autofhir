FHIR-35987: Align shareable publisher steward wording

Issue request:
FHIR-35987 was a Published/Persuasive with Modification FHIR-I change request for R5 asking to clarify that publisher is a synonym for steward. The approved resolution changed CanonicalResource-style publisher short names to "Name of the publisher/steward (organization or individual)" and changed the definition to responsibility for release and ongoing maintenance of the artifact.

Initial application:
The issue was initially applied in PR #2358 by git commit 272e3fb71ecb0d87630a48101b00015f0f18b038, whose message includes "J#35987: Clarified publisher definition in canonical resources" and which updated CanonicalResource plus the generated concrete canonical-resource StructureDefinitions. Current CanonicalResource.publisher and the concrete resource StructureDefinitions already carry the publisher/steward short name and release/maintenance definition from that application.

Additional context:
The active fhir.ini [resource-infrastructure] entries list CanonicalResource and MetadataResource, and MetadataResource.publisher is mapped to CanonicalResource.publisher. The active fhir.ini [logical] entries also list the Shareable logical model, whose spreadsheet source defines Shareable.publisher. That Shareable.publisher source still used the older proposal wording "Name of the publisher (or steward)" and "that published (or stewards)", even though Confluence terminology minutes tied valueset-steward replacement to FHIR-35987 and FHIR-I minutes record the final 15-0-0 approval. FHIR-29944 is an older related ValueSet steward cleanup issue and is already represented on the combined branch as superseded background.

AutoFHIR reconciliation:
This commit updates only source/shareable/shareable-spreadsheet.xml so the active Shareable.publisher short name and definition match the already-applied CanonicalResource publisher/steward wording. It intentionally leaves publisher search-parameter descriptions and generated-looking SVG text unchanged because the issue targeted element short/definition text and the authoritative source already conveys the search parameter and diagram semantics.

Recommendation:
Keep this source fix. It completes the bounded FHIR-35987 application by aligning an active logical-model input with the approved CanonicalResource-style wording without reopening older ValueSet steward questions or changing unrelated search parameter descriptions.
