FHIR-53414: Align EventDefinition examples and trigger guidance

Issue request:
FHIR-53414 was Applied/Persuasive for R6 and asked to add EventDefinition examples for named events, data events, data events with profiles, and periodic events. The final resolution also required correcting TriggerDefinition invariants and guidance so condition can be used with any trigger type while only data-change triggers populate current/previous data context.

Initial application:
The issue was initially applied by git commit 9d99198558, linked from Jira via PR 3971. That commit added the EventDefinition example resources, the example list entries, the supporting ExampleEventDefinitionLogic library, EventDefinition notes, and TriggerDefinition spreadsheet edits. Current source retained the examples and most of the application, but left the TriggerDefinition condition guidance saying every event supplies current resource context, left the required-type-elements XPath out of sync with the FHIRPath invariant, and left EventDefinition narrative snippets referring to an undefined consecutivelyFrom helper and a profile URL that did not match the example resource.

Additional context:
EventDefinition and TriggerDefinition are active current-build artifacts in source/fhir.ini. The local Jira search only found the seed and an external FHIR-us-cql issue using similar stick-test example material; that external IG issue is not a core FHIR reconciliation target. Zulip and Confluence searches for FHIR-53414 and EventDefinition examples found no directly relevant or conflicting community evidence.

AutoFHIR reconciliation:
This commit keeps the applied example set and makes the remaining source corrections required for the current core build: TriggerDefinition's general guidance and condition comment now say condition is allowed for any trigger type but data-change triggers are the source of current/previous data context, the XPath form of the required-type-elements invariant now matches the FHIRPath rule for name-or-code, timing, data, and subscriptionTopic, and the EventDefinition narrative snippets now match the checked-in example resources and ExampleEventDefinitionLogic CQL helper name.

Recommendation:
Keep this source fix as-is. It completes the Applied Jira request in current core source without broadening the issue scope; no additional core FHIR change is recommended for FHIR-53414.
