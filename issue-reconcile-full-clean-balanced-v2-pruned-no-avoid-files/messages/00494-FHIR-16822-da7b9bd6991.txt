FHIR-16822: Generalize Measure patient wording

Issue request:
FHIR-16822 was Published/Persuasive for the STU3 Measure section. It asked CQI to review Measure documentation where patient-based wording was used even though the Measure subject model should be generalized to subject.

Initial application:
The Jira comment records SVN 14855. In git, b06ccf7d682d1e5bb2489464b8d16998b57ebe1c is the matching GF#16822 application commit; it updated source/clinicalreasoning-quality-reporting.html from patient/patient-list wording to subject/individual wording in the then-current Quality Reporting topic.

Additional context:
The current build has a broader subject model than the STU3 text: Measure and MeasureReport are active CQI resources, the Quality Reporting page is in the source hierarchy, and the Measure operations are listed as current inputs. Later Measure changes, including Group-based population reporting and group-level Measure subjects, left several active source comments, operation parameter descriptions, example descriptions, and scoring paragraphs using patient-level or Patient-based language where subject, individual-level, summary-level, or neutral case wording is now required. Explicit Patient examples and CQL snippets remain appropriate and were not generalized.

AutoFHIR reconciliation:
This commit changes the remaining stale patient-specific wording in active Measure, MeasureReport, Measure operation, and Quality Reporting source. It uses neutral case wording for generic scoring formulas, individual-level wording for report-level parameters and subject-list examples, summary-level wording for a summary MeasureReport example, and subject-based wording for Group-supported measure comments. It also corrects the coupled ratio sentence label from performance rate to performance ratio.

Recommendation:
Keep this source change. It completes the original FHIR-16822 intent against the current R6 source while preserving patient-specific examples where Patient is explicitly the subject. Future edits should continue to avoid replacing concrete Patient examples with abstract wording unless the surrounding rule is intended to apply to all Measure subjects.
