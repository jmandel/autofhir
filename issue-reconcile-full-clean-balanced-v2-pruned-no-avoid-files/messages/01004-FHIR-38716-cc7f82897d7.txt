FHIR-38716: Fix TestScript expression guidance links

Issue request:
FHIR-38716 was Published/Persuasive for R5 and asked that use of TestScript.setup.action.assert.expression be clarified because R4B users could not tell whether assert.expression should evaluate to boolean true or to a value compared through assert.value. The accepted resolution was to update the Testing FHIR page and the TestScript resource definition page.

Initial application:
The issue was applied in HL7/fhir commit 18d19c0f005d09d375aa017b21824b3535918fff and merged by PR #2527 in a4a09e3aa1. That change added a Testing FHIR "Use Expressions" section and updated TestScript.variable.expression, TestScript.setup.action.assert.compareToSourceExpression, and TestScript.setup.action.assert.expression comments/definitions.

Additional context:
Current core no longer contains source/testing.html or source/testscript/structuredefinition-TestScript.xml. Commit f9a44787c45071394532c7c2ee94d76f30f47387 removed the testing resources from core and added the active source/fhir.ini [additional-ig-list] entry that delegates testing content to the FHIR Testing IG. The external HL7/fhir-testing-ig source and rendered CI pages still contain the FHIR-38716 guidance, but the current core base URL used lowercase hl7 plus index.html and the active source/fhirpath.html link used the stale plural StructureDefinitions-TestScript-definitions.html filename, so core's current cross-IG pointers did not reliably reach the applied assert.expression guidance. FHIR-I minutes confirm the 2022-12-12 Persuasive vote, and direct Zulip search found no conflicting issue-specific discussion.

AutoFHIR reconciliation:
This commit keeps the authoritative guidance in the external Testing IG and fixes the current core source that points to it. source/fhir.ini is active build configuration, so its testing IG locator now uses the reachable build.fhir.org/ig/HL7/fhir-testing-ig base without embedding index.html. source/fhirpath.html is an active core narrative page, so its TestScript FHIRPath usage item now links to the current singular StructureDefinition-TestScript-definitions.html page and labels the target as assertion expressions rather than invariants.

Recommendation:
Keep this source fix. No TestScript resource prose should be reintroduced into core while the resource and Testing FHIR page are maintained in HL7/fhir-testing-ig; future TestScript wording changes should be made in that IG, with core retaining only accurate cross-IG links.
