FHIR-36396: Remove remaining Medication V2 mapping hyphen

Issue request:
FHIR-36396 was a Published/Persuasive Pharmacy technical correction for R5 asking that erroneous hyphens between HL7 v2 field/component identifiers and their descriptions be removed from the Medication V2 mapping table, including the Medication strength/ingredient mappings.

Initial application:
The issue was initially applied by Jira-tagged commit b9257918056a31ebdc080627432cc94db78637e0, which edited active source/medication/structuredefinition-Medication.xml and removed most listed hyphens. That application missed one same-pattern value in the Medication.ingredient.item V2 mapping: RXD-2-Dispense Give Code.

Additional context:
Medication is an active current-build resource in source/fhir.ini, while MedicationKnowledge still has a stale copied mapping but is not listed as an active resource. Pharmacy minutes for 2022-03-28 record FHIR-36396 as a technical correction with agreement to change, and the originating Zulip thread confirms the convention that hyphens separate v2 fields while dots separate components.

AutoFHIR reconciliation:
This commit changes the active Medication StructureDefinition V2 mapping from RXD-2-Dispense Give Code to RXD-2 Dispense Give Code. It intentionally leaves the out-of-build MedicationKnowledge copy unchanged.

Recommendation:
Keep this source fix as-is. It completes the already-approved formatting correction in the build-scoped Medication source without broadening the change to inactive copied resources or unrelated V2 mapping cleanup.
