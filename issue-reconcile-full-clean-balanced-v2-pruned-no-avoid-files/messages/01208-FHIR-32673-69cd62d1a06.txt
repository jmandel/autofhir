FHIR-32673: Correct text-advanced POST example

Issue request:
FHIR-32673 was a Published/Persuasive with Modification FHIR-core search-page change request for R5. It asked whether token `:text` searches should support word-boundary or prefix-style matching, and the accepted resolution defined two additional token-oriented modifiers: `:text-advanced`, equivalent to token `:text` but using advanced string processing, and `:code-text`, for partial text searching on the code/value portion of Coding or Identifier.

Initial application:
No historical commit with FHIR-32673 in the original subject/body was found. The requested modifiers were nevertheless applied during the 2022 search modifier rewrite: commit 6ce165cfe8e0ba45096d394c0a433af5bd8524cc added the detailed `text-advanced` search-page section, and commit 7c3f73fb1f51cbbb40b332c19799a40dbab2bfaf added `code-text` and `text-advanced` to the search-modifier-code CodeSystem while applying nearby search modifier issues. That application left one stale example in the `text-advanced` section: the POST form used `code:text-ad=headache`, a non-existent modifier.

Additional context:
The linked Zulip discussions show the use case was advanced, word-based text matching for token display text without changing the basic token `:text` semantics. FHIR-I minutes on 2021-12-13 record the 12-0-0 persuasive vote. Later reconciliations already represented on the combined branch, FHIR-40842 and FHIR-35812, corrected the `:code-text` CodeSystem wording and kept `:text-advanced` target-text examples aligned with `:text`. FHIR-36651 appeared in a later meeting note as related/covered, but its current Jira state is Resolved - change required for separate VCL/in-vcl behavior and is outside this seed decision.

AutoFHIR reconciliation:
Updated the active source/search.html `text-advanced` POST example from `code:text-ad=headache` to `code:text-advanced=headache`. No CodeSystem or value set source was changed because `source/fhir.ini` actively includes the search-modifier-code value set, and its current CodeSystem already contains both modifier codes with definitions consistent with later accepted corrections.

Recommendation:
Keep this commit as-is. It fixes the only remaining misleading source defect found for FHIR-32673 while preserving the already-applied modifier definitions and avoiding broader redesign of token text-search semantics.
