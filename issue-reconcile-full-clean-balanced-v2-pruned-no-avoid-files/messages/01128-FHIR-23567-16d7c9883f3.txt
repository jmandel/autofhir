FHIR-23567: Remove stale Media guidance from Resource Guide

Issue request:
FHIR-23567 was Published/Persuasive for R5 and asked OO to merge the Media resource into DocumentReference. The Jira record and comments identify PR #588 as the initial application and note the companion MNM Attachment issue FHIR-23568.

Initial application:
The original Media merge work landed in commits 5c62f91cd8 and 53b7c8e1a2. Those commits removed Media from the active build resource list, added Media-derived DocumentReference examples and metadata, updated references such as ClinicalImpression and DiagnosticReport to target DocumentReference, and left Media only as a deleted/non-active resource entry. The active current source still has DocumentReference in source/fhir.ini while Media is absent from the active resource list.

Additional context:
The current DocumentReference definition already covers photos, videos, and audio recordings, and related ImagingStudy guidance already points non-DICOM media content to DocumentReference. The companion FHIR-23568 Attachment metadata decision is already represented on the combined branch. The build-scoped Resource Guide is still published through publish.ini and hierarchy.xml, but it still described Media as a current diagnostic resource and linked to media.html, which is now only an R4B/historical resource link elsewhere in source/history.html.

AutoFHIR reconciliation:
This commit updates source/resourceguide.html to replace the stale Media resource paragraph with current DocumentReference/Observation guidance, updates the ImagingStudy paragraph to point to DocumentReference instead of media.html, and removes the Media row from the diagnostic resource table. It intentionally does not edit the retired source/media folder, generated-looking SVG artifacts, or unrelated workflow-warning suppression rows.

Recommendation:
Keep this source fix. It closes the remaining implementer-facing stale Resource Guide guidance for the Media-to-DocumentReference merge without broad cleanup of retired source artifacts.
