FHIR-31481: Align SubstanceDefinition domain search description

Issue request:
FHIR-31481 is an Applied/Persuasive BRR clarification for the R4-era SubstanceSpecification/SubstanceDefinition content. It requested changing SubstanceDefinition.version from a substance business identifier to a business-level edition or revision identifier, and changing SubstanceDefinition.domain from a human/veterinary-only phrasing to the applicable usage of the substance with human or veterinary only as examples.

Initial application:
The requested element wording was applied in git commit d96304345bcdde00400edbac0a77762cacca2580, which updated source/substancedefinition/structuredefinition-SubstanceDefinition.xml for SubstanceDefinition.version and SubstanceDefinition.domain. That application did not update the parallel SubstanceDefinition-domain search parameter description, which still carried the old human/veterinary-only wording.

Additional context:
SubstanceDefinition is active in source/fhir.ini, and source/substancedefinition/bundle-SubstanceDefinition-search-params.xml is the source search-parameter bundle in the active resource folder. Searches for FHIR-31481 in Zulip and Confluence found no relevant community discussion or conflicting decision, and current source contains no other copy of the old requested wording.

AutoFHIR reconciliation:
This commit updates the SubstanceDefinition-domain SearchParameter description to match the applied SubstanceDefinition.domain wording, removing the stale implication that the domain is limited to only human or veterinary use.

Recommendation:
Keep this source fix. It completes the already-applied Jira clarification across the active search parameter source without changing conformance behavior beyond aligning implementer-facing description text.
