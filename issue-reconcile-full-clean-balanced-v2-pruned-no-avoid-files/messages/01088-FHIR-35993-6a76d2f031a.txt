FHIR-35993: Mark terminology server CapabilityStatement vocabulary-owned

Issue request:
FHIR-35993 was Published/Persuasive for R5 and asked that the Terminology Service CapabilityStatement referenced from the Terminology Service page move from FHIR Infrastructure ownership to the Vocabulary WG.

Initial application:
No source commit explicitly mentioning FHIR-35993 was found. Later source state had already moved the Terminology Service page and TerminologyCapabilities resource to the vocabulary work group, but the specific CapabilityStatement/example-terminology-server source still lacked example-level work group and publisher metadata, so the current CI page rendered it as FHIR Infrastructure-owned.

Additional context:
The current work group code remains `vocab`, with display text now rendered as Terminology Infrastructure after later work group naming changes. The CapabilityStatement resource itself remains owned by FHIR Infrastructure, so changing the global CapabilityStatement work group would be overbroad; the active example instance needs its own `structuredefinition-wg` and publisher/contact metadata instead.

AutoFHIR reconciliation:
Added the `structuredefinition-wg` extension with value `vocab` plus Terminology Infrastructure publisher/contact metadata to `source/capabilitystatement/capabilitystatement-terminology-server.xml`. The file is in build scope through the active CapabilityStatement resource and `list-CapabilityStatement-examples.xml`, and it is linked from `source/terminology-service.html`.

Recommendation:
Keep this source change. It applies the published tracker narrowly to the Terminology Service CapabilityStatement example without reassigning the CapabilityStatement resource as a whole.
