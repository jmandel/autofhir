FHIR-32313: Remove hidden space from ResearchStudy status activity code

Issue request:
FHIR-32313 was Published/Persuasive for R5 and asked to make the ResearchStudyStatusActivity value set codes lowercase to match FHIR code system style. The Jira comments clarified that a research-study-statusDate-activity CodeSystem and value set needed to exist and listed the mixed-case source values to normalize.

Initial application:
No source commit was found that explicitly mentioned FHIR-32313. The statusDate activity CodeSystem appears to have been created indirectly in a80f42593 for FHIR-33053, whose Jira comment points item 1 back to FHIR-32313. That commit lowercased the concepts but introduced registration-submission with a trailing non-breaking space, making the actual code value different from the requested lowercase code.

Additional context:
The BRR terminology Confluence page that references FHIR-32313 lists registration-submission without trailing whitespace. ResearchStudy is active in source/fhir.ini, and source/researchstudy is the active resource folder containing this CodeSystem source. Later FHIR-37691 replaced statusDate in the resource model and moved the successor studyRegistration terminology to the FHIR Extension Pack, where research-study-registration-activity already uses the clean registration-submission code; this reconciliation therefore limits the core edit to the remaining core statusDate activity CodeSystem source.

AutoFHIR reconciliation:
Removed the hidden U+00A0 non-breaking space from source/researchstudy/codesystem-research-study-statusDate-activity.xml so the concept code is exactly registration-submission, consistent with the Jira/BRR terminology evidence and the surrounding lowercase code style.

Recommendation:
Keep this source fix. No broader ResearchStudy terminology refactor is recommended in this commit because later FHIR-37691/Extension Pack work already handles the studyRegistration successor terminology, and changing URLs, OIDs, or extension-pack content would exceed FHIR-32313.
