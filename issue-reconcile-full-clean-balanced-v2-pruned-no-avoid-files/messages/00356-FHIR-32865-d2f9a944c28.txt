FHIR-32865: Align MAR guidance paths

Issue request:
FHIR-32865 was a Published/Persuasive Pharmacy change request for R5 asking to add Medication Administration Record guidance to MedicationAdministration section 11.2.5, based on the Confluence Medication Administration Lists page.

Initial application:
The request was applied in commit 26e2a822594c064e06e61e26e5d1d2560c2c9fda, merged by 874c259a45661a3731b8b8915de80b730a173481, which copied the Confluence MAR guidance into source/medicationadministration/medicationadministration-notes.xml. Later cleanups adjusted some copied path text, including a68b6567bf3bf79008f25d7974edc76b9b91c75a and FHIR-41380, but the scheduled-MedicationRequest rows still used obsolete dosage/dosageInstructions paths after the current dosage model changed.

Additional context:
MedicationAdministration is active and approved in source/fhir.ini. The current MedicationRequest source defines dosageInstruction as DosageDetails; DosageDetails uses step.component to hold Dosage entries; Dosage defines timing, route, site, and doseAndRate.dose/rate. The existing MAR guidance still pointed readers to MedicationRequest.dosage.dose[x] and MedicationRequest.dosageInstructions.dosage.* paths, which no longer correspond to the current source model. Community searching found the originating Confluence guidance and minutes, with no directly relevant Zulip conflict.

AutoFHIR reconciliation:
Updated only the MAR table element labels in active MedicationAdministration notes: MedicationRequest dose/rate/timing/route/site now reference dosageInstruction.step.component and doseAndRate/timing/route/site, and the MedicationAdministration dose/rate row now names the full rate path. No clinical guidance text or resource semantics changed.

Recommendation:
Keep this commit as-is. It preserves FHIR-32865's MAR guidance while aligning element-path examples with the current source model; no work-group decision is needed unless Pharmacy wants a broader editorial rewrite of the MAR page.
