FHIR-28217: Align Goal acceptance participant wording

Issue request:
FHIR-28217 was Applied as Persuasive with Modification for Goal. It requested support for parties who have agreed to or accepted a goal, with the final decision to rename Goal.acceptance.individual to Goal.acceptance.participant, add PractitionerRole, CareTeam, and Organization reference targets, and update the description/definition to say the acceptance is reflected for an individual or organization.

Initial application:
The change was initially applied by git commit 0d8e3756353bd8c0e93994eea043a54216ae2f37, which renamed the element, added the three requested target profiles, and updated the short description. That commit left the authoritative definition as "The person ororganization whose acceptance/priority is being reflected" and left neighboring Goal.acceptance status/priority wording as individual-only.

Additional context:
Goal is an active resource in source/fhir.ini, so source/goal/structuredefinition-Goal.xml feeds the current build. FHIR-44978 introduced Goal.acceptance into the base Goal resource, and later Applied issue FHIR-48366 added Group to Goal.acceptance.participant, confirming that the current element should be described generically as a participant rather than only an individual. Confluence minutes for the original 2020 MCC Care Plan meeting also describe the need to record acceptance by a certain person or group. No Zulip or additional Confluence full-text hit was found that changed this Jira/source conclusion.

AutoFHIR reconciliation:
Updated the active Goal StructureDefinition so Goal.acceptance, Goal.acceptance.participant, Goal.acceptance.status, and Goal.acceptance.priority consistently describe the actor as a participant. The participant definition now covers the current target set, including individual, organization, care team, and group, and removes the typo/stale acceptance-priority wording. Updated the matching checked-in Goal SVG tooltips only as a generated diagram companion to the authoritative XML fix.

Recommendation:
Keep this source fix. It completes the FHIR-28217 description/definition application while preserving the later FHIR-48366 Group target; no broader Goal model change is indicated by the evidence reviewed.
