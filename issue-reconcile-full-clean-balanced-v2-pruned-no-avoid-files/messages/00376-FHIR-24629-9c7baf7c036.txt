FHIR-24629: Correct continuous variable Measure example

Issue request:
FHIR-24629 is an Applied/Persuasive CQI change request for R6. It asks to add a continuous variable measure example from the Quality Measure IG to the base Measure resource and add narrative references to the QM IG for additional Measure examples. The updated disposition explicitly does not move the continuous variable Measure profile into base FHIR.

Initial application:
The issue was applied by HL7/fhir#3938: commit 6a646a3a8c added source/measure/measure-EXM55-FHIR.xml and listed it in source/measure/list-Measure-examples.xml, and commit 615ce38d21 added the contained Library and changed the example to reference it. No prior Issue-Reconcile-Key commit for FHIR-24629 existed on the combined branch.

Additional context:
source/fhir.ini actively lists measure=Measure, so the Measure source directory, example list, example resources, and examples header feed the current build. FHIR-49945 was already reconciled on the combined branch and later touched the same Measure examples area by removing stale Measure.topic content and refreshing examples prose, but it did not address the EXM55 group linkId, measure-observation input reference, or QM IG examples reference. The Quality Measure IG EXM55 source used R4 extensions; in current R6 base Measure, the corresponding group linkId and inputPopulationId are native elements, and inputPopulationId is defined as the id of the population element providing input.

AutoFHIR reconciliation:
This commit fixes the applied continuous-variable example in current build scope by changing the malformed group linkId attribute from value- to value, by making the measure observation inputPopulationId reference the actual measure-population linkId, and by adding the requested Measure examples narrative link to the Quality Measure Implementation Guide.

Recommendation:
Keep this commit as-is. It completes the applied FHIR-24629 source work without moving the QM continuous-variable profile into core; future profile-specific refinements should remain in the Quality Measure IG unless CQI makes a new final decision.
