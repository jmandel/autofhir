FHIR-17048: Correct transaction example identifier URLs

Issue request:
FHIR-17048 was Published/Persuasive for STU3 and asked that the transaction ifNoneExist and conditional update examples declare the identifiers used by their conditional search criteria. The Jira comment also noted that distinct patient demographics would be clearer, but the summary, application comment, and applied change centered on making the conditional identifiers real.

Initial application:
The issue was applied by 2aabd5950d83268fab71bf57f77c3527ea95b0d5 (svn r14444), which added Patient.identifier elements to source/bundle/bundle-transaction.xml and changed the conditional create/update criteria to use those identifiers. That implementation left the new example system as the malformed HTTP URL http:/example.org/fhir/ids.

Additional context:
source/fhir.ini actively includes Bundle, source/bundle/list-Bundle-examples.xml lists Bundle/bundle-transaction, and source/http.html links bundle-transaction.html with bundle-response.html as the matching response, so both XML examples are current build inputs. A later FHIR-31965 reconciliation added the matched conditional-create response body and copied the same identifier system into source/bundle/bundle-response.xml. FHIR-40498 is a later Triaged/unresolved request to add conditional references to the same transaction example; it is background only and not a final source-edit decision for this seed.

AutoFHIR reconciliation:
Updated source/bundle/bundle-transaction.xml and source/bundle/bundle-response.xml so the conditional identifier system is the normal example.org HTTP URL, http://example.org/fhir/ids, everywhere the request criteria and matching resource identifiers appear. No patient-name or birth-date edits were made because the published issue's semantic requirement is the identifier linkage, which is now present and internally consistent.

Recommendation:
Keep this source change. It corrects a small but real defect in the applied FHIR-17048 example without taking on the unresolved FHIR-40498 enhancement or adding redundant editorial changes.
