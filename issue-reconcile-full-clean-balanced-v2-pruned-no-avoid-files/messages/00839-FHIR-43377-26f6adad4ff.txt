FHIR-43377: Point MPHO profile text to OO Incubator

Issue request:
FHIR-43377 was Applied/Persuasive with Modification for R5 and asked to add an optional BiologicallyDerivedProduct profile for medical products of human origin (MPHO) to FHIR Core, including mandatory traceability elements and identifier guidance.

Initial application:
The request was initially applied by d392376bf1, merged as PR #3198, which added StructureDefinition/MedicalProductOfHumanOrigin and related BDP profile pages. Later cleanup commits adjusted the profile casing, cardinalities, warnings, and biologicalSourceEvent wording.

Additional context:
The BDP resource and module page are active in the current build through source/fhir.ini and source/hierarchy.xml. Later OO decisions FHIR-52021 and FHIR-54998 concluded the MPHO profile was not ready for R6 normative core and should be removed from FHIR Core and moved to the OO Incubator IG. Commit 6bf92471f8 removed the core profile and examples, and the OO Incubator continuous build now carries StructureDefinition-medicalproductofhumanorigin.

AutoFHIR reconciliation:
Updated the active BDP module page so its MPHO profile sentence no longer reads as an unqualified core-profile reference. It now links to the OO Incubator profile and states that the profile is under development there, matching the later migration while preserving the traceability guidance relevant to the original issue.

Recommendation:
Keep this commit. Do not restore the MPHO profile to FHIR Core unless OO/FMG reverse the later FHIR-52021/FHIR-54998 migration decision; continued profile maturation belongs in the OO Incubator IG.
