FHIR-29692: Correct recursive package path guidance

Attribution note: surfaced while reviewing FHIR-31805, but direct Jira backing for this change is FHIR-29692.

Issue request:
FHIR-31805 was a Published FHIR-core BR&R change request resolved as Persuasive for R5. It asked why PackagedProductDefinition had two recursive package paths and requested guidance that clearly explains when each path should be used. The final resolution required explanatory text distinguishing internal package layering from aggregation of independently distributable packaged products.

Initial application:
The guidance was applied before this reconciliation through several FHIR#31805-tagged commits, including fbfbf287b1, 20fdf9f363, 4b17e84190, de460423b6, and 4b90a7338b, which added and refined PackagedProductDefinition Scope and Usage text and updated related element definitions. The current source retained the intended explanation, but later FHIR-29692 renamed PackagedProductDefinition.package to PackagedProductDefinition.packaging in the StructureDefinition without carrying that element-path rename through all narrative references.

Additional context:
FHIR-29692 was Published/Persuasive and changed the element name because the child backbone represents packaging details, not the whole package. The active StructureDefinition now defines PackagedProductDefinition.packaging.containedItem.item and PackagedProductDefinition.packaging.packaging, and fhir.ini confirms PackagedProductDefinition, MedicinalProductDefinition, and ManufacturedItemDefinition are current build-scope resources. BR&R minutes show the work group continued discussing and rewording FHIR-31805 after the August 2021 vote context, and no Zulip evidence was found that changes the Jira/source conclusion.

AutoFHIR reconciliation:
This commit keeps the FHIR-31805 guidance and corrects only stale current-spec path references. It changes the recursive relationship bullets to PackagedProductDefinition.packaging.packaging and PackagedProductDefinition.packaging.containedItem.item(PackagedProductDefinition), and fixes the same stale path in nearby MedicinalProductDefinition and ManufacturedItemDefinition guidance that points readers to the relevant PackagedProductDefinition packaging path.

Recommendation:
Keep this commit as-is. The substantive distinction requested by FHIR-31805 is already present and remains consistent with the published decision; these path-name corrections are necessary so implementers can follow the guidance against the current R5/R6 element names. FHIR-29692 is related evidence for the rename but is not independently decided by this commit.
