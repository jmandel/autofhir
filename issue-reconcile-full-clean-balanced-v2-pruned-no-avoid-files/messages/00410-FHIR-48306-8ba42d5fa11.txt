FHIR-48306: Clarify StructureDefinition experimental narrative

Issue request:
FHIR-48306 was an Applied/Persuasive with Modification FHIR-I change request for R6 asking to clarify StructureDefinition.experimental so it classifies artifacts authored for testing-only use, not lifecycle/status readiness. The approved resolution changed CanonicalResource.experimental and inherited definitions from "For testing purposes, not real usage" / "is not intended for genuine usage" to "For testing only - never for real usage" and "no version of this resource will ever be intended for genuine usage", with comments explaining examples, version consistency, and stability expectations.

Initial application:
The issue was previously applied by upstream commit a53a3f1ad6ce52b1ebac190f79bf193bc41ebbdc, which updated CanonicalResource.experimental and many inherited/generated StructureDefinition definitions. The current combined branch already contains that commit and the authoritative CanonicalResource and StructureDefinition element definitions carry the approved short, definition, and comment text. However, source/structuredefinition/structuredefinition-introduction.xml still repeated the old ambiguous hand-written metadata-table wording that the structure "is not intended for genuine usage".

Additional context:
source/fhir.ini lists canonicalresource as an active infrastructure interface and structuredefinition as an active resource, with MetadataResource.experimental mapped to CanonicalResource.experimental, so both the generated definitions and the StructureDefinition narrative page are in current build scope. The cited Zulip thread distinguishes experimental from draft/FMM/status and records the reporter filing FHIR-48306. FHIR-I minutes from 2025-01-20 record the Persuasive with Modification vote for the issue. A related Jira search found no separate final tracker that changes this scope.

AutoFHIR reconciliation:
Updated the StructureDefinition narrative metadata table so its experimental row now says the structure definition is authored for testing purposes and no version of it will ever be intended for genuine usage. This aligns the hand-written page summary with the already-applied generated element definitions and removes the remaining stale wording without touching generated SVG artifacts.

Recommendation:
Keep this commit as-is. It is a narrow source correction in an active narrative page that completes the FHIR-48306 clarification; no further core FHIR source work was identified for this issue.
