FHIR-12632: Fix ElementDefinition Vital Signs example label

Issue request:
FHIR-12632 was a Published/Persuasive FHIR-I change request asking to replace DSTU2 DAF profile examples in the StructureDefinition and ElementDefinition notes with STU3/core examples. The Jira description names Vital Signs and ClinicalDocument profile examples, while the resolution records Data Absent Reason and ClinicalDocument profile examples.

Initial application:
Commit 77cd78889cce26f63b32f940eb5ad1d3a5eeed7f applied the issue by replacing the StructureDefinition DAF Patient and US Core extension examples with ClinicalDocument and Data Absent Reason examples, and by changing the ElementDefinition resource-constraint example links from the external DAF Patient profile to the local vitalsigns profile links. That initial ElementDefinition hunk left the visible link text as "DAF Patient", so the source still displayed the old DAF example name even though the target profile had been changed.

Additional context:
The current StructureDefinition notes were later refactored and no longer contain the ClinicalDocument resource-constraint example, but they do still use the Data Absent Reason extension example through the current extensions-location macro. The ElementDefinition page remains an active source page for the ElementDefinition type, and source/fhir.ini maps ElementDefinition to elementdefinition while listing ElementDefinition as a type. The current Vital Signs profile source defines the linked profile as "Vital Signs Base Profile".

AutoFHIR reconciliation:
This commit changes only the stale ElementDefinition example label from "DAF Patient" to "Vital Signs Base Profile". No StructureDefinition source change is needed because the current StructureDefinition notes no longer carry the stale DAF label and already use a current Data Absent Reason extension example.

Recommendation:
Keep this commit as-is. It completes the remaining visible part of the original non-substantive example refresh without broadening the issue into unrelated profile or extension-example changes.
