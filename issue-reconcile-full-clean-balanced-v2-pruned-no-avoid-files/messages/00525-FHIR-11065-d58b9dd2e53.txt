FHIR-11065: Use proxy in Consent privacy directive text

Issue request:
FHIR-11065 was a Published/Persuasive CBCC correction for the DSTU2 Consent page, section 6.4.1. The issue asked to replace the idiosyncratic term "Substitute Decision Maker" with the more generic "proxy" and to replace "client" language with "healthcare consumer" / "consumer" in the Privacy Consent Directive paragraph.

Initial application:
The Jira comment records svn revision 10603. Git commit 362208d37f5ff6d1154327d54817e05dc6c3634a (#11065 - correct wrong wording) applied the "client" to "healthcare consumer" / "consumer" changes in source/consent/consent-introduction.xml, but left "Substitute Decision Maker" unchanged. Later Consent refactoring moved the same paragraph into source/consent/consent-notes.xml without changing that term.

Additional context:
Consent is an active resource in source/fhir.ini, and source/consent/consent-notes.xml is the current active Consent narrative source containing the affected Privacy Consent Directive paragraph. Current source/consent/consent-introduction.xml already uses generic "personal representative" language in the Scope and Usage section, which is consistent with the issue rationale. A disabled legacy Contract ConsentDirective profile also contains "Substitute Decision Maker", but source/fhir.ini only notes that ConsentDirective became Consent and no active fhir.ini/list reference to that profile was found, so it was not edited for this Consent issue.

AutoFHIR reconciliation:
Changed the active Consent Privacy Consent Directive paragraph from "delegate authority to a Substitute Decision Maker" to "delegate authority to a proxy", completing the terminology substitution requested by the published issue while preserving the already-applied healthcare-consumer wording.

Recommendation:
Keep this source fix. It completes the published CBCC correction in active Consent narrative source; revisit the legacy Contract ConsentDirective profile only if that disabled artifact is intentionally reactivated in the current build.
