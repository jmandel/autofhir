FHIR-15797: Fix Blood Pressure profile summary list formatting

Issue request:
FHIR-15797 is a Published/Persuasive STU3 technical correction for FHIR-core profiles. It reported that the Blood Pressure profile text summary rendered the bullet children under item 3 as siblings and made the following item 4 appear as a new list.

Initial application:
The issue was originally applied in git commit c3aea2a3e283dd9a40883ec92ab0df20531fa72e, whose subject references #15802 and #15797 and adjusts the Blood Pressure summary row in source/observation/observation-vitalsigns-profile-spreadsheet.xml. During the later source rework, the Blood Pressure profile summary moved into source/observation/structuredefinition-profile-bp.xml; the current source retained the corrected item-3 indentation but still expressed the following top-level item as a new "1." item with under-indented children.

Additional context:
Observation is active in source/fhir.ini, source/igs.xml includes the Observation Vital Signs Profiles IG, and source/observation/implementationguide-Observation-vitalsigns.xml lists StructureDefinition/bp as an IG resource. The combined branch already contains the FHIR-15802 audit for the same historical commit, but FHIR-15802 concerned the Blood Pressure LOINC typo rather than this summary-list formatting. Zulip only had the tracker bot notification for FHIR-15797, and Confluence had no direct references.

AutoFHIR reconciliation:
This commit updates both Blood Pressure profile summary extensions in source/observation/structuredefinition-profile-bp.xml so the final top-level requirement is explicitly item 4 and its nested bullets are indented under that item. No coded constraints or profile semantics were changed.

Recommendation:
Keep this source fix. It preserves the original applied non-substantive correction in the active R6 source and lets the normal publication build regenerate the rendered Blood Pressure profile summary with a single ordered list and nested bullets.
