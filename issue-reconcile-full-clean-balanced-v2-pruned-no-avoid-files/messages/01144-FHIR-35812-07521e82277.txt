FHIR-35812: Align :text identifier display wording

Issue request:
FHIR-35812 was a Published/Persuasive with Modification FHIR-core search-page issue for R5. It asked the specification to clarify whether the `:text` modifier for token search parameters applies to Identifier text and, if so, how; the accepted wording named CodeableConcept.text, Coding.display including nested codings, the text and coding display within Identifier.type, and Identifier.assigner.display.

Initial application:
The issue was initially applied in commit 6a0622d0bdd16adf3b66af7e8cace93733820b27, which added Identifier.assigner.display to the detailed `:text` section of source/search.html. Commit 82418ca8e77ceefa65a24270427f91e0a7d64f6e later verified PR 1799 and preserved that detailed wording, but the modifier summary table and the linked search-modifier-code CodeSystem still omitted Identifier.assigner.display.

Additional context:
Later search-page work added reference support and Reference.display examples for `:text`, and FHIR-32673 defined `:text-advanced` as the advanced-text-processing counterpart to token `:text`. The current search page defines modifiers by reference to the search-modifier-code CodeSystem, and source/fhir.ini actively includes the search-modifier-code value set that uses that CodeSystem, so the stale parallel definitions remained part of the current build surface.

AutoFHIR reconciliation:
Updated source/search.html so the `:text` summary row, detailed `:text` section, `:text-advanced` summary row, and detailed `:text-advanced` section consistently list Identifier.assigner.display while retaining the later Reference.display context. Updated source/searchparameter/codesystem-search-modifier-code.xml so the `text` and `text-advanced` concept definitions carry the same examples.

Recommendation:
Keep this commit as-is. It completes the already-approved identifier clarification across the active search-page and CodeSystem surfaces without changing the search algorithm or expanding beyond the established `:text`/`:text-advanced` textual-value semantics.
