FHIR-43353: Correct vital signs unit binding summary

Issue request:
FHIR-43353 is an Applied FHIR-core Observation change request from OO, resolved Persuasive with Modification for R6. It asked to remove the overly restrictive required ucum-vitals-common binding from Vital Signs component values, and the approved resolution also called for a preferred UCUM binding on Observation.valueQuantity and a preferred component.valueQuantity UCUM binding.

Initial application:
The issue was applied in git 5fb05686fb, which changed the formal Vital Signs Base Profile source to add a preferred ucum-vitals-common binding for Observation.valueQuantity and relax Observation.component.valueQuantity from required to preferred. Later FHIR-47136/FHIR-44721 work changed the component valueQuantity binding to the all-UCUM value set http://unitsofmeasure.org/vs, matching the later approved component-unit direction.

Additional context:
Observation is active in source/fhir.ini, and source/observation/implementationguide-Observation-vitalsigns.xml includes StructureDefinition/vitalsigns, so the edited profile source is in the current build. The current formal differential already has preferred bindings for Observation.value[x] and Observation.component.value[x]:valueQuantity, but both source-backed summary extensions still described Observation.valueQuantity.code as having a required Vital Signs Units binding and a fixed UCUM system. FHIR-44721 is already represented on the combined branch and confirms the current all-UCUM component binding; FHIR-49736 previously removed unrelated stale component mandatory summary text from the same base profile.

AutoFHIR reconciliation:
This commit updates the structuredefinition-summary and profile-summary extensions in source/observation/structuredefinition-profile-vitalsigns.xml so the Vital Signs Base Profile summary says UCUM units are preferred and Observation.valueQuantity.code has a preferred binding to Vital Signs Units. It leaves the already-correct formal valueQuantity and component.valueQuantity bindings unchanged.

Recommendation:
Keep this source-changing commit. It completes the remaining FHIR-43353-facing source cleanup without reopening the later FHIR-44721 component binding decision or making broader Vital Signs summary modernization outside this issue.
