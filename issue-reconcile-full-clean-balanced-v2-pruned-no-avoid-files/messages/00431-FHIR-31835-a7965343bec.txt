FHIR-31835: Align SubstanceDefinition jurisdiction binding

Issue request:
FHIR-31835 was Published/Persuasive for R5 and asked that the SubstanceSpecification jurisdiction and language elements use the same bindings used elsewhere in FHIR, and that countryOfOrigin have a required binding.

Initial application:
No source commit found in this checkout explicitly names FHIR-31835. The issue appears to have been applied through the broader BRR MedDef binding work: commit 9ee11711505a added SubstanceDefinition.name.language, SubstanceDefinition.name.jurisdiction, and SubstanceDefinition.sourceMaterial.countryOfOrigin bindings, with countryOfOrigin required but jurisdiction left as an example binding. Later commit ba6dd4995575 changed name.language to the current required all-languages binding, and commit f48feed3e0a updated the jurisdiction value set URL to the current THO jurisdiction value set.

Additional context:
SubstanceSpecification is represented in the current build as the active SubstanceDefinition resource; source/fhir.ini lists substancedefinition under active resources and assigns it to BRR. The current source already satisfies the language and countryOfOrigin portions of the issue, and related FHIR-31543/FHIR-31836 binding work supports keeping substance-specific value sets mostly at example strength. Jurisdiction is not substance-specific, though, and the current FHIR common jurisdiction binding uses the THO jurisdiction value set with extensible strength and the common-binding marker.

AutoFHIR reconciliation:
This commit updates only SubstanceDefinition.name.jurisdiction in active source, adding the common-binding extension and changing binding strength from example to extensible while preserving the THO jurisdiction value set. It leaves name.language and sourceMaterial.countryOfOrigin unchanged because they already have the requested required bindings.

Recommendation:
Keep this source fix. It completes FHIR-31835 without changing the broader substance-specific example bindings reviewed under FHIR-31836; if BRR later wants product/substance name jurisdictions to remain weaker than the common jurisdiction binding, that should be recorded as a new explicit decision.
