FHIR-46911: Clarify MedicationAdministration subpotent dose text

Issue request:
FHIR-46911 was Applied as Not Persuasive with Modification for R6 after a Pharmacy WG 9-0-0 vote. The requester found MedicationAdministration.isSubPotent confusing when described as "Full dose was not administered" and also noted the related subPotentReason element. The WG kept the subPotent term but decided to clarify the description with the ordered-dose meaning.

Initial application:
Commit be847eb09f2234df9555e6f35a2256a794d5ad9a applied the issue by changing only MedicationAdministration.isSubPotent.short from "Full dose was not administered" to "An indication that the full ordered dose was not administered". The same source still left isSubPotent.definition and both subPotentReason description strings using the older "full dose" wording.

Additional context:
MedicationAdministration is active in source/fhir.ini, and source/medicationadministration/structuredefinition-MedicationAdministration.xml is the authoritative resource StructureDefinition source. The May 2025 Pharmacy WG minutes explain that "full dose" was ambiguous between the intended "full ordered dose" and a typical/usual guideline dose, and record the passed motion to add "ordered" to the current description. Zulip searches for this issue and the element terms found no conflicting discussion.

AutoFHIR reconciliation:
Updated MedicationAdministration.isSubPotent.definition and MedicationAdministration.subPotentReason short/definition in the active StructureDefinition source so all built descriptions consistently refer to the full ordered dose.

Recommendation:
Keep this source fix as-is. The element names remain unchanged per the WG decision, and no further core changes are needed unless Pharmacy later reopens the naming question.
