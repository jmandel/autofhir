FHIR-14254: Align Claim submit examples with sequence names

Issue request:
FHIR-14254 was Published/Persuasive for STU3 and requested consistent names for elements that refer to sequence elements across Claim, ClaimResponse, and ExplanationOfBenefit. The accepted pattern was that a referring element should use the referenced element name plus Sequence, such as Claim.item.sequence being referenced from ClaimResponse.item.itemSequence.

Initial application:
The issue was initially applied in three Jira-tagged commits on 2017-12-04: 5747911b8432630cf2723cebc98907a7118bff53 for ClaimResponse, e7de0775bc639ffc5422d59636df328ea4fc3167 for Claim, and 38d54b901fc5ed78cc46dbc139000fbe5315501b for ExplanationOfBenefit. Those commits renamed the active resource definitions and many examples from legacy *LinkId/sequenceLinkId forms to the current *Sequence names, but they did not update the Claim $submit request and response snippets.

Additional context:
Claim, ClaimResponse, and ExplanationOfBenefit are active resources in source/fhir.ini. The Claim $submit OperationDefinition is in the active Claim source tree, and its build example extensions reference $submit-request.txt and $submit-response.txt. Current Claim and ClaimResponse StructureDefinition source defines Claim.item.careTeamSequence and ClaimResponse.item.itemSequence, so the snippets were stale relative to the normative element names. Other remaining legacy-name hits found during the check were either fhir.ini cross-version rename mappings, retired ProcessRequest source, or the separate legacy QUICK model definition rather than current Claim/ClaimResponse/EOB source.

AutoFHIR reconciliation:
Updated the Claim $submit request example to use careTeamSequence and the Claim $submit response example to use itemSequence. No other source changes were made.

Recommendation:
Keep this commit as-is. It fixes the only in-build stale references found in the seed resource family and aligns the operation examples with the current resource definitions; no further core source change is recommended for FHIR-14254.
