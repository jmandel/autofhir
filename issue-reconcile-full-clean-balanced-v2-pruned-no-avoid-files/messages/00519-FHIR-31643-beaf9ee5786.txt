FHIR-31643: Point Citation links to EBM resource page

Issue request:
FHIR-31643 was a Published/Persuasive CDS technical correction raised against R4B for FHIR-core-Citation. The request said the Citation Resource example page was only a placeholder and asked for complete Citation examples; the recorded resolution was "Agreed, will add Citation examples to the spec" for R5.

Initial application:
No commit explicitly tagged FHIR-31643 was found. The issue appears to have been applied implicitly in the former core Citation source: commit a519c04228cfe36a06fc82ef797d78c4f8352a16 added source/citation/citation-example-systematic-meta-review.xml and updated list-Citation-examples.xml in October 2021, and later Citation example commits including e3baacba23b0f32cb9abb32147bb104091928413 added further example instances.

Additional context:
Citation is no longer an active FHIR-core resource. Commit 71567db3ee039ac6977be5f96a7e013896569a36 removed source/citation and the active Citation build configuration, while current core narrative states that Citation moved to the Evidence Based Medicine on FHIR IG. The EBM IG now has a Citation page and many Citation example instances, but the core links introduced by the move targeted https://build.fhir.org/ig/HL7/ebm/StructureDefinition-Citation.html, which currently returns 404.

AutoFHIR reconciliation:
This commit updates the in-scope core narrative/history references to Citation so they point to https://build.fhir.org/ig/HL7/ebm/citation.html, the current EBM IG Citation page. It intentionally does not restore source/citation or add core Citation examples because the Citation Resource and its example inventory are now maintained outside this FHIR-core build.

Recommendation:
Keep this commit as-is for FHIR-core. If additional Citation examples or example metadata are needed, reconcile that in the HL7 EBM IG source; do not reintroduce core Citation example files for FHIR-31643.
