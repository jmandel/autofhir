FHIR-5547: Remove stale XML Tools download references

Issue request:
FHIR-5547 was a Published/Persuasive DSTU1 change request for the FHIR-core downloads page. It reported that the XML Tools zip linked from downloads.html#refimpl was corrupt and also asked whether the document-rendering stylesheet in that zip had been updated to use Bundle resources for documents.

Initial application:
The corruption fix was applied in git-svn commit 5d8921e1b92ab1c33853a4d87685fc1a8031e7a2, whose message is "#5547 xml tools file corrupt" and whose git-svn-id records SVN revision 4006, matching the Jira comment. That commit changed the old Java Utilities.path helper used by the historical build tooling. The Java implementation tree is no longer present in the current core checkout, and current publish.ini has no XMLTools zip generation or XML Tools download file entry.

Additional context:
Later R5-era decisions moved mutable tool and reference implementation listings out of the core downloads page. FHIR-30088 replaced the downloads-page Reference Implementations rows, including the XML Tools row and downloads.html#refimpl anchor, with a Confluence Open Source Implementations link. FHIR-31735 then moved additional validation and tool-specific documentation to the FHIR Tools Registry. A contemporaneous Zulip #committers thread for "XML tools" records Ward Weistra asking during FHIR-31735 whether the dead XML Tools URL should stay, and Grahame Grieve replying "remove it". Those related issues are already represented on the combined branch, so this commit does not publish duplicate decisions for them.

AutoFHIR reconciliation:
This commit removes the remaining current-source references to the deleted downloads.html#refimpl anchor. It replaces the Documents page's obsolete XML Tools stylesheet sentence with current guidance to apply the document presentation rules using implementation tooling, changes Validation to describe running Schematron with an ISO Schematron processor instead of a nonexistent XML Tools download, and changes Resource Formats to point to current implementation support resources rather than the removed downloads-page reference platforms section. The edited pages are active build inputs in source/hierarchy.xml and publish.ini.

Recommendation:
Keep this source-changing commit. It preserves the historical FHIR-5547 fix without reviving the obsolete XML Tools zip in core, and it aligns the remaining current pages with the later work-group decision to remove stale in-spec tool downloads. Any future XML document-rendering or Schematron tooling inventory should be maintained through the referenced implementation-support/tooling registries unless FHIR-I explicitly decides to reintroduce a core download.
