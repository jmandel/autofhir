FHIR-5302: Correct Slot status search parameter wording

Attribution note: surfaced while reviewing FHIR-5303, but direct Jira backing for this change is FHIR-5302.

Issue request:
FHIR-5303 was a Published PA change request from the Jan 2015 ballot. It objected that the Slot scope/usage wording categorized slots as open, booked, or blocked while the SlotStatus value set used BUSY, FREE, BUSY-UNAVAILABLE, and BUSY-TENTATIVE. The accepted resolution was Persuasive with Modification: remove the v2-derived wording from the Slot scope and usage section.

Initial application:
The historical application commit be470cb21da4107826991acb4bd95704746d88a2, titled "Trackers: 5301, 5302, 5303 Slot and Schedule Ballot reconciliation and QA updates," removed the HL7 v2.7 block containing "Slots are categorized as open, booked, or blocked" from source/slot/slot-introduction.xml and changed the SlotStatus binding description from appointment-focused wording to slot-focused wording in the then-current Slot spreadsheet source.

Additional context:
Slot is an active current-build resource in source/fhir.ini, and the current Slot source already uses the free/busy status model in source/slot/structuredefinition-Slot.xml, source/slot/codesystem-slotstatus.xml, and source/slot/valueset-slotstatus.xml. However, the active Slot search parameter bundle still described Slot.status as "The free/busy status of the appointment," which is a missed current source location for the same slot-versus-appointment wording correction. Jira, Zulip, and Confluence searches found no later or conflicting decision for FHIR-5303.

AutoFHIR reconciliation:
This commit updates source/slot/bundle-Slot-search-params.xml so the Slot-status search parameter description says "The free/busy status of the slot." It leaves the already-correct Slot scope/usage text and SlotStatus code system/value set unchanged.

Recommendation:
Keep this focused source fix as-is. No follow-up is needed for FHIR-5303 unless the PA work group wants a broader cleanup of other Slot search parameter descriptions outside this ballot-comment scope.
