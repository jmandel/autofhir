FHIR-22531: Finish lipid panel example cleanup

Issue request:
FHIR-22531 was Applied with resolution Not Persuasive with Modification for R6. It asked about multiple DiagnosticReport/Observation lipid profiles sharing the title "Example Lipid Profile"; the OO decision was to remove the example lipid profiles from the DiagnosticReport profile page, link users to the lipid panel DiagnosticReport example instead, and name the example appropriately.

Initial application:
Prior FHIR-22531 source commits removed the DiagnosticReport lipid ImplementationGuide/profile files, emptied the DiagnosticReport packs list, created/repointed the lipid panel DiagnosticReport example, and updated links from the removed profile pages to diagnosticreport-example-lipid-panel.html. Those changes left two stale source details: the active lipid panel example still declared meta.profile http://hl7.org/fhir/StructureDefinition/lipids-diagnostic-report even though no DiagnosticReport profile pack remains, and profiling-examples.html still displayed the old "Example Lipid Profile" label for the lipid panel link.

Additional context:
The current build scope still includes DiagnosticReport in source/fhir.ini, source/diagnosticreport/list-DiagnosticReport-examples.xml actively lists DiagnosticReport/lipid-panel-example, and source/diagnosticreport/list-DiagnosticReport-packs.xml contains no profile pack entries. OO minutes from 2025-01-14 confirm that the lipid profiles were examples rather than intended core profiles and specifically call for the example wording to read "Lipid Panel Report". Remaining "Example Lipid Profile" occurrences under source/structuredefinition are generic StructureDefinition examples/invariant fixtures outside the DiagnosticReport profile listing and were not changed here.

AutoFHIR reconciliation:
Removed the stale meta.profile declaration and matching comment from source/diagnosticreport/diagnosticreport-example-lipid-panel.xml, and changed the profiling-examples.html visible link text from "Example Lipid Profile" to "Lipid Panel Report" while preserving the intended link to diagnosticreport-example-lipid-panel.html.

Recommendation:
Keep this source fix. It completes the applied FHIR-22531 decision without restoring removed profiles or broadening the change into unrelated StructureDefinition fixtures; if those older generic examples need modernization, handle that under a separate tracker.
