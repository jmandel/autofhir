FHIR-38873 + FHIR-38682: Normalize MedicationStatement naming

Attribution note: surfaced while reviewing FHIR-38873, but direct Jira backing for this change is FHIR-38873 + FHIR-38682.

Issue request:
FHIR-38873 was a Published/Persuasive Pharmacy technical correction for R5 asking that narrative be checked for consistent FHIR resource naming after the MedicationUsage resource was renamed back to MedicationStatement, including capitalization/spelling such as MedicationUsage, MedicationAdministration, and MedicationStatement.

Initial application:
No git commit found in the current repository history explicitly mentions FHIR-38873. The underlying rename-back decision was applied by FHIR-38682 in commits b2032629f28 and fa758a19fa, which renamed the resource folder and many MedicationUsage/Medication Usage references to MedicationStatement/Medication Statement. Later history left three current-build inconsistencies: the root MedicationStatement ElementDefinition still used malformed medicationstatement/medicationadministration wording, and the Library and Measure CMS146 data-requirements JSON examples still named the removed MedicationUsage type.

Additional context:
source/fhir.ini actively builds MedicationStatement, Library, and Measure, so the edited resource definition and examples are in current core build scope. The remaining MedicationUsage references after this reconciliation are intentionally retained in source/terminologies/codesystem-fhir-old-types.xml, whose description says it lists old resource names no longer used in this FHIR version. Pharmacy minutes for 2022-11-14 record FHIR-38873 as "Will be updated," and no exact-key Zulip discussion was found.

AutoFHIR reconciliation:
This commit updates the active MedicationStatement root ElementDefinition to use the canonical MedicationStatement and MedicationAdministration resource names where it was using malformed lower-case concatenations. It also changes the included CMS146 data-requirements examples in source/library and source/measure from MedicationUsage to MedicationStatement, aligning them with the active resource name and with source/library/library-cms146-example.xml.

Recommendation:
Keep this source fix. It removes the remaining current-build naming defects found for FHIR-38873 while preserving the intentional old-type terminology entry for compatibility/history.
