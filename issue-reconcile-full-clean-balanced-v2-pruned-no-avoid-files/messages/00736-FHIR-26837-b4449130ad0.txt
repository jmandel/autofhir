FHIR-26837: Correct NamingSystem translate-id examples

Issue request:
FHIR-26837 was a Published/Persuasive with Modification FHIR-core NamingSystem change request from the Vocabulary work group. It asked to add a NamingSystem $translate-id operation for identifier translation, with source identifier value, source identifier type, target identifier type, optional preferredOnly and date inputs, and a Parameters return carrying target identifiers with preferred flags and validity periods.

Initial application:
Commit 25159ea161 added OperationDefinition/NamingSystem-translate-id, included it in source/namingsystem/list-NamingSystem-operations.xml, and added request/response example snippets. Later same-operation work corrected output parameter types and naming through FHIR-38717 and FHIR-42703, both already represented on the combined branch. The current operation definition and list entry therefore apply the substantive issue, but the original request example still had malformed Parameters JSON for targetType and preferredOnly, and the response example represented the preferred flag as a string rather than a JSON boolean.

Additional context:
NamingSystem is active in source/fhir.ini, and the translate-id OperationDefinition directly references the edited request and response snippet files through build example extensions, so these examples feed the current built operation page. Zulip and Confluence evidence corroborate the identifier-translation use case and the 2021 Vocabulary tracker handling. No later decision was found that narrows the seed operation or makes the malformed example syntax intentional.

AutoFHIR reconciliation:
Corrected the $translate-id request example so targetType uses a valid valueCode property and preferredOnly uses valueBoolean with a JSON boolean. Corrected the response example so targetIdentifier.preferred also uses valueBoolean with a JSON boolean.

Recommendation:
Keep this source commit. It completes the seed operation's current source surface by fixing active examples introduced with the operation, without duplicating the already-published FHIR-38717 and FHIR-42703 follow-up fixes or broadening into unrelated spelling cleanup.
