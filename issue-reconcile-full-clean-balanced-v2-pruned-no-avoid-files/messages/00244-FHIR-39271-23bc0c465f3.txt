FHIR-39271: Align MedicationStatement status wording

Issue request:
FHIR-39271 was a Published Pharmacy ballot issue with resolution Not Persuasive with Modification. The resolution kept the R5 status redesign but renamed MedicationUsage back to MedicationStatement, confirmed that the status value set includes draft, and clarified that MedicationStatement.status reflects the recording status of the statement while MedicationStatement.adherence carries taking/not-taking information.

Initial application:
The status redesign was applied earlier by 6cdd7b792e for FHIR-32060, changing the codes to recorded, entered-in-error, and draft and adding a comment that the new statuses differ from prior MedicationStatement statuses. The rename back to MedicationStatement was applied by b2032629f2 and fa758a19fa for FHIR-38682, which restored the active resource folder and fhir.ini entries. That application left one active MedicationStatement status code definition saying "medication usage" and converted the FHIR-32060 transition note into the malformed phrase "MedicationStatement or MedicationStatement".

Additional context:
FHIR-38682, FHIR-39329, and FHIR-39333 are the same Pharmacy discussion family: the work group kept the status/adherence model, changed the resource name back, clarified adherence text, and expanded the example adherence codes. The October 2022 Pharmacy minutes and linked Zulip thread support the same interpretation that status is about the statement record and adherence is used for taking/not-taking assertions, including cases without a prescription instruction.

AutoFHIR reconciliation:
This commit updates the active MedicationStatement status CodeSystem draft definition to refer to the medication statement rather than medication usage, and fixes the adjacent StructureDefinition status comment so it clearly points to previous releases of MedicationStatement. Both files are under the active source/medicationstatement resource listed in source/fhir.ini, so they feed the current build.

Recommendation:
Keep this commit. It is a narrow source correction to make the current active MedicationStatement status wording match the published FHIR-39271 resolution and its supporting status/adherence decisions; the broader related Jira issues are cited as context rather than separately reconciled here.
