FHIR-5872: Link OperationOutcome to DetectedIssue extension

Issue request:
FHIR-5872 was a Published/Persuasive FHIR-core change request from DSTU1 asking to add a standard extension for linking OperationOutcome to the then-Contraindication resource and to point to that mechanism from the OperationOutcome/Contraindication wording.

Initial application:
The Jira comment says the issue was applied in SVN revision 5862, and git commit 361aa07d5c81530bc985e333d2ab7d318c8d09b8 is that revision. It added an OperationOutcome.issue extension named contraindication with value Reference(Contraindication). Later commit 1408563d743f15eff785f59063b34b538b4d4651 and Jira FHIR-8043 renamed Contraindication to DetectedIssue, and commit cc54b56e72272bed97b5c33459fc90bc2bfe52d8 updated the OperationOutcome narrative to use DetectedIssue.

Additional context:
OperationOutcome and DetectedIssue are active current-build resources in source/fhir.ini, while fhir.ini records Contraindication as a retired name that became DetectedIssue. The extension definition no longer belongs in core source: commit dd468d4f1799dd79819315b211588ef1cf4586e0 removed OperationOutcome extension definitions from core, and the current FHIR Extension Pack source maintains http://hl7.org/fhir/StructureDefinition/operationoutcome-detectedIssue with context OperationOutcome.issue and value Reference(DetectedIssue). A community search found no FHIR-5872-specific contrary discussion; a 2024 implementers Zulip thread mentions operationoutcome-detectedIssue as an existing OperationOutcome extension.

AutoFHIR reconciliation:
This commit makes the active OperationOutcome narrative point to the standard OperationOutcome Detected Clinical Issue extension. It does not move or duplicate the extension definition back into core, because the authoritative extension source is now in the Extension Pack.

Recommendation:
Keep this commit as-is. It completes the seed request in the current core build by linking the active resource narrative to the standard extension while preserving the current extension-pack ownership of the StructureDefinition.
