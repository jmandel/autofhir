FHIR-15755: Show section focus in mixed Composition example

Issue request:
FHIR-15755 was Published with a Persuasive with Modification resolution for the STU3 Composition resource. It requested adding Composition.section.focus, providing a composition-section-subject extension for rare multi-subject compositions, adding a mother/child example that shows a section with a different focus than the Composition subject, and making the logical-subject rule clear.

Initial application:
The Jira-tagged commit 832f5cb8c6 added Composition.section.focus, notes for compositions about multiple entities, and the mixed mother/child Composition example. The current source still contains the focus element definition and SHALL wording, and the section-subject extension is now present in the FHIR Extension Pack. However, the active mixed example did not actually include Composition.section.focus on the mother section.

Additional context:
Composition is an active resource in source/fhir.ini and the mixed example is listed in source/composition/list-Composition-examples.xml, so the example is in build scope. Later FHIR-27891 changed document-bundle inclusion wording involving Composition.section.focus but did not change the section focus semantics. FHIR-54500 is a later Triaged question about family-history section focus and is not a final source-edit decision.

AutoFHIR reconciliation:
This commit updates source/composition/composition-example-mixed.xml so the mother's section uses Composition.section.focus to reference Patient/infant-mom, making the example demonstrate the FHIR-15755 rule. It also corrects the same section title from "Mpther's Details" to "Mother's Details" so the intended mother section is clear.

Recommendation:
Keep this source fix as-is. The core Composition definition, notes, and extension-pack placement already satisfy the rest of FHIR-15755; any broader family-history clarification should wait for a final decision on later issues such as FHIR-54500.
