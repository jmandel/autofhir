FHIR-19461: Rename Claim diagnosis ICD10 binding

Issue request:
FHIR-19461 is a Published/Persuasive Financial Management change request for STU3 Claim asking to change the binding name on Claim.diagnosis.diagnosis from ICD10 to ICD10-example because the old name made the sample value set look complete.

Initial application:
The issue was included in broad Claim commit afb5ec66f6, but that application changed the binding description to "Example ICD10 Diagnostic codes" while leaving the binding identifier/name as ICD10. The 2021 spreadsheet-to-StructureDefinition refactor preserved that remaining ICD10 bindingName in source/claim/structuredefinition-Claim.xml.

Additional context:
Claim is active in source/fhir.ini, so source/claim/structuredefinition-Claim.xml is current build input. The current binding already has example strength and points at the sample ICD-10 value set, and later binding-strength work such as FHIR-53057 did not alter this diagnosis binding name. Jira and community searches found no later decision superseding the requested rename.

AutoFHIR reconciliation:
Changed the elementdefinition-bindingName extension on Claim.diagnosis.diagnosis[x] from ICD10 to ICD10-example, leaving the existing example strength, description, and ValueSet URL unchanged.

Recommendation:
Keep this source fix. It completes the specific Published request without broadening the change to other Claim-family artifacts that were not part of FHIR-19461.
