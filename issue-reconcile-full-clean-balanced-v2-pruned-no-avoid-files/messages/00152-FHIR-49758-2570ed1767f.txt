FHIR-49758: Remove stale RelatedArtifact example wording

Issue request:
FHIR-49758 was Applied with a Persuasive with Modification resolution for R6. The approved change replaced RelatedArtifact usage in the EBM resources by removing Evidence.relatedArtifact, EvidenceVariable.relatedArtifact, Citation.relatedArtifact, and ArtifactAssessment.content.relatedArtifact, adding citeAs markdown where applicable, and adding relatesTo backbone elements with ArtifactRelationshipType-target relationships.

Initial application:
The main source change was applied in git commit 16e8cfe739612663eb51cf987d198926a137b635 and merged by HL7/fhir pull request #3397 in 4b88be5eb7e5f709fc79d844cfd5cf79fd2648a9. The current active Evidence, EvidenceVariable, and ArtifactAssessment StructureDefinition source already contains citeAs and relatesTo and no longer defines the removed relatedArtifact elements. A later source refactor 0e7c1284959c0184d03a19e0df5e7fb3900d905a made ArtifactAssessment.content.relatesTo a contentReference to ArtifactAssessment.relatesTo. Citation was later removed from the current build.

Additional context:
The remaining current-spec problem was not in the core element definitions but in active Evidence example metadata. FHIR-45094 had added the quoted-source Evidence example and its list entry for Evidence.relatedArtifact before FHIR-49758; after the structural replacement, the actual relatedArtifact element was removed/commented out but both example descriptions still told readers the example used the removed relatedArtifact element. FHIR-53002 later changed relatesTo.type from code/required to CodeableConcept/extensible for ArtifactAssessment, Evidence, EvidenceVariable, and Citation, so the current datatype/binding shape intentionally differs from the original FHIR-49758 wording.

AutoFHIR reconciliation:
This commit updates source/evidence/evidence-example-quoted-source.xml and source/evidence/list-Evidence-examples.xml to describe the quoted-source example without naming the removed relatedArtifact element. It makes no structural changes because the active StructureDefinition source already reflects the FHIR-49758 replacement, adjusted by later applied decisions.

Recommendation:
Keep this commit as-is. It removes the last active EBM resource source references to relatedArtifact while preserving the later FHIR-53002 CodeableConcept/extensible relatesTo.type decision and the current build state where Citation is no longer an active core resource.
