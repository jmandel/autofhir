FHIR-36665: Align NutritionOrder enteral schedule note

Issue request:
FHIR-36665 was Published with resolution Persuasive with Modification. It asked how to represent a NutritionOrder PRN/as-needed order and its reason; the approved change was to make the NutritionOrder schedule locations for oralDiet, supplement, and enteralFormula into backbone elements with .timing, .asNeeded, and .asNeededFor children.

Initial application:
No relevant source commit message explicitly named FHIR-36665. The implementation appears in 1a5062f0a4, "Update Nutrition Order with JIRA dispositions," which converted the NutritionOrder schedule elements into BackboneElement structures and added the timing, asNeeded, and asNeededFor children for oralDiet.schedule, supplement.schedule, and enteralFormula.administration.schedule.

Additional context:
The current build actively includes NutritionOrder through source/fhir.ini, and the authoritative StructureDefinition now contains the requested PRN schedule elements. While checking the surrounding NutritionOrder source, the active notes page still pointed implementers to removed enteral formula paths, including the nonexistent enteralFormula.schedule path instead of the current enteralFormula.administration.schedule path. Confluence OO minutes identify FHIR-36665 as part of the R5 NutritionOrder ballot work and later track it as needing application; Zulip searches found no directly relevant conflicting discussion.

AutoFHIR reconciliation:
This commit corrects source/nutritionorder/nutritionorder-notes.xml so the enteral feeding note uses the current NutritionOrder element paths enteralFormula.maxVolumeToAdminister and enteralFormula.administration.schedule. This keeps the built narrative consistent with the applied PRN schedule backbone and current StructureDefinition.

Recommendation:
Keep this source fix. The main FHIR-36665 structural change is already present, and this commit removes the remaining misleading NutritionOrder narrative references discovered in the same schedule area.
