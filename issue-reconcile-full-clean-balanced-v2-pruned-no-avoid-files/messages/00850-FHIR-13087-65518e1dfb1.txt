FHIR-13087: Correct No Known Latex Allergy example label

Issue request:
FHIR-13087 was a Published, Persuasive with Modification Patient Care change request for FHIR-core AllergyIntolerance. It asked for the common no-known-allergies use case to be covered by examples, with the approved resolution to add three examples for NKA, NKDA, and No Latex Allergy using AllergyIntolerance.code.

Initial application:
The issue appears to have been initially applied in git commit bd3f8a7ba5, whose message includes "#13087 Add allergy examples for negation" and which added the three AllergyIntolerance example instances. The current source still contains AllergyIntolerance/nka, AllergyIntolerance/nkda, and AllergyIntolerance/nkla instances using SNOMED CT negated AllergyIntolerance.code values, and the active AllergyIntolerance examples list includes entries for all three.

Additional context:
AllergyIntolerance is active in source/fhir.ini, so the resource folder and examples list are in current build scope. Later core issues FHIR-25514 and FHIR-26410 refined the surrounding AllergyIntolerance negation guidance: FHIR-25514 removed the clinicalStatus invariant that was inappropriate for "no known" cases, and FHIR-26410 clarified that AllergyIntolerance.code is the preferred place to represent no known allergies and added the NKA example inline. A Patient Care Confluence negation page lists FHIR-13087 in the AllergyIntolerance negation issue chronology, and no direct Zulip hit for FHIR-13087 was found. The current examples satisfy the substantive request, but the examples list description for the No Known Latex Allergy entry misspelled "Latex" as "Latext".

AutoFHIR reconciliation:
This commit corrects the active AllergyIntolerance examples list description from "No Known Latext Allergy" to "No Known Latex Allergy". No example content, code, coding system, or conformance semantics were changed.

Recommendation:
Keep this commit as-is. The requested examples are present and aligned with later negation guidance, and this source correction removes the remaining visible typo in the build-scoped examples list for the third requested example.
