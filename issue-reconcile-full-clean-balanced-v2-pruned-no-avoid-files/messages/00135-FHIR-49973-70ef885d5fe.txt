FHIR-49973: Add stratum scores to CMS146 summary report

Issue request:
FHIR-49973 was an Applied/Persuasive FHIR-core CQI change request for R6. It asked that the CMS146 summary MeasureReport example show measure scores for the group and group.stratifier.stratum levels, using numerator 200, denominator 500, denominator-exclusion 100, and a proportion score of 200/(500-100)=0.5.

Initial application:
The issue was initially applied by 710ff0b715f08e1607c008ee0fa600711742ad90, merged through HL7/fhir#3423, which added group.scoring=proportion, group.improvementNotation=increase, and group.measureScoreQuantity=0.5 to the CMS146 examples. In the current CMS146 summary report source, that application left the group-level score correct but did not add any stratum-level measureScore values.

Additional context:
source/fhir.ini lists MeasureReport as an active resource, and source/measurereport/list-MeasureReport-examples.xml includes the CMS146 summary example, so source/measurereport/measurereport-cms146-cat3-example.xml is in current build scope. The current MeasureReport StructureDefinition includes MeasureReport.group.stratifier.stratum.measureScore[x], and related FHIR-49921 confirms the proportion calculation uses numerator divided by denominator after exclusions and exceptions.

AutoFHIR reconciliation:
This commit adds measureScoreQuantity value 0.5 to the six CMS146 summary strata where denominator minus denominator-exclusion is non-zero. It intentionally leaves the other and unknown gender strata without a score because their denominator after exclusions is zero, making a numeric proportion undefined rather than 0.0.

Recommendation:
Keep this commit as-is. It completes the applied FHIR-49973 request in the active core MeasureReport summary example without changing unrelated individual or subject-list examples, and without inventing scores for undefined zero-denominator strata.
