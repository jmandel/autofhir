FHIR-31625: List Medication ad comparator example

Issue request:
FHIR-31625 is a Published/Persuasive Pharmacy R5 change request to create a Medication example using the new "sufficient quantity for" code. The Jira comments and its parent FHIR-30879 clarify that the requested Medication example should demonstrate the QuantityComparator code `ad`, meaning sufficient quantity to reach a stated total.

Initial application:
FHIR-30879 was applied by c4807a5165ee632872ef9f6289fee8e9e1abbb5f, which added `ad` to the QuantityComparator code system. FHIR-31625 was partially applied by 934e7819020c72ee6e3ba509ecb5445a1850f109, which added `medicationexample0322.xml` using `<comparator value="ad">` and `medicationexample0323.xml` using the older `qs` ingredient-strength code. Follow-up commit 3eb5717dffc361838e1914e146f174a6f40b45b6 added only `medicationexample0323` to the Medication examples list/header, leaving the `ad` example source present but omitted from the discoverable example index.

Additional context:
FHIR-19439 established the separate `qs` CodeableConcept path for plain sufficient quantity, while FHIR-30879 and the linked Zulip discussion distinguish that from `ad`/"sufficient quantity to" on Quantity. Medication is active in `source/fhir.ini`, and after later FHIR-46416 and FHIR-48405 cleanups the `medicationexample0322.xml` body still correctly demonstrates `strengthQuantity` with the `ad` comparator. Before this reconciliation, the active Medication folder had 25 example XML files but the Medication examples list and header had 24 links, with `medicationexample0322` as the only missing example.

AutoFHIR reconciliation:
This commit adds `medicationexample0322` to `source/medication/list-Medication-examples.xml` and `source/medication/medication-examples-header.xml` with text identifying it as the hand-sanitizer example that uses the `ad` Quantity comparator. The example body is intentionally unchanged because it already models the approved `ad` code.

Recommendation:
Keep this fixed commit. It makes the already-authored FHIR-31625 example visible in the current Medication examples page; no further Pharmacy or MnM decision is needed unless the work group wants broader narrative about `ad` vs. `qs`.
