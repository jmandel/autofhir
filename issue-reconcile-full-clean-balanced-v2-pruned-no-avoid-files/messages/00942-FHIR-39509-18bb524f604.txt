FHIR-39509: Align SupplyRequest scope summary

Issue request:
FHIR-39509 was a Published/Persuasive R5 Orders and Observations change request asking to update the SupplyRequest Scope and Usage text by replacing "The scope of the SupplyRequest resource is for recording the request of supplies used in the healthcare process" with "The scope of the SupplyRequest resource is for recording the request of supplies used in the healthcare process to be delivered to a particular location." Jira records the resolution as "Make change as proposed" with an 8-0-0 vote.

Initial application:
The issue was applied before R5 publication. Commit 94e4f4c06f1d1aef0dbd9f5b8ccdbbb1af0bf0fe inserted the requested location-focused sentence into source/supplyrequest/supplyrequest-introduction.xml, and follow-up commit 125fd027345c3417618377d5c7e1114125e7f235 corrected the leading-word typo introduced by the first commit. The retained local SupplyRequest introduction and the current HL7/oo-incubator SupplyRequest page-content source both contain the approved sentence.

Additional context:
The 2022-11-21 OO HCP minutes record the motion for four neighboring SupplyRequest updates, including this scope-and-usage change, and the 2022-11-28 minutes record creating linked Jira issues FHIR-39508 through FHIR-39511 for the package of changes. Later, the current core branch stopped building SupplyRequest: source/fhir.ini has no active supplyrequest entry in the resource or work-group lists, core ballot/module pages point SupplyRequest to the OO Incubator IG, and commit 3b38b80cf23f9cbb306fab8fcedb293315478c32 removed the immature OO resources from active core lists. A Zulip OO discussion confirms the supply resources were pulled out of core to progress together in an OO incubator IG. However, the active core Medications module still repeated the pre-FHIR-39509 SupplyRequest/SupplyDelivery summary phrase while linking to the external SupplyRequest page.

AutoFHIR reconciliation:
This commit updates source/medications-module.html, an active core narrative page, so its SupplyRequest/SupplyDelivery summary says the request of supplies is to be delivered to a particular location. It intentionally leaves the dormant local source/supplyrequest/supplyrequest-introduction.xml unchanged because that retained source already has the approved wording and is no longer active in the core build. It also makes no external repository edit because the current HL7/oo-incubator SupplyRequest source already has the FHIR-39509 sentence.

Recommendation:
Keep this source commit. Future authoritative SupplyRequest resource-page changes should be made in HL7/oo-incubator, but active core pages that summarize or link to SupplyRequest should remain aligned with the approved location-focused scope.
