FHIR-46029: Remove stale DeviceMetricObservation OID

Issue request:
FHIR-46029 is an Applied/Persuasive R6 OO change request asking to remove the DeviceMetricObservationProfile core profile because it was not referenced usefully, had questionable constraints, and Devices confirmed any needed profiling should live in an IG rather than core.

Initial application:
The removal was applied by commit 0c4fafcc6c9db057a5817f7db252ccecff100d55 and merged by HL7/fhir#3803 as dd48894db7387cc525402ab3307d2b66301b2d9e. That application deleted the DeviceMetricObservation StructureDefinition source, profile narrative, the satO2 example, active Observation implementation guide/example references, and the source/oids.ini entry for http://hl7.org/fhir/StructureDefinition/devicemetricobservation.

Additional context:
OO minutes on 2025-06-24 record the decision to remove the profile from Observation after DEV indicated DeviceMetric was sufficient, and the 2025-10-09 minutes record the 11-0-3 vote. A committers Zulip thread during PR #3803 confirms the implementer was removing DeviceMetricObservation references including OIDs. A later unrelated source/oids.ini edit, 9a629f87585abe7125746f230050b53761adf90a, accidentally reintroduced the devicemetricobservation OID entry while removing sevco. FHIR-49923 corrected the profile's FMM before removal and is already represented on the combined branch; it does not require reintroducing the removed profile.

AutoFHIR reconciliation:
Removed the stale source/oids.ini entry for http://hl7.org/fhir/StructureDefinition/devicemetricobservation. source/oids.ini feeds the active OID List page through publish.ini and source/hierarchy.xml, so retaining an OID for a removed core StructureDefinition would leave the current build with an active registry reference to a profile that no longer exists in core.

Recommendation:
Keep this source fix. The profile source and Observation references are already gone, and this commit restores the OID registry cleanup that PR #3803 originally made before a later unrelated edit reintroduced the line.
