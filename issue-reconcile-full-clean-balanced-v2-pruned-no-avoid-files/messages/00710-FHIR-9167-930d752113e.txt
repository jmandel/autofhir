FHIR-9167: Correct Break-Glass DICOM links

Issue request:
FHIR-9167 was a Published/Persuasive with Modification Security WG change asking AuditEvent to make recording a break-glass event more obvious. The applied resolution required a break-glass AuditEvent example, a pointer from the AuditEvent common-scenarios event-code table, updated break-glass dragon text, an OperationOutcome note, and a security-page reference to the Break the Glass protocol.

Initial application:
The issue was partly applied in October 2019. Commit 60d57263ef5a87ba3260badaf09beb6692e8eb4b added the AuditEvent/example-breakglass-start example, commit 8f93636e058fa1a4b9ce4240fea41076e10e6760 added the Break-Glass started row to source/auditevent/auditevent-notes.xml and other AuditEvent guidance, and commits 64b57e7a7436014ad8c2623fdba04ee1e20ffa3e and 3f0086f26e2033889a536a2c9c0b346add1b1245 fixed early breakglass example references/content. The current source also includes the example in source/auditevent/list-AuditEvent-examples.xml and links to it from the security break-glass text.

Additional context:
FHIR-9166 was resolved no-change as a duplicate of FHIR-9167, so it is supporting background rather than a separate current reconciliation. Later Security WG issue FHIR-53885 moved the standalone Break the Glass material from security-labels.html to security.html; the current security page still includes the FHIR-9167 AuditEvent example and OperationOutcome guidance. The active source/fhir.ini resource entry for auditevent=AuditEvent makes source/auditevent/auditevent-notes.xml build-scope source. A 2022 DICOM-link conversion commit, c1d765ab73d0bf137c30793009baf937473668ac, changed the Break-Glass row to DICOM canonical links but preserved the copied anchors for 110114 and 110122 while the visible row labels remained 110113 and 110127.

AutoFHIR reconciliation:
This commit corrects the Break-Glass started row in source/auditevent/auditevent-notes.xml so the visible DICOM Security Alert code 110113 links to DCM_110113 and the visible Emergency Override Started code 110127 links to DCM_110127. No other source changes were made because the example, example-list entry, security-page Break the Glass text, and later section move are already present in current build-scope source.

Recommendation:
Keep this commit as-is. It is a narrow source fix to the remaining FHIR-9167 semantic/link defect in an active AuditEvent page; no further core FHIR source work is indicated for this issue unless the Security WG later revisits the broader Break the Glass guidance.
