FHIR-41407: Allow Group as QuestionnaireResponse source

Issue request:
FHIR-41407 was an Applied/Persuasive with Modification FHIR-core QuestionnaireAnswers change request asking that QuestionnaireResponse support family or household Groups as both author and source. The accepted resolution was to add Group as an allowed author and source, with comments on both elements indicating that the referenced Group SHALL contain only Patient and/or RelatedPerson members and that other collections of people must use Organization.

Initial application:
The prior Jira-tagged application was git commit ecc9102e069e6363c7341ca65018009c84ba4eab, which added Group and a limiting comment only to QuestionnaireResponse.author. The current build-scope QuestionnaireResponse StructureDefinition still lacked Group on QuestionnaireResponse.source and still had no source-side limiting comment, so the Applied resolution was only partially represented.

Additional context:
QuestionnaireResponse is an active resource in source/fhir.ini, so source/questionnaireresponse/structuredefinition-QuestionnaireResponse.xml feeds the current build. FHIR-41674 records the related Group-versus-Organization boundary concern and was later resolved no-change because other source changes already addressed the general concern. Confluence SDC minutes for 2023-08-03 and 2023-10-05 record discussion and the Persuasive with Modification disposition for FHIR-41407; no directly relevant Zulip thread was found.

AutoFHIR reconciliation:
This commit completes the source-side application by adding Group as a targetProfile for QuestionnaireResponse.source and adding the required source comment limiting Group use to family, household, or similar units whose members SHALL be Patient and/or RelatedPerson. It also aligns the existing author comment with the Jira resolution's SHALL-member wording without broadening the already-applied author type change.

Recommendation:
Keep this commit as-is. It is a narrow current-build source fix that completes the Applied Jira resolution and preserves the intended boundary between Group and Organization for QuestionnaireResponse actors.
