FHIR-13732: Restore Common Languages to trial-use status

Issue request:
FHIR-13732 was Published with resolution Not Persuasive with Modification for the STU3 Languages value set request. The approved disposition rejected merging the larger language-code list, changed the Language binding away from extensible/Common Languages toward a broader maximum value set, and specifically said the Common Languages preferred value set should be non-normative while maximum bindings for normative elements should be normative.

Initial application:
The Jira comment cites svn revision 14714, which maps to git commit d141f78c79b5de737def71b3d00737af2789503e. That commit changed the Language binding from extensible Common Languages with max All Languages to preferred Common Languages with max All Languages, and added a Trial-Use standards-status extension to source/terminologies/valueset-languages.xml. Follow-up commits normalized that extension to valueCode trial-use.

Additional context:
Later R6 work changed the binding representation to the current required All Languages primary binding plus starter Common Languages additional binding pattern, which is consistent with FHIR-13732's goal of allowing the complete BCP-47 language space while retaining Common Languages as a starter/preferred set. However, commit 9987f9c0c3ce5ec4f277c22ed71cbb2d210efeb6 changed Common Languages back to normative without citing FHIR-13732 or another language value-set decision, reintroducing the status contradiction the seed issue had resolved.

AutoFHIR reconciliation:
Restored source/terminologies/valueset-languages.xml to standards-status trial-use. The current binding rows and resource StructureDefinitions were left unchanged because their required All Languages plus starter Common Languages pattern already reflects later binding-policy decisions and preserves the maximum/all-language behavior required by the seed.

Recommendation:
Keep this source fix. If future normative-ballot cleanup wants Common Languages normative, that should be backed by an explicit work-group decision because FHIR-13732 intentionally made the Common Languages starter/preferred set non-normative.
