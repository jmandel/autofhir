FHIR-5301: Correct Schedule service type search guidance

Issue request:
FHIR-5301 was a Published Patient Administration DSTU1 technical correction for the Schedule resource. The ballot comment asked that the incomplete Schedule scope/usage text be replaced with guidance on finding schedules for HealthcareService categories or practitioner/location actors, and the final Persuasive with Modification resolution required removing HL7 v2 references and reworking the Schedule scope and usage section with more accurate information.

Initial application:
The issue was initially applied by commit be470cb21d, which removed the unfinished ballot placeholder and the explicit HL7 v2/RIM discussion from source/schedule/schedule-introduction.xml and added the actor and checking-availability guidance. A later 2017 Schedule QA commit preserved that applied guidance but changed the old type-property sentence into a generic "type parameter" sentence.

Additional context:
Schedule is active in source/fhir.ini, and the current Schedule source no longer has v2 references. Later Published issue FHIR-22687 changed Schedule.serviceType to CodeableReference(HealthcareService) and split the Schedule search surface into service-type and service-type-reference search parameters. The active Schedule introduction still referred to a non-existent generic "type parameter", while bundle-Schedule-search-params.xml defines service-type and service-type-reference and no Schedule type search parameter.

AutoFHIR reconciliation:
This commit updates the active Schedule scope/usage guidance to name the current service-type and service-type-reference search parameters, preserving the FHIR-5301 searching guidance while aligning it with the current Schedule conformance source.

Recommendation:
Keep this source-changing commit. It completes the current-build reconciliation for FHIR-5301 by retaining the applied scope/usage rewrite, confirming the v2 references are gone, and correcting the only stale search-parameter name found in the active Schedule narrative.
