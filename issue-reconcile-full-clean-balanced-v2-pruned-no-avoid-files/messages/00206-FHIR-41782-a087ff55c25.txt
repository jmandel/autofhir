FHIR-41782: Correct HealthcareService referral eligibility code

Issue request:
FHIR-41782 was Applied/Persuasive for HealthcareService referral requirements. The approved resolution added HealthcareService.referralRequired, expanded HealthcareService.eligibility with value[x], period, and an invariant requiring code when value is present, and updated the earlier FHIR-39306 eligibility example from referral-required to specialist-referral-required.

Initial application:
The source was initially updated by a2b02dee29, which added referralRequired, the expanded eligibility backbone, and the new eligibility CodeSystem/ValueSet. The same commit introduced the intended specialist-referral-required code in the CodeSystem and referralRequired comment, but misspelled the same sample code as speciailist-referral-required in the HealthcareService.eligibility.value[x] comment. A follow-up commit, 542ad8d070, corrected the CodeSystem id and added the ValueSet binding.

PA WGM minutes for 2023-09-13 record the FHIR-41782 motion and note its relationship to FHIR-39306. Later source history corrected adjacent validation details, including eligibility.period's datatype and invariant warning behavior, without changing the intended specialist-referral-required eligibility code.

AutoFHIR reconciliation:

Recommendation:
