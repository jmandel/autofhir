FHIR-14370: Remove stale Provenance userId wording

Issue request:
FHIR-14370 was Published/Persuasive for STU3 by the Security WG. It asked that the defunct Provenance Party References section be rewritten or removed now that the old userId/URL reference pattern was gone; the recorded resolution was to remove section 6.3.4.4 "Party References".

Initial application:
Commit df8241d8ed19f08b12c18f34bf71c7bdbf611ef9 explicitly included GF#14370 and removed the Party References section from source/provenance/provenance-notes.xml. Earlier commit f72fd6237875c6ba9d2a21e235881c7fed559700 applied the related Reference-definition work from FHIR-13570 by moving Provenance examples and spreadsheet text away from URI/userId-style choices toward Identifier/Reference choices.

Additional context:
Provenance is an active resource in source/fhir.ini, and source/provenance/list-Provenance-examples.xml lists provenance-example-sig as a current Provenance example. Later FHIR-15659 work simplified Provenance.agent.who to a single Reference element, so the old whoIdentifier/whoReference split no longer exists in the current build. Current source/provenance/provenance-notes.xml no longer contains the Party References section, but the signature example still had a visible XML comment using the old camelCase userId wording.

AutoFHIR reconciliation:
This commit changes only that stale example comment, replacing "userId" with "user identifier" and correcting the same sentence's spelling, while leaving the authoritative example structure unchanged: Provenance.agent.who remains a Reference carrying an identifier.

Recommendation:
Keep this commit as-is. It preserves the original application of FHIR-14370 and removes the only remaining current Provenance wording that could be mistaken for the removed userId element; no broader Provenance text rewrite is needed.
