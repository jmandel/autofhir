FHIR-39006: Use List schema for XDS example

Issue request:
FHIR-39006 was Published with resolution Persuasive for R5. It asked that, because DocumentManifest was retired and IHE XDS features were replaced with List, the XDS mapping and XDS SubmissionSet example from DocumentManifest be taken over by List.

Initial application:
The issue was initially applied in commit ed4d4f176dfec6d909d93ad47a0fa4a7de3c1208, which added XDS mappings to List, added List notes about XDS use, and introduced source/list/list-example-xds.xml. That new example correctly used the List resource, but its schemaLocation still pointed at ../../schema/documentmanifest.xsd copied from the retired DocumentManifest example.

Additional context:
FHIR-38865 finalized removal of DocumentManifest from core, and the current fhir.ini actively registers List while DocumentManifest is only present in removed-resource/history/change-map contexts. Zulip discussion before the ballot described XDS SubmissionSet as moving from DocumentManifest to List.

AutoFHIR reconciliation:
This commit changes the XDS SubmissionSet List example schemaLocation from documentmanifest.xsd to list.xsd so the example's declared schema matches the resource it now represents.

Recommendation:
Keep this source fix. It completes the narrow mechanical part of the FHIR-39006 migration and avoids leaving a retired DocumentManifest schema reference in an active List example.
