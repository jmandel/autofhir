FHIR-53412: Clarify Timing offset source text

Issue request:
FHIR-53412 was an Applied/Persuasive R6 FHIR-I change request to add Timing.repeat.startOffset and Timing.repeat.endOffset and clarify the relationship between Timing.repeat.when and the implicit repeat window, after the submitter narrowed the request to exclude startEvent and endEvent.

Initial application:
Commit ba10a6f24d181dec80b69dd90e68e0337421e7a0 added the Timing spreadsheet rows, constraints, narrative, and dosage examples for this change. The current source already contains the requested startOffset/endOffset elements, and source/fhir.ini lists Timing and Dosage as active normative datatypes, so source/datatypes/timing.xml, source/datatypes.html, and source/dosage-examples.html are in the current build scope. The application left seed-scope wording defects: endOffset said events "step" instead of "stop", the new Timing repeat-window paragraph had a broken code tag for count, and a dosage example still described startOffset as an extension instead of the new element.

Additional context:
FHIR-I minutes for 2025-11-10 confirm the 10-0-0 motion to include startOffset and endOffset but not startEvent/endEvent. Later issues FHIR-54058 and FHIR-54062 are Resolved - change required, not Applied/Published, and request broader Timing example-table and constraint updates. FHIR-54252 raises a larger Pharmacy dosage-cycle design concern. Those later issues are related context but are not decided by this seed commit.

AutoFHIR reconciliation:
Corrected only the bounded seed-scope source defects: the endOffset short definition and definition now say repeat-period events stop before the end of the period, the Timing narrative uses a valid code tag for count, and the dosage example identifies Timing.repeat.startOffset as an element. This commit intentionally does not redesign the offset constraints or the Timing example table because that belongs to later unresolved application work.

Recommendation:
Keep this commit as the FHIR-53412 cleanup. Revisit FHIR-54058, FHIR-54062, and FHIR-54252 separately when resolved-change-required issues are in scope, especially for the offset constraints, the Timing example table, and cyclic dosage modeling.
