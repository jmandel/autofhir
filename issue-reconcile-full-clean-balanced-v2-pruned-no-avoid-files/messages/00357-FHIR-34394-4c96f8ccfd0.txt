FHIR-34394: Restore recordedDate recorder contrast

Issue request:
FHIR-34394 was Published/Persuasive with Modification for R5 Patient Care. It asked to clarify that Condition.recordedDate represents the first recorded date while Condition.recorder represents the most recent author, without renaming either element.

Initial application:
The issue was initially applied in git commit 7fc5cd4fe9, which added the requested recordedDate contrast sentence and the new recorder comment in source/condition/structuredefinition-Condition.xml. A tightly related later commit, 431d503d44 for FHIR-34395, replaced recorder/asserter with participant and intentionally struck the recordedDate sentence that referred to recorder.

Additional context:
Condition is an active resource in source/fhir.ini, so source/condition/structuredefinition-Condition.xml is build scope. Later Applied work in FHIR-39602 restored Condition.recorder and Condition.asserter, and FHIR-48804 refined the recorder definition while leaving the current recorder comment that says the recorder is the most recent author. With recorder present again, the recordedDate comment was the only remaining source location that no longer matched the FHIR-34394 resolution.

AutoFHIR reconciliation:
Restored the missing final sentence to Condition.recordedDate.comment: "By contrast, the recorder is the most recent author." This is a source correction in the active Condition StructureDefinition and aligns the recordedDate-side comment with the existing recorder-side comment.

Recommendation:
Keep this commit as-is. The edit is limited to the missing sentence required by the published FHIR-34394 decision and is consistent with later Condition recorder decisions; no separate related issue should be reopened by this change.
