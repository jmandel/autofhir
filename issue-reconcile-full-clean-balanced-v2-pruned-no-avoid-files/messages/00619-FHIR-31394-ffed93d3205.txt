FHIR-31394: Align ClinicalUseDefinition scope summaries

Issue request:
FHIR-31394 was Published/Persuasive with Modification for R5. It asked to reconcile ClinicalUseIssue/ClinicalUseDefinition scope notes after warning was introduced, add NutritionProduct and BiologicallyDerivedProduct to the subject and interactant/therapy choices, update affected descriptions, and adjust the status wording away from "current issue".

Initial application:
The issue was mostly applied before this reconciliation. Git commits 9bc8c0b, f61a872, and fac0ec4 added NutritionProduct and BiologicallyDerivedProduct to ClinicalUseDefinition.subject, ClinicalUseDefinition.interaction.interactant.item[x], and the reused otherTherapy.treatment model, and updated the main Scope/Boundaries narrative. FHIR-32064 and FHIR-31790 later fixed related warning and status gaps, but the current resource-level description and Medication Definition module summary still described only medicinal product/medication/device/procedure and the module summary still omitted warning.

Additional context:
ClinicalUseDefinition is active in the current build. contraindication.otherTherapy reuses the indication.otherTherapy content reference, so the added NutritionProduct and BiologicallyDerivedProduct target profiles in that shared element cover the contraindication request. FHIR-31790, already represented on the combined branch, intentionally supersedes the exact old status-definition wording by changing ClinicalUseDefinition.status to a required publication-status code. Confluence minutes show FHIR-31394 review/coordination but no different scope decision, and Zulip search found no conflicting discussion.

AutoFHIR reconciliation:
This commit updates source/clinicalusedefinition/structuredefinition-ClinicalUseDefinition.xml so the StructureDefinition description and root element short/definition include substance, biologically derived product, and nutrition product along with the already-reconciled warning type. It also updates source/medication-definition-module.html so the active module overview no longer omits warning or the added product types. These hunks are necessary because the stale summaries contradicted the applied conformance and Scope/Boundaries source and could mislead implementers about current ClinicalUseDefinition scope.

Recommendation:
Keep this source fix. It is a narrow completion of the published FHIR-31394 application; no further core change is needed for the element target-profile additions or status wording unless a separate work group decision chooses to rewrite the broader ClinicalUseDefinition description style.
