FHIR-44784: Align ImplementationGuide manifest profile wording

Issue request:
FHIR-44784 is an Applied FHIR-core Change Request for ImplementationGuide. It requested changing the profile short text from "Profile(s) this is an example of" to "Profile(s) this resource is valid against" and replacing the example-only comment with wording that profile can identify profiles expected to be valid for both example and non-example resources.

Initial application:
The Jira comment records application in git commit 3d93b0b026. That commit updated ImplementationGuide.definition.resource.profile in the active ImplementationGuide source, but it did not update the parallel ImplementationGuide.manifest.resource.profile element, which still carried the same obsolete short text and example-only comment.

Additional context:
ImplementationGuide is active in source/fhir.ini, and source/implementationguide/structuredefinition-ImplementationGuide.xml is the authoritative source for both definition.resource.profile and manifest.resource.profile. FHIR-I minutes from 2024-03-25 show the vote and rationale: profiles are increasingly used to govern infrastructure/canonical resources that are not examples, and the old examples list should not appear as the element comment. Jira search found no separate manifest.resource.profile issue, and Zulip search found no conflicting discussion.

AutoFHIR reconciliation:
This commit applies the FHIR-44784 wording to ImplementationGuide.manifest.resource.profile as the missed parallel source location. The definition.resource.profile element was already correct, so no other source changes were needed.

Recommendation:
Keep this commit as-is. It completes the applied wording correction across the two active ImplementationGuide resource profile elements and removes the remaining example-only description that could mislead implementers using manifest.resource.profile for non-example IG resources.
