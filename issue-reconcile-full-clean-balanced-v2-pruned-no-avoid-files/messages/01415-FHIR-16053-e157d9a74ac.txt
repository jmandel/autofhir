FHIR-16053: Correct CompartmentDefinition pluralized prose

Issue request:
FHIR-16053 was a Published/Persuasive STU3 technical correction for FHIR-core CompartmentDefinition. It asked to fix prose that pluralized the resource name as "CompartmentDefinitions", because FHIR resource type names should not be pluralized that way; the approved replacement was common-noun "compartment definitions" wording.

Initial application:
The issue was initially applied by git-svn import commit 7a4eb42986b33c6a1fe454781c5379e2c2c0f388, whose subject is "GF#16053 - fix typo" and whose git-svn revision 14425 matches the Jira comment. That commit changed the original note from "CompartmentDefinitions can only be defined by HL7 International" to "compartment definitions can only be defined by HL7 International".

Additional context:
CompartmentDefinition is an active current-build resource in source/fhir.ini. Later Applied issue FHIR-51604 intentionally revised the first note to "CompartmentDefinition instances" and added clarification about HL7-defined resources being hostable on other servers, preserving the seed issue's intent for the original sentence. However, the current active narrative still contained the same pluralized-resource-name pattern in two nearby statements: one introduced by the FHIR-51604 application and one in Boundaries and Relationships. FHIR-51604 and FHIR-19651 are already represented on the combined branch, so this commit only reconciles the seed typo.

AutoFHIR reconciliation:
This commit changes source/compartmentdefinition/compartmentdefinition-introduction.xml to say "CompartmentDefinition resources" instead of "CompartmentDefinitions" in both remaining prose occurrences. The edit is limited to active source narrative, preserves the later substantive clarifications, and also removes the accidental double space in the FHIR-51604-added sentence.

Recommendation:
Keep this source fix as-is. No further core follow-up is needed for FHIR-16053 unless a future work-group decision intentionally adopts a different style for referring to CompartmentDefinition resources.
