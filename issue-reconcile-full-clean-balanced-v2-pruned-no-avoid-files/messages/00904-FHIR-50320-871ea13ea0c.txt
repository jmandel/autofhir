FHIR-50320: Correct copied validate-code coding array

Issue request:
FHIR-50320 was an Applied/Persuasive Vocab technical correction for R6 asking that the CodeSystem $validate-code CodeableConcept example represent CodeableConcept.coding as an array rather than a single JSON object.

Initial application:
The issue was initially applied by commit 8930df49cfda9f57b445806eb1d114c707a54e9b, which changed source/codesystem/$validate-code-request.txt and source/valueset/$validate-code-request.txt from "coding" : { ... } to "coding" : [{ ... }]. The current operation example sources remain correct.

Additional context:
The April 2025 Zulip thread that led to FHIR-50320 confirmed the CodeSystem/$validate-code valueCodeableConcept example was a documentation typo. Vocabulary minutes on 2025-08-14 approved the technical correction after Lloyd McKenzie indicated the proposed disposition could proceed. While checking FHIR-18065, the active terminology-service.html narrative page was found to contain a copied validate-code CodeableConcept example that still used the old object shape.

AutoFHIR reconciliation:
This commit updates the active terminology service copy so its CodeableConcept.coding member is an array, matching the corrected operation example files and the CodeableConcept datatype contract.

Recommendation:
Keep this commit as-is. It is a narrow copied-page cleanup for the same validate-code example family and avoids leaving a visible current-source example that contradicts the already-applied FHIR-50320 correction.
