FHIR-11453 was a Published/Persuasive FHIR-core modules-page correction from the DSTU2 ballot. It asked to fix the bullet text "What information is going to be exchanged" by adding the question mark, moving that bullet to the last position, adding links to the content domains, and adding follow-on guidance about the remaining sections.

Initial application:

That commit updated source/modules.html by adding the question mark, moving the bullet to the end of the then-current list, and adding the remaining-sections sentence, but it did not add any content-domain link.

Additional context:
The current source/modules.html page is in build scope through source/hierarchy.xml and publish.ini. Later FHIR-19572 added a Conformance bullet after the FHIR-11453 bullet, so the FHIR-11453 bullet was no longer last; later module evolution also made the hard-coded remaining-sections list stale relative to the included module index below.

AutoFHIR reconciliation:
This commit updates source/modules.html so the content question is again the last bullet, links it to the content modules in the included module index, and replaces the stale hard-coded module-area list with a durable reference to the complete module index below.

Recommendation:
Keep this commit as-is. It completes the missed linking/order portion of FHIR-11453 while preserving the later FHIR-19572 Conformance bullet and avoiding another hard-coded module list that can drift as modules change.
