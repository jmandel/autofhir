FHIR-14898: Point R4 history to archived diffs

Issue request:
FHIR-14898 was a Published/Persuasive FHIR-core-many request from the STU3-to-R4 ballot cycle asking for R3->R4 diffs because the then-current draft exposed R2 diffs while R3 was the current release. The accepted resolution said the R3/R4 diffs would be included before R4 publication.

Initial application:
The issue appears to have been applied during the R4 cycle by commit 3c3f93c3dae503d0598b2b5abfc927a3a8ea063f, which changed source/diff.html from a DSTU2 comparison to a Release 3/DSTU3 comparison. The published R4 site now contains the R3/R4 structural difference analysis and R3/R4 transform page.

Additional context:
Later R5/R6 work repurposed the current diff.html page to compare R4/R4B/R5 with the current R6 build and split the current version-specific diff pages. The current history page still linked the R4 release note's R3/R4 difference analysis to the relative diff.html, which now sends readers to the current R6 diff page instead of the archived R4 analysis. The current build does not publish r3maps.html, so the historical R4 transform reference also needs to point at the permanent R4 publication.

AutoFHIR reconciliation:
Updated build-scope source/history.html so the R4 release note links to the permanent R4 R3/R4 diff and transform pages and scopes the old compare-to-r3 footer instruction to the R4 publication.

Recommendation:
Keep this source fix. It preserves the current R6 diff pages while restoring implementer access from the current version history to the R3/R4 artifacts that satisfied FHIR-14898.
