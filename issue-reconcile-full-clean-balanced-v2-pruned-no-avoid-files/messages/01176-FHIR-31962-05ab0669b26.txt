FHIR-31962: Add Group to CanonicalResource list

Issue request:
FHIR-31962 was Published/Persuasive for R5 and asked that canonicalresource.html include the same table/list of resources inheriting from CanonicalResource that appears on references.html#canonical; the resolution was to put the table both places.

Initial application:
No commit explicitly mentioning FHIR-31962 was found on the relevant source paths. The CanonicalResource introduction was originally created with the [%canonical-resources%] include, and a later 2024 source edit replaced that include with an explicit maintained list of CanonicalResource implementers, so the requested content was present in current source but had to remain aligned with later resource modeling changes.

Additional context:
The CanonicalResource interface page is in current build scope through active source/fhir.ini infrastructure entries, and Group is an active resource in source/fhir.ini. FHIR-41583 later made Group carry CanonicalResource elements; git history shows Group.baseDefinition changed to CanonicalResource in 96e781301d8, and current Group source still declares the CanonicalResource template/base and Group.url canonical identifier. That made the CanonicalResource page list stale because it omitted Group.

AutoFHIR reconciliation:
Added Group to source/canonicalresource/canonicalresource-introduction.xml so the current CanonicalResource page lists all active, concrete resources that inherit from CanonicalResource. No other table/list content was changed.

Recommendation:
Keep this source fix. If the publisher later supports a generated CanonicalResource list on this page, replacing the maintained list with the generated include would reduce future drift; until then, this explicit list should include Group.
