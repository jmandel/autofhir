FHIR-43205: Align Ingredient example strength

Issue request:
FHIR-43205 was Applied/Persuasive for the BRR MedicinalProductIngredient/Ingredient example. The Jira reports that the Ingredient strength was shown as 5mg/1mg, which is not realistic because the numerator cannot exceed the denominator, and resolves to change the strength to 0.5mg/1mg.

Initial application:
The issue had been partially applied in upstream commit 2bc81a3d8d4417341b84d8f3d5f46ec71b6cd0a6, which changed source/ingredient/ingredient-example.xml numeric concentration and reference-strength values to 0.5 and 0.503. That application left the public XML comment saying 5mg/1mg and copied invariant-test resources still using the old 5 and 5.03 values.

Additional context:
Ingredient is active in source/fhir.ini, and source/ingredient/list-Ingredient-examples.xml lists ingredient-example as a built Ingredient example. The originating Zulip discussion explicitly called out both the rendered 5mg/1mg concentration and the source XML comment as misleading, and BRR minutes record the 16-0-0 vote for FHIR-43205.

AutoFHIR reconciliation:
This commit updates the remaining stale XML comment in the active Ingredient example to 0.5mg/1mg and adjusts the derived tablet-weight explanation from 10mg to 100mg. It also aligns the three Ingredient ing-1 invariant-test inputs with the accepted 0.5 and 0.503 strength values and fixes the copied "calculations" typo in the same edited denominator comment.

Recommendation:
Keep this source fix. It completes the already-applied Jira decision in current build-scope source without changing the ing-1 pass/fail conditions; no broader Ingredient model change is indicated.
