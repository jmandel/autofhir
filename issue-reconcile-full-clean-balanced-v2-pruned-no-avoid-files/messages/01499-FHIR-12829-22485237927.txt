FHIR-12829: Fix CapabilityStatement resource profile link

Issue request:
FHIR-12829 was a Published FHIR-core Conformance change request with a Persuasive with Modification resolution to support linking profiles to REST resources by moving CapabilityStatement.profile inside CapabilityStatement.rest.resource and naming it supportedProfile.

Initial application:
The Jira comment records svn revision 12734. In git history, 3046b26fdb (#12829 & #10121 CapabilityStatement tasks) removed the top-level CapabilityStatement.profile row from the CapabilityStatement source spreadsheet and added CapabilityStatement.rest.resource.supportedProfile plus an example. Current source defines CapabilityStatement.rest.resource.profile and CapabilityStatement.rest.resource.supportedProfile, and source/fhir.ini preserves a migration mapping from CapabilityStatement.profile to CapabilityStatement.rest.resource.supportedProfile. One active narrative page still retained the obsolete CapabilityStatement.profile link.

Additional context:
Later FHIR-25462 clarified the difference between the system-wide CapabilityStatement.rest.resource.profile and use-case-specific CapabilityStatement.rest.resource.supportedProfile. The REST transactional-integrity paragraph discusses incomplete support for resource features and values, so the current resource-level profile element is the appropriate replacement for the removed top-level link. Direct FHIR-12829 Zulip and Confluence searches found no conflicting community guidance.

AutoFHIR reconciliation:
Updated the active source/http.html REST page to link to CapabilityStatement.rest.resource.profile and describe it as a resource profile, replacing the stale CapabilityStatement.profile anchor. No generated artifacts were edited, and the old-path migration mapping in source/fhir.ini was left intact.

Recommendation:
Keep this source fix as-is. It removes a broken/stale reference caused by the CapabilityStatement.profile move while aligning the REST narrative with the later profile vs supportedProfile clarification.
