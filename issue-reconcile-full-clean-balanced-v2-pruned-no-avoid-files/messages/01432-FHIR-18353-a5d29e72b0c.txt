FHIR-18353: Align conformance processing definition

Issue request:
FHIR-18353 was a Published/Persuasive with Modification FHIR-core issue for the extensibility page. It asked for more nuance around the requirement to "refuse to process" unknown modifier extensions, replacing the broad phrasing with a linkable definition of "process the data of" so that simply storing or moving whole resources unchanged would not be treated as prohibited processing.

Initial application:
Commit d095c440f325f9a3a3adf28bcad4c636839f1b5b applied the main extensibility-page change by defining "processing the data of a resource" and by changing the summary rule to say an application SHALL refuse to process the data of the resource or affected element. That application left the active conformance rules page with the older "processing the data of a resource typically means" wording in its Is-Modifier section.

Additional context:
source/conformance-rules.html is in current build scope through the active publish.ini conformance-rules.html entry and is linked from the extensibility page as the definition of modifier elements. FHIR-I minutes from 2019-04-15 record the final FHIR-18353 vote as clarifying that "refuse to process" means "refuse to process the data of". Related modifier-extension issues from the same meeting have already been represented on the combined branch, so this commit is limited to the remaining FHIR-18353 wording alignment.

AutoFHIR reconciliation:
Updated source/conformance-rules.html's Is-Modifier processing paragraph to use a formal "For the purpose of this section ... is taken to mean" definition and aligned the copied list punctuation with the corrected extensibility-page wording. No change was needed in source/extensibility.html, which already carries the d095c440f3 FHIR-18353 wording.

Recommendation:
Keep this commit. It completes the published clarification in the active conformance rules page without broadening the issue beyond the modifier-processing definition and leaves the already-correct extensibility text unchanged.
