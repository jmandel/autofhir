FHIR-20509: Align MeasureReport data-exchange wording

Issue request:
FHIR-20509 was a Published/Persuasive FHIR-core CQI change request to rename the MeasureReport report type code from data-collection to data-exchange for R5.

Initial application:
The original application changed the MeasureReport type CodeSystem concept and the mrp-1 invariant expression to use data-exchange, but some current MeasureReport narrative and definition strings still described the report type as data-collection.

Additional context:
The current MeasureReport resource is active in source/fhir.ini, and the current CodeSystem only defines the data-exchange code. FHIR-26681's validation wording is in the same MeasureReport type/score area, and FHIR-55083 later added the other report type without changing the stale data-collection phrase in the type definition.

AutoFHIR reconciliation:
Updated the active MeasureReport StructureDefinition, MeasureReport introduction, and the checked-in MeasureReport SVG tooltip so the report type prose consistently names data-exchange while preserving the existing mrp-1 invariant semantics.

Recommendation:
Keep this source fix. Future diagram regeneration should preserve the same data-exchange wording from the authoritative StructureDefinition.
