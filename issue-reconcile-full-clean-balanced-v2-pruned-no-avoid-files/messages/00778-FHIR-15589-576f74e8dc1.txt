FHIR-15589: Remove stale substitution modifier comment

Issue request:
FHIR-15589 was a Published Pharmacy change request, resolved Persuasive with Modification for STU3, after identifying missing modifier reasons on Medication.amount and MedicationRequest.substitution.allowed. The final resolution was to remove Medication.amount as an isModifier and remove MedicationRequest.substitution from being treated as an isModifier.

Initial application:
Jira comments record a pre-application at git-svn revision 13603 and application at revision 13825. In the git history, 5ebb8db8d2d83621e046ede3e487cec74eb4f79b is the explicit GF #15589 pre-application commit touching the old Medication and MedicationRequest spreadsheets; it added modifier-reason columns/reasons while the historical rows still carried modifier wording. Later source rework moved the resource definitions into current StructureDefinition XML, where Medication.amount no longer exists and MedicationRequest.substitution/allowed no longer have isModifier=true, but the old substitution.allowed comment saying it was labeled as a modifier remained.

Additional context:
source/fhir.ini actively includes Medication and MedicationRequest as current resources, so source/medication/structuredefinition-Medication.xml and source/medicationrequest/structuredefinition-MedicationRequest.xml are in current build scope. Current Medication only marks Medication.status as a modifier, not the retired Medication.amount element. Current MedicationRequest correctly marks status, intent, and doNotPerform as modifiers, but not substitution or substitution.allowed. Jira searches found only FHIR-15589 and the public-health parent FHIR-15584 for the Medication amount/substitution modifier terms; direct Zulip and Confluence searches found no conflicting community decision.

AutoFHIR reconciliation:
Removed the stale MedicationRequest.substitution.allowed[x] comment that said the element was labeled as a modifier. No Medication.amount source change was needed because that element is absent from the current Medication StructureDefinition, and no substitution modifier metadata needed removal because it was already absent.

Recommendation:
Keep this commit as-is. It preserves the existing non-modifier metadata and removes the remaining wording that contradicted the FHIR-15589 disposition and current ElementDefinition flags.
