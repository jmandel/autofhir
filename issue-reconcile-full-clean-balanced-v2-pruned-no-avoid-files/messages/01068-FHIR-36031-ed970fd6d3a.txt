FHIR-37199: Correct BDP division source-event reference

Attribution note: surfaced while reviewing FHIR-36031, but direct Jira backing for this change is FHIR-37199.

Issue request:
FHIR-36031 was Published with a Persuasive resolution for R5. It asked to update BiologicallyDerivedProduct descriptions, definitions, terminology bindings, and search parameters; among the requested definition changes, BiologicallyDerivedProduct.division described aliquots as distinguished by the same biologicalSource and productCode identifiers.

Initial application:
The Jira comment points to PR #1812 commit c721d59. In the main source history, 102e300798b7ca5cc171881c395792f6e63d4d67 applied the BDP definition updates and introduced the division definition that referenced biologicalSource and productCode. That was correct for the source state at the time because FHIR-34346 had recently renamed BiologicallyDerivedProduct.sourceIdentifier to BiologicallyDerivedProduct.biologicalSource.

Additional context:
BiologicallyDerivedProduct is an active resource in source/fhir.ini. Later Published issue FHIR-37199 renamed the shared Device, NutritionProduct, and BiologicallyDerivedProduct element from biologicalSource to biologicalSourceEvent and updated its definition/comment. The three authoritative StructureDefinitions now use biologicalSourceEvent, so the remaining BiologicallyDerivedProduct.division reference to biologicalSource was a stale element-name reference left from the FHIR-36031/FHIR-34346/FHIR-37199 change sequence. The generated-looking BiologicallyDerivedProduct SVG still has the same hover-title text and should be regenerated through the normal build process rather than hand-edited here.

AutoFHIR reconciliation:
This commit updates the authoritative BiologicallyDerivedProduct StructureDefinition so the division definition refers to biologicalSourceEvent, the current element name, while preserving the FHIR-36031 meaning that division distinguishes aliquots with the same source-event and product-code identifiers.

Recommendation:
Keep this source fix as-is. No further semantic change is needed for FHIR-36031; if maintainers want diagrams synchronized, regenerate the checked-in SVG artifacts from source.
