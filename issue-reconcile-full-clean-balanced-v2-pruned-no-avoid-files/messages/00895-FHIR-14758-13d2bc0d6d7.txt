FHIR-16148: Correct Encounter f202 diagnosis example comment

Attribution note: surfaced while reviewing FHIR-14758, but direct Jira backing for this change is FHIR-16148.

Issue request:
FHIR-14758 is a Published/Persuasive with Modification Patient Administration STU3 issue for FHIR-core Encounter. It asked to address principal diagnosis guidance for Encounter.diagnosis.role, preferably by updating the f202 Encounter example and removing the now-redundant encounter-primaryDiagnosis extension rather than adding a new principalDiagnosis role code.

Initial application:
The issue was initially applied by git commit c1e9ac08c9, which removed the encounter-primaryDiagnosis extension from source/encounter/encounter-example-f202-20130128.xml and added a second Encounter.diagnosis entry with Chief Complaint coding and rank=1. The current source no longer contains encounter-primaryDiagnosis or encounter-relatedCondition extension definitions in core or the Extension Pack search, so the extension-removal part remains applied.

Additional context:
Later Published Encounter decisions changed the current model. FHIR-16148 redesigned Encounter.reason and Encounter.diagnosis for R5, removed Encounter.diagnosis.rank, changed diagnosis.condition to CodeableReference, and moved diagnosis ranking for billing to Account. FHIR-38807 then completed the remaining current Encounter prose corrections, and FHIR-38784 later made Encounter.reason.use and Encounter.diagnosis.use repeat. These later decisions mean the old f202 comment's role=CC and rank=1 wording was no longer safe in the current build, even though the example entry itself remains useful as a diagnosis classified with Chief Complaint.

AutoFHIR reconciliation:
This commit updates the active f202 Encounter example comment to describe the current example as a diagnosis classified with the Chief Complaint diagnosis use code. It intentionally does not reintroduce Encounter.diagnosis.rank, does not add a principalDiagnosis code, and does not change the current preferred binding or broader Encounter diagnosis model because those are governed by later Encounter decisions and an unresolved R6 binding discussion.

Recommendation:
Keep this source fix. It preserves the applied FHIR-14758 example while removing stale guidance that referenced a retired Encounter.diagnosis.rank element. Broader questions about whether Encounter.diagnosis.use should include additional principal-diagnosis or billing classifications should remain with active/future PA terminology work rather than this STU3 clarification.
