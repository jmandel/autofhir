FHIR-20195: Add CMS146 supplemental data example

Issue request:
FHIR-20195 was an Applied/Persuasive CQI issue raised against STU3 and applied for R4. It asked for a worked MeasureReport example showing how supplemental data is communicated as Observations.

Initial application:
No git commit explicitly mentions FHIR-20195. The closest historical application is ca11697531, which added the current Quality Reporting topic link to the CMS146 Measure and MeasureReport examples after explaining supplemental-data reporting. The CMS146 MeasureReport example narrative contained supplemental-data rows, but the current XML resource did not actually include MeasureReport.supplementalData references or contained Observation resources.

Additional context:
Later CQI issues FHIR-29807, FHIR-29816, FHIR-34495, and FHIR-37559 refined the rule from evaluatedResource-based reporting to the current MeasureReport.supplementalData element. FHIR-37559 added the element and current guidance that summary reports use contained Observations counting each supplemental-data value. A 2021 Zulip thread confirmed implementer confusion about the CMS146 supplemental-data example and the lack of concrete MeasureReport guidance.

AutoFHIR reconciliation:
This commit updates the active CMS146 summary MeasureReport example to include contained Observation resources for the gender and deceased supplemental data already described in its narrative, and references them from MeasureReport.supplementalData. The edited file is in build scope because MeasureReport is active in source/fhir.ini and the CMS146 summary report is the first entry in source/measurereport/list-MeasureReport-examples.xml as well as the linked example from the Quality Reporting topic.

Recommendation:
Keep this source fix. It brings the current worked example into line with the active MeasureReport.supplementalData guidance without changing the broader reporting model; separate work can revisit individual or subject-list supplemental-data examples if CQI wants additional examples beyond the summary report linked by the issue.
