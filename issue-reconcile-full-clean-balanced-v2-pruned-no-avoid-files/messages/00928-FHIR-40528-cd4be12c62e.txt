FHIR-40528: Fix BodyStructure search parameter codes

Issue request:
FHIR-40528 was Applied with Persuasive with Modification resolution for R6 after OO reviewed BodyStructure QA findings. It asked to fix the BodyStructure search parameter names `included_structure` and `excluded_structure` to follow the style guide, and to correct misspelled search-bundle path values for `includedStructure.structure` and `excludedStructure.structure`.

Initial application:
FHIR-38657 initially added/renamed the included and excluded BodyStructure structure search parameters in commit 03961b2845, leaving the SearchParameter.code values as `included_structure` and `excluded_structure`. The Jira-tagged FHIR-40528 application commit d543b63773 corrected the misspelled path extension values from `includedStrcture`/`excludedStrcture` to `includedStructure`/`excludedStructure`, but did not change the underscore codes named by the Jira QA finding.

Additional context:
`source/fhir.ini` actively lists `bodystructure=BodyStructure`, so `source/bodystructure/bundle-BodyStructure-search-params.xml` is in current build scope. The SearchParameter.code definition says maximum compatibility uses lowercase ASCII characters and hyphens. Later BodyStructure ticket FHIR-53473, although only Resolved - change required and not separately decided here, confirms the intended names as `included-structure` and `excluded-structure`; FHIR-53205 was retracted and does not override this correction. OO minutes record the FHIR-40528 persuasive vote, and no directly relevant Zulip discussion was found.

AutoFHIR reconciliation:
Changed only the two BodyStructure SearchParameter.code values from underscores to hyphens. The already-applied path typo fix remains unchanged, and the broader FHIR-53473 description updates were intentionally left out because they are outside this Applied seed's source-edit scope.

Recommendation:
Keep this commit as the FHIR-40528 reconciliation. Consider FHIR-53473 separately when the broader BodyStructure search-parameter description cleanup is applied or explicitly brought into scope.
