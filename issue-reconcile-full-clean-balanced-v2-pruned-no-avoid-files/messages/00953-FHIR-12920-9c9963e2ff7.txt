FHIR-12920: Align Person structured definition

Issue request:
FHIR-12920 was Published/Persuasive for the PA work group. It asked that Person's definition state that Person is a linking resource used to convey shared demographics for other Patient, Practitioner and/or RelatedPerson resources, and that Person instances are never directly referenced as actors; actors are identified as Patient, Practitioner, or RelatedPerson according to role.

Initial application:
The issue was partly applied in narrative source by c385e310a0, which rewrote the Person Scope and Usage and Boundaries and Relationships sections. Commit 6934243988 then changed the first Scope and Usage sentence to the exact proposed wording, but 08ec2966ae immediately backed that narrow first sentence out to the broader current wording. The narrative still preserves the substance by describing Person as a linkage resource for common demographics across roles and by saying Person instances are not actor references.

Additional context:
Person is active in the current build through source/fhir.ini [resources] person=Person and work group person=pa. Later Published issue FHIR-21241 reinforced the actor-reference rule and was applied by 44ec49c381, making the narrative prohibition more explicit. The current structured Person description and root element definition/comment had not been kept in sync: they still described Person generically and the comment said Person was a primary resource to point to for role actors, conflicting with the narrative and later clarification.

AutoFHIR reconciliation:
This commit updates source/person/structuredefinition-Person.xml, the active StructureDefinition source, so the resource description and root element definition identify Person as a linkage resource for common demographics and administrative information across roles. It also replaces the stale root comment with language that allows linking Patient, Practitioner, RelatedPerson, and Person records while making clear that clinical and administrative actor references use the appropriate role-specific resource. The already-correct narrative files were left unchanged.

Recommendation:
Keep this source fix. It completes the original FHIR-12920 intent on the structured conformance surface without restoring the narrower first sentence that was deliberately backed out, and it aligns with the later FHIR-21241 clarification.
