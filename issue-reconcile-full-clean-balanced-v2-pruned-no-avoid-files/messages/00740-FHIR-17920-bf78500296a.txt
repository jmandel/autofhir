FHIR-17920: Complete Claim summary flags

Issue request:
FHIR-17920 was Published/Persuasive with Modification for the FM Claim resource. It requested adding Claim.identifier, Claim.use, patient, created, billingPeriod, provider, and insurer to the summary view, with the final resolution also adding the total amount.

Initial application:
The 2018 Jira-tagged batch commit afb5ec66f6 applied most of the request in the then-active Claim spreadsheet by marking use, patient, billablePeriod, created, insurer, and provider as summary, but it left Claim.identifier and the Claim total amount element unset. The current XML StructureDefinition inherited those two omissions through the source conversion.

Additional context:
Claim is an active current-build resource in source/fhir.ini. Later source refactors renamed the older Claim.patient path to Claim.subject, and the current source uses Claim.billablePeriod and Claim.total for the billingPeriod/total amount concepts. The parallel ClaimResponse summary issue FHIR-17931 has already been reconciled separately on the combined branch and confirms this is a same-change-family issue, not a reason to broaden the Claim edit beyond the two missing current Claim elements. Zulip and Confluence searches found no relevant conflicting community record.

AutoFHIR reconciliation:
Marked Claim.identifier and Claim.total with isSummary=true in source/claim/structuredefinition-Claim.xml. Existing summary flags already covered Claim.use, Claim.subject, Claim.billablePeriod, Claim.created, Claim.insurer, and Claim.provider.

Recommendation:
Keep this source fix. It completes the Published FHIR-17920 request for the current Claim element names without reintroducing removed/non-current paths or changing unrelated Claim elements.
