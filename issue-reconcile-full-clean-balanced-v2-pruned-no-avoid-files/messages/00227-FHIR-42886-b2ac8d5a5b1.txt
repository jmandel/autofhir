FHIR-42886: Convert EvidenceVariable example to definition

Issue request:
FHIR-42886 was Applied as Persuasive with Modification for R6. It replaced the removed EvidenceVariable.characteristic BackboneElement with EvidenceVariable.definition 0..1 CodeableReference, allowed definition.concept with an example binding, limited definition.reference to Group, and required introductory text to match the new structure.

Initial application:
The issue was primarily applied by git commit b6ffbe50c67dfcc7f9ceac3463e582537ad2d85c, which removed EvidenceVariable.characteristic from the StructureDefinition, added EvidenceVariable.definition, revised the introduction, and removed or converted most examples. Later commits dc839c2165367b960e9f166b1a5429002e43489c and 6ac79742bb62f4e97b76ad6cea017dc197cb3bc7 restored converted examples. A minimal legacy example file, source/evidencevariable/evidencevariable-example.xml, was not converted and still used direct EvidenceVariable.characteristic.

Additional context:
source/fhir.ini has EvidenceVariable.characteristic entries only in the [r4-r6-changes] and [r5-r6-changes] migration/change-map sections, where removed old element paths are expected. Current source/source evidence shows EvidenceVariable is an active resource in fhir.ini, the StructureDefinition has EvidenceVariable.definition as CodeableReference(Group), and the narrative introduction explains definition.concept and Group references. A Zulip search found no conflicting discussion; a CDS/HEvKA Confluence summary records that the work group changed the request from deprecation to outright removal because the element was only maturity level one.

AutoFHIR reconciliation:
This commit converts the remaining direct EvidenceVariable.characteristic in source/evidencevariable/evidencevariable-example.xml to EvidenceVariable.definition.concept while preserving the original text concept, "Diabetic patients over 65". This brings the example into the same current R6 shape as the StructureDefinition and the other converted EvidenceVariable examples.

Recommendation:
Keep this commit. No additional core source changes are recommended for FHIR-42886 unless a future build process reveals another generated artifact derived from the old example; the current authoritative XML, narrative, and examples now consistently use EvidenceVariable.definition.
