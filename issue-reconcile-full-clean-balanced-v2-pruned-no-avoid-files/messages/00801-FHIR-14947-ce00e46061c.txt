FHIR-14947: Finish Clinical Module rename

Issue request:
FHIR-14947 is a Published/Persuasive Patient Care change request for the STU3 Clinical Summary module page. It asked to rename the section title from Clinical Summary Module to Clinical Module because Clinical Summary could be misunderstood as a document type.

Initial application:
The historical application appears in commit 722ed5c93f4bc9828e96f0f5b476bedc3486fb92, which explicitly included GF#14947 in a Clinical Summary Module typo-fix batch and changed source/clinicalsummary-module.html from Clinical Summary Module to Clinical Module in the page title, heading, intro, and index text.

Additional context:
The current source/clinicalsummary-module.html already uses Clinical Module, but source/hierarchy.xml still labeled the built navigation page as Clinical Summary and later diagnostic module updates added two active links labeled Clinical Summary Module. publish.ini lists both clinicalsummary-module.html and diagnostics-module.html as current published/special pages, so these labels feed current built pages. Later related issues FHIR-40584 and FHIR-50920 updated the same module family but did not reverse the FHIR-14947 rename.

AutoFHIR reconciliation:
This commit changes the active hierarchy title to Clinical and updates the two diagnostics-module links to say Clinical Module. It leaves the stable file name clinicalsummary-module.html unchanged and does not touch unrelated uses such as clinical summary document type examples.

Recommendation:
Keep this source-changing commit as-is. It completes the already-approved rename on current active source surfaces while preserving URL stability and avoiding unrelated terminology changes.
