FHIR-32194: Clarify Measure group basis abstract types

Issue request:
FHIR-32194 was a Published FHIR-core Measure change request resolved Not Persuasive with Modification. It asked to narrow the Measure.basis value set because some all-types codes are not useful as a population basis; the final decision instead kept the all-FHIR-types binding for Measure.basis and Measure.group.basis and required element documentation that abstract types can be valid, with authoring environments free to constrain further based on content needs.

Initial application:
The issue was initially applied by commit 14927613a0a69db2add0762b1174e242356a91d4, which added the abstract-type clarification to the then-current root Measure.basis requirements text. Later Measure refactors deprecated and then removed the root Measure.basis element, leaving the active Measure.group.basis element without the FHIR-32194 clarification.

Additional context:
FHIR-32079 records the same no-narrowing decision for the CQF Measures populationBasis extension. FHIR-32069 replaced the old all-types value set with the current fhir-types terminology while preserving the relevant all-FHIR-types concept. FHIR-49922 and FHIR-50664 moved Measure calculation definition to group-level elements, and FHIR-50500 later introduced Measure.group.basisRequirement with examples that can use Resource as a broad basis when more specific DataRequirements define the counted cases. source/fhir.ini lists Measure as an active resource, so source/measure/structuredefinition-Measure.xml is build-scope source.

AutoFHIR reconciliation:
This commit updates Measure.group.basis requirements to carry forward the FHIR-32194 clarification: the binding to all FHIR types can include abstract types such as Resource and DomainResource, and authoring environments may constrain the selection further for content needs. No generated diagram/SVG files were edited.

Recommendation:
Keep this source fix as-is. It restores the published FHIR-32194 clarification to the current authoritative group-level Measure basis element without narrowing the required binding or adding redundant narrative elsewhere.
