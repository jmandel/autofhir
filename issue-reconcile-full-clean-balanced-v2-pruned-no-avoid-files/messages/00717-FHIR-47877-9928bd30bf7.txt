FHIR-47877: Introduce PoCD expansion in Device module use case

Issue request:
FHIR-47877 is an Applied/Persuasive R6 technical correction for FHIR-core Device asking to introduce the "PoCD" abbreviation before using it in the Point-of-Care device text.

Initial application:
The issue was initially applied by git commit 221fd4e0c8, which changed source/device/device-introduction.xml to expand the Point of Care Devices abbreviation before the subsequent PoCD use. That historical application did not carry an Issue-Reconcile-Key trailer. A later Device text refactor, 3cf635fa2b, moved the device category descriptions from Device into DeviceDefinition and preserved the intended current wording as "Point-of-Care Device (PoCD)" and "Point-of-care medical devices (PoCD)" in source/devicedefinition/devicedefinition-introduction.xml.

Additional context:
The active Device module page is listed in source/hierarchy.xml and was later expanded by FHIR-50446 / git commit 07e1774d2b with common use cases. That later applied use-case text introduced a new "F2 (PoCD scenario)" label without expanding PoCD on the module page, reintroducing the same abbreviation problem outside the original Device page section. OO Confluence minutes record the work group's Will Fix direction for FHIR-47877; no Zulip discussion was found that changes the source/Jira conclusion.

AutoFHIR reconciliation:
This commit changes the active Device module use-case label from "F2 (PoCD scenario)" to "F2 (Point-of-Care Device (PoCD) scenario)". It intentionally leaves the DeviceDefinition category text unchanged because the current authoritative category description already introduces PoCD correctly.

Recommendation:
Keep this source fix as-is. It is a narrow editorial reconciliation that preserves the later FHIR-50446 use case while making the current Device module consistent with the applied FHIR-47877 abbreviation rule.
