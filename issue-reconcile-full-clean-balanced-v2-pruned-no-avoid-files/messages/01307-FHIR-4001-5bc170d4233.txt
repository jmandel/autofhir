FHIR-4001: Use current enteral formula productName in examples

Issue request:
FHIR-4001 was Published/Persuasive with Modification for DSTU1 NutritionOrder/NutritionRequest and requested renaming EnteralFormula.baseFormulaName to a product-name element because product name better captures the intent and distinguishes it from formula type.

Initial application:
The historical NutritionOrder StructureDefinition carried committee notes for [#4000][#4001][#4002] saying to change "...name" to "...productName", and the pre-current enteral formula element was NutritionOrder.enteralFormula.baseFormulaProductName. A later NutritionOrder revision replaced that StructureDefinition element with the current NutritionOrder.enteralFormula.productName, but two active examples still used baseFormulaProductName.

Additional context:
source/fhir.ini actively includes NutritionOrder, and list-NutritionOrder-examples.xml lists the enteral bolus and enteral cycled examples. fhir.ini keeps baseFormulaProductName only as an R4/R5-to-R6 change map to the current productName element. No Zulip or Confluence evidence was found that changes the Jira/source conclusion.

AutoFHIR reconciliation:
Updated the two active enteral feeding examples to use NutritionOrder.enteralFormula.productName, matching the current authoritative StructureDefinition and preserving their product/brand-name values.

Recommendation:
Keep this focused source fix. Broader stale NutritionOrder example elements from later model revisions, if any, should be handled under their own issue trail rather than expanding FHIR-4001 beyond the product-name request.
