FHIR-19960: Add designation-use THO codes

Issue request:
FHIR-19960 is Published/Persuasive with Modification and requested adding a designation-use code for consumer-friendly terms, with Jira follow-up recording that the R5 core designation-use value set should include the THO hl7TermMaintInfra codes consumer and preferredForLanguage.

Initial application:
The THO code system work was completed outside core, but no core commit mentioning FHIR-19960 was found. The current core source for source/valueset/valueset-designation-use.xml still composed only the two SNOMED CT designation-use concepts, so CodeSystem.concept.designation.use and ValueSet.compose.include.concept.designation.use did not expose the promised HL7 codes through their active extensible binding.

Additional context:
UP-107 and Vocabulary minutes discussed the broader designation-use ownership problem and identified the intended final value set content as the existing SNOMED CT codes plus consumer and preferredForLanguage from hl7TermMaintInfra. FHIR-29821 later added additionalUse to handle overlapping designation use semantics without changing the singleton use cardinality, and that issue is already represented on the combined branch. A 2023 terminology Zulip thread confirmed that leaving the THO codes unhooked from http://hl7.org/fhir/ValueSet/designation-use was a left-hand/right-hand failure rather than an intentional reversal.

AutoFHIR reconciliation:
Added a second compose.include to source/valueset/valueset-designation-use.xml for http://terminology.hl7.org/CodeSystem/hl7TermMaintInfra with concepts consumer and preferredForLanguage. This file is in the active ValueSet resource area, and source/fhir.ini lists valueset as an active resource with the vocab work group, while the CodeSystem and ValueSet StructureDefinitions bind designation.use and designation.additionalUse to this value set.

Recommendation:
Keep this source fix. It implements the published Jira decision without adding unresolved display semantics from UP-107 or duplicating the already-audited FHIR-29821 additionalUse work.
