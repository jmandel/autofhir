FHIR-13468: Correct Request doNotPerform guidance

Issue request:
FHIR-13468 is a Published/Persuasive with Modification FHIR-I issue for STU3. It asked to add Request.doNotPerform as a modifier element immediately before Request.code, update reasonCode/reasonReference descriptions so they can explain why something should not be performed, and add guidance that Request.code can pre-coordinate prohibition such as NPO or DNR without also setting doNotPerform.

The current source retained the accepted doNotPerform element and guidance, but the initial application left spelling/element-name typos in the explanatory text.
