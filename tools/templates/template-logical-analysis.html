Detailed Cross Analysis for the <%pattern-title%>.

Analysis Legend

The detailed analysis table compares each pattern element with the corresponding resources and records why any variance is acceptable or still needs work group follow-up. Each row uses these columns:

  • Resource: the resource being compared against the pattern.
  • Matches: resource element(s) or extension(s) mapped to the pattern element.
  • Issues: detected variance, such as a missing element or a name, type, cardinality, modifier, summary, or binding difference.
  • Tasks: follow-up action or reference for the work group when the variance is not already accounted for.
  • Status: whether the variance is unresolved, suppressed as an accepted workflow warning, or covered by a mapping exception.
  • Notes: the explanation captured for the variance. Mapping-exception explanations come from source/*/*-mapping-exceptions.xml; Unknown means a variance has been acknowledged but still lacks a substantive explanation.

Suppressed workflow warnings are maintained in source/suppressed-workflow-warnings.xml. Mapping exceptions are validated by tools/schema/mappingExceptions.xsd, which requires every exception to carry a reason so absent explanations are flagged during source validation rather than silently disappearing from the table.
