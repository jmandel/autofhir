ICD-9 and ICD-9-CM

Responsible Owner: [%wgt fhir%] Work GroupStandards Status:Informative

There is no FHIR system identifier specified for codes defined in the base ICD-9 code system. The URL "http://hl7.org/fhir/sid/icd-9-cm" is the FHIR system identifier for ICD-9-CM diagnosis and procedure codes. The source of ICD-9-CM diagnosis codes is the CDC/NCHS, at http://www.cdc.gov/nchs/icd/icd9.htm. See Using ICD-[x] with HL7 Standards for details.
