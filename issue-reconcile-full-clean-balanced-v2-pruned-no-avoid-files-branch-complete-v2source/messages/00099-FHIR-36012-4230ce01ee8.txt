FHIR-36012: Deduplicate stripped UCUM common codes

Issue request:
FHIR-36012 was a Published/Persuasive MnM change request for R5 asking to remove all UCUM curly-brace comments from the standard/common UCUM value sets, remove display text that only reflected those comments, and eliminate duplicate codes created by removing comments.

Initial application:
The Jira comment points to git commit 8b690b1bd5, which applied the main source change to source/valueset/valueset-ucum-common.xml by removing curly-brace annotated UCUM concepts. The current source/datatypes/valueset-ucum-units.xml has no enumerated concepts and only includes the whole http://unitsofmeasure.org system, so there were no source-level comments to remove there. A reconciliation check found that the prior application left two duplicate ucum-common concepts introduced by annotation stripping: U/10*12 and fmol/mg.

Additional context:
FHIR-33063 records the parallel published guidance that UCUM curly-brace annotations are discouraged in FHIR codes. The originating Zulip thread shows the practical concern was that annotated UCUM strings such as {ScoreOf} should not populate the common-units drop-down list, and a later committers thread confirms the intended FHIR-36012 application was to drop curly-braced codes. FHIR-45248 later discussed UCUM display strings and noted that the current R6 build no longer publishes the old ucum-units expansion, so it does not require a core source change for this issue.

AutoFHIR reconciliation:
Removed the two duplicate concept blocks in source/valueset/valueset-ucum-common.xml that were directly introduced by stripping comments from previously annotated codes, leaving one U/10*12 concept and one fmol/mg concept. The commit intentionally leaves pre-existing alternate-display duplicates alone because they were not caused by FHIR-36012, and it makes no change to ucum-units because the current source contains no explicit commented concepts.

Recommendation:
Keep this source fix as-is. It completes the de-duplication part of FHIR-36012 without broadening into unrelated UCUM display cleanup or historical expansion behavior.
