Issue request:
FHIR-34525 was Published with a Persuasive with Modification resolution for R5. It reported that the Procedure.used comment referred to nonexistent Procedure.device and directed the comment to say that implanted or removed devices use Procedure.focalDevice.manipulated.

Initial application:
The issue appears to have been applied in git commit 0e1ea923399d5bc6f2fdefb6b09e4073674d04fc, which changed source/procedure/structuredefinition-Procedure.xml so Procedure.used.comment now says "For devices actually implanted or removed, use Procedure.focalDevice.manipulated." The Jira comment linked GitHub commit b7766ba from the same PR branch, but the source-changing commit in the current history is 0e1ea923.

Additional context:
Procedure is an active resource in source/fhir.ini and source/procedure/procedure-notes.xml is the resource notes source for that active resource. A later Procedure notes change for FHIR-44689 added a local "Use of Procedure.used" paragraph in 2024 that still said focal devices should appear in Procedure.device, reintroducing the stale name into active narrative source even though the StructureDefinition was already corrected.
