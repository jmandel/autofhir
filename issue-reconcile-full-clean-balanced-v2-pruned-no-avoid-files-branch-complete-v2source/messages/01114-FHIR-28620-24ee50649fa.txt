FHIR-28620: Remove stale genetics example reference

Issue request:
FHIR-28620 was a Published, Persuasive with Modification request to make R4B Observation-genetics guidance, extension pages, and examples clearly deprecated and to direct implementers to the Genomics Reporting Implementation Guide. The final Jira resolution recorded that the material had been corrected for R5 and would be removed rather than kept as current core content.

Initial application:
The R4B application is visible in c1ade242 and merge f916279, which added the stronger disclaimer to the old Observation-genetics guidance and related genomic artifacts. Earlier R5 history in 3cfe12f removed the outdated clinical genomics artifacts, including the old Observation-genetics page, profiles, extensions, and examples such as Observation/example-genetics-brcapat.

Additional context:
The linked Zulip thread confirms the original R4B compromise: existing R4 content could not be removed in R4B, so stronger warning language was the available action. In the current build, Observation and RiskAssessment are active resources; the old Observation-genetics source files are not in core, and the current Observation notes point to the Genomics Reporting guide instead. The former Observation-genetics extensions now live in the separate FHIR Extension Pack, where they are retired/deprecated and carry a Genomics Reporting Guide replacement reason. Current core source still had one active RiskAssessment example basis reference to the removed Observation/example-genetics-brcapat example.

AutoFHIR reconciliation:
Removed the stale RiskAssessment.basis reference to Observation/example-genetics-brcapat from source/riskassessment/riskassessment-example-breastcancer.xml. No old Observation-genetics deprecation note was added back to current core because those core artifacts are no longer built, and the Extension Pack copy of the old extensions already records their deprecated replacement guidance.

Recommendation:
Keep this source fix. If a future work group wants the breast cancer risk example to cite genomic evidence, add a new current, non-deprecated evidence example; do not restore references to the removed Observation-genetics example family.
