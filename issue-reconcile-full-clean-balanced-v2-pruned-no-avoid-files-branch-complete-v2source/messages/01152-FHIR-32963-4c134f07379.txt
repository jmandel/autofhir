FHIR-32963: Publish DefinedParameters profile

Issue request:
FHIR-32963 was a Published/Persuasive R5 FHIR-core change request asking for parameter definitions to be expressible in Parameters resources when a parameter has no value, so expression evaluation operations can still communicate parameter type and cardinality. The resolution requested a parameter-definition extension for Parameters.parameter and a DefinedParameters profile that allows the extension.

Initial application:
The issue was applied in commit 272e3fb71ecb0d87630a48101b00015f0f18b038, recorded from PR HL7/fhir#2358. That commit added source/parameters/implementationguide-Parameters-cqf.xml, source/parameters/structuredefinition-profile-definedparameters.xml, and a Parameters-cqf entry in source/parameters/list-Parameters-packs.xml, but left the Parameters-cqf entry XML-commented. Later source changes retained the DefinedParameters differential and FHIR-32965 extended it with dataAbsentReason support, but the current R5 and CI Parameters profile pages still did not surface DefinedParameters because the pack reference was inactive.

Additional context:
The Jira resolution used the name cqf-parameterDefinition, but the actual R5 implementation used the generic http://hl7.org/fhir/StructureDefinition/parameters-definition extension on Parameters.parameter. The older cqf-parameterDefinition extension is a separate TriggerDefinition/ParameterDefinition extension from FHIR-15751 and now lives in the FHIR Extension Pack. The parameters-definition extension also lives in the Extension Pack, while the DefinedParameters profile remains in the core Parameters source folder. FHIR-32965 is same-change-family evidence and is already represented on the combined branch by an audit commit, so this commit does not republish it.

AutoFHIR reconciliation:
This commit makes the existing Parameters-cqf implementation guide active in source/parameters/list-Parameters-packs.xml. That guide references StructureDefinition/definedparameters, and the profile's differential already allows Parameters.parameter.extension:definition using the parameters-definition extension, so no new profile or extension definition was added.

Recommendation:
Keep this source fix. It is the narrow missing build-scope connection needed for the Published FHIR-32963 profile to appear with the active Parameters resource; further work should only be considered if the work group wants to rename, relocate, or add narrative examples for the profile.
