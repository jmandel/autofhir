FHIR-16945: Correct medication definition collapse residue

Issue request:
FHIR-16945 was a Published BRR change request, raised for STU3 and applied for R5, asking to collapse the growing MedicinalProduct/Substance definition resource set into a more sustainable model. Its final disposition was Not Persuasive with Modification: the earlier voting was unclear, later work had overtaken the request, and FMG had approved the principle of the medication definition resources.

Initial application:
The issue was not applied by a commit explicitly mentioning FHIR-16945. The application happened through the later R4B/R5 medication-definition redesign: old MedicinalProduct resources were removed or commented out, MedicinalProductDefinition/SubstanceDefinition and peer definition resources became active, and the medication definition module now explains that applications may use only the needed subset rather than every resource.

Additional context:
Current source/fhir.ini keeps the new Medication Definition resources active and records the R4-to-current rename/collapse mappings for the retired names. The old MedicinalProductPharmaceutical mapping still pointed to a misspelled AdmininistrableProductDefinition target, and the active MarketingStatus examples page still sent readers to retired MedicinalProductPackaged examples. Prior combined-branch reconciliations for FHIR-28431 and FHIR-31792 handled specific stale FHIR ModelInfo elements in this same resource-family area, but did not attempt a wholesale generated ModelInfo resource-name refresh.

AutoFHIR reconciliation:
Corrected the build-scope MedicinalProductPharmaceutical mapping to AdministrableProductDefinition and updated the MarketingStatus examples page to point to current MedicinalProductDefinition and PackagedProductDefinition examples. No broader resource rearchitecture was attempted because the authoritative resource set and module narrative already reflect the later approved medication-definition model.

Recommendation:
Keep this targeted source fix. If the work group wants the illustrative FHIR ModelInfo library regenerated to replace all remaining legacy medication-definition class names, track that separately from this FHIR-16945 reconciliation so it can be generated and reviewed as a computable-model maintenance change.
