FHIR-25929: Finish Pharmacy CodeableReference cleanup

Issue request:
FHIR-25929 was a Published/Persuasive R5 Pharmacy change request to replace every Pharmacy choice attribute that offered CodeableConcept and Reference alternatives with CodeableReference across Medication, MedicationAdministration, MedicationDispense, MedicationKnowledge, MedicationPrescription/MedicationRequest, and MedicationStatement.

Initial application:
Historical Pharmacy commits 8c940464 and 1dcdc4c applied the R5 CodeableReference migration to the main resource definitions and many examples. Current Medication, MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement StructureDefinitions now use CodeableReference for the relevant medication, reason, device, performer, ingredient, and notPerformedReason elements, and a current source check found no remaining CodeableConcept+Reference mixed choice in the medication StructureDefinitions. The reconciliation did find remaining active source locations missed by the initial application: three non-Archive example resources still used the old medicationReference element, and MedicationRequest/MedicationStatement comments and example listings still named obsolete reasonCode, reasonReference, or reasonForUseReference fields.

Additional context:
source/fhir.ini lists Medication, MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement as active resources and records that MedicationPrescription became MedicationRequest. MedicationKnowledge source already uses CodeableReference at the relevant indication and ingredient item elements, and later git history removed MedicationKnowledge from the active fhir.ini resource list. Direct Zulip and Confluence searches for FHIR-25929 found no conflicting community discussion; a later PHWG minutes page references the Pharmacy WG R5 update of medication elements to CodeableReference as accepted context for a related Immunization discussion.

AutoFHIR reconciliation:
This commit converts the active MedicationAdministration, MedicationDispense, and MedicationRequest example resources from medicationReference to medication CodeableReference/reference form. It also updates active MedicationRequest and MedicationStatement comments, MedicationRequest example list/header descriptions, and resource-side mapping-exception text so current rendered guidance names reason, reason.reference, or coded reason instead of removed R4 choice element names. It intentionally leaves Archive examples and external/pattern mapping values such as reasonCode map expressions unchanged because those are not current resource element declarations.

Recommendation:
Keep this source-changing commit. The current core Pharmacy source now consistently exposes the FHIR-25929 CodeableReference model for active resources and examples; any broader cleanup of archived examples or generic workflow pattern wording should be handled separately if a work group decides those historical/pattern artifacts are in scope.
