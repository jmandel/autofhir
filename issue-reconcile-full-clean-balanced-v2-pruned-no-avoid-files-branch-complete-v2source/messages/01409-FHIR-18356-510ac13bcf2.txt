FHIR-18356: Scope modifier-extension narrative guidance

Issue request:
FHIR-18356 was a Published, Persuasive with Modification FHIR-I change request raised against STU3 extensibility/narrative wording. It said the specification could not guarantee every modifier extension would be included in narrative when the modified element itself was not described, and the approved resolution narrowed the Narrative.status = extensions rule to modifier extensions that extend elements described by the narrative.

Initial application:
The issue was initially applied by c886442b778844b081ed58c57728277926d2a659, which updated source/narrative.html to the approved scoped wording. That left two active source locations with the older broad rule: source/datatypes/narrative.xml still defined the extensions status as reflecting all modifier extensions, and source/extensibility.html still said any modifier extension SHALL be represented in narrative.

Additional context:
The older broad wording came from FHIR-16423 commit fe5743607404d3b80d049da7a8fde4dc85be2d5d, and FHIR-17688 later cited the FHIR-16423 narrative clarification as already partly addressed. source/fhir.ini keeps Narrative, the narrative type page, and the extensibility type page in the active current build, so the remaining broad wording was not an out-of-scope generated artifact.

AutoFHIR reconciliation:
This commit updates source/datatypes/narrative.xml and source/extensibility.html so their modifier-extension narrative guidance matches the already-applied narrative page scope. It does not change the conformance-rules Is-Modifier element text, which addresses modifier elements generally rather than the modifier-extension narrative-status rule narrowed by FHIR-18356.

Recommendation:
Keep this source fix. It completes the FHIR-18356 application by harmonizing the active datatype and extensibility source with the approved narrowed narrative rule, without reopening the broader FHIR-16423 decision to allow modifier extensions.
