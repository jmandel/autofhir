FHIR-28600: Add grouped MedicationRequest examples

Issue request:
FHIR-28600 was a Published/Persuasive pharmacy change request raised for R4 and applied for R5. It asked for MedicationRequest examples showing grouped requests for "Ondansetron 8mg orally or IV twice a day as needed for nausea" and "Compazine (prochlorperazine) 5-10mg PO or 25mg PR bid prn nausea or vomiting".

Initial application:
The historical FHIR-28600-tagged commit bb4b0e4139 added medicationrequest0341.xml and medicationrequest0342.xml, but those files were not added to list-MedicationRequest-examples.xml. Later MedicationRequest example work added the currently listed grouped route examples, medicationrequest0343a.xml and medicationrequest0343b.xml, and later dosage refactors updated them to the current R6 dosageInstruction shape.

Additional context:
MedicationRequest is an active resource in source/fhir.ini, and list-MedicationRequest-examples.xml is the active example list in the MedicationRequest source folder. Current narrative already explains that route-choice MedicationRequests should be represented as two MedicationRequest resources sharing a groupIdentifier. The listed grouped examples, however, had drifted from the Jira examples: the Ondansetron pair used 4 mg and intramuscular route coding rather than the requested oral/IV 8 mg pair, and there was no listed prochlorperazine oral/rectal pair. Jira, Zulip, and Confluence searches found no later final decision reversing the FHIR-28600 request.

AutoFHIR reconciliation:
This commit keeps the existing grouped-example pattern and updates the listed Ondansetron pair to match the requested 8 mg oral and IV alternatives. It also adds a listed prochlorperazine pair using the same groupIdentifier pattern for the requested 5-10 mg oral and 25 mg rectal alternatives. No unrelated MedicationRequest guidance was changed.

Recommendation:
Keep this source fix. It is limited to active MedicationRequest example source and brings the published FHIR-28600 request into the current example list while preserving later dosageInstruction and groupIdentifier patterns.
