FHIR-23714: Update remaining SMART documentation link

Issue request:
FHIR-23714 is a Published/Persuasive FHIR-core Security work group change request raised against STU3 and applied for R5. It asked that the section 6.1.0 security summary bullet stop linking SMART documentation to http://docs.smarthealthit.org/ and instead link to the HL7 SMART App Launch Implementation Guide.

Initial application:
The requested security-page bullet was applied by git d97f7c47d6 on 2020-04-08, which changed source/security.html from docs.smarthealthit.org to the HL7 SMART App Launch URL for J#23714. Later security narrative cleanup in git 4910300636 also corrected the authentication section SMART link. Current source/security.html already has HL7 SMART App Launch links in both locations.

Additional context:
Duplicate Jira issues FHIR-17813 and FHIR-35911 both point back to FHIR-23714 for the same security-page SMART documentation correction, and FHIR-35911 records that the change was already done by FHIR-23714. Security WG Confluence minutes list FHIR-23714 in the January 2020 block-vote preparation and list FHIR-23714 among Jira items applied to the FHIR core build in April 2020. While checking for stale current-source occurrences, the same obsolete SMART docs URL remained in the active Restful Security Service CodeSystem source under the active CapabilityStatement resource folder.

AutoFHIR reconciliation:
This commit leaves source/security.html unchanged because the issue-requested security-page link is already correct, and updates source/capabilitystatement/codesystem-restful-security-service.xml so the SMART-on-FHIR concept definition points to the HL7 SMART App Launch Implementation Guide rather than the obsolete docs.smarthealthit.org site. The edited file is in build scope because source/fhir.ini lists capabilitystatement as an active resource.

Recommendation:
Keep this source fix as the final FHIR-23714 reconciliation. It preserves the historical security-page application and removes the only remaining current-source docs.smarthealthit.org occurrence found under source/ outside historical release archives; the duplicate issues do not need separate commits.
