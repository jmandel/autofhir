FHIR-40384: Update Observation recorder extension reference

Attribution note: surfaced while reviewing FHIR-40335, but direct Jira backing for this change is FHIR-40384.

Issue request:
FHIR-40335 was an Applied OO Change Request, resolved Persuasive with Modification for R6, asking core Observation notes to clarify where devices belong across Observation.subject, Observation.focus, Observation.device, and the observation-recording extension.

Initial application:
The issue was initially applied by git commit 65ec458f8b, which added the requested Subject of an Observation guidance to source/observation/observation-notes.xml. The current source still contains the subject, focus, device, and device-search guidance from that application.

Additional context:
FHIR-54036 later moved the recorder-related bullet from the Subject section into a new Performer of an Observation section without changing its extension name. FHIR-40384 was later Published in the FHIR Extension Pack with the final extension name and semantics as observation-human-transcribed, making the old observation-recording reference stale in the core text. Observation is active in the current core build via source/fhir.ini, and the Extension Pack source contains the applied observation-human-transcribed StructureDefinition.

AutoFHIR reconciliation:
This commit keeps the applied FHIR-40335 subject/focus/device guidance and updates the two stale core references to link to the human-transcribed extension. The Performer text now describes what that extension actually records: that an observation value was human-transcribed after being displayed, printed, or otherwise rendered for human consumption.

Recommendation:
Keep this source fix. FHIR-40335 remains applied in core, and no further core change is needed unless OO later decides to introduce a separate recorder identity extension or Provenance guidance beyond the published human-transcribed extension.
