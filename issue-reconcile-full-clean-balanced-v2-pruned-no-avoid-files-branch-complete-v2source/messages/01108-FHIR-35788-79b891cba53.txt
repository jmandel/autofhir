FHIR-35788: Rename SubscriptionStatus status binding

Issue request:
FHIR-35788 was Published with a Persuasive with Modification resolution. The issue reported that SubscriptionStatus was declared both as the SubscriptionStatus resource and as the code type for SubscriptionStatus.status, creating a code-generation name collision; FHIR-I resolved to rename the value set to SubscriptionStatusCodes in R4B and R5, with no change to the code system name.

Initial application:
The rename was partially applied before this reconciliation. Commit 8fa50a0dbc renamed the ValueSet name to SubscriptionStatusCodes, and commit 87c5c17847 restored the code system name to SubscriptionStatus while renaming the value set/source URL family and updating Subscription.status to use bindingName SubscriptionStatusCodes. That same 87c5c17847 commit changed SubscriptionStatus.status only from the old subscription-state value set URL to ValueSet/subscription-status, leaving its bindingName as SubscriptionStatus.

Additional context:
The active current build includes SubscriptionStatus as a resource in source/fhir.ini, and source/subscriptionstatus/structuredefinition-SubscriptionStatus.xml is the authoritative StructureDefinition source for that resource. Current source already preserves the Jira note that the code system remains named SubscriptionStatus, and the value set resource itself is named SubscriptionStatusCodes. No Zulip discussion was found that changes the Jira/Confluence decision; FHIR-I minutes for 2022-01-24 confirm the motion to rename the value set to SubscriptionStatusCodes in R4B and R5.

AutoFHIR reconciliation:
This commit updates SubscriptionStatus.status's elementdefinition-bindingName from SubscriptionStatus to SubscriptionStatusCodes so the active resource element uses the renamed code/value-set binding name and no longer recreates the collision described by FHIR-35788.

Recommendation:
Keep this commit as-is. It is a narrow completion of the published FHIR-I decision and does not rename the code system, canonical value set URL, or SubscriptionStatus resource.
