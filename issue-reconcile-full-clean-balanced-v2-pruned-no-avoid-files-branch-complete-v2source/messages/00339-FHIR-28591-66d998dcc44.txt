Issue request:
FHIR-28591 is a Published FHIR-core Financial Management change request, resolved Persuasive with Modification for R5, asking to clarify Claim Type definitions, replace the Claim.type comment, add Claim scope text about supported claim types depending on jurisdiction, and update the external claim-type CodeSystem definitions.

Initial application:

Those changes added the requested Claim scope paragraph and replaced the Claim.type comment, but they did not touch the parallel ExplanationOfBenefit.type comment that binds to the same Claim Type value set.

Additional context:
source/fhir.ini lists both claim=Claim and explanationofbenefit=ExplanationOfBenefit as active resources and assigns both to the FM work group, so both StructureDefinition files feed the current core build. The current core source contains source/claim/valueset-claim-type.xml as a ValueSet that includes http://terminology.hl7.org/CodeSystem/claim-type, but no authored core CodeSystem-claim-type source; a live terminology.hl7.org check still shows the old 1.0.1 definitions, making that part a THO/UTG follow-up rather than a core-source edit. FHIR-26708 is same-change-family background from CARIN BB and says the core definition updates were submitted as FHIR-28591. Community searches found no conflicting Confluence record and only an older Zulip thread about whether DME should be a separate claim type.

AutoFHIR reconciliation:
This commit updates ExplanationOfBenefit.type to use the same Claim Type comment already applied to Claim.type, removing the stale pre-FHIR-28591 guidance from an active parallel element bound to the same value set. It does not edit generated history files or the external claim-type CodeSystem definitions, because those definitions are not authored in this FHIR core checkout.

Recommendation:
Keep this core-source fix. Separately consider a THO/UTG terminology change for http://terminology.hl7.org/CodeSystem/claim-type if the Financial Management work group still wants the code definitions from FHIR-28591 reflected in the current terminology publication.
