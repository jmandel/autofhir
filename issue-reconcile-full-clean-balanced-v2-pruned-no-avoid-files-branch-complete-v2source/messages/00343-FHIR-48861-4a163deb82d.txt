FHIR-48861: Complete Request ended status application

Issue request:
FHIR-48861 was Applied/Persuasive for R6 and asked to add a higher-level Request pattern status of 'ended', defined as no longer to be acted upon without distinguishing how much action occurred, as a parent for terminal request states.

Initial application:
Historical commit 1555ba4c2b1aa996160b4895a4bb9973d210e0b3 added the 'ended' concept to source/request/codesystem-request-status.xml and source/request/request-spreadsheet.xml, nesting the generic Request terminal states completed and revoked. The application left Request.status' spreadsheet short list without 'ended', did not declare hierarchyMeaning on the CodeSystem despite nested concepts, and left stray literal text in the spreadsheet cell for the new code.

Additional context:
source/fhir.ini lists request as an active logical pattern, so source/request feeds the current build. The same 2024-11-18 workflow minutes also record FHIR-48862, which explains that Request status changes remain under requester control and may move to 'ended' when an authorization expires. Current concrete Request resources already show the generated Request status short list with 'ended | completed | revoked'. No directly relevant Zulip discussion was found. The generic Request pattern uses 'revoked' for terminated-before-completion requests, so this reconciliation does not add resource-specific 'stopped' or 'cancelled' codes to the generic RequestStatus code system.

AutoFHIR reconciliation:
This commit adds hierarchyMeaning='is-a' to the RequestStatus CodeSystem, updates the Request.status spreadsheet short list and explanatory text to include the higher-level 'ended' status with completed/revoked terminal children, and removes the stray duplicate 'ended' text from the request-status worksheet cell.

Recommendation:
Keep this commit as the source correction for FHIR-48861. Further WG review is only needed if the generic RequestStatus code system should gain separate stopped/cancelled codes rather than continuing to use revoked for non-completed termination.
