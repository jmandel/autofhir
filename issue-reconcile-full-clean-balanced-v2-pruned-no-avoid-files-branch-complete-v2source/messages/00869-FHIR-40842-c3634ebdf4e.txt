FHIR-40842: Correct code-text CodeSystem description

Issue request:
FHIR-40842 is an Applied/Persuasive FHIR-core Technical Correction for the search page. It asked that the brief :code-text description stop describing display-text matching and instead say that the modifier performs a standard string search against code values.

Initial application:
The issue appears to have been partially applied by PR 3442 in commit 2d75aa13d33fc4e852fd09b1133fe61640f35ca6, which updated the modifier listing table in source/search.html. That application did not update source/searchparameter/codesystem-search-modifier-code.xml, so the normative search-modifier-code CodeSystem still described :code-text as matching CodeableConcept.text, Coding.display, or Reference.display.

Additional context:
FHIR-32673 introduced :code-text to support partial text searching on the code or value portion of Coding or Identifier, distinct from text/display searching. The current search page links search modifiers to the search-modifier-code CodeSystem, and source/fhir.ini actively includes the search-modifier-code value set that uses that code system, so the stale CodeSystem definition remains part of the current build surface. FHIR-I minutes on 2024-12-09 record FHIR-40842 being moved to a Technical Correction and assigned for correction.

AutoFHIR reconciliation:
Updated the code-text concept definition in source/searchparameter/codesystem-search-modifier-code.xml to the accepted wording: this modifier is used to do a 'standard' string search against code values. No other source was changed because source/search.html already carries the corrected table wording and detailed description.

Recommendation:
Keep this commit as-is. It completes the original applied correction across the linked CodeSystem source without expanding the issue beyond the accepted wording.
