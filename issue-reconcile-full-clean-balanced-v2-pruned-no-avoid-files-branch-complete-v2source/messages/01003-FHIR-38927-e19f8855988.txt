FHIR-38927: Align glossary document definition

Issue request:
FHIR-38927 was Published with a Persuasive disposition for the R5 FHIR Documents page. The issue asked whether the sentence "A document is a frozen set of resources with a fixed presentation..." should use "frozen" when the next document-instance sentence already covers specific frozen resource versions. The approved resolution removed "frozen" from that first sentence while retaining "frozen" in the document-instance sentence and clarified that each document version contains specific versions of referenced resources.

Initial application:
The main documents-page change was applied in git commit 336f6adee7e632a0486a3514e1797d1bf4b6f574 on 2023-02-15, which changed source/documents.html from "A document is a frozen set of resources..." to "A document is a set of resources..." and left the following document-instance frozen-versions wording. That commit did not touch the active glossary page, whose Document entry had been added earlier and still described a document as an "immutable set of resources".

Additional context:
Current source/documents.html is in build scope through source/hierarchy.xml and publish.ini and already matches the approved FHIR-38927 document-page wording. Current source/help.html is also in build scope as Glossary #1 and in publish.ini; before this reconciliation it was the only active source occurrence preserving the same frozen/immutable-set semantics in a parallel Document definition. FHIR-38929 and FHIR-38930 are adjacent document-introduction ballot comments already represented on the combined branch, and they support keeping the Bundle/Composition introduction and the removal of separate document-immutability terminology rather than reopening those decisions. FHIR-I minutes for 2023-01-09 record the FHIR-38927 Persuasive vote, and no conflicting Zulip or Confluence full-text discussion was found.

AutoFHIR reconciliation:
This commit changes the active glossary Document definition in source/help.html from "A document is an immutable set of resources with a fixed presentation..." to "A document is a set of resources with a fixed presentation...". It intentionally leaves source/documents.html unchanged because that authoritative documents page already has the approved wording, including the retained "specific frozen versions" phrase for document instances.

Recommendation:
Keep this source fix as-is. It removes the remaining active parallel frozen/immutable definition without broadening the issue beyond the approved document-definition wording; if an external Word source for the glossary is later restored and used for regeneration, mirror this same wording there.
