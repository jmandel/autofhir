FHIR-18310: Align Observation refinement context guidance

Issue request:
FHIR-18310 was a Published STU3 Observation change request resolved Persuasive with Modification. It asked to revamp the Observation #refine guidance by replacing "code translations" wording with "additional codes", reversing the oxygen-saturation coding example order, replacing the explicit precondition-extension example with grouping/extension guidance, and requesting implementer feedback about extensions for this purpose.

Initial application:
FHIR-17578 first added the Observation notes refinement section in commit 1c6e2d841cd2. FHIR-18310 was then applied by commit 6451d68796eb, which changed the wording to "additional codes", reversed the oxygen-saturation example order, removed the explicit precondition extension example, added the Observation grouping/extension alternative, and added the implementer feedback note. Observation is active in source/fhir.ini, so source/observation/observation-notes.xml feeds the current build.

Additional context:
Later R6 work changed the current mechanism for the independent context that the old precondition-extension example represented. FHIR-51529 added Observation.interpretationContext as a core element for preceding or concurrent context that is critical to interpreting an Observation, and FHIR-42899 limited the observation-precondition extension to R5 and earlier with direction to use Observation.interpretationContext after R5. The current core notes still retained a generic "extensions may be used" sentence in the FHIR-18310 paragraph, which no longer matched the current build's authoritative mechanism.

AutoFHIR reconciliation:
Updated source/observation/observation-notes.xml so the third refinement bullet still points readers first to Observation grouping, but now directs current-build users to Observation.interpretationContext when critical preceding or concurrent context is not itself part of an Observation grouping. The existing FHIR-18310 additional-code wording, coding-order example, and implementer-feedback note were left unchanged.

Recommendation:
Keep this source fix. It preserves the FHIR-18310 intent while aligning the current R6 Observation notes with later applied core and extension-pack decisions. A separate FHIR-51529 audit can still assess broader narrative coverage for the new element, but this stale FHIR-18310 paragraph should no longer recommend extensions as the current mechanism.
