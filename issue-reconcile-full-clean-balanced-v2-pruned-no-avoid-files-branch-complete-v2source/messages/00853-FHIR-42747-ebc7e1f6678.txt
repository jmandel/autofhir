FHIR-42747: Expand ventilation order details example

Issue request:
FHIR-42747 is Applied/Persuasive with Modification for the active FHIR-core ServiceRequest artifact. It reported that the example titled "Order for mechanical ventilation with order details" had its order details commented out and resolved to uncomment the content and add multiple orderDetails and multiple parameters, using FHIR-32265 and the ServiceRequest Parameters discussion as context.

Initial application:
The issue was initially applied in HL7/fhir PR #3204 by commit 25298e96747255a29bdb9b20287c6c9aa1f6912e, later merged by a20a61fc78ab98338c3170a3884a5aa6898b8fa0. That commit replaced the commented-out legacy orderDetail content with one ServiceRequest.orderDetail containing one parameter, so the example no longer had zero order details but still did not satisfy the approved multiple orderDetails/multiple parameters request.

Additional context:
ServiceRequest is active in source/fhir.ini and the ventilation example is listed in source/servicerequest/list-ServiceRequest-examples.xml, so source/servicerequest/servicerequest-example-ventilation.xml is in current build scope. FHIR-32265 defines the current orderDetail backbone shape with optional parameterFocus and repeating parameter. The linked ServiceRequest Parameters page and FHIR-32265 comments provide the mechanical ventilation use case with Puritan Bennett device context, multiple ventilator settings, and an oxygen saturation target.

AutoFHIR reconciliation:
Updated source/servicerequest/servicerequest-example-ventilation.xml to include two orderDetail repetitions and nine parameter repetitions. The first orderDetail groups ventilator settings under a Puritan Bennett parameterFocusReference, and the second captures the oxygen saturation goal plus monitoring instructions. This keeps the change limited to the authoritative active example source.

Recommendation:
Keep this commit as-is. It completes the applied Jira request in the current build without changing the ServiceRequest model; FHIR-32265 remains related background rather than a separately decided issue in this reconciliation.
