FHIR-24676: Relax Consent PurposeOfUse binding

Issue request:
FHIR-24676 was Published/Persuasive with Modification. It originally asked FHIR security to create a PurposeOfUse value set assembling HL7 v3 PurposeOfUse and ISO 14265 PurposeOfUse codes, but the final resolution instead changed the binding to example so ISO codes can be used without a conflict.

Initial application:
No source commit or current source comment was found that explicitly mentions FHIR-24676. Related R5 security terminology work had already left the active AuditEvent, Provenance, Contract, and ConsentDirective PurposeOfUse-related bindings at example strength, but git history showed Consent.provision.purpose remained extensible from the R4B draft through current HEAD.

Additional context:
FHIR-27547 recorded MnM guidance about the consequences of overlapping code systems in value sets, and FHIR-27548 left ISO vocabulary acquisition outside the FHIR-core change. Security WG minutes on 2021-11-22 describe the specific PurposeOfUse problem for implementers wanting ISO codes and state that Consent would change to example binding absent more concrete guidance; 2022-02-14 minutes also flagged FHIR-24676 as needing a different resolution tied to binding strength. No Zulip discussion was found that contradicts this Jira/Confluence/source history.

AutoFHIR reconciliation:
This commit changes the active Consent StructureDefinition source, source/consent/structuredefinition-Consent.xml, so Consent.provision.purpose now has an example binding to http://terminology.hl7.org/ValueSet/v3-PurposeOfUse. Consent is an active resource in source/fhir.ini, and this hunk is necessary because the extensible binding still imposed the HL7-v3-code mapping obligation that the final resolution intended to avoid for ISO PurposeOfUse users.

Recommendation:
Keep this source fix. It completes the seed resolution in the remaining active source location while leaving the existing example-strength AuditEvent, Provenance, Contract, and ConsentDirective bindings unchanged.
