FHIR-49736: Remove stale vital signs component summary requirements

Issue request:
FHIR-49736 is an Applied/Persuasive with Modification OO change request for R6 asking to remove Must Support from Observation.component in the FHIR Vital Signs Base Profile, including component sub-elements, and move that Must Support requirement to the Blood Pressure-specific profile.

Initial application:
No prior source commit explicitly named FHIR-49736. The same change family was applied under FHIR-47136: commit 983b8c8cd0 removed the actual Observation.component Must Support flags from the base vitalsigns differential and added Blood Pressure-specific component requirements, with later FHIR-47136 follow-up commits refining component.value[x] slicing and constraints.

Additional context:
The current build-scope source has Observation as an active resource and the Observation Vital Signs IG lists both StructureDefinition/vitalsigns and StructureDefinition/bp. The current vitalsigns differential no longer marks Observation.component or its sub-elements Must Support, and the Blood Pressure profile marks component, systolic/diastolic slices, component.code, component.valueQuantity, and component.dataAbsentReason as Must Support. However, the two active summary extensions in the base vitalsigns StructureDefinition still carried old component-specific mandatory-requirement paragraphs for component.code, component.valueQuantity/component.dataAbsentReason, and Observation.related.target, which made the base profile summary contradict the applied decision.

AutoFHIR reconciliation:
This commit removes those stale component-specific mandatory-requirement paragraphs from source/observation/structuredefinition-profile-vitalsigns.xml in both the structuredefinition-summary and profile-summary extensions. It leaves the formal base differential and the Blood Pressure profile unchanged because their constraints already match the accepted resolution, and it does not attempt unrelated broader vital-signs summary modernization.

Recommendation:
Keep this source-changing commit. It completes the FHIR-49736 reconciliation for current core source by eliminating the remaining base-profile summary text that could make component sub-elements look mandatory outside Blood Pressure; any further cleanup of unrelated value-unit or binding wording in the summaries should be handled under the relevant separate trackers.
