FHIR-5215: Add provider to glossy patient narrative

Issue request:
FHIR-5215 was a Published/Persuasive DSTU1 ballot comment asking that the glossy Patient example show birthdate, gender, and provider in the human-readable narrative because those are customary Patient summary attributes.

Initial application:
The issue was initially applied in svn revision 4514, now git commit bfcc5b66382cfa9ebc6119af6644156bffe75a3f, which changed source/patient/patient-glossy-example.xml and images/shot.png to add gender and birth date to the narrative. That implementation left the provider outside the narrative even though the example carried a careProvider/generalPractitioner display value.

Additional context:
The current build still includes Patient as an active resource in source/fhir.ini, and source/patient/list-Patient-examples.xml lists Patient/glossy as the glossy example. Later changes renamed careProvider to generalPractitioner and updated the summary-page image to JSON for FHIR-41514, but those later changes did not reverse the FHIR-5215 request to include the provider in the narrative. Zulip and Confluence searches found no conflicting community guidance.

AutoFHIR reconciliation:
This commit adds a provider paragraph to source/patient/patient-glossy-example.xml text.div so the active glossy Patient example narrative now includes the provider display alongside the existing name, MRN, gender, and birth date.

Recommendation:
Keep this source fix. If maintainers regenerate binary promotional assets such as the summary screenshot or glossy PDF for a future publication, use the corrected Patient/glossy example as the source so those visuals stay aligned.
