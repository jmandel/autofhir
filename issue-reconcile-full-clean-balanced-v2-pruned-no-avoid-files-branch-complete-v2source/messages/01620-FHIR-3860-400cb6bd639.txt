FHIR-3860: Clarify optional search parameter syntax

Issue request:
FHIR-3860 was Published with a Persuasive with Modification resolution for DSTU1. It asked that REST search syntax stop implying that a query marker and search parameters are required when searching all instances, and the resolution approved optional-brace syntax such as GET [base]/[type]{?[parameters]{&_format=[mime-type]}} with application recorded as svn 4594.

Initial application:
The issue was initially applied by git-svn commit 9b37f384b7c53ea94e4e7152f111269458d338d2 (#3860 / svn 4594), which corrected type, POST, and compartment search patterns in source/http.html. The all-resource search form was not corrected in that commit, and a later HTTP-page refactor for POST search (7415a1eb0824ba59d977db335205d71eed004312) reintroduced required-looking [parameters] syntax for multi-type and all-type search examples.

Additional context:
A later Published issue, FHIR-19523, made the intended rule explicit on source/search.html: searches with no filters, including GET [base], GET [base]/Patient, POST [base]/_search, and POST [base]/Patient/_search with no body, should return all records in scope unless rejected as overly broad. That current conformance text means the HTTP interaction syntax should not present additional search parameters as mandatory. Exact FHIR-3860 Zulip and Confluence searches found no community record that changed the Jira/source conclusion.

AutoFHIR reconciliation:
Updated the active core RESTful API source page source/http.html so the multi-type examples make additional filters optional, the all-resource GET and POST examples use optional-brace syntax, and the malformed POST _search "?{?" query syntax is removed. No source/search.html change was needed because it already contains the no-filter conformance rule.

Recommendation:
Keep this source fix. It reconciles the remaining current-build syntax drift with FHIR-3860 and later no-filter search guidance without changing search semantics or broadening the page beyond the affected examples.
