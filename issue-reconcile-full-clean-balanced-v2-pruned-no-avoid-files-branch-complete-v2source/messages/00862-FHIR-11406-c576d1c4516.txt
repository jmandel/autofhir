Issue request:
FHIR-11406 was a Published FHIR-core/FM change request from the DSTU2 ballot asking for additional detail about exchanging EligibilityRequest, EnrollmentRequest, Claim, and supporting information through Communication, with final resolution stating that solicited and unsolicited Communication examples had been added.

Initial application:
No current git commit was found that mentions FHIR-11406 directly. The relevant work appears in earlier FM source history: a78f0611f6 added the finance Communication and CommunicationRequest examples, a5160b5bbd added the Financial Module "Attachments - Supporting Information" section, and later refactors kept Communication active in source/fhir.ini and listed both finance Communication examples for the current build.

Additional context:
The current Financial Module already distinguishes solicited and unsolicited attachments, and list-Communication-examples.xml includes both FM Solicited Attachment and FM Unsolicited Attachment examples. The unsolicited Communication example, however, still carried the example category code SolicitedAttachment, contradicting its title, text, example list entry, and the Financial Module definition of unsolicited attachments. Zulip and Confluence searches found no conflicting work-group decision; a 2017 connectathon thread confirms the solicited workflow as CommunicationRequest followed by Communication, and a 2016 implementers thread references the unsolicited attachment example as an FM example.

AutoFHIR reconciliation:
This commit changes only source/communication/communication-example-fm-attachment.xml, replacing the unsolicited example's category code with UnsolicitedAttachment. The file is in build scope because Communication is an active resource in source/fhir.ini and the example is referenced by source/communication/list-Communication-examples.xml.

Recommendation:
Keep this source fix as-is. It preserves the already-applied section and examples while removing a misleading example-code contradiction; no additional core source change is indicated for FHIR-11406.
