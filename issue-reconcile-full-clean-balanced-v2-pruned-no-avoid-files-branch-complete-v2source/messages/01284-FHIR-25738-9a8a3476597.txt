FHIR-25738: Modernize profiling examples

Issue request:
FHIR-25738 was a Published/Persuasive FHIR-core technical correction for R5. It reported that the profiling examples page was not current: examples did not use ElementDefinition.id and used the obsolete ElementDefinition.name where current FHIR uses ElementDefinition.sliceName.

Initial application:
No git commit explicitly mentions FHIR-25738. The same page was partially modernized by later related work: b0b61f5 changed one reported name element to sliceName for FHIR-34007, and 76a58b57 added many ElementDefinition.id and sliceName entries for FHIR-20569. Current source still retained malformed or incomplete ids, lower-case slicename elements, old StructureDefinition/baseType and binding.conformance syntax, and stale discriminator paths in build-scoped examples.

Additional context:
The Jira request originated from the same 2020 Zulip thread in which the reporter identified profiling-examples.html as clearly wrong and Grahame Grieve asked for a task. FHIR-I minutes on 2020-04-20 recorded FHIR-25738 as a technical correction needing no vote. The current build includes source/profiling-examples.html through source/hierarchy.xml and publish.ini; source/profiling.html provides the current List.entry discriminator path examples using item.resolve(), which the examples page needed to match. The combined branch already has an audit commit for FHIR-34007, so this commit does not publish a duplicate decision for that narrower issue.

AutoFHIR reconciliation:
Updated source/profiling-examples.html so the current examples consistently use valid ElementDefinition ids for sliced children and reslices, correct sliceName capitalization, current StructureDefinition.type and ElementDefinition binding/fixed-value syntax, current Coding.code/display elements, and item.resolve() discriminator paths. Also corrected directly adjacent example typos that would otherwise keep the examples invalid or misleading, including the blood-pressure closing tag and the HDL cholesterol code/display in the lipid example.

Recommendation:
Keep this source fix. It completes the broader Published FHIR-25738 correction on the active profiling examples page without reopening separately audited related issues; future cleanup of unrelated profiling narrative wording should use a separate tracker.
