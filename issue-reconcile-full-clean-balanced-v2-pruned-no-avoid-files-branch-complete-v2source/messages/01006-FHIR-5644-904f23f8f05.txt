FHIR-13396: Clarify MedicationAdministration body-site reference

Attribution note: surfaced while reviewing FHIR-5644, but direct Jira backing for this change is FHIR-13396.

Issue request:
FHIR-5644 is Published/Persuasive with Modification and asked, as a Pharmacy follow-up to FHIR-3600, to change MedicationAdministration.dosage.site to a bodySite-style choice of CodeableConcept or Reference(BodySite), using the same value set as the then-current resources.

Initial application:
No git commit found mentions FHIR-5644 directly. The application trail is through the same BodySite work family: FHIR-6253 comments record that Pharmacy resources were updated in SVN 6619-6621, and commit c765f2b228b307043933ea0c2b106ffd8529e2eb changed MedicationAdministration.dosage.site to MedicationAdministration.dosage.site[x] with CodeableConcept | Reference(BodySite).

Additional context:
FHIR-6253's WG disposition already preferred a simple CodeableConcept in core with BodySite references handled by extension. FHIR-10735 later made that rule explicit for the inconsistent BodySite direct references: core body-site fields should remain CodeableConcept, and the richer anatomical structure should be reached through the standard bodySite extension. Commit 6e938aa2cf6f9d2262954ae81884d995a149afd1 applied that later decision to MedicationAdministration by removing the site[x] choice and adding extension guidance. FHIR-13396 then renamed the resource from BodySite to BodyStructure, and the current extension-pack definition of http://hl7.org/fhir/StructureDefinition/bodySite is in context for MedicationAdministration.dosage and targets Reference(BodyStructure). Pharmacy WGM minutes from 2021 also describe MedicationAdministration.device, dosage.site, and/or the bodySite (BodyStructure) extension as available.

AutoFHIR reconciliation:
This commit does not reintroduce the obsolete site[x] choice because that would conflict with FHIR-10735. It updates the current in-build MedicationAdministration.dosage.site comment so the standard bodySite extension guidance names the current BodyStructure resource instead of the retired BodySite resource.

Recommendation:
Keep this source correction. If Pharmacy wants a first-class MedicationAdministration bodyStructure or CodeableReference element rather than the extension pattern, that should be raised as a new tracker rather than treating FHIR-5644 as overriding FHIR-10735.
