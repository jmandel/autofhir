FHIR-25555: Remove discharge from medication category examples

Issue request:
FHIR-25555 was Published/Persuasive with Modification for R5 Pharmacy category attributes. It asked to broaden category descriptions beyond administration location examples, remove "discharge" from the exemplar value set for where medications are expected to be consumed or administered, and update the exemplar value set name.

Initial application:
The 2020 FHIR-25555 commits partially applied the request: 356f7ed created administration-location code systems for MedicationAdministration, MedicationDispense, and MedicationRequest without discharge, while 68b064d renamed MedicationRequest to category but still included discharge. Later source refactors and FHIR-51726 moved the example category code systems back into core, leaving discharge in the active CodeSystems that feed the current example value sets.

Additional context:
MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement are active resources in source/fhir.ini. Current source already uses category-named ValueSets and retains broader category prose where later decisions still permit it. FHIR-53306 later removed the broader examples from MedicationAdministration/MedicationStatement and added terminology follow-up notes, so this reconciliation does not restore that superseded wording. The 2020 Pharmacy minutes and Zulip discussion both confirm that discharge overlapped with community and should not be part of the exemplar location-oriented value set.

AutoFHIR reconciliation:
Removed the discharge concept from the active MedicationAdministration, MedicationDispense, and MedicationRequest category CodeSystems. Their ValueSets compose from these CodeSystems, so the exemplar category value sets now expand to inpatient, outpatient, and community only, matching the FHIR-25555 decision while preserving the current category names and later descriptive wording.

Recommendation:
Keep this commit. Future Pharmacy/Terminology work such as FHIR-53306, FHIR-36027, or UP-555 can still redesign or move these example code systems, but the current core source should not continue to publish discharge as an exemplar location category after FHIR-25555.
