FHIR-24097: Correct MedicationDispense status code sources

Issue request:
FHIR-24097 was a Published/Persuasive Pharmacy change request raised from QA for MedicationDispense.status. It asked that the required binding for the code-typed MedicationDispense.status use the internally defined medicationdispense-status codes rather than a terminology.hl7.org CodeSystem URI, applied for R5.

Initial application:
Commit 8c940464f5f46e1b990e93df032065d1717847de applied the core request in February 2020 by changing source/medicationdispense/codesystem-medicationdispense-status.xml and source/medicationdispense/valueset-medicationdispense-status.xml from http://terminology.hl7.org/CodeSystem/medicationdispense-status to http://hl7.org/fhir/CodeSystem/medicationdispense-status. The current active MedicationDispense StructureDefinition binds MedicationDispense.status to http://hl7.org/fhir/ValueSet/medicationdispense-status, but the application left two source inconsistencies: the CodeSystem.valueSet backlink used the wrong case in the value set canonical, and medicationdispense-example.xml still represented the primitive status element as a Coding with the old THO system URI.

Additional context:
source/fhir.ini has MedicationDispense as an active resource, so the resource definition, terminology files, and examples in source/medicationdispense are current build inputs. FHIR-36259 and its linked terminology Zulip discussion later reaffirmed that R5 FHIR-defined MedicationDispense code systems should use hl7.org/fhir rather than terminology.hl7.org; FHIR-40692 later changed MedicationDispense status code content but did not change the URI ownership conclusion.

AutoFHIR reconciliation:
This commit corrects the CodeSystem.valueSet backlink to http://hl7.org/fhir/ValueSet/medicationdispense-status and changes the primary MedicationDispense example to use the primitive code form <status value="completed"/>. That removes the remaining stale terminology.hl7.org MedicationDispense.status system reference and aligns the example with the current code-typed element.

Recommendation:
Keep this commit. It completes the original FHIR-24097 URL correction in current build-scope source without reopening the later status-code content decisions.
