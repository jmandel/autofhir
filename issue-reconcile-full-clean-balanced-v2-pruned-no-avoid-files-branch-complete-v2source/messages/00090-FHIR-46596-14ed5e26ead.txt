Initial application:

A later nutrition module addition introduced three current use-case references to ClinicalImpression that were not covered by the rename application.

Additional context:
Later cleanup in FHIR-50192 removed the invalid ClinicalAssessment-rather-than-ClinicalAssessment rationale from the resource definition. Current source/fhir.ini no longer lists ClinicalAssessment or ClinicalImpression as active core resources after fad1b9cf84 moved several immature resources out of the current core build, and current active pages link ClinicalAssessment to the PC incubator. Historical entries that deliberately describe the old ClinicalAssessment-to-ClinicalImpression rename were left unchanged.

It does not edit out-of-build clinicalimpression/clinicalassessment resource directories or historical release notes.

Recommendation:
Keep this commit. It completes the seed rename for current active narrative pages while respecting the later decision to keep ClinicalAssessment outside the active core resource list.
