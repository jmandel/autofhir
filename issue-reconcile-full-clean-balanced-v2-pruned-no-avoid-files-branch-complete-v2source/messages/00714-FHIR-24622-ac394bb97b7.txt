FHIR-24622: Document variable extension realization usage

Issue request:
FHIR-24622 was Published with a Persuasive with Modification resolution for R5. It asked to allow the variable extension to be used with ActivityDefinition, PlanDefinition, and RequestGroup, with the same semantics as Questionnaire; the final resolution also asked that usage be discussed in the PlanDefinition and ActivityDefinition realization topics.

Initial application:
The Jira comment points to HL7/fhir#2288. Its source commit 47eab681fc556b8bcd18e8d3555145dd24b79a6d updated the then-active general extensions spreadsheet to allow the variable extension on PlanDefinition, RequestOrchestration, ActivityDefinition, and Measure-related contexts, but it did not add the requested realization-topic prose. A later core commit, dd468d4f1799dd79819315b211588ef1cf4586e0, removed extension definitions from the R5 core source as part of the move to the FHIR Extension Pack.

Additional context:
The current core build still includes ActivityDefinition, PlanDefinition, and RequestOrchestration as active resources in source/fhir.ini, while the variable StructureDefinition is now maintained in the Extension Pack. The current Extension Pack source already carries the relevant contexts for PlanDefinition, PlanDefinition.action, ActivityDefinition, RequestOrchestration, and version-scoped RequestGroup/RequestGroup.action. Searches found no Zulip or Confluence discussion that changed the Jira/source conclusion.

AutoFHIR reconciliation:
This commit updates the active PlanDefinition and ActivityDefinition realization narrative pages to explain that FHIRPath expressions can use named variables declared with the variable extension and that the variables follow the same Questionnaire-style scoping to descendant expressions and extensions on the same element. No core extension-definition edit was made because that artifact has moved out of this checkout and the Extension Pack context list is already aligned with the issue.

Recommendation:
Keep this source fix. Any future change to the extension's allowed contexts should be made in the FHIR Extension Pack, but the core realization topics now contain the usage guidance requested by FHIR-24622.
