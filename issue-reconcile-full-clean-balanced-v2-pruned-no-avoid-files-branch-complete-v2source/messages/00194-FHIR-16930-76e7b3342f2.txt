FHIR-16930: Remove stale OccupationalData guide entry

Issue request:
FHIR-16930 was Published/Persuasive for STU3 and asked that OccupationalData not exist as a FHIR core resource. The final resolution says the work group agreed to withdraw the resource and that Grahame would remove it.

Initial application:
The issue was initially applied in the SVN/Git history by efef182022eba3d6868acbe3fda5360783848135, whose message says "remove ODH (GF#16930)" and whose patch removed OccupationalData from active fhir.ini resource/workgroup/status mappings and removed Resource Guide prose. The current fhir.ini still has no active OccupationalData resource entry and only retains a commented note that OccupationalData for Health was dropped.

Additional context:
FHIR-14868 reached the same withdrawal conclusion and explicitly points readers to FHIR-16930. Zulip discussion after the withdrawal clarified that OccupationalData was retired and replaced by profiles on Observation and an ODH implementation guide. Historical release notes still mention that OccupationalData appeared in R4 draft/ballot builds, which is historical record rather than current-resource guidance.

AutoFHIR reconciliation:
Removed the remaining current Resource Guide table row that linked to occupationaldata.html and classified OccupationalData as an ongoing resource. The Resource Guide is included in the current page hierarchy and linked from current documentation pages, while no source/occupationaldata.html page exists and OccupationalData is not active in fhir.ini. No out-of-build occupationaldata source folder files or historical release notes were changed.

Recommendation:
Keep this source fix. It completes the intended core-spec withdrawal by removing the only current guide reference that still presented OccupationalData as an available resource; the remaining historical mentions and inactive source remnants do not change current implementer guidance.
