FHIR-40716: Remove expansionSource from ValueSet example

Issue request:
FHIR-40716 was Applied/Persuasive with Modification for the FHIR-core ValueSet artifact. The Vocabulary work group decided to retire the valueset-expansionSource extension because ValueSet.url should be used instead and the extension did not appear to have current use.

Initial application:
Core had already moved extension definitions out of the R5 source in dd468d4f17, and the FHIR Extension Pack later changed StructureDefinition-valueset-expansionSource to retired with replacement guidance. The current core source still had one active ValueSet example instantiating the retired extension in source/valueset/valueset-example-expansion.xml, so the retirement was not fully reflected in core examples.

Additional context:
The ValueSet resource is active in source/fhir.ini, and source/valueset/list-ValueSet-examples.xml lists ValueSet/example-expansion as a built example. A 2019 Zulip thread shows the original extension was already ambiguous around literal URLs versus ValueSet.url, and 2024 Vocabulary minutes/Jira record the later decision to retire it. The remaining source/oids.ini entry is a historical canonical/OID registry mapping, not an active extension use.

AutoFHIR reconciliation:
Removed the valueset-expansionSource extension instance and its now-stale explanatory comment from the active prepared-expansion ValueSet example. No Extension Pack files were changed in this core commit because the extension definition there is already retired/deprecated.

Recommendation:
Keep this commit as-is. It removes the only current core example use of the retired extension while preserving the example's own ValueSet URL, compose, expansion, identifier, and OID registry history.
