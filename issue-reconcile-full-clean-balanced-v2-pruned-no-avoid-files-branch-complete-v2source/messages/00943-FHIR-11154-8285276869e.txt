FHIR-11154: Align AllergyIntolerance onset example text

Issue request:
FHIR-11154 was a Published Patient Care change request with a Persuasive with Modification resolution. It reported that AllergyIntolerance.onset and AllergyIntolerance.reaction.onset appeared duplicative and directed the short descriptions to be aligned with their definitions: the resource-level onset identifies when the allergy or intolerance was identified, while reaction.onset describes when manifestations showed.

Initial application:
The issue was initially applied in git commit 87f224c94cabbf01ee3789f815f26c69d05608d4, which changed the AllergyIntolerance source spreadsheet short for AllergyIntolerance.onset from "Date(/time) when manifestations showed" to "Date(/time) when allergy or intolerance was identified." The current authoritative StructureDefinition source already preserves the distinct meanings, with AllergyIntolerance.onset[x] shortened to "When allergy or intolerance was identified" and AllergyIntolerance.reaction.onset shortened to "Date(/time) when manifestations showed." The static AllergyIntolerance fragment embedded in source/conformance-rules.html was not updated and still showed the reaction onset wording for the resource-level onset row.

Additional context:
AllergyIntolerance is an active resource in source/fhir.ini, and source/conformance-rules.html is an active Conformance page referenced from hierarchy.xml and other source pages. FHIR-11089, resolved in the same Patient Care vote block, later made AllergyIntolerance.onset polymorphic and helps explain the current onset[x] source wording. Searches for FHIR-11154 in Zulip and Confluence found no community evidence that changes the Jira/source conclusion.

AutoFHIR reconciliation:
Updated the active Conformance Rules example row for AllergyIntolerance.onset so its visible description matches the current authoritative AllergyIntolerance.onset[x] short description. No change was needed in source/allergyintolerance/structuredefinition-AllergyIntolerance.xml because that source already distinguishes onset[x] from reaction.onset.

Recommendation:
Keep this source fix. It removes the remaining active-source contradiction for FHIR-11154 without broadening the change to unrelated stale details in the illustrative conformance table.
