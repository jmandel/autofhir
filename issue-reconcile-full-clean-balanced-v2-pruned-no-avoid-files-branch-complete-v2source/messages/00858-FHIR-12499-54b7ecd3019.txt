FHIR-12499 was a Published/Persuasive FHIR-core Medication change request for the DSTU2 Medication example 0312. The reporter noted that the nystatin strength was encoded with UCUM code u, which is catalytic activity rather than the medication unit, and suggested an arbitrary unit; the final Jira comment records the pharmacy decision to update the example to IU based on a product monograph.

Initial application:
The issue was initially applied by git commit 4f5fe65422a89b2e434652d99e869ab248196f53, which changed the Medication example numerator code from u to IU. A later medication UCUM correction in 17795bbfaf5fb47e4c1961e386c5fea10e7b4926 changed that code from IU to [IU], leaving the current authoritative Medication example source semantically correct.

Searches for related Jira, Zulip, and Confluence evidence found no later or conflicting decision.
