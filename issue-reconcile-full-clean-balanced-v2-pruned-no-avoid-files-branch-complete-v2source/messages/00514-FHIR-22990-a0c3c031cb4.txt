FHIR-22990: Include bundle types in AuditEvent subtype examples

Issue request:
FHIR-22990 was Published/Persuasive for R5 by the Security work group and asked to add the Bundle Type value set to the value set used for AuditEvent.subtype.

Initial application:
No prior git commit mentioning FHIR-22990 was found on the relevant AuditEvent or Bundle sources. R5 source and the current branch both retained the AuditEvent subtype value set without an import of http://hl7.org/fhir/ValueSet/bundle-type.

Additional context:
Later FHIR-32441 changed the AuditEvent subtype binding to example and moved the current source toward an example value set, while FHIR-44746 later restored the current element name back to AuditEvent.subtype. Those later changes affect the target file/name but do not reverse the request to include bundle types as example subtype codes.

AutoFHIR reconciliation:
Added an include for http://hl7.org/fhir/ValueSet/bundle-type to source/auditevent/valueset-audit-event-sub-type-example.xml. The file is in build scope because AuditEvent is an active resource in source/fhir.ini and the AuditEvent.subtype binding points to this value set.

Recommendation:
Keep this source fix. It directly applies the published Security decision while preserving the later example binding semantics and current AuditEvent subtype model.
