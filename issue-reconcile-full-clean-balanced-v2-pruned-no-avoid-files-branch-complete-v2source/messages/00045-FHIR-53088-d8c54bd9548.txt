FHIR-53088: Correct complex extension base URL

Issue request:
FHIR-53088 was Applied as Persuasive with Modification for R6. It asked the Extensibility page to clarify that local child extension URLs are allowed only for child extension slices introduced by a StructureDefinition defining a complex extension whose base is http://hl7.org/fhir/StructureDefinition/Extension, not by derived profiles of an existing complex extension.

Initial application:
The issue was applied in upstream source commit c9eb1465db96232b9300125b8a29ff8477acbc21, which changed source/extensibility.html from the older "child extensions defined within complex extensions" wording to the approved scope. That application accidentally left a trailing apostrophe inside the coded canonical URL, making the base URL read http://hl7.org/fhir/StructureDefinition/Extension'.
