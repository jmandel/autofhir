FHIR-12235: Replace stale ImagingStudy baseLocation wording

Issue request:
FHIR-12235 was Published/Persuasive with Modification for DSTU2 by Imaging Integration. It asked to replace ImagingStudy.baseLocation and ImagingStudy.series.baseLocation with 0..* Reference(Endpoint) elements, update definitions/comments and implementation notes, add an endpoint search parameter, and remove the old baseLocation terminology bindings.

Initial application:
The issue was initially applied in d6c6d61a7220660624430008cee9d5aaee9727d1, which updated ImagingStudy and ImagingManifest together for GF#12235/GF#12236 and added Endpoint examples. Later source-generation/refactor history preserved the new ImagingStudy.endpoint and ImagingStudy.series.endpoint elements and endpoint search parameter, but two active ImagingStudy requirements strings still referred to the retired baseLocation name.

Additional context:
ImagingStudy is active in source/fhir.ini, while ImagingManifest is listed under removed resources. Later FHIR-14080 removed ImagingManifest and moved the relevant endpoint notes into ImagingStudy. Current ImagingStudy notes and search parameters already describe study/series Endpoint references and same-connection-type precedence, and a later FHIR-47660 reconciliation left the older baseLocation requirements wording as the remaining follow-up.

AutoFHIR reconciliation:
This commit updates the two active ImagingStudy endpoint requirements strings to describe study-level and series-level endpoints instead of the obsolete baseLocation element name. It does not edit the removed ImagingManifest spreadsheet or the r4-r6 change-map aliases in fhir.ini, because those are not current ImagingStudy conformance text.

Recommendation:
Keep this commit as-is. It completes the current build-scoped portion of FHIR-12235 without changing the Endpoint cardinality, target type, search parameter, or implementation guidance.
