FHIR-14802: Clarify Appointment terminology relationship note

Issue request:
FHIR-14802 was a Published/Persuasive PA change request for Appointment asking for some connection between serviceCategory and serviceType. The accepted resolution was to add Appointment notes guidance that relationships may exist among serviceType, serviceCategory, and specialty coded values, but those relationships may exist only in terminology rather than in the Appointment resource structure or properties.

Initial application:
The issue was initially applied in git commit a97e4034ed9, which added an Appointment notes bullet and STU feedback text for ServiceCategory, ServiceType, and Specialty. Commit 6a844f570e5 immediately adjusted "may" to "might", but left the confusing phrase "but not these might not be visible" in the notes text. Appointment remains an active build resource in source/fhir.ini, and source/appointment/appointment-notes.xml is the current source fragment carrying the note.

Additional context:
The current Appointment StructureDefinition defines serviceCategory, serviceType, and specialty as separate coded elements with example bindings, consistent with the Jira decision not to add a structural linkage. Jira searches for the same Appointment terminology relationship terms found only FHIR-14802 in core. Exact FHIR-14802 Zulip and Confluence searches found no conflicting community decision. FHIR-14805 was encountered in nearby Appointment history, but it concerns appointmentType code guidance and is not the same relationship question.

AutoFHIR reconciliation:
This commit removes the stray "not" from the Appointment notes sentence so the existing guidance clearly says the terminology relationships might not be visible in the actual Appointment resource or profile. It does not add structural constraints or duplicate guidance elsewhere.

Recommendation:
Keep this source fix as-is. It preserves the work group decision while correcting an ambiguity introduced during the original application, and no broader Appointment model change is supported by the seed evidence.
