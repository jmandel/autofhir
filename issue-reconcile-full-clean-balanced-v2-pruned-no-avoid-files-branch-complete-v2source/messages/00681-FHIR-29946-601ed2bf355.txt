FHIR-29946: Align ConceptMap relationship refinement guidance

Issue request:
FHIR-29946 was Published/Persuasive with Modification for R5. It asked for guidance because ConceptMapRelationship is exhaustive and required, and the approved resolution chose a FHIR-defined ConceptMap Properties code system with a relationshipRefinement concept of type Coding for refined relationships such as categorized by or grouped by, plus ConceptMap usage-note updates.

Initial application:
Git commit df5716f79e7f65a2e95bb516ce8a21e91d91bc69 added source/conceptmap/codesystem-conceptmap-properties.xml, registered it in source/fhir.ini, and added ConceptMap usage prose. That initial prose used the then-current target.product/property shape, and commit 0ea77251fbc8235f859e90d09fd857666b0bbf8b later changed it to ConceptMap.group.element.target.property after the R5 structural work. The remaining current text still did not describe the required ConceptMap.property declaration and still suggested valueCode as an option even though the approved relationshipRefinement property is Coding-valued.

Additional context:
ConceptMap is active in source/fhir.ini and the conceptmap-properties code system is actively registered, so both edited files feed the current build. Later FHIR-40504/FHIR-40544 work split ConceptMap mapping properties from additional attributes: the current StructureDefinition says ConceptMap.group.element.target.property.code references ConceptMap.property.code, and the R4-to-R5 change note says mapping properties are defined using ConceptMap.property. FHIR-40504 already has a reconcile commit on the combined branch, so this commit only reconciles the FHIR-29946-specific relationship-refinement guidance.

AutoFHIR reconciliation:
Updated the ConceptMap scope/usage note to say that a relationship refinement is declared via ConceptMap.property with a code, the relationshipRefinement URI, and type Coding, and that target.property then references that property code and carries the refined relationship in valueCoding. Updated the relationshipRefinement code-system definition to use the FHIR type name Coding and to preserve the approved grouped by example.

Recommendation:
Keep this source fix. It aligns the active R6 ConceptMap guidance with the FHIR-29946 decision and the later approved ConceptMap.property model without reopening the broader FHIR-40504 property/additionalAttribute work.
