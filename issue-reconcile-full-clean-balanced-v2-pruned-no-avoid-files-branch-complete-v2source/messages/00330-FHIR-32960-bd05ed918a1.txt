FHIR-32960: Align vaccine administration guidance

Issue request:
FHIR-32960 was a Published/Persuasive Pharmacy change request for R5 asking whether MedicationAdministration includes vaccines. The final resolution clarified that MedicationAdministration is not the primary representation for vaccine administration: Scope and Usage should refer readers to Immunization for vaccines, while Boundaries should allow MedicationAdministration for vaccination workflow reasons only when systems also create and expose an equivalent Immunization instance.

Initial application:
The issue was partially applied by git commit 6cdd7b792e2241b7191584bd35915d4b0f9841f8, which removed "and vaccines" and "non-vaccine" from the MedicationAdministration page and added the workflow exception text. That application left two small remnants in the same active page: "resource/Profile" and "Medication Administration resource". It also did not update the active Immunization Boundaries paragraph, which still said MedicationAdministration was intended for "non-vaccine medications" and used the pre-FHIR-32960 exception wording.

Additional context:
Both MedicationAdministration and Immunization are active resources in source/fhir.ini. Pharmacy minutes on 2021-07-19 record the FHIR-32960 motion to fix the Scope and Usage consistency issue and note that Boundaries should acknowledge MedicationAdministration may exist for workflow purposes. Searches found no later Jira, Zulip, or Confluence decision reversing this clarification; older FHIR-7731 and FHIR-7732 explain the wording that FHIR-32960 later clarified but do not supersede it.

AutoFHIR reconciliation:
This commit removes the obsolete "resource/Profile" phrasing and normalizes the resource name on the MedicationAdministration page. It also updates the active Immunization Boundaries paragraph to match the clarified MedicationAdministration guidance, removing the stale "non-vaccine medications" rule and adding the same explicit allowance plus equivalent Immunization requirement.

Recommendation:
Keep this commit as-is. It completes the FHIR-32960 clarification across the two active pages that present the MedicationAdministration/Immunization boundary, without changing conformance structures or adding unrelated guidance.
