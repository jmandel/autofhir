FHIR-40792: Align contains modifier code definition

Issue request:
FHIR-40792 was Applied/Persuasive for R6 after a 6-0-0 FHIR-I vote. It asked to define a `:contains` search modifier for hierarchical reference searches so a single search can return the selected node, its ancestors, and its descendants.

Initial application:
The issue was applied by PR 3967 as commit f41c8ea93f5763d8335d679863f9a3fc45dde6db, which updated the core search page to list `contains` for reference parameters, describe the ancestor/descendant behavior, and add a Task `part-of:contains` example. That application left the active `search-modifier-code` CodeSystem definition with only the prior field-containment wording.

Additional context:
FHIR-36684 is the earlier published search-modifier clarification that listed `contains` only for string and uri parameters, so FHIR-40792 is a later same-area decision expanding the modifier semantics to supported reference hierarchies. Confluence minutes show the April 2023 request for a Zulip thread and the May 2023 FHIR-I WGM decision that further Zulip discussion was unnecessary before the Persuasive vote. No directly relevant Zulip thread was found for the issue key.

AutoFHIR reconciliation:
This commit updates the authoritative `search-modifier-code` CodeSystem definition so the terminology artifact matches the search page's R6 hierarchical `:contains` semantics. It also corrects the adjacent typo in the search-page modifier summary from `hierarchial` to `hierarchical`. Both edited files are current core source: `search.html` is the FHIR core search page and `source/fhir.ini` actively includes the `search-modifier-code` ValueSet/CodeSystem family.

Recommendation:
Keep this commit as-is. The current search page already carries the substantive behavior; this reconciliation closes the remaining parallel-definition gap in the modifier CodeSystem. Future work should only revisit this if FHIR-I wants more formal computable constraints for which reference SearchParameters support hierarchical `:contains`.
