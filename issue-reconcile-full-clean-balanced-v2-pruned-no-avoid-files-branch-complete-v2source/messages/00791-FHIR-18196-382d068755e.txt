FHIR-18196: Correct ActivityDefinition subject resolution wording

Issue request:
FHIR-18196 was Published/Persuasive for STU3 by CDS. It requested adding a 0..1 subject CodeableConcept to PlanDefinition.action, documenting that an action subject overrides a parent/root PlanDefinition subject, documenting by-type subject resolution during realization including ActivityDefinitions, and changing the $apply patient parameter to subject with cardinality 1..*.

Initial application:
The issue was initially applied in git commit 2b9949c7e4ad0746b24d36bd1172bf7c46feae2f, which changed the PlanDefinition and ActivityDefinition spreadsheets plus the PlanDefinition $apply request example. Current generated source already has PlanDefinition.action.subject[x] at 0..1 with CodeableConcept and the requested override/resolution comment, and both PlanDefinition/$apply and ActivityDefinition/$apply use subject 1..*. However, the ActivityDefinition/$apply subject parameter documentation still said supplied subjects resolve as the subject of the PlanDefinition.

Additional context:
ActivityDefinition and PlanDefinition are active resources in source/fhir.ini, and their operation list files reference the $apply OperationDefinitions, so the edited OperationDefinition source is in current build scope. Later FHIR-29211 expression-context guidance is already represented on the combined branch and does not change this issue's subject-resolution requirement. Zulip and Confluence searches found no conflicting community evidence for FHIR-18196.

AutoFHIR reconciliation:
Changed ActivityDefinition/$apply subject parameter documentation so subjects provided to the ActivityDefinition operation resolve as the subject of the ActivityDefinition, not the PlanDefinition. No PlanDefinition.action source change was needed because the current source already carries the requested action subject element, CodeableConcept choice, cardinality, and override/resolution comment.

Recommendation:
Keep this commit as-is. It preserves the already-applied PlanDefinition changes and fixes the only directly related stale wording found in the active current source.
