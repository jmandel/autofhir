FHIR-46397: Remove stale Device.displayName comments

Issue request:
FHIR-46397 was Applied with a Persuasive resolution for R6 to remove Device.displayName because it duplicated the Device.name backbone, especially Device.name.display as the preferred display-name flag.

Initial application:
The Jira-tagged source commit 8f12564689 removed the active Device.displayName element by commenting it out and replaced displayName values in specimen-container examples with Device.name entries, but it left commented-out Device.displayName XML in the active StructureDefinition source and built examples.

Additional context:
Device is an active current-build resource in source/fhir.ini, and the five specimen-container examples are referenced by source/device/list-Device-examples.xml. Earlier FHIR-22113 and FHIR-39162 history explains why Device.displayName was introduced and then replaced by Device.name/display, while the 2024 OO HCP minutes record the FHIR-46397 9-0-0 motion to remove Device.displayName. A current build.fhir.org example still exposed the old displayName line as an XML comment, so the remaining comments were visible specification surface rather than only private editor history.

AutoFHIR reconciliation:
Removed the stale commented-out Device.displayName element block from source/device/structuredefinition-Device.xml and removed the commented displayName lines from the five active specimen-container Device examples. The intentional release-note text saying Device.displayName was removed was left intact.

Recommendation:
Keep this commit as-is. It completes the applied R6 removal without changing the Device.name replacement content or unrelated Device example data.
