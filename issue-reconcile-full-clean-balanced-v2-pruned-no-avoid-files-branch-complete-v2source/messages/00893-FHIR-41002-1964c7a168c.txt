FHIR-41002: Replace stale Observation canonical FHIRPath example

Issue request:
FHIR-41002 is an Applied/Persuasive R6 Orders and Observations change request for FHIR-core Observation. It asked to remove the invalid Observation.value-canonical, Observation.value-markdown, and Observation.component-value-canonical search parameters because FHIR-40560 removed the corresponding canonical and markdown choices from Observation.value[x] and Observation.component.value[x].

Initial application:
The search-parameter portion was applied before this reconciliation. Commit 02474e83d75 changed the invalid Observation-value-markdown entry to Observation-value-string, and commit 66ee797aab commented out the remaining Observation-value-canonical and Observation-component-value-canonical entries; the current source has removed those obsolete entries entirely.

Additional context:
Observation is an active current-build resource in source/fhir.ini, and source/observation/bundle-Observation-search-params.xml contains no value-canonical, value-markdown, or component-value-canonical SearchParameter entries. FHIR-40560 and the 2023-03-06 OO HCP minutes confirm that canonical and markdown were removed from both Observation.value[x] and Observation.component.value[x]. Later commit 8926ed3049 for FHIR-45455 added examples to the built FHIRPath narrative page and introduced Observation.value.ofType(canonical), recreating the same invalid Observation value expression outside the search-parameter bundle. The source/fhirpath.html page is linked from the core documentation and implementation-support pages, so it is in current build scope.

AutoFHIR reconciliation:
This commit changes the stale FHIRPath ofType example from Observation.value.ofType(canonical) to Observation.value.ofType(string). It intentionally leaves the already-correct Observation search-parameter bundle unchanged, because the invalid search parameters requested by FHIR-41002 are no longer present.

Recommendation:
Keep this source fix as-is. The current search-parameter application should remain unchanged; future Observation.value search-parameter work should follow the already represented related audits for FHIR-44931, FHIR-45339, and FHIR-41255 or a new OO decision.
