FHIR-41583: Align Group status audit metadata

Attribution note: surfaced while reviewing FHIR-30431, but direct Jira backing for this change is FHIR-41583.

Issue request:
FHIR-30431 was a Published FHIR-core Group change request, resolved Persuasive with Modification for R5, asking why Group.active was not a modifier when Patient.active was. The approved resolution was to update Group.active to mirror Patient.active's modifier and meaningWhenMissing behavior.

Initial application:
The issue was applied in git commit 14cf0e36f8b60a5507c6add4b039cea6ffcffa99, which added meaningWhenMissing, isModifier, and isModifierReason to Group.active in source/group/structuredefinition-Group.xml. Patient.active already had the corresponding modifier and missing-meaning metadata.

Additional context:
FHIR-41583 later changed Group for conceptual CohortDefinition support by adding CanonicalResource-style metadata, adding Group.status as a modifier status element, and then removing Group.active. That related issue is already represented on the combined branch by reconcile commit 1a124d02c1efbf24a9faccb297a4cf5f4983539d, so this commit does not duplicate a FHIR-41583 decision. The current Group source is in build scope through source/fhir.ini, and after the later refactor the only stale Group.active semantic residue in active source was the build entered-in-error-status metadata still pointing at .active = false.

AutoFHIR reconciliation:
This commit updates source/group/structuredefinition-Group.xml so Group's entered-in-error-status metadata points at the current Group.status element using .status = retired. No Group.active element is restored; current Group.status remains the modifier status element that carries the post-FHIR-41583 replacement semantics.

Recommendation:
Keep this source fix. It preserves the FHIR-30431 outcome after the later Group.active-to-Group.status refactor and removes a stale active-element reference without reopening the already-audited broader FHIR-41583 Group redesign.
