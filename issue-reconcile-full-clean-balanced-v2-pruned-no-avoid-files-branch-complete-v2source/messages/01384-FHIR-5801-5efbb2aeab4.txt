FHIR-7704: Correct Coding.system URI guidance

Attribution note: surfaced while reviewing FHIR-5801, but direct Jira backing for this change is FHIR-7704.

Issue request:
FHIR-5801 was Published with a Persuasive with Modification resolution to improve Coding.system URI documentation by extracting system URI management and registration guidance into one section and referring to it from relevant places.

Initial application:
The Jira comments record svn revision 5735, represented in git as 303df2d0c1, which added the centralized Managing Terminology System URIs/Choosing a system guidance in source/terminologies.html and changed source/datatypes.html so Coding.system links to that section. That initial application correctly centralized the guidance, but later model changes left one sentence in the centralized section using obsolete ValueSet.codeSystem.system and ValueSet.uri names.

Additional context:
Current source/datatypes.html still directs Coding.system readers to source/terminologies.html#system and states that CodeSystem.url is the correct system value, while source/codesystem/codesystem-introduction.xml says Coding.system refers to a CodeSystem resource by canonical URL. FHIR-7704 and commit db97687e38 cleaned the same obsolete ValueSet inline-code-system wording from source/datatypes.html but did not touch the centralized source/terminologies.html note. Later FHIR-50716 and related terminology minutes updated URI selection policy toward THO/TSMG without changing the CodeSystem.url versus ValueSet.url rule.

AutoFHIR reconciliation:
Updated the centralized Choosing a system note in source/terminologies.html to say that codes defined by a CodeSystem resource use CodeSystem.url as the Coding.system value, not ValueSet.url. This removes the only remaining obsolete ValueSet.codeSystem.system/ValueSet.uri wording in current source while preserving the single-section guidance requested by FHIR-5801.

Recommendation:
Keep this commit. No broader source rewrite is needed for FHIR-5801 because the current spec already centralizes Coding.system URI management and links to it; this commit only corrects stale terminology that would otherwise mislead current implementers.
