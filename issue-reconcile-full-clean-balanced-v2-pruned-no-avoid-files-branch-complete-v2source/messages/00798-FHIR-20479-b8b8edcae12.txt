FHIR-20479: Align Encounter subject wording

Issue request:
FHIR-20479 is a Published/Persuasive Patient Administration change request for FHIR-core Encounter. It asked to clarify that an Encounter may be about a patient even when the patient is not present by changing the resource intro sentence from "An interaction between a patient and healthcare provider(s)..." to "An interaction between healthcare provider(s), and/or patient(s)...", changing Encounter.subject from "present at the encounter" to "related to this encounter", and adding detail that the patient may not be present.

Initial application:
The issue appears to have been partially applied by git commit 7c617a3490739b95606a58a83c35e1d44ce3b436, which updated source/encounter/structuredefinition-Encounter.xml's resource description and Encounter.subject short/definition. That application did not update the root Encounter element definition, which still repeated the old "between a patient and healthcare provider(s)" wording, or the Encounter patient/subject search parameter descriptions, which still said the subject or patient was "present at the encounter".

Additional context:
source/fhir.ini actively lists encounter=Encounter, so the Encounter StructureDefinition and search parameter bundle are current core build inputs. FHIR-32346 later added the Appointment contrast to the Encounter root definition; this reconciliation preserves that later context while replacing only the stale opening sentence with the already-approved FHIR-20479 wording. FHIR-21770 and FHIR-13601 clarify that Encounter-patient is patient-only, not Patient-or-Group; this reconciliation preserves that patient-only meaning while removing the now-misleading presence requirement.

AutoFHIR reconciliation:
This commit updates source/encounter/structuredefinition-Encounter.xml so the root Encounter definition uses the FHIR-20479 resource wording and still includes the FHIR-32346 Appointment/planned-activity contrast. It also updates source/encounter/bundle-Encounter-search-params.xml so Encounter-patient and Encounter-subject descriptions say the patient or subject is related to the encounter rather than necessarily present.

Recommendation:
Keep this source fix. It completes the published FHIR-20479 clarification across the authoritative Encounter definition and search parameter descriptions without undoing later approved Encounter wording or patient-only search parameter semantics.
