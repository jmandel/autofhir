FHIR-27881: Update payer/payor glossary definitions

Issue request:
FHIR-27881 was Published with a Not Persuasive with Modification resolution. It declined renaming Coverage.payor to Coverage.payer, but required updated Coverage.payor wording about the insurance issuer or party accepting payment responsibility and required the Financial Module Glossary definitions for both payer and payor to use the transaction-responsibility definition.

Initial application:
The merge commit d10524542f7201a073d3a2e84e0abed57a71fa8b listed FHIR-27881 as changing the Coverage.payor definition. The underlying source commit 720258c80a99566e1259c4c1a1dcacd8fbc5abbf changed Coverage.payor as part of the later Coverage.insurer/paymentBy model and added the long payer definition to the Insurer glossary row, but the Payer and Payor glossary rows still said only "A public or private insurer."

Additional context:
FHIR-30928 and FHIR-32076 later finalized the R5 Coverage model by renaming the issuer element to Coverage.insurer and separating non-insurance payment responsibility into Coverage.paymentBy. Current Coverage source reflects that later model, so no Coverage element rename or definition hunk is needed for this issue. The financial module page is in current build scope through source/hierarchy.xml and publish.ini.

AutoFHIR reconciliation:
Updated source/financial-module.html so the Payer and Payor glossary rows now carry the transaction-responsibility definition already present on the Insurer row. This applies the remaining glossary part of FHIR-27881 without changing the later Coverage.insurer/paymentBy model.

Recommendation:
Keep this source fix. Broader payer/payor spelling modernization or model changes should remain with later terminology or Coverage issues rather than being folded into this reconciliation.
