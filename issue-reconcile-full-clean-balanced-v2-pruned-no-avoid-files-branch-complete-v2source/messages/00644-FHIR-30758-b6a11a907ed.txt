FHIR-30758: Clarify otherTherapy treatment scope

Issue request:
FHIR-30758 was an Applied/Persuasive R5 BRR change request for ClinicalUseIssue otherTherapy. The accepted change renamed otherTherapy.medication[x] to a therapy-oriented element, added ActivityDefinition as a reference target, and broadened the example therapy ValueSet beyond drug therapies; later Jira comments record that using SNOMED CT Therapeutic procedure instead of all Procedure was acceptable.

Initial application:
The structural request was first applied in 447e322ee6dae0af815d4430df0bfbae89dc9209 by renaming medication[x] to therapy[x] and adding ActivityDefinition. ClinicalUseIssue was later renamed to ClinicalUseDefinition for FHIR-31847, FHIR-37921 renamed otherTherapy.therapy to otherTherapy.treatment to satisfy build naming rules, and 9d5ab5f45f584f5ee05d7c2056e417b8610f9cb4 widened ValueSet/therapy with the product and drug/substance SNOMED CT filters while retaining Therapeutic procedure.

Additional context:
ClinicalUseDefinition is the active current-build resource in source/fhir.ini, while ClinicalUseIssue is commented out. The current structure already includes ActivityDefinition, NutritionProduct, BiologicallyDerivedProduct, Medication, MedicinalProductDefinition, and SubstanceDefinition targets, and ValueSet/therapy includes Therapeutic procedure plus the product and drug/substance filters. However, the treatment element short and definition still described the element as a specific medication, which undercut the accepted non-drug therapy scope.

AutoFHIR reconciliation:
Updated only ClinicalUseDefinition.indication.otherTherapy.treatment wording so the element definition describes a treatment that may be medication, substance, biologically derived product, nutrition product, procedure, or other activity. No cardinality, type, targetProfile, binding, ValueSet composition, examples, or generated diagram source was changed.

Recommendation:
Keep this source fix as-is. The current structural model and ValueSet already implement the approved FHIR-30758 semantics, and this commit removes the remaining medication-centric wording that could mislead implementers.
