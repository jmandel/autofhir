FHIR-36933: Fix jurisdiction UsageContext binding purpose

Issue request:
FHIR-36933 was an Applied/Persuasive FHIR-I change request to add a jurisdiction usage-context type and make the Jurisdiction value set available through the ConformanceUseContext/UsageContext value set for places such as extension and obligation definitions. The final 2023 disposition reopened the earlier extension-only resolution and approved adding jurisdiction to usageContext as proposed.

Initial application:
No explicit FHIR-36933-tagged source commit was found. The current source already has the jurisdiction value-set include in source/terminologies/valueset-use-context.xml and the THO usage-context-type jurisdiction code exists through UP-459. A later FHIR-45507 commit, e3fe9fdef25099c995e905af26b84a15734f81c4, added source/datatypes/UsageContext-additional-bindings.xml with a jurisdiction-specific additional binding, follow-up commits fixed its XML structure and THO URL, but the jurisdiction binding purpose remained misspelled as exetensible.

Additional context:
FHIR-I minutes show the issue was first resolved in 2022 by choosing a jurisdiction extension, then reopened and approved on 2023-08-21. Zulip discussion immediately before the 2023 vote identified the R5 jurisdiction inconsistency and the missing jurisdiction code in the THO usage-context-type CodeSystem; UP-459 subsequently implemented that THO code. FHIR-38841 is the same change family for topic/jurisdiction migration and is already represented on the combined branch, so this commit does not duplicate that issue.

AutoFHIR reconciliation:
This commit corrects the jurisdiction UsageContext additional-binding source fragment from purpose value exetensible to the valid binding-strength purpose extensible. The edited fragment belongs to the active UsageContext datatype source, while the jurisdiction value-set include and external THO code are already present and were left unchanged.

Recommendation:
Keep this commit. It fixes the only remaining current core source defect found for FHIR-36933; no further core source change is recommended unless a later work group decision changes how jurisdiction usage contexts should be represented.
