FHIR-37879: Clarify payee provider references

Issue request:
FHIR-37879 is an Applied FHIR-core Claim change request resolved Persuasive with Modification. It asked that Claim, ClaimResponse, and ExplanationOfBenefit payee descriptions clarify that when the payee type code is 'provider', the referenced party is the billing provider identified by the corresponding provider element.

Initial application:
The issue was initially applied by commit ee3ca87b00 and merged by 79f858d3e9. That change replaced several generic "provider" references with "billing provider" in Claim, ClaimResponse, and ExplanationOfBenefit payee text, but it did not explicitly connect the 'provider' payee type to Claim.provider, ClaimResponse.requestor, or ExplanationOfBenefit.provider, and Claim.payee.type still listed only "provider" without the requested explanation.

Additional context:
Claim, ClaimResponse, and ExplanationOfBenefit are active resources in source/fhir.ini. In the current R6 source, ClaimResponse uses ClaimResponse.requestor rather than ClaimResponse.provider; the ClaimResponse.requestor definition/comment identify that element as the billing provider. No Zulip or Confluence evidence was found that conflicts with the Jira resolution or the source/history reading.

AutoFHIR reconciliation:
This commit updates the authoritative StructureDefinition XML for Claim.payee, Claim.payee.type, ClaimResponse.payeeType, ExplanationOfBenefit.payee, and ExplanationOfBenefit.payee.type so the 'provider' payee code remains visible while explicitly identifying it as the billing provider specified by the relevant resource element.

Recommendation:
Keep this source-changing commit. No terminology or example change is recommended because the code remains 'provider' in the external payeetype code system and the resource element definitions now provide the requested local clarification.
