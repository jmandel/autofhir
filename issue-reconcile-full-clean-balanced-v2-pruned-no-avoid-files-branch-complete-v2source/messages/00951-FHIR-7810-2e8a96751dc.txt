FHIR-7810: Add RXD-19 medication expiration mapping

Issue request:
FHIR-7810 was a Published/Persuasive Pharmacy change request from the 2015 May DSTU QA process. It asked to populate the Medication batch/expirationDate HL7 v2 mapping with RXA-16 Substance Expiration Date and RXG-20 Substance Expiration Date; the Jira discussion also recorded a reviewer concurrence to add RXD-19 Substance Expiration Date.

Initial application:
The issue appears to have been partially applied in SVN-migrated commit 651364cb098a623c36afc1d6b9d56578507d897c, which listed tracker #7810 and added the RXA-16/RXG-20 mapping to Medication.product.batch.expirationDate during a medication v2 mapping cleanup. That commit did not include the RXD-19 addition requested in the Jira comment. The current build-scope source has since moved the element lineage to Medication.instance.expirationDate and still carried only RXA-16/RXG-20.

Additional context:
Medication is active in source/fhir.ini, and fhir.ini records the old Medication.batch.expirationDate lineage to the current Medication.instance.expirationDate. Current source searches found no other Medication expiration-date v2 mapping containing RXD-19. Related FHIR-7816, already audited on the combined branch, removed an RXD-19 mapping from MedicationPrescription/MedicationRequest dispenseRequest.validityPeriod because that was a prescription validity period rather than a product expiration date; it does not conflict with adding RXD-19 to Medication.instance.expirationDate.

AutoFHIR reconciliation:
This commit updates the active Medication StructureDefinition source so Medication.instance.expirationDate maps to RXA-16 Substance Expiration Date, RXG-20 Substance Expiration Date, and RXD-19 Substance Expiration Date. The hunk is necessary because the current source otherwise preserves only the partial historical application and omits the reviewer-requested v2 dispense expiration field.

Recommendation:
Keep this source fix as-is. No broader core source follow-up is needed unless Pharmacy reopens Medication v2 mappings; FHIR-7816 should remain separate because it concerns prescription validity, not medication instance expiration.
