FHIR-53885: Fix Break the Glass moved-section links

Issue request:
FHIR-53885 was an Applied/Persuasive with Modification R6 Security WG change request about Security Labels section 6.1.1.3. The Jira said the Break the Glass examples looked like UDAP/HTTP request examples rather than FHIR-core meta.security examples and were inconsistent with 6.1.1.1; the approved resolution was to move 6.1.1.3 to the Security Principles page and update the UDAP reference to FAST Security for Scalable Registration, Authentication, and Authorization with a non-version-specific link.

Initial application:
The issue was initially applied by commit b7b0249d1f4cc7d8442639d6c728fc7c22359905, which removed the Break the Glass section from source/security-labels.html and inserted it into source/security.html. Later same-PR/security-page commits, including FHIR-53719, refined the FAST Security wording and non-versioned links. The moved section was present on the current Security page, but two build-scope source references still pointed to the old security-labels.html#break-the-glass anchor.

Additional context:
source/secpriv-module.html lists both Security Principles and Security Labels as current security module pages, and source/security.html now owns the break-the-glass anchor. OperationOutcome is an active FHIR resource in source/fhir.ini, and source/operationoutcome/list-OperationOutcome-examples.xml includes the break-the-glass example, so its embedded markdown link feeds a current example. Confluence Security WG minutes reference FHIR-53885 in the 2026-03-30 block-vote evidence path, while focused Zulip searches found no issue-specific or conflicting discussion.

AutoFHIR reconciliation:
Updated source/security.html so the Access Control considerations link targets security.html#break-the-glass, and updated source/operationoutcome/operationoutcome-example-break-the-glass.xml so the example description also points to the moved Security page section. No Break the Glass content was re-added to Security Labels, and no FAST Security wording was changed because the current wording already uses the proper IG name and non-version-specific links.

Recommendation:
Keep this source fix as-is. It completes the applied page move by removing stale references to the old Security Labels anchor; further core work is only needed if the Security WG later chooses a substantive redesign of the Break the Glass examples.
