FHIR-32293: Restore NutritionProduct ingredient summary example

Issue request:
FHIR-32293 was a Published FHIR-core NutritionProduct change request, resolved Persuasive with Modification for R5. It asked for better NutritionProduct examples, with the final OO motion and Jira resolution specifically including an ingredient summary in at least one example.

Initial application:
The issue was initially applied by the 2023-02-27 FHIR-32293 commits: 8ed86983840228391570c86c6963935fcffc6a49 added apple, nutritional shake, and peanut butter examples to the NutritionProduct examples list; f61dcd644596722f6aa5e53cada89de265691349 converted those examples to XML and included ingredientSummary in the peanut butter example; and 85071273a9f7103b63eb019433149af2f6c8da1a corrected example ids/references. The next-day QA reorder commit def9fb4121a90589bf9d3915a9c7bb0aa5a4c7c8 moved the same ingredient-label text from ingredientSummary into the generic note element, apparently because ingredientSummary was not yet part of the R5 NutritionProduct model.

Additional context:
FHIR-40094 later added NutritionProduct.ingredientSummary as a 0..1 markdown element for R6, with a peanut butter ingredient-label definition matching the text from the FHIR-32293 example. That issue is already represented on the combined branch by a no-change audit commit, and FHIR-53526 later reordered status before code in the examples without addressing ingredientSummary. NutritionProduct is active in source/fhir.ini, and source/nutritionproduct/list-NutritionProduct-examples.xml lists the peanut butter example as a current build example.

AutoFHIR reconciliation:
This commit restores the FHIR-32293 example intent against the current R6 model by moving the peanut butter ingredient-label text from NutritionProduct.note to NutritionProduct.ingredientSummary, placing it after nutrient and before ingredient in the current StructureDefinition order. This avoids teaching implementers to use a generic note for the textual ingredient summary now that the dedicated element exists.

Recommendation:
Keep this source fix. No additional FHIR-32293 source work is recommended unless the work group wants more NutritionProduct examples beyond the current general, apple, shake, peanut butter, high-protein enteral, and adult formula examples.
