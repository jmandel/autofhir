FHIR-48828: Remove remaining FHIR-I core profiles

Issue request:
FHIR-48828 was Applied/Persuasive with Modification for the FHIR-core profile list. It asked FHIR-I to decide which FHIR-I profiles still belonged in core; the final disposition removed actualgroup, example-composition, groupdefinition, and shareabletestscript, while retaining provenance-relevant-history with informative status, revised guidance text, an outdented Request relevant-history heading, and no separate mustSupport notes section.

Initial application:
ActualGroup and GroupDefinition had already been removed by upstream commit e72a7377005d09491d1e7a2c742db31f8d103ed4 under FHIR-41487. ShareableTestScript's source profile was removed when TestScript moved out of core in f9a44787c45071394532c7c2ee94d76f30f47387, but its StructureDefinition OID entry remained. Upstream commit 4961dcb9df16e3e7316d64a1062c5f5c5c7701d4 applied the provenance-relevant-history status, description, and must-support notes cleanup, but did not remove the still-active DocumentStructure/example-composition StructureDefinition source or stale profile OID rows.

Additional context:
FHIR-I minutes on 2025-06-09 record the final Persuasive with Modification vote and say detailed dispositions are listed in the Jira resolution. The earlier WGM minutes noted that Grahame's feedback was needed on where some profiles should move. FHIR-48829 is the closely related ProvenanceRelevantHistory retention decision and is already represented on the combined branch by an Issue-Reconcile-Key audit commit, so this commit does not decide it again. source/fhir.ini actively includes StructureDefinition as a built resource, so examples listed in source/structuredefinition/list-StructureDefinition-examples.xml and their StructureDefinition source files are build-scope inputs rather than inert files.

AutoFHIR reconciliation:
This commit removes the remaining DocumentStructure/example-composition StructureDefinition source from the active StructureDefinition examples list, deletes source/structuredefinition/structuredefinition-example-composition.xml, and removes stale OID rows for the removed example-composition and shareabletestscript profiles. It leaves the separate DocumentReference/example-composition resource example and example-section-library StructureDefinition example alone because they are distinct artifacts not named by the FHIR-48828 disposition.

Recommendation:
Keep this source-changing commit. The FHIR-48828 profile-list decision is now reflected in current core source: the named removed profiles no longer have active core StructureDefinition/profile source or OID rows, while provenance-relevant-history remains in core with the applied guidance changes. Do not create another FHIR-48829 commit; its retention audit already exists on the combined branch.
