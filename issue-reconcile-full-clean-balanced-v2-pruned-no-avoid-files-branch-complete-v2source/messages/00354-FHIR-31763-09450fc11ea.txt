FHIR-31763: Align ActivityDefinition subject prose

Issue request:
FHIR-31763 was Published/Persuasive for R5 by the CDS work group. It reported that ActivityDefinition.subjectCanonical was unconstrained even though its definition described only the same product-definition targets used by PlanDefinition, and resolved to update the allowed canonical references to match PlanDefinition.subjectCanonical.

Initial application:
Git commit 0667dac4d8 applied the structural part of the decision by adding the product definition targetProfiles to ActivityDefinition.subjectReference and limiting ActivityDefinition.subjectCanonical to EvidenceVariable. The active source prose and diagram tooltip still described the product definition resources as canonical-reference targets.

Additional context:
ActivityDefinition is an active, approved resource in source/fhir.ini. The later same-family PlanDefinition decision FHIR-37485 confirmed that non-canonical product definition resources belong under subjectReference rather than subjectCanonical. Community searches found no separate Zulip or Confluence discussion that changed the Jira/source interpretation for ActivityDefinition.

AutoFHIR reconciliation:
This commit updates the active ActivityDefinition StructureDefinition, matching mapping-exception metadata, and checked-in diagram tooltip so product definition resources are described as Reference targets and canonical subject references are described as limited to EvidenceVariable.

Recommendation:
Keep this commit as-is. It completes the FHIR-31763 application in the current source and keeps ActivityDefinition aligned with the PlanDefinition subjectReference/canonical split.
