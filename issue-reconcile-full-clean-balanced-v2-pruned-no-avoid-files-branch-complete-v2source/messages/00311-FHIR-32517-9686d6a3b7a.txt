FHIR-32517: Mark Provenance activity value set as example

Issue request:
FHIR-32517 was Published with resolution Persuasive with Modification. It asked that ProvenanceActivityType not remain an extensible value set, with resolution to change Provenance.activity to an Example binding, reduce the value set to representative ISO 21089 lifecycle examples, and update the value set narrative to make clear it is a sample and to point implementers to other potentially useful code systems.

Initial application:
The issue was initially applied in git commit cd1c06923912f70a88c90d186ff3283b40e0403b, which changed Provenance.activity from extensible to example and reduced source/terminologies/valueset-provenance-activity-type.xml to ISO lifecycle examples. That implementation left two authoritative terminology metadata remnants still saying the value set was extensible: the ProvenanceActivityType row in source/terminologies/bindings.xml and the valueset-extensible extension in source/terminologies/valueset-provenance-activity-type.xml.

Additional context:
source/fhir.ini actively lists provenance=Provenance, so source/provenance/structuredefinition-Provenance.xml is current build input. The current Provenance.activity element already has an example binding to http://hl7.org/fhir/ValueSet/provenance-activity-type, and the current value set description says it is an example FHIR value set of representative ISO 21089 lifecycle activity type codes. Later Applied issues FHIR-55798 and FHIR-55797 refined the value set description and added destroy without reversing the example-binding decision. The valueset-extensible extension definition says it marks whether a value set is intended for extensible binding, so retaining it contradicted FHIR-32517.

AutoFHIR reconciliation:
This commit changes the active ProvenanceActivityType terminology binding row from extensible to example and removes the valueset-extensible=true extension from source/terminologies/valueset-provenance-activity-type.xml. It does not change the already-correct Provenance.activity element binding, the current representative code list, or the later value set description.

Recommendation:
Keep this commit as-is. It completes the source-level application of FHIR-32517 while preserving later ProvenanceActivityType updates; no further core FHIR source change is recommended from this issue.
