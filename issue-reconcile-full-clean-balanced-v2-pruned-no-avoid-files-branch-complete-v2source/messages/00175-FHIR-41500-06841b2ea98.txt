FHIR-41500: Clarify MedicationStatement information source

Issue request:
FHIR-41500 was an Applied/Persuasive Pharmacy change request asking whether Device could be added to MedicationStatement.informationSource so a system that compiles a summary statement can be recorded as the source of the information.

Initial application:
The issue was initially applied by git commit 2daabbe269a4d53896cbf62a39f3a025581023e1, which added Device to the MedicationStatement.informationSource Reference target profiles in source/medicationstatement/structuredefinition-MedicationStatement.xml. The combined branch did not already contain an AutoFHIR Issue-Reconcile-Key commit for FHIR-41500.

Additional context:
MedicationStatement is an active build resource through source/fhir.ini. The current target profiles already include Device, and later related Pharmacy work added Group to the same element and added a separate MedicationStatement.author element after clarifying that informationSource remains the source of the information, not the author. The informationSource short and definition still said only "person or organization", which was stale once Device and Group were permitted target profiles.

AutoFHIR reconciliation:
This commit updates the authoritative MedicationStatement.informationSource short and definition to say "Who or what" provided the information. It leaves the already-correct target profiles unchanged and avoids adding duplicate narrative elsewhere.

Recommendation:
Keep this source fix as-is. It preserves the applied target-profile change while removing contradictory element wording that could otherwise obscure the allowed Device information source.
