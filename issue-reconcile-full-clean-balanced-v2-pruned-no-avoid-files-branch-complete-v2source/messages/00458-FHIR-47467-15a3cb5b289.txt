FHIR-47467: Add R5 resource diff links

Issue request:
FHIR-47467 is an Applied/Persuasive FHIR-I R6 ballot issue asking that Resource Content version-diff tabs not point only at R4, because R6 should also compare against the last published release, R5. The recorded resolution said to do this near final publication and noted that mapping/conversion pages are maintained separately.

Initial application:
The Jira-tagged commit dbb78e2435 removed scattered R4 Conversions links from datatype/resource cross-link blocks as part of the mapping-page cleanup. Later non-Jira QA commits renamed the tab from "R4 Diff" to "Version Diff", added r5-r6 change metadata in source/fhir.ini, and created global diff-r5.html/diff.html R5 comparison pages. However, the active resource and interface templates still rendered only R4/R4B XML/JSON links in each resource's Version Diff tab.

Additional context:
FHIR-I minutes for 2024-11-25 record the 10-0-0 Persuasive motion and explain that the work was deferred until final publication because the comparison work is large. Current build output already generates per-resource R5 diff artifacts and R5-to-R6 diff content, so the remaining source problem is stale link/navigation prose rather than missing comparison data.

AutoFHIR reconciliation:
Updated the active resource-page templates in tools/templates/template.html and tools/templates/template-intf.html so both the tab view and All view link to R5, R4, and R4B XML/JSON diff artifacts. Updated the special Resource/Meta source notes in source/resource/resource-notes.xml to stop saying "Changes since Release 3" and to point the reader to the Full Difference page for R5, R4B, and R4 comparisons. These files are in current build scope: the templates feed resource/interface pages, and source/fhir.ini has an active resource=resource entry for source/resource/.

Recommendation:
Keep this source fix. It completes the applied issue by aligning resource-page diff navigation with the generated R5/R6 comparison artifacts; no related Jira issue needed a separate decision from this bounded investigation.
