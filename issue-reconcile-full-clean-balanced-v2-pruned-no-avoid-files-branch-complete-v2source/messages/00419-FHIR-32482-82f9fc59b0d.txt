FHIR-32482: Correct Medication status definitions

Issue request:
FHIR-32482 was a Published Pharmacy change request, resolved Persuasive with Modification for R5, asking that Medication status definitions stop implying stock availability. The accepted wording changed active, inactive, and entered-in-error so they describe whether the medication record is current and appropriate for reference in new instances.

Initial application:
The issue was applied in git commit 934e7819020c72ee6e3ba509ecb5445a1850f109, a multi-issue Pharmacy commit that changed source/medication/codesystem-medication-status.xml from availability wording to record-currentness wording. That application captured the intended active definition but left two applied-text defects: inactive said "is not is appropriate" and entered-in-error said "not appropriated". Later status-code metadata commits did not correct those definition strings.

Additional context:
Medication is an active current-build resource in source/fhir.ini, and source/medication/codesystem-medication-status.xml is the local CodeSystem feeding the Medication status ValueSet bound by Medication.status. Pharmacy WGM minutes for May 2021 record the same decision: Medication.status is not about availability; the Medication.status element description was good; the value descriptions should be updated. Jira and Zulip searches found no later conflicting decision for this status wording.

AutoFHIR reconciliation:
This commit updates the authoritative Medication status CodeSystem definitions to match the accepted Jira/Pharmacy wording: active is "current", inactive is "not current" and not appropriate for new references, and entered-in-error is not appropriate for new references. No neighboring Medication.status element narrative was changed because the minutes explicitly said that description was good and the defect was in the status value descriptions.

Recommendation:
Keep this source fix as-is. It is a narrow correction to the active terminology source, completes the published FHIR-32482 wording, and avoids broader Medication.status narrative churn that the Pharmacy minutes did not request.
