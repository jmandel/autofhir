FHIR-19345: Remove stale Process resource references

Issue request:
FHIR-19345 is Published/Persuasive for Financial Management and requested removal of the ProcessRequest and ProcessResponse resources, addition of comparable Task examples on the Financial Management page, and Financial page documentation explaining Task use for the former ProcessRequest/ProcessResponse business purposes.

Initial application:
The issue was applied in November 2018 by GF #19345 commits. Commit bbc5d920 added Financial Module Task documentation and Task financial examples. Commit 0a36b9b0 added the financial Task code/input terminology and adjusted the examples. Commit 642e610a removed ProcessRequest and ProcessResponse from active build metadata, hierarchy, resource list, workflow pages, and status-code metadata. Current fhir.ini keeps ProcessRequest and ProcessResponse only in removed-resource/commented historical entries, so the resource definitions that remain under source/processrequest and source/processresponse are not active current-build resources.

Additional context:
Current active source still had two artifacts inconsistent with that removal: the active Resource Guide order-management table linked processrequest.html and processresponse.html as Present resources, and the active Task example list repeated the display label "Cancel a preauthorization" for the poll, release, reprocess, status, and status-response examples, with the reprocess description also copied from the cancel example. FHIR-16924 and 2018 workflow minutes support the same conclusion that ProcessRequest/ProcessResponse should not remain as current resources, while a 2019 Zulip thread clarified that their use cases moved partly to Task and partly to RESTful query patterns.

AutoFHIR reconciliation:
This commit removes the stale ProcessRequest and ProcessResponse rows from the active Resource Guide and corrects the Financial Task example list labels/descriptions so each example advertises its actual Task business purpose. It intentionally leaves removed-resource metadata, old-type terminology, historical release notes, resource-name tracking, suppressed workflow warnings, QUICK historical model content, and out-of-build source/processrequest and source/processresponse files unchanged because those are historical/generated/reference artifacts rather than active current-resource documentation.

Recommendation:
Keep this commit as-is. The active resource list and Financial Module already reflect Task as the replacement; this cleanup removes the remaining current-spec contradiction and fixes the Task example index without reopening out-of-build historical artifacts.
