FHIR-34375: Clarify qualification status period handling

Issue request:
FHIR-34375 was an Applied/Persuasive PA change request for Practitioner asking to add a codified registration/license status under Practitioner.qualification, with a preferred binding to a new qualification-status value set. The final resolution also said the status concept overlaps with period, specified the inactive-status period interpretation, and noted that the change should also consider Organization.qualification.

Initial application:
The explicit source application in 8a72f002f103699cbac8522fbdddadb120b4812f added Practitioner.qualification.status, Organization.qualification.status, the qualification-status CodeSystem, and the qualification-status ValueSet. The follow-up 16b7d8a91a8357943f8e39bcb52b8ee768fb8b85 added standards-status metadata to the terminology. Before this reconciliation, the current source still omitted the requested Practitioner.qualification.period comment, left Organization.qualification.period without matching guidance despite using the same status value set, and carried a broken Practitioner.qualification.status definition phrase from the original application.

Additional context:
Practitioner and Organization are active core resources in source/fhir.ini, so their StructureDefinition XML files are current build inputs. PA September 2023 minutes reference FHIR-34375 and record the persuasive resolution, preferred binding, and passed motion. Later FHIR-55302 and FHIR-55309 propose moving qualification-status terminology to THO, but those issues are only Resolved - change required and do not supersede the current core source obligation for FHIR-34375 in this default Applied/Published reconciliation run.

AutoFHIR reconciliation:
Added the inactive qualification status period interpretation comment to Practitioner.qualification.period and Organization.qualification.period, preserving identical semantics for the shared qualification-status binding. Also corrected Practitioner.qualification.status so its short text and revoked/cancelled period sentence match the intended and Organization wording.
