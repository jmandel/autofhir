FHIR-16861: Clarify CodeSystem content-mode wording

Issue request:
FHIR-16861 was a Published/Persuasive STU3 vocabulary issue asking to replace confusing CodeSystem content-mode terminology binding wording, especially the "How much" phrasing for codeSystem-Content, with clearer extent-based wording.

Initial application:
The issue was applied in SVN revision 14733, represented in git by e3e436ef84433dfd4b6472d5e1435ef6d7a86de1, which changed source/codesystem/codesystem-spreadsheet.xml from "How much of the content..." to "The extent of the content...". That application removed the quantity-sounding wording but kept the plural verb "are represented" with the singular subject "extent"; later source refactors carried that text into the current XML source, and FHIR-28499 copied the CodeSystem definition and binding description into TerminologyCapabilities.codeSystem.content.

Additional context:
CodeSystem and TerminologyCapabilities are active resources in source/fhir.ini, and the current CodeSystem XML, content-mode CodeSystem/ValueSet descriptions, and TerminologyCapabilities XML all contained the same grammar problem. The checked-in SVG class diagrams also exposed either the old "How much" text or the copied singular/plural mismatch in their titles. Related Jira searches found no later final decision superseding this wording, and quoted Zulip/Confluence searches found no conflicting community context.

AutoFHIR reconciliation:
This commit changes the active XML definitions and binding/value set descriptions to "The extent to which ... is represented..." so the wording keeps the issue's intended meaning while fixing the remaining grammar problem. It also updates the companion SVG titles for CodeSystem and TerminologyCapabilities so the checked-in diagrams do not continue to display the pre- or partially-applied wording.

Recommendation:
Keep this commit as a narrow completion of the published FHIR-16861 correction. No separate FHIR-28499 reconciliation commit is needed here; that issue only explains why the same CodeSystem content-mode wording also appears in TerminologyCapabilities.
