FHIR-53025: Align ImagingStudy procedure narrative and diagram

Issue request:
FHIR-53025 was an Applied/Persuasive R6 Imaging Integration change request to revert FHIR-50894, which had moved the performed-procedure relationship from ImagingStudy.procedure to ImagingStudy.partOf. The accepted resolution requires ImagingStudy.procedure to reference the performed Procedure resource, with matching detailed definitions, notes, search parameter expression, and example usage.

Initial application:
The Jira-linked PR HL7/fhir#3729 applied most of the change through commit 235456643091f44f295a33d4e307de5c945fb7b9, replacing ImagingStudy.partOf with ImagingStudy.procedure in the active StructureDefinition, procedure search parameter, XR example, and Event mapping exception. Follow-up commits 4ee338d0947581a6c88706c8a12810b29c733412 and 4bfa3ce24d7cfa48173d629089b208711d521d25 further adjusted the Event mapping exception. However, the implementation left the Imaging Study Procedures note saying the procedure was something the study was "part of", and the active ImagingStudy SVG diagram still showed the removed partOf element plus the old CodeableReference procedure shape.

Additional context:
FHIR-50866 established the nearby DiagnosticReport rationale for keeping a procedure element to identify performed procedures, while FHIR-50894 temporarily moved ImagingStudy performed procedures to partOf before being explicitly reversed by FHIR-53025. FHIR-52026 later corrected the requested-procedure side of the same notes section to ServiceRequest, leaving the performed-procedure sentence as the remaining stale source. source/fhir.ini actively lists imagingstudy=ImagingStudy and assigns imagingstudy to the ii work group, so the ImagingStudy notes and SVG diagram are in current build scope.

AutoFHIR reconciliation:
Updated source/imagingstudy/imagingstudy-notes.xml so the performed procedure is described as the Procedure referenced by the imaging study's procedure element. Updated source/imagingstudy/imagingstudy.svg to show ImagingStudy.procedure as Reference(Procedure), remove the stale ImagingStudy.partOf row and old CodeableReference procedure row, and close the resulting gap in the active diagram.

Recommendation:
Keep this commit as the reconciliation for FHIR-53025. No additional core source changes are recommended for this issue; the remaining Procedure-related history is background or already reflected in the current source.
