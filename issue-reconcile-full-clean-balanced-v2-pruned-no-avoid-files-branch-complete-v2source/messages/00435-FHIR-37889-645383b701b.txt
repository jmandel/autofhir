FHIR-37889: Remove leftover NamingSystem terminologies bundle

Issue request:
FHIR-37889 was a Published/Persuasive R5 Vocabulary change request asking that the Terminology and Identity System NamingSystem example bundles at namingsystem-terminologies.html and namingsystem-registry.html be removed because they duplicated content authoritatively maintained in HL7 Terminology and could become misleading.

Initial application:
Commit 76c99d3aae applied the issue by deleting the contents of source/namingsystem/namingsystem-registry.xml and source/namingsystem/namingsystem-terminologies.xml, but it left both files as empty Bundle resources. Commit ededc6fc84 later removed the empty registry file for FHIR-40117, leaving source/namingsystem/namingsystem-terminologies.xml as the remaining source artifact from the FHIR-37889 bundle pair.

Additional context:
The NamingSystem resource is active in source/fhir.ini, so files in source/namingsystem are in the current build scope. The current NamingSystem examples list no longer references the terminology or registry bundles, and source/namingsystem/namingsystem-registry.xml is already absent. Vocabulary minutes from 2022-08-15 record FHIR-37889 as resolved with a recommendation to delete the page, and FHIR-40117 records the later conclusion that the empty registry file should not exist at all. Zulip and Confluence searches found no conflicting community decision.

AutoFHIR reconciliation:
Deleted source/namingsystem/namingsystem-terminologies.xml, the remaining empty Bundle source file, so the current source no longer carries either of the removed NamingSystem bundle examples.

Recommendation:
Keep this source-changing reconciliation as-is. It completes the published FHIR-37889 removal using the same treatment already applied to the matching empty registry file under FHIR-40117.
