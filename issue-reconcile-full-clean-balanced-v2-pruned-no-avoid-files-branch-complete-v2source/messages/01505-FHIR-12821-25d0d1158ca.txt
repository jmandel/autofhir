FHIR-12821: Use no-dialect starter languages for communication

Issue request:
FHIR-12821 was Published with a Persuasive with Modification resolution for DSTU2. It requested splitting the existing language guidance so spoken/understood communication languages, specifically Patient and Practitioner communication, could use a common language value set that excludes dialect tags while preserving the broader all-BCP-47 required binding.

Initial application:
The explicit implementation was svn revision 14493, now git commit 747f0b7cd9e26f4d74436f87f55e5a73d1009fe9, which added source/terminologies/valueset-written-languages.xml and registered it in source/fhir.ini. That application did not update Patient.communication.language or Practitioner.communication.language, leaving both starter additional bindings pointed at the dialect-inclusive http://hl7.org/fhir/ValueSet/languages value set.

Additional context:
The current build scope includes Patient and Practitioner as active resources and written-languages as an active value set in source/fhir.ini. The current written-languages value set description says it does not include dialects, and current source contains no hyphenated regional language tags in that value set, while Common Languages still includes regional variants. FHIR-18803 later corrected only the written-languages description typo and is already represented on the combined branch; no Zulip or Confluence evidence was found that supersedes the Jira/source conclusion.

AutoFHIR reconciliation:
This commit changes the Patient.communication.language and Practitioner.communication.language starter additional bindings from ValueSet/languages to ValueSet/written-languages. The required binding remains all-languages, preserving valid BCP-47 language tags while making the starter/common list match the no-dialect value set created for this issue.

Recommendation:
Keep this source change as-is. It completes the bounded Patient and Practitioner adoption requested by FHIR-12821 without broadening the change to later resources or generated diagrams.
