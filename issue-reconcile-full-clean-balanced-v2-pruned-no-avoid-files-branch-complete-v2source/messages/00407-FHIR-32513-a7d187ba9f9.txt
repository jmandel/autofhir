FHIR-32513: Align Procedure implant example with device action value set

Issue request:
FHIR-32513 is an Applied/Persuasive FHIR-core Procedure issue. It requested replacing the overly broad SNOMED CT intensional Procedure deviceAction value set with an enumerated set containing only 129336009 Implantation, 278312000 Reattachment, 282089006 Replacement, and 129303008 Removal.

Initial application:
The Jira comment links GH commit 1c3625010a99e556dceb214ccadaedd0819dcdd8, which changed source/procedure/valueset-device-action.xml from an is-a filter under SNOMED CT 129264002 to the four enumerated SNOMED CT codes. That applied the value set itself, but the active Procedure implant example still coded Procedure.focalDevice.action with the old local http://hl7.org/fhir/device-action code "implanted".

Additional context:
source/fhir.ini lists Procedure as an active resource and approved artifact, and source/procedure/list-Procedure-examples.xml includes procedure-example-implant, so the example is in current build scope. Procedure.focalDevice.action has a preferred binding to http://hl7.org/fhir/ValueSet/device-action, so an implant example should use the requested SNOMED CT implantation code when that exact concept is present. The standalone local device-action CodeSystem remains outside this issue's requested value set change; this commit does not remove or reinterpret it.

AutoFHIR reconciliation:
This commit changes source/procedure/procedure-example-implant.xml so Procedure.focalDevice.action uses SNOMED CT 129336009 with display "Implantation" instead of the old local device-action/implanted coding. The value set source was already correctly enumerated, so no value set hunk was needed.

Recommendation:
Keep this commit as-is. It completes the applied value set correction across the directly related active Procedure example without broadening the scope to terminology cleanup or unrelated Procedure tracker work.
