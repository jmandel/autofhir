FHIR-38841: Add topic and jurisdiction useContext values

Issue request:
FHIR-38841 was Published with a Persuasive with Modification resolution for R5 to deprecate MetadataResource.topic and CanonicalResource.jurisdiction and define a way to convey topic and jurisdiction through UsageContext, including formal usage-context-type codes and updates to the UsageContext values example value set.

Initial application:
The issue appears to have been applied in 49b86f8a69, which updated CanonicalResource, MetadataResource, and definition pattern source. Current source already marks MetadataResource.topic as deprecated and recommends useContext.code http://terminology.hl7.org/CodeSystem/usage-context-type#topic, but the prior application did not update source/terminologies/valueset-use-context.xml to include the requested topic and jurisdiction value sets.

Additional context:
UP-401 later implemented the topic and jurisdiction codes in the THO usage-context-type CodeSystem, and FHIR-39632/its reconciliation moved UsageContext code references to THO URLs. FHIR-48492 is a later Applied issue that reverses only the jurisdiction deprecation decision: CanonicalResource.jurisdiction is now intentionally active with authority-maintainer semantics, while useContext can still carry jurisdictions of use. ValueSet/use-context is in current build scope through the ConformanceUseContext binding in source/terminologies/bindings.xml and the UsageContext.value[x] example binding in source/datatypes/usagecontext.xml.

AutoFHIR reconciliation:
Added http://terminology.hl7.org/ValueSet/jurisdiction and http://hl7.org/fhir/ValueSet/definition-topic to source/terminologies/valueset-use-context.xml so the active UsageContext values example value set includes both value sets explicitly requested by the FHIR-38841 Jira comment. No change was made to CanonicalResource.jurisdiction because FHIR-48492 supersedes that portion of the R5 decision.

Recommendation:
Keep this commit. It completes the remaining FHIR-38841 core source omission while preserving the later FHIR-48492 jurisdiction reversal. No further core change is recommended for this issue unless a separate work group decision changes the topic deprecation policy.
