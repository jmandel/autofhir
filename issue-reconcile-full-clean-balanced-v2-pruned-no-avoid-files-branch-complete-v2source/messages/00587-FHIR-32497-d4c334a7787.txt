FHIR-32497: Fix PractitionerRole specialty qualification reference

Issue request:
FHIR-32497 is a Published/Persuasive Patient Administration change request for R5 asking PractitionerRole.specialty to stop being tautological, make the specialty role-specific, and add a usage note that general practitioner capabilities independent of role are represented by Practitioner.qualification.

Initial application:
The request was initially applied by git commit 3f289b0831, which changed the PractitionerRole.specialty definition to the requested role-specific wording and added the requested Practitioner.qualification comment. The active current build source is source/practitionerrole/structuredefinition-PractitionerRole.xml because source/fhir.ini lists practitionerrole as an active resource owned by PA.

Additional context:
Later Published/Persuasive issue FHIR-25033 intentionally replaced the FHIR-32497 definition and comment with broader wording distinguishing PractitionerRole.specialty from Practitioner.qualification, and PA minutes record both the FHIR-32497 vote and the later FHIR-25033 clarification vote. The later wording still carries the same rule-specific meaning, but the current source referred to the non-existent Practitioner.qualifications property instead of the actual Practitioner.qualification element. No directly relevant Zulip discussion for FHIR-32497 was found.

AutoFHIR reconciliation:
This commit preserves the later FHIR-25033 definition and explanatory comment while correcting the element-path reference in PractitionerRole.specialty from Practitioner.qualifications to Practitioner.qualification. It intentionally does not restore the older FHIR-32497 prose or change the short display, because the later PA decision supplies the current approved wording and the initial FHIR-32497 application did not change the short display.

Recommendation:
Keep this commit as-is. It is a narrow current-build correction that makes the FHIR-32497 usage note point to the real Practitioner.qualification element while respecting the later FHIR-25033 wording. Any desire to further revise the PractitionerRole.specialty short display should be handled as a separate work-group decision.
