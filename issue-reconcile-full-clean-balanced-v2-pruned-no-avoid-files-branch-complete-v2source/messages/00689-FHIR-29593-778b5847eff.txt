FHIR-29593: Clarify SHALL-NOT conformance expectation

Issue request:
FHIR-29593 was a Published/Persuasive FHIR-core Vocabulary issue requesting that the Conformance Expectation CodeSystem add a SHALL-NOT code/display, with the definition that support for the specified capability is prohibited to be considered conformant.

Initial application:
The issue was first applied by ffdf5bcf1e0e on the temporary CapabilityStatement2 source, adding SHALL-NOT with the requested prohibition definition. That CapabilityStatement2 source was later removed by 6e3572528e77. The active CapabilityStatement CodeSystem source subsequently received SHALL-NOT in f094b0ede945 for FHIR-40228, but that later application left the definition text malformed as "should not occur only in any circumstance."

Additional context:
The current build scope keeps CapabilityStatement active in source/fhir.ini, and the active conformance-expectation ValueSet composes all codes from http://hl7.org/fhir/conformance-expectation. The active source/capabilitystatement/codesystem-conformance-expectation.xml therefore remains the authoritative local FHIR-core source for this CodeSystem. FHIR-40228 and FHIR-44609 confirm later FHIR-I handling: SHALL-NOT belongs in the broader ConformanceExpectation code system, while CapabilityStatement-specific prohibition is expressed through the separate capabilitystatement-prohibited modifier extension rather than by using SHALL-NOT in the capabilitystatement-expectation extension.

AutoFHIR reconciliation:
This commit keeps the existing SHALL-NOT code and display, and corrects only the malformed definition so it clearly states that support for the specified capability/requirement is prohibited and should not occur in any circumstance.

Recommendation:
Keep this source fix. It preserves the applied SHALL-NOT concept while removing wording that could obscure the conformance meaning; any further THO canonical cleanup or Extension Pack changes should remain with the later terminology/extension issues rather than this FHIR-core reconciliation.
