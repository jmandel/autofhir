FHIR-34088: Expose common search parameter canonical URLs

Issue request:
FHIR-34088 was a Published/Persuasive FHIR-I R5 change request asking that canonical URLs for SearchParameter resources be visible without requiring users to inspect download files. The accepted resolution specifically called for canonical URL links in resource-page search parameter tables and in the common-parameters table at search.html#table for rows that are actual SearchParameters.

Initial application:
No source commit explicitly tagged with FHIR-34088 was found. Existing source and rendered output already covered adjacent parts of the request: the search parameter registry describes the canonical URL pattern, and resource search pages expose each SearchParameter canonical URL through the generated searchParamTable output. The hard-coded common-parameters summary table in source/search.html still lacked any canonical URL column.

Additional context:
source/search.html is the authoritative source for the built search.html summary table. SearchParameter is active in source/fhir.ini, and the Resource and DomainResource search-parameter bundles define the actual common SearchParameters that correspond to the summary rows. The generated current build uses canonical ids such as Resource-id and DomainResource-text, so the table should expose those canonical URLs while leaving search-control parameters without populated canonical URLs.

AutoFHIR reconciliation:
Added a Canonical URL column to the common-parameters summary table and populated it with links to the generated Resource or DomainResource search-parameter details for the actual SearchParameter rows. The search-control rows remain in a separate four-column table, so non-SearchParameter controls are not given blank or invented canonical URLs.

Recommendation:
Keep this source change as-is. If the publisher later generates the search.html summary from the SearchParameter bundles, this hand-maintained table can be replaced, but the current source now satisfies the FHIR-34088 resolution for the built common-parameters table.
