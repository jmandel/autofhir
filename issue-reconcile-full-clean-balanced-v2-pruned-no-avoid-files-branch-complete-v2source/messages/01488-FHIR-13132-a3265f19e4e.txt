FHIR-13132: Soften publish box backgrounds

Issue request:
FHIR-13132 was a Published/Persuasive FHIR-core change request asking to fix harsh color choices: the orange/gold version flag, blue-on-red footer links, and yellow side menus.

Initial application:
The issue was applied in svn revision 14598, now git commit 26b87b075e1b3a536e672ca38ac633d56831eeec, which changed the inline publication notices from gold to #ffefef, softened footer link colors, and changed the in-page table of contents color from #ffeb7e to #fffbe6. The current combined branch had no prior Issue-Reconcile-Key audit commit for FHIR-13132.

Additional context:
The site template now loads tools/html/fhir-pub.css through tools/templates/newheader.html. That stylesheet was introduced later in git commit e87fa1ae313b3ebc1514036064d589b66c624392 with gold backgrounds for p#publish-box-current and p#publish-box, reintroducing the exact publication/version flag color that the original application had softened. Current published FHIR pages use id="publish-box" with fhir-pub.css, confirming this stylesheet is a publication-surface input. FHIR-13636 shared the original svn revision but concerned icon contrast, so it was treated only as related background.

AutoFHIR reconciliation:
This commit changes tools/html/fhir-pub.css so p#publish-box-current and p#publish-box use #ffefef, matching the color chosen by the original FHIR-13132 application. It leaves the already-softened footer links, active fhir.css in-page TOC color, milestone/past publication colors, and unrelated icon changes untouched.

Recommendation:
Keep this commit as-is. It restores the already-approved non-substantive color correction to the current CSS-backed publication notice without changing semantics or reopening the separate icon contrast issue.
