FHIR-17069: Correct Bundle response history wording

Issue request:
FHIR-17069 was a Published/Persuasive STU3 correction for FHIR-core Bundle.entry.response. It reported that the response definition had been copied from request processing text and asked for wording that describes the results of the corresponding request in batch/transaction responses and the result information carried in history.

Initial application:
The Jira was applied in svn revision 14404, preserved in Git as 5fe1b30f925aa52214da30dfc72fd38bc8d79e36 ("GF#17069 - fix definition"), by changing the old bundle spreadsheet definition from request-processing wording to response/result wording. The current source migration carries that intended definition in source/bundle/structuredefinition-Bundle.xml, but also retained the original typo "where when returning history".

Additional context:
source/fhir.ini has an active bundle=Bundle resource entry, so source/bundle/structuredefinition-Bundle.xml is in current build scope. Later history/request/response decisions, including FHIR-17075, FHIR-19619, and FHIR-32011, refine related history Bundle behavior but do not supersede the top-level Bundle.entry.response definition. FHIR-53053 is only Triaged and concerns Bundle.entry.response.outcome, so it is not a final decision for this reconciliation. Zulip and Confluence searches found no contrary community record for the malformed phrase.

AutoFHIR reconciliation:
This commit corrects the retained grammar error from "where when" to "were when" in the authoritative Bundle StructureDefinition definition. It also updates the matching checked-in Bundle SVG title for the same active element so the rendered diagram hover text does not diverge from the corrected source definition. Historical tools/history release snapshots were intentionally left unchanged.

Recommendation:
Keep this source fix as-is. It completes the already-applied FHIR-17069 correction without changing the approved semantics; any broader rewrite of Bundle.entry.response.outcome text should wait for a final decision on a separate issue such as FHIR-53053.
