Issue request:
FHIR-16370 was a Published/Persuasive FHIR-core HTTP issue requesting that the JSON Patch link on the RESTful API patch section move from jsonpatch.com to the official RFC 6902 URL, matching the stability and authority of the XML Patch RFC link.

Initial application:

Additional context:

No Zulip or Confluence evidence was found that conflicts with using the RFC for this reference.

Recommendation:
Keep this source fix. It completes the stable-RFC-link intent of FHIR-16370 for the current patch section without changing the FHIR-29715 422 behavior or adding unrelated REST wording changes.
