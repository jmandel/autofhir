FHIR-32856: Align AllergyIntolerance description text

Issue request:
FHIR-32856 was a Published Patient Care R5 clarification, resolved Not Persuasive with Modification, asking to refine the AllergyIntolerance description from the older comma/"unique" wording to "Risk of harmful or undesirable physiological response which is specific to an individual and associated with exposure to a substance." The resolution explicitly left the period and rejected adding redundant negative-scope examples because the Boundaries/Misuse section already covers them.

Initial application:
The Jira comment points to commit a152978212, which added the J#32856 committee note and changed the root AllergyIntolerance element definition to the approved wording. That commit did not update the StructureDefinition.description metadata, and it did not update the static AllergyIntolerance example embedded in source/conformance-rules.html, so current source still exposed the old comma/"unique" text in those locations.

Additional context:
AllergyIntolerance is an active core resource in source/fhir.ini, and source/conformance-rules.html is linked from the current documentation page, so both changed files are in the current build scope. The 2021-06-24 Patient Care minutes referenced FHIR-32856 and match the Jira resolution record. Jira/Zulip/Confluence searches found no later decision that reverses the approved description wording. FHIR-32916 shared the original implementation commit but concerns AllergyIntolerance.recorder target profiles and already has a separate combined-branch audit commit.

AutoFHIR reconciliation:
This commit updates StructureDefinition.description to the same approved wording already present on the root AllergyIntolerance element definition, and updates the stale conformance-rules AllergyIntolerance example title and explanatory quote so current built documentation no longer presents the pre-FHIR-32856 wording.

Recommendation:
Keep this source fix as-is. It completes the original FHIR-32856 application without introducing the rejected negative-scope examples, and no further work-group review is indicated unless a future issue intentionally reopens the AllergyIntolerance resource description.
