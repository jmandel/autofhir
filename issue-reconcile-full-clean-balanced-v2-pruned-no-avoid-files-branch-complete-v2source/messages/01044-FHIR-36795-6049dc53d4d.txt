FHIR-36795: Align productStatus ModelInfo

Issue request:
FHIR-36795 is a Published/Persuasive with Modification OO change request for R5 asking that BiologicallyDerivedProduct.status use an Example binding rather than Required so implementation guides and profiles can add or subtract status concepts. The accepted resolution changed BiologicallyDerivedProduct.status to BiologicallyDerivedProduct.productStatus and changed the binding to exemplar/example.

Initial application:
The Jira comment links PR #1884 commit bf561c9, but that commit is a merge synchronization and the semantic local source application is commit aa60cb835a78d4f3d4fe017b04898aa62a1cbb02, "changed status to productStatus for FHIR-36795." That commit renamed the StructureDefinition element to productStatus, changed its datatype from code to Coding, changed the binding strength from required to example, and updated BiologicallyDerivedProduct examples. Later source changes preserved the productStatus Coding element and example binding, and current release notes state that .status was renamed .productStatus and now has an example binding.

Additional context:
BiologicallyDerivedProduct is active in source/fhir.ini and marked normative. The FHIR ModelInfo Library sidecar is also an active publication surface: the Library examples page links source/library/library-fhir-model-definition-content.xml as the FHIR model information file used by CQL tooling, publish.ini copies that content file, and source/library/library-fhir-model-definition.xml embeds the same payload. Confluence OO HCP minutes for 2022-04-18 reference FHIR-36795, direct readers to the Jira vote, and note that it was applied to the build. The companion productCategory binding issue FHIR-36799 is a same-change-family background issue already represented on the combined branch, so this commit does not decide or alter that issue.

AutoFHIR reconciliation:
Updated the active FHIR ModelInfo sidecar so BiologicallyDerivedProduct exposes productStatus as FHIR.Coding instead of the old status element typed as FHIR.BiologicallyDerivedProductStatus. Removed the now-stale BiologicallyDerivedProductStatus model type, conversion metadata, and FHIRHelpers ToString overload, and refreshed the embedded base64 payloads in the Library resources so they match their sidecar content files.

Recommendation:
Keep this commit. It completes the applied FHIR-36795 rename/type/binding change across the active ModelInfo publication surface without taking over unrelated BiologicallyDerivedProduct model drift or the already-audited FHIR-36799 productCategory issue. Any remaining BDP ModelInfo mismatches outside productStatus should be reconciled under their own Jira evidence trail.
