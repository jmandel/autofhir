FHIR-25031: Correct Base logical-model links

Issue request:
FHIR-25031 was Published/Persuasive for R5 and asked FHIR core to add a "base" type with no properties for logical models, avoiding inherited Element.id and Element.extension conflicts for CDA V3 Acts and the II datatype extension attribute.

Initial application:
No prior commit on the current branch or combined branch was tagged with Issue-Reconcile-Key: FHIR-25031. The issue appears to have been applied by the untagged 2019 commit cbdf7d1e55, which rebuilt the abstract type framework, added source/datatypes/base.xml, registered Base as an abstract infrastructure type in source/fhir.ini, and documented Base as having no properties or constraints. Later source also made Element and Resource specialize Base and updated StructureDefinition.baseDefinition guidance for logical models.

Additional context:
Zulip discussion before the Jira vote records the same design: logical models sometimes need to avoid inherited FHIR id/extension baggage, Base should have no elements, and CDA ANY would change baseDefinition from Element to Base. MnM minutes record the 2019-12-17 persuasive vote. The current source already contains the requested Base semantics, but two explanatory links around that guidance were misleading: the Base section linked "Logical Models" back to types.html, and the logical-model page swapped the Element and Base anchor targets.

AutoFHIR reconciliation:
This commit makes the narrow source fix needed for the current spec: source/types.html now links the Base logical-model sentence to logical.html, and source/logical.html now links Element to types.html#Element and Base to types.html#Base. The authoritative Base definition, fhir.ini registration, and StructureDefinition guidance were otherwise left unchanged because they already satisfy the Jira decision.

Recommendation:
Keep this source fix. It preserves the applied Base semantics and removes misleading navigation in the active type-framework/logical-model source pages; no additional FHIR core source change is indicated for FHIR-25031.
