FHIR-18407: Clarify ImplementationGuide narrative guidance

Issue request:
FHIR-18407 was Published/Persuasive for R5. The issue asked whether FHIR should set rules for narrative after noting that DomainResource narrative definitions said resource definitions may define clinically safe narrative content, and the final resolution was to note in ImplementationGuide that implementation guides might provide guidance about what should be included in narrative.

Initial application:
The issue was initially applied by e74e3bc65e9afeaf98a9ab002ca8c94710278077, which added the Roles of Implementation Guides section to source/implementationguide/implementationguide-notes.xml. That section included a human-readable-content bullet for narrative, but the bullet said "user of the narrative in the resources", leaving the intended "what content should be included" guidance ambiguous.

Additional context:
The current build includes ImplementationGuide as an active resource in source/fhir.ini, and source/implementationguide/implementationguide-notes.xml is the active narrative source for that resource. The general Narrative page and DomainResource text still explain that resource definitions and profiles may set narrative content expectations, but the Jira resolution specifically required the ImplementationGuide guidance. Bounded Jira, Zulip, and Confluence searches found no later or conflicting decision for this issue.

AutoFHIR reconciliation:
This commit updates the ImplementationGuide notes bullet to say that implementation guides often detail additional rules about what content should be included in resource narratives. This preserves the existing section while making the applied FHIR-18407 resolution explicit and correcting the ambiguous historical wording.

Recommendation:
Keep this source correction. No additional work is needed unless the work group wants broader narrative authoring guidance beyond the narrow FHIR-18407 resolution.
