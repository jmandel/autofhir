FHIR-26878: Complete current BackboneType datatype lists

Issue request:
FHIR-26878 was a Published/Persuasive FHIR-core technical correction asking that the BackboneType datatype lists be complete and consistent. The issue specifically noted that datatypes allowing modifier extensions derive from BackboneType and that source/types.html had an apparently exhaustive list missing entries that were present elsewhere.

Initial application:
The issue appears to have been applied in commit 5cbc14c7d0f361941099bf72066b75c3f74f6d4f, which added Statistic and OrderedDistribution to the source/types.html BackboneType list as part of broader R5 MnM work. Later R5 work removed OrderedDistribution and Statistic from that list when those datatypes changed, but subsequent active BackboneType datatypes were not added to either active list.

Additional context:
Both edited files are in current build scope: source/fhir.ini lists the affected datatypes in [types], maps the datatype pages through [type-pages], and maps BackboneType to the types page. Current active datatype spreadsheet rows show Timing, RelativeTime, Dosage, DosageDetails, DosageSafety, DosageCondition, ProductShelfLife, MarketingStatus, and ElementDefinition based on BackboneType. FHIR-50466 is a later Triaged issue about structure-table display of BackboneType inheritance, but it is unresolved and does not change the published requirement that these lists be accurate.

AutoFHIR reconciliation:
Updated source/datatypes.html and source/types.html so the modifier-extension/BackboneType lists enumerate the current active BackboneType datatypes. This keeps the two human-readable lists aligned with the authoritative active datatype source rows and removes a stale exhaustive-list omission.

Recommendation:
Keep this source fix. Future datatype additions or removals that change BackboneType inheritance should update these lists together, or replace them with generated content if the publisher gains a reliable macro for BackboneType descendants.
