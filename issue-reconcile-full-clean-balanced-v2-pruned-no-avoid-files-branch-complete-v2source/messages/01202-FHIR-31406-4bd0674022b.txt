FHIR-31406: Document suppressing inherited descriptive properties

Issue request:
FHIR-31406 was Published as Persuasive with Modification for R5. It asked FHIR-I to support deleting inherited, informational ElementDefinition properties in profiles by defining a boolean ElementDefinition-suppress extension for comment, requirements, alias, example, mapping, label, and code, and by updating snapshot generation guidance so the marked property is removed from the generated snapshot; for comment, the overriding value must match because comments can convey conformance rules.

Initial application:
