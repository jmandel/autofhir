FHIR-17802: Remove stale contained narrative prohibition

Issue request:
FHIR-17802 was a Published/Persuasive FHIR-core FHIR-I clarification for STU3. It reported that the contained-resource section said contained resources can contain narrative while the Narrative page still said contained resources SHALL NOT have their own narrative; the resolution said GF#13870 had removed the invariant and the remaining textual prohibition should be removed as a technical correction.

Initial application:
The GF#13870 application in commit a18a11e219deb516933a73c8edf8f8a460f45051 removed the references-page prohibition and added the current rule that contained resources can contain narrative but that their narrative is ignored when rendering the containing resource. The later GF#18483 commit 1e886ea379d2668be97b3aaf9b9c03a37c18a974 removed the exact Narrative page sentence cited by FHIR-17802, but the source conversion in 33b409a4b6d544598262f2f074ebb4b6dc466157 preserved a stale DomainResource.text comment saying contained resources do not have narrative.

Additional context:
DomainResource is an active infrastructure resource in source/fhir.ini, and the Narrative and References pages are active type pages. The active StructureDefinition/example profile also carried the same obsolete text in DiagnosticReport.text. FHIR-18483 is the same dropped-invariant family and confirms the WG intent to remove the Narrative page statement. FHIR-5344 is older DSTU1 history that made the no-narrative rule consistent before it was superseded by GF#13870 and FHIR-17802/FHIR-18483.

AutoFHIR reconciliation:
This commit removes the obsolete contained-resource narrative prohibition from source/domainresource/structuredefinition-DomainResource.xml and source/structuredefinition/structuredefinition-example.xml. It leaves invariant-test fixture copies alone because they are negative QA inputs, not current normative or example guidance.

Recommendation:
Keep this source fix. It aligns the active element comments and example with the current References guidance without reintroducing redundant narrative-page prose or changing unrelated invariant-test fixtures.
