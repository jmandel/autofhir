FHIR-8067: Align MedicationRequest wording

Issue request:
FHIR-8067 is a Published/Persuasive Pharmacy issue for DSTU1 MedicationPrescription. It requested changing the MedicationPrescription description from "instructions for administration of the medicine to a patient" to "instructions for administration of the medication to a patient," and the Jira resolution was Fix.

Initial application:
The issue was initially applied in svn/git commit ef67da50345c3f324ff27053b95b42e8a463184b, which changed the MedicationPrescription spreadsheet wording from "medicine" to "medication." In the current build, MedicationPrescription has become the active MedicationRequest resource; its StructureDefinition description already uses "medication," but the repeated MedicationRequest row in active medication narrative introduction pages still had the old "medicine" wording.

Additional context:
source/fhir.ini lists MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement as active resources in the Pharmacy work group, and notes the MedicationPrescription to MedicationRequest rename. Jira search found no later final issue changing this wording, and Zulip/Confluence searches found no discussion or work-group minutes that conflict with applying the same terminology correction to the current active narrative pages.

AutoFHIR reconciliation:
Updated the MedicationRequest description row in the active MedicationAdministration, MedicationDispense, MedicationRequest, and MedicationStatement introduction pages so the narrative wording consistently says "administration of the medication to a patient." No conformance definition change was needed because structuredefinition-MedicationRequest.xml already contained the corrected wording.

Recommendation:
Keep this source fix. It completes the originally applied terminology clarification across the current active MedicationRequest narrative surfaces without changing conformance semantics.
