FHIR-32530: Remove remaining SearchParameter XPath surfaces

Issue request:
FHIR-32530 was a Published/Persuasive with Modification FHIR-I R5 change request for SearchParameter. It asked to prevent SearchParameter.xpath and xpathUsage from becoming normative; the accepted resolution was to drop xpath, rename xpathUsage to processingMode, update descriptions to refer to expression rather than xpath, and revise spd-1 to depend on expression/processingMode rather than xpath.

Initial application:
The issue was initially applied in the FHIR-32530 pull-request merge 740be33565faee58584fe5e7d3a6018a56df0d5f. That history renamed the SearchParameter element to processingMode, renamed the search-xpath-usage CodeSystem/ValueSet to search-processingmode, updated generated search-parameter bundles, and added the R5 conversion mappings in source/fhir.ini. A follow-up commit ed66b703fa76e6c2b1c26921429e98fc20bbb0b4 fixed the primary SearchParameter.processingMode definition to refer to expression, but a merge-fix commit c8d7bfb94c0fee9083e9ef6002478133942bb678 kept the old xpath wording on the CodeSystem 'other' concept.

Additional context:
SearchParameter and Library are active current-build resources in source/fhir.ini. The FHIR and QUICK ModelInfo sidecar files are linked from the Library examples page and copied by publish.ini, so stale SearchParameter model surfaces remain build-visible even though the authoritative SearchParameter StructureDefinition is mostly correct. The linked Zulip discussion explicitly called out the 'other' code definition as needing the xpath reference removed. FHIR-34467 and FHIR-35974 later trimmed the processing-mode code set and are already represented on the combined branch, so they are cited here but not decided again. FHIR-41588 is a later Triaged technical-correction observation of the same stale xpath wording and is not final enough for a separate decision in this run.

AutoFHIR reconciliation:
This commit changes the Search Processing Mode CodeSystem 'other' definition from xpath to expression, removes SearchParameter.xpath and renames xpathUsage to processingMode in the active FHIR ModelInfo sidecar, updates the corresponding FHIRHelpers conversion, removes stale QUICK.SearchParameter.xpath from the active QUICK ModelInfo sidecar, and refreshes the embedded Library payloads that mirror the edited sidecars.

Recommendation:
Keep this commit. It completes the FHIR-32530 application across the remaining current-build SearchParameter terminology and ModelInfo publication surfaces without duplicating the already-published FHIR-34467/FHIR-35974 audit commits. Do not create a separate FHIR-41588 reconciliation commit unless that Triaged issue reaches a final Applied/Published workflow state and still needs independent audit.
