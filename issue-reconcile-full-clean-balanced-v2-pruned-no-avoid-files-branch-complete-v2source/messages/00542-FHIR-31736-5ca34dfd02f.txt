FHIR-31736: Clarify medication definition relationship from medications module

Issue request:
FHIR-31736 was Published/Persuasive for R5 and asked for stronger documentation explaining how clinical medication resources and Medication Definition resources, including MedicationKnowledge and medicinal product definition artifacts, are supposed to work together. The approved resolution was to improve the documentation.

Initial application:
The issue was initially applied in the source by commits 0da95fb4eb30f604cbb284f2cce3b13fccd82324 and 03e8dd570954e63cb3e8a4a808e14894b1b01984, which added the Medication Definition module's Relationship to Prescribing section and fixed the in-page link. The current source still contains that section and its diagram.

Additional context:
The Medication Definition resources and the Medications module are in the current build surface: source/modules-list.html links both modules, and source/fhir.ini lists Medication and the product definition resources as active resources. The Medications module still described the product definition resources only as a draft regulatory-registration set, which conflicted with the applied Relationship to Prescribing text that says the distinction is not regulatory versus prescribing and that the same defining information supports clinical, catalog, manufacturing, and regulatory contexts. Confluence BR&R minutes for 2022-02-10 record FHIR-31736 as Persuasive with the applied change approved 10-0-0. Zulip searches for the issue key and the clinical/regulatory medication-resource phrasing found no conflicting community discussion.

AutoFHIR reconciliation:
This commit updates the current-build Medications module paragraph that introduces the product definition resources. It removes the stale draft/regulatory-only framing, points readers to the Medication Definition module, and links directly to the existing Relationship to Prescribing section instead of duplicating the detailed narrative.

Recommendation:
Keep this source change. It preserves the already-applied Medication Definition guidance while ensuring implementers who enter through the Medications module are directed to the same clinical-versus-regulatory relationship guidance.
