FHIR-47283: Clarify subscription polling methods

Issue request:
FHIR-47283 was an Applied FHIR-core Subscriptions change request resolved Persuasive with Modification. It asked the Subscriptions Framework polling paragraph to stop saying events are observed using Bundles, and to instead say polling-based methods observe events using both search and history interactions.

Initial application:
The issue was initially applied in git commit 75068c1b9c7a78ed76359614adb95feb58a900f6, which replaced the Bundle/history wording with search/history interactions in source/subscriptions.html. That application left the sentence saying "a polling-based method" even though the approved resolution and commit subject identified multiple polling methods.

Additional context:

FHIR-I approved the subscription block vote containing FHIR-47283 on 2025-03-31, and PR HL7/fhir#3967 later carried the subscription-related source updates into the current branch.

AutoFHIR reconciliation:
