FHIR-31589: Correct ServiceRequest supportingInfo guidance

Issue request:
FHIR-31589 was an Applied, Persuasive with Modification Orders and Observations change request to clarify that ServiceRequest.supportingInfo is for existing clinical context, not questions or actions to be performed, and that orderDetail is the appropriate place for delivery instructions or questions to gather.

Initial application:
The Jira comment says the change was added through HL7/fhir PR 3125 commit 8ba996c. In this checkout, local commit 531e8fe561a24490cbb9215afaab132a25ecf2e2 applied the same wording to source/servicerequest/structuredefinition-ServiceRequest.xml, but the active ServiceRequest.orderDetail comment referred to a misspelled non-existent `supportingInformnation.element`.

Additional context:
ServiceRequest is an active resource in source/fhir.ini, while ProcedureRequest is retired/merged into ServiceRequest. The active ServiceRequest.supportingInfo element remains in the same build source and was later typed as CodeableReference(Resource) by FHIR-37355; FHIR-11181 is the earlier issue family member that introduced supporting clinical information on ProcedureRequest.

AutoFHIR reconciliation:
This commit corrects the active ServiceRequest.orderDetail comment to point to the existing `supportingInfo element`. It does not change the intended FHIR-31589 semantics; it removes the typographical artifact that made the current generated guidance point to no real element.

Recommendation:
Keep this source correction as-is. No work-group review is needed unless OO wants a broader wording change beyond correcting the element reference.
