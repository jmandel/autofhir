FHIR-32563: Add missing Device specification example

Issue request:
FHIR-32563 was Published as Persuasive with Modification for OO. It asked that Device.specialization.systemType have an example binding or example concepts, with the final motion to add the suggested specialization system type list. The requested IEEE 11073 MDC examples included Medication Monitor as partition:term code 8::4168.

Initial application:
The issue was partially applied before this reconciliation. Git commit 3932ce4be6 added a binding for Device.specialization.systemType and created source/device/valueset-device-specialization-systemtype.xml with most of the requested MDC concepts. Commit 5ffc19505fc corrected the Device specialization binding strength from extensible to example, and commit ac8c3aa2b3 renamed Device.specialization to Device.conformsTo and renamed the value set to source/device/valueset-device-specification-type.xml. That history preserved the requested binding but left the Medication Monitor concept out of the value set.

Additional context:
Device is active in the current build through source/fhir.ini, and the R4/R5 Device.specialization.systemType path maps to current Device.conformsTo.specification. The current StructureDefinition binds Device.conformsTo.specification to http://hl7.org/fhir/ValueSet/device-specification-type with strength example. OO Confluence minutes from 2022-04-04/2022-04-11 show the same communicating-devices sample list, including Medication Monitor 8::4168. FHIR-32564 is the adjacent Device.version.type binding issue and is already represented on the combined branch; FHIR-32409 is broader background but its final resolution did not supersede this issue.

AutoFHIR reconciliation:
This commit adds the one missing requested concept, IEEE 11073 MDC 8::4168 encoded as decimal 528456, to source/device/valueset-device-specification-type.xml. No other Device source changes were needed because the current element rename, example binding, and value set wiring are already correct.

Recommendation:
Keep this source fix. It completes the published FHIR-32563 example list in the current build-scoped Device source without changing binding strength, element definitions, or unrelated Device terminology.
