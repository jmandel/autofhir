FHIR-32947: Correct Observation stats example code system

Issue request:
FHIR-32947 was Published with resolution Persuasive with Modification for R5. The Jira asked to stop using the old Observation $stats example code system/value set reference, and the final OO decision said the examples should use the correct Observation Statistics CodeSystem.

Initial application:
The issue was applied through PR #2655. Git history shows commit 6acf45e308 changed source/observation/$stats-response.txt from http://hl7.org/fhir/observation-paramcode to https://www.hl7.org/fhir/valueset-observation-statistics in all eight example Coding.system values. That removed the obsolete observation-paramcode URL but left Coding.system pointing at a ValueSet rendered-page URL rather than the approved CodeSystem canonical.

Additional context:
The Observation resource is active in source/fhir.ini, and source/observation/operationdefinition-Observation-stats.xml includes $stats-response.txt as the response example for the Observation $stats operation. The local CodeSystem source declares http://hl7.org/fhir/observation-statistics as the CodeSystem URL, and the ValueSet source composes that same CodeSystem. OO minutes for 2023-02-03 confirm the approved action was to update the examples with the correct codeSystem and explicitly link the Observation Statistics CodeSystem page.

AutoFHIR reconciliation:
This commit updates all eight statistic component codings in source/observation/$stats-response.txt to use the CodeSystem canonical http://hl7.org/fhir/observation-statistics. This preserves the original applied intent while correcting the remaining semantic error in the example.

Recommendation:
Keep this source fix. No related Jira should be decided from this investigation; the THO-maintenance note in OO minutes was explicitly a separate future action and no current core-source change is needed for it here.
