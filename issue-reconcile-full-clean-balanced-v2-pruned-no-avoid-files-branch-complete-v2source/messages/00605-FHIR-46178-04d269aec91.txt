FHIR-46178: Fix Common Languages German designations

Issue request:
FHIR-46178 was Applied/Persuasive for R6 and asked FHIR-I to correct Common Languages value set typos, wrong English/base designations, and missing German translations, with the resolution to update ValueSet values where applicable and leave display-selection issues to tooling.

Initial application:
The source was initially applied by git commit 502f2d64666dccef3f8d18d4faeba79afc1b1751, which edited source/terminologies/valueset-languages.xml for FHIR-46178. That commit corrected the bs-BA English typo and added the requested German designations, but it also left three source-level German display defects: a leading space before Griechisch (Griechenland), Punjabi represented as the region name Punjab, and Slovakia represented as Slovakien.

Additional context:
FHIR-I minutes on 2024-08-19 record the ticket as concerning the Additional Designations and Language Displays table and note a tooling aspect, but the current authoritative ValueSet source still carries the wrong literal designation values. Later language-maintenance work, including FHIR-49796, reorganized the same value set and designation-use coding but did not correct these three German values. The source file defines http://hl7.org/fhir/ValueSet/languages and is referenced by current build inputs such as the search page and active StructureDefinition bindings.

AutoFHIR reconciliation:
This commit corrects only the remaining source defects in source/terminologies/valueset-languages.xml: el-GR German designation now has no leading blank, pa German designation is Punjabi rather than Punjab, and sk-SK German designation uses Slowakei rather than Slovakien. No English display changes were made because the seed decision did not require changing the long-standing English Slovakian labels.

Recommendation:
Keep this commit as-is. It completes the source portion of FHIR-46178 while preserving the separate tooling/display-selection concern noted by FHIR-I; no additional core source follow-up is needed for the inspected Common Languages values.
